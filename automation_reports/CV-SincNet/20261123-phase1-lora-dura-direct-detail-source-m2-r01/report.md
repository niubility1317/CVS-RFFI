# LoRa 双信道直接复谱系数先导

## 训练与对照

上轮等剂量结果显示，直接把 R17 已有修正投影到可重复子空间会吞掉有效细节，而把配对 clean 的实际修正投影到同一空间能保留大部分三城区收益。本轮学习基底系数，并从拟合开始使用最终复谱修正及逐带剂量约束。[配对方向对照](../20261123-phase1-lora-dura-repeatable-detail-source-m2-r01/report.md)

Full 与 residual 分别加载已经冻结的 96 维源基底、各自的门控和实际复响应半量／门控 R69 基线。仅从本路线的源 U 读取 clean 与两份同物理 practical。每台源机固定 600 包拟合、另 100 包波形留出。候选输入为当次接收 IQ、冻结基线和 R17 提议在同一接收同步坐标下的复谱，推理无需 clean 或第二份观测。仅替换 1–8 kHz、9–32 kHz 两段修正的方向，逐 chirp 保留 R17 新增修正的原范数，保留带外、载波和门外波形。目标是配对 clean 去载波复差，并使用同一逐带范数约束。

每条信道两头使用相同源批次、32 轮优化、batch 128、AdamW 3e-4、相同两层 512 宽主干初始化。自由头输出两带全部复系数，受约束头只输出 96 个冻结基底系数，且配对目标以同基底投影后匹配剂量。基底限制归一化前的方向，逐 chirp、逐带的剂量匹配会改变最终波形的线性子空间归属。两头按各自参数独立裁剪梯度。留出波形报告原 R17、两头及配对投影能达到的归一化误差。留出仅相对于本轮新头，冻结祖先曾使用原源 U。拟合与波形留出均无 F、TX 标签、源 V 或目标访问。

## 冻结测试与发布

另固定 1,000 个源 V 包，每台源 RX 200 个，同一批包回放两路线。该面板与最近三轮 R17 锚定、门控效用和可重复投影的评价子集互斥。比较直通、现有基线、原 R17 新增修正、自由头、受约束头，以及受约束头和 R17 方向平均后重新匹配同剂量。使用相同冻结 Tri-set 2026092702。每条路线的全部七景预测提交后才读 V 标签，报告 clean、六景和低城区、逐 RX 正确数及配对区间。只有能同时改善各路线六景和低城区并保护 clean 的候选才考虑扩大正式验证。最终目标仍是原 15 台未见 RX、30,000 包、同一冻结三种子和原验收线。

运行 ID `20261123-phase1-lora-dura-direct-detail-source-m2-r01`。N607 普通账户、既有环境及独立只写一次发布根，入口 `python -m experiments.pamf_lora_main.direct_detail_source publish`。GPU 3、6、2、0、4、1、5 按已核实容量分配，同卡同 run 一条，最多两路并行。真实基线、匹配基底、源样本和有限训练梯度 smoke 通过才进行正式拟合。数据不匹配、训练或预测非有限、剂量不一致或不完整评分时停止该轮后续派发，保留现场。输出两份冻结双头模型、源训练与留出波形读出、七景预测和两份源评分。
