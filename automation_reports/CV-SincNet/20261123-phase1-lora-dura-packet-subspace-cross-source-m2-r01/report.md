# LoRa DURA 公共和独有复谱的同剂量交叉置换

## 源域实验

上一轮 residual 的精确公共、精确独有修正单独分别使六景少 125、395 次正确，联合增加 365 次。因子化学习虽把独有方向拟合得更准，全量读出仍下降。现在用已经冻结的两路线因子化和同容量对照权重做交叉置换，分开检查公共方向、独有方向和两者的相对幅度，顺便评估无需真值的混合头能否复现改善。

沿用每路成熟门控和当前物理包的真实载波跟踪坐标。补偿每条 chirp 的归一化尺度后，按每条 chirp 实际功率权重计算每个频点的公共分量，并取各条剩余偏差作为独有分量。按 1–8 和 9–32 kHz 分别做匹配。两个分量在恢复到实际接收 IQ 的度量下正交。固定分解学习版的每包每段实际修正量和两个分量各自实际幅度时，分别只用精确公共方向、精确独有方向、两者方向。另保留学习方向，引入真实幅度比例，维持原每段合计功率。零方向的退化情况使用原方向。带外完全保留。信号参考来源是原模拟接收扣掉新增噪声，已知方向、幅度和精确扣噪只用于源诊断。

无需真值的混合头在相同范围把同容量不限制模型的公共方向匹配到分解模型的公共剂量，保留分解模型的独有分量。学习原版和混合各保留一条半量。另有按原父版剂量的精确联合与精确扣噪。总计十二种读出、七景。训练参数更新为 0。两路使用同一 900 个源 V 物理包、五台源机各 180，避开原分解和同噪声扰动评分面板。使用同一冻结 Tri-set 2026092702。全景预测写入后再独立使用源 V 标签，复核逐接收机、逐场景和配对正确数。正式目标仍为同一冻结三种子、15 台新接收机、30,000 个物理包，六景至少 67.0%、低城区至少 53.0%、clean 至少 64,490/90,000。
