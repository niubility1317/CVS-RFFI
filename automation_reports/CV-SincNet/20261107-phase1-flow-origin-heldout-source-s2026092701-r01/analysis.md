# 流恢复起点覆盖的源域留出对照

以固定 DURA 源上下文的前 384 个物理记录各三个视图训练，两臂都固定五轮、batch 32、相同初始化、记录顺序和优化器；不同的只有均匀时间与 0.5 概率采样起点。后续 128 个互斥源记录的三个视图仅用于本次评估。起点覆盖臂 5760 次源视图曝光中有 2887 次采到起点；均匀臂为 0 次。N607 的真实 DURA checkpoint 无 query 源检查、本机 GPU 的真实源上下文检查通过。未读取 F、TX 标签、V 或目标，不保存权重。
