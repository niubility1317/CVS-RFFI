# 独立大容量时频恢复网络：训练后源域诊断

独立时频网络仅以 received IQ 推断，训练期间未读取 DURA、TX 标签、F 权重或输出、V 和目标；训练结束后才使用冻结 DURA 进行源域对照。固定 20 轮训练完成，首轮源 IQ 损失 0.299041，末轮 0.170472。
