# LoRa 三种子原生 Full 与 Residual 正式矩阵

来源为 300 包的独立双路线源域评分。相同固定 40,000 步 W24 DURA 在 Full 和 Residual 六景分别较直通净增 43 和 20 次，clean 均为 297/300。两起单种子盲测另已归档。正式运行使用同一份冻结 G 权重、源门限 0.06148705、中心半量更新及原生边缘保持规则。三份 F 使用登记的星地增强 W24 模型种子 2026092701、2026092702、2026092703，源域训练配方、验证选模和冻结回执不变。中间种子固定原 E104。正式运行无需新训练、校准或按目标条件选臂。

沿用已登记的 15 台未见接收机和各 2,000 包的盲采样顺序。两个接收路线分别为 `full_native` 与 `native_residual_w24_v1`，每路 clean 加六景。所有读出共享当前接收波形和各自种子相同的冻结识别器。Full 固定对照为原冻结半量 DURA 和原复响应半量，中心窗写回规则沿用原生 Full 已登记实现；Residual 固定对照为历史 39,520 步的 R69 门控半量，使用已经验证的六窗提取与中心内侧写回。两个路线都包括直通。旧 Tri-set 指标和 256 kHz 六窗正式成绩按原登记保留。

每条路线有三个分片，各管五台互斥接收机。每份接收 IQ 和每次恢复只计算一次，再交给三个冻结 F。先用实际三份 F、冻结 G 和原 DURA 对照在源 U 上执行无目标检查。全部六个分片预测固定且逐包 clean 直通跨路线完全一致后，独立本机评分再打开官方发射机标签。按每种子、路线、场景、接收机和合并口径报告正确数、净纠错、改对改错，按接收机分层从物理包重抽 1,600 次，并保留同包跨种子和跨景关联。方案报告列出 Full 六景 67%、低强度城区 53%、clean 至少 64,490/90,000、两路相对各固定对照提高并保持 clean 的逐项判定。Full 六景距本方案 clean 不超过 3 个百分点另列作进一步目标。保留未通过行。

N607 普通用户。入口 `python -m experiments.pamf_lora_main.w24_formal publish`，固定当前提交、精确命令、数据、CWD 和输出根见登记。等待原训练终点至多两小时，之后按实际 GPU 余量优先 0、5、3、4、2、7、1、6，源冒烟等待 GPU 至多 30 分钟。最多两个在跑的本轮预测工人，每个 8 个 CPU 信道工人。数值、来源、无目标冒烟、形状、失联或矩阵闭合失败时保留当前输出和状态。预期 `smoke.json`、六份冻结分片回执与预测数组、本机 `scores.json`。根目录单一、不可覆盖。

## 正式预测启动

三份星地增强 W24 源域冻结权重均已独立读回，种子 2026092701、2026092702、2026092703 分别冻结于 E108、E104、E112。N607 的真实权重无目标检查通过。双路线已进入正式预测，首分片分别由 GPU 0 和 GPU 3 的 worker 执行。控制进程和本机独立收集评分进程均存活。该阶段尚未产出正式分数。

## 恢复器资源

新 W24 DURA 共有 1,271,038 个参数，源域训练循环 40,000 步耗时 13,976.25 s（约 3 小时 53 分钟）。同一权重在 N607 RTX 3090 上以固定受扰源包测得 B1 激活恢复中位数 63.19 ms、P95 67.15 ms，共 30 次。计时包含设备同步，信道生成与识别器分别运行。节点同时运行其他实验。 [源包时延记录](../20261125-diagnostic-lora-w24-native-residual-source-s2026112559-r02/report.md)
