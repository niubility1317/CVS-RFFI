# 多解耦源域反事实诊断：随机前向混杂已实证

**三个原始 E200 纯 CE 父模型的全量 L_s 诊断均完成，状态 VERIFIED。旧动作损失和 keep 约束存在可测量的随机前向混杂。** 这解释了约束的一个实现问题，不能据此断言修正后必然达到 84%，也不能把上一轮测试差异全部归因于它。

## 范围与证据

- Run：`20261011-phase1-stage2-counterfactual-source-manysig-m3-r01`；执行提交：`3e3e8064f2114bc8ef9af78119137051c32f57b7`。
- 每 seed 全部 6,300 个原有有标签源域物理 ID，固定原父权重和 L/T 动作网络；无 U_s、目标域或 V 前向，无优化器、无参数更新。
- 每 seed 固定 12 个批次测量编码器 E 的梯度，其余样本保留完整前向标量分布。梯度结论不外推为全部训练步的分布。
- 独立读回三行完成产物、逐进程 GPU 分配与日志；所有参数、buffer、前向缓存、模式、grad 和 RNG 恢复检查通过。每卡总进程上限为 4。
- 完整分层 JSON 位于本 run 的 `evidence/sSEED_audit.json`，包括 TX、RX、TX×RX；不导出逐样本 IQ。

同一 IQ 两次独立 train 前向的 margin 差值均值接近零，但 RMS 为 2.60 至 2.70。单边正部损失截掉负值，因此零均值噪声仍产生正损失。父缓存使用 eval，学生初始使用 train，导致 keep 在模型尚未变化时已经广泛触发。已核对实际身份路径有 13 个 Dropout，无 BatchNorm，branch-drop 与 MixStyle 关闭；这里的 train/eval 差异与该配置中的 Dropout 相符。

零干预确定前向不仅损失为零，36 个梯度探针的零动作梯度也全部为零。不能只把增强侧设为 eval，必须让约束两侧都使用相同确定前向；普通 CE 的 Dropout 可以保留。

## 下一版已明确的修正

1. 为 keep、动作比较和 R 关系建立确定身份前向，保留梯度；普通 CE 仍使用原 train 路径。相同输入必须产生零变化损失。
2. 动作目标从恢复全部高置信 margin 改为修复有限分类风险：达到固定源端风险阈值后停止加压，避免对已足够可分样本持续扩大 margin。阈值及损失规则必须在下一版训练前固定，不能用目标测试调整。
3. R 不再将所有 TX 的接收条件效应压为同一标量 margin。先评估跨 TX 的低维父表示条件差分，并用父缓存控制变量减少 8 包关系估计噪声；留出验证不通过的方向不给身份网络施加约束。
4. 保留原父权重继承、三 seed、每方案 40 epoch、同预算 CE 对照、每卡最多 4 进程和冻结后自动 clean 测试。诊断不替代下一轮正式训练。

## 当前完成边界

本 run 只完成源域机制诊断，没有产生新身份 checkpoint 或新测试成绩。性能目标仍为三 seed clean 均值至少 84%，当前未达成。历史实验的完整回顾见 [多解耦回顾](../../../docs/CVS_MULTI_DISENTANGLE_RETROSPECTIVE_20261011.md)；后续机制只使用本次与既有源域证据，不以历史目标成绩选参数或选择性重跑。
