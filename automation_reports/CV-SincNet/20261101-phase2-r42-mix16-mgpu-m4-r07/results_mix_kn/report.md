## R42 的 query 恢复和融合效果

自然 query 补集、K5/N20 下，R42 的 672 单元平均宏 H 如下；括号为相对同一 support 下 raw query 的变化。

| support | raw query | 仅 DURA query | raw+DURA 融合 query |
|---|---:|---:|---:|
| raw | 57.86% | 55.84%（−2.02pp） | 61.53%（+3.67pp） |
| DURA | 52.20% | 68.02%（+15.82pp） | 66.02%（+13.82pp） |

跨全部 16 个 K/N 格，support 为 raw 时，仅 DURA query 在 8 格高于 raw query、8 格低于；融合在 16 格均高于 raw query。support 为 DURA 时，仅 DURA query 与融合都在 16 格高于 raw query。这些是 R42 自身不同 query 路径的比较，不是与 LocalRidge 的同输入配对收益。

- [逐格性能与四 seed 样本标准差](kn_metrics.csv)：旧类、新类、宏 H、macro-F1、类别最低召回。

- 汇总表 `mean_gain_at_least_5pp` 是逐格 672 单元均值是否达到 +5pp；`units_gain_at_least_5pp` 是单元级达到 +5pp 的数量。
- 融合 Q2 没有原版同输入基线；融合相对原 raw 和原 DURA 的比较分别标为跨输入。单元级收益与 pool/RX/MIX/day/TX 全量聚合另存私有分析目录，保留原始精度。
