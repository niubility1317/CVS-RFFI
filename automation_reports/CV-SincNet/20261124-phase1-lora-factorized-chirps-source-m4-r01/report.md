# LoRa 公共复谱与逐 chirp 独有谱联合恢复

## 预登记

上一轮方差区间在两条路线都未超过匹配 DURA。隔离计量显示，低城区的留一残差在 9–32 kHz 可提供有效去噪方向，1–8 kHz 的候选残差同时含相当比例的原有 chirp 差异。本轮让公共非载波分量可以借用其他 chirp，给真实逐 chirp 变化保留独立的复数自由度。 [上一轮识别结果与留一计量](../20261124-phase1-lora-variance-envelope-source-m4-r01/report.md)

从当前六条 256 点实收前导得到逐条载波旋转、RMS、相干度和去扫频谱。两臂使用相同的外带噪声功率与包内正负频点的差异能量，构造四带中心方差。各源 RX 从拟合源 U 取 100 个 clean 物理包，共 500 包。逐频点按包内样本方差估计独有复谱功率，再从跨包公共均值方差中扣除独立成分的有限样本影响，得到非负公共功率。统计量与接收机身份脱钩，共存储 4,096 B。

粗恢复与细化网络产生同结构复谱中心。对于每个频点，给定公共随机量 S、逐 chirp 私有量 D 和当前噪声方差，收到的残差被表示为 S＋D＋噪声。联合臂先将私有量边缘化，对公共量按每 chirp 的私有加噪声方差做精度加权后验。再分别根据当前观测和公共后验计算私有后验。正则化后的两个复量同时写回原去扫坐标，原载波系数保留。独立臂在每条使用相同总方差及同一网络，其他 chirp 不提供此后验的共有协方差。冻结后另做三种归因，在同一联合权重上取消耦合或仅交付总修正的平均／零和分量。纯工程读出以源 U 固定复数均值为中心。

多 chirp LMMSE 已用于优化发射前导和链路 CSI 估计。这里沿用既有 LoRa 发射前导，在收端用合法 clean IQ 估计公共与私有波形的方差，优化的是待冻结识别模型读取的复 IQ。与单一幅度谱收缩不同，该估计可以据其他 chirp 的不同相位和噪声精度校正指定 chirp 的复值。仅在实际配对消融后判断独立作用。 [LoRa 多 chirp 估计原论文](https://doi.org/10.1109/JIOT.2024.3363170) · [信号子空间原论文](https://people-ece.vse.gmu.edu/~yephraim/Papers/sap%201995%20sig%20subspace.pdf)

两臂均从零端到端优化，254,735 个可训练参数，3,600 步、batch 12 和两个独立扰动视图及一个同扰动弱谱成对视图。仍用 5,000 合法拟合 U（其中 500 用于计算复谱统计）、2,500 clean 门限、500 留出 U。通用受扰为半概率仅加性噪声与半概率叠加短复回波，匹配上一轮的扰动和损失。训练、统计估计及冻结隔离识别器、V、TX、真实噪声、实际算子和目标。

先进行一次真实权重无 query smoke。冻结后，两路线在同一批 900 源 V 物理包、同一 Tri-set 2026092702 下完成七景共 13 个读出。独立 CPU 只在两路预测都固定后接合标签。逐路、逐景、逐 RX 报告净纠错、95% 物理包区间、clean、训练和 B1。同一预登记端到端读出在两条路线六景均超过匹配 DURA 且保持 clean 才能晋级。 [实验登记](experiment.json)

## 留出源 U 的公共谱与独有谱保真

另做五折隔离。每折用其他四台源 RX 各 100 个实际源 U clean 包估计协方差；在被留出 RX 的 100 包上分别注入通用加性噪声或短回波，并以同一接收旋转和 RMS 对齐配对参考。这里比较纯工程后验，未运行学习提案、部署门限或识别器。五折的源先验中，1–8 kHz 的公共方差占总方差 98.55% 至 98.73%，9–32 kHz 为 85.40% 至 95.92%。频带统计按来源只用于本节。

轻加性噪声下，1–8 kHz 公共复谱相对误差从独立后验的 0.1343 降到联合后验的 0.0381，真实分量增益中位数从 0.752 升至 0.979。宽加性噪声中公共谱误差从 0.4377 降到 0.3271，但联合工程后验的独有谱真实增益中位数只剩 0.0034，独立后验为 0.1548。宽噪声加回波时，公共谱误差从 1.3047 升至 2.8539。联合后验对加性噪声的优势与对原有独有谱、公共回波的处理能力需要分别检验。未读取 F、V、TX 标签或目标。当前训练保持预登记方案。 [各带幅相与误差](source-u-factorized-covariance.json) · [隔离脚本](source_u_factorized_covariance.py)

## 私有复谱是否具有可重复的跨 chirp 结构

同一五折以合法源 U 拟合各频点的完整私有复协方差。私有协方差向相同迹的零和各向同性结构收缩 15%，公共功率与上一节保持相同。比较两者作为纯工程估计器时的幅相，不改变训练。五个源折中，1–8 kHz 私有谱的前两特征方向合计占 66.2% 至 69.5% 的能量。有一定可重复结构。Clean 直输工程求解时，加入结构的私有误差从 0.446 降至 0.389。宽加性噪声下仅从 0.99408 降至 0.99385，真实私有增益中位数从 0.00345 到 0.00328。单独给私有先验增加协方差的表达能力，仍无法从高扰动中找回弱私有复值。这个结果来自源 U 的工程估计，不用于选模，也无 F、V、TX 或目标读取。 [复协方差隔离计量](source-u-structured-private.json) · [复现脚本](source_u_structured_private.py)

## 私有复谱能否从相邻频点获得证据

在同一五折、同一组留出波形上固定公共分量，只替换私有复谱的 1–32 kHz 后验。对照使用源 U 独有复谱的逐频方差，候选使用匹配的跨频复协方差并向相同对角收缩 15%。在宽加性噪声时，1–8 kHz 的私有复谱相对误差由 0.99339 降到 0.98585，绝对夹角中位数从 0.649 降到 0.375 rad，真实分量增益中位数由 0.00384 到 0.00784。宽噪声加回波时，近载波误差从 0.99389 降到 0.98663，实际增益仍低于 0.01。跨频统计保留了可重复的相位信息，恢复幅度仍然很小。这个对照无模型训练更新、F、V、TX 或目标访问。 [私有复谱各带结果](source-u-private-frequency.json) · [复现脚本](source_u_private_frequency.py)

## 冻结模型的公共与私有幅相验证

在相同 500 个留出源 U、相同通用扰动、同一接收同步坐标下读取两组最终权重。按冻结旁路全量计入，每个条件分母为 500 包。Clean 触发 0 次，轻噪声 334、宽噪声 459、轻噪声加回波 338、宽噪声加回波 467。四个非载波频带都计算公共和私有的复误差、实际信号方向增益和复夹角。无 F、V、TX 或目标访问。

在宽加性噪声下，1–8 kHz 私有谱相对误差由独立半量的 2.497 降到联合半量的 2.288，真实增益中位数从 0.722 到 0.769。含宽噪声和回波时，联合半量的私有相对误差从 2.418 降到 2.178，但公共相对误差从 2.286 升至 2.590。以同一联合权重关闭耦合，在后一条件下公共误差为 2.200、私有误差为 2.405。实际学习提案与半量读出避免了纯工程私有谱近乎完全收缩，回波条件下的公共谱仍是薄弱环节。 [冻结模型幅相计量](source-u-frozen-factorized-wave.json) · [复现脚本](source_u_frozen_factorized_wave.py)

## 固定权重下的耦合与逐分量归因

联合半量相对同权重关闭耦合，在 5,400 次受扰判定中分别改变 full 297 次、residual 833 次预测，净正确数分别增加 53 和 147。95% 同包区间分别为 [28,77] 和 [103,196]。按外带观测扰动划分，轻扰动层（门内至 0.15）贡献 43 和 135 次，其余中度和最高层合计贡献 10 和 12 次。保持相同总方差的结构变化在该组冻结权重上有可分辨的识别收益。与独立重新训练的半量相比，联合半量净变更为 ＋6、＋12，区间跨零。
