# LoRa W24 原生带外 IQ 条件恢复

N607 GPU 3 已完成两组各 12,000 步、冻结、Full 源域七景预测及独立评分。原生带外组未达到正式晋级条件。 [预登记](experiment.json) · [运行状态](events.jsonl)

## 匹配试验

两组是从零训练的 405,991 参数整包时谱网络，使用相同初始化、随机波形流、源包、批量 8、AdamW 余弦日程和损失。两组只改变三个输入观测量的来源。窗内组用去扫 W24 中心的局部复残差和对数能量。原生组用 1 MHz 实收和 33 点 Hamming 高通的残差，每个中心位置汇总相邻四个原生样点的复均值及局部对数能量。输入用当前接收跟踪坐标。最终仍以原冻结预处理得到的 W24 IQ 为基准，只回写中心窗差量，两侧各 24 个原生点保持。三个真实源包的归一化跟踪窗与冻结预处理中心最大差 3.58×10⁻⁷。

每组训练 12,000 步，拟合池 16,000 个合法源 U_s 包，固定 160 个互斥 U_s 用于留出波形评测。每批含一个 clean 对，其余为合法同条源 IQ 的独立通用受扰配对。损失包括实出中心时间误差、近载波复谱、两个分支、边缘、跨 chirp 差分、半量频谱误差和显式 clean 恒等。冻结前 W24、TX、V 和目标访问均为 0。冻结后登记半量及全量中心差量，300 包 Full 源域同包七景在全部预测固定后单独评分。

最终原生带外组的 clean 恒等波形误差比窗内组低约 79%，W24 clean 两组同为 296/300。包级能量排序的优势没有转化为带外半量的识别净收益。精确方向和局部能量的隔离诊断降低了把带外复残差作为替代局部观测的依据。
