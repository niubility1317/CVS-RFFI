# WiSig 实收前导锚定的联合截窗恢复

[预登记矩阵](experiment.json) · [实验状态](events.jsonl)

## 设计

输入为 Main split 既有 25 MS/s、256 点实收复 IQ。L-STF 的单周期为 20 点，标准时标下 L-STF 与 L-LTF 分界为第 200 点。时标估计在该坐标周围搜索 ±40 整数点。中心可见短前导的间隔 20 复乘积提供粗频偏，校正后的重复误差变化提供过渡证据。前导组额外计算实收短前导和当前候选下可见长前导与协议复波形的归一化相关。两组网络结构相同，重复组的两个波形相关输入置零。

模型前向选择一个时移并复制重叠段的接收坐标。训练反向采用候选概率的连续梯度，时标学习只由合法源 IQ 的重建误差驱动。两组都用同一份当前包在可见前导上的复增益和估计频偏外推缺失边界。未接收的边界只获得公开波形和当前包有效估计。后续联合粗层和细化读取对齐 IQ、边界掩码、预测残差与重复方差代理，输出有界复数修正。同一权重和门限用于两路线。

| 接收量 | 来源与计算 | 误差 |
| --- | --- | --- |
| 当前 IQ 及候选过渡样点 | 当前 256 点复 IQ，前导结束后可用。搜索由包内周期变化和可见模板支持。 | 长前导很短、重复有周期别名、超过窗口覆盖的位移无法由候选组表示。 |
| 粗频偏和有效噪声 | 可见短前导的间隔 20 复乘积和相位修正后差分能量的一半。 | 存在周期模糊，噪声代理包含波形失配、相关干扰与残余频偏。 |
| 可见前导复增益 | 每候选以公开复模板为基，分别在短、长前导求最小二乘标量响应。 | 是采集、信道和硬件的合成响应，高阶频率选择性会留下残差。 |
| 信心与旁路 | 最强时标分数与零位移分数之差，联合有效重复噪声。 | 波形相似的两个时移可能得分接近，强扰动可能破坏相关。校准仅用源 U。 |

## 训练与匹配对照

两臂各 18,085 参数、40,000 个 AdamW 更新、batch 24。WiSig 既有 U_s 中 52,092 包用于拟合、4,096 包独立校准、512 包固定留出。每次更新两份独立通用扰动，末三包保留两份 clean 身份映射。扰动独立于注册场景，在源波形上应用一般有色噪声、复增益、短回波以及可变截窗。边界扰动通用地混合反射和公开协议外推。合成位移、复增益、噪声参数和实际逐点噪声均不输出给候选。监督为合法源 IQ 的时域、频谱保真和同源扰动一致性，粗层、定位和细化连续联合训练。

每臂的旁路阈值由固定源 U 估计量的各自最大值乘 1.02 后再加 1e−6。有效噪声或时标置信差任一超过阈值时运行恢复，否则原样返回。固定记录两臂的仅时标、粗恢复、联合和真实旁路四类读出。用于比较的 R69 原权重有模拟作用和噪声方差的历史监督，当前运行只见实收 IQ；新候选从零训练，没有继承这些监督。

Schmidl 和 Cox 的接收同步使用重复前导识别时间和频偏。WiSig 发布方使用更长记录的前导做同步、长训练均衡及频偏回写。本方案在登记的短窗内只使用可见前导，时标在源 IQ 重建循环中学习。训练的可微候选选择与 Spatial Transformer 的条件采样思想相关；此处搜索轴受真实接收坐标约束，最终评估冻结设备识别。 [OFDM 同步原论文](https://doi.org/10.1109/26.650240) · [WiSig 原论文](https://arxiv.org/abs/2112.15363) · [WiSig 作者实现](https://github.com/WiSig-dataset/wisig-process-raw/blob/master/matlab_equalization/equalize_channel.m) · [Spatial Transformer 原论文](https://proceedings.neurips.cc/paper/2015/hash/33ceb07bf4eeb3da587e268d663aba1a-Abstract.html)

## 双路线冻结验证

在终步冻结后才加载 Main split Tri-SIG-TIME SSL seed 2026092701。两路线各同包复用原配对直通和 R69，验证固定的 1,800 个源 V 物理包。每路线 clean 和六种 practical 的全部预测固定后，独立 CPU 才读源标签。统计正确分项、低城区、逐景逐接收机、同包纠错和改错，以及估计移位与平均补齐样本数。前导组只有同一读出两路线都超过同次 R69 六景且保持 clean 才晋级。

评分后另在隔离的源波形诊断中，用同物理包的 clean 波形在 ±64 点范围求最大有效重叠复相关。该值是隔离时标参考，仍受传播相位和波形失配限制。分开统计时标估计误差、实际重叠区与边界的复波形误差，以及 0–6.25、6.25–10 和 10–12.5 MHz 三带的幅相。此诊断不读识别器、TX 或目标，也不供任何候选校准和选模。 [时标与幅相归因代码](../../../tools/wisig_anchored_window_audit.py)

## 训练及执行实测

N607 状态 VERIFIED，执行提交 a1e543247712004f9b1fe1616f201dec30835822。归档、远端编译、单步实源检查和独立 P0/P1 检查通过。重复组在 GPU 0 训练 974.04 秒，前导组在 GPU 1 训练 964.30 秒。两臂各 40,000 步，801 条有限值训练记录，每臂峰值 CUDA 分配 169.39 MiB。终步真实权重检查通过。单包前导组的旁路和通用扰动触发时延分别为 3.17 和 5.14 ms，每种输入计时 20 次，包含当前包定时及相应恢复，不含识别器。
