## 方法、成本和证据边界

SignedCovariance r01原模型/数据/单阶段30轮不变，只增加已授权GPU4常规容量路径，保留GPU6原继任路径。

All 1340293 learned G parameters scratch: 1230341 physical seed2026092701 and 109952 confidence seed2026092702. Exact zero initial covariance update; no old G weights.

Zero TX labels. Physical uses source simulator Action/noise; signed-mode CNN uses actual noisy paired IQ/STFT/original frozen F0 continuous features.

全部30轮/7410步、63000条每轮完整源排列、189000次L_s和1701000次U_s曝光已核实。最终权重逐值等于E30技术状态，源先验固定，模型/优化器有限，各参数头实际更新。源目标组成复算最大误差3.51e-09。训练期间F0前向行数1890000，完整source审计见training_final_audit.json。

实际训练阶段19865.736秒；epoch计时合计19852.496秒、均值661.750秒。两个预测阶段共4010.343秒。均为共享负载整阶段计时，含相应初始化/数据读取/真实源检查等成本，不是B1时延或独占提速倍数。

原Main两总体七景三流42单元全部固定后独立truth-last。再次复算全部1302组、868raw配对及DURA/clean配对，最大指标差1.2e-14，raw/DURA复用判决差0。公开CSV只包含聚合数据；各总体TX/RX/day/RX×day和macro-F1完整保留。combined_group_metrics.csv从互斥总体的混淆计数合并，不平均百分比。
