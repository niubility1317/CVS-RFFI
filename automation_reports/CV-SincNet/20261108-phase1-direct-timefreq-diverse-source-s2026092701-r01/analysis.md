# 源视图轮换独立恢复：冻结后源域对照

该独立网络使用固定 32768 条合法源 ID、每轮三个视图和 20 轮。首十轮依次读取 01–30 共 30 个已存在源模拟视图，后十轮重复相同顺序；训练记录为 20 组视图、19 次切换，目标网络和优化器保持连续。训练未读取 DURA、F、TX 标签、V 或目标。

固定第 20 轮后，与未轮换基线在同一个已探索源 pilot 上比较。两版拟合 ID 相同，pilot 的 672 条记录与拟合 ID 不相交；轮换版训练时使用过 pilot 所在的源模拟视图类型，但未使用这些 pilot 记录。每个源组每景 48 条。两版的源记录曝光量和更新步数相同，但输入视图不同，轮换版还需重复读取数据。
