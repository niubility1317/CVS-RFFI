# WiSig Main split 的边界与重叠区隔离归因

[预登记实验](experiment.json) · [执行记录](events.jsonl)

## 数据、读出与边界

固定 WiSig Main split 的 Tri-SIG-TIME SSL seed 2026092701、原 R69 v1.0 权重和已登记的同一批 1,800 个源 V 物理包。Full 和 residual 各覆盖 clean 与六景。输入为数据提供方已经均衡的 25 MS/s、256 点复 IQ 窗口。原软件用较长捕获的前导估计与均衡，名义裁窗包含完整短训练字段和长训练前缀。研究中的重叠区读出直接进入冻结识别器。 [WiSig 原论文](https://arxiv.org/abs/2112.15363) · [作者均衡实现](https://github.com/WiSig-dataset/wisig-process-raw/blob/master/matlab_equalization/equalize_channel.m)

隔离流程按同包 clean 估计整数移位，在原坐标保留真实重叠的接收样点。缺失后缀在已验证的协议范围内用 L-LTF 外推，其他缺失点沿用登记的反射填补。随后分别用 R69 的复 IQ 替换缺失边界、重叠区或两者。另在固定 R69 边界时，单独替换重叠区相位或幅度。配对 clean 边界及其加上拟合的全局复标量也单列。在原位测算 R69 相对于配对 clean 的残余对齐。R69 只作为冻结对照及隔离比较的波形来源。

诊断直接使用配对源波形及完整 R69 读出。生产候选的输入、拟合、校准和阈值皆未使用本诊断波形。无优化步和新增参数，目标读取为零。归档、远端编译、真实权重的四源包无目标检查均通过。执行提交为 `f7b1d663f6060685cefb31ac42a9ae4e6945caf3`。两卡分别固定 full 和 residual 的各七景预测，独立 CPU 后置真值评分完成。任务已结束，完成核验依据为发布记录、进程派发日志和实际冻结产物。两路重新生成的直通与原 R69 决策均逐样本吻合已有的同识别器归档。

## 源域冻结结果

所有读出的 clean 均为 1,775/1,800。六景分母 10,800，低城区分母 1,800。表内为正确数。

| 读出 | Full 六景 | Full 低城区 | Residual 六景 | Residual 低城区 |
| --- | ---: | ---: | ---: | ---: |
| 直通 | 9,057 | 1,081 | 9,062 | 1,085 |
| 原 R69 | 10,194 | 1,543 | 10,195 | 1,544 |
| 配对时标加协议/反射边界 | 8,952 | 1,079 | 8,959 | 1,083 |
| 只换 R69 边界 | 9,326 | 1,148 | 9,330 | 1,153 |
| 只换 R69 重叠区 | 9,953 | 1,483 | 9,956 | 1,485 |
| 换成配对源边界 | 9,484 | 1,210 | 9,492 | 1,217 |
| 配对源边界加整包复标量 | 9,817 | 1,338 | 9,820 | 1,340 |
| 固定 R69 边界，仅换重叠区相位 | 9,869 | 1,399 | 9,870 | 1,401 |
| 固定 R69 边界，仅换重叠区幅度 | 9,476 | 1,221 | 9,469 | 1,222 |

单做配对时标和缺边外推，六景相对直通净减 105 和 103 次，区间为 −180 至 −31、−180 至 −29。随后只换 R69 重叠区，六景净增 1,001 和 997 次，95% 同包区间 +931 至 +1,072、+928 至 +1,068。只换 R69 边界净增 374 和 371 次，区间 +314 至 +434、+312 至 +431。两个改动合用的交互差为 −133［−191，−77］和 −132［−189，−75］。这些值量化固定混合波形下的结果。

固定 R69 边界后，重叠区仅替换相位带来 +543 和 +540 次正确，区间 +476 至 +605、+474 至 +602。仅替换幅度带来 +150 和 +139 次，区间 +95 至 +206、+86 至 +193。两者合用的交互差为 +175［+111，+242］和 +186［+123，+255］。因此当前读出中的重叠区相位是较大的独立因素，联合幅相仍有额外收益。完整 R69 相对仅换重叠区还多判对 241 和 239 次。换真边界再配全局复标量的隔离对照距 R69 仍差 377 和 375 次。

两路低城区中，原始重叠经过配对时标对齐后的平方复相关中位数为 0.7081，R69 在原读出坐标与配对 clean 的中位数为 0.9785。R69 残余移位绝对值不超过 2 个采样的有 1,795/1,800 包。对齐与缺失点的实际分布仅记录在隔离诊断中。逐景逐接收机正确数、纠错、改错和各交互区间，在本机 `local_artifacts/20261124-diagnostic-wisig-main-overlap-source-m2-r01/readout` 的 `source-scores.json`、`predictions-complete.json` 和 `factorial-paired.json`。独立 CPU 已按接收机复核所有正确数。 [交互复核代码](../../../tools/wisig_overlap_pairing.py)
