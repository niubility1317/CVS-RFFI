# LoRa 私有谱方差保持收缩与冻结识别

## 预登记

前一轮测到包内顺序结构在 clean 有效，遇到实际新增噪声后其预测收益接近零。更早的同剂量消融表明，改动复数方向会显著影响识别。本轮固定同一秩四恢复权重、同一公共谱、同一细化中心及噪声估计，仅比较私有谱中沿相同正交模态的收缩增益。 [顺序特征噪声复核](../20261124-phase1-lora-order-noise-prior-source-cpu-r01/report.md) · [同剂量方向消融](../20261124-phase1-lora-private-dose-direction-source-m2-r02/report.md)

在同包六条去扫复谱上，以 Helmert 正交矩阵表示零和私有空间。把既有的逐 chirp 四频带实收方差估计投影到该空间。实部和虚部各使用复噪声方差的一半。每带分解一次 5×5 对称矩阵。令每个频点、每个 I/Q 坐标的合法 source clean 私有方差为 s，当前包对应模态的估计噪声方差为 n。匹配 Wiener 增益为 g=s/(s+n)，新读出为其平方根。两个读出用同一细化中心及相同模态，模态符号和相位保持。平方根读出在该局部标量高斯假设下把 s+n 的方差映回 s。沿同一正实方向放宽收缩可能同时保留噪声，严格检验识别。此处比较的是设备识别和物理 IQ。感知—失真研究提供的是分布保真与点重构权衡的参考。 [高斯线性估计和 Wasserstein 感知—失真原论文](https://papers.neurips.cc/paper_files/paper/2021/file/d77e68596c15c53c2a33ad143739902d-Paper.pdf)

四种新读出对两侧 1 至 64 kHz 的私有分量分别写回完整估计或与原观测的半量混合。公共谱、带外和 DC 均使用原秩四的半量，且共用相同 clean 旁路。完整私有读出可检验方差匹配的效果，半量读出控制整体扰动。冻结 F 只在预测阶段读取。源 U smoke 校验原秩四半量逐值一致、公共分量近似零改动、数值有限及实际冻结 F 链路。本轮不训练、调阈或使用目标；同一规则依照实收 IQ 和合法 F-free 的冻结合同应用两路。

固定 Tri-set 2026092702，源域两路使用同一 900 个物理包、clean 加六景；独立预测其余 11,100 个源 V clean。先闭合所有预测和物理包，再由独立 CPU 读真值。比较直通、匹配半量 DURA、原秩四半量、两种匹配增益各自的半量／完整私有。单个固定平方根读出须在两路六景均胜过实际匹配 DURA、保持主面板及完整 clean，才用该机制建设后续从零训练的正式候选。当前各行为冻结权重归因。B1 记录同次四个读出和父网络的总成本。任一来源、数值或预测闭合失效则停止后续派发。
