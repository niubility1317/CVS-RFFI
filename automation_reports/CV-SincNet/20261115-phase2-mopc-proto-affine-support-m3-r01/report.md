# ProtoNet→MoPC 仿射桥接候选诊断

ProtoNet 旧类负平方距离可写为 `2 z·p - ||p||² - ||z||²`。最后一项对全部旧类相同，数学上不影响旧类 softmax 与 argmax；原移植将其作为可训练的额外输入坐标，新增分类权重亦会作用于该坐标。候选在进入 MoPC 时去除这一坐标，旧类分数只相差共同偏移，不改变仓库 MoPC 损失或 SGD，也不采用梯度裁剪。候选改变了 C 阶段的特征维数和可训练模型，不能声称 C 训练或新类预测与旧桥接等价，也不能把两版结果静默混为同一方法。

GPU5 加载 clean 故障任务同一次保存的真实 B-K10、原 old/new 支持与原 seed；正式注册前逐样本检查原/候选旧支持的有限性、严格 argmax、中心化 logits 和 softmax，一项不符即失败。随后仅用新支持、公开仓库公式、无裁剪执行 N20 注册；不读取 query/truth、不生成预测。GPU6 对先前 paper 公式 seed1731 的已知合成非有限案例测试候选；GPU7 对公开仓库公式 N20 的合成 seed1731–1734 检查候选。合成输入与真实任务不同，不能据其声称真实根因；故障任务原产物保留。

每卡一进程，启动前至少 6000 MiB，避让其他 owner；各诊断使用独占 `runs/20261115-phase2-mopc-proto-affine-support-m3-r01/gpu{5,6,7}.log`。该候选尚未用于正式预测，且仅适用于 ProtoNet 桥接；对 DADDA 及其他 B 主干不推断同因或修复。
