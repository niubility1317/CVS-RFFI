# LoRa W24 弱相位探针经过匹配信道的训练对照

Run `20261126-phase1-lora-w24-probe-transport-s2026112991-r01`。N607 **VERIFIED / SOURCE_NOT_QUALIFIED**。两臂末步权重已冻结，Full 源域七景独立评分完成。 [实验登记](experiment.json) · [运行事件](events.jsonl)

## 可证伪假设

现有整包 U-Net 的保真训练把弱复数变化加到受扰观测。此对照检验，在模拟信道之前施加同一个弱相位探针，是否能提高经过扰动后的弱指纹传递及冻结 W24 的同包正确率。

两组使用同一份源域原损失 U-Net 的 24,000 步冻结模型权重，重置 AdamW 并各续训 12,000 步，batch 16，同种子 2026112991。每组用 20,000 个源 U_s 拟合、500 个互斥留出。祖先权重固定为合法源末步，恢复器拟合和冻结没有 W24、TX、源 V、目标观测或目标统计权限。固定权重文件只加载模型状态。

从对齐的源 IQ 提取带限弱相位差，映射至 1 MS/s 原始采样点，限制幅度在 0.16 rad 内并在各 chirp 原生端点衰减至零。乘性相位改变保持原始 IQ 幅度。两组共享同方法生成的干净探针参考与两份受扰视图。对照将干净探针造成的复差加到第一份受扰孔径。候选让探针 IQ 经过与第一份观测相同随机状态的通用扰动，回放独立生成器保持后续主采样流一致。仿真参数随随机状态共同确定，模拟器允许输入相关定标。两组取 2,000、6,000、9,000 和最终 12,000 步的同口径留出误差，均评估先施加探针再扰动的视图。

## 冻结测试

两组固定末步恢复器，分别生成半量及全量中心回写。E104 在冻结后执行 300 源 V 包的 Full 七景预测。直通、原长训 DURA、首尾 DURA 和祖先 U-Net 预测逐包核对。预测全固定后由独立过程连接源标签。半量候选六景必须严格超过固定对照，低城区达到最强对照，clean 达到直通，才启动 30,000 包正式 Full 三分片。所有目标预测固定后独立评分。正式正确数验收为六景 162,000、低城区 25,500 和 clean 28,566。

## 探针、波形与资源

在 80 个固定留出的源 U_s 包上，两种训练构造的 A/B 基础受扰孔径、干净探针参考和后续主随机流逐项相同。中心探针差异的 L2 范数除以对照探针范数，结果的中位数为 0.0032%，第 90 百分位为 22.77%。中心探针传递后的范数比中位数为 1。加性扰动下两种构造近似相同，主要差异出现在部分带相位作用的扰动。该核验只使用源 U_s，用于解释处理差异。 [探针物理对照复算](audit_probe_action.py)
