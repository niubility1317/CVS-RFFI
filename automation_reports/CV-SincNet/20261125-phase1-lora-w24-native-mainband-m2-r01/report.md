# LoRa 原生主带弱复谱保真消融

上一轮用分量重放发现，已知去新增噪声的低城区源 V 正确数从 144 增至 263/300。Wiener 虽准确估出噪声功率，但高郊区在 0–100 kHz 内保留 98.7% 总体有效功率时，单独重放该频带的有效信号改动便使 91/100 降至 33/100。本轮核查原生弱复谱约束能否在降低波形误差的同时保住冻结 W24 的识别。 [失真分解](../20261125-diagnostic-lora-w24-distortion-source-s2026112559-r01/report.md) · [分带证据](../20261125-phase1-lora-w24-native-wiener-pilot-s2026092702-r01/report.md)

两臂均用原生 1 MS/s 八 chirp、223,075 参数的两阶段恢复骨架，从同一初始化端到端训练。各 3,600 步、B6、AdamW 初始学习率 2e-4 余弦降到 2e-5、每第五步输入 clean 恒等样本。5,000 个已登记 U 包用于拟合，2,500 个不相交 U 包冻结一次共同门限，500 个互斥 U 包检验弱复谱保真。训练随机抽取与目标独立的通用有色扰动。两臂共用实收对齐、时频粗恢复、观测一致性细化及全局波形和原生接缝损失。主带臂额外用合法源 clean 暂定每条 chirp 相位坐标，从复谱减去八 chirp 均值后，对 0–100 kHz 内的逐频点复误差作局部能量归一化与对数压缩。粗恢复和细化对应权重为 0.03、0.15。源 clean 坐标只用于训练及隔离诊断，部署用当前包的原实收对齐。两组部署用固定半量，采样、门控和写回坐标相同。

源数据校准、拟合与冻结的 F、TX、V、目标读入均为零。部署不使用模拟器参数、真实信道作用、真实噪声、场景标识、接收机名或训练数据。与已完成的 256 点去扫复差方向约束相比，这次比较的是原生采样率下主带复误差对实际识别的影响。既有先验证据只支持启动匹配对照。 [既有方向约束消融](../20261124-phase1-lora-private-secant-source-m4-r01/report.md)

两臂冻结后用 4 个源 U 包做有限值和真实识别器无目标检查，再测已登记 Full 的 clean 加六景。15 台未见接收机各按固定种子 2026112572 无放回抽 200 个包，总计 3,000 个物理包。预登记读出为相同增强 W24 E104 直通、已冻结既有复响应半量、匹配普通训练半量、主带保真半量。两臂均进入独立测试。主消融为主带半量减普通半量，引用逐景、低城区、clean、逐 RX 与物理包分层 95% 区间。直通与已登记完整盲预测相同物理索引重配。所有预测冻结后独立评分。此为单种子 Full pilot。

N607 普通用户，模块入口 `python -m experiments.pamf_lora_main.w24_mainband publish`。优先选可用 GPU 2、7、4，至多两卡，每卡一个本次 fit 工作者。有一张可用卡时顺序执行，双臂都冻结后一个目标预测 worker。CPU 信道并发 8。出现数据权限、checkpoint 契约、非有限数值、无目标检查或预测闭合故障时停止下游并保留产物。预期记录为 `calibration.json`、两臂 `steps.jsonl`、`G.pt`、`frozen.json`、`smoke.json`、预测矩阵和独立评分。
