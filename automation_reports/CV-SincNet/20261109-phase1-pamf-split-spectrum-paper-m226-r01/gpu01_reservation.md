# 释放 GPU 0、1

2026-11-10 用户明确要求两组 PAMF 实验都不再占用 GPU 0、1，并选择尽快停止这两张卡上属于两组的当前任务，接受未完成阶段重跑。范围限 `20261109-phase1-pamf-split-spectrum-paper-m226-r01` 和 `20261109-phase1-pamf-no-reference-completion-m190-r01`。其他 owner 的进程保持不变。

各队列以独立控制目录接续，禁止新任务派发到 GPU 0、1，其他 GPU 的并发限制保持既定数值。交接只对经 PID、工作目录、完整命令、GPU 和独立进程组核实的目标任务发送停止信号。停止前、停止后均检查原完成产物；已完成的行不重复运行。

未完成的训练／预测行保留原目录、权重片段和日志，在独立的 `-gpu01-r01` 输出目录重新排队。新配置保持原数据、模型、种子和训练预算，下游预测／独立评分依赖指向对应的新输出。既有资源不覆盖；不在目标数据反馈下选择或重排实验。每次中断前后保存单行日志和状态，技术故障保留可恢复交接记录。

实际释放状态以远端 GPU、进程和控制器的独立读回为准；不能只凭停止命令或控制器返回值宣称释放成功。
