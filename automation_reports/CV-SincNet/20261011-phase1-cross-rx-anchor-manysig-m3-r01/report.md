# 原E200跨RX身份锚点诊断

状态 LOCAL_VERIFIED，未启动。三种子2026092701/02/03分别加载对应原E200权重；身份网络冻结，0次更新，不读取target。此诊断与当前续训/压缩实验并行，不改变健康任务。

已完成的源域图诊断发现95.56%至95.98%邻居来自同RX。为了区分真实跨RX身份支持与同RX局部结构，本诊断只使用6300条L真实TX拟合锚点。每个RX分别取32近邻，温度0.07，比较原模型、同RX锚点、5RX等权、排除同RX的4RX等权、模型与跨RX各半混合，以及仅当4RX全部同类且均值最大概率≥0.95时混合。全部固定读出均报告，U不提供TX、不根据UID索引构造配对。

固定两种距离：原归一化身份表示cosine，以及L类内协方差收缩白化后的cosine。后者用每类L均值计算类内残差，协方差为0.9*S_w+0.1*trace(S_w)/p*I，特征右乘其逆平方根后再归一化。它是诊断身份相关距离的工具，不是创新性或真正物理可辨识分解的声明，也不训练第二骨干。

所有锚点和矩阵仅由L拟合，随后在56700条U记录无标签分布/跨RX一致性，在27000条V记录准确率、四档覆盖错误、修复/破坏、RX/day/TX分层。V不拟合任何状态。模型state_dict前后逐值一致。父模型已见全部5个源RX，因此本实验是排除同RX锚点的源域诊断，不是真正未见RX泛化。

来源、源域角色与物理ID使用现有已验证契约，父权重完整来源经verify_parent核对。不加载任何E40变体，不用压缩实验选择的权重，不访问测试成绩。每卡最多3总进程，唯一launch owner，输出独占。完整配置见experiment.json。

本地检查覆盖：同RX标签改变不会改变跨RX读出、会改变同RX读出；单条查询与分批查询一致；查询不更新拟合状态；两种距离都得到有效概率。独立P0/P1审查通过后发布。
