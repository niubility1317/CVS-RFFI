# 三专家与蒸馏单专家：源域 GPU 时延

固定源域训练得到的三专家和蒸馏单专家，112 条合法源 pilot IQ，相同输入并交替测量执行顺序；固定 DURA 与两个修正网络均为 eval。GPU 7、FP32/TF32 off、每次计时前后 CUDA 同步，源输入已在 GPU。每个模型和路径在每种 batch size 测量前预热 5 次；B1 测量 112 个配对 batch，B8 测量 28 个配对 batch。未读取 F、TX 标签、V 或目标。

修正网络参数分别为 351301、117062；包含同一 DURA 后分别为 618252、384013。中位数比值是两个聚合中位数之比，不是逐样本比值的中位数。

**范围：**本次 GPU 同时有其他工作，延迟分布波动较大；有限样本及单次共享负载不能代表隔离设备或长期性能。DURA 上下文为当前 eager 路径，未使用官方优化 graph；计时不含模型加载、主机到 GPU 的输入传输和识别器，因此不能与已发布的 DURA＋旧 F50 端到端时延直接比较。两个网络权重与输出不同，测速不证明预测一致或身份性能保持；两版完整七景评分仍在运行。
