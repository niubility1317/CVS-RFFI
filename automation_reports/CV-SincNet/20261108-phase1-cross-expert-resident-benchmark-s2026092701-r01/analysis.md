# 交叉专家网络源训练数据预加载对照

N607 RTX 3090 共享 GPU，512 个合法源 ID × 3 视图，batch 128。相同模型、批次与 AdamW 初态，两种顺序各对照 4 步；计时不含源缓存加载和直接恢复器预计算。

| 顺序 | 常规批次拷贝 | GPU 预加载 | 预加载变化 |
| --- | ---: | ---: | ---: |
| 常规先 | 189.821 s | 187.539 s | 快 1.20% |
| 预加载先 | 140.256 s | 180.816 s | 慢 28.92% |

两组各四步的损失、模型、优化器与随机状态均逐位相同。源数据传入 GPU 的一次性耗时分别 0.0153、0.0096 秒，所选缓存 15734784 字节，按相同字段估计完整 52896 条约 541866624 字节。未读取 TX 标签、F 权重或输出、V 或目标，未保存权重。

该共享 GPU 的短程对照无法证明稳定提速，执行顺序和资源争用可能影响计时；不能据此改动在训模型，也不能宣称完整训练或最终预测逐位一致。该结果与卷积路径为主要耗时的诊断一致。
