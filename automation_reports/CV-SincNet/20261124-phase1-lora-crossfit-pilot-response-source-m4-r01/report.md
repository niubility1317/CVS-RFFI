# LoRa 跨组验证前导响应与联合恢复

## 预登记

此前两路线的识别净损失集中在旁路与轻扰动。已评分的另一批 300 源包上，低郊区的精确扣噪接已知反演额外增加 45 次和 36 次正确判定。旧三抽头均衡在 residual 上有稳定损失，说明单次前导拟合输出不能直接当作可逆作用。本轮测试有限支持、前导组之间双向留验的样本内估计。历史精确扣噪／反演只用于问题定位。 [扰动分层及反事实回读](../20261124-phase1-lora-real-source-pair-contrast-m4-r01/report.md) · [旧三抽头实验](../20261123-phase1-lora-dura-pilot-joint-source-m4-r01/report.md)

输入为已截取的六条实收 chirp、公开的 LoRa 前导与固定采样率。旧跟踪提供每条的去扫相位、实收 RMS、载波复振幅与相干度。新估计先保留每条独立的载波振幅，用邻近 ±1 至 ±4 个采样点的移位模板构造八个复响应基。去扫后去均值，再回到原 IQ 坐标拟合。窗两端各留 4 点，拟合不依赖模板的循环拼接边界。奇、偶两组分别以实收相干度平方加权做岭回归，岭强度为 0.02 加 0.20 倍本包外带方差代理。用另一组的估计预测本组实收去载波残差，取两个非负残差解释比例的较小者作为支持度。如果任组缺少信号或响应解释不足，支持度为零。两组响应均值乘支持度的平方根，将频响相对单位作用的偏差限制在幅度 0.45 以内。估计仍可能混入接收硬件、发射指纹与公共干扰。高支持度表示组间可预测，来源仍需通过冻结结果检验。

原 IQ 中用上述作用组装频域正则化逆解。刻画相干修正的分母为作用功率加逐 chirp 外带方差对应的先验权重。学习先验参与分子同一解析式，解回去扫后保留原载波分量，最终以实收相位与 RMS 回写。工程读出用实收自身作逆解先验，不读取任何网络输出。恒等对照共用相同的粗恢复和细化骨架、输入及噪声估计。两路线共用源 U 的旧 clean 旁路门限，旁路策略的未覆盖问题不在本轮直接改动范围。

文献中的前导频域 LS／MMSE 用完整循环 chirp 估计多径并用于解调。本轮的输入是已登记的六段窗口，身份判决依赖实测细节。估计以非循环内部观测、留组预测与单位附近约束判断是否做有界反演。参考工程链沿用公开的 LoRa 前导与同步思路，相同物理包的冻结识别判断最终效果。 [LoRa 前导均衡原论文](https://doi.org/10.36227/techrxiv.16760101.v1) · [频率相关信道估计](https://doi.org/10.1109/VETEC.1996.501446) · [LoRa GNU Radio 公开实现](https://github.com/tapparelj/gr-lora_sdr)

两臂同初始化、参数量 254,735，batch 12、3,600 步及三视图，保持平均粗／细波形误差、0.45 分层上尾、同包一致性和原弱谱差异传递项。训练用同一份原始合法源 U 划分，5,000 拟合、2,500 仅门限、500 留出。通用扰动从连续随机复数的带限短卷积和有色加性噪声生成。回波绝对抽头和不超过 0.48 并随距离衰减，通用噪声的幅度缩放为 0.15 至 1。两臂都只以源 IQ 和通用受扰波形计算损失，生成的抽头或实际测试参数没有进入模型输入或监督。真实用接收 IQ 估计作用。两路线的权重和规则一致，拟合和冻结不访问 F、V、TX、目标、实际 practical 算子或逐点噪声。

两包真实载入无 query smoke 后并行拟合。权重冻结后同一个 Tri-set 2026092702 对 full 和 residual 的 900 个共同源 V 物理包逐景预测。九个读出含直通、匹配半量 DURA、仅工程均衡、恒等粗／细／半量、跨组响应粗／细／半量。所有两路七景预测固定后独立 CPU 才读取源 V 标签。核对同包正确、纠错／改错、逐 RX 与逐景、clean、扰动分层支持度和 B1。预定同一读出需在两路线六景都超过匹配 DURA，且保持 clean，才进入正式扩展。 [Residual 三种子正式对照](../20261124-phase1-lora-residual-r69-fixed-baseline-m2-r01/report.md)

## 源 U 前导估计诊断

两次诊断均使用同一组 500 个保留源 U 物理包。轻扰动和宽扰动由通用短抽头与有色噪声合成。未读取 V、识别器、TX 标签或目标集。对照中的同包 clean 频响和注入频响仅用于计算误差。两次诊断没有改变已发布训练、阈值和推理规则。

- 轻扰动频响误差第 90 百分位为恒等估计 0.02140、旧逐 chirp 估计 0.01178、跨组估计 0.00649。跨组估计将非载波波形误差第 90 百分位从 0.04767 降至 0.04059。宽扰动下同一波形误差仅从 0.26140 降到 0.26089。500 个 clean 源包中有 499 个获得正的跨组支持，表明跨组支持也会确认原有的稳定响应。
- 从另 500 个源 U clean 包估计复频响均值及协方差。协方差收缩将保留 clean 波形改动均方根的第 90 百分位从 0.03214 降至 0.00511。轻扰动的非载波波形误差第 90 百分位为直通 0.04767、原跨组估计 0.04059、协方差收缩 0.04138。宽扰动改善仍约 0.0005。这些结果只检验合成扰动的数值可估性，尚无独立识别验证。

复核文件：[跨组估计计量](source-u-crossfit-action.json)、[clean 响应统计](source-u-clean-response-statistics.json)、[跨组诊断脚本](source_u_crossfit_action.py)、[统计诊断脚本](source_u_clean_response_statistics.py)。

按接收机做五折隔离。每折用其他四个接收机各 100 个源 U clean 包估计统计量，再测留出的接收机上 100 个保留源 U 包。合并后 clean 波形改动均方根的第 90 百分位为 0.00755（未收缩 0.03214），轻扰动非载波波形误差的第 90 百分位为 0.04124（直通 0.04767）。在五个源接收机中，pluto_1 的 clean 改动最大，第 90 百分位为 0.00944。两种收缩的宽扰动误差均约 0.2609。此留出测试仍是合成扰动诊断。 [逐接收机诊断](source-u-held-rx-response-statistics.json) · [复现脚本](source_u_held_rx_response_statistics.py)

工程逆解在轻扰动下造成主要损失。跨组半量在最高扰动层的正收益不足以抵消旁路和轻扰动的退化。最高扰动的支持度较低，单靠工程逆解的判定几乎没有变化。后续机制可优先验证轻扰动下的 clean 响应保护，并单独检查粗恢复收益是否能在联合细化后保留。两项在本实验中尚无联合识别证据。 [分层逐景计数](source-observed-severity.json) · [复现脚本](source_observed_severity.py)
