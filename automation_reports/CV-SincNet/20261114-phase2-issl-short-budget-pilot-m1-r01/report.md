# ISSL clean 短预算配对验证

复用 20261113-phase2-clean-native-pilot-r01 的 ISSL 源权重、五个 capsule、模型种子 2026092701、K5/N20、原 support/query split，比较四组 C 阶段预算：自监督／迁移分别为 50／25、100／50、200／100、400／100 epoch。原 2000／300 预算已有五个固定预测，保留作为完整预算对照；已有输入和目标结果已暴露，本研究用于开发评估。

四组固定保留原修复版 ISSL 网络、损失、优化器、源旧类回放、数据权限与固定步进学习率，每项同一原 seed、原顺序和输入，预算提前固定。四组生成各自独立固定预测后，再作 truth-last 配对评分，逐接收机报告旧类、新类、宏 H 和宏 F1、实际耗时和缺项。短预算参数不得由目标结果中途调节；所谓近似性能由实际配对误差披露，不能预设结论。

目标运行根为 `runs/20261114-phase2-issl-short-budget-pilot-m1-r01`，使用其他 owner 空闲的物理 GPU 6、7，最多每卡两个本任务进程并在每次启动前保持 6000 MiB 余量；遇到其他 owner 进程时整卡避让。输出为 20 个子任务（四组预算乘五个 capsule），每个在加载源 checkpoint 后先进行无 query smoke。任何错误停止新增并自然排空，保留日志及所有产物。长预算已有输出不覆盖、不重新训练。冻结结果后独立评分，不改变主队列。
