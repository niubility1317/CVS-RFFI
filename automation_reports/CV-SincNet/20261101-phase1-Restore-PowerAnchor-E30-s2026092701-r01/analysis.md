## 这次检验了什么

与固定 FeatureCond/c865 的唯一科学变化是在原损失上增加 .1×(sqrt(Praw/Pclean)−1)²。P 为逐记录平均 I²+Q²；Praw 来自单位投影前 raw_restored，Pclean 为同条合法源 clean 的 detached 复功率。部署仍只接收当前 IQ，单位投影及全部结构保持，幅度参考不进入前向。

原源端路径诊断测得 FeatureCond 投影前平均复功率 75.83，实际部署输出通过单位投影归一。这个尺度自由度没有被原波形目标直接约束；不能拿未经独立训练的 raw 当作新部署路径。本次检验约束该自由度是否有益，不把它当作已证明的 Main 退化原因。末轮源梯度诊断未发现普遍冲突或 globalclip 激活，因而没有追加 PCGrad 或分组裁剪。对照由被诊断模型确定，权重 .1 固定，无扫描。

完整损失为 IQ NMSE + .05 STFT + .1（输出 F0 余弦误差+源方差标准化 MSE）+ .1（预测 latent 余弦误差+同尺度 MSE）+ .1 幅度比平方误差。共享 encoder、160 维连续回归、四 FiLM、单位复功率输出和 globalclip1 保持；无逐记录 F 输入梯度限幅。

4670178 参数从零单阶段 30 轮/7410 更新，实际 E0 逐张量一致。原 L_s6300/U_s56700、R07 的 20+10 份 draw、源顺序、AdamW/.001 暖启247步再 cosine 到2e-5/WD1e-4/B256tail24 保持；无旧 G、DURA、coarse 或神经 IQ 教师祖先。F0 clean63000 特征及 f57 源方差尺度作为 loss 参考，teacher 停止梯度。方法明确 F-guided，无 TX/logits/CE/类原型、新身份头、V/OE/novel/目标训练或选模，OE 仅冻结诊断。

固定 final30 后两个 Main 总体168000×七景全部预测完成，再独立 CPU truth-last；raw/DURA 同 IQ-ID 判决精确复用，新 G 完整推理。没有因源质量跳过测试，没有目标结果回流选择参数或重跑。该 Main 已曝光、仅单 seed，不构成新的独立盲测或未知设备保真证明。

## 关于恢复比例与发射机特质

低档城区实际准确率为 65.433929%，相当于 raw clean 准确率的 75.612340%；DURA 对应79.503388%。这只是准确率保留比例，不能命名为波形或发射机信息恢复率，也不是任意网络的性能上限。

IQ NMSE、冻结 F(clean) 判决一致率和真实 TX 准确率各自回答不同问题。恢复网络可以让已有身份线索更易被固定 F 使用；是否成功要看真实 TX 净纠错和 clean 保持。即使某景超过 raw clean，也先称任务收益，不能据此证明不可辨识信息被还原。没有可靠条件熵或 MMSE 下界估计时，不能给理论“最多几成”的数值。
