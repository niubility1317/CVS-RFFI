# LoRa DURA 冻结宽带上的近载频方向精修

上一轮在不提高实际剂量的情况下换入已知 1–32 kHz 方向，full/residual 六景多答对 340/512 条，远高于外侧频带替换。用现有窄带输出直接替换没有可靠收益。本实验冻结成熟 G、宽带 G 和时频处理契约，单独改善近载频两段的实际恢复信号。

## 配方

每个源 U 包保留同一模拟接收作用、尺度和 AGC，只替换独立噪声。第一份观测逐值核对注册缓存。只抽两份均通过成熟门的源包用于匹配训练。冻结宽带先输出每个输入实际的复谱修正。新模型读取一次当前接收和该次宽带恢复复 IQ，在 1–8 与 9–32 kHz 两段单独更新复杂方向。重新定标至同条 chirp 原宽带分量的 RMS，保留载波、其他频带和总剂量。初始化逐值等于冻结宽带，恢复器各分支都不读取 F 或目标。

两臂使用同一时频网、底座、种子和训练流。两者共同以实际无新增噪声的源信号作弱频带复杂重构监督，按每带真实信号能量与 0.001 的下限常数归一化，经 log1p 抑制离群。配对组额外用 0.12 倍一致性项，先把两个最终重构误差搬回第一个观测的共同物理坐标，再在共同频带内计算两者差值。独立噪声只在训练提供，部署实际前向仍只需一次接收。两路线分别训练，每台源 RX 700 个 U 拟合和 80 个 U 留出，1600 步，每步 8 个同物理配对。种子 2026112784，AdamW 1.5e-4 余弦至 2e-5。训练 F、TX 标签、V 和目标读取为 0。

## 验证与发布

所有读出使用相同冻结门和 900 个源 V 包，各 RX 180，排除两个前序宽带评分面板。固定七景读出为直通、成熟恢复、冻结宽带、两种新近载频输出、一条配对组半步方向，以及按相同分带幅度的已知近载频方向及精确扣噪对照。沿用 Tri-set 2026092702。七景预测完整落盘后才连接源 V 类别，输出逐接收机、配对净纠错和置信区间。无目标访问。三种子正式门槛仍为六景 67.0%、低城区 43.0% 与 clean 64,490/90,000。
