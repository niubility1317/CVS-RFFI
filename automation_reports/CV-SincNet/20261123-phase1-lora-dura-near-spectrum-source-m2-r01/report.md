# LoRa DURA 冻结宽带上的近载频方向精修

上一轮在不提高实际剂量的情况下换入已知 1–32 kHz 方向，full/residual 六景多答对 340/512 条，远高于外侧频带替换。用现有窄带输出直接替换没有可靠收益。本实验冻结成熟 G、宽带 G 和时频处理契约，单独改善近载频两段的实际恢复信号。

## 配方

每个源 U 包保留同一模拟接收作用、尺度和 AGC，只替换独立噪声。第一份观测逐值核对注册缓存。只抽两份均通过成熟门的源包用于匹配训练。冻结宽带先输出每个输入实际的复谱修正。新模型读取一次当前接收和该次宽带恢复复 IQ，在 1–8 与 9–32 kHz 两段单独更新复杂方向。重新定标至同条 chirp 原宽带分量的 RMS，保留载波、其他频带和总剂量。初始化逐值等于冻结宽带，恢复器各分支都不读取 F 或目标。

两臂使用同一时频网、底座、种子和训练流。两者共同以实际无新增噪声的源信号作弱频带复杂重构监督，按每带真实信号能量与 0.001 的下限常数归一化，经 log1p 抑制离群。配对组额外用 0.12 倍一致性项，先把两个最终重构误差搬回第一个观测的共同物理坐标，再在共同频带内计算两者差值。独立噪声只在训练提供，部署实际前向仍只需一次接收。两路线分别训练，每台源 RX 700 个 U 拟合和 80 个 U 留出，1600 步，每步 8 个同物理配对。种子 2026112784，AdamW 1.5e-4 余弦至 2e-5。训练 F、TX 标签、V 和目标读取为 0。

## 验证与发布

所有读出使用相同冻结门和 900 个源 V 包，各 RX 180，排除两个前序宽带评分面板。固定七景读出为直通、成熟恢复、冻结宽带、两种新近载频输出、一条配对组半步方向，以及按相同分带幅度的已知近载频方向及精确扣噪对照。沿用 Tri-set 2026092702。七景预测完整落盘后才连接源 V 类别，输出逐接收机、配对净纠错和置信区间。无目标访问。三种子正式门槛仍为六景 67.0%、低城区 43.0% 与 clean 64,490/90,000。

`20261123-phase1-lora-dura-near-spectrum-source-m2-r01`，入口 `python -m experiments.pamf_lora_main.near_spectrum_source publish`。N607 普通账户、LoRa Python、发布 CWD、不可覆盖 release/run。两条路线分卡，依次 3、6、2、0、4、1、5，单卡总可见计算进程不超过四个。实际源 smoke 必须正确定标、同源复现和梯度非零。任何合同、数据角色、数值或评分闭合异常停止后续派发并保留。输出独立 smoke、每路两臂权重、训练和留出轨迹、固定七景预测及独立源评分。

## 已验证结果

N607 GPU 3/6 完成两路真实源检查、1600 步训练、双臂冻结和八组七景源域评分，状态 VERIFIED / SOURCE_SCORED。执行提交 a64efd5acd0f637249d567a57f2ccd20e8b4b9d8。每路 33 条训练记录全部检查，有限无技术异常。Full/residual 门内源训练配对为 3182/3500，留出 364/400。配对组重构误差相对冻结宽带分别下降 7.8% 和 3.7%，共同坐标下的配对误差分别下降 15.1% 和 6.6%。F、TX 真值、V 和目标读取在训练中均为 0。

- Full 相对冻结宽带，近载频直接监督净增 +6 条，95% 物理包区间为 −17 至 +28。配对监督净减 1 条，区间 −29 至 +25。相对成熟 DURA，两条学习结果也均无可靠六景提升。
- Residual 的直接、配对、半步相对冻结宽带六景净增 +82、+86、+53。配对组纠错 380、改错 294，区间 +24 至 +148。相对成熟半量仍少答对 83 条，95% 区间 −160 至 −7。配对组低城区虽多判对 8 条，区间 −22 至 +37。配对组相对直接监督六景只多 4 条，区间 −22 至 +33，一致性项的独立识别收益尚未证实。
- 已知近载频方向在相同分带剂量下，比冻结宽带分别多 +331/+559 条。Residual 学习精修追回约一半原来宽带相对成熟半量的损失，并达到了已知近载频净提升的约 15%。同幅度已知方向的巨大差距说明，两路当前的主要问题仍是准确估计微弱设备相关信号的局部复谱，而整体复误差和一致性改善不足以证明分类收益。

本次两个学习候选未进入目标访问。后续可先检验更强的近载频参考跨 chirp 对齐与长窗口上下文，在相同误差及守门口径下研究能否学到真实相位细节。仅调整配对损失权重没有充分证据支持。正式三种子六景至少 67.0% 目标保持进行中。
