# LoRa 恢复改动的奇偶验证与全源域 clean 压测

## 依据

上一轮扩大弱扰动触发，源域 full 与 residual 分别较匹配半量 DURA 多判对 7 和 67 次。留接收机和同包噪声带宽反事实显示，绝对功率门难以从某些接收机的原背景中辨认新增扰动。本轮比较两种处理。用奇偶 chirp 的互相预测来审核是否施加已有恢复量，同时设置无需检测的控制，在同一完整源域 clean 面板测量实际改错。 [上轮结果](../20261124-phase1-lora-rank-guard-extension-source-m2-r01/report.md)

先在源 U 检验奇偶证据。冻结原先验，旧旁路低郊区的 97 个源包中，量程至 64 kHz 的检查补回 46 包，全带检查补回 51 包。2,500 个 clean 校准和独立 500 个 clean 留出下，两检查都在留出 clean 上零新触发。重新拟合先验并校准时完全排除 RTL-1，近带／全带检查仍接受 51/100 和 64/100 个该 RX clean，另外四折各为 0/100。统计量支持“共同波形可恢复”的部分证据，未能普遍区分某台接收机的固有噪声与新增噪声。 [包内验证探针数据](source-u-action-support-probe.json)

## 运算和输入

在当前六条实收 chirp 上使用原载波跟踪、RMS 和相干度，每条 chirp 的跟踪单独进行。按固定索引分为奇、偶两个三 chirp 组。每组使用同一冻结的源 U 复谱先验，用本组的观测方差和组内频谱对比计算解析半量提议。对照该组原始平均波形，用另一组的观测平均检验二次误差是否减少，再交换两组。每带取两个有方向性的相对误差下降的较小值。近带对 0 至 8、9 至 32、33 至 64 kHz 等权平均，全带再等权纳入外带。载波仅进入第一带的差异归一项，实际编辑仍为零载波。两个门限分别取 2,500 个 clean 源 U 包统计量最大值加 1e-5。该检查用解析提议估计支持度，真正回写的增量来自固定秩四网络。当前包估计的频谱误差并非真实噪声和信道参数。

这种互检使用 Noise2Self 一类独立观测验证的思路。LoRa 包的两个子组共享公共波形，也各有独有成分及同步误差，独立性只是一种近似。因此以匹配的识别结果和留接收机诊断检验半量编辑是否有用。扰动视图和精确噪声只用于冻结后归因，阈值获取及校准隔离实际信道、V、F、TX 与目标。 [Noise2Self 原论文](https://proceedings.mlr.press/v97/batson19a.html) · [固定秩四权重报告](../20261124-phase1-lora-shared-spectrum-covariance-source-m4-r01/report.md)

## 固定矩阵

七路读出含直通、匹配半量 DURA、原秩四半量、原旁路追加四分之一或半量的两路无附加检测控制、近带或全带互检通过后才追加半量的两路候选。原门已触发包每个读出均保持原半量。沿用同一整包恢复权重和跨路线规则，G 无新增训练。在同一 900 源 V 包上完成 full 与 residual 各七景。再对同源 V 中余下 11,100 个物理包只预测 clean，补足全部 12,000 个源 V clean。对完整 clean 报告逐 RX 的净正确数、纠错、改错和标签变化。两路线以及互斥 clean 补集完成并核对物理覆盖后，由独立 CPU 评分接入源标签。补集仅验证 clean。

任何扩展采用同一读出，须在两条路线均超过匹配 DURA 六景、保住主面板及完整 clean 正确数。留接收机误触发和强场景损失用于说明跨设置风险。本轮零目标访问。启动先做真实 checkpoint 无 query 检查，之后自动校准、B1、双路线预测、补集预测与独立评分。技术错误仅保留所属 run 产物并按独立状态核验。 [实验登记](experiment.json)

## 固定恢复方向的剂量反事实

另用 150 个留出源 U 包重放两路各三个代表场景。保持实收同步、载波和 RMS 坐标，精确新增噪声仅用于比较。将固定秩四组的复数改动按公共与独有谱以及频带拆分，计算固定半量及区间 [0,1] 内逐包最佳标量能消除的新增噪声误差能量。后者用到实际噪声，仅是沿原改动方向的隔离诊断。

在低城区 1 至 8 kHz，原半量消除 full 和 residual 的新增噪声误差能量 68.9% 和 70.0%。按逐包最佳标量分别为 91.7% 和 93.5%。在 9 至 32 kHz 对应的固定半量为 74.8% 和 74.9%，最佳标量为 99.6% 和 99.8%。这个误差口径保留接收机固有噪声和传播作用，结果不能替代固定识别结果。实际矩阵未采用逐包最优剂量，始终保留现有强扰动半量。 [Full 剂量反事实](source-u-rank-dose-oracle-full.json) · [Residual 剂量反事实](source-u-rank-dose-oracle-residual.json)
