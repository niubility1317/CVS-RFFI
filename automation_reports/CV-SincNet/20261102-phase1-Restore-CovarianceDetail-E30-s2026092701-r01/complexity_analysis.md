# 新双分支恢复器的结构成本

本项为本地合成零IQ上的静态运算计数，不加载数据或训练权重、不测时延，不修改当前N607训练。

逐层 Conv／Linear／attention 的模块名、形状和MAC见complexity.json。计数含attention的QKV、输出投影、QK及AV两次矩阵乘法；其内部out_proj不重复计入。反卷积按输入元素×输出通道×kernel计算，避免误按输出长度重复计数。物理估计计数与既有176636032 MAC独立核对一致；实际观察到6个物理attention和4个细节attention。完整state逐值保持不变。

核心小计不是完整FLOPs或时延：未计bias、归一化、激活、softmax、插值、FFT算术、Action组装和其他逐点运算；Cholesky／三角求解另列，不能当作0成本。FP64与FP32算术的硬件代价不同，也不能将MAC简单换算成毫秒。冻结识别器F0不在G部署输入或计算中，端到端G+F应另计F的成本。

这些运算计数不随初始输出层为零而跳过模块，也不证明任何恢复收益。完整30轮训练时间、峰值显存、最终权重下的G／G+F实测时延及原Main七景表现仍待完成；旧DURA的4.531972ms不属于本版。
