# LoRa 无标签源包的跨扰动距离保真

[预登记矩阵](experiment.json) · [实验状态](events.jsonl)

## 训练信号与恢复结构

恢复器沿用六条实收前导、逐 chirp 去扫和 64 点短时复谱。粗层用其余五条前导作复谱先验，在当前实收系数中按预测方差与同 chirp 时间平均外带功率作融合。细化读取实收、先验残差和粗恢复，输出有限的短时复数修正。重叠相加后，与原实收去扫坐标和幅度对齐，去扫载波不改动。旁路直接返回实收 IQ。

一批 24 个合法源 U 包从同一台源接收机中抽取。每次更新为其中 22 包各生成两份独立通用受扰观测，另 2 包两份读出均保留 clean 身份映射。两臂共用相同两份观测和原始无标签 IQ。源 V 和冻结识别器在训练与校准过程中关闭。

包间关系约束使用两组源波形特征。第一组是以实际去扫载波为相位基准的正负频复均值，第二组是奇偶 chirp 两半交叉计算的正负频乘积。该乘积保留相反频带间的相位闭合关系。两个频段分别为 1–8 与 9–32 kHz。先用源包的短窗原坐标与尺度将两次恢复放在同一参照系，再将四组实测复特征拆成实虚量。每维按同批源 IQ 的离差和固定小量归一。

计算源 IQ 的全包对距离，并与扰动 A 的恢复包到扰动 B 的恢复包的距离矩阵配对。对角保留同一物理包在两次扰动下的一致性，非对角匹配实际源 IQ 的连续距离。整个损失使用对数平方距离及平滑 L1，对角和非对角的权重分别为 0.30 和 0.70。这一区分来自物理包与扰动对的位置，不用设备标签，也不会把不同物理包都判作不同设备。该距离仅在训练和独立源域归因时计算。

| 接收量 | 来源与时点 | 误差 |
| --- | --- | --- |
| 当前接收 IQ 和前导配准置信度 | 六条 chirp 可用后从当前包计算 | 受残余频偏、相位漂移、未建模回声影响。 |
| 留一重复复谱与预测方差 | 其余五条 chirp 的短时复均值和离差。预测方差由源 U 的复谱先验回归拟合 | 公共干扰会进入均值，离差也会包含真实逐 chirp 变化。 |
| 有效外带功率 | 短时复谱外带模方中位数除以 ln 2，再在同一 chirp 内平均 | 受外带真实信号、非高斯及非平稳噪声影响。 |

## 消融和相关工作

每臂 5,797 参数、40,000 个 AdamW 更新。使用 20,000 个 U 包拟合、互斥 2,500 个校准门限和 500 个固定留出。两臂的结构、初始化、源抽样、观测扰动、优化预算相同。同一优化循环联合粗恢复和细化。基础损失包含实测源 IQ 复谱风险、独立扰动一致性和先验预测方差似然。关系组只额外加入包间距离损失，权重从 0.25 平滑增加到 0.80。拟合和冻结不接 TX、识别器、V、目标或精确信道与噪声。

Park 等的关系蒸馏用样本间距离及角度传递教师表示。VICReg 用视图一致性和特征方差抑制表示坍缩。Shen 等用无监督对比学习提取 LoRa 射频指纹并评估设备识别。这里没有训练识别头或教师特征。距离目标由同批真实源 IQ 的载波相对复特征直接计算，评估仍使用恢复后冻结识别器。与项目内既有同包 Gram 和有符号波形差消融相比，本轮匹配批内全部物理包的连续距离，并给两个恢复输入独立通用扰动。 [关系蒸馏原论文](https://openaccess.thecvf.com/content_CVPR_2019/html/Park_Relational_Knowledge_Distillation_CVPR_2019_paper.html) · [作者实现](https://github.com/lenscloth/RKD) · [VICReg 原论文与实现](https://github.com/facebookresearch/vicreg) · [LoRa 无监督识别原论文](https://livrepository.liverpool.ac.uk/3184752/)

## 冻结评测

完成终步更新再连接同一冻结 Tri-set seed 2026092702。Full 与 residual 在同一 900 个源 V 包上各覆盖 clean 和六种 practical，包含直通、成熟半量 DURA，以及两个训练臂的粗恢复、全量及半量读出。两路线全部预测固定后独立 CPU 关联源标签并按同包、场景和接收机复算。关系组只有同一读出同时提高两路线同包 DURA 六景且保持 clean 才晋级。
