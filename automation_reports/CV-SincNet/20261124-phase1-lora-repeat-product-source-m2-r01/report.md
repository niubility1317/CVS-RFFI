# LoRa 跨重复复谱乘积工程对照

[预登记矩阵](experiment.json) · [运行事件](events.jsonl)

源 U 按接收机留出发现，跨重复复谱乘积对独立噪声下的公共弱谱有益，独有成分却受损，本轮只测公共读出。冻结现有跨频解析半量先验、clean 门和逐包物理 IQ RMS。每两条 chirp 为一组，预测当前组只读另外两组的同包实收复谱。线性项包含目标频点、共轭镜像和左右邻频。产品项用八组固定频率间隔，配对频率和等于预测频点。两组共享拟合数据，均保留原先验的逐 chirp 独有编辑及每带物理范数。 [原跨频工程先验](../20261124-phase1-lora-cross-frequency-source-m2-r01/report.md)

闭式岭回归在 20,000 个源 U 包及各自通用扰动视图上一次估计，无神经网络迭代优化。每条路线在同一个冻结 Tri-set 2026092702 和相同 900 个源 V 包上固定 clean 和六景预测。独立 CPU 在两路预测关闭之后接真值。预定比较产品公共方向、线性公共方向以及匹配原 DURA。 [跨组特征留出方法](../../../tools/lora_cross_repeat_product_probe.py)

## 冻结测试

N607 已验证执行提交 `9ae11efb986118a9a22d66323e9d7284a5cfd5c4`。闭式校准使用 60,000 个源 U 视图，耗时 5.48 秒。线性和乘积合计保存 47,616 个 FP32 统计值，另复用 527,340 值的跨频先验。本轮零优化步、零目标读取，冻结门限 0.0372647159。真实权重检查通过，RTX 3090 B1 中位数为旁路 3.15 ms、通用受扰激活 17.56 ms，激活计时包括三个工程读出。Full 与 Residual 预测用 GPU 0、1。

| 匹配半量 DURA | 3,094 | 374 | 2,960 | 403 |

六景分母为 5,400，低城区和 clean 各为 900。两路各行 clean 均为 667，原 IQ 旁路零触发。低城区 Full 和 Residual 分别 736 和 900 包激活。逐景逐 RX 的独有改变量中位数最大值分别为 3.01×10⁻⁸ 和 3.34×10⁻⁸，两个路线中各组剂量差中位数均为零。

相对线性公共方向，乘积项在 Full 的纠错和改错均为零，Residual 分别为 4 和 5，净差 −1〔−7，+5〕。Residual 六景逐 RX 净差为 0、−1、−1、0、+1，低城区净差 −1〔−4，+3〕。相对匹配半量 DURA，Full 六景净差 −29〔−66，+5〕，Residual 六景净差 −251〔−319，−184〕。相对解析半量分别净差 −37〔−65，−11〕和 −153〔−216，−84〕。区间按源 RX 内物理包配对重抽 1,600 次。

同包产品项未改善匹配线性读出。两种公共方向替换在固定独有成分和 IQ RMS 后均比原解析方向更差。本轮工程对照停留在源域。完整产物位于 `E:/type10-7/local_artifacts/20261124-phase1-lora-repeat-product-source-m2-r01/readout`，包含同包固定预测评分、逐景和逐 RX 配对。状态为 `VERIFIED / ANALYZED`。 [源 U 留出结果](../../../docs/analysis/LORA_CROSS_REPEAT_PRODUCT_20261124.md)
