# LoRa 跨重复复谱乘积工程对照

[预登记矩阵](experiment.json) · [运行事件](events.jsonl)

源 U 按接收机留出发现，跨重复复谱乘积对独立噪声下的公共弱谱有益，独有成分却受损，本轮只测公共读出。冻结现有跨频解析半量先验、clean 门和逐包物理 IQ RMS。每两条 chirp 为一组，预测当前组只读另外两组的同包实收复谱。线性项包含目标频点、共轭镜像和左右邻频。产品项用八组固定频率间隔，配对频率和等于预测频点。两组共享拟合数据，均保留原先验的逐 chirp 独有编辑及每带物理范数。 [原跨频工程先验](../20261124-phase1-lora-cross-frequency-source-m2-r01/report.md)

闭式岭回归在 20,000 个源 U 包及各自通用扰动视图上一次估计，无神经网络迭代优化。每条路线在同一个冻结 Tri-set 2026092702 和相同 900 个源 V 包上固定 clean 和六景预测。独立 CPU 在两路预测关闭之后接真值。预定比较产品公共方向、线性公共方向以及匹配原 DURA。 [跨组特征留出方法](../../../tools/lora_cross_repeat_product_probe.py)
