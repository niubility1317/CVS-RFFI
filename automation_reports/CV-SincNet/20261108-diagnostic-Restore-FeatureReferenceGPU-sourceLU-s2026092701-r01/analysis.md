# 源参考特征缓存：真实 GPU 数值对照

**MEASURED：这两个 GPU 单步对照没有通过预设的参数更新等价容差。** 两条路径都使用固定原地面 Tri-SIG-TIME SSL F0、原 source-only JointPrior E30 状态和相同的 FeatureResponse 恢复网络结构；只修改 no-grad 源扰动参考特征的取得方式，恢复输出的两次 F0 前向和顺序保持。所有 AdamW 更新只发生在独立内存副本中，没有保存模型或改变在训权重。

原 R07 draw1 固定 256 条源记录，L_s/U_s 各 128 条；原源模拟器 Action 和噪声保持，覆盖四种固定 1% 扰动。缓存计算采用 batch 256，在线源参考和 G 训练采用 microbatch 32；每次逻辑批 256 并累积 8 个微批，固定 epoch 1 和 3，分别比较在线和缓存各一步。F0 及源数据契约与原训练核对；没有 TX 标签、分类 logits、V、OE 或目标数据访问。
