# LoRa DURA 读出和旁路范围的源域诊断

## 原始与恢复观测融合

在同一 12000 包源 V 上用三种子的冻结候选集合 Tri 和固定形状保护 G，所有恢复器及分类器均不更新。按同 TX/RX 的物理顺序分出等量开发和核对半区。六景统计采用当前 fixed gate，未触发的样本逐点旁路；恢复时同时计算原始和恢复的分类概率。融合权重代表恢复观测的占比，置信规则只在恢复概率间隔相对原始的领先值达到指定门槛时选择恢复。本诊断不读取目标数据。

| 读出 | 开发半区净纠正 | 核对半区净纠正 |
| --- | ---: | ---: |
| 直接使用形状保护输出 | +109 | +64 |
| 融合权重 0.25 | +46 | +19 |
| 融合权重 0.50 | +71 | +51 |
| 融合权重 0.75 | +79 | +49 |
| 恢复间隔至少领先 0.00 | +76 | +47 |
| 恢复间隔至少领先 0.05 | +39 | +15 |
| 恢复间隔至少领先 0.10 | +12 | +10 |

融合可以改变误纠错，但这些固定方式在两个半区均低于直接使用保护输出。当前数据未提供继续发布该类简单置信融合的依据。

## 旁路样本上的识别损失

取种子 02 的同一 12000 源 V 面板，使用同包原始和星地 IQ 的同一个冻结 Tri。表中“clean 可纠正”仅计星地直通判错、同包原始 IQ 判对；“替换损伤”计星地直通判对、同包原始 IQ 判错。该诊断表明潜力所在，不参与 G 更新，也不以原始 IQ 作为目标运行时输入。

| 六景内观测分组 | 包 × 场景数 | clean 可纠正 | 替换损伤 |
| --- | ---: | ---: | ---: |
| 原门控触发 | 5508 | 2993 | 229 |
| 高相干旁路 | 61386 | 11564 | 3348 |
| 中间相干区被学习门控旁路 | 4769 | 2211 | 229 |
| 过低相干旁路 | 337 | 224 | 5 |

当前门控仅覆盖 2993/16992（17.61%）的配对 clean 可纠正机会。最大一组未覆盖来自 0.94 以上的高相干旁路。高相干度主要反映公用 chirp 结构的可观测性，不能证明细粒度身份特征保持。过去的放宽门槛和本次概率融合都没有改善受保护方向的净识别效果。对高相干路径的下一项机制诊断需分开估计 CFO、相位、增益和剩余非载波形状的可恢复性。

## 高相干旁路的配对物理上限

在种子 02 的 3000 个等距源 V 包上，筛出 15374 次相干度至少 0.94 且原门控旁路的星地曝光。借助其同包 clean 观测分开估计相位、跨 chirp 中位数 CFO 差和每 chirp RMS 比例。该反事实只用于训练和部署之外的归因，不能把对应的 clean IQ 或测得的参数传给目标恢复器。

| 源域反事实 | 正确数 | 相对直通净变化 |
| --- | ---: | ---: |
| 原始 practical 直通 | 9540 | 0 |
| 校正相位 | 9410 | −130 |
| 校正共同 CFO | 9568 | +28 |
| 校正共同 CFO 和相位 | 9426 | −114 |
| 校正共同 CFO、相位和增益 | 9425 | −115 |
| 使用同包原始 IQ | 11662 | +2122 |

固定 CFO 只解释了配对干净差距的一小部分。相位或幅度调整没有增加总正确数。

在同一批高相干曝光上，把 clean 与星地观测各自配准，再用 clean 的去载波归一化残差代替星地残差。合成输出始终保留星地观测的载波相位、频率和反归一化坐标。以下仍为含真实配对 clean 的诊断。

| 替换的去载波分量 | 相对直通净纠正 | 六景中增益为正 |
| --- | ---: | ---: |
| 六条 chirp 共享残差 | +672 | 6/6 |
| 各 chirp 独有残差 | +193 | 6/6 |
| 共享及独有残差 | +1892 | 6/6 |
| 两种残差，步幅限为观测 RMS 的 15% | +1785 | 6/6 |
| 完整同包 clean IQ | +2122 | 6/6 |

直接替换两种非载波残差解释了同包 clean 反事实 89.16% 的净增，限制步幅后仍解释 84.12%。这与“当前 G 修改共享残差会错化”一致。共享成分本身具有身份价值，只有恢复方向正确时才适合修改。下一条针对性训练应在六 chirp 的统一坐标上拟合 clean 的共享与独有残差，从两份独立源星地观测监督保持重复结构。所有配对 clean 和真值继续隔离在合法源域，实际部署增益通过完整冻结目标矩阵判断。
