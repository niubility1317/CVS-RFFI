# LoRa W24 整包公共 chirp 与弱复数差异的匹配长训

Run `20261126-phase1-lora-w24-chirp-components-s2026112991-r01`。N607 启动 **VERIFIED**，两臂正在源域训练。 [实验登记](experiment.json) · [运行事件](events.jsonl)

## 结构与损失

两臂用同一随机初始化和原整包时频 U-Net 的 308,676 个参数。时间分支在接收端对齐、归一化坐标中产生公共复数修正。频谱分支减去包内均值，产生和为零的逐 chirp 修正。两支共用包级限幅，保持这一分解。恢复器只更新 384 个中心采样点，48 个原生边界点保持实收。源域报告分别给出实际半量和全量回写。

对照采用原始整包 U-Net 损失。候选保留相同基础损失，并在半量读出上增加 0.10 倍公共分量误差和 0.30 倍逐 chirp 差异误差。四频带的绝对 FFT bin 为 1–8、9–32、33–80、81–192，按各带复波形能量归一化，设置 0.002 能量下限。新损失只使用同一合法源 IQ 配对生成的受扰和原始中心窗。两臂均记录两个额外损失分量。

## 训练与冻结

源 U 从同一固定划分选 20,000 包训练、500 包独立留出。种子 2026112991，batch 16，AdamW 余弦学习率 2e-4 至 2e-5。两臂分别训练 24,000 步，在第 2,000、6,000、12,000、18,000 步复核留出波形，固定末步权重。训练路径限合法源 U_s 与本臂输出目录，既有恢复权重只在冻结后作比较。固定 E104 识别器首次参与本轮时，两份恢复权重已冻结。

实际发布提交 `92ae791f2a4197862789c758dc6b92ca8c006011`。发布归档比对 VERIFIED，N607 编译 PASS。九项定向测试及独立 P0/P1 审查通过。两臂真实源 U 启动 smoke 在 1 步完成，监督标记与目标读取计数均为零。控制器 1101646。对照在 GPU 3，监督组在 GPU 2。训练开始后保留原始日志和冻结权重。启动时每卡各有一个其他 Python 任务，显存余量均超过 12 GiB。

## Full 同包验证

训练后用同一 300 个源 V 物理包生成七景盲预测，同时复现直通、原长训半量 DURA、首尾半量 DURA 和 24,000 步原损失 U-Net 的对照预测。预测全部固定后，独立评分。候选的半量读出须在六景严格超过所有固定对照，低城区达到最佳对照，clean 达到直通。

通过源域门槛时，发布器将自动启动同一 E104 的正式 Full 三个分片，覆盖 15 台未见 RX、30,000 个物理包。已启动独立收集和评分进程，只有全部目标预测固定才连接原始标签。评分输出逐景、逐 RX、纠错和改错。验收正确数门槛为六景 162,000、低城区 25,500、clean 28,566。当前两臂的准确率、训练耗时、峰值显存和推理时延均待实际产物。
