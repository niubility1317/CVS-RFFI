# LoRa 同包物理修改量与方向隔离对照

[预登记](experiment.json) · [运行事件](events.jsonl)

固定原接收前端、先验、clean 门和相同物理包。解析方向来自实收 IQ，隔离精确方向来自实际新增噪声。两方向各用原解析半量的 0.5、1、2、3、4 倍真实物理 IQ 修改 RMS。无裁剪，精确方向在高档可能出现过扣。另对比相同门下的自然精确剂量及全包精确扣噪，以区分活动覆盖和修改量。两路线各 900 个源 V 包，七景，用原 Tri-set 2026092702 固定预测后独立评分。本轮没有候选拟合、校准或目标读取。 [已有一次同量对照](../20261124-diagnostic-lora-mixture-directions-source-m2-r01/report.md)
