# 源记录对比中的同设备负对下界

本候选将同一源物理记录的不同视图视为正对，将不同记录视为负对。Phase1 源数据限定为六类发射机，因此不同记录即使属于同一设备，也会按实例对比的定义被计入负对。这对区分单条记录是预定行为，但对希望保留设备身份的表征可能构成假负例；其影响尚未由本候选的正式识别测试验证。

只用公开的六类数量及预登记采样配置，可以给出不依赖真实 TX 标签的数学下界。对于一批中 `m` 条不同物理记录，令 `m = 6q + r`，其中 `0 ≤ r < 6`。即使六类分配得最均匀，同设备但不同记录的有序配对也至少有 `r(q+1)q + (6-r)q(q-1)` 个。每类对应多少条记录未知时，实际数量可以更高。

当 batch 32 的物理记录互不相同时，共有 992 个按记录判定的有序负对，其中至少 140 个来自同一设备，约占 14.1129%。这不是识别错误率，也不是读取 TX 标签得出的经验占比。

按已冻结的 32768 个源记录、三个视图、五轮、batch 32 和固定随机种子复算 15360 个批次，15213 批有 32 条不同记录，146 批有 31 条，1 批有 30 条。对每批选择每个物理记录的一个代表计算下界，可知 15236824 个按记录判定的有序负对中，至少 2148920 个来自同一设备，整体下界约为 **14.1035%**。对含重复记录的批次，这种代表法可能低估下界；同一记录的重复视图按实现仍全部是正对。

这次是对采样器的无数据复算，没有读取源 IQ、TX 标签、识别器、V 或目标，也没有运行网络训练。本机与 N607 的 CPU 采样复算结果一致；小规模穷举测试验证了下界公式。[复算程序](../../../experiments/phase1_dura_orthogonal/instance_collision_bound.py)固定对应本次预登记采样配置。

以上只是目标冲突的可能性，不证明辅助编码器实际丢失了设备信息，也不证明候选识别率会下降。已登记候选仍按原配置等待 GPU，并在训练后完成全部七景测试；该分析不会改变其训练、选择或测试。其他无跨记录负对的源扰动响应方案也继续按既定队列推进。
