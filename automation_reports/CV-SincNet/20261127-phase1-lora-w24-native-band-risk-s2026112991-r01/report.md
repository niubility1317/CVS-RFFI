# LoRa W24 整段 DURA 近载波分带复误差

Run 20261127-phase1-lora-w24-native-band-risk-s2026112991-r01，单种子、Full 七景。 [实验登记](experiment.json)

## 对照与假设

上轮整段模型只去新增噪声后，合法通用扰动波形误差明显改善，低城区仅比整段复原原录波多判对 2 个源包。既有精确噪声隔离诊断显示，逐 chirp 差异噪声和公共噪声的联合处理影响识别。本轮保持上轮原生 DURA 加噪前参考和全包半量读出，检验是否能通过分带复误差改善冻结识别。

两组都用 1 MHz 的 8,192 点完整复 IQ，模型 111,698 参数，随机初始化种子 2026112991，20,000 个合法源 U_s 拟合、500 个互斥留出，每批 16 包含两个恒等包。用相同短回波、缓慢相位和加性噪声的配对原生观测。24,000 次 AdamW，2e-4 至 2e-5 余弦，权重衰减 1e-4，裁剪 1。冻结末步，留出固定在 2,000、6,000、12,000、18,000 和末步。

候选仅在共同损失外增加半量输出的复数分带误差。坐标由同一实收跟踪产生。分离八条 chirp 的公共均值和逐条差异，在绝对 1–8、9–32、33–64 kHz 三段等权计入。每一段计算平均误差功率，以加噪前参考的对应频段功率加 0.02 归一化并取 log1p。公共／差异权重 0.30／0.70，乘总体 0.50。对照只记录这些项。共同目标继续包括两次早期输出、整段误差、原生端点、基础公共及逐 chirp 差异项、恒等保真。合成参考只用于训练监督，两组只接收 IQ。拟合、校准和冻结隔离 F、TX、V、目标、登记 practical 和真值轨迹。
