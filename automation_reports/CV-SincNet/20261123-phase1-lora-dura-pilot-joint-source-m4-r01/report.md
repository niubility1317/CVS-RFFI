# LoRa DURA 接收前导工程均衡与并行联合训练

## 方法

已知噪声和实际模拟算子仅作独立诊断。正式候选的输入是当前实收 IQ 和接收机已知的协议前导模板。该原则与实际 LoRa 接收机用前导估计、补偿定时和载波偏移一致。[GNU Radio LoRa 实机原型](https://arxiv.org/abs/2002.08208)

两个训练任务共用网络结构、初始化、数据、噪声、批次和迭代数。一起更新粗恢复、时域与频域噪声先验、第二阶段卷积先验。在第二阶段，恒等组以加性观测的恒等算子做正则化投影。均衡组先从当前包的实际 IQ 和接收端已生成的同步前导估计三抽头复响应，收缩向恒等作用，再在频域使用同一噪声尺度和学习先验做正则化均衡。两组均保护去载波坐标的载波分量，以同一个源 clean 门控制旁路。评测另外固定一行无学习模型的工程均衡。

训练只接触合法源 U 的单个 clean 视图。通用合成扰动由非定值白／相关噪声和随机两条局部复回波组成，扰动从恒等延伸到信号 RMS 的量级，独立于测试频道和实际轨迹。两组共用固定数据种子，在同一恢复损失中同时优化粗恢复和均衡后恢复，并对两个独立输入施加同包一致性。训练不读 F、TX、源 V、目标、practical 视图和仿真真实参数。

## 联合训练与加速

每一组仅一次端到端训练。无分阶段预训练、阶段化冻结或手工接权重。每组 1,400 步、batch 12 包及两次观测，单一优化器更新全部神经参数。每台源 RX 1,000 个训练、500 个 clean 校准及独立 100 个 U 留出包。两组分卡并行。支持 BF16 时，训练卷积可自动混合精度。前导估计、线性求解、FFT、损失和正式评分保持 FP32。记实测优化循环总秒数和各子候选 GPU，不以算法成本推断速度。

训练冻结后，使用恒等组的仅源 clean 校准门作为两组共用的固定阈值。两个模型分别在 full／residual 使用同一份已训练权重，候选只看到接收 IQ。五台源 RX 各 180 包，固定同一冻结 Tri-set 2026092702。八种读出覆盖直接识别、成熟 DURA、仅工程均衡、两组各自粗恢复和联合恢复，以及均衡联合半量。先固定全部七景预测，再独立使用源 V 标签，核对逐 RX、低城区、六景与 clean。门控实际误触发按原结果计入。正式目标依然是 15 台新 RX、30,000 包及三种子，六景≥67.0%、低城区≥53.0%、clean≥64,490/90,000。

## 发布

`20261123-phase1-lora-dura-pilot-joint-source-m4-r01`，入口 `python -m experiments.pamf_lora_main.pilot_joint_source publish`。N607 普通账户、现有 LoRa Python、独立归档发布 CWD 和不可覆盖输出。源训练选卡顺序 0、4、5、1、2、3、6，评分优先 3、6 两路线。单卡总计算进程少于四。各组先用真实源合法波形和通用扰动进行只读数据检查和训练梯度 smoke，再独立连续训练。输入或协议、非有限数值、冻结来源或评分闭合出现系统故障停止本 run 后续派发，保留已写产物。预期双 smoke、两个联合权重、训练和耗时读出及两路独立七景评分。
