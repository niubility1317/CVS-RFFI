# LoRa 同包独立时间窗噪声谱置信收缩

## 预登记

上一轮隔离结果表明，在平坦通用扰动中，接收侧原生噪声谱产生明显伪颜色。32 点窗内相位构造的功率核可减轻整数移频误差，但原接收谱估计的偏差更大。本轮检验从同一包的两组互不重叠时间观测获得的谱形证据，能否改善复波形和冻结识别。 [上一轮双路线及映射诊断](../20261124-phase1-lora-rf-noise-transport-source-m4-r01/report.md)

同上一轮，部署只读取当前包六条 256 点 chirp，同一个去扫追踪、原接收 32 点 Hann 复 STFT、逐 chirp 噪声谱、包内收缩、平均功率、观测旁路及回写坐标。两臂都把去扫相位在各 STFT 窗内的频域功率作为卷积核，核沿频率归一化。固定圈频卷积把原接收谱形平滑搬运到去扫坐标，输出每窗平均功率与平坦估计一致。短窗反射与频率栅格产生近似，真实传播与相关干扰都可能污染原接收 PSD。

仅候选根据实收信号估计谱形置信度。前导每条 chirp 的 8 个互不重叠区段交替分给两组，每组四段，两组覆盖整个扫频。排除原主瓣的频点在各组内以中位功率形成谱形，支持不足的频点用该组总体中位功率。分别除以本组频率均值并中心化。两组在相同接收频率的内积扣除远距离循环频移的互相关均方根，再按两组平均谱形的能量归一化并截到 [0,1]，得到包级权重。候选保留该权重的实收谱形，余量回到同功率的平坦谱。所有频点权重由这个确定的观测式生成，训练无真实噪声标签或门限拟合。两组区段的时间支持互斥，长时相干干扰或载波泄漏仍可产生相关偏差。

联训粗恢复、观测约束和细化。输入噪声谱有一个上述差异，网络、可学习参数量、幅度限制和其余观测量相同。输出修改通过重叠合成去掉去扫直流，并写回原实收时标和尺度。

## 训练与验收

单种子两臂匹配从零初始化、5,000 个拟合 U、2,500 个独立 U 旁路包、500 个留出 U、1,800 步、batch 12、AdamW 日程及与目标 practical 无关的通用有色扰动和短回波。沿用同扰动下真实源 IQ 差异保真目标。训练、校准和冻结零读取 F、TX 真值、源 V、目标或实际 practical 算子及噪声。

真实权重首先在两个源 U 包执行无 query 检查。固定粗恢复、细化及细化半量，对两路各七景、同一 900 物理源 V 包和冻结 Tri-set seed 2026092702 预测。两路全矩阵冻结后由独立 CPU 读取 TX 真值。与原成熟半量 DURA 同包配对，报告低城区、clean、逐场景、逐接收机、按物理包配对区间及 B1。留出 U 的隔离估计比较预先固定三种通用谱形，重复采样只用于度量候选估计误差。两路线都须超过同包成熟 DURA 六景并保持 clean 才进入正式对比。N607 优先使用有实际余量的 GPU，发生输入绑定、数值或预测闭合异常时停止下游。

## 相关工作

Ledoit 与 Wolf 研究把不稳定的经验协方差向结构化参考收缩。本轮采用当前包两个时间窗组的一致性来控制对角噪声谱向同平均功率平坦谱收缩，并使用 LoRa 窗内轨迹做频率搬运。目标是恢复复 IQ 后的设备识别，比较包含相同网络与功率预算的消融。 [Ledoit 与 Wolf 原论文](https://www.ledoit.net/Well-conditioned2004.pdf) · [Chiani 与 Elzanaty 的 LoRa 波形原论文](https://arxiv.org/abs/1906.04256)
