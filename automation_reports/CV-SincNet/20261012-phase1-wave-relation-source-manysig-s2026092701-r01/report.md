# 波形关系新表示先导：预登记

本次保持 84% clean 三种子最终目标。当前阶段仅源端可证伪，不访问目标，不新增采集或目标支持集；新身份实验按既定默认自动 clean 与六种 practical 测试。

## 历史经验

E20 CE clean 三种子均值 79.4891%；E20→E40 的 RESP_LU 80.3940%，低于额外 clean 前向对照 80.5415%。关系损失和数字响应拟合未证明独立身份收益；原最终特征 TX 散度比例约 76.6% 至 80.2%，不能仅因 RX 差异存在就更强地抹除特征。

新增完整源诊断已返回：24 个固定模型、288 个记录、4,536,000 个源样本操作前向。RESP_LU 浅层频谱留出 L 的旧目标 MSE 0.082931，真实响应闭合 0.088458；中层时序为 0.453954 与 0.491058。E20 时序零操作输出能量浅层约 1.43、中层约 0.53；把 h 置均值明显恶化，而把 q 置均值影响很小。因此不支持“只依赖 q”，也不能把旧目标拟合当成当前真实等变性。证据是机制诊断，不能推出准确率因果结论。

## 固定先导

一个模型种子 2026092701，五个源 RX 分别整机留出。每 row 在其余四个 RX 的 5,040 个合法 L 上，从零拟合 IQ、RAW_REL、COMPLEX_REL、GL2_REL 四头。20 个真实完整遍历，每头 800 更新；原 U 不打开，V 的 5,400 个 heldRX 物理包只评估。没有骨干、教师或统计参数先见过 heldRX。全部 15 个 TX 类对、day、混淆、NLL、间隔及每 epoch 日志保留。

共享 K 为 seed=2026101207 的 256×32 固定正交线性投影。复 Gram 消除常复增益；行空间投影消除满秩条件下可逆共同二维混合。无前导假设或理想激励。数值秩相对阈值 1e-8，无 ridge；退化包保留。严格性质不涵盖任意 FIR、时变 AGC 或非线性链。相同 4096→96→64→6 参数化，但重复／零坐标导致有效输入宽度不同，必须据实说明。

晋级只按源 V：相对 RAW_REL 平均提升至少 1 个百分点，5 RX 中至少 4 个非负，最差 RX 不低于 RAW_REL 最差值 1 个百分点以上，均值至少 30%。通过者按源 V 均值、最差 RX 排序，完全并列优先弱不变量。没通过则不扩大强不变分支。该先导不能替代后续匹配 CVS 身份实验。

## 发布与停止

矩阵、数据/物理角色、命令、环境、路径、GPU、owner 和产物以 experiment.json 为准。代码由一个 Git execution commit 固定；一次 archive 传输比对、远端编译、真实 E20 无 query smoke 后继续。每 GPU 最多 3 个总 CUDA 进程，计入其他 owner。错误输入权限、输出冲突、无法启动或确定系统技术故障才停止本 run，低性能不停止、不重试；保留所有旧任务和产物。
