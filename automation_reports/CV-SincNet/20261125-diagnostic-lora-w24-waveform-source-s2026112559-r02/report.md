## 独立评分结果

**VERIFIED**。两条路线各七景均完成实收 IQ 逐点核对与独立评分。各指标均为 300 包中位数，表中三个误差按实收、半量和全量的顺序排列。为了测量 chirp 之间较弱的差异，表中先减去八条 chirp 的共同均值，再计算频带复数 NMSE。识别正确数来自已冻结的同包 W24 E104 源域读出对照。

| 低强度城区 | 0–100 kHz 复数 NMSE | 100–160 kHz 复数 NMSE | 160–192 kHz 复数 NMSE | 冻结 W24 正确包数 |
| --- | ---: | ---: | ---: | ---: |
| Full | 0.05679 → 0.01060 → 0.00478 | 34.60 → 2.543 → 1.086 | 50.33 → 1.773 → 1.563 | 150 → 164 → 158 |
| Residual | 0.1855 → 0.04636 → 0.00579 | 90.22 → 21.14 → 3.440 | 117.1 → 27.02 → 5.513 | 127 → 131 → 102 |

Residual 低强度城区在三个频带的幅度 NMSE 和相位弦损失也随回写幅度增大而降低。该场景从半量改为全量，0–100 kHz 复数 NMSE 再降约 87.5%，识别却少判对 29 包。Full 低强度城区在 160–192 kHz 的相位弦损失从半量 0.312 升到全量 0.485，同时该频带复数 NMSE 继续降低。两条路线的 clean 相同，正确数为 297、293、292。clean 的 0–100 kHz chirp 差异复数 NMSE 从半量的约 9.34×10⁻⁵ 增至全量的约 3.74×10⁻⁴。

在这个冻结对照中，改善中心窗的幅相保真仍可能伴随识别退化。该归因记录了两种读出的波形与识别结果，未定位造成改错的特定设备指纹。后续候选保持已登记的半量无门控读出与测试规则。完整逐景、逐频带结果见 `waveform-scores.json`。 [同包识别读出对照](../../../docs/analysis/LORA_W24_READOUT_SWEEP_20261125.md)
