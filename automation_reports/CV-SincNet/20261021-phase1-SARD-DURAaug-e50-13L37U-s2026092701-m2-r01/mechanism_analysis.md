# 为什么 DURA 恢复后增强没有改善 PAMF

本轮的主要证据指向：完全替换原 As 后，训练中的星地扰动被明显削弱，但识别器的跨接收机学习仍主要作用于原域普通视图；这不是一次覆盖全部训练目标的恢复域适配。该解释与日志及测试模式一致，但尚未通过机制消融证明每一项的因果贡献。

run：`20261021-phase1-SARD-DURAaug-e50-13L37U-s2026092701-m2-r01`；模型seed2026092701，从零E50＝13L＋37U。原固定FINAL50测试、模型和DURA权重均不变。本分析只读取已有完整日志、固定分数和实际代码，新增训练更新0、新增F/G前向0。

## 已核实的控制条件

完整逐条比较两组19314个L/U batch的role和物理样本顺序，差异为0；11100步的场景计数差异为0，ordinary相对raw的MSE也逐步完全相同。两组As场景均为low suburban237149、mid urban236344、low urban236907包，总710400。因而本轮差异不能归因于源数据顺序、信道场景抽样或普通增强日程不匹配。

两组均完成11100更新，使用同一默认联合训练头、As KL0、ordinary/raw KL、ownEMA和旧U机制。DURA输入是同一原practical residual输出；训练和测试固定同一G权重、FP32/TF32off及reuse=True/graph=True/native=False。测试缓存IQ直接保存共同engine输出，没有在F输入前另加第二次恢复。源smoke证明F可以通过detached普通tensor反向传播；detach只隔断G梯度，不会冻结F。以上未发现明显的错接或不训练问题，不表示所有数值和机制问题均已排除。

## 1. 原本困难的星地训练视图变得接近原IQ

以下是全部11100步的均值，均来自训练日志，不是目标评分：

|源训练指标|匹配SARD|DURA恢复后增强|
|---|---:|---:|
|ordinary与raw的MSE|0.204052|0.204052|
|第二混合视图与raw的MSE|0.604891|0.112289|
|As单独CE|0.757315|0.324554|
|As分类梯度代理范数|12.115311|5.023333|

第二混合视图含64个ordinary和64个As，故MSE不是单独As的NMSE；不能把它解释成恢复器的独立重建质量。ordinary完全相同而第二视图MSE从0.604891降至0.112289，确认替换后训练扰动显著变弱。As CE从0.757315降至0.324554，也说明该源分类任务更容易。梯度代理是代码记录的平均∥30(p−y_LS)∥，不是完整网络参数梯度范数。

原As同时提供了对传播和接收机残余失真的压力，促使F学习在严重变化下仍可识别TX的特征。恢复后仍存在失真；一个在原As上训练的鲁棒F可能更能容忍未知RX上的恢复残差。完全删去原As可以削弱这项训练压力。它能解释raw六环境准确率从71.8820%降至34.0940%的方向，但不能单独证明恢复后性能下降的全部机制。

## 2. 只替换As输入，没有把整个学习目标切到恢复域

原损失实际为：

```text
L_L = 0.5 RD(ordinary128)
    + 0.5 [0.5 RD(ordinary64) + 0.5 CE(As64)]
    + 0.25 RD(raw128)
    + w_SC SC(ORD128)
```

As独立KL为0，RD包含该视图本身的两次CE和保留的KL。替换只将As64变成G(H(x_s))。在有标签CE系数合计1.25中，恢复视图的系数是0.25，即20%；这是系数占比，不是全部loss或实际梯度的20%。其余ordinary/raw监督仍占80%，U分支也没有DURA视图。

更关键的是，11100步的crossview_mode全为ORD128。对比学习启用后的39960条逐层记录中，恢复/卫星视图新增anchor总数为0，模式也全部ORD128。浅中层CROSS_RX只使用普通增强的128个样本，虽然代码计算了混合视图特征，但ORD128不会把它们选入该对比损失。因此本轮确实训练了恢复样本的分类CE，却没有显式训练恢复输出在不同RX之间的同TX对齐；不能把这次替换等同于“整个PAMF已经更适应恢复域”。

代码依据：[原SARD混合CE/KL](../../../code/worktrees/phase1_urban_sigtime_20261014/experiments/cvs_as_temperature84/loss.py)、[六前向及对比入口](../../../code/worktrees/phase1_urban_sigtime_20261014/experiments/cvs_crossview_supcon41/model.py)、[ORD128选择规则](../../../code/worktrees/phase1_urban_sigtime_20261014/experiments/cvs_crossview_supcon41/relations.py)。

## 3. 相同恢复器不保证源/目标恢复分布相同

训练看见G(H(x_s))，部署看见G(H(x_t))；x_s和x_t已经含不同接收机的链路响应。使用同一个G只保证同一处理函数，并不自动消除跨RX的差异。固定DURA的目标是源域配对IQ误差、谱误差和IQ蒸馏，不是TX分类或RX不变性目标；波形恢复得更接近源clean，不等于在未见RX上判别信息的间隔更好。

测试模式更像F的整体跨域泛化退化，而不是仅最恶劣信道失败：恢复后clean下降2.4470pp，郊区三景下降3.1280至3.2351pp，urban三景下降2.3042至3.2298pp。甚至不经过G的target clean也下降2.3143pp。与此同时，源clean V为98.4037%→98.4556%，并未下降。

据此可推断：更易拟合的源恢复视图，没有形成更能迁移到目标RX的身份特征。G可能保留或引入了可被F利用的源RX残差，也可能改变微弱TX特征；这些仍是假设，本轮没有以新的跨RX特征间隔、响应相关性或机制消融确认，不能写成已证明的根因。

## 4. 37U增加了曝光，但没有补齐恢复域学习

两组U曝光均为2097900次，唯一U物理样本均56700。实际接受伪标签33778／33357次，接受率1.6101%／1.5900%；U标签始终隐藏。接受数是重复曝光中的通过次数，不是唯一已标注样本数。增加到37U不等于获得同等数量的有效伪标签CE监督，且原U弱/强增强路径始终不含DURA。两组接受率相近，不能把性能差简单归因于某组U没运行；但这项半监督训练也不能被视为恢复域适配已经充分。

## 判断与后续检验方向

用户的直觉有合理前提：如果G后的源/目标分布可迁移、F确实学到了恢复域身份不变性，且训练没有牺牲原本有用的扰动覆盖，那么训练恢复视图可能改善G+F。本轮不满足这些条件的充分证据，因此结果并不与该条件性判断矛盾。

当前证据支持保留原As的价值，不支持直接全量替换。若继续研究，较有针对性的下一步是保留原As，再以匹配预算加入或混合恢复视图；先以合法源域检查恢复前后同TX跨RX距离、类间margin及分类梯度冲突。是否把恢复视图纳入CROSS_RX、是否用于隐藏U，应分别做独立消融，不能一次同时改多个机制。此处仅给出源证据支持的检验方向，没有启动新训练、追加目标测试、调整阈值或扩种子，也不保证下一方案有效。

本轮只有一个F模型seed、一个冻结G；不能据此否定所有恢复域训练方案或声称跨seed定论。原默认PAMF-T1-E50与DURA v1保持。完整性能和历史对照见[正式测试报告](test_results.md)。
