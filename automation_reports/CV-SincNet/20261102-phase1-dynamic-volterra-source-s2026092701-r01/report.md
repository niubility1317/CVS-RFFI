# Phase1 独立动态记忆多项式恢复网络

该网络直接从单条受损 IQ 生成波形，不调用 DURA 或物理后验。对七个相对时延构造复数线性与三次记忆基函数，用输入幅值、相对复相关和冻结盲模型的噪声尺度驱动时变复数系数；零初始化严格返回输入，整体 IQ 相位旋转下输出同步旋转。网络 15,028 参数，不含盲噪声估计器、输入保护门和分类基座。既有输入保护门关闭时直接返回输入，推理不读取源干净波形、设备身份、其他样本或真值。网络本身不调用物理先验；冻结盲估计器和门控的既有训练来源须单独披露。

训练使用与源验证和留出记录不重叠的 8192 条源训练 IQ，及固定的第 21、22、23 轮视图。使用配对源 IQ 和冻结 Tri-SIG-TIME SSL 特征构造损失，五轮后固定最后一轮；不直接读取 TX 身份、U_s 真值、V 或地面测试。源训练使用 F 特征，属于 F-guided。源记录和视图此前已探索，不称盲测。

先做 64 条源拟合和 28 条源评估记录的真实训练预检，失败则停止；通过后进行完整训练并固定 672 条源预测，随后进行合法 L_s truth-last 源评分。预先登记 clean 和六个受损视图，每景 168000 条 Phase1 地面测试，全部预测固定后独立评分与审计；报告跨 RX 和跨 RX+day。总集 clean 基准 86.538690%，相对下降 3% 的门槛 83.942530%，同时报告下降 3 个百分点的门槛 83.538690%。已探索地面开发集不代表独立盲测或真实卫星性能。

源实验 `20261102-phase1-dynamic-volterra-source-s2026092701-r01`、地面实验 `20261102-phase1-dynamic-volterra-ground-test-s2026092701-r01`。CPU 两线程、负载超过 72 等待，使用独立不可覆盖输出；预测固定后才独立读取真值，低分不停止健康任务。地面结果不回流训练或选模。该路线可与 DURA 做冻结对照，未来与 DURA 组合需另行固定并测试。
