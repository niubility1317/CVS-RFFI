# LoRa Phase1 完整外部对照补跑

补跑 RIEI、DRIFT-v2、IB-RFF、SDG，使用相同模型种子 2026092701 至 2026092703。四种原生全损失配方均接入 Phase1 Cell D 的普通 PL（置信度 0.95、权重 1）和 practical IQ 拼接 CE（权重 0.68）。沿用 RIEI 与 DRIFT-v2 的 100 轮预算、SDG 的 200 轮预算，以及 IB-RFF 两阶段各最多 200 轮的源验证停止和最佳权重规则。训练从零开始，SDG 保留其原生视图，RIEI 保留交替优化。原方法预算与 PAMF 的 E50 分开披露。

数据直接复用主实验 `20261121-phase1-pamf-lora-rx5-main-m18-r01` 中已隔离的 L/U/V、源 practical IQ 与物理包索引。无标签源域 TX 真值不参与训练。目标集仍为 15 台新接收机的同一批 30,000 个包，每行保留原始地面接收和已注册的六个 practical 星地信道。读取同 seed、同 LoRa 源契约的冻结 DURA-LoRa 作为配对前处理，固定报告直接和恢复后的结果，避免把识别器差异归因给 G。补跑与原主实验都有完整预测之后，独立评分程序读取本地原归档真值。

补跑使用独占 N607 发布与输出目录。先跑真实 LoRa 源 IQ 上的四个原生训练步和检查点回读。主实验源训练期间补跑最多占一台 GPU 的一个空闲槽，随后按可用显卡均匀分发。同卡限额计入已有工作。出现会破坏训练、合法预测或数据权限的技术错误时停止本追加派发并保留产物。
