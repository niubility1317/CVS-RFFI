# 冻结 DURA 修正的源域物理步长诊断

## 方法与边界

冻结 DURA v1 和源训练第 20 轮的大容量归一化修正器。令 a 为 DURA 输出、d 为修正器输出减 a、A 为 DURA 从 received IQ 估计的信道。对每条记录，在 0 至 1 内选择使 `||received - A(a + αd)||²` 最小的 α。物理步长只使用 received、a、d 和估计 A；源 clean 仅用于计算波形误差及不可部署的理想步长。此处没有训练新网络或创建可直接部署的候选。

672 条已探索源 pilot 中，每个接收机组和每景各 48 条；候选修正器的 32768 条拟合 ID 与 pilot 不相交，原 DURA 是否见过这些记录未知。均不读取 F、TX 标签、U_s 真值、V 或目标。

| 源组 | DURA NMSE | 完整修正 NMSE | 物理步长 NMSE | 源 clean 理想步长 NMSE | 物理步长相对 DURA：更低／更高／相同 |
|---|---:|---:|---:|---:|---:|
| RX4/6（288 条） | 0.015318 | 0.016367 | 0.014933 | 0.013575 | 110 / 20 / 158 |
| RX8（288 条） | 0.037208 | 0.032400 | 0.035969 | 0.031625 | 180 / 11 / 97 |
| 合计（576 条） | 0.026263 | 0.024383 | 0.025451 | 0.022600 | 290 / 31 / 255 |

物理步长在全部 12 个受损组的平均 NMSE 均低于 DURA，但合计仍有 31/576 条误差升高。完整修正在 RX8 上的平均 NMSE 低于物理步长；物理步长更保守，均值约 0.196，255/576 条为 0。理想步长均值约 0.641，依赖 source clean，不能用于推理。
