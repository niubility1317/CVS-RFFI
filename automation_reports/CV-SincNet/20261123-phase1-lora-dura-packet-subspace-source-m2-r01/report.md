# LoRa DURA 同包自然复谱分解

## 研究依据

在上轮与普通降噪的配对比较中，同噪声扰动约束为 residual 全量净增 114 条六景正确，但相对成熟 DURA 的低城区仍落后。另一批自然波形表明，1–8 kHz 的信号方向增益有所恢复，9–32 kHz 却继续损失。此前源域等幅置换也显示，单独优化真实方向增益可能引回较大的正交误差。这里直接拟合自然波形的两个正交复谱分量，避免用人工扰动的响应替代自然信号目标。

## 训练配方

保留路线匹配的成熟 DURA 参考及其门控。收到的六条 chirp 各自跟踪载波和分数频偏，与成熟恢复搬到同一当前观察坐标。头部只读当次接收 IQ、其成熟恢复、二者残差和当前信号质量。相同的两套全包 U-Net 分别读复频域和时域。控制组直接相加两套输出。试验组在每个频点把频域头投影成六条相同的平均分量，把时域头投影为六条均值为零的独有分量。两臂容量、输入、初始权重、残差剂量、损失与批次完全相同。所有近频输出从零更新启动。实际修正只放在载波两侧 1–32 kHz，每包同一尺度限制校准坐标内的 RMS≤0.12，保留两个分量的正交性。

源监督为从同包实际接收扣除新增噪声后，与成熟恢复的复差。目标与前向使用同一频带和剂量限制。训练损失在 1–8 和 9–32 kHz 分别计算公共、独有修正的误差，各按精确修正分量能量及 0.002 下限归一化，取 log1p 后平均。按路线独立拟合。每台源 RX 1,000 个 U 包及独立 80 个 U 波形留出包。采用同物理波形的两份固定作用重放，批内抽 12 条门内 practical 观测和 2 个 clean 恒等观测。模型种子 2026112869、2,200 步、AdamW 2e-4、余弦退火至 2e-5。训练 G 不读 F、真实 TX 类别、V 或目标。预测不会读取精确参考、第二次观测或 TX 信息。

## 冻结源验证

固定同一 900 个源 V 物理包，每台源 RX 180，排除前两次分频和弱信号评分面板。固定 Tri-set 2026092702。十个读出包括直通、成熟恢复、两个学习全量、因子化半量、仅学习的公共或独有分量，以及诊断用的精确公共、精确独有和精确联合修正。精确分量从同一剂量的联合修正分解，单分量对应自己的实际剂量。两条路线先固定七景预测，再独立连接源 V 类别，报告六景、低城区、clean、逐 RX 和配对净纠错。正式三种子目标仍为 15 台未见接收机、30,000 个包，六景至少 67.0%、低城区至少 53.0%、clean 至少 64,490/90,000。
