# 增强 W24 的 LoRa Residual 输入缺失诊断

已登记的 LoRa Residual 保存第 2 至第 7 条 chirp 的 256 kHz 中心窗，共 1,536 个复数点。增强 W24 的登记接口使用八条 chirp 的 384 点中心采样，以及每条首尾各 24 个 1 MS/s 原生点。同一个低率中心窗可以对应不同的原生边缘和未记录 chirp，当前缓存无法逐值给出原生 W24 输入。用已冻结 E104 对源域物理包做配对检查，测量只使用现有观测会带来多大识别损失。

五台已登记源接收机各取固定的 60 个 V 包，复用前一失真诊断的种子 `2026112559` 与物理顺序，按接收机分层且不读发射机标签抽样。每个包计算五条读出。第一条使用登记的 Full 原生输入。第二条将第一条的首尾原生边缘置零。第三条在第二条基础上只保留中间六条 chirp。第四条将同一 Full IQ 按现有六窗接口提取后，经 3/2 多相重采样为 384 点，仅保留观测到的中间六窗。第五条用同口径输入适配实际登记的 256 kHz Residual 模拟接收。第四、五条仅对中间有效中心窗重新定标，缺失边缘与首尾 chirp 统一置零。所有改动都只进入冻结识别器的输入，不重训、不校准、不加载恢复器。Full 和 Residual 都沿用现有生成配置，身份及模拟器参数不进入识别器。clean 共同使用原采集记录。

启动后先用真实源 U 包检查两种信道输入和各模式输出。用同一冻结识别器先完成全部七景、300 个物理包的盲预测，再单独开启 V 标签评分。报告逐景、逐接收机、逐包净纠错和 95% 配对区间。第四条与第一条量化同一 Full 接收记录中的输入缺失，第四条与第五条反映两条信道路线在相同六窗接口下的分数。源域诊断不读取目标数据。原生 Residual 如需额外采集或仿真输入，将另行登记并保留历史 256 kHz 口径。

入口 `python -m experiments.pamf_lora_main.w24_residual_aperture publish`，N607 普通用户，CPU 预测和独立评分，不占 GPU。6 个 CPU 波形进程，使用较低进程优先级。使用原 W24 代码发布 `e6dde7d40f2cc3dd7b21d83daa4bcbabac52d3ae` 与增强 E104 冻结权重。预期 `smoke.json`、`predictions.npz`、`source-predictions.json`、`source-scores.json`。来源、配对、有限值或预测矩阵失败即停止并保留现有工件。

## 独立源域评分

**VERIFIED**。冻结了同一组 300 个源包的五种读出和全部七景，随后独立进程读取 V 标签，目标读取计数为零。区间固定接收机，并按物理包分层重抽 2,000 次，保留同包六景关联。

| 输入 | Clean / 300 | 六景 / 1,800 | 低城区 / 300 | 六景较原生净差与 95% 区间 |
|---|---:|---:|---:|---:|
| 八条原生 W24 | 297（99.00%） | 1,367（75.94%） | 135（45.00%） | 0 |
| 八条中心，原生边缘置零 | 294（98.00%） | 1,324（73.56%） | 135（45.00%） | −43 [−66, −21] |
| 仅中间六条原生中心 | 112（37.33%） | 699（38.83%） | 100（33.33%） | −668 [−749, −593.98] |
| Full 降至已有 256 kHz 六窗接口 | 90（30.00%） | 577（32.06%） | 82（27.33%） | −790 [−872, −709] |
| 登记版 Residual 256 kHz 六窗 | 90（30.00%） | 613（34.06%） | 79（26.33%） | −754 [−839, −671] |

只遮掉原生边缘点使六景少判对 43 次。再遮掉首尾两条 chirp，六景进一步少判对 625 次，clean 少判对 182 次。两步遮挡保留原归一化。原生六中心与低率六中心的差值还包含按实际六窗重新定标，不能单独归因于采样频率。登记 Residual 和 Full 的低率读出共用六窗适配方式和 clean 物理记录，Residual 读出相对完整原生 Full 六景改对 110 次、改错 864 次，五台源接收机净变化均为负。不同生成路线比较同时反映信道与观测覆盖变化。

现有六窗补零接入的 clean 仅为 30.00%，本轮排除将它直接用作冻结 W24 的正式 Residual 输入。后续原生 Residual 评估需要八条实际接收 chirp 和可核对的原生边界来源，使直通和恢复器共用同一份观测。这里的结果只用于源域输入诊断。

独立评分与逐 RX 结果路径为登记 run 的 `readout/source-scores.json`。
