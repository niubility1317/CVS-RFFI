# 源域相邻频谱比值诊断

- 固定代码：`7ed869a93a26e353a851a36e36f3e129cec4abbd`。在合法的 672 条 Phase1 Main split 源域 IQ 配对上，比较相邻频点正则复数比值与归一化复数频谱的同记录检索；RX4/6 和 RX8 各七景，每组 48 条。
- 规则：正则强度固定为单记录平均频域功率的 0.01；特征归一后比较复数余弦绝对值，同分保守排序。报告每组 top-1、平均倒数排名和中位排名。
- 在访问源 IQ 前固定探索标准：12 个受损源组中至少 8 组的比值 top-1 比频谱高 5 个百分点，才支持进一步源域研究；这不是识别性能、部署或目标结果门槛。
- 输入仅为源 L_s/U_s IQ，使用同记录 clean IQ 作非部署参考；不读取 TX 标签、训练好的识别器权重/输出、V 或目标，不更新模型。既有 672 条 pilot 曾被研究使用，不是独立泛化集。
- CPU 单线程、低优先级；使用独占输出目录，实源八条无查询检查后执行。不存在模型 checkpoint，因此不适用 checkpoint smoke。测试、独立审查、输入路径、执行命令和停止规则见登记。
- 相邻频谱比值受到 [He 等人关于去噪频谱商的研究](https://arxiv.org/abs/2603.08402)启发；这里只检验比值描述符，不假定重复前导码、不进行接收机校准，也不复用论文识别器。
