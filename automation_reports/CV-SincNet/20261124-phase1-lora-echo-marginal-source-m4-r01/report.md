# LoRa 短回波不确定性与联合恢复

## 预登记

上一轮的隔离诊断显示，在留出源 U 的宽噪声加回波条件下，1–8 kHz 公共复谱相对误差从 1.3533 降到 0.7609。仅宽噪声时从 0.1655 升到 0.2332。clean 保护校准改善了工程均衡的判定，但联合候选仍未超过匹配 DURA。本轮在同一训练中用加性和短回波两种观测解释约束粗恢复和细化。 [同物理包结果与隔离诊断](../20261124-phase1-lora-clean-pilot-protected-source-m4-r01/report.md)

当前包输入是六条已登记的 256 点实收 chirp、已知前导和采样率。沿用实收估计的旋转、载波振幅、RMS 及相干度，以相干度平方加权得到包内公共分量。每个源 RX 取拟合 U 的首 100 个 clean 包，共 500 包。对公共复谱的 ±1 至 ±32 kHz 频点，估计同一份实虚拼接的均值及协方差特征基。单包噪声代理为逐 chirp 外频带功率估计的加权合成。64 个复数频点构成 128 维实向量。额外持久统计占 66,560 B。

加性观测把公共谱视为恢复先验与测量噪声之和。回波观测在此基础上把 ±1 至 ±4 个采样点的短作用写成当前包测得载波与理想前导产生的 16 列实值设计。按各实／虚抽头 0.06/(1+|lag|) 的固定先验尺度，积分未知系数。用低秩恒等式把求解降到 16 × 16。先使用冻结 clean 均值计算两种观测的边缘似然差，除以 4 后限幅、转为软权重。温度固定处理邻频误差相关性。该权重为模型内观测证据指标。两臂使用同一信任头，输入为当前证据、噪声代理、相干度和谱能量，训练只基于复 IQ 损失。

粗／细后验以各自网络给出的公共谱为中心。两臂共用已登记的学习骨架、加性一致性、统计量、同一信任头与损失。回波臂额外在后验均值中扣入短回波不确定性项。后验替换仅应用在上述公共非载波频带，保留回写前输出的逐 chirp 差分、载波与带外分量。工程消融用冻结源均值而省去学习先验。另保留同一回波臂冻结权重、推理仅取消回波项的成对读出。LoRa 前导均衡文献利用前导估计复信道后均衡解调。这里的模型平均借鉴边缘似然处理模型不确定性的关系，实际输出为保留身份细节的待识别 IQ。 [LoRa 前导均衡原论文](https://www.inderscience.com/info/inarticle.php?artid=118986) · [贝叶斯模型平均原文](https://sites.stat.washington.edu/www/research/online/hoeting1999.pdf)

两臂从同一随机种子训练，3,600 步、batch 12 和三视图，均为 254,832 可训练参数。沿用 5,000 合法拟合 U（其中 500 额外计算谱统计）、2,500 clean 门限、500 留出波形。独立 50% 通用模拟分支只有加性噪声，其余同时含通用短复卷积。通用扰动的任何已知参数或分支标志均未交给恢复器或进入损失。训练和冻结隔离识别器、V、TX 标签、实际 practical 算子和噪声及目标。

首阶段是真实冻结权重无 query smoke，通过后自动训练。冻结后同一 Tri-set 2026092702 和同一批 900 个源 V 包，两路线各七景、共 11 个读出。逐景和逐 RX 报告纠错、改错、净正确数和同包区间，补记门内回波权重、训练和单包 B1。完整两路线预测固定后才独立关联 V 标签。晋级限于同一个预登记联合模型读出在两个路线的六景均值均超过各自匹配 DURA 并保持 clean。所有参数、命令、资源和终止规则见 [实验登记](experiment.json)。

## 六条 chirp 提供的独立观测量

用 500 个保留源 U 计算 ±1 至 ±4 个采样点的前导移位列。对每包、每带，比较各 chirp 移位列相对相干度加权公共列的偏差能量，以及移位列总能量。第一种坐标把每 chirp 载波设为单位，只衡量模板形状差异。第二种保留当前包估计的复载波。实际注入的通用短卷积和噪声只用于生成诊断视图。

1–8 kHz 的归一化模板差异能量比例中位数为 clean 5.63×10⁻⁸、轻噪声加回波 2.97×10⁻⁷、宽噪声加回波 2.80×10⁻⁶。保留实收载波变化后，宽噪声加回波的中位数为 0.00562，P90 为 0.01212。9–32 kHz 的同类数值略高。低频多 chirp 的模板形状差异很小，观测到的差异里有相当一部分来自载波变化。仅凭组间重复，看不到稳定硬件响应和稳定传播响应的来源。诊断未读取识别器、源 V、TX 或目标，未改动运行中的训练。 [逐带计量](source-u-chirp-observability.json) · [复现脚本](source_u_chirp_observability.py)

## 将回波判定和近载波恢复分到不同频带

仍用上述五折、500 个保留源 U，把同一公共谱后验的回波权重换成只看 9–32 kHz 或只看 1–8 kHz 的边缘似然，复谱重建式保持一致。两个频带的观察统计由同折源 U 子块独立估计。9–32 kHz 仅占本近载波短回波设计列能量的约 1.73%。只用这段时，clean 权重 P90 从全带的 0.678 降到 0.254，但宽噪声有回波／无回波的中位数分别为 0.495／0.484，区分空间很小。宽噪声加回波的 1–8 kHz 误差从 0.7612 增至 0.8968。只用近载波证据的结果接近全带。固定高频域检测削弱了过度确信，也丢失了回波有效信息。诊断无 V、识别器、TX 或目标读取。 [频带证据计量](source-u-frequency-evidence.json) · [复现脚本](source_u_frequency_evidence.py)

## 实收外带噪声代理的隔离校验

每台源接收机取 30 个保留 U 包，共 150 个物理包。在 full 和 residual 的低郊区、高城区、低城区中复放当次源包观测。以同一实收载波、RMS 与 chirp 权重同时变换外带代理和隔离轨迹噪声。第一项比较代理与实际公共噪声在对应频带的平均能量。第二项将实际公共噪声与只累加各 chirp 功率的独立近似比较。匹配轨迹及真实噪声只在本节使用，无模型调用、校准或训练，V、TX 和目标读取均为零。

六个路线与场景组合中，1–8 kHz 的「代理均值／实际均值」为 0.958 至 1.100，9–32 kHz 为 0.916 至 1.049。低城区两路线按实际噪声比较，公共分量功率与独立近似相差约 1% 或更少。按包比值的离散程度明显更大。Full 高城区中，两带的中位数为 2.56、2.42，P90 为 4.92、4.30。因此平均功率接近并不足以支持单包置信度，后验的噪声方差需要考虑估计误差。 [双路线噪声计量](source-u-noise-proxy-trace.json) · [隔离脚本](source_u_noise_proxy_trace.py)

## 回波项的冻结读出与扰动分层

保持回波组的所有权重、信任头、公共谱和门限，只在半量输出中撤掉回波边缘化修正。两条路线每条各 5,400 次受扰判定，实际仅改变 full 的 4 次和 residual 的 3 次预测。六景净正确数分别变化 0 次和 −1 次（开启相对关闭），两路线低城区正确数均不变。因此该训练对照的粗恢复增益在最终半量下没有表现为可辨别的直接回波修正收益。

按实收扰动代理划分旁路、轻扰动（门内至 0.15）、中度（0.15 至 0.40）和最高扰动（超过 0.40）。与匹配 DURA 相比，回波半量在 full 的净差依次为 −13、−22、＋1、＋1，residual 为 −22、−33、−12、＋5。与匹配加性半量相比，residual 的 ＋16 全部出现在轻扰动层。该收益来自端到端训练后的整体波形差异，单独切换推理时的短回波项在该层净差为 −1。 [逐景分层配对](source-observed-severity.json) · [分层复现](source_observed_severity.py) · [冻结预测逐条核对](echo-switch-differences.json) · [核对脚本](echo_switch_differences.py)
