# 源域响应梯度投影：单步可行性结果

N607 CPU 结果已独立读回，真实 DURA checkpoint 和 8 条源样本的 smoke 通过。固定 DURA 和独立 direct 专家，从同一随机种子初始化时频网络；32 条源记录计算损失和梯度，另外 32 条不重叠源记录只用于评价。只优化时频网络输出头的 2308 个参数，三种模式各在 3e-5 和 3e-6 的 AdamW 学习率下独立执行一步，不保存模型。四个源组分别为 RX4/6、RX8 与高郊区、低城区的组合；每组各 8 条拟合和 8 条留出记录。输入为已探索源 IQ，合成立方幅度扰动的相对 RMS 为 1%。未读取 TX 标签、F、V 或目标。

波形梯度和响应梯度的内积为 -0.0105104，投影后为 -8.19×10⁻¹²，符合数值精度内的正交关系。但 AdamW 是逐参数预条件优化器，梯度投影的几何关系不能保证实际损失下降。

这只是源域、单方向、单步、输出头和一个初始化的探索，源 pilot 曾被探索，DURA 是否见过其中记录未知。它不能证明长期训练、其他优化器或其他扰动方向无效，也不能推断 TX 身份准确率、七景识别表现或真实在轨性能。实际训练使用完整网络和 GPU，与本检查不同。源码 commit d452377d30b04fd938ef7a38645a492d0a01e237；两项投影测试通过，独立 P0/P1 审查通过，远端包校验和编译通过，执行 56.1 秒，完整结果位于远端 run 的 result.json。
