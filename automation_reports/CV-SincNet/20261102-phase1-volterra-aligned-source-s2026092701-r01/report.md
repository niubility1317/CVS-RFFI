# Phase1 对齐感知动态记忆恢复

源训练诊断发现，既有动态记忆网络在 110 条受损训练记录上使直接归一化 IQ 误差由 2.0249 降至 0.5410，却使经 ±64 点时延和复增益对齐的误差由 0.09245 升至 0.40868；同样的错向在此前探索的源留出上出现。本实验据此使用相同 15,028 参数动态记忆架构，检验训练目标与源评估对齐是否改善恢复。训练记录与视图已探索，不能称独立盲测。

使用配对源 IQ，先从 ±64 点时移及最优复增益计算每条输出与干净源波形中央 128 点的归一化误差；时移和最优增益仅由当前训练配对估计，并在反向时固定，推理不读取干净 IQ。总损失为对齐误差，加 0.2 倍冻结 Tri-SIG-TIME SSL 特征余弦误差、0.2 倍温度 2 软类别 KL、0.05 倍置信加权伪类别间隔和 0.05 倍截断对数功率比平方。功率项用于抑制幅度收缩；伪类别可能错误，不是真实身份。F 保持冻结，因此方法为 F-guided。时移估计在训练配对内完成，不跨样本检索。

保持动态记忆基础版相同的 8192 条源训练记录、固定第 21、22、23 轮视图、五轮预算、初始化和优化器。不直接读取 TX 身份、U_s 真值、V 或地面测试。先进行 64 条源训练及 28 条源评估记录的真实预检，再进行完整训练，固定 672 条源预测后独立连接合法 L_s 身份评分。该模型及盲噪声估计器、输入保护门不调用 DURA 或条件物理先验；保护门关闭返回输入。

预登记 clean 和六个受损 Phase1 地面视图各 168000 条，所有预测固定后独立评分审计，报告跨 RX 及跨 RX+day。总集 clean 基准 86.538690%，相对下降 3% 的门槛 83.942530%，同时报告下降 3 个百分点的门槛 83.538690%。已反复探索的地面开发测试不能称独立盲测或真实卫星表现。源实验 `20261102-phase1-volterra-aligned-source-s2026092701-r01`，地面实验 `20261102-phase1-volterra-aligned-ground-test-s2026092701-r01`；CPU 两线程，负载超过 72 等待，唯一输出，低分不停止健康任务。模型与损失固定，不从地面测试回流选模或调参。
