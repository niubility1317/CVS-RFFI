# DURA 正交恢复的 GPU 源训练计时

状态：ANALYZED。N607 RTX 3090 物理 GPU 7，当时与其他两个进程共享；同一固定 512 个合法源 ID、三个缓存信道视图（1536 条曝光）、一轮源 IQ 训练。F/TX 标签/V/目标均不读取；FP32，TF32 关闭；CPU 为 2 线程。GPU 7 以 cuda:0 暴露给该进程。

| 路径 | DURA 源数据准备批量 | 准备时间 | 数据转设备 | 一轮训练 | 端到端 |
|---|---:|---:|---:|---:|---:|
| CPU | 8 | 12.917 秒 | 0.000 秒 | 1.420 秒 | 15.704 秒 |
| GPU 7 | 8 | 15.053 秒 | 0.006 秒 | 1.023 秒 | 17.875 秒 |
| GPU 7 | 32 | 4.987 秒 | 0.006 秒 | 1.135 秒 | 7.977 秒 |

GPU 批量 32 的端到端时间为 CPU 的 1.969 倍速度，准备阶段为 2.590 倍；批量 8 的 GPU 端到端较慢。训练损失分别为 0.02406042069196701、0.02406042069196701、0.024060418208440144。样本有限、运行顺序固定且 GPU 被共享，不能保证完整训练同样加速。

CPU 与 GPU 及不同准备批量可能产生浮点差异，源损失接近不代表权重逐位相同或正式测试结果不变。GPU 支持保留 FP32、固定模型与训练日程，完整新训练仍须按项目协议冻结和正式测试。本实验是 source-only 一轮计时，无新正式 checkpoint 或目标测试。

原有 CPU 新模型已在 GPU 适配之前完成五轮训练，源预测 smoke 通过，七景正式预测继续按原既定 CPU 流程运行；本计时不改变或替换原实验结果。

后续新启动的正交恢复训练默认使用 CUDA 和源数据准备批量 32；启动器要求明确通过 CUDA_VISIBLE_DEVICES 指定且仅指定一张物理卡，并在评分阶段隐藏 GPU。正式运行仍按空闲显存、并发约束及独立输出根逐次预检。
