# 大容量恢复器源域初始梯度诊断

使用已验证的 Phase1 源上下文，固定随机种子取两组互不重叠的各 1024 个物理记录，每条记录的三个模拟视图属于同一组。独立新初始化大容量 DURA 修正分支，只计算输出头的批次梯度，batch32、每组 96 个批次；使用与正式训练相同的源 IQ 损失，没有执行参数更新。真实 DURA checkpoint 在前 32 条源上下文上重放通过；未读取 F、TX 标签、V 或目标。

| 指标 | 源组 A | 源组 B |
| --- | ---: | ---: |
| 平均梯度范数 | 0.0006071 | 0.0006290 |
| 单批梯度范数的均值 | 0.0010227 | 0.0010241 |
| 平均梯度范数／单批范数均值 | 0.5937 | 0.6142 |
| 两组平均梯度余弦 | 0.9973 | 0.9973 |

在这次初始化、样本和损失下，两组**聚合后的输出头梯度**方向接近，平均梯度范数分别约为单批范数均值的 59.4% 和 61.4%。这不支持把该次初始化的两组平均梯度描述为完全相互抵消；它没有测量逐记录梯度，不能推出所有记录方向一致。三个视图共享物理记录，也不是 6144 个独立记录。

该模型是独立新初始化，不是在跑训练的第 8 轮 checkpoint；初始化状态、训练轨迹和其余网络参数的梯度都不同，不能据此认定或排除正式训练后续阶段发生梯度抵消。源训练损失和梯度也不是身份准确率，诊断不用于调整在跑模型或改变其预登记七景测试。
