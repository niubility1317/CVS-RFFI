# LoRa 双采样率 DURA 源训练

一份新权重直接处理已登记 Full 和 Residual 中 `6×2×256` 的实收 IQ，也接受有真实首尾的 `8×2×432` W24 输入。两种输入各在自己的接收采样网格上对齐。使用共用中央六条 chirp 的 72–112 kHz Hann 外带量标定唯一门限，并将其按采样率换算为各自网格的单点观测方差。边界缺失时，在条件通道中提供明确的不可用标记，数据一致性求解仅作用于实收中心。宽输入保留原生首尾。源域结果已经显示共享带数值可对齐，同时存在 RTL 留出 clean 误触发。本轮把同一门控纳入原定评估，干净正确数由冻结后同包测试判定。 [模型与统一入口](../../../experiments/pamf_lora_main/dura_apertures.py) · [门控源证据](../20261125-phase1-lora-dura-w24-io-s2026092702-r01/report.md)

按原 W24 预算从零训练 40,000 步，种子 `2026112991`。拟合、校准、留出分别为同合法盲 U 角色的 20,000、2,500、500 包。每个 batch 的 16 个源包分为两个等大的采样网格组。两组分别经原生捕获速率上的通用扰动得到输入，并共用原两阶段 DURA 的权重、优化器和半量读出。在每组保留 1 个原样包，匹配既有两包的身份保持损失预算。一次 AdamW 联合更新粗恢复、两步 CG 的观测估计和后续细化。初始学习率 `2e-4`，余弦下降至 `2e-5`，总梯度范数上限 1。锁定第 40,000 步。拟合、校准、留出波形检验均无 TX、识别器、源 V、目标或仿真轨迹读取。 [训练入口](../../../experiments/pamf_lora_main/dura_dual_aperture_train.py)

冻结后在已登记的两路线源 V 上，用同一固定读出与直通、原冻结 DURA 和扩容 DURA 做同包比较，观察 clean、六景和低城区。首轮正式目标验证固定 Tri-set 种子 `2026092702`，沿用 15 台接收机和两路原登记 IQ，每台取同一盲序前 200 个物理包。预测和评分分别运行，源 V 结果用于解释与研判，固定子集照常完成。晋级三种子 30,000 包矩阵的科学阈值依据独立源 V，在两路线的六景正确数均严格超过同次配对原 DURA，且 clean 正确数至少持平。正式硬指标仍以原目标为准。W24 单种子四组测试使用其已发布的独立权重和独立矩阵。 [双路线评测登记](../20261125-phase1-lora-dura-dual-aperture-pilot-s2026092702-r01/report.md)

## 去扫频坐标的观测作用检查

用 500 个合法源 U 留出包，在真实 1 MS/s IQ 上施加通用复增益、共轭镜像、8 µs 延迟叠加和白噪声，再提取同一中央六窗的 256／384 kS/s 两种视图。比较逐 chirp 变化、整包共享两种作用，以及各自的弱、强条件。两个读出各只有三个复系数，正则、约束、交叉折、固定三次逆更新和半量回写相同。弱、强条件的复系数 RMS 系数为 0.12、0.28，附加噪声 RMS 系数为 0.035、0.12。仿真参数用于生成和隔离诊断，接收侧估计及其门限只使用 IQ。

设接收端估计的去扫频单位相位为 \(p\)，时移为 \(S\)，接收坐标为 \(v\)。原始 IQ 上的复增益、共轭镜像和回波在去扫频坐标中的列分别为 \(v\)、\(\bar p^2\bar v\) 和 \(\bar pS(pv)\)。两个采样网格上的数值等价性均已验证。当前 DURA 的朴素列为 \(v\)、\(\bar v\) 和 \(S(v)\)。Tarighat 等的 OFDM 原工作同样建模前端共轭镜像，其均衡使用 OFDM 信号及相应训练。本诊断考察 LoRa 去扫频坐标变换、包内重复观测与真实弱复谱保真。 [对照代码](../../../tools/lora_receive_frame_action_probe.py) · [OFDM 原论文](https://escholarship.org/uc/item/5zn8g5c9)

| 原生 clean | −0.018／−0.021 dB | +13.98／+13.17 dB | 0／0 |
| 弱相对作用 | −12.04／−11.79 dB | −6.08／−6.08 dB | 500／500 |

| 弱整包共享作用 | −0.073／−0.056 dB | −0.18／−0.18 dB | 21／8 |
| 强整包共享作用 | −0.024／−0.016 dB | −0.071／−0.064 dB | 1／0 |

误差变化为同包原始 IQ 坐标模型相对朴素去扫频坐标模型的中位数，负值表示降误差。前两列比较无门控的工程对照。异折实收重复观测用于正向误差，源 clean 用于独立计算复谱误差。clean 的直通误差为数值舍入量，开启门控前两臂都会引入修正。强相对作用下，两个采样率的五台接收机方向一致，门控激活的 496、497 个包整包和独有复谱误差均下降。共享作用下，仅使用相对重复结构无法估出共同作用。隔离输入无扰 clean 作为作用拟合参考时，强共享档正向误差额外下降约 10.5 dB，显示参考可观测性是这一档的限制。

门控采用候选在异折上相对单位作用的预测误差降幅。两个采样网格共用门限 0.543297，由独立 2,500 个实际 clean 源 U 包的最大值乘 1.05 冻结。依次剔除五台接收机的各 500 个校准包后，受留出接收机各 100 个真实 clean 包仍为零触发。弱共享条件仍有 21、8 个激活包的整包误差上升。完整逐机证据为 `source_receive_frame_action_r02.json`，未访问目标、冻结识别器、TX、源 V 或星地轨迹。该诊断不修改已提交训练和正式测试。
