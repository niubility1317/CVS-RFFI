# Phase1 现有决策的事后选择上界

本分析在三个已完成实验的固定预测上，假设逐条知道测试真值，并从原始接收信号、DURA、边界学生和特征条件模型的预测类别中挑选正确类别。这个假设选择器不可部署；结果只是**限制在这四种已有预测类别内的选择上界**，不是任意集成方法、新网络或新波形的性能上界。

三组实验均使用同一个冻结 Tri-SIG-TIME SSL 基座；七个视图的 168000 个物理 ID 逐条相同，原始接收信号的预测逐条一致。核查全部 42 个预测数组及完成记录后才读取真值。此 Phase1 单随机种子开发测试此前已被观察，本分析属于事后探索，不是独立盲测，也未更新模型。

| 场景 | 原始接收准确率 | DURA 准确率 | DURA、边界学生、特征模型三选一的特权上界 | 再加入原始接收预测的特权上界 |
| --- | ---: | ---: | ---: | ---: |
| 高信号 | 80.6155% | 84.3435% | 87.7458% | 90.6488% |
| 中信号 | 78.1077% | 83.0161% | 87.0345% | 90.4250% |
| 低信号郊区 | 75.7446% | 81.3220% | 86.0208% | 90.1220% |
| 高信号城市 | 77.0500% | 83.0494% | 87.3935% | 90.5744% |
| 中信号城市 | 62.7958% | 75.7060% | 83.8851% | 89.0565% |
| 低信号城市 | 51.6048% | 68.8012% | 79.3476% | 86.0244% |

原始 clean 基座准确率为 86.5387%。项目原评分器的下降不超过 **3 个百分点**对应 83.5387%；若按更严格的**相对下降 3%**计算，则为 83.9425%。两种口径均在结果中分别记录，不能混用；例如中信号城市的三选一特权上界 83.8851% 高于前者、低于后者。

低信号城市中，四种预测的真值选择上界比 DURA 高 17.2232 个百分点。达到相对下降 3% 门槛需要相对 DURA 净增加 15.1413 个百分点，即至少保住约 87.91% 的这部分理论净增量；按项目 3 个百分点口径则约为 85.57%。如果实际选择器还损伤原本正确的 DURA 判断，需要修复更多记录。这是算术约束，不证明仅凭输入能识别正确专家。

完整逐视图计数见 [result.json](result.json)，分析脚本见 [oracle_bound.py](oracle_bound.py)。该结果可以提出源域选择器的研究假设；任何后续训练、门控和参数选择都应仅使用合法源域数据，测试结论仍需按已观察开发集的限制解释。
