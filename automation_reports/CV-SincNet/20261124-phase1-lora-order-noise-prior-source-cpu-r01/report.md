# LoRa 包内顺序特征的实收噪声修正

## 预登记

五折留一表明，同包其余五条 chirp 的顺序信息让 clean 1 至 8 kHz 独有谱平方误差合计少 26.53%。但在登记低城区，直接使用含噪顺序特征让误差增加 26.04%（full）和 26.80%（residual）。本轮只检验能否根据接收噪声估计限制这条特征，让已有信息在含噪时仍可用。 [未修正顺序特征](../20261124-phase1-lora-cross-component-prior-source-cpu-r02/report.md)

数据、拟合回归、岭值、公共谱输入、原后验、源折、白噪种子与四个登记回放单元完全复用上轮。每条 chirp 从自己去扫后的带外中位功率估计噪声。第 j 条顺序特征的噪声方差由其他五条的这些估计按顺序拟合权重平方传播。假设实部与虚部各占复噪声方差的一半。将各实坐标的顺序特征向合法 clean U 拟合的均值移近，使用信号方差除以信号与估计噪声方差之和作为权重。协方差的参考对照仍为逐维对角近似。公共特征、原始回归、私有误差增益和带外读出保持不变。原始噪声代理可能包含真实设备弱谱，而且 raw 噪声仍可能在 chirp 间相关。

每折 800 个合法 clean U 用于拟合，500 个 held U 用独立白噪验证，150 个 held U 用两路登记回放。实际新增噪声只构造独立评分参照。未访问 F、V、TX 或目标。相对固定私有中心的半量读出，预先要求 1 至 8 kHz 私有误差在两路低城区均降低至少 2%，低郊区两路均非负，才建议纳入后续联合恢复训练。以未修正顺序、仅公共上下文和固定中心归因。真实源 IQ smoke 覆盖启用噪声调整的分支。13 项聚焦测试和独立 P0/P1 审查通过。

## 相对固定中心的剩余收益

Full、residual 低城区在 1 至 8 kHz 的原始顺序半量分别增加 26.04%、26.80% 的误差。加入观测噪声约束后，相对固定中心仅降低 0.0024%、0.0009%。两路都低于预登记 2% 门槛。噪声约束挡住了不可靠的顺序改动，本轮没有证据支持把这一分支接入联合恢复器或进入冻结识别。源 U 含有可测的 clean 顺序结构，其在实收条件下的保真仍需其他观测。
