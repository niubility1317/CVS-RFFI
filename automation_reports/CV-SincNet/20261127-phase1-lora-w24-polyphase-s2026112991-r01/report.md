# LoRa W24 原生多相接收观测

Run 20261127-phase1-lora-w24-polyphase-s2026112991-r01。Full 星地原生七景，单种子 300 包源域筛查。 [实验登记](experiment.json)

## 假设与匹配对照

W24 中心窗的下采样略去一部分 1 MHz 原生复 IQ。候选在相同原生支持窗内构造偏移 ±1、±3 个原生样点的四路复数滤波权重，减去各自沿中心重采样抽头的投影，再令各路白噪声增益与中心抽头一致。所得四路实收观测保留中心抽头丢掉的局部复数信息。录制边界发生反射而使一个样点重复时，该点的原生补充观测置零。用同一个接收跟踪相位和每 chirp 的实收中心 RMS，把补充观测变换到恢复器输入坐标。对照以 W24 中心复 IQ 在四处相同索引偏移的差分取代原生观测。两组均将四路复数量的实虚部送入同结构整包时频 U-Net，共 312,260 个可训练参数。

相同随机种子 2026112991，从零训练。相同 20,000 个合法源 U_s 拟合包、500 个互斥留出包、通用扰动、batch 16。每组 48,000 次 AdamW 更新，学习率按余弦从 2e-4 降至 2e-5，梯度裁剪 1。留出点为 2,000、6,000、12,000、18,000、24,000、36,000 和 42,000 步及末步。源 IQ 弱相位探针在通用信道之前加到实录，普通对和探针对重放同一通用扰动。两组训练实际半量读出、粗输出、复数波形误差、同包一致性、弱探针与 clean 恒等。双倍编辑只做冻后压力对照。保留每条 chirp 的跟踪直流及 48 点原生边缘。

## 冻结与执行

拟合仅用合法源 U_s IQ 和同条源配对。无 TX、源 V、W24、目标、practical 观测或仿真分量。冻结两组 48,000 步末步权重后，由原 E104 和默认分类头在相同 300 包上评两组半量与双倍读出，直通、原长训 DURA、首尾 DURA 和历史整包 U-Net。七景盲预测固定后独立连真值。候选六景严格超过固定比较、低城区至少达到最高比较且 clean 达到直通时，进入三分片、15 台未见接收机、30,000 包 Full 独立 truth-last。
