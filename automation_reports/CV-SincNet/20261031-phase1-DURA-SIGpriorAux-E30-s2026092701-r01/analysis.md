## 新版所验证的机制

两版均在两个原 prior 编码器的中层 B×16×128 特征上，按时间池化成 8 段，经 Linear128→160 预测冻结 F 的实际加权 TripleSIG。预测目标逐记录、与配对 clean 相同；不读 TX 标签，不是新增身份分类器。新增辅助损失固定为 .01×两个 prior 的相对 MSE 均值，目标 detach、分母下限 1e−4，原四物理项和输出端 SIG alpha1/IQ 梯度 cap .5 保留。辅助损失是普通梯度，位于输出 SIG 上限之外，全网梯度裁剪 1；它也可通过 prior 输入影响更早的 G 模块，不能称只有 prior 更新。

主版把预测的 160 维特征再经 Linear160→112 转成三个解码层（28/16/12 通道）的缩放 1+.1tanh 和偏移 .1tanh；条件层零初始化。对照只接受相同辅助训练，推理完全跳过预测头、没有条件层。二者原始 G 参数、预测头初始化、随机流、训练目标与预算匹配。主版与对照的差异包括条件层及其对整个训练轨迹的作用，不将两独立训练模型的差值说成同一冻结权重下的瞬时开关效果。

同一初始 prior.out 为零、条件层也为零，初始条件层梯度为零是预期行为。真实 smoke 已确认辅助损失立即到达两个 prior 的浅层、中层和预测头，主版前向确实调用 2 个预测头与 2 个条件层，对照调用 0 个；严格 E0 重载、优化执行与原生输出、原 F 状态和默认头保持。推理只输入 received IQ，内部预测来自本条信号；没有注入 clean 特征、F、TX、RX 或场景。

本次是不同位置和作用路径的新假设，未宣称源域资格通过。旧 coarse 中层 SIG、统计量 FiLM、period20、RX/梯度/物理 oracle 的负结果保留，不改名或重新解释为本版成功证据。共同主基线为原 SIG47591；两新版相互比较用于检验参与解码的条件路径，新增 aux 版对原 SIG 的比较用于检验中层辅助约束。没有继承旧 G 或使用 oracle IQ。
