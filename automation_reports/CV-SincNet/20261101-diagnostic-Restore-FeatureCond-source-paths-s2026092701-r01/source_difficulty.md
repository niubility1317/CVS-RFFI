# 已冻结源样本的失锁、噪声与重复错误分析

**固定源面板的低档城区错误主要集中在模拟失锁记录。该事实不能直接解释目标域退化，也不能当作恢复极限。** 本文复用已经完成、同索引同 draw 的 512 条原 L_s/U_s ×20 份信道记录；不新增神经前向、训练、TX 读取或 V/OE/目标访问。

低档城区1436条观测中，失锁645条（44.9164%）。FeatureCond 与 F(clean) 不一致162条，其中失锁131条（80.8642%）；不是131条真实TX错误。该面板包含重复物理记录，不能把10240条当作独立样本或独立设备。

噪声列为缓存中 ||received−A(clean)||²/||clean||² 的实测能量比，A为该源观测的模拟真作用。它不是接收信号对噪声的SNR，更不是原地面记录的总SNR。state/lock来自模拟器工程代理，状态、信道衰落、补偿和噪声相关，不能由分组差异宣称某一因素的独立因果贡献。

失锁子组中，已知真作用、源总体均值高斯先验和128步求解的 oracle_mean128，Fclean一致率只有37.984496%；FeatureCond为79.689922%。这说明这一有限线性/高斯恢复器不能代替充分的信号先验，不能把“已知信道”对应分数叫作最优恢复上限。

向冻结FeatureCond条件分支额外传入sourceclean特征后，失锁子组一致率为95.658915%，修复105条、损伤2条、净增103条；已锁定子组则净变化0。额外输入本身携带clean信息且与训练时预测latent分布不同，因此这是源端反事实，不是部署收益或可达上限。此前将latent权重提高到1已做完整Main测试，不能由这个oracle继续推定简单加权一定有效。

## 计算核对与用途

三份已有诊断按epoch/source_index/scene对齐，identity路径的Fclean判决一致；DURA一致性逐条复核。scene/state/lock三个分区的样本数和每模型一致计数重组均回到全体10240条；每组净修复等于两个一致计数之差，20次错误直方图重组回到各方法总错误。模型和评分产物未改变。

源端证据支持继续区分“高噪声下特征估计不确定”与“输出波形优化”，不支持用源误差改善代替跨RX Main实测。当前PowerAnchor仍按固定30轮完成并自动七景测试；这里没有据目标误分类形成变体，也没有额外部署输入。
