# 时频双专家恢复器的训练计算量核算

核算对象为固定代码 commit f89c6c645d3ff0423be20b584e8bfa7c85dc3531 中的 CrossExpertRefiner（width 192），不改变正在运行的训练。用全零形状 [1, 2, 256] 输入执行一次 CPU 前向，并通过 Conv1d 的实际输出形状计算 output.numel × (in_channels / groups) × kernel_size；这只是计算量核算，不读数据、checkpoint、识别器或标签。

- 模型参数：3,576,004；卷积层：28。
- 每个输入的卷积前向：911,622,144 次乘加，按一次乘加为两次浮点运算约 1.823 GFLOP。
- 每批 128 条：116,687,634,432 次卷积乘加。
- 每轮 17,632 个源 ID × 3 个模拟视图，即 52,896 条；卷积前向约 96.442 万亿次浮点运算。20 轮约 1.929 千万亿次，仅包括卷积前向。
- 核大小 3、5、7 分别贡献每条 340,328,448、568,197,120、3,096,576 次乘加。

计数未包括归一化、激活、FFT/IFFT、损失、梯度计算、优化器、数据搬运和两套冻结父模型的准备。上述 FLOP 不是时间测量，也不能单独判定瓶颈或推断可实现吞吐。N607 实时只读观察到 GPU7 同时运行其他进程，当前训练进程仍有 GPU 活动，但尚未完成首轮；具体训练阶段和归因仍待日志与实测。用户未限制网络参数量，后续应在保持或提高恢复能力的前提下考虑计算布局，而非仅以压缩参数为目标。

独立登记的 GPU 驻留数据基准 20261108-phase1-cross-expert-resident-benchmark-s2026092701-r01 正在等待资源，比较短程训练的损失、模型、优化器和随机状态是否精确一致，并测量实际耗时。该基准不能证明完整训练或最终测试输出相同，也不会改变已有在训实验。
