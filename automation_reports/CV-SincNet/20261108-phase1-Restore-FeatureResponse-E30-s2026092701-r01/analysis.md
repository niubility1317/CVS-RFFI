## 方法、成本和证据边界

原 dense 响应恢复器增加源端 F0 连续特征差分响应损失，训练部署仍使用相同后验。

All 1471463 G parameters from scratch with original physical and prior seeds; no control G weights or optimizer state loaded.

Zero TX labels. Original physical Action/noise source supervision, paired IQ/STFT, continuous frozen F0, source IQ response and source continuous feature response.

全部30轮/7410步、63000条每轮完整源排列、189000次L_s和1701000次U_s曝光已核实。最终权重逐值等于E30技术状态，源先验固定，模型/优化器有限，各参数头实际更新。源目标组成复算最大误差4.51e-08。训练期间F0前向行数7560000，完整source审计见training_final_audit.json。

实际训练阶段38474.987秒；epoch计时合计38455.369秒、均值1281.846秒。两个预测阶段共1720.332秒。均为共享负载整阶段计时，含相应初始化/数据读取/真实源检查等成本，不是B1时延或独占提速倍数。

原Main两总体七景三流42单元全部固定后独立truth-last。再次复算全部1302组、868raw配对及DURA/clean配对，最大指标差1.2e-14，raw/DURA复用判决差0。公开CSV只包含聚合数据；各总体TX/RX/day/RX×day和macro-F1完整保留。combined_group_metrics.csv从互斥总体的混淆计数合并，不平均百分比。

低档城区67.546429%，相当于raw clean准确率的78.053444%；这是任务准确率保留比例，不是IQ信息恢复比例或理论上界。

代码、模型、source-only数据及最终30轮冻结点保持原预登记；资源调度只改变等待条件，全部科学阶段实际使用原release/commit。当前结果不用于调整其他在训候选、按场景组合或重新选择checkpoint。默认DURA保持，整个研究目标仍依完整逐景与clean保护证据判断。
