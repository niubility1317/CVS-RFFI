# LoRa W24 弱复数差异传递与训练预算

Run 20261127-phase1-lora-w24-weak-transfer-s2026112991-r01。Full 星地原生七景，单种子 300 包源域起步。 [实验登记](experiment.json)

## 假设与对照

固定原整包时频 U-Net 的 308,676 个可训练参数。两组均从种子 2026112991 从零训练，用相同 20,000 个合法源 U_s 拟合包、500 个互斥留出包、通用模拟扰动、batch 16。48,000 次 AdamW 更新，学习率按余弦从 2e-4 降至 2e-5，梯度裁剪为 1。已有 U-Net 权重只用于冻后对照。

两组都直接训练实际半量 IQ 和粗输出。标准弱传递项对同一源包的扰动观测和弱差异观测进行配对。弱差异取同批源 IQ 的有符号复变化。候选额外增加 0.35 倍的私有复增益误差。在去掉跨 chirp 共用值后，计算读出误差沿参考弱差异的复内积，并按该 chirp 的频带参考功率加 0.0001 归一化。分别计量归一频率绝对值 0 至 1/32 和 1/32 至 1/8，略去直流。权重和路径都在训练前固定，两组都记录该误差。Clean 恒等及其余损失一致。双倍回写仅做压力对照。

## 冻结与识别

分别写出每组第 24,000 次更新后的权重与第 48,000 次更新后的末步权重。留出轨迹记录 2,000、6,000、12,000、18,000、24,000、36,000、42,000 和末步。24,000 步是长余弦日程的中点。24,000 与 48,000 的识别对照检验继续拟合的同包变化。

拟合与训练冻结只见合法源 U_s 和通用同源配对 IQ。无 TX、源 V、冻结 W24、目标、practical 记录或真实调制轨迹。两组完全冻结后始用原 E104、默认头与原输出来评价 300 包源 V。源盲预测涵盖两组末步实际读出及双倍压力、两组中点实际读出、直通、原长训 DURA、首尾 DURA 与原 U-Net。全部预测固定后独立连真值。

候选只按 48,000 步规则进正式 Full。六景须严格超过匹配末步对照及四条固定历史读出，低城区至少达到对照最高值，clean 至少达到直通。正式测试固定 15 台未见 RX 各 2,000 包，全部七景和三个分片，独立 truth-last。中点权重只进入源域预算分析。
