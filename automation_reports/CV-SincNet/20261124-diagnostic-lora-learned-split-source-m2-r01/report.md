# LoRa 冻结联合修正的公共、独有与幅相归因

[预登记矩阵](experiment.json) · [运行事件](events.jsonl)

固定上一轮联合复谱终步模型、同一源校准门限、同一 Tri-set seed 2026092702。两条 practical 路线各使用同一 900 个源 V 物理包，覆盖五台源接收机、clean 及六景。此处拆分实际模型的修正。输入只有实收 IQ，沿用原追踪去扫、旋转及逐 chirp 幅度尺度。先将修正分成公共均值与零和独有分量，再分别回写原实收 IQ。幅度和相位读出在固定公共修正后，对归一化独有复谱做幅相组合，然后重新去均值并去掉新增载波分量。重新中心化也会影响最终的幅度和相位，因此称幅度导出的修正和相位导出的修正。等量对照单独匹配独有修正的原 IQ RMS，公共修正固定。

N607 执行提交 `6288f07f1692d3d2b9876925fc0b24fc24e4d45f`。一次独立 P0/P1 发现缓冲区尺寸错误，修正后定点复核通过。实际冻结权重检查、发布归档、远端编译均通过。GPU 1 和 3 分别完成 Full 和 Residual。新预测的直通、半量 DURA、原联合全量和半量与归档决策逐包一致。两路全部七景固定后独立 CPU 读取源 V 标签。无新增参数、训练、校准、精确噪声或目标读取，实测结果状态 `VERIFIED`。 [原联合长训](../20261124-phase1-lora-joint-spectrum-source-m4-r01/report.md)

- 公共和独有联合的正确数交互在 Full 为 −74［−123，−27］，Residual 为 +257［+179，+339］。交互按联合加直通减两个单项计算。它与精确扣噪的同类因子对照具有不同方向和大小，因而既有模型的公共编辑效果不能用合成真实噪声的公共份额直接推断。 [先前精确扣噪诊断](../20261124-diagnostic-lora-noise-split-source-m2-r01/report.md)
