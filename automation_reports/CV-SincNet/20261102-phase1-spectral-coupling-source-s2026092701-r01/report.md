# Phase1 独立频域耦合恢复网络

网络直接从单条接收 IQ 生成波形，不调用 DURA 或物理后验。将 256 点 IQ 变换至复频域，以七个固定频率偏移作为可学习的复数耦合基；每个频点的复系数由输入频谱幅值、邻频相对复相关和冻结盲模型的噪声尺度预测。该结构可以表达频率平移和频谱泄漏补偿，而不限定只做逐频点相乘；系数由同一条输入逐样本决定，不访问其他样本。零初始化返回输入，整体 IQ 相位旋转下输出同步旋转；表达能力检查覆盖完整一个频点的频移。模型 14,678 参数，不含盲噪声估计器、输入保护门和分类基座。既有输入门关闭时返回原输入。

训练使用与源验证、源留出记录不重叠的 8192 条源训练 IQ 和固定第 21、22、23 轮视图；使用配对源 IQ 与冻结 Tri-SIG-TIME SSL 特征损失，训练五轮后固定最后一轮。不直接读取 TX 身份、U_s 真值、V 或地面测试；使用冻结 F 特征，因此为 F-guided。冻结盲估计器及门控使用既有 source-only checkpoint，网络不加载条件物理先验。源记录此前已探索，不称盲测。

先进行 64 条源训练和 28 条源评估记录的真实权重预检；通过后完成完整训练并固定 672 条源预测，再进行合法 L_s truth-last 评分。预先登记 clean 与六个受损场景各 168000 条的 Phase1 地面测试，全部预测固定后才进行独立评分和分组审计，报告跨 RX 和跨 RX+day。总集 clean 基准 86.538690%，相对下降 3% 的门槛 83.942530%，另报告下降 3 个百分点的门槛 83.538690%。反复观察的地面开发测试不能称为独立盲测或真实卫星链路。

源实验 `20261102-phase1-spectral-coupling-source-s2026092701-r01`，地面实验 `20261102-phase1-spectral-coupling-ground-test-s2026092701-r01`。CPU 两线程，负载超过 72 等待；唯一输出、truth-last 评分，低分不停止健康任务。源结果与地面结果均不改变已固定模型或系数。该独立路线与 DURA 的组合需另行登记和测试。
