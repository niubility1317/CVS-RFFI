# LoRa W24 固定总量下的分量范数与方向析因

固定星地增强 W24 E104、默认头和 24,000 步原生 Practical 精确扣噪监督权重的实际半量回写。使用同一批 300 个已登记源 V 包的 Full 七景。两条旧对照为直通和冻结半量，要求逐包复现。实收估计的单位相位用于中心窗去 chirp，按包内公共／逐 chirp 零均值差异和绝对 FFT bin 0–32／33–192 分成四个正交分量。

保留中心总修正 L2 范数，分别只换四个分量的真实能量占比、只换各分量的真实复方向、两者都换。第四个干预参考行直接扣除中心全部新增噪声，允许总范数改变。四个干预均保留原半量的原生边缘，按各行走原 W24 定标。无新增噪声时全部干预保留原半量。如果一个真实分量没有可定义的学习方向，该包的只换能量行保留原半量。

对照用于区分分量间能量分配、分量内复方向及总剂量。报告六景和低城区的改对、改错、净变化和按源接收机分层的配对区间。真实冻结权重无目标冒烟先于盲预测。七景六路全部封存后由独立源评分进程连接标签。真值波形只作隔离干预；无新拟合、选模及目标读取。实收重放、同包对照、数值不变量或封存发生技术问题时停止并保留该运行。 [实验登记](experiment.json) · [先前整体方向与幅度对照](../20261127-diagnostic-lora-w24-practical-direction-factor-s2026112559-r01/report.md)

继承 r01 的固定矩阵。r01 在实际无目标冒烟遇到归档 Torch 和 NumPy 转换兼容问题。r02 改用已验证的缓冲区和 DLPack 转换，且在张量边界显式转换为 complex64。输出目录独立。 [r01 失败记录](../20261128-diagnostic-lora-w24-component-allocation-s2026112559-r01/report.md)
