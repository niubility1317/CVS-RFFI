# LoRa W24 包内公共复谱细化与双频段监督

Run `20261126-phase1-lora-w24-common-refine-s2026112991-r01`。N607 **VERIFIED / SOURCE_NOT_QUALIFIED**。两臂完成 12,000 步训练和 Full 源域七景独立评分。 [实验登记](experiment.json) · [运行事件](events.jsonl)

## 设计

源域噪声拆分发现，在逐 chirp 差异噪声已扣除时，同时控制两段公共噪声带来的识别收益远大于单段收益。本轮增加一个接收端复谱细化级，以冻结的原损失整包 U-Net 半量结果为起点。两组共享 349,814 个参数，只训练零初始化输出的 41,138 个新参数。

细化头读取实收及初步恢复的复谱均值、实收质量加权复谱、跨 chirp 离散度、噪声代理和频率坐标，预测包内公共复谱残差。回写乘接收质量相关的连续噪声系数。在由实收估计的跟踪相位对齐后，以实收 RMS 计量的附加 IQ 修正在八条 chirp 中相同。回写时，每条 chirp 乘回各自的跟踪相位。半量公共编辑的 RMS 上界为包 RMS 的 22%。初始输出逐点复现原骨干读出。48 个原生边缘点继续使用实收。

对照保留原损失。候选额外加入低、高频段各 0.25 倍的公共复误差，以当前合法源模拟受扰对的同带公共扰动功率归一。分带为绝对 FFT bin 0–32 和 33–192。两组记录相同两项指标。损失只对两份通用受扰视图的同包源参考计算，既有 clean 恒等与弱探针传递约束保留。

两臂加载同一份已验证合法源 24,000 步 U-Net 末步模型权重，骨干冻结，优化器全新。每臂只训练细化级 12,000 步，batch 16，同种子 2026112991，同一 20,000 源 U 拟合包及 500 留出包。沿用原通用扰动和调度，留出检查为 2,000、6,000、9,000 步和末步。不读取 W24、TX、源 V、目标或实际 practical 轨迹。
