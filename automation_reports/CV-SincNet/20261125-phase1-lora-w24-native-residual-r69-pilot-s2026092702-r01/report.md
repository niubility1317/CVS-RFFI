# LoRa 原生 Residual 与固定 R69 的盲测配对

本轮源依据为同一冻结 40,000 步恢复器在原生 Full 和 Residual 的配对源 V 实验，原生 Residual 六景净增 20/1,800，clean 正确数持平。固定原生 Residual 接收设置 `native_residual_w24_v1`，复用 LoRa 原登记的 15 台目标接收机与物理包顺序，登记种子 `2026112592` 各台无放回抽 200 包，共 3,000 包、七景。三条读出在同一份 1 MS/s 接收 IQ 上连接同一份冻结星地增强 W24 E104，种子 `2026092702`。新恢复器权重、源门限 0.06148705 和中心半量更新跟原生 Full 小试一致。没有训练、再校准或种子选择。

匹配历史对照使用 LoRa Residual R69 的 39,520 步源冻结 `G/lineage/r69/final.pt`（训练 run `20261123-phase1-lora-dura-residual-practical-m1-r01`，发布提交 `fd67669f3a3186a12a528f1f662fdca865a4fdde`）及其独立冻结扰动门限 0.45286365（门限 run `20261123-phase1-lora-dura-residual-gate-m1-r01`，发布提交 `c99556d506b583be3db15722c6ad820a719aab50`）。历史训练用带标签和无标签角色的源 IQ、Residual 信道配对、无噪作用和噪声方差，隔离训练好的 F、发射机真值和目标。新接法在同一接收包提取历史输入的中间六条 256 kHz 中心窗。门控、实收投影、半量恢复均复用。经确定性插值只把修正量写回六条 chirp 内侧，原生首尾边缘与另外两条 chirp 保持不动。推理只接收盲实收 IQ。

先以实际三份冻结工件检查四个合法源 U 包的 clean 与低城区输入、激活和旁路，再开启目标预测。所有 105 个接收机与场景组合固定后，本机独立对齐到原生 Full 冻结增强 W24 的同包 clean，逐包一致才打开标签。逐景及逐接收机记录准确率、净纠错和按固定接收机分层重抽物理包的配对 95% 区间。旧 Full 受扰分类仅在其原路线作证据。原登记 256 kHz 的正式历史结果保留原身份。

入口 `python -m experiments.pamf_lora_main.w24_residual_pilot publish`。N607 普通用户，优先 GPU 0、5、3 中有至少 12 GiB 余量的一张，8 个 CPU 信道工人。GPU 最长等待 30 分钟，模型来源、源冒烟、非有限、同包 clean 或完整预测矩阵错误即停止下游并保留工件。预期 `smoke.json`、15 份接收机冻结数组、activity、预测回执和独立评分。
