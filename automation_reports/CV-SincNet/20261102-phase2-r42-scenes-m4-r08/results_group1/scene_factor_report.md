## B 后 C 的资源测量

固定 P01/MIX01/1-1、seed1、K5/N20，对 R42 与原版、两种 support 路径各测三次 B 冷启动、从 A 直接 C、B 后 C。B 后 C 仅复用旧 support 特征，重新拟合完整核，不继承 B 的系数；12 次 B 后 C 的特征和模型状态均通过与冷 C 的比较。这项核验和耗时只对应该固定资源测试点，不能扩展为所有样本的独立准确率比较。实际耗时、三次范围与 GPU 共享状态见 [B/C 资源汇总](bc_resource_summary.csv)。

## 三阶段与 DURA 因子

A0 是未使用目标 support 的冻结基座；B 仅使用旧类 support 适配；C 使用旧、新类 support 注册。因输入和类别集合变化，B 到 C 的指标差包含新类竞争，不能单独解释为遗忘。A0 与 B 使用旧类宏准确率，C 另列旧类、新类、宏 H、macro-F1 和最低类别召回。

[完整 A0/B/C 和 DURA 路径表](factor_stage_summary.csv) 分开列出 MIX、LS、MU、LU；空白代表不适用，未填为零。融合 Q2 相对原版 raw/DURA 是跨输入比较，不能当成同输入。各单场景严格配对和融合比较见 [单场景配对表](scene_paired.csv)。
