# 相同缓存路径的 GPU 训练重复性

同一缓存、同一模型、种子、GPU 7 和五轮训练连续运行两次，不读取 TX 标签、F、V 或目标。两次分别耗时 77.14 秒、76.65 秒。

尽管输入与种子相同，最终 22 个参数张量仍非逐位相同，最大绝对差 4.247e-7；五轮损失和源分组浮点结果也存在差异。此前现算与缓存对照最大差为 4.210e-7，与此次同路径重复差异同量级。

这证明当前 GPU 路径的重复训练本身不保证逐位一致，但单次对照不能排除缓存产生额外差异，也不能推断地面预测是否一致。完整识别测试结果不受此诊断修改；确定性计算仍待核验。
