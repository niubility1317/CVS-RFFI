# DURA 恢复前端与信道压力测试

**VERIFIED / ANALYZED**。使用论文原版 Main split、三视图完整 PAMF，固定模型种子 2026092701 和 DURA v1.0。跨接收机、双跨各固定抽取 3,072 条物理记录。17 个条件中的每条路径使用同一输入。全部预测固定后，独立连接真值。试验共 170 个总体评测单元，含 TX 和 RX 分层共 2,380 条记录。[预测闭合](prediction_complete.json) · [独立评分](scoring_complete.json)

## 展开结构、身份保真及成本

同权重单阶段展开的锁定六景均值为 75.03% 和 71.18%，完整 DURA 分别高 5.87 和 5.84 个百分点。对应的新实现六景增益为 6.13 和 6.66 个百分点。单独读取 DURA 内部粗恢复输出在 clean 上仅为 15.98% 和 16.31%。本次固定 L-STF 正则化 LS-MMSE 均衡为 36.78% 和 37.92%。这两种读出的 clean 损伤须与完整方案的收益同时报告。独立训练的单次恢复网络已用同样本补测。完整 DURA 相对该网络，锁定六景增益为 6.26 和 6.34 个百分点。 [同样本单次恢复对照](../20261124-phase1-pamf-dura-single-advisor-s2026092701-r01/report.md)

以跨接收机锁定六景为例，DURA 使波形 NMSE 从 1.9744 降至 0.0342，对数功率谱 MSE 从 0.0953 降至 0.0108，冻结身份特征到配对 clean 特征的余弦距离从 0.0788 降至 0.0198。六景共 2,824 次错变对、1,194 次对变错，净增 1,630 次正确判断。Rayleigh 条件下，NMSE 仍从 2.0605 降至 1.0504，但特征距离上升，净减少 342 次正确判断。

共享 N607 RTX 3090 上预热后的 B1 中位延迟依次为直接识别 12.11 ms、导频均衡 15.09 ms、内部粗恢复 30.52 ms、单阶段 50.81 ms、完整 DURA 13.35 ms，均包含同一识别头。完整 DURA 使用固定 CUDA Graph，单阶段使用原生执行。该组实测反映各自运行路径和当时的 GPU 共享负载，不用于归因结构本身的计算量或推断星载能耗。[启动与实测时延](n607_launch_readback.json)
