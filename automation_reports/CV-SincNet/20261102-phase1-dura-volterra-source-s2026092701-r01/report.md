# Phase1 DURA 锚定的动态记忆修正

固定原始两阶段 DURA，先对当前受损 IQ 生成锚定波形；以该锚点为初始输出，使用输入驱动的动态复数记忆多项式预测线性和三次残差，输出连续 IQ 修正。新增修正网络 15,028 参数，不含 DURA、盲噪声估计器、保护门及分类基座；零初始化严格返回 DURA，保护门关闭时也返回 DURA。训练和推理均冻结 DURA、盲估计器及门控，不加载条件物理后验或设备身份。单条推理只访问当前 IQ；该网络为 DURA 的后置修正，区别于插入 DURA 内部的时间相关模块。

训练使用 8192 条与源验证、留出记录不重叠的源训练 IQ，固定第 21、22、23 轮视图，五轮后固定最后一轮。目标为 ±64 点时移与复增益对齐的中央 IQ 误差，加 0.2 倍冻结 Tri-SIG-TIME SSL 特征余弦误差、0.2 倍温度 2 软类别 KL、0.05 倍置信加权伪类别间隔和 0.05 倍截断对数功率比平方；对齐使用训练源配对 IQ，推理不访问干净 IQ。F 冻结，伪类别不是真实身份；本实验为 F-guided，不直接读取 TX 身份、U_s 真值、V 或地面测试。源记录此前已探索，不称盲测。

CPU 上重算 672 条固定源记录的 DURA 分类，与原 GPU 源对照决策一致；这只验证这些记录的分类，不保证波形位级一致。先执行 64 条源训练和 28 条源评估记录的真实预检；通过后完整训练、固定 672 条源预测，再连接合法 L_s 身份评分。预先登记 clean 与六个受损 Phase1 地面视图各 168000 条，全部预测固定后才独立评分、审计并报告跨 RX 和跨 RX+day。总集 clean 基准 86.538690%，相对下降 3% 的门槛 83.942530%，另报告下降 3 个百分点的门槛 83.538690%；已探索地面开发测试不代表独立盲测或真实卫星链路。

源实验 `20261102-phase1-dura-volterra-source-s2026092701-r01`，地面实验 `20261102-phase1-dura-volterra-ground-test-s2026092701-r01`。CPU 两线程、负载超过 72 等待；独立不可覆盖输出和 truth-last 评分，低分不停止健康任务。源或地面结果不得回流改变已固定模型。
