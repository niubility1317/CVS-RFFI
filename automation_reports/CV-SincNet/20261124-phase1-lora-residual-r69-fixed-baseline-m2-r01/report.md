# LoRa residual 固定 R69 三种子配对补齐

Residual practical 已有 seed 2026092702 的整套七景、15 台目标接收机和 30,000 个物理包对照。现有同种子直通、R69 半量及门控半量的预测和独立评分直接复用。已核对 N607，另两种子旧设想的 R69 重训目录和预测目录均未创建。补齐 2026092701、2026092703 时复用原 residual R69 2026092702 权重、实收投影和同一门限，只切换到原 Tri-set 的另两份冻结 F。此口径直接分离识别种子变化与恢复器变化。 [原 Residual R69 及首种子正式对照](../20261123-phase1-lora-dura-residual-gate-m1-r01/report.md)

此处复用历史 R69。其训练使用源 L/U 的 residual practical 信道配对、无噪目标作用及噪声方差，历史训练隔离 F、TX 标签和目标数据。本次权重、门限和 F 均不更新。推理只接收当前合法盲 IQ，每包六条 256 点对齐 chirp，R69 与投影后固定半量修改，并沿用现有扰动门。每条路线保持原有历史基线；full practical 的同冻结识别种子旧对照继续保留。

两个读者先复用真实 R69 源包无 query 检查，均通过才能打开已登记的 residual 盲预测缓存。每个种子写齐三路、七景和 15 台接收机，共 315 份预测。顶层状态必须等两个新种子都闭合后写入。独立本机评分进程随后按种子核对冻结元数据、合法物理包顺序、三路完整预测和已有 full 对照，再读取官方标签。报告 clean、六景、低城区、逐场景／逐 RX 和同包净变化。本次仅补正式对照，结果不进入 LoRa 恢复器的拟合、校准与选择。
