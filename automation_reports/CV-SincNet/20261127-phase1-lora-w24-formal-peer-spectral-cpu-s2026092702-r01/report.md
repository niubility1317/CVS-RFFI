# LoRa W24 跨 chirp 方向的条件式正式 Full 测试

该入口等待 48,000 步父训练的独立源域评分。只有跨 chirp 组达到此前登记的六景、低城区及 clean 门槛，控制器才接通目标预测。若源域未晋级，直接记录 \`SOURCE_NOT_QUALIFIED\` 并退出，不读取目标 IQ 或真值。旧两组 Practical 的 CPU 正式任务独立继续。 [源训练登记](../20261127-phase1-lora-w24-peer-spectral-direction-s2026112991-r01/report.md)

通过时，使用原冻结 PAMF W24 E104、默认头及原归一化，预测同一批 15 台未见接收机各 2,000 个物理包的 clean 与六种 Full practical 场景。复用直通、旧 DURA、旧复响应及全量调用旧 W24 的已封存同包对照。新增原固定幅度方向、仅本 chirp、跨 chirp 三路。三路均对每个实收包执行，参数与源预测一致。另保留 CPU 直通与原归档直通的逐景逐机分歧计数。

N607 单 CPU 预测进程，两个推理线程、两个重放进程，三个 10,000 包分片按序。正式盲预测前执行真实源 U 和冻结 E104 无目标检查。所有预测固定后由独立 Windows 评分器校验分片、活动计数、物理顺序、类别编号和 CPU 直通差异，再连接真值。跨 chirp 的正式验收以 162,000 次六景正确、25,500 个低城区正确包及至少 28,566 个 clean 正确包为准。 [实验登记](experiment.json)
