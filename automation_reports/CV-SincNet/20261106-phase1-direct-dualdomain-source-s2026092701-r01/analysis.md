# 独立时域频域恢复器：源域结果

独立模型 42308 参数，从零初始化，接收 IQ 直接输入；时域与复频域残差头初始为零。使用源 L_s/U_s 的 8192 条 IQ、3 个固定模拟 epoch、20 轮 GPU 训练。训练阶段 DURA、F 权重与输出、TX 标签、V 和目标读取均为 0；固定 checkpoint 后，DURA 才用于源域对照。

源准备 4.11 秒，20 轮优化 273.9 秒；训练损失从 0.975868 降到 0.729277。该预算和损失均不同于五轮 DURA 改进版，不能直接比较训练损失或成本。

| 源组（每组 48 条） | DURA IQ NMSE | 独立模型 IQ NMSE |
|---|---:|---:|
| RX8 clean | 0.00003287 | 0.26321471 |
| RX8 低城区 | 0.10067829 | 0.97427464 |
| RX4/6 低城区 | 0.03740450 | 0.94778126 |

这些源域波形指标明显弱于 DURA，但不是 TX 识别准确率；源样本曾被探索，DURA 也可能见过相应源域。不能把它当作独立泛化证据。根据预登记，冻结识别器的七景预测与独立 truth-last 评分仍继续，不能因源指标取消。当前 formal evaluation 为了与 DURA 配对，另外计算 DURA；独立模型本身不依赖 DURA。
