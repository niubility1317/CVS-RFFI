# 浅中层 Fishr 与 MixStyle：完成后的反思

本批 11 个固定方案、各 3 个种子全部完成。每个学生从对应原生 E20 追加 20 轮；全部 5,544,000 条 clean 预测固定后独立评分。84% 目标仍未完成。本文区分测试结果的事后解释与可用于继续研究的源域证据；不据测试排名调整方案、种子或重跑。

## 这次实际改变了什么

Fishr 接入浅层 time_down 和中层 t2.pool，梯度穿过身份骨干；用于读取梯度统计的两个辅助头先在冻结源特征上预热，之后辅助 CE 只更新头。MixStyle 直接作用于有标签 L 的额外身份前向，使用同 TX、同 day、跨 RX、不同物理包的合法供体，以身份 CE 优化骨干。它们并非只约束最终 embedding，也并非只训练一个与身份骨干断开的辅助网络。

新增三项可解释性对照：OLD_PAIR 与独立双批修正 Fishr 比较估计量；单层与双层比较作用位置；L_REPLAY 与 STYLE 比较额外监督前向和风格扰动。各 Fishr 行共享校准定义，系数只在训练前由合法 L 确定，训练中不按当前批追逐梯度比例。后端浮点计算存在极小差异，不能宣称跨 GPU 校准值逐位相同。

## 测试结果说明的范围

- F_BOTH 为 80.4302%，相对原 E20 提高 0.3798 个百分点，相对同预算 CE 续训提高 0.5419 个百分点。它相对 SSL 的三种子增量均为正，但相对原 E20 的第三种子仍下降 0.1643 个百分点。不能说所有种子均优于原基线。
- F_BOTH 相对 OLD_PAIR 平均提高 0.0931 个百分点，只有 2/3 种子为正。估计量理论偏差得到改善，并不自动意味着明显识别收益；三个种子不足以断言小差异显著。
- 浅层 MixStyle 相对 L_REPLAY 的三个种子均为正，平均增加 0.1589 个百分点；双层 MixStyle 相对 L_REPLAY 增加 0.0867 个百分点。额外身份 CE 不能被记成风格机制独有的贡献。
- JOINT 为 80.3484%，相对原 E20 三种子均增加，平均增加 0.2980 个百分点。完整风格路径与 Fishr 的交互量 JOINT−STYLE_BOTH−F_BOTH＋SSL 为 −0.1458 个百分点，三个种子均为负。这个交互包含额外 L CE，不能被解释为已证实的纯风格梯度冲突，更不能由此直接选择新的损失权重。

完整配对差、RX/TX/day、原错误修复与原正确破坏均见 [完整分析](final_analysis.md)。不使用目标域类别错误定位来指导后续训练。

## 完整源日志支持的判断

已核对 146,520 个主更新、660 个 epoch、3,000 个辅助头预热更新、21,600 次校准读出，以及所有源训练 stdout。没有遗漏行或异常标记。

1. **不能再把收益小简单归因于辅助机制没有梯度。** F_BOTH 的浅层分组 Fishr 合并梯度／主 CE 梯度均值约 0.123 至 0.153，中层约 0.067 至 0.079；JOINT 浅层约 0.151 至 0.192，中层约 0.086 至 0.101。这些是相应参数组、实际辅助步的范数比，不是全模型每步比例，也不能据范数推断方向正确。辅助头 CE 到身份骨干的审计梯度均为零，符合设计。
2. **风格路径确实被执行，但对已学会的身份任务仍较温和。** 合法 donor 覆盖约 99.79% 至 99.82%，实际改变约 47.90% 至 50.59%，记录的相对特征变化均值约 0.0348 至 0.0472。风格路径训练准确率仍约 98.70% 至 98.97%，和 clean 路径差异小。不同前向带有不同 dropout，已有准确率／改判差不是隔离后的风格因果效应。
3. **大量 U 被使用，不等于提供大量新身份信息。** 非 CE 行每个有效步都接受 128 个 U；固定同伴教师与学生分歧约 1.80% 至 2.06%，每批约 2.31 至 2.64 个。没有 U 身份真值，不能把分歧记成纠错。其余同判样本仍可提供概率分布约束，但是否只是维持成熟边界，需要源域诊断验证。
4. **统计目标不等于物理因素已解耦。** 此前源域审计发现真实 RX 下存在梯度统计差异，独立双批改善有限样本平方估计的偏差；这并未证明 RX 差异全是应删除的信道因素。TX 与接收响应耦合时，强制统计一致也可能改变有效身份证据。本批不能给出已实现物理可辨识解耦的结论。
5. **计算代价已经增加。** 同一共享 GPU 运行条件下，CE、SSL、F_BOTH、JOINT 的平均主训练及源诊断时间分别约 2.19、4.22、8.47、9.73 分钟。每个 Fishr 行另有 119,880 次辅助 L 样本使用；每个风格／replay 行有 511,488 次额外 L 使用。主更新相同不等于算力预算相同；这些墙钟数也不能当作独占硬件速度比较。

## 继续研究应先回答的问题

以下是由源诊断缺口形成的研究问题，不是根据测试排名确定的新实验配方，也尚未启动新训练。

- 对固定合法 L，在相同模型状态及可控随机数下，分别测浅层、中层扰动的身份 margin、真实 RX 差异方向、主 CE 梯度与 Fishr／风格梯度夹角，区分覆盖不足、任务太容易和方向相互抵消。不能仅继续放大正则系数。
- 对合法有标签源留出样本固定覆盖率，核实同伴教师真实修复、破坏及校准；父 E20 已见过全部源 RX，事后留一个 RX 不能冒充未知 RX 泛化。如果需要真正未见 RX 的证据，必须从初始化开始隔离该 RX。
- 比较早期学习与成熟 E20 续训时，应预先固定 scratch20 与 E20＋20 的训练方式和报告范围。先明确机制是否改变表征形成过程，再解释续训路径依赖；不能凭本批结果断言从头训练必然更好。
