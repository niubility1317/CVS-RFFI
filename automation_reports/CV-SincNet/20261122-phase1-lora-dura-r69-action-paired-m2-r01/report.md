# LoRa 原 DURA 接收作用的配对校准

沿用同合同的已冻结 LoRa R65 教师，保留原 R69 的粗恢复、接收作用估计、两阶段 prior 与四次 CG。前 600 次教师更新仅训练原接收作用估计器。以同物理包 clean 残差对齐到观测载波坐标，估计原实线性算子能否把这份波形映射成实际 practical。平滑后的误差约束可解释的信道分量，高频未解释残差设置方差参考。粗恢复与先验在这个校准阶段无梯度。教师随后 1,800 步恢复联合训练，学生复制该教师后两阶段后联合 2,400 步。保留原配对、相位、谱、恒等与两阶段蒸馏损失。联合期作用损失权重教师 0.15，学生 0.10。

先前对齐版使用相同的本 LoRa 数据合同和同一多个源信道 realization。训练作用、方差、先验与门控均不打开 TX 真值、F 或目标。先冻结同源带作用校准教师、学生，再用原合法留出源池拟合新恢复器效用门控。一次模型检查全量和半量，两档修正上限分别为观测 IQ RMS 的 15% 和 7.5%。

固定 LoRa 种子 2026092702，拼接同一个冻结 Tri-set 和已有六路对照，保留直通、固定、形状保护、上一轮高相干半量、未经作用校准的 R69 全量和半量。相同 30,000 包、15 未见 RX、clean 和六种 practical。840 份盲预测、56 个评分单元，冻结后独立评分。目标报告同 F 的纠错、错改、对角线变化、与 clean 的差距，以及新增作用监督是否比本 R69 原版产生真实收益。

使用 `python -m experiments.pamf_lora_main.full_dura_publish --draw-submit ... --stack-submit ... --r69-submit ... --r69-action`。N607 普通账户允许 GPU0–7，按容量选择。工作目录 `CV-SincNet/releases/20261122-phase1-lora-dura-r69-action-paired-m2-r01-release`，唯一输出 `CV-SincNet/runs/20261122-phase1-lora-dura-r69-action-paired-m2-r01`。真实 checker 验证估计器梯度和粗恢复无梯度，再运行固定训练、源波形审计、盲预测与独立评分。异常来源、梯度、限幅、预测或协议错误才停止。
