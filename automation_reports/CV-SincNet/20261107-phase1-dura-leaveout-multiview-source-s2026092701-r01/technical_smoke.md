# 留一视图教师候选技术检查

真实固定 DURA 权重及合法源域缓存用于本机 RTX 5070 Ti 的无 query 检查。对应源记录三个模拟视图的 clean IQ 对齐；每个训练视图的教师只取另两个视图的 DURA 输出均值。多尺度修正初始输出与 DURA 缓存逐值一致，六步源 IQ 更新的损失与两条修正头梯度有限，DURA 无梯度且保持冻结。

源视图教师构造、对应关系错误的拒绝、冻结 checkpoint 的来源合同及相关已有候选，共八项针对性测试通过；独立 P0/P1 审查未发现直接阻止合法运行的问题。此小样本检查不保存模型，不读取 F、TX 标签、V 或目标，不能代表识别效果或正式训练完成。
