# LoRa 私有复谱方向的偏差与噪声约束

## 预登记

原通用接收机扰动训练降低低城区 9 至 32 kHz 的复谱误差，但真实私有谱在参考方向的增益继续下降。另一轮匹配实验对两包合成弱差分约束复增益，真实源包低频增益有所提高，双路识别未提升。本轮直接约束原 clean 源包的逐 chirp 私有复谱，在相同方向计量正负噪声对的平均偏差和噪声响应。冻结接收机扰动权重作为唯一训练配方对照。 [接收机扰动消融](../20261124-phase1-lora-generic-receiver-physics-source-m3-r01/report.md) · [私有差分旧实验](../20261124-phase1-lora-private-secant-source-m4-r01/report.md)

沿用原包与弱差分分支及四个观测。取原包的两个半量输出，先统一回合法源 clean 的去扫坐标和尺度，再计算均值及半差。分别从均值误差、半差及 clean 参考中去掉包内 chirp 均值，保留各 chirp 独有成分。在 1–8 与 9–32 kHz 内，用各 chirp 的真实复谱方向做匹配投影，分母为该 chirp 同带真实能量均值加 1e-4。平均偏差和噪声响应分别取复增益模方的 log1p，按同一系数加权，两个频带均衡。合计新增损失权重 0.20。近零参考方向自然降低权重，复投影同时约束实偏差和正交相位泄漏。原粗恢复、全量、半量和真实弱差分损失全部保留。已有 Noise2Noise 通过同信号噪声观测的统计期望学习去噪。本轮使用合法源 clean IQ 构造私有方向，正负噪声用于测量同一方向的偏差与响应。 [Noise2Noise 原文](https://proceedings.mlr.press/v80/lehtinen18a.html) · [公开实现](https://github.com/NVlabs/noise2noise)

只在源 U 从零做一次端到端联合训练。与冻结接收机扰动组保持相同初始化、3,600 步、每步 12 包和四观测，并复用原增强、随机流、清洁旁路和恢复网络。5,000 个无标签源包拟合，2,500 个源 U clean 校准，500 包留出。推理只用单份实收 IQ 及已有实收估计，不计算投影损失或读取 clean 参考。冻结后两路各运行同一 900 个源 V 物理包的七景及共用 11,100 个 clean 补集，统一交给独立评分器。统计纠错和改错、逐源 RX、包级配对重抽区间以及单臂 B1。半量预定义为主读出，要求双路六景都超过接收机扰动组、秩四半量及匹配半量 DURA，两路低城区至少持平 DURA，完整源域 clean 至少持平直通。此次不读取目标。

定向 7 项测试、CLI 和一次独立 P0/P1 审查通过。执行提交 a0d57c3a2158209db1ac527662728f3441633d01。N607 首步真实权重 smoke，自动完成拟合、双路预测、clean 补集及独立评分。

## 识别与私有谱保真的关系

与同训练配方对照相比，半量在 Full 六景净多判对 15 次，在 Residual 净多判对 23 次。两个 95% 配对区间均跨零。相对匹配半量 DURA，Full 六景净多 2 次，Residual 净少 26 次。低城区分别比 DURA 多 14 和 5 包。Residual 粗恢复相较对照下降 129 次，95% 区间为 [−172, −85]。点估计收益集中在半量读出。完整 12,000 包 clean 上与直通逐包一致。新臂未满足双路六景晋级条件，未读取目标。

同分布的通用留出实验中，1–8 kHz 和 9–32 kHz 的方向噪声风险分别从 1.396 降到 1.187、从 0.0741 降到 0.0637。相应方向偏差风险分别从 5.502 小幅降到 5.472、从 0.218 升到 0.236。两路低城区回放中，9–32 kHz 的私有谱相对误差分别从 5.827 降到 4.139、从 2.997 降到 2.304，真实方向实增益中位数则从 0.620 降到 0.559、从 0.516 降到 0.499。因而本轮验证了部分方向噪声下降，实收的弱信号幅度仍未恢复。此前单独补幅也损伤了双路识别。后续应直接改善实收的结构估计，在许可源域诊断中同时衡量真实方向实增益、噪声泄漏与识别净纠错。
