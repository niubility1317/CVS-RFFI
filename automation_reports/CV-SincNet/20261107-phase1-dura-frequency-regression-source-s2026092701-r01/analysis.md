# DURA 源域全局频域回归诊断

从同一固定源上下文按物理记录索引划分，28672 条记录的三个视图拟合、4096 条不同记录的三个视图留出。同一记录的视图不会跨划分；但原 DURA 可能见过这些源记录，因此不能称为对 DURA 的独立数据。仅使用源配对 IQ，未读取 F、TX 标签、V 或目标。

学习每个频点共享的复数线性残差，输入为 DURA IQ、received IQ 及二者的时域共轭；使用固定 ridge 0.001。比较全局一组参数和按拟合集可观测物理方差/接收功率四分位分成四组的参数。源 clean 用于拟合及源误差评价，不作为逐条部署输入；本诊断未保存系数、未进行目标预测。

三个等大小源视图汇总：DURA 平均 NMSE 0.023956，全局回归 0.023814，噪声分组回归 0.023662；分组回归比 DURA 相对降低 1.23%，7910/12288 条记录改善。三个最低噪声组虽然平均误差也略降，但改善记录仅 1049/3046；不能假设逐条无损。

这些是源域配对波形误差，不是 TX 身份识别准确率。三个视图是训练缓存中的模拟视图，不能等同七景地面结果；有价值的方向仍需冻结实现后进行完整七景测试。[逐组数据](result.json)，[登记](experiment.json)。
