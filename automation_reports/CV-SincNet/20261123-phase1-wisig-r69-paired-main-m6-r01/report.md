## 对照与数据

固定 Main split 的原三视图 Tri-SIG-TIME SSL，按种子编号固定取 2026092701、2026092702 和 2026092703，均沿用原三视图最终 E50 学生和联合训练的默认分类头。对每个种子分别用同一冻结 F 做直通和 R69 后识别，共两条接收路线、六行。每行包含 clean、六种 practical、仅跨接收机 126,000 包和双跨 42,000 包。两个子集按物理 ID 互斥，可汇总为每景 168,000 包。

Residual 复用历史 Main split 的 residual/post_sync/noeq 输入。Full 在相同 168,000 个物理包上沿用原冻结信道实现、每景配置、随机命名空间、种子和虚拟接收机设置，仅切换到 full/post_sync/noeq。按物理 ID 核对两路 clean IQ 逐条一致，并先落地全部 full 观测再用于预测。两路线共享同一 R69 权重和 Graph-RR 推理。报告准确率、按景和接收机的纠错与改错、clean 正确数、六景及三种子配对结果。

原 R69 是 Main split 的固定 LU 对照，265,000 量级完整网络的确切参数量为 266,951。沿用原 stage2 固定 E20/4,940 步权重。其训练历史使用合法源 IQ 的实值配对波形和冻结上游教师，信道作用及新增噪声方差由模拟器向上游训练提供监督。推理接口仅接收当前 256 点实收 IQ，由模型内部估计等效作用和方差。新候选的研发权限另按现行目标约束，本轮只建立冻结基线。

## 发布与停止

N607 普通账户、沿用原 WiSig 三视图 release 的五套依赖。先在真实源 L 上对冻结 F ＋ R69 执行一次无目标检查。通过后并行生成 full 观测和运行 residual 预测。六行预测均固定后，以单独 CPU 进程先核实全部行再连接目标真值。每条路线最多三条不同物理 GPU 的并发预测；按显存和当前实际 PID 选择可用槽。FP32、TF32 关闭、批量 128。输入契约、非有限输出、识别器绑定、输出碰撞或评分完整性失效时停止后续派发，保留已写结果。

同一发布根和输出根各只有一个 owner。精确命令、代码版本、环境、逐行种子及产物在 [experiment.json](experiment.json)。独立 P0/P1 启动审查通过，核对全部 168,000 个同包 clean 字节一致，并用一个物理包逐景复核原 residual 输出以及配对 full 的有限值。本地两项聚焦检查通过。

## 接收端输入核对

WiSig 原始采集用 25 Msps。作者均衡时先转换到 20 Msps，用 L-STF 自相关找起点并校正频偏，再用 L-LTF 估计信道并做 MMSE 均衡。随后把频偏重新施加到波形，并转回 25 Msps 保存前 256 点。后续估计器可用频偏估计对齐包内相位，同时保留冻结识别器原有的波形坐标。[WiSig 原始论文 §IV-B](https://arxiv.org/pdf/2112.15363#page=4)

在合法源 U clean 上按种子 20261123 抽取 4,096 包，只读 `U_s_x.npy`。第 80 至 199 点的 20 点延迟归一化复相关绝对值中位数为 0.924，10% 至 90% 分位为 0.700 至 0.997。16 点延迟的中位数为 0.083。第 200 至 255 点的 20 点延迟中位数为 0.103。该结果支持在前导内部用 20 点重复结构做接收估计。后段需按各自结构判断。此次只验证结构可观测性，未拟合估计器或使用源 V、目标数据及标签。
