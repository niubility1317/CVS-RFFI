# LoRa W24 原配方和原生 Full 恢复对照 r03

替代 [r02](../20261125-phase1-lora-w24-native-full-s2026092702-r02/report.md)。r02 在 GPU 3 用真实源 U 冒烟时，原 W24 Sinc 前端读自定义滤波器的张量版本计数，`torch.inference_mode()` 产生的张量没有这个计数。r03 的分类器调用使用原 W24 的无梯度执行口径。r02 在打开目标输入前退出，保留日志和发布。r03 沿用冻结 E108 原配方和三项配对矩阵，原始物理身份及预测、评分规则保持一致。
