# 受界动作表示与跨日接收机成分：三种子结果

**源域诊断完成，状态 VERIFIED。固定收缩的共享接收机分量在全部 27 个“留出 TX＋留出日”条件优于零预测，达到预登记的下一步研究条件。84% clean 目标仍未达成，本轮没有新增身份训练或目标测试。**

这次结果改变了后续动作：可以继续设计稳定接收机分量约束，先做源 V 身份保持核验；不再仅因上一轮统一缩小后的 oracle 很弱，就否定受界物理动作的局部表示能力。

## 跨 TX 与跨日预测

量化口径：完整 joint160 接收机组差的预测 MSE / 零预测 MSE，越低越好；不是识别准确率。每种子含三个 TX 留出折×三个日期。固定系数 0.4 在运行前已登记，没有根据结果调整。

|模型种子|系数 1，跨 TX＋日期|系数 0.4，跨 TX＋日期|0.4 有收益条件|
|---|---:|---:|---:|
|2026092701|1.084136|0.958587|9/9|
|2026092702|1.044445|0.939026|9/9|
|2026092703|1.028177|0.929107|9/9|

固定双半包检查（A 拟合→B 评价，反向亦然）共有 54/54 个条件优于零预测，误差比均值 0.943528。分组按物理 ID 固定，三个模型用同一划分。

系数 1 的效果明显较差，说明未经收缩的跨 TX 共享偏移不能直接全量减除。0.4 的成功也仅支持已知源 RX 的保守关系估计，不能当成未知目标 RX 的校正器。所有父网络曾见全部源 TX/day；留出发生在辅助估计器，不是端到端未见环境训练。

## 接收机差异由哪些部分构成

对 RX 中心化后的平衡 TX×day×RX 组均值作平方能量分解。各项在该描述性分解中正交相加；这里没有训练正交损失。

|模型种子|稳定 RX|RX×日期|TX×RX|TX×RX×日期|
|---|---:|---:|---:|---:|
|2026092701|22.79%|2.03%|64.26%|10.92%|
|2026092702|25.75%|1.93%|61.63%|10.70%|
|2026092703|26.67%|2.39%|58.39%|12.54%|

稳定 RX 分量约占 23% 至 27%，而 TX×RX 项约占 58% 至 64%。这解释了单个全局 R 位移为什么难以覆盖大多数差异，也说明“所有 TX 共享同一特征扰动”假设过强。不能据此把 TX×RX 项全部视为应删除的噪声，它可能同时包含身份与接收机响应的耦合。
稳定 RX 与 TX×RX 项在双半包中的交叉能量均为正且接近其全量能量，说明它们能在固定不重叠包子集中复现。把全量能量减去交叉能量解释为估计噪声，需要包误差独立且零均值；本实验未验证这些假设，因此不作因果或纯噪声结论。

## 直接受界求解修正了先前的保守估计

|模型种子|无界局部 oracle 误差比|无界解整体缩小|盒约束最优解|盒约束解释比例|
|---|---:|---:|---:|---:|
|2026092701|0.654059|0.971164|0.735660|26.43%|
|2026092702|0.582836|0.972830|0.676194|32.38%|
|2026092703|0.620868|0.967153|0.716290|28.37%|

逐条件块直接约束每个动作坐标在 [-1,1]，保留每个组自己的平均 Jacobian；不再让一个过大的坐标迫使所有坐标等比例缩小。最优解比统一缩小解好得多。
54 个 block×parent 求解全部核验通过：最大边界误差 2.22e-16，最大投影梯度 1.11e-15，相对零预测目标的凸一阶差距界最大 1.7e-14。实际 SciPy 版本为 1.15.0。
这仍是读取待解释位移的 oracle，表示的是局部线性模型的能力，不是预测方法的成绩，也不证明有限 IQ 动作能产生相同特征变化。不能把约 29% 的组差解释比例换算成识别准确率提升。
算法说明：[SciPy lsq_linear 官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.lsq_linear.html)。

## 下一步落实范围

预登记条件已满足：每个模型、每个留出日均至少 2/3 TX 折有收益（实际全部 3/3），三个模型的稳定 RX 双半交叉能量均为正。下一步优先采用稳定 RX 分量作为保守 R 约束的估计对象，再检查源 V 中真实样本的身份 margin、错误变化及接收机分层。检验时只用 L_s 拟合，V 不更新任何参数。
需要同时保留两项边界：固定 RX 估计器只用于源域训练约束，最终推理仍由身份骨干完成；TX×RX 项暂不整体压缩，避免误删身份相关变化。物理动作路线若继续，先学习可跨 TX 预测的受界动作，再做真实 IQ 核验，不能直接使用 oracle 动作训练身份骨干。
任何新的 E40 三种子训练须先冻结具体 R 目标、权重和同预算 CE 对照，并保留 clean 自动独立评分；不能把这份诊断称为 84% 性能目标达成。
