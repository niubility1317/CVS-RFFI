# 受界动作表示与跨日接收机成分

状态：LOCAL_VERIFIED，尚未执行。设计在运行前固定。

上轮源域诊断显示：全局 RX/day 共享位移跨 TX 的 9 个折均比零预测好，但条件 Jacobian 预测未稳定优于原 R。本轮只回答两个未决问题：统一缩放是否低估了动作边界内的表示能力；共享 RX/day 位移是否包含跨日稳定的 RX 成分。

使用原始三个 E200 纯 CE 基座的同一批 6,300 个源域包缓存、归一化 joint160 和 8 维导数。无身份更新，无 V 拟合，无 U/target 读取，无自动目标测试。所有身份父模型曾见全部源 TX/day，因此这里只检验辅助关系留出，而非未见环境的端到端模型泛化。

1. **受界局部 oracle**：逐条件块求 min ||A a - delta||²，约束每个组常量动作坐标在 [-1,1]。A 使用当前组自身的平均 Jacobian，并对块内势函数中心化。使用 BVLS，tol=1e-10、max_iter=1000，保留可行性、投影梯度和凸一阶差距界。它读取待解释位移，只作局部表示能力上界，不能作预测置信度或训练目标，也不保证有限 IQ 动作有效。与无界解和原统一缩小解同口径比较。
2. **平衡成分分解**：在 RX 中心化的 TX×day×RX 组均值上，分解稳定 RX、RX×day、TX×RX、剩余三因素项。各项平方能量应严格相加。这是描述性分解，不直接识别硬件或信道因果。
3. **固定双半包核验**：物理 ID 加固定盐后排序，每组拆成两个不重叠的 35 包子集，三个模型使用相同划分。保留 signed cross-half 能量，包括负数。cross-half 可抑制独立零均值包噪声的解释需要额外假设；不重叠 ID 本身不证明统计独立。
4. **跨 TX 与跨日预测**：三组 TX 留出折，分别测试 RX/day 同日、RX-only 同日和 RX-only 留一日。只在拟合 TX/day 上计算源 RX 偏移，报告 full/full、A/B、B/A，固定系数 1 与 0.4 的全部结果。0.4 来自上轮平衡环境 ridge 的有效缩放，运行后不调整。已知源 RX 预测不能解释为目标新 RX 校正器。

下一步规则：固定 0.4 的跨 TX＋留一日预测，在每个模型种子、每个留出日都至少 2/3 折优于零预测，且三个模型的稳定 RX 双半交叉能量均为正，才考虑稳定 RX 约束的训练设计；仍需先检查真实源 V 的身份保持。oracle 单独不能触发训练。本 run 不启动身份训练。

验证：6 项合成检查覆盖盒约束解析最优解、秩亏情况、分解与负交叉能量保留、TX/day 拟合隔离、已知稳定接收机效应迁移、双半分组不重叠与完整覆盖。独立 P0/P1 审查结果随后记入 evidence。

算法参考：[SciPy lsq_linear 官方说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.lsq_linear.html)。实际运行版本随结果保存。
