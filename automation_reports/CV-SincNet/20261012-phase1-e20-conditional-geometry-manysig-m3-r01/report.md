# 下一项源侧问题：方差相同是否掩盖身份对应关系

这是一项数学与合成实现研究，不是当前六行实验的改版。它来自对实际估计器的核对，不依据任何目标得分，也没有改变现行训练、选择规则或队列。

## 当前估计器实际保留与丢失的信息

当前 `unbiased_variances` 先按TX分层抽样，再估计每个RX中六类均匀混合分布的梯度方差。它**同时包含类内方差与类间均值散布**，不能误写成“只约束类内方差”。最终 `penalty` 匹配各RX的这个混合方差，未逐个TX匹配条件均值。

Fishr 原始方法也是域级损失梯度方差正则；本项目采用浅中层虚拟仿射坐标及有限总体修正，是自身的扩展。[Fishr作者实现与说明](https://github.com/alexrame/fishr)。以下反例针对统计量的信息边界，不反驳该方法的经验效果，也不证明本项目失败原因已经确定。

构造六类敏感度模板为六个基向量。每个RX分别置换“TX标签对应哪一个模板”，但各RX都有完整同一组模板。所有RX的混合分布完全相同，因此均值、对角方差乃至完整协方差都相同；同一TX跨RX的模板对应关系却不同。只增加非对角协方差仍无法识别这个反例。

CPU/CUDA合成检查中，现有有限总体A/B方差目标为0或2.05e-34，完整协方差跨域最大差小于2.8e-17；保留TX索引的交互能量为0.133333。输入为人工敏感度矩阵，不是实际IQ或分类准确率；没有证据表明真实网络恰好出现了类别置换。

## 候选统计：只约束身份与接收机的交互

固定day和层，记 `M[y,r] = E[g | TX=y,RX=r]`。先保留两个主效应，再计算交互项：

`B[y,r] = M[y,r] - mean_r M[y,r] - mean_y M[y,r] + mean_yr M[y,r]`。

这样，TX共同的身份模式、RX对所有TX相同的加性变化都不会被这一项直接惩罚。它测量“接收机是否以不同方式改变不同身份的损失敏感度”。它不等于消除全部接收机信息，也不保证全部交互都是有害因素。

可用原有独立A/B采样得到 `B_A/B_B`，构造 `J = mean(B_A * B_B)`。样本均值是有限总体均值的无偏估计，双重中心化是线性运算，所以在A/B独立条件下，`E[J] = mean(B_population²)`。两批允许重复遇到同一物理样本；关键是独立抽样，不是强制批间互斥。无需对均值额外应用当前方差估计器的有限总体系数。

不能把同批次的 `mean(B_A²)` 当作无偏量：合成零交互例中，其期望为0.08125，而独立A/B内积的完整枚举期望约为0；非零例的真实能量0.01125，独立内积期望仍为0.01125。每例枚举16种单批抽样与全部256种A/B组合。负的单次交叉值是合法噪声，不能截断为0而仍声称无偏。

此外已检查加性TX/RX主效应不改变B、总方差四项正交分解、合成小型卷积网络CE导数的混合二阶回传，以及权重／缓冲／模式／RNG／已有梯度均未改变。该小型卷积检查不是生产CVS网络检查，尚未发布新训练。

## 下一步真实源诊断的固定范围

先固定原始纯CE旧门控＋cos E20的三个种子，不从任何测试排名选模型。对各模型的完整合法L_s 6300条，在eval模式提取浅层time_down、中层t2.pool的真实CE/margin原始虚拟坐标导数，同时保留原逐样本归一化margin作为统计参考。三个模型都已见过五个源RX；本诊断不能冒充未见RX验证。

逐day、TX、RX形成90个单元，每单元70条。完整均衡总体分解为：TX主效应、RX主效应、TX×RX交互、单元内散布；以精确分解读回验证。另报告当前混合方差目标、条件均值交互、类别均值散布与实际样本幅度。固定全L尺度只作离线单位换算，不回填当前训练在444步的校准尺度。

身份与接收机向量均只在内存中用于统计；不保存IQ、逐样本特征、派生模型或优化器。每模型L6300一次前向覆盖，batch128共50前向；三个模型合计18900条读出、150前向，CE/margin由同一次logits计算两次一阶反向。无身份／辅助头更新，不读取U/V用于前向或拟合，不访问target。原checkpoint和所有运行任务保持不变。

下一次发布前，必须登记这三行只源诊断并核对原始E20完整来源、真实单元计数、state/RNG保护及输出统计。诊断回答实际信号是否存在，随后才决定是否把交互项与原Fishr/MixStyle做固定三种子训练对照；不能由本合成反例直接宣称性能改善或84%可达。


## 本次诊断实现与资源

本包落实上述三个原E20、完整L_s的固定诊断，身份／辅助头更新均为0。生产每模型50前向6300L、100次一阶求导；三行合计150前向18900L、300次一阶求导。远端发布预检另计3前向24L、6次一阶求导。每卡最多3个总进程，当前六行训练不变。

readout在原生CVS身份网络的同一次logits上直接求CE/margin导数，保留原逐样本RMS margin作为统计参考；aggregate分解严格按三个day、六TX、五RX、每单元70条。两层×三统计×三day＝每模型18条汇总，每条包含30个源单元聚合量。浮点64用于总体分解；网络读出保持注册FP32策略。不同阶统计的数值大小不能直接当成同等训练权重。

源cache含V，由反序列化一次性载入后丢弃，返回的L无V样本；不打开U缓存。模型参数、缓冲、模式、RNG和已有梯度核对不变，不保存逐样本梯度或特征。checks用原生随机网络合成180条验证读出与汇总，非生产模型性能。preflight另核对原始三个E20完整来源并在真实L上每模型读8条。无target入口，无独立测试评分；本次仅报告source统计和实际成本。


补充固定离线对照：每模型32次同TX/day内的均衡RX标签置乱，保持每RX单元70条。所有统计／层复用同一组置乱，diagnostic_seed=model_seed+507127，再加day*100003+index*1597。只复用已读出的内存梯度，不增加前向、不改真实标签／源cache或训练配置。保留全部置乱结果，用作有限池描述性参照，不把尾部计数当作总体显著性结论。
