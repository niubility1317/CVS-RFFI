# 浅层和中层条件敏感度：源证据与下一步假设

本记录依据 `20261012-phase1-e20-conditional-geometry-manysig-m3-r01` 的完整源 L 诊断撰写。三个模型均为固定原始 E20；本记录不读取正在运行的 energy6 目标成绩，不据其结果选择下一步方法。

## 已知结果

六个 seed×层组合中，raw margin 经完整 L 固定 RMS 换算后的 TX 主效应占总中心化能量的 35.38% 至 54.35%，TX×RX 交互占 10.69% 至 17.82%。归一化 margin 的 TX 主效应为 55.47% 至 68.83%，交互为 6.90% 至 14.61%。所以逐样本归一化没有消除全部接收机关联，也没有使身份信息本身消失。

CE 的对应交互为 5.80% 至 10.23%，单元内散布为 81.33% 至 89.08%。这与其导数受置信度加权一致：少数低置信样本可能占较大能量。该观察不能单独证明 CE 优于或劣于 margin，也不能证明散布均为噪声。

18 个 seed×层×统计汇总的交互能量均高于各自 32 个同 TX/day 平衡置乱控制。但这只是有限源池描述，未建立时间独立性、可交换性或总体显著性；不能将 0/32 写成 p=0。

当前混合梯度方差包含类内方差与类均值散布，并非完全忽略类别。但是，它没有显式约束同一 TX 跨 RX 的条件均值对应关系。此前合成反例和本次真实源关联共同支持检验这个缺口；它们都不能证明去除该关联一定改善未知 RX。

## 下一轮固定研究问题

保持 shallow `time_down` 和 middle `t2.pool` 的特征增强及虚拟仿射探针，研究条件交互约束是否比混合方差约束更有用。模型最终层仍用身份 CE；不把所有改动移到最终 embedding。

在同一个 day 的完整 6 TX×5 RX 关系格上，令 M[y,r] 为一个层内的条件敏感度均值，定义

`B[y,r] = M[y,r] - mean_r(M[y,r]) - mean_y(M[y,r]) + mean_y,r(M[y,r])`。

用独立 A/B 抽样的 `mean(B_A * B_B)` 估计交互能量。保留 TX 主效应以及与 TX 无关的共同 RX 主效应，约束身份判断对接收机的条件依赖。该交叉估计可为负；不截断，不用同批平方替代，不宣称获得物理可辨识的发射机/信道分解。A/B 在有限池中独立抽取时允许重合。

拟验证三种机制，每种固定三个 seed，scratch20：

1. **MARGIN_INTERACTION**：raw margin 固定层 RMS + 条件交互，替换对应混合方差项。
2. **CE_INTERACTION**：真 CE 敏感度固定层 RMS + 条件交互，替换对应混合方差项。
3. **CE_MOMENT_INTERACTION**：真 CE 的混合方差与条件交互相加；两项各用源梯度标定后等权组成辅助方向，共享原来的总梯度上限，不把两个独立上限相加。

固定第三种为组合主假设，同时报告全部三种，无目标成绩驱动的淘汰。对照使用已冻结 energy6 中同 seed、同目标的 MARGIN_ENERGY / CE_ENERGY，并报告固定原始 P0。现有 energy6 的结果无论正负都保留，不改其训练、不选择性重跑。

其余机制继承 energy6：三种子、20 epoch、合法隐藏 TX 的 U 主路径、无 EMA/星地增强、浅/中层受控 MixStyle、E2 后辅助启用、每 4 个身份更新一次 A/B 辅助、总辅助梯度分组上限 0.2、固定 final20、V 仅健康检查、逐行自动 clean prediction 后独立 truth-last 评分。对照方法的目标预测不参与参数、候选或标定选择。

实现前需要明确记录新增交互项的梯度标定细节。继续复用同一批 A/B 前向；混合方差项和交互项分别测量梯度，组合项只共享总上限。新增求导、耗时和峰值显存须如实计量，不能把相同 epoch 说成相同计算量。辅助标定只使用本行合法源 L，禁止把本次 E20 离线 RMS 直接回填 scratch 模型。

## 必要边界

同一 TX 的接收机关联也可能含有效可识别信息。保留 TX 主效应是统计上的保护，不保证训练参数更新完全不会影响身份，因此还需记录身份梯度与辅助梯度关系、实际裁剪、分类损失和每层更新量。新方法的有效性最终由完整固定三种子 clean 测试检验，84% 仍未实现。

本文件是源证据支持的后续设计，不代表九行实验已注册或发布。正式运行仍须逐行登记、原生混合二阶导数检查、独立 P0/P1 审查和发布后状态读回。
