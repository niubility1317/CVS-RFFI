# Phase1 自适应 Hankel 奇异谱恢复：实验登记

本实验探索独立于 DURA 内部结构的恢复器，同时保留与 DURA 对照和未来组合的可能。固定 Tri-SIG-TIME SSL 地面基座及既有源域物理后验、噪声估计和门控；不读取 Phase3 数据。物理后验继承冻结基座的伪类别先验，因此属于基座引导方法。

## 结构与训练

对物理后验 IQ 的 225×32 复数 Hankel 矩阵计算奇异值分解。以奇异值能量、秩位置、噪声尺度和接收信号相对后验的差异作为输入，训练 16161 参数的秩域网络，预测有界奇异谱修正，再通过反对角线平均重建 IQ。网络零初始化时严格保持原后验；干净保护采用固定的既有门控。物理后验、门控与分类基座保持冻结，DURA 不作为该模型的一部分加载。16161 参数仅指新增秩域网络。

使用不与物理先验拟合集及源评估集重叠的 8192 条源训练记录，分别取第 21、22、23 轮已固定信道视图，训练 5 轮并固定最后一轮模型。损失包含配对波形和冻结基座特征，训练不直接读取 TX 身份；不使用目标真值训练或选模。训练后先固定 672 条源预测，再进行独立 truth-last 评分。源域已被探索，不称盲测。

## 预检及正式评估

先执行真实源数据预检：64 条拟合记录、28 条评估记录，并检查复数 SVD、梯度、有限值和冻结状态；预检失败则停止。预检通过后训练和固定预测。完整地面测试包含 clean 和六个受损场景，各 168000 条，全部预测固定后才独立读取真值评分；同时检查跨 RX 和跨 RX+day 子组。既往 clean 基准为 86.538690%，相对下降不超过 3% 的门槛为 83.942530%；下降不超过 3 个百分点的门槛为 83.538690%。该地面开发集已被反复探索，不能称为独立盲测或真实卫星结果。

源实验标识 `20261102-phase1-adaptive-hankel-source-s2026092701-r01`，地面实验标识 `20261102-phase1-adaptive-hankel-ground-test-s2026092701-r01`。运行使用不可变发布目录及登记提交；每任务 CPU 两线程，调度检查负载、GPU 显存及计算进程数，GPU 阶段与 DURA 控制器使用同一把锁。结果较低不作为终止健康任务的理由。当前登记不包含实验成绩，实际成绩以固定预测与独立评分文件为准。
