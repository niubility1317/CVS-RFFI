# LoRa 星地恢复的自然弱指纹保真对照

## 机制与权限

同一源 RX 的两包真实 IQ 各自完成相位及载波坐标对齐，提取它们在去载波坐标中 1–8 kHz 和 9–32 kHz 的实际复数差。把差的一半放回第一包的坐标。原包及带自然差异的同源副本施加同一份通用扰动，恢复输出在第一包坐标中的差须按两段分别保住。另有一份独立扰动用于普通同包一致性。接收端只看到当前 IQ。该对照研究自然差异的有限差分保真，与此前固定人工探针的实验分开。论文创新性仍需与最相近的原始工作和公开实现核对。

两个候选共用恒等观测模型、同一初始化与数据种子 2026112991、相同生成输入、三视图及单一 AdamW 优化循环。波形对照附加保真权重为 0，保真候选为 0.35。粗恢复／细化和一致性权重 0.35／0.65／0.10 均固定。每条 1,800 步、batch 12，同一批包来自同一源 RX，五台源 RX 各 1,000 个未带标签的 clean U 拟合包、500 个 clean 校准包和 100 个留出包。源恢复训练隔离标签、F、V、目标、practical 方案和仿真真值。五组中的留出包只用于诊断合成压力下的保真误差。

## 验证矩阵和发布

固定区间及全量、半量输出在源端从两路观测分别独立验证，共六个读出。每路用五台源 RX 的 900 个相同物理包及同一冻结 Tri-set 2026092702，完整 clean 和六景。比较直通、成熟 DURA、波形对照及新机制，并报告逐包纠错、改错、低城区、逐 RX 和 clean 门控。两路共用同一候选权重与仅源 clean 拟合的同一阈值，预测全部固定后源侧独立读真值。源验证作为筛查，目标三种子完整验收保持原范围。

N607 普通账户，入口 `python -m experiments.pamf_lora_main.natural_detail_source publish`，执行身份由 Git commit 确定，独立 release CWD 与不可覆盖输出根 `20261123-phase1-lora-dura-natural-detail-source-m4-r01`。真实源 smoke 后将两个 fit 和两路 score 各自分散到两张实际可用的 GPU，每卡总计算进程最多四个。混合精度用于卷积，复杂运算和评分保持 FP32。技术停止条件为源契约、非有限梯度、冻结校准或评分闭合失败，已产证据保留。预期有两条训练日志与冻结权重及两路预测、逐景评分和配对分析。
