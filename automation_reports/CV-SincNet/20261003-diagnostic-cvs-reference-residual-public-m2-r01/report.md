# 参考约束残差架构：公开可行性验证

状态：ANALYZED。新架构12项聚焦验证及独立审查通过；正式72输入、144算子前向、120差异对照完成，独立NumPy重算VERIFIED。真实源训练与测试尚未启动。本轮不根据历史测试排名选择架构。

## 架构与研究问题

前一轮完整源域诊断表明，自由动态核能携带接收域信息，但未显示相应去信道作用。本设计以已知L-STF激励约束“条件量怎样作用于信号”：对80:160内四个20点周期做相对CFO校正，用公开320时移模板匹配，在9个周期延迟基[-4,4]上求可微正则最小二乘响应；9个有界正则参数经原单CE学习。该量是表观周期响应，delay−4与周期delay16等价，不声称实际物理CIR。

从各周期观测减去该参考响应，再采用公共复标量或逐频响应的共轭正则逆处理残差。两臂完全相同的神经编码器处理2×80残差并零出口融合到原始CVS身份特征。原始IQ/PA通路始终保留；不会把参考拟合能吸收的TX线性或IQ失真一并作为唯一身份输入丢弃。原始实现锚为residual_fusion类，不加载其历史权重，也不是按测试分数选定checkpoint。

全部训练约束仍为原CE、无增强、无辅助损失、无新训练策略；本轮只执行未训练算子的公开探针。原型的初始整体函数与自身从零原CVS完全一致，三步合成CE检查显示全部参数获得有限梯度，新增正则参数在出口打开后得到非零梯度。补偿层采用明确FP64/complex128运算以解决逆响应对舍入误差的放大，神经参数/原主干仍FP32；后续须测实际资源，不称为纯FP32全算子。

## 固定公开验证

六种TX算子×四种信道×三种RX算子，共72输入，两臂共144次前向。TX含理想、线性记忆、IQ镜像、三阶/五阶非线性及三阶记忆；信道含无多径及delay1/4/16的两径；RX含理想、IQ镜像及三阶非线性。所有激励在负时间也由解析式生成，不以零填充伪造前历史。完整系数及矩阵唯一源为experiment.json所指physics.py。

同时报告残差中的TX差异保留和同一TX差异在H/RX变化下的漂移，不以“残差更小”直接称为性能更好。独立NumPy实现重算完整算子、中间状态、输入级联和全部120个TX差异对照。这里没有真实设备标签或分类准确率，不能替代最终测试。

## 先行工作与声明边界

前导估计与ZF均衡后接神经网络已有研究：[KAN-ResNet与ZF均衡，2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC11991494/)。因此不把已知参考均衡、最小二乘或动态滤波本身宣称为首创。候选贡献是可学习正则响应、残差补偿与原始指纹保留的耦合结构，是否足以支撑论文仍需完整相关工作与真实实验。

已知单一周期激励仍存在TX/信道/RX混淆。强均衡可能擦掉TX差异，原始旁路保留信息并不自动保证跨接收机泛化。先根据本次公开物理证据判断候选是否值得固定源训练矩阵；不以测试结果调参或选择性重跑。

结果不支持逐频补偿普遍优于标量控制：IQ镜像的漂移有所降低，PA三阶/五阶与记忆三阶的漂移反而放大。线性TX差异残留很小，导致相对漂移的分母很小；必须同时看绝对差异，不能据此单独判定泛化。加入RX非线性后，逐频补偿的优势进一步不稳定。单一周期激励只在占用频率约束表观响应，未激励频率的逆响应依赖有限延迟基外推；公开结果展示了这一限制。
