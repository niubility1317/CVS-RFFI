# 浅中层敏感度的目标与归一化：源侧研究结论

本文件记录数学分析和合成数值核验，不改变正在运行的 18 行训练或本轮 18 模型优化器诊断。现有测试结果不用于选择本文件中的方向、种子、权重或重跑。84% 三种子均值仍是未达成目标。

## 原始方法与当前实现的差别

Fishr 原文与作者实现对齐不同训练域的损失梯度方差，理论讨论联系到 Fisher 信息及局部损失几何。当前实现则对主身份 margin 关于浅中层虚拟通道仿射坐标的敏感度做逐样本 RMS 归一化，再计算按身份、RX 条件划分的有限总体 A/B 方差差异。它不是原论文的分类器参数梯度实现，不能因同称 Fishr 就把原方法的结论完整迁移过来。[Fishr 论文](https://proceedings.mlr.press/v162/rame22a/rame22a.pdf)；[作者代码](https://github.com/alexrame/fishr)。

MixStyle 作者实现强调在较早的特征层混合统计量，并建议避免最靠近预测层的位置。本项目当前 time_down、t2.pool 的放置符合浅中层研究方向；但同身份、同 day、跨 RX 的供体规则、困难候选搜索和双向受限变化都是本项目扩展，仍需自身的射频识别证据。[MixStyle 作者说明](https://github.com/KaiyangZhou/mixstyle-release)。

## 可精确推导的关系

设六类主身份 logits 为 z，真实身份为 y，当前 margin 定义为：

`m = z_y - logsumexp(z_k, k != y)`。

则单样本 `CE = softplus(-m)`，对于同一个浅层或中层虚拟坐标 v：

`g_CE = dCE/dv = -(1-p_y) * dm/dv = -w*g_margin`。

这里 w 仍在计算图内。进一步对身份权重求导时，w 的导数必须保留；把置信度分离后再乘回去，会改变真正的混合二阶导数。

若 RMS 归一化不含 epsilon 且梯度非零，则 `normalize(g_CE) = -normalize(g_margin)`。整个坐标向量变号不改变域内方差，也不改变当前方差差异的 A/B 内积。因此“CE + 同一逐样本归一化”不能被当成一个普遍不同的新机制。

实际 epsilon 为 1e-6，精确关系是：

`normalize(g_CE) = -g_margin / sqrt(mean(g_margin^2) + (epsilon/w)^2)`。

当 w 很小或原梯度很小时，两者会明显不同；不能声称无条件等价。原生 CE 在低精度、极高置信度下还可能出现数值饱和。上述关系用于解释，不建议通过分离的 w 人工近似 CE 二阶梯度。

## 已完成的数值证据

合成 float64、六分类、逐样本仿射坐标检查已通过，完整结果在 `evidence/loss_sensitivity_identity.json`，可运行入口是 `experiments/cvs_scratch_optimizer_audit/loss_sensitivity_identity.py`。不读取源 IQ 或目标数据，不进行参数更新。

- CE 与 softplus(-margin)、原始梯度恒等式、对身份权重的混合二阶导数均通过解析对照。
- 无 epsilon 的归一化变号误差为 1.78e-15；本组合成非退化输入在实际 epsilon 下的误差为 6.47e-11。
- 显式近零反例的归一化差为 0.9999，验证了“只在远离稳定项时近似等价”的边界。
- 将 w 分离后，合成二阶导数的差范数为 0.1534，说明保留置信度梯度不是可忽略的实现细节。

这些是数学与实现证据，不是实际源域梯度分布或目标性能收益证据。

## 下一项值得区分的机制

后续应区分“margin 的方向约束”和“CE 的真实幅度约束”，而不是只更换名字：

|固定对照|待检验因素|
|现有逐样本归一化 margin|已存在的参考机制|
|原始 margin 敏感度，不逐样本归一化|单独检验保留幅度|
|原始 CE 敏感度，不逐样本归一化|进一步保留真实身份损失的置信度幅度与混合二阶导数|

这是机制方向，不是已发布的新训练矩阵。若进入下一批，应保持浅中层位置、A/B 源数据采样、身份网络、20 轮预算、三种子、同一 MixStyle 方式和 U 监督来源一致；使用各机制自身的源 L 梯度进行原有固定校准。对比归一化与不归一化时不能沿用数值相同的旧系数冒充同等强度。所有未修改的健康实验继续完成。

当前 AdamW 诊断会补充“同一损失梯度究竟引起多大权重位移”的证据。梯度限幅、实际位移和最终泛化是不同问题：更大的位移既不自动有效，也不自动无效。新的损失敏感度仍是虚拟特征坐标的 Fishr 类机制，不称作原论文的完整复现，不从源侧数学结果承诺 84%。
