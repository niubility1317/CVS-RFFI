# 同一冻结识别器下的 clean 保留与恢复净纠错

低档城区，DURA v1.0 的总正确数是 raw clean 的 79.50%，而原 clean 正确样本的逐条保留率为 73.78%。另有 5,744 条 raw clean 和受损直接识别都错、经恢复后识别对。

复用原地面训练完整 Tri-SIG-TIME SSL 默认头的 Main 两类总体，共 168,000 个原物理样本。三路都以真实 TX 计正确与否，分别比较 raw clean、该场景受损 IQ 直接识别和同一受损 IQ 经恢复后的识别。原七景、四路、两个总体的 56 个预测单元早已完整固定并评分。本次只复算已有决定。

原 raw clean 正确 145,385 条。DURA 输出总正确数等于保住的 clean 正确数加上 clean 原本错误、恢复后正确的数量。其中一部分 clean 错误在受损 IQ 直接识别时已经转正，三路配对将这部分从恢复独有的纠错中分开。

直接处理 clean 输入时，DURA 把 330 条原错误改对，把 201 条原正确改错，净增 129 条。跨接收机和跨接收机与日期分别净增 55 条和 74 条。这表明同一冻结识别器确实可从变换后的 IQ 获得判别收益。仅凭这些决定无法确认是哪一类物理发射机特质被增强。

低档城区，DURA 使 39,676 条原 clean 正确、受损直读错误的样本重新识别正确。同时把 13,638 条原 clean 和受损直读都正确的样本改错。与该景受损直读相比，总计修复 45,420 条，损伤 16,530 条。

## 固定源特征指导的收益来自哪里

相同结构、源预算和输入下，历史 TF 源特征指导版在低档城区比纯 IQ 版净多对 13,968 条。其中原 clean 正确组净增 13,806 条，占总净增的 98.84%。原 clean 错误组净增 162 条。clean 和受损直读都错、仅恢复后正确的计数从 4,352 变为 4,049。这组固定对照的主要收益是减少原身份判别能力的损失。

## 核实与适用范围

全量原 raw 决定与同一 F0 官方缓存逐条一致。三路计数与原准确率及受损直读配对逐项一致。全程没有新的模型前向、IQ 读取、训练或正在运行的新候选结果访问。结果是既有 Main 的历史回顾，用于区分“总准确率接近 clean”和“同一批 clean 正确样本得到保留”。无法给出波形恢复的理论上限，也不作为新模型或测试条件的选择依据。
