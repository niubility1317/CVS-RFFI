# 原地面 Tri-SIG-TIME SSL 的三种恢复比例

本分析只复算已完成原 Main split 的正式聚合与三方配对计数，没有新 IQ 读取、模型前向、训练或目标真值访问。原实验在 cross_rx 126000 和 cross_both 42000 两组全部视图预测固定后独立评分；固定同一 Tri-SIG-TIME SSL 原默认头及 DURA v1。基础数据和结果见[原主测试分析](analysis.md)、[逐条三方配对](clean_received_three_way.md)。目标测试已在开发中曝光，仅作事后描述，不用于选模或调参。

原 raw clean 判对 145385 / 168000，即 86.538690%。下表将“恢复几成”分为三个不同口径，全部使用对应的同一物理样本和真实 TX 正误：

- **准确率相对值**：恢复后正确数 / raw clean 正确数。它比较两个整体正确数，分子分母不必由同一批正确样本组成。
- **clean 正确样本保留率**：恢复后仍判对的 raw clean 正确样本数 / raw clean 正确样本数。这是逐条保留率。
- **信道差距净挽回率**：(恢复正确数 − 受损直接识别正确数) / (raw clean 正确数 − 受损直接识别正确数)。分子是净纠错，已经扣除新损伤；不等同于所有错误样本的修复比例。仅在本表分母为正时使用。

## 低档城区的逐条解释

受损直读正确 86696 条；DURA 恢复后正确 115586 条。其中相对受损直读错变对 45420 条、对变错 16530 条，净增 28890 条。原 clean 相比受损直读多 58689 条正确，因此净挽回率为 28890 / 58689 = 49.23%。

恢复后正确的 115586 条中，有 107262 条属于原 clean 也正确，保留率为 107262 / 145385 = 73.78%；另有 8324 条原 clean 识别错误而恢复后正确，其中 5744 条在 clean 和受损直读都错误。这证明固定识别器对部分恢复输出更易作出正确判断；它不能证明重建出的发射机物理特征是真实的，也不表示总体胜过 clean。

对已完成的独立 MismatchedPrior，低档城区正确 116744 条，相当于 clean 正确数的 80.30%，原 clean 正确样本保留率为 75.64%，信道差距净挽回率为 51.20%；仍距 3 pp 线 23601 条，且两个 clean 群体均下降。该已曝光目标结果只作实际历史描述，不按场景拼接为一个部署模型。

## 边界

上述三个数均是固定识别器和这批样本的识别统计，不是 IQ 波形、真实发射机信息的恢复百分比，也不是任何算法的信息论上限。原地面接收 clean 本身包含接收机与环境影响；固定分类器在某些转换后可能比原 clean 判得更好。要量化波形失真须在权限允许的独立评分侧比较对应 IQ，不能将历史旧 F50 或其他观测的 NMSE 改标为本测试。

六景 DURA 正确数与原正式结果一致；逐景将两个总体的 clean、受损、恢复正确数及错变对/对变错之差与正式结果独立复核，六景均闭合。新训练模型尚未完成的事实不因本分析而改变。
