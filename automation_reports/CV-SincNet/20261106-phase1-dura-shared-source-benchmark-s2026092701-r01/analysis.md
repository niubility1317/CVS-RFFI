# 三个冻结恢复器的源域共享推理验证

在 Phase1 源 L_s/U_s IQ 的 14 个 RX/场景组中各取 8 条，共 112 条。固定原 DURA、Tri-SIG-TIME SSL 和三个已冻结的正交恢复模型；不读取 TX 真值、V 或目标数据，不训练或更新模型。

分别运行三套独立前向与一次共享 DURA／物理上下文、共享 raw 和 DURA 分类器前向。所有批次、三个模型的 DURA 输出、创新方向、噪声方差、恢复 IQ、raw/DURA/恢复后分类器 logits 均做逐字节比较，差异为 0。比较前确认三套 DURA 和分类器权重逐字节相同。

N607 CPU、两个线程、batch 8，独立串行前向合计 5.306 秒，共享前向 2.454 秒，比例 2.162 倍。计时按批次交错测量，仅为同一机器、同一时段、112 条源样本的小规模串行结果；不等于多进程并行吞吐或完整七景加速。

本验证不读取或重放目标测试记录，不能证明 168000 × 7 的完整测试输出逐位一致；也没有迁移或中断现有三个预测进程。若未来要接管正式测试，仍需先确定可恢复的输出边界并完成适用范围内的等价验证。
