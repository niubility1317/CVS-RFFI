# 有效风险监督能否改善第二阶段身份学习

状态 RUNNING，已核实 N607 进程、实际配置和日志。目标保持 clean 三种子均值至少 84%。上一轮源机制诊断在同一离线预算下发现：STATE 输入下，CE、margin、rank 监督的 V 候选间隔排序一致率三种子均值分别为 51.13%、81.09%、82.23%；打乱身份条件后，后两者下降到 76.61%、76.86%。这支持检验监督目标与状态条件，不代表身份分类收益。没有使用目标测试成绩决定本矩阵。

## 物理变化与身份目标

保持既有 L-only 接收机频谱 bank：L 排除当前 TX 和 day，U 仅使用 RX/day，不读 U TX。其他四个 RX×0.5/1.0 两种强度共八候选；33tap 有限 FIR，截断前幅度约束 ±3dB，512 点线性卷积并保持包 RMS。它是可实现的源 RX 作用近似，不等同于真实目标信道。

前 888 次身份更新只用 L CE。之后 L clean/动作 CE 经 888 步渐入至各半；U 使用当前学生 clean eval/no_grad 的软概率，置信度阈值 0.95、KL 权重 0.25、固定噪声标准差 0.015，与对照完全一致。没有 EMA、权重平均或星地信道增强。所有非 CE 行使用全部合法 U 的无标签训练流，不解封 TX。

风险输入是 40 维直接 IQ 统计＋现有身份模型 160 维归一化特征＋6 个 clean logits，再加 8 维动作系数。复用身份表示，不增加身份分类骨干。状态在当前身份模型 eval/no_grad 下计算，随后恢复每个模块原模式；风险损失绝不回传身份。网络两层宽 48，共 12721 参数，以相同状态的零动作输出作差，确保零动作风险为零。全部标准化均复用原 L 统计，V/U 不拟合统计。

采样固定为 50% 均匀＋50% softmax(同包风险减均值/标准差)，标准差下限 1e-6、温度 1。不按 V 或 target 调温度。预热权重从物理阶段开始即可使用，不再依赖 CE 饱和后的在线冷启动。RFIX 固定辅助权重，但身份状态随骨干变化；RANK/RFIX 专门检验这种变化是否要求在线更新。

## 在线辅助步骤

每四次身份更新执行一次（不是每四个 epoch），取当前 L 批最后最多 32 个样本，在当前身份模型 eval/no_grad 下测 clean 与全部八候选，共每步 288 包次身份前向。MARGIN 监督为真实类相对最强竞争类间隔的下降，SmoothL1；RANK 对同包 28 对候选使用 logistic 排序，真实间隔差绝对值大于 0.01 才参与。身份状态、目标和动作系数均隔离梯度。独立 AdamW，LR 0.001、weight decay 1e-4，与已验证辅助预热优化设置一致。

RANK/MARGIN 各 1998 次辅助更新、63936 个 L 包次、575424 个辅助目标身份前向包次。所有物理行各有 1022976 个 L 和 1022976 个 U 动作视图。风险选择还需相同数量的 clean 状态前向，额外成本单独记录。RFIX 无辅助 optimizer 或更新。预热的共享历史成本单独引用，不把它算作零成本或在所有行重复归入身份训练耗时。

## 核验与测试

本地检查覆盖六方案 native 前后向、控制目标相等、辅助对身份零梯度、零动作锚定、RFIX 无训练参数、U dummy TX 毒化不改变 bank、延迟启用与各行预算。远端 preflight 对三种子三种风险用法逐一加载实际 E200 和辅助权重，核验真实 U 动作与 L 在线损失。独立 P0/P1 审查后以固定 Git 版本发布；每卡最多三个总进程，八卡共享，不影响其他健康任务。

源 V 只检查遗忘和异常，不追求小幅准确率提升，不选 epoch；已见 RX 的 V 不冒充未知 RX。训练记录逐步损失、辅助梯度、候选排序、动作分布变化、U 覆盖、身份权重移动、每 epoch JSONL/CSV 和详细文本。身份更新结束后，每行立即冻结 final，自动对固定 168000 clean query 逐样本预测，再由独立 scorer 连接 truth 并复算，全部六方案三种子完整报告。测试推理仅使用身份模型。排序改善与 clean ≥84% 是不同结论；未证实完整三种子目标前不宣布成功。
