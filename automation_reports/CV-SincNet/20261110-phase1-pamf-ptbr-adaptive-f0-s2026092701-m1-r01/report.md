# PAMF 物理分支自适应参考梯度预算：单种子对照

状态：预登记，尚未启动。run 为 `20261110-phase1-pamf-ptbr-adaptive-f0-s2026092701-m1-r01`；候选、数据权限、父模型、路径、训练预算、停止规则和产物见 [experiment.json](experiment.json)。本方案与固定 0.1 参考预算候选的比较在后者目标评分前固定；历史 F0 基准和先前方法的目标结果已暴露，因此不能称整个研究从未接触测试数据。

本方法保留旧版完整三视图 PAMF、普通 PL0.95、β=0.5 的已知有界双径干预、五分支关系、L/U 各 0.05、每步相同抽样及 E20＋10＋20 训练日程。只对参考分支的 L/U 关系项施加同一个当前批次标量。对参考投影参数 `θ_ref`，`g_base` 为原真实标签监督完整目标和原普通 PL 的梯度，`g_ref` 为两条物理参考关系项按既定五分支平均及权重计算的合计梯度；令 `s = clip(||g_base|| / (||g_ref|| + 1e−12), 0.1, 1)`，若参考关系梯度近零则 `s=1`。比例停止梯度，直接 L／PL 和其余四条分支关系不变。比例只由当前源 L/U 批次计算，不用源 V、目标数据或 U 真值。

该方案由全量源 V 的 F0 梯度探针和 11 设置源采样探针启发：参考关系与直接梯度比值随条件明显变化，固定 0.1 不一定合适。探针本身只是固定模型 eval 局部结果，完整限制见[研究报告](../../../docs/reports/pamf_physics_branch_ssl_20261110/report.md)。本候选的优化路径与 GradNorm 等已有梯度平衡思想相关，不宣称全局首创或性能保证。`s≥0.1` 允许关系梯度在下限时超过基准梯度；该公式不判断梯度夹角，也不能保证 Adam 实际参数更新、身份保真或未见 RX 的收益。

比较同 seed 普通 PL、等权 β=0.5、固定 0.1 参考预算；前者已有结果直接复用。候选使用自身同契约 F21 scratch E20 前缀，新增 6660 次更新，源筛查与固定预算候选一致：最终 V 较普通 PL 不低于 −0.2 pp、较等权 β=0.5 不低于 −0.1 pp，记录锚点、非有限值及自适应权重的全程分布。筛查不取消预登记的单 seed 七景和 weak 测试。目标预测全部冻结后独立 truth-last，完整同 row、RX/day/TX/scene 及同包净纠错分别报告。

每步额外计算两次对参考参数的梯度，不增加部署图，但总训练计算不等于等权或固定预算。须如实记录实际耗时、显存及尺度是否经常触及上下限。为保护 GPU 配额，本 run 等固定预算 owner 退出、无运行任务且匹配分数可用后发布；真实 F21 E20 无查询 smoke 是首个运行步骤，需验证自适应比例实际执行、有限梯度和 L/U 可用性。当前无真实运行或性能结果。

源物理诊断会运行并记录，但它的孤立技术失败不取消已冻结模型的预登记预测及独立评分；缺失诊断会保留为技术缺项，不将整个实验标为完整。系统性训练、预测或评分失败仍按停止规则停止新派发并保留健康任务与已有产物。

核心 L/U 钩子、比例上下限、零关系梯度、空 U 接受集合、隐藏标签权限及来源规则已做聚焦验证。强制 `s=1` 时，合成真实分支图中的总损失和全部参数梯度与等权 β=0.5 实现一致；涉及源／U／目标边界及原方案回归共 23 项检查通过。使用虚构路径执行完整调度准备，验证两种匹配对照、候选冻结依赖和评分依赖；另用 dispatcher 状态机模拟诊断失败，确认两类预测及两类评分仍完成，缺项保留为 `PARTIAL_TECHNICAL_FAILURE`。唯一独立 P0/P1 审查发现源诊断被误设为额外放行依赖，该问题已修复并通过一次定向复核；未发现其他直接 P0/P1。真实 checkpoint smoke 与正式运行仍待执行。
