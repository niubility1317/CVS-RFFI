# LoRa W24 的 CPU 正式 Full 星地测试

N607 CPU 评测控制器发布后只等 r02 的两组 24,000 步权重冻结。两组均进入试验，源域准确率不影响资格。冻结 W24 E104、默认头、原处理和主测试 15 台接收机保持原口径。先跑真实 checkpoint 的无目标冒烟，再完成 clean 与六种 practical、共 30,000 个物理包的 Full 盲预测。独立评分等待三个分片全闭合才读标签。

两组候选在 CPU 推理，历史直通和恢复对照沿用已封存 GPU 预测。另记 CPU 直通与旧对照的逐景、逐接收机预测分歧。相同包和相同 Full 信道观测用于配对。单预测进程用两个 CPU 线程，最多两个并行信道生成进程。
