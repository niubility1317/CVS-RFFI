# LoRa full 与 residual 实际作用反演诊断

## 对照与目的

三阶段联合恢复在强 residual 场景带来较多错改。本次建立实际同包作用、噪声及裁窗的源域反事实，比较作用可信时的反演收益、只扣新增噪声的收益，以及地面参考恢复后的识别上限。Full 使用原 1 MHz 复数前导和注册的连续随机轨迹，保留真实上下文、时变分数延迟、主及镜像通路与原 AGC。Residual 使用原 256 kHz 的六个独立冻结快照，保留同包几何和原延迟补偿。已知轨迹只在源域诊断，模型拟合更新数为 0，目标访问为 0。

逐包验证作用于原始输入时重建无噪声接收波形，最大相对误差限定 2e-9。已知无噪和已知新增噪声须逐值重建实际接收精度，经注册裁窗后与 full 源 V 缓存核对。Residual 另外执行常规路线读出核对。求解器随后仅接收观测和已知作用，使用配对波形检查用的真实输入不进入数值逆问题。最小二乘迭代上限 30，固定绝对/相对容差 1e-5，正则 `clip(sqrt(3*noise_power),1e-5,1)`。两组分别求解原观测和已扣噪声的观测，正则完全相同。反演使用原 native 观测上下文，随后按每包 RMS 归一化为原分类输入。其余诊断保留相同投影门，维持观测载波，非载波修正幅度以每 chirp RMS 0.15 平滑限幅。

读取直通、各路成熟恢复半量、仅扣已知新增噪声、有噪已知作用求逆、扣噪已知作用求逆、两种求逆的有界载波保留读出以及配对 clean。后六路有物理真值、噪声或配对接收波形，仅用于定位差异。配对 clean 读出在独立实际 IQ 上等于同包直通 clean。使用同一个冻结 Tri-set 2026092702；六景读出相互独立、在当前包上执行。

## 固定矩阵和发布

每台源接收机取 60 个源 V 包，共 300 个物理包，避开上轮联合恢复的 900 包面板。两路共用同一批包，均完成 clean 与六景、全部固定读出。所有预测先同时写齐七景，再独立连接该路线的已见源 V 标签，逐景、逐接收机、逐配对物理包统计净纠错与 95% 配对区间。不访问目标数据或查询。验收线继续使用 67.0% 与原低城区、clean 约束，先导结果不替代三种子正式评价。

运行 `20261123-phase1-lora-dura-exact-action-source-m2-r01`，入口 `python -m experiments.pamf_lora_main.physical_inverse_source publish`。N607 普通账户和既有 LoRa Python，独立发布根/输出根，CWD 为发布根。GPU 优先顺序 3、6、2、0、4、1、5，两条路线分 GPU，最多总计算进程 4 个/卡，作用反演每路使用 8 CPU 工作进程。真实源包 smoke 执行两个代表场景，要求精确重放、有限输出和合法基线。重放失配、数据、非有限、预测闭合或评分失败即停止该轮后续派发并保留产物。预期双 smoke、七景固定预测、作用复现误差、分类成绩和配对区间。
