# 固定 DURA 对源输入相位旋转的响应

固定 DURA v1.0，将 672 条已探索的合法源接收 IQ 分别旋转 0°、90°、180°、270° 后运行恢复器。逐记录比较恢复输出与两个参照的归一化波形均方误差：原 clean（原相位）和同步旋转的 clean（同步相位）。另比较输出对原 DURA 输出的相位不变与相位等变偏差。误差按原 clean 能量逐条归一，14 个源 RX/场景组各 48 条；下表为 14 组等权均值。未读取 F、TX 标签、V 或目标数据，未更新模型。

| 输入旋转 | 对原 clean 的误差 | 对同步旋转 clean 的误差 | 更接近原 clean 的记录数 |
| --- | ---: | ---: | ---: |
| 0° | 0.022517 | 0.022517 | 0/672（参照相同） |
| 90° | 0.688313 | 0.904047 | 331/672 |
| 180° | 1.209449 | 2.598393 | 475/672 |
| 270° | 0.978161 | 0.659872 | 214/672 |

分组差异很大。以 90° 为例，RX4/6 clean 相对原 clean 和同步旋转 clean 的误差分别为 1.797451 和 0.135592，RX8 clean 分别为 1.866789 和 0.168627；这两个 clean 分组的 96 条记录均更接近同步旋转参照。同一旋转下，RX4/6 低城区分别为 0.174920 和 1.661262，43/48 条更接近原相位；RX8 低城区分别为 0.225137 和 1.632877，46/48 条更接近原相位。

这表明固定 DURA 在这些合成扰动下既不是全局严格相位不变，也不是全局严格相位等变，响应随源样本和场景明显变化。可研究依观测条件进行相位处理的独立网络，但不能从本诊断断定该网络会提高识别准确率；当前两个独立相位网络和 DURA 修正的训练与七景矩阵不变。

输入旋转是事后构造的合成扰动，并未验证其分布与真实信道一致；clean 两种参照刻画的是不同假设，并不自动确定真实正确相位。源 pilot 曾被探索，DURA 可能见过其中记录。波形误差不证明发射机身份信息、目标识别收益或真实在轨性能。真实 checkpoint 的 8 条源样本 smoke、5 项聚焦测试和一次独立 P0/P1 审查通过，完整原始数值保留于远端本 run 的 `result.json`。
