# 条件相位恢复器的源域理想旋转诊断

固定原 DURA 和完成 5 轮训练的条件相位模型，对 672 条合法源 pilot 比较：原 DURA 输出、根据同记录 clean 求得的 ±90° 内最优单位幅度整体旋转、以及训练所得整体相位／幅度分支。该逐记录理想角仅用于本诊断；源训练合法使用 clean 配对，但未使用此理想角，部署时没有 clean。14 个源 RX/场景组各 48 条，下面为各组等权均值。候选的训练 ID 与 pilot 互斥；原 DURA 可能见过 pilot。未读取 F、TX 标签、V 或目标，也未更新模型。

| 源指标 | 结果 |
| --- | ---: |
| 理想整体相位角逐记录绝对值的均值 | 0.030955 rad，约 1.774° |
| 已学习整体分支有效相位角绝对值的均值 | 0.000596 rad，约 0.034° |
| 原 DURA 波形 NMSE | 0.022517 |
| clean 参考理想相位旋转后的 NMSE | 0.020358 |
| 仅加入已学习整体相位／幅度分支的 NMSE | 0.022522 |
| 完整双分支模型的 NMSE | 0.022465 |

逐记录理想相位在 670/672 条上降低波形误差；理想整体旋转的组均 NMSE 比 DURA 低约 9.59%。相比之下，已学习整体分支的有效相位平均幅度较小，单独加入该分支时 264/672 条波形误差低于 DURA。这一比较支持继续研究如何从可观测输入估计相位，但不能证明当前网络必然有缺陷：理想角逐记录使用 clean，并可利用该条样本的噪声；部署时不能获得它，也不保证它可由输入可靠预测。

理想相位只在所指定的单位幅度整体旋转族内优化，不是任意恢复网络、身份准确率或真实在轨性能的上界。源 pilot 曾被探索，且 14 个分组不代表独立真实链路。波形误差、理想相位和分支行为均不能代替冻结 Tri-SIG-TIME SSL 的完整七景识别评分；本诊断不用于调整或取消已固定候选。真实 DURA 与候选 checkpoint 的源样本 smoke、四项聚焦测试和独立 P0/P1 审查通过。
