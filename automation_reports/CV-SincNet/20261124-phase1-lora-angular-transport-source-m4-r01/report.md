# LoRa 同物理 IQ 改动量的复数修正方向

[预登记矩阵](experiment.json) · [运行事件](events.jsonl) · [混合方向隔离诊断](../20261124-diagnostic-lora-mixture-directions-source-m2-r01/report.md)

先前固定八个实收混合专家后，配对 clean 路由相对实收路由两路线净增 17、44 次。同物理剂量的精确诊断方向相对按波形选择专家，分别额外净增 56、258 次。这次两臂用完全相同的逐包物理 RMS 约束，检验频带复方向是否可从接收观测和合法源波形学到。

## 接收前端和两段更新

| 输入 | 来源、时点及误差 |
| --- | --- |
| 当前包六条对齐前导及定标 | 同一套去扫跟踪器计算每条有效频偏、复相位、RMS 和置信。使用实际收到的六窗，保留原采样关系，局部失配下有效频偏会混入时偏。 |
| 统一跨频先验 | 两组各在同一批 20,000 个源 U 上从零计算公共和独有 I/Q 协方差。当前包的非载波方差保持读出作为解析半量基准。先验统计包含原地面硬件和接收变化。 |
| 公共和独有方差代理 | 当包在去扫、Helmert 坐标下的双边外带功率中位数。逐维按圆复高斯近似换算。硬件侧带、有色干扰与跟踪误差可能使估计偏移。 |
| 相对作用和留出创新 | 用真实奇偶前导互作参考，在四点时间锚上用交错八点块正则拟合复作用与预测残差。绝对作用未知，留出量也包含器件独有成分。 |

在去扫的频域中，粗层用实收、解析修正、对折参考、接收估计作用及方差产生复数提议；细层额外读取粗修正、粗恢复后的波形及前向观测创新。平行组把每个学习系数投影到该频点原解析方向，允许不同频点的增量大小和符号变化。复方向组保留额外的复法向。在时域内按各 chirp 的物理 RMS 加权移除提议沿整包原解析半量的分量，将正交长度限制在原向量长度的 1.5 倍，最后缩回原半量范数。两臂在训练、预测和同权开关时均有相同预算，主读出最多编辑原实收 RMS 的 15%，相对原方向最多约 56.3 度。读取矩阵另有两倍剂量对照，其上限为 30%。各输出保持去扫载波并在未经重采样的原坐标叠加。

每组一次端到端从零训练 40,000 步，batch 24。源 U 拟合 20,000 包，门限和留出分别 2,500、500 物理包。训练分别优化粗细恢复到合法未叠加扰动的源波形、非载波谱误差、跨通用扰动一致性、源实测公共与独有弱谱差异的复数保真、前向误差超过当包观测预算的惩罚。只使用目标独立的通用突发扰动，训练不接收精确逐点噪声、场景、TX、冻结识别器或任何目标数据。两路使用相同的冻结权重、同一 U-only clean 阈值。

DnCNN 通过卷积残差学习去噪。这里的网络用合法源波形约束恢复，经过观测条件、解析参考方向与固定物理范数限制，独立比较同剂量下复数方向。LoRa 两遍同步使用波形可见前导识别并补偿时频偏移。本轮沿用已登记六窗的坐标，在该坐标内调整非载波复谱。 [DnCNN 原论文](https://arxiv.org/abs/1608.03981) · [作者公开实现](https://github.com/cszn/DnCNN) · [LoRa 两遍同步原论文](https://arxiv.org/abs/2502.08485)

## 冻结矩阵

两条路线复用同一 Tri-set 种子 2026092702、同一组 900 个源 V 物理包，分别完成七景和 13 个固定读出。主读出预定为完整复方向，在两路线分别超过匹配半量 DURA 且保持 clean 才晋级，评测只在终步冻结后运行。双路所有预测固定后由独立 CPU 读取标签。新增噪声只在评分后的隔离波形审计中计算方向余弦。

## 合法源 U 等量方向核查

独立 CPU 使用同一 U 分区重算解析方向，在 500 个合法留出 U 包上生成固定通用扰动。对每包，在给定原解析半量 RMS 和最大允许角度下，直接用合法未叠加扰动源 IQ 求平行与完整非载波修正空间内的几何方向。五台 RX 的中位几何角在平行空间为 9.73° 至 11.81°，完整空间为 13.25° 至 14.56°。相对平行几何方向，允许额外复方向进一步降低归一化波形平方误差的逐 RX 中位数为 0.000746 至 0.001067，500 个包均减少超过 0.00001。这项核查未使用识别器、源 V、目标或实际逐点噪声。首个审计输出发现浮点残余载波可能进入平行参考，复算显式对两组去除参考载波，并验证完整空间包含平行投影；训练和预登记未改变。 [匹配方向复算](../../../tools/lora_angular_direction_bound.py)

## 波形和方向归因
