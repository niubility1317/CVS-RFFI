# 原 Tri-SIG-TIME REPL 的 LoRa 六 chirp 适配

以合法同合同 LoRa E140 纯监督模型中已训练的三视图骨干和原分类头初始化。保留固定局部序列重排和 LoRa 参考响应。原 backbone 按每个 chirp 前向，聚合六段 160 维特征后使用同一个原分类头。该初始化由包含 LoRa 附加分支的历史监督训练得到。本次适配仅启用其中原 Tri 骨干与分类头，额外分支不进入预测。两条行共享同一原分支起点，记录初始源 L 与七景 V 指标。

固定种子 2026092702，28 轮、2,464 个联合更新。标注批次按已验证的五接收机均衡包布局全部覆盖 2,800 L。标注保留 .01 平滑、ordinary/raw 双视图 KL、浅层与中层跨 RX 对比、As 双 CE 和 As KL0；As 在合法同包 practical 视图中轮换。U 每步 64 个物理包，每轮无重复抽样。保持原 .95 当前学生硬伪标签、无 EMA、raw As、1.25 归一化、六次学生前向、同伪类跨接收机共享样式方案、融合特征对比 .05、原头外推 .25 和三组 L 锚 U 梯度保护。保护前后 U 梯度范数、点积、限幅和冲突、接受率、标注和冻结源 V 七景轨迹均记录。比较原 U 权重 6 与预先固定的 LoRa 降权 3。

两种 Tri 权重均覆盖固定 15 个目标 RX、同一批 30,000 包、clean 和六种 practical，合计 210 个独立盲预测数组、14 个新评分单元。独立评分同时比较同种子普通 PL、原适配 Tri 及候选集合 Tri 的已冻结预测。U 真值仅在预测完成后由授权的独立程序接入，给出逐轮和按类伪标签正确率。该轮分离识别器变化，恢复器组合后续独立登记，绝不利用测试真值选择本次权重、轮次或门槛。

使用 `python -m experiments.pamf_lora_main.full_adaptive_publish --warmup-submit ... --native-repl`，源端同合同监督及 E140 发布记录。N607 普通账户，GPU0–7 容量调度，输出目录 `CV-SincNet/runs/20261122-phase1-lora-native-tri-repl-m2-r02`，CWD `CV-SincNet/releases/20261122-phase1-lora-native-tri-repl-m2-r02-release`。真实同合同权重及合法源 IQ 的六次 U 前向、配对和保护更新 smoke 通过后，自动并行训练两行、完成盲预测和独立评分。任何合同、梯度、步数、前向或矩阵技术错误即停止。

继承 r01 冻结的两行设计和科学判据。r01 在实际 N607 源 smoke 中因 Torch 2.1 与 NumPy 整数数组直接索引兼容错误退出，未启动训练。r02 仅以项目 tensor 转换构造索引，并显式导出逐包记录，避免依赖 NumPy 桥。原目录与日志保留。
