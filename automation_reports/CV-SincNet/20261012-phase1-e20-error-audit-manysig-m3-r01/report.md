# E20 浅中层机制的源域纠错与梯度诊断

本轮检查新增目标是否有纠错信息，保持原生 CE＋旧门控＋cos E20 身份权重固定。三种子为 2026092701、2026092702、2026092703。目标 84% 尚未实现；这次诊断不训练新的身份候选，也不访问目标集。

前一轮的源域记录证明：浅中层 Fishr 加权梯度和 U 主路径 MixStyle 均实际生效。但梯度更大、覆盖更多无标签样本不能证明方向有用。本轮保持全部八个已登记方案，不用目标成绩选择方案、参数、样本或 checkpoint。

## 1. 固定样本的错误变化

对每个 seed 的原生 E20 与八个 E20＋20 最终权重，读取完整 L（6,300）和 V（27,000）。模型均为 eval/no_grad。用原生 E20 的预测及固定阈值 0.95 建立高置信正确、高置信错误、低置信正确、低置信错误四组，然后按相同物理 ID 比较纠正、破坏、持续错误、真实类别 margin、NLL 及置信度变化。输出全量与 RX/day/TX 分层和固定置信分箱。另复用已经得到的逐样本读出，将七个机制方案与固定 CE 续训终点逐 ID 配对；这部分置信组单独由 CE 终点定义，不与 E20 初始分组混用。

本父模型见过全部五个源 RX，V 只代表已知源域泛化；不得称为未知 RX 测试，不用 V 反向传播。

## 2. 相同权重上的梯度方向

三个原生 E20 各自固定骨干，用全部合法 L 的冻结特征为浅层 time_down 和中层 t2.pool 的 876 个辅助参数预热 200 步。仅辅助头更新，不继承旧辅助权重，不产生可部署身份 checkpoint。

同一轮、同一权重、同一 L/U 批次和随机状态下，计算 CE、SSL、MULTI、MIX_L、MIX_U、FISHR_RAW、FISHR_BUDGET、JOINT 八个已登记目标。24 轮的 step 为 1332＋4i；每轮主 L、辅助 L、独立参照 L 分别取相邻循环的三个不同 day，各 60 个有标签样本，并断言物理 ID 不重叠。每轮 U 为 128 个；U 没有 TX 真值。梯度参照仅是独立 L 的 CE，V 不在梯度接口内。

保留实际训练 dropout，冻结会更新统计量的模块，所有目标仅 autograd 不执行 optimizer.step。分别记录 CE、KL、辅助 CE、Fishr、总目标在浅层 time_fuse、中层 t2、完整编码器（排除分类头）、分类头上的梯度范数、与参照的点积/余弦/范数比及负向标志。所有模型状态、模块模式和 CPU/CUDA RNG 必须恢复且一致。固定 step 是诊断定位，不等于复现实际训练全过程的梯度方向。

## 3. 数据、继承与执行

输入复用已验证的 L/U/V 物理 split，不重复构建数据。原生 E20 来源由 cvs_e20_foundation.verify 核对；全部八个终点复用原登记固定 final20，严格校验配置、预算、来源与权重。读取仅限源配置、训练元数据、合法源 IQ 和 checkpoint，不打开目标预测、真值、评分或目标错误列表。

每 seed 单独输出目录、单独 worker；唯一 owner 为 codex/root/e20-error-audit-20261012。共三个 GPU worker，调度含其他所有 owner 每卡最多 3 个进程。技术失败保留产物，不自动重跑或覆盖；不干预健康任务。CPU/GPU 原生网络检查及独立 P0/P1 检查通过后，以已推送不可变版本发布。

## 4. 报告与解释边界

每 seed 输出 source_predictions.pt、paired_readouts.json、gradient_audit.json、head_probe 日志、来源、实际配置和耗时/峰值显存。总计 899,100 次源样本模型读出（3×9×33,300），576 个目标梯度记录（3×24×8），600 步辅助头更新，0 步身份更新，0 个目标样本。

三种子完整报告修复/破坏的绝对数和配对差、置信度校准、高置信错误的纠正率，以及各层梯度一致/冲突的分布。梯度余弦只表示局部一阶兼容性，不能当成实际更新收益或跨接收机提升的证明；不凭源诊断保证 84%。报告还应区分基线继续训练的错误迁移与机制新增的净作用。
