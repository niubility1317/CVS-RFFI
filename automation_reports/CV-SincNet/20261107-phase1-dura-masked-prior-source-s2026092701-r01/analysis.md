# 遮挡先验约束 DURA：源训练状态

固定 DURA 和仅使用源 IQ 训练的遮挡先验，以 0.05 权重的遮挡区域一致性约束训练多尺度修正。N607 GPU 训练完成固定五轮：32768 个合法源 ID、每个 ID 三个模拟视图，训练损失从 0.022665 降至 0.021753。训练记录显示未读取 TX 标签、识别器权重或输出、V 或目标数据；DURA 保持冻结。

在先前已探索的 672 条源 pilot 波形上，14 个 RX/场景分组各 48 条；相比 DURA，11 组波形 NMSE 降低、2 组升高、1 组相同。例如 RX8 低城区从 0.100678 降至 0.098782；RX4/6 低城区从 0.037405 升至 0.038275。源 pilot 与该修正网络的训练 ID 分离，但不能据此断言原 DURA 未见过这些样本。波形 NMSE 并不是身份识别准确率，不能用来宣称正式性能提升。

固定最终权重已进入 Phase1 Main split 七景预测，连接冻结 Tri-SIG-TIME SSL 原默认头；七景全部预测固定后独立 truth-last 评分。截至本次核验，clean 已预测 32768／168000 条，尚无完整七景准确率或与 DURA 的配对纠错结果。不得依据源 pilot 结果改变固定测试矩阵或选择性重测。
