# WiSig 联合恢复与波形质量选择

检验归档读出之间的错包互补能否在部署时利用。新的多提案恢复和选择头从零在同一训练循环拟合。已有直通与原 R69 只作评测对照，历史标签后验覆盖只用作研究动机。 [上轮隔离诊断](../20261123-phase1-wisig-observed-amplitude-source-m3-r01/selector_ceiling.json)

## 实收提案与选择信号

以固定 25 MS/s、256 点实收 IQ 为唯一输入。共享粗恢复利用当前包短前导重复估计频偏与扰动。参考上轮实收幅度保护，粗恢复用实收谱对可信幅度做锚定，再估计延迟、复短作用和镜像并将观测残差投回细化。六个读出为直通、粗恢复、无额外幅度投影的细化、有幅度投影的细化、保留实收谱幅度的加权相位，以及保留实收谱相位的幅度修正。

选择器输入包括短前导相干度和噪声代理、频偏、延迟、主作用和镜像估计、前向拟合留出残差、四个位置的重复误差，以及各提案对实收 IQ 的编辑能量、能量比和谱幅变动。所有量在收包后从当包计算，含观测误差和模型不确定性。选择器既不读类别概率，也不读设备、接收机、场景或路线标识。实际输出是一条确定的波形。训练误差经提案经过联合损失更新共享粗恢复与细化，估计特征停止梯度，避免通过改变用于排序的证据绕过波形质量学习。

## 源域训练与冻结

源 U 拟合池 51,836 包，独立留出 768 包，校准 4,096 包。同一 AdamW 训练 1,200 步、batch 48。每次以通用时移、短回波、幅相变换和着色扰动造三路输入。两路来自同一源波形，第三路共享扰动但带有实测源 IQ 的弱差异。优化各提案的复波形和谱幅保真、选择器预测分布下的预期重建风险、源配对损失导出的软排序、弱差异传递及同包一致性。生成参数与逐点扰动从不作为网络输入或监督目标。训练与校准隔离 TX 真值、识别器、源 V、目标和实际 practical 模拟状态。

在互斥源 U 校准池固定两个对照。静态对照始终输出同组六路中通用受扰波形平均风险最低的一路。门控动态读出只在最佳恢复与直通的分差超过 clean 校准分差 99.9% 分位且大于零时改动。未加门的动态读出和各固定单提案均记录。运行条件在两条路线完全相同。通用受扰校准只用合法配对源波形，无分类输出或真值。

混合专家工作学习按输入分派专家。本实验每个专家是同一接收记录上的合法 IQ 提案，排序依据复波形与谱幅损失。选择后再用独立冻结识别器验证相应设备识别效果。识别拒绝理论分析类别后验上的拒绝区间，这里旁路代表保留原 IQ。 [混合专家原论文](https://www.cs.toronto.edu/~hinton/absps/jjnh91.pdf) · [最优拒绝决策原论文](https://ieeexplore.ieee.org/document/1054427)
