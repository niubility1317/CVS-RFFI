# Phase1 后验采样源域预检 r03

r02 在真实源预检中首次完成数组转换，随后发现使用分解矩阵重建协方差会放大浮点误差：实测重建相对误差 1.18e-7，后验均值最大差约 3.36e-4；混合权重最大差约 5.55e-8。r02 保留，无固定预测或源身份评分。本次条件后验直接使用原始协方差，先验采样仍使用其 Cholesky 因子；源数据、随机种子、模型、六成分、选择器、样本预算均保持不变。

代码和配置以本报告所在 Git commit 为准。N607 普通用户进程，工作目录为 CV-SincNet 项目根，CPU 执行、禁用 CUDA、每进程 2 线程，负载超过 72 时等待。入口为 release 内的 `experiments/phase1_posterior_sampling/sample_source_controller.py --commit <本报告所在 commit>`。

先对 28 条固定源记录进行真实模型预检；通过后固定 672 条源预测，再连接合法 L_s 真值评分并独立复核。输出和控制器均使用 `20261102-phase1-posterior-sampling-*-s2026092701-r03` 独立目录；不访问 U_s 身份、V 或目标测试真值，不进行目标地面性能主张。输出包括预检 result、固定预测、源评分和独立复核。系统性技术错误停止并保留原产物；低性能不是停止理由。

本地病态协方差回归验证直接使用原协方差的后验与既有参考实现一致，并确认忽略原矩阵会产生可检测偏差。
