# LoRa DURA 全非载波较大剂量训练

依据已完成的带宽与等幅矩阵，允许完整非载波方向使用其实际可修正幅度时，源域六景达到 67.87% 和 69.39%。扔掉载波修正不损失这项收益。两倍旧学习向量仍无法稳定提高识别，且低城区幅度不到 3% 整 chirp RMS。本轮用相同成熟 DURA 前置、共用网络架构和完整复杂误差方向，实际学习较宽与较高幅度的修正。

## 源配方

两臂仅改变训练和交付频率支持，共用成熟半量、物理门、初始化、U 样本与相同整 chirp RMS 上限 0.45。窄带使用 1–8、9–32 kHz 两段，宽带继续包含 33–64 和 65 kHz 到奈奎斯特频率。复频率两侧同时纳入。两组只允许修改非载波。教师是源模拟轨迹中的实际无噪接收 IQ 与成熟恢复在各自观测坐标中的完整复差，投影到允许频带，再用实际整 chirp RMS 限幅。该上限取自两路源归因中可解释剂量的量级，训练与部署共用。逐带误差以相应的教师能量和同一常数归一化，防止高频修正淹没低频训练。没有新的识别器信号、目标标签或额外输入观测。

同包固定信道与 AGC，生成相互独立的两份噪声观测，逐值核对已登记第一观测。每路每 RX 700 个 U 拟合和独立 80 个 U 留出。两臂各 1800 步、种子 2026112758、比例相同的 clean 恒等曝光，每步 12 条门内 practical 加 2 个 clean，AdamW 2e-4 余弦至 2e-5。使用匹配已冻结 G，训练 F、TX、V 与目标读取为零。

## 冻结验证

每路使用同一 900 个源 V 物理包，每 RX 180，排除上一轮学习向量及带宽剂量两个面板。固定七景配对读出为直通、成熟半量、学习窄带全量、学习宽带的全量、四分之三和半量，以及已知窄带、已知宽带和精确扣噪。冻结 Tri-set 2026092702，七景预测完整写出后连接源 V 真值。逐 RX 和逐场景独立对照净纠错、改错和配对区间。阈值继续以正式三种子 67.0% 六景、43.0% 低城区和 64,490/90,000 clean 为准，本轮不接触目标。
