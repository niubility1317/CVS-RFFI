# 时频跨恢复网络的源域初始响应梯度

使用固定 DURA 和直接恢复器，重新按种子 2026110830 初始化时频跨恢复网络；**没有读取正在训练的模型或其 checkpoint**。源 pilot 中 RX4/6 和 RX8 的高郊区、低城区各 8 条，共 32 条。对每条 clean 构造四种相对 RMS 1% 的人工微扰，通过原观测的 DURA 估计物理作用注入 received，再对受扰输入重新计算两个冻结恢复器输出。

对新网络的两个输出头共 2308 个参数，计算波形保护损失梯度和每种响应损失梯度，先对四个等量源组求平均，再计算余弦与范数比。参考系数 0.01 只用于量纲对比，并非已经选定的后续训练权重。

在这一初始化和小样本上，幅度三次项、相位斜坡的梯度余弦为负，共轭与局部差分为正。若仅考虑每次单独加入一种响应项、权重 0.01 的**无穷小普通梯度下降**，表中两类内积均为正，因此两项在该一阶近似下均为下降方向；幅度三次项的响应内积接近零，余量很小。AdamW 的预条件、权重衰减、有限步长、同时加入多个方向或其他训练阶段均不受此结论保证。
