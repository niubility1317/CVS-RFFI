# LoRa 实测源包配对的复数差异保真

## 预登记

先前近载波波形损失和频偏精度均有实质改善，最终六景识别仍低于 DURA。本轮把保护对象改为两个真实采集包之间的有符号复数差异。在同一源接收机内按训练批顺序两两配对。训练不使用发射机标签，也不预设包对的身份关系。之前弱谱传递实验在单包上注入局部谱差异，本轮用完整的实测包作为两个端点。 [原自然弱复谱消融](../20261123-phase1-lora-dura-natural-detail-echo-source-m4-r01/report.md) · [频偏细化结果](../20261124-phase1-lora-packet-phase-tracker-source-m3-r01/report.md)

对一对实测源 U 包，在原采样坐标施加同一组短复回波和同一份通用有色加性噪声。噪声尺度取该对的逐 chirp RMS。每包生成两视图，两视图之间独立抽样。共享扰动只用来构造可解释的训练配对。由于同一次噪声对两包相同，实际差异在原始坐标中不被独立噪声差直接占据。训练前两份原 clean 波形分别确定各自的去扫相位与 RMS。将预测乘回实收坐标后再用各自 clean 坐标评估两包差值。评估去扫绝对频带 1–8、9–32、33–64、65–128 kHz，使用参考差异带能量加 0.002 归一化，比较复数差异的幅度和相位。实收外带 RMS 代理给出有界扰动权重，使用两包两视图的均值 d，权重 1+2d/(0.15+d)。候选以 0.40 混合系数将分带差异损失用于粗、细恢复。对照计算相同诊断但梯度仅来自共同损失。部署时模型只读当前包，不访问配对包或源 clean 参考。

两臂匹配相同源 U 角色、接收机内配对和扰动序列、254,735 参数的镜像模型、AdamW、余弦日程、batch 12、两视图、3,600 步以及每批两个完全 clean 的锚点。共同损失含逐样本粗／细复数误差、两视图细化一致性及 0.45 的实收扰动分层上尾项。两臂均用原独立逐 chirp 去扫、外带噪声尺度和恒等作用作恢复约束，回写使用该实收包的相位和 RMS。这轮关注差异损失，保持原去扫方式及已验证的源 U clean 门限以限制其他变化。5,000 个无标签源包用于拟合，2,500 用于 clean 门限，500 留出只做波形诊断。训练、校准和冻结隔离 F、V、TX、目标与任何实际 practical 算子及逐点噪声。

Sobolev Training 把目标函数的导数信息纳入训练，Relational Knowledge Distillation 用教师特征的距离和角度监督实例关系。这里使用两份实测端点的有限复数差，保留其符号、相位和尺度，监督恢复器直接输出 IQ，训练无需教师。归因和效果判断以冻结识别器实际结果为准。 [Sobolev Training 原论文](https://proceedings.neurips.cc/paper/2017/hash/758a06618c69880a6cee5314ee42d52f-Abstract.html) · [关系蒸馏原论文](https://openaccess.thecvf.com/content_CVPR_2019/html/Park_Relational_Knowledge_Distillation_CVPR_2019_paper.html) · [公开实现](https://github.com/lenscloth/RKD)

首先在两个实测源 U 包用真实恢复与识别检查无 query 路径。两路固定同一 900 个源 V 包、七景及 Tri-set 2026092702。读出包含直通、同路成熟半量 DURA、两臂粗恢复、完整细化和半量。预测全写齐并冻结后，由独立 CPU 读取源 V 标签。报告同包纠错、改错、逐景和逐 RX 净差、95% 配对区间、clean、源 U 差异风险与 B1。进入正式评测须用同一配置超过两路匹配 DURA 的六景正确数，并保住 clean。 [原三种子 residual 对照](../20261124-phase1-lora-residual-r69-fixed-baseline-m2-r01/report.md)

## 打破共享扰动后的源 U 检查

冻结两组恢复权重后，500 个留出源包组成 250 对，每包独立生成通用有色噪声与短复回波。与训练不同，包对两成员的扰动不再共用。两组对比用相同观测、正常运行门限和各自原始 clean 坐标。误差是分带复差均方除以该带参考差异功率加 0.002，再取 log1p。主诊断保留通用扰动原强度。由于原强度没有扰动代理 ≤0.15 的包对，另将所有新增扰动在同一批波形上统一缩到四分之一，产生 221 个轻扰动对。弱化比例只用于冻结机制诊断。

较强诊断中，实收扰动代理 >0.40 的 59 对上，完整细化的 1–8 kHz 复差误差从点损失的 2.8507 降到差异损失的 2.7008，9–32 kHz 从 0.6468 降到 0.5821。全部 250 对的对应误差从 3.0596／0.9248 到 3.0115／0.8946。两条高频带在全组上未获改善。半量细化在各带结果接近。

四分之一扰动诊断的 221 个轻扰动对上，完整细化的 1–8 kHz 误差为 1.4637 对 1.4543，9–32 kHz 为 1.2278 对 1.2161。33–64 与 65–128 kHz 的误差则略升。结果支持近载波复差的部分波形收益。诊断未连接识别器、V、TX 标签或目标。复现脚本可接受可选参数 0.25，默认是原强度。 [独立扰动复差数据](independent-source-u-pairs.json) · [复现脚本](independent_source_u_pairs.py)

## 拟合与运行

两组均从零训练 3,600 步。GPU 3 点损失组耗时 418.93 秒，GPU 6 差异组耗时 431.97 秒。两组参数均为 254,735。共有的源 U 门限为 0.04594118。留出 U 保留共享扰动时，完整细化的 1–8 和 9–32 kHz 有符号复差误差分别从 0.9816、0.3214 降至 0.7311、0.2618。改为独立扰动后变化幅度更小，见上述独立检查。RTX 3090 上差异约束模型的 B1 时延中位数为 clean 旁路 2.29 ms，通用扰动触发恢复 48.75 ms，每类测 24 次。N607 发布、实际训练、冻结和独立评分 VERIFIED，执行提交 5e524d03d6328ecd980bdeed3c1d70c39284489e。两条路线的七景预测全部固定后才关联源 V 标签，本轮零目标访问。 [点组训练记录](point-complete.json) · [差异组训练记录](pair-complete.json) · [B1](b1.json)
