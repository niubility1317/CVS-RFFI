# 遮挡先验损失优化：真实源样本短程训练对照

从已验证且不含 F/TX/V/目标的确定性 DURA 源上下文缓存，取固定 64 个源训练物理 ID 在三个模拟源视图中的 192 条数据。使用固定源域遮挡先验和独立初始化的 DURA 多尺度修正，在本机 RTX 5070 Ti、FP32、TF32 关闭、确定性算法下比较原损失与省略未使用插值的实现。

两条路径均以相同种子初始化模型、数据顺序和遮挡位置，使用相同 AdamW、梯度裁剪、batch32；各先进行一条两轮预热轨迹，再各训练两轮（12 次更新）。真实源上下文和权重的 8 条小样本检查通过。

| 比较项 | 结果 |
| --- | --- |
| 每步训练损失 | 12/12 逐值一致 |
| 最终模型参数 | 全部逐值一致，最大绝对差 0 |
| 训练后的源波形输出 | 192/192 条逐值一致 |
| 训练计时，原／精简 | 0.2824 / 0.2757 秒 |

计时各仅一次、顺序固定、样本很小，不作为完整训练加速结论。短程同设备结果不能证明 N607 全量五轮训练或目标七景预测逐值一致。源 IQ 和模型权重仅保存在本地／远端私有运行目录，不进入 Git。
