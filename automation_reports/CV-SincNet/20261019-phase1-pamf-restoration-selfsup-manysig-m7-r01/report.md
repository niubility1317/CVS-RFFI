# 星地观测恢复器：七网络与冻结 F 身份保真验证

状态：首轮研发已分析。七行源训练／预测／评分 VERIFIED；主 run 的目标评分因目录错误 FAILED，原预测已由独立恢复 run 完成评分。科学判定：未达到稳定身份恢复标准。

本轮检验同一份输入的 `F(received)` 与 `F(R(received))`。F 和原默认分类头始终冻结，不训练新头。恢复 IQ 经原 PAMF 操作重新生成 Sinc／时域、复 FFT／镜像关系、PA、参考响应和 SIG_TIME，所有分支来自同一个恢复信号。

## 固定设计与预算

矩阵、六类 seed、命令、路径及技术停止规则唯一维护于 [experiment.json](experiment.json)。代码与配置提交：`f99b9202617fa2f61c929b50cef9c541e8876c35`；已推送并独立核对远端分支 OID。

| 顺序 | 候选 | 训练／推理 |
|---|---|---|
| 1 | 残差时序 CNN | 单次残差恢复，输出层零初始化 |
| 2 | 1D U-Net | 多尺度编码、插值与跳连，单次恢复 |
| 3 | 时频双分支 | 完整复 FFT、频域残差与 IFFT，输出一致 IQ |
| 4 | 条件扩散 | 64 级 cosine／v 目标；完整 16 步 DDIM，受损 IQ 为条件 |
| 5 | 条件流匹配 | `z0=received+0.02*noise` 的配对直线路径；16 步 Euler |
| 6 | 物理展开 | 49 tap 圆周 FIR 代理与 3 次数据一致性／可学习近端步骤 |
| 7 | Transformer | 四点 token、3 层全局注意力，单次残差恢复 |

每种候选从零训练，使用全部 6,300 条 L_s 和 56,700 条 U_s，共 63,000 个源物理 ID。训练端不打开任何 TX 标签文件，不使用 PL、标签置信门控、TX 分类损失或生成后的分类梯度。U_s 的 IQ 直接参与恢复监督。

每个 epoch 247 次更新，20 个 epoch 共 4,940 次更新；每行合计 126,000 次 L_s IQ 曝光与 1,134,000 次 U_s IQ 曝光，约 20% 替换为 clean→clean，实际数量写入训练日志。一个源物理样本预生成一个固定 practical 训练观测，七个候选共享；此首轮没有跨 epoch 重采信道。生成模型内部的训练时间与高斯噪声每次更新重采。恢复器 epoch 的样本数与历史 F epoch 不同，不能把二者当成相同成本。

优化器 AdamW，LR 0.0003，weight decay 0.0001，batch256，固定 20 epoch cosine 日程，最终权重，FP32。确定性目标是 raw IQ NMSE＋0.2 log FFT 误差＋各 0.05 的原 frequency、PA、默认初始化 Sinc、高频与参考响应误差。扩散／流匹配采用自身速度目标，另加 0.2 倍重建目标。最优复增益对齐误差仅诊断，不进训练损失、推理或候选排序。

## 输入、坐标与模型来源

原源域 RX 索引 1／3／4／6／8，day1／2／3，原 L_s／U_s／V 物理角色不变。源 V 只取固定 1,800 条开发面板（每 RX×day 120 条，不使用 TX 标签抽取），不更新模型或统计。训练、V 与目标物理角色沿用既有验证结果。源端 IQ 缓存整体镜像到 N607，复用 READY／EXACT_MATCH，不重新划分或建立验证链。

clean 指叠加本次 practical residual 之前的地面接收 IQ，仍含原 RX、传播和采集噪声。公开 impulse 坐标检查确认六场景均有 24 点数值延迟、该次主峰偏移 24 点、传播核长 62。主指标使用完整 256 点；另报前 232 点误差和明确标注的复增益对齐诊断。推理不读真实 clean，不做真值相位、增益或时间对齐，窗口尾部不可直接观测的信息不声称可靠反演。

冻结读出为两个既有、完整来源已核实的 PAMF：主基座 AsF（T1，scratch E20＋自身 E10，共 6,660 次更新；SIG_TIME_X3／CENTER_25K）和 cleanF（SIG_TIME，纯 CE E200／10,000 次更新）。精确源角色及 AsF 的 scratch 父链匹配，默认头保留。AsF 导出复用原三视图签名，并按原公式 `origin+25000*coordinate` 固化 Sinc 物理频率，严格加载现有权重。两个 F 训练成本独立保留，恢复器不继承其权重。现有两读出均属 PAMF，不能把它们称为独立外部架构验证。

## 有效性判定与独立评分

逐行保存 clean 和六个 practical 的全部恢复波形、两个原默认头的恢复前／后 logits 和 joint160；之后独立 CPU scorer 才读取源 V TX 标签。每行自动训练→冻结→预测→评分，不等待整批训练完成。

首要看主 AsF 的真实 TX 准确率、每 TX／RX 混淆、修复／破坏／净纠错、真实 TX margin、原 clean 特征配对与其他 TX 的差异，以及 clean 输入通过恢复器后的保持情况。配对特征对比只在评分侧进行，不建立新预测头或回流推理。波形 NMSE、频谱和 PAMF 输入误差提供辅助证据，不能单独证明指纹恢复。

扩散与流匹配主结果均采用预登记的一次 ID 固定噪声采样，正式恢复执行完整采样流程。每个视图前 128 个 ID 另做两次固定随机诊断，报告身份切换率与各次准确率，不选最好一次、不平均 IQ，额外成本单列。

源域资格：AsF low urban 至少提高 0.5 个百分点、clean 下降不超过 0.2 个百分点、六场景平均 raw IQ NMSE 不恶化、clean IQ NMSE≤0.02。合格者按源 V low urban 准确率最高选择，完全并列按固定顺序；若全部不合格，仍只对源端最高者做一次明确的负结果确认，不据此扩种子或追加预算。

源选择冻结后，仅选中一个恢复器，对固定 1,200 个未见 RX 目标物理 ID 进行 clean＋六 practical 的 Phase1 paired diagnostic；全部预测固定后独立 scorer 连接原 TX truth。新六场景由 builder 固定，注入 RX 会话固定，不能当作历史 satellite 观测。目标结果不反馈训练、选择、重排或重跑。该 paired diagnostic 不属于 Phase2，不修改 `p2_min_v1` 权限；单种子不声明稳定增益或真实在轨验证。

## 方法来源

条件扩散采用 [DDPM](https://arxiv.org/abs/2006.11239) 的条件去噪思路、[v 参数化](https://arxiv.org/abs/2202.00512)及 [DDIM](https://arxiv.org/abs/2010.02502) 采样；流匹配采用[向量场配对路径回归](https://arxiv.org/abs/2210.02747)。这里的 1D IQ 条件路径与损失是待检验的任务适配，原论文结果不作为射频指纹有效性证据。

## 自监督正确性结论

恢复网络训练属于**合成退化配对自监督**：`x∈L_s∪U_s，r=Aξ(x)，R(r)≈x`。它不需要 TX 标签，但需要增强前的源域原观测 x；不能称为完全没有 clean 参照的盲恢复。恢复器本身不加载已有 F，不使用 CE、KL、伪标签、F 分类分数或 F 的训练梯度。PAMF 输入损失使用原确定性变换和默认初始化 Sinc，全部冻结；不是学习过身份的 F 特征损失。模型目标均有明确 x 锚点，不以相互一致替代配对端点。

原比较流程的 source V **选模使用了 TX 标签**，因此不能把原端到端研发流程称为全无监督。新增 `unlabeled_selection.py` 只接受原坐标波形 NMSE，拒绝 TX/F/识别字段；clean NMSE≤0.02 后以六场景平均 NMSE 最低选择，同样得到 U-Net。该规则是在全部源诊断后补充、首次成功目标评分前执行的校核；不是新的前瞻盲选实验。完全复用原先已冻结的 U-Net 目标预测，无新增训练或 GPU 预测。已有 F 使用过监督预训练，也不属于全无监督系统。

原 15 项聚焦检查已通过；本轮新增 6 项实际运行：`python -X utf8 -m pytest tests/test_pamf_restoration_unsupervised.py -q`。覆盖禁用分类损失/教师加载仍可优化恢复器、解析扩散 v 与完整 DDIM 端点、流匹配 Euler 端点、推理禁用 clean-dependent 训练路径、无 TX 选模白名单、评分路径不提前读取真值。检查验证训练定义与实现边界，不等于验证真实身份细节已恢复。
