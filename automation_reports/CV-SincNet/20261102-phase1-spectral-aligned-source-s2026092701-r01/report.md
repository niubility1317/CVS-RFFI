# Phase1 对齐感知频域耦合恢复

基础频域网络的源训练诊断显示，110 条受损记录的直接归一化 IQ 误差由 2.0249 降至 0.3006，而经 ±64 点时延与复增益对齐的误差由 0.09245 升至 0.22507，高置信干净 F 伪类别一致数由 97/109 降至 88/109；源留出也观察到同向变化。本实验使用同一 14,678 参数频域耦合架构，检验对齐感知目标能否改善上述冲突。上述样本和源视图已探索，不是盲测。

模型及训练配置与基础频域版本保持相同：8192 条源训练记录、固定第 21、22、23 轮视图、五轮预算、初始化和优化器。训练损失为 ±64 点时移与最优复增益对齐的中央 IQ 误差，加 0.2 倍冻结 Tri-SIG-TIME SSL 特征余弦误差、0.2 倍温度 2 的软类别 KL、0.05 倍置信加权伪类别间隔和 0.05 倍截断对数功率比平方。每个时移和增益仅由当前训练配对选取，推理不读取干净 IQ；伪类别不是真实身份。F 保持冻结，本方法为 F-guided，不直接读取 TX 身份、U_s 真值、V 或地面测试。

先进行 64 条源训练与 28 条源评估记录的真实预检，完整训练后固定 672 条源预测，再连接合法 L_s 身份评分。预先登记 clean 与六个受损 Phase1 地面视图各 168000 条；全部预测固定后才独立评分、审计并报告跨 RX 与跨 RX+day。总集 clean 基准 86.538690%，相对下降 3% 的门槛 83.942530%，另报告下降 3 个百分点的门槛 83.538690%。该地面开发集已反复观察，不代表独立盲测或真实卫星链路。

源实验 `20261102-phase1-spectral-aligned-source-s2026092701-r01`、地面实验 `20261102-phase1-spectral-aligned-ground-test-s2026092701-r01`。CPU 两线程、负载超过 72 等待；独立不可覆盖输出和 truth-last 评分，低分不停止健康任务。地面结果不回流训练或调参。固定后可与基础频域和间隔一致性版本对照。
