# 固定恢复模型的源域微扰响应

对同一批 672 条合法源 IQ，比较冻结的 DURA、普通多尺度修正、响应约束多尺度修正。两个修正网络使用相同的 32768 个源训练 ID、三视图和五轮，source pilot ID 与二者训练集分离；不能据此断言 DURA 从未见过 pilot。对每条源 clean IQ 构造相对 RMS 1% 的合成扰动，经该记录的 DURA 估计物理算子注入 received，再对扰动信号重新估计恢复上下文。指标是输出变化相对已知输入扰动的归一化平方误差，越小表示在这个代理任务中越接近保留所加变化；投影增益越接近 1 表示沿所加方向保留越多。每个 RX/场景组 48 条，以下为 14 组等权平均。

| 合成变化 | DURA 响应误差 | 普通修正响应误差 | 响应约束版响应误差 | 响应约束版优于普通修正的组数 |
| --- | ---: | ---: | ---: | ---: |
| 共轭 | 0.3272 | 0.3437 | 0.1605 | 13/14 |
| 幅度三次项 | 0.4134 | 0.4191 | 0.3002 | 12/14 |
| 相位斜坡 | 0.9198 | 0.9250 | 0.3972 | 12/14 |
| 局部差分 | 0.3505 | 0.3536 | 0.1475 | 12/14 |

例如 RX4/6 低城区的共轭方向投影增益为 DURA 0.1880、普通修正 0.1827、响应约束版 0.4338；对应幅度三次项为 0.1666、0.1681、0.2601。结果支持该训练目标确实改变了合成扰动的局部响应，但仍未完整保留全部扰动。波形 NMSE、人工方向及 DURA 自身估计信道均不能证明真实 TX 身份细节得到恢复。

该诊断在两种修正网络的地面成绩已经揭示后，用于解释已观察现象，不构成独立验证，也不能作为目标成绩调参或后续选模依据。此前七景正式结果为响应约束版仅三景高于 DURA、其余三景下降，仍只有 1/6 个受损场景满足相对 raw clean 的 3% 目标。训练和本诊断未读取 F 权重或输出、TX 标签、V 或目标；无模型更新。首次技术运行完成源计算后因远端混合版本 NumPy 的 mean 导入异常中止；本次改用张量汇总重新完成，分组口径一致。真实 checkpoint 源域 smoke、三项针对性测试和独立 P0/P1 审查通过；详细数值保存在本目录 `result.json`。
