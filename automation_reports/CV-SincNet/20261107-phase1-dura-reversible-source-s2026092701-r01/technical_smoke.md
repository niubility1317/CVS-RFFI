# DURA 可逆耦合源域 GPU 技术检查

在本机 RTX 5070 Ti 上，使用真实 DURA 源上下文的 192 条 IQ 视图，对四层奇偶加性耦合进行 6 次源 IQ 更新。初始化输出逐值等于缓存的 DURA 波形，四个耦合头均收到有限梯度。更新后对 32 条源视图执行逆变换，反算 DURA 波形的最大绝对误差为 1.1920928955078125×10⁻⁷，满足 `rtol=1e-5, atol=1e-6`。

训练仅使用源 IQ 和 DURA 上下文，不读取 F、TX 标签、V 或目标。这个检查只验证初始化、梯度和数值可逆性；有限精度下不是逐值无损证明，也不是识别准确率。正式实验将按预登记在 N607 GPU 训练五轮并进行完整七景 truth-last 测试。
