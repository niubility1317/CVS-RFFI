## 核心梯度路径

- COUPLED 保留原辅助 CE 的特征计算图，沿用旧 JOINT 的浅中层 Fishr 和 U MixStyle。已有 CPU/CUDA 检查证明同权重、同输入和随机状态下，旧 JOINT 与新 COUPLED 的总损失、各损失、全部参数梯度、RNG 及 style 明细逐位一致。
- 其他启用辅助头的方案只在辅助 CE 入口对特征 detach，头仍参与主优化器。Fishr 使用独立的可导特征图，读出 W/b 在正则中 detach。检查确认辅助 CE 对全部身份参数梯度为零、对头非零；Fishr 对头梯度为零，对启用层的骨干梯度非零。
- F_SHALLOW、F_MIDDLE 只调用所选层的 Fishr；未启用层不计算方差正则。预算组合固定除以 2，不因只剩一层而放大。计划零项明确记录 `inactive_by_design`，包含实际直接贡献和合并梯度比例。
- U MixStyle 接入真实强视图主路径，固定两层，保留主 dropout。沿用已修复的 U 专用 helper，允许批内重复出现，同时用真实物理 ID 排除同包 donor；双方高置信、同伪类别、同 day、跨 RX。U 真值不读取。
- 辅助专用前向隔离 RNG 并恢复 dropout 模式。局部 head-only 回归保留辅助头训练，证明与 SSL 的身份梯度、一次 AdamW 更新和 RNG 逐位一致，同时头确实发生更新。该证据是有界实现核验，不冒充完整训练轨迹等价或性能结果。

## 来源、预算和测试闭环

- 24 行登记配置与代码逐项一致，8 方案各 3 个 seed。每行严格加载对应原生纯 CE E20，来源验证绑定物理角色、原始执行提交、scratch 继承链及固定 final20；无旧辅助头或优化器继承。自身终点配置、父来源和完整 state 严格加载，错误父路径被拒绝。
- 所有行追加 20×222＝4440 次身份更新。启用辅助头时先执行 L6300 缓存及 200 次头更新，骨干 state 校验不变；随后 999 次 L60 辅助计算。非 CE 行为 3996 个 U128 批次、511488 次 U 使用。CE 实际不加载 U 缓存、不建 U 迭代器或辅助网络；CE/SSL 不执行暖头。所有方案关闭 EMA、星地增强及 IQ 物理动作。
- L/U/V 复用合法物理 split；U schema 排除 TX 真值，旧缓存仅保留合法 IQ 和 metadata。V 只作固定轮次健康检查；final 增量20固定，不使用 V 或目标成绩选模。
- 每行训练冻结后立即串联 clean168000 预测与独立 truth-last 评分。主配对为 JOINT−COUPLED；全部 24 行必须完成，整批为 4032000 条新预测、336 条主分层及 96 条日期指标。评分结果不控制训练、候选或重跑。
- 三阶段使用单 row PID 串联；唯一 owner、独占输出、共享容量锁与预约计数保持。每 GPU 最多 3 个总进程，包含其他任务；已有 run/release/prediction 拒绝覆盖，UNKNOWN 不自动重启，技术失败保留产物。
