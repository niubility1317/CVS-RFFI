# 固定 DURA 源域上下文缓存核验

在 N607 GPU 7、FP32/TF32 关闭、batch 32，使用同一固定 8192 条合法源 IQ、三个固定模拟视图（共 24576 条），实际重新准备两遍 DURA 上下文。未读取 TX 标签、F 权重或输出、V、目标 IQ 或目标真值。

缓存中的接收 IQ、DURA anchor、物理残差方向、方差、clean IQ 五个完整张量，均与第二次独立重新计算逐值相同；场景计数也相同。

| 操作 | 时间 |
|---|---:|
| 首次完整准备 | 68.305 秒 |
| 再次完整准备 | 67.932 秒 |
| 写入缓存 | 0.197 秒 |
| 读取缓存 | 0.172 秒 |

缓存大小 201451916 字节（约 192.1 MiB）。本次复用节省约 67.76 秒准备时间；缓存读取可能受文件系统缓存和并发负载影响。这是单次准备阶段对比，不能直接推断完整训练或测试加速倍数。完整训练的权重与预测逐项一致尚未验证。

缓存只适用于固定 DURA、相同源物理 ID 和三个源视图、CUDA FP32/TF32 off、batch 32 的无模拟动作监督训练。原始源 IQ 与缓存仅保留在 N607，不提交仓库；缓存不会用于目标或其他 owner。
