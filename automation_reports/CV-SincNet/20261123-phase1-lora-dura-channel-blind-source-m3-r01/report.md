# LoRa DURA 信道盲源波形先导

## 边界

用户允许用已知噪声、信道轨迹的源反事实定位差距，并允许参考真实通信中的估计与均衡。精确 80% 扣噪与精确反演依赖逐包真噪声和信道真值，单列为诊断。正式候选不得读取这些量、practical 场景、预设信道参数表、接收机 ID 或目标信息。工程同步、前导或导频估计属于允许输入，前提是能在当前实收 IQ 中获得，且正式比较中的输入契约一致。可参考从 LoRa 已收到的前导估计和补偿偏移的实机原型。[Tapparel 等的 GNU Radio LoRa 实现](https://arxiv.org/abs/2002.08208)

本轮选用更严格的训练对照，恢复器连 practical 训练视图都不读取。仅读取同一合法 U 角色的单份 clean IQ，并在内存上生成独立通用复白噪声和一阶相关噪声。噪声相对原信号 RMS 的比例从 0 到 1 连续采样，分布与测试仿真器无关。两次加入噪声的输入回到原实际坐标做恢复一致性，保留两份 clean 恒等曝光。训练不读 TX 类别、F、源 V、目标、practical 波形或模拟轨迹。

## 训练和输出

单个候选采用 DURA 的粗恢复、再对观测做约束的两阶段结构。第一阶段使用原 Denoise 时域／频域先验。第二阶段从当前 IQ、粗恢复结果、观测误差和接收端可估计噪声尺度计算先验，再用单独的加性观测一致性约束更新，载波保持当前观测。此先导未引入单包多径均衡。真实额外的频偏、时偏与前导估计仅属于可独立实现的工程候选。

每台源 RX 固定 1,000 个训练、500 个源 clean 校准和 100 个留出 U 包，三份物理 ID 互斥。门槛为校准样本所测信号外带噪声指标的最大值的 1.05 倍。门控只使用输入，实际 clean 如果误触发会完整计入评分。训练 1,900 步，每步 12 个物理包、每包两份通用噪声输入，AdamW 2e-4 余弦至 2e-5，种子 2026112991。单独冻结权重与阈值，full 和 residual 加载同一份。对比用的成熟 DURA 在评分中独立生成，不提供候选特征、门控或训练监督。

## 固定验证与发布

固定 900 个源 V 包、每台 RX 180 个，两个信道均使用相同物理行和冻结 Tri-set 2026092702。实际评测波形使用注册的 full／residual 生成协议，候选只获得输出 IQ；评测接口不传逐包噪声或轨迹。固定直通、成熟 DURA、盲恢复第一阶段、第二阶段和第二阶段半量共五个读出。所有七景预测写齐后独立连接源 V 标签。正式目标继续为 15 台未见 RX、30,000 个包、原三种子六景至少 67.0%、低城区至少 53.0%、clean 至少 64,490/90,000，源先导结果单独归档。

`20261123-phase1-lora-dura-channel-blind-source-m3-r01`，`python -m experiments.pamf_lora_main.channel_blind_source publish`，N607 普通账户、LoRa Python、独立发布 CWD 和不可覆盖输出。源 smoke 及唯一训练节点优先 2、0、4、1、5、3、6，冻结后两条评分按 3、6、2、0、4、1、5 分卡，每卡总计算进程少于四。先用真实 raw U 检查数据形状、梯度、finite 以及阈值，来源或评分系统性不一致时停止本 run 后续派发。预期真实源检查、单份权重及门槛、两路七景预测和独立评分。

## 完成结果
