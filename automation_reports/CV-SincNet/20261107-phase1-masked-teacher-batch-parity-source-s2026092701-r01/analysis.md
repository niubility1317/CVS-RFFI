# 遮挡教师批量预计算源域对照

固定源遮挡先验、512 个源 ID 的三个视图及五轮遮挡顺序，比较 teacher target 计算 batch 32 和 256。每种批量预热后，两次交替顺序计时；所有结果均在本机 RTX 5070 Ti、FP32、TF32 关闭和确定性算法下取得。此为源域教师前向与输入准备的技术对照，不更新恢复模型。

| 对照轮次 | batch 32 | batch 256 | 教师输出 |
| --- | ---: | ---: | --- |
| 1 | 0.437 秒 | 0.047 秒 | 逐值一致 |
| 2 | 0.453 秒 | 0.063 秒 | 逐值一致 |

每轮各 7680 条教师输出、每条 512 个浮点数；两轮最大绝对差均为 0。两轮均值分别为 0.445 秒和 0.055 秒，教师计算部分约 8.1 倍；计时很短，且包括输出收集、显存分配和各自批量的输入准备。此比值不能用作整轮训练或 N607 加速比，也不能单独证明不同批量下训练损失、模型参数、七景预测一致。训练使用的实际样本顺序随机数取自 1536 条子集，不冒充完整 98304 条正式训练顺序。

源上下文和教师通过既有真实 checkpoint 来源检查；只读取合法 L_s/U_s 源 IQ 和固定模拟视图，不读取 F、TX 标签、V 或目标。独立 P0/P1 审查未发现本对照的直接错误。运行中的训练没有修改。结果存放在本机独立输出目录；运行配置及状态见 [experiment.json](experiment.json) 和 [events.jsonl](events.jsonl)。
