# Tri 监督 AdamW 参考主方向实验

用户要求研究哪些损失有利于泛化，并使后续优化以合法参考方向为主。本批固定十类、六源各 4 行：原同合同 seed 2026092701 的 Tri 源 E20 自身续训 E21–E50，U 总权重为 6／3，额外 U 更新相对参考更新的幅度上限为 0.25／0.5；其他机制与现有双锚点训练一致。

每步在当前参数和当前段 AdamW 状态下，计算完整 L-only 的实际参数更新作为参考。参考仅来自合法 L_s 标签与原监督目标，保留此前联合训练的动量，因此不是独立训练的纯监督轨迹，也不是未经 AdamW 的原始梯度。先对相对 L-only 的实际 U 额外位移保护完整 L 和 ordinary 有标签 CE，再逐参数组将额外位移范数限制为参考更新范数的指定比例；量化后重新检查两锚点与比例，不合格则回到 L-only。参考为零时回到 L-only，方向未定义并单独计数。对于非零参考，实际总步与参考的余弦理论下限为 sqrt(1−cap²)：cap 0.25 为约 0.9682，cap 0.5 为约 0.8660；该方向约束不保证实际损失或泛化性能改善。

每行记录参数组三种实际位移范数、比例、总步／参考方向、完整 L 与 CE 方向、量化及零参考回退、源 V 和 U 接受率。训练不使用 V 梯度或更新状态；U 真值只在 E50 冻结后由独立程序评分诊断，不用于训练或选模。clean 的 cross_date、cross_rx、cross_both 预测固定后独立 truth-last 评分，主口径合并 cross_rx 和 cross_both；不跑星地或 weak。历史 target 结果与 seed 已曝光，所有行固定在新增测试前，属于探索性比较。

N607 普通账号在 GPU 2、3、4 间按可用容量轮流分配；其他 owner 与待初始化进程计入每卡总上限 3，资源不足时排队，不停止或重启现有任务。协议、非有限或系统技术失败停止新调度并保留产物。具体矩阵、命令、路径及源 checkpoint 来源见 `experiment.json`。
