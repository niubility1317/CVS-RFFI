# LoRa Tri 与 DURA 逐项归因试验

## 已核对的故障

本试验从原 LoRa 包对齐试验 r02 继续。SF7/BW125 kHz 的完整上扫频符号长 1.024 ms。r02 已把 practical 信道卷积和分数时延计算放回正确的 1 MHz 物理采样率，逐包提取前导中的 6 个 chirp，每个保留 256 个复采样。相同时长预算下，六 chirp 相对单 chirp 有收益。输入对齐属于已经验证的修正，本试验固定该数据。

r02 冻结权重复算，Tri 的有标签训练 46.38%，clean 源验证 43.88%，设备 33 的训练与源验证均为零。分类瓶颈在训练源内已出现。普通 PL 有标签训练为 47.25%，源验证 43.63%（冻结 FP32 复算）。原 Tri 的全局准入要求至少 4 个预测类别同时达到精度和跨 RX 支持，r02 各训练轮均未接纳 U。原 DURA 只有 583/4160 源训练对实际走恢复分支，训练目标对整包做全局相位匹配，去劣化残差预算为输入 RMS 的 15%。重新比较用相同盲测物理包，无目标数据参与本轮更新、门槛或选模。此前已查看同一批目标结果，因此这一批是开发读数。

## 候选及控制

| 待验证的问题 | 唯一差异 | 同行对照与指标 |
|---|---|---|
| 原 IQ 六路特征平均后区分弱 TX 的线索不足 | 在保留原 IQ 分支上加零初始化 log STFT 残差头。相邻帧 log 功率差抵消静态频率增益，保留六个 chirp 通道 | spectral_pl − raw_pl，源 V 总体、逐 TX 与最差 RX，目标各景 |
| 设备 33 等低召回 | 同源冻结 F 的 L 召回直接决定加权 CE，低于 50% 才加权，全部候选共同使用切分均衡的标签批 | spectral_focus − spectral_pl，逐类 L 起点、逐类 V 召回和强类代价 |
| 全局策略把 U 压到 0 | 对每个预测 TX 独立求最低合格阈值。每类需 ≥14 条、≥3 RX、Wilson 95% 下界 ≥0.73。每批每类至多 2 个 U，交叉 RX 对比只用真实同类的 L 锚点，U CE 与对比系数固定 0.35、0.025 | spectral_tri − spectral_focus，源 V 分档、U 接收率、独立离线 U 准确率、L/U 样本梯度余弦和范数 |
| DURA 梯度被旁路和跨 chirp 干扰稀释 | 两条 G 都仅用可触发恢复的源 L/U IQ 配对，残差 RMS 上界 25%，并保持高相干包逐点透传。chirp 相对 phase 增加逐 chirp 的小 CFO 和相位配准后残差监督 | 同一冻结 spectral_tri 下看 direct、parent_dura、phase、chirp，按场景计净纠错/新增错误及触发量。phase 相对 parent_dura 是一组联动变更，chirp 相对 phase 单独识别配准贡献 |

同种子 2026092701，四个 F 都从同一 LoRa r02 仅用源域的 E30 packet_sup 开始，继续训练 18 epoch，各 50 步/epoch，固定末轮冻结。F 共同保留 L 原波形 CE、practical CE、跨 RX 对比和成对 KL。两个 G 均从同源 r02 F-free E15 开始，各 10 epoch，固定末轮。G 训程只有 L/U 波形，接收机/X 真值访问权限和 r02 相同。L_s=1600，U_s=2560，V=800。盲测 15 个新 RX 每个 128 条，固定物理包共 1920 条。四个 F 各直推，另给 spectral_tri 接三种 G，全部 clean 加六种 practical 共 49 行。逐景报准确率、macro F1、逐 RX、G 净纠错。U 真值只由独立本地评分程序在所有输出冻结后计算。

## 发布前实际波形检查

同源 F/G 真权重和 IQ 样本已拉回本地。频谱头初始 logits 与原 F 完全相等，首步频谱头梯度范数 1.239，第二步频谱卷积权重梯度范数 0.000993。设备 33 的原 L 召回为 0，归一化 CE 权重 1.293，强类为 0.862。每个标签小批实测包含 8 类，各有 4 个不同 RX。源验证确认设备 37 经 0.65 阈值分档后正确 57/66，5 个 RX，Wilson 下界 76.07%。触发规则同时验证每批逐类限额和真实 L 的跨 RX 捐赠约束。DURA 的 48 条实际 clean 透传逐点一致，12 条触发样本均通过 RMS 限幅。以实际源 chirp 注入已知 375 Hz 偏移和逐 chirp 相位，单一整包相位目标的 MSE 为约 0.5674，逐 chirp 目标约 8.35e-15。这个受控检验只证明实现能保留指定扰动，不是泛化成绩。置错数据角色与打乱 checkpoint 契约均被拒。

## 运行约定

同一父 F 在盲 U 上，逐类策略过滤后有 229/2560 条候选，固定 PL 0.95 有 12/2560 条候选。训练时仍按每批接收限额执行，实际进入损失的比例和准确率以训练日志与独立评分为准。两种 G 用实际 practical 源配对对各自的监督目标做反向，梯度范数分别为 0.116 和 0.079。相位配准目标不同，两个目标的绝对 MSE 不作跨目标优劣比较。

代码身份为包含本报告与本轮实现的单一 Git commit。run ID 为 20261122-phase1-lora-packet-refine-m6-r01。从仓库根使用 `python -m experiments.pamf_lora_main.refine_publish`，输入上轮两个发布回执和 N607 普通账户运行配置。远端发布根 `CV-SincNet/releases/20261122-phase1-lora-packet-refine-m6-r01-release`，结果根 `CV-SincNet/runs/20261122-phase1-lora-packet-refine-m6-r01`，按历史冻结的 CVS-RFFI Python 环境运行。GPU 0–6 按实测空闲显存一任务一设备，排除 GPU 7，保留其他 owner。系统性技术故障包括父源输入不符、无目标 smoke 失败、任一训练或预测错误、矩阵缺行，触发停止后续派发并保留产物。科学无收益仍对完整矩阵评分。预期产物为逐行冻结权重、epochs.jsonl、source_audit.json、盲测预测、独立 scores.json 和 u_offline_scores.json。
