512 条参考记录的均匀随机 top-1 基准为 0.20%，top-5 为 0.98%。以 DURA 查询时，等权组合的 top-1 在三个视图分别较单独功率高 7.03、11.33、6.64 个百分点，较单独四阶统计高 1.95、6.45、4.49 个百分点。

该检查的参考库直接使用 clean 源信号，不能在目标端部署；同记录匹配可能反映调制或波形内容，**不是 TX 身份识别准确率**。不能据此断言四阶统计模型的正式识别性能，也不能用此改变其已固定训练或测试。完整 MRR 和匹配距离保留于服务器该 run 的 result.json。
