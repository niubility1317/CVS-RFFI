# LoRa 实收跨频点复协方差工程对照

[预登记矩阵](experiment.json) · [运行事件](events.jsonl)

上一轮的邻点相位读出降低了源 U 合成扰动下的相位损失，两条 practical 路线低城区的 9–32 kHz 独有复谱 NMSE 随之升高。本轮检验跨频点的实测协方差能否改善这类弱谱恢复。六条去扫前导先经正交线性变换分为一个公共坐标和五个跨 chirp 差分坐标。两种协方差用相同的 20,000 个源 U 物理包、六个均值及两个二阶矩拟合。逐频点对照保留每个频点内 I/Q 的二阶相关。联合对照再保留 90% 跨频相关，维持相同的逐频边际协方差。

| 可用量 | 来源、时点及误差 |
| --- | --- |
| 去扫复谱、相位和 RMS | 实收六条 256 点对齐前导齐备后计算。载波保持，恢复变更沿相同的逐 chirp 相位和 RMS 回写原 IQ 坐标。其相位包含接收机与有效时频失配。 |
| 源先验 | 合法源 U 原始地面接收 IQ 的非载波二阶矩。联合组和逐频组冻结同一个源包分区，无标签、训练识别器、目标数据或实际新增噪声。先验包含地面采集失配。 |
| 噪声方差代理 | 六条前导去扫后的公共和独有外带功率中位数，按圆复高斯换算成每实维方差。外带为 `64 < abs(f) ≤ 128 kHz` 的 FFT 频点，包含真实信号与硬件失配。以场景和 RX 报告估计值，独立波形审计复算同带误差。 |
| Clean 旁路和幅度上限 | 实收外带 RMS 六窗中位数高于独立 2,500 个源 U 包的最大值的 1.05 倍时启用；整包编辑 RMS 最大为实收的 30%。 |

对每个协方差特征方向，设源特征方差为 λ、接收估计方差为 v。后验均值读出将中心化坐标乘 λ/(λ+v)，方差保持读出改乘其平方根。在按各方向加同性噪声的模型下，平方根修正恢复源边际方差。它保留了更多实收幅相，但可能在低信噪条件下保留更多噪声。本工程对照使用单位前向作用；弱复谱、已知波形失配和多径并入有效噪声。两个读出均回写完整非载波修正。相同 IQ RMS 的比较把同包两个方差保持输出缩到共同较小剂量。

Zoran 和 Weiss 从干净图像学习多维协方差并在含噪成像模型上作后验估计，Lebrun、Buades 和 Morel 的公开 NL-Bayes 实现通过相似图像块估计局部协方差。本对照的样本单位是实测源 LoRa 前导，使用正交重复坐标、I/Q 联合协方差、实收外带方差及同包等回写量，以冻结设备识别检验跨频项。只在本矩阵内解释该项的独立作用。 [EPLL 原论文](https://people.csail.mit.edu/danielzoran/EPLLICCVCameraReady.pdf) · [NL-Bayes 原文和实现](https://www.ipol.im/pub/art/2013/16/)

解析校准一次完成，零优化步。匹配的两路线各评测同一批 900 个源 V 包、同一冻结 Tri-set 种子 2026092702、clean 与六个 practical 视图。两路线共用校准矩阵和旁路阈值，预测全部固定后由独立 CPU 读取标签。主读出预定为跨频方差保持。晋级需要两路线各超过匹配半量 DURA 六景并保持 clean。

## 估计误差与弱复谱

独立进程在评分后使用同包重放，实收恢复计算结束后才调用新增噪声参考。固定源 U 上，最大的 16 个跨频特征方向分别包含公共和独有协方差迹的 96.37% 和 60.39%。低城区的外带噪声方差代理相对同频带实际噪声，Full 公共和独有中位偏差为 +0.48、+0.09 dB，Residual 为 +0.07、−1.45 dB。高强郊区的公共偏差为 +9.59 和 +3.93 dB，与较低噪声时外带信号泄漏的假设一致。Full 高强郊区 39/900 包触发，Residual 为 495/900。

两路线跨频项相对同量逐频改善了独有复相关，幅度和复 NMSE 小幅上升。以直通为基准，两项 NMSE 大幅下降。Residual 低城区 900/900 包触发，各 RX 的实际编辑量中位数均触及 30% RMS 上限。Full 低城区 736/900 包触发，五台 RX 的中位编辑量为 25.2% 至 30.0%。以同一实收判据开门时，不同路线的变更幅度和收益明显分化。该证据支持后续把跨频方向保留为先验，在一次联合训练中学习公共及独有方向各自的观测置信和连续回写强度。回归监督仍只来自合法源 IQ 与通用扰动。 [隔离幅相审计](../../../tools/lora_local_phase_fidelity.py)
