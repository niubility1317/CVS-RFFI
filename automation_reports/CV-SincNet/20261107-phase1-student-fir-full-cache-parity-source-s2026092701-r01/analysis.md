# 独立学生滤波全量源训练缓存对照

本机 RTX 5070 Ti，确定性 FP32、TF32 关闭；固定 32768 个合法源记录及每个记录三个视图，batch 32，各训练五轮。两条训练使用同一冻结源学生、FIR 初始权重、源 IQ 和训练顺序。缓存版首次计算冻结学生输出 16.782 秒包含在总时间内；两次计时先后顺序固定，仅运行一次。

未缓存版总用时 190.703 秒，缓存版 133.766 秒，减少 29.86%，约 1.43 倍。全部 15360 步损失、最终全部参数和固定 192 条源输出逐值相同。真实源模型和源数据合同检查通过；无 TX 标签、F 权重及输出、V 或目标数据读取。

这些是同机源域训练轨迹对照，不能推断 N607 实际加速、不同硬件的训练权重或完整地面测试预测逐值相同，也不是星地识别成绩。正式候选仍需在 N607 启动训练、固定模型并完成七景 truth-last 评分。
