# E20 + 20：浅中层梯度预算 Fishr 与 U 主路径 MixStyle

本批固定 8 方案 × 3 种子，24 行。从对应种子的原生纯 CE、旧门控、cos E20 继续训练 20 轮。主目标仍为 clean 测试三种子均值达到 84%，必须同时报告每个种子。本文件固定源域机制探索，不依据历史目标测试排名选超参数或加载获胜变体。

## 来源与反思

上一批源日志的全量检查发现，固定权重 Fishr 的骨干梯度相对主 CE 很弱；十次抽样审计的平均比例约 0.00027，其中包括预热零值。这个量不能冒充所有步骤的梯度比例。MixStyle 仅在每四次主更新一次的 60 个有标签辅助样本上作用，未进入 128 个无标签样本的主前向。本批分别检验这两个源侧执行问题。所有负结果保留，不把有机制梯度等同于有测试收益。

身份网络保持原生结构，直接在浅层 `time_down` 和中层 `t2.pool` 的实数通道特征上作用。最终身份表示不再叠加 feature/margin 损失。所有方案都不使用物理 RX IQ 动作、星地增强、EMA 或额外教师模型。这是固定的机制对照范围，不根据目标分数决定开关。

## 辅助头与预算

每个多层方案新增两只六分类线性头，共 876 个训练参数，不继承历史辅助权重。先冻结 E20 主网络，以 eval/no_grad 对全部 6300 个 L 提取一次两层时序均值缓存。用同一天 6 TX × 5 RX × 2 样本的 60 样本批，只更新辅助头 200 次，AdamW lr=0.003、weight_decay=0.0001。校验原骨干所有 state 逐位不变，私有随机流不改变主训练采样。独立记录 6300 次特征提取样本、12000 次头训练样本使用、200 次头更新、时间和内存。CE/SSL 不执行该预热。

随后所有方案新建主 AdamW，lr=0.0002、weight_decay=0.0001，20 轮 cosine 降至 0.000001；20×222=4440 次主更新。L 批 128。前 444 步仅主 CE，后续 888 步线性升权。非 CE 方案此后共 3996 批 U，511488 次样本使用，覆盖全部 56700 个合法 U；U TX 标签始终不读取。主目标使用当前学生 eval/no_grad 弱视图概率，阈值 0.95，强视图噪声标准差 0.015，KL 权重 0.25×ramp，分母为完整主批。

多层方案从 step448 开始每四次主更新附加一次辅助计算，共 999 次；每次同一天 60 个有标签样本，累计 59940 次 L 使用。两个头 CE 取均值，系数 0.1×ramp。MIX_L 每次含 clean 和 mixed 两次前向，CE 各半；其余多层组一次。辅助步骤与主步骤共用一次主 optimizer.step，并非每四个 epoch 更新。等主更新数不等于等总计算量，预热、额外样本和实测资源必须单列。

## MixStyle 的约束

在浅中层 `[B,C,T]` 图上混合 detached 通道时序均值和标准差，保留标准化后的局部内容。每层独立概率 0.5，Beta(0.1,0.1)，移动量 `0.3*(1-beta)`。L donor 为同 TX、不同 RX、同日期、不同物理样本。U 使用当前弱视图的 detached 伪类别，仅当 donor 和 recipient 都达到 0.95，且同伪类别、不同 RX、同日期时允许混合。拒绝样本使用各自唯一伪组，不能作为 donor。实际 donor 资格与混合次数、比例、特征变动量逐层记录；高置信不等于真实正确。

MIX_U/JOINT 的修改进入实际 U 强视图主前向，在主分类头计算 KL；不额外拷贝学生或读取 U 标签，保留主路径 dropout。两个位置按网络拓扑先后作用；中层统计来自已经过浅层扰动的图。推理关闭所有 hook，原生身份输出路径不增加辅助网络计算。

## Fishr 公式与真实作用力度

令第 l 层池化特征为 z，辅助线性读出为 W,b，`p=softmax(Wz+b)`。逐样本读出参数梯度值为 `g=(p-onehot(y)) outer [z;1]`。在同一日期、各 RX 相同 TX 比例的批中，计算每个 RX 的中心梯度方差 v（分母 n），再对五 RX 的 `||v_rx-mean_rx(v)||²` 取坐标与 RX 均值，得到 F_l。无方差归一化，无 EMA。W,b 在此正则的计算图中 detach，z 保持可导；辅助 CE 单独更新 W,b，避免读出头靠缩放直接缩小正则。

RAW 使用 `mean_l(2*ramp*F_l)`。BUDGET 使用同一 F_l，浅层选 `time_fuse` 参数、中层选 `t2` 参数计算参考梯度，不包含 Hz 参数：

`lambda_l = min(10000, 0.1*ramp*||grad_theta_l CE_main|| / (||grad_theta_l F_l||+1e-12))`

lambda 停止梯度，最终正则 `mean_l(lambda_l*F_l)`。分母过小、缺失或非有限时跳过该项并记录原因；主总损失与训练梯度仍须有限。两层均值之前请求 10%×ramp，均值之后每层直接贡献约 5%×ramp，受 cap 影响可能更低。中层项还能回传到浅层，因此合并后的浅层实际比例并非固定 10%。每次辅助步骤记录系数、cap、均值前后比例、两个参数组收到的总 Fishr 梯度比例；不把配置比例冒充实测比例。

这是一种源侧力度控制实验，尚不能证明它能改善未知接收机泛化。全部源码、源数据核验、梯度与 warmup 验证、独立 P0/P1 审查通过后发布。
