# SatIQ PAMF-SUP 同卫星波束分类权重共享

[配置](experiment.json) · [事件](events.jsonl) · [卫星与波束误差依据](../20261120-diagnostic-satiq-formal-hierarchical-source-e30-e40-s2026111907-r01/report.md) · [同预算基准](../20261120-diagnostic-satiq-full-header-uw-time-source-e1-s2026092701-r01/report.md)

正式第 40 轮首选波束所属卫星正确率仅 4.4265%。如果以真实卫星作离线分组，同星条件波束准确率为 24.9629%。因此测试能否通过训练中的分类权重共享改进跨卫星排序。每个波束的权重等于原独立波束权重加同一卫星 ID 的共享权重的 0.5 倍，再按原方法归一化。共享向量全零初始化，所以初始有效权重和原基准一致。稀疏映射来自源训练契约的波束标签表，包含 115 个卫星 ID 组。训练和推理始终输出 3,103 个完整波束分数，逐包推理无需卫星标签和候选过滤。

保持原 11,000 点对齐输入、五分支、256 维融合、同一分类与原型损失、相同采样和 Adam，采用常数分类倍率 30。从相同种子全新训练。固定第 5,000、20,000、28,225 步报告同一 49,814 条源 V 的 Top-1 与主 CE，首轮匹配基准为 109 条、0.2188%、主 CE 7.5832。若有收益，再核对原首选卫星与同星条件波束指标。独立 T 留出。

本地合成检查覆盖相同初始分数、共享向量梯度及合法的波束权重形状。N607 真实 L 小检查只核对实现，不作为性能结果。

**VERIFIED 已排队。** 2026-11-20T19:47:38+08:00 核对 N607 控制进程 PID 2821290 及真实 32 包小检查退出码 0，主头和五路分数逐元素一致。共享与独立权重的 CE 梯度范数分别为 13.5991 与 28.1623，无训练 PID。
