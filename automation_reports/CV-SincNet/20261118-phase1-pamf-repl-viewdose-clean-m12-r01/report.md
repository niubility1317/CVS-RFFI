# 等剂量基础 CE 与 KL 视图归因

状态 PLANNED。逐行配置与路径见 [experiment.json](experiment.json)。

两种设置各六行。同源数据、同 Tri E20、种子 2026092701、固定 E50。一个组保持基础 CE 总系数 1，并复用原配对 KL，比较普通加噪、全量原始、两者各半。另一个组关闭基础 CE，保持配对 KL 总系数 0.8 及各设置原有的 KL 倍数，在同三个视图方案间分配 KL。两组分别复用 [已完成的损失剂量对照](../20261118-phase1-pamf-repl-lossdose-clean-m16-r01/analysis.md) 中相同剂量的 `aux1_ce1p0` 与 `aux1_ce0p0`。既有同设置同种子的普通 PL 用于主比较。

六个无标签前向、置信阈值 0.95、共享风格配对、各视图的样本分母与浅层/融合项均延用同一流程。仅改变特定损失对既有视图的权重。普通加噪和原始视图都覆盖整个 U 批次，使用同一当步接受掩码。原 As 槽为半批原始 IQ。各训练轨迹仍会产生不同的接受掩码。逐步记录各视图 CE、KL、分母、接受率及现有 L/U 梯度，AdamW 继续每 100 步采样。

主 clean 合并 `cross_rx + cross_both`，另行保留跨日期 clean 诊断。冻结后才预测，预测后独立评分，U 真值另由冻结后评分使用。同一已曝光种子上的结果只用于探索。GPU 仅使用现有空余容量，停止规则限系统性错误、数据权限和技术故障，保留已运行的健康任务。
