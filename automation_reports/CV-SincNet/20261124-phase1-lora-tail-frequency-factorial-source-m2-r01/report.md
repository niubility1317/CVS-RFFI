# LoRa 冻结复数修正的频带析因

## 预登记

先前在同一批已加扰源域低城区包上，尾部损失同时降低了两条信道路线 9–32 kHz 复数误差和外带误差上尾，六景识别却没有稳定提升。这里用冻结的平均损失组和尾部损失组定位识别损益。两组权重、去扫坐标和门限直接沿用。参考是两条路线各自原有的成熟半量 DURA，识别器为冻结 Tri-set 2026092702。 [上轮尾部损失配对结果](../20261124-phase1-lora-tail-pilot-source-m4-r01/report.md)

在门限激活的同一接收包上，沿去扫后的绝对频率切分正负两侧。四个频带为 1–8、9–32、33–64、65–128 kHz。第一组以接收信号为起点，逐带加回尾部模型的半量复数修正，16 种组合包含直通和原尾部半量。第二组以平均模型完整细化为起点，逐带替换为尾部模型的完整细化，16 种组合包含两种原细化。两组和同路 DURA 共 33 个读出。两次干预保留原直流载波，使用实收相干度、样点旋转、幅度尺度及外带扰动门限，原坐标回写。两路各重放同一组 900 个源 V 包、同样七景。源 U 只用于两包真实权重、无 query 检查。

每路七景的预测写齐后，独立 CPU 先比对两路物理 ID 和历史对应的五个读出，逐包核对 direct、DURA、尾部半量、平均完整、尾部完整的预测，再读取源 V 真值。对每包、每景的正确性，用四频带全组合的 Shapley 值分配净变化。95% 配对区间按固定接收机分层，在层内重抽物理包并保留同包六景关联，共 1,600 次。每包任选组合的全知计数只描述现有修正的诊断空间。固定组合若在本面板同时达到两路六景超成熟半量 DURA 且 clean 持平，只作为独立源域验证候选。该实验无训练、无目标访问和真值选模。使用已有的五源接收机面板，区间的解释限于这些接收机、冻结识别器和当前扰动重放。Shapley 归因的背景见原始定义，频带干预针对实收复数修正。 [Shapley 原文](https://doi.org/10.1515/9781400881970-018) · [基于移除的归因框架](https://jmlr.org/papers/v22/20-1316.html)

固定运行矩阵、环境、输出、命令和失败停止规则见登记。

## 源域识别结果

固定组合无一同时超过两路 DURA。两路所有读出的 clean 均为 667/900，候选恢复器均零触发。六景正确数分母为 5,400，低城区分母为 900。最佳频带组合为本面板的事后最大值，区间只反映同包差异，未修正组合比较次数。

65–128 kHz 的收益在尾部半量相对于直通时，两路配对区间均在零以上。Full 的 9–32 kHz 半量修正贡献为 −24.0，配对区间在零以下。平均模型换成尾部模型的完整细化时，9–32 kHz 六景归因区间在两路都跨零。先前隔离的低城区实际复数误差改善，因而不足以推断该频带在六景的识别收益。

尾部半量全频带相对直通，full 纠错 125 次、改错 100 次。Residual 纠错 242 次、改错 221 次。假设知道每个包每个场景的真值并从 16 种半量读出中任选，六景正确数可以到 3,338（61.81%）和 3,337（61.80%）。这组上限只用于量化各组合的纠错互补性。固定掩码未跨过 DURA，对含新模型的独立源域研究保留 65–128 kHz 贡献及低频修正损失作为设计线索。
