# 固定恢复器的源域噪声响应

在此前微扰响应比较的同一批 672 条合法源 IQ 上，给每条 received 输入增加四次独立高斯方向的微小噪声；每次噪声归一化为该条 received RMS 的 1%，三个固定模型使用完全相同的噪声。对每个扰动，计算“恢复输出变化能量／输入增加噪声能量”，再按每组 48 条、每条四次、14 个 RX/场景组等权平均。该值衡量局部敏感性，等于 1 表示输出变化与注入噪声的能量相同；它不是识别准确率。

| 模型 | 输出变化能量／输入噪声能量 | 加噪前后源 IQ NMSE 平均差 |
| --- | ---: | ---: |
| DURA | 0.518789 | +0.00005307 |
| 普通多尺度修正 | 0.520183 | +0.00005356 |
| 响应约束修正 | 0.551990 | +0.00005178 |

响应约束版在 13/14 个组的局部噪声响应高于普通修正；组均值高约 6.1%，但三个模型的平均能量比均小于 1。RX4/6 低城区分别为 0.14259、0.14356、0.15990，RX8 低城区分别为 0.35045、0.35268、0.36362。加噪后 NMSE 差有噪声与原误差的交叉项，少量抽样、弱扰动下个别分组可为负；不能仅凭局部响应能量推断波形误差或身份准确率必然变差。

结合此前固定人工信号方向的响应比较，这提示源域训练可研究同时保持信号变化、控制无关噪声的约束。这里比较的响应约束模型曾经完成地面测试，选择它用于事后解释，不是独立目标验证；禁止用这些已观察的目标分数选择新模型或调整新方案。高斯加噪是局部代理，并不等同于真实星地噪声。四个固定随机方向、单一扰动强度和源 pilot 不足以建立统计普遍性。训练模型未改变，诊断未读取 F 权重或输出、TX 标签、V 或目标。真实模型源 smoke、两项针对性测试和独立 P0/P1 审查通过，完整聚合结果见本目录 `result.json`。
