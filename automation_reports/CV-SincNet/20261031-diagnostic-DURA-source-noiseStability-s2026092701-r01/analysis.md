## 实际观察与解释

缓存 01/20 的非 clean 样本分别为 428/431 条。单阶段原 NMSE 为 2.423354%/2.270134%，扰动后为 3.174511%/2.914779%；默认原为 2.417283%/2.308843%，扰动后为 3.128499%/2.917593%。两者均受额外噪声影响，但增益差只有约 11.19% 和 0.57%，不是预定的 25% 以上。该结果不能证明不存在任何噪声稳定性问题；它说明当前对照没有把单阶段质量差距明确定位到这一因素。

“噪声增益”是非 clean 总体平均输出变化能量除以平均输入扰动能量。其值约为 0.10 至 0.124，表示这组各向同性扰动的输出变化能量小于输入扰动，不能写成网络把全部接收噪声放大了相同倍数。它也不是对所有扰动方向的 Jacobian 范数或恢复极限。

源 clean-F 选择一致数（不是 TX 真值准确率）：缓存 01 单阶段 native488、+ε482、−ε476，默认 native486、+ε479、−ε474；缓存 20 单阶段 native497、+ε485、−ε497，默认 native498、+ε487、−ε488。两模型都出现部分判断扰动；这些指标只描述，不用来调整噪声强度、资格、类别权重或选模型。完整 role/RX/day/scene/state/lock 分解见 results.json。

## 方法、权限和成本

冻结原纯 G repeatViews E30/7410/8cf8e22 与默认 R69 E20/4940。两者接收同一 source512（128L/384U）、缓存 01/20 的相同 received。独立 CPU 随机种子 2026103113+view 生成标准正态向量，乘以缓存标量方差的平方根，形成 ±ε；两模型逐条扰动完全相同，clean 场景 ε=0，原 clean 与 received 均不改变。

这是可控的各向同性接收端扰动。缓存方差来自原 source 模拟器的标量噪声监督，不表示重新抽样原生信道完整噪声分布；不将本次条件说成新的独立物理观测或精确降低 SNR 3dB。负扰动用于配对降低一阶误差交叉项，不是新的原始样本。

五项聚焦检查及实际模块 --help 通过，一次独立 P0/P1 审查 PASS。执行 commit 7475398c2b188ad37358ec8c8e10b1691b4ec65c；一次 N607 preflight、一归档本远 SHA、远端编译已完成。首步两模型各 2Ls 的真实 G/F 原头检查 PASS 后直接运行。PID1349938 的实际 CWD/argv/CUDA空/日志807→938字节已核实，完整四单元后进程自然结束；未操作其他 owner。
