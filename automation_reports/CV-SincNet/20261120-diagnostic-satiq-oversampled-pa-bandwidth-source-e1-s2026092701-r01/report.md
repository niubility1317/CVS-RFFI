# SatIQ PAMF-SUP 非线性分支带宽对照

[配置](experiment.json) · [事件](events.jsonl) · [原 PA 基准](../20261120-diagnostic-satiq-full-header-uw-time-source-e1-s2026092701-r01/report.md)

正式第 60 轮的非线性支路在 256 点、581.82 kS/s 网格上使用 1、3、5 阶记忆多项式，四个滞后。用种子 2026111923 抽取 4,096 条已知源训练包，只读冻结正式权重，比较相同带限输入在 256 和 2,048 点形成的幂项。在 0–250 kHz 的五阶谱中，256 点相对 2,048 点的差分能量中位数为 0.0851%，第 99 百分位为 2.1808%。三阶差分能量中位数为 0.0344%。这批包在 2,048 点上均未触发 I/Q 的幅值裁剪。

保持原输入带宽时，把多项式提高到较密网格再投影到原 256 点，冻结模型的 PA 投影相对变化中位数为 1.03%，首选一致 3,915/4,096，正确 122 → 121。把 500 kHz 截止只用于三阶和五阶，在相同 256 输出网格投影后，PA 投影相对变化中位数为 9.10%，首选一致 2,781/4,096，正确 122 → 124。两次冻结测量为源 L 上的敏感性对照，没有重新拟合或预测独立 T。

新训练把两组的三阶与五阶均放到 2,048 点，再只保留 256 点网格能表达的频率，原滞后保持相同样点间隔。250 kHz 组的渐变带为 187.5–250 kHz，500 kHz 组为 375–500 kHz。一阶、门控输入、其他四条分支、融合 256 维和全 3,103 类分类头沿用原实现。两组都从头用相同数据及 28,225 步训练，固定 5,000、20,000、28,225 步比较单包 Top-1 和主 CE。原 256 点直接做幂项的首轮作历史基准，直接判断带宽时比较两条 2,048 点训练。独立 T 留出。

本地验证已确认三阶折叠项去除、正负频率映射、Nyquist 点、四个原滞后、线性项恒等与有限梯度。
