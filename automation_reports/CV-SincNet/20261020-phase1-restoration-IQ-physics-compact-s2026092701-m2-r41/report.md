## 方法、权限与训练成本

全链 dense 通道收窄，四组 GroupNorm 内等量取通道，decoder skip 保留原拼接偏移；三步 prior 共享长卷积权重，保留分步 bias/GN/pointwise。全部 coarse/action/prior 联合更新。输入仅当前 IQ、输出一份 IQ，原 PAMF 统一计算 FFT/PA/时域/统计。

损失保留最终 paired-clean IQ NMSE＋λ×三个 stage 到冻结原 R17 IQ 教师的 NMSE 均值，λ 固定 E1=10 线性至 E20=1；另加 0.1 coarse-clean NMSE、0.1 复合信道两探针 NMSE 和 0.01 实轴原生噪声方差 log 比平方，均使用匹配当前 received 的原 R07 合成参数。clean 配对确实进入优化，因此准确名称为 TX 无标签模拟配对自监督，加已知合成信道参数监督及 F-free IQ 教师；不是没有 clean/参数信息的盲无监督学习。teacher 保留原上下文、停梯度且不更新。恢复器训练 0 TX 标签、0 F 权重/输出、0 V/target；原 F 仅在冻结评估和无 query smoke 使用。

两行均原 L6300/U56700 全部 63000 条，20 个原 R07 received 缓存 epoch，15% clean/85% residual。batch256/micro64，最后不满 batch 按实际分母累积，4940 次 AdamW、一次/globalbatch clip1，FP32/noTF32，固定学习率日程。
