# 独立学生复数滤波：源训练完成

N607 GPU 5，固定合法源 32768 个物理 ID × 三视图，在冻结的源学生上增量训练 FIR 修正五轮；父学生此前训练 20 轮，不能与从零训练五轮模型视为等预算。训练不使用 F、TX 标签、V 或目标，原 DURA 仅作源 IQ 教师；推理不调用 DURA。

真实源训练 smoke 通过，五轮优化日志耗时 215.5 秒；此前 GPU 一次性学生输出预计算 33.674 秒、源上下文读取 0.720 秒及传输 0.263 秒另计，源教师及父学生训练成本也另计。没有同一 N607 条件下未缓存训练实测，不能声称此数值就是 N607 的加速倍数。

672 条已探索源 pilot 的 14 个等量分组中，14/14 组的新学生平均 IQ NMSE 低于固定父学生，但低城区仍明显高于 DURA；波形误差不是身份识别成绩。全部七景预测正在运行，尚无正式识别结论。
