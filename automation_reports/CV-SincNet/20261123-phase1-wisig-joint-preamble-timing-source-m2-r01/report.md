# WiSig 短长前导共享五抽头定时恢复源域对照

本实验检验整数定时修复能否在实际主对比所用的冻结 Tri-SIG-TIME SSL 上复现收益，以及短、长前导共享一个短信道响应能否提高定时可靠性。两路各用同一组 1,800 个源域 V 物理包，同一 clean 和六实用视图，均沿用既有信道实现及成对缓存。读出使用 seed 2026092701 的原分类头。五个读出同时固定，分别为直通、原 R69、边界变化与长前导相关、共享五抽头加反射补边、共享五抽头加公开前导补边。

## 接收估计

输入为当前接收包的 256 点复数 IQ。只用 40 至 119 点的短前导重复估计粗频偏，并在 160 至 240 点上搜索 L-STF 到 L-LTF 的转换位置。单相关对照用周期残差的前后变化和 16 点长前导复相关评分。联合方法比较转换前 40 点和转换后 16 点，让两个字段共享一个中心对齐的五抽头复 FIR。奇偶样本交叉拟合，两个字段分别以各自接收能量归一后等权评分。远离名义位置超过 5 点的最佳假设与名义区间的最佳假设计算分差。两种估计各自以相同 4,096 个源 U clean IQ 的 99.9% 分位固定触发阈值，两路共用。所有估计都可以由部署时的单包 IQ 和公开波形计算。[WiSig 原论文 §IV-B](https://arxiv.org/pdf/2112.15363#page=4) · [GNU Radio 公开 legacy 前导序列](https://github.com/bastibl/gr-ieee802-11/blob/maint-3.10/examples/wifi_phy_hier.grc)

触发后整数搬移原接收样本。共同覆盖片段保持原始复数 IQ。单相关对照在缺前缀时镜像填充，缺后缀时用 L-LTF 和可见前导得到的复增益填充。联合方法先作反射补边对照，再用短 FIR 预测缺失前缀或后缀。合成点恢复接收端载波相位坐标。没有训练更新。配对 clean IQ 只用于预测后的波形差诊断，不参与候选和阈值。

## 固定矩阵

N607 用两个可用物理 GPU 分别预测两路，先运行冻结识别器和原 R69 的真实 checkpoint smoke。两路全部视图和读出写出后独立 CPU scorer 才读取源 V TX 真值。报告 clean 正确数、六景配对差和区间、逐 RX 变化、触发包数及波形 NMSE。若联合方法在两路均未同时超过 R69 的六景均值并保持 clean，定时单模块留作局部诊断。输入、数值、checkpoint 绑定或输出闭合异常时停止派发。无目标访问。

本地四项针对性测试通过，包含通用正负位移、复增益等变性、完整保留收到的重叠样本与无信号有限值。独立 P0/P1 审查通过。版本、输出路径、命令及配额见同目录实验登记。

## 源域结果 VERIFIED

N607 执行提交 `18c053a17454ed8e7614b6b15ec891e0b00ac91f`，归档传输、远端编译和真实冻结 checkpoint smoke 通过。控制器 PID 1954180，已独立读取工作目录和命令。控制器记录 full 预测 PID 1954679 分配到 GPU 3，residual 预测 PID 1954680 分配到 GPU 6，两路分别写出七景并闭合产物。独立 CPU scorer PID 1955005 的命令和工作目录已现场核实。预测两路分别用时 9.85 秒和 9.79 秒，包含全部五种读出及波形诊断。当前未测单方法部署延迟。单相关与联合定时的源 U 分差阈值分别为 2.006413 和 0.659070。

共享五抽头的两个读出使用相同位移。改用协议补边后，full 和 residual 六景分别净多判对 65 和 68 次。相对直通，该联合方法 full 纠正 63 次、改错 89 次，residual 纠正 64 次、改错 90 次，均净少 26 次。两路按同一物理包、RX 和采集日分层的 95% 配对区间均约为 −54 至 0。相对 R69，联合方法分别净少判对 1,163 和 1,159 次。低城区 full 和 residual 各 179 包触发定时，两路 clean 各 1 包触发，clean 正确数均保持。逐景、逐 RX、波形误差及区间见 [源域独立评分](source_scores.json) 和 [源 U 阈值](timing_thresholds.json)。

历史同一源面板的 F50 默认头在边界估计后明显改善。当前 Tri-SIG-TIME SSL 默认头下，单相关对照和共享五抽头均未复现相对直通的收益。两轮同时更改了实现与识别器，两者各自的贡献尚待隔离。共享五抽头协议补边的收益限于同位移镜像对照。两条路线的直接前导定时方案均不晋级正式主对比。
