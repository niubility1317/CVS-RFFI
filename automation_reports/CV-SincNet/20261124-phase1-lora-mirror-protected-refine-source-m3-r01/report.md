# LoRa 包内镜像证据约束细化

## 预登记

镜像频点的上一轮匹配消融在 residual 粗恢复多判对 96/5,400，完整细化后净差为 −8/5,400。本轮检验实收镜像信息能否保护粗恢复已得到的信号方向。基础模型、接收输入、共轭频点、源 U 损失和推理坐标沿用原镜像臂。复杂度与识别比较以同规模、同 3,600 步已冻结的原镜像臂作对照。每一候选端到端训练一次。 [原镜像共轭恢复](../20261124-phase1-lora-conjugate-companion-source-m4-r01/report.md)

从当前实收包的六条对齐 chirp 中，排除正在修正的 chirp，另外五条按相对顺序分为 3 条奇偏移和 2 条偶偏移。两个集合各自按实收相干度平方加权平均镜像共轭谱。在去扫绝对频率 1–8、9–32、33–64、65–127 kHz 中，分别计算两组单位归一化内积的实部。减去独立白噪声归一化内积约一标准差的经验底值，再取正部 s。以 s/(0.2+s) 表示观测一致程度。在每带将两组均值合成一个复数方向，从细化相对粗恢复的增量中减掉沿该方向的投影，扣除比例等于一致程度。DC 与 Nyquist 不参与投影，其他复数方向使用原更新。两路共用同一算式与源 U 门限。信道约束沿用恒等作用与同一实收外带方差代理，不拟合真信道。本轮只估计同包谱方向的重复支持。全波形 practical 中 chirp 可能共享干扰，该系数也可能受相干干扰或频偏失配影响，不能解释为已知噪声方差或纯信号概率。

两组互斥观测提供交叉证据，沿用复数子空间投影思路。在本实验中，保护方向从当前包内部估计，用于约束波形细化，而原子空间检测方法构造具有信号和干扰模型的统计检验。Noise2Noise 用独立受扰样本替代干净训练目标。本实验的洁净目标来自合法实测源 U，本包分组只用于推理和训练中的方向支持。 [子空间检测原论文](https://doi.org/10.1109/78.301849) · [Noise2Noise 原论文](https://proceedings.mlr.press/v80/lehtinen18a.html) · [公开训练实现](https://github.com/NVlabs/noise2noise/blob/master/train.py#L107-L108)

新臂从零训练 3,600 步，沿用 5,000 个源 U 拟合包、2,500 个互斥 clean 校准包和 500 个同源留出包。batch 12，匹配独立通用有色噪声和短回波、三视图复数误差、弱复谱差异传递、0.45 上尾项、AdamW 与余弦日程。校准只用 clean 外带功率。训练、校准和冻结隔离 V、识别器、TX、目标以及任何 practical 真算子和噪声。第一步使用真实父 R69、原镜像、冻结 F 与两个源 U 样本做无 query 检查。冻结后，沿两路线复用同一 900 个源 V 包、七景、Tri-set 2026092702。读出含直通、同路成熟半量 DURA、旧镜像粗／完整／半量、在旧镜像权重上直接加保护的完整／半量、新保护臂粗／完整／半量以及新臂同剂量完整／半量。同剂量对照保持未经保护的最终修正方向，每条 chirp 的每个频带匹配保护后相对实收的改动范数。当原方向为零时保留保护结果。

两路预测全冻结，独立 CPU 首先逐包核对两路物理 ID 和父 run 五个对应读出，再读源 V 真值。报告完整、半量及同剂量配对差，逐场景、逐 RX、逐频带支持、clean、参数量和 B1。进入正式测试的读出须在两条路线的六景都超过成熟半量 DURA 并保住 clean。新旧权重来源、命令、环境、GPU、停止规则与产物见实验登记。


## 旧镜像模型的同包粗细转移

在旧 run 已冻结的 900 个源 V 包上逐景复核，共 5,400 次场景曝光。Residual 的粗恢复有 379 次仅镜像正确，283 次仅同侧邻频正确，净差为 +96。在前 379 次中，细化后有 24 次仍是镜像独自正确，168 次两组都正确，175 次两组都错，12 次只剩邻频正确。镜像细化丢失了其中 187 次，邻频也追上了一部分。粗阶段两组正确性相同的 4,738 次曝光，在细化后有 109 次镜像独自正确和 109 次邻频独自正确。Full 的粗阶段净差 +24 在细化后降至 −9。此归因只关联旧 run 已经固定的合法源 V 标签。 [同包转移明细](parent-coarse-fine-transitions.json) · [复现脚本](parent_coarse_fine_transitions.py)

## 旧权重加投影后的留出源 U 波形误差

500 个留出源 U 包只施加独立通用有色噪声和短回波。用实收坐标比较复数误差。该检查不读取源 V、识别器、TX 或目标，也不改训练。触发恢复的 2,868 条 chirp 中，1–8 kHz 的平均归一化对数复数误差，从普通细化的 1.3057 降到保护细化的 1.1781，同剂量对照为 1.2189。71.16% 的活跃 chirp 在这一频带误差下降。按实收扰动指标取最高 10% 的 288 条 chirp，普通、保护、同剂量依次为 1.2333、1.1395、1.1779。其他三个频带的活跃均值下降均小于 0.001。保护主要改变了近载波频带。采用原粗恢复时该频带误差更低（0.5709），已有源域识别结果显示粗读出本身有明显退化。 [源 U 波形检查](frozen-source-u-projection.json) · [复现脚本](frozen_source_u_projection.py)
