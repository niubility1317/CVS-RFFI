# 恢复极限、识别增强与现有性能证据

**目前能报告的是已达到的识别效果，尚不能给出“最多恢复成 clean 的八成或九成”的可信理论数值。** 逐场景距同一 raw clean ≤3 个百分点并保持 clean，是这项工作的主验收；训练效率为支线。

## 先区分三个问题

| 问题 | 合适指标 | 能说明什么 |
|---|---|---|
| 指定 clean 波形还原到什么程度 | 同物理记录的 IQ NMSE、相位/频谱误差 | 对指定参考波形的误差 |
| 冻结识别器是否保留 clean 判决 | F(G(received)) 与 F(clean) 的判决/连续特征比较 | 与该识别器参考输出的保持程度 |
| 恢复后能否正确识别真实发射机 | 固定默认头的真实 TX 准确率、修复/损伤、逐 TX/RX/day | 实际任务收益 |

三个指标不能相互换算。特别是 1−NMSE、与 clean 的判决一致率、恢复准确率/clean 准确率，都不能直接命名为“发射机信息恢复率”。clean 默认头本身也有错误，因此恢复后的单项任务准确率不是必须低于该固定头的 raw clean 准确率。

## 当前 DURA 达到的是多少

同一原地面完整 Tri-SIG-TIME SSL/default head/Main split 的 raw clean 为 86.538690%（145385/168000）；≤3pp 要求每景至少 83.538690%（140345 条正确）。

| 场景 | DURA 准确率 | 距 raw clean | 准确率保留比例 |
|---|---:|---:|---:|
| 高档郊区 | 84.343452% | 2.195238 pp | 97.463287% |
| 中档郊区 | 83.016071% | 3.522619 pp | 95.929429% |
| 低档郊区 | 81.322024% | 5.216667 pp | 93.971868% |
| 高档城区 | 83.049405% | 3.489286 pp | 95.967947% |
| 中档城区 | 75.705952% | 10.832738 pp | 87.482202% |

## 为什么波形最优与识别最优可能不同

设 clean IQ 为 X，星地观测为 Y，恢复为 G(Y)。在给定联合分布和平方误差目标下，条件均值 E[X|Y] 是最小均方误差估计；这一定理只规定平方误差最优。[MIT 最小均方误差课程](https://ocw.mit.edu/courses/res-6-012-introduction-to-probability-spring-2018/1937367208c8d3b6f1d9ae0a7e2a4373_MlsVWPWIxHI.pdf)

据平方误差的正交分解，可写成：

$$\mathbb E\|X-G(Y)\|^2=\mathbb E\|X-\mathbb E[X\mid Y]\|^2+\mathbb E\|\mathbb E[X\mid Y]-G(Y)\|^2.$$

本任务的推论是：第一项代表该分布和观测下不可由确定估计消除的均方不确定性，第二项才是某个恢复器相对条件均值的额外误差。现在没有可靠估计第一项，不能把某一神经网络误差当作不可恢复部分。多个可能 clean 的平均也未必保持固定 F 最需要的高阶局部结构，因此降低 IQ NMSE 不保证提高 TX 准确率。后一句是对本任务的机制解释，不是已经量化的因果分解。

网络参数固定后，T→Y→G(Y) 构成马尔可夫链，数据处理不等式给出 I(T;G(Y))≤I(T;Y)。恢复器可让已有信息更易被固定 F 使用，但不能由单条观测产生新的独立发射机证据。[Polyanskiy 与 Wu，2017](https://dspace.mit.edu/entities/publication/47c8e0bc-4dff-436f-a2f4-e091e5095bf4)

因此“突出某些发射机特质”是可检验的研发方向。应检验固定 F∘G 的真实身份纠错，以及源内外、未知设备和 clean 的保持。若只把输出推向六类头偏好的模式，闭集分数上涨仍不足以说明未知设备特征被保留；本恢复器训练继续只用原 L_s/U_s，OE 仅冻结诊断。

若希望给识别极限一个信息论数值，六类下可用 Fano 型下界 P_e≥max(0,(H(T|Y)−1)/log₂6)。它要求原观测下的条件熵或其可靠界；这里没有这样的估计，不能用某个模型的错误率替代。[Stanford 信息论讲义，第10讲](https://tselab.stanford.edu/mirror/ee376a_winter1617/Lecture_10.pdf)

## 现有实验排除了什么，又没有排除什么

已完成的未限幅特征指导对照相对固定 VarF 在六景均有小幅收益，但仍全部低于 DURA，且合并 clean 减少91条正确。它说明放开这一梯度限制对该模型有实际作用，没有解决跨 RX 星地识别差距。

PHY-MSAT 的源端 IQ/连续特征误差更低，clean 增加1138条正确，低档城区主准确率却只有62.831548%。因此“物理求解更强、参数更多、源端更低误差”不足以推出主性能提升。该模型还改变了结构和源 action 监督，不能将结果归因于单个因素。

冻结 source V1800 的低档城区 Fclean 判决一致率：DURA86.111111%、原MSAT88.055556%、PHY91.166667%、FullFGrad89.555556%。这些验证记录没有参与新 G 更新，结果弱化了单纯训练记录记忆这一解释。但它们仍属于原源 RX/day 范围，不能证明未见 RX 泛化良好，也不是 TX 准确率。

源端 true-H/true-noise 反事实只在同一有限网络、同一源面板中替换物理量。PHY 低档城区 true-H 将 Fclean 一致率从90.250696%提高到91.643454%，并非100%；真值替换还会影响已学先验的上下文。它提供机制诊断，不是最优网络、真实 TX 或目标域的上限。

配对源端相位/增益/FIR压力诊断中，+90°使 F0(clean) 自身约21%的判决改变。直接强制 G 的相位等变并不能据此保证更好的固定 F 识别。gain0.7/1.4还改变了原 clean 单位功率约定。当前连续特征条件候选因而检验源连续特征预测与单位功率输出，没有据这项诊断强制群平均。

这些研究仍没有将信道不可辨识、噪声损失、源至目标分布差异、G 的估计误差和固定 F 的非最优性分离成可相加的百分点。继续据合法源机制证据设计对照，每版固定后完成同一 Main 七景和独立评分；不根据目标误分类调参、选模或选择性重跑。
