## 这次检验了什么

本次从零训练 4670178 参数的共享 MSAT 编码器，连续回归原 F0 的 160 维源 clean 特征。四个 FiLM 层以当前 received 所预测的特征调节瓶颈和解码器，残差 IQ 最终投影到原 clean 的单位复功率。全部学习参数重新初始化，旧 G、DURA、coarse 和神经 IQ 教师没有进入初始化或训练。

F0 clean 特征只作为停止梯度的损失目标；G 前向和部署只接收当前 IQ。连续特征回归层不是六类分类头，原 F0/default head 保持冻结。训练无 TX 标签、logits、CE、类原型或另训身份头。这是 F-guided 方法，需披露原 F0 知识和训练计算成本。

相对固定 FullFGrad，本次同时加入连续特征条件、辅助特征回归和单位功率投影，因此是系统比较，不能将结果单独归因于某一项。两个模型原 L_s6300/U_s56700、R07 的 20+10 draw、源样本顺序、30 轮/7410 更新、AdamW/学习率/批次和全局参数 clip1 匹配；不同结构初始张量不相等。

损失为 IQ NMSE + .05 STFT + .1（输出 F0 余弦误差 + 源方差标准化 MSE）+ .1（预测连续特征余弦误差 + 同尺度 MSE）。源 F0 clean63000 缓存与原源方差尺度复用；没有 V/OE/novel/目标拟合、早停或选模，OE 只允许冻结诊断。

源端配对变换诊断显示，旋转相位会明显改变 F0(clean) 自身判决，增益变化也会离开原 clean 单位功率约定。本次据此使用单位功率约束，没有强制相位等变、群平均或新增相位/增益/FIR 训练增强。这些源诊断不能证明 Main 失败的唯一原因。

两个 Main 总体的 168000×七景预测全部固定后独立 CPU truth-last。raw/DURA 同 IQ-ID 判决精确复用，新 G 完整推理。固定 final30，没有源质量取消测试，也没有目标反馈调参、选模或选择性重跑。原 Main 已是曝光开发基准，单 seed 不构成新的独立盲测或未知设备保真证明；默认 DURA 保持。

## 能否说“恢复成 clean 的几成”

本次低档城区准确率为 64.372619%，除以 raw clean 的准确率得到 74.385941% 的准确率保留比例。DURA 对应比例为 79.503388%。这两个比例不能解释为波形或发射机信息恢复比例。

IQ NMSE 衡量与指定 clean 波形的平方误差，F(clean) 判决一致率衡量冻结识别器决策保持，真实 TX 准确率衡量任务表现。三者没有通用的一一换算。本文没有给出信道与噪声下可辨识性的理论界，也没有用 true-H 的有限网络反事实冒充最优恢复上限。

恢复网络可以学习保留并突出对冻结 F0 有用的源端发射机特征，但效果必须由同一真实 TX 的净纠错和 clean 保持验证。即使某景超过 raw clean，也只能先称为该任务上的识别收益，不能据此证明丢失信息被完整还原。当前六景≤3pp目标仍以表中实际验收为准。
