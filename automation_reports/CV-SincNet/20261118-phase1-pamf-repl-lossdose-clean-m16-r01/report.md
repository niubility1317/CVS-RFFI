# 伪标签 CE 与辅助损失剂量交叉实验

状态为本地准备。逐行数据契约、源权重、配置和评分输出见 [experiment.json](experiment.json)。

主要目标是提高十类和六源的跨接收机 clean 准确率，相对同设置、同种子的普通 PL 做逐物理样本配对。上一批六源在显著降低梯度冲突后 clean 没有提高，十类的收益也有限。因此这批直接改变 U 各项对训练的贡献，梯度和 AdamW 继续作为机制诊断。

同一合规 Tri E20、固定阈值 0.95、U 公共权重 0.75、固定训练到 E50。在每种设置交叉四个基础 CE 倍数 1、0.5、0.25、0 和两个辅助倍数 1、0，共 16 行。十类开启辅助时包含浅层跨 RX 与 KL，六源包含 KL 与小权重融合。所有行使用相同已注册数据和接受机制。1/1 是完整剂量对照，0/0 是零 U 梯度续训控制，仍执行 U 前向，不能等同全程纯监督。各剂量交互可在同条件下配对解释，普通 PL 保留现有冻结对照。

主 clean 合并 cross_rx 与 cross_both，cross_date 单列；E50 模型冻结后独立预测评分、离线诊断 U 正确率。使用单个历史种子和已曝光目标，探索后再在预先固定的独立种子上复核。全部训练和选模使用合规源数据，验证保持只读。逐步记录加权 CE 与辅助损失、梯度范数和方向，每 100 步记录 AdamW 反事实。N607 空闲时均匀分配，保留现有健康任务和所有实验产物。系统性技术或协议失败可停止本批新派发。
