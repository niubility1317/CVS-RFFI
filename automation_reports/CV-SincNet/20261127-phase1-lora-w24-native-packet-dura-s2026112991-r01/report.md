# LoRa W24 完整 8,192 点原生 DURA

Run 20261127-phase1-lora-w24-native-packet-dura-s2026112991-r01。Full 星地七景。固定 W24 E104 和默认分类头。 [实验登记](experiment.json)

## 恢复链路

DURA 输入和输出均为同一个 1 MHz 采样时标上的连续 8,192 点复 IQ。对每条 chirp 用公开 LoRa 上扫频和实收相位斜率作跟踪，提取跟踪相位、相干和远带噪声估计。粗恢复和两个先验网络的卷积直接沿整个 8,192 点时轴运行，覆盖八个 chirp 及物理接缝，输入含实收、跨 chirp 差异和两步更新的创新。两次学习先验细化在同一份实收观测上做对角加权 MAP，观测作用近似为恒等，学习逐点先验与观测不确定性，随后投影到保留跟踪直流、限制修正 RMS 的输出。完整输出恢复到原幅相，保持每 chirp 的跟踪直流。W24 的裁窗、重采样、边缘点、包尺度和分类统一在恢复后按原实现执行。

以一个 111,698 参数模型从零训练，种子 2026112991。20,000 个合法源 U_s 拟合包、500 个互斥留出包，通用扰动，batch 16，同条源录波监督。每步两个实收 clean 恒等曝光。24,000 次 AdamW，2e-4 到 2e-5 余弦，裁剪 1。留出检查 2,000、6,000、12,000、18,000 及末步。损失直接约束写回半量后的整段复 IQ，加入两个早期读出、在跟踪坐标的低频公共和逐 chirp 差异复误差、原生两端样点及 clean 恒等。拟合不调用 W24，也不读取 TX、源 V、目标、登记 practical 观测或仿真真值。

## 同包对照

同一末步权重生成四条读出。主读出对完整捕获的原生差量乘 0.5 后，调用原 W24 前端。边缘消融用完全相同的恢复后 W24 中心，同时换回直通的已归一化原生边缘 48 点。另保留同两条双倍编辑压力对照。设计由此对比保留恢复后边缘的影响，同时用直通、原长训 DURA、首尾 DURA 和原 U-Net 对比总链路。早期 1,200 步原生恢复使用 E108，另作历史背景。

权重冻结后才加载原 E104。300 个同物理源 V 包的七景盲预测全部固定后独立读真值。整段半量只有六景严格超过固定对照、低城区达到最高对照且 clean 达到直通时，才触发同一物理顺序下的三个正式 Full 分片及独立 truth-last。正式口径 15 台未见 RX、30,000 包。

## 整段恢复可利用的空间

已归档的同一 300 包源域隔离对照使用精确新增噪声，仅恢复 W24 中心得到六景 1,680/1,800、低城区 259/300。精确去掉原生边缘噪声后，按恢复后中心 RMS 运行原 W24，结果为 1,714/1,800 和 270/300。边缘存在可利用的增益。当前原生网络的边缘回写增加了部分误改，后续应检查哪些改动偏离真实复噪声，而继续扩大原生读出幅度已有负证据。 [精确分量隔离诊断](../20261125-diagnostic-lora-w24-noise-aperture-source-s2026112559-r01/report.md)
