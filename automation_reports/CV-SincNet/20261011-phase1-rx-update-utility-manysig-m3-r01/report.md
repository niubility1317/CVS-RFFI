# 困难动作是否产生有用的跨接收机身份更新

状态 ANALYZED / VERIFIED，三种子诊断全部完成。本实验延续已提出的“新目标如何更新成熟骨干”问题，不使用目标测试成绩选择机制。已有源证据证明margin排序可学习，但该监督只问哪种IQ扰动更难，并未直接问哪种训练更新能帮助其他RX。这里分离二者。

三种子2026092701/02/03，均加载对应原E200与只在L预热的RANK_STATE辅助网络。父模型及风险网络来源沿用已核实契约并在加载时复核；没有E40身份或压缩权重继承。每种子30批，按5RX×3day循环两次。更新批来自单一RX/day，每类5条合法L，共30条；探针来自其他4RX、其他2day、6类每格2条，L和V各96条。V只无梯度前向，不用于动作选择或参数拟合。不是对全部27000条V的准确率评估，探针可重复，统计不把批次当作独立seed。

对全部8种物理动作，构造0.5clean CE＋0.5动作CE的身份梯度。另比较clean、均匀动作的期望梯度、冻结风险概率加权的期望梯度、真实L margin最难动作的梯度。概率加权是期望目标，区别于实际训练的随机单动作。每个候选和每个固定策略的方向先按encoder/fusion-head的1:3比例缩放，再归一化到相同dense参数相对L2位移1e-4或1e-3。原生Hz参数排除，模型eval消除随机前向。它不是AdamW重放，两个尺度均固定报告，不由V选择。

每个虚拟更新后测独立RX/day的L、V CE、margin和修复/破坏，并在finally中恢复所有参与参数；每批进一步核验整个模型及辅助state_dict逐值不变。L_selected只按L探针更新后CE选8候选之一，再报告对应V效果，V的数值不能改变选择。该策略是使用L反馈的诊断参考，不是已经训练出的效用网络，也不是可部署的oracle。

每种子720个恢复步（30×2×12）；0持久身份更新，0辅助更新，无U文件，无target loader，无新测试预测。保存全部预登记批次、样本ID、梯度配对、候选和策略效果；不以抽样日志当完整训练分析。模型已见全部源RX，因此探针衡量已知RX间迁移，不能冒充真正未知RX泛化。后续是否值得学习“更新效用”要由这些源证据回答，长期身份训练仍需独立固定40轮验证。

本地检查覆盖正常及异常时精确恢复、V无法影响L选择、RX/day排除及三配置。远端preflight用真实E200、辅助与源IQ验证8候选、2尺度的全部恢复路径。发布后唯一owner使用八卡空余容量，每卡最多3总进程，不影响其他健康任务。

完整结果与解释见 [源域结论](analysis.md)。没有新的身份训练成绩，也未达到84%目标。
