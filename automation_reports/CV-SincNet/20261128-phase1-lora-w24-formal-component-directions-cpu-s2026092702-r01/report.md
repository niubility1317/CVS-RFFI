# LoRa W24 分量方向训练的正式 Full 配对测试

固定两个读出为原跨 chirp 权重和新增分量方向损失权重。两者均使用同一个原生 8,192 点 Practical 父权重和相同四分量范数读出，保留父版原生边缘。只使用当前实收 IQ，冻结星地增强 W24 E104、原默认头、前端和类别顺序。复用匹配物理行的直通、旧 DURA 半量、旧复响应半量及原长训 W24 全量调用读出。 [恢复器训练](../20261128-phase1-lora-w24-component-directions-s2026112991-r01/report.md)

覆盖同一 30,000 个物理包、15 台未见接收机、clean 及六个已登记 Full practical。N607 CPU 控制器等待新增训练的固定 48,000 步末版权重。真实 checkpoint 无目标冒烟通过后，三个独占 10,000 包分片顺序预测。源域诊断分数只供解释。全部预测封存后由独立本地评分器读取真值，报告逐景、同包净纠错、逐接收机和 TX，另记 CPU 直通与历史 GPU 归档判决差异。
