# WiSig 冻结恢复输出的幅相交叉对照

复用已完成的 360 个源域物理包和两条路线七景的冻结波形。固定同一 Main split Tri-SIG-TIME 识别器，种子 `2026092701`。两组交叉对照分别交换原 R69 与居中 FIR 末步的逐点幅度、相位，以及居中 FIR 第一次与第二次 MAP 的逐点幅度、相位。使用共同的 256 点输出坐标，按 ( |a[t]| b[t]/|b[t]| ) 组合。相位提供样点为零时用幅度提供方的原样点。权重、公式和排列对两路线及 clean 固定。两模型在父对照中已做完整无门控恢复。交叉读出用于源域归因，冻结原模型输出为诊断材料。

原 1,800 包隔离对照给出时延基线。配对时移单独使用时，两路线六景相对直通分别少判对 105 和 103 次。边缘采用同一 R69 补全时，只使用重叠区 R69 的相位，相比只使用其幅度，六景多判对 393 和 401 次。该历史对照使用同包干净参照确定重叠区。本轮幅相组合全部从两种实际恢复 IQ 获取。 [实际恢复波形与时间坐标](../20261125-diagnostic-wisig-waveform-source-s2026112501-r01/report.md)

N607 普通账号，在原居中 FIR 发布工作目录使用一张有余量的 GPU。入口为 `python -m experiments.pamf_unrolled_restore.wisig_stage_polar publish --repo . --context <源域上下文> --ssh-config <直连配置> --output <发布目录>`，独立输出根 `runs/20261125-diagnostic-wisig-stage-polar-source-s2026112501-r01`。先用四个合法源 U 包和真实权重检查两种恢复及幅相合成。两路 14 个视图逐包复现四项归档辨识类别。全部预测固定后，独立 CPU 进程读取源 V 标签，报告逐景及逐接收机计数、净变化和 95% 同包区间。目标读取、源训练及校准均为零。来源、物理 ID、归档预测、数值或覆盖不一致时停止下游，保留产物。 [登记](experiment.json)

## 双路线源域评分

**VERIFIED**。实际权重检查、14 个视图四种原读出的逐包类别复现、双路线覆盖与独立评分均通过。每路线六景分母 2,160，低强度城区和 clean 各 360 包。

以居中 FIR 末步为基准，只换 R69 相位的六景增量为 Full +316（95% 区间 [257，377]）、Residual +317（[257，378]）。只换 R69 幅度的增量为 +178（[124，234]）和 +184（[129，242]）。换相位比换幅度分别多判对 138（[69，205]）和 133（[64，200]）次。换相位后，两路低强度城区均提升 65 个正确包。完整 R69 的幅度和相位组仍比相位交叉组多 134 和 136 次正确。幅相交换依赖两种已冻结模型的输出，仅用于量化差异。

居中 FIR 内部首阶段到末步六景净增 100 和 98。保留第一次 MAP 相位并换成末步幅度，就有 +57（[21，93]）和 +56（约 [21，91]）。只使用末步相位的两路增量均为 +27，区间跨 0。R69 与 FIR 的差距较多体现在相位，现有 FIR 第二次 MAP 的独立幅度收益更明确。此结果支持后续用合法源 IQ 检查相位保真的直接收益，同时保留第二阶段幅度恢复。完整的逐景、逐接收机和配对区间见 `source-scores.json`。
