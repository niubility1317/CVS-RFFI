# Phase1 源域共享 FIR 校正探针

本探针拟合一组所有记录共享的复数直通和共轭 FIR 系数，作用于冻结 DURA 输出。拟合与参数选择使用源域配对 clean IQ；固定系数之后，波形校正本身只需要 DURA 输出。滤波器采用中心窗口，需要完整窗口或前视。

固定抽取 1024 条 Phase1 源训练物理记录，与前两个源域探针的记录均不重叠。按物理记录分为 614 条拟合、205 条选择、205 条留出，两个视图复用分组。比较 1、3、5、9、17 tap，三个 ridge 参数及保留原输出，选择组按波形 NMSE 选出 17 tap、ridge 0.000001；输出校正限制为 DURA 波形 L2 范数的 20%。

| 留出视图 | DURA → 共享滤波 IQ NMSE | DURA → 共享滤波的 clean 教师一致数 | 修正 / 损伤 |
| --- | ---: | ---: | ---: |
| 1 | 0.024602 → 0.024568 | 197/205 → 197/205 | 0 / 0 |
| 20 | 0.020511 → 0.020488 | 199/205 → 198/205 | 0 / 1 |

共享滤波在这批源域留出记录上略微降低波形误差，但未增加教师一致数。指标改善幅度很小，不能据此判断统计显著性或测试表现；clean 教师一致性不是 TX 准确率。留出记录只对本探针留出，仍属于项目源训练集；两个视图共享物理记录。

已保存[固定系数及完整结果](result.json)。独立程序直接加载固定系数、重算留出源信号并复核上述计数和 NMSE，没有重新拟合；未读取 TX 标签、V 或测试 IQ。诊断与复核脚本分别为 [probe.py](probe.py) 和 [verify.py](verify.py)。
