# LoRa 实收相位与等量隔离参考

[预登记矩阵](experiment.json) · [运行事件](events.jsonl) · [父实验冻结评分](../20261124-phase1-lora-received-update-source-m4-r01/report.md)

上轮双方向恢复在低城区的相位剂量中位数为零，Full 和 Residual 六景均低于匹配 DURA。本轮核对去掉相位置信裕量能释放多少求解方向，实收重复前导能提供多强的相位信息，以及精确相位在同剂量和更大剂量下的用途。复用原源 U 的 40,000 步、9,512 参数双方向模型、冻结门限 0.03304616 和 Tri-set seed 2026092702。零新训练，零新校准。

## 实收读出与隔离参考

- **相位裕量关闭。** 两轮求解仅移除相位坐标的保守置信扣减，保留幅度坐标的扣减与原 10% 物理限幅。读出仍为联合复更新，耦合求解可能改变幅度系数。
- **时域学习相位和实收重复相位。** 时域学习相位取上述波形相对原观测的相角。重复相位分为各含三条和两条实收 chirp 的不交叠同包参考，排除本条，用逐 chirp 相干度加权，取两参考的角一致性确定剂量。两种相位均去除功率加权的常数和线性相位，保留原时间索引与逐点幅度。两种原幅度保持读出最多修改相对原 IQ 的 10% RMS，固定等量读出再缩至每包两者改动量的较小值。未触发父门限时逐点复制。
- **隔离相位参考。** 使用已知逐点加性噪声，在实收去扫坐标去掉非载波噪声后，取其时域相角并保留实收幅度。隔离剂量分别为两实收读出的共同预算、10%、20% 及全量。共同预算完全由两条实收读出确定，隔离支撑不足时最多使用其完整相位。零噪声场景输入逐点保持。隔离参考的量和方向均没有供给实收读出。

所有剂量沿同一包真实 IQ 的相位短弧二分求解。用无标签源 U 实做实际冻结权重与识别器的无查询检查，随后在同一 900 个源 V 物理包上完成两路线七景。要求直通、半量 DURA、原双方向粗和细读出逐包决策一致。两路线的全部候选预测闭合后用独立 CPU 读取标签。同包按接收机分层重抽，保留跨场景相关性。没有目标访问。

LoRa 两遍同步用收到的前导处理时频及采样偏差，面向后续通信解调。当前试验使用已经登记的上扫窗及其余 chirp 作相位支持，仍在原有 IQ 整体坐标回写局部变化。信道鲁棒 LoRa 指纹工作训练其特征与识别器，本试验通过冻结识别器检验相位读出的损益。 [Tapparel 与 Burg 原论文](https://arxiv.org/abs/2502.08485) · [GNU Radio 作者实现](https://github.com/tapparelj/gr-lora_sdr/blob/master/lib/frame_sync_impl.cc) · [Shen 等原论文](https://arxiv.org/abs/2107.02867)
