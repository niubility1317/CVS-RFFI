## 指标与数据口径

固定原 F50 seed2026092701/defaulthead，raw clean 为 84.6761904762%（142256/168000）。本报告复用 default DURA、noVar E20、RXcanonical E20 和 raw 各七景既有输出，合计 28 个评分单元；每单元 168000 个物理样本，同一总体配对。不是 4704000 个独立物理样本，也没有新增 G/F 前向或优化更新。所有旧输出完整性与物理 ID 顺序在评分连接 clean/truth 前核对。

逐包 NMSE = ||恢复IQ−cleanIQ||² / ||cleanIQ||²，再对全部物理样本平均。能量拟合分数定义为 100×(1−平均NMSE)，可以低于 0，不是相关系数、信息恢复比例或逐点正确率。识别保留率定义为 恢复识别准确率 / raw clean 准确率，两者量纲和含义不同。

本项目 clean 是原地面接收 IQ 的固定预处理表示，不是无接收机、无噪声、无多径的理想发射端波形。因而恢复到 clean 也不等于恢复出真实硬件的全部发射机细节。

## “极限”为什么还不能给单一百分比

普通平方误差满足以下分解（X 为 clean，Y 为接收信号，g 为任意恢复器）：

    E||X−g(Y)||²
      = E||X−E[X|Y]||² + E||E[X|Y]−g(Y)||²

理论最小均方误差是条件方差的期望。它取决于真实 clean 分布、条件信道、噪声、窗口上下文和允许的先验信息。我们没有估计出完整真实条件分布，有限若干模型的最好成绩不能证明已接近这个极限；归一化逐包风险的最优估计还需考虑分母权重，不能把上述普通 MSE 公式直接当成本报告 NMSE 数值下界。

有几类明确限制：

1. 深衰落和频谱零陷会使逆滤波放大噪声；接收端只拿到一次 256 点观测，网络需要在“反演”和“根据源分布补全”之间取舍。参考 SNR=30 dB 不是每条接收信号的实际 SNR，也不代表原 clean 本身无噪声。
2. 在未知复信道中，clean 的整体相位与信道相位可能存在歧义。例如 A(x)=aHx+b·conj(Hx)，对任意单位复数 c，令 x'=cx、a'=a/c、b'=b/conj(c)，就能产生同一无噪接收信号。已知导频和信号先验可以减少部分歧义；不能据此计算整个数据集有多少百分比无法恢复。
3. 有限窗口存在具体不可辨识例子：若因果反射算子恰为纯24点延迟，最后24个 clean 点不进入本窗口的接收值。相关信号先验可预测部分内容，但无法从“24/256”推出本数据固定损失 9.375% 的信息。实际多径不等于该纯延迟例子。
4. 确定性后处理不能凭空增加接收观测关于真实 TX 的信息。在满足 TX→clean→received→restored 的条件模型下，信息只会保留或减少；但同一固定 F 的识别率可以提高，因为 F 并非最优判决器，而且输入表达更适合其已学特征。

本次还计算了使用逐条 clean 的理想对齐参照，仅在评分端使用：default low urban 仅校正整体相位后 NMSE 从 6.9580% 降到 6.3013%，消除 9.44% 的剩余误差；同时允许复增益/相位后降到 6.1763%，消除 11.24%。也就是说，即使白送正确整体幅相，约 88.76% 的原剩余误差仍在。它只能说明“整体幅相不是全部问题”，不是可部署方案、任意新恢复器的误差下界或识别率上界。raw clean 的原始误差为0，对其定义“移除误差比例”没有意义；原计算JSON中的浮点除法近零值不作科学解释。

因此，现在可以准确回答的是“已经达到几成”；真实极限仍是未知，不能声称上限恰为 93%、95% 或99%。已知真实信道的估计器也只能是额外信息下的理想参照，不能随意称为所有算法的上界。

## 恢复之外，突出发射机特征是否有依据

有依据开展独立试验，但尚无目标域稳定提升的证据。下表比较两个既有同一源数据单阶段 E20，展示 NMSE 与识别不完全同步：

| 场景 | noVar→RXcanonical NMSE | noVar→RXcanonical 识别率 | 识别变化（百分点） |
|---|---:|---:|---:|
| clean | 0.0318% → 0.0995% | 84.7423% → 84.8667% | +0.1244 |
| 高档郊区 | 1.7771% → 1.7935% | 80.9042% → 81.5970% | +0.6929 |
| 中档郊区 | 2.3117% → 2.3195% | 79.4065% → 80.2268% | +0.8202 |
| 低档郊区 | 2.9179% → 2.9055% | 77.8690% → 78.7982% | +0.9292 |
| 高档 urban | 2.3191% → 2.3253% | 79.9988% → 80.6042% | +0.6054 |
| 中档 urban | 4.8051% → 4.8234% | 74.3929% → 74.4821% | +0.0893 |
| 低档 urban | 7.0916% → 7.1262% | 68.4708% → 68.4179% | -0.0530 |

其中多个场景的 NMSE 略变差而真实识别提高，clean 的 NMSE 也变大而识别提高。参考和损失权重同时改变，不能把收益单独归因 RX 特征操作；low urban 反而略降，六景仍全部低于默认 DURA。此前 cos 特征、原头投影和后验约束也未稳定改善正式星地结果，不能靠 F 置信度或源域改善宣布成功。

这个现象符合“波形失真”和“识别用途”需要分开衡量的研究背景。[Liu 等，NeurIPS 2019](https://arxiv.org/abs/1904.08816)讨论了固定分类器下的信号恢复、失真与分类之间的关系；该论文不是本项目 IQ 恢复极限的证明。
