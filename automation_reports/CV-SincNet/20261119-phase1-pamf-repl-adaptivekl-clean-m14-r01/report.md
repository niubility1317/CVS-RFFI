# Tri 对称 KL 样本自适应加权

**VERIFIED / ANALYZED**。N607 真实 E20 冒烟 14/14 通过，已核对各 worker 的 PID、CWD、命令、GPU 0–6 均衡分配及日志增长。56 个任务全部完成，含 14 条训练、14 条预测、14 条 clean 独立评分和 14 条冻结后 U 诊断。发布提交 `7e92f6e2943a4536a527620ff59cb3d42042dc60`。见 [实验结果与完整诊断](analysis.md)。

主指标是固定 E50 后 `cross_rx + cross_both` 合并 clean 准确率。十类与六源各新增 7 个候选，逐物理样本与各自最强固定配置、普通 PL、原 Tri 比较。最强固定配置在同种子上的结果分别为 84.0507% 和 86.4486%。普通 PL 分别为 84.1994% 和 86.4285%。本轮选定种子已有目标成绩，因此用于探索。完整配置和执行路径见 [实验登记](experiment.json)。

十类固定 ordinary 对称 KL、浅层跨 RX 对比因子 2、融合 0。六源固定 raw 对称 KL、浅层 0、融合 0.10。两者固定 U 权重 0.75、KL 因子 1.5、KL 视图系数 0.8、伪标签 CE 0 和无梯度投影。复用同设置、同种子和同 source 数据契约的 Tri 源域 E20。E21 至 E50 含 6660 次更新。E50 是唯一测试 checkpoint。

投票是四个原有训练视图对原始 eval 伪类别的一致比例。分布差异是四个训练视图相对原始 eval 概率分布的平均总变差。RX 加权用已接受样本的源接收机批内频数倒数。这些量均脱离梯度。只在原 0.95 接受集合内去均值，并按最大绝对偏差缩放。权重为 `1 + 0.75 × 强度 × 缩放后的分数`。接受样本均值为 1，权重在 0.25 至 1.75，拒绝样本权重为 0。KL 继续按完整 U 批大小归一。权重预算恒定之后，实际 KL 损失和梯度仍可随样本权重改变。

| 变量 | 每个设置的强度 |
|---|---|
| 加权给投票一致的样本 | 0.5、1.0 |
| 加权给投票分歧的样本 | 0.5、1.0 |
| 加权给分布差异小或大的样本 | 各 0.5 |
| 加权给接受样本较少的源 RX | 0.5 |

执行入口为 `python -m experiments.pamf_repl_adaptive_kl.publish`，用已有 N607 普通账号、项目环境和独立 release CWD。代码身份取包含本登记及候选实现的发布提交。GPU 只用 0–6，计算进程上限为每卡两个，计入现有其他 owner。预留 12 GiB 用于放行初始化。每行先执行真实 E20 无查询冒烟，训练结束后自动 clean 预测，再独立读真值评分。独立 U 正确率诊断在模型冻结后执行，保持训练和选模时 U 真值不可用。clean 含 `cross_date`、`cross_rx`、`cross_both`。

运行保存逐步监督 CE、源验证、伪标签接受率、权重范围与分配幅度、各参数组的 L/U 梯度和每 100 步的 AdamW 对照。独立评分同时给出跨 RX 净纠错、各 clean 子集和 U 正确率。阻断性任务一旦技术失败即停止新派发，保留活动任务及现有产物。
