# 固定恢复器预测噪声的源域排序诊断

2026-11-08。仅诊断原始 L_s/U_s 训练源域中固定抽取的 512 条记录（各 256 条），每条复用三次原始信道模拟，共 1536 个视图；固定 CovarianceDetail 源域 E30 恢复器及此前保存的同一 Tri-SIG-TIME SSL F0 连续特征，不更新模型、不读取 TX 标签、分类 logits、V、OE 或目标数据。真实模型和源样本 smoke 通过，新增 F0 前向次数为 0。

按每视图接收实数 IQ 平均功率分别归一化恢复器估计噪声方差和模拟记录噪声方差；与既有恢复 F0 特征相对 clean 特征的标准化平方误差比较。模拟噪声与 clean 特征误差仅为诊断参照，部署时不可直接获得。

| 源视图排序关系 | Spearman 相关系数 |
| --- | ---: |
| 预测噪声代理与模拟噪声代理 | 0.9850 |
| 预测噪声代理与 F0 特征误差 | 0.7794 |
| 模拟噪声代理与 F0 特征误差 | 0.7818 |

按预测噪声代理从低到高分四等组，每组 384 个视图，对应平均特征误差分别为 0.004668、0.016426、0.019254 和 0.161930。第一组含 220 个 clean 视图，第四组含 167 个低城区视图，场景构成差异明显。对预测代理不全相等的 511 条记录，484 条的预测最大噪声视图也是模拟代理最大视图；487 条的预测最大视图特征误差高于同记录的预测最小视图。

事后按场景计算预测代理与特征误差的 Spearman 系数：clean −0.053（220 视图）、high suburban 0.192（219）、mid suburban 0.417（226）、low suburban 0.414（206）、high urban 0.405（204）、mid urban 0.707（209）、low urban 0.711（252）。这些是源训练样本的描述性关联，并未控制信道、信号功率或其他因素，也不代表预测可信度的校准。两种噪声代理共享接收功率分母，会影响它们之间的相关性。

独立 SciPy 复算三项全体相关系数，最大绝对差 1.11×10⁻¹⁶；另用数组索引独立复算同记录比较。固定源样本非总体随机样本，三视图属于重复观测，模型也见过该训练域，不能将数值直接外推到未知接收机或目标集。

该结果支持在未来独立候选中研究使用**模型自身估计**调节先验、更新幅度或特征保护，并在源端检验 clean 身份保持和不同场景；它不证明这些改法会提高识别率，也不允许把模拟真噪声或目标真值用于部署或训练选模。最终以冻结候选后的同一 F0、两总体七景和独立 truth-last 为准。
