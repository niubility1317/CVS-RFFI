# LoRa DURA 分频近载频相位校准

整包注意力在 full 和 residual 相对新增自注意力分别少／多答对 4 条，缺少有意义的共同六景增益。上一轮在独立 150 包低城区相位核查中，估计相位使 residual 的 1–8 kHz 误差中位数由 0.514 降至 0.324 rad。9–32 kHz 直接使用载波对齐坐标的误差为 0.139 rad，共用宽近载频相位为 0.356 rad。Full 同一频带的两个误差为 0.051 和 0.123 rad。独立训练与已知方向的差距仍大。来源见相邻整包实验报告。

## 配方

保持一次注册接收的六个 chirp、各自的载波频偏跟踪、成熟半量和匹配 full/residual 的冻结宽带底座。新模块按 1–8 和 9–32 kHz 分别学习供体到参考 chirp 的相对旋转和相干可信度。证据来自原观测、当前恢复的各带与共用近频带、两 chirp 的质量以及距离。估计允许在观测相位和已对齐载波之间插值。初始 1–8 kHz 较信任观测相位，9–32 kHz 较信任已对齐载波。对角恒等，互换两 chirp 后相位取共轭。每个带只使用自己的旋转及可信度，保留本 chirp 的局部恢复路径。最终保持每条 chirp 的各带修正范数和带外复频谱，初始输出逐值等于冻结宽带。

两臂结构、初始化、主波形目标、固定门、样本与优化日程相同。相位监督臂附加 0.08 倍的相干加权复相位误差与置信度误差。参考来自同一次源接收减去已知新增噪声的波形，处于当前输入的跟踪坐标。该波形只用于拟合目标，推理仅有一次接收。两臂的一致性损失权重均为 0，只记录诊断。每源 RX 900 个合法 U 物理包用于训练，80 个独立 U 包用于留出。每步 8 对同包独立噪声观测，固定种子 2026112817、1,900 步、AdamW 1.5e-4 余弦至 2e-5。每 50 步记录波形误差、配对一致性和分频相位误差。G 训练仅用源 U IQ 与匹配冻结恢复权重。F、真实 TX、V 与目标读取均为 0。

## 固定七景读出与发布

预先固定相同 900 个源 V 物理包，每台 RX 180 个，排除分带对照、近载频和最近整包注意力面板。沿用冻结 Tri-set 2026092702。八种读出为直通、成熟半量、冻结宽带、无相位监督、相位监督、相位监督半步、诊断性等幅已知近载频和精确扣噪。两条路线分别固定七景预测后独立连接源 V 真值。核对 clean、六景、低城区、逐 RX 和同包纠错。相位损失和识别结果分别判断。只有保护 clean 且六景、低城区相对同路线成熟恢复均有可靠改善，才考虑相同协议的未见接收机评测。正式目标保持 15 台未见 RX、30,000 包、三种子六景至少 67.0%、低城区至少 43.0%、clean 至少 64,490/90,000。

运行 `20261123-phase1-lora-dura-band-phase-source-m2-r01`。入口 `python -m experiments.pamf_lora_main.band_phase_source publish`。N607 普通账户，既有 LoRa Python，发布目录为 CWD，新的不可覆盖发布与输出目录。GPU 优先 3、6、2、0、4、1、5，两路分卡，每卡总计算进程少于 4 时启动；GPU 7 排除。实际源检查先验证观测重放、源合同和有限梯度。合同错配、重放失败、非有限结果或评分闭合错误时停止该 run 的后续派发，保留现有产物。预期双真实检查、双冻结权重、完整训练及留出统计、七景预测和独立评分。
