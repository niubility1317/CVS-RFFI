# LoRa 源域 clean 前导响应保护与粗恢复保留

## 预登记

上一轮跨组估计相较恒等粗恢复在 full 与 residual 分别多判对 47 次和 119 次。仅工程均衡在轻扰动层相较直通分别少判对 21 次和 55 次。留出接收机源 U 诊断中，用其他接收机估计的统计收缩将 clean 改动 RMS 第 90 百分位从 0.03214 降至 0.00755。本轮在冻结识别中检验这一方向。 [上一轮结果](../20261124-phase1-lora-crossfit-pilot-response-source-m4-r01/report.md)

沿用奇偶组交叉估计和包内噪声代理。频响先按占用频带内的复数均值归一化。每台源接收机从合法拟合 U 的 1,000 个包中取首 100 个 clean 包，共 500 包，估计实部与虚部拼接后的均值与协方差。当前包相对响应减去 clean 均值，按特征值 λ 乘 τ/(τ+λ)，τ 为最大特征值的 4%，下限 10⁻⁶。零支持对应单位作用，复响应绝对改动最多 0.45。增加 1,050,624 B 冻结统计，无新增可训练参数。两条路线使用同一份权重、统计量及推理规则。

两臂均联合优化粗恢复、当前包观测约束和细化。一臂再约束细化中的工程改动方向。每包用已校准工程逆解减实收观测确定方向，仅粗恢复具有同向分量时补回细化留下的缺口。参考幅度上限和一次补回幅度上限均为工程改动范数。正交方向由细化器自由处理。载波保留在同一去扫时间坐标。已有 LoRa LS/MMSE 用前导估计链路并均衡解调，OFDM SVD 利用信道的频率相关性。本轮从实收 clean 源波形统计天然响应的变异，对该数据中变异大的方向降低补偿，以匹配冻结识别作为效果判断。若真实传播作用和原有响应共享同一方向，收缩也会保留其中一部分。 [LoRa 前导均衡原文](https://doi.org/10.36227/techrxiv.16760101.v1) · [频率相关性原文](https://lup.lub.lu.se/search/publication/1056136)

两新臂随机初始化，各 254,735 可训练参数、3,600 步、batch 12、三视图及原复谱保真目标。通用短复回波和有色扰动与 practical 独立。只用 5,000 个源 U 拟合包（其中 500 个额外计算响应统计）、2,500 个门限包及 500 个留出波形。校准时间单列。旧跨组权重具有完全一致的源 U 合同、随机种子、扰动及训练预算，仅作冻结对照。两臂训练和冻结均不读取识别器、V、TX、真实传播参数、实际噪声和目标。

同一冻结 Tri-set 2026092702 在同一批 900 个源 V 包上跑 full 和 residual 七景。13 个读出为直通、匹配半量 DURA、校准前后工程均衡及三个联合模型的粗恢复、完整细化和半量细化。两条路线七景预测固定后，独立 CPU 才读取源真值。报告逐景、逐接收机、同包净变化、95% 区间及 B1。预定同一联合读出在两个路线的六景均值均超过匹配 DURA 且保持 clean 才可晋级。运行、配置、路径及技术停止规则见 [实验登记](experiment.json)。

## 通用传播响应与源 clean 响应的重叠

从拟合源 U 的同一 500 包重建冻结统计，在 500 个保留源 U 上做隔离诊断。499 个包具备正留组支持。占用带内，收缩后 clean 相对响应残差留存的能量比 P10／中位数／P90 为 0.95%／4.21%／17.70%。在同一批波形上，以另一个固定种子独立抽取通用短卷积，只分析已知注入的归一化频响。相同收缩对这些传播相对响应保留 34.46%／63.36%／91.60% 的占用带能量。单抽头注入中，±1 采样点的纯虚抽头仅保留 9.28% 和 20.24% 的占用带能量。全频带收缩是能量不增算子，个别实验的带内比值可超过 1，因为投影混合带内外分量。

结果量化了源 clean 保护和真实传播补偿之间的重叠。当前校准会压低一部分已知注入响应，尤其是近邻复抽头。这个诊断只用通用合成作用，零识别器、源 V、TX 标签或目标读取，未改动已运行配方。 [响应重叠计量](source-u-response-overlap.json) · [复现脚本](source_u_response_overlap.py)

## 隔离检查：显式保留未知回波的不确定性

将五台源接收机轮流留出。每折用其他四台各 100 个合法源 U clean 包估计当前载波坐标下的包内公共复谱分布。用当前 chirp 相干度和外频带噪声代理形成观测均值及噪声方差。对比加权平均、单高斯后验、以源包为局部中心的等权高斯混合，以及将当前观测中 ±1 至 ±4 个采样点的短回波边缘化的后验。最后一个读出按无回波与有回波两种边缘似然进行后验平均。短回波列由当前包的载波振幅和导频模板计算。固定标准差 0.06/(1+|lag|)，不使用注入抽头或功率拟合先验。测试的 500 个源 U 包只用于计量。指标为恢复公共复谱的误差能量除以配对参考能量。

| 留出源 U 条件和频带 | 单高斯 | 源包高斯混合 | 固定边缘化回波 | 两模型后验平均 |
| --- | ---: | ---: | ---: | ---: |
| clean，1–8 kHz | 0.0018 | 0.0026 | 0.1549 | 0.0526 |
| 轻噪声加回波，1–8 kHz | 1.6014 | 1.4553 | 0.7419 | 0.7262 |
| 宽噪声加回波，1–8 kHz | 1.3533 | 1.3110 | 0.7810 | 0.7609 |
| 宽噪声加回波，9–32 kHz | 0.3819 | 0.3891 | 0.2127 | 0.2138 |
| 仅宽噪声，1–8 kHz | 0.1655 | 0.1634 | 0.3795 | 0.2332 |

相较单高斯估计，边缘化明显降低回波条件的近载波误差。两模型平均在同条件下进一步将真实信号方向增益中位数由 0.476 提高至 0.550，仍低于单位增益。约高分位的 clean 包也可产生很高的回波后验，clean 的回波后验 P90 为 0.942，单凭这一似然仍会误判一部分天然响应。该结果支持将未知回波带入观测模型，同时分别约束有回波和无回波输入下的真实信号传递。当前训练模型没有使用这项检查，未读取识别器、源 V、TX 标签或目标，未获得额外识别证据。 [隔离检查计量](source-u-echo-marginal.json) · [复现脚本](source_u_echo_marginal.py)
