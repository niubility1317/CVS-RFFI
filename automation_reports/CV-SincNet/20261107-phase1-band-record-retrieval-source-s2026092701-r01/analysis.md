# 频段平衡的源域同记录检索

从固定合法源数据按源物理 ID 索引模 8 选出 4096 条记录，各有三个模拟视图；参考库是这些记录各自的 clean IQ。比较普通 IQ 余弦表示和四频段归一化余弦表示，以同一源记录的 received 或 DURA 输出作为查询。分频使用与频段平衡候选相同的四个区间及每段能量下限；噪声四分位只由其余源 ID 的可观测噪声比确定。本诊断不训练模型，不读 F、TX 标签、V 或目标。

DURA 查询的频段归一 top-1 比普通表示低 103 条，约低 0.8383 个百分点；最高噪声组分别为 1323/3095 和 1353/3095。排名采用严格大于正例得分的乐观平局处理；DURA 普通及频段归一分别有 7、5 条出现平局。完整分组指标在独立结果文件中。

同记录检索可以利用报文内容、接收机或其他非身份线索；clean IQ 参考库在部署时不可用。DURA 可能见过这些源记录，因此这不是严格的 DURA 未见源检验，也不是发射机身份准确率。此项只是表征代理，不直接等同正在排队的频段平衡训练损失；已登记新版仍按计划完成七景正式测试。源上下文和 GPU 检查通过，统计耗时约 2.2 秒，缓存构建与读取另计。
