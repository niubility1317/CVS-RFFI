# LoRa 接收坐标误差与私有谱泄漏

## 预登记

此前将私有谱分开交换幅值和方向，仍未取得双路识别收益。这轮固定物理包与波形输入，分解当前实收跟踪的横向相位斜率、中心相位和逐 chirp 归一化误差。目标是量化它们会把多少公共结构漏进私有谱，并检验接收端可直接计算的抑制方法。 [上一轮幅相消融](../20261124-phase1-lora-private-polar-source-m2-r01/report.md)

基准是对隔离去掉新增噪声后的同一接收波形运行原跟踪器。它保留本路线的接收信道与波形失真，仍受跟踪器自身模型限制，作为此次误差分解的参考坐标。以当前实收和参考坐标的逐 chirp 比值构造三个乘法因子。在样本 128 处分出中心常相位，其余旋转为相对斜率因子，RMS 因子为参考 RMS 除以实收 RMS。把三种误差单独或联合施加于同一参考波形，形成八个固定读出。去扫坐标下，私有量由逐 chirp 减去包内均值得到。不同 chirp 的坐标乘子可能把公共量漏进私有谱，也会改变原私有量。记录这两项及交叉项，全部按参考坐标的逐 chirp RMS² 加权。

四条实收变体均先从相同实收 IQ 独立计算。局部斜率在原跟踪找出的频点周围，用二次窗和 ±0.8 rad 的半 chirp 相位斜率网格细化。奇偶采样组的斜率差平方给出不确定性代理，用它决定是否向包内斜率中位数收缩。去偏 RMS 用外带方差代理扣除噪声功率，保留至少 20% 原实收方差。固定变体为局部斜率、包内收缩斜率、仅 RMS 去偏、包内收缩与 RMS 去偏联合。载波估计不分辨 CFO 和采样时偏的物理来源。公开 LoRa 同步用完整前导估计多种偏移，本轮只使用已登记的六段窗，检验偏移估计误差如何进入用于恢复的私有复谱。 [LoRa 开源物理层原论文](https://arxiv.org/abs/2002.08208) · [两遍精同步原论文](https://arxiv.org/abs/2502.08485)

固定五个源 RX 各 30 个留出 U 包。测试 clean、独立通用有色噪声、Full 与 Residual 的低郊区和低城区。候选坐标估计只读输入抓取 IQ。源参考、实际噪声、场景只用于输出后的诊断。无 F、V、TX、目标或训练更新。比较各频带的坐标误差、公共泄漏和额外噪声以及逐 RX 指标。若同一个实收变体在两路低城区的 1–8 和 9–32 kHz 均将坐标误差降低至少 20%，且源 U clean 对应频带的相对误差均不超过 0.05，才用该前端组织匹配的源域训练对照。诊断不能替代冻结识别。N607 CPU-only，先在真实 U 数据通过无目标 smoke，再执行回放。数据契约、纯数值分解或回放失败时停止。4 项聚焦测试和独立 P0/P1 审查通过。

## 下一步可验证的前端改动

低城区 1–8 kHz 中，原跟踪坐标误差分别为参考私有能量的 2.46 倍和 2.65 倍。公共成分泄漏分别为 2.44 倍和 2.47 倍，远大于原私有成分变形的 0.014 倍和 0.141 倍。单因子中斜率影响最大。Full 与 Residual 在这一频带的直接新增噪声仍约为私有能量的 19.5 倍和 20.2 倍。9–32 kHz 的对应噪声比例更高。坐标修正只能解决其中一部分。

包内斜率收缩在低城区 1–8 和 9–32 kHz 内，使 Full 坐标误差分别减少 69.7% 和 68.9%，Residual 分别减少 55.1% 和 47.7%。五个源接收机的四个配对切片均改善，幅度为 39.5% 至 75.3%。相对仅做局部斜率，包内收缩进一步降低 Full 的误差，Residual 基本持平。仅 RMS 去偏使两路这些频带的误差增加约 56% 至 101%。

无条件斜率收缩在 clean 的 1–8 kHz 相对误差为 0.136，超过 0.05 的预登记限值。此前同一留出源面板和跟踪器使用源域冻结旁路，150 个 clean 全部旁路，低城区触发数为 Full 101/150、Residual 150/150。后续单独登记使用旧门限的包内斜率收缩与匹配对照，在拟合和推理时按同一实收估计生成坐标，逐包 clean 从原始 IQ 直通，最后用冻结识别器核对两路收益。 [冻结门限与覆盖记录](../20261124-phase1-lora-private-band-risk-source-cpu-r02/source-u-private-risk.json)
