结构上，R13 同时收窄 coarse 的时域/谱域网络、action estimator 和三个 prior；GN 四组内直接取前部通道，没有用源 IQ 校准函数。保留通道索引与 decoder 拼接偏移正确，不代表函数等价：GN 每组统计集合变了，输出卷积失去其余通道贡献。coarse/action 又决定后续全部阶段的初值和物理求解参数，误差可以逐阶段传播。这是可检验的机制推断；本轮没有单独冻结/互换组件，不能把下降唯一归因于某个模块或 GN。

clean 目标准确率接近原版，而扰动场景损伤较大，只能作为已冻结结果的现象描述，不能据此选场景调参。加入 F 知识没有形成稳定补救：原宽度 task 也下降，全部 task 行全程触发梯度裁剪；其损失目标和知识权限不同，不构成 F-free 失败的解决方案。F 分数、目标结果和 V 的分类分数都不作为下一恢复器的训练/选模/参数依据。

减参也没有等比例加速：44 万 IQ 版同卡 batch1 中位延迟 51.5474 ms，父模型 44.5279 ms；20 万 IQ 版 43.2092 ms，父模型 43.4602 ms。测量只有16条source V、顺序执行且有共存负载，不能推导普适速度结论。小通道卷积执行效率、启动/访存与固定 FFT/6次CG成本是可能原因，当前没有逐算子计时，不能定论。

下一组固定试验 R14 只用上述源 IQ 损失、裁剪和结构事实提出的假设：保留原 R38 的完整 coarse/action，单独压缩 prior，并保留同冻结上下文的原宽度对照。三行使用相同 IQ 目标、源数据/顺序、优化器和10轮预算；原R38父权重不变。它可检验在不破坏原物理上下文时能否压缩先验，尚不保证成功。每行均完成七场景正式测试；目标评分不回流调参或选择性重跑。完整统计见同目录 failure_analysis.json。
