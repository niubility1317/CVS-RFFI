# Phase1 源域连续波形融合诊断

本诊断检验已固定 DURA 输出和独立物理后验之间的连续 IQ 混合是否在端点均不匹配冻结基座干净伪类别时产生额外匹配。混合系数预先固定为 0、0.25、0.5、0.75、1；不训练模型、不按源结果选择部署参数。物理后验继承冻结 F 伪类别先验，标为 F-guided；两路输入的计算均为单样本推理。源记录及其他视图已探索，非盲测。

从既有固定 672 条源 pilot 中按记录顺序选 RX4/6 和 RX8 各七景每格 32 条，共 448 条；不以标签或性能筛选。固定所有五种混合的预测后，以冻结 Tri-SIG-TIME SSL 在配对干净源 IQ 上的置信度 ≥0.95 的输出作为伪目标，逐组报告每个系数的匹配数、两端点理想并集、全部系数理想并集、仅内部系数命中的数量和配对对齐 IQ 误差。伪标签不是真实设备身份；事后理想并集不可用于部署，不是地面准确率。任何已观察源结果均不改变本次系数或记录选择。

先运行 28 条真实源预检，再固定 448 条源预测，最后读取源干净波形的 F 伪目标评分；不读取 TX 身份、U_s 身份真值、V 或地面测试，不更新模型。CPU 两线程，负载超过 72 等待；输出独立不可覆盖。运行编号 `20261102-phase1-continuous-fusion-source-s2026092701-r01`，低分不停止。该固定插值是机制诊断而非新训练网络，也不能替代新的恢复网络七景正式测试。
