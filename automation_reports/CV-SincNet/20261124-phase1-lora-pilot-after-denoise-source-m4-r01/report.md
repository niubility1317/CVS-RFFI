# LoRa 去噪前导的交叉校正

## 预登记

在相同源包上，已知作用反演在保留原始噪声时收益有限，扣噪后收益增大。历史方案从有噪前导直接拟合两组响应，强扰动时经常得不到另一组支持。本轮检验只降噪、保留原接收作用的粗输出，是否能为后级估计提供更多可靠证据。 [噪声与作用归因](../20261124-phase1-lora-common-failure-physics-source-m2-r01/report.md) · [原始跨组方案](../20261124-phase1-lora-crossfit-pilot-response-source-m4-r01/report.md)

两臂结构、参数、种子、预算、损失和样本相同。由合法源 U IQ 生成同一通用扰动下的两份独立有噪观测，让粗恢复预测另一份有噪观测中的去载波成分。滤波、时延、相位、镜像和加性扰动均来自通用训练生成器。使用同噪弱信号变化约束半量输出的幅相保真。后级直接优化原始源 IQ，并将每个分带的全量编辑限制在同包粗编辑的物理范数内。粗恢复、接收动作求解和细化共用一次连续优化。借鉴 Noise2Noise 的配对有噪目标。本轮额外分离接收作用与噪声，并保留合法原始源 IQ 作后级波形目标。 [Noise2Noise 原文](https://proceedings.mlr.press/v80/lehtinen18a.html) · [公开实现](https://github.com/NVlabs/noise2noise)

接收端输入仅为同一实收包的六条 chirp。逐条估计同步坐标、相干度和外带噪声。粗恢复分别处理相间两组三条前导。对照从原始观测拟合八个延迟项，候选从降噪前导拟合。两臂都要求对面未经修改的 IQ 支持响应，使用相同源 U 响应协方差收缩，并把响应偏离恒等的模限制在 0.45。正则逆解都读取去噪后的 IQ、同一估计噪声口径和学习先验。在作用支持为零时退回恒等响应。粗网络和细化网络从一次优化中得到梯度，解析响应估计为确定性步骤。门限沿用同源校准，whole-clean 留出集逐包核对直通。

7 项聚焦测试与一次独立审查通过。审查发现零初始化粗编辑会暂时将细化剂量锁为零，冒烟改为先做一次实际更新，再核对粗阶段与细化阶段的梯度。每臂 3,600 步、batch 12，三种波形读出共用物理包选取。每个源接收机 1,000 个训练、500 个 clean 校准和 100 个留出源 U，AdamW 从 0.0002 余弦降至 0.00002。相同模型及门限覆盖 Full 和 Residual。训练不读取精确噪声、真信道参数、practical 轨迹、TX 标签、识别器或目标。识别器 Tri-set 2026092702 仅在冻结后用于源评测。两路各 900 包七景、共同 11,100 个额外 clean。保留匹配半量 DURA、秩四半量、各自粗恢复、两组联合半量和同权重关闭作用半量。预测闭合后独立 CPU 评分，并记录支持度、逐景/RX 和单包时延。

晋级规则固定为候选在两路六景均超过匹配半量 DURA、原始前导半量及同权重关闭作用半量，低城区均至少持平 DURA，完整 clean 判对数持平直通。本轮仅源域。数值、真实无目标冒烟、数据来源或预测闭合出错时停止后续工作。训练和预测使用不同空闲 GPU 分行，以实时显存为准。命令、环境、路径和产物见 [实验登记](experiment.json)。

冻结后另做 150 个源 U 留出包的低郊区和低城区诊断。用相同实收坐标比较两组粗输出、对照匹配子空间的孤立无新增噪声响应、以及同包原始干净 IQ 的私有谱幅相。诊断的无噪声输入只用于对比冻结输出，响应参照仍受八延迟项与校准限制。见 [隔离诊断脚本](audit_source_u_pilot.py)。

## 判断

去噪前导半量相对原始前导半量，两路分别少判对 6 次和 7 次。相对同权重关闭作用，仅多判对 3 次和 2 次，配对区间跨零。相对匹配半量 DURA，Full 和 Residual 六景净差为 −43 和 −115，低城区为 −9 和 −19。候选的完整 clean 为 8,986/12,000，与直通逐包一致，本轮停在源域。

较重扰动触发后，交叉支持为正的比例从 Full 325/976、Residual 125/794 增至 517/976 和 262/794。低城区留出源 U 上，候选粗恢复相对同作用无新增噪声的归一化平方误差，比原始前导组减少 82.3% 和 95.5%。同一批包的响应 RMSE 在 Full 从 0.00689 增至 0.00734，Residual 约为 0.00518。正支持计数增加未带来响应精度或固定识别的收益。低城区 1–8 kHz 私有谱实增益中位数仍只有 0.573 和 0.546，波形平均误差的改善伴有明显弱谱幅度损失。

本轮使用一个恢复训练种子和一个冻结识别种子的匹配双路源域对照。已知信道作用和噪声只在额外源 U 诊断中用于构建参照，未进入候选、门限或选模。正式目标矩阵尚未执行。 [历史读出逐包复核](frozen-controls-audit.json)
