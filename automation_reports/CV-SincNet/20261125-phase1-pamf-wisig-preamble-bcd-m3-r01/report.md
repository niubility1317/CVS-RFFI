# WiSig Main split 单包前导与跨接收机方差 B/C/D

本实验复用三视图 PAMF 同种子 2026092701 的正式 A 行及其合规 E20。B、C、D 各从同一前缀加训 E21–E30 和 E31–E50，新增 6660 步，累计 11100 步。沿用原联合默认头、L 监督、U 侧原 REPL 及固定时间重排。三行均按固定终点完成正式测试。逐行命令、路径与字段见 [experiment.json](experiment.json)。

- B 在 25 MS/s 的 256 点输入上读取样本 20:180。以 80:160 稳态窗估计公共相位步进。对早、中、晚完整短训练周期分别计算相对复增益、对数能量比和模板残差，按稳态相干度加权，共 12 维。通过现有参考响应投影训练 768 个新增权重，E20 装载时以零初始化。
- C、D 额外使用合法 L_s 的 TX×RX×日期组中心。同 TX 同日的跨 RX 两两差估计 12 维散布，记录组内包间变化对照。C 使用对角方差。D 对散布向对角收缩 0.2，取最大两个特征方向，重标到与 C 相同的总剂量。两行使用同一剂量系数，扰动 L2 范数不超过 0.20。扰动仅应用在训练态的新增描述量，标签生成、源验证及正式预测使用未扰动单包描述量。U_s 的 TX 真值始终隐藏。
- 正式测试是未见 RX 126000 包和未见 RX＋日期 42000 包的同一物理集合，每行含 clean 和六种 practical。每行完整预测及 opaque ID 闭合后独立评分，报告 Accuracy、Macro-F1、逐 RX/TX/日期指标，以及相对 A 的修复、损伤和净纠错。以 B–A、C–B、D–B 和 D–C 解释差异。按用户指定使用完整 Main split，留一源 RX 重训不属于本次矩阵。

已有对照和评测划分曾在历史实验中公开。单种子差异用于本次匹配比较。需要独立划分和多种子确认后再作更广泛结论。

## 发布前核对

数学与接口测试覆盖同一包的顺序、共同相位斜率、零信号、合法分组、C/D 等剂量、旧权重迁移、训练扰动和推理确定性。一次独立 P0/P1 审查核实真实本地模型旧权重迁移、新参数梯度与更新、严格冻结重建、预测/评分隔离及提交路径。发布时执行一次真实 N607 E20 无 query smoke，通过后立即派发。
