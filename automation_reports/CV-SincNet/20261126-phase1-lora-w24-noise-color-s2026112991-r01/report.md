# LoRa W24 等能量宽带与有色噪声训练对照

Run `20261126-phase1-lora-w24-noise-color-s2026112991-r01`。 [实验登记](experiment.json) · [运行事件](events.jsonl)

## 实验设计

检验原始采样时钟上的有色噪声训练，能否提高冻结 W24 在 Full 七景中的同包识别。对照用原生宽带复白噪声，候选用随机带宽及中心频偏的平滑有色复噪声。滤波在连续 8,192 点输入上执行，原生中心频移范围为采样率的 −0.07 至 +0.07 倍，半带宽为 0.045 至 0.250 倍。在 W24 八条 384 点中心窗计算噪声总功率，两组都精确匹配同一通用原始扰动的功率。每个训练视图以 35% 概率保留同一通用混合扰动原样，其他视图使用对应独立复噪声。两组共享源包、主随机流、混合扰动比例、损失、优化日程和结构。

两组加载源 U_s 原损失 U-Net 的固定 24,000 步模型张量，重置 AdamW，各续训 12,000 步，同种子 2026112991、batch 16。使用 20,000 个合法源 U 包拟合、500 个留出，统一在第 2,000、6,000、9,000 和 12,000 步使用有色留出构造。恢复器只输入观察端可用 IQ，拟合和冻结期间隔离识别器、标签、源 V、目标和已登记 practical 轨迹。

## 冻结评估与发布

固定两份末步权重后，E104 对 300 源 V 包七景完成半量和全量预测，并逐包核对四条历史基线。独立评分在预测全量固定后连接源标签。候选半量须在六景超过全部固定对照，低城区达到最佳对照且 clean 达到直通。仅在通过时启动覆盖 15 台未见接收机、30,000 包的正式 Full 三分片，再按 truth-last 独立评分。

执行提交 `7b1b946b95f8b786305fc6a09ae156d6be9371cb`。N607 GPU 顺序 2、3、0，启动时核对每卡至少 12 GiB 余量、可见既有训练及本轮每卡至多一个 worker。使用唯一输出根，系统性协议或技术故障才停止其所属任务。模型、源预测、独立评分、运行日志及分组分析均留存。

N607 启动 **VERIFIED**。发布归档比对 VERIFIED，远端编译 PASS。两份真实祖先 checkpoint 的源 U smoke 通过，控制器 1231878 在独占发布目录启动，GPU 2 的对照及 GPU 3 的候选训练日志已增长。十项定向测试和独立 P0/P1 审查通过。
