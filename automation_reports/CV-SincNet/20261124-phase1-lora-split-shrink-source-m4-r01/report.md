# LoRa 包内重复与独有复谱分开恢复

[预登记矩阵](experiment.json) · [实验状态](events.jsonl)

## 结构设计

以两条已登记 practical 路线共同提供的六条 256 点前导 chirp 为输入。沿用接收端前导配准、逐 chirp 去扫频和当前包尺度估计。在固定识别器的原采样坐标回写复数修正，旁路时保留原始 IQ。粗恢复和细化读取同一包，使用同一冻结权重和旁路阈值。

令 (X_j(f)) 为去扫后的复谱，(M(f)=\operatorname{mean}_j X_j(f)) 为六条 chirp 的共同谱，(R_j(f)=X_j(f)-M(f)) 为该条的剩余结构。把奇偶 chirp 合成两个互不重叠的读出，计算相同频点的复交叉功率实部及分组不一致能量。1–32 kHz 的相位一致证据限制对共同复谱的衰减。全频段的共同谱和各 chirp 剩余谱有独立的实值衰减门。粗层估计第一组门，细化根据粗层能量与实收残差能量调整门。输出为 ((1-g_M)M + (1-g_R)R_j)。两个门共享当前包的外带能量尺度，均限制在 0 至 0.70，直流载波门固定为 0。网络输出受实测共同谱和剩余谱约束，保留输入支持的复方向。

| 接收量 | 来源与可用时点 | 误差和失配 |
| --- | --- | --- |
| 原始 IQ、配准置信度 | 同一包的六条接收 chirp，接收完前导可计算 | 固定去扫参考与实际传播可有时偏、相位漂移和码片内失配。置信度是现有接收配准评分。 |
| 重复复谱、独有复谱与复交叉证据 | 六条复谱的均值、离差及奇偶分组的复乘积 | 两组只在独立噪声假设下提供互补证据。共同干扰、残余频偏和调制外接收机失配都会污染估计。 |
| 有效外带噪声功率 | 去扫后 >64 kHz 的复系数模方中位数除以 ln 2，前导结束后可用 | ln 2 按圆对称复高斯模型标定。外带真实弱信号、滤波和有色噪声影响该数，作为当前包扰动强度代理。 |
| 信道作用 | 本轮沿用实收前导坐标变换，频谱恢复仅使用包内统计 | 当前变体没有独立的显式信道逆滤波器。 |

## 匹配训练与对照

每臂 36,004 个参数、40,000 个 AdamW 更新，batch 24。用 20,000 个合法源 U 物理包拟合，另预留互斥的 2,500 包定旁路阈值和 500 包核对收敛。通用扰动包含独立绘制的缓变相位、短回声、有色加性扰动和包内共同扰动。两臂共用源 IQ 复谱损失、同包扰动一致性和真实源 U 弱复谱差异传递损失。两阶段始终在同一个优化循环里训练。沿用初期重粗恢复、后期提高细化损失的连续日程。终步冻结后才载入识别器。拟合与校准隔离 TX、识别器、V、目标、注册信道算子及仿真噪声。

主方法分开衰减重复和剩余复谱。长度匹配的标量组用相同的门候选计算逐包、逐频的总编辑范数，再沿原实收复谱方向衰减。两个拟合臂各自训练。另加同门推理消融，复用分开恢复组一模一样的冻结参数、两阶段门和实际编辑量，只把施加方向改为整谱标量衰减。这个消融固定编辑幅度和增益来源。粗恢复、细化全量和细化半量全部评分。

FullSubNet 在语音去噪中把全带和逐频邻域信息串联，估计干净语音频谱掩码。本方案沿 LoRa 前导的 chirp 维分解共同与独有成分，使观测支持的两个复方向独立衰减，并在冻结识别任务中配对验证。LoRa 波形论文给出了连续相位调制及频谱推导。这里的 1–32 kHz 是去扫坐标中的实验设计，来自已有合法源域频带配对结果。 [FullSubNet 原论文](https://arxiv.org/abs/2010.15508) · [作者实现](https://github.com/Audio-WestlakeU/FullSubNet) · [LoRa 波形原论文](https://arxiv.org/abs/1906.04256)

Shen 等用接收前导相邻谱图列的幅度比减弱慢变信道，再以有标签的深度度量学习识别设备。两种方法均用接收前导的重复性。本轮交付的是原时间坐标的复 IQ，训练监督来自无标签源波形和独立扰动。同门消融检验的是保持复谱编辑量时，分解共同与独有成分能否单独改善同一个冻结设备识别器。 [LoRa 信道鲁棒识别原论文](https://livrepository.liverpool.ac.uk/3148161/1/TIFS2022_LoRa_RFFI.pdf) · [作者实现](https://github.com/gxhen/LoRa_RFFI/tree/main/Openset_RFFI_TIFS)

## 冻结测试

连接同一份 Tri-set seed 2026092702。两路线各评估同一组 900 个源 V 物理包及其 clean 和六景，以直通、成熟半量 DURA、两臂三个读出和同门消融三个读出对照。全部预测固定后独立读取源 V 真值。检查双路线 clean 正确数、全部六景与低强度城区、逐接收机净纠错和物理包配对区间。分开恢复组的同一读出须在两个路线超出匹配成熟 DURA 的六景均值并保持各自 clean，才进入目标验收。

识别评分后，在独立诊断中重放同包。把恢复编辑投影到接收时标下的共同与独有谱，量化两类成分实际衰减的差异。逐频带报告相对源波形和扣除精确加性噪声的同包接收参考的复谱、幅度和相位一致性。用后者的实收坐标估计外带噪声功率偏差。精确加性噪声全程留在诊断侧。 [波形归因代码](../../../tools/lora_local_phase_fidelity.py) · [独立逐包配对代码](../../../tools/lora_geometry_pairing.py)

## 运行与收敛

N607 执行状态 `VERIFIED`。发布提交 `ddbc41e680a4d1ec80069712df180e3192d32008`。发布归档传输与远端编译通过，独立 P0/P1 检查通过。GPU 3 训练标量组 1,080.59 秒，GPU 4 训练分开组 926.50 秒。两组各完成 40,000 步，有 801 条有限值训练记录。峰值 CUDA 分配分别为 425.21 和 423.38 MiB。共同旁路阈值为 0.0372647159。真实冻结权重检查通过。RTX 3090 单臂 B1 路径的 clean 旁路和扰动触发中位时延分别为 3.18 和 8.46 ms，每种输入计时 20 次，包含恢复器和三种恢复强度的原坐标回写。

固定留出终步的标量组与分开组细化复谱误差分别为 1.87871 和 1.90353，弱谱差异传递误差分别为 0.05432 和 0.04161。分开组在该指标保留了更多源包弱差异。两组在 12,000 步以后留出的粗、细复谱误差均基本持平。两条路线分别在 GPU 4 和 5 完成全部预测，独立 CPU 确认两份物理 ID 一致后读取源 V 真值。全程零目标读取。

## 独立复核与波形归因

独立逐包复算与原预测评分的 11 路逐景正确数完全一致。以各接收机内的物理包为单位做 1,600 次配对重抽样。同门全量的净收益 95% 区间为 full +9 至 +45 次、residual +44 至 +97 次。半量相对 DURA 的区间分别为 −78 至 +2 次、−251 至 −129 次。任意场景与接收机的完整纠错、改错、正确数及区间保存在本轮 `scene-rx-paired.json`。

同包原时标复算显示，低强度城区分开组全量的 1–8 kHz 共同谱与独有谱衰减中位数分别为 full 0.272 和 0.496、residual 0.376 和 0.575。65–128 kHz 两类门趋同，分别达到本包外带能量允许的上限 0.496 和 0.575。所有实测场景中，粗与细的分带衰减中位数最大差异为 (6\times10^{-8})。结合 12,000 步之后的留出指标和无识别纠错，说明该训练配方下细化未学出有效的额外调整。
