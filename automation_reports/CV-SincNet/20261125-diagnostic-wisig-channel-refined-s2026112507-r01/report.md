# WiSig 十类信道估计的分数时延与多普勒精修

实验 `20261125-diagnostic-wisig-channel-refined-s2026112507-r01` 已在 N607 完成并由独立进程评分。代码、冻结配置和矩阵见 [experiment.json](experiment.json)，运行状态见 [events.jsonl](events.jsonl)。

## 方法与数据

估计器只读取同一源包的 256 点 clean 和受损 IQ。先用 Adaptive 估计，再扫描分数时延与频偏、逐径加入候选，并联合精修分数时延、公共相位、慢变增益和采样钟偏。估计过程使用反射边界、残差白化、窄带干扰回归和对大残差降权。多个候选按拟合误差和复杂度加权。

只通过 480 对源 U IQ 的时块留出预测选参，复杂度惩罚为 5，精修波形的混合权重为 0.35。十组留出预测残差的平均比值为 0.98488。采样钟偏组下降 6.17%。四折开发集比较也检查了按残差收益、模型差异或估计信噪比分组调权，三种规则的最大组平均残差均高于固定权重。

复核使用 60 个源 V 物理包，与最初的十类面板互斥，其中三个 Practical 条件曾用于历史专项诊断。本轮共 44 个原始条件和 26 个双倍功率条件，每种方法评分 4,200 个条件与包的组合。两种估计完成后，独立 CPU 评分进程才读取模拟器参考。波形 NMSE 在沿用的 80 个采样点计算。

物理包聚类 bootstrap 使用 900 次重采样。原始三径分数时延与采样钟偏组的精修中位数 95% 区间为 0.2083% 至 0.3191%。时变多径为 0.3074% 至 0.4423%。

| Practical / Full 条件 | 作用 NMSE 中位数 | 作用 NMSE P90 | 已知精确形状、仅拟合一个复增益的实测中位数 | 原始实收信噪比中位数 |

| strong Low Urban | 3.9639% → 3.2149% | 18.4183% → 14.0746% | 0.0595% | -0.21 dB |
| default ×2 Low Urban | 2.5460% → 1.6424% | 9.2445% → 6.4991% | 0.0330% | 2.78 dB |
| strong ×2 Low Urban | 6.2040% → 4.8486% | 29.3709% → 25.5347% | 0.1312% | -3.22 dB |

最后一项增益诊断由评分侧使用精确无噪波形作为模板计算。它只量化固定模板下的单包噪声，评估后的信道估计器没有得到模板。在独立白噪声、已知形状、LS 拟合一个复增益的理想模型下，256 点要达到 0.1% 中位 NMSE，平均信噪比需约 4.33 dB。已知四维复子空间、拟合四个系数时约为 11.57 dB。该模型用于观测预算讨论，适用条件为独立白噪声和固定正确的模型形状。

本轮的 0.1% 判定使用逐族中位数。R07 白噪声探针算子误差与 DURA/PAMF 识别率由各自的正式实验计算。新估计器定位为源域有配对参考的诊断。
