# DURA 对源 IQ 受控小扰动的响应

对 672 条已探索 Phase1 源 pilot，每组 48 条，使用固定 DURA 估计的实线性物理作用。以对应源 clean IQ 构造共轭、幅度三次、相位斜率和相邻差分四种方向，各自归一到 clean 复 IQ RMS 的 1%。把估计作用施加到扰动后加至 received，重新估计并执行完整 DURA；比较恢复输出变化与构造的源端扰动。原始 checkpoint 首批重放通过；无 F、TX 标签、V、目标读取或模型更新。

投影增益为恢复变化在原扰动方向上的实内积除以扰动能量；理想同向等幅为 1。相对响应平方误差为 `||恢复变化−扰动||²/||扰动||²`，响应范数比为两者范数之比。这些都是先逐记录计算再取组均值，增益低可能包含方向旋转；范数接近 1 也不保证方向正确。
