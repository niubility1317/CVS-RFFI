# WiSig 冻结恢复的幅相交换

检验上一轮波形恢复的幅度误差是否解释识别退化。复用同一固定 IQ 恢复权重、源 U 门限、冻结 Tri-SIG-TIME SSL 2026092701 和原 R69。两条路线分别包含相同的 1,800 个源 V 物理包与 clean、六种 practical 视图。设备型号判定使用原分类头。训练和校准更新均为零。

## 可部署读出

使用原实收和拟合结果在相同 256 点基带时间坐标的单位化 DFT。除直通、原 R69、全量拟合和原带门拟合外，固定三项拆分。第一项只把拟合结果的包 RMS 匹配到实收值，保留频谱形状。第二项组合实收幅度和拟合相位。第三项交换两者角色。采用实收幅度的读出另加一条逐频点加权的相位修正。权重以两路较小的谱功率为分子，加入实收短训练重复差分的有效噪声功率为分母。拟合谱先匹配包 RMS。频点缺少可靠相位时使用可用输入的原相位。门控版复用父实验同一份源 U 门限，应用于包级硬相位和加权相位两种读出。模型、门限、归一和推理规则共用于两路线。按包配对检验四项组合的准确率交互，作用范围限于本次实收和拟合波形。

经典幅相分解说明信号的不同结构可由幅度或相位主导。本实验固定接收记录和识别器，检验 WiSig 信道损伤下的设备判定，并加入包内可估扰动对相位改动的约束。 [Oppenheim 与 Lim 原论文](https://dsp-group.mit.edu/wp-content/uploads/2024/11/ImportancePhaseSignals_1981.pdf)

## 隔离诊断与执行

另起预测进程，以配对源 clean 参考的相位或幅度分别替换实收对应分量，加上配对 clean 参考端点。隔离诊断存放在单独输出根。对照幅相和分类术语仅适用于这组冻结输入。可部署读出只用当前实收和冻结模型结果。配对源 clean 在可部署预测进程只用于分类后的波形误差诊断，未传入恢复器。两路两类共四个预测矩阵完整并且物理 ID 匹配后，独立 CPU scorer 才读取设备真值。

N607 首步检查真实冻结权重，无目标访问。完成 B1 计时后用两个可用物理 GPU 并行预测两路线，各记录完整七景、阶段进程和输出。报逐景、逐 RX、配对净变化和置信区间，及 3 个频带的幅度误差和复相关。可部署读出同一规则须在双路同时超过原 R69 并保持 clean，且有同包证据支持，才考虑正式扩展。数值、路径、预测闭合或数据契约异常停止派发。配置和冻结产物见实验记录。
