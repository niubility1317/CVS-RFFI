# 扩大修正范围：源域小样本优化检查

独立时频网络扩大修正上限后，用 96 条合法源 IQ 视图做一次小样本优化检查。两模型使用相同初始化权重、相同输入顺序、batch32、AdamW 学习率 0.0003、权重衰减 0.001 和梯度裁剪；每版各训练 64 步。训练未读取 DURA、F、TX 标签、V 或目标。表中的 NMSE 在同一批 96 条训练视图上计算，属于样本内检查；这些视图不能视为 96 个独立发射机或独立测试。

| 更新步数 | 原 2 倍上限：源样本 NMSE | 新 8 倍上限：源样本 NMSE |
|---:|---:|---:|
| 0 | 1.852384 | 1.852384 |
| 1 | 1.851162 | 1.847831 |
| 8 | 1.710108 | 1.564499 |
| 16 | 1.435734 | 1.003608 |
| 32 | 0.987990 | 0.588145 |
| 64 | 0.494271 | 0.206163 |

在这次小样本、固定顺序和 64 步优化中，新版本的样本内 NMSE 下降更快；扩大上限也使初始化时输出头的梯度尺度改变，因此这不是对输出范围单独因果贡献的完全隔离。样本内下降不等于跨接收机泛化或身份识别提升。正式实验使用独立的完整源训练与预登记七景预测，仍须等待全部预测固定后独立 truth-last 评分。

## 完整源训练前 3 轮（进行中）

N607 正式训练中，两版均使用 32768 条源 ID × 3 个固定视图、batch32 和同一源 IQ 目标。每轮数字是在模型持续更新过程中累计的平均训练目标。

| 训练轮次 | 原 2 倍上限 | 新 8 倍上限 |
|---:|---:|---:|
| 1 | 0.269212 | 0.145950 |
| 2 | 0.198967 | 0.075125 |
| 3 | 0.190374 | 0.066964 |

新版第 3 轮训练目标比原版同轮低约 64.8%。输出头初始梯度尺度不同，优化轨迹不相同。该结果是单次训练期损失而非固定权重的独立评估，更不是 TX 识别准确率；不能据此选择 checkpoint 或宣称目标达成。新版仍按预登记训练至第 20 轮，冻结后完整七景预测及独立 truth-last。
