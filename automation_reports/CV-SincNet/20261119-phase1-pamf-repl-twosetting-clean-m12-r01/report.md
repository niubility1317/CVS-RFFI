# Tri 十类三因素探索与六源独立种子复核

十类历史最佳 84.0905%，相对普通 PL 84.1994% 净少 134 条，差距集中在 `cross_both`。本轮从同一合规 E20 开始，八条使用种子 `2026092701`，固定 U 权重 0.75、浅层跨 RX 对比系数 2、普通视图 KL 系数 1.5。完全交叉三因素的开关。第一因素原始视图伪标签 CE 系数 0.25，乘 U 权重后为 0.1875，保留原全批平均。第二因素给视图分歧大的已接受样本增加 KL 权重，强度 0.5，批内平均权重守恒。第三因素浅层对比中，让同伪类的不同源 RX 对正样本分配等质量，再取 0.5 比例与原分布混合。每个因素既有单独对照，也有联合对照，可报告主效应和交互。现有硬掩码、增强、模型和监督训练保持固定。

六源预先固定两种历史配方。固定配方用 raw KL 1.5、融合权重 0.10、U 权重 0.75，CE 关闭。同日期配方在相同基础上将 0.5 的融合正对分配给同日期跨 RX 正对。开发种子上分别达到 86.4486% 和 86.4667%，普通 PL 为 86.4285%。现在对两种配方使用 `2026092702`、`2026092703` 复核，保留两种配方的所有结果。种子 02、03 未用于这两个配方的选择。目标接收机和日期属于历史测试设计。

使用相同设置和模型种子的原三视图 Tri E20，自身续训固定 E30/E50，总 11100 步。训练只用原源数据契约。冻结后生成三个 raw clean 子集预测，由独立阶段读真值评分。主指标是合并 `cross_rx + cross_both` 的同物理 ID 净纠错，对照同种子普通 PL 和原 Tri。六源逐种子报告结果，十类如有达标候选再固定配方进行独立种子复核。记录每步 L/U 梯度、各有效损失、源验证、AdamW 抽样和冻结后 U 诊断。

发布入口是 `python -m experiments.pamf_repl_two_setting.publish`，N607 普通账号及原 Python 环境。允许 GPU 0–6，单卡总进程至多两条，准入保留 12 GiB。真实源 E20 冒烟通过后直接派发。阻断性技术错误停止新派发，保留健康任务和已有结果。预期 12 行，各含训练、预测、clean 评分和冻结后 U 诊断共 48 项。[运行矩阵](experiment.json)
