# Phase1 源域 FIR 半窗口交叉拟合

本诊断检查逐窗配对滤波收益能否延续到同一窗口中未参与系数拟合的另一半。它使用此前固定的 512 条 Phase1 源训练记录（128 条 L_s、384 条 U_s）及源视图 1、20；两视图共享物理记录。冻结 Tri-SIG-TIME SSL 和原 DURA，未读取 TX 标签、V 或测试 IQ。

对每条 256 点 DURA 输出，分别比较：原 DURA；用整段配对 clean 拟合的广义复数 FIR；以及用左半段 clean 拟合后预测右半段、用右半段 clean 拟合后预测左半段的交叉拟合 FIR。比较 1、3、9、17 tap；各方法按每半段 DURA L2 范数的 20% 独立截断，防止跨半段截断尺度引入本半段 clean 信息。

交叉拟合在中点之前构造 anchor 滑窗；多 tap 的边界行仍可读取中点另一侧的 DURA 输入，最多跨越 `taps // 2` 个点。被预测半段的 clean 目标不参与其系数拟合。两半并非独立物理样本，且另一半 clean 仍属特权信息，因此交叉拟合也不能直接部署。

在这组源训练记录中，9 tap 整段拟合降低波形误差，但交叉拟合的平均误差高于原 DURA。可能原因包括逐窗拟合对已知 clean 的过拟合、窗口内变化或两者共同作用；本诊断不能区分这些原因。不能将特权整段拟合的改善当作模型可获得的增益，也不能据此判断正在排队的神经网络最终表现。clean 教师一致性不是 TX 真实准确率。
