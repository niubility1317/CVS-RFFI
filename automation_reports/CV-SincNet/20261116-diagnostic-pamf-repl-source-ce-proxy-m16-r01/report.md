# Tri 分类头梯度代理的源域筛查

为评估后续“按梯度组织无标签批次”的可行性，在十类、六源各使用原 Tri 同合同 seed 2026092701 的 E20 参数，固定 8 个源训练批次。每批使用实际 L ordinary CE、原生 U 伪标签 CE、完整 L 和原始完整 U 损失的计算图，提取各参数组梯度。U 伪标签 CE 是 ordinary、mixed／As、raw 三槽原生加权组合，不等于仅 ordinary CE。

每个 L128 批次分别与同设置其余 7 个独立计算的 U256 批次组成 56 个有序配对。以分类头上的 L ordinary CE 与 U 伪标签 CE 余弦排序，预先比较代理最高和最低的候选，同时记录完整 L 与完整原始 U 在 t2、分类头、其他参数组的范数、点积和余弦。各个配对复用批次，不是 56 个独立种子或试验；同 checkpoint 的不同批次、随机增强及前向缓冲仍可能变化。

这是对代理方向的初筛，不会重新组织或选择训练数据。U256 单独计算的完整梯度不能视为 U64 重组后含 MixStyle 和对比的梯度；本诊断也不能代表真实后续 AdamW 动量、样本覆盖或目标 clean 性能。如果代理关联弱，不宜直接依靠代理组织批次；如果关联强，仍须开展预登记的真实重组训练与覆盖对照，才能判断是否有效。

N607 普通账号使用 CPU 及两线程，不占 GPU。仅使用合法源 L_s 和盲 U_s，U 真值、源 V 和测试集均不读取；模型与空动量优化器影子均不用于训练，不持久化梯度或模型。完整输入角色、来源、命令、路径、停止条件与预期结果见 `experiment.json`。独立 P0/P1 审查未发现阻断项；合成反例和未定义代理方向的针对性测试通过，真实 checkpoint 运行待核验。
