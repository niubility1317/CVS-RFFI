# 竞争波束监督首轮结果与取舍

- [配置](experiment.json) · [状态](events.jsonl) · [训练轨迹](../20261119-diagnostic-satiq-pamf-sup-native-beam-rank-s2026092701-r01/report.md)
- 竞争版和 [普通原型监督 320 维](../20261119-diagnostic-satiq-pamf-sup-native-expansion-prototype-s2026092701-r01/report.md) 均完成固定的 28,225 步。评分核实固定 49,814 条已知类 V 包和三个配对的训练/验证检查点引用，其中普通版闭集打分复用[同轮结果](../20261119-diagnostic-satiq-pamf-sup-native-enrolled-head-s2026111907-r02/report.md)。读出控制器 PID 2080698，退出码 0。

## 从哪方面入手

普通原型监督 320 在首轮中仍有约 90.6% 的查询同时被同星和跨星错波束压过。这里从分类头的训练目标入手，保留 75% 的全类 CE，将其余 25% 用于真波束与当前分数最高的 8 个错波束。错误类在全部训练波束中选取。波形、网络、标签、数据顺序、五路辅助监督和扩展块原型监督保持一致。

## 同预算结果

| 指标 | 普通全类 CE | 竞争波束 CE |
|---|---:|---:|
| 验证全类 CE | 7.5685 | 7.5376 |
| 分类头 Top-1 | 0.2148% | 0.1746% |
| 分类头 Top-5 | 1.0620% | 0.9114% |
| 随机同星 K16 原始 AUC | 0.5653 | 0.5630 |
| 跨日同星 K16 白化 AUC | 0.6740 | 0.6750 |

竞争项的训练 CE 在 5,000、20,000、28,225 步分别为 3.3905、2.9814、3.0286。跨日白化 AUC 差约 +0.10 个百分点，按卫星配对的 95% 区间为 −0.27 至 0.49 个百分点。验证全类 CE 降低，但分类头 Top-1 与 Top-5 都下降，跨日收益的区间跨零。

## 取舍

该竞争损失作为首轮消融归档，百轮保留 [普通原型监督 320 维](../20261119-phase1-satiq-ccs2023-fused320-extproto-sup100-s2026092701-r01/report.md) 作为扩维候选。后续用同轮结果比较 160、256、320 与 SatIQ。此处全部为源验证，独立测试仍留出。
