## 方法、权限与训练成本

全链 dense 通道收窄，四组 GroupNorm 内等量取通道，decoder skip 保留原拼接偏移；三步 prior 共享长卷积权重，保留分步 bias/GN/pointwise。全部 coarse/action/prior 联合更新。输入仅当前 IQ、输出一份 IQ，原 PAMF 统一计算 FFT/PA/时域/统计。

损失是最终 paired-clean IQ NMSE＋λ×三个 stage 到冻结原 R17 IQ 教师的 NMSE 均值，λ 固定 E1=10 线性至 E20=1。clean 配对确实进入优化，因此准确名称为 TX 无标签模拟配对自监督，含 F-free IQ 教师；不是没有 clean 信息的盲去噪。teacher 保留原上下文、停梯度且不更新。恢复器训练 0 TX 标签、0 F 权重/输出、0 V/target；原 F 仅在冻结评估和无 query smoke 使用。

两行均原 L6300/U56700 全部 63000 条，20 个原 R07 received 缓存 epoch，15% clean/85% residual。batch256/micro64，最后不满 batch 按实际分母累积，4940 次 AdamW、一次/globalbatch clip1，FP32/noTF32，固定学习率日程。

## 独立加载与 PAMF 接入

两份最终权重均已取回，并在原方法 commit `e0868f0a0c3cf056a1753a5b4e5ce4f0bff84381` 的独立代码快照下通过本机 CPU 加载/前向检查：E20/4940、参数数目和完整状态严格匹配，优化器为空，未加载教师或 F checkpoint。输入为固定合成 IQ，输出 `[1,2,256]` 有限；这是可用性验证，不是新增性能证据。

使用固定方法版本，输入沿用原 Phase1 的 float32 `[B,2,256]` 切片与幅度约定。`checkpoint_path` 指向交付的对应最终权重，`received_iq` 是按该约定构造的 Torch 张量：

```python
import torch
from experiments.pamf_iq_joint_compact.runtime import load_checkpoint

restorer, metadata = load_checkpoint(checkpoint_path, "cpu")
restorer.eval().requires_grad_(False)
with torch.no_grad():
    restored_iq = restorer(received_iq.to("cpu", dtype=torch.float32))
```

恢复器单独推理仅需当前 IQ 和自身权重。接回原冻结 PAMF 时，从这同一份 `restored_iq` 按原流程派生 FFT、PA、时域和统计输入，再用原默认头；不另外生成相互独立的模态或重训分类头。两版全部七场景正式测试已实际走通该读出。权重作为本地实验产物交付，不提交到 Git。
