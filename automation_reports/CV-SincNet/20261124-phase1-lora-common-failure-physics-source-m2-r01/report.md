# LoRa 共同失败包的噪声与接收作用归因

## 预登记

上一轮同一源域面板中，Full 六景存在 1,050 次同包 clean 可判对但四个接收读出全错。Residual 对应 1,048 次。两路低城区共同满足此条件的物理包有 123 个。以往已知作用和独立噪声的 300 包面板与这批只交叠 26 个。此次保留同一 900 个物理包、五台源接收机、同一冻结 Tri-set 2026092702，在两条路径上分别量化去掉新增噪声和校正已知接收作用对这些失败的恢复量。 [既有同包结果](../20261124-phase1-lora-frame-marginal-source-m2-r01/report.md) · [历史隔离噪声与反演](../20261124-phase1-lora-received-discrepancy-inverse-source-m2-r01/report.md)

固定直通、路线匹配半量 DURA、扣除同次新增噪声幅度的 80% 和 100%、原有噪声已知作用反演，以及两档扣噪后反演。Full 的反演右端限于原登记的六段 256 点接收窗口。Residual 使用每条 chirp 的原登记窗口逐条反演。以原未扣噪观测中的精确噪声 RMS 确定同一包三档共同的阻尼系数。正则化 LSMR 最多 30 步，输出转回源时间坐标和原分类输入格式。只扣噪的对照保留原接收时间坐标。精确算子、噪声和用于对齐的真值仅在隔离诊断出现，不拟合恢复器、不选候选或门限。受扰读出覆盖全部 practical 包，含原恢复器旁路的包，用于测量作用本身。所有新诊断读出在 clean 直接使用原波形。 [LSMR 原论文](https://epubs.siam.org/doi/10.1137/10079687X)

对两路七景统一生成并固定预测。独立 CPU 在两路闭合后才读取源 V 标签。先核对同包物理 ID 和历史直通、DURA，再计算全样本六景、低城区、逐接收机和配对区间。按之前冻结的四组读出定义每路共同失败和双路共同失败，记录单独扣噪、单独反演、两者联用和仍失败的数量。所有结果仅用于机制归因，不作为部署成绩、正式目标验收或选择门槛。0 次新增训练，0 次目标访问。

3 项聚焦测试与一次独立 P0/P1 审查通过。N607 使用登记的 Python 和发布目录。两路最多同时运行，每路线 8 个 CPU worker。真实源 U 先按每接收机一包检查 clean、低城区、冻结识别器和全部诊断臂。实收重放、时域坐标、数值、预测或评分覆盖失败即停止，不变更其他任务。命令和工件见 [登记](experiment.json)。

## 归因结论

在固定源面板上，完全扣噪后接反演，Full 六景达到 72.61%，低城区达到 68.78%。Residual 分别为 73.81% 和 73.33%。完全扣噪只做直通时，Full 六景为 65.78%，低城区为 58.89%。仅在原始噪声下做已知作用反演，相对直通 Full 六景净增 100 次，Residual 净增 18 次，Residual 配对区间跨零。受扰结果采用单个已冻结识别种子。两路所有新诊断的 clean 均为 667/900，逐包类别与直通一致。

在 123 个两路共同失败的低城区包中，完全扣噪后再反演，Full 纠回 102 个（82.93%），Residual 纠回 104 个（84.55%）。两路分别有 56 和 43 个包只有联用才纠回。固定相同阻尼后，两项联用仍体现出正交互。按包在各接收机内配对重抽 4,000 次，交互量定义为扣噪后反演净差减去原始噪声下反演净差。

| 交互量及 95% 区间 | Full 六景 | Residual 六景 | Full 低城区 | Residual 低城区 |
| --- | ---: | ---: | ---: | ---: |
| 精确扣噪 80% | +126 ［56，197］ | +168 ［97，245］ | +7 ［−23，36］ | +34 ［4，63］ |
| 精确扣噪 100% | +269 ［179，363］ | +380 ［286，479］ | +80 ［45，115］ | +108 ［74，142］ |

低城区从 80% 到完全扣噪，双路共同失败包的联合纠回数分别从 49 到 102 和 48 到 104。这使强扰动剩余噪声及其与作用校正的配合成为下一项可检验的重点。本轮的数值来自精确轨迹和精确噪声的隔离诊断。接收端仍需用合法估计量单独验证，正式 30,000 包三种子验收仍未执行。 [交互量核对](source-interaction.json) · [复现脚本](audit_source_interaction.py)
