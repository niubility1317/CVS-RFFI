# Phase1 源域连续波形融合诊断 r02

沿用 r01 已登记的全部输入、32 条每组与场景的样本选择、五种混合系数和评分方案。r01 真实源预检完成模型推理后在保存数组时失败；服务器上的 PyTorch `.numpy()` 返回另一 NumPy ABI 的数组类，与环境默认 NumPy 的 `savez` 不兼容。r02 使用 DLPack 将张量转换为当前 NumPy 数组，并对评分所需张量同样转换。r01 日志保留；模型、数据、实验目标和系数未改变。

先执行 28 条真实源预检，再固定 448 条预测，最后按干净源波形的冻结 F 高置信伪类别进行源域评分。伪类别不是真实身份，理想并集不可部署；不读取 TX 身份、U_s 身份真值、V 或地面测试，不更新模型。CPU 两线程，负载超过 72 等待；输出独立不可覆盖。运行编号 `20261102-phase1-continuous-fusion-source-s2026092701-r02`。本实验是固定插值的源域机制诊断，不是新训练网络或地面性能结果。
