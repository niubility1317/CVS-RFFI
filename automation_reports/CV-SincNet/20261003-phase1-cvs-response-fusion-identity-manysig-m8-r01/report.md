# CVS约束响应融合：源训练

状态PLANNED，尚未启动正式训练。目标是保留原单一CE和训练方案，仅用神经网络结构提升Phase1识别性能。上一轮完整源V几何发现：响应大部分能量位于分类差异子空间之外，并通过联合归一化明显放大原分类置信度。该观察支持检验融合机制，但不保证新约束改善识别。

本轮比较两个同参数量结构。`response_span_mean`将响应映射到中心化分类权重张成的子空间，使用ridge稳定求解，不是严格正交投影。`response_anchor_mean`对主干独立归一化，再加有界响应，取消末端联合L2，使分类差异零空间响应不能靠改变公共分母放大原logit。两者均为237147参数，不增加损失、增强、重加权、采样、teacher或训练阶段。完整算子与边界见[设计](../../../docs/CVS_RESPONSE_FUSION_DESIGN_20261003.md)。

2结构×4种子，共8个scratch模型；原200轮×50步、batch128、AdamW/cosine、FP32、源划分不变。对照是浅层、双路和三种既有响应结构，共20份冻结源记录；仅读取元数据，不继承权重。28份记录按四seed均值0.5V+0.5最差源RX选模，性能完全相同才比较成本。不因低性能停机或选择性重跑。

新候选获选后，仅4份固定E200权重进入clean预测；40份既有冻结预测复用，共44行。168000相同物理query、6类、7个RX；全部预测固定后独立truth-last评分，报告352份ALL/RX统计、88组汇总及80组配对差值。若既有控制保留，核对并复用其完成证据。所有未选候选不读取query；测试结果不反馈结构、选择或调参。

输入为equalized=1、center256、unitRMS，源V使用已见源RX。本实验不能证明任意多径不变性、物理硬件恢复或TX/RX因果分离。Anchor的特征不是单位向量，不自动支持旧余弦原型或Phase2新类协议。LEO、support适应、新类与D92三阶段指标均为N/A。

本地78项模型与源流程检查通过；公开随机输入3步CE验证了所有参数梯度和实际融合诊断。正式训练及测试未完成，性能与论文目标尚未达成。
