# 原 DURA 源域梯度可行性

从固定、来源已核实的 DURA v1.0 权重加载内存副本，使用 4 条源 L_s/U_s IQ（clean、高郊区、中郊区、低郊区各一条），计算源 clean IQ 归一化误差，并做一次临时 AdamW 更新。没有保存新权重，原 checkpoint 未写入；未读取 F、TX 标签、V 或目标数据。

物理估计及粗恢复模块 185615 个参数、先验模块 81336 个参数均获得有限且非零的梯度。GPU 7 的 batch 4 单步耗时 2.435 秒，报告的峰值已分配显存 143802368 字节（约 137 MiB）；显存统计从模型与输入加载后开始，包含当前驻留模型及后续计算，不包含加载时已释放的临时峰值。

这只说明反向传播在该小批次可运行，不证明完整训练可行、模型性能改善或识别准确率提高。后续应测量更大批量和稳定吞吐，再固定独立训练矩阵和完整七景评分。远端证据：runs/20261106-phase1-dura-gradient-source-smoke-s2026092701-r01/result.json。
