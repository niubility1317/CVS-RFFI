## 本家族的具体结果

三接收机组合的 clean full−CE 为 −2.3347/−1.4609/+3.0875 个百分点，正差分别为 1/3、0/3、3/3。ManyRx 的 RX 等权 clean Accuracy 从 72.3870% 变为 75.6362%，配对差 +3.2492 个百分点，正差 3/3。Chrono 的目标 RX、D3 主未来结果从 69.8159% 变为 80.3032%，配对差 +10.4873 个百分点，正差 3/3；三个原始差为 +10.5429/+8.5143/+12.4048 个百分点。

五组各自的六种 practical 场景 full−CE 均值全部为正：F0 为 +11.0516 至 +29.1782，F1 为 +7.2272 至 +20.8046，F2 为 +13.8518 至 +31.6611，ManyRx 为 +9.9017 至 +27.2017，Chrono 主未来子集为 +15.8508 至 +39.1643 个百分点。这里描述跨三个模型种子的均值，不将场景或包数视为额外独立训练次数，也不意味着每种子、每接收机都同样受益。

因此，本固定实现中，F0/F1 的 clean 劣化与星地压力改善同时存在，未来日期和更多 RX 条件也有正收益。不能仅按 F0 clean 将 SDG 概括为无效，也不能因这些压力结果将其概括为所有条件均优于 CE。完整方法保留原生两视图及对比目标，收益归于整个训练流程，不能独立归因于单个对比损失。
