# CVS补偿响应：完整源V判别几何

状态PLANNED。上一轮完整源诊断确认响应支路已激活、范数约为主干的49%，但源准确率贡献较小，且开启后的源V交叉熵更高。本次用同12个冻结E200模型，保存完整27000V的主干/响应特征、补偿系数、分类头及全开/关闭的logit，独立重算几何、间隔和交叉熵。

预登记问题：响应是否主要沿主干方向；响应及归一化后变化在分类差异子空间占多少能量；CE变化是否集中在正确或错误样本；相同TX跨RX/day的描述量有多大。TX→TX/RX/day→cell内散度仅是观测数据的均值分解，不称为因果信道分离或互信息。

12模型×2条件，共648000次分类决定；逐物理样本核对先前源诊断预测。模型权重、buffer、源选择保持不变。零优化器更新、零模型拟合、零目标访问。原始特征仅为诊断产物，不进入下一模型训练。该诊断不能代替独立测试，也不改变主实验已完成的固定控制复用结论。
