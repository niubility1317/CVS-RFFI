# 大容量跨视图一致性：源训练与波形诊断

固定 DURA，从零训练归一化大容量修正网络。32768 条合法源 ID 各使用三个模拟视图，源 IQ 损失外加入 0.1 权重的同记录视图离散度；训练未读 F、TX 标签、V 或目标。20 轮训练目标从 0.023596 降至 0.019900，未加权视图离散项从 0.010393 降至 0.008910；这些是训练期统计，不代表身份准确率。

每步采样 10 条源记录 × 3 视图，末批 8 条，因此每轮 3277 步、20 轮共 65540 步。未加权稳定基线 batch32、每轮 3072 步、20 轮共 61440 步；两版源记录曝光相同，但更新次数不同，不是完全匹配的计算预算。
