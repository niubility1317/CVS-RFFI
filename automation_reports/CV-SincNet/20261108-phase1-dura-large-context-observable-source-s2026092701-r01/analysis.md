# 可观测风险加权：源训练与波形诊断

使用与稳定基线相同的 32768 条合法源记录、三个模拟视图和 20 轮预算；可观测物理残差高组额外施加固定源波形风险损失。训练不读取 F、TX 标签、V 或目标；模型不在推理时读取风险阈值或 RX。实际被标记比例为 24.7192%，每轮一致；总训练目标从 0.057496 到 0.051118，目标含额外损失项，不能直接与无此项的稳定基线训练损失比较。

固定最终轮后，在已探索源 pilot 做波形诊断：RX4/6 与 RX8 各七景、每格 48 条，记录与本次修正网络 fit 不重叠，但原 DURA 是否见过其中记录未知。以下受损场景分别列出同输入 DURA、风险加权版和未加权稳定版 NMSE。
