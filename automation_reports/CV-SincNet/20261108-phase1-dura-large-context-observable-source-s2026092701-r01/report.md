# 源物理残差加权 DURA：预登记

- 固定代码提交 5cec1fb17a4b92aa0a91fc82a74fcd9151c90717，原 DURA v1.0 冻结；独立从头训练 14,793,858 参数的归一化全局上下文修正网络，不继承其他候选。
- 训练目标：固定 DURA guard 加 0.5 倍高物理残差源样本的归一化 IQ 误差均值；残差比为物理伴随残差平方均值除以 DURA 输出平方均值。阈值 0.00937667116522789 来自种子 2026110803 的 4,096 个合法源记录 × 3 视图的 75% 分位数，阈值的物理记录互斥源复核见既有源实验分析。无选中样本的批次附加损失为零。阈值仅用于源训练，不用于推理路由。
- 使用源 32,768 物理记录 × 3 视图，batch32、AdamW 0.0003、20 轮固定取最终轮，记录每轮实际被选比例；不读取 TX 标签、F、V 或目标数据。
- 测试：冻结后接 Tri-SIG-TIME SSL 原默认头，Phase1 Main split 的 clean 和六种 practical，每景 168,000 条固定地面模拟记录，七景预测全部固定后独立 truth-last；报告逐景、TX/RX/day 和 DURA 配对。目标结果不回流训练或选模。
- N607 GPU7：预检空闲 20,889 MiB、2 个其他计算进程，队列再次确认至少 4,096 MiB 且总计算进程少于 3 才启动。具体命令、路径、预期产物及技术停止规则见 experiment.json。
- 13 项针对性测试通过；真实原 DURA 与合法源 IQ 的 6 次 GPU 更新通过，末批被选比例 21.875%；独立 P0/P1 静态审查未发现阻断问题。源阈值来源由主任务记录，审查未独立复算该数值。
- 状态：远端 GPU7 训练已启动；发布包核验与编译通过，源域冒烟通过，训练进程 681912；尚无正式身份识别结果。
