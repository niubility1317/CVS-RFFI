# LoRa DURA 复谱带宽与修正幅度归因

## 固定矩阵

接同一个冻结成熟恢复输出。Full 使用复响应半量，residual 使用门控 R69 半量。原接收、成熟、门控、样本、F 和相位坐标相同。由已知源模拟噪声得同包无新增噪声的接收波形，单一参考方向为该波形与成熟输出的复杂差值。此模拟轨迹仅用于源归因。

在去载波后比较双侧 1–32 kHz 与全部非载波两个嵌套支持。四档上限为原始接收坐标下完整 chirp RMS 的 0.02、0.05、0.10、0.18。每个包和 chirp 的成对实际幅度取上限与两方向可用 RMS 的最小值。使用共同相位与幅度渲染，控制对不会过冲已知向量。渲染后独立复算两行实际 RMS 差，必须不超过 1e-6。记录门内实际平均剂量，解释上限未碰到的组。

另固定无上限的 1–32、1–64 kHz、全部非载波、包括载波的完整真向量四行，保持成熟波形中未更新的频点。完整向量和独立精确扣噪对照的区别为后者按原输入包功率归一化。上一轮冻结直接和平衡网络另各评估固定 1、1.4、2 倍输出，仅使用当前接收 IQ 和成熟恢复，无模拟器真值或训练。该矩阵用于判断是否值得扩大训练频带及允许何种修正剂量。部署候选未达前按固定源尺度报告。

五台源 RX 各取 180 个 V 包，共 900，与上一轮学习向量评分面板互斥。两路在同一物理包与全部七景完成 21 个固定读出。接冻结 Tri-set 2026092702，全部预测及物理 ID 固定后独立连接源 V 真值。记录六景、低城区、clean、逐 RX 与配对净纠错区间。无 G 更新，无目标读取。三种子正式目标沿用 67.0% 六景，43.0% 低城区，clean 64,490/90,000。
