# LoRa DURA 分段复响应恢复

## 源证据

从同一冻结 DURA 半量出发，在 600 个源验证包上恢复去载波后的完整复系数。使用配对 clean 构造精确修正，7.5% RMS 上限下六景由 2,091 增至 2,399 次正确，低强度城区由 256 增至 303 次。偏移 1–48 回收低强度城区净收益的 44/47。仅替换去载波复谱的幅度或仅替换相位均下降。完成物理波形及源预测后才读取源 V 标签。配对 clean 只用于诊断。

两组源 L/U 先验均完成 1,800 步。训练共享头、局部头、数据顺序、24 practical 和 8 clean 每步曝光、7.5% 修正上限及门控配方相同，仅变化逐频段误差归一化。整体误差组带双门控的源六景为 2,105 次，低强度城区为 260 次。频段归一化为 2,108 和 269 次。两组源 clean 均为 439/600，新增分支完全旁路。120 包小面板上，分段组双门控六景 404/720，低强度城区 50/120，clean 94/120。与既有半量依次持平、净多 1 次、持平。基于较大面板的配对结果，正式验证固定频段归一化组。

## 训练与盲评

从零初始化两个复频谱预测头，并把同合同旧半量模型冻结为前置和默认旁路。对其每条 chirp 跟踪接收载波，建立去载波归一化复频谱。共享头与逐 chirp 头预测 Cartesian 复增量，直流固定，恢复后乘回原接收载波和尺度。按绝对频点偏移 1–8、9–24、25–48、49–128 分段，除以每段配对误差能量加固定下限后平均。使用每包 7.5% RMS 上限，源 clean 恒等损失按实际注入 IQ 能量计算。

固定种子 2026092702。1,800 步，43,200 次源 practical 和 14,400 次 clean 恒等曝光。两份 practical 观测、held U 分割、原训练源物理包与旧半量 checkpoint 保持匹配。源 U 留出集拟合效用门控，另检查新修正强度是否超过源 clean 的最大修正。拟合期间不读 F、TX 真值或目标。部署使用观测 IQ 和源冻结权重。

矩阵固定六个历史对照和两档复响应剂量。全量为源 pilot 的 7.5% 上限，半量为 3.75%。未触发时逐条复用旧半量预测。同一冻结 Tri-set 在 15 台未见接收机的 30,000 个物理包上执行 clean 与六种 practical。总计 840 份数组和 56 个独立评分单元。完整预测冻结后才读取目标真值，按接收机与场景统计相对同种子旧半量的纠对和改错。正式三种子门槛保持六景 57.0%、低强度城区 43.0%、clean 至少 64,490/90,000。
