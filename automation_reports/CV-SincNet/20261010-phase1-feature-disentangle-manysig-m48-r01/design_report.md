**我建议下一版采用：状态条件多解耦＋关系均衡采样＋受控特征增强＋条件化的方向梯度 Fishr。**

这四部分应分别承担明确任务：

- **多解耦网络**解释哪些变化可以施加、这些变化如何作用于当前信号。
- **采样机制**保证不同接收机之间的比较具有相同的类别和观测条件。
- **特征增强**扩大身份骨干经历的变化范围。
- **Fishr**约束不同真实接收条件下的任务梯度统计，减少模型对个别源 RX 的训练规律产生依赖。

其中，最需要认真设计的是 **Fishr 的统计对象、特征增强的物理边界，以及两者使用什么样的批次**。这些地方处理不好，损失可以明显下降，泛化却未必改善。

下面给出一版可以直接转成实验规格的设计。文中的具体超参数是建议起点；本轮完成了代码与文献核对，没有开展新的射频训练实验。

## 二、从射频指纹原理看，增强必须保留什么

可以将接收过程概念化为：

\[
x_{y,e}
=
\mathcal R_e\!\left[
\mathcal H_e\!\left[
\mathcal P_y(s)
\right]\right]
+\epsilon_e.
\]

其中，\(\mathcal P_y\) 包含发射机 \(y\) 的硬件作用，\(\mathcal H_e\) 和 \(\mathcal R_e\) 分别表示传播及接收链作用。实际接收信号同时包含这些因素；WiSig 的研究也明确讨论了接收机、信道和采集日期对指纹识别的影响。[arxiv.org](https://arxiv.org/html/2112.15363v2?utm_source=chatgpt.com)

这里最重要的限制是：

**接收条件变化与身份信息经常存在交互，不能把某一种统计量整体划为“域风格”。**

### 1. 独立改变 I、Q，可能直接改写硬件特征

设复信号为 \(z=I+jQ\)。如果独立缩放：

\[
z'=aI+jbQ,
\]

则

\[
z'
=
\frac{a+b}{2}z
+
\frac{a-b}{2}z^*.
\]

当 \(a\neq b\) 时，会引入共轭项。这类作用与 IQ 不平衡的 widely-linear 表达有关，可能改变用于识别发射机的线索。

所以，原始 IQ 或仍具有明确复数对应关系的特征，不能直接套用独立实通道的随机 style 缩放。

### 2. 幅度分布也可能包含身份

当前 PA 路径涉及高阶非线性表征。对于类似

\[
z|z|^{2k}
\]

的项，幅度变化会以不同阶数影响各分量。强行混合幅度分布、重写尾部或抹平高阶矩，可能同时削弱 PA 指纹。

### 3. 最终 embedding 不适合随意增强

当前最终 \(z\) 用于 cosine 分类：

- 整体径向缩放大部分会被归一化抵消；
- 任意方向的噪声会直接改变分类角度；
- 同类 embedding 插值也可能收缩类内分布。

例如，在同类样本近似独立、协方差为 \(\Sigma\) 的简化条件下：

\[
\operatorname{Cov}
\left[
\lambda z_i+(1-\lambda)z_j
\right]
=
\left[\lambda^2+(1-\lambda)^2\right]\Sigma.
\]

当 \(\lambda=0.5\) 时，协方差缩小为原来的一半。它可能有平滑决策面的作用，但不能据此声称扩大了接收条件覆盖。Manifold Mixup 原论文也把类条件表示的 flattening 作为其研究对象之一。[proceedings.mlr.press](https://proceedings.mlr.press/v97/verma19a/verma19a.pdf?utm_source=chatgpt.com)

**因此，下一版应优先增强有证据支持的变化方向，并把通用统计增强限制在一个可检验的浅层位置。**

## 三、采样先改：新增独立关系流，保留原生训练预算

### 3.1 原生 L/U 流保持现有定义

当前实际训练链是：

- 有标签 L batch 为 **128**；
- U batch 为 **256**；
- 每个 epoch 固定 **222 次原生更新**；
- L 迭代器耗尽后继续循环；
- U 身份学习从原有伪标签阶段进入；
- clean＋LEO 拼接、cosine 调度和旧伪标签门控继续保留。

这里的 222 步由 stack 的 U 长度预算适配决定，即使 MUSE 没有开启也一样。因此，不适合直接替换原生 sampler，再把产生的差异归因于新机制。  
依据：[原生预算适配](https://github.com/niubility1317/CVS-RFFI/blob/e99f4e06d6ac741399d1349ff5240bb57d53af7a/experiments/cvs_phase1_stack/runtime.py)。

### 3.2 新增 B48 关系批次

我建议每 **8 个原生 step** 取一次：

\[
\boxed{
B_{\mathrm{rel}}
=
6\ \mathrm{TX}
\times
2\ \mathrm{RX}
\times
4\ \text{不同物理包}
=
48
}
\]

具体规则：

1. 选择两个不同源 RX。
2. 选择同一个 source day。
3. 使用全部六个 TX。
4. 每个 TX×RX×day 格抽四个不同物理包。
5. 同一格内先无放回遍历，再重新打乱。
6. 若格内支持不足，记录并换一个可行组合，不复制包补齐。

这样，每个 RX 恰好有 24 个样本，六类各四个；两 RX 的类别与日期组成一致。

五个源 RX 有十个无序 RX 对，与三个 source day 组合得到：

\[
10\times3=30
\]

个关系 block。公平轮换这些 block，一轮需要：

\[
30\times8=240
\]

个原生 step。所有源 RX 始终参与正常身份训练。

这里的“不同物理包”也不能自动等同于独立采集。若存在原始采集块或时间索引，应进一步分散抽取；没有这些元数据时，至少准确报告不同 PID 数量。

### 3.3 为什么建议覆盖全部六类

Fishr 的域内方差满足全方差分解：

\[
\operatorname{Var}(g\mid r)
=
\sum_y\pi_{y|r}\operatorname{Var}(g\mid y,r)
+
\sum_y\pi_{y|r}
(\mu_{y,r}-\mu_r)^{\odot2}.
\]

其中，\(\pi_{y|r}\) 是 RX 内的类别比例。

这意味着：**即使每个 TX 的条件机制没有变化，类别比例变化也能改变 Fishr 的统计。**

全部六类、每类四包，可以先控制这个混杂。相比之下，每次随机选四类，再让各 RX 分别积累 EMA，可能在历史统计中重新引入类别组成差异。

不过，这仍然是“相同类别先验下的总体 Fishr”，不等于 class-conditional Fishr。后者需要逐类估计方差，而每格四个包的统计波动更大，我不建议首轮就同时加入。

### 3.4 困难采样放在下一层，保持 Fishr 流公平

困难样本采样值得尝试，但我建议先用于**动作增强或 R 关系选择**，Fishr 主统计流继续公平轮换。

后续可以采用：

\[
q_t(g)
=
0.8q_{\mathrm{uniform}}(g)
+
0.2q_{\mathrm{hard},t-1}(g).
\]

困难程度来自上一窗口合法源训练数据的分类间隔、组损失等。这样每个组都有基础覆盖，不会长期集中在少量高损失样本。

需要明确两种目的：

- 如果希望改变训练目标、更加重视困难组，就承认这是风险重分配。
- 如果仍希望估计均匀组目标，则使用重要性权重修正。

重要性权重应乘在 **block loss 外面**。先给单样本梯度乘权重再求方差，会把权重的平方带入二阶统计，改变 Fishr 的定义。Group DRO 为预定义组上的最坏组风险优化提供了参考，但不能推出高损失重采样一定改善射频泛化。[arxiv.org](https://arxiv.org/abs/1911.08731?utm_source=chatgpt.com)

### 3.5 U 和 R 的边界

首轮 B48 和 Fishr 只使用 \(L_s\) 的真实标签。现有 TX-balanced sampler 会读取真实类别索引，不能直接用于隐藏 TX 标签的 U。U 继续沿用旧伪标签规则。

R 的 descriptor、recipient、destination 三个角色及 fit/calibration 分区继续由物理 ID 固定。**B48 不兼任三个角色的共同统计池。** R 仍从同一 reference version 的独立角色 bank 取数，并分别记录可用关系数、实际选中关系数和真正参与训练的关系数。

## 四、特征增强采用两层设计

## 4.1 第一层：利用多解耦网络生成有依据的作用

继续保留：

\[
F_{\mathrm{id}}=C\circ G\circ E,
\qquad
D_L,\ D_T,\ D_R.
\]

对于 L/T，动作应作用于 recipient 自己的状态：

\[
\widehat{\Delta h}_{i,k}
=
D_k(\bar h_i,s_i,p_k),
\]

其中，\(\bar h_i\) 是停止梯度的参考特征，\(s_i\) 是该包的可观测状态，\(p_k\) 是受控动作参数。

**跨样本迁移应优先迁移动作参数，并在新 recipient 上重新计算作用。**

直接把另一个包的 \(\Delta h_j\) 加到 \(h_i\) 上，忽略了同一失真对不同波形的作用差异，也容易把 donor 身份信息带进来。

对当前 \(h349\)，仍应区分：

| 部分 | 下一版处理 |
|---|---|
| base160＋physical160 | 由状态条件作用网络预测变化 |
| reference29 | 对确实存在的数字 IQ 变换，从变换后信号重新计算 |
| R 的真实跨 RX 变化 | 没有逐包真实置换时，不虚构“精确 reference29” |

### 让动作模型承担候选筛选价值

我建议加强以下流程：

1. 在合法物理范围内生成若干候选参数。
2. 用作用模型快速估计这些参数对身份损失或 margin 的影响。
3. 在预测可靠的区域选择部分困难候选，同时保留随机覆盖候选。
4. 把选中的动作真正施加到 IQ。
5. 重新经过真实 \(E\rightarrow G\rightarrow C\) 前向训练。

这能检验作用模型是否有能力帮助模型发现更有效的训练变化。

**同一个实际增强端点如果已经完整进入真实 IQ CE，就不要默认再把同端点虚拟特征 CE 当作额外信息。** 虚拟路径的价值应来自更便宜的候选评估、跨样本作用迁移或经过验证的新组合。

还有一个关键区分：

> 作用模型拟合失败，可以降低虚拟特征的权重；物理上合法的困难 IQ，不应仅因为当前模型预测错误而被删除。

否则可靠性机制可能把最需要学习的困难样本排除掉。

### L/T 组合继续保留条件性与执行顺序

联合动作应围绕实际顺序建模，例如：

\[
D_T(h_L,s_L,p_T)
\approx
h_{LT}-h_L.
\]

这里的 \(s_L\) 来自施加 L 动作后的观测。不能一边使用原始状态，一边假设已经描述了“经过滤波后”的时间变化。

首轮优先验证条件作用和 rollout 误差；只有稳定的剩余交互确实存在，再增加独立交互网络。

## 4.2 第二层：浅层弱 MixStyle

MixStyle 的原始方法在中间特征上混合样本的均值与标准差，并对这些统计停止梯度；其研究背景主要是视觉域变化。[arxiv.org](https://arxiv.org/pdf/2104.02008?utm_source=chatgpt.com)

在当前射频网络中，我建议把它作为一个明确的受控候选：

\[
\boxed{
\text{time\_down 单点}
+
\text{同 TX、不同 RX、同 day 配对}
+
\text{弱统计移动}
}
\]

### 插入位置

首轮只使用 `time_down`。

暂不同时放到 `time_down` 和 `t1`，也不直接放到 PA 分支、reference29、\(h349\) 或最终 \(z160\)。

理由是 `time_down` 仍保留时间维，可以明确计算通道统计；最终 embedding 已经承担身份判别，任意统计混合更难解释。

### 具体形式

设该层特征为 \(H_i\in\mathbb R^{C\times T}\)：

\[
\mu_i=\operatorname{sg}(\operatorname{mean}_T H_i),
\qquad
\sigma_i=
\operatorname{sg}
\left(\sqrt{\operatorname{var}_T H_i+\epsilon}\right).
\]

选择合法 donor \(j\)，令：

\[
\lambda\sim\operatorname{Beta}(0.1,0.1),
\qquad
a=\eta(1-\lambda).
\]

构造：

\[
H_i'
=
\frac{H_i-\mu_i}{\sigma_i}
\left[(1-a)\sigma_i+a\sigma_j\right]
+
(1-a)\mu_i+a\mu_j.
\]

建议从：

\[
p_{\mathrm{style}}=0.15,
\qquad
\eta=0.2
\]

开始。

这里：

- \(p=0.15\) 是模块调用的开启概率；
- \(\eta=0.2\) 限制最大统计移动比例；
- Beta 参数 0.1 并不表示很小的扰动，它倾向于两端取值；
- 实际移动量是 \(a\)，还取决于合法 donor 覆盖率。

### 放进已有身份 CE，不额外再叠一个 style 损失

首轮建议仅增强**原生 L 身份前向中的逻辑 clean 行**：

- 使用已有身份 CE；
- 保留原有 clean＋LEO 数量、拼接和 CE 权重；
- 不额外增加一次相同样本的 style CE；
- 不增加 style KL；
- U、EMA teacher、D 拟合、D 校准、Fishr 专用前向和验证全部关闭 style。

这样，A 开关主要改变特征分布，新增数据曝光较容易控制。

配对条件应显式满足：

\[
y_i=y_j,\quad
r_i\neq r_j,\quad
d_i=d_j,\quad
\mathrm{PID}_i\neq\mathrm{PID}_j.
\]

无合法 donor 就保持原特征，不能自动降级成随机跨 TX 配对。

### 必须承认它是表示扰动

只改时间分支时，频率、PA 和 reference 分支仍来自原 IQ。这个联合表示未必对应某个真实接收波形。

因此，浅层 MixStyle 可以作为正则化手段，但不能被解释为真实 RX 置换，也不应进入作用模型的拟合目标。

还需要检查模型是否通过降低时间分支利用率来适应这种不一致：

- 固定源训练批次上的时间、频率、PA 分支梯度变化；
- source V 上完整模型与关闭时间贡献后的 margin 差；
- clean、LEO 和最差 RX 的分别表现。

关闭分支只是依赖性探针，也可能产生分布外特征，不能单独当成严格的因果贡献。

### DSU 留作互斥替代

DSU 根据特征统计的不确定性产生随机统计变化，原始作者实现的统计梯度与尺度参数化也和 MixStyle 不同。[arxiv.org](https://arxiv.org/abs/2202.03958?utm_source=chatgpt.com)

RF 场景中，batch 统计方差可能混合 TX、RX、质量和工作状态差异。因此：

- 首轮先试弱 MixStyle；
- DSU 作为替代项单独比较；
- 若改成条件残差方差、log-std 扰动或截断尺度，应明确标为 RF 改造版；
- 不同时开启多个统计增强方法。

## 五、Fishr 应如何适配当前 cosine 身份骨干

这是下一版最值得认真实现的部分。

### 5.1 原始 Fishr 的统计对象

对环境 \(e\) 内的单样本身份损失：

\[
\ell_i=\operatorname{CE}(F(x_i),y_i),
\qquad
g_i=\nabla_W\ell_i,
\]

计算域内样本梯度方差 \(v_e\)，再匹配不同环境的 \(v_e\)。Fishr 可以只在分类器参数上计算这些统计，最终惩罚仍可反传到特征提取器；Fish 使用的域平均梯度关系与这里的样本梯度方差不同。[proceedings.mlr.press](https://proceedings.mlr.press/v162/rame22a/rame22a.pdf?utm_source=chatgpt.com)

按作者代码的归一化方式，可以写成：

\[
\mu_e=\frac1{n_e}\sum_{i\in e}g_i,
\qquad
v_e=
\frac1{n_e}
\sum_{i\in e}(g_i-\mu_e)^{\odot2},
\]

\[
L_F
=
\frac1{|\mathcal E|}
\sum_e
\operatorname{mean}_j(v_{e,j}-\bar v_j)^2.
\]

论文和作者代码在方差分母、参数坐标归约上存在尺度差异，移植时必须固定定义，再标定权重。  
依据：[作者 Fishr 实现](https://github.com/alexrame/fishr/blob/7b8fdf1e0b15226ded9b58efd37698e74e616ab7/domainbed/algorithms.py)。

### 5.2 当前 cosine 头的正确梯度

以下是针对当前分类器的推导。

定义：

\[
u_i=\frac{z_i}{\|z_i\|},
\qquad
v_c=\frac{w_c}{\|w_c\|},
\qquad
a_{ic}=s\,v_c^\top u_i,
\qquad s=30.
\]

令：

\[
\delta_{ic}=p_{ic}-\mathbf1[y_i=c].
\]

在归一化范数高于 epsilon 的正常区间：

\[
\boxed{
\nabla_{w_c}\ell_i
=
\frac{s\delta_{ic}}{\|w_c\|}
\left[u_i-(v_c^\top u_i)v_c\right].
}
\]

所以，当前头不能直接使用普通线性分类器的

\[
(p-y)\otimes z
\]

作为真实参数梯度。

### 5.3 原始权重梯度存在范数捷径

如果令所有权重行同时变为：

\[
W'=aW,\qquad a>0,
\]

则 cosine logits 不变，但：

\[
g_i'=a^{-1}g_i,
\qquad
v_e'=a^{-2}v_e.
\]

因此，在无历史 EMA 的即时统计中：

\[
L_F'=a^{-4}L_F.
\]

**分类函数完全不变，单纯增大权重范数就可以减小 Fishr 惩罚。**

有 EMA 时，变化还受到历史统计影响，但这种参数化问题不会因此消失。

### 5.4 推荐方向梯度版本

我建议下一版使用：

\[
\boxed{
g_{ic}^{\mathrm{dir}}
=
s\delta_{ic}
(I-v_cv_c^\top)u_i
=
\|w_c\|\nabla_{w_c}\ell_i.
}
\]

它描述分类器权重方向上的切空间梯度，消除了惩罚值对权重行正缩放的依赖。

应明确命名为：

> **基于分类器方向梯度方差的 Fishr 改造。**

实现要求：

- 使用最终融合后的 \(z160\)；
- 保留全部六个类别行；
- 单样本梯度张量为 `[B, 6, 160]`；
- 只沿样本轴求方差，得到 960 个参数坐标的统计；
- \(p,u,v\) 及投影项均保留计算图；
- 固定 scale=30；
- 不再将每个 \(g^{\mathrm{dir}}\) 单位化。

最后一点很重要：梯度幅度包含任务难度信息，将每个梯度再次归一化，会改变所匹配的对象。

建议直接用解析式构建可导张量，并做一次与自动微分或有限差分的对照。无需假定现成逐样本梯度库能够自动正确支持这个自定义 cosine 头。

### 5.5 在同条件内跨 RX 匹配

对 B48，本次两个 RX 具有相同日期和类别组成。再分别计算：

- clean 条件下的梯度方差；
- 同一种实际 LEO 场景下的梯度方差。

设 \(b=(d,a)\) 表示日期和实际场景条件，参数坐标数 \(M=960\)，采用：

\[
L_F^{(b)}
=
\frac1{4M}
\left\|
\widetilde v_{r_1,b}
-
\widetilde v_{r_2,b}
\right\|_2^2.
\]

这里的 \(1/4\) 对应“两域分别到共同均值的距离再平均”。

初始组合可以设为：

\[
L_F
=
0.75L_F^{\mathrm{clean}}
+
0.25L_F^{\mathrm{LEO}}.
\]

这两个权重是建议起点。它允许模型在不同噪声条件下具有不同统计，只要求同一条件内的 RX 更一致。

实际 LEO 没有 applied 时，不再把 clean 副本当作额外独立 LEO 观测。某个条件没有足够支持，也不能以零方差代替缺失数据。

同日期、同场景只能减少混杂，仍不能保证各 RX 的底层质量完全相同。因此 Fishr 应保持较弱起点，并观察质量分层后的统计，而不是强制所有差异消失。

### 5.6 使用每桶独立计数的 EMA

建议按：

\[
k=(\mathrm{RX},\mathrm{day},\mathrm{actual\ scene})
\]

保存统计。

第 \(n_k\) 次有效更新时：

\[
m_k
=
\beta\,\operatorname{sg}(m_k^{\mathrm{old}})
+
(1-\beta)v_k,
\]

\[
\widetilde v_k
=
\frac{m_k}{1-\beta^{n_k}}.
\]

初始取 \(\beta=0.9\)。

这里采用的是**每桶零初始化去偏**，不同于 Fishr 作者代码中的 \(m/(1-\beta)\) 补偿；它属于本项目改造，原始参数梯度对照也应使用同样流程，以隔离参数化的影响。  
作者原始 EMA 依据：[MovingAverage 实现](https://github.com/alexrame/fishr/blob/7b8fdf1e0b15226ded9b58efd37698e74e616ab7/domainbed/lib/misc.py)。

必须满足：

- 只更新本次真实出现的桶；
- 只比较本次都已更新的两个 RX；
- 旧状态 detach，当前更新值保留图；
- 缺席桶不加计数，不以零更新；
- checkpoint 保存未去偏的 \(m_k\)、计数和更新时间；
- source V 不更新这些状态。

去偏只处理初始化缩小，并不让历史统计变成当前模型下的无偏估计。其当前梯度系数为：

\[
\frac{1-\beta}{1-\beta^{n_k}},
\]

新桶和成熟桶仍有差别。因此，Fishr 权重应在常见桶已有一定积累后定标，并记录桶的年龄与更新数。

### 5.7 Fishr 专用前向关闭随机 style

随机增强会把额外波动加入样本梯度统计。强混合也可能同时压缩不同 RX 的差异，让合成统计看起来更一致。

所以首轮：

- Fishr 来自真实 IQ 前向；
- 保留上述 clean/实际 LEO 条件划分；
- 关闭随机 MixStyle；
- 不把虚拟 \(r\rightarrow r'\) 特征标为真实 \(r'\) 样本；
- 不加入伪标签 Fishr。

这样，特征增强带来的训练变化和真实接收条件下的统计改善才更容易区分。

### 5.8 它仍然不是完整不变性的证明

方向梯度解决了权重范数问题，但对角方差仍依赖特征坐标基。共同旋转特征和分类器，可以保持预测不变，同时把某些协方差差异移到非对角项。

此外，分类器梯度方差匹配不等于整个网络的 Hessian 匹配，也不能直接继承为纯 TX 硬件解耦结论。

因此，应把它表述为：**鼓励同条件下的真实源 RX 具有更一致的任务梯度统计。**

## 六、联合训练：把梯度路径写进设计，而不是留给实现猜测

建议总目标写为：

\[
\mathcal L
=
\mathcal L_{\mathrm{native}}^{\mathrm{style}}
+
\lambda_{\mathrm{rel}}\mathcal L_{\mathrm{rel\ CE}}
+
\lambda_{\mathrm{act}}\mathcal L_{\mathrm{real\ action}}
+
\lambda_{\mathrm{virt}}\mathcal L_{\mathrm{virtual}}
+
\lambda_R\mathcal L_R
+
\lambda_F\mathcal L_F.
\]

其中，MixStyle 已经进入原生 L 的身份 CE，不再单独增加一个重复的 style 损失。

| 训练路径 | Style | 更新对象 | 关键约束 |
|---|---|---|---|
| 原生 L 身份 CE | 仅逻辑 clean 行可启用 | \(E,G,C\) | 保留原拼接和 CE 权重 |
| 原生 U 路径 | 关闭 | 沿原伪标签规则 | 不读取隐藏 TX |
| D 的作用拟合 | 关闭 | 对应 \(D_k\) | 参考特征停止梯度 |
| 真实 IQ 动作 CE | 关闭 | \(E,G,C\) | 对变换后 IQ 重新编码 |
| 校准通过的虚拟特征 | 关闭 | 首轮默认 \(G,C\) | D 不接身份 CE 梯度 |
| R 统计约束 | 关闭 | 按独立拟合/身份步骤更新 | 保留固定分袋与共享作用 |
| Fishr | 关闭 | 经真实 \(z\) 回到 \(E,G,C\) | 当前梯度统计可导 |
| 验证 | 关闭 | 不更新 | 不更新 teacher 或统计 bank |

现有虚拟 EG 路径的结果不能直接推导 Fishr 是否应更新 E。两者的梯度定义不同：这里的 Fishr 通过真实 IQ 前向和真实 cosine 决策参与训练。

### 多解耦与 Fishr 的互补关系

局部动作可以近似为：

\[
\Delta h\approx J_k(h)p.
\]

若 \(p\) 零均值、协方差为 \(\Sigma_p\)，二阶展开给出：

\[
\mathbb E_p[\ell(h+J_kp)]
\approx
\ell(h)
+
\frac12
\operatorname{tr}
\left[
\nabla_h^2\ell\,
J_k\Sigma_pJ_k^\top
\right].
\]

这说明动作增强已经会改变模型在特定变化方向上的局部学习行为。该式是局部近似，也不保证非线性网络的特征 Hessian 总是半正定。

Fishr 又在真实 RX 间约束任务梯度统计，因此二者可能互补，也可能重复施加压力。

**下一版必须比较增强单独、Fishr 单独和两者组合。不能用两个辅助损失都下降来证明互补。**

R 同样需要重新验证：如果加入关系采样和 Fishr 后，R 不再改善分类间隔尾部，它的身份约束就应减弱；保留几个网络本身不构成研究收益。

## 九、建议的消融：先分离作用，再验证联合版本

### 9.1 先确认采样与 Fishr 的价值

| 对照 | 回答的问题 |
|---|---|
| 当前 native | 历史参照 |
| native＋同预算随机 B48 CE | 多一点源 L 曝光是否已经有效 |
| native＋关系 B48 CE | 关系组织是否提供收益 |

| 上一项＋方向梯度 Fishr | 消除 cosine 范数影响后是否更稳定 |

原始 W 梯度版与方向梯度版使用相同批次、条件桶、EMA 和日程，以隔离参数化影响。二者均应准确标注为当前训练协议下的适配版本。

### 9.2 在同一个多解耦版本上做增强×Fishr

| 配置 | 浅层增强 A | 方向 Fishr F |
|---|---:|---:|

| 多解耦＋S＋F | 关闭 | 开启 |
| 多解耦＋S＋A＋F | 开启 | 开启 |

这是验证互补性的核心四组。

### 9.3 再补两个机制对照

在源域选择并冻结的联合设置上比较：

- **关闭 R 的身份约束**：检查 Fishr 加入后，R 是否仍改善真实跨 RX 尾部。
- **统一扰动网络替换独立网络**：匹配容量、动作候选、真实视图与训练预算，继续检验“多解耦”的独立价值。

作用模型还应保留直接真实增强对照。否则联合版本取得收益，也无法区分收益来自 Fishr、MixStyle，还是独立作用网络。

正式比较继续使用完整训练、配对 seeds 和固定终点。短运行用于确认公式、数据流与数值是否正确，不用于宣布泛化优劣或判断模型容量不足。

## 十、哪些指标能判断优化是否成立

我建议保留下面这张最小诊断表，避免新增机制只在自己的指标上表现良好。

| 层面 | 必须检查的内容 | 要解决的疑问 |
|---|---|---|
| 身份效果 | source V 宏平均、各 RX、最差 RX、各场景 | 平均提升是否伴随困难 RX 退化 |
| 身份间隔 | 正确类对最强错误类的 margin、低分位与错误尾部 | 是否以压缩身份差异换取统计一致 |
| 关系采样 | 30 个 block 覆盖、不同 PID、重复率、最大等待时间 | 各 RX 是否实际获得均衡支持 |
| 特征增强 | 合法 donor 覆盖、实际变化比例、\(\|\Delta H\|/\|H\|\) | 配置是否生效、强度是否符合设计 |
| 分支利用 | 时间/频率/PA 梯度与依赖性探针 | 模型是否通过弃用某条分支适应增强 |
| Fishr | 真实条件下方差差距、各桶年龄、实际梯度、W 行范数 | 惩罚下降是否来自有效统计改善 |
| 作用模型 | 留出包误差、跨 recipient 迁移、联合动作误差 | 学到的作用是否能够迁移 |
| R | 独立分袋支持、实际使用关系、真实目的 RX 尾部 | R 的拟合改善是否帮助身份 |

实现时还有几处必须接通：

1. **现有 Fishr 最小域数默认值不能直接复用。** 新关系流每次只有两个 RX，要显式支持两域，否则可能静默返回零。
2. **MixStyle 配对需要显式 RX、day、PID 和前向角色。** 当前“同 TX、跨 domain”谓词不足以自动保证同一天。
3. **标签只服务增强配对。** 内部纯 CE 分类头继续保持无 label-dependent margin 的行为。
4. **Style 状态按调用清理并按角色累计。** 不能只读取最后一次前向的计数，因为随后 teacher 或 Fishr 的关闭调用会覆盖它。
5. **核对旧 Style schedule。** 原生参数存在 late-stage 最小强度设置，不能让它把新设计的 0.2 上限悄悄抬高。
6. **私有随机流覆盖整个数据管线。** sampler、DataLoader、donor、Beta 抽样和动作选择都要隔离，避免改变原生采样与 LEO 随机序列。
7. **每个稀疏审计指标使用自己的观测次数。** 梯度范数、夹角等不能除以全部辅助调用数。

## 我建议优先落实的版本

**首个完整候选保留 \(D_L+D_T+D_R\)，加入 B48 关系采样、`time_down` 的弱条件 MixStyle，以及在真实同条件 RX 上计算的方向梯度 Fishr。**

其中优先级是：

1. **先把 B48 关系流和正确的 Fishr 统计做准确。**
2. **把弱 MixStyle 作为 A 开关，完成增强×Fishr 四组对照。**
3. **让 L/T 作用模型承担可靠候选筛选与作用迁移，并避免重复训练相同端点。**
4. **最后依据真实源 RX 的分类间隔尾部，判断 R 和困难采样是否继续提供增益。**

这条路线最有研究价值的地方，是形成一条可检验的训练链：**多解耦提供变化依据，采样提供可比较的真实观测，特征增强扩展训练覆盖，Fishr约束任务统计，身份 CE 和尾部指标检验是否仍保留了有用的发射机信息。** 每一部分都应通过自己的机制对照证明必要性，联合版本的收益再由完整源域选择和冻结后的独立评测确认。
