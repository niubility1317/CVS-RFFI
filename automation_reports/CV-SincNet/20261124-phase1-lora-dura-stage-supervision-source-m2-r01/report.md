# LoRa DURA 第一阶段复谱监督

## 预登记

冻结原坐标恒等版的源 U 诊断显示，在四个切片上第一 MAP 四分之一量均放大了 1 至 8 kHz 私有谱误差，第二 MAP 读出则低于直通。例如 Residual 低城区第一和第二 MAP 的误差中位数分别为直通的 1.27 倍和 0.70 倍。该证据用于定位第一阶段的学习目标。 [逐阶段源诊断](../20261124-phase1-lora-dura-baseband-source-m2-r01/report.md)

新增训练项直接作用于第一 MAP 的半量读出。在实收物理坐标按既有规则混合，转入既有的源／接收配对坐标。一项衡量相对真实源包的分带复谱误差，另一项衡量从同一源 IQ 构造的弱差分经过成对扰动后能否恢复。两项沿用最终阶段的形式，分别使用 0.15 和 0.175 的权重。最终阶段及原粗恢复损失照旧，两个 MAP 阶段在同一优化循环学习。中间层加辅助目标有先例。本轮使用复数物理波形和源 IQ 差分，一次前向计算三个读出，部署仍使用原最终阶段。 [Deeply-Supervised Nets 原论文](https://proceedings.mlr.press/v38/lee15a.html)

原坐标恒等版是同初始化、同参数量、同数据和同优化预算的匹配对照。模型存储参数 614,939，B12，FP32，2,400 步，5,000 个源 U 拟合包。仅用源 U 与独立通用扰动训练，校准沿用原合法源 U clean。训练不接入识别器、TX 真值、源 V、目标包或真实噪声。源 V 及 B1 在冻结后独立评估。两路线目标矩阵在训练前固定。15 项聚焦检查及一次独立 P0/P1 审查通过；真实无目标检查失败、数据契约异常、数值异常或覆盖失败时停止后续阶段。

已核实归档传输、远端编译、真实源冒烟、训练进程及日志增长。训练在 N607 的 GPU 7 上运行，与 GPU 3 的去扫坐标版分别发布。冻结后自动进行登记的双路线目标测试和独立评分。
