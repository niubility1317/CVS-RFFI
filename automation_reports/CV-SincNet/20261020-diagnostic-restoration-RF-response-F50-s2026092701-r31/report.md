本轮新增问题：原三步恢复器是否把观测中可分辨的小幅变化也压掉？在 source V 原1800条上，以 clean x 构造 PA 幅度、PA 相位、IQ 镜像、单延迟残差四种方向，另有同幅随机方向控制。每个方向去除 x 的复数张成空间，再归一化为 ||δ||/||x||=1%/2%。这些是录音 IQ 坐标中的合成方向，不是经辨识的真实 TX 参数导数，不把它们自动称为硬件指纹。

方向用 FP64 构造并两次投影，投影后/原方向能量比须大于1e-8，随后才归一化并转回FP32。常量/近常量产生的退化方向置零且单列无效数，避免放大舍入误差。独立P1审查已定位原FP32绝对阈值问题，常量复IQ/近退化回归复现后已修复。

对每个原缓存场景观测 r，用原实际线性作用 A 构造 r±Aδ，再分别运行同一个原恢复器。主测量是 [R(r+Aδ)−R(r−Aδ)]/2 对 δ 的投影增益、余弦及归一化误差；对称中点偏移另列，用于揭示非线性。两个幅度均预先固定，不能据结果调幅。原噪声样本、实际 AGC/旋转固定，因此这是线性接收作用下的反事实；不声称已重新生成全部非线性物理接收链。

已知 A、原标量模拟器方差 n 和原 SCALE² 下，零 prior 的 soft MAP 用 CG64 计算方向响应，报告自身正规方程残差。这个诊断 oracle 不进入部署。以 δᵀAᵀ(nI)⁻¹Aδ≥9、oracle 方向 NMSE≤0.1、CG 相对残差≤0.001 定义本轮“可观察”记录；它依赖上述有限模型，不能等同真实卫星可辨识性。
