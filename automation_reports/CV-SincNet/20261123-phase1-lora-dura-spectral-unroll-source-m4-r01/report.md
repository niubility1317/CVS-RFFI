# DURA 性能优先研发与两条 LoRa 信道的源域先导

## 历史路线

WiSig 的主要跃升发生在时频粗恢复和软数据一致性阶段。固定 F50 后，R11 将低仰角城区从直通的 30.2994% 提升到 65.2292%。随后 R17 使用三套不共享的时域 U-Net、逐步反投影和每步两次 CG，在对照中将低城区从单次 IQ 恢复的 64.3946% 提高到 67.2167%。这两个参考使用各自报告内的匹配对照。

R38、R44、R46、R65 和 R69 接着降低先验与迭代开销。R69 相对 R65 的低城区提高 0.8655 个百分点，clean 下降 0.2310 个百分点。共享先验试验的六个受损场景均下降。R69 适合作为成熟基线，本轮性能设计回到 R17 的独立先验和三次迭代。原 WiSig 数字见 [R11](../20261019-phase1-restoration-formal-nativeMAP-F50-s2026092701-r11/report.md)、[R17](../20261020-phase1-restoration-unrolled-selfsup-s2026092701-m2-r17/report.md)、[R69](../20261021-phase1-restoration-R65-four-route-s2026092701-m4-r69/report.md)。

## LoRa 两条信道的配对诊断

同一冻结 Tri-set，种子 2026092702，在相同 2,000 个既有源 V 物理包上回放两条信道。每条信道使用自身冻结的 R69 与原门控。分别在去载波的 1–8 kHz 和 9–32 kHz 保持修正 RMS，按配对 clean 方向求解多个候选张成的复数空间。目标读取和 G 参数更新均为零。读出保持门控覆盖，低城区 residual 启用 2,000 包，full 启用 939 包。六景计数分母 12,000，低城区分母 2,000。

| 源域读出 | residual 六景 | residual 低城区 | full 六景 | full 低城区 |
| --- | ---: | ---: | ---: | ---: |
| 直通 | 6,445 | 841 | 6,794 | 846 |
| 门控 R69 半量 | 6,604 | 874 | 6,791 | 855 |
| 聚合供体两方向 | 6,684 | 876 | 6,800 | 858 |
| 同包原始与恢复波形复数空间 | 7,005 | 924 | 6,818 | 865 |
| 同接收机不同包的等维复数空间 | 7,001 | 926 | 6,818 | 863 |
| 直接取配对 clean 方向 | 7,172 | 956 | 6,829 | 869 |

相对 R69，同包复数空间的六景净差 95% 配对区间为 residual +339 至 +465 次、full +14 至 +41 次。换成同接收机不同包得到相近的识别变化。诊断可支持扩大复数方向空间；当前供体对照对同包内容的专属识别增益支持较弱。所有扩展方向由配对 clean 参与求解，仅用于诊断。Full 的低覆盖会压缩该读出的全量净差，该 R69 对照与正式最优复响应半量分别保留。

## 首轮实现与预登记

`SpectralUnroll` 保留同合同 R17 的粗恢复、冻结的作用估计、三步独立时域先验及每步两次 CG。每步增加独立复频谱 U-Net，以收到的 IQ 和当前反投影残差形成复系数修正，再回到时域参与当步软一致性求解。谱分支零初始化。LoRa 使用固定参考 chirp 表示，WiSig 接口默认原始 IQ 坐标。网络推理只使用当前 IQ。训练同时最小化整波形误差和分频带复数重建误差，弱频段分母设能量下限。

LoRa 先导固定 full/residual 两条路线，每条从自身相同物理合同的 R17 权重开始，比较纯时域三步续训和时频三步续训。四行每行 600 步、batch 64、AdamW 6e-5、种子 2026092702。两路线独立训练权重。候选与时域控制使用相同的波形损失、采样顺序、clean 恒等配比和训练预算。粗恢复与作用估计冻结。权重冻结后，在先前配对诊断的固定子集上取每源接收机 100 包，共 500 包。先生成并保存 clean 与六景的全矩阵预测，再读取 V 真值。报告相对同路线门控 R69、未续训 R17、时域续训，以及最后一项将新架构的修正 RMS 匹配 R69 的对照。

运行 ID 为 `20261123-phase1-lora-dura-spectral-unroll-source-m4-r01`。普通账户 N607 使用现有 LoRa 运行环境和独立只写一次的 release/run。入口 `python -m experiments.pamf_lora_main.spectral_unroll publish`，读取现有 source/残差父版回执，GPU 从 3、6、2、0、4、1、5 按容量选取，同 run 单卡单 worker，总并发不超过 4。两条真实源 smoke 先核对各阶段梯度。数据合同、梯度、非有限、训练或评分发生错误时，停止继续派发并保存证据。预期交付两条 smoke、四份源权重和训练记录、两组固定源预测和评分。

冻结评估的口径保持相同 F、相同包和场景。后续正式 LoRa 复核分别对比各自最强既有 DURA 与直通，先看六景均值、低城区和 clean 正确数，并逐接收机报告净纠错。源先导仅用于判断当前复频谱设计是否值得扩大验证。WiSig 复测使用已登记同合同的 R17/F 和原 residual 流程。WiSig full practical 需另核查原始采集窗口与模拟前后同步坐标，保持配对物理 ID。四格分别报告，模型结构可共用，各自的源训练权重与信道合同分别保存。

## 首轮结果

发布代码 `b4fab96993cd84b05789134ee383627d2f661f03`。两条真实源 smoke 通过，四行均完成 600 步，独立重载并完成七景源预测及评分。Clean 六种读出均为 388/500，所有 clean 波形逐包旁路。两路线分别计算，六景分母 3,000，低城区分母 500。

| 读出 | Full 六景正确数 | Full 低城区 | Residual 六景正确数 | Residual 低城区 |
| --- | ---: | ---: | ---: | ---: |
| 直通 | 1743 | 217 | 1690 | 216 |
| 门控 R69 半量 | 1738 | 220 | 1718 | 223 |
| 门控 R17 半量 | 1740 | 221 | 1744 | 224 |
| 纯时域续训 | 1742 | 219 | 1469 | 186 |
| 时频续训 | 1735 | 216 | 1594 | 210 |
| 时频续训，匹配 R69 修正 RMS | 1734 | 216 | 1650 | 221 |

Full 的时频续训六景相对 R69 净差为 −3，95% 配对重抽样区间 −12 至 +7。Residual 为 −124，区间 −174 至 −76。匹配 R69 修正 RMS 后，residual 净差缩至 −68，区间 −109 至 −29。该干预直接表明部分损失随修正剂量变化，剩余差距无法用总 RMS 解释。相同时域续训在 residual 低于未改 R17 275 个六景正确判断，频谱容量仅部分挽回这项训练损伤。

两路线时频版最后一个训练批次均取得低于时域对照的配对损失，冻结识别改善未随该损失变化。第一轮可证伪的机制是「把先验整体移到低能量频段配对目标」。后续优先保留成熟时域展开方向，单独训练残差分支，在与最终读出相同的观测坐标中学习修正，再分离剂量和方向的贡献。初版保留源诊断，LoRa 未进入目标验证。

WiSig 原有 full/residual 1,800 个源 V 的物理 ID、clean 和 RX/day 对齐已核实，真实 24 包两路 smoke 通过。WiSig 固定混合训练及双路独立读出另登记在 [WiSig 双路线先导](../20261123-phase1-wisig-dura-spectral-unroll-source-m2-r01/report.md)。
