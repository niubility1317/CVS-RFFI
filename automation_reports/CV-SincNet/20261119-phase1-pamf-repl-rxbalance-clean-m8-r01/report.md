# Tri 接收机正对分布自适应试验

**VERIFIED / ANALYZED**。发布提交 `2a9eb3650131a477b32da5f732fbcaa112683c75`。8/8 真实 E20 冒烟及启动核验通过，24 项训练、预测和独立评分任务全部完成。见 [clean 结果与训练诊断](analysis.md)。

设置级降低全局 U 剂量的 E50 校准未保住原 Tri 的三种子平均领先幅度。本轮固定原 Tri 权重 6、阈值 0.95、伪标签 CE、配对 KL、其他 U 损失及原梯度保护。唯一干预是同类跨 RX 正对的概率分配。[全局剂量校准](../20261119-phase1-pamf-repl-sourceadapt-calibration-clean-m12-r01/analysis.md)

对已接受伪标签的每个锚点，原分布平均分配给所有同伪类跨 RX 正对。新分布先给该锚点实际覆盖的各其他源 RX 平均分配，再在每个 RX 的合法正对内均分。训练按 0.5 比例混合原分布与均衡分布。若只有一个可用的其他 RX 或原正对已经平衡，直接使用原算式。正负对集合、归一化范围及标量损失系数保持原 Tri。报告每步实际发生调整的锚点比例和分布总变差。

接收机划分一、接收机划分二、5% 标注和三源各两个候选。分别只对浅中层对比和融合对比启用该机制。全部使用种子 `2026092702`、原同设置同种子 E20、相同日程 E21 至 E50。冻结后执行三个 clean 子集，独立 truth-last，主指标为 `cross_rx + cross_both`。与原 Tri 和普通 PL 逐物理 ID 配对。已在历史实验中见过这些目标设置，本轮用于探索性方法归因。
