# WiSig 实收作用与两阶段观测求解

[预登记矩阵](experiment.json) · [运行事件](events.jsonl)

## 接收端输入与求解

输入为 WiSig Main split 的 25 MS/s、256 点实收复 IQ。使用可见 L-STF 重复、公开 L-STF/L-LTF 及 ±40 点时标候选。采用同一包幅度尺度和可见前导两段最小二乘增益补齐边界，另保留当前窗口实收掩码。边界样点进入学习先验，观测似然项只计算实收范围。

| 接收信息 | 测量与使用 | 误差 |
| --- | --- | --- |
| 有效时标、相对频偏、短长前导响应 | 当前窗采满后比较重复、可见协议模板及观测能量，回归位置由源 IQ 重建学习 | 短训练周期混叠、较短的长训练可见段、CFO/时延与硬件耦合，以及超出候选范围的移位 |
| 估计作用 \(\widehat A\) | 只从时标校正后的实收 IQ、公开复波形、预测失配及掩码等特征，估计逐样点主复响应、共轭项与两个相邻延时项 | 有限量训练段中，真实传播、截窗和地面接收硬件效应可能混合。逐点输出是有效相对作用。 |
| 有效方差 \(\widehat\sigma^2\) | 以 20 点重复的相位补偿差分功率为底，由当前 IQ 学习有界的局部校正 | 导频差分包含估计失配和干扰，模型拟合的是接收残差功率。 |
| 旁路 | 接收候选长训练峰相对零移位拟合的正增量，加上 6 个短训练块邻对的归一化差分中位数。两量之一超过固定门限才触发。 | 信道也可能保留高前导相似性。前导偶发异常可能增加门误触发，故单列各视图触发数及 clean。 |

两臂估计相同结构的实线性观测作用。第 \(t\) 点为主复增益乘 \(x_t\)、镜像复增益乘 \(\overline{x_t}\)，加上作用于 \(x_{t-1},x_{t+3}\) 的两个复抽头，窗外为零。每个学习阶段根据实收、掩码、当前状态和反投影残差产生先验 \(p\)，再近似解 \(\lVert W^{1/2}(y-\widehat A x)\rVert^2+\lambda\lVert x-p\rVert^2\)。\(W\) 来自可见掩码和估计有效方差。逐点臂在同一个已知实伴随残差上应用每点实 2×2 对角块的逆。耦合臂以同一个逆作预条件器，对含样点间耦合的正规方程执行两步 PCG。两阶段的观测与学习先验在同一循环内训练。

同权重读出包括关闭样点耦合、把作用换成恒等算子、把求解权重的有效方差固定。恒等作用也改变先验的作用特征和反投影残差；固定方差只影响求解，学习先验仍收到估计方差。两路线共用同一模型和旁路，门限只由同一组 4,096 个源 U 的两个接收量最大值乘 1.02 加 `1e-6`。门限与模型权重分开记录。

Deep ADMM-Net 从已给的 MRI 测量算子出发学习迭代重建，原 R69 对同包估计作用执行重复先验与求解，但历史训练包含模拟作用和噪声监督。本轮比较接收端估计作用下的两种解算方式，训练只用源实测 IQ 和独立通用扰动，不读取模拟参数、目标、TX 或识别器。冻结识别任务及合法输入边界保持独立。 [Deep ADMM-Net 原论文](https://proceedings.neurips.cc/paper/2016/hash/1679091c5a880faf6fb5e6087eb1b2dc-Abstract.html) · [原冻结 DURA/R69 机制](../../../docs/DURA_V1.md) · [WiSig 发布方实现](https://github.com/WiSig-dataset/wisig-process-raw/blob/master/matlab_equalization/equalize_channel.m)

## 匹配训练与冻结评测

每臂 40,238 参数、40,000 个 AdamW 步、batch 24。52,092 个合法源 U 拟合、4,096 个独立源 U 旁路校准、512 个留出。同一循环产生两份独立通用扰动，包含时标截窗、有色噪声、短回波、平滑复增益和共轭混合，保留部分源 IQ 身份映射。损失作用于真实源波形的粗细恢复，以及把源波形经过估计作用映射到当前接收观测的误差。方差损失使用停梯度的接收残差功率。一致性和弱复谱损失同时优化，不使用逐包真实参数作训练目标。

终步冻结后使用 Main split Tri-SIG-TIME SSL seed 2026092701。两路线各同序 1,800 个源 V 包、七景、17 个读出，匹配直通与原 R69。两路完整预测固定后独立 CPU truth-last 评分。预登记部署读出为带门和全量耦合，各自需要两路线分别严格超过原 R69 六景并保持 clean。只有通过的冻结读出可进入正式扩种子矩阵。

## 源 U 旁路敏感度

旁路的两个输入量独立于恢复权重，因此可在训练期间单独核对。通过 4,096 个校准源 U 得到接收阈值 0.3770815、1.1984075，在 512 个独立源 U 留出评测未改波形、两档反射边界移位、正弦非线性相位和通用混合扰动。所有固定输入和校准规则均保持。这个检查不读识别器、训练权重、源 V 或目标。 [源 U 旁路复算](../../../tools/wisig_received_guard_probe.py)

| 固定源 U 读出 | 触发 / 512 | 来自长训练拟合增量 | 来自短训练差分 |
| --- | ---: | ---: | ---: |
| 未添加扰动 | 0 | 0 | 0 |
| 反射边界移位 12 点 | 65 | 65 | 0 |
| 反射边界移位 28 点 | 2 | 2 | 0 |
| 非线性相位 | 0 | 0 | 0 |
| 通用混合扰动 | 183 | 183 | 0 |

原波形保持逐点旁路，较大的反射移位和纯相位扰动在此探针中也常走旁路。带门和全量读出都保留在冻结评测矩阵中，以区分门控覆盖与恢复器本身的识别收益。

## 接收作用、对齐与复波形

两路线逐包隔离复核保留同一原地面接收参考和实收窗掩码。Full 低城区中，带估计作用的正向残差功率中位数为 0.2508，单位作用为 1.9983，所估有效方差为 0.9106。Residual 同口径为 0.2506、1.9983、0.9100。这个正向拟合收益与同权恒等作用挽回识别的方向相反。低城区的估计时标距参考至多两点的有 363/1,800 包，两路线一致。Full 低城区重叠区域复 NMSE 的中位数为直通 2.0046、原 R69 0.0194、耦合全量 0.3177、耦合带门 1.7955。实收短训练区的复相位一致性分别为 0.0130、0.9949、0.9219、0.1324。耦合全量相对直通改善这些波形指标，冻结识别仍显著退化。保留逐景、逐 RX、实收与填充区域的审计，以及所有负结果。 [独立波形审计](../../../tools/wisig_repeat_drift_fidelity.py)
