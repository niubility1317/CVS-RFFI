# 源域机制诊断后的判断与下一步

本轮已完成三个种子、原 E20 与固定 CE20 共六个模型的源域诊断。身份零更新，无目标访问。新证据支持调整监督与扰动的定义，不能据此宣称已经提高测试准确率，84% 目标保持未完成。

## 已核实的发现

**第一，当前 Fishr 与身份 CE 的局部方向联系较弱。** 完整身份参数上，Fishr 与 CE 的平均 cosine 在 P0 为 0.0284，在 CE20 为 0.0552；浅层组分别为 0.0750、0.0897。它并非没有梯度，也没有表现为平均意义上的强烈反向。统计对齐目标与身份 CE 目标不同，方向接近垂直可能保留源 CE，也可能没有触及身份边界；单凭此结果不能断言 Fishr 无效。下一步需要直接检查主身份判别器的局部敏感度，不能把辅助读出头的统计差异自动当作有效身份信息。

**第二，风格增量与主 CE 有局部冲突，但风格与 Fishr 并未呈现明显平均冲突。** 排除“未执行扰动”的数值控制后，P0 的风格增量与 CE 平均 cosine 在 −0.3503 至 −0.2164，CE20 在 −0.3705 至 −0.1209；相对 Fishr 的平均 cosine 则约 −0.0194 至 0.0133。这不支持把组合收益有限直接解释为“Fishr 和 MixStyle 互相抵消”。增强可能用源拟合损失换取不变性，CE 方向冲突本身也不等于应删除增强，尤其不能据此直接采用投影梯度或更大权重。

**第三，旧日志中的改判差包含明显 dropout 成分。** 在固定三天／三种子的 1,080 个样本出现位置中，P0 独立 dropout 改判 42 次，同 mask 的强度 1.0 浅层风格改判 5 次、中层 16 次、双层 20 次。CE20 分别为 dropout 10 次、风格 2／6／7 次。它们是特定固定局部样本的实测对照，不是整个源池的估计。此前不同 dropout 前向的改判不能直接记为风格机制创造的新身份难例。

**第四，大梯度比值不代表大量新难例。** 在真正发生扰动的行中，风格增量／CE 梯度范数比的中位数，P0 约 0.257 至 0.802，CE20 约 0.341 至 1.559。CE20 的最大值 66.98 对应 CE 梯度范数仅 0.005852、风格增量范数 0.391967；分母很小会拉高比值。报告保留中位数、最大值与原始范数，不使用这个极值设定新损失权重。

**第五，必须区分真实扰动与数值残差。** 每个模型 648 个风格单元中有 292 个未实际扰动。它们的 logits 和 CE 差严格为零，但重复 backward 产生约 1e-7 相对范数的差异。归一化后这些微量残差也有 cosine，却没有风格方向含义。原始数据全部保留；分析按实际 changed_packets 分层，不重新训练、不改变采样、不用后验数值阈值挑选结果。

## 下一轮机制应回答什么

下一步保留“浅层＋中层”的研究范围，把重点从更大正则移到更直接的身份监督。以下是源证据形成的待验证设计，不是已发布训练或已证实有效的方法。

1. **用主身份判别器定义多层敏感度。** 在浅、中层通道上引入仅用于求导的单位缩放变量 a，前向 a=1 不改变模型。对于合法 L，定义身份 margin：

   m_i = logit_y − logsumexp(logit_other)，s_i^(层) = ∂m_i/∂a_i^(层)。

   CE = softplus(−m)，因此 ∂CE/∂m = p_y−1。源域高置信正确样本会使 CE 梯度很小；margin 敏感度可作为不受该概率因子直接压缩的候选统计。它仍然需要反传、有限样本修正和真实成本测量，不等于天然更好的解耦。先以同 TX/day 的源 RX 条件分组核查敏感度，再定义层统计一致目标，避免依赖尚未充分解释主身份边界的独立线性头。

2. **让风格网络提供可核验的身份难例。** 保留同 TX/day、跨 RX、不同 PID 的合法供体与凸组合范围，以固定数量候选的主身份损失／margin 作为困难度依据，设置随机候选和同预算额外前向对照。搜索和训练要使用可控随机数，防止选择到的只是 dropout 噪声。真实类别保持不代表混合特征必然物理可实现，必须记录原始 IQ 供体关系与源身份变化，不能把任意特征外推称作真实信道。

3. **把早期塑形和成熟续训作为独立因素。** 用户允许 scratch20 与 E20＋20；后续固定矩阵应明确区分二者，各自有同预算 CE/半监督对照。当前 P0/CE20 只是两个成熟 checkpoint，不能直接证明从头训练优于续训。若研究未知 RX 代理，必须从初始化开始隔离该 RX；原 E20 已见全部源 RX，不能伪装成留一 RX 未知验证。

未标签源 U 仍按已有合法半监督路径进入身份学习，不能把 L 的诊断扩展成解封 U 真值。新的机制方案、权重、调度、训练行及测试范围需在运行前固定；后续代码应首先证明前向等价、梯度到达浅中层、源角色不越界及费用可承受，再发布三种子实验。不能把本轮局部 gradient cosine 或增强准确率当作保证达到 84% 的依据。

完整表、全部种子、数值控制及成本见 [分析报告](analysis.md)。当前批次已结束，无训练进程遗留；下一步从上述源机制问题继续，保留原 E20 来源与追加 20 轮预算，不按历史目标分数选择性重跑。
