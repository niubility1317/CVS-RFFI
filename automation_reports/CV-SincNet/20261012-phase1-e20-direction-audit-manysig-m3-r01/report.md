# E20 源域浅中层梯度方向与受控风格诊断

本轮先解决源证据缺口：已有日志证实 Fishr 梯度非零、风格特征实际变化，但没有隔离 dropout，梯度范数也不能说明方向是否有用。诊断不创建身份候选、不选择模型或增强强度，不测试目标域。

固定模型为每个种子的原生纯 CE＋旧门控＋cos E20（P0），以及固定纯 CE 续训 20 轮（CE20）。种子为 2026092701/02/03，两个模型按对照角色全部执行，来源不依赖测试排名。CE20 使用 20261012-phase1-e20-cross-style-manysig-m33-r01 的 CE 行；继承契约及源冻结必须核实。

仅 L_s 的 6,300 个真实物理包可进入前向/统计。U 不加载，源 V 随旧 source_cache 反序列化后丢弃，不前向、不反传、不更新状态；不接入 target loader。每个模型新建浅中层读出头，在冻结 L 特征上预热 200 步；固定 L 校准 12 对批次。头预热可以更新辅助头，身份始终零更新，头与优化器不作为模型产物保存。

每个模型固定 36 对独立批，三天各 12 对，每批同一天 6 TX×5 RX×2 包＝60，A/B 间允许重叠。完整模型 autograd 测 CE、两层 Fishr 单项/组合及风格 CE 的实际梯度；覆盖全部身份参数和既有浅中层组，辅助头不计入身份参数。固定 Fishr 系数来自初始 L 校准，不通过诊断挑选。

对同一 A+B，分别在浅层 time_down、中层 t2.pool、双层使用固定强度 0.3 和 1.0，p=0.5、Beta(0.1,0.1)，合法 L 供体同 TX/day、跨 RX、不同物理 ID。每层随机供体跨强度配对。主诊断在 eval 模式进行，消除 dropout；额外每模型每 day 一组受控训练 dropout，冻结具有持久统计的模块，对比同随机数无扰动重放、同随机数风格和独立随机数无扰动。

指标包括 clean/styled CE、准确率、margin、正确修复/破坏、KL、实际 donor/扰动覆盖，CE/Fishr/style 梯度范数及夹角。风格独有梯度明确为 ∇(CE_style−CE_clean)，不得把 CE_style 与 CE_clean 本身的正相关解释为风格有效。零范数时 cosine 为 null。记录全模型 state_dict、参数 .grad、训练标志与 CPU/CUDA RNG 不变；所有临时 hook 必须移除。

固定总规模为 3 个 worker、6 个模型、216 对批次、1,296 个主风格诊断单元、18 组 dropout 对照。训练与校准源读出、实际诊断前向/读出、耗时/显存单列；三种子全部保留，不根据结果追加强度扫描。源 RX 均已被模型见过，这不是未知 RX 验证；梯度夹角仅是当前源批的局部证据，也不能独自证明目标性能。

输出为不可覆盖 source-only run 的配置、来源、头预热/校准、诊断统计及完整文本日志。不保存原始 IQ、特征图或新 checkpoint。不改旧实验、不重测目标、不依据目标评分研发。完成本地聚焦验证与一次 P0/P1 审查、Git 提交并核实远端后发布；最多每 GPU 3 个总进程，唯一 owner 为 design.py 定义值。


本地验证：完整原生网络 CUDA 36 对×6 变体、3 组 dropout、369 次前向／39,960 次 L 读出通过。最终 CPU 核心检查通过；早期 CUDA 小模型检查的版本范围单列。初次本地 helper 将已为 1/2/3 的合成日期误加 1，被合法日期检查拒绝；修正 helper 后通过，正式源数据与实现未作放宽。独立 P0/P1 审查 PASS，无发现。


三种子、六模型源诊断完整完成：216 对真实梯度、1296 个 eval 风格单元、18 组 dropout 控制；身份零更新，无新测试集成绩。实际源读出共286200（另加preflight6）。完整结果见 [分析](analysis.md)，目标84%保持未完成。

源证据归纳与下一步待验证机制见 [reflection.md](reflection.md)。未扰动行的浮点梯度残差单列，所有原始记录保留；实际扰动方向与零扰动数值控制不混合。
