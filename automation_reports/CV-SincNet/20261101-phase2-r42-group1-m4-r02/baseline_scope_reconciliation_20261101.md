# R42 与双侧 DURA 原版结果的统计范围核对

本说明只读取已完成的评分，不新增预测或评分，不改变实验队列。原版双侧 DURA 指 support DURA、query 仅 DURA（S1Q1），基座为 Tri-SIG-TIME SSL。

用户引用的完整原版报告与上一份 R42 汇总中的原版数据一致。按模型种子、物理池、episode、接收机、阶段、K、N 逐条连接，主工作点 672 条及先导 16 条的 query 数量、旧类宏准确率、新类宏准确率、宏 H 均无差异。主工作点 672 条的 split_id 也一致；先导缓存未保存 split_id，此项未核验。

数值差异来自统计范围：原版完整 K/N 曲线每格为 MIX01 的 84 单元均值；R42 全 K/N 先导每格仅 P01/MIX01/RX1-1/seed2026092701 的一个单元。上一份汇总的“原版”列在先导表内也是该单单元的配对原版值。应明确标为“配对原版（单单元）”，不能当作原版完整均值。
