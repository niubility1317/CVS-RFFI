# LoRa W24 低城区扣噪方向与幅度析因

固定 r02 已从零训练 24,000 步的精确扣噪组和原 E104 默认头。复用原生 Full 的同一批 300 个源 V 包、五台源接收机、相同物理顺序与信道实现。各景先将整段 DURA 的实际编辑用 0.5 半量回写，再经 W24 原生中心投影及原生边缘。参考为同一个信道实现的加噪前 IQ。

将中心和边缘分开，固定六条读出。直通和冻结半量为基准。四条干预分别为保留学得方向换真实范数、保留学得范数换精确减噪方向、两者都换、保留方向取最优非负投影幅度。Clean 上四条干预保留半量原输出。各读出按自身中心 RMS 标准化。两条全真值相关的历史 GPU 端点用于记录与本次 CPU 的预测差异。

N607 CPU 单预测进程，两推理线程和两重放 worker。先在合法源 U 跑真实 checkpoint 冒烟并确认 W24 前端与正式入口相等。全部七景预测封存后，独立 CPU 过程只连接源 V 标签。训练、选模、目标 IQ 及目标真值读取均为 0。正式 Full 测试按原安排继续。 [实验登记](experiment.json) · [幅度和方向的前置波形测量](../20261127-phase1-lora-w24-native-practical-supervision-s2026112991-r02/report.md)

在现有半量造成的 98 次误改中，固定幅度只换真实方向可以挽回 83 次，继续替换幅度的净变化为 +3。五台源接收机均出现该效果，各自挽回 14/21 至 13/14。对直通与半量都错的低城区包，换方向挽回 50 包，再换幅度净多挽回 42 包。五台源接收机在这个分组中追加幅度均有正净变化，范围 +5 至 +14 包。固定幅度方向分支可以独立验证原有误改是否可减少。要处理低城区两路都错的困难包，后续还需独立核对方向改善后修正幅度的估计误差。两个分组均为源域事后诊断，未改变在训模型、原晋级规则或正式测试矩阵。

下一轮源配对训练优先在实际 W24 中心与边缘约束减噪方向，并保留现有幅度规则作为匹配对照。宜直接度量归一化后弱复谱与相位误差是否减少，同时确认 clean 保持。该结论来自源域隔离诊断，原正式 Full 任务和冻结权重按原计划继续。原始决策、评分、`factor-attribution.json` 的逐接收机和 TX 配对结果及运行日志已回收。
