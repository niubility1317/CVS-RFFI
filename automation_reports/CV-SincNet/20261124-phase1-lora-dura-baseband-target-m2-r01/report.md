# LoRa DURA 去扫坐标版目标测试

## 预登记

采用固定 2,400 步的新权重和原源 clean 门限。半量为首要读出，另固定四分之一量。每个剂量与同一物理包上已冻结的原坐标恒等版同剂量配对，同时报告原匹配半量 DURA 和直通。两条路线都使用同一模型和推理规则。 [训练定义](../20261124-phase1-lora-dura-baseband-source-m2-r01/report.md)

冻结 Tri-set 2026092702、15 台未见接收机、30,000 个相同物理包、Full 和 Residual 各七景。每路 210 份预测全部冻结并独立核对后，评分侧才读取目标真值。报告六景、低强度城区、clean、逐 RX、同包纠错改错和区间。正式验收以目标结果为准。
