# 源域理想相位的可预测性

从固定 DURA 的合法源上下文中使用 32768 条物理记录，每条三个模拟视图。按源物理记录索引取模，24579 条用于拟合、8189 条留出；同一记录的三个视图不跨两侧。训练集 clean 配对仅用于生成拟合目标和评估误差，TX 标签始终隐藏；没有读取 F、V 或目标数据。留出集对本次 ridge 拟合是记录互斥的，但固定 DURA 或其他历史模型可能见过这些记录，不能称为独立模型盲测。

预测目标是源 clean 参考下的受限最优整体相位。对三种预先固定的可观测特征，用训练侧统计标准化并拟合 ridge；不保存部署模型。留出侧共 8189 条物理记录、24567 个视图。以下相位 MSE 与波形 NMSE 均为留出视图的平均值；变化百分比相对零相位，正值表示误差增大。

| 留出预测规则 | 相位 MSE | 相位 MSE 变化 | 波形 NMSE | 波形 NMSE 变化 |
| --- | ---: | ---: | ---: | ---: |
| 零相位，即原 DURA | 0.00492567 | 0.000% | 0.02287923 | 0.000% |
| 训练侧常数均值 | 0.00491854 | −0.145% | 0.02287387 | −0.023% |
| 均值与噪声特征 | 0.00476383 | −3.286% | 0.02289350 | +0.062% |
| 再加二阶／四阶复矩 | 0.00475055 | −3.555% | 0.02289605 | +0.074% |
| 再加输入间相对相关 | 0.00472934 | −3.986% | 0.02288950 | +0.045% |

以 clean 逐条求得的理想相位对应 NMSE 为 0.02063528，但 clean 在部署时不可得。三个线性特征预测器的相位 MSE 较零相位下降约 3.29% 至 3.99%，其平均波形 NMSE 却均略高于原 DURA。训练侧常数只带来约 0.023% 的波形误差下降；这既不是身份识别收益，也不足以作为部署方案。

这是一种固定 ridge 模型、一个源记录划分及三种预定特征的诊断，不能推出非线性模型无法预测相位，也不能把理想角解释为真实身份指纹。三个视图来自同一批物理记录，24567 个视图不能视为独立物理样本。波形和相位误差不代替 Tri-SIG-TIME SSL 七景识别评分；该诊断不回流调整当前已冻结候选。

真实 DURA checkpoint 和 32 条源上下文重放通过，完成产物的权限计数、留出视图数和各方法对照已复核。r01 在远端 NumPy/PyTorch 布尔转换处于拟合前失败；r02 仅修复类型转换，划分与矩阵不变。五项原有检查、一项新增掩码检查、一次独立审查及一次针对性复核通过。
