在此前探索过的 672 条源 IQ 上，固定训练后的辅助编码器、同初始化随机编码器、DURA 与候选恢复器；候选拟合 ID 与这组源记录互斥，但原 DURA 可能见过同源域。按公共接收机和场景分成 21 组，每组从 clean 表示中寻找相同物理记录。未读取 TX 标签、F 权重或输出、V 或目标，不更新模型。

下面汇总六个受损场景的 576 条源记录，按各组记录数加权；“同记录匹配率”是组内 clean 波形检索 top-1，并非 TX 识别率。

训练后编码器对受损源输入的同记录匹配高于随机编码器；但在 DURA 输出上，随机编码器的匹配率反而高于训练后编码器。因此不能把该结果解释成训练后的编码器在所有视图均更优。候选相对 DURA 的训练后编码器组内匹配率从 79.17% 到 80.38%，仅反映这组源记录，不证明识别正收益或统计显著。
