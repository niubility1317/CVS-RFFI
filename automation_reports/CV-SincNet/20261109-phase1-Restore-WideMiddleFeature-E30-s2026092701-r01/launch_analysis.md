# 宽时频恢复器：源 F0 中层特征保护

本候选已预登记，实际训练与正式成绩以远端产物为准。方法是独立的 F-guided 恢复器，不替换默认 DURA v1。代码提交 5503fa43e499db5c6fb1e9dcb63520e81769d333。

## 设计和对照

复用匹配宽时频版本的架构、从零初始化、源先验、样本顺序、物理监督和源 IQ／STFT／最终 F0 特征／响应损失；新增冻结 F0 的中层 t2.pool 特征保护。该模型完整参数量与对照同为 6170283，训练从零单阶段 30 轮、7410 次更新，不读取历史 G 权重或优化器。

对每条训练源记录，比较恢复 IQ 和同条 clean IQ 的 F0 中层图；中层图均方误差除以 clean 图均方能量（下限 1e-8），基准权重为 0.01。以该项对恢复 IQ 的输入梯度范数为对象，逐样本将其限制在配对 IQ NMSE 输入梯度范数的 0.5 倍以内；比例系数停止梯度。此上限不等于 G 参数梯度上限，最终与其他损失合并后仍执行原分支梯度裁剪。训练日志记录中层损失、上限系数与触发比例。

中层结果只在源 L_s/U_s 模拟配对上参与训练，F0 冻结；不读取 TX 标签、F 分类 logits 或交叉熵作为 G 损失，也不使用源 V/OE 或目标数据。原训练器启动 smoke 会调用冻结 F0 默认头检查接口，但该输出不用于 G 的损失和更新。中层 clean 参考只用于源训练，部署恢复器输入仍为单条受损 IQ 与固定源先验。

依据是 28 条源样本的[多层输入梯度诊断](../20261109-diagnostic-Restore-MultilevelFGradient-sourceLU-s2026092701-r01/analysis.md)，该小面板只提供机制线索；0.01 和 0.5 是固定研发设定，不声称最优或已经证明能提升识别。与宽时频对照使用不同 GPU 时，数值轨迹可能不同，不能把所有结果差异归因于损失本身。

## 固定验证与计算成本

以相同地面 Tri-SIG-TIME SSL 冻结默认头评估 Main 两总体共 168000 条，每总体都计算 clean 与六种 practical。先固定本行全部预测，再独立 truth-last 评分；六景各须至少 140345 条正确（83.538690%），两总体 clean 分别不低于 111019/126000 与 34366/42000。逐景、逐 TX/RX/day 及配对纠错与损伤均单独报告；不根据目标结果选 checkpoint 或选择性补跑。

训练每条源记录两次后验和五次 F0 特征前向，比宽时频对照多一次 clean F0 前向，另计算中层输入梯度；实际训练时间和显存以运行记录为准。恢复器部署路径仍为一次后验与细节网络，本项不增加恢复器推理时的 F0 调用；完整识别链仍运行原 F0。
