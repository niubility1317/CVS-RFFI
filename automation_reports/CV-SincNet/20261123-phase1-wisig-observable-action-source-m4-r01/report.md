# WiSig 实收 IQ 拟合前向算子的源域消融

使用同一个实收窗口估计观测作用，使粗恢复和细化仍在原接收 IQ 坐标。比较匹配的恒等一致性和拟合算子一致性，沿用冻结 Tri-SIG-TIME SSL 2026092701、原 R69 和两条路线各 1,800 个同包源 V，覆盖 clean 与六景 practical。两组各有无门和相同门限读出。

## 观测模型

以当前 256 点的短前导重复估计频偏和有效扰动，并用估计旋转和实收 RMS 建立内部复数坐标。两级网络使用可观测质量、位置、归一 IQ 和粗恢复。粗结果与原观测的有界互相关给出整数延迟候选。用偶数索引拟合含五抽头、线性幅相漂移代理与共轭镜像项的短复数作用。位移超出 256 点窗口的部分补零。未用于拟合的奇数索引给出有效残差方差，可包含噪声、干扰和粗恢复失配，两组都使用同一路径计算这一置信度。恒等组的校正使用 IQ 与候选间的差。拟合组用广义线性作用回放候选，再把残差通过其真实伴随投回 IQ，以范数界和残差方差限制校正。正则化和展开步骤留在同一训练循环。输出回到原包的相位和幅度坐标。

以 51,836 个源 U IQ 作为合法拟合池，768 个作波形留出、4,096 个作门限校准。两组各 1,200 步、batch 48、相同参数量和初始化，使用独立通用的时移、回波、幅相和着色扰动。实测源弱差异和原波形共享一次通用扰动，另抽独立扰动约束同包一致性。只给网络受扰波形和源 IQ 目标，不提供合成参数、逐点噪声或实际 practical 模拟状态。两个 q=0.999 门限分开从校准 U 的前导转换分差和重复差分扰动求出，超过任一门限则允许编辑。两个模型与两路实用输入共用门限，训练与部署均从同一当前观测计算前向作用。

MoDL 通过学习先验和已给定的观测算子执行数据一致性。本试验的观测作用来自受扰包与粗恢复的拟合。可分离最小二乘通过求解线性子问题降低拟合复杂度，此处固定边界、整数移位与短算子结构，只验证其在射频设备识别上的增量。 [MoDL 原论文](https://arxiv.org/abs/1712.02862) · [可分离非线性最小二乘原论文](https://doi.org/10.1137/0710036)

## 固定执行与门槛

N607 首步用源 U 做实际冻结识别器和原 R69 的无目标 smoke，之后独立校准、匹配拟合、B1 计时和双路线预测。两路七景预测全部冻结后才通过独立 CPU scorer 连接源 V TX 真值。保留各模式准确率、clean 正确数、逐 RX 纠错、改错及配对区间。波形诊断使用配对源 clean，在原基带以 0–3.125、3.125–6.25 和 6.25–12.5 MHz 绝对频带检查幅度误差和复相关实部。该诊断只发生在冻结预测。只有一个明确固定读出同时在两路保持 clean，六景超过原 R69 并有配对证据支持时，才进入后续扩大验证。契约、非有限值、预测闭合和冻结证据失败时停止后续派发。没有目标访问。

七项本地聚焦测试与独立 P0/P1 审查通过。执行身份、路径和预算见同目录实验登记。

## 隔离前向诊断

固定 128 个无标签源 U 留出包，用独立种子 2026112329 验证单一整体相位和通用整点移位、局部复滤波与加性扰动两组输入。只在本独立诊断用已知作用核对估计，未读取识别器、源 V 或目标数据。对混合扰动，拟合组 92/128 个包的延迟估计距施加的延迟 2 点以内，对照组为 65/128。全量 IQ 重建的 NMSE 中位数从 0.5042 降至 0.4573。相位单扰动从 0.3861 降至 0.3362。两组在 clean 上的无门输出均有非零波形误差。这一诊断验证了算子在已知通用作用下的行为。 [隔离诊断数据](action_diagnostic.json) · [复现代码](action_diagnostic.py)
