# E20 独立种子教师互补性：固定源域诊断

本次检验学生自身伪标签是否缺少独立纠错信息。复用已保存的三个原生 E20 模型在完整 L/V 上的预测，只分析 source_predictions.pt 的 parent 部分；不分析续训终点，不读取目标结果或 U 身份真值。无新训练、无新模型前向、无 GPU 占用。

固定学生种子为 2026092701、2026092702、2026092703。每个学生的 LOO2 教师是另外两个种子的概率均值；ALL3 是三个模型的均匀概率均值，只算一个教师，不能称为三个独立重复。各 E20 使用同一合法物理数据契约、原始从零训练及固定 final20 来源，选择全体固定种子，不按历史目标成绩挑选或加权。

报告 L6300/V27000 的准确率、NLL、15 个等宽置信分箱 ECE、RX/day/TX 分层和每学生的纠错／破坏。预先固定置信阈值 0.95，另固定“两位教师 argmax 相同且双方置信度均至少 0.95”的一致门控。报告教师改判子集的覆盖、正确率、修复、破坏，以及学生高置信错误的纠正情况。所有空子集明确数量为零、比例为 null。三模型错误交集和至少一个模型正确的 oracle 仅作不可部署的诊断上限。

跨种子按同一角色严格核对 PID 顺序、唯一性、标签、RX/day，L/V 物理 PID 不交；校验每行六类概率有限且归一。不得用 V 更新模型、教师权重、归一化或阈值；阈值及均匀组合已在运行前固定。本诊断不输出候选模型，也不新增目标测试。

本轮属于已授权性能研发中的只读源证据复算。既有 source artifact 及其来源只读不变，下载到独占 local_artifacts 目录；指标和报告进入 Git，原始张量不进入 Git。三份原始文件也含此前固定源终点字段，安全反序列化后仅取 parent，测试以 poison endpoints 证明未访问其他字段。总计复用 99,900 条原 E20 源样本模型读出，不将同样本的组合统计夸大为新独立样本。

输入来源为 20261012-phase1-e20-error-audit-manysig-m3-r01，所有源 RX 均已被 E20 学过；此诊断不能证明未知 RX 泛化，也不能证明 U 伪标签的真实准确率或训练增益。是否引入独立教师还须结合纠错质量、覆盖及部署成本，不因源均值微增就声称接近 84%。

E20 的训练本身未访问 target，来自从零纯 CE 和固定 final20。用户在已经查看轮次探索结果后指定 E20 为后续基线，这一背景沿用原来源记录；后续目标结果属于已暴露基准上的研发，不能称为全新盲测。本诊断仍只读取合法源预测，不按目标成绩选种子或拟合教师。
