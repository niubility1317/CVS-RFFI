# Phase1 DURA 全局相位相关修正实验

在冻结 DURA 的两个先验阶段各增加一个全局时间相关模块。每个位置的条件由接收信号、当前状态、原先验、物理后验及盲估噪声形成；查询与键由相位不变的幅值、复相关和噪声条件生成，并可学习时间位置间的相对相位相关。注意力只在同一条 256 点 IQ 内计算，聚合三个复数残差信号并输出有界连续修正。全局相位旋转下输出同步旋转，零初始化严格保持原 DURA；两个新增模块共 21,120 参数，不包含 DURA、物理后验、保护门及识别基座。

使用不与物理先验拟合集及源评估集重叠的 8192 条 Phase1 源训练记录及已固定第 21、22、23 轮视图，训练 5 轮并固定最后一轮。损失使用配对源 IQ 及冻结 Tri-SIG-TIME SSL 特征和软输出；恢复器训练不直接读取 TX 身份、U_s 真值、V 或地面测试。DURA、保护门、物理后验和识别基座保持冻结；物理先验继承冻结基座的伪类别，故该方法属于 F-guided。禁止调用使用源身份标签训练的非局部先验。源域已被探索，不称盲测。

先做 64 条源拟合记录与 28 条评估记录的真实权重训练预检，失败则停止；通过后训练并固定 672 条源预测，再进行合法 L_s truth-last 评分。每个网络版本必须执行 clean 和六个受损 Phase1 地面视图各 168000 条，七景预测全部固定后独立评分与审计，报告跨 RX 和跨 RX+day。总集 clean 基准 86.538690%，相对下降 3% 的门槛为 83.942530%；同时报告下降 3 个百分点的门槛 83.538690%。该地面开发测试已被反复观察，不是独立盲测或真实卫星性能。

源实验 `20261102-phase1-dura-correlation-source-s2026092701-r01`，地面实验 `20261102-phase1-dura-correlation-ground-test-s2026092701-r01`。使用共享 GPU 锁、CPU 每任务两线程、固定模型与不可覆盖输出根，资源不足等待。完整七景预测前不得读取地面真值，低分不停止健康任务；结果不回流训练或调参。
