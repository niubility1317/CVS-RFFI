# LoRa W24 整段 DURA 新增噪声监督对照

Run 20261127-phase1-lora-w24-native-additive-s2026112991-r01。Full 星地七景，固定原 W24 E104、默认头和全部前端。 [实验登记](experiment.json)

## 假设与对照

用同样的 DURA 恢复连续 8,192 点、1 MHz 原始复 IQ，固定 half 回写，之后走原 W24 裁窗、重采样、边缘样点、尺度处理和分类。两组同为 111,698 个参数和两个数据一致性更新。对照复原原源录波，候选只移除新增扰动，目标为短回波和缓慢相位作用之后、添加噪声以前的信号。合成中间量只定义损失，进入恢复器的只有实收 IQ。

种子 2026112991。两组共享 20,000 个 TX 盲源 U_s 包，500 个互斥留出包，逐步抽样与扰动 RNG 相同。24,000 次 AdamW、batch 16，2e-4 至 2e-5 余弦，权重衰减 1e-4，裁剪 1。每步末两包做恒等约束。损失为半量复误差、早期读出、低频公共和逐 chirp 差异误差、原生端点与恒等项。额外记录各模型到两个参考的原生 NMSE。每组冻结末步，固定检查 2,000、6,000、12,000、18,000 和末步。拟合及冻结阶段仅传入 U_s 根与自己的输出目录。

## 推进规则

末步冻结后完成实际 E104 无目标 smoke，再对 300 个同包源 V 做 Full 七景盲预测。八行包括固定直通、原长训 DURA、首尾 DURA 和原 U-Net，两组各有半量主读出及双倍诊断。候选半量六景必须严格超过各固定对照和匹配对照，低城区至少达到最高对照，clean 达到直通。此时才执行登记的三片正式 Full 测试和独立 truth-last。发生系统协议、数值或预测失败即保留产物并终止该次运行。

N607 优先使用 GPU 0、3，5、6 候补，单卡一个本次 worker。实际路径、代码提交、发布命令与产物范围见实验登记。18 项相关测试通过，独立 P0/P1 审查通过。

N607 启动 **VERIFIED**。发布归档比对、远端编译和两路实际 U_s 冒烟通过。控制器 PID 1842531，GPU 0 训练复原组，GPU 3 训练新增噪声组。读回 worker 的 PID、CWD、参数、GPU 和日志增长。首步两个参考的原生 NMSE 在两组分别完全相同。

40 个互斥留出源 U_s 包上的通用扰动复算中，只去新增噪声把修正与真实新增噪声的逐包复方向余弦中位数由 0.8721 提至 0.9911。相对已知加噪前信号的剩余误差功率中位数，由注入噪声功率的 29.18% 降至 3.01%。同样的半量读出，整段实收 RMS 回写由 19.27% 降至 14.75%，W24 中心回写由 16.44% 降至 8.84%，边缘由 19.96% 降至 14.54%。clean 的原生回写均低于实收 RMS 的 0.21%（逐包中位）。这批合法通用扰动的精确分量只用于解释结果。 [复方向与 W24 回写审计](audit_native_edit.py)

新增噪声目标在匹配实验中改善了复噪声方向，也把整段恢复从低于直通推到高于直通。最难低城区对这项改动响应弱，增加读出幅度还使该组六景少 265 次、低城区少 59 包，表明继续放大同一修正会扩大识别损伤。同一 300 包上，W24 中心坐标的既有新增噪声 U-Net 为六景 1,448、低城区 186、clean 296。原生去噪相比该路线为 −11、−20、0，低城区为改对 17、改错 37。这一横向比较还同时改变了模型与训练预算，无法单独归因于 8,192 点输入。 [中心坐标匹配实验](../20261127-phase1-lora-w24-additive-reference-s2026112991-r01/report.md)

两组各 111,698 个可训练参数。GPU 0 复原组训练 1,491.84 秒，GPU 3 新增噪声组 1,509.12 秒，共约 0.83 GPU 小时。两组峰值 CUDA 张量分配均为 1.96 GiB，拟合卷积启用 BF16。冻结后 GPU 0 单包恢复加原 W24 前端（含搬运，排除 E104 分类）中位数／P95 分别为 16.63／25.38 ms 和 22.31／27.91 ms。共享机器上两组同构，单次计时差异需同负载复测。
