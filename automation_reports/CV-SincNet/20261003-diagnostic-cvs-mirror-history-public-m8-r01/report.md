# 连续前历史与零启动：公开FIR机制验证

**状态：VERIFIED。8份冻结权重的配对诊断完成，独立NumPy全量复算通过。** 这项验证纠正了旧诊断的解释：纯音和DC上的大幅变化主要来自包前置零的启动边界。补齐真实前历史后，这两类信号的变化接近数值误差；噪声与周期包络仍有变化，因此不能宣称对一般多径卷积不变。

这是公开合成信号上的机制结论，不是识别准确率。全部旧模型的测试集成绩已在[304模型clean补测报告](../20261003-phase1-cvs-all-frozen-clean-backfill-manysig-m304-r01/report.md)给出，本文没有训练、选模或读取测试集，未因本诊断改变历史测试结果。

## 配对方式与完整性

固定mirror_energy、mirror_subspace各4个seed，共8份原E200权重。共同生成索引−16至255的公开波形，按观察窗RMS统一缩放；同一个256点观察窗分别使用零前历史和连续前历史。FIR为直达加复系数0.23+0.09j的延迟支路，延迟为2、8、16。每份模型包含6噪声、6纯音、6周期包络、6DC、6全零信号。此生成器与旧公开诊断不同，因果比较限定在本次相同波形的两种历史模式之间。

分支分别用FP32、FP64运算；整个模型的归一化160维表征只用FP32。模型状态逐张量检查未变，优化步数为0。NumPy独立核对FIR、RMS、STFT、复Gram/楔积公式，覆盖1,440个包级比较、44,640个频率对、10,080帧及720个表征比较。两种历史只改变前delay个原始IQ点，未做RMS归一化时的STFT差异只在首帧出现；RMS归一化后不能直接沿用这个局部性断言。

纯音在连续前历史下受到固定复增益作用；DC同理。两种结构对此接近不变，不能把旧零历史纯音/DC结果解释为普遍信道失效。mirror_subspace在连续噪声上的Q变化仍约0.973、表征变化约0.249；周期包络分别约0.250和0.0556，说明有限窗多径情况下仍存在真实的结构敏感性。

平方分解保留有符号交叉项：零历史变化=连续历史变化+历史边界差，两者范数不能直接相减作为“边界贡献百分比”。Q接近零时不使用相对误差膨胀推断输出爆炸。FP64只用于核查分支运算；不能据此声称整个模型双精度性能或真实发射机分类因果关系。
