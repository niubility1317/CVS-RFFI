# Phase1 期中模型源域细化诊断

两项诊断使用同一组 512 条 Phase1 源训练物理记录（128 条 L_s、384 条 U_s）及 clean、源视图 1、源视图 20，冻结 Tri-SIG-TIME SSL 和 DURA。所有学生候选决策固定后才读取合法 L_s 标签；未读取 U_s 标签、V 或测试 IQ。两种受损视图共享物理记录。结果不能代表固定第 30 轮模型或独立测试表现。

## 边界学生第 27 轮

第 27 轮检查点 SHA-256 为 `7712b989bc5de26028ebedbb8aac0aaad367e427de634c52ed7c34ee137295dc`。学生只接收接收 IQ 和 DURA 输出。对照 oracle 则使用每条源 clean IQ 的教师类别作为输入梯度目标，是不可部署的特权诊断；两者均限制在 DURA 波形 L2 范数的 5% 内。

| 源视图 | DURA 与 clean 教师一致 | 学生一致 | 学生修正 / 损伤 | 特权 oracle 一致 |
| --- | ---: | ---: | ---: | ---: |
| clean 经 DURA | 512/512 | 512/512 | 0 / 0 | 512/512 |
| 1 | 491/512 | 491/512 | 5 / 5 | 512/512 |
| 20 | 492/512 | 490/512 | 1 / 3 | 512/512 |

在 128 条有真标签的 L_s 记录上，学生在两个受损视图分别由 121 增至 122、保持 125。特权 oracle 的 clean 教师一致性只说明源域输入边界可被目标梯度推动，并不说明推理时知道正确目标或保留物理保真。

## 类别条件模型第 14 轮：预测类别自细化

第 14 轮检查点 SHA-256 为 `df5893f3358580b663c87cadc586eca5ea1ff9cd6caf850e7b23698a2ae75496`。先由模型只根据接收 IQ、DURA 和冻结基座分数提出类别；对与 DURA 判断不同且置信度达到门槛的记录，将该**预测类别**作为输入梯度细化目标，最多 12 步、5% L2 范围，只有冻结基座确认细化结果属于预测类别时才接受。细化不使用 clean 或真实标签，但梯度扰动可能是对抗性的，幅度约束不保证物理保真。

| 源视图 | 置信度门槛 | 提议数 / 与 clean 教师相同的提议数 | 接受数 | 与 clean 教师一致：DURA → 细化 | 修正 / 损伤 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 | 0.50 | 33 / 9 | 33 | 491 → 477 | 9 / 23 |
| 20 | 0.50 | 16 / 9 | 16 | 492 → 494 | 9 / 7 |
| 1 | 0.95 | 0 / 0 | 0 | 491 → 491 | 0 / 0 |
| 20 | 0.95 | 0 / 0 | 0 | 492 → 492 | 0 / 0 |

在这些期中源记录上，细化可以使基座接受所提出的类别，但宽松门槛下不少类别提议与 clean 教师不一致。0.50、0.70、0.80、0.90、0.95 均为源域事后比较；不能把较低门槛的结果当作已登记的 0.95 配置，也不能用此样本选择测试门槛。完整结果包含候选生成器、L_s 标签及 BLOCKED 子集。

完整记录见 [boundary.json](boundary.json) 和 [self_refine.json](self_refine.json)；分别重新运行 [boundary_probe.py](boundary_probe.py) 和 [self_refine_probe.py](self_refine_probe.py) 均得到逐项相同结果。正式实验仍固定使用第 30 轮，clean 教师一致性不是 TX 真实准确率。
