# LoRa W24 观测条件化整包复数速度场

N607 GPU 3 已完成 16,000 步、固定权重、Full 七景源域预测及独立评分。四步半量未达正式晋级条件。 [预登记](experiment.json) · [运行状态](events.jsonl)

## 结构与训练

网络从零训练，共 386,933 参数。时域卷积和复谱支路以当前整包的实收 IQ、状态 IQ、实收质量、去扫外带功率中位估计和积分时间为输入。192 个位置 token 跨八条 chirp 交互。输出为匹配实收坐标的复数速度。

训练点取同条通用受扰 IQ 到原源 IQ 的直线路径。每批 8 包，含一个 clean 恒等对。路径时间有 25% 取 0，其余连续取样。配对损失包括整窗复误差、近载波加权复谱误差、相邻 chirp 差分以及两个支路各自的速度风险。训练使用 16,000 个 U_s 的拟合池，16,000 步 AdamW 余弦训练，另有 160 个互斥 U_s 用于同样受扰和 clean 的波形留出。只有最终步冻结；步数 2,000、8,000、16,000 的留出只测波形。

## 冻结后的匹配验证

取得冻结权重后，一步和四步固定欧拉求解共同以实收 IQ 为起点。每种步数读取半量和全量中心窗修正，原生边缘 IQ 原样送入冻结 W24。以同一 300 包源 V 完成 Full 七景，加匹配历史首尾半量和直通。所有预测固定后，单独评分进程读取源标签。拟合、波形留出和冻结阶段 W24、源 V、TX 和目标访问均为 0。

正式晋级使用预先指定的四步半量。它须满足源域 clean 至少等于直通，六景和低城区分别较首尾父版至少多 18 次、10 包，且两项均优于一步半量。
