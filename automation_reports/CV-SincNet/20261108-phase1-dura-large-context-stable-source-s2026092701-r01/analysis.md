# 归一化大容量恢复网络的源域持续梯度检查

使用独立初始化的归一化网络、冻结原 DURA v1.0 和合法源 IQ 样本，固定抽取缓存中的前 96 个视图，重复执行 256 次 batch 32 更新；使用与正式训练相同的 DURA guard 波形损失、AdamW 0.0003、权重衰减 0.001。该小样本用于机制检查，不读取发射机标签、识别器权重或输出、V 或目标，也不影响正式训练的权重和选模。视图可能对应相同的物理记录，不作为独立样本计数。

| ---: | ---: | ---: | ---: | ---: |
| 1 | 0.0267093 | 0% | 0.6244 | 0.004274 |
| 32 | 0.0266986 | 0% | 0.6490 | 0.010495 |

输出头梯度范数来自每个记录步的最后一个训练批次；损失和解码器输出统计来自同一组重复使用的 96 个视图。这次小样本检查未观察到原最终模型在抽样上出现的解码器全零现象，但不证明完整训练不会饱和，也不证明对未见源数据或地面识别有效。正式模型独立在 N607 训练，冻结后按预登记七景独立评分。
