## 最终模型的源训练抽样激活复核

训练结束后，以种子 2026110802 从训练源上下文抽取 64 个物理记录及其三个视图，共 192 个视图，读取冻结的最终模型，在 CPU 上检查前向及源损失梯度；不读取 TX 标签、F、V 或目标。这个抽样与原大容量 DURA 版的激活检查一致，但来自两版都使用的训练上下文，不是独立泛化数据。

归一化版解码器输出均方根为 0.73082，源损失对输出头权重的平均梯度范数为 0.0005717；原版在相同抽样上的解码器输出和输出头权重梯度均为零。归一化版该抽样的 DURA 平均 NMSE 为 0.0266832、候选为 0.0189767；161 个视图波形误差降低，31 个保持完全相同，0 个升高。输出修正的平均归一化能量为 0.0041381。三个视图共享物理记录，不应当作独立物理样本。

结果支持归一化版在这次训练样本上避免了原版的全零解码状态，并产生了实际的源波形修正；这不是对所有样本的保证，也不能推断身份识别收益。另一个已探索源 pilot 的 RX4/6 与 RX8 结果方向不同，见上节；七景正式预测仍按固定计划进行。
