# LoRa 联合幅相与弱复谱关系长训

[运行矩阵](experiment.json) · [登记状态](events.jsonl)

## 方法与权限

使用两路线共同提供的 6×256 点实收 IQ。频域粗层读取本条、其余 chirp 的复均值、跨 chirp 离差，以及去扫后 |f|>64 kHz 的总外带功率和去均值外带功率。后者以 C/(C−1) 修正去均值造成的自由度变化，反映独立变化的有效能量。设备细节、传播失配和相关干扰会使两种功率代理偏离真实噪声。粗层输出有界复谱编辑，时域细化读取粗波形和实收残差，输出另一复数编辑。两阶段共用实收功率系数、逐频限幅和载波保护，每一条 chirp 回到实际接收尺度和时标。

两组都匹配源波形的复谱误差以及共享扰动下实际弱谱差异的传递。关系组独立加入一项约束，将未加本次扰动的合法源 U 与恢复 IQ 的 1–8 和 9–32 kHz 去均值谱做跨 chirp 归一化复 Gram。它刻画差异成分的相对功率和复方向，对跨 chirp 共同复偏置与全局常相位不敏感。该损失只用于训练。每臂 35,332 参数，固定 40,000 步、batch 24。两臂各用同一批原始 20,000 个源 U 包和通用扰动，另设互斥的 2,500 个校准和 500 个留出包。优化器持续运行，按同一日程提升细化和弱差异损失权重，关系组追加 Gram 权重。训练及冻结隔离 F、V、TX、目标、practical 算子和逐点噪声。

Ephraim 与 Van Trees 使用噪声子空间提升语音，DCCRN 联合恢复语音幅相。本方案用接收机可用的功率与包内重复结构作条件，在固定 LoRa 识别头之前输出复 IQ。比较对象是从实测源 U 获得的跨 chirp 弱频带关系；该关系通过匹配长训消融判断是否保留设备细节。最近的 LoRa 谱形搬移实验在同平均噪声能量下改变接收 PSD 的频率表达。本轮把差异设在监督损失中，两个臂共享完全相同的接收量。 [子空间原论文](https://people-ece.vse.gmu.edu/~yephraim/Papers/sap%201995%20sig%20subspace.pdf) · [DCCRN 原论文](https://www.isca-archive.org/interspeech_2020/hu20g_interspeech.pdf) · [作者实现](https://github.com/huyanxin/DeepComplexCRN) · [LoRa PSD 传递证据](https://github.com/niubility1317/CVS-RFFI/commit/7fc2dc685)

## 独立评测矩阵

终步固定两臂。先做真实权重无目标检查，再对两路线各 900 个同物理源 V 包和七景写出直通、成熟半量 DURA、每臂粗层与联合全量/半量的固定预测。连接同一冻结 Tri-set seed 2026092702。全部预测都写完后才由独立 CPU 读源 V 真值，按 RX 分层解读逐包结果。两路线分别提高匹配 DURA 且保持各自 clean 才进入下一阶段。

评分完成后复核所有逐景×逐接收机配对正确数、纠错、改错和 95% 区间。波形侧重放相同物理包，用同一实收坐标比较候选与两个隔离参考。一个参考是按直通波形常复增益对齐的同包源 IQ，另一个保留传播失配并扣除精确仿真加性噪声。对每个参考另外计算同样逐频限幅内的闭式最小复平方误差。它只界定给定观测可行集里的波形误差，精确参考不接候选，不参与识别评测、门限、训练或选模。 [波形归因](../../../tools/lora_local_phase_fidelity.py) · [逐景逐接收机配对](../../../tools/lora_geometry_pairing.py)

## 同包波形归因

两条路线的逐景×逐接收机配对计数和 1,600 次物理包分层 bootstrap 已独立复算，逐景正确数与原评分逐项一致。隔离波形重放也完成。每个恢复读出使用直通 IQ 的原时标和去扫频坐标，比较时用同一常复增益对齐同包源波形。`bounded_pair_projection` 在同样的观测逐频限幅内直接朝已知参考作复平方误差最小编辑，只用于描述波形差距，未生成候选识别分数。

Residual 低城区相对扣噪接收参考，关系组全量的 9–32 kHz 复误差为 12.052，接近同限幅投影的 11.679。对齐源波形的复相关仍相差 0.216。该对比表明，在这个裁窗和度量下，大幅削减复噪声误差后仍可能保留不了实际源复谱方向。同一读出在 residual 低城区比直通少判对 123 个包，进一步验证了波形误差与识别的分离。该结论限于当前候选及这套波形对齐规则。
