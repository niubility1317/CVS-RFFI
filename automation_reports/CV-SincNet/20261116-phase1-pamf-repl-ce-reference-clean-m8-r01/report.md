# Tri 有标签 CE AdamW 参考主方向实验

与完整监督参考实验逐行匹配：十类、六源各固定 U 权重 6／3、相对参考额外步幅上限 0.25／0.5，共 8 行；使用原同合同 seed 2026092701 的 Tri 源 E20，各自继续 E21–E50。参考是同一当前参数和 AdamW 状态下，仅用当前普通有标签 CE 梯度得到的实际更新，梯度只来自 L_s；它保留先前联合训练的动量，不是另训纯监督模型的更新。

相对 CE-only 更新的额外位移同时包括其余监督项和全部 U 项，不能叫作纯 U 增量。该额外量先同时保护完整 L 与 ordinary CE 的当前梯度，再按参数组限制为 CE-only 参考更新范数的 0.25／0.5；量化后重新核对锚点、范数和总步方向，不合格回退 CE-only，参考为零时也回退并记录。非零参考时总步与参考余弦理论下限为 sqrt(1−cap²)，分别约 0.9682／0.8660；这种局部方向约束不保证实际损失或泛化提升。

每行记录参考和总更新方向、各参数组额外步比例及回退、原 L/U 梯度、源 V、U 接受率；冻结 E50 后独立离线评分 U 真值，训练和选模不读取真值或评分。clean cross_date、cross_rx、cross_both 预测冻结后独立 truth-last 评分，主口径合并 cross_rx 和 cross_both，不跑星地或 weak。当前 seed 和历史 target 已曝光，全部结果仅为探索性；不根据 target 或 U 真值挑选、重排或更改候选。

使用 N607 普通账号，GPU 2、3、4 按可用容量轮流调度，含其他 owner 与待初始化任务的每卡总数上限 3；容量不足则排队，保留健康进程。协议、非有限或系统技术失败停止新调度。命令、数据合同和输出见 `experiment.json`。独立 P0/P1 审查未发现阻断项，CE 梯度选择与既有实际 AdamW／FP32 数值边界测试通过；发布后的真实设备 smoke 和训练状态待核验。
