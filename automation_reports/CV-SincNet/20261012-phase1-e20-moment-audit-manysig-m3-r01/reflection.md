# 浅、中层 Fishr 与 MixStyle：本轮结论和后续设计依据

本轮状态为 VERIFIED / ANALYZED。三种子均完成了原 E20（P0）与同种子纯 CE 续训 20 轮（CE20）的固定诊断。结论来自合法有标签源域 L，不使用目标成绩选择机制；本轮没有新训练权重和 clean 测试成绩，84% 目标尚未完成。

## 1. Fishr 的主要问题包括估计幅度偏大，不能笼统归结为没有域信号

在真实 RX 分组、每个 TX/RX 取 2 个样本时，旧方差平方损失的均值是全 L 有限总体参考的 1.469 至 1.596 倍。只把单个方差改为分层无偏估计后再平方，比例仍为 1.487 至 1.630，说明平方带来的估计噪声不可忽略。

独立 A/B 两批的中心化方差内积将该比例降至 0.998 至 1.016。对应虚拟通道仿射梯度与全 L 参考的平均余弦为 0.907 至 0.971，旧平方为 0.839 至 0.932。这个结果支持修正统计估计，而不支持简单增大旧损失权重。

但是，旧方法在真实 RX 上的方向并非完全无效；其余弦本来就较高。真实 RX 的全 L 参考损失约为类内打乱 RX 对照的 36.6 至 45.3 倍，浅层和中层都存在可测的条件 RX 关联。不能把全部 Fishr 信号说成采样噪声，也不能仅凭 RX 关联就断言该信号完全不含身份信息。

类内打乱 RX 后，小批旧平方是自身有限总体参考的 33.625 至 34.869 倍。A/B 内积仍有明显随机波动：m=2 时负值比例为 44.4% 至 50.9%，对参考梯度余弦只有 0.042 至 0.074。无偏期望不保证低信号下单步可靠；负值不应截断、取绝对值或按符号挑选批次。

## 2. MixStyle 确实进入了浅、中层，但当前扰动较弱

在同 TX、同 day、不同 RX、不同物理样本的配对规则下，固定弱 MixStyle 实际改变了约 46.57% 至 54.81% 的样本层读数。计入未启用轮次后，平均相对特征变化只有 1.27% 至 1.74%。因此“加入了 MixStyle”不等于主身份任务已经接受了足够的特征扰动。

完整 L 的 TX×day 条件统计显示，通道均值的 RX 间/内比为 1.0244 至 1.2029；log 标准差为 0.6318 至 1.0358。中层 log 标准差的关联在种子间有所不同。均值、尺度和层位置需要分别记录，不能把所有风格坐标统一视为纯接收机因素。

这些是缓存特征上的局部运算，尚未证明连续作用于两个 hook 时的身份保持情况。下一步实际训练必须记录主身份 CE、预测变化、浅中层实际位移，以及反传到对应骨干的梯度，不能用辅助头正确率代替主身份网络的效果。

## 3. 下一版应落实的机制与对照

1. 保留浅层 `time_down` 和中层 `t2.pool` 两个作用位置。分别检查单层与联合作用，不把机制退回最终 embedding。
2. 为 Fishr 增加分层有限总体方差修正与独立 A/B 内积变体；两批内部不放回，批间独立且允许重叠，同一步两批共享同一组模型与辅助头参数。两条计算图均反传。辅助头先在合法 L 上预热，并明确后续辅助头与骨干的更新时序。
3. 配套同样前向样本预算的旧 Fishr 对照，报告实际时间和显存。m=2 的 A/B 比旧单批多一次统计批；不能把它与更大单批比较后只归功于估计公式。
4. 不直接沿用同批梯度范数决定的随机缩放来宣称无偏。可以在预登记中采用固定权重或独立校准的尺度，但任何自适应实现都应按真实更新重新核验。
5. MixStyle 采用明确的浅层、中层及联合对照，保留同身份、同 day、跨 RX 的合法 L 配对。提高强度的方案必须有固定范围和主身份保持证据；当前局部诊断不足以证明更大强度安全。U 可以继续进入原半监督主路径，不能为了配对读取 U 的 TX 真值。
6. 保留同预算 CE 与半监督对照，身份训练预算继续遵守原 E20 追加 20 轮；若另发从头实验则为 20 轮。无 EMA、无星地训练增强，逐 row 冻结后自动 clean 预测、独立 truth-last 评分。新的矩阵、权重及调度须先完整登记，不能把本报告中的研究方向说成已经发布的训练。

## 4. 适用边界与成本

三种子的全部 5 个源 RX 均已参与父模型训练。本轮是源统计可靠性诊断，不是未知 RX 泛化证明。Fishr 方向以共享虚拟通道仿射参数为参照，不是完整骨干梯度。辅助探针 CE 也不是主身份模型 CE。

本轮共 1200 次辅助头更新、75600 次 L 样本模型读出、7776 个 Fishr 估计和 432 次局部 MixStyle 试验。三个 worker 的实测运行时间分别为 33.83、33.53、33.57 秒，硬件均为 RTX 3090；各进程记录的 PyTorch 峰值已分配显存为 64207872 字节，不含驱动上下文和全部进程常驻成本，也不等于未来训练开销。

身份基础状态前后逐位不变，没有 U/V 前向、V 更新、目标预测或目标评分。旧打包缓存会一起反序列化 L/V，随后丢弃 V；已在 resolved config 中明示。完整结果见 [analysis.md](analysis.md)、[逐轮统计 CSV](evidence/fishr_rounds.csv) 和 [原始源诊断](evidence/source_results.json)。
