# 低城区源样本：波形误差和已知信道反事实

复用已完成的源域协方差反演诊断。原实验在 512 条合法 L_s/U_s 源训练记录上使用 20 次固定模拟视图；其中低城区为 1436 个视图、来自 485 条记录，视图并不独立。F0 是原冻结 Tri-SIG-TIME SSL，未新增模型前向或更新，也未读取 TX 真值、V、OE 或目标数据。源先验由同一合法训练域拟合，因此这不是独立泛化测试。

定义每视图 IQ 归一化均方误差为 mean((输出−同条 clean)²)/mean(clean²)，然后对视图取平均。全协方差反演使用模拟器记录的真实完整线性信道和噪声方差，以及固定源 IQ 均值和协方差；它是特定高斯线性方法的理想参数对照，真实参数在部署时不可用。

| 低城区源视图 | 原接收 IQ | DURA v1.0 | 已知信道与噪声的全协方差反演 |
| --- | ---: | ---: | ---: |
| 平均归一化均方误差 | 2.006094 | 0.063043 | 0.060968 |
| 误差中位数 | 1.995767 | 0.023261 | 0.037104 |
| 误差第 90 百分位 | 2.137781 | 0.164558 | 0.155285 |
| 与 F0(clean) 决策一致 | 59.05% | 83.91% | 87.74% |

以平均误差计算，已知参数反演比 DURA 低 3.29%；其误差平方根对应的归一化 RMS 量为 24.69%，DURA 为 25.11%（均为先平均单视图 NMSE 再开方，并非逐视图 RMS 的平均）。逐视图比较中，已知参数反演 798 个误差更低，638 个误差更高。与 DURA 的 F0(clean) 决策一致性相比，已知参数反演使 117 个从不一致变一致、62 个从一致变不一致，净增加 55/1436；这个一致性不是实际 TX 准确率。

如果强行以原接收 IQ 的平均逐点 NMSE 作为分母，DURA 的平均误差低 96.86%。该数字只是上述口径下的**误差缩减比**，不是恢复了 96.86% 的 clean 波形或身份信息，也不是理论上限。为检查简单相位因素，逐视图使用真实 clean 拟合一个最优常相位（仅作不可部署的事后对照，不做幅度均衡），接收 IQ 的平均 NMSE 仍为 1.884898。这个对照不能解释所有误差来源；逐视图 IQ 误差、识别器特征和实际 TX 识别应分开报告。

原接收 NMSE 已从同一源配对重新计算，与既有记录的最大绝对差为 4.39×10⁻⁷；配对一致性四类计数相加等于 1436。结果仅说明该源面板和这两条固定方法的差异；已知物理参数的 Gaussian 反演并非任意非线性恢复器的信息论上界，不能据此推断目标星地测试的恢复极限或下一版收益。
