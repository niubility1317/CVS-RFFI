# LoRa 弱复谱方差匹配与等修改量 Wiener

[预登记实验](experiment.json) · [运行事件](events.jsonl)

## 方法和可用接收量

这组工程对照检验弱复谱差异被收缩后，保持其分布方差是否能提高冻结识别。输入为同包的六条对齐 LoRa 上扫窗，每条 256 点、256 kS/s。用实际前导估计有效频移和载波相位，并保留原来的样点和回写尺度。对去扫复谱做六维正交 Helmert 变换，第一维为公共分量，余下五维保留 chirp 差异。只处理双侧 1–32 kHz，载波和其他频点的修正量为零。

| 输入量 | 可用时点及算法 | 误差来源 |
| --- | --- | --- |
| 当前包 IQ 和已知上扫参考 | 前导六条窗到齐后，采用去扫峰、滞后相关和载波相位 | 只有上扫窗时，接收时偏和频移可混合。配准误差还会让真实响应能量进入外带。 |
| 干净源均值和 I/Q 协方差 | 部署前从 5,000 个匿名源 U 包按 RX 均衡估计，按频点分别计算。公共分量单独统计，五个独有模态共享同一协方差 | 两条 practical 路线共用同一份校准。矩阵估计会受源接收机、幅相估计和真实独有谱差异影响。 |
| 接收噪声方差代理 | 去扫后分别取公共和独有分量的 64 kHz 外复功率中位数，除以 `2 ln 2` 得到 I/Q 单分量方差 | 标度依据圆对称复高斯。窄带、有色或相关干扰会导致近载波方差与外带不符。两项偏差用独立复核估计。 |

在源 I/Q 协方差的每个主轴，以源特征方差 `S` 和接收估计噪声 `N` 得到 Wiener 增益 `g = S/(S+N)`。方差匹配采用 `sqrt(g)`。在这个标量高斯模型中，若输入变异为 `S+N`，Wiener 输出变异为 `gS`，平方根读出输出变异为 `S`。实际频带统计、干扰与单包复数方向的保真由冻结测试核验。

对照组以同一个全量 Wiener 编辑方向为基础，按原 IQ 的物理 RMS 缩到和方差匹配相同。对个别非等幅 chirp 的情况，两臂都调整至较小编辑量。两者同时受实收 IQ 的 10% RMS 限幅，采用同一 clean 阈值。仅公共分量或仅独有分量走平方根的两个消融，另一分量仍走普通 Wiener。Clean 门下逐样点复制。这里使用相关理论的方差保真原理，测试无线前导的接收估计、弱复数频带和冻结设备识别。理论中的分布接近并不直接给出识别收益。 [Freirich、Michaeli 与 Meir 原论文](https://proceedings.neurips.cc/paper_files/paper/2021/file/d77e68596c15c53c2a33ad143739902d-Paper.pdf) · [Blau 与 Michaeli 原论文](https://openaccess.thecvf.com/content_cvpr_2018/html/Blau_The_Perception-Distortion_Tradeoff_CVPR_2018_paper.html)

## 数据和评分

两路共用 5,000 个源 U 包估计协方差、2,500 个互斥源 U 包设门限、500 个互斥源 U 包用于留出计量。工程对照没有可训练参数，优化步数为零。校准时不读取 F、源 V、TX 及目标，也不读取真实信道、精确噪声和已登记场景。冻结后同一 Tri-set seed 2026092702 对 900 个源 V 物理包和两路线七景做配对预测。预测全部固定后独立 CPU 连接源 V 真值。包级区间在五台接收机内分层重抽 1,600 次，同包六景联合重抽。候选对照为直通、匹配原半量 DURA、后验均值、等修改量后验均值、方差匹配和两个分量消融。

本地检查覆盖正交分解、闭式方差恒等式、原 IQ 等剂量匹配、clean 精确旁路和非弱频带不动。独立 P0/P1 在不同 chirp 增益下实测两组物理 RMS 差最大为 `2.98e-8`。 [等修改量与保真测试](../../../tests/test_lora_variance_transport.py)

## 冻结评分

N607 发布和执行已独立核验，状态为 VERIFIED。执行提交为 `057aae28c5000b194307034ef229a65af795de1e`。在 GPU 6 校准耗时 2.78 秒，clean 门限为 0.04594118。真实识别器、原 DURA 和实收片段的无目标检查通过。Full 和 residual 预测分别用 GPU 3 和 6。两份七景预测全部固定后，独立 CPU 评分，实际目标读取为零。RTX 3090 的单包中位时延为 clean 旁路 2.19 ms、通用扰动触发 4.88 ms，均测 20 次并包含全部五种工程读出，识别器不计时。

## 复幅相和噪声估计复核

独立评分后重放同一批 900 包。用直通确定每条 chirp 的复增益，将源参考对齐到实收幅相坐标，该对齐对所有读出相同。公共分量的中心化功率比和有符号增益以该源参考为分母。另用扣除实际仿真加性噪声的接收波形评估整体复谱误差，真实噪声仅进入事后计量。

| 低城区 9–32 kHz 中位数 | 公共中心化功率比 | 公共有符号增益 | 公共复相关实部 | 对隔离扣噪参考的整体复谱 NMSE |
| --- | ---: | ---: | ---: | ---: |
| Full 等修改量后验均值 | 0.260 | 0.034 | 0.057 | 1.482 |
| Full 方差匹配 | 0.298 | 0.041 | 0.059 | 1.431 |
| Residual 等修改量后验均值 | 7.664 | 0.141 | 0.068 | 39.689 |
| Residual 方差匹配 | 8.359 | 0.156 | 0.070 | 39.444 |

两路有符号增益均上升，但复相关仍低。Full 公共功率更接近同包参考，residual 公共功率已偏高，补偿后偏差进一步增大。低城区 full 触发 641/900，residual 触发 899/900，五台 RX 的两种匹配读出实际 RMS 剂量中位数都达到 10% 上限。

对真实噪声的事后统计显示，公共/独有外带噪声代理的中位偏差，在高强郊区分别为 full +9.59/+1.08 dB、residual +3.93/+0.15 dB。低城区相应为 full +0.48/+0.09 dB、residual +0.07/−1.45 dB。外带误差缩小时，近载波单包幅相仍可能缺乏可辨识证据。两份 `*-aligned-waveform-fidelity.json` 含四个频带、逐景及逐 RX 的完整数据。 [复幅相与估计误差复核](../../../tools/lora_local_phase_fidelity.py)
