# WiSig 接收端相位保真的固定权重训练

原 R69 与居中 FIR 在 360 包源域幅相交叉对照中，换入 R69 相位分别带来 316 和 317 次六景净纠错，换入其幅度分别为 178 和 184。在固定观测权重的居中 FIR 上新增仅使用源 IQ 的相位保真训练。R69 权重、输出、目标数据和仿真真实作用均与拟合隔离。扰动重抽样一致性、弱复谱、观测残差、方差似然、clean 恒等与原所有阶段损失继续沿用。 [源域幅相结果](../20261125-diagnostic-wisig-stage-polar-source-s2026112501-r01/report.md)

两个 MAP 输出在现有三视图上计算正则化复相量弦损失。每个样点用源参照的功率相对该包平均功率计算置信权重。相量分母的稳定尺度为参照 RMS 的 0.05 倍，置信权重为样点功率除以样点功率与包均功率 0.04 倍之和。一阶段和末步分别占相位项的 25% 和 75%，相位项总权重 0.20。该项保留同时间网格上的绝对复相位。两次 MAP 的首尾观测倍率仍是 8 和 1，结构与原固定权重组相同，共 576,089 参数。没有新增推理操作。识别器始终读取完整恢复输出。

用与固定权重组相同的 52,092 个无标签源 U 包、512 个留出包、相同逐包扰动流、种子 `2026092701`、初始化、40,000 步和 batch 24。一个端到端优化器联合粗恢复、观测作用和细化。训练前对同一真实源包、同模型和同随机流逐项比对原损失与新增配方的基础损失，同时比较扰动随机数状态。再做 3 次源 U 更新，确认全部阶段得到梯度。只有源恢复权重冻结并通过来源检查后才接入原 Main split Tri-SIG-TIME，并对两条路线各 1,800 个相同物理包、clean 与六景进行完整无门控恢复。原 R69 与直通复用已登记的同包盲预测。输出全量冻结后由独立 CPU 读取源 V 标签。固定权重组沿原健康队列完成，随后以相同物理包、场景和识别器作配对比较。

在语音恢复中，Takaki 等用 STFT 幅相分布构造波形训练损失。这里使用样点域的参照功率加权相量损失，并把它同时施加到两次原生 IQ 观测约束输出。机制收益以后续冻结识别对比为准。 [Takaki 等原论文](https://arxiv.org/abs/1810.11945)
