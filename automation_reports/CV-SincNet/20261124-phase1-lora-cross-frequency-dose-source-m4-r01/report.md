# LoRa 跨频先验的连续回写

[预登记矩阵](experiment.json) · [运行事件](events.jsonl) · [跨频工程对照](../20261124-phase1-lora-cross-frequency-source-m2-r01/report.md)

先前跨频复协方差在等物理 IQ RMS 下比逐频协方差多判对 Full 238、Residual 521 次。固定方差保持在 Full 比 DURA 多判对 49 次，在 Residual 少判对 287 次，低城区五台 RX 的编辑量中位触及 30% 上限。本轮固定同一解析跨频方向，以两臂相同的训练预算检验能否用接收端证据分配公共和独有回写强度。

## 先验、观测与两段求解

| 可用量 | 来源、时点与误差 |
| --- | --- |
| 当前 IQ 与跟踪坐标 | 两路均接收六条 256 点对齐前导，独立读取协议去扫坐标、每 chirp 的 RMS 与跟踪置信。恢复沿原相位及尺度回写，不重新截窗或归一化。有效频偏可含时偏。 |
| 公共和独有跨频方向 | 在每组相同的 20,000 个源 U 上重算两个二阶矩。六窗 Helmert 分解与非载波矩阵保持上一轮形式。每源 U 包无需类别标签。源协方差含地面采集噪声、接收机与设备的联合变化。 |
| 接收噪声方差代理 | 实收在去扫和 Helmert 坐标下的外带功率中位数，换算为每实维方差。I/Q 相关和跨频耦合由先验提供，外带代理本身仍使用对称复噪声模型。实际色噪、失配和硬件侧带可能造成偏差。 |
| 相对作用与失配 | 实收奇偶 chirp 互作参考，四个时间锚点内以交错 8 点时间块做正则复增益与留出误差。只在本包数据齐备后计算；参考混合了真实变异和干扰，无绝对传输算子。 |
| 观测可信度 | 同包奇偶相干、两组差异、跟踪分数、公共和独有能量、提议回写与接收 IQ 的内积。没有 RX、场景、生成种子或路线输入。 |

解析方向分别是公共和独有协方差的方差保持回写。粗层预测两个有界系数并产生初始复增量。细层同时利用粗层系数、估计作用下的归一化创新和相对奇偶参考的失配变化，重新组合原来的两个方向。两组使用相同的可见输入、网络和梯度目标。统一组在两个阶段各取两个 logits 的均值，分开组让公共与独有系数独立。低于独立 clean 源校准阈值时逐点旁路，激活后总编辑量上限为原 IQ 的 30%，去扫载波保持。固定解析读出用同一组方向和单位系数。两组等量读出使用分开组同一权重，将开启与关闭独立系数的原 IQ 编辑量缩到逐包较小值。

两组各从零训练 40,000 步，batch 24，均用 20,000 个固定源 U 物理包、2,500 个独立 clean 门限包和 500 个独立留出包。协方差先验由同一拟合分区解析初始化并冻结。每步对合法源 IQ 生成与目标独立的通用突发、相位漂移和干扰，并使用源 IQ 的实测弱频带差异检查复数传递。粗细非载波谱重建、跨扰动一致性、公共和独有真实源波形差异，以及超出实收估计方差与留出失配预算的观测误差在同一循环优化。固定终步，不读冻结识别器、TX、源 V、目标、真实噪声或 practical 轨迹来训练与冻结。

BM3D 的两段协作滤波用第一段基本估计支持第二段经验 Wiener 收缩，Chen、Yu 和 Pock 的反应扩散训练学习各层滤波器及非线性。本方法固定实测 LoRa 协方差方向且粗细共享原方向，学习当前前导上两个可单独开关的复增量系数，观测创新来自估计作用。独立贡献由同权同物理 RMS 的冻结识别消融检验。 [BM3D 原作者页面及实现](https://webpages.tuni.fi/foi/GCF-BM3D/index.html) · [反应扩散原论文](https://openaccess.thecvf.com/content_cvpr_2015/html/Chen_On_Learning_Optimized_2015_CVPR_paper.html)

## 冻结矩阵

两路使用同一固定 Tri-set 种子 2026092702、同一批 900 源 V 包和 13 个固定读出。每路六景共 5,400 个判定，低城区和 clean 各 900 个。两路全部预测固定后，由独立 CPU 读取源标签。主读出预定为分开组全量，只有两路线均超过匹配的半量 DURA 且 clean 无损才进入正式阶段。实际新增噪声仅供评分后的波形隔离归因。

## 合法源 U 方向核查

独立 CPU 进程用同一解析先验和另一个固定通用扰动种子，在 500 个源 U 留出包上检查两个方向的能力。每条轴枚举 `[0, 1.25]` 的 21 个系数，并与统一对角线比较，每个组合执行 30% 实收 IQ RMS 上限。误差是输出到原始合法源 IQ 的物理平方差，按原实收包能量归一。逐 RX 中位数中，直通误差为 0.155 至 0.166，解析固定强度为 0.024 至 0.033。在各包允许用原始源 IQ 搜索系数的比较中，分开相对统一的额外减量中位数只有 0.000017 至 0.000029，54% 至 58% 的包减少超过 0.00001；分开读出的最优总编辑量在五台 RX 的中位数仍为 30%。这是固定网格的波形几何对照，与正在训练的权重隔离，实际推理不进行源参考搜索。 [合法源 U 方向复算](../../../tools/lora_cross_frequency_dose_projection.py)

## 实收强度及弱复谱

低城区 Full 与 Residual 分别有 736、900 个包触发。Residual 五台 RX 的公共系数中位数在 1.004 至 1.007，独有系数在 0.996 至 1.002，五台的总 IQ 编辑量中位数仍为 30%。Full 的公共和独有系数中位数分别为 1.006 至 1.033 和 1.024 至 1.048，实际编辑 RMS 为 26.0% 至 30.0%。接收方差相对同外带真实方差的低城区中位偏差，在 Full 为公共 +0.48 dB、独有 +0.09 dB，在 Residual 为公共 +0.07 dB、独有−1.45 dB。此方差误差来自评分后隔离审计。
