# LoRa DURA 近载频相位对齐与整包注意力

在上轮固定源域面板中，每条路线、每景抽取 150 个已核实的源包，5 台源 RX 各 30 个。对照使用同一 practical 波形减去已知的新增噪声。低城区独立跟踪的载波频偏误差中位数／90 分位为 full 2.83／31.84 Hz、residual 8.37／75.21 Hz。将各 chirp 向整包中位值收拢后，full 变为 2.81／30.08 Hz，residual 变为 12.20／125.14 Hz。对应的无新增噪声 residual 包内频偏离散中位数／90 分位为 156.94／641.01 Hz。两个高郊区对照的独立跟踪误差中位数均低于 0.8 Hz。每个 chirp 保持独立频偏跟踪。相位校正用于同一包各 chirp 之间传递频谱上下文。

## 配方

保留同一次注册接收的六条 chirp。两臂共用原模型的伴随 chirp 均值和同一基础局部提议。新增注意力分支读取接收 IQ、冻结宽带恢复 IQ、估计质量、相对 chirp 位置和有符号频率。整包臂在 1–32 kHz 频带对齐并聚合六条 chirp。对照臂将新增注意力限制在当前 chirp。两臂使用相同初始化、数据和损失，初始输出逐值等于冻结宽带。两段近载频修正保留各自 RMS，其他频点逐值保留。冻结成熟 DURA 半量和匹配 full/residual 的宽带父模型。

两路分别使用 5 台源 RX，每台 800 个 U 包训练，80 个 U 包留出。相同接收波形保留接收作用、尺度和 AGC，替换为两份独立噪声。选用两份均通过固定门的模拟观测。固定种子 2026112799，1700 步，每步 8 对观测。两臂使用与前一实验相同的近载频复数误差和 AdamW 1.5e-4 至 2e-5 余弦日程。一致性损失权重均为 0，记录其变化用于诊断。恢复器拟合阶段仅使用合法源 U IQ，读取 F、TX 真值、V 和目标的次数均为 0。

## 固定验证与发布

预先固定 900 个源 V 包，每台 RX 180 个，排除宽带分带和上一轮近载频的评分面板。沿用冻结 Tri-set 2026092702。八种读出覆盖七景，分别是直通、成熟 DURA 半量、冻结宽带、自注意力对照、相位对齐整包注意力、整包半步、等幅已知近载频方向及精确扣噪。预测全部写入后独立读取 V 标签，同包比较逐 RX 正确数、纠错和改错。本轮源域诊断的正式目标仍是 15 台未见目标 RX、三种子六景平均至少 67.0%、低城区至少 43.0%，且 clean 至少 64,490/90,000。

发布入口 `python -m experiments.pamf_lora_main.packet_near_source publish`，使用已核实的 LoRa Python、源上下文、普通账户和残差 practical 父发布记录。N607 使用提交打包的发布 CWD，新 release 和 run 输入输出均有固定位置。候选 GPU 优先级 3、6、2、0、4、1、5，分卡各一路，总可见计算进程少于四个时启用。真实源 smoke 核查重放、冻结权重、梯度和数值。如数据角色、父模型、重放、训练数值或评分闭合存在系统性错误，停止继续派发并保留已存产物。预期产物为独立 smoke、两路双臂权重、训练和留出轨迹、七景预测及独立评分。
