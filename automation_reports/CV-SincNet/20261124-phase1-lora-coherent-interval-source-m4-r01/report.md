# LoRa 可信公共复谱区间保护与联合恢复

[配置和冻结矩阵](experiment.json) · [执行记录](events.jsonl) · [上一轮方差匹配消融](../20261124-phase1-lora-variance-transport-source-m2-r01/report.md)

## 可用信息和方法

上轮方差匹配在物理 RMS 相同的条件下提高两条路线的正确数。公共分量提供主要收益，但固定增益在 residual 低城区进一步放大已偏高的公共功率。本轮将逐频点的幅相保护放进粗恢复和细化，所需统计来自当前包和合法源 U。

| 接收或部署统计 | 推理取值 | 误差 |
| --- | --- | --- |
| 当前 6 条实收 IQ、公开上扫参考与配准质量 | 六个 256 点裁窗到齐。先去扫，按粗峰和短滞后细校估计内部相位坐标，以同一坐标回写 | 上扫频偏与时偏可混合，窗口边缘及残余时频误差会改变重复性。 |
| 相对作用 `Â` | 每 32 点以其余各 chirp 为参考，做正则复增益拟合，再按有效能量和失配收缩 | 该量含相对传播、硬件差异和残余同步。绝对传播作用无法由该量单独确定。 |
| 外带 `σ̂²` | 去扫后从两类谱统计。短时时频窗上估算方差并输入粗细层，整窗分别估计公共外带功率和逐 chirp 的扰动 RMS | 波形泄漏、有色和组间相关干扰造成偏差。它衡量可用功率代理。 |
| 公共复谱交叉功率和源功率包络 | 按配准质量加权得到奇、偶两组平均谱。在每个频点取实部交叉功率，扣 1.5 倍公共外带功率，分母含两组离差。真实源 U 的逐频点公共功率 99% 分位提供包络 | 两组共享失真时，较高交叉功率可能来自共同干扰。源包络随未见接收设置变化，事后分别报告支持频点上的复保真。 |

对 1–32 kHz 每个非载波频点，将普通恢复的公共编辑分解为沿实收公共复数方向的实部和垂直方向。以经外带修正的证据设幅度下限、限制向上编辑，并限制相位偏离。对区间投影按置信度插值。保护只处理公共编辑，独有残差直接继承普通提案。匹配训练臂保留普通编辑的复方向，使用同频点、同计算坐标的编辑能量标量。粗恢复投影后进入细网络，最终提案再次投影。给同一冻结区间权重做方向／标量消融，按两种编辑的原 IQ 物理 RMS 较小值匹配最终剂量。两臂还都按当前外带扰动将物理 RMS 上限从 7% 连续调整至 20%。Clean 旁路时逐元素复制。交叉谱测量方法需要可信的组间非共同扰动，短时谱幅估计同类工作也在其他任务中讨论了幅度和相位。本轮检验的是 LoRa 上扫重复、当前包约束、原坐标复 IQ 输出和设备识别。 [交叉谱原文](https://arxiv.org/abs/1003.0113) · [Ephraim 与 Malah 相位与幅度原文](https://malah.net.technion.ac.il/files/2017/09/Malah_Y-Ephraim_enhancement_1984.pdf)

## 训练和测试

两个 5,797 参数候选都从零训练，使用相同的 20,000 个合法源 U 包及相同扰动抽样。保留互斥的 2,500 个校准包和 500 个留出包。每臂 batch 24，单优化器 AdamW 连续 40,000 步。粗和细的波形风险、独立受扰视图一致性、先验方差似然及真实源 IQ 公共／独有弱差异在同一循环优化。相同扰动观测上的弱变化由真实源 U 波形差异构造。通用扰动的生成参数、精确信道与噪声、TX 标签、V、F 和目标数据均对训练隔离。终步直接冻结。

两条路线共用冻结的两臂权重、门限与规则。源 V 配对测试使用同一 900 个物理包、Tri-set seed 2026092702、clean 和六景。矩阵含直通和匹配半量 DURA，两臂各自的粗／全／半量，同权重等物理 RMS、关闭保护、关闭 `Â`、关闭 `σ̂²`。两条路线的全部同包预测落盘后，独立 CPU 才读源标签。主读出为区间全量。只有两路均超过同口径 DURA 六景并保持 clean，才进入正式目标矩阵。 [代码](../../../experiments/pamf_lora_main/coherent_interval.py) · [本地验证](../../../tests/test_lora_coherent_interval.py)

## 运行核验

N607 发布、实际执行及最终输出独立核验为 VERIFIED。执行提交 `119aecf077d5b0071f8b2b38f2c673beb961dff5`。归档对比、远端编译、单步真实源检查、终步真实权重 no-query 检查及独立 P0/P1 复核通过。标量臂在 GPU 6 训练 1,522.86 秒，区间臂在 GPU 3 训练 1,503.83 秒。均连续完成 40,000 步，各有 801 条有限值训练记录，峰值 CUDA 分配均为 450.81 MiB。两组冻结门限为 0.0372647159。Full、residual 分别在 GPU 1、6 完成预测，后置独立评分。候选拟合及整个评分无目标访问。

RTX 3090 的区间臂 B1 中位单包时延，clean 旁路为 1.84 ms，通用扰动触发为 8.09 ms。各测 20 次，含配准及粗／全／半量读出，不计识别器。固定留出终步，标量与区间的细化复谱风险分别为 2.60054 和 2.60052，公共弱谱差异误差为 0.002871 和 0.002881，独有误差为 0.008903 和 0.008974。两组平均保护置信均为 0.02374。

## 逐频带归因

完成冻结评分后，对相同的 900 个物理包重放。用直通的配准坐标和同一个复数标量把配对源参考对齐到实收坐标，独立审核置信不低于 0.10 的频点。低城区 9–32 kHz 的公共复谱，共有 `900 × 48 = 43,200` 个包内频点。Full 的支持点为 11,085（25.66%），residual 为 320（0.74%）。直通相对对齐源的归一化复相关实部，在支持点和其余点分别为 full 0.295 与 0.029、residual 0.551 与 0.097。当前置信能找到一批与源幅相更一致的频点，但在 residual 高扰动下可保护的覆盖很小。

低城区 9–32 kHz 对同包精确扣噪参考，区间全量的复谱 NMSE 分别为 3.595 和 52.905，直通为 19.760 和 110.867。用同一权重关闭公共保护后，NMSE 约为 3.552 和 52.868。公共区间约束只贡献很小的输出差异，主要波形变化来自联合粗细层。对两路线稳定提高识别，仍需从包内取得能覆盖受损频点的观测依据。精确噪声与配对 IQ 只进入事后计量。 [幅相复核脚本](../../../tools/lora_local_phase_fidelity.py)
