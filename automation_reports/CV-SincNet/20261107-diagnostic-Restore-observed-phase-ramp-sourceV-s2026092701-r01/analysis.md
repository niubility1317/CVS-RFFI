# 从接收观测校正信道相位和漂移

低档城区的 120 条源记录中，原盲估、相位校正、相位加漂移和已知模拟路径的 F(clean) 判决一致率依次为 81.67%、86.67%、76.67% 和 90.00%。两条校正的配对修复／损伤分别为 7／1 和 4／10。

冻结原 CovarianceMAP E30 的物理估计器和源 IQ 先验。在盲估算子的接收端引入整体旋转和随时间线性变化的相位，利用同一条接收 IQ 和原源高斯先验计算边缘似然。均匀取 256 个整体角度，9 个漂移格点覆盖整段 −45° 到 +45°。两者使用 15° 尺度的零中心离散高斯先验。此参数在运行前固定，未根据任何分数挑角或扫描超参数。

标量噪声下，每个旋转的观测协方差由同一个矩阵做正交相似变换。三条盲估路径共用一次 Cholesky，对转回原坐标的条件后验按似然和先验加权。原估计器本身来自接收 IQ，因此把它的算子和噪声当作固定量使用是一个似然代理。源模拟真参数只在已知模拟对照和冻结误差计算中使用。

## 物理误差与部署边界

低档城区的平均模拟 Action 相对 MSE 由 0.021806，经整体相位校正为 0.019304，经相位加漂移校正为 0.023791。这里比较的是加权平均旋转算子与模拟参考，已知路径使用缓存真算子。F(clean) 一致率衡量复现同一冻结识别器的 clean 判决，真实 TX 和目标数据均未读取。
整体相位版在固定源面板的七景一致率均至少持平，但 clean 的波形误差从 0.000018 升至 0.002699。相位加漂移在源 clean 损伤 10 条一致判决，低档城区净少 6 条。整体相位版可作为原 E30 权重的一次冻结推理对照，完整 Main 仍须检验两总体 clean 与六景真实 TX。
