# 原 F＋跨 RX50：源验证特征几何诊断

使用已预登记的三个本机 BASE final50 student，完整前向同一源 V 27000 个物理样本，统计实际部署 joint160 的类内离散、跨 RX/day 漂移和类间角度。零训练，不拟合分类头，不用原型作分类决策。当前八行正式训练及 clean 测试矩阵保持原计划。

数据契约、类别、源 RX1/3/4/6/8、day1/2/3、split392005 均复用已有合法来源；只读 V，L_s/U_s/target/truth 不读取。默认头及全部参数、buffer 保持不变。每模型先真实 checkpoint 零输入 smoke，通过后立即继续本模型 V。参考实现为原训练 commit31467086c3ced30237f3ac86e91eae68645425d7；分析实现由本次 Git 提交标识。

唯一一次独立 P0/P1 审查与角度数值检查、协议负例完成后发布。一个本机 GPU0 worker 顺序处理三个模型；全 owner source/predict 并行最多3，空闲系统内存至少4.5GiB。任何角色、参考实现、checkpoint、shape、数值或状态不符即停止该诊断，保留产物和其他健康进程。输出目录不可覆盖。具体命令、矩阵、停止规则见 experiment.json。

部分冻结目标结果已暴露，因此本分析是探索性源诊断，不声称新的盲测，也不把源几何当成目标准确率。各类别使用同一公式，不按目标分数排名或拟合权重。私有特征和 checkpoint 留在本机，仅聚合数值与实现进入 Git。

## 完整源几何结果

三个固定 BASE 模型均完成27000个V样本，共81000次特征前向，耗时29.13秒（包含模型首轮初始化）；峰值CUDA分配不超过92.38MiB。三个真实checkpoint的无query smoke均PASS，模型参数/buffer不变，训练、分类头拟合、目标、U真值读取均为0。

“角度离散/漂移”为1−cos，越小越集中；类间间隔为1−最近其他类质心余弦。留出RX间隔：样本对其他源RX同类均值的余弦，减去对其他源RX异类均值的最大余弦，只统计连续几何量，不产生原型分类预测。逐seed、逐RX及6×6类间余弦矩阵见result.json。

20-19的相对跨RX漂移均值0.43360，留出RX q10仅0.00565±0.01536，表明其类间间隔更易受到接收机变化影响。14-7与20-19是最近类对，跨seed均值余弦0.92623。6-15的绝对类内离散更大，但类间余量也更大，说明单独追求类内更紧不能完整解释可分性。以上是源域描述性证据，不等于目标改善或因果证明。

下一步可据此研究只在L_s训练中建立的跨RX难正对/近异类约束；不从V拟合分类器，不把V质心带入部署，不按目标类别难度设特殊分支。当前八行试验及扩种子规则保持不变。
