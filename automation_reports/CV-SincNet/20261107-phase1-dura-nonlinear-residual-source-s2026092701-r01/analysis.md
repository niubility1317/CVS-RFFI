# DURA 源非线性残差可预测性

在已探索的 32768 个合法源物理 ID 中，按固定索引模 8 划分 28672 个拟合、4096 个留出 ID，三个模拟视图始终归于同一侧。使用已冻结的 received 与 DURA IQ，按拟合侧可观测噪声比四分位拟合全局或分组复岭回归。线性模型包含四个原／共轭特征；三次模型在此基础上加入八个幅度相关特征。拟合使用源 clean IQ，不使用 F、TX 标签、V 或目标；拟合系数未保存。

相对 DURA，三次分组平均 NMSE 降低约 0.053%，5901/12288 条降低；与线性分组相比，三次分组有 7084/12288 条降低，但平均 NMSE 略高。最高噪声四分位内，三个视图中有两个的三次分组平均 NMSE 高于 DURA。结论取决于此固定特征、岭系数和源样本，不能视为非线性方法的上界。

DURA 可能见过这些源记录。留出划分只适用于本次回归，不构成 DURA 的严格未见源评估；波形 NMSE 不等于 TX 身份准确率。该分析没有形成新的正式恢复网络，不据此访问目标或取代逐版七景测试。完整输出位于登记的本机独立目录；执行 16.77 秒，源缓存准备成本另计。
