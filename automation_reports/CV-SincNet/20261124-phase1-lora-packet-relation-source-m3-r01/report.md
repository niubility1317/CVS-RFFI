# LoRa 同接收机源包的复谱关系保真

## 预登记

单包耦合自助法在四个低强度回放组中选中了波形平方误差更小的端点，但 Residual 的实际识别更低。本轮在恢复训练中保留不同真实源包之间的复谱关系，避免仅用单包点误差表示可区分的信息。已有真实源差异损失比较两个加扰源包输出的复差，已有私有方向约束比较每个包自身光谱方向，本轮保留上述固定配方，增加与同批其他清洁包之间的复数关系。 [单包校验](../20261124-phase1-lora-fission-risk-source-m2-r01/report.md) · [真实源差比较](../20261124-phase1-lora-real-source-pair-contrast-m4-r01/report.md) · [冻结匹配训练](../20261124-phase1-lora-private-direction-risk-source-m3-r01/report.md)

沿用原始 IQ 的两个正负噪声输入和两条弱差分输入。对原包的正负噪声半量输出分别转换到对应源 clean 的去扫坐标，按 1–8、9–32 kHz 分离包内公共谱和各 chirp 私有谱。对同一接收机的小批量，按视图在包维去均值，再用同批 clean 每包每带功率加 2e-4 的平方根作为共同尺度。把每个恢复输出与其他清洁包的复内积同两个 clean 包的内积比较。复差同时约束实部与虚部，同一条样本作锚的对角项屏蔽。对偏差模方取 log1p，四个组件等权。权重 0.30，并保留原 0.20 私有谱方向偏差及噪声损失。相关工作以样本间关系约束神经网络特征，本轮锚点直接来自合法源 clean IQ，无教师特征、发射机真值或识别器输入。 [Tung 与 Mori 原论文](https://openaccess.thecvf.com/content_ICCV_2019/html/Tung_Similarity-Preserving_Knowledge_Distillation_ICCV_2019_paper.html) · [Park 等原论文](https://openaccess.thecvf.com/content_CVPR_2019/html/Park_Relational_Knowledge_Distillation_CVPR_2019_paper.html)

匹配对照固定为已完成的 direction_risk。新臂沿用其训练数据和初始化，从零做一次联合训练，5,000 个无标签源 U clean 拟合、2,500 个源 U clean 核对原门限、500 个独立源 U 留出，3,600 步，每步 12 包及四观测。完全复用原扰动及随机流，实收模型、门限和读出保持一致。新增关系损失只用于拟合及隔离诊断，部署仍仅依赖单包实收。合法源 U、通用扰动与源留出完全隔离目标和识别器。冻结后两路各使用同一单种子冻结 Tri-set 2026092702、各 900 个源 V 包的七景及共同 11,100 个 clean 补集。对全部冻结预测独立接入源 V 真值。半量为主，要求两路六景超过 direction_risk、秩四半量和匹配 DURA，两路低城区至少持平 DURA，源 clean 完整正确数至少持平直通。另报告同包配对区间、B1 与留出源 U 波形及关系。

10 项定向测试、CLI 与一次独立 P0/P1 审查通过。执行提交 af06e182d2ef259462232c4194bb6138288890c6。N607 使用真实冻结识别器的无目标 smoke，之后训练、冻结、双路预测、clean 补集和独立评分。无目标读取。

## 识别损益与关系保真

相对匹配 direction_risk 半量，新增关系损失使 Full 六景净少判对 45 次（95% 区间 [−76, −12]），Residual 少 78 次（[−119, −37]）。低城区对应少 33、24 包。相对匹配 DURA，两路六景分别少 43、104 次。Residual 粗读出比匹配粗读出多判对 35 次，但仍比 DURA 少 143 次。完整 clean 的类别与直通逐包一致，共 8,986 条正确。本轮主读出未通过双路筛选，没有进入正式目标矩阵。

在与训练分布相同的 150 包通用扰动留出中，关系组公共近带风险从 3.1241 降到 3.0351，公共中带从 0.4540 降到 0.4383。私有近带从 4.4224 降到 4.3944，私有中带从 0.0194 升到 0.0222。低城区实际回放的公共近带关系误差在 Full 从 0.0904 升到 0.2809，在 Residual 从 0.1472 升到 0.2144。相同的同 RX 复谱关系在通用扰动和登记回放下没有得到一致改善。当前源 clean 关系项及固定权重没有可复现的双路识别收益。

留出审计首轮在一套通用扰动调用中漏开关系风险统计。独立补算后，两套通用扰动的两个权重都保存了完整 14 项风险。实际回放的关系和幅相、正式源预测及独立评分未受影响。
