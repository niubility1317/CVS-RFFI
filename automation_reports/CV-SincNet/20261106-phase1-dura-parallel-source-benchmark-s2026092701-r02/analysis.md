# 三个并行独立进程与共享推理：源域对照

三个冻结的 DURA 正交恢复模型，对同一批 112 条源 L_s/U_s IQ（14 组 × 8 条）在 N607 CPU 上运行。独立方案使用三个进程、每个进程两个线程；共享方案使用一个进程、两个线程。两者 batch 8，均输出物理上下文、恢复 IQ 与分类器 logits。

| 方案 | 本次耗时 |
|---|---:|
| 三个独立进程并行 | 2.033826 秒 |
| 一个共享进程 | 2.387686 秒 |

共享相对并行的速度比为 0.852，其耗时约高 17.4%。这是一轮小规模测量；各自不含模型加载和进程启动，均包含输出编码，独立并行侧另包含输出传回。不能外推到不同批量、GPU 或其他机器。

对全部 112 条、三个模型逐批比较 DURA 上下文、恢复 IQ 和分类器 logits，数据类型、形状与逐字节输出一致；未读取 TX 真值、V 或目标数据。该检查不能证明完整 168000 × 7 测试输出一致。已有正式预测均未迁移或中断。当前证据不支持为这三条 CPU 并行任务切换至单进程共享路径。

r01 的真实权重源 smoke 后，子进程因冻结模型加载修改的模块搜索路径触发导入冲突，未得到测速结果；r02 在子进程启动时恢复加载前路径，并在进程异常退出时执行受限清理，完成测量。远端证据：runs/20261106-phase1-dura-parallel-source-benchmark-s2026092701-r02/result.json。
