# Sinc Hz 参数优化尺度源域诊断

当前48行半监督训练保持不变。日志encoder相对位移约1e-7，fusion约2.5%至18.5%；整体encoder范数可能被Hz频率参数主导，不能把此数直接解释为全部骨干几乎不动。

诊断以三个原CE E200权重、完整6300合法L_s的确定性CE梯度为输入。每批独立参数副本做fresh AdamW首步，比较三档LR与原Hz/f/fs坐标。u=f/fs时梯度由链式法则变为fs×g_f；映回Hz后比较实际float32变化，区分非零梯度与真实零更新。原模型参数精确逐项检查不变，真实optimizer更新0；不用U标签、U样本、V前向/拟合或target。此诊断不能代表运行中SSL的累积Adam状态，也不能证明跨RX测试提升。原始父来源、source角色与预算复用原契约，CPU执行。

只输出诊断数值，不生成新预测模型，因此target测试N/A；不依据诊断热修改健康训练。若发现尺度问题，后续新机制需单独固定源规则/预登记/实现验证后才发布。

## 完成结果与调优力度判断

VERIFIED：执行提交 `ad20545a0b4366fe24589b2c0c7bdf9373da6c26`，单个 CPU 诊断进程 PID 4034075，21.0745 秒完成。独立读回每个 seed 的 50 批原始记录、合计 6300 个 L_s 样本，频率参数每批六个坐标/学习率比较完整。三个模型的全部身份参数精确保持不变，真实身份更新为 0，U 样本/目标访问为 0；已有 V 缓存可反序列化，没有 V 前向、拟合或选择。原始批记录保存在 evidence。

三个 seed 均出现同一结果：原始 Hz 坐标的 LR=3e-5 与 1e-4 下，非零梯度但实际 float32 参数更新为零的比例是 100%。LR=3e-4 下平均 low/band 变化分别仅 0.080341/0.040188 Hz；不能把该变化直接解释为有效梯度学习，AdamW 的乘法 weight decay 也参与了更新。

频率参数以 25 MHz 采样率对应的原始 Hz 存储；高端 low/band 的 float32 间距达到 0.5/0.25 Hz。身份参数整体范数约 12,488,565，去除频率参数后仅 64.76 至 65.05。因此此前整体 encoder 相对变化很小不能证明所有卷积和融合权重都被冻结；Hz 量纲主导分母。

把独立参数副本改用 u=f/fs，链式梯度 g_u=fs*g_f 后，三个 seed 的非零梯度零更新比例都降至 0。LR=3e-5 时平均 low 变化 730.54 至 735.70 Hz、band 变化 695.58 至 701.25 Hz；LR=1e-4 约 2.3 至 2.5 kHz，LR=3e-4 约 7 kHz。这证明坐标影响实际调优力度，也说明直接沿用普通网络的较大 LR 到归一化频率参数可能造成过大物理步长。

以上是原始 E200 上每批重新初始化 AdamW 的一次虚拟更新，**不是当前半监督优化器轨迹，也不是 clean 泛化提升证据**。源域 CE 已很小（0.0003215 至 0.0003713），其梯度尺度也不能代表 SSL 与辅助损失的梯度。

## 后续优化设计（尚未发布新的训练矩阵）

继续执行已冻结的 48 行半监督矩阵：身份 encoder/head 从 3e-5/1e-4 到 1e-4/3e-4，再到 3e-4/1e-3；全身份骨干更新，40 epoch，同预算对照，逐行自动 clean 测试。当前健康训练不修改。

下一版把普通卷积/融合权重、分类头、物理频率参数分组。频率使用 u=f/fs 的优化坐标或等价的高精度主副本，以物理 Hz 步长独立记录和限制；E200 初始化前向必须保持一致，AdamW moments 的坐标与 checkpoint 恢复必须一致。先以源域检验有效频率边界、最小带宽、Nyquist 裁剪和实际参数变化，再预登记训练。不能直接把上述 750 至 7500 Hz 的诊断步长当成最佳设置。

监测强度按模块报告真实 delta 与初始范数，频率另报 Hz 变化、非零梯度零更新率、有效滤波器变化；不能继续只用混合量纲的整体范数。源 V 可用于固定的合法诊断，目标结果不回流设置新参数或选择性重跑。
