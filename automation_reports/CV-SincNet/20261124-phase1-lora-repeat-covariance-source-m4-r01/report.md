# LoRa 跨 chirp 噪声协方差白化与匹配恢复

## 预登记

前期同包诊断发现，给原短时 Wiener 读出换用精确总噪声功率并未带来识别收益。隔离扣噪比全量 Wiener 在 full、residual 分别多判对 423 和 871 次。这轮检验噪声相关方向的估计价值。输入只用当前 LoRa 接收包的 6 个已登记 256 点 chirp，沿用共识前导追踪取得各 chirp 的旋转、载波相干性及归一化坐标。训练与推理使用同一追踪，修改量回写到原实收坐标，保留每条 chirp 的复载波及原包时序。

把同频 bin 的 6 条去扫频谱组成复向量。用两侧 |f|≥96 kHz 的包内频点估计 6×6 外带噪声协方差，限制单点过大能量的影响。候选保留 75% 的非对角元素，匹配对照取同估计的对角。两组均加入相同的对角下界。按 8 个 bin 分块，以相邻三块估计白化 IQ 在重复轴上的局部协方差，并在其复数特征向量坐标做 Wiener 式软收缩。粗层学习修正收缩率，细化层再用同一观测的粗修正能量调整权重。两层在同一优化中训练。去扫直流先从子空间统计中排除并保留在输出。噪声协方差是从单包外带估计的代理，混入真实弱谱或缺少跨频稳定性时会失配。

两组完全匹配初始化、5,000 条合法源 U 拟合包、2,500 条独立 U 旁路校准、500 条留出 U、1,800 步、批量 12、AdamW 0.0002 至 0.00002。三视图使用真实源包之间的弱复谱差异及同噪声配对；扰动为独立通用短回波、复色噪声和连续比例的公共与独立噪声混合。生成器只返回 IQ，无实际基准算子、场景标签、逐点噪声、真值方差、F 或历史恢复权重监督。两路线共享每组一份权重及同一个干净源 U 的噪声旁路。固定评估粗恢复、细化全量及细化半量三种剂量。

## 验证

沿用 900 个相同源 V 物理包、两路线各七景、同一冻结 Tri-set seed 2026092702、直通和路线匹配成熟半量 DURA。先由真实权重在两条通用受扰的源 U 波形上完成无 query 检查。两条路线所有预测固定后独立 CPU 才依据物理 ID 读取源 V 真值。本次不接触目标。以按源 RX 分层的物理包区间报告匹配的跨 chirp 协方差增益，列出逐场景、逐接收机变化及 clean 正确数。只有同一固定读出在两条路线均超过匹配成熟 DURA 六景且保住 clean，才扩大正式目标验证。

N607 优先用有余量的不同 GPU，保留其他 owner 进程。遇到输入、冻结、数值或预测闭合异常时停止下游阶段。命令、配置、环境及产物见同目录登记。

## 相关工作

Ephraim 与 Van Trees 的信号子空间方法利用加性噪声下的信号、噪声协方差构造线性估计。Lev-Ari 与 Ephraim 研究了有色噪声下的子空间实现。这里的向量维度为同一包不同 chirp，而非语音帧或并行麦克风；噪声代理来自同包外带，二阶段软收缩由合法源 IQ 学习，评估标准包含冻结设备识别和原载波保真。 [子空间估计原论文](https://people-ece.vse.gmu.edu/~yephraim/Papers/sap%201995%20sig%20subspace.pdf) · [有色噪声子空间原论文](https://people-ece.vse.gmu.edu/~yephraim/Papers/spl%202003%20Sig%20Sub%20Colored%20Noise.pdf)

## 收缩饱和的隔离检查

从留出 U 固定抽取 50 个包，用新的通用扰动重放冻结网络。粗层对收缩 logit 的中位增量为对角组 8.93、协方差组 8.36，细化分别再加 3.32 和 2.60。两组终步输出相对实收观测只剩约 0.1105% 的非载波能量。两个输出之差的平均功率相对该观测非载波功率的中位数为 3.68×10⁻⁹。

当各特征方向的收缩率趋近同一个常数时，白化、特征向量投影和逆变换会抵消，最终只剩近似标量收缩。这解释了两臂的决策重合。实验定位了当前目标函数与收缩参数化的退化，尚未验证跨 chirp 协方差在保住弱复谱时的独立贡献。
