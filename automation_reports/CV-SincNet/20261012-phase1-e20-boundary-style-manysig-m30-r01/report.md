## 主身份浅、中层敏感度

层位固定 `time_down` 与 `t2.pool`。对实特征 H 引入临时坐标：H′=aH+b·stopgrad(std_t(H))，a=1、b=0，形状 [B,C,1]。这些坐标不是网络参数，不训练、不存储、不参与推理。恒等前向保留原判别输出。

身份间隔 m=z_y−logsumexp(z_{k≠y})。由于 CE=softplus(−m)，CE 梯度带有 p_y−1 的高置信度衰减因子；本方案直接计算 s=∂m/∂(a,b)，再用每样本 RMS 归一化 s/sqrt(mean(s²)+10⁻¹²)。归一化消除向量整体幅值，但不保证对任意 logits temperature 严格不变，也不证明物理可辨识。记录低范数比例，检查是否通过敏感度退化降低损失。

两个独立 L 批 A/B 各60样本：同一天，6TX×5RX×2，批内物理 ID 唯一，批间允许重叠。按有限 L 分层无偏方差估计，各 RX 的中心化方差向量取 A/B 内积。有符号交叉项允许负值，不截断。两个图均保留；二阶梯度通过主身份网络，可影响选定层上下游；浅层项不被强制隔断到浅层。这是 Fishr 式跨域敏感度方差约束，统计对象为 margin 对虚拟坐标的导数；不将其等同于标准损失对网络参数的经验 Fisher。

启用前仅用 L 做12对校准，各层固定系数 min(10000,0.2×平均 CE 梯度范数/(平均本层项梯度范数+eps))。margin 用自身新统计量，PROBE_FISH 沿用旧 probe 的 old-pair 参考范数，二者是完整机制比较，不能声称只改变统计坐标而完全等尺度。训练阶段固定系数只乘 ramp，层和固定除以2。前444步仅 L CE，随后888步线性 ramp；活跃阶段每4次身份更新执行辅助步骤，共999次、119880次 L 模型读出、1998次前向。不是每4个 epoch。

只有 PROBE_FISH 创建两个线性头：6300个 L 冻结特征，200次头更新，辅助 CE 不更新身份骨干；Fishr 中头停止梯度。新 margin 各行零辅助可训练参数，无头预热。所有辅助模型读出在 eval 下执行，恢复原训练状态及随机状态；主身份更新保持普通 dropout。

## 受控风格搜索

同 L 批、同 TX/day、跨 RX、不同真实物理 ID 选择 donor；允许采样器重复出现同一物理样本，但供受体必须不同 PID。浅层后接中层依次混合时序均值和标准差，保留归一化内容；p=1、Beta(0.1,0.1)、强度=ramp。不能将此特征插值直接解释为经过真实 IQ 验证的物理信道。

每步私有随机流生成4个双层候选，hard 与 random 使用同一候选生成规则。eval/no_grad 执行 clean＋4候选，hard 按整批真实 L CE 选最大值，平局最小索引；random 私有随机流选索引，承担相同5次 eval 前向成本。不能逐样本拼接不同候选，因为中层 donor 特征依赖上游候选。再恢复 train，回放所选候选的一次可导前向，加入主身份 CE，权重为 ramp。所选候选基于 eval 难度，train/dropout 中不保证仍最难，分别记录两种读出。

clean 与额外训练前向使用相同 dropout RNG，额外流程退出恢复主路径 RNG。L_REPLAY 额外一次 clean CE，无候选搜索或 hooks；RANDOM/HARD 成本匹配，STYLE 与 REPLAY 仅训练 CE 预算匹配，搜索成本不同，须如实报告。每个风格行3996次额外训练前向、511488次 L 读出；随机/困难搜索另有19980次 eval 前向、2557440次 L 读出。记录实际供体覆盖、特征变化、候选 CE、选择、eval/同掩码训练的身份差值。
