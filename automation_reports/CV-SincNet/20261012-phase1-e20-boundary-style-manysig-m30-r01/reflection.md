# 本轮设计前的反思

当前仍未证明达到 clean 三种子均值 84%。本轮设计依据上一轮已完成的源域方向诊断，不使用目标测试排名选择机制或参数。诊断证据见 `../20261012-phase1-e20-direction-audit-manysig-m3-r01/analysis.md` 与 `reflection.md`。

1. 辅助网络有可优化损失，不等于能约束身份判别。源域诊断中，旧 probe Fishr 与身份 CE 梯度的平均方向联系较弱。因此保留 PROBE_FISH 对照，同时把新统计直接定义在主身份 margin 对浅、中层坐标的敏感度上。是否提高泛化仍由冻结后的独立测试验证。
2. 随机风格变化不一定带来有效困难。合法供体和较大的特征位移也不能单独证明有用。本轮比较同候选、同搜索成本的随机选择与整批最大 L CE 选择，并保存 eval clean/候选读出。特征插值只是一种受控增强，不冒称真实信道反事实。
3. 额外前向和 dropout 会混淆增强作用。此次额外训练前向与 clean 使用相同掩码；L_REPLAY 识别额外监督作用，RANDOM_STYLE 与 HARD_STYLE 识别困难选择作用。搜索增加的五次 eval 不隐藏在“同20轮”中。
4. 数值小残差和梯度比例不能脱离分母解释。上一轮无实际风格改变时出现约1e-7量级的反传残差，不能归一化后作为方向证据。新日志保留实际层改变率、敏感度低范数率、原始范数及校准系数；大比例必须结合 CE 梯度绝对范数分析。
5. 解耦结构需要明确的层位和主路径作用。本轮浅层、中层、双层及联合方案全部预登记，二阶梯度可通过主身份网络上下游；新 margin 分支不增加身份提取骨干或辅助分类头。半监督 U 仍进入主身份 KL，辅助项不能取代对 U 的有效利用。

应避免用训练稳定、梯度非零或源域准确率高代替泛化结论。本轮保留全部30行结果和成本；完成前不宣称性能改善，完成后不依据测试排名选择性重跑。
