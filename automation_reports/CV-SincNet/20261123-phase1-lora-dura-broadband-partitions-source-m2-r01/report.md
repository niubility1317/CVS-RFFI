# LoRa DURA 冻结宽带向量的频带置换和组合

## 固定对照

沿用宽带训练先导中两路分别冻结的窄带、宽带模型，接同一成熟 DURA 恢复、同一保护门及观测对齐。Full 使用原复响应半量，residual 使用门控 R69 投影半量。读出对照先复现直通、成熟、学习窄带、学习宽带全量和半量。实际候选包括仅保留宽带近载频 1–32 kHz、仅保留 33–128 kHz、仅保留 65–128 kHz，以及用窄带模型接管 1–32 kHz、分别连接上述两种外侧更新。组合在整 chirp RMS 0.45 限幅内保留原宽带外侧向量，按剩余能量限制近载频向量。无模拟器轨迹、标签或额外观测用于这些实际读出。

以冻结宽带全量为共同底座。每次只替换去载波后双侧 1–8、9–32、33–64、65–128 kHz 的一个频带，或整个 1–32、33–128 kHz，或不含载波的全带。已知向量来自同物理包的源模拟无新增噪声接收，按父版整 chirp RMS 0.45 限幅后取对应频段。原幅度置换只固定其他频点，允许混合后的总量变化。等幅组把置换分量缩放到学习版在所选支持内的原 RMS，教师能量为零则保留原分量，在实际交付 IQ 上复算整 chirp RMS，差值上限 1e-6。另保留独立精确扣噪对照。已知分量仅用于源域归因。这一矩阵可区分局部方向和局部剂量误差。

固定同一 900 个源 V 物理包，每台源 RX 180 个、避开宽带训练的源评分面板，沿用 Tri-set 2026092702。两路线各评七景 × 25 个预定读出。全数预测先写出，再独立连接源 V 类别，报告 clean、六景、低城区、逐 RX、净纠错及配对区间。整个运行 G 更新和目标读取为零，固定目标继续是三种子六景至少 67.0%、低城区 43.0%、clean 至少 64,490/90,000。

## 发布

`20261123-phase1-lora-dura-broadband-partitions-source-m2-r01`，`python -m experiments.pamf_lora_main.broadband_partitions_source publish`。使用 N607 普通账户及既有 LoRa Python，独立不可覆盖 release/run，CWD 对应发布根。两条路线按 GPU 3、6、2、0、4、1、5 分卡，每卡总可见计算进程最多四个。源 smoke 用每路 15 个包验证 clean 门、低城区剂量、模型来源和有限性，无 F 与标签读取。坏合同、剂量失配、非有限或预测无法闭合停止后续派发并保留产物。输出两份真实源 smoke、两路七景预测和按 RX/物理 ID 的源评分。
