# Phase1 识别一致性引导的独立频域恢复

固定使用独立频域耦合网络（14,678 参数）及与基础版本相同的 8192 条源训练记录、三个源视图、五轮预算、初始化和优化器；该模型不调用 DURA 或物理后验。唯一方法变化为源训练损失：归一化配对波形误差，加 0.2 倍冻结 Tri-SIG-TIME SSL 特征余弦误差，加 0.2 倍温度 2 的冻结基座软类别分布 KL，再加 0.05 倍置信度加权的伪类别间隔损失。伪类别及目标间隔由配对干净源 IQ 的冻结基座输出生成，间隔上限 4；不直接读取 TX 身份。该方法明确属于 F-guided，伪类别可能错误，不能当作身份真值。

盲噪声估计与输入保护门均使用既有冻结 source-only checkpoint，门关闭返回输入。推理只输入当前受损 IQ，不使用源干净 IQ、TX 身份、其他样本或真值。源记录及不同视图已被探索，非独立盲测；测试数据不得用于训练、选模或调整超参数。

先完成 64 条源训练与 28 条源评估记录的真实训练预检，通过后进行完整源训练，固定 672 条源预测，再独立连接合法 L_s 身份评分。新版本预登记 clean 和六个受损 Phase1 地面视图各 168000 条；七景预测全部固定后独立评分、审计并报告跨 RX 与跨 RX+day。总集 clean 基准 86.538690%，相对下降 3% 的门槛 83.942530%，另报告下降 3 个百分点的门槛 83.538690%。已反复探索的地面开发测试不代表真实卫星链路。

源实验 `20261102-phase1-spectral-margin-source-s2026092701-r01`、地面实验 `20261102-phase1-spectral-margin-ground-test-s2026092701-r01`。CPU 两线程，负载超过 72 等待；独立不可覆盖输出和 truth-last 评分，低分不停止健康任务。基础频域网络与本版本地面结果仅作固定后对照，不根据已看测试结果重选模型或权重。
