# 大型时频网络前向分段 GPU 计时

在共享 RTX 3090 GPU2 上，用固定 128 条合法源 IQ、batch 128、deterministic FP32 且关闭 TF32，检查 CrossExpertRefiner 的前向各阶段。固定种子将时域和频域输出头初始化为标准差 0.001 的非零正态值，以便两个分支均影响输出；这不是在训模型的 checkpoint。先热身，再运行原始参考前向和两次逐阶段同步前向；每次以 uint8 字节视图核对整个输出与原 forward，均完全一致。未使用 F、TX 标签、V 或目标，未更新或保存模型。

| 分段 | 第一次 | 第二次 |
|---|---:|---:|
| 输入归一化及拼接 | 0.000834 秒 | 0.000952 秒 |
| FFT 及频域输入拼接 | 0.000777 秒 | 0.001455 秒 |
| 时域卷积分支 | 46.165865 秒 | 46.217891 秒 |
| 频域卷积分支 | 21.687357 秒 | 22.623992 秒 |
| IFFT 及输出合成 | 0.001081 秒 | 0.001075 秒 |

两次观测中时域与频域网络分支占前向绝大多数时间，FFT/IFFT 本身较短。这一检查以阶段同步来划分耗时，只测固定单批、两次前向，GPU 同时运行其他 owner 任务；不能据此归因具体算子、外推真实完整训练吞吐或宣称加速。输出逐字节一致仅覆盖这个固定批次和诊断模型，不构成全输入或最终训练测试一致性保证；现有在训模型未改动。
