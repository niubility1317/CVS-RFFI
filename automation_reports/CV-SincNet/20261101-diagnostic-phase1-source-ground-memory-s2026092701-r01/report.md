# Phase1 source ground memory and contrastive retrieval

These experiments use frozen Tri-SIG-TIME SSL and DURA and only Phase1 source training signals. They evaluate retrieval of device classes, not recovery of waveforms and not Phase1 target-test accuracy. Source splits are receiver 1/3/4, days 1/2 for fitting the memory and network; receiver 4/6, day 3 for validation; receiver 8, day 3 for holdout. Physical IDs do not overlap across these splits. Frozen experts have seen source records; IDs can overlap earlier diagnostics. Source targets mix true L_s labels and U_s clean-teacher pseudo-labels with confidence at least 0.95. The source-label helper loads all L_s labels but evaluation labels are discarded before the fixed retrieval decisions. No U_s true labels, validation IQ or test IQ were used. Simulated satellite channels are not validated real satellite links.

The clean-source feature memory contains 1,577 training features across six classes. On 287 valid low-urban holdout targets, DURA is correct 255; direct 1/5/15/30 nearest-neighbor classification gives 251/252/252/251, and class-centroid classification 252. Of 32 DURA errors, only six have their target class among the 30 closest references. Target-class coverage is an oracle diagnostic, not a deployable accuracy or a bound on arbitrary retrieval networks.

A two-layer shared feature embedding was trained using class-supervised contrastive and paired clean/degraded alignment objectives, on 1,612 source training IDs (1,577 usable memory IDs). The strongest validation combination had aggregate +1 correct across three impaired views, but receiver 6 low urban was -4 and its clean view was -1. The predeclared per-receiver protections rejected all 20 epoch/retrieval combinations, retaining DURA. The receiver-8 holdout was not evaluated for this learned network. Source validation observations informed the next action but do not establish target performance.

The independent complete reruns reproduced both JSON artifacts exactly; the smoke runs exercised source sampling, model training and retrieval. Protocol manifests record source code and dependency SHA-256 values before full execution.
