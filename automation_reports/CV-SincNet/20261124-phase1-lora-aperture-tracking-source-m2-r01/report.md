# LoRa 双孔径有效频偏与原坐标恢复

[预登记](experiment.json) · [运行事件](events.jsonl)

## 方法与权限

输入为两路线共同提供的六条 256 点前导 IQ 及公开上扫模板。在每条去扫频的两个不重叠 128 点 Hann 孔径上计算 2,048 点功率谱，用平均对数归一化功率找到共同可信的峰。相邻三个点插值。局部峰不一致时缩小对原独立峰的更改，单条更改限制在一个 256 点频点。随后估计由孔径分歧引起的内部不确定性和跨 chirp 可见离差，比对两者后对高不确定 chirp 作有限收缩。

相对同步只改各条估计相对包内中值的频偏，保留包内中值、样点和幅度。另把旧独立、双孔径及自适应频偏仅用于 Wiener 内部跟踪，估计方差、半量剂量相同，各自的修正回到原 IQ 坐标。门限由 2,500 个合法源 U 的未加扰样本固定，计算取后验跟踪外带 RMS 的 1.05 倍最大值。无网络拟合、无可训练参数。基准只给上扫裁窗，局部斜率同时受频偏、时偏和源相位变化影响。孔径分歧是观测代理，真实的 chirp 内相位变化也会增大分歧。

Xhonneux 等介绍 LoRa 联合频偏和时偏估计，Tapparel 与 Burg 给出用完整前导改善采样偏移的两遍方法和作者实现。这里面对每条上扫的实际窗数据，保留包内绝对中心并按窗间分歧约束局部修正。在冻结复 IQ 识别任务上分别评价仅同步及同步坐标进入 Wiener 的收益。 [频偏和时偏估计原论文](https://arxiv.org/abs/1912.11344) · [两遍同步原论文](https://arxiv.org/abs/2502.08485) · [作者实现](https://github.com/tapparelj/gr-lora_sdr)

## 同包矩阵

固定两路线 900 个源 V 物理包、七景、同一 Tri-set 2026092702。统一比较直通、成熟半量 DURA、旧独立频偏的相对同步、双孔径相对同步、自适应相对同步的全量和半量，以及三种内部坐标的同方差 Wiener 半量。预测全固定后才由独立 CPU 打开源 V 真值。只有同一个读出在两路线均提高 DURA 六景正确数并保持 clean 才晋级。隔离误差归因在评分后核对同包实际仿真加性噪声，以扣噪但仍保留传播失配的 IQ 作为统计参考。

## 隔离估计误差

完成独立源 V 评分后，同物理 ID 重放两路线，用精确仿真新增噪声只在诊断侧构造扣噪参考。保留传播失配和硬件效应。参考有效频偏由固定旧独立跟踪器对扣噪波形估计，代表这套跟踪坐标，可能含源波形及多径偏差。相对误差按各估计和参考分别扣除包内中心后计算。重放的激活数与两路线已冻结预测逐景一致。下表统计门内样本，每格为逐 chirp 的中位数 / P90，单位 Hz。 [隔离归因代码](../../../tools/lora_aperture_frequency_diagnostic.py)

| 路线与场景 | 旧独立绝对误差 | 双孔径绝对误差 | 自适应绝对误差 | 扣噪后实际包内离差 |
| --- | ---: | ---: | ---: | ---: |
| Full 高强度郊区 | 1.30 / 9.14 | 8.37 / 22.30 | 8.36 / 22.22 | 3.06 / 15.04 |
| Full 低强度城区 | 6.43 / 42.16 | 16.16 / 65.95 | 15.76 / 60.29 | 5.86 / 21.42 |
| Residual 高强度郊区 | 0.84 / 2.39 | 8.12 / 15.19 | 8.18 / 15.33 | 55.15 / 168.42 |
| Residual 低强度城区 | 8.21 / 72.49 | 17.76 / 100.21 | 18.53 / 123.50 | 147.19 / 652.83 |

在 residual 低城区，三种相对误差依次为 14.19 / 92.76、22.52 / 127.60、23.99 / 152.05 Hz。双孔径即使用扣噪波形，较旧独立参考的频偏差仍为 8.69 / 19.49 Hz。这表明窗位置和加权改变有效频偏，估计误差的一部分与源波形或传播作用有关。Residual 的真实包内差异远大于独立跟踪的噪声扰动误差，在这里频偏融合不能代替实际复谱恢复。Full 的相对同步小幅收益也没有伴随参考偏差下降。该结果只支持保留旧独立估计作为当前工程对照。
