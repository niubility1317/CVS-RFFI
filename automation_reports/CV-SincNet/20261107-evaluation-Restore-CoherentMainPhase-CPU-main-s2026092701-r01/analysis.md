## 方法与结果边界

复用原 CovarianceMAP E30/7410 权重、源均值及全协方差，固定 256 个候选角度，从收到的 IQ 估计主路相位，再执行原后验恢复；本实验没有新增训练、模型更新、目标拟合或目标调参。新路径使用 N607 CPU 两线程，FP32 IQ/F0 与 FP64 观测因子/Cholesky；原版和 DURA 决策复用已有 GPU 缓存，运行设备和数值路径不同，差异不能只归因于相位方法。

合并后六个星地场景都高于原 CovarianceMAP，低档城区净多对 1739 条（+1.035119 个百分点）。跨接收机且跨日期总体的高档郊区、中档郊区、低档郊区分别比原版净少 38、106、4 条，不能把合并收益解释为每个总体均改善。相对 DURA，只有中档城区略高（+0.048810 个百分点），其余五景较低；低档城区距门槛仍少 25713 条。

低档城区准确率为 68.233333%，相当于 raw clean 准确率的 78.847199%；这只是任务准确率保留比例，不是 IQ 信息恢复率或理论上界。

这是一项固定单 seed、已曝光基准的对照。目标结果未用于选择参数、场景路由、重训或改动其他在训候选；默认 DURA 未更换。相位路径由此前合法源诊断固定，参见[源诊断](../20261107-diagnostic-Restore-coherent-main-phase-sourceV-s2026092701-r01/analysis.md)。

## 独立核验与成本

双总体七景四条决策流共 56 个单元全部固定后 truth-last；独立复算 1736 个分组和 1302 个 raw 配对，最大指标差 1.25e-14，原 raw/DURA 缓存判决差 0。新 G 训练更新为 0，父恢复器原训练为 30 轮。CPU 两线程源样本吞吐 19.20 条/秒是预测前测量，不能当作全量实测或 GPU 延迟。
