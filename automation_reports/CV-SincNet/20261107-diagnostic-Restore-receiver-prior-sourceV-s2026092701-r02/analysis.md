# IQ 先验对源接收机变化的敏感性

固定源 V480 的低档城区，盲估信道下全源、同 RX、其他 RX 先验的正确数为 401、412、341；已知模拟信道和噪声下为 426、434、379。raw clean 为 474。

仅用原 L_s/U_s 拟合均值和完整 512 维 IQ 协方差，沿原 0.001 的对角收缩。每个 RX 的同组先验使用该 RX 的 12,600 条训练记录。其他 RX 先验从另外四个 RX 各抽 3,150 条，每个 RX×day 保持 105 条 L_s 与 945 条 U_s。两种先验均为 1,260 L_s 和 11,340 U_s。全源先验使用原 63,000 条，样本量单独列为较大基准。

同 RX 和其他 RX 保持统计样本量与 L/U 配额，但改变了接收机组成。原全源同时包含五个 RX 且样本更多。同组先验不等于同包或同 TX 标签。当前结果仍同时包含均值、协方差与接收机组成的作用，未分离各项。整个诊断按已知源 RX 选先验，性能不能扩写到未知 Main 接收机或理论上界。
