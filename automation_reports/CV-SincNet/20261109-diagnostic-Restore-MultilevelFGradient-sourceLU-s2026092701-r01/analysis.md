# 源域多层特征与波形损失的输入梯度

**同一固定源恢复器的 28 条源样本中，F0 浅层与中层损失对恢复 IQ 的梯度方向较相近；它们与 F0 最终特征损失的梯度方向在多数样本上差别较大。** 这为研究多层特征约束提供线索，但不证明设备身份更易识别，也不证明增加该损失能改善星地测试。

## 固定方法

使用已核验源 CovarianceDetail final30、冻结的地面 Tri-SIG-TIME SSL F0，以及既有 R07 源训练配对 draw 1。七个源模拟场景中，每景按原顺序各取 2 条 L_s、2 条 U_s，共 28 条；这是训练内的固定非代表性小面板。恢复器和 F0 全程冻结，不读取 TX 标签、F0 分类 logits、V/OE 或目标数据，不更新任何模型。

对每条记录，先恢复受损 IQ，再将恢复输出作为独立可微输入，计算四项损失对这条恢复 IQ 的梯度：

- 波形损失：配对 IQ NMSE 加 0.05 倍多尺度 STFT 幅度误差。
- 最终特征损失：0.01 倍的 F0 fused160 余弦误差与源方差标准化均方误差之和。
- 浅层特征损失：time_down 输出与同条 clean 输出的均方差，除以该 clean 特征的均方能量。
- 中层特征损失：t2.pool 输出按同样方式计算；两层能量下限均为 1e-8。

实际记录的单条特征形状分别为浅层 48 × 128、中层 96 × 32、最终特征 160。下表为两条输入梯度的余弦；每对均为 28 条非零有限梯度。余弦接近 1 表示局部输入方向接近，接近 0 表示方向接近正交，负值表示钝角；它不直接说明 G 参数梯度、优化后的表示或发射机识别效果。

| 输入梯度对 | 余弦中位数 | 最小值 | 最大值 | 负值数量 |
|---|---:|---:|---:|---:|
| 波形／最终特征 | 0.1532 | 0.0557 | 0.2754 | 0/28 |
| 波形／浅层特征 | 0.2418 | 0.1323 | 0.4260 | 0/28 |
| 波形／中层特征 | 0.2368 | 0.0996 | 0.3625 | 0/28 |
| 最终／浅层特征 | 0.0553 | −0.0672 | 0.4882 | 1/28 |
| 最终／中层特征 | 0.0890 | −0.0235 | 0.8124 | 1/28 |
| 浅层／中层特征 | 0.8471 | 0.6218 | 0.9588 | 0/28 |

低城区仅 4 条，最终／中层梯度余弦分别为 0.0427、0.2393、0.0789、0.8124，差异较大，不能把总体中位数当作所有样本的性质。分别用 Python 标准库和 NumPy 从同一固定结果复算中位数与负值计数，结果一致；这只复核汇总运算，不是重新执行模型或独立测量梯度。

中层未加权损失的输入梯度范数与上述带 0.01 权重的最终特征损失之比，中位数为 47.03，范围为 3.51 至 196.93。比值受损失定义和权重影响，不是两层重要性的比较，也不是 G 参数更新比例；它提示新增中层损失时须明确权重及梯度控制，不能直接套用任意系数。

## 如何使用这一结果

可在原合法 L_s/U_s 配对上，将单个中间层连续特征与现有波形和最终特征目标组合，作为独立、同初始化和同预算的 F-guided 研究对照；clean 特征只在源训练时作为参考，部署仍只输入单条受损 IQ。浅层与中层在该面板方向相近，不能据此断言二者冗余或任一层更好。中层也可能强化波形内容、接收机或信道细节，造成身份与 clean 损伤；小样本梯度不同只是必要性线索，不是识别收益证据。

本结果来自历史 CovarianceDetail，而不是当前在训的宽时频恢复器，也未测试多层损失。任何新版本都须从零单阶段训练，遵守 F 指导和无 TX 标签权限，在冻结后完成两个总体的 clean 加六场景预测与独立 truth-last 评分；不能以源诊断或目标成绩事后选 checkpoint、选路或改变在训配置。
