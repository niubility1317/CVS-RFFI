# Phase1 DURA 锚定的频域耦合修正

固定原始两阶段 DURA，以其输出为锚点；独立频域耦合网络从当前接收 IQ 的七个复数频偏基生成连续后置修正。新增网络 14,678 参数，不含 DURA、盲噪声估计器、保护门及分类基座；零初始化严格保留 DURA，保护门关闭时返回 DURA。网络可表示跨频点耦合和完整一频点平移，推理只访问当前 IQ 和冻结 DURA 输出；不加载条件物理后验、设备身份或其他样本。

与 DURA 后置记忆版本使用相同 8192 条源训练记录、固定第 21、22、23 轮视图、五轮预算、初始化种子和优化器；两种网络参数化不同。训练损失为 ±64 点时移与复增益对齐的中央 IQ 误差，加 0.2 倍冻结 Tri-SIG-TIME SSL 特征误差、0.2 倍温度 2 软类别 KL、0.05 倍置信加权伪类别间隔和 0.05 倍截断对数功率比平方。对齐仅用当前训练配对；F、DURA、盲估计器及门控冻结。伪类别不是真实身份，本版本为 F-guided，不直接读取 TX 身份、U_s 真值、V 或地面测试。源记录已探索，非独立盲测。

CPU 上重算既有 672 条源记录的 DURA 分类与 GPU 源对照完全一致；该检查不保证 DURA 波形位级一致。先做 64 条源训练及 28 条源评估记录的真实训练预检，再完成完整训练并固定 672 条源预测，随后独立连接合法 L_s 身份评分。预先登记 clean 和六个受损 Phase1 地面视图各 168000 条，全部预测固定后独立评分及审计，并报告跨 RX 和跨 RX+day。总集 clean 基准 86.538690%，相对下降 3% 的门槛 83.942530%，另报告下降 3 个百分点的门槛 83.538690%；已反复探索的地面开发集不代表独立盲测或真实卫星链路。

源实验 `20261102-phase1-dura-spectral-residual-source-s2026092701-r01`，地面实验 `20261102-phase1-dura-spectral-residual-ground-test-s2026092701-r01`。CPU 两线程、负载超过 72 等待，独立不可覆盖输出、truth-last 评分，低分不停止健康任务。源或地面结果不得回流修改已固定模型。
