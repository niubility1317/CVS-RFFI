# LoRa 主载波分离的弱旁带监督

[预登记矩阵](experiment.json) · [运行事件](events.jsonl)

源 U 确认，同时依赖实收坐标的载波特征能够解释被跟踪误差移入弱带的载波能量。构造清晰参考时分离强载波，在接收坐标监督真实剩余信号。两臂都用同一个可部署接收入口、固定解析先验、粗细层、接收作用约束和训练预算。 [源 U 载波泄漏分离证据](../../../docs/analysis/LORA_CARRIER_LEAKAGE_20261124.md)

六条实收去扫窗由协议模板、有效频偏和实收载波相位提供内部基。原物理 IQ 尺度通过逐窗 RMS 回写。相对复作用与留出残差、外带方差沿用实收交叉留出与稳健功率，估计误差由终步隔离波形审计报告。两臂都只改 1–8 和 9–32 kHz 的复数方向，按实际 IQ 物理内积去掉与解析修正平行的部分，切向 RMS 上限为原带幅度的 0.25，分别匹配两带 RMS。低于源清晰门时逐样点返回原 IQ。其他频带保留解析先验。 [已有跨频先验](../20261124-phase1-lora-cross-frequency-source-m2-r01/report.md)

两臂从零各连续训练 40,000 步，batch 24，并共享源 U 物理样本、通用扰动和优化日程。终步权重和门限覆盖 Full、Residual。在同一冻结 Tri-set 2026092702 上，分别固定两路线 900 个源包的 clean 和六景预测，随后独立 truth-last。主读出预定为先分离载波的细化，两路均需超过同次半量 DURA 且保持对应 clean，才进入正式矩阵。

## 完整训练与冻结测试

N607 实际执行提交 `fdadb8046cd05eb4003275b1f607d04f439cd61d`。独立进程、工作目录、参数、GPU 及日志核对齐备。完整参考和分离载波分别在 GPU 6、4 执行 40,000 步。两臂各有 801 条有限训练记录及五次固定留出记录，优化耗时分别为 1,808.56、1,786.22 秒，峰值 CUDA 分配各 377.80 MiB。每臂 10,356 个可训练参数，另含同源拟合的 527,340 值跨频先验。门限均为 0.0372647159。零 F、TX、V、目标和仿真轨迹进入拟合。无目标真实权重检查通过，RTX 3090 的分离载波恢复 B1 中位时延为清晰旁路 2.79 ms、扰动激活 15.63 ms，含粗细输出，无识别器开销。

从 1,800 步到终步，两臂各自定义下的留出细化波形误差分别由 1.89248 降到 1.87741、由 2.05499 降到 2.03621。由于两个参考不同，此项只作各臂内部比较。两臂同定义的终步弱差异传递错误，公共为 0.00440 与 0.00584，独有为 0.01398 与 0.01732。两臂在读取的固定留出点上观测惩罚均为零。观察到的改动来自波形及差异损失共同拟合。

完成全部预测和独立评分后，在同物理包、原采样点、同一实收跟踪坐标复核幅相。以下以隔离无新增噪声的接收为参考，给出 9–32 kHz 独有谱的逐包中位数。
