# LoRa 三阶段联合接收作用与波形恢复先导

## 假设与固定对照

沿高容量 WiSig R17 的物理展开思路，检验在当前 LoRa 注册窗口中，用中间恢复结果和观测残差重估接收作用、噪声功率及波形，是否比同容量单次接受波形更有效。训练前固定两条 LoRa 信道路由。Full practical 为 1 MHz 连续 post-sync/no-EQ 生成后取六条对齐窗口，residual practical 为 256 kHz 同包几何和逐 chirp 残差。模型接口每次读取一个实际接收包，输入包括当前 IQ、观测一致性算子的当前残差、同包复频谱上下文和观测估计的相干度。无场景名称、独立接收重放、clean 或已知作用参数作为推理输入。

两臂同样三个独立时频块、同种子初始化、相同源样本次序和损失。单次接受臂把观测波形固定到最后，逐块累积先验和作用估计。展开臂每阶段接纳一份中间波形，下一块用这份波形的接收域残差重估主响应、镜像响应和频率相关噪声功率。作用与真实伴随成对，调制坐标中的频带方差约束反投影。输出保留观测载波频点，每 chirp 非载波更新 RMS 限幅为 0.18。固定对照读出为直通、full 成熟复响应半量或 residual 同源 R69 有门控投影半量、单次接受、三阶段展开全量、三阶段展开半量。候选和参照共用各路已冻结的扰动门，逐景记录触发率和净纠错。

## 源域拟合与评分

每路使用相同五台源接收机各 400 个 U 包和另 60 个不相交 U 包做波形留出。每个源包复用两份注册信道观测，实际重放必须与既有 IQ 缓存逐值一致。已知噪声只用于源端监督，在接收域分离重放信号与噪声。由训练目标同时约束非载波波形、已知重放信号、按频带估计的噪声功率及同物理包的两次恢复一致性。每步抽 10 个物理包，其中 2 个使用 clean 身份保持，两次重放作为训练对。每路各自从零训练，固定 1400 步，AdamW 2e-4，种子 2026112581。逐 50 步记录总损失及频带主损失，留出只读。训练不读取 F、TX 真值、V 或目标数据。

两条路均在同一份 900 包源 V 上测试，每台接收机 180 包，排除最近的原采样旁带面板及 R17 方向面板。所有读出使用同一冻结 Tri-set 2026092702。每路线的七景预测与源包 ID 全部固定后再连接相应 V 真值。报告 clean、六景、低城区、逐 RX、纠错与改错、物理包分层配对区间。无目标读取。该矩阵检验机制与训练可用性，正式目标仍需三固定种子和 30,000 个未见接收机包。

## 发布

运行 `20261123-phase1-lora-dura-joint-unroll-source-m2-r01`。入口 `python -m experiments.pamf_lora_main.joint_unroll_source publish`，N607 普通账户、项目原 LoRa Python、归档 CWD、配置中的同源根路径，发布包与运行输出各用该 ID 独立命名。GPU 优先 3、6、2、0、4、1、5，最多两条工作进程并分卡，最多四个可见计算进程/卡。真实源 smoke 在两个路由检查已有缓存、已知噪声与各阶段物理梯度，失配、非有限值、覆盖或预测失败即停止本次后续派发并保留产物。预期两份 smoke、两份双臂冻结权重、日志、同一物理行的两套七景预测和独立源域评分。
