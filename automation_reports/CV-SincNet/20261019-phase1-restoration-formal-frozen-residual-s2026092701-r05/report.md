## 数据、训练与读出边界

完整正式输入复用原 received_views 和 opaque 物理 ID，不抽样或重排，不重新生成信道。每个视图都是同一批 168000 个物理样本，七视图属于相关观测，不能当作 1176000 个独立物理样本或七个模型 seed。source_target_disjoint 与 VALIDATED_ONCE 句柄按既有协议复用，formal/reference 只读取 index.ids，不读标签。

原正式会话 receiver_seed=2027、namespace=phase1_full_six_fixed_20261002_v1、fc=2450MHz，区别于训练与 1200 面板会话；仍是同一原生工程信道引擎，不冒充独立物理族、在轨数据或新的独立盲测。此处为 Phase1，不是 Phase2 K-shot 部署结论。

恢复训练以全部 6300 L_s 与 56700 U_s 的 clean 原接收 IQ 合成配对，TX 标签读取为 0，属于无 TX 标签的合成自监督；不能称完全不需 clean 数据。源波形规则 A 不读取 F/TX；另设规则 B 使用 source V TX 标签辅助验收，单独披露。原 F 本身是监督预训练模型。恢复受损视图时不提供对应 clean 参考；clean 对照本身也通过同一恢复器。配对 clean 参考仅用于独立评分，不用于构造受损视图的恢复输出。

R04 的 R 为 E20/4940 更新；R05 为冻结粗恢复 E20＋从零修正 E20，累计 R E40/9880 历史更新，修正期粗恢复更新为 0。原 cleanF E200/10000 与 AsF scratch E20＋自身 E10/6660 更新分别计入历史成本。恢复一份 IQ 后调用原 PAMF 的 FFT、PA、时频及其余分支，未独立生成互不相容的 FFT。

## 执行核实

一次发布归档比较、远端 compile/import、两条真实源样本复合 checkpoint/no-query smoke 与独立 PID/CWD/argv/GPU/日志增长均通过。全部七视图预测标记 count=168000、TX_truth_reads=0、state_updates=0；独立 scorer 的实际 truth 连接在预测后，完整 stdout 无 traceback/OOM/运行错误。输出不可覆盖，没有重启或修改健康任务，数据/权重/原日志/机器状态不提交。

prediction 中的 per_view_seconds 是批量处理完整视图（含两 F）的耗时，restoration_only_seconds 是批量恢复器耗时；两者都不是单样本 batch1 延迟。batch1 以原源计时另计：粗恢复约 11.520 ms，确定性修正约 17.170 ms，FP32、同口径，仅作各次实测。
