# LoRa 实收噪声方差与私有复谱修正风险

## 预登记

上轮固定频带消融显示，附加私有谱修正提高了 Full 的源 V 识别点估计，Residual 的同包错误显著增加。两路的复波形误差均下降。这轮检验实收 IQ 能否预测每包每带的**附加修正**波形风险，连同干净复方向上的幅相偏差报告。历史识别结果仅用于定义研究问题。 [固定频带析因](../20261124-phase1-lora-private-band-factorial-source-m2-r01/report.md)

冻结原秩四恢复及 clean 门限，将半量读出作为初值 B。从完整 Wiener 私有读出减去半量，得到增量 D。一个频带内剂量 a 的相对平方误差为 2aL + a²Q。Q 为按逐 chirp 实收 RMS² 加权的增量能量，L 由实收残差在增量上的投影和 Stein 导数项相加。原实收方差估计提供每个 chirp 和频带的对角近似，I/Q 各使用方差的一半。四组复符号探针用中心差分估计导数迹，步长固定 0.025，固定当前包去扫坐标、归一化和质量估计。剂量限制在 0 至 1。该估计沿用白盒外的 Monte Carlo SURE 差分思路。噪声方差来自当前包，坐标也由当前包估计，实际噪声可以带相关性。这里是局部风险近似。 [Ramani、Blu 和 Unser 原论文](https://bigwww.epfl.ch/publications/ramani0803.pdf) · [Eldar 广义 SURE 原论文](https://arxiv.org/abs/0804.3010)

每个源接收机固定 30 个留出 U 包，共 150 包。相同物理包覆盖 clean、独立通用白噪声和通用有色噪声、Full 与 Residual 的低郊区及低城区。通用噪声参考是原 U IQ。登记路线先完成仅实收输入的风险与剂量计算，再用隔离去噪参考评分。全过程无身份标签、识别器、V 或目标读取。比较保持半量、半步、完整、实收风险剂量、不加导数项和隔离参考最优剂量。后者只用于显示固定修正线段上的物理上限。保留分接收机和频带的误差、风险符号一致率、相关性、增益及相位。clean 原阈值必须全部旁路。

若两路低城区的 1–8 和 9–32 kHz 中，实收风险剂量的波形误差均优于固定半步，且中位实增益距 1 的距离及中位相位偏差不比半步大，才保留为后续冻结识别消融的候选。波形指标用于证伪判断，不用作识别结论。本轮 CPU、无拟合、无新预测和评分。完成前运行真实源权重无目标 smoke。来源、数值或回放闭合出错即停止。聚焦测试 5 项通过，独立 P0/P1 审查通过。
