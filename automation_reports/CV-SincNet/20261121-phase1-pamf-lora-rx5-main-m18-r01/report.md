# LoRa 五源接收机三种子主对比

用 IEEE DataPort 的 LoRa 多接收机数据测试 PAMF 在新信号体制和未见接收机上的泛化。选取五台异型接收机作为源域，按固定包序号分配 7% L、63% 隐藏 TX 的 U 和 30% V。保留发布方测试集中其余 15 台接收机的 30,000 个受控采集包。10 个发射类别对应官方标签 31 至 40。数据只提供采集批次，避免跨天外推表述。

所有方法取前导第 4 个上扫频符号中央 1 ms，经抗混叠重采样得到 256 个复数样点。PAMF 保留三视图和融合结构，将 Wi-Fi 固定参考换成公开 LoRa SF7 上扫频参考。原始接收和六种 practical 都使用相同包。模拟通过项目 residual / post_sync / no-EQ 生成，载频 868.1 MHz，采样率 256 kHz，参考 SNR 30 dB，各物理包与场景预先确定。三种子共用同样探测样本和信道输出。原始接收分数包含采集时的地面链路和接收机影响。

主比较为 PAMF-Sup、普通 PL、原 Tri、自适应 PAMF、ResNet18 和自适应 PAMF + DURA-LoRa。分类器固定 E50，原 Tri 的 U 权重为 6。对于自适应 PAMF，先在 B200-1 和 RTL-1 各做一次只用源域的留一接收机校准。每折 E20 前缀共用，再比较 U=6、4.5、3 的 E30 源验证。候选在两折都须提升，且通过现有配对净纠错规则，才降权。最终三个种子用同一冻结权重，在完整五源池重训，融合层使用跨接收机正样本均衡。每接收机每类 56 个标签，沿用低标注规则的关闭状态。ResNet18 使用相同的地面 IQ、实用信道增强和标签预算。

DURA-LoRa 保留 DURA v1.0 的两阶段、四步 CG 结构，LoRa 权重在固定源域 L/U 的 clean–practical IQ 对上从零训练 20 轮，不读取类别真值、识别器或目标。输出须标注 DURA-LoRa，用同一个冻结自适应 PAMF 对同一批 IQ 做直接读出与接 DURA 读出。WiSig 权重和旧蒸馏链结果不继承。

预登记矩阵和运行约束见 experiment.json。N607 普通账户，GPU 0–6，每卡本任务最多一进程且计入其他任务后最多两个进程。源域真实 IQ 检查经训练入口写 checkpoint 后回读，验证通过后继续。预测全部冻结后评分程序读取原始测试归档标签，报告准确率、Macro-F1、逐设备接收机结果和同物理记录净纠错。遇到协议、物理仿真、训练或预测技术故障时停止派发并保留产物。
