# LoRa 冻结局部相位与实收幅度联合对照

[预登记矩阵](experiment.json) · [运行事件](events.jsonl) · [父实验](../20261124-phase1-lora-phase-dose-bursts-source-m4-r01/report.md)

上一轮局部相位的同权、同量收益在 Residual 为 +100 次，但仍比 DURA 少 83 次。更早的隔离扣噪试验显示，幅相正确方向联用可产生额外识别收益。本轮固定已经训练 40,000 步的 9,426 参数局部相位模型，比较两个可部署的幅度方向，并独立判定在同剂量或更大剂量下隔离幅度所能贡献的收益。没有新训练和新校准。

## 接收信息与比较

两条路线均只向实收读出提供当前包六个 256 点上扫窗。使用父版去扫、相对复相位坐标、逐 chirp RMS 和前导一致性。幅度的两个参考方向均来自同包接收 IQ。

| 幅度估计 | 实收计算 | 误差来源 |
| --- | --- | --- |
| 外带功率去偏 | 在去扫坐标估计双侧 64 kHz 以外的中位功率除以 \(\log 2\)，记为 \(\widehat\sigma^2\)。把原功率 \(a^2\) 改为 \(\max(a^2-\widehat\sigma^2,0.25a^2)\)，再取根。 | 加性白噪声的全带均值和外带代理可能不同。相关干扰、色噪、弱设备边带与同步失配会混入估计。 |
| 分组重复前导幅度 | 对本条之外五条分成三条和两条，按当前包相干度分别取复均值 \(c_1,c_2\)。用 \(\sqrt{[\operatorname{Re}(c_1c_2^*)]_+}\) 估计局部幅度，以两组相角一致性、正交叉功率及 \(\widehat\sigma^2\) 控制相对回写。 | 两组可能含有相同传播失配或相关干扰，且重复前导各条的独有幅度可能不同。交叉项在噪声独立且共享信号成立时可减小独立噪声偏差。 |

用每条原始 chirp 的物理 RMS 归一化幅度路径，保持原样点相位和索引。每包幅度改动上限为原 IQ RMS 的 6%。两个方案分别在原相位和固定局部相位上回写幅度。同量对照以两者实际径向 RMS 的较小者为上限，使用同一相位，保留逐 chirp RMS。无观测相位的零幅点逐点保留。旁路门为父版 0.03726472，两条路线的权重和规则相同。

隔离幅度使用非载波精确扣噪参考，仍以相同路径维持逐 chirp RMS。该参考以实收两方向中的较小剂量做一次对照，再做全径向读出。幅度参考分别与实收相位和固定局部相位组合，精确噪声只传入隔离对照函数。实收剂量匹配、相位、幅度和判别输入都不依赖模拟真值。以上范围与 Rician 幅度去偏和跨仪器交叉谱的常见使用相联系。本试验在同包 LoRa 短窗中使用它们的对应接收统计，用冻结的识别器检验设备信息是否保留。 [Gudbjartsson 与 Patz 的原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC2254141/) · [Rubiola 与 Vernotte 的原论文](https://arxiv.org/abs/1003.0113)

每路线在同一 900 个源 V 物理包完成 13 个读出的七景预测。直通、半量 DURA 和固定局部相位须逐包复现父实验。两路线文件均闭合后，独立 CPU 才读取标签。独立配对同时衡量幅相交互、同 RMS 差异、逐 RX 纠错与改错。所有权重固定，无目标访问。
