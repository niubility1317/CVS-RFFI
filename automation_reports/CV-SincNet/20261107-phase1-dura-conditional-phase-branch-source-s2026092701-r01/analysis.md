# 条件相位双分支的源域贡献

固定训练完成的条件相位双分支模型和原 DURA，在 672 条合法源 pilot 上分解每条恢复结果。每个源 RX/场景组有 48 条，共 14 组；训练候选的源 ID 与 pilot 互斥，原 DURA 可能见过 pilot。未读取 F、TX 标签、V 或目标，未更新模型。候选与 DURA 的分组波形误差和源训练摘要复算一致，最大差小于 3×10⁻⁶。

| 指标 | 14 组等权均值 | 解释 |
| --- | ---: | --- |
| 整体相位修正角的绝对值 | 0.001604 rad，约 0.092° | 记录级绝对值再平均 |
| 局部分支混合权重 | 57.28% | 14 组均值范围约 57.19% 至 57.55% |
| 整体相位／幅度分支实际修正能量 | 0.00000226 | 已含门控和混合权重，按 clean 能量归一 |
| 局部分支实际修正能量 | 0.00005467 | 同上 |
| 修正后源波形 NMSE | 0.022465 | 每记录先归一，再分组平均 |
| 原 DURA 源波形 NMSE | 0.022517 | 同输入、同口径 |

在这批已探索源记录中，整体相位修正角较小；实际整体相位／幅度支路的平均修正能量约为局部分支的 1/24。支路能量、相互作用和识别器敏感性并不等价，因此不能据此认定整体分支对识别没有作用，也不能据此调整、选取或取消其他候选的正式测试。

输入中的合成场景不代表真实在轨信道，源 pilot 不是独立盲测。波形 NMSE 和分支权重均不是 TX 身份准确率；条件相位版与复矩版的七景预测仍需全部固定后独立评分，才能判断实际性能。结果与方法经真实 DURA 和候选 checkpoint 源 smoke、聚焦测试及一次独立 P0/P1 审查核验。
