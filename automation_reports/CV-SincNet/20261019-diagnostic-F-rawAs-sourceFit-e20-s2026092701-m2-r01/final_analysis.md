# 纯 F raw＋As：冻结源拟合与信道泛化诊断

**RAW_AS 相对普通 As 的源端改善很小，未形成一致的识别增量；既有 FAIL 决定保持。** low urban 的训练流重建、同 L 新实现、源 V 新实现分别比 B1 多判对 2、1、25 个观察，准确率差为 +2.898551、+0.724638、+0.694444 个百分点；mid urban 的源 V 则少判对 9 个观察（−0.250000 个百分点）。不能用这一局部低 urban 改善救回已关闭的固定 whole-raw 配方。

本诊断仅补齐源域测量，不读取正式目标 IQ、truth 或分数，不重新训练、换头或修改源晋级标准。模型 seed 为 2026092701，只有 1 个模型 seed；两次信道 draw、多个 RX/day 及逐包计数均不充当独立模型 seed，样本标准差不适用。

## 面板、重建与指标口径

原源角色保持 L6300／U56700 隐 TX／V27000，源 RX 为 1/3/4/6/8，day 为 1/2/3，split392005。复用旧诊断已固定的 180 个 L 物理 ID：E20 实际消费序列中，每个 TX×RX×day cell 按顺序首次出现最多 2 个 ID，共 90 个 cell；没有根据预测结果重选样本。保留其真实 epoch、step、slot 和完整物理五元组，读取 IQ 前核对 L_s 角色。

三种输入分别是：原 Dataset float32 raw；原训练命名随机流的完整 practical As 重建；相同 L ID 的两个固定新 namespace、三个场景的新实现。三场景旧流子集分别为 50、61、69 个 ID；“同 L 新实现”表按旧观察所属场景配对，因此观察数分别为 100、122、138。对全部 180 个 ID×2 draw×3 场景的完整预测也保留在 NPZ 中。V 为另外 1800 个合法源验证 ID，每场景 2 draw、3600 个观察；V 与 L 不是同一物理样本，不能作逐包 L/V 错误配对。

RAW_AS 对应 step/slot 确认消费相同 L ID，原生日志确认每步 128 个 As 及实际 raw/extra 输入路径。其逐包 scene 没有单独持久化，场景由既有 producer、Config、seed、RX/day/eq session 和命名流确定性重建；重建 metadata 与旧诊断一致。B1 与 RAW_AS 的训练使用了这些对应命名流观察；B0、RAW_NOAS 从未接受 As 训练，它们在该输入上的结果仅是冻结参照，不能称作其 As 拟合率。

历史 As IQ 未保存，`historical_IQ_byte_comparison=false`。本诊断复用旧的独立整批／单包一致性证据，并核对当前重建 metadata；没有声称与历史存档 IQ 字节相等。额外 CPU 信道生成包括 896 个整批训练流重建观察和 1080 个既定新 namespace 观察；显式核验后的 L raw 读取为 1076 次。这些是数据生成／读取成本，不是额外模型前向。

以下每格统一为“正确数 / 观察数；准确率；标准 CE”。标准 CE 是默认 logits 的真标签负对数似然，不加温、不作标签平滑；训练 smoothing=0.01 的 CE 在完整 JSON 中另列，二者不混用。

## Seen-to-new 与难度组成的有限解释

RAW_AS 的训练流重建 → 同 L 新实现准确率分别为：low suburban 88.000000% → 95.000000%、mid urban 86.885246% → 70.491803%、low urban 68.115942% → 65.217391%。其中 mid urban 在按两个 draw 展开的配对中修正 11、损坏 31，净少 20 个正确观察；low urban 修正 25、损坏 29，净少 4。

同场景的新随机实现也可能更难或更容易，不能把上述差距直接等同于记忆或过拟合。复用的旧／新观察组成如下；“信号与新增噪声比”只描述模拟器新增噪声，**不是包含原录音噪声的总 SNR**。

| 场景 | BLOCKED：旧→新（计数/n） | unlocked：旧→新（计数/n） | 信号与新增噪声比均值：旧→新/dB |
|---|---:|---:|---:|
| low suburban | 6/50 → 4/100 | 5/50 → 3/100 | 19.051 → 21.149 |
| mid urban | 21/61 → 54/122 | 8/61 → 31/122 | 18.649 → 15.786 |
| low urban | 37/69 → 78/138 | 26/69 → 54/138 | 10.693 → 10.869 |

mid urban 的新观察 BLOCKED/unlocked 比例更高、信号与新增噪声比更低，所以其下降不能单独证明信道记忆；low suburban 的新观察相对更容易。low urban 的旧／新组成较接近，RAW_AS 在其训练暴露命名流重建的 69 个观察中仍错 22 个，新实现与 V 中也保留较多错误。这说明严重受损身份提取的困难已经出现在源训练观察内，不只是未见 RX 正式测试才出现；它既不证明物理上限，也不证明当前架构或所有优化方法无法改进。

## 既有源决定保持关闭

本诊断运行前，训练 run 已按预登记规则固定 FAIL：RAW_AS−B1 的 V 两 draw mid/low urban 均值为 +0.222222 个百分点，低于 +0.5；全 V27000 clean 相对 RAW_NOAS 为 −0.307407 个百分点，超出 −0.2 的容差。相对 B0 为 −0.088889，单项通过不抵消其余失败。

资格使用的全 V27000 clean 为：B0 98.055556%、B1 97.762963%、RAW_NOAS 98.274074%、RAW_AS 97.966667%。这里不使用上节 V1800 clean 面板代替全 V，也不把本次 L180 子集诊断新增为晋级门槛。固定 whole-raw 配方不追加 E50、不据此改比例、seed 或日程救援；没有读取或利用正式目标分数作该决定。
