# 大容量 DURA 修正网络的训练后源域诊断

固定训练 20 轮已完成；源 IQ 损失第 1 轮为 0.0225810533，第 20 轮为 0.0225810980，数值几乎不变。训练完成后固定的 14 个源域小组中，每组 48 个样本，候选与 DURA 的归一化 IQ 均方误差接近；这些结果不能替代身份识别测试。

对训练所用源上下文以种子 2026110802 抽取 64 个源物理记录、每条三个视图，共 192 个视图，用冻结的最终模型进行 CPU 前向。抽样平均 DURA IQ 误差为 0.0266831610，候选为 0.0266820937；相对源 clean 能量归一化的修正能量均值为 2.20896×10⁻⁷。90 个视图误差降低，71 个升高，31 个保持完全相同，三个视图之间不独立。输出头权重范数为 0.0467231、偏置范数为 0.00294794。

这些证据说明在该源训练抽样中，修正确实非零但幅度很小；不能从中判断目标身份准确率或断定训练停滞的根因。该抽样来自训练上下文，不能作为独立泛化证据。模型已按固定计划继续执行 Phase1 七景地面预测，全部预测完成后独立 truth-last 评分。

进一步在相同 192 个源视图上检查最终模型的层输出：Transformer 输出均方根为 8.8406；第二个解码卷积输出均值为 -28.7308，99.73% 的值不大于 -10，随后 GELU 的输出在抽样中全部为 0。输出头权重的源样本平均损失梯度范数为 0，偏置梯度范数为 0.0002043；第一层局部卷积梯度范数约为 1.8×10⁻¹⁵。该检查表明最终 checkpoint 在这组样本上出现了解码激活饱和，不能据此断言整个训练过程或其他样本均如此。

为验证可能的修复，另建独立版本：Transformer 输出采用逐 token LayerNorm，两层解码卷积后采用 GroupNorm，再接 GELU。它从头初始化，继续固定原 DURA，只用源 IQ 训练；真实 checkpoint 和 96 条源视图的 6 步 GPU 冒烟通过，输出头每步均有有限非零梯度。是否改善地面身份识别有待该新版本完整七景评分。
