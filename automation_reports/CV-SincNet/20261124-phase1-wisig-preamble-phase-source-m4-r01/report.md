# WiSig 分段短前导校正与从零展开恢复

## 预登记

目的有二。先单独检验恒定相位校正能否提高冻结设备识别，再用成对消融检验它是否改进两阶段展开恢复。合法源 U 抽取 2,048 个片段的快速观察表明，解调后的名义 STF 与公开波形对应相位在两段的圆统计平均方向约为 −35°，绝对偏离中位数分别为 8.28°、7.62°。这项观察只定位模型假设，从源 U 独立校准段重新估计实际冻结参考角与门限。

接收输入是当前 256 点 IQ。由原短训练重复算法估计频偏，先为匹配滤波暂时移除相位斜率，并把参考时刻固定在第 120 点。对两段各包含 3 个 STF 周期的观测分别匹配 20 个公开模板时移。两段归一化复相关和的幅度最大值选择共同循环时移。匹配相关均至少 0.50、两段单位相位内积至少 0.80 时才认定测量可靠。按固定划出的 4,096 个源 U 包，使用可靠包投影角的圆均值及围绕均值的绝对偏差 q=0.999。计算当前包绕短前导锚点的常角修正，实际输出乘该单位复数，保留时间样点、复幅度和实收频偏。对照包括无门纯相位与带置信门的纯相位。

两组恢复器从同随机初始化训练，使用与原 R69 相同的 266,951 参数结构和二阶段各两次 CG。两组共同使用合法 U_s 的 51,836 个拟合 IQ 和独立的通用合成扰动。匹配源 U 采样、三视图、弱差异传递损失、AdamW FP32 和 1,200 步。唯一区别是其中一组在两阶段求解之前使用上述固定带门相位校正，展开网络在统一校正坐标内预测输入作用、残差方差和 IQ。绝对相位校正依据当前短前导，而补偿相位没有提供给作用估计器作为显式监督。原历史 R69 权重只用于无 query 检查及冻结对照，不参与训练、蒸馏或阈值。额外的完整恢复旁路对两组使用同一规则，采用 U 冻结的时偏、有效扰动指标与可靠相位偏差的并集。

## 验证和停止条件

两条路线使用同一恢复权重和阈值。各测试 1,800 个相同 Main split 源 V 物理包、七个视图及冻结 Tri-SIG-TIME SSL seed 2026092701，匹配直通与原冻结 R69。训练前真实权重仅在源 U 进行无 query 检查。两路预测均固定后由独立 CPU 读取源 V 真值，按接收机和采集日分层评估同包差异，不访问目标数据。正式晋级需同一冻结读出在两路线六景超过原 R69，且 clean 正确数至少相等。N607 先核实资源，优先 GPU3 和 GPU6，各最多分配一条本 run 并行任务，出现校准、数值或闭合错误即停止后续队列。具体命令、实际代码身份、环境和路径见登记。

## 与公开方法的关系

Moose 利用相邻重复符号的相位变化估计 CFO，用于 OFDM 解调。这里借用短训练的相邻重复结构，CFO 仅用于提高匹配相位的可比性，恢复只改一个全窗口常角。 [Moose 原始论文](https://calhoun.nps.edu/bitstream/handle/10945/62145/Moose_Technique_for_Orthogonal_Frequency.pdf?sequence=1)

WiSig 发布方在完整记录上估计 CFO 与均衡响应，为保留硬件扰动在均衡后加回 CFO。本试验只依赖发布窗中已有的 STF，参考角从无标签源 IQ 校准，对当前观测判断是否纠正整体旋转，再以冻结设备识别验证损益。 [WiSig 原论文](https://arxiv.org/abs/2112.15363) · [发布方均衡实现](https://github.com/WiSig-dataset/wisig-process-raw/blob/master/matlab_equalization/equalize_channel.m)
