# 大型时频网络卷积算法自动选择：源域 GPU 对照

固定 CrossExpertRefiner、相同初始化、源输入与批次，比较 deterministic FP32、TF32 关闭时，cuDNN benchmark 关闭和开启。512 个合法源 ID 各有三个固定模拟视图，共准备 1536 条；每条轨迹按相同种子打乱后执行四步、batch 128。不同条件独立初始化、使用相同 CPU 分批索引和传输。热身后做两对对照，并反转两种条件的执行顺序；不保存权重，不读取 F、TX 标签、V 或目标。

| 执行顺序 | 关闭自动选择 | 开启自动选择 | 耗时变化 | 损失、模型、优化器及 CPU/GPU/采样 RNG 逐值一致 |
|---|---:|---:|---:|---|
| 先关闭再开启 | 161.502 s | 161.046 s | −0.28% | 是 |
| 先开启再关闭 | 138.891 s | 203.599 s | +46.59% | 是 |

两对短程训练状态均精确一致；但计时结果不稳定，未观察到可靠加速。测试在 RTX 3090 GPU2 与其他两个 owner 进程共享时进行，其他负载可能随时间改变，不能把第二组较慢归因于 cuDNN，也不能据此外推其他硬件或完整训练。计时不含数据准备和冻结父模型输出准备；已执行各模式一次热身。测试只覆盖每种模式的两次四步轨迹，不证明完整训练或正式预测逐值一致，不能用作在训实验的热切换依据。
