# F 跨 RX 同 TX：同 RX 负样本替换的源域诊断

状态：LOCAL_VERIFIED，尚未启动。

基底为原始 F＋跨 RX 同 TX 对比学习的三个已冻结模型。保留原默认头；本次无训练、无 U/V/目标域访问，不使用星地增强，也不新增 practical 测试。

候选比较 ALL、SAME_RX 和逐锚点数量完全匹配的 RANDOM_MATCHED。三者使用共同有效锚点、固定跨 RX 同 TX 正样本、温度 0.2 和原 SupCon 分母。既有弱类额外同 RX 损失的负结果保留；本次研究原负样本池替换的依据。

完整读取每模型 L_s 6300 个样本（各 TX 1050），三个模型共 18900 次实际样本前向。批量 128、不丢尾批，50 批/模型。六项目标共 900 次特征 VJP，选取实际部署 id_backbone 并排除整个默认分类头。两种固定 Sinc 梯度度量均报告。无优化器更新、头拟合或分类器诊断。

预先固定判断：弱 TX 14-7 和 20-19、全部三个基线种子，在两个固定层汇总的同 RX 异 TX 负样本余弦相似度比其他 RX 高至少 0.02，有效锚点比例至少 99%。梯度仅作描述，不据此选择坐标度量或调参。通过也只表示可开展另行预登记的匹配训练实验，不构成泛化、准确率或因果结论。

完整矩阵、输入来源、命令、环境、CWD、输出根、资源和停止规则见 experiment.json。原模型来源代码为 31467086c3ced30237f3ac86e91eae68645425d7，固定 final50，实际加载时复核同契约与来源。运行使用文件入口，确保原始不可变 release 优先导入。

数学与协议负测试通过；一次真实 checkpoint 无 query 的 CPU 检查通过；一次独立 P0/P1 检查通过。原始模型未成为新训练的初始化。
