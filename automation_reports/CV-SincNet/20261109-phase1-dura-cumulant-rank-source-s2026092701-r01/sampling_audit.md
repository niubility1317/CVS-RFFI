# 当前源记录排序训练的同设备负对下界

训练中，同一物理记录的多个视图为正对，不同物理记录为负对。不同记录也可能来自同一设备，因此该目标存在把同设备不同记录推开的潜在冲突；它不是设备身份监督。

只依据 Phase1 源域六类设备的公开设定和已固定采样顺序，不读取 IQ、TX 标签、F、V 或目标，复算计划的 20 轮、每批 32、每轮 98304 个视图，种子 2026110902。这里是已登记完整训练日程的采样推演，不表示未完成轮次已经执行。

| 统计 | 数值 |
| --- | ---: |
| 计划批次数 | 61440 |
| 29／30／31／32 条不同记录的批次 | 1／2／581／60856 |
| 不同记录有序负对 | 60947302 |
| 同设备不同记录有序负对的保守下界 | 8595722 |
| 下界占全部记录负对的比例 | 14.1035% |

设一批有 m 个不同物理记录，分属六类，令 m = 6q + r，0 ≤ r < 6。即使六类分布尽可能均衡，至少有 r·q·(q+1) + (6-r)·q·(q-1) 个同设备有序记录对。对有重复视图的批次只取每条记录一个代表计算分子，分母则保留所有不同记录视图有序对，因此结果仍是保守下界。实际同设备负对数量可能更高。

使用独立小规模穷举验证该公式和重复视图时的下界方向；复算程序为 [sampling_bound.py](../../../experiments/phase1_cumulant_rank/sampling_bound.py)。这项数学计算不证明真实设备标签分布、模型表征退化或目标识别变化，也不能由此改动正在运行或已预登记的训练、预测及测试。正式七景结果仍需全部预测后独立 truth-last。
