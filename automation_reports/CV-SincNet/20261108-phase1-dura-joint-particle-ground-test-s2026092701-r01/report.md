## 方法与固定矩阵

固定代码 commit 0cddb5ff260381205a5445d04507ed211fac9989。原 DURA v1.0 的 checkpoint、算子和参数冻结；独立初始化 1,790,786 参数的修正网络，初始输出与 DURA 完全相同。每条输入单独获得 DURA 估计算子，通过三个展开步骤，在波形候选和当前观测拟合出的正则复数增益之间交替；物理残差使用估计算子的真实伴随。源训练每条使用一个随机候选，推理使用四个固定反向成对噪声候选并平均成一条 IQ。有限候选并未证明是经校准的概率后验，不称 Gibbs diffusion 复现。

训练固定 32,768 条合法 L_s/U_s 源物理记录、每条三个既定模拟视图、20 轮、batch 32、AdamW 学习率 0.0003、权重衰减 0.001；最终轮冻结。目标为按源 clean 能量归一化的波形误差加 0.02 倍 DURA 改变量，无 TX 标签、F 权重或输出、V 或目标数据进入 G 训练。源预测预检中的冻结 F 只在独立进程用于无查询接口核实，预检模型不作为正式初始化。模型种子 2026110812、训练顺序 2026110813、训练噪声 2026110814，固定推理噪声 2026110811；源记录抽样 2026110611。

一次启动阶段检查包含真实冻结 DURA 的源 IQ 梯度和独立冻结 Tri-SIG-TIME SSL 接口；其后自动训练、七景预测和独立 truth-last 评分。Main split clean 及六种 practical 每景各 168,000 条；全部预测固定后报告 DURA 配对、净纠错、TX/RX/day、raw clean 相对 3% 及绝对 3 个百分点两种口径。GPU 执行 DURA 与新候选，分类器保持 CPU、同一默认头；GPU3 每阶段须至少 8,192 MiB 空闲、总计算进程少于 3，且本任务每卡最多一个训练或预测 worker。技术失败、非有限值、权限错误或输出冲突时停止本 run 并保留证据，不停止其他 owner。

源模拟反事实显示直接替换 DURA 的真实模拟信道或方差不保证波形误差下降，因而本设计联合更新波形候选和可观测增益；这仅为研究假设，并不保证身份性能。目标集历史已曝光，此次不是新独立盲测。

14 项合成数值和流程检查通过，含预测失败不评分、伴随梯度和逐记录独立性；独立 P0/P1 检查及桥接问题定点复核通过。合成 GPU 单层多相卷积与普通卷积输出、梯度相近；完整模型同卡单次比较为 24.831 秒和 0.204 秒，输出与输出层梯度最大差分别为 9.54e-7 和 2.79e-8；先后顺序、冷启动和共享负载使其不能视为稳定加速倍数，也不保证训练逐位相同。正式真实权重预检和完整测试尚未执行。
