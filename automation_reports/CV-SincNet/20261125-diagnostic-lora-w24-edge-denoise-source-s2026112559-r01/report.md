# LoRa W24 实际半量中心输出的原生边缘恢复

使用星地增强 W24 E104 和 40,000 步原 W24 DURA 的实际无门控半量中心输出。固定原先两条路线各七景的 300 个源 V 物理包。原半量、直通、仅估计边缘、半量加估计边缘在 GPU 预测进程固定。两路逐点核对实收中心，并逐包复现原直通与半量的识别类别。 [原半量识别对照](../../../docs/analysis/LORA_W24_READOUT_SWEEP_20261125.md)

边缘工程对照只使用当前实收的八条 1,024 点原生 chirp。按能量定标的 Hann 窗估计每包 350 kHz 以外的功率，将中位数除以 ln 2，并换算到 W24 实收中心 RMS 的尺度。对每个原生 24 点边缘分别拟合七点二次 Savitzky–Golay 曲线，并从实收边缘减去平滑残差。减量为噪声代理除以噪声代理与边缘残差功率之和，再乘 0.5。该连续系数无需场景、接收机 ID 或整包门限。拟合只改原生边缘，原半量中心保持实际冻结 IQ。 [Savitzky–Golay 原论文](https://pubs.acs.org/doi/10.1021/ac60214a047)

四种实收读出全部冻结后，另起 GPU 进程生成隔离参考。在同一实际半量中心上只把边缘替换成无新增噪声的对应样点，共同使用实收中心 RMS。该读出量化在实际中心恢复既定时，完美去除边缘新增噪声可带来的独立收益。所有预测均固定后，独立 CPU 按同一物理 ID 读取源 V 标签并评分。目标读取和训练均为零。

N607 普通账号，原 W24 发布工作目录，一张有余量的 GPU 和八个 CPU 信道工人。入口 `python -m experiments.pamf_lora_main.w24_edge_denoise_source publish --repo . --context <源域上下文> --ssh-config <直连配置> --output <发布目录>`，新根 `runs/20261125-diagnostic-lora-w24-edge-denoise-source-s2026112559-r01`。先核对真实源 U 权重、两种路线、计算精度和分类输出。原观测、分类基线、覆盖或冻结不匹配时停止对应下游并保留文件。输出含两路合法预测、隔离并入后的双路预测及独立评分。 [预登记](experiment.json)
