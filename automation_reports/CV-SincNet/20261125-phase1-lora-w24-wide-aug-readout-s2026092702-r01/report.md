# 40,000 步 W24 DURA 接星地增强 W24 的 Full 配对小试验

用户指定后续 LoRa 恢复研发使用星地增强 W24。固定增强版 E104 种子 2026092702，用原登记原生 Full 视图，比较增强 W24 直通、既有复响应半量及独立 40,000 步 W24 DURA 半量。后者配对原 W24 E108 的跨输入输出试验继续保持原口径，两套试验分别登记。

恢复器来源为 `20261125-phase1-lora-dura-w24-train-s2026112991-r01` 固定终点，训练发布提交 `7615e8e4024e7f38688ffe69db3f632f5256f613`。使用已登记的原生源 U，20,000 包拟合、2,500 包 clean 校准、500 包留出，配合与目标独立的通用扰动。训练、校准和冻结均隔离 F、TX、V、目标、实际或模拟器真值。完整源角色和训练配置通过原发布模块的冻结证明匹配，重用其唯一阈值、权重及原中心半量更新。增强识别器来源为 `20261125-phase1-lora-pamf-w24-sat-aug-s2026092702-r01`。其原始 W24 提取代码发布提交为 `e6dde7d40f2cc3dd7b21d83daa4bcbabac52d3ae`。两条新预测在同一个 `8×2×432` 实收 W24 输入上计算。恢复仅修正中心点，保留原生两端的 48 个点，不接收场景、接收机标识、真实噪声或信道参数。

冻结后在 4 个源 U 包的 clean 和通用高噪声输入上检查门限旁路、实际恢复、端点保持和有限分类。随后每台未见接收机按固定种子 `2026112581` 无放回抽 200 个包，合计 3,000 个，同包覆盖 clean 和六个 practical 场景。沿用增强 W24 已登记原生 Full 模拟与盲物理 ID。新预测全部冻结后，对照同包既有复响应半量，直通必须与此前冻结全量直通逐包一致。独立评分给出逐接收机、逐景正确数、改对改错和固定接收机分层的物理包配对 95% 区间。Residual 保留其原有 256 kHz 输入登记，本试验覆盖原生 Full。

N607 普通用户。入口 `python -m experiments.pamf_lora_main.w24_wide_transfer publish`，版本身份使用本次发布 Git 提交。运行及发布目录均独立，以实验登记命令、项目 Python、CWD 及输入路径为准。等待既有训练进程正常冻结，最长 2 小时。其后按当前负载在 GPU 2、7、4 中取一张有至少 12 GiB 余量的卡，最多等待 30 分钟。来源、权限、有限值、冒烟、直通配对或冻结矩阵错误时停止该试验并保留产物。预期工件为 `state.json`、`smoke.json`、`evaluate.log`、15 份冻结接收机数组、`predictions/complete.json` 和独立 `scores.json`。
