# LoRa 原生 Residual 与 Full 的同一恢复器源域配对

登记 `native_residual_w24_v1` 作为源域候选输入，输出八条 1 MS/s chirp。沿用原 post-sync/no-EQ Residual profile，同包共享几何和接收机硬件，每条 chirp 单独取冻结快照。每条中心 1 ms 的两侧分别保留 12 µs，以同一份快照、同一随机过程生成 1,024 个输出。输入向前推进 31 个采样补偿数值 FIR 延迟，使用邻接实录作为卷积前置上下文，录制范围外补零。把 256 kHz 参考噪声功率换算到 1 MHz 采样，接收机质量代理基于参考频带内通道能量和参考噪声功率。没有为缺失帧复制原 clean 边缘。历史 256 kHz 六窗生成路径保留原语义。

复用已登记原生源数据，五 RX 各取固定 60 个源 V，面板种子 `2026112559`。两路线使用同一物理包、同一 clean 波形、同一份源冻结增强 W24 E104，比较直通、既有复响应半量和 40,000 步 W24 DURA 半量。两路 G 都固定为训练 run `20261125-phase1-lora-dura-w24-train-s2026112991-r01` 的同一终点权重、同一源门限和中心半量更新，使用同一 `8×2×432` 接收输入接口。启动时使用真实 U 包检查两种信道视图、模型出分和旁路。B1 记录固定受扰源 U 包的活跃 G 推理时延，30 次计时，区间包含同步而无信道仿真和识别耗时，节点并行负载另见运行状态。

仅预测源 V 七景，先验证两路线的 clean 类别逐包一致并冻结全部预测，再以独立 CPU 进程读取源 V 发射机标签。按路线、场景和接收机记录正确数、净纠错及固定接收机分层 95% 区间。两路 clean 均须保持、两路六景均须较各自直通改善，方有源域证据支持固定 G 的后续盲目标比较。当前只做原生接收与冻结模型的源域可行性，后续正式验证尚需匹配的 R69 对照及独立矩阵。

入口 `python -m experiments.pamf_lora_main.w24_native_residual_source publish`。N607 普通用户、FP32、优先 GPU 0、5、3 中有至少 12 GiB 余量的卡，一个评测 worker、8 个 CPU 信道工人。GPU 最长等待 30 分钟。出错保留输出，来源、波形结构、非有限、源冒烟、clean 对齐或冻结矩阵异常即中止下游。预期 `smoke.json`、两个路线各一份冻结预测、活动记录和独立 `source-scores.json`。
