# LoRa Tri 星地分类监督配对结果

两组均按种子 2026092702 完成 E140 后的 2464 次更新。210 份盲预测固定后，独立评分 15 个未见 RX、30,000 个物理包、clean 与六种 practical，并核验训练 U 决策。

| 方法 | clean | 六景均值 | 城区低强度 |
| --- | ---: | ---: | ---: |
| 普通 PL | 69.9233% | 55.3167% | 41.2633% |
| 继续监督 | 70.2800% | 55.4094% | 41.4167% |
| 原 Tri-set | 70.3633% | 55.3956% | 41.2733% |
| 增加 U practical 硬标签 CE | 70.2133% | 55.2956% | 41.4000% |
| 有标签 practical CE 从 0.35 提至 0.45 | 70.3567% | 55.5017% | 41.5000% |

增加有标签 practical 权重，六景较 Tri-set 分别净增加 14、12、45、20、32、68 个正确预测，总计增加 191 次，clean 少 2 个包。训练集 clean 为 81.50%，源验证 clean 为 74.70%，源验证六景均值为 56.73%。相对原 Tri-set 的源验证六景 56.58%，固定加权的改善同时出现在源验证和目标单种子。

U practical 分支有 22,428 次硬标签曝光，来自 8,117 个包。其中 22,323 次正确，正确率 99.5318%，覆盖原硬标签曝光的 98.63%。额外 U practical CE 按整批归一平均为 0.09870，渐入后的总 U 损失从原 Tri-set 的 0.02826 增到 0.05805。单独审计输入标签正确率较高，但该组 clean 少 45 个正确包、六景少 180 次正确预测，仅城区低强度增加 38 个。最高频四个伪标签 TX36、TX37、TX39、TX40 占 95.1% 的 practical 标签曝光。目标 TX38 六景少 1,054 次正确预测，TX33 和 TX32 分别少 339 和 173 次，说明汇总指标掩盖了跨类转移。源验证 clean 从 74.88% 升到 74.98%，与目标 clean 的变化方向不同。

固定提高真实标签 practical CE 得到小幅单种子收益。高精度硬标签在星地分支的覆盖分布偏斜，且相干度门控几乎保留全部已接受样本。当前结果支持检查按源验证调节的真实标签星地权重，高精度本身不足以支持全面加大 U practical CE。
