# 源域 R 目标实现率：固定诊断设计

状态 LOCAL_VERIFIED，尚未运行。本轮不训练身份网络、不改变 checkpoint、不访问目标数据、预测或评分。对应原始 E200 父网络及 B0/B2/B3/S3 固定 E40 权重全部纳入，三个种子不筛选。

研究依据来自已有源日志：R 的所有关系均活跃，30 个审计点骨干梯度非零；L/T 的固定源数字压力风险下降。但这些日志没有证明预定 RX 组差位移已经实现。诊断目的在于补足这项证据，不因 clean 测试结果调权重或重跑。

每个模型读取全 L_s 6,300 与源 V 27,000 个包，按原来90个 TX/day/RX 组计算归一化 joint160 均值。P0复用已验证缓存；12个E40网络实际eval前向，逐模型检查所有参数和buffer不变。CPU2线程串行，总新前向399,600个包，无优化器或CUDA使用。

对每个原条件块和全部RX对，定义 delta=(mu_g^model−mu_h^model)−(mu_g^P0−mu_h^P0)，target=−alpha*(p_g−p_h)。使用训练原有的完整160维、块等权/块内关系等权、冻结标量c，计算总体风险0.5 E[c||delta−target||²]。遍历全部总体均值，此时不需小袋方差修正；解析测试与袋大小等于总体时的原训练函数相等。

风险分成0.5 E[c||delta||²]、−E[c delta·target]、0.5 E[c||target||²]。另外报告 delta 沿每对 target 的投影能量与其他方向能量。进度系数=E[c delta·target]/E[c||target||²]，可为负或大于1，绝不是识别准确率；零可信目标能量记null，不加正下限。

所有模型分别在固定旧B3和新S3两套目标上评价，主解释用S3，不事后挑一套更好看的目标。V使用自己的父组均值，仍使用仅L_s拟合的p/c/alpha；V不拟合任何参数。源条件均为父网络已见环境，不宣称未见RX端到端泛化。

固定比较B3−B2、S3−B2、S3−B3、B2−B0的组差改变量。它们包含参数优化轨迹变化，不能把每个向量坐标都解释为因果效应。按当前头＋当前特征、父头＋当前特征、当前头＋父特征三个代数组合报告源分类与margin，辅助区分头与特征变化；不将头交换当作部署候选，也不在V拟合。

结果解释：如果S3在L_s和V均朝预定方向移动并降低相对B2的总体目标误差，说明约束得到实现，后续应研究可覆盖扰动范围；若保持父组差的项占主导而沿目标修正很少，应先研究目标与优化作用的关系；若仅L_s实现而V不复现，应研究源内统计迁移。这里只描述下一步研究分支，不发布新权重搜索或选模规则。
