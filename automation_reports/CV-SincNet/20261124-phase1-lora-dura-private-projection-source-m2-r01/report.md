# LoRa DURA 近带独有复谱保护

## 预登记

扩容版 DURA 在 Residual 低城区把 1–8 kHz 独有复谱对 clean 的实增益从直通的 0.60 降至约 0.22。另一轮留出源 U 测量中，近带和混叠侧能量差与同接收作用下的无新增噪声功率，在低城区的相关系数为 Full 0.750、Residual 0.267。这支持检验比统一减小恢复量更有针对性的边界。 [DURA 扩容结果](../20261124-phase1-lora-dura-prior-width-source-m2-r01/report.md) · [奇偶交叉功率测量](../20261124-phase1-lora-interleaved-band-power-source-cpu-r01/report.md)

取冻结宽版 DURA 的原半量输出。在从实收获得的去扫坐标里减去六条 chirp 的均值，得到输入和修正的独有频谱。只在绝对频率 1 至 8 kHz，计算实收独有谱能量与相隔 128 个频点的混叠侧能量。两者的非负差除以近带实收能量，再限制到 0 至 1，得到单包保护比例。该差值等于相位对齐后的奇偶交叉功率实部，实际成形和噪声着色会影响其偏差。将修正在实收近带独有谱方向上的负实投影按此比例削减。其余方向、共有谱及带外修正保留。回写使用原实收跟踪和同一包尺度。 [奇偶交叉参考](https://arxiv.org/abs/1003.0113) · [SciPy 公开交叉谱实现](https://github.com/scipy/scipy/blob/main/scipy/signal/_spectral_py.py)

Ephraim 和 Van Trees 的语音增强用噪声与信号协方差定义子空间，并最小化有噪声约束的信号失真。本试验约束冻结 DURA 输出的包内独有复谱改动方向，直接以同包识别判断。交叉谱参考中的双仪器独立背景假设在本数据的同包奇偶样点上未成立为已知事实，因而只把估计用作保守读出依据。 [原信号子空间论文](https://people-ece.vse.gmu.edu/~yephraim/Papers/sap%201995%20sig%20subspace.pdf) · [交叉谱去相关条件](https://arxiv.org/abs/2010.04473)

预定对照为直通、匹配半量 DURA、宽版原半量、整包宽版四分之一、取消近带独有编辑、完全去掉近带反向投影，以及保持原编辑方向但匹配主读出近带编辑范数。主读出使用实收估计比例，固定不拟合。源面板 900 个包，两路线、同一冻结 Tri-set 2026092702、clean 加六景。额外完成 11,100 个 clean 补集，所有预测固定后独立连接源 V 真值。主读出须在两路六景同时超过既有半量 DURA、原宽版半量和等范数对照，低城区及完整 clean 至少持平各自参照，再考虑扩大验证。另隔离核对同批 150 个留出源 U 的分带复幅相和保护活跃比例。无新训练、阈值重估或目标访问。

N607 先读取少量真实源 U 做无目标冒烟，通过后测 B1，再分别运行两条路线和 clean 补集。不符合同、数值异常或预测不完整即停止本次任务。5 项聚焦测试与一次独立 P0/P1 审查通过。命令、路径和输出见 [实验登记](experiment.json)。
