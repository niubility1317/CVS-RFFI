# 源域推理：跳过未使用的 DURA 分类

七景预测现有路径对 received、DURA anchor、候选恢复结果分别执行冻结 Tri-SIG-TIME SSL，但最终保存的预测只使用 received 与候选结果；独立配对评分读取已固定 DURA 基准。此诊断在同一批次仍计算 DURA 波形，只跳过 anchor 的识别器前向；没有修改或切换现有预测进程。

使用尾部保护固定候选和 112 条已探索的合法源记录（RX4/6 或 RX8 × 七景，每组 8 条），CPU 两线程、batch 8，交替先后执行原路径和跳过路径。原始与恢复输出的全部 logits 最大绝对差均为 0，决策差异均为 0；原始及 anchor 决策也与既有源 pilot 一致。未访问 TX 真值、U_s 真值、V 或目标；F 仅作冻结源推理。

单次配对计时，原路径 2.131 秒，跳过路径 1.690 秒，约 1.26 倍、节省 20.7%；含重复 DURA 和候选前向，但不含模型加载。未单独预热且机器共享负载，112 条结果不可直接外推到完整七景。

**范围限制：**只证明这 112 条源样本相等，尚未完成 168000×7 地面输出逐项相等和实测加速，不能据此宣称正式预测结果完全不变，也未切换现有或未来正式预测路径。
