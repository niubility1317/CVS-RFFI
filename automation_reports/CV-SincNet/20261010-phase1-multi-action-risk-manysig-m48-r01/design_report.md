**下一版我建议继续保留“一个身份骨干＋多个独立作用网络”，但要重点改变这些网络参与身份学习的方式：让 L/T 网络寻找有物理依据、能够被真实 IQ 核验的困难扰动，让 R 网络约束跨 RX 的判别分布和错误尾部。**

这比继续增加网络容量、统一提高辅助损失权重，更有针对性。

我核对了 `e99f4e06d` 的实际实现、36 个模型的结果和配对统计。**本轮确实修正了上一版的若干结构问题，但还没有证明多解耦形成了稳定、实质性的域泛化收益。** 目前更明确的信号是：

- L 对 clean 有小幅一致改善。
- 当前 L/T/R 组合相对 L/T 有改善，但这个对比同时改变了辅助预算。
- 把整个虚拟约束直接回传到 E，在 LTR 上出现一致退化。
- R 的统计目标仍遗漏了对逐包识别至关重要的信息。
- L/T 的正式训练用途，大部分是在重新加权已经训练过的增强终点。

以下先说明本轮结果真正支持什么，再给出下一版完整设计。**这是基于代码和结果的研究设计，本次没有启动新的训练。**

## 二、先修正三处诊断口径，否则下一轮仍可能误判机制

### 1. 梯度日志存在确定性的归一化错误

当前 `runtime.py` 只在每 888 个原生步执行一次梯度审计，但写入 epoch 指标时，对所有指标统一除以该 epoch 的全部辅助调用次数。

于是，稀疏记录的梯度余弦、范数也被额外缩小。

例如，一个 epoch 有 56 次辅助调用，仅其中一次测得余弦 0.56，最终 epoch 记录会变成：

\[
0.56/56=0.01.
\]

**这个 0.01 已经不是实际梯度余弦。**

该错误影响日志，不影响实际训练 backward，也不推翻身份评分。但是，在修复之前，不能用这些 epoch 梯度数值判断“辅助梯度很弱”“两条路径近乎正交”。

下一版应：

- 为每个指标分别维护观测次数。
- 稀疏审计保留原始 step 快照。
- 未观测的指标记录为缺失，而不是零。
- 同时记录乘过可靠度、分支系数和预算之后的实际梯度。
- 把 R 和总辅助损失加入梯度审计。

当前审计主要比较未经加权的 L/T 损失，R 没有进入同一套梯度任务列表。这是另一个需要补上的缺口。[训练与日志实现](https://github.com/niubility1317/CVS-RFFI/blob/e99f4e06d6ac741399d1349ff5240bb57d53af7a/experiments/cvs_multi_state_action/runtime.py)。

### 2. R 的“关系总数”并不等于实际训练关系数

当前 R 每次 fit 选择一个关系进行训练，但返回的 `relations` 是当时全部候选关系的数量，随后被累加。

因此，记录中的数百万关系，不能解释成实际训练过数百万个独立关系。实际 R fit 大约是每 seed 9,880 次，而且同一批物理观测会反复参与。

下一版应分开记录：

\[
N_{\text{available}},\quad
N_{\text{fit-used}},\quad
N_{\text{identity-used}},\quad
N_{\text{audit-used}},\quad
N_{\text{unique physical IDs}}.
\]

这会直接影响对 R 数据量、统计可信度和训练成本的判断。[R 实现](https://github.com/niubility1317/CVS-RFFI/blob/e99f4e06d6ac741399d1349ff5240bb57d53af7a/experiments/cvs_multi_state_action/receiver.py)。

### 3. 源诊断完成了，但完整结果没有随本次报告发布

本次提交包含四个源审计流程完成的回执，但没有完整的 action、receiver、composition、TX 留出及逐 epoch 梯度结果。

因此，目前可以确认状态条件、二阶项、exact29 等修改已经实现，不能据此量化它们分别改善了多少源域留出预测能力。

**这些已产生的诊断应优先补齐，能恢复的日志无需重新训练。** 下一轮的分析需要连上这条证据链：

\[
\text{作用预测}
\longrightarrow
\text{实际准入与加权梯度}
\longrightarrow
\text{源身份收益}
\longrightarrow
\text{冻结测试收益}.
\]

## 三、当前 L/T 的核心局限：拟合准确，并不自动带来新的身份训练信息

这是本轮最需要改变的地方。

### 1. 正式训练中的 L/T 主要预测已经训练过的终点

当前所有非 native 配置，包括 L-only，都已经训练真实：

\[
x_L=A_L(x),\qquad
x_T=A_T(x),\qquad
x_{LT}=A_T(A_L(x))
\]

的分类损失。

随后 L/T 网络又预测对应的特征位移，并在虚拟特征上进行分类训练。正式路径使用的是本样本的已知人工参数 \(p\)；跨 TX donor 和参数估计器主要存在于冻结诊断中。[正式训练路径](https://github.com/niubility1317/CVS-RFFI/blob/e99f4e06d6ac741399d1349ff5240bb57d53af7a/experiments/cvs_multi_state_action/runtime.py)。

假设动作完全准确，并暂时忽略参考坐标漂移：

\[
h(x)+D_k(h(x),s(x),p)=E(A_k(p)x).
\]

那么：

\[
\operatorname{CE}\!\left(C G[h+D_k],y\right)
=
\operatorname{CE}\!\left(C G[E(A_kx)],y\right).
\]

对 G/C 而言，这就是再次训练已经使用过的真实增强终点。

所以，当前 L/T 的收益可能来自：

- 对部分增强样本重新加权；
- 只更新后端的梯度分配；
- 参考模型带来的正则化；
- 动作近似误差造成的额外扰动。

这些都可能有用，但**不能自动解释成学到了额外的跨域变化信息**。

从数学上说，若损失在相关特征区域内满足 Lipschitz 条件，动作拟合误差小可以给出：

\[
\left|
\mathcal L_{\mathrm{virtual}}
-
\mathcal L_{\mathrm{real\ aug}}
\right|
\leq
K\left\|\widehat{\Delta h}-\Delta h\right\|.
\]

它控制的是虚拟训练与指定真实增强训练之间的差异。即使右侧为零，也不能推出未知 RX 上的风险下降。

### 2. `_EG` 还引入了不同的 E 梯度

考虑最理想的精确位移：

\[
\tilde h
=
E_\theta(x)
+
\operatorname{sg}\!\left[
E_\theta(A_px)-E_\theta(x)
\right].
\]

前向数值满足：

\[
\tilde h=E_\theta(A_px).
\]

但反向传播满足：

\[
\frac{\partial\tilde h}{\partial\theta}
=
\frac{\partial E_\theta(x)}{\partial\theta},
\]

而真实增强训练使用：

\[
\frac{\partial E_\theta(A_px)}{\partial\theta}.
\]

两者不同。

因此，本轮 LTR_EG 的退化值得重视，但不能简单归因于“扰动建模错误”。它也可能涉及这种梯度路径与 R 统计约束的组合。

**下一版默认让 E 通过真实增强 IQ 更新；学习到的虚拟 R 作用先只更新 G/C。**

### 3. 当前分支增减还伴随预算变化

当前 L→LT 会通过 `virtual_terms.mean()` 将原有 L 项的贡献约减半。

LT→LTR 在 R 项存在时，又把 L/T 总系数从 0.05 降到约 0.041667，并给 R 分配约 0.008333。即便某次 R 可靠度为零，这种预算预留仍可能发生。

所以：

- LT−L 不能单独证明 T 有害。
- LTR−LT 不能单独证明收益全部来自 R。
- 当前缺少的 **L+R** 是下一轮必须补上的配置。

## 四、从通信和射频指纹原理出发，重新限定各分支该处理什么

### 1. 身份证据与接收条件并不天然分居不同特征维度

一个概念性的接收模型可以写为：

\[
u_y=\mathcal T_y(s),
\]

\[
x_{r,d}
=
\mathcal P_{r,d}\!\left(
\alpha_{r,d}(t)[h_{r,d}*u_y](t)
+
\beta_{r,d}(t)[h_{r,d}*u_y]^*(t)
+
n_{r,d}(t)
\right).
\]

其中：

- \(\mathcal T_y\) 包含发射机的硬件作用；
- \(h_{r,d}\) 表示链路中的有效滤波；
- \(\alpha,\beta\) 可描述主分量与共轭镜像分量；
- \(\mathcal P\) 表示同步、增益和后续处理。

这个模型只是说明混合关系，不主张它覆盖全部实际硬件机制。

对于射频指纹，PA 非线性、IQ 不平衡、频率偏差等都可能提供身份信息，同时也会受到接收链影响。用已知前导估计出的有效响应，也可能包含发射机响应。

因此，**不能把“能被某类信号变换改变的特征”全部视为应删除的域信息。**

一个简单的数学限制是：如果允许的扰动集合中存在 \(A\)，使得

\[
x_{y_2}=A(x_{y_1}),
\]

而模型又被要求严格满足

\[
F(Ax)=F(x),
\]

那么：

\[
F(x_{y_1})=F(x_{y_2}).
\]

这两个身份就无法再区分。域不变表示与信息保留之间的冲突，也有相应理论研究，但其结论不能直接替代具体 RF 链路分析。[proceedings.mlr.press](https://proceedings.mlr.press/v89/johansson19a.html?utm_source=chatgpt.com)

**下一版应学习有范围、有条件的稳定性，保留对类别区分必要的变化。**

### 2. CFO 应处理“可支持的变化”，不能整体抹除

接收频偏通常混合了 TX、RX 与传播运动的贡献：

\[
f_{\mathrm{obs}}
=
f_{\mathrm{TX}}-f_{\mathrm{RX}}+f_{\mathrm{prop}}+\varepsilon.
\]

WiSig 的均衡数据在同步和均衡之后，重新施加了估计频偏，以供指纹识别使用。因此，使用 equalized 数据并不意味着 CFO 已从身份证据中消失。[arxiv.org](https://arxiv.org/html/2112.15363v2?utm_source=chatgpt.com)

下一版可以在有标签源交叉数据上检查一个统计模型：

\[
\hat f_{y,r,d}
=
a_y+b_{r,d}+e_{y,r,d}.
\]

它的用途是估计哪些频偏变化在多个 TX 上共同出现、哪些变化更接近稳定的 TX 差异。它依赖可检验的加性假设，并不自动恢复纯 TX/RX 振荡器参数。

如果交互残差 \(e_{y,r,d}\) 很大，就应降低这种分解的解释强度，而不是强行把所有频偏变化交给 T 消除。

### 3. 当前 T 的物理尺度需要重新标定

当前 T 使用：

\[
\phi=0.08p_0+0.10p_1\tau+0.06p_2\tau^2,
\qquad \tau\in[-1,1].
\]

在 25 MHz、256 样本条件下，换成实际时间单位，大致对应：

| 分量 | 当前最大量级 |
|---|---:|
| 常相位 | ±4.58° |
| 线性频偏增量 | ±3.12 kHz |
| 二次项等效频率变化率 | ±\(7.34\times10^8\) Hz/s |

二次项可以作为人工相位曲率压力测试，**不能直接解释为真实 LEO 轨道多普勒变化率**。

实际 practical 模拟还包含接收质量相关残余频偏、相位跟踪残差、共轭镜像、新增噪声及 AGC；weak 使用的又是另一套残余信道配置。当前确定性 T 对，并没有分别监督这些变化。[实际 practical 残余模型](https://github.com/niubility1317/CVS-RFFI/blob/e99f4e06d6ac741399d1349ff5240bb57d53af7a/code/leo_practical/residual.py)；[信道参数](https://github.com/niubility1317/CVS-RFFI/blob/e99f4e06d6ac741399d1349ff5240bb57d53af7a/code/leo_practical/channel.py)；[weak 配置](https://github.com/niubility1317/CVS-RFFI/blob/e99f4e06d6ac741399d1349ff5240bb57d53af7a/code/training_controls.py)。

下一版 T 应明确区分：

\[
\phi(t)
=
\phi_0+2\pi\Delta f\,t+\pi\Delta\dot f\,t^2+\eta(t).
\]

这里的 \(\eta(t)\) 是随机相位过程，与确定性二次曲线具有不同语义。

### 4. 当前 clean 的“质量匹配”几乎退化

数据先进行单位复数 RMS 归一化：

\[
\operatorname{mean}(I^2+Q^2)\simeq1.
\]

但 donor 匹配使用：

\[
q=\log\operatorname{mean}(x^2)\simeq-\log2.
\]

这使 clean 包的该指标几乎相同。RX/day/condition 匹配确实执行了，但不能把这一功率近邻匹配解释成已经匹配了 SNR 或接收质量。[动作匹配实现](https://github.com/niubility1317/CVS-RFFI/blob/e99f4e06d6ac741399d1349ff5240bb57d53af7a/experiments/cvs_multi_state_action/actions.py)。

建议替换成有实际变化的观测量：

- 重复前导的相干度；
- 拟合有效响应后的残差比；
- 相位或频偏估计的不确定性；
- 已有且合法保留的归一化前质量信息。

这些仍应称为质量代理，除非经过校准，否则不直接称为真实 SNR。

## 五、下一版 L/T：保留状态作用模型，增加条件边监督，改变训练用途

### 1. 保留已经修好的结构

本轮已经实现的以下部分应保留：

\[
D_k(h,s,p)
=
J_k(h,s)p+
Q_k(h,s)\operatorname{vec}_{\mathrm{sym}}(pp^\top).
\]

以及：

\[
\Delta r=r(A_px)-r(x).
\]

它们分别解决了状态相关性、偶数项和固定 29 维前端响应的问题。下一版没有必要再回到旧的固定全局低秩作用空间。

建议的主架构职责如下：

| 模块 | 主要任务 | 对身份模型的作用 |
|---|---|---|
| \(D_L\) | 预测有效线性动作在不同接收状态下的作用 | 提出有价值的线性扰动，由真实 IQ 更新身份模型 |
| \(D_T\) | 分别处理常相位、频偏增量及有依据的时间变化 | 提出有价值的时间扰动，由真实 IQ 更新身份模型 |
| \(D_R\) | 解释真实源 RX 间的条件判别分布变化 | 在可靠范围内训练 G/C 的逐包识别和尾部风险 |
| 身份骨干 \(E,G,C\) | 保留 TX 判别能力 | 推理时仍只使用原身份路径 |

### 2. 用“条件边”补上交互，先充分利用已有网络

当前主要拟合的是：

\[
D_L(h_{00},x_{00},p_L)\approx h_{10}-h_{00},
\]

\[
D_T(h_{00},x_{00},p_T)\approx h_{01}-h_{00}.
\]

但已经生成的四个端点，还能提供一条很有价值的监督：

\[
\boxed{
D_T(h_{10},x_{10},p_T)
\approx
h_{11}-h_{10}
}
\]

它回答的是：

> 相同的时间扰动，在已经受线性变化影响的波形上，会产生什么作用？

若轮换执行顺序，生成 \(x_{11}=A_L(A_Tx)\)，则可以监督：

\[
\boxed{
D_L(h_{01},x_{01},p_L)
\approx
h_{11}-h_{01}
}
\]

这让同一个独立网络学习“作用如何依赖当前状态”，能够处理一部分交互，而不需要立即增加 \(D_{LT}\)。

实施时有三个要求：

1. 所有对照共享相同的顺序日程。
2. 条件边应替换或轮换部分原有拟合任务，并记录实际训练量。
3. 除了使用真实中间状态的拟合误差，还要测量实际链式预测误差。

例如：

\[
\hat h_L=h_0+D_L(h_0,s_0,p_L),
\]

\[
\hat h_{LT}
=
\hat h_L+D_T(\hat h_L,s_L,p_T).
\]

必须检查 \(\hat h_{LT}\) 与真实 \(h_{LT}\) 的差异。只在真实 \(h_L\) 上拟合良好，不能证明两条学习路径组合后仍然可靠。

### 3. T 内部按物理语义分头，但保持一个独立 T 网络

建议 T 保留共享状态处理，再区分：

- 常相位；
- 频偏增量；
- 随机相位或同步残差。

如果扩大常相位范围，参数输入应体现周期性，例如使用：

\[
\sin\phi_0,\qquad 1-\cos\phi_0.
\]

这样不会把 \(0\) 和 \(2\pi\) 当作完全不同的物理状态。需要注意，使用周期基函数不代表整个非线性编码器响应可以被单个谐波精确表示；模型阶数仍要通过源留出结果决定。

频偏和曲率则用 Hz、Hz/s 定义范围。随机相位过程应使用明确的过程模型和强度参数，不能继续由一个二次项代替。

### 4. 让 L/T 网络用于寻找困难动作

建议把主要用途改为：

\[
p^\star
=
\arg\max_{p\in\mathcal P_k(c)}
\ell\!\left(
C G[h+D_k(h,s,p)],y
\right),
\]

其中 \(\mathcal P_k(c)\) 是由源观测、接收状态及部署先验限定的动作范围。

动作网络提出候选后，生成真实 IQ：

\[
x^\star=A_k(p^\star)x,
\]

并使用：

\[
\boxed{
\mathcal L_{\mathrm{act}}
=
\operatorname{CE}\!\left(F_\theta(x^\star),y\right)
}
\]

更新身份模型。

这里 \(p^\star\) 对身份更新停止梯度。**E 沿真实 \(x^\star\) 前向回传。**

这样，L/T 网络的价值变成：在可接受的范围内，帮助找到随机增强不容易覆盖、当前模型确实处理不好的方向。

这一方案仍然需要防止动作模型被“钻空子”：

- 参数范围不能任意外推。
- 预测误差必须在源留出数据上评估。
- 选中的动作必须用真实端点核验。
- 保留固定比例的随机动作，维持覆盖并估计提案偏差。
- 预测与真实风险差异大时，降低该状态下的提案使用率。
- 真实 IQ 的身份 CE 不因动作模型拟合失败而自动消失。

首轮可以使用小候选集，然后将选中的 L、T、组合动作放入现有真实增强槽。候选搜索、exact29 和真实核验的开销需要全部记录，不能预设这种方案一定更快。

**普通随机增强、精确终点 G-only、学习动作提案后真实 IQ 更新，必须作为不同对照。**

## 六、下一版 R：从均值对齐转向判别分布与错误尾部

### 1. 当前 R 的几个目标存在数学冗余

本轮已经修复了“先均值、后非线性”的问题，现在是逐包经过 G/C 后聚合。这一点是正确的。

但当前 R 主要匹配：

- raw-z 均值；
- normalized-z 均值；
- 所有竞争类 margin 的均值；
- normalized-z 均值在锚点方向上的投影。

对固定 cosine 分类器：

\[
f_y(z)=s\,\bar w_y^\top\hat z,
\]

有：

\[
\mathbb E[m_{yj}]
=
s(\bar w_y-\bar w_j)^\top\mathbb E[\hat z].
\]

所以平均 margin 和锚点投影主要是对同一个均值进行判别方向加权，并没有补上完整分布信息。

更进一步：

\[
\operatorname{tr}\operatorname{Cov}(\hat z)
=
1-\|\mathbb E[\hat z]\|^2.
\]

因此，**仅添加 normalized-z 的总方差，仍然不能解决这个信息缺口。**

一个构造例子能够说明问题：

\[
A=\{(0.6,0.8,0),(0.6,-0.8,0)\},
\]

\[
B=\{(0.6,0,0.8),(0.6,0,-0.8)\}.
\]

两组向量都为单位范数，均值相同。所有固定线性投影的均值也相同。若真实类方向是第一坐标、竞争类方向是第二坐标，A 中有一半样本被竞争类超过，B 则全部正确。

这证明：**当前均值目标可以完全满足，同时逐包识别率明显不同。** 这是数学反例，并不意味着已经定位了本轮实际退化的唯一原因。

### 2. 在五维竞争 margin 空间里匹配更有信息的统计量

对于六类任务，定义：

\[
m_y(z)
=
\bigl(f_y(z)-f_j(z)\bigr)_{j\ne y}
\in\mathbb R^5.
\]

建议优先建模：

\[
\mu_m=\mathbb E[m_y],
\]

\[
\Sigma_m=\operatorname{Cov}(m_y),
\]

以及：

\[
m_{\min}=\min_{j\ne y}m_{yj}
\]

的下尾分布。

这比直接估计 160 维特征的完整协方差更适合目前的小袋统计，也更直接对应身份判别。

R 的拟合目标可以写成：

\[
\mathcal L_{R,\mathrm{fit}}
=
\lambda_\mu\|\hat\mu_m-\mu_m'\|^2
+
\lambda_\Sigma
\|\hat\Sigma_m-\Sigma_m'\|_F^2
+
\lambda_q d_{\mathrm{tail}}
+
\lambda_\Delta\mathbb E\|\Delta h_R\|^2.
\]

其中协方差使用收缩估计，尾部分布也必须报告估计误差。

需要保留本轮已经落实的：

- 描述、recipient、目的统计三袋分离；
- other-TX 共享描述；
- day/condition 匹配；
- 参考版本和贡献年龄管理；
- 辅助 TX 留出；
- 与 directed other-TX mean 等强基线的比较。

小袋不能因为加入更多统计项就变成可靠分布估计。有效样本量按不同物理 ID 计算；样本不足时，应向较粗的条件统计收缩，并降低约束强度。

### 3. R 的身份目标直接约束逐包分类和下尾风险

拟合 R 时，可以使用冻结教师的目的条件分布。

训练身份模型时，建议让目标转向：

\[
\operatorname{CE}\!\left(
C G[\operatorname{sg}(h)+\operatorname{sg}(\Delta h_R)],
y
\right),
\]

并加入低 margin 样本的尾部风险。

令：

\[
r_i=\operatorname{softplus}(-m_{\min,i}),
\]

可以使用：

\[
\operatorname{CVaR}_{\alpha}(r)
=
\min_{\eta}
\left[
\eta+
\frac{1}{\alpha}
\mathbb E(r-\eta)_+
\right].
\]

这样关注的是最困难的一部分样本，而不是让平均表示看起来接近。

**教师 raw-z 均值不再作为身份模型必须硬对齐的几何目标。** 教师主要帮助解释接收条件变化，身份标签决定最终分类任务。

这里仍有一个边界：跨 RX 没有真实逐包配对，R 作用不具有唯一物理解释。需要通过小作用、平滑性、留出泛化和真实源验证，控制生成特征的可信范围，避免只改善虚拟样本的尾部。

## 七、训练组织：让每种监督沿适合它的路径更新

我建议下一版默认采用以下分工：

| 损失或任务 | 更新对象 |
|---|---|
| 原生 clean、LEO、合法伪标签训练 | 原身份模型 |
| L/T 作用拟合 | 对应独立动作网络 |
| L/T 选中并核验的真实 IQ 分类 | E＋G＋C |
| R 条件分布拟合 | 独立 R 网络 |
| R 虚拟分类与尾部风险 | G＋C |
| 源校准和身份验证 | 不反向传播 |

一个主训练形式是：

\[
\boxed{
\mathcal L
=
\mathcal L_{\mathrm{native}}
+
\lambda_{\mathrm{act}}\mathcal L_{\mathrm{real\ selected}}
+
\lambda_R
\sum_c\rho_R(c)\mathcal L_{R,\mathrm{risk}}(c)
}
\]

其中：

- \(\mathcal L_{\mathrm{native}}\) 保留原门控、cosine 和 clean＋LEO 训练；
- L/T 的普通重复虚拟 CE 不再默认作为主要新增目标；
- \(\rho_R(c)\) 来自源条件下的可靠性；
- 缺少证据时允许相应作用关闭，不为“用满预算”强行放大权重。

### 1. 用固定贡献和实际梯度记录控制预算

下一轮至少区分两种对照：

**贡献消融：** 保持已有分支系数不变，移除一个分支时，其预算留空。回答新增分支是否提供收益。

**等预算对照：** 用明确登记的真实终点或其他控制替代该分支。回答收益是否只是多了一份训练压力。

同时在 E、G/C 两个参数块分别记录：

\[
r_k^{(B)}
=
\frac{\|\lambda_k\rho_k g_k^{(B)}\|}
{\|g_{\mathrm{native}}^{(B)}\|+\epsilon}.
\]

还应记录优化器实际更新量，因为 Adam 状态会影响梯度如何转化为参数变化。

梯度余弦只作为诊断，不能机械地要求所有辅助梯度都与 native 同向。困难域训练产生局部冲突，并不自动意味着无效。

### 2. 对真实增强的一致性项单独做控制

`real_views` 本轮四个 seed 的六场景结果都低于 native，但它同时包含额外真实增强 CE 和一致性项。

因此，下一轮应该保留一个 **真实增强 CE-only** 对照，分清：

- 增强分布本身的影响；
- 增加 CE 曝光的影响；
- 一致性目标的影响。

特别是在基础视图预测错误时，强制增强视图复现该概率分布，未必有助于识别。身份 CE 与辅助一致性应分别评估，不能一起增减后归因。

### 3. 合法 U 可以扩展 L/T 作用拟合，但作为独立消融

已知数字动作：

\[
x\rightarrow A_px
\]

不需要 TX 真标签。因此，L/T 可以在合法 source-U 上使用：

- 已知参数监督；
- normalized-z 端点误差；
- 中心化 logits 端点误差。

其中中心化 logits 可定义为：

\[
\ell_c
=
\ell-\frac{1}{C}\mathbf1\mathbf1^\top\ell.
\]

这不需要读取 U 的 TX、RX 或 day 真值。

当前代码明确保护 `visible_source_L_only`，所以下一版应新增独立的无标签作用拟合入口，保留现有 L/R 断言。身份监督继续遵守原伪标签门控。

这个消融还要有“L-only、同样无标签损失”的对照，否则换损失和加入 U 两件事会混在一起。

## 八、源选择也必须升级：从接近饱和的 clean 分数转向有区分力的源压力验证

本轮源选择分数接近 97.3%，结构之间只有很小差异，却没有可靠预测目标表现。

下一版应保留现有 L/U/V 物理角色，在既有 V 内建立固定的源压力验证：

- 参数与随机实现独立于训练；
- 检查未用于拟合的动作组合；
- 分别观察真实源 RX、日期和 TX 的风险；
- 报告 macro 指标、困难组表现和 margin 尾部；
- 将实际施加增强的样本与增强跳过的 clean 副本区分开。

辅助拟合留包与身份验证必须保持概念分离。当前辅助校准包仍参加身份训练，因此它们不能代替身份 V。

选择规则应预注册，至少同时约束：

\[
\text{clean 判别保留},
\qquad
\text{源压力场景表现},
\qquad
\text{困难群体风险}.
\]

可以采用 clean 非劣约束，再比较源压力组的平均风险和尾部风险。若源差异落在明显的统计噪声范围内，应优先选择结构更简单、证据更稳定的方案。

关注群体风险有成熟研究基础，但直接使用最差组训练也不保证泛化；过参数模型可能把所有训练组都拟合得很好，真正的问题仍在组外泛化。[arxiv.org](https://arxiv.org/abs/1911.08731?utm_source=chatgpt.com)

**不需要为了做这些诊断，随意让某个源 RX 永久退出身份训练。** 辅助 TX 或关系留出、源 V 压力验证与最终完整源身份训练，应分别组织。

本轮报告也明确承认，已有 24 个模型在全矩阵结束前被独立评分。当前这些测试结果已经公开，后续在同一批结果上作分析属于回顾性研究。下一轮可以据此提出假设，但选择仍应来自冻结的源规则；若没有新的未暴露评估数据，应如实说明这一限制。

## 九、下一轮必要对照与实施顺序

### 1. 必须回答的实验问题

| 对照 | 要回答的问题 |
|---|---|
| native | 新方案是否实际改善身份识别 |
| 新动作分布＋随机参数＋真实 CE | 改善是否来自增强分布变化 |
| 精确终点 G-only | 改善是否只是后端 CE 重加权 |
| 学习动作提案＋真实 IQ 更新 | 动作网络是否帮助找到更有用的训练变化 |
| L、LT、**LR**、LTR | L/T/R 的实际贡献和互补关系 |
| R 均值目标与 R 判别分布目标 | 新收益是否来自分布形状和尾部约束 |
| 相同作用形式的 shared 与独立网络 | 独立参数化是否有必要 |
| L-only 与 L＋U 的同损失拟合 | 无标签源数据是否改善动作覆盖 |

当前 unified 与 LTR 的辅助参数已经基本匹配：约 457,969 对 458,515。下一轮应进一步匹配作用形式、输入、损失和曝光量。当前 shared 通用残差形式与独立 L/T 的显式多项式形式仍有差别，不能把它们的差异全部解释为是否独立建模。[统一模型实现](https://github.com/niubility1317/CVS-RFFI/blob/e99f4e06d6ac741399d1349ff5240bb57d53af7a/experiments/cvs_multi_state_action/model.py)。

### 2. 先做源机制诊断，再进入完整身份训练

源诊断优先检查：

1. 真实参数、解析参数、学习参数分别带来什么误差。
2. 条件边是否改善组合预测，实际链式闭合是否成立。
3. 作用模型能否在辅助未参与拟合的 TX 上保持能力。
4. R 的方向协方差和下尾是否真的更接近目的条件。
5. 动作提案预测的困难程度，是否能被真实 IQ 复现。
6. 固定其他条件、单独改变噪声时，剩余错误是否显著。

这些诊断的有限步数只能表示检查预算，不能直接作为网络容量已经达到上限的证据。正式身份比较继续采用一致的从零初始化、完整训练预算和冻结评估。

### 3. 第四个网络的加入条件

现阶段我不把新增交互网络列为主配置。先让已有 L/T 学会条件边，再检查剩余交互是否：

- 稳定存在；
- 可在源留出数据上预测；
- 发生在判别相关方向；
- 能改善身份风险。

同样，三个 weak 场景退化不能直接证明缺少 \(D_N\)。只有固定 L/T 条件、独立改变噪声后，确认噪声引起了主要且可迁移的剩余任务误差，再考虑增加随机作用网络。

### 4. 代码层面的优先改动

| 优先级 | 改动 |
|---|---|
| P0 | 修复逐指标观测次数、R 关系计数、加权梯度和 R 梯度记录 |
| P0 | 补齐已产生的源审计、训练曲线和动作准入结果 |
| P1 | 修正质量代理；将 T 参数改为明确物理单位和过程语义 |
| P1 | 增加条件边监督及实际链式闭合检查 |
| P1 | 增加精确终点 G-only、LR 和预算匹配对照 |
| P2 | 将 L/T 改为动作提案，经真实 IQ 核验后更新 E/G/C |
| P2 | 将 R 改为判别分布拟合、逐包 CE 和尾部风险 |
| P3 | 单独评估合法 U 的无标签作用拟合 |
| 条件触发 | 增加独立交互或随机噪声网络 |

还有一项可以直接降低重复开销：当前已经算出的固定 29 维前端响应，又在动作 fit/predict 中重复计算；部分 teacher 角点在当前主效应训练里没有使用。下一版应按实际任务复用缓存。加入条件边后需要的角点则保留。

本轮 LTR 平均训练墙钟约 11.46 小时，LT 约 5.61 小时，native 约 4.82 小时。它们来自共享 GPU 负载，不能视为隔离性能基准，但足以说明 R 相关计算值得单独分析。[资源记录](https://github.com/niubility1317/CVS-RFFI/blob/e99f4e06d6ac741399d1349ff5240bb57d53af7a/automation_reports/CV-SincNet/20261009-phase1-multi-state-action-manysig-m36-r02/results/resources.json)。
