# 合并非有限检查的完整源训练对照

固定真实源遮挡先验、DURA 源上下文、修正网络初始状态和随机数；对全部 32768 个源物理记录的三个视图，在本机 RTX 5070 Ti、FP32、TF32 关闭、确定性算法下，分别进行五轮、batch 32 的原检查与合并检查训练。每条路径先使用小样本预热一轮，完整对照按原版后合并版的固定顺序各运行一次。真实源 checkpoint 和源上下文 smoke 通过，不读取 F、TX 标签、V 或目标，也不保存训练权重。

| 指标 | 原检查 | 合并检查 |
| --- | ---: | ---: |
| 源物理记录／视图 | 32768／98304 | 32768／98304 |
| 五轮更新 | 15360 | 15360 |
| 优化阶段耗时（秒） | 361.234 | 343.610 |

全部 15360 步损失与最终全部参数逐值一致。单次计时减少 4.88%，顺序固定且 GPU 共享，不能当作 N607 实测加速。原运行中的 N607 训练没有热修改。本对照没有生成七景预测，也不能单独证明不同硬件或不同执行条件下预测逐值一致。

非有限输入在 optimizer.step 前仍报错；合并路径发现非有限 loss 时会先反传和裁剪，再终止，不做参数更新。正常、非有限 loss、有限 loss 的非有限梯度和缺失梯度已有针对性测试。[结果](result.json)。
