# 浅中层受限双向统计扰动

目标仍为 clean 测试三种子均值至少 84%，每个种子单独报告。本轮基于源域机制事实探索，不以已读目标成绩选择方向、校准设置、种子或超参数。当前所有健康实验不修改。

## 来源与待验证假设

已核对的原 `weak_mixstyle_u` 使用同身份、同 day、跨 RX、不同物理 ID 的合法 L 供体，对通道均值和标准差做凸插值。前批完整六行源反事实中，42.89% 至 60.16% 的批次即使取四个增强中最大的 CE，仍低于 clean CE。该事实只说明已有候选的源域难度，不能推出更难的增强必然提升泛化。

当前在训 clean-inclusive m9 已加入恒等候选，仍未改变增强的候选范围。本轮检验：在限制统计位移的前提下，将一部分候选沿同身份跨 RX 差异反向移动，是否能提供不同的训练信号。它是特征层增强假设，不声称反向统计量对应一个已核验的真实 IQ 信道，也不预设标签一定严格不变。

## 变换与匹配对照

浅层 `time_down`、中层 `t2.pool` 顺序执行。对于当前特征 z，取时间均值 μ 和含 1e-6 方差稳定项的 σ，两者从计算图分离。供体 j 由上述 L 规则产生。每个候选使用私有随机种子与 a=ramp×(1−Beta(0.1,0.1))，无供体时 a=0。

令 dμ=clip((μj−μ)/σ,−1,1)，dℓ=clip(log σj−log σ,−log 2,log 2)，方向 s∈{−1,+1}：

`z′ = (z−μ) exp(s a dℓ) + μ + s a σ dμ`。

因此，构造的均值位移每通道不超过 ramp×σ，缩放系数在 [2^(−ramp),2^ramp] 内，满强度时为 [0.5,2]。这是从分离统计量得到的变换参数界，不是原始射频物理不变性证明。输入对输出的显式梯度为正的缩放系数；统计量不被反向改写。未匹配样本和 ramp=0 时逐位保留输入。

|候选池|四个候选方向|其他候选设置|
|---|---|---|
|POS|+1,+1,+1,+1|相同四个私有种子、供体规则、幅度和统计位移限制|
|BIDIR|+1,−1,+1,−1|仅候选索引 1、3 改方向，不新增前向|

两个池均另含 clean，共五个候选。每次用整批合法 L 的 eval/no_grad CE 选择最大者，增强平局取最小索引；clean 与最大增强精确平局时保留增强。随后恢复 clean 主前向之前的 Dropout 状态，只对选中的一个完整候选做可微训练重放。选中 clean 时不装风格 hook。每次仍为 5 次候选 eval 加 1 次训练重放，不能将不同候选逐样本拼接。

POS 与 BIDIR 的同策略比较用于检验方向变化。相对于旧 m9 的对比还包含标准差插值改为受限 log-scale 变换与截断，因此不能称为只有一个方向差异。跨 run 同 seed 不保证 GPU 数值轨迹或中间权重逐位一致。

## 固定矩阵

三种 Fishr 设置全部保留：DELAY 在 444 次身份更新后校准；CAP 在初始化时校准并对联合辅助梯度限幅；DELAYCAP 在 444 次更新后校准并限幅。每种设置都有 POS 与 BIDIR，三个模型种子固定为 2026092701、2026092702、2026092703，共 18 行。主方案预先固定为 DELAYCAP_BIDIR，主要配对对照为 DELAYCAP_POS；另两组方向对照也全部报告。

随机初始化原生旧门控身份网络与原生分类头，cos 指 cosine 学习率。每行 20 轮、每轮 222 步、共 4,440 次更新。AdamW 0.0002 至 0.000001，weight decay 0.0001，L batch 128，label smoothing 0；前 444 步为纯 L CE，之后 888 步 ramp。

保留浅中层主身份平滑 margin 敏感度的 A/B 方差内积，真实二阶梯度，每四次身份更新执行一次，活动阶段共 999 次。每次独立 L 批各 60 个样本，6 TX×5 RX×2，批内 PID 唯一、跨批重叠合法。每样本敏感度 RMS 归一化，有符号有限总体修正估计不截负值。它是 Fishr 类虚拟坐标约束，不等同于标准模型参数经验 Fisher。校准 12 对 L60，固定系数与分母 2；CAP 对 `.time_fuse.`、`.t2.`、其他全部身份参数的联合辅助梯度使用同一个分离缩放因子，保证每组辅助梯度不超过主损失梯度范数的 0.2 倍。该界不保证 AdamW 位移或方向。

## 数据、来源与测试

沿用 L6300、U56700、V27000 的实际物理契约。U 的真实 TX 始终隐藏；所有 U 经另外两个原始纯 CE E20 模型的固定概率均值参与 ALL soft KL，温度 1，教师不含当前学生 seed。学生不加载教师权重，完整教师训练来源核对继续保留。历史模型轮成本为学生 20 加两教师 40，不能将全方法称为无预训练。共享教师缓存与学生训练成本分列。

不启用 EMA、星地增强、U 风格混合或辅助可训练头。V 仅在 E5/10/15/20 eval/no_grad 健康诊断，不拟合、不选模；所有行固定 final20。每行 3,996 次额外 L 训练重放、19,980 次候选 eval；18 行共 79,920 次身份更新。

每行训练与冻结后自动预测相同 168,000 个 clean query，预测固定后独立 truth-last 评分。总计 3,024,000 次 clean 决策。报告每种子、均值/SD、Macro-F1、RX/TX/day、NLL、配对差、成本与完整缺项。原 E20 P0 和旧 m9 固定参考全部保留；目标成绩不回流调参、选择或重跑。当前为已暴露开发基准的固定评估，不宣称新盲测。
