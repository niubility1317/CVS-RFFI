# LoRa 公共谱与包内顺序能否预测独有谱

## 预登记

前序 LoRa 工程结果支持公共谱的跨频关联。秩四公共结构帮助了完整包读出，私有谱单独加入频率协方差时，在宽噪声中恢复的真实幅值仍很小。最新带外噪声条件预测在实用回放无稳定增益。本轮检验独有谱是否有另一种可观测信号来源，即同包公共波形以及其他 chirp 的顺序变化。 [公共谱协方差](../20261124-phase1-lora-shared-spectrum-covariance-source-m4-r01/report.md) · [独有谱序列研究](../20261124-phase1-lora-factorized-chirps-source-m4-r01/report.md) · [带外预测局限](../20261124-phase1-lora-offband-noise-source-cpu-r01/report.md)

对每个 clean 源包，估计原前导旋转和逐 chirp RMS，在同一坐标取复 FFT，减去六条谱均值作为独有分量。公共模型从载波两侧 1 至 64 kHz 的包均复谱预测每条 chirp 两侧 1 至 32 kHz 的独有谱。第二模型同时读取 1 至 32 kHz 的顺序特征。对于第 j 条，只用其他五条的复谱拟合关于 chirp 顺序的直线斜率，乘第 j 条相对整包中心的索引。该顺序特征不会直接读取第 j 条的原始频谱。公共特征仍用整包六条。I/Q 拼为实向量，按训练均值和尺度标准化，每条 chirp 做固定岭系数 0.10 的联合多输出回归。独立先验的 clean 检查保留每条自身的留出性质。整包回写时才投影为包内零和，不改变固定的公共谱和带外读出。整包结果仍有跨 chirp 耦合。多任务高斯回归也利用输出间关联做预测。本轮只检验实测复谱中这种关联的可用性。 [多输出相关性原论文](https://proceedings.neurips.cc/paper_files/paper/2007/file/66368270ffd51418ec58bd793f2d9b1b-Paper.pdf)

五折按接收机留一。每折只使用另外四台各 200 个合法拟合源 U clean 包，拟合接收机固定先验、方差与回归。每台留出接收机 100 个包用于 clean 与独立通用白噪声验证，其中固定 30 包再进入登记 full 和 residual 的低郊区、低城区回放。接收机只是数据折标签，不进入预测式。通用加性白噪在原接收 IQ 上独立生成，采样的尺度保持在 0.04 至 0.26 倍每条波形 RMS。未把生成强度或新增噪声输入回归。

实收预测共用原秩四公共—独有后验。主要比较固定私有均值作为中心、同一中心改用解析后验的公共谱回归、再加入其他五条原始顺序特征。私有回写量使用完全相同的估计噪声方差、原拟合私有边缘方差与 Wiener 增益。加入顺序特征时，其他五条直接来自观测，以保持待预测 chirp 不进入这一特征。另保留以原始公共谱作为输入的诊断对照和原秩四解析参考。两路使用相同配方。通用白噪的真波形与登记回放隔离扣噪真波形，仅用于输出后的误差、增益和相位对比。训练与调度不使用实用轨迹、F、V、TX 或目标。

先看两段 clean 复谱中相对固定均值的预测误差。拟接入后续训练的预定波形条件为：同一个已登记公共输入分支，在同一分析频带至少四台留出接收机的 clean 误差下降，并且在 full、residual 的低城区，相对匹配固定中心的半量私有误差均下降至少 2%；低郊区两路均非负。只用这些合法波形证据决定是否继续，不从隔离真值调整岭系数、特征或权重。本阶段不做冻结识别评分。N607 CPU 执行，真实源 IQ smoke 检查有限输出，回放必须核对原接收序列。本地 11 项聚焦测试和独立 P0/P1 审查提供支持。
