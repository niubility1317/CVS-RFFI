## 训练与成本

两行均为 TX 无标签模拟配对自监督，训练实际使用原 L6300/U56700，0 TX 标签、0 F 权重/输出、0 V/target 优化。配对 clean 和已知合成接收作用参与训练，因此不称没有 clean 信息的盲去噪；原监督 F 只用于冻结评估。prior 从零训练，只继承原冻结 R02/R07 上下文。三配对前向与原 R17 单配对训练的计算成本不同。两行使用相同的 (r,x)、(r±Aδ,x±δ) 三组配对 IQ NMSE；实验行额外加入 0.01 倍、按完整 batch 分母平均的可观察方向响应误差。响应参照由已知 A、原噪声和固定 ridge/CG64 计算，teacher 与可观察门均停梯度。控制行也计算参照与门以匹配执行路径，但该响应项权重为 0。推理只用当前 IQ、输出一份 IQ，原 F50 从同一输出派生 FFT/PA/时域/统计，未另外拟合分类头。
