# 反向配对流：完整源训练预算的检查合并对照

在本机 RTX 5070 Ti 上，以相同固定初始化、32768 个合法源 ID × 三视图、五轮、batch 32，比较原数值检查与合并检查。FP32、TF32 关闭、确定性算法；原路径先执行、优化路径后执行，一组配对，双方均完成 15360 步。

| 路径 | 训练循环耗时 | 相对原路径 |
| --- | ---: | ---: |
| 原检查 | 207.953 秒 | 基准 |
| 合并检查 | 185.329 秒 | 减少 22.624 秒，10.88% |

两条轨迹的全部逐步损失、最终模型状态、最终 AdamW 状态、CPU／GPU／顺序／时间／潜变量生成器状态均逐值一致。固定前八条源输入的恢复输出亦逐值一致；没有对完整地面测试输出作比较。计时包括训练循环、epoch 随机量生成与传输以及相应同步，不含源上下文加载、预热及最终一致性检查。单组固定执行顺序且 GPU 共享，不能据此宣称稳定平均提速或 N607 同样收益。

真实冻结 DURA 源上下文检查通过；训练不读 F、TX 标签、V 或目标，不保存模型权重。原 r01 在中断后没有最终结果和可核实退出原因，保留 UNKNOWN；本 r02 使用独立输出和持续日志完成，未覆盖旧产物。原始结果见 [result.json](result.json)。

训练入口的默认关闭选项 `--fast-flow-guards` 已扩展到反向配对流。仅内部均匀采样的合法时间省略重复范围检查，损失与梯度的非有限值仍在优化器更新前报错。17 项针对性检查通过，独立 P0/P1 审查无阻断问题；代码提交 `08b0af1539db949a0c8ee1d7eb1b49cffadad893` 已推送并独立核对远端 OID。现有 N607 训练保持原执行版本，没有热切换。该技术对照不构成识别准确率提升，也未证明性能下降不超过 3%。
