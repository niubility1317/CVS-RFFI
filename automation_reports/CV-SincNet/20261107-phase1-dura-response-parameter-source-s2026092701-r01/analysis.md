# 源微扰响应与参数梯度

固定原 DURA、已有 117062 参数修正网络的源初始化，以及 32 条合法源记录的三个模拟视图。对每条源 clean IQ 构造相对均方根 1% 的四种变化，通过 DURA 对该 received 估计的物理作用注入观测，再重算完整 DURA；比较修正网络在原观测和扰动观测上的输出变化与已知源扰动。无需 TX 标签、F、V 或目标，未进行参数更新或保存模型。

对每个方向分别计算响应误差损失及原 DURA guard 损失对修正网络全部可训练参数的梯度。三个等量视图批次各自求梯度后取平均，再计算余弦；范数比以响应损失参考权重 0.01 计算。负余弦表示两项在此初始化上的下降方向有冲突，正余弦表示有同向分量。

| 合成方向 | 参数梯度余弦 | 0.01 加权响应梯度／原损失梯度范数 |
| --- | ---: | ---: |
| 共轭变化 | -0.1083 | 0.1962 |
| 幅度三次变化 | -0.1365 | 0.1089 |
| 相位斜率变化 | 0.2474 | 0.4666 |
| 局部差分变化 | 0.2810 | 0.1710 |

上述值只针对这 32 条源记录、三个视图和一个固定未训练修正初始化；0.01 是诊断参照，未据此确定正式训练权重。合成方向、DURA 估计物理作用和响应误差只是源域代理，不证明真实发射机身份变化或目标识别收益。DURA 可能见过源记录；不能将单批梯度关系外推到完整训练或所有源数据。真实 DURA checkpoint、源缓存和来源合同检查通过；未读取 F/TX/V/目标，GPU 诊断计时约 9.6 秒，不含数据读取。

## 固定权重相加的一阶分析

令 `a` 为三个视图批次平均的原保护损失梯度，`b` 为某一种响应损失的平均梯度，`g = a + 0.01b`。根据上表的余弦 `c` 和范数比 `r`，可直接得到 `a·g/||a||² = 1+rc`，以及 `b·g/(||a||||b||) = c+r`。

| 合成方向 | 原保护项归一化内积 `1+rc` | 响应项归一化内积 `c+r` |
| --- | ---: | ---: |
| 共轭变化 | 0.9787 | 0.0878 |
| 幅度三次变化 | 0.9851 | -0.0275 |
| 相位斜率变化 | 1.1154 | 0.7139 |
| 局部差分变化 | 1.0480 | 0.4519 |

对于每次只加入表中一种响应项的理想无穷小普通梯度下降，四种情况下原保护损失均为一阶下降；幅度三次响应损失则为一阶上升。仅把响应梯度投影到不损害原保护梯度的半空间，也不能自动保证响应项下降；未来可考虑同时约束两项下降方向，再做实际训练验证。这是对相同小样本聚合梯度的代数推导，没有进行优化步骤；AdamW 的逐参数缩放、权重衰减、有限步长或同时加入多个方向均不由此结论保证。
