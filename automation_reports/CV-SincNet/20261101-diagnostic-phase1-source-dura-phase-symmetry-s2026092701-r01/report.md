# Phase1 source DURA phase-response investigation

Status: source-only research diagnostics; neither averaging method advanced to Phase1 test. A blind source noise gate, selected from earlier source findings, enables modifications only for estimated low-SNR records. DURA and Tri-SIG-TIME SSL are frozen. The 795 source IDs include 514 receiver 4/6 day 3 validation and 281 receiver 8 day 3 holdout records; these IDs exclude the earlier cycle-network, SNR-proxy and gated-network samples, but may overlap other source diagnostics and frozen models saw source records. Simulated satellite data is not a validated real link.

The initial hypothesis treated DURA as phase-equivariant: rotate input IQ through eight global phases, restore each, inverse-rotate the outputs, and average. Full averaging made the three source-validation impaired views lose 307 correct mixed-target decisions in total; the predeclared rule retained DURA. Regeneration reproduced the validation counts. On the 310 gated low-urban validation records, the full average's median RMS amplitude was only 1.67% of DURA's; paired-source aligned MSE rose from 0.056900 to 0.890491. This severe cancellation is waveform degradation, not only a classifier-score change.

The separate response diagnostic compared DURA outputs without fitting gain. For a 180-degree input rotation on the same gated low-urban sample, the median normalized squared difference between the two unrotated outputs was 0.002560, while the difference from a 180-degree rotated original output was 3.999110. Thus these outputs are approximately in a common phase frame on this sample, rather than following the tested input rotation. Synthetic identity-equivariant and real-source smoke checks also passed; the error was the unsupported model-symmetry assumption, not an omitted inverse transform in the implementation.

After inspecting that evidence, the source pilot was corrected to average DURA outputs directly in their observed common frame. This was post-hoc on the same source records, not an independent selection. Validation selected blend 0.25 at aggregate +2. On 271 valid receiver 8/day 3 source holdout targets, low-urban correctness fell from 242 to 240; its 69 true L_s subset fell from 63 to 62. On all 281 paired source holdout IQ records, mean aligned MSE fell from 0.103507 to 0.102535. Mid urban gained one mixed-target decision and its mean MSE also fell, but the evidence does not justify target testing. The corrected complete run was repeated with identical JSON; a synthetic invariant-frame test proves direct averaging preserves, while inverse rotation cancels, a common output.

A label-assisted diagnostic of the original inverse-rotated phase-orbit waveforms found low-urban source holdout 242/271 baseline, 259/271 if the correct candidate can be selected using the source target, and 255/271 if an altered correct candidate must also improve paired aligned IQ MSE. The latter yields 65/69 on true L_s versus baseline 63/69. These are nondeployable, per-record source oracles; they bound only the tested candidates, not arbitrary restorers, and the output-frame mismatch cautions against naive averaging or treating the oracle as a real result.

Source mixed targets combine true L_s and confident U_s clean-teacher pseudo-labels. Candidate waveforms and decisions were fixed before source transmitter labels; source clean IQ was used for source simulation and post-hoc waveform quality, never as inference input. No U_s transmitter labels, validation IQ or test IQ were read. Prior Phase1 development-test results were observed, so further use of that test is nonblind.
