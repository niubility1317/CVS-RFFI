# Tri 六设置源 RX 分项更新迁移诊断

2026-11-16，用户授权使用已有检查点做分项诊断、与既有 Tri/PL 成绩结合分析、评估计算开销；不修改其他正在运行的实验。

## 预登记矩阵

Main（5 源 RX）、2/3/4/6 源、十类共 6 设置；固定 model seed 2026092701；使用原 Tri E20 和 E30。每设置按排序后源 RX 的首、中、末选最多 3 个 RX，分别作本次更新的留出参考，L/U 更新排除该 RX。参考从原 L_s 按类抽 8 条（六类48、十类80），与更新 L128/U256 物理样本互斥；参考、更新索引只由合法源元数据和固定 seed 决定。

两源严格留一 RX 后不能形成跨 RX U 配对，额外保留两 RX 均可参与更新、参考物理样本互斥的辅助对照。它只测跨样本迁移，不能称 RX 留出。合计 38 个快照，每快照8臂，共304次可丢弃优化器更新。

8臂：L-only、原完整U、分别去除基础伪标签CE/配对KL/浅中层对比/融合对比/外推增量、同Tri检查点上的普通PL单步。最后一臂不是已训练PL模型。移除基础伪标签CE仍保留外推增量中的正外推CE和负普通CE，只是分解归因反事实，不能称关闭全部U分类或推荐训练配方。各分项梯度须重建原U梯度，移除项后重新执行原完整L锚点、按组cap1的原梯度保护；不新增实际参数更新保护。

E20/E30是原分段训练的新段起点：下一段分别10/20轮，按原首步cosine LR、CENTER_UNITS物理clip5和AdamW空动量执行。不是任意中间步动量，更不是完整训练反事实。其他源RX、L_s样本和E30祖先已被父模型训练见过，本诊断仅是本次更新的留出源RX迁移代理，不是独立未见RX泛化。

## 权限、评价与停止

只使用源L_s真实标签、U_s IQ与公共RX/day；不读取U真值、V、target、测试IQ或测试真值。参考指标为同一raw clean L_s样本的真实标签CE（LS0）、逐类CE和正确数；不作星地部署结论。参考未参与该快照梯度构造，不用其结果选分项或改变矩阵。影子参数/优化器全部丢弃，不写原检查点或训练状态。

完整U收益=参考CE(L-only)-参考CE(full U)。第j项条件收益=参考CE(without j)-参考CE(full U)，正值表示在其他项保留、原guard重算条件下保留j更好；不能相加为独立贡献。报告两检查点、每RX、类均值和正负次数，不将相关快照当独立seed。既有测试摘要仅用于诊断完成后的回顾性对照，不作为方向选择、超参数或停训反馈。

成本分别测原图及原梯度计算、额外五分项梯度、参考梯度、PL对照、每臂影子optimizer与参考前向，CPU2线程/FP32。原图计时含分解观察器的部分重复算子，是插桩基线估计，不能当未插桩训练时间或GPU在线开销。记录总快照耗时及运行环境，不外推GPU倍数。

协议/来源/非有限/梯度闭合/原backward不匹配/参考隔离失败则停止本诊断，保存产物，不根据收益正负提前停止，不触碰其他owner进程。真实检查点源前向和完整首个影子快照是运行第一步的smoke，PASS后继续固定矩阵。
