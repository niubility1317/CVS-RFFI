# LoRa 局部突发与相关扰动下的相位修正

[预登记矩阵](experiment.json) · [运行事件](events.jsonl) · [基础扰动组](../20261124-phase1-lora-phase-dose-source-m4-r01/report.md)

基础通用扰动的合法源 U 检查显示，500 个留出包全部要求全包满剂量，逐 RX 约 95.3% 至 96.6% 的受支持位置能量也要求满剂量。在局部学习可以做出不同决策之前，训练数据本身必须含有可靠程度不同的重复前导参考。本组在相同模型、源物理包、损失、学习率、两阶段观测估计和 40,000 步预算下改用一种通用扰动混合。两臂从零训练，仍比较全包标量和逐位置剂量。基础两臂照原方案跑完整。

## 扰动与数据权限

通用扰动按 40%、30%、30% 混合基础扰动、局部独立相位突发和跨 chirp 相关突发。独立臂给各 chirp 不同的有界相位和中心。相关臂从六条随机选 2 至 4 条共享相位突发，剩余观测提供不完美的参考。支持窗使用平滑升余弦，中心、半宽和有符号幅度独立抽样。两份实际源 U 相关波形共用随机数状态，噪声振幅可以随波形能量标定变化。无真实场景号、航迹、精确噪声、信道作用参数和目标统计作为拟合或选模输入。恢复器只读当前包六条 IQ、从中估计的 \(\widehat A\)、\(\widehat\sigma^2\) 及重复信息。粗细相位在同一步联合优化，回写保持逐点实收幅度、样点索引以及功率加权的常数和线性相位约束。整包上限 10% 原 IQ RMS。

相同 500 包的独立固定通用扰动网格中，498 包仍在全包最大档；逐 RX 偏向满剂量的区域能量降至 83.2% 至 86.2%，零剂量位置能量占 5.5% 至 7.8%。这里的区域选择独立评估且在联合低阶相位投影之前。基础组零剂量位置能量占 1.2% 至 2.2%。两类结果都只度量合法源 U 的监督差异。 [九档相位剂量复算](../../../tools/lora_phase_dose_grid.py)

冻结评估仍在同一 900 个源 V 包、Tri-set seed 2026092702 和两条路线各七景。先写定全部 13 个读出的两份预测，再独立评分。报告固定主读出、等实际 IQ RMS 对照、精确不参与候选的波形归因、逐景逐 RX 净纠错与配对区间。进一步计算扰动改变前后，局部相对全包的净收益差。应在相同物理包联合计算该差及不确定性。

## 同量相位位置与弱谱

独立波形重放使用固定物理行、同一直通去扫相位坐标和原时间索引。低城区的参考相位来自隔离侧精确非载波扣噪，实收恢复计算结束后才使用该参考。整个受扰场景中，Full 736 包、Residual 900 包触发。Full 触发包的局部剂量离散度逐 RX 中位数为 0.003–0.014，Residual 为 0.365–0.381。基础通用扰动组的对应中位数均为零。
