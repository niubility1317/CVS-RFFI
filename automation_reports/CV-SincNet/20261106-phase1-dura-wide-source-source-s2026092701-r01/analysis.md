# 扩大源数据覆盖：GPU 训练

原 DURA 冻结、修正网络从头初始化，固定 32768 个合法源记录（完整包含原 8192 fit ID）、3 种模拟视图和 5 轮，batch 32。与原 8192 条 5 轮对照相比，样本曝光及参数更新次数均为四倍，成本不匹配。训练不读取 F、TX 标签、V 或目标；固定最终权重，不依据源或目标成绩选模。

N607 GPU 7：首次源上下文准备和保存耗时 432.1 秒，GPU 优化 339.2 秒，数据传输 0.252 秒；缓存约 769 MiB，DURA 原训练成本另计。真实 checkpoint 训练 smoke 和冻结权重 112 条源预测 smoke 通过；七景预测已启动。

## DURA 源域误差与可观测量的探索性分析

复用本 run 的合法源上下文缓存，以种子 2026110803 随机抽取 8,192 条源物理记录及每条三个既定视图。按物理记录分为各 4,096 条的阈值拟合组和评估组，每组各 12,288 个视图；同一物理记录的三个视图不跨组。仅使用源 received、clean、冻结 DURA 输出、估计方差和物理残差，不读取 TX 标签、F、V 或目标。此分析事后探索，并非事前注册的模型选择实验。

在拟合组分别取可观测量的 75% 分位数；源波形高误差定义也由拟合组 DURA 对 clean 的归一化 IQ 误差的 75% 分位数（0.01673658）确定。下表在评估组计算，精确率指被可观测量阈值标记的视图中实际处于高误差的比例，召回率指所有高误差视图中被标记的比例；高误差标签仅用于源域诊断。

| 源可观测量 | 评估组被标记视图 | 高误差精确率 | 高误差召回率 | 被标记 / 未标记平均 NMSE |
| --- | ---: | ---: | ---: | ---: |
| 估计噪声方差 / DURA 能量 | 3,041 | 72.54% | 70.57% | 0.07077 / 0.00766 |
| 物理伴随残差能量 / DURA 能量 | 3,070 | 75.54% | 74.18% | 0.07214 / 0.00701 |
| received 能量 / DURA 能量 | 3,088 | 74.71% | 73.80% | 0.07202 / 0.00692 |

按三个源视图分别检查，物理残差高组平均 NMSE 为 0.07030 至 0.07387，低组为 0.00689 至 0.00707。三视图共享物理记录，不能将 12,288 个视图当作独立记录。评估组只相对阈值拟合物理互斥，仍来自原 32,768 源上下文，DURA 可能在其自身训练中见过；不声称对新接收机或目标数据独立泛化。

这些统计表明，可观测物理残差在该源分布中包含恢复波形误差线索；它不是身份错误、未见域性能或有效路由的证据。所算阈值没有用于任何在跑模型、目标预测或候选选择，不能依据该表宣称识别性能提高。
