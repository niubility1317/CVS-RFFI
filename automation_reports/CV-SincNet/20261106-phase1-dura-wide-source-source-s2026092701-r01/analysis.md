# 扩大源数据覆盖：GPU 训练

原 DURA 冻结、修正网络从头初始化，固定 32768 个合法源记录（完整包含原 8192 fit ID）、3 种模拟视图和 5 轮，batch 32。与原 8192 条 5 轮对照相比，样本曝光及参数更新次数均为四倍，成本不匹配。训练不读取 F、TX 标签、V 或目标；固定最终权重，不依据源或目标成绩选模。

N607 GPU 7：首次源上下文准备和保存耗时 432.1 秒，GPU 优化 339.2 秒，数据传输 0.252 秒；缓存约 769 MiB，DURA 原训练成本另计。真实 checkpoint 训练 smoke 和冻结权重 112 条源预测 smoke 通过；七景预测已启动。
