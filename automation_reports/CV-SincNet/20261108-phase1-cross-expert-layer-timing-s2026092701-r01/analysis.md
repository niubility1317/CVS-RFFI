# 大型时频恢复网络逐层 GPU 计时

固定 128 条合法源 IQ、完整 CrossExpertRefiner、deterministic FP32 和 TF32 关闭，时频输出头按固定种子赋予标准差 0.001 的非零权重和偏置。热身及原始参考前向后，对 Conv1d、GroupNorm、GELU 注册仅计时的钩子，逐层同步 CUDA，两次完整输出均与无钩子原 forward 字节级一致。未读取 F、TX 标签、V 或目标，模型未更新、未保存。

9 个高耗时卷积位于两个残差分支，卷积核均为 5，扩张率分别为时域 2、4、8、16、32、2 和频域 2、4、8。相同进程、输入形状和 GPU 条件下，扩张卷积的耗时占本次插桩前向的绝大部分；这为进一步检验数学等价的卷积计算路径提供具体方向。

每一模块前后都同步 GPU，会改变执行时间；GPU2 同时承载其他 owner 工作，且仅一个批次和两次前向，不能将绝对耗时或比例直接推广到独占设备及完整训练。输出逐字节一致仅针对该固定批次与诊断模型，不证明所有数据、梯度或训练结果一致。当前没有加速结果，未改变在训模型。
