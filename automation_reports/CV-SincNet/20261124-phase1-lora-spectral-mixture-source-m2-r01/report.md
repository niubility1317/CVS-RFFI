# LoRa 奇偶前导条件跨频混合先验

[预登记矩阵](experiment.json) · [运行事件](events.jsonl) · [连续回写对照](../20261124-phase1-lora-cross-frequency-dose-source-m4-r01/report.md)

上一轮在同一个跨频方向上学习两个整包强度，等量消融没有观察到正向识别变化。Residual 低城区五台接收机的编辑剂量中位数仍为 30%。这一轮改写条件均值与协方差，检验实收前导能否支持与统一先验不同的复数修正方向。

## 信号模型与输入权限

| 可用量 | 来源、时点和误差 |
| --- | --- |
| 当前前导 IQ、对齐相位与 RMS | 共用六条 256 点实收前导。每条 chirp 独立去扫、跟踪旋转和定标，在原采样点回写；每条可见有限的有效频偏和时偏。 |
| 混合先验 | 从固定 20,000 个无标签源 U 原始地面接收包计算 Helmert 公共和独有联合协方差。将跨频公共协方差前 12 轴作为路由空间，固定从零拟合 8 个分量，做 64 次全量 EM。随后按软责任估计共同特征基中的条件均值和方差。条件矩向全局先验收缩。 |
| 每折路由方差与一致性 | 奇、偶三条分别取归一化去扫谱的复均值。每折只用本折复均谱外带中位功率估计该均值的每实维噪声方差。全包读出单独从六条平均估计。外带可能含侧带、色噪及硬件失配；两折也可能受共同失配。 |
| 收缩方差与旁路 | 公共和独有复修正的方差代理仍来自同包 Helmert 外带，路由概率本身由指定折产生。用相同独立 2,500 源 U 包固定 clean 阈值，两路共用。 |

对每个分量，在相同跨频特征基中减去该分量条件均值，按相应信号方差和实收方差的比值做平方根后验收缩，再加回均值。奇、偶概率分别混合这些复谱提议，三条 chirp 由对折概率决定提议的权重。主读出将奇偶交叉的半量提议与全局先验半量插值，插值权重是两折概率一致度乘以后验相对先验的偏离强度。固定概率对照保留各分量但移除实收路由。同量对照将统一和对折读出缩到逐包相同的较小物理 IQ RMS。所有分支保持原去扫载波，单次整包编辑 RMS 上限为原 IQ 的 30%。两路线冻结同一个混合状态和阈值。

Zoran 与 Weiss 使用高斯混合从干净图像块学习统计先验，公开 EPLL 实现用可见退化图像的似然选择分量，随全图求解更新重叠图像块。这里的路由观测是同包两组实际 LoRa 前导，对折概率给当前组加权，输出在同一个冻结 IQ 判别器评估。消融可区分多分量先验、实收选择以及改动量。 [EPLL 原始论文](https://people.csail.mit.edu/danielzoran/EPLLICCVCameraReady.pdf) · [公开实现与方法](https://www.ipol.im/pub/art/2018/242/)

## 冻结测试矩阵

这是全量 EM 的工程对照，源 U 学习和门限固定与冻结识别器、TX 标签、源 V、目标、注册轨迹及真实新增噪声隔离。固定 500 个留出 U 包只用于报告通用扰动下的实收路由统计，两路线均使用冻结 Tri-set 2026092702、同一组 900 个源 V 物理包、七景及 11 个固定读出。两路预测全固定后用独立 CPU 读取标签。主读出固定为一致性混合半量，须两路各超过半量 DURA 并保持 clean 才晋级。隔离新增噪声用于评分后的频带归因。

## 路由置信和弱谱复核

独立 CPU 复核 500 个固定源 U 留出包及与目标独立的通用扰动。同一包在 clean 与受扰状态只有 33/500 被分到相同的高后验分量。先验权重只有 1.46% 的分量，从 clean 的 3/500 上升到受扰的 428/500。五台 RX 的受扰最大后验中位数均为 1.0，但主分量标准化平方距离中位数从 clean 的 0.31 至 0.71 升至 4.73 至 6.87。这个距离以所选分量方差和同组估计噪声之和为分母，按 12 维平均。分量编号由同一模型产生，只用于衡量混合路由稳定性。两折高一致性可能来自对同一宽分布分量的共同偏好。 [独立源 U 路由复算](../../../tools/lora_spectral_mixture_routing_audit.py)

实际 practical 低城区的激活数为 Full 736/900、Residual 900/900。五台 RX 的最大后验中位数范围分别为 0.673–0.738 和 0.471–0.577，奇偶概率总变差中位数范围为 0.346–0.383 和 0.368–0.451。主读出的交叉信任系数中位数范围为 0.599–0.618 和 0.473–0.542。Full 和 Residual 的低城区公共外带方差中位偏差分别为 +0.48、+0.07 dB，独有中位偏差为 +0.09、−1.45 dB。
