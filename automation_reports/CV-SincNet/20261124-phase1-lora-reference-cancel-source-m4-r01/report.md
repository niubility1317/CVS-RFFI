## 接收模型和匹配消融

输入为同包六条实收前导 IQ。沿用已知 LoRa 上扫参考及配准估计，在 256 kS/s、每 chirp 256 点的窗口中读短时时频先验。每个 32 点步幅估计相对复增益，置信度根据重复段幅度和相对拟合残差收缩。该估计同时包含相对的载波残差、传播差别和真实 chirp 差异。用去扫后的 64 kHz 外稳健功率估计有效噪声尺度。相关干扰和前端失配会改变这两项能解释的成分。

每对 chirp 在整窗复谱中分解公共和独有分量。每频带以 33–127 kHz 的三个保护参考及源 U 复交叉协方差构建一个阻塞方向。给仍有参考能量的分量求复岭解。一对拟合、一对验证、一对执行，轮换三组。固定组和留出验证组共用相同的阻塞方向及求解，区别是相消剂量固定为 1 或由留出风险决定。源功率取校准组逐 RX 99% 分位的最大值并放大 10%。裕量取两份通用源扰动下风险差中位数的四分之一。跨组共享噪声和实收坐标漂移会改变经验功率覆盖。中间修正与粗层相加，然后进入细化。整窗去扫坐标的载波保持，整包输出修正 RMS 限于实收的 10%。两条路线用同一权重和源门限，旁路逐样点复制实收 IQ。

源域两臂从零训练，共用 20,000 个源 U 包、2,500 个互斥校准包、500 个互斥留出包，40,000 次 AdamW 更新、batch 24，共 960,000 次包抽取。源 U 的两个独立通用扰动视图训练同包一致性，第三份视图在一份扰动上叠加真实源包差异以检验局部复谱传递。弱差异损失分别衡量公共和独有分量。通用扰动包含相位漂移、独立高斯和带色噪声、短回波及非整数频点干扰。拟合、校准和冻结阶段隔离源 V、TX 真值、冻结识别器、目标 IQ、测试场景配置和精确传播/噪声参数。

冻结的 Tri-set 种子为 2026092702。Full 和 residual 各用同一批 900 个源 V 物理包和七景。两路线包含直通、原成熟半量 DURA、仅同步、同步加相对 LS 与 Wiener、两臂各三种读出、同权重关闭相消或遮蔽估计量。独立 CPU 评分在双路预测和物理 ID 固定后读取源真值。按接收机分层重抽物理包 1,600 次，保留同包跨景相关。

## 生产形状合成检查

使用实装六条 256 点 chirp 的相消器，每种条件生成 256 个新合成包。只有合成测试计量能读取真实噪声。共同关联方向稳定时，验证组在 1–8 和 9–32 kHz 降低噪声均方误差 61.99% 和 73.78%，固定组为 73.11% 和 81.60%。独立噪声时，固定组两带噪声误差增加 20.22% 和 3.34%，验证组平均剂量为 0.0056，两带分别增加 0.10% 和变化约 0.00%。当参考与噪声的关联方向在三对 chirp 之间冲突时，验证组的剂量为零，固定组两带噪声误差分别增加 169.28% 和 164.72%。两组 clean 逐点一致。这些数值衡量构造场景中的剂量行为。 [生产形状合成检查](../../../tools/lora_reference_cancel_observability.py)

## 同包幅相与估计误差

双路独立评分后，在相同 900 个物理包上重放实收窗口。各方法沿用直通的去扫、时间和 RMS 坐标。一个参考是用直通复增益对齐的源波形，另一个是在接收波形中隔离扣除实际仿真加性噪声。两类参考只进入事后计量。

| --- | ---: | ---: | ---: |
| Full 直通 | 19.760 | 14.376 | 0.2254 |
| Full 留出验证全量 | 7.259 | 4.166 | 0.2969 |
| Full 同权重关闭相消 | 7.259 | 4.166 | 0.2969 |
| Residual 直通 | 110.867 | 98.144 | 0.0939 |
| Residual 留出验证全量 | 70.941 | 61.265 | 0.1058 |
| Residual 同权重关闭相消 | 70.941 | 61.258 | 0.1058 |

低城区中，各带各分量的相消剂量中位数均为零。Full 在 1–8 和 9–32 kHz 的独有分量平均相消剂量为 0.0221、0.0261，residual 为 0.0465、0.0506。对实际噪声的独立重放显示，解析相消项在 1–8 kHz 独有分量的逐包平均噪声误差反而上升约 0.14% 和 0.24%。校准的源功率界在 clean 该分量覆盖约 99.3%，到低城区降为 full 31.3% 和 residual 10.1%。这解释了源校准上界迁移到受扰观测时的局限。相比之下，9–32 kHz 的公共分量在低城区仍有约 97% 覆盖，但相消剂量和净收益都接近零。

同带宽外带估计相对真实噪声功率的偏差中位数，在高强郊区为 full +4.39 dB、residual +1.38 dB，在低城区约为 +0.19 dB、+0.15 dB。精确功率接近时，相消方向仍缺乏足够交叉证据。同权重关闭相消几乎复现整体 9–32 kHz 波形和准确率，当前恢复的主要变化来自联合粗细层。下一轮的待检验问题是如何从现有六条 chirp 得到真正能预测近载波扰动的独立观测。两份 `*-waveform-fidelity.json` 保留逐景、逐 RX 和四个频带的结果。 [幅相与估计误差复核脚本](../../../tools/lora_local_phase_fidelity.py)
