## 读出、权限与运行核验

使用同一原冻结 R69 E20/4,940、当前 Main split Tri-SIG-TIME SSL seed 2026092701、相同 1,800 个源 V 物理包。两路线各自覆盖 clean 和六景。直接读出实收 IQ，再使用只读挂钩记录原前向计算的粗恢复、第一先验、第一次观测一致性求解、第二先验及完整 R69 终点。每次求解使用原两次共轭梯度更新。先验是原前向中的完整 IQ 提议，已经包含其基准粗恢复项。挂钩在原求解过程中不修改状态，完成后从模型移除。

本实验零新增参数、零训练、零拟合、零目标读取。候选输出和分类过程均由当前实收 IQ 计算，阶段读出没有匹配 clean 辅助。R69 为历史合法源 IQ 训练的冻结对照，原作用及噪声估计器继承模拟监督，推理只见实收 IQ。详见原配方。 [DURA v1.0 的训练与推理](../../../docs/DURA_V1.md)

N607 `VERIFIED`，执行提交 `d0d43cf6c7f085b89155b6e2b4f5dbc96c90841c`。真实检查点 smoke、一次独立 P0/P1、归档传输和远端编译均通过。两条路线分别在 GPU 0、GPU 1 完成。14 份预测矩阵的挂钩终点与原 Graph-RR IQ 逐样点一致，其最大差为 0，原直通与 R69 决策也逐包重现已归档对照。两路线七景固定后独立 CPU 读取源 V 标签。另由 CPU 按相同物理 ID 和接收机复算计数、纠错、改错及 1,600 次分层配对区间。

## 同包复幅相复核

评分后在隔离进程加载同包 clean，以原实收和其配对参考的最大有效重叠复相关确定重叠位置。所有读出在同一名义输出坐标使用这组位置，没有另行相位矫正或幅度重标定。短训练相位余弦以参考点的功率加权。下表为低城区的逐包中位数。 [逐景幅相复算入口](../../../tools/wisig_repeat_drift_fidelity.py)

Full 低城区短训练区的幅度 NMSE 从第一次先验的 0.0786 经第一次求解降到 0.0143，第二次先验为 0.0564，最后为 0.0065。第一次到第二次求解，Full 和 Residual 的边界复 NMSE 从 0.1323、0.1326 降至 0.0677、0.0677。相位与幅度均在求解后进一步改善，和较高的设备识别正确数同步出现。相位独立贡献仍引用此前固定边界的因子互换。 [同识别器的重叠区幅相因子](../20261124-diagnostic-wisig-main-overlap-source-m2-r01/report.md)
