# 响应保持目标对物理估计器的作用范围

## 已核实的梯度路径

当前响应保持版使用源记录构造同信道、同噪声的 `y` 和 `y+Aδ`，分别执行恢复前向，再以恢复差分与 `δ` 的相对平方误差作为响应损失。两次前向都会根据各自的输入重新估计物理算子和噪声；两个估计结果在进入后验和先验网络之前均执行 `detach()`。见 [源训练读出](../../../experiments/pamf_phase3_restoration/response_joint_prior.py) 和 [配对响应目标](../../../experiments/pamf_phase3_restoration/response_joint_prior_trial.py)。

物理分支和先验分支参数不共享，因此响应损失对物理分支参数没有直接反向梯度；它可以更新条件均值、协方差及其共享先验上下文。真实源两条检查确认联合细节目标对物理分支的梯度隔离，并分别确认单独响应项到均值头和协方差头均有有限非零梯度，见 [启动核验](training_started.json)。这是已登记的设计，不是运行失败。

物理分支并未被冻结。每个训练批次仍通过原始 `y` 对应的源 Action 和噪声监督更新物理参数；响应损失只是没有直接约束物理分支在 `y+Aδ` 下的估计变化。源两条检查是实现核验，不能量化完整数据或 Main 上的损失来源。

## 对诊断和下一版的含义

响应误差在前几轮偏高，可能涉及物理估计变化、条件先验变化及两者交互；现有训练日志只保存方向曝光与总体误差，没有把这些贡献拆开。不同轮次的模型、源 draw 和先验条件也同时变化，因此不能从日志认定某一分支是原因。[前四轮观察](training_progress_E04.md)

模型完成并冻结后，可在合法源端对相同样本、同一物理噪声和同一扰动，比较完整的重新估计响应与固定原输入物理估计时的响应，并分别按四方向报告均值、分位数和误差尾部。两者差异包含先验输入与物理估计的交互，不是可直接相加的因果分解。固定估计不向恢复器提供真实信道，也不是理论上界；另用真实源 Action 的反事实只能作为带额外信息的诊断。

如果上述固定条件诊断支持物理估计敏感性，再预登记独立对照：在不改变当前运行的前提下，利用训练中已有的 `y+Aδ` 前向，以相同的合法源 Action/噪声监督其物理估计；或者检验经过完整后验的响应梯度是否对物理分支有益。每项须独立比较 clean 保持、六景真实身份净纠错和实际代价。不能预先断言会提升性能，也不能用已揭示的目标错例确定参数或路由。

本分析只读取当前公开代码和已有源检查记录，没有新模型前向、训练更新或目标真值读取。现有固定 30 轮及自动七景测试继续，默认 DURA 不变。
