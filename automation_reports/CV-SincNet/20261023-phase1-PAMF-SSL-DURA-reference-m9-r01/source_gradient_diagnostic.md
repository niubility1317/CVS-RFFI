# E30 源域梯度诊断

只在 CPU 读取原 RXPSM 同 seed E30／6660 学生和自身 EMA；每 seed 固定前 8 个源 L128／U256 批次，共 24 个 probe。每次还原原模型参数、教师、统计与 L-only 原型，计算原 T1 有标签损失和原 RXPSM 已加权 U 损失的梯度；没有 optimizer、EMA 或已保存参数更新，没有 U 真值、目标或 GPU 工作。

这是以原 raw L IQ 作为受控首个 L 输入的诊断，内部六次 T1 前向保留；没有模拟 native 外部 ordinary 随机变换或 Adam 的真实步长。临时 L-only 原型／置信统计在 probe 后丢弃。不能把局部欧氏梯度冲突直接证明成测试集下降原因，也不能由此保证后续目标涨幅。
