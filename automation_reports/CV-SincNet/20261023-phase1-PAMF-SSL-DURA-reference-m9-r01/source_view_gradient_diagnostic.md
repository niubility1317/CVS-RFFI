# 原 E20 两类 U 视图的梯度贡献

仅 CPU、无目标／U 真值／源V／持久模型或教师更新。三个seed各固定前4个L128／U256批次，对预先声明的原F20纯监督E20和原RXPSM E20分别作同样诊断，共24次。两个来源均逐项核实scratch20／4440、实际source角色合同、seed、checkpoint身份、无目标选择及默认头。F20初始化自己的教师、空L-only原型与初始高斯状态；RXPSM复用自身E20的教师、原型与置信统计，因此不是只隔离教师参数的比较，也没有据此选择父模型。

每次还原原参数和初始状态，受控首个L输入为raw IQ，保留内部六次T1 L前向、原U普通噪声／Practical各一半、软目标和原型项。只将原已加权U损失的逐记录项按实际视图mask拆为两部分，仍除以完整256，严格核实二者之和等于原U scalar。分别对同一完整L和已有raw-L两前向真实CE图求导；无optimizer／EMA／保存参数更新，临时L-only统计丢弃。诊断代码为已提交51e4ccf的无新机制路径，真实父权重保持原来源。

这里“作用方向相反”指两个分支各自与raw真实CE梯度的内积异号，不是两个U梯度之间已测得负内积。实际原配方两个分支使用不同的128条记录，不能将差异完全归因于变换；它是原优化器当前接收梯度贡献的描述。首个外部ordinary随机变换未模拟，native Adam实际步长也未模拟，不能证明目标损伤或收益。

两个E20起点都有这一现象，没有支持替换原父模型的独立证据。下一条仍固定原同seed RXPSM E30，只检验视图分别投影和范数平衡。普通分支小不等于应被任意放大；新方案把每个非零投影视图限制在full-L范数的一半，总U范数不超过full-L，但仍可能放大噪声，须正式测试。
