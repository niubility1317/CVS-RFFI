# 已有 SSL 模型源状态检查

这是非阻断的机制诊断：读取 PSM、RXPSM、VIEWANCHOR 各三个固定模型的 E20/E30/E50 源状态。VIEWANCHOR 的 E20/E30 复用 RXPSM；没有新的 GPU 前向、训练、目标文件读取或 U 真值读取。当前 PAIREDU/UCRIC 方案、参数、预算和父模型均保持。

类别权重未显示明显塌缩，原型覆盖也完整。这里的类别是教师软目标 argmax 的累计有效权重，不是 U 真实分类准确率；均衡的预测分布也可能包含错误伪标签。教师置信度不能当作正确率。

在 RXPSM 与 VIEWANCHOR 的最终 L-only 原型中，同 TX 跨 RX 余弦均值约0.972至0.986；所有30个类别/接收机锚对其他 RX 的平均同类参考均高于最相近异类参考，但部分余量较小，最小约0.0055。该结果描述源域最终特征，不证明逐 U 正确，也不证明目标 RX 泛化。

per_class 使用 float32 累加，effective 使用逐批权重和再累计，最终两种量的相对差约0.0014%至0.0023%。JSON完整保留各自原值与实际差异，类别占比以per_class自身和归一化；整数U曝光、optimizer更新数与目标正确计数保持各自独立口径。

现有固定720条源 V 诊断仅作健康参考；本任务验收仍为原168000×七景目标测试、三个模型seed、单PAMF与固定DURA＋同一PAMF双读出。当前源统计未提供严重类别失衡或缺失原型的证据，两条正在运行的候选按原计划完成，不根据这些摘要热改或择种子。
