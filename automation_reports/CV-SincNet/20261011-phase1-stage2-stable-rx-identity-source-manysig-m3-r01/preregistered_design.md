# 稳定接收机分量：源 V 身份保持

状态：LOCAL_VERIFIED，尚未执行。检查规则在运行前固定。

上一轮稳定接收机分量在 27/27 个跨 TX＋留一日条件下优于零预测。本轮检查它能否在真实源 V 的固定特征上减弱，同时保持身份区分。该检查不等于实际训练后的性能，也不访问目标测试。

仅从 L_s 的归一化 joint160 组均值估计 RX 分量。每个 V 日期使用其余源日期，拟合包括全部六个源 TX；估计时先在各 TX/day 块内对 RX 中心化，再按组等权平均，固定收缩 0.4。对 V 使用 normalize(z - alpha*p_RX)。变换不接收 V 标签，不拟合 V，不改变分类头；已知源 RX/day 只用于源诊断，不能移作未知目标 RX 推理方法。

固定 alpha=0、0.25、1.0。0 是原基座；0.25 是唯一主判断；1.0 只检查过强减除，不允许事后改选它。三种子分别报告准确率、错误数、修复与破坏数、margin、有限保持风险、RX/day/TX 分层。

推进条件：每个种子在 alpha=0.25 下，V 总体准确率下降不超过 0.2 个百分点，任一源 RX 下降不超过 0.5 个百分点。用错误数整数比较实现边界，避免浮点误判。通过后才冻结稳定 R 的训练目标；本 run 不启动身份训练或目标测试，也不把源 V 指标称为 84% clean 目标达成。

完整来源：原始匹配种子 E200 纯 CE＋旧门控＋cosine 权重，无新模型初始化。原 cosine 权重读取后必须在 L_s 回代复现已保存 parent margin；L_s/V 物理 ID 契约及缓存顺序核对。无 V 参数更新，无 U/半监督/星地增强。

验证：8 项合成检查覆盖 leave-day 与 fit-TX 隔离、变换不依赖标签及排列、错误与修复计数、原始 scale30、错误分类头拒绝、未知 RX/day 拒绝、总体与 RX 精确阈值边界。独立 P0/P1 审查通过。CPU 2 线程，三种子串行。
