# R 条件特征方向源域闭式诊断

状态：LOCAL_VERIFIED。尚未执行；下列设计在运行前固定。

本轮解释此前源域观察：全局 R 在 TX 4/5 留出折均失效。它可能来自物理扰动不能跨 TX 预测，也可能来自同一扰动经过不同波形后产生不同的特征方向。全部设计依据源域证据和用户报告第 8.1、9.4 节；目标测试分数不参与设计、选择或拟合。

使用三个原始 E200 纯 CE 基座已经保存的 L_s 特征和数值导数。每种子同一批 6,300 个物理样本，共 90 个组、18 个条件块（实际分组重新核对）。留出 TX 折为 (0,1)、(2,3)、(4,5)。身份网络曾训练全部六个源 TX，因此这里仅检验辅助关系跨 TX 预测，不能称为端到端未见 TX 泛化。

固定五个预测对照：

|对照|输入与输出|作用|
|---|---|---|
|global_rank2|40 维状态→全局 rank-2 特征位移|复现现行 R|
|global_full|40 维状态→全局 160 维位移|检查 rank-2 容量限制|
|tangent_state|状态→8 维动作，再由当前组自己的平均 Jacobian 作用|检验方向条件化|
|global_environment|源 RX/day→全局特征位移|已知源环境的共享偏移对照|
|tangent_environment|源 RX/day→8 维动作，再由当前组自身 Jacobian 作用|分离动作参数和特征响应|

动作对组内样本是同一 a_g；每个样本使用自己的 J_i，所以平均预测为 mean(J_i) a_g。不是逐样本状态动作策略，也不把别的 TX 的特征差加到当前 TX 上。

各块内预测势函数中心化。拟合采用等块、等组权重；评价采用等块、等 RX 对权重。岭系数固定 0.1；状态标准化仅来自拟合 TX，条件设计的列 RMS 也仅来自拟合组。全局与条件参数化的尺度、参数量不同，不能把差异单独归因为条件化。

同时报告原始预测和受界预测：每个条件块使用同一个 beta=min(1,1/max|a_g|)，避免逐边裁剪破坏环一致性。受界仅保证局部动作坐标范围，不证明有限 IQ 变化等于 Jacobian 预测。

另列使用留出位移的局部切空间最小二乘 oracle，rcond=1e-6。它只回答现有 L/T 导数能表示多少差异，绝不是预测成绩、置信度或训练目标。对无界解统一缩小后的值也不是最优受界 oracle。

后续源域动作：若受界条件预测在每个种子的折均值都优于 global_rank2，且每种子多数折 c>0，则进入真实 IQ 核验；否则保留负结果，进一步区分导数表示不足与状态预测不足。此次不会自动启动身份训练，也不会访问目标测试集。

验证：4 项合成检查通过，包括留出特征不改变拟合系数、旋转 Jacobian 跨组预测、限幅与环一致性、oracle 上界；独立 P0/P1 审查通过。CPU 闭式运算，2 线程，三个种子串行，不占 GPU 训练名额。
