# R 条件特征方向源域诊断结果

**三种子诊断已完成，状态 VERIFIED。当前条件 Jacobian 方案没有达到预登记的推进条件，本轮不据此发布新的身份训练。84% clean 目标仍未达成。**

这次实验只使用原始 E200 纯 CE 基座的源域缓存；身份更新为 0，没有新增目标预测。此前 B0–B3 clean 结果保持原报告，本次不把源域诊断分数称为识别准确率。

比较量是“留出 TX 的完整 160 维接收机组差预测 MSE / 零预测 MSE”。小于 1 表示有预测收益，越低越好。表中先对每个种子的三个折取等权均值，再对三个种子取均值；不是合并 MSE 后求比值。

|全局 160 维 R|1.273384|1.393115|1.207643|1.291381|3/9|

数据口径：每份基座均观察同一批 6,300 个合法 L_s 物理样本，90 个接收机组、18 个 TX/day/quality 条件块。三个模型种子不是三份独立采集数据，9 个折不能当成 9 次独立数据实验。身份父网络见过全部六个源 TX；只在辅助拟合中留出 TX。

**主要判断**

1. 增加全局输出容量没有解决迁移。全维 R 拟合折平均误差比为 0.225757，留出折却为 1.291381；原 rank-2 为 0.626225 / 0.984028。这个拟合与留出差距支持保留容量控制，而非扩大 R 网络。
2. 当前条件预测也没有稳定取胜。状态条件方法未限幅时 9/9 折都不如零预测。受界后 8/9 折略有收益，但第三种子的平均误差比为 0.997754，高于原 R 的 0.936823。环境条件 Jacobian 方法同样只在前两个种子的均值优于原 R。两者都未达到预先固定的“每种子均优于原 R，且每种子多数折 c>0”条件。
3. 源环境共享偏移是值得保留的源域线索。它在 9/9 折优于零预测，平均误差比 0.946627，相对零预测约减少 5.34% 的组差平方误差。但它使用已知源 RX/day，未检验新 RX，也未证明 clean 识别提升，更不能直接作为目标接收机校正器。
4. 不能把问题完全归为导数方向缺失。允许使用留出位移且不限制动作幅度的 oracle 平均误差比为 0.620294，说明当前局部张成空间能表示一部分差异。但对应动作坐标往往远超注册边界；这只是可表示性诊断，不是可用的扰动策略。

|---|---:|---:|
|tangent_state|11.682|0.08562|
|tangent_environment|9.687|0.10323|
|oracle|23.897|0.04185|

无界 oracle 解整体缩小后的误差比为 0.969904，但这不是最优受界解，不能声称“物理边界内最多只能解释 3%”。它提示应先区分保守缩放损失与受界表示能力，再决定是否增加物理维度。真实 IQ 有限动作核验本轮未执行，因为两个条件候选没有满足预登记推进规则。

**下一步源域研究**

优先验证两件事：其一，用明确盒约束的最小二乘求解受界 oracle，并保留收敛与最优性残差，判断统一缩放是否过于保守；其二，把源 RX/day 共享偏移分解为跨日稳定接收机成分和日变化成分，并用独立包子集检验估计噪声。后者只是解释源域关系，不能把已知 RX 标签当成未知目标 RX 的可用状态。
在这些证据形成之前，不增加辅助网络深度、不扩大动作幅度，也不把 5.34% 的关系误差下降换算成 clean 准确率提升。后续若产生训练变体，仍从对应原始 E200 基座出发，保持 40 轮、三种子、同预算 CE 对照和预登记后的自动 clean 测试。
