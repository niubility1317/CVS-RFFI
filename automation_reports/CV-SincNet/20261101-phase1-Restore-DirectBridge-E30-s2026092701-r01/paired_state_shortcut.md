# 配对中间状态与原观测条件的代数捷径

**同时给出中间状态、原 received 和时间时，存在精确的训练 clean 代数解。** 这是本版训练进行中、尚未开始其 Main 预测时发现的方法限制；不据此热改、停止或取消已固定 DirectBridge 的训练/测试。

设合法源配对为 clean $x$、received $y$，训练状态为 $z_t=(1-t)x+ty$。当 $0<t<1$ 且估计器同时读取 $z_t,y,t$ 时：

$$x=\frac{z_t-ty}{1-t}.$$

因此，中间训练位置的低重建误差可能来自这个解，而非学到了从真正受损观测推断身份线索的先验。端点 $t=1$ 仍需做实际恢复，不能由上述恒等式判断完整网络一定使用了捷径或最终性能必然无效。

部署中若第一次预测为 $c$，更新后 $z_{3/4}=c/4+3y/4$。在后续位置代入这个解析解，预测仍为 $c$；继续使用固定更新，到最终仍得到 $c$。这说明理想化的该捷径不会给首步增加恢复能力。它不是对实际神经网络各步误差的测量，也不是信道恢复上限。

本地合成 IQ 检查已验证三个中间位置的解析解及四步固定点。检查不读取真实源 IQ、TX、V/OE/目标或checkpoint，不新增神经预测或训练。新增5项检查加原DirectBridge7项共12项通过；源码见 tests/test_restoration_state_bridge.py。

独立 StateBridge 对照因此只删除估计器中的原 received 两通道：输入为当前 $z_t$、时间与坐标；received 仅初始化部署状态。其余随机初值、四步公式、训练时间分布、全部损失、数据顺序、30轮预算和正式Main矩阵匹配，无旧G权重祖先。新版本独立登记、输出和测试，当前 DirectBridge 保持原方案。两者结果均按完整冻结预测后的真实 TX 准确率、clean保持和净纠错解释，不由解析反例或源训练均值预判胜负。

原 InDI 的直接迭代形式只向估计器提供当前状态与时间，方法形式可核对 [原文第4节与式5](https://arxiv.org/html/2303.11435v1)。本项目的 F 指导、IQ 功率支持和具体网络仍属于独立改造，不继承图像论文性能结论。
