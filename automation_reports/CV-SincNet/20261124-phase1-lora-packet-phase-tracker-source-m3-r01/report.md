# LoRa 整包二次相位与独立线性频偏

## 预登记

已有 150 源包的低城区隔离诊断显示，原独立跟踪与无新增噪声波形的频偏相差，full 中位数／P90 为 2.83／31.84 Hz，residual 为 8.37／75.21 Hz。把 residual 的逐 chirp 频偏拉向整包中位值时，误差增至 12.20／125.14 Hz。无新增噪声条件下该路线也存在约 157 Hz 的包内离散中位数。本轮保留逐 chirp 线性频偏，只共享可从实收前导复测的二次相位。 [历史频偏诊断](../20261123-phase1-lora-dura-packet-near-source-m2-r01/report.md)

对已截取的 6×256 实收复 IQ，先用原前导模板逐 chirp 做 8 倍 FFT 峰及局部延迟相位跟踪。在线性去扫坐标中，用 9 个预定二次相位模板在 −0.6 至 0.6 rad 测量单位能量的相干占比，逐 chirp 复振幅自由。奇、偶两组分别按原相干度平方加权，求峰值并在内部格点做三点抛物线插值。两组同号时取幅度较小的估计，异号或无信号时取零。应用整包二次相位后，以各 chirp 自己的去扫相干功率和一、二阶导数做两步受限频偏更新。修正总幅度截在 −0.4 至 0.4 rad，根据信号曲率、原相干度及相干功率变化接受或保留原值。每 chirp 的常相位、线性频偏和回写 RMS 保持独立。新细化仍用恒等近似观测作用，实际扰动输入为去扫外带功率代理。它没有取得逐包传播参数，也不把二次项命名为可辨识的采样频率偏移。

Tapparel 与 Burg 的同步路线提前在前导估计采样频率偏移，公开 GNU Radio 接收链用前导完成时频同步并供解调。本轮只利用基准已有的六条上 chirp 窗口，在恢复器内部学习前端修正后的观测，同时另观察独立二次相位同步对冻结识别的影响。共同弯曲可能含振荡器、接收误差及硬件指纹，原载波线性频偏没有在识别输入中直接删除。逐 chirp 的相干功率峰值更新使用经典复单音集中似然。 [两次时频同步原论文](https://arxiv.org/abs/2502.08485) · [GNU Radio LoRa 接收代码](https://github.com/tapparelj/gr-lora_sdr) · [复单音极大似然原论文](https://doi.org/10.1109/TIT.1974.1055282)

新臂只用合法源 U 从零训练 3,600 步，匹配上一轮镜像模型 254,735 参数、初始种子、网络、AdamW、余弦日程、batch 12、三视图、通用有色噪声与短回波、弱频谱差异传递以及上尾项。重训的唯一机制差异是接收坐标。旧方式计算源 U 门限和推理旁路，所有读出使用同一 clean 门限与原样回写。联合恢复的复数增量乘回估计相位和 RMS 再叠加原 IQ。同步独立读出只消除共同二次项，便于判断这一步对冻结识别有无直接帮助。训练、校准不接触 V、F、TX、目标、实际场景参数或新增噪声。权重冻结后在 500 个留出 U 上验证通用的独立线性与共享二次相位注入。参照是原 clean 波形的估计频偏加已知注入，度量估计对注入的响应。该诊断并不估计实际传播频偏的真值。

先执行两包真实无 query smoke。冻结后，两路同一 900 个源 V 包和七景用 Tri-set 2026092702 生成 12 路固定预测。含直通、同路半量 DURA、原镜像的粗／完整／半量、只改二次相位、旧权重仅改逐 chirp 峰值的半量、旧权重改整包坐标的完整／半量，以及新训练臂粗／完整／半量。两路预测写齐后，独立 CPU 逐物理包核对五个旧镜像相关端点和原预测身份，再打开源 V 标签。两路同一固定新读出须同时超过匹配 DURA 的六景并保持 clean，才考虑扩展验证。逐景、逐 RX、配对差和工程估计误差同期保留。


## 隔离重放的估计误差

从已冻结的父面板固定抽取 150 个源 V 物理包，五台源接收机各 30 个。分别重放 full 和 residual 的高郊区及低城区，并核对实收样本与已登记输入一致。已知新增噪声只用来构造诊断参照。候选本身只接收观测 IQ。本诊断未读标签、未改训练或门限。表中是每种估计在含噪波形和其自身无新增噪声波形上，中心瞬时线性频偏差的绝对值。频偏包含原波形和观测的影响。

| 路线及场景 | 原逐 chirp 中位 / P90 | 独立峰值细化中位 / P90 | 加整包二次相位中位 / P90 |
| --- | ---: | ---: | ---: |
| Full 高郊区 | 0.40 / 0.99 Hz | 0.28 / 0.69 Hz | 0.28 / 0.69 Hz |
| Full 低城区 | 4.61 / 42.33 Hz | 3.11 / 22.40 Hz | 3.14 / 22.53 Hz |
| Residual 高郊区 | 0.79 / 2.18 Hz | 0.58 / 1.41 Hz | 0.59 / 1.41 Hz |
| Residual 低城区 | 7.51 / 72.27 Hz | 4.11 / 34.21 Hz | 4.09 / 34.18 Hz |

低城区的 P90 相对原跟踪分别减少约 47% 和 53%。使用同一无新增噪声的独立峰值估计作为参照，两个路线的 P90 也分别从 41.81 降至 22.40 Hz、从 72.12 降至 34.21 Hz。两路 P99 仍在 162 至 176 Hz 附近，峰值细化未消除所有大误差。二次相位绝对估计量在低城区的中位数为 full 0.018 rad、residual 0.017 rad。二次项对线性频偏稳定性的增量很小。 [隔离重放全部分位数](source-physical-phase.json) · [复现脚本](source_physical_phase.py)

进一步固定每路线低城区原估计最差的 5% chirp，共 45 条。独立峰值细化使其中 33/45（full）和 36/45（residual）的同 chirp 误差下降。这个固定尾部的 P90 只从 301.8 到 299.9 Hz、268.2 到 258.7 Hz。分别有 23 条和 22 条原相干度低于 0.2，达不到局部更新条件。少量误差达到 kHz 量级，远超过约 128 Hz 的修正上限。该结果把主要的中等误差改善和仍待解决的粗峰大偏差区分开。 [固定尾部统计](source-physical-phase.json)

对粗峰大偏差另做了固定规则的隔离检查。至少两条高相干 chirp（相干度 ≥0.45）支持同一个 ±4 kHz 邻域，且当前低相干 chirp（<0.2）的独立 FFT 峰在邻域外时，才在邻域内为该 chirp 重新寻找自己的峰。替代峰幅度须至少达到原峰的 35%，归一化相干功率至少达到 0.015。每路线 900 条低城区 chirp 中，full 未触发，residual 只触发一条。该条相对无新增噪声参照的误差由 15.343 kHz 降至 280.49 Hz，residual 超过 1 kHz 的条数从 4 降到 3。其余粗峰大偏差仍存在。此规则只作台架诊断，各读出和训练结果使用原预登记配置。 [粗峰检查与复现](source-physical-phase.json)


## 留出源 U 的通用相位注入

在 500 个留出源 U 包上，施加通用有色噪声、独立的逐 chirp 线性相位和整包二次相位。已知注入量只用于误差比较。线性参照为真实源 IQ 原跟踪值加已知注入，二次参照为原 clean 两组估计加已知注入。原线性跟踪的误差中位数／P90／P99 为 8.19／57.09／123.51 Hz。使用独立峰值细化后为 5.99／24.72／53.55 Hz，加入整包二次相位后为 5.92／24.79／53.98 Hz。共同二次项的绝对误差中位数／P90／P99 为 0.0126／0.0427／0.1017 rad。这个检查验证同一机制对受控注入的响应范围。 [源 U 注入读出](source-u-phase.json)

## 观测量及部署成本

Full 有 1,629 次包级场景曝光触发恢复，其中 1,215 次的二次项非零。Residual 为 3,425 次触发、2,829 次二次项非零。活跃样本的二次项绝对值均值分别为 0.0244 与 0.0246 rad。两路线采用相同相干峰检验、门限和新训练权重。估计阶段仅依赖已取样的六条实收 chirp、已知理想前导和采样率。 [Full 二次项统计](full-phase.json) · [Residual 二次项统计](residual-phase.json)

新模型 254,735 参数，GPU 3 训练 3,600 步耗时 497.12 秒。RTX 3090 单包 B1 中位时延为 clean 旁路 3.83 ms，通用扰动触发时 57.90 ms，各测 24 次。N607 发布及源码执行、末端产物回读 VERIFIED，实际代码提交 5973a39b2b882b57139feb1736c0323cc517b650。五个旧权重相关端点的预测与父记录逐包一致。两路线七景预测全部冻结后才关联源 V 标签，本轮零目标访问。 [B1 结果](b1.json) · [源训练记录](packet_phase-complete.json)
