# LoRa DURA 实收方差版目标测试

## 预登记

实收方差版采用同一接收端估计完成训练与推理。逐 chirp 在去扫后的当前 IQ 中取绝对频率超过 64 kHz 的带外功率中位数，用于 DURA 两阶段 CG 数据项和先验的方差输入。粗恢复、学习的作用算子、双阶段先验、训练预算和初始权重与原宽版匹配。用既有源 U clean 校准得到的门限决定是否恢复。两条 practical 路线共用同一次冻结的权重和门限，无逐场景调参。 [源训练和估计说明](../20261124-phase1-lora-dura-observed-variance-source-m2-r01/report.md)

在 15 个未见接收机上，用同一 30,000 个物理包、原七个视图和固定 Tri-set 2026092702，测试第二阶段半量和四分之一量读出。半量是首要读出，两个剂量分别比较同批目标包上已经冻结的原宽版半量和四分之一量。原宽版的历史预测按两个路线各自完整的数组、固定种子、场景、包序、直通预测及门控计数核对后再合入。历史直通和匹配 DURA 保持原样。

N607 先跑一次源 U 真实权重冒烟，再并行预测两条路线。使用相对空闲且显存足够的 GPU，优先 7、3、6、2，并保留其他 owner。若输入合同、源权重、两路覆盖或数值异常，停止本 run 并保留已有产物。两条路线各 210 份预测全部固定后，本地独立评分器才读取目标真值。记录六景、低城区、clean、逐 RX 和同物理包纠错／改错及配对区间。B1 沿用同权重的源域 GPU 同卡已有实测。性能验收使用目标测试结果，源域用于解释。

10 项聚焦检验和独立 P0/P1 审查通过。 [完整命令和路径](experiment.json)

## 验收判断

实收方差半量和四分之一量在两条路线的六景均低于同剂量原宽版，四组 95% 配对区间都在 0 以下。半量的 Full 和 Residual 分别净减 1,621 条和 8,733 条，四分之一量分别净减 509 条和 2,903 条。两路线的两种读出也均低于各自匹配的原 DURA。clean 四组均为 21,109/30,000，持平。实收带外方差改动未通过目标性能验收。

诊断已验证带外估计更能反映整包噪声尺度，当前试验检验的是将该估计同时接入数据项和先验并重新联合训练的总体效果。因粗恢复与作用估计也随训练更新，本次结果没有单独度量各模块的贡献。单包与原宽版同卡计时见源域报告。 [训练记录与单包时延](../20261124-phase1-lora-dura-observed-variance-source-m2-r01/report.md)
