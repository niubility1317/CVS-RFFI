# LoRa 精确反演收益的载波与细节归因

## 预登记

上一轮去噪前导使粗波形误差明显下降，但相同物理包上的冻结识别收益有限。历史已知作用诊断同时保持观测载波和限制细化编辑能量，两项影响混在一起。本轮使用已核验的精确扣噪和反演端点，在同一批 900 个源 V 包上，等功率交换三项波形分量，识别反演收益的来源。 [历史反演及限幅对照](../20261123-phase1-lora-dura-exact-action-source-m2-r01/report.md) · [近期噪声与作用归因](../20261124-phase1-lora-common-failure-physics-source-m2-r01/report.md) · [去噪前导](../20261124-phase1-lora-pilot-after-denoise-source-m4-r01/report.md)

每个受扰包的两个诊断端点为精确 100% 扣噪与精确扣噪后反演。沿用原注册的六窗、原已知作用和正则阻尼。两端点各自用同一逐 chirp 跟踪器分成相位轨迹、在该轨迹下的复均值与零均值细节。轨迹含逐 chirp 载波线性相位和中心相位，复均值主要表示载波幅度。三项各从两个端点取值，得到完整八格析因。混合结果按包定标至扣噪端点的 RMS，无分带或局部编辑剂量限幅。另保留一个固定原始实收旋转基底的投影读出，移除反演增量在该载波方向上的分量，只做同样的全包定标。该读出保留载波投影到共同尺度。所有新读出在 clean 使用原始观测。

Full 与 Residual 的同一 900 个物理包、五台源接收机、七景使用冻结 Tri-set 2026092702。先真实源 U 五包每路线检查 clean、低城区及完整运算。从同一个源安全接口获得操作数，全部预测固定后独立 CPU 评分。评分前核对物理 ID、两路各七景的历史直通、半量 DURA、扣噪和完整反演的逐包一致性。按接收机分层重抽同一物理包，计算三个因素在其余两个因素四种组合中的平均边际净差，以及每组读出保留了多少原本由完整反演纠回的判断。逐景、接收机及成本同时记录。真算子和精确噪声仅用于本隔离诊断，禁止拿诊断读出做部署候选或正式目标评分。

6 项聚焦测试及一次独立 P0/P1 审查通过。N607 按空闲显存分配不同 GPU，模拟与反演每路线 8 个 CPU worker。运行验证限于不变输出、真实 smoke、双路预测与独立评分。实收重放、数值、覆盖或历史端点不一致即停止。执行命令和产物见 [登记](experiment.json)。

## 判断

Full 的主要识别增量来自去载波细节。只替换细节，六景比仅扣噪多判对 320 次［244，393］，低城区多 87 次［59，116］。同时替换相位轨迹与细节，保留了完整反演纠回的 715/722 次。只交换相位轨迹的六景净差为 −1 次，配对区间跨零。

Residual 的幅度和细节表现出强交互。只替换载波幅度，六景少判对 133 次。只替换细节，少判对 93 次。两项一起替换，多判对 383 次，低城区由 562/900 升至 663/900。将两种轨迹取值下的幅度与细节交互取平均，Residual 六景交互量为 +621 次［518.5，721.0］，低城区为 +323 次［282.5，364.5］。Full 对应为 +3 次［−6.5，13.0］和 +1 次［−5.0，6.5］。两条路线只交换轨迹的六景增量都缺少一致证据。

固定实收载波投影的对照没有局部编辑限幅，但低城区仅保留完整反演编辑能量中位数的 4.43% 和 14.40%，并改变了可校正的细节分量。该对照的识别损失说明这种固定投影会阻断本反演的大部分作用。上述析因进一步区分了轨迹、幅度与细节，指出后续可以检验幅度和相对细节的联合重建，避免将两者分别估计后直接拼接。所有结果使用固定 900 个源包与一个冻结识别种子，精确噪声和已知作用只用于归因。 [配对交互](source-amplitude-detail-interaction.json) · [交互复现](audit_amplitude_detail_interaction.py)
