# 源训练合并非有限检查对照

固定真实源 DURA 上下文、固定源遮挡先验和初始模型，本机 RTX 5070 Ti、FP32、TF32 关闭、确定性算法；512 个源物理记录各三个视图、五轮、batch 32。预热后两组交替先后顺序，模型初始化、训练顺序、遮挡随机数、优化器和梯度裁剪相同。每组逐步比较全部 240 次损失和全部最终参数。

| 先后顺序 | 原检查（秒） | 合并检查（秒） | 逐步损失和最终参数 |
| --- | ---: | ---: | --- |
| 原→合并 | 6.125 | 5.578 | 逐值一致 |
| 合并→原 | 5.735 | 5.328 | 逐值一致 |

两组原检查均值 5.930 秒，合并检查均值 5.453 秒，单机小样本约减少 8.04%。两组均逐步损失和最终参数逐值一致。受固定小样本、共享 GPU 和两次顺序测量限制，这不是 N607 的实测加速，也不证明完整五轮源预算或目标七景的逐值一致。

合并版本仍在 optimizer.step 前检查非有限 loss 和梯度范数及关键梯度是否存在；非有限 loss 时先做反传和裁剪再报错，参数未更新。单元测试覆盖正常梯度等价、非有限损失、有限损失但非有限梯度、缺失关键梯度。真实源先验 checkpoint 和源上下文 smoke 通过，不读取 F、TX 标签、V 或目标；不保存训练权重。正在运行的任务未更改。[原始结果](result.json)。
