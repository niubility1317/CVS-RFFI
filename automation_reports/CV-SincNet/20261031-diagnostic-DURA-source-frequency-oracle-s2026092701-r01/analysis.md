# 源频点理想修正：弱频点高相对误差未转化为稳定身份收益

最弱四分之一频点的相对恢复误差很高，但理想修正这些频点也没有稳定改善原 F 的 clean 选择。当前证据不支持仅因弱频点误差大就加重其损失。最强四分之一频点的复数理想修正，在两模型、两缓存视图均改善了选择保持，下一步可继续分离其幅度与相位成分；尚不能据此认定新的训练约束有效。

## 固定源面板与全部结果

512 个原训练池物理样本（128 L_s、384 U_s）×缓存01/20，noVar和默认DURA均只复用此前保存的恢复IQ。每包按其clean FFT功率排序，分成4组各64个复频点；Q1最强、Q4最弱，不是固定频带，也没有使用TX标签选频点。

表中是恢复后F与同一条clean输入的F选择一致数，分母512，绝非真实TX正确数。

Q4约占clean能量0.109379%。noVar两视图complexQ4只净+1/−1条，默认则−2/0条；只修正Q4相位或幅度同样未稳定改善。误差大的弱分量可能包含噪声、无关成分或部分有效信息，本结果不能证明Q4完全不含身份信息。即使complexQ4降低波形误差，也未给出同方向的教师选择收益。

Q1占clean能量约88.477817%。复数修正使noVar选择478→494、496→507，默认486→501、498→506。它同时消除了幅度与频率相关相位误差，尚未隔离两者。Q1耗费更多参考能量且移除更多误差，不能将这些差异直接解释成单位能量身份信息量；也不能只凭本结果把普通IQ损失再加大。

## 数学和权限边界

复数替换直接将该分区的恢复FFT系数换成clean系数，Parseval下移除对应误差；四个complex替换的逐条误差降幅相加等于原误差。phase-only保留恢复谱幅度，magnitude-only保留恢复相位；零系数处的相位无定义，使用明确的中性处理。幅度理想修正在相位错误时甚至可能增加总MSE，因此不会强制所有幅度干预降误差。

全部干预都消耗逐条sourceclean，不能部署、不能进入target推理，也不是任意算法的恢复上界。F选择一致是机制代理，不是真实TX准确率；512条训练池结果也不代表整个源V或正式目标总体。没有自动训练资格、按场景选择或目标结果反馈。

## 文献适用范围
