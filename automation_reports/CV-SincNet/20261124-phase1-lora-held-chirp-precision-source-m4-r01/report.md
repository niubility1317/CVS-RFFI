# LoRa 实收前导交叉预测风险与复方向恢复

[预登记矩阵](experiment.json) · [实验状态](events.jsonl)

## 接收端做法

使用同一包的六条接收前导 chirp。去扫后，逐条保留实收复均值，把剩余复信号送入 64 点正弦窗、32 点步幅的短时变换。移除复均值可以减小载波经加窗泄漏到邻近频点的影响。粗层用其余五条 chirp 在同一短时频点的均值及离差回归先验和源域残差方差。恢复修正经重叠相加回到原坐标，每条修正的时域均值固定为零。旁路时原样返回接收 IQ。

先验风险另有一个实收估计。对其余五条支持 chirp 逐个留出，用其余四条的均值预测。被留出的那条和四条均值的复差，等于它相对五条均值的离差乘 \(5/4\)。因此用支持离差的复协方差乘 \((5/4)^2\) 即可得到全部交叉预测误差的协方差，无须运行额外的网络。减去被预测支持 chirp 的平均观测噪声，收缩小样本伪协方差并截断负特征值。该量保留四条预测均值的噪声和结构失配，作为可观测的预测风险。

方向组沿实收风险的两个正交实轴分别控制复数修正。高风险方向少依赖先验，低风险方向多依赖。标量组使用同一预测风险的迹，两个方向同权。把方向组的两个融合增益归一到同样的逐频点均值。两个臂共用加窗、预测方差、局部有效噪声和细化结构。固定方向组权重、把方向增益改为同均值标量，构成额外消融。匹配的是观测风险和融合增益的迹，实际复冲量还随各包的创新方向与后续细化改变。

| 接收量 | 来源与可用时间 | 误差与限制 |
| --- | --- | --- |
| 复均值、去扫和配准置信度 | 六条实收前导可用后，从各条 IQ 计算 | 仍受残余时偏、频偏及包内相位变化影响。 |
| 短时有效观测噪声 | 外带复模方中位数除以 ln 2，75% 本窗与 25% 同 chirp 时间平均 | 有色相关噪声、外带设备细节与接收失配都会影响代理。 |

| 学习的先验方差 | 输入留一支持统计，在合法源 U 上联合以实测波形残差似然拟合 | 其误差可以反映训练扰动到 practical 的变化。 |

## 训练及对照

两个臂均从零训练。每臂 5,797 参数、40,000 个 AdamW 更新、batch 24。源 U 拟合、旁路校准和固定留出分别为 20,000、2,500 和 500 个互斥包。两个臂同初始化、数据、扰动、损失和学习率，按同一优化循环联合粗恢复、观测融合和细化。使用实测源 IQ 的复谱误差、独立扰动一致性、真实源弱复谱差异传递及先验残差似然。通用扰动独立于 practical。拟合和冻结隔离识别器、TX、V、目标、真实信道与精确噪声。

Mehra 的自适应滤波用创新检验已有协方差。Picinbono 和 Chevalier 用复数及其共轭进行广义线性估计。这里以同包留出前导的预测残差构造两个复方向，对粗恢复与细化共用该约束，并在冻结的设备识别器中比较同迹消融。与相邻的 LoRa 交叉前导均衡不同，这里估计预测风险与复方向，未拟合多抽头信道逆。公开的 Noise2Self 用互补掩码构造自监督误差，本方案使用合法源 U 波形监督联合拟合。 [Mehra 原论文](https://doi.org/10.1109/TAC.1970.1099422) · [广义线性估计原论文](https://doi.org/10.1109/78.403373) · [Noise2Self 原论文](https://proceedings.mlr.press/v97/batson19a.html) · [作者实现](https://github.com/czbiohub-sf/noise2self)

## 冻结验证

在终步冻结后分别在 full 和 residual 评估相同 900 个源 V 包。使用 Tri-set seed 2026092702，覆盖 clean 及六种 practical。逐项保留直通、成熟半量 DURA、两个训练臂及同权标量消融各三个读出。两路全部预测固定后独立 CPU 关联源标签，按物理包、场景和 RX 核对各项计数。方向组须同一读出两路六景都超过匹配 DURA 且保持 clean 才晋级。
