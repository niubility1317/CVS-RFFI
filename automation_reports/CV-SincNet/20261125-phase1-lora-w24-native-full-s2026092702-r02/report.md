# LoRa W24 原配方和原生 Full 恢复对照

本次替代 [r01](../20261125-phase1-lora-w24-native-full-s2026092702-r01/report.md)。r01 的 N607 独立真实源 U 检查发现原版 `chirp_samples` 返回双精度数组，冻结模型入口只接收 float32。r01 在 WAIT_GPU、没有预测子进程时按精确 PID 停止，保留全部文件。r02 在恢复入口显式定标并转换成 float32。大批量恢复差分通过 CPU DLPack 读取，标签用小整数列表回传，以匹配该环境的 PyTorch 和 NumPy。物理数据、观测、预测矩阵、恢复权重和冻结 W24 原配方沿用 r01 登记。

使用独立发布与运行根 `20261125-phase1-lora-w24-native-full-s2026092702-r02`。读取当时 GPU 空余显存和进程数，优先顺序 3、0、5、7、2、6、1、4，至少 12,288 MiB 空余，每卡最多一个本运行预测 worker，允许卡上已有至多 7 个其他进程。CPU 信道生成并发 12。模块入口和 truth-last 矩阵沿用 r01，运行产物相对路径保持一致。
