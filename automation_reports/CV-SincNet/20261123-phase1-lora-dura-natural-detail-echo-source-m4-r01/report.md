# LoRa 通用多径扰动下的弱指纹保真消融

在上轮两臂匹配的加性噪声实验中，弱差异约束提高了源域全量恢复的识别率。下一轮只改变训练观测生成，将原 IQ 与加入真实源弱复谱差异的 IQ 施加相同的两抽头复回波和同一份加性扰动。另生成一份独立扰动用于恢复一致性。前级仍走相同单进程联合训练。训练只接收合法源 U clean IQ 及通用扰动后的 IQ，不使用真实或 benchmark 信道参数、强化接收轨迹、TX 真值、F、V 或目标数据作拟合、校准或冻结输入。

两臂各固定 1,800 步，保真权重分别取 0 和 0.35。相同模型、初始化、源 IQ 划分、批次、噪声生成和推理门槛。训练时的通用回波幅度上限为 0.25，每包两条相对位移为 1 和 −2 的复回波。回波系数仅在构造通用扰动时使用，网络读到的是实际各合成观测和原源 IQ 目标。推理只输入当前包的 IQ。同一冻结权重、同一源 U clean 门槛用于两路 practical。固定输出剂量 1 和 0.5。

## 验证与晋级

两路均复用上轮 900 个源 V 物理包、同一冻结 Tri-set 2026092702 和七景输入，保留原波形对照、原保真、成熟 DURA、直通，以及本轮多径训练的匹配两臂。已有四个 additive 读出复用固定预测，不重跑训练。对源 V 完整预测先落盘，再连接标签。比较逐景正确数、低城区、逐 RX 净纠错和分 RX 同包重抽区间。源域至少需在两路线的六景均值同时超过成熟 DURA、clean 保持且配对改善稳定，才进入正式目标测试。交互结果区分保真约束和混合多径训练是否互相增益。

N607 普通账户和共享既有 LoRa 环境。独立、不可覆盖发布及输出根。优先可用 GPU、同时最多两条独立源 fit，随后两路冻结评分，单卡资源按实时显存及现有计算进程申请。首步真实源 smoke，契约、非有限值、校准、冻结、预测闭合等任一技术异常停止后续派发。使用仓库登记中的精确入口和输出路径。

## 源域结果 VERIFIED

两组各完成 1,800 步，训练 worker 分别用时 421.89 秒和 561.65 秒，均启用 BF16 卷积。共用的源 clean 门槛为 0.04594118，clean 触发数为 0。源 U 留出中的弱差异损失从 0.12737 降至 0.03643。两路均完成相同 900 个物理包的七景冻结预测及源 V 评分。与上一轮的直通和成熟 DURA 决策逐包完全一致。
