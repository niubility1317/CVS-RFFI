# LoRa 原生 8,192 点同信道独立加噪的两阶段恢复（Full）

此前在相同中心窗修正幅度下，更换为正确的降噪方向曾让源域六景净增 132 次、低城区净增 33 包。本轮检验，让第一阶段面对保留同一信道作用的独立有噪参照，能否改善可部署降噪，再由第二阶段恢复冻结 E104 需要的身份信息。 [源域方向与幅度诊断](../20261127-diagnostic-lora-raw8192-edit-direction-s2026112559-r01/report.md)

两组原生第一阶段从同一已冻结 18,000 步父版开始。第二阶段用去扫的时域和复频域残差细化，初始回写为零。每组共 325,480 个可训练恢复参数、新增 20,000 步，每步 L_s 和 U_s 各 8 包。两组的接收输入、见证噪声和训练流程匹配，唯一差异是第一阶段独立加噪参照是否保留输入模拟使用的通用信道作用。

第一阶段用 W24 中心线性误差、原生配对误差及合法源 clean 恒等约束。第二阶段固定原 E104，使用 L_s 真标签和置信阈值 0.95 的 U_s 同包 clean 伪标签，以及原有波形、频谱与 clean 保真损失。第二阶段梯度不更新第一阶段。训练不读取目标、源 V、U_s 真实标签、正式 practical 视图或精确信道和噪声轨迹。

两组共享固定的源冻结及七景独立评分。初始发布的条件式正式测试接续记录在原登记，实际正式范围按下文的最新要求执行。执行代码 `fc8c14c22b5de5c3198dcca00a3e45d3827a4555`，完整矩阵和输出见 [预登记](experiment.json)。
