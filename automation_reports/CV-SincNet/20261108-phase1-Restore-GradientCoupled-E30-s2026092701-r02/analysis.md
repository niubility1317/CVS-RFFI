# 梯度耦合恢复器：30 轮正式测试分析

## 结论与口径

该候选未达到目标：以相同冻结 Tri-SIG-TIME SSL 识别器的 raw clean 为参照，六个星地场景逐个要求差距不超过 3 个百分点，本次为 0/6。六景均低于固定 DURA v1，且均低于匹配的 CovarianceDetail 对照。不同候选的训练和物理梯度路径不同；这些结果只证明本次单种子、既定数据划分和模拟信道下的表现。

本次从零单阶段训练 30 轮（7410 更新），E15 因资源限制中断，恢复模型、优化器与随机状态后跨 GPU 续训；未完成的部分轮次重算。恢复器用合法 L_s/U_s 模拟配对和同一冻结 F0 的连续源特征，不读 TX 标签、目标数据或源 V/OE 来训练，因此是 F 指导方法，不是 F-free。F0 为 Tri-SIG-TIME SSL 的 Main split seed 2026092701，原默认头未替换。

训练以 final30 冻结；cross_rx 126000 条和 cross_both 42000 条在 clean 与六场景的全部预测固定后，独立 truth-last 评分。每个合并视图均为 168000 条，同一物理样本按场景配对。正式测试已多次用于项目研究，该结果不应称为新的独立盲测或真实卫星链路证明。默认 DURA 未变。

## 对方法的判断

候选只把 IQ／F0 损失经后验传给物理分支的梯度缩放为 0.05；物理监督梯度在分支裁剪前保留，最终更新仍受独立裁剪与 AdamW 影响。匹配 CovarianceDetail 保持其他基础配方并截断该梯度。候选六景均更差，与源训练中 action、IQ 和 F0 特征误差的方向一致；这支持本次耦合设置可能干扰了物理估计的解释，但训练轨迹和多项机制交互不能证明单一因果。跨 GPU 续训和单 seed 也限制归因。

F0 特征指导本身不能等同于本次物理梯度耦合：两版都使用连续 F0 源特征。正在独立训练的特征响应候选包含额外扰动响应约束，仍须完成其预登记的 30 轮及正式测试；本结果不改变其配方或选择其 checkpoint。

训练期完整对照、分段耗时及统计口径见同目录 source_progress_E30.md。训练效率的比较须在相同硬件与共享负载下实测；本次不以不同设备的单轮耗时比值宣称加速。
