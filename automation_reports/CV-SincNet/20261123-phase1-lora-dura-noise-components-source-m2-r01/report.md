# LoRa DURA 复增益与正交残差置换

## 固定源矩阵

继承信号保留先导各路线的普通噪声监督和信号保留两组冻结权重。两者原始前向、包功率归一化逐值复用。用同包模拟轨迹得到无噪接收信号，在同一观测对齐坐标中，将各个复谱误差分成沿该信号的复数投影和与它复正交的残差。频带为去载波后双侧 1–8 kHz 与 9–32 kHz。普通监督为共同参照，在每条 chirp 的每个频带，分别替换为保留组的复增益、正交残差，或两者一并替换。固定普通组归一化尺度、带外和载波。保留组原始全带读出独立报告。

另从普通组分别逆向修正已知复增益偏差、已知正交残差，取两个分量 RMS 较小者且最多 0.06，作为相同上限。第三组在两个正交修正方向平分功率，与前两组总 RMS 相同。交付波形按共同尺度复算，等幅误差不得超过 1e-6。另并列一个无需模拟器信号的候选，沿普通输出在两个频带中的方向投影两模型之差，并按原方向范数 15% 限幅。该候选前向只依赖真实接收和两个冻结模型。以上读出各自使用 full 或 residual 合法来源的原门控和成熟半量。

两路共用相同的 900 个源 V 物理包，每台源 RX 180 包，与上一轮保留面板互斥。固定同一 Tri-set 2026092702。完整七景与 12 个读出写出后才连接源 V 标签，逐 RX 核对配对纠错和改错。除直通、成熟半量和两个冻结学习组，另外报告三项置换、三项等幅反事实、无真值增益候选及精确扣噪。反事实分量使用已知源波形，仅作归因。无 G 更新和目标读取，正式目标沿用 67.0%。

## 发布

`20261123-phase1-lora-dura-noise-components-source-m2-r01`。使用 `python -m experiments.pamf_lora_main.denoise_components_source publish`，N607 普通账户、登记 LoRa 环境、不可覆盖 release 与 run，CWD 为发布根。GPU 3、6 优先，其次 2、0、4、1、5，最多两路并行分卡，每卡总计算进程最多 4。先在每路 15 个真实源包的 clean 和低城区验证门控、等幅和有限性，无 F 和标签读取。坏契约、非有限、等幅或闭合错误停止后续派发。预期真实 smoke、两套路由的七景冻结预测及独立源评分。

### 分量置换

只把信号保留组的正交残差移植到普通噪声监督输出时，六景净少答对 69 条（full）、215 条（residual），95% 包配对区间为 −114 至 −22、−318 至 −113。仅移植其复增益时，两路六景分别净变 −19、+91，区间均跨零。仅复增益置换在 full 低城区多答对 20 条，95% 区间 +1 至 +39。两分量同时置换与分别置换的差额为 −29/−117 条，残差路线的配对区间 −206 至 −36。增益改善在较差的正交残差背景下没有保持相同收益。该因子对照固定两个频带外的波形，只解释这两个频带内的学习误差。

### 等幅修正

修正基准为普通噪声监督输出。Full 单纠增益、单纠正交和等幅联合作用的六景净增量依次为 +73、+95、+222。Residual 对应为 +180、+5、+412。联合修正的 95% 配对区间分别是 +175 至 +268、+341 至 +482。联合在两路低城区分别净增 68 和 106 条。相同交付剂量下，residual 的单纠增益比单纠正交多判对 175 条，95% 配对区间 +32 至 +313。Full 的两项单独修正差值仍不足以下结论。

相对成熟半量，联合反事实 full 六景仍差 167 条。Residual 多判对 82 条，区间 −5 至 +176，低城区增加 38 条，区间约 +5 至 +70。各源接收机的六景联合修正相对普通监督均改善。仅靠可观测模型输出估计增益的读出，full/residual 比成熟半量少判对 459/305 条。精确扣噪的高分仍来自已知源轨迹，当前实际模型权重未进入目标预测。

下一轮可用完整复谱改正向量作为源教师，保留按分量约束的训练和同剂量端到端对照。目标是让两类误差在同一次更新中被校正。增大单独增益惩罚和继续用普通模型输出方向作信号方向，都缺少支持。三种子正式六景 67.0% 保持未达。
