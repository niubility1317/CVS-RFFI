# 独立 FIR 学生：七景预测类别完整一致性

七景共 1176000 条物理记录视图、2352000 个 raw／恢复类别决策全部一致。原预测未保存全部波形和 logits，因此七景全量结论只覆盖这两类已保存决策；不能声称全量波形或 logits 逐值一致。此前 112 条合法源 IQ 的检查中，恢复波形、raw logits 和恢复 logits 逐值相同，检查范围仅限该源样本。[源域检查](../20261107-phase1-direct-fir-skip-source-s2026092701-r01/analysis.md)

此次全量重放累计 6058.6 秒，包含读取、预测和逐批类别比对，不包含模型加载；原正式预测日志在最后一景完成 163840 条时已累计 18097.8 秒，之后还有 4160 条及收尾。两次运行的共享机器负载、输出写入和核对工作不同，不能据此给出严格的全量加速倍数。先前相同机器上 112 条源样本的单次交替计时为原路径 1.7113 秒、快速路径 0.5427 秒，约 3.15 倍；该小样本串行计时不证明其他模型或并行场景的加速比例。

这是对特定冻结独立 FIR 学生的技术优化验证，并非恢复质量提升。该学生在正式低城区的准确率为 41.0673%，低于 DURA 的 68.8012%，六个受损场景均未达到目标。[正式识别结果](../20261107-phase1-direct-student-fir-ground-test-s2026092701-r01/analysis.md) 其他架构或执行环境需要各自验证，现有预测未中断或迁移。
