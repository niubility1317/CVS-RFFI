# LoRa 公共与差分复谱的联合协方差

## 预登记

固定信道的重复观测诊断中，Residual 路线只有同时应用公共和私有修正才有净收益。本轮使用当前实收六条 chirp，检验两组复谱之间的相关性是否改善同包估计。公共分量取六条的正交常数模式，私有分量取与它正交的五个差分模式。将 ±1 至 ±32 kHz 按四对相邻频点分块，每块含六模式、八频点的 I/Q 共 96 维。用 5,000 个合法源 U clean 物理包按相同独立固定规则估计均值和完整实协方差，每接收机 1,000 个。协方差固定保留 75% 经验协方差并加入 25% 对角矩。拟合隔离 TX、F、V、practical 及目标，不需要理想信道、实噪声方差、真值或额外观测。 [重复观测诊断](../20261124-phase1-lora-noise-replicas-source-m2-r01/report.md) · [秩四公共谱对照](../20261124-phase1-lora-shared-spectrum-covariance-source-m4-r01/report.md)

推理沿用原秩四相位跟踪、逐 chirp RMS 与源 U 冻结旁路。观测噪声方差由实收归一化去扫谱外带的中位功率估计，假设每条 chirp 的近带噪声为等方差圆对称，原 chirp 间在估计模型中独立。应用正交变换传播此方差，保留不同 chirp 方差在公共与差分之间形成的非对角协方差。两臂采用同一均值、对角及块内协方差、实收噪声估计和半量更新。对照只清除信号先验的公共到私有和私有到公共协方差。以加性观测模型的条件噪声期望形成恢复。将两臂各自半量修正与原秩四半量修正按 1 比 3 混合，再在 1 至 8 kHz 和 9 至 32 kHz 两个频带各自归一到原秩四的物理 IQ 改动能量。载波和其余秩四频点保持原值。直接后验半量及等剂量组合都固定先验和推理规则跨两路共用。

相关背景包括广义线性复值均方估计和以邻域多维高斯统计进行的 BLS-GSM 降噪。前者给出允许 I/Q 相关的估计思路，后者用图像邻域和隐变量尺度观测噪声。本实现使用实测源 LoRa 前导构造常数与差分模式先验，条件估计使用所收前导估计的不等噪声方差。BLS-GSM 作者 Matlab 实现在实验室软件页列出。本轮 LoRa 信道稳健性与采用信道不变谱图并训练分类器的工作放在同一任务背景下，当前分类器保持固定，实际收益用原始与输出 IQ 的分类配对来判断。 [Picinbono 与 Chevalier](https://cedric.cnam.fr/~chevalip/) · [Portilla 等原文](https://www.cns.nyu.edu/pub/lcv/portilla03-reprint.pdf) · [作者软件](https://www.cns.nyu.edu/~lcv/software.php) · [LoRa 信道稳健识别](https://arxiv.org/abs/2107.02867)

## 判定

秩四等剂量联合相对等剂量分块，两路六景净差为 0 条［−3，+3］和 +2 条［−2，+6］。低城区净差为 +1 条和 +3 条。与秩四半量比较，两路六景分别多 4 条和少 2 条，区间均跨零。相对半量 DURA，Full 六景少 13 条且低城区少 1 条，Residual 六景多 20 条且低城区多 11 条。直接使用联合后验半量的六景在两路也低于半量 DURA。

联合版和分块版在留出低城区 1 至 32 kHz 的公共及差分相对误差变化均低于 0.04%。源 clean 拟合得到的交叉协方差可测，当前加性观测模型及实收噪声估计下，这些交叉项只造成很小的复谱变化。结论限于本次固定模型、剂量及源面板。全部新增恢复读出在 12,000 个源 V clean 包上与直通预测逐条一致，正确数为 8,986。正式目标预测仍待源筛查通过的候选。
