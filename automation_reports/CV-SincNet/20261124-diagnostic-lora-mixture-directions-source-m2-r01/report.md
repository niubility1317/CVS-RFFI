# LoRa 混合路由和复修正方向的同量隔离诊断

[预登记矩阵](experiment.json) · [运行事件](events.jsonl) · [冻结混合先验](../20261124-phase1-lora-spectral-mixture-source-m2-r01/report.md)

上一轮奇偶混合先验在通用受扰留出源 U 上过度集中于同一低权重分量，实收条件回写也没有带来两路线识别增益。本轮固定该先验和接收端提议，检验误差主要来自路由载体、受限的专家方向，还是固定的写回幅度。

## 隔离对照

所有实收控制沿用上一轮的六窗 IQ、门限、前导跟踪、校准状态和接收机估计噪声。奇偶分量概率乘以相同的八个条件跨频提议。实际传播和分量条件矩保持冻结。直通、半量 DURA、统一先验半量、实收对折半量和原一致性半量共五个原读出。两路各七景逐包比对这五个原预测。

| 读出 | 使用的参考和可回答的问题 |
| --- | --- |
| 同量实收路由 | 仅实收 IQ 估计奇偶路由，采用同包统一先验半量的实际物理 IQ RMS。作为所有隔离路由的剂量对照。 |
| 同量扣噪路由 | 用隔离精确扣噪波形估计奇偶概率。实际回写的八个提议仍完全由原实收 IQ 生成。 |
| 同量配对 clean 路由 | 仅路由改用同包原始地面接收的 clean 前导。观察额外消除传播失配后，已有专家是否更有用。 |
| 同量波形选专家 | 把八个实收提议逐一缩放到共同 RMS，以与隔离已知非载波修正的复数内积选择一个。选取过程仅比较波形。 |
| 同量精确方向 | 用同一物理 RMS 沿已知非载波增量回写，比较固定幅度下的方向差距。 |
| 全量精确非载波 | 在相同实收跟踪坐标扣除已知非载波噪声，无幅度上限。clean 新增噪声为零。 |

同量对照的预算是同包、同实收原坐标下的统一先验半量编辑 RMS。该预算仅在原候选激活包应用，其他包旁路；每个隔离读出还核对实际写回剂量。全量精确对照覆盖全部有非载波新增噪声的包，同时区别剂量和激活范围。扣噪、配对 clean、真值方向和选专家只进入隔离读出，零训练、校准、权重更新或候选选模。

两路线各固定 900 个同序源 V 物理包、同一 Tri-set 识别器种子 2026092702、七景和 11 种读出。两路预测全部固定后再由独立 CPU 读取源标签。正式目标完全隔离。先验及实收路由只比较模型产生的混合分量，用于量化可观测性；分量对齐没有 TX 身份语义。

## 路由可观测性与方向覆盖

低城区沿用实收门，Full 736 包和 Residual 900 包激活。实收全包路由与配对 clean 的主分量一致数为 407/736 和 464/900，换用隔离扣噪路由后为 338/736 和 466/900。Full 同包精确扣噪后仍有传播作用，主分量一致数下降，说明主分量编号与受损识别收益之间还受其它波形变化影响。

| 低城区逐 RX 中位数范围 | Full | Residual |
| --- | ---: | ---: |
| 原物理 IQ 同量编辑 RMS 比 | 12.60%–15.00% | 15.00% |
| 实收和配对 clean 的折均概率总变差 | 0.491–0.641 | 0.547–0.726 |
| 扣噪和配对 clean 的折均概率总变差 | 0.620–0.957 | 0.584–0.660 |
| 同量实收路由对精确方向的投影 | 0.385–0.424 | 0.291–0.313 |
| 同量波形选专家对精确方向的投影 | 0.385–0.424 | 0.292–0.313 |

投影是归一化物理复内积，分母为精确非载波修正的平方范数。它同时反映与精确方向的对齐程度及当前有限回写量。因各组逐包剂量相等，组间差异描述方向变化。选专家相对实收路由的投影变化很小。对这八个专家，配对 clean 提供的路由信息带来有限识别收益，Residual 六景仍比 DURA 少 53 次。相同物理剂量下的精确方向在两条路线取得更大的正向净纠错。结果支持把新机制的重点放到实收条件下可恢复的复修正方向，并用路由固定的等量消融检验。此结论限于已测试的八个专家和固定输入，未使用冻结识别器输出选择方向。
