## 接收观测与冻结矩阵

当前包六条复 IQ 按各 chirp RMS 归一化，加 Hann 窗后在两侧 70 至 91 kHz 和 92 至 119 kHz 取频带内功率中位数和中位数／平均。按每包六 chirp 排序，取第 3、5 项，共 8 个标量。输入完全来自采样率 256 kHz 的实收波形及固定频带，无空闲段额外观测。源 U clean 的中位与四分位距标准化，非负权逻辑回归拟合 clean／通用注入的可分性。仅固定 2,500 个真实源 U clean 最大分数加 0.01 为门限。估计量是相对保护带功率及谱平坦度的组合，不作逐包真实噪声方差解释。

复用已端到端训练一次、严格匹配本次源 IQ 合同的秩四组权重。两条路线共享同一保护带拟合、门限和恢复倍率规则。原门触发部分保持原半量；保护带新增触发部分对比四分之一、半量、以及按原扰动指标与原门阈值比的平方渐增到半量。两门均旁路时保持输入逐点一致。重采样、原去扫坐标和载波复原沿用冻结秩四组。除 8 权重与偏置外本轮不重训恢复网络。源拟合、源校准和获取恢复权重时隔离 TX、V、F、目标、实际场景和仿真轨迹。

## 输入带宽反事实

在相同 225 个留出源 U 包上，使用只读的已知新增噪声，将其 0 至 60 kHz 复谱保持原样，60 至 68 kHz 滚降至零。两路均保留原传播作用、原输入时间坐标和原幅度基准。滤波后保留约 49% 至 51% 的全带新增噪声能量。固定保护带探针在每路线三个代表场景均由 225/225 检出降为 0/225。去掉全部真实新增噪声时，各项为 0/225 或 1/225。旧去扫门在占用频带内仍能触发一部分样本。这项隔离诊断说明新增检测主要依赖带外噪声。下游识别只评登记的原始实收视图。 [带宽反事实及误差核对](source-u-guard-bandlimit.json)

## 带内触发探针

把实收 chirp 分成不重叠的 32 或 64 点时间窗，以 Hann 加权的已知去扫模板在局部估计和移除主载波。随后只在原始接收频率的 |f| ≤ 60 kHz 且离当前 chirp 脊线至少 32 kHz 的单元度量残差。分别使用每条 chirp 的局部残差信号和减去包内共享量后的信号。八个功率特征与八个谱平坦度特征采用相同 clean 标准化及非负回归，对照只用任一子集。只以通用带限噪声拟合，实际源回放和带宽反事实留在冻结后。

在保留原 0 至 60 kHz 噪声的回放上，双类特征的带内门在 full 高郊区检出 223/225，其余代表场景均为 225/225。Full 低郊区可额外触发 194/225，而旧去扫门为 31/225。通用带限注入 0.015 时，检出 499/500，留出 clean 有 2/500 次触发。留 RTL-1 接收机时，含绝对功率分数的三个探针均触发 100/100 个 RTL-1 clean。纯平坦度保住 clean，但各轮没有检出同级通用带限噪声。带内检测解决了保护带缺失时的检出问题，接收机背景噪声与新增噪声重叠仍然存在。下一步评估恢复改动对当前波形的支持与风险，避免把绝对噪声水平直接当作恢复收益。 [带内探针及各留接收机结果](source-u-inband-guard-probe.json)
