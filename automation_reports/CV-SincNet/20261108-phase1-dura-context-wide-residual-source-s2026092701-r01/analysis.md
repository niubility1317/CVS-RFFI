# DURA 大范围修正的源域依据

## 修正范围的源域可达性

该大容量修正分支的逐时刻复数修正幅度限制为 DURA 输出分量 RMS 的 0.25 倍，再乘原噪声门控。对 672 条既有源 pilot，固定真实 DURA，利用同条源 clean 计算到该逐时刻可达圆盘的最小波形误差；这是特权源域几何下界，不是部署算法，也不是身份准确率。

| 源低城区分组 | DURA NMSE | 0.25 倍上限理想下界 | 0.5 倍上限 | 1.0 倍上限 |
|---|---:|---:|---:|---:|
| RX4/6 | 0.037404 | 0.013038 | 0.005323 | 0.001374 |
| RX8 | 0.100678 | 0.048131 | 0.022498 | 0.004417 |

这两个分组均每组 48 条，受损样本上的原噪声门控均为 1。较大的修正范围降低了源样本的理想波形误差下界，但并不能保证网络能够学到最优方向，或者提高目标识别率。clean 中门控为 0 的样本不会因放宽范围而改变。该分析不使用 F、TX 标签、V 或目标，不修改已有模型和七景测试。

## 固定第 20 轮的源 pilot 对照

两版均使用同一固定 DURA、32768 条源拟合 ID、三视图及 20 轮预算；源 pilot 每组每景 48 条，与修正器拟合 ID 不相交，但此前已用于探索。两版独立训练且输出尺度导致初始梯度不同。数值为波形 NMSE，不是身份识别准确率。

| 源组 / 场景 | DURA | 原 0.25 倍范围 | 新 1.0 倍范围 |
|---|---:|---:|---:|
| RX4_6/clean | 0.000046 | 0.000046 | 0.000046 |
| RX4_6/practical_high | 0.005421 | 0.006502 | 0.006181 |
| RX4_6/practical_mid | 0.008028 | 0.009099 | 0.010913 |
| RX4_6/practical_low_suburban | 0.008719 | 0.009696 | 0.009870 |
| RX4_6/practical_high_urban | 0.009094 | 0.010549 | 0.011014 |
| RX4_6/practical_mid_urban | 0.023243 | 0.023914 | 0.023793 |
| RX4_6/practical_low_urban | 0.037405 | 0.038416 | 0.045774 |
| RX8/clean | 0.000033 | 0.000033 | 0.000033 |
| RX8/practical_high | 0.015451 | 0.013186 | 0.013384 |
| RX8/practical_mid | 0.015404 | 0.012373 | 0.012654 |
| RX8/practical_low_suburban | 0.024758 | 0.022069 | 0.020460 |
| RX8/practical_high_urban | 0.015304 | 0.013250 | 0.012929 |
| RX8/practical_mid_urban | 0.051656 | 0.044362 | 0.044589 |
| RX8/practical_low_urban | 0.100678 | 0.089147 | 0.095288 |

受损六景等权平均：RX4/6 的原版／新版为 0.016363／0.017924，RX8 为 0.032398／0.033217；对应 DURA 为 0.015318／0.037208。新版在 RX4/6 全部六组高于 DURA，在 RX8 全部六组低于 DURA；相对于原 0.25 版，12 组中 8 组均值更高、4 组更低。此源域单 seed 描述不作为目标成绩，也不取消预登记七景预测。

## 冻结后的七景结果

七景独立评分完成，大范围版在六个受损场景均低于 DURA 和独立训练的原范围稳定版；完整结果见[七景分析](../20261108-phase1-dura-context-wide-residual-ground-test-s2026092701-r01/analysis.md)。这与源 pilot 的理想可达性空间并不矛盾：理想界使用了部署时不可得的 clean IQ，也不保证训练模型的身份保持。
