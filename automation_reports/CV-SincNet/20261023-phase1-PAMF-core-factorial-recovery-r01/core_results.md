# PAMF 三核心机制：24 个逻辑模型完整结果

状态：ANALYZED。8 个组合 × 3 个 F seed，raw、DURA-L、DURA-LU 三种读出及七景独立评分全部闭合。原有输入绑定错误的旧 F 产物未进入本分析；两条源物理诊断技术失败通过已登记的新 run 替代，旧失败保留。

A 为跨物理 RX 的同 TX 身份对比（CRIC）；B 为 ordinary128、ordinary64、raw128 成对随机预测的对称 KL 一起启停；C 为原生 own EMA、选择门控、伪标签及无标签熵一起启停。分组先于本批目标读出固定，没有按收益重新分组。

**主要判断：B 在完整组合中的 clean 收益方向一致；A 和 C 在完整组合中没有显示稳定正收益。** 本批结果不支持将三个机制都写成普遍增益，也不用于替换已经固定的最终 T1、调参或选择性重跑。

## 物理感知证据与限制

11 个固定物理干预覆盖 identity、两档平坦增益、恒相位、四档相对 CFO、FIR 回波及两档模拟 PA。逐干预的特征余弦距离、默认头预测翻转率和参考描述符相对 L2 见 core_source_interventions.csv，全部结果保留。模拟 PA 变化不假设发射机身份标签保持，不能把预测稳定性或特征距离直接解释为真实硬件解耦。独立训练的结构消融和严格监督 SIG_TIME_X3 等架构面板仍待完成。

## 成本与数值复核

12 个新 F 完成 600 模型轮、133200 次更新，增量训练为 20.453379 个共享 worker 小时。24 个逻辑 F 的完整来源合计 40.622977 个共享 worker 小时，含复用的原 T1 及修复 F 来源，不是本次额外开销；不同历史并发负载下的耗时不能当作独占 GPU 小时或因果提速比例。没有新 G 训练、另训头或新增 A/B/C 部署计时。共享 G 祖先、预测和其他面板成本单列，不以“复用”冒称零训练成本。

36 份独立完成的评分输入覆盖 24 个逻辑格。已本地独立重算 24192 份序列化混淆矩阵、raw 复用一致性及全部净纠错；五份完整 CSV 的 512085 个数值单元复核通过。Python 版本间最大浮点差为 9.95×10^-14，小于预定 10^-10 绝对比较容差；不是把所有文件误称为逐字节相同。分析只读取冻结评分、训练成本和源诊断，没有读取目标真值或 IQ。
