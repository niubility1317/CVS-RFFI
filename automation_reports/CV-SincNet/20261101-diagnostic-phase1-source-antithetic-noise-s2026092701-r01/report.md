# Phase1 source antithetic noise DURA

Status: source-only experiment. This tests four independent pairs of equal-and-opposite Gaussian perturbations to received IQ. Each component's perturbation standard deviation is 0.2 times the input component RMS. Eight frozen DURA outputs are averaged in the common output frame, and mixed with the original DURA output using strengths 0.25, 0.5, or 1. A pre-existing blind noise proxy and input/output difference gate control modifications. No clean IQ, simulator SNR or source labels are used during inference.

The protocol and code hash were fixed before execution. On 530 source validation records from receivers 4 and 6, the full average was selected with aggregate +5 correct across three impaired views, including +2 low urban. On 260 valid source receiver-8 holdout targets, low urban fell 236 to 235 (L_s 55/62 unchanged), mid urban fell 233 to 231 (L_s 54/62 unchanged), and low suburban stayed 257. All 260 clean targets stayed correct. Across all 265 heldout IQ records, low urban aligned mean MSE rose 0.105559 to 0.105745; the other two impaired views also rose. The full run was repeated and the result JSON matched exactly; the four-record smoke checked antithetic cancellation and real model inference.

Legacy field names in the generated JSON (status SOURCE_ONLY_EQUIVARIANT_DURA, phase_count and median_orbit_variation) are inherited from the original experiment harness; they denote this perturbation experiment and do not mean phase rotations were used. The actual perturbation, seeds, gating and selection are specified in the code and fixed manifest.

Labels mix actual L_s and high-confidence U_s clean-teacher pseudo-labels. Receiver/day holdout applies to this diagnostic, but fixed models saw source records and IDs may overlap other source probes. No U_s true labels, validation IQ or test IQ were read. The simulator has not been validated as a real satellite link. Do not interpret this as Phase1 target performance.
