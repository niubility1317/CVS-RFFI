## 下一步方法：待验证的研究假设

1. **识别特征约束与波形保真共同优化。** 允许独立 F 指导对照：冻结原 Tri-SIG-TIME SSL，在合法 L_s/U_s 源端模拟配对上比较 clean 和恢复信号的中间特征，并保留波形、频谱及身份信息保护约束。不得使用真实 TX、类别交叉熵或目标输出训练 G；该对照应明确标注非 F-free。FeatureResponse 正按固定源配方等待运行。特征差异长尾可能使少量样本主导梯度，需在合法源端记录分位数、梯度和分场景表现；不能凭诊断直接声称改善。
2. **针对复杂信道设计更大容量的多尺度复数时频网络。** 可组合宽带/窄带分支、长程时序上下文、多尺度频域交互，以及自适应残差输出，让网络学习信道补偿与残差信息保护；不受 DURA 结构或参数量限制。大模型只是假设，实际以六景及 clean 配对为准。
3. **保护不确定信息而非统一强去噪。** 在源端学习残差幅度与多尺度可信度，设置连续、可训练的保真约束；同时检查深衰落、多径或频偏下的特征偏移，减少对已经可识别信息的破坏。训练或推理门控不得读取目标真值，也不能利用 target 测试分数选路。BoundedProjected、ResponseReliability 正在验证不同形式，并非已验证有效。
4. **专门覆盖强城市信道的训练难例。** 在不扩大 L_s/U_s 权限的前提下，用真实协议范围内多径、衰落、频偏及噪声组合生成配对，并以场景均衡或合法源端难例加权降低弱场景遗忘。分开统计 clean、轻/重信道，避免只改善平均值。模拟误差与目标不匹配风险需要用冻结后的正式测试评估。
5. **用成对指标定位损伤。** 每版保持同 F、同样本、七视图；统计净纠错、001、clean 对变错、受损输入对变错以及 TX/RX/day，观察从哪个强度开始恶化。实验配方和候选选择只使用合法源数据，测试结果仅作为已冻结版本的报告。

## 可恢复极限与训练效率

已完成的源 V 小样本已知模拟信道加高斯 oracle 是 107/118 = 90.68% 的 clean 正确数保持率；它不是 Bayes 上界，不代表目标或真实卫星链路。观测信息在严重衰落与噪声中可能丢失，不能凭现有结果量化 IQ 物理恢复上限；需要在明确的信道和先验下评估已知信道 oracle、受限识别 oracle，或信息论/统计界，并严格区分源诊断与目标结果。

性能优先，当前新恢复器从零单阶段训练 30 epoch，并保留自动冻结、全视图预测和独立评分。效率通过缓存合规源配对、减少重复 F 前向、批量化与实测吞吐改善；改变 F 前向或损失近似必须另版验证性能，不因省时牺牲验收。
