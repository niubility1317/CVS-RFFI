# 固定源 V480 的理想信道参照与可恢复性边界

## 数据和用途

本分析只复算已完成的源域聚合结果，不新增模型前向、训练、数据或真值访问。原诊断使用同一冻结 Tri-SIG-TIME SSL 默认头，源 V 固定五个源接收机、三个日期各前 32 条，共 480 条；各七景是同一批物理记录。模型预测固定后，原诊断才由独立评分侧连接源 V TX 真值。具体预测、协议和核验以[噪声与收缩诊断](../20261107-diagnostic-Restore-posterior-bias-noise-sourceV-s2026092701-r01/analysis.md)和[接收机先验诊断](../20261107-diagnostic-Restore-receiver-prior-sourceV-s2026092701-r02/analysis.md)为准。

以下低档城区每格分母为 480；源 clean 正确数为 474、准确率 98.7500%。该固定源样本并非目标 Main，且按源 RX/day 取前 32 条，并不是独立同分布随机样本；不能把其准确率、差距或相对比例外推为目标性能或置信界。若仅在此样本上机械使用距同批 clean 不超过 3 个百分点，则至少需 460 条正确，具体工程验收仍使用目标 Main 的 168000 条及其独立阈值。

最后两路均使用部署时不可获得的同记录 clean、真实信道或噪声，只是固定高斯增益下的反事实分解。它们不能部署、不能作为所有恢复算法的上界，也不能说明能达到 3 pp。已知信道两行同样带有额外模拟真值；同 RX 一行还使用已知源接收机身份，不能推广到未知目标接收机。相对 clean 的正确数比值，例如 434/474 = 91.56%，是两组正确数之比，并非相同样本保留率：同 RX 已知行恰好保住 434/474 条原 clean 正确样本；全源已知行则为 425/474，另外有 1 条 clean 错而该行正确。

## 有效信号与限制

在同一批低档城区源样本上，全源已知信道的两项反事实分别比原高斯多对 26 条和 32 条；配对修复／损伤分别为 32／6、33／1。两种反事实对原本丢失的 clean 正确样本有 21 条共同修复，因此不能把它们的收益相加。最差实测信噪比四分位中，原高斯保住 88/119 条 clean 正确样本，去掉噪声影响和去掉收缩失真分别保住 102/119、106/119。已知模拟信道仍有明显误差，说明在这组固定先验和估计器下，信道估计以外的收缩、噪声放大与先验匹配也值得检验；这不是对正式 Main 差距的因果分解。

同样 12600 条源训练 IQ 和 L/U 配额下，低城区同源 RX 已知先验正确 434 条，其他源 RX 已知先验正确 379 条；该干预同时改变接收机统计组成，不能将收益直接迁移到未见接收机。原交叉分析指出协方差替换的影响大于单独均值替换，但仍仅限固定先验、源 V480 与原 F0。

已有结论与新任务边界保持一致：恢复网络只能学习原 L_s/U_s 模拟配对，可使用已授权的冻结 F0 连续特征约束；源 V 仅验证，G 不直接读取 TX、OE、目标 U/Q 或 clean 真值。正式验收必须在冻结后完成 Main 两总体全部七景预测，再独立 truth-last 评分。当前源诊断不能选取正式测试中的最佳结果，不能代替正式测试，也不能证明 IQ 或真实发射机物理特性的恢复极限。
