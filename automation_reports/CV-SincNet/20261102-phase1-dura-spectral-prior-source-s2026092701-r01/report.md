# DURA 频域后验修正：Phase1 源训练与地面验证

## 候选与数据权限
保留冻结 DURA 双阶段估计、原 prior 和数据一致性求解；在每阶段 prior 后插入新模块。模块对 received、当前状态、原 prior 与盲物理后验均值做复 FFT，以振幅、相对复相关和盲估噪声作为相位不变条件，预测每个频率的复数残差混合，逆 FFT 后形成跨时域修正。零初始化时与原 DURA 精确一致，推理只使用当前受损 IQ；不是从现有离散输出中逐条选一个。保护门关闭时沿用原 DURA。

仅使用 Phase1 合法 L_s/U_s 配对源 IQ 与冻结 Tri-SIG-TIME SSL 特征／源干净预测，不读取训练 TX 真值、U_s 身份真值、V 或目标测试。物理先验采用冻结基座对源 clean 的伪类别，属于 F-guided 依赖；不加载直接使用 TX 身份训练的非局部上游。保持原 DURA 与基座冻结。此前源记录和开发测试已多次探索，不声称盲测。

## 固定训练与测试
本报告所在 Git commit 为代码身份。与已运行 DURA 后验均值分支使用相同 8,192 条源物理记录、模拟视图 21/22/23、五轮、batch 8、固定末轮与固定门槛；仅修正结构改变。先做 64 条源训练／28 条源预测真实权重预检，再固定 672 条源预测，随后独立读取合法 L_s 进行源评分；源评分不回流选模。地面七视图每景 168,000 条，冻结全部预测后由独立程序 truth-last 评分，比较同一 DURA、clean、六受损视图、跨 RX 和跨 RX+day。目标各受损视图 >= 83.942530%，同时报告 83.538690% 的 3 个百分点口径。

N607 普通用户；项目 CVS-RFFI Python，CPU 2 线程，TF32 禁用，源训练与地面 GPU 使用既有共享操作系统租约，选卡须剩余显存至少 12,288 MiB、可见计算进程少于 2 条，CPU 负载超过 72 等待；不改变其他进程。命令入口 `python -X utf8 -u -m experiments.phase1_dura_spectral_prior.source_controller --commit <本报告所在 commit>`，七景及独立评分各有独立控制器。source run `20261102-phase1-dura-spectral-prior-source-s2026092701-r01`；ground run `20261102-phase1-dura-spectral-prior-ground-test-s2026092701-r01`；所有根不可覆盖。仅协议越界、数值非有限、输出冲突、无法合法预测或技术失败时停止并保留产物，低成绩不停止。

## 本地结构验证
真实 DURA 原生两阶段随机权重结构上，2 条合成 IQ 的零初始化输出最大绝对差 0；两个频域阶段梯度范数为 0.0040477、0.0071216，优化一步后输出有限且原 DURA 不变。模块检查还覆盖整体相位等变、跨时间位置梯度、零初始化与形状边界；以上不包含真实 checkpoint 或实际源／目标 IQ，不能证明性能。
