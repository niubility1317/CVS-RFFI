# LoRa R17 固定频带剂量的方向增量试验

## 设计

上一轮同时更新时域和频域先验。LoRa residual 高城区 1–8 kHz 修正过量至原 R17 的 5.16 倍，且方向余弦由 0.734 降至 0.135。匹配全频 RMS 后仍损失六景正确数。原 R17 未改权重的读出作为本轮锚点。[上轮双路线证据](../20261123-phase1-lora-dura-spectral-unroll-source-m4-r01/report.md)

Full practical 和 residual practical 各使用本信道冻结的 R17、原源 L_s/U_s 配对。冻结完整 R17，保留接收作用估计、三次独立时域先验与六次 CG。额外网络输入为当前 chirp 的去载波观测以及三次展开各自产生的修正频谱。仅在 1–8 kHz、9–32 kHz 内预测与原频带修正正交的复数分量。逐带恢复原 R17 修正范数，限制切向分量为原单位方向的 0.35 以内。其他频点和载波保持，合成波形仍处于观察坐标下。对每个频带使用配对 clean 形状的方向损失。匹配父网络与轨迹坐标、逐带固定剂量是本次与此前 residual 全波形切向头的区别。

独立训练两路候选，固定种子 2026092702、AdamW 1e-4、batch 64、700 步。训练无 F、TX 标签、V 或目标读取。每路训练开始前用真实来源数据核对梯度且确认 R17 无梯度。两路分别复用已验证的原恢复门。全路冻结后，在既有源 V 上用两路线共用的 1,000 个物理包（每台源 RX 200 个），与前一时频先导的 500 包互斥。该面板复用了此前更大范围物理诊断的源域数据。固定比较直通、门控 R69 半量、门控 R17 半量，以及新增分支仅作用 1–8 kHz、仅作用 9–32 kHz 或同时作用两个频带。先保存同路线全部七景预测，再读取 V 标签。另核对每个频带的绝对范数差与按 RX 分层的物理包配对区间。

本次为源域研发。后续正式候选须在相应路线保护 clean，六景和低城区同时改善，并与该路线更强的旧正式管线同物理比较。不可把两个场景的增益外推为无退化。正式目标仍以 15 台未见 RX、30,000 个物理包和原冻结 Tri-set 三种子为准。

## 发布口径

运行 `20261123-phase1-lora-dura-r17-anchored-source-m2-r01`，N607 普通账户既有 Python 环境，独立不可覆盖 release/run。入口 `python -m experiments.pamf_lora_main.r17_anchored_source publish`，使用原数据、残差父版回执和源码提交。GPU 依次 3、6、2、0、4、1、5，同 run 每台 GPU 最多一条、双路线最多两条。任何合同错误、冻结隔离失效、非有限值、剂量不一致或覆盖失败时停止该轮继续派发，保留现场。预期两条真实源 smoke、两份冻结方向头、两套路由的预测与七景源评分。
