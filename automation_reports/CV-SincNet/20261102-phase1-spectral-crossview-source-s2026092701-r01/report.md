# Phase1 多信道视图一致性频域恢复

在独立频域耦合架构（14,678 参数）上，源训练时按同一物理记录配对第 21、22、23 轮固定模拟信道视图。对齐 IQ、冻结 Tri-SIG-TIME SSL 特征、软类别分布、伪类别间隔和输出功率的单视图目标沿用对齐感知频域版本；另加 0.1 倍三个恢复视图相对于其平均软类别分布的 KL，以及 0.05 倍冻结基座归一化特征相对于三视图中心的余弦误差。跨视图中心停止梯度，接收机组均衡；一致性不使用设备身份。伪类别不是真实身份，F 保持冻结，故为 F-guided。训练前核查三视图配对的干净 IQ 与接收机顺序一致。

使用相同 8192 条源训练记录、三个已固定视图及五轮训练；每批 8 条物理记录、共 24 个视图，AdamW 学习率与初始化沿用基础频域版本。每轮记录和视图总暴露次数相同，但相对每批 16 个独立视图的基础版本，优化器更新次数不同；因此对比同时包含配对损失和批处理方式差异。源记录及视图已经探索，非独立盲测。

网络、盲噪声估计器和保护门不调用 DURA 或条件物理先验；推理只输入当前单条受损 IQ，不依赖其他视图、干净 IQ 或身份。训练不直接读取 TX 身份、U_s 真值、V 或地面测试。先执行 64 条源训练与 28 条源评估的真实预检；通过后完整训练，固定 672 条源预测，再独立连接合法 L_s 身份评分。

预先登记 clean 和六个受损 Phase1 地面视图各 168000 条，全部预测固定后独立评分及审计，并报告跨 RX 和跨 RX+day。总集 clean 基准 86.538690%，相对下降 3% 的门槛 83.942530%，另报告下降 3 个百分点的门槛 83.538690%。已反复观察的地面开发集不代表独立盲测或真实卫星链路。源实验 `20261102-phase1-spectral-crossview-source-s2026092701-r01`、地面实验 `20261102-phase1-spectral-crossview-ground-test-s2026092701-r01`。CPU 两线程、负载超过 72 等待，独立不可覆盖输出和 truth-last 评分，低分不停止健康任务；地面结果不回流训练或调参。
