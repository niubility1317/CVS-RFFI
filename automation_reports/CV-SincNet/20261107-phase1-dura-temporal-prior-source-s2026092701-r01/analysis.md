# 时序先验恢复训练：源域分段计时

N607 已登记的时序先验训练仍在运行。其第 1 轮日志记录累计 32,010.5 秒；后续仍有活动训练进程。实际速度受共享 GPU、CPU、数据准备及进程调度影响，不能直接从显卡总体利用率判断原因。

为获得粗略参考，在本机 RTX 5070 Ti 上使用已核实合法的 32 个源 IQ 视图、冻结源遮掩先验和相同恢复器结构，固定 mask 起点，预热 3 步后计时 12 步。每段前后调用 CUDA 同步，数值为各段的平均墙钟时间；未计入数据装载、单独的主 IQ 损失构造及清零梯度。使用 FP32、TF32 关闭和确定性算法，未读取 TX 标签、F、V 或目标数据。

| 分段 | 每批平均时间 |
| --- | ---: |
| 恢复器前向 | 13.87 ms |
| 时序先验前向 | 11.51 ms |
| 反向传播 | 30.12 ms |
| 有限性检查与梯度裁剪 | 8.27 ms |
| 优化器更新 | 3.23 ms |

这些分段加和约 67.0 ms，但不是完整训练吞吐：该测量使用固定小批次且每段主动同步；N607 使用完整源数据和共享资源，硬件及负载不同。远端一次进程监测表明 GPU 6 同时运行其他计算任务，单次采样不能量化各任务对训练的影响。当前证据不足以确定远端慢的根因，也未证明任何加速方案的数值等价性。运行中的训练、预算、输出和其他任务均未更改。
