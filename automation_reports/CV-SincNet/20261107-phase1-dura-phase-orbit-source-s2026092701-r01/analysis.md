# DURA 源 IQ 相位旋转一致性

固定用户指定的 DURA v1.0，对 672 条合法源 IQ 的 received 分别施加 0°、90°、180° 和 270° 全局相位旋转，独立执行 DURA，再将各输出旋回原相位；比较原路径与四路径 IQ 等权平均。每条源记录配对 clean IQ，使用按该记录 clean 能量归一化的波形 NMSE；路径离散度是四个旋回输出相对其均值的平均能量，同样按 clean 能量归一化。14 个 RX/场景组各 48 条。

14 组等权平均：原 DURA NMSE 为 0.022517，四路径平均为 0.442419；路径离散度为 0.603788。平均波形 NMSE 较原路径降低的组数为 0/14，逐条样本降低 3/672。这不支持将当前简单四路径平均形成部署候选，也不能推断其他相位校正或训练机制必然无效。
