# LoRa R44 展开中的载波、细节与功率损失

固定两份源 V 面板。第一份为阶段追踪所用的 120 包，第二份为五台源接收机各 120 包。两份分别计算。所有分支均使用同一冻结 R44 和冻结 Tri-set，保留同一个观测载波坐标，先完成所有预测再读取源标签。没有读取目标或更新 G/F。

## 首次缩幅与后续细节损失

在第二份面板的低强度城区，把 IQ 正交分解为沿观测载波的复系数与去载波残差。表中两项功率均按同包同 chirp 的 clean 功率归一化，再对 3,600 条 chirp 取均值。

| 阶段 | 载波功率 / clean | 去载波细节功率 / clean | 总功率 / clean |
| --- | ---: | ---: | ---: |
| 原始接收 | 86.67% | 13.47% | 100.13% |
| 粗恢复 | 24.21% | 1.62% | 25.83% |
| 第 1 次展开 | 40.94% | 0.39% | 41.33% |
| 第 2 次展开 | 41.11% | 0.37% | 41.48% |
| 第 3 次展开 | 40.79% | 0.36% | 41.15% |

粗恢复已经丢失大部分载波和去载波细节。展开部分提高了载波功率，同时进一步压低去载波细节。R44 末步的细节功率约为原始接收的 2.69%。

## 载波单项保护

第一组改法只在最终输出替换载波或替换去载波细节。第二组使用相同冻结网络重新计算展开。每级求解后补回观测载波的读出会把补后的 IQ 传入下一级。受限求解则先固定观测载波，将数据梯度和正规方程投影到去载波子空间，每级仍使用两次共轭梯度。原生求解的独立重放与原模型核对一致。两类展开改法都验证了观测载波系数的数值保持。

| 冻结读出 | 120 包六景 / 720 | 600 包 clean / 600 | 600 包六景 / 3,600 | 600 包低强度城区 / 600 |
| --- | ---: | ---: | ---: | ---: |
| 直通 | 395 | 439 | 2,059 | 250 |
| 既有半量 | 404 | 439 | 2,091 | 256 |
| R44 原生 | 331 | 431 | 1,773 | 194 |
| R44 普通末步半量 | 394 | 434 | 2,076 | 250 |
| 只补回观测载波 | 346 | 432 | 1,825 | 189 |
| 只补回观测细节 | 390 | 441 | 1,985 | 226 |
| 补载波并放大原生细节 | 286 | 434 | 1,377 | 152 |
| 每级求解后补载波 | 352 | 432 | 1,842 | 194 |
| 每级求解后补载波，末步半量 | 394 | 435 | 2,070 | 247 |
| 求解内固定载波 | 350 | 430 | 1,844 | 195 |
| 求解内固定载波，末步半量 | 392 | 435 | 2,071 | 247 |

补回原观测细节比只补载波多 160 次六景正确。放大原生残差到接近接收能量会进一步掉点，说明细节的方向也已改变。两种载波约束使原生读出略有恢复，加入相同的限幅半量后均略低于普通末步半量。载波的功率损失解释了总缩幅的大部分，恢复身份信息仍需要保护原观测细节。

## 逐级保护原始细节

以原始接收为锚点，比较只在最终输出保护与在粗恢复、每次两步共轭梯度后保护。三种保护都精确保留观测载波，使用与原方法一致的平滑 15% RMS 限幅。第一种仅限幅。第二种要求去载波输出在原始细节方向上的实系数至少为 0.9。第三种精确锁定该复系数，允许正交残差。逐级保护后的 IQ 继续进入后一级先验和两步求解。

| 冻结读出 | 120 包六景 / 720 | 600 包 clean / 600 | 600 包六景 / 3,600 | 600 包低强度城区 / 600 |
| --- | ---: | ---: | ---: | ---: |
| R44 普通末步半量 | 394 | 434 | 2,076 | 250 |
| 末步保留 90% 同向细节，半量 | 373 | 434 | 1,857 | 214 |
| 末步锁定同向复系数，半量 | 362 | 431 | 1,762 | 214 |
| 逐级限幅，半量 | 395 | 435 | 2,070 | 247 |
| 逐级保留 90% 同向细节，半量 | 370 | 437 | 1,838 | 214 |
| 逐级锁定同向复系数，半量 | 359 | 430 | 1,754 | 213 |
| 逐级限幅，全量 | 365 | 434 | 1,935 | 238 |
| 逐级保留 90% 同向细节，全量 | 318 | 433 | 1,553 | 185 |
| 逐级锁定同向复系数，全量 | 290 | 426 | 1,440 | 183 |

在 600 包面板低强度城区，普通半量输出功率为原接收的 96.64%，逐级锁定半量为 100.07%。逐级锁定的实际修正 RMS 约为 2.59%，小于普通半量的 5.56%，仍少 37 次正确。保护原方向会同时保留其混入的噪声。当前冻结网络产生的正交变化单独使用时，无法代替有限的同向衰减。

## 半量修正的分量归因

将同一 R44 半量增量投影到原接收去载波细节方向。实投影只改变该方向的幅度。复投影允许全局复系数变化。其余为正交残差。分别保留分量、尝试匹配原增量 RMS 并限制放大至 3 倍。这里保留原始半量的所有分量作为同包对照。

| 修正分量 | 600 包 clean / 600 | 600 包六景 / 3,600 | 600 包低强度城区 / 600 |
| --- | ---: | ---: | ---: |
| 直通 | 439 | 2,059 | 250 |
| 既有 DURA 半量 | 439 | 2,091 | 256 |
| R44 完整半量修正 | 434 | 2,076 | 250 |
| R44 只保留同向实投影 | 443 | 1,671 | 189 |
| R44 只保留同向复投影 | 442 | 1,673 | 188 |
| R44 只保留正交分量 | 431 | 1,784 | 217 |
| R44 同向实投影，匹配原 RMS | 439 | 1,343 | 162 |
| R44 正交分量，有限幅度匹配 | 431 | 1,618 | 197 |
| 既有半量接受区，再加 R44 同向修正 | 439 | 1,747 | 190 |
| 既有半量旁路区，再加 R44 同向修正 | 443 | 1,976 | 254 |

低强度城区的 R44 半量增量中，约 96.55% 的能量处在沿原始细节的实投影。它单独使用时，低强度城区正确数从 250 降到 189。正交分量虽小，却影响组合结果。完整增量六景为 2,076，比直通多 17 次，两个单独分量均劣于直通。逐级保护损失与这一分解一致。可以观察到同向与正交部分有耦合，保留其中任何一项作为独立恢复规则都会失去原组合的收益。

## 求解权重与作用校准

固定 R44 权重、三次展开和每次两步共轭梯度。改变先验方差倍数，以调整观测作用相对于先验的权重。另一对照只将先验锚点及初始迭代从粗恢复换成原接收，仍读取同一粗恢复和作用特征。下表为同一 600 包面板。低强度城区原生功率按源 clean 归一化。

| 先验锚点及方差倍数 | 原生六景 / 3,600 | 末步半量六景 / 3,600 | 原生低强度城区功率 |
| --- | ---: | ---: | ---: |
| 原粗恢复，0.125 倍 | 978 | 1,625 | 18.49% |
| 原粗恢复，1 倍 | 1,773 | 2,076 | 41.15% |
| 原粗恢复，8 倍 | 1,045 | 1,781 | 196.01% |
| 原粗恢复，64 倍 | 923 | 1,701 | 571.85% |
| 原粗恢复，256 倍 | 874 | 1,693 | 1,145.04% |
| 原接收，1 倍 | 1,637 | 1,835 | 108.41% |
| 原接收，8 倍 | 1,090 | 1,730 | 270.89% |
| 原接收，64 倍 | 912 | 1,700 | 659.18% |

提高观测权重使原生功率越过 clean，并继续扩大，准确率下降。换用原接收作锚虽然回到了接近 clean 的功率，六景仍落后。单个权重或功率匹配无法修复当前冻结求解。

对登记的 120 个源 V 包重放匹配的 1 MHz practical 轨迹，逐值核对观测。按相同包尺度取实际新增噪声，实方差定义为复噪声能量的一半。先将配对 clean 转到接收相位，计算估计作用的前向结果，与无新增噪声轨迹比较。整个校准诊断不读 F 或 TX 标签。按 chirp 汇总的中位数如下，R17 完整继承作用阶段，生成的数值逐项相同。

| --- | ---: | ---: | ---: | ---: | ---: |
| 高强度郊区 | −0.12 dB | +16.55 dB | 0.016 | 0.292 | 0.401 |
| 中强度郊区 | −0.73 dB | +13.04 dB | 0.018 | 0.361 | 0.459 |
| 低强度郊区 | −0.88 dB | +9.81 dB | 0.029 | 0.417 | 0.509 |
| 高强度城区 | −0.14 dB | +16.92 dB | 0.017 | 0.288 | 0.401 |
| 中强度城区 | −0.57 dB | +10.89 dB | 0.057 | 0.411 | 0.508 |
| 低强度城区 | −0.55 dB | +1.12 dB | 0.150 | 0.831 | 0.831 |

低强度城区的前向增益功率中位数从 0.570 降至 R38 的 0.010 和 R44 的 0.012。R44 的噪声方差中位数约 0.0327，真实值约 0.0264。以固定先验方差乘前向增益功率、再除估计噪声方差衡量相对数据项，该值从作用阶段的 0.354 降至 R44 的 0.00492。低强度城区的主要漂移来自作用增益。其余多景还伴随明显噪声方差高估。压缩阶段开放了作用和粗恢复参数，但当前去载波重建目标没有继续直接监督前向作用或噪声方差，第一次可测漂移出现在 R38。

## 换回校准上下文

保留原冻结 R44 三个先验模块，只替换粗恢复、作用或方差。早期作用和方差始终由同一个冻结作用检查点在自己的粗恢复输出上生成。表中的半量读出使用同样的末步保护。

| 与 R44 先验组合的上下文 | 600 包原生六景 / 3,600 | 600 包半量 clean / 600 | 600 包半量六景 / 3,600 | 600 包原生、半量低强度城区 / 600 |
| --- | ---: | ---: | ---: | ---: |
| 原 R44 | 1,773 | 434 | 2,076 | 194、250 |
| 仅早期作用 | 1,452 | 422 | 2,009 | 199、249 |
| 仅早期方差 | 945 | 433 | 1,741 | 128、223 |
| 同时换成早期作用和方差 | 1,932 | 433 | 2,067 | 212、250 |
| 早期粗恢复、作用和方差 | 1,888 | 433 | 2,042 | 199、244 |
| 仅早期粗恢复 | 1,559 | 409 | 1,839 | 186、245 |

作用和方差需联动使用。换回两者后，600 包原生六景净多 159 次，低强度城区多 18 次，末步半量六景少 9 次。在 120 包面板，原生从 331 到 373，半量从 394 到 397。先验仍是原上下文下训练的权重，直接替换结果说明校准有影响，也显示重新匹配先验有必要。

另启动配对源训练，从同一 R44 先验分别初始化两组。一组固定 R44 粗恢复、作用和方差，另一组固定早期已校准的这三项。共享完全相同的源 L/U 采样、800 步、去载波重建目标和两份 practical 观测配方。每组 6,400 次 L、19,200 次 U 曝光，其中 4,000 次为恒等。只更新先验，冻结 F 仅在两个训练结束后用于源诊断，评分不读取目标。GPU 3 的独立全链路训练继续使用原冻结和评测计划。
