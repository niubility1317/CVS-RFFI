数据使用原接收机划分、同包 crop 与注册的 1 MS/s practical 处理。已登记对齐审计排除固定时移。源反事实逐 chirp 校正整体相位将 395 次正确提高到 406 次，逐 chirp 校正复增益为 404 次。高相干子集替换同包 clean 的去载波共享及独有残差时，保留受扰观测的载波，净增加 1,892 次正确。该反事实只说明被损伤的信息位置。早期使用同一恢复方向的半量修正在三种子实测比直通高 0.7337 个百分点，完整剂量没有复现同等收益。

原完整链正式盲测在 NumPy 故障修复后完成。种子 2026092702 的冻结 Tri-set 直通为 clean 70.3633%、六景 55.3956%、低城区 41.2733%。原完整输出为 60.7467%、26.5456%、19.0467%。加既有门控为 70.3633%、52.4533%、32.2133%。门控保住 clean，剩余落差指向恢复方向和覆盖范围。该评分为单种子，阶段诊断固定在源域。实测同种子前期半量对照六景 56.0417%、低城区 42.2700%。

随后完成的观察相位链将原生六景提高到 42.8456%，低城区提高到 26.8733%，clean 为 63.6267%。既有门控读出三项为 70.3633%、53.0689%、34.1067%。相位适配相对原生链回收 16.3000 个百分点，仍距直通六景 12.5500 个百分点。幅相失配解释了部分损伤，去载波形状仍需独立优化。

完成同样预算的四条既有链均已正式评分。完整动作库版本相对观察相位链，原生六景为 42.7439%，加门控为 53.4883%，门控后的低城区为 35.1733%。追加去载波细节损失的版本保持同一观察相位粗恢复和作用起点，原生 clean、六景、低城区分别为 67.5467%、46.1872%、31.2200%。加门控分别为 70.3633%、53.7656%、36.2933%。这组控制表明修正作用监督主要回收门控下的部分低城区样本。只在展开损失中加入细节项也只能部分回收，仍落后直通六景 1.6300 个百分点。四条既有链均在各自的 1,050 份盲预测固定后评分。

## 新全链路

保留原八阶段、网络、求解步数、压缩顺序、种子和训练预算。粗恢复从零初始化，后续每阶段只接本 run 的直接父权重。保留 15% 恒等，非恒等粗恢复和展开训练使用原已登记两份匹配 physical practical 观测。作用估计使用已冻结的同合同双观测动作库，含 28,000 个 L/U 物理包。配对参考旋转到观测相位时同步变换作用系数。

每层用接收 chirp 估计的载波坐标形成归一化去载波学习目标。从同包 clean 独立提取形状，恢复 IQ 保留接收载波和坐标。修正量采用平滑限幅，单 chirp 的上限为接收 RMS 的 15%。损失同时监督有界后的形状、网络原生形状和载波幅相，末次更新与各级平均共同计入。紧凑阶段对每个源 chirp 和每级教师做比较，教师的形状误差低于同包直通时才蒸馏该输出，权重 0.25。原版物理作用探针目标、CG 和剪枝仍保留。该修改直接对应粗恢复分布、动作监督以及末级蒸馏三个有证据的失效点。

每阶段记录 20 轮损失、步数、源 L/U 曝光及参数。训练结束后固定 120 个源 V 包的七景，分别记八阶段的直通、原生及投影去载波误差，以及原生能量比。G 更新隔离 F、V、TX 与目标。源诊断和目标测试均在权重冻结后进行。盲测保持同一冻结 Tri-set、15 个未见目标 RX、30,000 个物理包、clean 和六种 practical。保留此前八条冻结参照，新测完整有界输出、半量输出和既有门控输出，共 1,155 份预测数组。全部预测固定后独立评分，报告三者相对直通和前期半量的同包净纠错。用户目标按新方案六景均值距同方案 clean 最多 3 个百分点判断，另核对 clean 保护和低城区。本次结果为单种子初筛。
