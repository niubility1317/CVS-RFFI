# Phase1 源域类别可靠性门控探针

本探针检查能否从推理时可见的信息判断类别条件模型的改类提议是否可靠。固定使用类别条件模型第 14 轮检查点；门控输入仅包括冻结 Tri-SIG-TIME SSL 和候选波形的类别概率、接收与 DURA 能量，以及候选是否被冻结基座判为提议类别。门控本身是源域训练的逻辑回归。

选取 4096 条源训练物理记录（1024 条 L_s、3072 条 U_s），按记录分为 2456 条拟合、820 条选择、820 条留出；clean 和两个源视图复用同一分组。上游第 14 轮模型已见过这些源记录，因此留出仅针对门控拟合。L_s 使用真标签；U_s 只在 clean 教师置信度至少 0.95 时使用伪标签。全部提议先固定，再读取 L_s 标签；不读取 U_s 标签、V 或测试 IQ。

拟合组中有 207 个符合条件的改类提议，其中 79 个符合各自源目标。选择组对门控置信度 0.50、0.60、0.70、0.80、0.90、0.95 进行比较，并包含不改类基线；按两个受损视图的净正确数选择，约束 clean 视图的反事实净损失不超过 1%。选择结果为 0.50，在选择组两个受损视图合计净增 2 条，clean 反事实净减 1/820 条。

每个受损留出视图的 795 条有效记录包括 205 条 L_s 真标签和 590 条高置信 U_s 伪标签，不能称为 795 条真实标签准确率。实际生成候选经过冻结基座复核，只有其类别等于提议类才接受。clean 留出组有 820 条记录；实际生成候选没有被接受，与 clean 教师一致数保持 818/820，205 条 L_s 真标签正确数保持 204/205。这只表示该组没有发生实际候选替换，不是 clean 保护保证。

模型选择时的净收益和 clean 约束采用反事实改类计算；实际生成候选及 clean 留出统计是在看到初始反事实结果后补充的事后分析，不能视为严格预注册的独立确认。该门控在这批源记录上未显示可用收益，不进入正式测试。完整初始与补充结果见 [initial.json](initial.json)、[phase1_class_gate_source_probe_v2.json](phase1_class_gate_source_probe_v2.json)。[verify.py](verify.py) 不重新拟合门控或上游模型，直接加载固定权重重算留出记录，已核对上述实际候选和 clean 计数。
