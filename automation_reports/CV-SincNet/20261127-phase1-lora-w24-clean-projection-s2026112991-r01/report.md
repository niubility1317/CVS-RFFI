# LoRa W24 双步整包干净先验投影

Run `20261127-phase1-lora-w24-clean-projection-s2026112991-r01`。仅使用 Full 星地路线，先跑单种子 300 包源域筛查，再按预登记规则决定是否启动正式预测。 [实验登记](experiment.json)

## 假设与预算

验证在合法源 clean IQ 上显式训练投影，能否使双步恢复改善固定 W24 的同包识别。两臂同一结构、随机初始化 2026112991、346,154 个可训练参数、20,000 个源 U_s 拟合包、500 个互斥留出包和同样的通用受扰配对。每臂 48,000 步、batch 16，AdamW 学习率按余弦由 2e-4 降至 2e-5，梯度裁剪 1。留出损失在 2,000、6,000、12,000、18,000、24,000、36,000、42,000 及末步记录，检查后半程是否仍有收益，两臂均固定末步。

在接收跟踪坐标中把 8 条 chirp 压为各 64 维，再通过包内注意力混合和复数解码。两步共享参数，两步均回到原观测，在跨 chirp 公共和差异子空间按实收频谱高频功率估计保留观测。保留每条 chirp 的跟踪直流与 48 点原始边缘。训练直接优化实际第一步和第二步读出，分别记录首尾、内侧、复数均方误差、弱探针传递、同包一致性及 clean 恒等。候选独有 0.40 的源 clean IQ 投影重建风险。原始训练预算中一个记录点位于 24,000 步，本轮学习率日程按 48,000 步展开。双倍编辑只做冻后压力对照。

训练、定权和冻结只访问合法源 U_s IQ 与通用受扰配对。固定 F、TX、源 V 和目标均不参与拟合。冻结后原始 E104 接原默认分类头，与直通、原长训 DURA、首尾 DURA、原始整包 U-Net 做七景同包对照。300 包候选实际读出六景严格超过固定对照、低城区达到最高对照且 clean 达到直通时，进入三分片、15 台未见接收机、30,000 包 Full 独立 truth-last；正式真值仅在全量盲预测固定后连接。
