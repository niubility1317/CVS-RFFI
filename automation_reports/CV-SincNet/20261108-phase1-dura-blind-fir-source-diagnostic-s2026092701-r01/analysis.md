# 多抽头盲信道修正的源域方向诊断

在 672 条已探索的合法 Phase1 源 L_s/U_s 记录上，冻结原 DURA，按 RX4/6 与 RX8、七个模拟视图划分为 14 组，每组 48 条。每条记录先以 DURA 原输出为当前波形，只使用同一条接收信号与估计作用拟合复数信道抽头；不读取 TX 标签、F、V 或目标数据。随后用源 clean 计算单方向受限理想步长。理想步长需要部署时不可用的 clean，因此不是恢复器预测或身份准确率。

下表中观测残差比为逐记录“拟合后残差平方和／拟合前残差平方和”的组等权均值，不是汇总残差能量之比。源波形 NMSE 为各组均值的等权平均。原方向和每个拟合方向均在相同 DURA 输出上，用各自方向做理想线搜索；没有将 oracle 波形用于训练或部署。

原 DURA 输出的组等权平均 NMSE 为 0.02251701。64 抽头明显降低当前观测的拟合残差，但对于使用 clean 才能得到的理想正向波形误差，较原方向的平均改善仅约 0.26%。它在 RX4/6 低城区的理想正向 NMSE 从 0.03717284 上升至 0.03719663（约 +0.064%）；RX8 低城区从 0.10060497 下降至 0.10057965（约 −0.025%）。每格 48 条，不能由组均值推断单记录收益或目标接收机分布。

这项结果说明在这批样本和当前 0.1 正则／25% 信道范数上限下，更多抽头可拟合观测，但单靠物理残差方向的可见波形收益有限。它不否定联合非线性训练、多步算法或其他约束，也不能证明真实 TX 身份性能；不能把它当作整个恢复问题的上界。拟合的每记录抽头使用当前观测，理想步长额外使用源 clean，仅用于本诊断。

真实 DURA 权重源 IQ 两条 smoke 通过，完整源诊断输出 672 条、8／32／64 三种抽头和 14 个完整分组，日志计时约 6.61 秒（不含初始化与 smoke）。源 metadata 记录 TX、F、V 和目标读取均为 0；未训练模型或保存恢复器权重。任务运行很短，启动时 GPU0 可用 24110 MiB、无其他计算进程；首次事后查询时进程已退出，完成由日志和 result.json 独立确认，没有运行时 GPU PID 快照。
