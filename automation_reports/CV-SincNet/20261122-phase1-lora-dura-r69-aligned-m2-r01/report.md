# 原版 R69 DURA 的 LoRa 载波坐标适配

既有固定形状和步幅模型作为正式对照。源冻结诊断在同一物理包上给出全理想形状净多判对 591 次、只恢复相位残差净多判对 439 次。以相位残差的配对学习改进恢复网络，并减少固定高相干门槛的覆盖损失。

使用原 DURA v1.0 的 R69 骨架，同机制 R65 三阶段教师与 R69 两阶段学生。时频粗恢复、接收作用估计、先验共享和两个阶段各两次 CG 均保留。WiSig 权重不迁移。LoRa 适配用实测 chirp 载波坐标对每段去载波并归一化，训练原两阶段估计去载波波形，保留收到的平均载波后逆变换回原 IQ。教师从零训练，学生继承同合同教师的后两阶段，源配对波形误差分别归一化幅度与相位分量并提高相位权重，保留 0.05 多尺度谱项、同源 clean 恒等项与按 1 至 0.1 衰减的阶段蒸馏。两阶段各 2,400 步，每步 20 条源 practical 配对和 4 条 clean。每五个 U 保留一个供源门控训练和独立源核对，不进入 G 更新。全程无 F、TX 类别、V 或目标更新。

一次训练评估两种限幅，15% 观测 IQ RMS 上限和其半量 7.5%。共享在冻结恢复后拟合的源 IQ 门控，使用搜索前固定的同物理包相位误差改善校准，clean 分界验证在源 L/U 上。完整测试与固定 Tri-set 种子 2026092702 配对。沿用同种子的原直通、固定 DURA、形状保护与半量 DURA 作为对照。每条路径涵盖 clean 与六种 practical、15 目标 RX、同一批 30,000 个物理包。共 630 份盲预测、42 个评分单元。模型与门控先固定，独立评分报告 clean 差距、七景成绩、净纠错及逐接收机。只有在科学判据支持时增加种子，不用目标成绩改变该组训练或阈值。

N607 普通账户，允许 GPU0–7，由容量调度。使用 `python -m experiments.pamf_lora_main.full_dura_publish --draw-submit ... --stack-submit ... --detail-dose-submit ... --r69-aligned`，其中 detail-dose-submit 指上一轮三种子冻结矩阵。由 Git commit 给定代码身份，工作目录 `CV-SincNet/releases/20261122-phase1-lora-dura-r69-aligned-m2-r01-release`，唯一运行根 `CV-SincNet/runs/20261122-phase1-lora-dura-r69-aligned-m2-r01`。真实源 IQ 与原 G 权重检查后执行教师、学生、源门控、盲预测和独立评分。任何数据合同、权重祖先、非有限、限幅或盲预测矩阵技术错误即停止。
