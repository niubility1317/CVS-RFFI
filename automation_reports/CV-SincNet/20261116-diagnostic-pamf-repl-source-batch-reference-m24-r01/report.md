# Tri 源域批次梯度波动参照

固定十类和六源各原 Tri 同合同 E20（seed 2026092701），每个设置独立重载相同源 checkpoint，依次取预先固定的 12 个 L128／U256 批次。采集原有完整监督梯度和原始无标签梯度，按 t2、分类头、其他参数分别计算 L–L、U–U、同批 L–U 和跨批 L–U 的范数、点积和余弦。每设置获得 66 对 L–L、66 对 U–U、12 对同批 L–U 及 132 对有序跨批 L–U；这些配对共享批次，不能作为 66 个独立种子或独立实验。

诊断在 N607 普通用户 CPU 运行，不占 GPU，重用源域 L_s/U_s；U 真值、源 V 和测试数据均不读取，不修改模型参数或训练 optimizer。模型参数从同一 E20 重载，但批次、随机增强与前向缓冲可能不同；比较包含这些波动。每批沿用已有源分析附带的两个空动量影子 AdamW 首步，共 48 次，均丢弃，不能解释为后续训练的真实动量或目标性能。用户选定 seed 的历史测试已经曝光，结果只作源机制诊断。

执行命令、源 checkpoint、数据角色、产物见 `experiment.json`，代码身份以发布记录为准。独立 P0/P1 审查未发现阻断项，局部合成配对测试通过；实际源数据运行和结果待核验。
