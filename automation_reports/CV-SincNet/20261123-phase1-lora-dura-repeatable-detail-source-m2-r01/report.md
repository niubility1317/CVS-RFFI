# LoRa 双信道可重复复谱方向先导

## 数据和方法

上一轮放宽 full practical 扰动门后，候选恢复存在逐包纠错空间，依据配对波形整体误差选择方向仍损害识别。本轮检验同包经独立信道观测时的可重复复谱方向能否提供更好的恢复约束。[前轮冻结读出](../20261123-phase1-lora-dura-signed-utility-source-m1-r01/report.md)

Full 与 residual 各从自身已登记的源配对中抽取每源接收机 900 个 U 包，共 4,500 包。使用同一物理包的 clean、两次 practical 实现。去载波后保留六条 chirp 在 1–8 和 9–32 kHz 的复谱，保留 chirp 各自的位置，不跨包引入供体。Clean 各源接收机组内去均值后估计协方差。同包两次信道观测之差用于估计随观测变化的协方差。使用带正则的广义特征分解固定前 96 个方向，并转成实 IQ 坐标的正交子空间。拟合全程只读取合规源 U IQ 和 RX/物理配对元数据，F、TX 类别、V 和目标读取均为零。推理只读取当次接收 IQ，无 clean、第二份信道观测、接收机 ID 或标签。

对 R17 新增修正比较可重复子空间投影、正交补投影和只保留可重复分量并允许减量的控制。前两种对每条 chirp 分别恢复两个频段的原修正范数，补空间是匹配剂量的方向对照。方向比较均保留带外和原载波的修正值。Full 基线继续使用正式复响应半量；仅在已冻结扰动门启用且旧响应附加分支未接受时，检验上轮 R17 追加候选。Residual 基线调用原门控 R69 半量，候选使用从同一接收坐标计算的 R17 半量与基线的有界差。两路各自继承既有门控，保护旁路输入。架构与测试流程可共用，基底权重和源指纹协方差分别匹配两条信道。

## 冻结验证与发布

每路使用相同固定 1,000 个源 V 物理包，五台 RX 各 200 包，与紧邻的 R17 方向、full 效用先导两个面板互斥。其他历史源诊断中可能使用过这些物理包。比较直通、当前路线基线、未投影 R17 追加、双带等剂量可重复方向、双带等剂量正交补、可重复减量。复用相同种子 2026092702 冻结 Tri-set。每路先写完七景预测及物理顺序，再使用独立于拟合的源评分。核对 clean、六景和低城区，逐 RX 报告净变化、重抽样区间以及等剂量误差。当前目标 57.0% 六景、43.0% 低城区及 clean 计数要求仍须由正式三种子实测验证。

运行 ID `20261123-phase1-lora-dura-repeatable-detail-source-m2-r01`，N607 普通账户、既有环境、独立不可覆盖 release/run。通过 `python -m experiments.pamf_lora_main.repeatable_detail_source publish` 使用 Git 提交源码与来源回执。GPU 优先 3、6、2、0、4、1、5，同卡同 run 一条，最多两条。每路先用真实源 IQ 和冻结恢复器检查计算和数据契约，再拟合完整源基底。合同错配、非有限、旁路或等剂量异常时停止后续派发，保留产物。预期两份冻结基底、真实检查结果、七景预测及各路线评分。
