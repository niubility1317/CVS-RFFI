## 方法、成本和证据边界

在固定耦合协方差结构上增加共享上下文的130参数均值输出头，按原先验逐坐标标准差限幅，仍经同一物理后验恢复IQ。

All1471463 G parameters scratch: physical1230341 seed2026092701, prior network241122 seed2026092702. Existing coupled-control parameters match at E0; new mean head130 parameters is zero. No ancestor G weights.

No TX labels. Physical Action/noise source supervision; shared mean/covariance prior network learns actual noisy IQ/STFT/original frozen F0 continuous features.

全部30轮/7410步、63000条每轮完整源排列、189000次L_s和1701000次U_s曝光已核实。最终权重逐值等于E30技术状态，源先验固定，模型/优化器有限，各参数头实际更新。源目标组成复算最大误差2.24e-09。训练期间F0前向行数1890000，完整source审计见training_final_audit.json。

实际训练阶段20055.409秒；epoch计时合计20041.243秒、均值668.041秒。两个预测阶段共2664.008秒。均为共享负载整阶段计时，含相应初始化/数据读取/真实源检查等成本，不是B1时延或独占提速倍数。

原Main两总体七景三流42单元全部固定后独立truth-last。再次复算全部1302组、868raw配对及DURA/clean配对，最大指标差1.29e-14，raw/DURA复用判决差0。公开CSV只包含聚合数据；各总体TX/RX/day/RX×day和macro-F1完整保留。combined_group_metrics.csv从互斥总体的混淆计数合并，不平均百分比。

低档城区66.709524%，相当于raw clean准确率的77.086357%；这是任务准确率保留比例，不是IQ信息恢复比例或理论上界。

代码、模型、source-only数据及最终30轮冻结点保持原预登记；资源调度只改变等待条件，全部科学阶段实际使用原release/commit。当前结果不用于调整其他在训候选、按场景组合或重新选择checkpoint。默认DURA保持，整个研究目标仍依完整逐景与clean保护证据判断。
