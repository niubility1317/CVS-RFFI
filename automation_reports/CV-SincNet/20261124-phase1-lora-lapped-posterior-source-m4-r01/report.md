# LoRa 短时复谱先验与局部不确定性融合

[预登记矩阵](experiment.json) · [实验状态](events.jsonl)

## 结构与接收量

读取同一包的六条 256 点前导 chirp。在既有前导配准和归一化坐标中，用 64 点正弦窗、32 点步幅计算每条 chirp 的八个短时复谱。首窗使用同一条 chirp 的末端作循环延拓。原坐标合成时两半窗平方和为 1，复数修正的时域均值固定为零，保留原去扫载波。门关闭时直接返回实收 IQ。

粗阶段从其余五条 chirp 的同坐标复均值、离差和外带功率估计预测当前 chirp 的复系数及预测方差。当前 chirp 的复系数只参与融合与细化。粗融合朝先验方向移动，权重为 \(0.85v_{\mathrm{obs}}/(0.02+v_{\mathrm{obs}}+v_{\mathrm{prior}})\)，其中两种方差均在加窗复系数尺度。细化读取当前实收复谱、粗输出、预测残差与估计置信度，输出受相同权重和噪声尺度约束的复数增量。最终回写原时标和物理尺度。

| 接收量 | 计算与时点 | 误差来源 |
| --- | --- | --- |
| 实收 IQ、去扫及配准置信度 | 六条前导可用后逐 chirp 计算，沿用当前接收侧跟踪。 | 局部相位、时钟和传播失配会污染坐标。循环窗经过边缘时把同一 chirp 的两端接在一起。 |
| 其余 chirp 的复均值与离差 | 用同包留一 chirp 重复结构，先验支路读取其余五条的同窗同频统计。 | 公共干扰会进入均值。离差同时包含接收噪声、相位失配与真实逐 chirp 差异。 |
| 局部有效噪声方差 | 每窗外带模平方中位数除以 ln 2，加权为 75% 本窗、25% 同 chirp 时间平均。 | 高斯近似忽略有色和脉冲噪声。外带信号会产生偏差。此量是观测代理，不接真实仿真噪声。 |
| 复谱先验方差 | 用留一重复统计，由源域联合训练的网络估计。 | 刻画先验相对源波形的预测风险，包含可重复指纹、时标与先验失配，不是传播噪声真值。 |

## 训练、消融与相关工作

两个臂各 5,797 参数，批量 24，按相同优化日程在一个 AdamW 循环训练粗恢复和细化，固定 40,000 步。20,000 个未标注源 U 包拟合，2,500 包校准旁路阈值，500 包作固定留出。通用扰动独立于目标 practical 生成。同包相对实测源 IQ 的复谱误差、不同扰动下的同源一致性和同扰动下的弱复谱差异传递共享。先验方差通过复预测残差的似然，由实测源 IQ 配对监督。训练阶段不读取 TX 真值、识别器、源 V、目标数据或信道仿真轨迹，真实噪声参数不作监督。

局部组使用每窗扰动强度，时间平均对照以同一 chirp 的平均替代。额外固定局部组权重，只在推理中对扰动强度作时间平均。初步比较报告局部组及两个匹配对照的粗、全量与半量。

Noise2Self 用互补掩码建立局部自监督损失，理论依赖噪声在被遮挡维和保留维的条件独立。本方案留一条接收前导作先验结构，用合法源 U 波形监督，当前 chirp 在融合和细化可见，允许其他 chirp 具有共享干扰。TF-GridNet 在语音任务建模时频上下文并扩展到多通道复谱估计。本方案显式分出包内复均值、实收噪声代理和预测方差，并把实际接收坐标下的复 IQ 交给冻结的 LoRa 识别器。 [Noise2Self 原论文](https://proceedings.mlr.press/v97/batson19a.html) · [作者实现](https://github.com/czbiohub-sf/noise2self) · [TF-GridNet 原论文](https://arxiv.org/abs/2211.12433) · [ESPnet 实现](https://github.com/espnet/espnet/blob/master/espnet2/enh/separator/tfgridnet_separator.py)

## 冻结测试

源 U 的最终更新完成后才载入冻结 Tri-set seed 2026092702。在相同 900 个源 V 物理包上分别执行 full practical 和 residual practical，两条路线均覆盖 clean 和六景。保留直通、成熟半量 DURA 及三个恢复组的三个读出。两条路线的全部预测固定后，由独立 CPU 读取源 V 真值，对应的净纠错逐景和逐接收机复算。局部训练组只有同一读出同时改善两路线的匹配 DURA 六景均值且保持两边 clean，才进入目标验证。

评分后独立重放源 V 同包，核查原时标的分频带复谱、幅度和相位。用精确加性噪声在同一窗上的实际外带功率复核观测方差，以留一先验相对源 IQ 的归一化预测误差核查先验方差。局部和时间平均代理都记录对数功率绝对误差以及去掉每条 chirp 整体偏差后的时间窗误差。 [波形诊断](../../../tools/lora_local_phase_fidelity.py) · [独立配对复算](../../../tools/lora_geometry_pairing.py)

## 独立归因

逐包复算覆盖 11 个读出，所有逐景正确数与原评分一致。1,600 次按接收机分层、按同一物理包重抽样，用于复核配对区间。完整纠错、改错、净变化和逐景逐接收机区间保存在本轮 scene-rx-paired.json。

低城区中，按物理包取中位数，局部噪声功率代理的对数绝对误差由 full 的 0.82 dB 降至 0.61 dB，由 residual 的 0.80 dB 降至 0.61 dB。去除每条 chirp 整体偏差后的时间变化误差，full 从 0.88 dB 降到 0.68 dB，residual 从 0.87 dB 降到 0.66 dB。Full 中城区的时间变化误差则由 0.87 dB 增至 1.21 dB。局部估计的可靠性取决于当前包是否存在可分辨的时间变化。

低城区以原尺度源 IQ 为参照，留一先验的平方预测误差除以网络预测方差。非直流系数按包平均后取中位数，full 为 15.99，residual 为 7.24。若该方差与残差二阶矩匹配，该比值期望为 1。实际幅度超过预测风险，提示留一先验在 practical 上偏自信。这一误差在冻结评分后以隔离源波形测量。

低城区相对同包扣除精确加性噪声的参考，局部全量把 9–32 kHz 复谱 NMSE 在 full 从粗恢复的 5.446 降为 1.248，在 residual 从 7.972 降为 1.429。该频带的幅度 NMSE 分别由 2.955 降为 0.455、由 4.827 降为 0.571，归一化复内积实部分别从 0.356 提升至 0.520、从 0.253 提升至 0.459。同期冻结识别在低城区分别净少判对 33 和 45 次。波形平均误差的降低没有传递为设备识别收益。精确加性噪声仅用于独立诊断。
