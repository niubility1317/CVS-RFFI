## 目的与对照

固定两份恢复器的实际半量修正和原 W24 E104 分类头。分别交换两份修正的全中心 L2 范数，以及同一去 chirp 坐标下的 1–8、9–32、33–64、65–192 双侧频点的分带 L2 范数。每包范数由八条 chirp 合计。换强度时保留相应复向量方向，分带行保留方向来源的直流分量。八条 chirp 的边缘 IQ 原样送入 W24。

## 权重与执行

首尾联合版使用源 U_s 的合法同条 IQ 模拟配对，从零训练 40,000 步。半量主目标版在该父版权重上匹配续训 1,800 步，将配对的全量／半量波形损失系数由 0.35／0.65 改成 0／1。本轮使用两份冻结权重，各 1,271,038 参数，无训练、校准或候选晋级。仅用源 U_s 一包跑真实权重 smoke，再重放固定的 300 包源 V。实收 IQ 生成与归档一致。直通和两条原始半量分类结果逐包匹配归档。七景预测冻结后由独立进程读取源 V 标签。

N607 GPU 3 的真实 checkpoint smoke 通过，预测进程一次显存快照为 1,286 MiB。该快照对应运行中的双模型诊断。本轮无新增训练成本，未测推理时延。r01 在 smoke 前退出，r02 记录退出码 −11，堆栈定位到对张量直转 NumPy 数组的有限值检查。r03 改为先转 Python 数值再生成等精度 float32 数组。三次运行使用独立目录，预登记的七行计算一致。前两次的状态和原始日志保留。

## 机制判断

- 保持首尾方向但换入半量主目标版总强度，六景净变 −24［95% 配对区间 −47，−1］、低城区 −15［−27，−3］。更大修正量在首尾方向上也会增加识别损伤。反向换入首尾总强度，半量主目标版相对自身六景 +1［−17，19］，低城区 −2［−10，6］。单纯缩小半量主目标版的实际修正量未恢复低城区表现。
- 两个方向各自从总强度匹配改用四带匹配，六景和低城区都仅多判对 1 次，四个配对区间均跨零。宽频带能量分配未解释这批样本的主要性能差距。所有行 clean 都是 297/300。
- 低城区中，两模型分带修正方向余弦的中位数按四带顺序为 0.966、0.993、0.992、0.987。半量主目标版 65–192 频点修正范数中位数从实收中心范数的 14.34% 增至 22.60%，9–32 仅从 6.26% 到 6.72%，1–8 从 3.61% 降至 2.52%。余弦衡量两模型彼此的一致性。此前独立的已知噪声隔离诊断给出了 9–32 kHz 方向误差的收益上界。 [幅相隔离诊断](../20261126-diagnostic-lora-w24-band-polar-source-s2026112559-r01/report.md)
