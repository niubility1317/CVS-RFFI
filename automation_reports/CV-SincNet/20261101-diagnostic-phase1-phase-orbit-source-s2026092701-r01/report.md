# Phase1 源域相位候选探针

本探针对每个输入构造 8 个固定全局相位旋转候选，使用冻结 Tri-SIG-TIME SSL 的分数选择一个真实候选波形。相位依次为 0、±π/8、±π/4、±π/2、π；旋转保持 IQ 能量，但不保证与原干净波形逐点一致。比较平均概率、类别多数票和最大单候选置信度三种预设规则，平票回退原波形。

使用固定的 512 条 Phase1 源训练物理记录（128 条 L_s、384 条 U_s）和两个源受损视图。另分别检查直接输入 clean IQ 和 clean IQ 先经过 DURA 两种口径。四组候选决策全部固定后才读取合法 L_s 标签；不读取 U_s 标签、V 或测试 IQ。两个受损视图复用相同的物理记录。

| 输入与原波形 | 原波形与 clean 教师一致 | 平均概率选择后 | 多数票选择后 | 最大置信度选择后 |
| --- | ---: | ---: | ---: | ---: |
| clean 原波形 | 512/512 | 484/512 | 467/512 | 504/512 |
| clean 经 DURA | 512/512 | 482/512 | 470/512 | 503/512 |
| 源视图 1 经 DURA | 491/512 | 446/512 | 437/512 | 460/512 |
| 源视图 20 经 DURA | 492/512 | 456/512 | 447/512 | 478/512 |

三种固定规则在这批源记录上均损伤部分原判断，且 clean 经 DURA 的完整管线也出现损伤，因此不将这些规则用于正式测试。选择非零相位并不一定改变类别：例如 clean 经 DURA 的最大置信度规则旋转 33 条，其中 9 条改变分类。128 条有标签 L_s 的准确计数与 BLOCKED 子集结果见 [result.json](result.json)。

这些记录属于训练集，结果不是独立测试；与 clean 教师一致也不等于 TX 准确率。完整固定相位集合和选择规则只支持上述探针结论，不能排除其他相位方法。源码提交为 `c4e1600cbc91dbabc4afd48730a99fc8b754d1b6`；重新运行 [probe.py](probe.py) 得到逐项相同的记录。
