# SatIQ 第 5 轮普通原型与 SCALR 式局部岭对照

[登记](experiment.json) · [事件](events.jsonl) · [SCALR 原方法说明](../../../docs/PAMF_PHASE2_SCALR_20261102.md)

## 改动与控制

从普通原型不能利用近邻类别内的局部差异入手。冻结相同的三个第 5 轮编码器，沿用同一 K16 注册包和查询包。每个注册波束用支持包的原型找到 3 个最近的其他注册波束。在这 4 个波束共 64 个支持包内拟合核岭。沿用 SCALR 的支持集条件留一选择，比较单尺度及多尺度 RBF 与岭惩罚 0.01、0.1、1。先比较支持集留一准确率，再比较平方误差，平手选更大惩罚。邻域和带宽由完整支持集决定，留一结果用于选参。查询包没有参与拟合，每个查询收到全部注册波束分数。本轮实现借用两个机制，沿用 SatIQ 的原有输入和冻结表示。

同一物理查询比较两种读出。随机面板 1,375 个注册波束和 12,785 个查询，跨日面板为 309 个波束和 4,865 个查询。白化只以共同抽样的 8,192 个源 L 包为每模型分别拟合。报告 JSON 保留跨星与同星 AUC、EER、命中数和支持选择分布。
