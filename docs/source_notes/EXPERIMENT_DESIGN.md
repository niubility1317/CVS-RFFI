## 二、实验设置（共用）

### 2.1 数据集：WiSig

| 属性 | 值 |
|------|-----|
| 发射设备 | 16 类 IoT 设备 |
| 接收机 | 12 台（训练 0-6，测试 7-11） |
| 采集日期 | 4 天（训练 day 0-1，测试 day 2-3） |
| 采样率 | 25 Msps |
| 样本长度 | 256 IQ 采样点 |
| 训练数据量 | 16,800 样本（20% 可用数据） |
| 测试数据量 | 204,000 样本 |

### 2.2 域划分协议

```
训练域: rx 0-6 × day 0-1（共 14 个域）
测试子集:
  - UDS (仅跨日期): day 2-3 × rx 0-6, 84,000 样本
  - SDU (仅跨接收机): day 0-1 × rx 7-11, 60,000 样本
  - UDU (严格跨天跨接收机): day 2-3 × rx 7-11, 60,000 样本
  - Overall: 全部测试集, 204,000 样本
```

### 2.3 评估指标

**主指标：** 综合 OOD 分数

$$\text{OOD} = (1 - w) \cdot \text{Overall} + w \cdot \text{UDU}, \quad w = 0.65$$

**辅助指标：**
- 各测试子集准确率（UDS / SDU / UDU / Overall）
- 最坏接收机准确率（worst-rx acc）
- 各卫星场景 UDU 准确率

### 2.4 卫星信道评估场景

|------|------|------|----------|------|--------|------|

| Low-Elev-LEO | LEO | 10-30° | 15-28 | 阴 | 高 | 弱 |

## 三、对比实验（Experiment 1: Comparison）

### 3.1 对比方法总表

| 方法 | 类型 | 骨干网络 | 核心机制 | 参数量 |
|------|------|----------|----------|--------|
| **ERM** | 基线 | CV-SincNet | 标准交叉熵训练 | ~1.05M |
| **DANN** [Ganin 2016] | 域对抗 | CV-SincNet | 梯度反转 + 域判别器 | ~1.05M |
| **MixStyle** [Zhou 2021] | 特征增强 | CV-SincNet | 特征统计混合 | ~1.05M |
| **Fishr** [Cha 2022] | 梯度正则 | CV-SincNet | 梯度协方差匹配 | ~1.05M |
| **GroupDRO** [Sagawa 2020] | 最坏域优化 | CV-SincNet | 域重加权 | ~1.05M |
| **SupCon** [Khosla 2020] | 对比学习 | CV-SincNet | 监督对比损失 | ~1.05M |
| **CVCNN** | 控制基线 | 复值 CNN | 纯复值卷积 | ~0.5M |
| **TIFS 2025** [Chen 2025] | 论文复现 | ResNet2D | 频谱图 + NT-Xent + Siamese | ~2.1M |
| **RIEI** [Wang 2024] | 论文复现 | ResNet1D | 发射/接收特征解耦 + MI | ~1.8M |
| **DRIFT** [Jiang 2024] | 论文复现 | ResNet1D | GRL + 中心正则 + 负MSE | ~1.5M |
| **CVS-RFFI (本文)** | 完整方法 | Dual CV-SincNet | 双骨干解耦 + 多分支 + 卫星一致性 | 1.05M |

| C-A05 | GroupDRO (Smooth) | τ=0.45, momentum=0.95 | 最坏域重加权 |
| C-A06 | SupCon | temp=0.07 | 监督对比学习 |

|---------|------|------|------|
| C-B01 | CVCNN | 复值 CNN | 控制基线 |

### 3.3 预期结果表（论文 Table I）

| 方法 | 参数量 | Overall (%) | UDU (%) | UDS (%) | SDU (%) | OOD 分数 |
|------|--------|-------------|---------|---------|---------|----------|
| CVCNN | ~0.5M | 84.54 | 75.14 | 95.12 | 79.14 | 78.21 |

### 3.4 分析要点

1. **同骨干对比（Group A）**：CVS-RFFI 相比最强同骨干基线 GroupDRO，Overall +5pp，UDU +8pp，验证了多分支物理感知特征提取和双骨干解耦的有效性。

2. **跨论文对比（Group B）**：CVS-RFFI 以 1.05M 参数量超越 TIFS 2025（2.1M）和 RIEI（1.8M），说明物理感知架构设计优于简单增大模型容量。

3. **UDU 性能差距**：CVS-RFFI 在最严格的 UDU 指标上比所有基线高出 8-20pp，表明其对双重域偏移的鲁棒性。

4. **卫星一致性训练的代价**：完整版在地面性能上仅有微小下降（Overall -0.16pp, UDU -0.57pp），但获得了显著的卫星信道鲁棒性。

### 4.3 单信道畸变消融

逐一施加单个信道畸变因子，定位性能瓶颈：

| 实验 ID | 畸变因子 | 参数范围 | 目的 |
|---------|----------|----------|------|
| S-SW01 | 仅 AWGN | SNR 5-30 dB | 噪声鲁棒性基线 |
| S-SW02 | 仅 CFO | σ=100-1000 Hz | 载波频偏敏感性 |
| S-SW03 | 仅相位噪声 | 线宽 10²-10⁵ Hz | 相位噪声敏感性 |
| S-SW04 | 仅多径 | 2-6 tap, τ_max=1-10 样本 | 多径敏感性 |

### 4.4 分析要点

1. 卫星一致性训练在 Storm-MP（最恶劣场景）上提升最大（+3-5pp），验证了一致性约束对严重畸变的鲁棒性。
2. Clear-LEO 和 Low-Elev 表现最好，因为信道畸变相对温和。
3. 所有场景均显著高于随机猜测（16.7%），证明模型捕获了对信道畸变不变的设备指纹。

## 五、消融实验（Experiment 3: Ablation）

### 5.1 组件消融（Component Ablation）

逐一移除各域泛化组件，评估其对 UDU 和卫星性能的贡献。

| 实验 ID | 移除组件 | 配置变化 | 预期 UDU 变化 |
|---------|----------|----------|--------------|
| A-C01 | 无 MixStyle | `--no_use_mixstyle` | -3.1 pp |
| A-C02 | 无正交损失 | `--lambda_ortho 0` | -3.2 pp |
| A-C03 | 无对抗域不变损失 | `--lambda_adv 0` | -2.4 pp |
| A-C04 | 无域感知对比损失 | `--lambda_domain_con 0` | -1.6 pp |
| A-C05 | 无 GroupDRO | `--group_ce_mode none` | -1.8 pp |
| A-C06 | 无卫星一致性训练 | `--use_sat_consistency 0` | +0.57 (地面) / -4.2 (卫星) |
| A-C07 | 单骨干（无解耦） | 移除域骨干 | -4.5 pp |

#### 组件消融结果表（论文 Table III）

| 移除组件 | Overall 变化 (pp) | UDU 变化 (pp) | 卫星平均变化 (pp) |
|----------|-------------------|---------------|-------------------|
| MixStyle | -2.5 | -3.1 | -1.2 |
| 正交损失 | -1.8 | -3.2 | -0.8 |
| 对抗域不变损失 (GRL) | -1.5 | -2.4 | -0.5 |
| 域感知对比损失 | -0.9 | -1.6 | -0.3 |
| GroupDRO | -1.2 | -1.8 | -0.4 |
| 卫星一致性训练 | +0.16 | +0.57 | -4.2 |
| 双骨干解耦（单骨干） | -3.1 | -4.5 | -1.5 |

#### 分析要点

- **正交损失**和**双骨干解耦**对 UDU 贡献最大（-3.2pp 和 -4.5pp），验证了显式特征解耦的关键作用。
- **MixStyle** 贡献显著（UDU -3.1pp），特征级域随机化有效扩展源域覆盖。
- **卫星一致性训练**是唯一对卫星性能有显著正向贡献的组件（+4.2pp），但以轻微地面性能下降为代价（trade-off）。

## 六、特征可视化与分析（Experiment 4: Feature Analysis）

### 6.1 UMAP 可视化

| 实验 ID | 可视化内容 | 着色方式 | 目的 |
|---------|-----------|----------|------|
| V-01 | z_id（身份特征） | 按发射机着色 | 验证设备聚类 |
| V-02 | z_id（身份特征） | 按域（rx_day）着色 | 验证域不变性 |
| V-03 | z_dom（域特征） | 按域着色 | 验证域聚类 |
| V-04 | z_dom（域特征） | 按发射机着色 | 验证身份无关性 |
| V-05 | z_id（无正交损失） | 按发射机着色 | 对比：未解耦 |
| V-06 | z_id（无正交损失） | 按域着色 | 对比：域泄漏 |
| V-07 | z_id（卫星畸变后） | 按场景着色 | 卫星信道对特征的影响 |

### 6.2 特征空间定量分析

| 实验 ID | 分析指标 | 目的 |
|---------|----------|------|
| V-Q01 | 域内方差 / 类间方差比 | 特征紧凑度 |
| V-Q02 | z_id ↔ 域标签互信息 | 域信息泄漏程度 |
| V-Q03 | z_dom ↔ 发射机标签互信息 | 身份信息泄漏程度 |
| V-Q04 | 正交损失前后 cos(z_id, z_dom) | 解耦效果 |
| V-Q05 | 最近邻域精度 (NN-domain acc) | 域可分性 |

### 6.3 分析要点

- z_id 按发射机着色时形成清晰聚类，且跨域样本混合良好 → 身份特征具有域不变性。
- z_dom 按域着色时形成清晰聚类，且跨发射机样本混合良好 → 域特征与身份解耦。
- 无正交损失时，z_id 中存在明显域聚类结构（同一发射机在不同域下形成分离子聚类）。
