# 频点内可学习时间关系：下一轮Phase1结构

## 目标与约束

目标仍为仅靠神经网络架构，提高身份识别和跨接收条件稳定性，使Phase1工作有足够论文证据。沿用原单TX交叉熵、源L/V物理划分、四模型seed、E200、原优化器和精度，从零训练；不加入增强、额外损失、teacher、预训练、目标适应或测试反馈。参数成本为次要指标。当前设计是待验证候选，不是已经成立的创新或性能结论。

## 源证据与取舍

[全主干前置滤波诊断](../automation_reports/CV-SincNet/20261003-diagnostic-cvs-frontfilter-attribution-source-manysig-m8-r01/report.md)已完成：动态系数改为L均值，仅改变108000次决策中的23次，净少对5次；全开净贡献0.00463个百分点。移除整个滤波导致较大下降，但正式从零训练对照仍未获益。因此不继续无依据地扩大滤波幅度或系数网络。

本轮采用直接构造包内相对关系的网络层，不再依赖CE自发学出有意义的逐包滤波参数。候选路线还包括逐时刻条件卷积、全通道白化：前者难以对应当前包内近静态信道，后者容易消除身份相关的通道能量且引入协方差病态，暂不采用。所选路线的代价是STFT有限窗近似，以及可能同时消除发射机线性响应。因此保留原RFF物理主干与绝对响应路径，只在原频率特征进入融合前加入关系分支，明确不宣称整网信道不变。

## 数学算子

输入为原契约IQ，形状B×2×256。使用长度64的周期Hann窗、hop32、无中心补零，得到7个时间窗。每窗执行复数64点FFT并fftshift，除以窗L2范数，得到S，形状B×64×7。它是网络内部确定性前向，不改变数据表示、训练集、损失或样本数量。

对全部频点共享一个无偏置复数线性层A∈C^(4×7)，得到v_f=A S_f。A以复fan-in随机初始化。频点不混合，因而在理想模型S'_f=h_f S_f下有v'_f=h_f v_f。

逐频候选的关系矩阵为：

\[
 Q_f={v_fv_f^H\over\max(\|v_f\|_2^2,\overline E/64,10^{-6})},\qquad
 \overline E={1\over64}\sum_f\|v_f\|_2^2.
\]

矩阵以实部、虚部展开为32个通道，保留64个频点；次序为real的4×4然后imag的4×4，乘积约定v_i conj(v_j)。理想频点在变换前后均由自身能量决定分母时，对非零复数h_f严格不变。Q半正定、Hermitian、秩至多1，trace≤1、Frobenius范数≤1。使用相对下限的频点不具有任意逐频幅度不变性；实数配对乘法和分母下限保证零输入前向及梯度有限。

配对控制使用同一v和分子，仅将分母的自身能量替换为该包64个频点能量的均值；同样执行相对及绝对下限，相对下限在该控制中不会改变分母。同样抵消每频点恒定相位，但保留频点间幅度比例；只对整个包共同复增益在绝对floor以上不变。其单频trace不超过64，而不是1。两个模型参数、初始化、训练预算和卷积接线完全相同，差别仅在分母的聚合范围。

关系编码器为Conv1d(32,32,k3,pad1)→GELU→Conv1d(32,32,k3,pad1)→GELU→AdaptiveAvgPool1d(4)→flatten128→无偏置Linear128到160。最后投影为零，新增随机初始化隔离，不扰动原scratch Shallow的参数和后续RNG。关系特征加到原frequency160维特征后，再进入原融合、160维表征和分类头。原time、behavior、频域CNN及统计路径完整保留，无新增Dropout/BatchNorm/跨包状态。

候选名称为`relation_packet_energy`与`relation_frequency_energy`。每个新增26744个参数：复A为56，两层卷积各3104，最终投影20480；总参数预计247731，必须以实例统计验证。初始完整函数与同seed scratch Shallow一致。

## 性质及反例

严格不变性只描述上述理想频点乘法作用下的关系分支，并非任意有限窗口时域FIR、整网或非线性RX。STFT与有限长线性卷积不精确满足逐频相乘，需要公开合成信号上的误差曲线和反例。持续深衰落与噪声会降低可辨别信息，不靠商表示恢复丢失的信息。

任意TX线性频响也可被同样消除：若两个设备仅相差可逆LTI响应，商分支无法保证区分。原绝对路径保留这些信息，但因此整网不具有该不变性。共享A不等于识别了真实信道，也不保证分支最终被CE使用；完整源诊断要记录出口增量、梯度、floor比例及各频点统计。高源V不能替代未见接收机泛化。

## 相关工作与可声称范围

[Brown等，ChaRRNets，2021](https://arxiv.org/pdf/2105.03568)已在短时频谱上构建频点增益等变/不变网络层，并讨论有限窗卷积边界。其层采用流形均值和距离，不能把频域信道不变的想法归为本项目首创。本轮检验复线性时间混合后的Hermitian关系、稳定能量分母及与RFF物理主干的结合；这只是明确的结构差异，仍需结果和充分消融证明贡献。该论文实验使用AWGN/CFO等增强，本轮不继承这些训练机制。

[Mohammad等，VTC2023-Fall](https://www.ieeevtc.org/vtc2023fall/DATA/2023003172.pdf)研究幅相谱图用于RFF；本轮仅核实其摘要，不将通用谱图或幅相信息声称为新颖。暂不主张完整先例检索已完成。

## 实现与验证顺序

1. 独立新模块实现两候选，原模型和已完成实验代码保持原状；验证复乘方向、STFT窗口与FFT轴、参数量、实际接线、初始同函数及RNG、严格分支性质和whole-model反例、零输入梯度、CE实际更新及state往返。
2. 在公开/随机tensor上完成几步原CE，记录实际出口变化和各组件梯度、计算成本；不读取任何真实样本或历史target评分来筛选候选。
3. 接入既有源训练、详细日志与固定E200选模入口，建立8行新run和唯一launch owner。两候选四seed与Shallow及Anchor固定源对照比较，按原性能优先规则冻结。
4. 本地验证、唯一独立P0/P1审查、Git发布与N607单次启动；训练时不热改。冻结后仅对预登记选中候选执行clean测试，独立truth-last；若仍选旧控制，仅核验其既有冻结测试。所有负结果保留，不追加LEO。

## 首轮公开检查及训练前修正

最初仅使用绝对1e-6下限。8个模型的24步公开CE和理想增益检查通过，但有限FIR检查显示逐频关系在delay8/16下的平均相对变化为0.9720/1.0641，整包控制为0.1104/0.1134。它们是合成敏感性而非分类性能；不能用理想域的约2e-7误差掩盖有限窗下的大幅变化。

原公开artifact保留。正式训练前将分母加入固定的包内平均频点能量1/64下限，以抑制极弱谱分量的单位范数放大；不搜索该比例，不读取源或目标数据选择它。强频点性质与弱频点稳定性分别检查，不再声称全部非零频点任意增益不变。修正后的公开FIR实测另行保存，不覆盖首轮证据；若敏感性仍大也如实报告，不能推断物理信道已消除。
