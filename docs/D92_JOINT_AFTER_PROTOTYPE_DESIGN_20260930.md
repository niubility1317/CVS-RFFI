## 3. 冻结表征公式

仍以当前原 b0∈R²⁵⁶、a0∈R⁴⁸⁰ 切成五块 r_l，维数为 160/96/160/160/160。原权重、缩放和 floor 已包含其中。对每块计算 `ρ_l=||r_l||`；非零块 `w_l=r_l/ρ_l`，零块 w_l=0。固定输入为

`x=(w_1,…,w_5)/sqrt(5) ∈ R⁷³⁶`，因此 `||x||≤1`。

唯一可训练参数为 `U∈R^(736×8)`、`V∈R^(8×736)`，共 **11776 个 float64 参数**。没有每类可学习向量或 logits。固定 rank=8，不扫描 rank。定义

`h=GELU(Vx)`，`v=Uh`，GELU 使用 exact-erf 形式；

`t_l=(I−w_l w_lᵀ)v_l`；

`δ_l=κ t_l/sqrt(κ²+||t_l||²)`，`κ=0.25`；

`r'_l=ρ_l (w_l+δ_l)/||w_l+δ_l||`。

零原块直接保持精确零。t 与 w 正交，`||δ_l||<κ`，故分母在数学上至少为 1；块范数保持 ρ_l，最大转角不超过 `atan(0.25)`。角度有限并不代表新旧类分离改善。它允许每个输出坐标由八个学习的非线性跨分支通道决定，表达空间明显不同于五个 β 加四个 η；仍受 rank、角度和原 encoder 信息的限制。

参数域固定为 `||U||_F≤1`、`||V−V0||_F≤1`，分别以径向投影实现。V0 是 736 维 DCT 的前八个正交行：第 0 行 `1/sqrt(736)`；第 j>0 行的第 k 项为 `sqrt(2/736) cos[πj(k+0.5)/736]`。V0 不依赖任何 target 类或统计量。

### 活初始化和反向

B 从 U=0、V=V0 开始。U=0 时前向直接返回原 b0/a0 的实际 bits，仍建立 h、切向投影与导数缓存。饱和残差在 t=0 的导数为恒等；对非零块 `∂r'/∂U` 一般非零，V 首步数据梯度为零，U 更新后 V 才一般可训练。不能仅因为初始输出恒等就跳过 adapter 反向。

输出伴随先经过单位化的 `ρ/||w+δ||·(I−yyᵀ)`，再经过

`κ/sqrt(κ²+||t||²)·[I−ttᵀ/(κ²+||t||²)]`，

以及切向投影。汇总后 `bar_U=Σ bar_v hᵀ`，`bar_V=Σ[(Uᵀbar_v)⊙GELU'(Vx)]xᵀ`。原 w、ρ、x 是固定缓存，不求导。零块/全部零输入、单类或真实零数据梯度如实报告，不宣称每个参数必须活跃。

训练、teacher 与 score 都使用同一逐样本乘加归约；不能再用训练 GEMM、评分 GEMV 的不同累加路线。teacher 和 query 均不改变 normalization 或任何持久状态。

## 4. 最终头与折隔离

拼接 r' 得 bθ/aθ，定义 `φθ=(bθ,aθ,bθ⊗aθ)`。唯一最终距离为

`d²=.5 d_original²+.5 d_adapted²`。

使用当前稳定 rank-2 差分引擎，不显式存储 123616 维 φ。Gaussian 带宽为本头当前联合距离的最近异类中位数，含零；中心迹匹配到本头 train 原始 interaction 的 s0，物理和 ridge 系数为 1。原项/s0 不求导，适配距离的 VJP 乘 0.5，带宽/中心化/迹缩放/ridge 伴随完整保留。

原输入相等必须映射相等；原输入不等而适配分量相等合法。联合距离仍满足 `.5 d_original²` 下界，因此原 tau0=0 的等价核及零导数可复用，依据不是 adapter 全局可逆。正带宽未分辨、下溢、非有限、切向/范数残差或头残差异常保留状态后报技术失败，不静默改核或加 epsilon。

沿用每类物理 ID 排序、模 min(k,3) 的内折。每个内头的头统计只来自自身 inner-train；内持出特征只用于自身前向，标签参与本设计的监督损失。全部内折标签都会训练共享 U/V，因此内层不是独立验证。outer-held 始终只评分；不为候选选择使用 query。

## 5. 冻结教师与旧类 margin 训练约束

“旧类”在此是合法 support 注册表中前一阶段的类别，不是 query 的真实角色。全部既有类别使用同一公式；标签置换同时携带其阶段身份，不能按具体 TX/class ID 设特殊系数。

- B：每折教师是该折旧 inner-train 的原 R0 LocalRidge，可直接保存首次 U=0 前向的教师分数。
- C_seq：每折教师使用冻结的 U_B/V_B，只在对应旧 inner-train 上拟合旧类 LocalRidge，再对对应旧 inner-held 前向。禁止使用 B 完整旧头替代这个折内教师。B 参数本身已经接受合法旧 support 监督，这是明确的顺序训练，不把教师分数称为无偏验证。

教师只产生训练常量，不参与最终分类。对有至少两个教师类别的旧 support i，令

`m_i^T=S^T_i,y_i−max_(j≠y_i,教师旧类) S^T_i,j`，

`q_i=clip(m_i^T,0,1)`。

教师错误时 q=0，目标是停止负 margin，而非保存错误类别；教师很大 margin 截到 1，避免极少数过置信样本占据尺度。对当前头的每个注册 support，当前 margin 是

`m_i(θ)=S_i,y_i−max_(j≠y_i,全部当前注册类) S_i,j`。

旧类保持直接面对新类竞争，不只比较旧类列。所有错类 max 并列取对称平均广义导数，教师 q 不反传。

先跨所有内折累计每类任务风险

`ℓ_c=Σ_(i:y_i=c) [1−m_i]_+²/(2n_c)`，

`R_task=sqrt(mean_(全部注册类 c) ℓ_c²)`。

对既有类累计

`e_c=Σ_(i:y_i=c) [q_i−m_i]_+²/(2n_c)`，

`R_keep=sqrt(mean_(既有类 c) e_c²)`。

训练总目标冻结为

`L=R_task+R_keep+(||U−U_anchor||_F²+||V−V_anchor||_F²)/(2N)`。

任务和保持系数均为 1，两者采用同一 unit-margin 半平方风险尺度；近端 N 是本阶段全部 outer-train 物理样本数。B anchor 为 (0,V0)，C_seq anchor 为本 row 的 (U_B,V_B)。不根据 Nnew、query 比例或成绩调权。C 的新类只有共同任务风险；前一阶段身份允许有保持目标，但最终 logits/温度/阈值不因身份改变。

### 一次固定的物理样本松弛

若 B 教师的所有 inner-held 都正确，`R_keep(anchor)` 可能严格为 0，保持梯度也为 0。无松弛的 `R_keep(trial)≤0` 会要求所有受保护正 margin 不下降，有限试探可能全部拒绝。教师存在错误时 anchor 风险可为正，这是不同条件，不能将所有 B 说成零风险。

本候选固定

`R_limit=R_keep(anchor)+ε_keep`，

`ε_keep=1/(2k sqrt(C_prev))=sqrt(C_prev)/(2N_prev)`。

当前平衡矩阵中，k 是每个既有类的 outer-train 物理记录数，`N_prev=C_prev·k`；每条记录在内持出累计中恰好出现一次。这个量来自“一条旧物理 support 出现 unit margin deficit=1”对类 RMS 的量级：该类 e 增加 `1/(2k)`，RMS 量级为 `1/(2k sqrt(C_prev))`。它是一次预设的训练误差尺度，不来自≤1 pp理想目标，不扫描倍数。

它不表示最多能错一条：风险可以分散到许多低 margin 样本，并改变多条预测。低 k 松弛更大，高 k 更紧；教师初始风险非零时上限是在该基准上相加。所有教师正确、anchor 风险/梯度为零时，正松弛允许有界的二阶改变，不再强制每条教师 margin 不降。有限试探仍可能全部拒绝，不能承诺必然更新。

若教师只有一个类别，错类 margin 不存在，保持项/约束整个记为不可用并关闭；不伪造 q。当前主矩阵既有类为 6，此边界用于实现正确性。

## 6. 固定的有限受约束优化

仍是四次迭代，每次最多三次 t0、t0/2、t0/4，`t0=1/8`，没有延长步数或调整旧学习率。每次复用当前已接受前向缓存，得到总梯度 g 及保持梯度 a=`∇R_keep`。

1. g=0 时记录 ZERO_GRADIENT；否则 `d0=−g/||g||`。
2. 令 `b=max(0,R_limit−R_keep(current))/t0`。a=0 或 `aᵀd0≤b` 时 d=d0；否则 `d=d0−a(aᵀd0−b)/||a||²`。这将已归一化方向投影到当前保持预算的线性半空间，投影后不再次归一化；d 的范数不超过 1。它只预测一阶风险，不能替代真实 trial 检查。d=0 时记录 ZERO_GUARDED_DIRECTION。
3. `θ_trial=Π_product_balls(θ+t d)`。两项 Frobenius 球分别投影，得到实际位移 Δ。Δ=0 时记录 ZERO_PROJECTED_STEP。
4. 接受同时要求：`L_trial≤min(L_current,L_current+1e−4 gᵀΔ)+tol_L`，以及 `R_keep_trial≤R_limit+tol_keep`。两个容差都是 `128*eps64*max(1,各自比较量的绝对值)`。独立数学审查给出了`gᵀd<0`但球投影后`gᵀΔ>0`的反例；单独Armijo可能允许总目标微升。因此增加实际总目标非增检查，不改变参数、试探次数或数据。这保证接受状态总目标在声明浮点容差内非增，不保证收敛或外层性能。真实保持检查仍必须执行。
5. 只有接受后才替换 θ/current cache。三次均拒绝时记录 ARMIJO_OR_KEEP_BUDGET_EXHAUSTED，保留已接受状态并结束；不加步、择最好外层步或选择性重跑。最后接受缓存直接提供最终目标，全 support 头另拟合一次。

保持约束是候选内部的训练定义，不是数据权限、实验审批或每轮性能门禁。它控制内层保持风险相对阶段起点的增量，并不保证 support OOF 或 query 旧类下降≤1 pp。尤其 C 的 anchor 联合头已经受新类注册竞争影响，守住这个训练上限不等于自动恢复 B 的完整旧类准确率；R_keep 目标才试图恢复教师 margin。

g 和 a 分别需要一套 score 伴随；每折复用同一 Cholesky，执行两套反向，不按11776个参数重拟合。以明确的两套三角求解计费，不通过拼 RHS 少报工作量。保持链与任务链可共享缓存和稳定距离中间量，但时间/内存按实际实现计。

## 7. B→C、K1 和对照

新候选 B 从零 U/DCT V 训练，不用本轮 PrototypeTransport 的九自由度状态热初始化。B 交付不可变 U_B/V_B、原旧 support ID/标签/raw 绑定和旧最终头。C_seq 核对同 row、同旧物理 support 后复制参数为初始化和近端 anchor，追加合法新 support，拟合全部注册类头；不会修改 B 对象。

所有 C 内教师/内头分别使用对应 inner-train。冻结的 θ_B 通过此前合法监督包含旧 support 信息，必须如实保留这一继承说明。没有源样本、逐样本源 feature 或 query 进入拟合；地面原型/聚合摘要不是本候选输入，也没有尚待 export 的隐藏依赖。

物理 k=1 不产生独立内持出监督：B 保持 (0,V0)，C 保持合法 anchor；本平衡 K1 矩阵仍精确 R0。single-class B 同样不适配。true K1 只做数值诊断；proxy trainK1 不构成新 K1 收益。Nnew=0 直接复用 B，不构建 C 教师或额外拟合。

预声明三路径为 R0、R_MC_seq、R_MC_reset_init。seq 是主候选；reset_init 把 C 参数初始化/近端 anchor 设为 (0,V0)，教师及其物理绑定仍来自同一合法 B，保持松弛按其自身 C 起点计算。该策略对照同时改变初始点、近端锚点及由阶段起点定义的保持上限，差异不能单独归因于初始化，也不应称为“完全删除所有 B 信息”的对照。对照不授予择优切换主候选的权限。
