# CVS 性能优先研发：包内有界注意力统计池化

本轮研究依据是合法源域曲线和实际网络接口。32 行初始源实验表明，固定时域平均池化可完成源训练，第一/二阶统计的源性能变化较小，未证明固定聚合已充分保留身份信息。原 time/frequency/PA 最后均采用全局平均池化，所有位置同权。研发不读取或分析目标预测、误判、RX/TX 分层或目标指标来设定候选、系数和源选择规则；当前已公开目标成绩仍由独立确认报告保留。

## 数学与优化路径

特征图为单个包的 `X∈R^(C×T)`。只为注意力评分计算包内标准化 `Z=(X-mean_t(X))/sqrt(var_t(X)+1e-5)`；原值 X 不作标准化后再聚合。令 `s_t=tanh(aᵀZ_t)`、`w_t=softmax_t(s_t)`、`μ=sum_t(w_t X_t)`。w 为正、和为 1，任意权重比不超过 exp(2)，避免硬选择少数位置。a 初始化 0，故初始精确退化为平均池化，唯一 CE 可直接更新 a。对评分的导数有 `∂μ/∂s_t=w_t(X_t-μ)`，可为区别于当前包均值的位置提供学习信号。标准化只决定位置权重，不能被称作信道估计、白化或接收机分离。

`attentive_mean` 仅输出 μ。`attentive_moments` 输出 `μ+tanh(g)⊙sqrt(sum_t(w_t(X_t-μ)^2)+1e-6)`，g 初始化 0。两个统计被合成回原 C 维，投影宽度、提取器深度/宽度、dropout、原稠密 time/frequency 融合和 PA 残差余弦头均保留。参数只增加 a（192）或 a/g（384），性能改善须来自聚合形式，而非堆积层数或扩大通道。它与经典 ASP 的均值/标准差拼接投影不同，不能称作完整复现。

注意力统计池化的原始研究用于说话人嵌入，利用时间加权均值和标准差；这里借鉴统计聚合思想，射频指纹效用是待测假设，不迁移论文性能数字。[Okabe、Koshinaka 与 Shinoda，Attentive Statistics Pooling for Deep Speaker Embedding](https://arxiv.org/abs/1803.10963)。


### 零初始化为何仍能学习

在 a=0 时，Z 每通道的时间均值为 0，tanh 导数为 1。固定特征图对注意力参数求偏导，可得 `∂μ_c/∂a_j=mean_t((X_ct-mean_t(X_c))*Z_jt)`，即原特征和标准化特征之间的包内协方差。新增参数即使初始输出退化到平均池化，也可在第一次 CE 更新时收到非零梯度；若该包某通道完全恒定，则对应协方差为 0，不作普遍非零保证。波动分支在 g=0 时的增益偏导为该通道的加权标准差，其他通道的增益偏导为 0。

这一解析式针对固定 X 的参数偏导，完整训练还会经过上游卷积和标准化的链式梯度。用当前实现进行合成 float64 自动求导核对，两个 Jacobian 均与解析式在 1e-12 容差内一致。它只验证数学实现，不证明射频指纹或测试性能提升，也不改变训练、源选模或测试权限。

## 通信原理

同一包不同时间片可能具有不同符号状态、包络与局部信噪比，均匀平均并不保证每个位置携带相同身份信息。时域/PA 池化对时间位置评分，频域池化对已学习频谱特征位置评分；它们不增加接收节点、独立样本或训练标签。单包特征池化对该轴的重排对称，但上游卷积有顺序与边界依赖，因此整个 IQ 网络不是任意重排或时间平移不变。没有强制 IQ 全局相位不变，也没有 CFO 消除或接收机补偿。注意力仍可能突出接收机/信道特征，不能保证泛化。

## 物理原理

可用简化观察模型理解候选：接收信号包含信道作用下的 I/Q 非理想性、PA 多项式及记忆响应，另有接收机响应与噪声。不同局部包络会激发不同非线性响应；平均值可能掩盖局部强弱，波动量为局部响应分布提供补充。这里只保留现有 Sinc 滤波、记忆多项式、包络门和 PA 统计，不声称从有限接收 IQ 唯一识别发射机物理系数。注意力系数是网络坐标中的学习参数，不能解释成硬件失真系数。原始复数相位与 PA 路径保持现有形式，避免以未经验证的相位消除丢弃指纹。

## 射频指纹原理与声明边界

身份信息可能分布于不同滤波特征的局部响应和波动。两个候选在同类共享、同包独立的公式下用 CE 学习聚合，假设可减少全局平均造成的信息压缩。波动项是可退化的补充，不能依据源性能先宣称它有效；均值与波动的区别在本轮两架构中比较。保留三分支与分类器，能使比较聚焦池化，但训练梯度会同时改变上游特征，结果不能被解释为只改变推理权重的因果效应。
