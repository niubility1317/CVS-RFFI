## 数学与信息边界

- 两个参数在非负和不超过 1 的可行域内，且归一化谱 λ 位于 [0,1]，所以 `gθ(λ)=λ(θ0+θ1λ)/(1+λ)` 位于 [0,1/2]。Wθ 保持正定，完整 interaction 距离中的新样本正交分量必须保留。重复特征值共享同一谱函数，算子不依赖该重根空间内选择的坐标轴。
- θ=0 时前向严格复用原 LocalRidge，与梯度是否为零是两件事。距离导数使用未乘 θ 的 `λ/(1+λ)` 和 `λ²/(1+λ)` 权重；不能因 identity 快捷路径而跳过数据导数。θ=(1,0) 是固定 WithinClassMetric 的解释性消融。
- 对 `A=(K+I)^−1Y`，`dA=−(K+I)^−1(dK)A`、`dS=dKcross·A+Kcross·dA` 正确。原 s0 固定，tau、径向中心迹、gamma 和交叉核的训练中心化必须按设计参与链式求导；tau=0 的等价关系在正定 W 下固定，采用零核导数自洽。
- 总目标是所有 inner-held 物理样本的平方误差和加一次参数近端项，再除以 2N。近端梯度为 `(θ−anchor)/N`，不按内折重复添加，也不等权平均不等大小折。固定 8 次投影梯度更新，不按 outer-held 或内层最好步挑状态。
- 每个内折独立用旧 inner-train 构建谱几何，用全部注册 inner-train 拟合闭式头。共享 θ 接受 inner-held 标签监督属于本方法的 SFT 训练；这个训练损失不是独立验证。outer-held 特征和标签完全不参与该过程。
- C 继承的是 B 参数作为初始值与近端锚点，以及最终头使用的完整旧训练几何。C 内折必须重新估计折内几何，不能借用 B 完整几何。C 最终谱权重可变，W 和旧分数均可能变；不能写成冻结整个 B adapter。继承需核对同一旧物理 ID、标签和特征。Nnew0 直接复用 B。
- 真实 K1 不拟合、不评分；proxy trainK1 精确回退原方法。outer-train K2 的 inner-train K1 无可辨数据梯度，不造空更新作为有效微调。没有原地面 A 时保持 N/A，B0 不能冒充 A。

## 非光滑导数的验证口径

最小值和中位数 tie 使用固定的对称分支平均，是算法指定的广义梯度约定，通常不等于某个单侧方向导数。例如 `min(t,−t)` 在 0 的分支梯度平均为 0，而沿任一非零方向的右方向导数为负。不能要求前者直接匹配单侧有限差分，再通过放宽容差使其“通过”。

无 tie 的小问题应验证整个核、闭式解与目标的通常有限差分；tie 点分别验证声明的分支平均、类别/行置换对称性及真实单侧方向行为，并明确这些量不同。对称广义梯度没有保证每一步是严格下降方向，设计允许零更新且保留实际轨迹，不得据此虚构收敛或延长预算。此注意已发送核心作者，尚未发现具体实现缺陷。

## 入口与汇总接续结论

已静态核对 `tools/evaluate_d92_joint_spectral_probe.py`、`tools/summarize_d92_joint_spectral_probe.py` 及对应合成测试。本节仅补接入范围，不重复上述核心数学或原组件审阅。

- 每个 OOF/proxy path 先固定外层 train/held，再分别拟合 B0 旧类头与 C0 全注册头。B/C preparation 只接收各自外层 train；summary 从物理 ID 重建 inner fold，核对 inner geometry 仅含 inner-train 的旧类，且与外层 held 不相交。最终状态固定后才对 held 打分与诊断。
- B_joint 与 B_fixed 共享 B preparation；C_joint、C_reset、C_fixed 共享 C preparation。C 的完整旧几何来自同一 B_joint，旧物理 ID、类映射和特征绑定由核心检查；C 内折重新构建几何。R_reset 复用 R_joint 的 B 分数，仅改变 C 参数初值与近端锚点。Nnew0 直接复用对应 B 状态及分数，不增加 C 拟合。
