# CVS 同步坐标保留身份网络：源证据与可证伪假设

当前状态为本地数学/CE原型，不是已发布实验，也没有新模型性能成绩。目标仍为普通交叉熵、无训练增强、仅身份骨干、原物理划分、clean-only；识别性能优先，成本为次要比较。后续正式候选需要从零训练、预登记和合法源域冻结，并默认完成独立 clean 测试。

## 源证据为何改变结构

全路径逐包同步的两个四seed源候选已完成 E200×50，全部80000步/1600轮日志核实；数学上有条件的公共相位及附加±80kHz不变性成立，但源V/最差源RX均没有超过原残差。不能从数学性质推断识别收益。

随后固定的源域信息诊断只用L_s拟合探针、V只读评分，未读取checkpoint、U或target。80:160频偏圆周坐标的固定线性探针源V为33.8296%，留一源RX均值34.9259%，六类机会水平为16.6667%。三窗口联合探针pooled源V51.8852%，留一源RX38.4630%。这些结果证明坐标有可被特定线性探针利用的身份关联，同时其接收机外推不充分；不证明TX晶振参数可识别，也不能单独归因上一轮下降。

设计依据是上述源证据与接收观测模型，不使用任何历史目标分数、目标RX/TX分层或重跑结果。完整证据：[源信息诊断](../automation_reports/CV-SincNet/20261002-diagnostic-cvs-cfo-information-source-manysig-m1-r01/report.md)、[同步源负结果](../automation_reports/CV-SincNet/20261002-phase1-cvs-synchronized-identity-manysig-m8-r01/report.md)。

## 数学与通信含义

在固定80:160窗口取4个20点重复周期，定义

```text
C = sum x[n] conj(x[n-20])
omega = arg(C)/20
aligned[n] = x[n] exp(-j omega n)
```

无效相关时omega=0，沿用已核实的退化处理。`aligned`和`omega`一起能逐点重建原received IQ：`x[n]=aligned[n]exp(j omega n)`。该重建不要求估计是真频偏，也不因主值跨界失效。只保留aligned的网络则删除了选择该坐标的包内信息。

对于有效相关且不跨主值分支的附加线性相位，aligned只增加公共常相位，omega相应平移；二者构成“同步形状与相对坐标”，不能把联合表征称为整个模型的频偏不变性。主值±625kHz、别名1.25MHz保留。圆周描述`[cos(20omega)-1,sin(20omega)]`避免主值边界的线性跳变；它本身也不能识别别名或唯一TX/RX频率。

接收频偏包含TX与RX的相对频率、可能的链路或处理效应。仅单包received观测没有唯一TX/RX拆分；保留这些坐标是为了防止过早丢弃可能有用的信息，不能据此宣称跨RX因果解耦。

## 有界条件化代替信息删除

两种本地原型分别保留上一轮的equivariant_memory或gauge_coherent身份核心。全部波形路径先经过固定同步；附加坐标仅来自当前包的相对频率和重复相干度，没有真实RX、身份标签、跨包状态或原始IQ旁路。

```text
v = [cos(20omega)-1, sin(20omega), clamp(coherence,0,1)-1]
u = identity_core.features(aligned)
gain = 1 + 0.25 tanh(Linear(3,160)(v))
features = u * gain
logits = existing_cosine_identity_head(features)
```

新增640个参数，映射作用于160维身份特征而非另建分类器；所有类共享同一条件化公式。gain范围0.75至1.25，限制坐标对已有特征的放大/压制。conditioner零初始化使原型初始输出与对应同步核心完全相同；只有普通CE决定是否以及如何利用坐标，不加物理损失、域骨干、教师或增强。

相干度是detached包内质量观测，避免零相关幅度的未定义梯度；频率坐标与身份核心保持可微。整个模型仍保留公共常相位性质，但明确不宣称附加频偏不变或任意RX/LTI不变。参数分别为203193（coordinate_equivariant）和164865（coordinate_gauge），比对应核心只增加640；正式训练的实际梯度、耗时、峰值和完整成本尚未测量，记N/A。

## 可证伪条件与下一步

本地8项检查通过：两核心均检查任意频移/主值跨界后的逐点重建、零初始化等价、有界gain及实际参数、非零conditioner的公共相位/逐包独立性、普通CE梯度和零相关输入有限梯度。测试只证明对应数学和执行行为，不证明识别提升。

下一轮若发布，固定两候选×原四model seed，E200×50、原L_s6300/V27000、U_s未用、scratch、普通CE、无增强、无域骨干、完整FP32。source选择仍按四seed平均0.5V+0.5最差源RX最高优先，性能完全并列后成本次选；使用完整12条源记录（8新+4原残差），不能只比较新候选。公共物理干预同时报告整体常相位误差与坐标变化下的输出响应，不能继续把整体仿射不变作为必达属性或筛选门槛。

若原残差胜出，保留其已核实历史clean，不测试未选新候选。若新候选胜出，只测试其4个冻结模型，与20个原冻结对照统一24行独立truth-last评分。源/测试负结果全部保留，目标结果不反馈调参、结构、重排或选择性重跑。

即使后续性能提高，也只能声明所检验的物理性质与代理基准收益；“真正RFF physics aware”的完整证据仍需要区分身份保留、指定接收干扰和不可辨识混淆，不能由一个有界条件化模块自动完成。
