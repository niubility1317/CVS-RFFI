## 第一层：监督与普通 PL 半监督

监督组与普通 PL 半监督组分别成章、成表、成图、成工作表。两组都报告 **RIEI、DRIFT、IB-RFF、SDG、PAMF、DURA+PAMF**。前五项直接识别，只有最后一项接入 DURA；两个 PAMF 展示项共享识别器。所有方法均标明学习方式，方法名不加版本后缀。

监督主比较使用四种外部方法的“有信道增强、关闭 PL”模型，以及 PAMF 的全程有标签训练版。PAMF 监督版为 50 轮有标签训练、11100 次更新，无无标签加载器，保留自身有标签目标，不称纯交叉熵。监督完整系统的 DURA 仅用有标签源集合的 IQ，不读取发射机标签，也不使用无标签源训练池。

半监督主比较使用四种外部方法的“有信道增强、普通 PL”模型和 PAMF 普通 PL 模型。PAMF 为 13 轮有标签加 37 轮联合训练，共 50 轮、11100 次更新；DURA 可用全部允许源训练 IQ，仍不读取发射机标签。监督和半监督之间的完整系统差异不能全部归因于识别器伪标签。

两组保留原生目标、预算和配方差异，不能声称严格等计算比较。普通 PL 阈值均为 0.95、权重 1，以完整无标签批次平均；无 EMA 教师、复杂筛选或额外拟合分类头。

## 第二层：训练信道增强与测试范围

| 学习方式 | 训练信道增强 | 当前报告测试范围 |
|---|---|---|
| 监督 | 关闭 | 仅目标接收机 CLEAN |
| 普通 PL 半监督 | 关闭 | 仅目标接收机 CLEAN，独立工作表 |
| 监督 | 开启 | CLEAN 和全部六种 practical |
| 普通 PL 半监督 | 开启 | CLEAN 和全部六种 practical，独立工作表 |

无增强控制目前只含四种外部方法。当前 PAMF 监督与普通 PL 模型都保留有标签信道视图，不挪入无增强组，不以历史其他配方补齐。缺少同条件 PAMF 项如实说明，不补零。

六种 practical 为高、中、低郊区和高、中、低城市。CLEAN 单列，六景均值不含 CLEAN。目标跨接收机、目标接收机与日期双跨分别报告；源接收机未见日只作单列诊断。无增强组不展示该诊断。未见日是更早日期，不能称未来预测。

## 第三层：恢复网络与泛用性

外部方法主成绩默认不接入 DURA。DURA 泛用性独立成节，并再分监督与半监督。固定相同识别器、数据划分、测试人群、场景和模型种子，采用“未接入 DURA／接入 DURA”并排双竖柱。柱高为准确率，表格另列种子内配对百分点差及其样本标准差；保留负值、CLEAN 损伤及非单调变化。

PAMF 的恢复前后对照也使用双柱。三个识别器通常共用一个同契约恢复器，不能称三套独立完整系统。DURA 不重新训练，不把缓存分类时间称为在线恢复加识别时延；常规识别和优化图执行分别说明。
