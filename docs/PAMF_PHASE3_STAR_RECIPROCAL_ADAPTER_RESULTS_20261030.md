## 2. 固定方法与冻结顺序

适配器 160→32 ReLU→160 共 10432 参数，两臂同 CPU 局部初始化 seed、最后层全 0。raw fused160 先单位化，网络残差逐条 L2 限幅 0.1，再单位化并恢复原 raw 范数。冻结原默认头向输入传梯度，不重训或换头；只重算 P1 fused 与原头 logits，其他 P1 分支、全部 P0、源六阈值保持。扰动限幅不保证旧类损失≤2 个百分点。

共同 trusted 为原 paired margin≥0 且原 P1 MSP≥0.95。self-PL 只取 trusted 自身 argmax。主方法额外对初始接收但非 trusted 的点，用 FP64 unit160 mutual10NN 图（排 self、opaque ID 稳定同分），至少 3 个 trusted 互近邻、最高标签票占≥0.8 才扩展。全部标签训练前固定，扩展点不递归投票，未选 U 不强归旧六类。

各臂 full U 固定 200 步、adapter-only fresh AdamW lr=.001、wd=.0001、betas=(.9,.999)、eps=1e-8、foreach=false、clip=5，无增强、重采样或早停。目标是固定伪标签 CE＋全 U 非对角 unit Gram MSE（权重 1，原 U 特征为 detached teacher）；未选 U 只参加结构保持。两臂独立同初始化，不继承控制状态。

每个 DA 独立注册：原和当前 margin 都负才为候选，在全 U mutual10NN 图的候选诱导子图取连通分量，自动 K、允许 0，不扫描真 K。组件至少 16 点，与初始 trusted 有互邻边的点比例≤.05，opaque ID 交替两半中心距≤本分量 LOO95% 欧氏半径，才注册 FP64 均值／半径（floor=1e-6）。

推理先旧类：old margin≥0 时保留当前原头旧标签，匿名不能覆盖；旧拒后才允许匿名半径竞争，否则拒识。同 DA 下 REG 不改任何已接收旧 label，也不新造旧 label。adapter、伪标签、注册和阈值先于 Q 冻结。全部 2×4 预测固定后才独立 CPU 评分；四份 arm/DA 映射只用 U truth，并先于 Q truth 冻结，不进入算法。
