## 发现与修复

|问题|后果|修复及验证|
|--|--|--|
|DRIC球约束活跃时的乘子初始化和迭代不可靠|小半径可无法收敛，零半径未被准确处理|消去域头、在活动半空间的零空间求解；使用强单调性界初始化并约束Newton区间；零半径精确求解。4个半径反例和12个已知KKT解覆盖耦合、球/半空间联合活跃|
|局部重放把autograd独立误当作前向独立，并缓存有状态模块|detach路径可能命中旧值，buffer更新可能丢失|缩小为确定性无buffer内建模块白名单，检查实际输入及参数版本；恢复forward属性原始存在状态。detach、自定义状态、异常恢复及真实模型缓存开关一致性通过|
|XT fit/monitor诊断受Dropout影响且消耗训练随机流|零学习率仍出现虚假的fit变化，观测影响训练|诊断放入隔离eval状态，训练内环模式不变；lr0变化为0，诊断开关的loss、梯度、随机状态一致|
|CF候选风险使用的buffer与最终提交不一致|可行性读数与实际候选状态不对应|每个候选测风险前恢复正式提交的原点buffer；BN候选状态反例及原有β端点一致性通过|
|阶段表使用固定步号|低频机制实际开启步可能被误读|按222步/epoch与全局接受步生成关键阶段的全部修正步，并逐份读回|
|低频监测直接按接受步轮换|步长与组内样本数有公约数时只访问部分样本|改用机制调用序号轮换，测试覆盖70个组内槽位|
|预热被动观察及有效系数记录不足|配置开关难以与当步生效状态对应|接通既有诊断频率，记录固定源L的整步风险/表征/头梯度变化及实际L/U系数；观察不控制训练，并显式区分任务漂移或响应恢复gap|
|部分配置类型与数值边界检查不足|bool、非有限数或冲突β模式可能漏检|补足严格类型、有限性、正容差和模式互斥检查，6个非法配置用例通过|

`reaudit_before_fixes.xml`保留最先复现的8个失败用例，涉及前四类问题；它是修复前证据，不是最新失败状态。前轮80项记录保留为`prior_acceptance_18b8c589.json`。
