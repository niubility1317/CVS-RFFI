# CVS 连续复相关增量：性能优先研发

本轮只改变确定性相位特征的公式，保留此前物理表征候选的参数数量、初始权重、所有原始路径、宽度、深度、池化、融合及身份头。两候选为 coherence_phase 与 coherence_dsq；后者使用同样的原生 DSQ 默认4通道，前者不启用 DSQ。与 phase_delta/phase_dsq 逐项对应，初始 state_dict 的每个张量完全相同，不重抽投影权重。正式全部从零训练，不继承其权重。

## 数学原理

令 Sinc 后相邻复数为 z_t=I_t+jQ_t，p_t=|z_t|²，C_t=z_t conj(z_(t−1))。原特征使用 θ=atan2(Im(C),Re(C)+eps) 再取 sinθ 与 cosθ−1。增加 eps 到实部只移动相位奇点：当 C=−eps+0j 时，两个 atan2 输入均为0，反向导数仍未定义。

新公式为 `u_t=C_t/sqrt((p_t+eps)(p_(t−1)+eps))`，直接使用 Im(u)、Re(u)，保留原包络 log1p(amp/包内时间均值)、包络差分与4×24输入通道。eps保持原生1e−6，不新增可调门槛或扫描。边界第一邻点的两个相关特征补0。

有 `|u|²=p_t*p_prev/((p_t+eps)(p_prev+eps))<=1`。两个功率同时远大于 eps 时趋近单位相位增量；弱能量时相关幅度收缩，不把低能量相位赋成同等可信的单位向量。统一复相位旋转在 C 和功率中抵消，只证明此补充特征不变，保留的整网原始路径并不不变。实际收到 IQ 及归一化保持不变，此计算属于模型内部特征，不是信道/数据增强。

例如实分量导数为 `∂u/∂I_t=conj(z_prev)/D−C*I_t/((p_t+eps)*D)`，D为上述分母。正 eps 使该相关函数全域有限且光滑，保守导数模界为2/sqrt(eps)。整网仍有原 clamp 与 CNN 非线性，不声称整个神经网络全域光滑、低梯度或必然提高泛化。

构造 z_prev=1、z_current=−eps 的 FP32 组件检查：本机 Torch2.10 对 atan2(0,0) 的反向返回0，原模块与新模块的梯度都有限，最初假设本机必然出现非有限梯度被实验否定。独立只读调用正式 N607 Torch2.1 CPU 后，原模块前向有限、192个输入梯度非有限；新模块前向和输入梯度均有限。此版本差异和实际模块路径均保存，不把数学奇点和某一版本的实现行为混用。完成的八行正式 source 训练全部梯度有限，没有证据说明这个构造点曾在训练发生，更不能用它解释 clean 的 seed 波动。该检查用于验证数学构造，不是对健康实验的故障诊断或重启理由。完整源曲线、组件导数证据保存在本轮现有 evidence 中。

## 通信原理

相邻乘积保留相位增量，统一初始相位抵消，载波频偏仍会贡献相邻旋转；不能称为 CFO 消除或 TX 专属 CFO。`u` 的模同时表达两点能量相对于既有数值尺度的可信度。没有增加观测节点、独立样本、接收机标签、全局 query 统计或拟合。频率 DSQ 仍只是对原四个镜像压缩特征作局部均值差分，不宣称任意信道补偿。

## 物理原理

PA 的包络非线性、记忆效应与振荡器的短时相位行为可能改变邻点关系；低幅度位置的相位容易受噪声影响，因此以连续复相关保留并弱化该信息是可检验假设。接收机、信道、波形内容与同步误差也贡献同一统计，数学界不代表物理因果分离。原 time/frequency/PA 路径全部保留，避免只靠相位相关解释身份。

## 射频指纹原理与实验解释

投影通道、身份特征160维和余弦身份头不变，通过普通身份 CE 学习组合；没有额外物理损失、域骨干、伪标签、teacher、EMA、adapter 或初始化继承。无需新增参数便可比较两种相位描述，性能变化不能归因于单纯扩宽/堆层。仍不能仅凭准确率证明某一物理机制或 TX/RX 解耦。

候选由当前完整源曲线与上述代数性质确定，不依据目标 seed/RX/TX 或目标评分选择 epsilon、结构、预算和重跑范围。完整 source 曲线表明终态 CE 低、最后20轮 V基本收敛，但未证明 atan2 病态导致实际源不稳定。本轮不以已测试最高的模型或 seed 初始化，不重测此前未选候选。
