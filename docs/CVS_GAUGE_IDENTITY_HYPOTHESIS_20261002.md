# 保留完整 IQ 的逐包相位规范化

本轮研究目标是纯交叉熵、无训练增强、只启用身份骨干时提升识别性能，同时让网络具有明确可检验的物理性质。参数轻量是次要条件。本文件在新的目标访问之前固定假设和源域选择规则，不根据历史或本轮目标成绩修改结构、超参数或排名。

## 可证明的性质与边界

接收 IQ 的公共相位包含载波参考。给定复数包 `x`，相位参考 `a(x)` 满足 `a(exp(jθ)x)=exp(jθ)a(x)`，定义

`G(x)=x*conj(a(x))/sqrt(|a(x)|²+ε)`。

因此实数精确运算下 `G(exp(jθ)x)=G(x)`。所有身份分支都位于 G 之后，整网满足公共相位不变性。非零参考只使全部 256 点 IQ 乘上一个固定复标量，保留幅度形状、相对相位、时序、频谱形状与频偏；不声称保留 RMS 预处理已消除的绝对发射功率。ε 固定为 1e-6。零参考输出为零；相干参考退化时回退至全包峰值参考。

峰值方案选择功率距最大值相对误差不超过 1e-5 的第一个样本。功率选择不依赖公共相位，但接近选择边界时不连续；浮点舍入可能改变参考选择。全网不变性指实数运算性质，实际 FP32/TF32 误差独立报告，不宣称逐位相等。

相干方案只用 80:160 的四个 20 点周期估计参考。对理想 `x_m(k)=v(k)exp(jω(20m+k))`，相邻周期相关得到 `exp(j20ω)`，对四周期对齐后平均得到 `v(k)exp(jωk)`。平均只用于确定一个参考相位，全部 IQ 波形仍完整保留，不将平均波形代替输入，也不从输入减去 CFO 或非线性失真。参考退化阈值为全包峰值功率的 1e-6，固定而非调参。

在已知正确周期相位、噪声独立且零均值的理想条件下，四周期平均的噪声方差为 σ²/4（6.0206 dB）。实际估计相位、相关噪声、均衡误差和多径不满足这些理想条件时，不能保证此收益。

AM/PM 模型 `x exp(jβ|x|²)` 在稳定参考点下保留 `β(|x_t|²−|x_anchor|²)` 的相对相位响应。AM/AM 幅度形状和频偏斜率也保留。合成测试检验这些性质，不将响应非零等同于已识别发射机硬件。

真实收到的 CFO 是 TX 与 RX 的相对频偏；收到的 IQ 镜像和非线性可由发射机、接收机和信道耦合共同产生。当前 received/equalized/RMS IQ 不足以唯一恢复 TX 的 PA/IQ 参数。接收机 IQ 失衡和多径作为明确反例，不声称本方案对任意信道或 RX 不变，也不把 received-PA 分支命名当作发射机参数识别证据。

## 依据与实现

源域诊断 `20261002-diagnostic-rff-preamble-source-manysig-m1-r01` 全部读取 L=6300 和 V=27000：20 点为扫描相关峰；80:160 的 V 周期内相干度为 0.9435056795，180 个 TX/RX/day/role 分组均值为 0.7870791365 至 0.9997210682。它支持当前周期和窗口假设，不能证明标准训练字段的精确采样对齐或 TX 因果归属。

两个候选复用残差身份网络的代码结构，保留时域、Sinc、频域与 received-PA 代理分支、160 维嵌入和普通 cosine30 分类头。参考前端没有学习参数；总参数仍为 164225。每个种子从零初始化，两个候选与原残差网络的核心初始权重按同一种子逐项一致。无 checkpoint、teacher、EMA、domain 或附加损失。

WiSig 的官方均衡流程执行采样率转换、同步、粗细 CFO 校正、LTF 均衡和子载波筛选，随后重新施加 CFO 并恢复采样率。因此本研究不能把当前输入当作未经处理的原始 RF，不能从中声称观察到完整 PA 带外谱再生。出处：[WiSig 论文](https://arxiv.org/html/2112.15363)、[绑定版本官方均衡代码](https://raw.githubusercontent.com/WiSig-dataset/wisig-process-raw/6530c6ed6be1d08544ac295040ed50f5babde86a/matlab_equalization/equalize_channel.m)。标准 L-STF 的 0.8 μs 周期对应 20 MHz 下 16 点、25 MHz 下 20 点；本轮不重建标准 L-STF 系数。[MathWorks L-STF 文档](https://www.mathworks.com/help/wlan/ref/wlanlstf.html)

## 固定矩阵与收尾

新增训练为两个参考方案×四个种子，每行 200 轮×50 步，batch128，每轮完整暴露 6300 个 L 样本，V 只评估，56700 个 U 不使用。相同物理角色、AdamW2e-4/wd1e-4、cosine1e-6、FP32、无裁剪、无增强。所有负结果保留，健康任务不热改、不重启。

在八个新源记录和四个已有 `residual_fusion` 源记录中，按四种子的 `0.5×V准确率+0.5×最差源RX准确率` 均值最高选择。完全并列再依次比较 V、最差 RX、MAC、参数；仍相同则按 residual_fusion、gauge_peak、gauge_coherent 顺序选择。不存在 0.2 个百分点成本优先区间。旧源记录只读完成/来源/角色/预算/资源元数据；不加载旧权重，不读旧目标成绩排名。

若新参考方案胜出，冻结后自动开展选中候选四个 clean 预测，加二十个已冻结对照预测只读复用，共 24 行统一独立 truth-last 评分。数据保持原 168000 个物理 query、6 个 TX、7 个 RX，逐包面对全部类 argmax。预测完成前不读 truth；测试结果不回流。

若已有残差源对照胜出，保留其已核实的历史 clean 测试与原报告，不为收尾重跑历史任务，不测试未选中的相位候选。新候选测试明确记 N/A，报告源域拒绝而非“测试提升”。这不表示真正 RFF physics-aware 与性能目标已经完成。

报告包含全量学习曲线、同 seed 差分、V/TX/RX/day 分层、冻结合成响应、实际参数/耗时/显存/常驻状态。源几何只用于解释，不用于训练或排名。clean 是已经暴露的闭集代理基准，不声称新盲测、卫星、多类新增或已校准 TX 硬件辨识。
