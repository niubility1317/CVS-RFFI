# 固定纯 CE 基线上的第二阶段多解耦方案

日期：2026-10-11。状态：**源端审计完成；优化设计完成；尚未实现或启动本版训练，84% 未验证。**

用户目标：以后复用第一次 CE 基线训练，在其上独立开展第二阶段多解耦训练，减少重复训练成本，争取 clean 测试准确率达到 84% 以上。用户已确认第二阶段每个方案采用 **40 个 epoch**，配套同预算纯 CE 续训对照；本轮交付范围明确为 **先给出完整优化设计**，不实现或启动本版训练。当前健康实验保持原冻结计划。

## 1. 结论

建议采用“**固定基线初始化＋真实干预的判别稳定性＋状态条件的单向裕量修复**”。保留一个身份网络和独立的 L/T/R 作用网络，让辅助网络解释或寻找干扰，身份网络通过真实 IQ 接受约束。第二阶段首版不继续叠加 Fishr、MixStyle、虚拟特征分布匹配和联合 L/T 动作。

核心改进不是增加一个身份分类器，而是解决三个具体问题：辅助约束能否回传身份编码器、辅助网络能否在未参与自身拟合的 TX 上解释接收状态差异、约束是否以提升弱条件性能而非降低强条件性能来满足。

84% 是最终测试目标，不能从源 V 的 98% 推算出来。本文只依据源域日志与代码提出机制，没有读取目标评分来选择父权重、超参数或候选。

### 3.1 R：成本高，身份约束弱

24 个 LTR 行中，R 正权重身份步只占尝试的 5.13% 至 8.61%，中位 6.69%。外层 `feature/runtime.py` 和内层 `multi_action_risk/receiver.py` 均存在 `detach()`，因此 R 不更新身份编码器 E。后半程可靠度的跨行中位约 0.000464，再乘固定系数 0.01，作用很弱。

当前 R 用约 5 个不同物理样本的袋估计均值、协方差和尾部，再取多个审核指标的最小值，还叠加 reference/live 双重审核。增加拟合次数无法补足这种统计目标需要的样本支持。新方案应减少统计维度和审核频率，而非直接放松所有审核。

24 行区段计时中位：R reference 审核约 5,973 s、live 审核约 2,836 s、R 拟合约 1,605 s；L/T/联合真实 IQ 身份前向分别约 86.7/85.3/84.5 s。这些计时在共享 GPU 上产生且存在嵌套，不能相加推导精确加速倍数。实际 E200 总时间 native 三 seed 平均约 2.79 h，LTR 变体约 6.34 至 7.10 h。

### 3.2 Fishr：当前实现的后期梯度消退

18 个含 LTR 的 Fishr 行，编码器 Fishr/CE 梯度比的“行内审核点中位数再取跨行中位数”，在 E41–E100 约为 3.67e-5，E101–E200 约为 5.57e-9。当前方向归一化仍保留 `softmax−one_hot`，分类变得自信后，梯度方差及方差差平方逐级变小。

这说明当前实现的固定早期校准没有维持后期作用，不等于证明所有 Fishr 方法无效，也不能排除其早期作用。第二阶段不再把它作为主增益机制。

### 3.3 L/T：真实约束有作用，但不应靠数量堆叠

每个 LTR 行各执行 L/T/联合真实 IQ 身份更新 9,990 次，每项 319,680 包。身份损失系数固定为 .015/.015/.02；epoch fraction 只控制辅助学习率，没有再次缩小这些身份系数。三项对 E 的合计梯度比从 E21–E100 中位约 8% 降至 E101–E200 约 1.57%。LTL 源压力准确率由 native 的 97.3407% 提至 LTR_S 的 97.7654%。

保留物理动作＋真实 IQ 身份学习有依据；继续增加虚拟状态拟合和联合前向没有充分依据。

## 4. 数学对象：约束判别裕量，而非删除所有域信息

记身份网络为 f_theta，固定父模型为 f_0。定义未乘分类 scale 的余弦裕量：

`m_theta(x,y) = cos(h_theta(x),w_y) - max_{k != y} cos(h_theta(x),w_k)`。

CE 仍使用固定 scale=30 的 logits。辅助约束统一采用固定倍数 `u_theta=30*m_theta`，不允许可学习 scale 通过数值放大满足约束。`sg` 表示停止梯度。下述阈值与统计量只用 L_s 确定，V 只验证。

定义单向惩罚 `H(z)=Huber_delta=1(max(z,0))`：z≤0 时为 0，0<z≤1 时为 z²/2，z>1 时为 z−1/2。这样对违约量 z 的导数不超过 1；这不保证对网络参数的梯度有界。首版用该惩罚替代平方 hinge，避免少量异常裕量差支配微调。

从通信模型 `x=R_d(H_d*T_y(s))+n` 出发，接收链路与发射机非理想性可能占据相同统计方向。CFO、频谱形状和相位状态都可能携带身份信息。因此不强制完整 embedding 与 RX 独立，不从 embedding 中直接减去 R 的预测，也不宣称彻底恢复了因果 TX 因子。

本版研究问题是：在可核验的局部干预与同身份接收条件变化下，能否减少**不必要的身份判别损失**。

## 5. 三类独立作用网络

### 5.1 L/T：有界真实动作与单向裕量保护

L 网络只产生预定范围内的短线性响应参数；T 网络只产生预定范围内的分数延迟和缓慢相位变化参数。沿用已实现并核验的源域物理动作边界，不引入卫星视图生成器或无约束 IQ 残差。输入为物理状态摘要和随机动作码，不增加身份分类头。

每 seed 先从严格加载的 f_0 建立参考，以 L_s 两次完整遍历作为拟议的动作拟合预算。冻结 f_0 参数，分别训练 L/T 最大化有界真实动作造成的父模型裕量下降。动作强度、合法性及幅度预算由既有源域物理范围限制；不因学生预测错误就丢弃合法困难样本。若新动作范围超出既有物理核验，不能直接继承其有效性结论。

短程第二阶段先冻结 L/T，使同一 seed 的消融共享相同动作网络及动作随机序列；不再每步拟合虚拟身份特征、反复刷新参考或做双重分布审核。冻结动作网络是否丧失后期困难性，通过真实裕量下降轨迹判断，不预设永远有益。

身份损失使用同一 IQ 的变换前后真配对：

`L_aug = mean_i CE(f_theta(A_k(x_i)),y_i)`；

`L_drop = mean_i H(sg(u_theta(x_i,y_i))-u_theta(A_k(x_i),y_i)-delta_k)`。

动作 CE 与裕量惩罚分别加权，具体归约和固定起始系数见第 6 节。

clean 一侧停止该差值的梯度，去除本辅助项直接降低 clean 裕量的通道。共享参数更新仍可能使 clean 裕量下降，需用 L_keep 和实际轨迹检查间接退化；停止梯度本身不是不退化保证。CE 负责纠正身份，第二项抑制动作额外造成的损失。每次仅一个 L 或 T 动作，按下文日程均衡执行；先不增加联合 L+T 前向。

### 5.2 R：跨 TX 验证的状态困难度预测

父模型只对 L_s 做一次 clean 前向，缓存物理状态、标签、RX/day、物理 ID、父模型裕量与正确性。令 g=(TX,day,粗质量区间,RX)，R 拟合条件组的中心化标量均值残差：

`target_g = mean_i_in_g u_0(x_i,y_i) - mean_balanced_RX[mean(u_0) | TX,day,质量区间]`；

`prediction_g = mean_i_in_g r_psi(state_i)`。

R 拟合损失使用双向 `Huber_delta=1(prediction_g-target_g)`，不使用身份约束的单向 H。按 TX/day/质量区间及其内 RX 均衡取均值，不让样本多的组支配损失。每组至少有 8 个不同物理 ID；条件不足时仅按预先固定的质量区间合并规则处理，不能合并不同 TX 或 day。中心化及关系差值始终使用相同条件。逐包噪声拟合不再作为 R 的主要目标。

R 输入只包含预定物理状态摘要；不输入 TX 标签、身份 embedding、RX ID 或当前学生 loss。TX 标签用于构造监督残差和评价，不作为 R 输入。R 的输入标准化在各折拟合 TX 上建立并冻结，避免将留出 TX 的状态用于拟合预处理器。

建议对六个 TX 建立三个固定双 TX 留出折：每个小 R 仅由另外四个 TX 的缓存拟合，给留出两个 TX 产生约束。三折是 R 族内部的小预测器，不是三个额外身份骨干。父身份模型本身见过全部源 TX，因此这里的“留出”只证明 R 的迁移性，不是未见 TX 或未见 RX 的身份识别实验。

可靠度评价对象为留出 TX 中同 TX/day/质量区间的跨 RX 均值差 `Delta_gh=target_g-target_h`，而非逐包残差。定义 `MSE_pred=mean_w[(prediction_g-prediction_h-Delta_gh)^2]`、`MSE_zero=mean_w[Delta_gh^2]`，两项必须使用完全相同的关系集合、分母和均衡权重。先在每个 TX/day/质量区间内平均其 RX 对，再对这些条件块均衡平均。

每个留出折使用一个冻结的 `c=clip(1-MSE_pred/MSE_zero,0,1)`，不再连乘方向准确率等小分数。方向准确率作为独立诊断报告；实际选定强弱方向前，预测差的绝对值必须超过该关系的固定误差容忍量 delta_R，否则只跳过该关系。这样将预测价值、方向模糊性与学生是否需要修复分别记录。

没有至少两个可比较 RX、没有足够独立物理 ID、没有有效条件块，或 MSE_zero≤1e-8 时令 c=0；不设置人为正下限。方向判平阈值固定为 1e-4 logit 单位，平局不进入方向准确率分母，分母为空记 N/A。所有 ID、组、条件块与关系计数均报告；重复分袋和共享一个组的多个 RX 对不算新的独立样本。c 在身份微调前冻结，不因当前学生 loss 升高而增大。

折内拟合、跨折预测和可靠度评估的所有数据都来自 L_s；V 不更新 R 或任何持久状态。该可靠度仍是源训练侧的机制诊断，不冒充独立泛化成绩。

### 5.3 R 如何直接约束身份编码器

从同 TX、同 day、粗质量区间重叠的两个真实 RX 抽独立样本袋 B_minus 和 B_plus。它们不是同步同包，不逐 IQ 强制配对。R 依据物理状态预测较弱与较强接收条件；每袋建议至少 8 个不同物理 ID，避免重复采样伪装独立样本。

`L_R = mean_relations c*H(sg(min(mean(u_theta(B_plus)),tau_y))-mean(u_theta(B_minus))-delta_R)`。

tau_y 固定为父模型 L_s 中同身份合法条件组均值的 75% 分位数，防止无限追逐某个极易组。令 v_g、v_h 为父模型在两个条件组内的裕量样本方差，n_g、n_h 为当前两个袋的不同物理 ID 数；固定规则 `delta_R=max(0.5,sqrt(v_g/n_g+v_h/n_h))`，单位均为 scale=30 的 logit 裕量。它是允许有限差距的噪声尺度，不是独立置信区间。组方差来源于一次性 L_s 缓存，不用学生输出重估。选强/弱关系、c、delta_R 和 tau_y 均停止梯度。

梯度沿 B_minus 的真实 IQ 回传 E 及分类头；B_plus 在这个关系项上停止梯度，但仍接受普通 clean CE。若学生已经修复差距，hinge 自然归零，不强迫所有 RX 表示相同。c=0 只关闭这一关系，普通身份更新和 L/T 步骤照常运行，不拒绝整步。

首版只匹配标量判别关系，不估计小袋的高维协方差和尾部分布。R 必须证明留出 TX 上有预测价值；如果长期 c≈0，只能报告 R 无效，不能将“分支已运行”当成有效多解耦。

## 6. 微调保护与低开销执行

父模型已很强，第二阶段需防遗忘，但不复制父模型错误。只对父模型在 L_s 上判对的样本增加单向裕量下界：

`L_keep = mean_main_batch 1[parent_correct]*H(min(u_0,tau_y)-u_theta-delta_keep)`。

u_0 来自一次性缓存。父模型判错的样本仅由真标签 CE 和合法辅助项学习；不强迫学生模仿错误预测。该保护项只加入对应变体，纯 CE 对照不启用。

首版总目标固定为：

`L = L_clean_CE + ramp(s)*[0.1*L_keep + I4(s)*(0.25*L_aug+0.1*L_drop) + I8(s)*0.1*L_R]`。

其中 s 为第二阶段从 1 开始的身份更新序号，I4/I8 分别表示每 4/8 次更新触发，`ramp(s)=min(s/444,1)`。C0 去掉全部辅助项，C1 仅保留 L_keep，C2 保留 L_keep 和 L/T，C3 全部保留。delta_keep=delta_L=delta_T=0.5 logit 单位。上述有限系数是本轮固定起始假设，不是已验证最优值，也不根据目标测试改动。

clean CE 和 L_keep 对主批次取均值，L_aug/L_drop 对最多 32 个动作样本取均值。L_R 对原计划关系取均值，失效关系贡献 0；不能只除以非零 c 的数量，也不能除以 c 之和将可靠度抵消。空集返回 0，c 只乘一次。正常身份学习时 R 和动作网络冻结，辅助参数不被身份损失更新。

为降低成本，建议把关系样本放进原有 clean 主批次：每 8 次身份更新，将 batch128 中 32 个位置预留给 2TX×2RX×8 个不同物理样本，其余 96 个按原规则抽取；其余步骤仍用普通主批次。所有新对照使用相同的预定样本序列，报告该采样差异，纯 CE 对照仍只有 CE 损失。这样 R 可复用主前向的真实裕量，不额外编码参考/审计 IQ。

L/T 仍每 4 次身份更新执行一次，最多处理主批次的 32 个 L_s 样本；不是每 4 个 epoch。在关系步骤与非关系步骤内分别均衡 L/T，例如第 4/8/12/16 步依次用 L/L/T/T，循环执行，避免 R 每 8 步总与同一种动作绑定。C2/C3 共享该日程和动作码。有 R 关系的步骤尽量复用同一 32 个样本，不另取 32 个审核样本。关系不满足不同 ID/质量重叠条件时只记录缺项，不放宽条件伪造配对。

训练节奏（40 epoch 已确认；其余为设计参数）：

| 环节 | 建议设置 | 作用 |
|---|---|---|
| 共享准备 | 每 seed 一次父模型 L_s 缓存；L/T 各两次 L_s 遍历；小 R 在缓存上拟合 | 成本单独记录，消融间复用 |
| 第二阶段第 1–2 epoch | 小学习率启动，辅助损失短 ramp | 避免成熟表征突变 |
| 第 3–40 epoch | 全身份网络微调，cosine 衰减 | 不重复 20 epoch 辅助等待 |
| 拟议峰值 LR | E=3e-5，融合/分类头=1e-4；最低 1e-6 | 新优化器日程，须在实现前固定 |
| 数据与预算 | 仍只用原 L_s；保持 222 次身份更新/epoch，40 epoch=8,880 次增量更新 | 累计 53,280 次，不隐去父 E200 |
| 验证 | 固定源 V clean、分 RX 与既定源压力；最终轮次冻结 | 不用目标反馈调参 |

表中 40 epoch 已由用户确认；LR 及准备预算仍为设计建议，尚未运行，也不声称是最优配置。辅助系数采用上面的固定有限值，不从成熟 CE 梯度的比例或倒数推导。后续实现中的 L_s 梯度审计只诊断实际作用，同时报告 CE、未加权辅助及加权辅助梯度；CE 范数接近零时比例记 N/A，并保留各自绝对范数，不能自动将辅助权重调至零或无穷大。若约束未满足而梯度长期消失，应报告实现或机制失效；若约束已满足，梯度下降属正常。梯度路径检查不等于训练收益证明。

本版不需要身份训练期间常驻父网络或持续父网络前向；父模型信息限于 L_s 缓存，L/T/R 推理成本很小但仍需实测。最终推理只用身份网络。

## 7. 最小可解释对照与 84% 验收

建议先做四组固定变体、每组三 seed，共 12 行第二阶段训练，复用已有三行父基线。不再复制上一轮 48 行从零训练矩阵。

| 组别 | 第二阶段目标 | 回答的问题 |
|---|---|---|
| C0 | 纯 CE，和其余组相同样本序列与更新预算 | 共同第二阶段训练配方有多少收益 |
| C1 | CE＋L_keep | 防遗忘项是否有效 |
| C2 | CE＋L_keep＋L/T | 真实动作与裕量稳定性能否提供收益 |
| C3 | CE＋L_keep＋L/T＋R | R 的真实条件关系约束是否再提供收益 |

这套增量对照可以分离保护项、L/T 组合及其上的 R 增量；不能单独识别 L 对 T 的贡献，也不能证明学习动作一定优于相同范围的随机动作。后二者留作有明确源端证据后再预登记的独立消融，不把首版同时堆成大矩阵。若仅先发布 C0/C3 三 seed，可以验证整体方案，但必须承认无法分离内部机制贡献。

主结果预先指定 C3，不在测试后挑四组里的最高值称为成功。用户已明确主要达标口径为 **C3 三 seed clean 准确率均值达到 84%**，同时报告每个 seed。进一步保留最小值、样本标准差以及相对 C0 的三 seed 配对差。均值达标不能写成每个 seed 都达标；只有一个 seed 达标也不能写成三 seed 达标；缺 seed 时结果为 partial，不用现有 seed 的均值替代完整口径。

令 P0 为原 E200 父模型。`C0−P0` 是共同第二阶段配方的收益，包含新的采样、优化器和学习率日程，不能单独解释为“只多训练 40 轮”的因果作用。`C3−C0` 才是本设计中多解耦组合的增量；同时报告 C3−P0。所有差值按相同 seed、相同测试物理 ID 配对，单位为百分点。

本轮目标分为三个可分辨的结论：

| 结论 | 所需证据 | 未满足时如何报告 |
|---|---|---|
| 性能达标 | 固定 C3 三 seed clean 均值≥84%，逐 seed 独立评分完整 | 性能目标未达成，不以源 V 或最高单 seed 替代 |
| 多解耦提供增量 | C3−C0 的三 seed 平均配对差为正，公开每个差值及波动 | 即使达到84%，也不能将达标归功于多解耦；三seed正均值不自动等于统计显著 |
| 成本得到控制 | 仅新增40轮身份训练；记录父训练、共享准备、各变体及测试的GPU时间和内存 | 不根据epoch比例宣称实测加速，不把未测成本写作零 |

机制诊断服务于解释：R 的留出 TX 条件关系预测是否优于零差基准；约束未满足时梯度是否到达 E；弱条件的真实裕量/正确率是否改善，强条件及父模型原正确样本是否退化。执行次数、c>0 或损失下降都不足以独立证明有效解耦。这些诊断只使用源域，不能成为按目标分数选择性重跑的理由。

样本级 bootstrap 不能代替三个训练 seed 的不确定性。clean 总体准确率、Macro-F1、各目标 RX 准确率及最差 RX 都应保留。还需证明 C3 相对同预算 C0 有实际收益，否则即使超过 84%，也不能把效果归因于多解耦。

冻结后按现有约定自动运行 clean＋六种 practical。只追求 clean 的当前目标不自动取消已约定的最终 practical 测试。预测固定后独立 truth-last 评分；结果不反馈其他健康训练、选模、结构或参数。当前目标被反复观察过，因此不能把持续围绕同一目标测试集进行的后验筛选包装成独立确认性提升。

## 9. 效率、证据与边界

第二阶段复用节省的是重复基线训练成本。总成本应写为 `一次父训练＋共享准备＋各候选第二阶段＋测试`。对未来单个候选报告增量成本，对论文/整体项目报告父训练摊销和累计成本。不能用 40/200 推断五倍实测加速，更不能把已花费的父训练隐藏。

本方案的可研究贡献是：**跨 TX 核验的状态残差预测，驱动真实跨 RX 的单向裕量修复，并和有界真实干预共同约束成熟身份模型。** 这是待验证的组合机制，不宣称已被证明有效或具有文献首创性。

Fishr 原论文研究跨域梯度方差匹配：[Rame 等，ICML 2022](https://proceedings.mlr.press/v162/rame22a.html)。RF 指纹已有对抗式设备/域解耦与特征重组：[DRRF，2022](https://arxiv.org/abs/2208.02724)，以及跨接收机对抗解耦：[Cross-Receiver Generalization，2025/2026](https://arxiv.org/abs/2510.09405)。这些文献支持相关问题的存在，不证明本方案能够达到 84%。

源证据：`local_artifacts/source_only_feature_evidence_20261011.json`（本工作树，只含源域审计汇总），以及 r01/r02 原始逐 epoch 日志、源诊断和辅助记录。原始产物仍保留原位置；本文版本化的是分析结论，不复制大型实验输出。
