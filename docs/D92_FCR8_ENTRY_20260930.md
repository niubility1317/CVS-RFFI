## 冻结接口与路径

核心模块为 `cvsrffi.d92_function_coordinate_residual8_local_ridge`。接口是 `prepare_function_coordinate_training`、`fit_function_coordinate_local_ridge(mode='B'|'C_seq'|'C_reset_init')` 和 `evaluate_function_coordinate_objective(prepared,Z,anchor_U,gradient=True,forward_cache=None)`。最终分类器为 LocalRidge，V0 固定，原坐标 U 最多有 5888 个参数，实际活动坐标数为 `736*latent_rank`；Z/W 不作为查询归一化器。

固定路径为 R0、主候选 R_FCR8_seq 和继承对照 R_FCR8_reset_init。沿用同一 160 parent：6 个旧类，K=1/5/10/20，新增类数=0/2/5/10/20，3 折物理 OOF 与全 anchor one-shot proxy。true K1 仅数值；proxy train K1 没有优化，三路径精确为 R0。新增类数为 0 时对应 B 直接复用。A 和 B−A 为 N/A，不把 B0 当作地面 A。

C_seq 的起点精确复制当前本行 B 的原坐标 U；C 使用新合法 outer-train 的 H/W，Z=0，不复制旧 Z。reset 从 U=0、Z=0 开始，但使用与 seq 相同的实际 B 教师。所有 head 的带宽、中心化、迹与标签统计仍只来自相应 inner-train；H/W 使用当前 outer-train 的无标签字典值，是共享优化器坐标，不构成独立 inner-held 验证。

## 独立摘要核对

摘要先确认完整 4 row／160 parent 和缓存／checkpoint 来源绑定，再读取外层合法 support held-score；失败、缺 parent 或不完整 marker 会提前拒绝。它完整重算三路径 B0/B/Cold/Cnew/H、适应增量、注册下降和 task absolute gap，生成完整 K×新增类数及 model/cohort、receiver/scene 结果与资源分层，不依赖完成 marker 的自述。

必要的 FCR 数学绑定包括：全部 H 奇异谱与冻结数值 rank、保留 SVD 子空间与白化误差、optimizer_coordinate_ids、动态 shape、Z0／U_B 精确继承、`U=anchor_U+Z@W.T`、函数近端 `0.5||Z||²`、直接物理 pre-tangent 位移与重构舍入误差、保持半空间方向、实际 trial 位移、Armijo／总目标非增／真实 keep 三条件及拒因、last accepted cache、全事件与实际计数。无 MC 产品球检查；停止于结构退化时核对保留的 `original_inner_geometry`，不会把已构建的距离引擎费用抹掉。

摘要只验证当前方法必需的绑定和坐标公式，不重做无关历史审查或有限差分拟合。有限差分和换基等变等数值证据来自 core 合成测试，由主 agent 统一执行。rank≤8、Z 路径界和 Frobenius 范数只描述 support 上、切向投影与饱和之前的功能坐标，不保证 query 几何、旧类保持、外层泛化或星载收益。

资源报告包括实际 U＋物化固定 V0 的 94208 B、head、继承状态、准备 H/W 和训练 cache 的数值大小，CPU／线程、训练与推理时间、峰值 RSS，以及全 NPZ 个数／字节／phase。独立 kernel、部署包、增量传输和 GPU 项未测时为 N/A。缓存、目标、archive 计时存在包含关系，不能重复相加；并行 lane 时间之和不是实际 wall time。参数数目减半不证明训练总算力减半。
