## 本次优化了什么

此前开放分支只接收中间时序统计、PA 和 SIG，未完整继承最终时频贡献、参考贡献及原分支尺度。本轮从同次原生可微前向提取四个实际 160 维贡献：时频、带原增益的 PA、带原增益的参考响应、已经限幅的 SIG。拼接后的 640 维特征进入开放集投影器。

两组均增加相同的 `29→32→640` 条件网络。C0 的条件输入为零，可学习常量残差；C1 使用本条样本的 29 维参考响应。两组都保留原参考贡献，并非“有参考网络／无参考网络”比较。每个分支的校正范数上限为该分支原贡献范数的 10%。该上限约束特征扰动，不保证准确率。

开放特征为单位化 64 维向量，共享关系评分器判断是否属于当前注册集合；旧类身份仍由原六类默认分类头给出。原融合特征保留，并通过零初始化有界残差连接开放分支。参考响应中显式 CFO 坐标 27 保持屏蔽，内部局部补偿保留；没有新增逐样本 clean 参考、信道逆或波形均衡。

这是同结构学习机制对照。C1 与 C0 的差异可用于评价新增参考条件输入；相对历史 M 的变化同时包含完整贡献输入及新增模块，不能全部归因于参考条件。

## 结果解释

C1 相对匹配 C0 的目标 R_U 增加 5.5556 个百分点，但 C_K 下降 2.7778 个百分点、A_K 下降 2.4306 个百分点。目标 AUROC 仅由 72.3036% 变为 72.3554%，源 AUROC 仅由 84.2250% 变为 84.2362%；这是点估计比较，不是显著性检验。不能把更强的拒绝倾向写成已解决已知／未知的可分性。

C1 的目标闭集正确数比原 F0 净少 7 条，造成 1.2153 个百分点损失；拒识器又拒掉 59 条候选原本能分对的旧类，造成 10.2431 个百分点损失。两部分合计 66 条、11.4583 个百分点。59 条正确误拒中，6-15 与 8-20 分别占 21、36 条；这是事后诊断，不能据此加入目标 TX 专属阈值或规则。与此同时，三未知类仍有 60、57、24 条被错误接收，拒识不足与误拒同时存在。

源端 42 组已知类约束均通过，但源 novel R_U 仍只有 38.9841%，跨 RX 后进一步暴露较弱的已知／未知分离。相对历史主 M，本轮目标 H 从 62.5231% 降至 55.7677%。因此保留本轮为负结果，不替换现行 PAMF，不扩展正式 RX 或多种子，也不以继续调阈值替代表征研究。

固定当前已校准 margin 和类别偏置，仅移动一个全局阈值也不能使这份 Q 同时达到 C_K≥90% 和 R_U≥90%。实现中的宏 AUROC 分别对已知 TX、未知 TX 等权；分数越大越倾向已知。因此对任意共同阈值 τ，有 `AUROC≥P(S_K≥τ,S_U<τ)=C_K(τ)×R_U(τ)`。两率均为 90% 要求 AUROC 至少为 81%；本轮为 72.3554%。这是同一完整 Q、同一宏权重下的必要条件，无需扫描目标阈值。它不排除重新学习分数、改变类别偏置或多变量判决，也不证明 AUROC≥81% 就足够达标。

后续优化需要重新检验跨 RX 身份结构与拒识分数的关系，并考虑保留同条星地 received 与恢复视图的互补身份信息。任何后续机制仍须源端开发、独立预登记；当前没有以这些目标 TX 诊断回收 Q、调参或启动新的适应／注册实验。
