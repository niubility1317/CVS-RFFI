# 因果包络耦合：同参数射频记忆原型

本原型尚未发布正式训练。依据是当前能量核心的实际12项记忆多项式输入、公共多项式表达及已完成的crossphase源侧负结果，不使用旧目标成绩。crossphase用相干替换位置功率后未超过原源控制，不能从一次替换对照确定损失究竟来自舍弃位置、anchor选择还是相干表示。本方案保留原读出，改变行为分支输入的物理基函数。

现有输入是 `z[n-m] (|z[n-m]|²/4)^q`，m=0至3、q=0至2；z是received IQ的原径向截幅，不是已知发射机激励。原型令 `P_bar[n]=(P[n]+P[n-l])/2`，l固定为1或4，然后用 `z[n-m] (P_bar[n-m]/4)^q`。仍为12个复数输入，所有深度、通道、投影、分类头及202553个参数不变，同seed初始state逐项一致。没有加载历史权重。

数学上，三阶项包含 `z[n-m] P[n-m-l]`；五阶项包含两时刻功率的乘积。它们一般不在原aligned多项式输入的线性张成空间内，但原整网后续非线性层可能近似形成交互，不能声称旧模型完全不能表达。P不受共同相位影响，故新基函数仍有相位charge1，继承最终读出的共同常相位性质；不清除received CFO，不宣称频率/RX/LTI不变。

通信和射频物理依据是信号与滞后包络的交叉记忆项。广义记忆多项式原论文显式包含aligned、lagging及leading包络项；本原型仅取两个因果包络时刻的固定平均，不是完整GMP，也不是数字预失真或PA系数辨识。[Morgan等，IEEE TSP，2006，式23至24](https://ieeexplore.ieee.org/document/1703853/)。原论文的PA建模结论不等于本RFF任务的识别优势。

在25MHz下，l=1与4分别对应40ns与160ns；延迟选择只是前瞻原型，尚未测量WiSig的真实器件记忆时间常数。received的RX滤波、非线性、噪声及均衡残差同样影响P_bar；这不能唯一恢复TX硬件，也不等于TX/RX因果分离。平均功率可能平滑有用瞬态，因此全部负结果仍需保留。

仓库此前rf_gmp是28项、有direct/image学习系数的独立算子，外接原残差网络；本原型在当前共享能量、整体相位结构内使用12项固定混合，原位置功率读出保留。不是重跑旧rf_gmp或依据其目标成绩组合模型。

本地仅用公共随机/退化IQ验证：同初始化/参数/state维度，显式多项式展开、因果性、lift线性空间反例、共同相位性质、CE所有梯度与state roundtrip。通过不代表源或clean改善。

正式源实验已准备为`20261002-phase1-cvs-coupled-identity-manysig-m8-r01`，按原数据/四seed/CE唯一/无增强/身份骨干/scratch/E200×50/完整FP32执行。56项聚焦测试和8个丢弃模型24次公共CE更新通过，唯一独立P0/P1审查PASS。source规则选中才冻结并做clean；控制保留时新候选测试N/A，目标结果不得回流。实际启动、状态和结果以对应run登记/报告及独立进程读回为准，本设计文档不证明运行或性能提升。
