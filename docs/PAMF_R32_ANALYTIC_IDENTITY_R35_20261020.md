# R35：R32 两行的固定解析 TX 归属对照

本轮在 R32 最终源预测和正式结果返回前固定诊断矩阵。R32 新增约束针对模拟小信号响应；R35 另检验它是否改善实际源 TX 的解析关联。R35 只读 R32 两行完成后的既有源 IQ，复用 R34 的指标、训练域校准和固定参考，不增加训练、分类头、恢复器/F 推理或目标访问。

## 固定矩阵

三行是 R17 源域选出的 `r17_reference`、R32 `pair_aug_control` 和 `observable_response`。原始受损 IQ 与 clean 参考共享。仅当 R32 两行均为完整 E20/4,940 更新且各自七视图 source 评分完成后才运行，不等待或读取 R32 正式目标集成绩。R35 不进入 R32 的源资格判断，不延迟或改变其自动正式测试；R33 的条件补测也不变。

三组固定配对比较为响应行减配对增强对照、配对增强对照减 R17、响应行减 R17。每组保留 clean、三郊区和三 urban，镜像不对称64、谱统计4、复参考残差24及等权综合92维，共三行×四组×七视图。所有总体/TX/RX/day 指标完整报告，不排名、不选择候选、不增加晋级阈值。

## 与 R34 一致的观测量

复用 R34 已固定的训练域均值/std、raw/R17 全部解析特征及原始物理 ID。原校准为训练 LU 缓存固定前8,192条（L6300/U1892，非均衡抽样），FP64累计、std下限0.05；本轮不重新读取训练 clean 校准，也不重新估计参数。R32 两行仅新增25,200次逐样本固定解析变换，0新神经网络预测。

先验证三行 source 来源、物理 ID、R34 校准权限、全部112解析特征单元的完整性与有限值；独立 CPU 评分进程随后才读取 V 标签。继承相同 cap2 的 clean TX×RX×day 参考库：参考 RX 和 day 均与 query 不同，参考格须六 TX 非零完整，格与其他五 TX 等权。同 TX 减其他 TX 平均余弦、正间隔比例和同包 clean 解析误差沿用 R34；配对行间差额在全部比较行与 raw/clean 共同有效记录上计算。

同样保留199次 RX×day 内 query 标签置换负控制（seed2026102034、参考库固定），它是描述性检查，不是 p 值或独立样本显著性。R34 的谱统计 clean 已低于该负控制；本轮仍原样保留并逐组解释，不能把其正增益当作 TX 真实性。R34 的 TX0/1 负间隔和 TX2 退化也不因均值提高而忽略。

run 为 `20261020-diagnostic-restoration-R32-analytic-identity-s2026092701-r35`，模块 `experiments.pamf_r32_analytic_identity.runner`，普通 N607、纯CPU2线程、0GPU，extract/score 顺序执行。R32 可独立继续训练或正式推理，不改其进程、源选模、损失或资源。新输出不可覆盖；精确 commit、命令、环境/CWD、路径和矩阵见预登记。

20项聚焦数学/协议检查、CLI help 和一次独立新输入/评分路径 P0/P1；发布沿用一次源句柄预检、单归档 SHA 比对、远端编译及实际执行产物核实。不加载任何 checkpoint，不增加 checkpoint smoke、数据重验或新签名链。输入/权限/路径错误、非有限值、冲突或不可运行属于技术失败，保留产物，不自动重试。

预期产物为启动及配置、两阶段记录与日志、R34 校准引用、112单元解析特征及物理ID、特征完成记录、1,260条分组、252条负控制、84条固定配对差、汇总和完成记录。单seed、同源域、相关视图；没有解码确认 payload 独立，没有新 TX、独立物理数据族或在轨证据。解析关联改善既不等于分类准确率，也不证明每个生成细节；整体70%／5个百分点和逐细节归属要求仍单独验收。
