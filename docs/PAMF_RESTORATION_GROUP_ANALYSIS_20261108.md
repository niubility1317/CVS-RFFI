# 星地恢复低城区的分组收益与损伤

2026-11-08。固定地面 Main split、同一 Tri-SIG-TIME SSL 冻结识别器和默认头；每版的两总体七景预测均先完成，再独立 truth-last 评分。本分析只汇总已评分结果，不新增预测、训练或目标数据访问，也不用目标分组调参、选模或建立路由。当前仍未达到六景距 raw clean 不超过 3 个百分点且两个 clean 总体均保持的目标。

低城区每版合计 168,000 条。DURA 准确率为 68.8012%；投影条件先验为 68.7381%，比 DURA 低 0.0631 个百分点；源接收机先验失配为 69.4905%，比 DURA 高 0.6893 个百分点；联合均值与协方差为 66.7095%，比 DURA 低 2.0917 个百分点。均为完整固定版本，不按组组合模型。

## 解释和下一步边界

- 结果支持把逐 TX、接收机、日期和净修复／损伤继续作为冻结后正式验收的必要报告，而不是只看总体准确率或波形误差。两总体 clean 仍须分别保持；先验失配版分别净少对 37、46 条，当前不能替代默认 DURA。
- 源域可研究接收机失配、细节保护和可靠度约束，但本表来自已暴露的目标测试，不能用具体 TX、接收机的真实标签选择模型、训练权重、阈值或推理路由。未知设备的保护仍需在既定权限下另行检验。
- 这是固定单模型种子、地面模拟信道和重复样本结果；同一物理记录的多场景模拟可能相关，不能把条数直接当成独立实验次数，也不能以此声称真实在轨或跨种子收益。
- TX 与接收机分组的 `count`、修复数、损伤数和净差由两总体相加复算，均与已公开的对应分组准确率差一致。按单一维度划分时各组合计均为 168,000；不同维度的组相互重叠，不能跨维度相加。
