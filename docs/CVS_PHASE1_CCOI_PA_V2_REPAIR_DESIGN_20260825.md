# CCOI-PA-V2：基于V1真实日志的定点修复设计

日期：2026-08-25

当前状态：V2设计、实现、本地验证和N607单seed C0–C4矩阵均已完成。真实checkpoint smoke、receiver导出、四场景prediction/truth和独立评分为`VERIFIED`；科学结论为`SCIENTIFIC_FAILURE_NO_PROMOTION`。

最终实验`PHASE1_CCOI_PA_V2_S20260824_20260825A`显示：最佳候选相对C1的LEO均值仅`+0.0095`个百分点，最佳LEO receiver-floor均值仅`+0.0361`个百分点，均未达到`+0.30`个百分点。C4 holdout NMSE相对C1下降`92.50%`且`R²=0.87407`，说明受控拟合链路有效；但真实配对相对shuffle仅改善`2.815%`。更关键的是，soft effective codes达到`35.216/48`时，hard argmax仍只有`4/48`个码被使用，top占比`70.52%`。因此V2否定了“receiver缺失或融合尺度失配是唯一瓶颈”，并定位出soft均衡不能替代离散挑战状态辨识。

## 1. 结论

V1已经证明训练与评估链路健康，但没有证明条件系统辨识有效。C0–C4均完成1,632,000条prediction与truth闭合，clean和三类LEO结果正常生成，无OOM、异常退出或非预期NaN；然而C2–C4相对同容量C1的LEO均值变化均小于0.01个百分点，远低于0.30个百分点晋级线。该结果应归类为`SCIENTIFIC_FAILURE_NO_PROMOTION`，不是训练故障。

V2只修复三个已证实问题：receiver元数据导出错误、算子logit量级未对齐、码本硬占用集中。冻结Core90、C0–C4归因结构、Phase1源域权限和全部评估场景保持不变。

## 2. V1证据与根因

### 2.1 receiver-floor无效

WiSig批次返回`(x,y,d,meta)`，移动后`extra=(d,meta)`。V1只在`extra`本身为映射时读取`rx_i`，因此没有进入嵌套`meta`，对目标receiver又回退到无法映射的domain值`-1`。这不影响总体准确率、分场景准确率或truth连接，但使receiver-floor不可用。

### 2.2 算子证据没有真正进入判决

V1设计写的是基线与算子证据的晚期融合，实际代码却执行`base_logits+alpha*operator_logits`。基础logit量级明显大于新初始化的算子logit，且`alpha≤0.2`，旁路只能造成极小扰动。源域校准只扫描alpha，没有校准两路尺度；因此“C2≈C1”不能单独否定条件响应，也可能是融合接口让条件响应不可见。

### 2.3 码本部分集中

48个码中33个被使用、15个未使用，最大码承担约49.5%的硬分配。V1已有均值分布到均匀分布的KL项，但权重较小，且没有直接约束最小有效码数和单码集中度。V2不强迫48码严格均匀，只要求软有效码数不低于36，且任一码的批次均值概率不高于0.10；超过阈值才产生惩罚。

## 3. V2实现

### 3.1 可核验receiver

元数据读取允许在tuple/list中递归寻找映射，但只读取明确的`rx_i`键。prediction写出前要求receiver可转换为非负整数；否则立即报错，避免再次得到形式完整但receiver指标虚假的artifact。独立scorer也拒绝主测试loader中的负值或未知receiver。

### 3.2 源域尺度标定凸融合

算子分类器先用自身logit在`L_s`和源域卫星视图上学习，避免梯度被小alpha缩弱。训练与选模仍只用合法源域角色。

在`V_cal`上分别计算每个样本去类别均值后的RMS：

\[
s=\operatorname{clip}\left(\frac{\operatorname{RMS}(\ell_{base})}{\operatorname{RMS}(\ell_{op})},0.25,20\right).
\]

最终融合为：

\[
\ell=(1-\alpha)\ell_{base}+\alpha s\ell_{op}.
\]

alpha网格为`0,0.05,0.10,0.20,0.35,0.50`。只按`V_cal`准确率选择，并列时选择更小alpha；因此算子没有源域证据时自动退回`alpha=0`。C0和所有`alpha=0`路径逐logit复现冻结基线。

### 3.3 有界码本平衡

对批次平均软分配`p_bar`计算熵和有效码数`exp(H(p_bar))`，同时计算`max(p_bar)`。损失只惩罚`有效码数<0.75K`或`max(p_bar)>0.10`的部分。该设计吸收了粘贴文本“覆盖度决定可辨识性”的思想，但否定了把每批强制成严格均匀配额的做法，因为严格配额可能制造不存在的挑战类型并损害真实结构。

## 4. 吸收、否定与合理性

V2继续吸收粘贴文本的核心：内容对齐只控制激励；设备特征应表示为挑战条件下的响应；需要集合级聚合、留出挑战预测和覆盖度诊断。V2还把“可辨识性不足时降低算子证据”落实为源域校准可选择`alpha=0`。

V2不接受三类扩大：不加入Soft-DTW、partial OT或多机制生成器；不使用目标域、query或receiver truth校准融合；不因V1负结果改变Core90和卫星增强基线。原因是这些变化会同时改变机制、数据权限或归因对象，无法判断修复是否有效。

这一取舍合理，因为V1已经把问题压缩到实现接口和表示利用率，而不是数据闭合或训练稳定性。先修复可观测错误，再用完全相同的C0–C4矩阵复验，能够回答“条件头无效”还是“条件头此前没有被正确使用”。

## 5. 预期判定

仍沿用V1门槛：C2或更高row相对C1的LEO均值和receiver-floor分别提升至少0.30个百分点，clean下降不超过0.50个百分点，三场景无被均值掩盖的大退化；C4 holdout NMSE相对C1下降至少5%且R²大于0。若尺度校准后alpha仍全部选择0，或真实q仍不优于shuffle，则结论是当前PA挑战表示没有独立判别价值，不再用增加融合权重掩盖负结果。
