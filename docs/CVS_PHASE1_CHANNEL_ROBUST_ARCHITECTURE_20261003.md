# Phase1架构研究：信道鲁棒性与射频指纹保留

2026-10-03。状态：第一轮结构实现、16份E200训练、源规则冻结及独立clean测试已完成，未取得测试识别提升。以下机制仍为研究假设；实际落地与结果见[实验记录](CVS_CHANNEL_ORDER_EXPERIMENT_20261003.md)。用户目标是仅凭Phase1形成独立论文，创新集中于神经网络结构；保持原训练流程和单一发射机分类交叉熵，不加入额外损失、数据增强、对抗训练、预训练或测试时适应。

## 研究问题

建议主线为：**在发射机、信道和接收机耦合的观测中，设计有选择地抑制传播失真、保留发射机判别信息的复数网络。**不能把“完全消除信道”或“恢复纯发射机指纹”当作已有结论。

接收链可写作：

\[
x=\mathcal R_r\!\left(\mathcal H_h\!\left(\mathcal T_y(s)\right)\right)+n.
\]

其中发射机和接收机算子可以非线性，信道在包内准静态条件下近似为线性卷积。只有在线性近似下，才能把接收机响应和信道合并为等效频响。接收机的非线性不能一般性地移到信道之前。

一个直接的不可辨识例子：若两发射机只差可逆线性滤波A，即T₂=A*T₁，并且允许的信道集合包含H₂=H₁*A⁻¹，则两者可能产生相同接收信号。对这个信道集合完全不变的表示也无法保留该发射机差异。这是本设计的数学动机，不是从历史目标分数推导的结构调整。有限阶、幅度受限等实际信道集合未必对任意A⁻¹封闭，因此结论的适用条件必须写清。

单一分类CE可以训练下述结构，但不能独自保证潜变量等于真实信道、正确分离TX/RX，或外推到任意新环境。合法源数据中同一TX跨接收机/日期的自然变化仍然重要；结构不能补回观测中不存在的可辨识信息。

## 建议结构：受限补偿与非线性运算次序交互

结构只围绕一个问题展开：线性传播失真会如何改变网络所见的非线性指纹？现有RFF physics-aware路径作为基础；普通attention只负责末端聚合，不作为主贡献。

### 1. 受限逐包复数补偿

小型上下文网络C读取当前包，输出少量系数a。用系数组合归一化的短复数滤波基Bₖ，形成Gₓ=I+Δₓ。一个可检验的参数化是：

\[
a=C(x),\qquad
\Delta_x=\rho\sum_{k=1}^{K}\frac{a_k}{\max(1,\sum_j|a_j|)}B_k,
\quad \|B_k\|_{2\to2}\leq1,\quad0<\rho<1.
\]

因此对每个固定输入得到的线性算子有‖Gₓ−I‖≤ρ，且‖Gₓv‖≤(1+ρ)‖v‖。短FIR基可用ℓ₁范数约束获得相应卷积算子上界；实现时必须固定边界模式并据实际算子验证。这个界约束放大程度，不代表整套输入条件网络具有相同Lipschitz常数。

Gₓ应称为“受限的判别式补偿算子”，不能叫真实H的估计或逆。系数在一个包内共享，不能每个采样点任意重写波形；不把上下文向量直接送入分类器，减少明显的环境捷径，但这种接线不能保证系数不携带TX信息。深衰落中不存在可靠信息时，有界算子也不能恢复丢失的信息。

推理只用当前包前向计算Gₓ，无梯度更新、RX编号、目标统计或跨query状态。这属于网络动态计算，不是额外训练策略或目标适应。

### 2. 共享复数非线性与运算次序差

用共享的可学习复数非线性模块F表示局部幅相耦合和memory效应。可沿用现有RFF结构，也可采用共享复卷积及幅度条件非线性。记

\[
u=F(x),\qquad v=F(G_xx),\qquad w=G_xF(x),\qquad d=v-w.
\]

F输出多个复特征通道时，Gₓ按相同时间滤波器逐通道作用于F(x)。两条路径必须共享F；w中的Gₓ沿用从原x计算的同一组系数，不能重新从F(x)估计，否则不再是同一算子的次序比较。

第一版应在首次下采样前的全采样率特征上构造d；不能把原IQ的FIR直接作用于降采样四倍后的特征，仍声称是同一物理算子。比较只用两路径的公共valid内区，或使用明确边界mask，排除padding导致的伪差异。逐包/逐层归一化放在d计算之后，避免将归一化不交换误解为非线性memory效应。

d直接表达“先做线性补偿再提非线性特征”和“先提非线性特征再做同一补偿”的差别。例如φ(z)=z|z|²时，φ(Hx)一般不等于Hφ(x)。这样，网络可以显式访问补偿对非线性模式的影响，不必完全依靠普通卷积隐式拟合。该结构是待验证假设：它可能对耦合失真有帮助，也可能主要响应接收机非线性或环境变化。

**d不是信道不变量，更不是TX独有特征。**若F是与Gₓ可交换的线性卷积，忽略边界时d为零；若Gₓ=I，d也为零。必须检测其实际输出、梯度和消融价值。初始化不能同时让d严格为零并让其唯一出口权重为零，避免交互分支被完全隔断。

F是网络构造的非线性映射，d并非对真实发射机或接收机非线性的直接测量。若F(0)=0且在相关有界输入域上为L_F-Lipschitz，则固定G下可得‖d(x)‖≤2ρL_F‖x‖；这只给出交互幅度上界，不证明鲁棒性。可采用G初始为I、滤波基非零、F已有非线性、d出口为非零小权重的方式保留初始输出并允许G获得梯度；不能同时把滤波基和系数置零。

### 3. 原信息与补偿信息联合读出

分类表示使用R(u,v,d)，保留原路径u；可以增加跨时间/频率的关系统计和已有可学习读出。原路径降低“补偿先抹除指纹、后端无从恢复”的风险，但也可能保留环境捷径，不能单靠skip声称指纹已经得到保护。

关系特征只针对明确定义的公共扰动做消除。例如同一频点、共享准静态通道的窗口比值在理想模型下能抵消公共因子，但噪声、深衰落和边界会破坏性质；同时也可能消去公共的线性TX响应。因此不建议把任意逐频归一化设为唯一输出通路。第一版无需再叠加独立的大型Transformer。

整个网络只优化L=CE(classifier(R(u,v,d)),y)。物理假设通过接线、共享参数和算子幅度限制体现，不通过增加loss实现。

## Phase1论文如何形成完整证据

建议的贡献不是三个模块名称，而是一条可证伪的因果链：受限补偿避免任意重写波形；次序交互暴露线性/非线性耦合；保留原路径允许分类器比较补偿收益与信息损失。是否改善泛化，要由冻结后的独立测试确认。

最小结构对照包括：原RFF网络、只加受限补偿、共享双路但无d、完整结构；再用去掉原路径和取消补偿幅度限制检验设计理由，并设参数/计算相近的普通复数网络控制。所有方法使用相同数据、单一CE、优化器、预算和seed。资源为次要比较，不为更少参数接受更低识别性能。

测试需要区分三种情况：同接收机跨真实信道、跨接收机尽量控制信道、二者同时变化。缺少受控采集时，只能报告“跨采集条件”或“跨接收机”结果，不能把效果归因于某一个因素。报告四seed配对结果、最差RX、逐TX/RX分层、特征漂移、实际补偿幅度、d的输出与梯度、训练/推理时间和内存。特征漂移下降必须结合类间可分性，防止把表示坍缩误判为鲁棒。

若增加合成物理机制测试，设计和强度应先冻结，训练不使用它们。对已经经过非线性RX的IQ再施加卷积，只能作为接收后等效扰动代理，不能宣称真实改变了TX与RX之间的传播信道。测试结果不回流调参、选模或选择性重跑。

当前契约为equalized=1、center256、unitRMS，首先只能研究剩余失真。要证明对原始多径的鲁棒性，必须另行明确原始IQ的可用性、物理样本划分和评估矩阵，不能静默替换输入或继承不匹配checkpoint。当前源V含已见RX，现有源选择分数也不是未见RX泛化证据。已公开查看过的历史测试不能重新称为盲测；论文确认集的安排需在新实验预登记中明确。

## 2026-10-03文献与可辨识性补核

本节是研究依据补充，不改变正在执行的读出模型或训练配置。原始来源核查与本项目推导分别说明；检索非穷尽，未建立首创结论。

- [ChaRRNets（2021），II-C/II-D及III](https://arxiv.org/html/2105.03568)：逐频公共复增益下构造等变均值与不变距离；原文明确STFT窗口边界会破坏物理卷积下的精确性质。实验还使用AWGN/CFO及部分多径增强，不能将其全部收益归于架构。
- [Shen等（2021预印本），IV-C及V](https://arxiv.org/html/2107.02867v1)：相邻STFT列相除再取对数幅度是已有信道处理；依赖相邻帧信道近似相同，训练另含triplet loss与增强。本项目不采用这些训练策略，也不能把相邻谱比重新命名为架构首创。
- [McAFF（2023），已核实摘要](https://arxiv.org/abs/2303.10691)：已有对IQ、CFO、FFT、STFT多表示的学习式注意力融合。该核查只覆盖摘要；当前读出控制不能仅凭“加入注意力”声称充分创新。
- [He等（2026预印本），II及III-B至III-D](https://arxiv.org/html/2603.08402v1)：已联合讨论信道与接收机耦合；利用重复LTF和相邻有效子载波谱比构造DSQ，再以CE训练CNN。其跨接收机部分需要源/目标接收机的匹配校准信号，并用MSE另训TCNN；验证为仿真。因而“同时考虑信道和RX”及“信道处理后CE分类”均非独有贡献；本任务保持无目标校准、无额外损失的边界，也不能将其完整系统与本实验直接作同协议数值比较。该文依赖特定LTF结构，不能从当前center256契约推断输入已满足这一前提。

以下是本项目的代数推导。理想逐频静态模型若为`X[f,m]=H[f]T_y[f]S[f,m]`，任何对任意非零逐频复增益严格不变的表示，也会消除处在同一作用族内的静态线性发射机响应`T_y[f]`。例如跨帧谱比与归一化外积`X_f X_f^H / ||X_f||²`都会消掉这个乘子。这个结论限于该线性、无噪声、非零增益模型，不表示真实RFF无法识别；非线性、时变失真或更受限的信道族可能保留可判别信息。

因此，后续架构需要同时回答两个具体问题：所施加的不变性对应哪一类信道作用；被保留下来的哪类接收信号变化仍能支持身份区分。仅有恒等式、参数增加或普通注意力不够。当前[读出控制实验](CVS_NEURAL_READOUT_20261003.md)检验局部相对相位和时间读出能力，但不证明任意信道不变，也不据此移植相邻谱比作为下一轮正式候选。深衰落、窗口边界与接收机非线性仍是未验证问题。
