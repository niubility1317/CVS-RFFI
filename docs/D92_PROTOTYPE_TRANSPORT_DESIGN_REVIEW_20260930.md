## 2. 数学核对

### 2.1 旋转、连续极限和零初始化

对非零块，w 为单位向量，`t=(I−wwᵀ)μ` 与 w 正交，`q=||t||≤||μ||≤1`。将设计式写成

`r'=ρ[cos(βq)w+A t]，A=sin(βq)/q=β sinc(βq)`，

可直接得到 `||r'||=ρ`，旋转角绝对值不超过 π/4。零块单独保持精确零，避免对零范数取单位方向。

设计给出的 β 导数正确：

`∂r'/∂β=ρ[−q sin(βq)w+cos(βq)t]`。

在 β=0 时，前向可直接返回原特征，但导数仍为 `ρt`；因此 adapter 不因两组参数全零而整体失活。η 的首步数据梯度确为零，β 非零后才一般可辨。几何对称、t=0 或退化 ν 的个别样本不保证非零梯度，日志不能把“通常可训练”写成每个参数必然更新。

对固定 w、ρ 的 δt，设计的方向导数

`δr'=ρ[Aδt+B t(tᵀδt)−β² sinc(βq)w(tᵀδt)]`

及 `B=[βq cos(βq)−sin(βq)]/q³` 正确。连续极限为 `A→β`、`B→−β³/3`。实现应使用稳定展开，不能先除零再清理 NaN。若输出伴随为 h，相应 VJP 是

`bar_t=ρ[A h+B t(tᵀh)−β² sinc(βq)t(wᵀh)]`，

再经过 `bar_μ=(I−wwᵀ)bar_t` 和 attention 导数。这里最后一项的转置方向必须保留；方向导数不能原样当作 VJP。

### 2.2 attention、核和伴随

固定 p、m、ν、J 时，设计的 attention 导数

`∂a_c/∂η_l=−a_c exp(η_l)[d_cl−Σ_j a_j d_jl]/ν`

正确。J 只由原特征距离确定，参数变化不触发离散邻域重选，故无需对 top-two 求导。边界并列全部纳入 J，避免按类别编号任意删类。

双分量距离等价于 `[φ0,φθ]/sqrt(2)` 的平方欧氏距离，具有合法半正定 Gaussian 核几何。零 β 前向精确沿用原 R0；其梯度只经过适配距离分量，必须乘 0.5。原距离和该折原始迹 s0 均为常量，但当前带宽、核中心化和 `gamma=s0/s_radial` 的反向仍必须完整保留。

`A=(K+I)⁻¹Y`、`V=(K+I)⁻¹(KcrossᵀG_S)`、`bar_K=−sym(VAᵀ)`、`bar_Kcross=G_SAᵀ` 的 ridge 伴随正确。每折一次 Cholesky 可以服务全部十个存储参数，不需要逐参数重拟合。

### 2.3 类风险与近端项

必须先跨所有内折累计每类 `ℓ_c=Σ h_i²/(2n_c)`，再计算 `L_data=sqrt(Σℓ_c²/C)`。其权重 `ℓ_c/(C L_data)` 正确；所有 ℓ 为零时采用零数据梯度。由此形成 G_S 后，各折复用前向缓存反传，无需再次拟合。

按折先求 RMS 再等权平均会改变目标；按 old/new 分组赋权也会改变目标。当前类对称 RMS 是明确的方法选择，全类损失相同时恢复类平均；均衡 K 时它与物理样本平均同尺度。近端项为 `||θ−anchor||²/(2N)`，梯度为 `(θ−anchor)/N`。N 增加时近端约束相对变弱，不能宣称它保证注册后旧类不下降。

## 3. Phase2、内折和继承边界

设计只训练由合法目标 support 驱动的共享特征 adapter；Phase1 encoder、BN 和原特征缓存固定，LocalRidge 是唯一最终分类器。它不读取源样本、逐样本源 feature、地面原型或摘要，不会扩张冻结地面原型的使用权限。合法目标 support 监督微调符合本次用户授权。

每个内头的 p、m、ν、J、带宽、中心化及原 s0 都由其 inner-train 独立构造。inner-held 的特征只供自身前向，标签参与共享参数训练损失；因此内层指标是训练指标。完整 outer-train 原型不得借给内折，outer-held 只用于冻结状态后的评分。

C_seq 继承同一 row、同一旧物理 support 的 θ_B 与最终旧原型。最终 C 原型表保留旧列、追加新列；内折仍从自身 inner-train 重建旧/新原型。θ_B 已受旧 support 标签监督，C 的旧 inner-held 标签通过它影响初始化属于真实顺序监督，不应将 C 内层分数解释为无偏持出评估。C_reset 是完整继承策略的对照。ν_C、邻居、全类头重算意味着“旧原型不变”不等于“旧类分数不变”。

每个 query 只使用自身原特征、固定原型与冻结 θ 生成映射，再面对全部注册类的同一 LocalRidge 头。J 限制特征 attention，不限制最终候选类别。整个规则不读 query truth、old/new/unknown 角色、query真实类别数量、配额或其他 query；不存在跨 query assignment。已注册类别表来自合法support，可以使用。最近原型、错类 max 和带宽并列采用类别对称处理，类别重命名不应改变方法。

K1 无合法内持出监督，保留 anchor；当前平衡 K1 的 B anchor 为零，故保持精确 R0。Nnew=0 直接复用对应 B。ν=0 的恒等 adapter 退化规则与 LocalRidge 的零带宽规则是两个独立判断，不能混写。

## 4. 稳定距离和有限优化合同

联合距离满足 `d_joint²≥0.5d_original²`。原特征相等时，固定原型下映射相等；原特征不等时，适配分量允许合并两点，但联合距离仍为正。因此原 tau0=0 的精确等价核及零导数可以复用；依据是冻结原分量，而非新映射全局可逆。

旧 Channel 的 `_checked_distances` 要求原/适配相等关系双向一致，不能直接套用；新实现应检查联合等价关系、下界和原相等输入的确定性映射。未分辨的正带宽、下溢、非有限值、正交残差或头残差异常属于技术失败，不应静默增加 epsilon、换邻居数或换核。

投影应是约束集合上的欧氏投影：β 按区间截断；η 可写成 `clip(v−λ,−b,b)`，其中 `b=log(2)/2`，λ 使五项之和为零。简单“截断后减均值”可能再次超界，不能替代该投影。归一化梯度、投影位移和 Armijo 使用同一当前目标及梯度；float64 比较容差应在实现配置中明确记录。

每次 trial 缓存必须与当前已接受缓存分开。只有 Armijo 接受后才替换当前参数与缓存；拒绝 trial 不得影响下一梯度。初始前向一次、每迭代最多三次 trial、最多四次迭代，给出 13 次完整目标前向和四次反向的上界。拒绝试探仍计费；有限预算耗尽是可报告的 solver 状态，不等于收敛或技术失败。最后接受态已被评估，无需额外“最佳步”前向。

旧 Channel 的非零参数 score 只有适配距离，不能直接复用。新 immutable state 和评分路径必须保存原/适配 support 特征、最终原型及完整头状态，评分显式组合两份距离；原 API 外形可以复用，数学语义不能删掉冻结原项。

## 6. 实装必要检查

以下是设计直接正确性检查，不新增审批、实验矩阵或性能门槛。

1. 零 β 的特征、距离、头和 score 精确 R0；正常非退化合成输入的 β 梯度可训练；η 首步零梯度、非零 β 后按有限差分核对；验证0.5梯度因子没有被快捷路径省略。
2. 非零 β 的全链条有限差分，包括旋转 VJP、attention、带宽、中心化、迹匹配、ridge 伴随和跨折 RMS；覆盖 q→0、零块、单类及全零类损失。并列位置核对声明的对称广义导数，不用不可微点的单侧差分假装唯一导数。
3. 对每折逐项核对 train/held 物理 ID 及 p/m/ν/J/s0 来源；改变 inner-held 标签不得改变这些几何统计，但允许改变训练损失与共享参数梯度。
4. 类别重命名、原型并列、支持行置换与 query 单样本/拼批预测等变；query 的 score 始终有全部注册类别列，不使用 batch 统计或角色。
5. 检查联合距离下界、原始相等输入的映射、合法适配分量合并、精确零带宽及近重复正带宽；拒绝旧 Channel 检查造成的假技术失败。
6. 检查 B→C 同 row 绑定、旧原型逐元素继承、内折原型重新构造、C_reset、N0 和 K1；禁止借用其他 row 的 θ_B 或完整原型。
7. 检查欧氏投影的盒界/零和、Armijo 接受/拒绝、零梯度/零位移/预算耗尽；被拒缓存不能污染接受态，每次前向、头分解和伴随求解必须可核对。
8. 检查非零参数 state.score 确实使用原/适配两分量，并核对持久状态和部署字节；峰值与时间实测前均记 N/A，不按80B推断完整资源开销。

这些检查通过后才可以说明对应数值行为已验证。本文件没有执行这些检查，也没有产生任何性能结论。
