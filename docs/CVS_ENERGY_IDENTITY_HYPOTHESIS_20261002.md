# 保留相对滤波能量的 RFF 身份网络原型

本轮仅检查结构原型，没有正式数据访问、权重继承、训练、选模或测试。本原型不改变正在运行的分数频偏校正实验，也不把合成检查当性能提升。依据来自原等变骨干的实际归一化公式和公共数学输入，不使用目标成绩。

## 被归一化删除的量

原 `RadialBlock` 在每个包、每个复数滤波通道中分别除以该通道的时间 RMS。径向门初始为 1、学习尺度初始为 1 时，非零滤波输出的每通道平均功率都接近 1。假设两个通道原功率比为 4，分别归一化后比例接近 1。学习到的固定通道尺度不能自动恢复逐包、随身份变化的原能量比例。径向门和更高阶时序统计仍可能携带信息，不能据此声称原模型删除了全部身份信息。

RFF 识别可能利用不同频带、不同记忆多项式分量间的相对响应。原行为基包含 1、3、5 阶及 0 至 3 点延迟；逐通道标准化会弱化这些分量的相对幅度。received 能量同时受到 TX、信道、RX 和既有均衡的影响，不把这种特征解释为独有 TX PA 系数。

## 本原型的作用

在每个复数 block 内改用一个全包、跨通道与时间共享的 RMS 分母：

`z'[c,n] = scale[c] z[c,n] / sqrt(mean_(c,n)|z[c,n]|² + epsilon)`。

所有通道共用同一正实增益，因此归一化本身保留通道功率比例；原学习尺度与径向门继续工作，门之后的比例可能变化。公共复相位与该运算交换，整体常相位性质保留。只改变归一化轴，不增加深度、宽度、学习参数或新损失，仍为 202553 参数。保留既有时间、频率、记忆行为与分类路径。

这里的模块来自本次新 scratch 构造，转换只复用该新模型自身刚初始化的参数，不加载任何历史权重。与原核心使用同一 seed 时全部初始化状态和参数结构相同，归一化是唯一差异。

## 证据边界与后续

合成检查覆盖通道功率比例、复相位交换、相同参数与初始化、零/弱/常量输入的有限 CE/全部参数梯度、严格状态读回。尚未证明源域或独立 clean 性能提升，不宣称任意 RX/LTI 不变或 TX/RX 因果分离。

当前分数校正实验完成后才依据合法源证据制定正式候选矩阵。正式实验继续沿用普通 CE、无增强、仅身份骨干、原物理划分、scratch、完整 FP32、性能优先的源规则；新候选选中并冻结后默认独立 clean 收尾。任何目标结果都不能回流本原型、矩阵、超参数或选择性重跑。
