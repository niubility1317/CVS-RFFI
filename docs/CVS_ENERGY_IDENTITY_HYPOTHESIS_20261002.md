# 保留相对滤波能量的 RFF 身份网络：源实验假设

本轮针对具体信息损失提出两个正式候选：逐包、逐滤波通道的 RMS 标准化会弱化滤波分量之间的相对能量。改为所有通道共享分母，保留这些比例，再由普通 CE 学习身份判别。原型检查通过，尚未证明源域或独立 clean 性能提升。依据是实际归一化公式、公共数学输入和冻结的源证据，不使用目标成绩。

## 被归一化删除的量

原 `RadialBlock` 在每个包、每个复数滤波通道中分别除以该通道的时间 RMS。径向门初始为 1、学习尺度初始为 1 时，非零滤波输出的每通道平均功率都接近 1。假设两个通道原功率比为 4，分别归一化后比例接近 1。学习到的固定通道尺度不能自动恢复逐包、随身份变化的原能量比例。径向门和更高阶时序统计仍可能携带信息，不能据此声称原模型删除了全部身份信息。

RFF 识别可能利用不同频带、不同记忆多项式分量间的相对响应。原行为基包含 1、3、5 阶及 0 至 3 点延迟；逐通道标准化会弱化这些分量的相对幅度。received 能量同时受到 TX、信道、RX 和既有均衡的影响，不把这种特征解释为独有 TX PA 系数。

## 候选的作用

在每个复数 block 内改用一个全包、跨通道与时间共享的 RMS 分母：

`z'[c,n] = scale[c] z[c,n] / sqrt(mean_(c,n)|z[c,n]|² + epsilon)`。

所有通道共用同一正实增益，因此归一化本身保留通道功率比例；原学习尺度与径向门继续工作，门之后的比例可能变化。公共复相位与该运算交换，整体常相位性质保留。只改变归一化轴，不增加深度、宽度、学习参数或新损失，仍为 202553 参数。保留既有时间、频率、记忆行为与分类路径。

这里的模块来自本次新 scratch 构造，转换只复用该新模型自身刚初始化的参数，不加载任何历史权重。与原核心使用同一 seed 时全部初始化状态和参数结构相同。输入已按原协议单位 RMS 归一化，保留的是相对滤波分量能量，没有恢复绝对发射功率。

|候选|身份核心输入|共享归一化|参数|
|---|---|---|---:|
|`energy_equivariant`|原 received 输入精确直通，α=0|六个时间/行为 block|202553|
|`energy_half`|全部 256 点固定 `x exp(-j 0.5 ω n)`，α=0.5|同一核心|202553|

只改变归一化轴，不增加深度、宽度、学习参数或新损失。保留现有时间、频率、记忆行为和分类路径，两者无学习对齐标量或坐标 conditioner。频偏估计沿用 25 Msps、窗口 80:160、滞后 20 重复相关，主值 ±625 kHz，歧义间隔 1.25 MHz。α 是固定波形校正比例，不是 TX/RX 晶振贡献比例。仅对有效且不跨主值分支的输入声明部分波形频率协变，不声明整网仿射相位不变。

本次矩阵依据冻结的源实验：原残差源性能优于原等变核心及全量/半量同步核心。前轮半量/学习校正较匹配全量校正略改善，但仍未超过原残差。因此当前验证核心是否删除相对能量，不依赖新增参数。设计输入只包括源证据和数学输入，不读取历史目标评分。

## 默认测试收尾与物理结论边界

新候选按源规则选中并冻结后，默认进行 `20261002-phase1-cvs-energy-clean-manysig-m24-r01`：四个新模型只预测 clean，二十份旧冻结对照只读复用，统一 24 行、168000 个物理 query、六 TX/七 RX，由独立 scorer 在预测固定后连接 truth。原残差胜出则保留已核实原测试，新候选测试 N/A，不查询未选模型。目标结果不得回流结构、α、超参数、选模或选择性重跑，不追加 LEO、SFT 或新增类。

“真正 RFF physics aware”的证据需要三个层面：运算对应明确的硬件失真机制；干预证据说明所保留身份信息及 RX/信道混淆；冻结模型在固定跨接收机测试上实际改善。当前只针对第一层的一个可检验信息损失，公共 TX/RX 同波形反例继续说明非唯一辨识。本轮即使性能改善，也不能仅凭共享归一化、常相位性质和 CE 就宣称完成 TX/RX 因果分离。
