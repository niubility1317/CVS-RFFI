# MV-KME-Ridge-v1（D92-MVKME-v1）

本候选检验固定 received IQ 的相位轨道和局部窗口经过冻结非线性编码器后，能否保留全窗口 identity160 与 FFT96 压缩掉的判别结构。方法标识为 `D92-MVKME-v1`。本设计由协议、数学和现有接口推导，没有读取目标评分来选择公式或参数，也不预先声称性能改善。

## 输入与权限

Phase1 的模型、参数和 buffer 完全冻结。每个物理样本只有 capsule 内原有的一份 received IQ。全部视图都是这份 IQ 的确定性数学变换，不调用 LEO 模拟、clean 参考或信道生成器，不增加 K。

训练接口仅接当前 row 的合法 support 表征、标签、物理 ID、注册类别和显式旧类成员表。不接 query、teacher、地面摘要、source IQ、source embedding 或 source loader。普通原型和量化摘要都不是本候选的输入；不存在借普通原型拟合分类头的问题。

query 逐样本使用冻结视图、Fourier 映射和分类头，不更新任何状态。固定无标签特征可以跨 row 缓存；学习得到的分类头和选参结果不得跨 row 持续训练或复用。prediction 冻结后才由独立 scorer 连接 truth。

## 固定视图与核均值

对复数输入 `x[256]`，窗口 0 是完整 IQ；窗口 1 至 3 分别截取起点 0、32、64 的 192 点，左右各补 32 个零。每个窗口采用相位 `0, π/2, π, 3π/2`，用 I/Q 交换与符号翻转实现。共 16 个视图，排列为 window 再 phase。

对每个视图，原生冻结 identity 前向输出 160 维向量，按 L2 范数归一化；范数不超过 `1e-12` 时输出零。每个补零后的窗口计算一次历史 FFT96。FFT 使用 float32 输入、逐样本减均值、以 `1e-8` 为阈值的 RMS 归一化、Hann 窗、FFTshift、log1p 幅度、96 点线性插值、减均值和 L2 归一化。该公式与已有 `spectral_logmag_sketch` 的固定 96 维分支一致，单独实现以免遮盖原生模型的 Python 包。

记 `z_jr` 为归一化 identity，`f_j` 为 FFT96，则

`u_jr = concat(z_jr, f_j) / sqrt(2)`。

固定 `Ω = Generator(PCG64(0)).standard_normal((128,256))`，float64，带宽为 1。映射为

`ψ(u) = concat(cos(Ωu), sin(Ωu)) / sqrt(128)`。

定义三个 256 维块：

- `r = ψ(u_00)`，原始视图；
- `g = mean_r ψ(u_0r)`，完整窗口四相位均值；
- `l = mean_(j=1..3,r=0..3) ψ(u_jr)`，局部窗口十二视图均值。

三个块不再归一化。Fourier 系数是预登记数学系数，不含 source 数据，也不是生成的源样本。

`φ_η = concat(sqrt(1-η) r, sqrt(η/2) g, sqrt(η/2) l)`，共 768 维。

先非线性映射再平均保留了部分视图分布结构。`g,l` 对四分之一圈相位旋转具有视图集合置换不变性，`r` 保留未强制不变的原始信息。裁剪会丢失部分内容，相位平均也可能抹去有效指纹；二者的收益是待检验假设。

这些变换不增加物理观测的信息量。新增的是相对已有压缩表示的非线性响应与局部信息，而不是新的独立信道样本。合成测试只检查本构造可证实的性质，不声称能证明有限观测间不存在任意线性映射。

## 当前 row 的辅助训练

设类数为 C，每类 K 个不同的物理 support，N=CK。中心化等类目标为

`Y_ic = 1[y_i=c] - 1/C`。

唯一训练目标为

`L(W) = ||ΦW-Y||_F²/(CK) + γ||W||_F²/C`。

闭式解：

`W = Φᵀ (ΦΦᵀ + KγI)^(-1)Y`。

计算采用 float64 Gram 特征分解；仅将浮点舍入级负特征值归零，明显非正定或非有限计算显式报错。对同一 η 与 fold，三个 γ 共用一次分解。query 分数为 `10 φ(x)ᵀW`，无额外拟合温度和类偏置。完全并列按物理 class ID 字典序决定。每类相同 K 保证等类权重；类别表置换仅置换输出。

## 固定参数与物理 support 选择

候选网格严格固定：`η=[0,0.5,1]`，`γ=[0.01,0.1,1]`，共九组。视图、窗口、随机种子、Fourier 维度、带宽和分数倍率均不搜索。

K1 使用 `η=0.5,γ=0.1`，不调用 holdout、不使用视图自验证、不借用其他 row 的 support。16 个视图先合成一个物理样本表征，不作为 16 条标签记录。

K≥2 使用 `F=min(K,3)`。每类按物理 ID 排序后，以位置模 F 分折；同一物理样本所有视图共同留出。每折按实际训练 K 计算 `Kγ`，不能将完整 K 错用于折内。每个物理 support 恰好得到一次 OOF 分数。

首先最小化旧、新类组宏平均 OOF NLL 的较大者，再比较全类宏平均 NLL；不存在的组不参与最大值。数值比较保留十位小数，最终并列选择较大 γ、较小 η。显式旧类成员只用于 support 选参风险计算，不用于 query 路由。最终按所选参数使用全部当前 row support 重拟合。

若合法物理 holdout 选择 η=0，这表示这些视图没有在该 row 的选择规则下提供优势；不能读取 query 结果后修改视图或重跑选择。

## API 与日志

- `make_received_views(received_iq[N,2,256]) -> [N,4,4,2,256]`。
- `received_fft96(received_iq[N,2,256]) -> [N,96]`。
- `build_fourier_blocks(received_iq=..., identity_views[N,4,4,160]=...) -> [N,3,256]`。
- `fit_mv_kme(support_blocks=..., support_labels=..., support_ids=..., classes=..., old_classes=...) -> MVKMEState`。
- `state.score(blocks[N,3,256])` 返回全部注册类分数；`state.predict()` 返回物理 class ID。
- `state.audit_dict()` 返回可序列化 JSON，不含系数大数组。

状态和数值数组只读。日志完整保存每候选每折实际训练 K、留出 K、物理样本数、Gram 维数、正则值、训练平方误差、正则损失、训练目标、各组 heldout NLL、固定分数倍率及温度、共享分解耗时、求解评分耗时和累计耗时。候选总体 OOF 结果和最终拟合也保留。共享分解耗时在三个 γ 记录中重复引用，不可简单相加当作总耗时；总耗时使用实际 `fit_seconds`。

闭式拟合没有 optimizer epoch、学习率或梯度更新；这些字段为 null 并说明原因。不记录虚构源域验证。非有限状态和结果显式报错。

## 资源核算

固定导出块若以 float32 保存，每物理样本每模型为 `3×256×4=3072` 字节，另计 ID 和元数据。每样本需 16 次冻结 native 前向；有完全匹配的原视图缓存时最多复用其中一次。新增视图特征不能从已有单视图 identity 缓存推导，必须报告实际前向次数和耗时。

每样本 Fourier 映射为约 `16×128×256=524288` 次乘加及 4096 次 sin/cos，另有四次 FFT96。头推理为 `768C` 次乘加。float64 W 为 `8×768C` 字节，C=26 时为 159744 字节；共享 Ω 为 262144 字节。`persistent_state_bytes` 明确仅统计两者数值存储，标识符、配置与日志另计，不能将其误报为完整进程内存或传输包大小。

N=520 时，单个 float64 Gram 矩阵为 2163200 字节。实现审计记录实际数组 `nbytes`、工作 support 表征字节及矩阵尺寸，不用估算代替实测峰值内存。冻结前向可用 GPU，辅助拟合可在 CPU 执行；本设计不虚构墙钟运行时间。

新增 source payload 为零。已有模型是否已部署由入口显式记录，按实际文件字节核算；不得把模型复用自动解释为通信总成本为零。

## 合成验证与边界

专门测试覆盖精确视图规则、历史 FFT 一致性（包括小幅度输入）、Fourier 范数与构造性非线性例子、轨道分支相位不变性、特征与评分分批不变、物理样本折叠完整性和实际训练 K、解析解与一阶驻点、类别和 support 排序等变、K1 的 26 类边界、零信号/重复退化状态、稳定并列、不可变数组、JSON 有限性及输入负测。

这些检查不构成性能验证。正式验收仍按预登记流程在不可变预测之后进行，不允许目标反馈进入训练、参数选择或重跑决定。
