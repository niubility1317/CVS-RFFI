## 来源、资源与机制核对

首尾联合损失恢复器使用 20,000 个合法源 U_s 拟合包及 500 个留出包，从随机状态训练 40,000 步。沿用 8 条 chirp、384 个中心点及 48 个实收原生边缘点的 W24 恢复结构。受扰半量风险在首尾两条与中间六条之间各分一半；新增首尾 clean 的恒等保真项。目标测试与源评估均使用同一冻结权重，恢复实际逐包运行，中心编辑固定乘 0.5。长训半量的匹配对照提供联合损失的整体对比，首尾权重和 clean 恒等项各自的独立贡献仍待消融。参数量 1,271,038，实测训练 18,864.90 s（约 5.24 小时），峰值 CUDA 张量分配约 3.18 GiB。同一 GPU 的源域 B1 恢复中位数／P95 为 75.56／91.56 ms，长训半量为 76.59／86.00 ms，均包含恢复器中心差量计算，不计 W24 分类和信道仿真。 [源训练登记](../../automation_reports/CV-SincNet/20261125-phase1-lora-w24-outer-objective-source-s2026112991-r01/report.md)

后续对比前核对了归档训练和推理的窗口实现。在 50 个仅有合法源 U_s IQ 的物理包上，分别检查原始输入和通用复数加噪输入。两套窗口使用相同包级中心 RMS 后，最大复数差异分别为 3.59×10⁻⁷ 和 4.81×10⁻⁷，归一化误差中位数均低于 7.4×10⁻⁸。两套重采样在该面板上对应到同一时间坐标，诊断零权重及零目标读取。另行匹配的 1,800 步两步／三步源筛查也已闭合；其短预算结果为独立证据。 [展开深度源筛查](../../automation_reports/CV-SincNet/20261126-phase1-lora-w24-third-prior-s2026112991-r01/report.md)
