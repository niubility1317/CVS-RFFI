# LoRa 实收复谱修正设计

## 决策和依据

新版先检验一个机制：在同一个粗恢复候选上，用当前包的实收证据分别估计幅度方向和相位方向值得回写多少。先验负责提出修正，观测求解负责限制改动，细化再核对两类方向。模型直接输出原裁窗复 IQ，供原冻结 Tri-set 识别。

此前两个 40,000 步候选在固定公共复谱后，相对匹配无约束全量在 Full 和 Residual 分别多判对 241 和 627 次。但两路最强读出仍比半量 DURA 少 26 和 99 次，且这两个最强读出属于不同推理规则。Residual 低城区 9–32 kHz 的独有分量复误差从 329.441 降至 178.291，复相关实部却从 0.0491 降至 0.0427。同一台冻结恢复器的另一次拆分表明，等修改量替换相位和幅度方向后，Residual 六景净增 171 次，低城区净减 17 次。固定公共分量适合保留为对照。固定全量相位回写也有风险。新版检验可观测的逐包方向收益，并以标量回写和等量回写对照隔离它的作用。 [公共锚定长训](../../automation_reports/CV-SincNet/20261124-phase1-lora-common-anchor-source-m4-r01/report.md) · [等量幅相拆分](../../automation_reports/CV-SincNet/20261124-diagnostic-lora-learned-split-source-m2-r01/report.md)

## 粗恢复、观测约束和细化

1. **提出复数修正。** 复用当前观测求解的两轮结构和相同预算的复 IQ 小网络。它读取原观测、重复结构、`Â`、`σ̂²`、组间预测残差和可用掩码，给出粗先验。先验和实收 IQ 在估计作用下做正则化观测求解，拟合项以有限区间内的估计精度加权。公共成分和零均值独有成分各保留一组修正。细化以原观测为共同起点，读取粗输出和反投影残差，重新提出累计修正并重算回写系数。
2. **保留方向。** 去扫、频移旋转和按包统一尺度之后，使用酉 FFT。按绝对频率 1–8、9–32、33–64 kHz 分带。独有分量先减六条的复均值。以该分量的实收复数相位为局部轴，把建议改动分成沿轴和正交轴两个实数方向。轴能量门限来自源 U。分解后仅在有效 chirp 中减方向均值，保证六条总和为零，同时让无效点的修正保持为零。少于两条有效 chirp 时该频点旁路。保留重新投影后两列真实的方向交叉项。公共方向单独使用其公共实收相位。两种分量的载波系数和这三带以外的系数回写均为零。
3. **计算剂量。** 每个频带、每种分量把两列实际将回写的复数方向记作 \(D=[d_a,d_\phi]\)。从当前包直接计算 \(H=\operatorname{Re}(D^*D)\)。风险头估计两列对恢复源波形方向的投影 \(b=\operatorname{Re}(D^*(x-y))\) 以及每列的不确定度 \(s\)。其中 \(x\) 仅在训练／源 U 校准提供，使用施加到 \(y\) 的同一接收坐标变换。推理只计算 \(\widehat b\)、\(s\) 和 \(H\)。从 2,500 个独立 U 校准包中预先分 1,250 个用于方向校准，其余用于 clean 门限。对前一组使用独立通用扰动，取逐包最大单侧标准化误差的预定 95% 分位数 \(\kappa\ge0\)，得到 \(b_-=\widehat b-\kappa s\)。方差头设正下限，最大值覆盖两轮和每个有效方向。对当前包的有效列求

   \[
   \underset{0\le g_a,g_\phi\le1}{\arg\max}\;
   2 b_-^\mathsf{T} g-g^\mathsf{T}(H+\lambda I)g.
   \]

   这是一个二维盒约束二次问题。检查内部驻点、四条边的极值和零更新，平局取较小的改动。\(\lambda\) 取该块平均方向能量的 0.01 倍，空列直接旁路。标量臂在同一问题里约束 \(g_a=g_\phi\)。同一损失形态可以跨频带分组，但量按各组真实基底计算。若 \(b_-\le b\) 逐列成立，目标值是该块平方误差改善的下界。源 U 覆盖只度量相同合法源分布条件下的表现，新接收机同时核查实际净纠错和风险覆盖失配。
4. **回写与旁路。** 将所有增量从频域转回原 IQ 坐标并叠加到原样本。首轮整包物理修改上限取实收 IQ RMS 的 10%，两臂共用。统一径向缩放保留构造中的零载波和独有零和；旁路时逐元素复制。记录激活和旁路 B1 延迟，分别报告恢复器及恢复器加冻结识别器。

与过去的实收公共锚定相比，公共分量允许在证据充分时作有界更新。与交叉留出逐包硬选相比，输出维度是同一候选的两个连续回写系数。SURE-LET 同样用二次风险组合多个去噪方向，但其原始白高斯设定用 Stein 风险估计。此处用合法源 IQ 对实收修正作复投影监督，部署依靠六窗观测，允许有色和相关扰动，并以冻结的设备识别检验收益。Noise2Self 利用测量子集之间的噪声独立性，本方案用两组重复估计失配，不以独立作为风险监督成立的前提。Shen 等以信道鲁棒特征训练识别器，本方案训练后回写复 IQ。创新检验限定在上述可配对的方向回写。 [Blu 与 Luisier 原论文](https://bigwww.epfl.ch/publications/blu0702.html) · [Noise2Self 原论文](https://proceedings.mlr.press/v97/batson19a.html) · [LoRa 信道鲁棒识别原论文](https://arxiv.org/abs/2107.02867) · [作者代码](https://github.com/gxhen/LoRa_RFFI)

## 连续训练与冻结验收

- **训练矩阵。** 标量与双方向各一臂。同一骨架、参数数、初始权重、优化日程、实际源 U ID 和扰动抽样序列。每臂从零一次连续训练 40,000 步，batch 24。5 台源 RX 均衡取 20,000 个拟合包，另取互斥的 2,500 个校准包及 500 个固定留出包。AdamW 同时更新两轮先验和风险头。相对作用用固定正则 LS，端到端梯度经过观测求解和回写。用源 U 复波形参考监督粗层、细层、方向风险头和保留弱源复谱差异。方向回归目标以当前实际回写基底计算，计算目标时对基底停止梯度。弱谱项对同一通用扰动下两份真实 U 波形的有符号差异计算，分别报公共和独有的 1–8、9–32、33–64 kHz 传递。在统一循环内逐步引入风险及细化损失，保留优化器状态。两路无元数据分流。只用独立的通用扰动。训练与校准隔离 TX 真值、冻结识别器、目标 IQ、目标统计和模拟真值。以预定末步冻结，记录固定留出轨迹、参数、实际 GPU、墙钟和峰值显存。
- **工程对照。** 原输入直通、匹配半量 DURA、仅同步、同步加正则 LS 和 MMSE/Wiener、仅学习恢复、两臂完整读出。仅同步对照仅在同步估计可辨时回写且使用有效边界。两臂完整读出采用同一校准和物理剂量上限，双方向终步另做同权同原始 IQ RMS 的标量对照。等量时将两个有效增量缩至较小者，任一无有效方向时该包取零。再分别旁路 `Â`、替换固定方差、冻结公共分量，定位来源。记录等量对照触发覆盖，避免把只出现在非零剂量的描述当作整集效果。
- **首轮识别。** 固定 900 个相同的合法源 V 包、五台源接收机、原冻结 Tri-set seed 2026092702。两路线均预测 clean 和六景，全部预测写定后独立 truth-last。双方向主读出需分别超过各路线匹配 DURA 的六景正确数，并维持直通与 DURA 中较高的 clean 正确数。机制比较报告同预算双方向对标量和同权等量方向对照的源配对区间。逐景、逐 RX、低城区给纠错、改错和净变化。复误差之外单列弱复谱的复相关、幅度和相位保真，比较两种估计的留出误差，按可观察置信分层。用物理包聚类并按 RX 分层重抽，以保留同包七景相关性。
- **正式矩阵。** 同一份最终权重、门限和推理规则覆盖 Full 和 Residual。冻结后在 15 台未见 RX、30,000 个相同物理包及原 Tri-set 三种子上完整预测，再独立评分。两路分别改善匹配原 DURA 的六景均值，clean 同时保持。Full 六景至少 67.0%，低城区至少 53.0%，clean 至少 64,490/90,000，并同包报告直通、已完成的半量 DURA 及当前最好冻结版本。六景距同方案 clean 至多 3 个百分点为进一步目标。按种子、场景、RX 和路线报告配对不确定性。目标结果不回流权重、门限或读出选择。 [正式基线和差距](OBSERVABLE_SATELLITE_RECOVERY_20261123.md)

## 设计验算

在 512 个确定性构造的两列问题中，边界加驻点的解均达到或超过 33×33 网格的最好目标值。保守收益目标从未高于实际平方误差改善。对 512 组掩码方向的实部和虚部单独回投后，六条之和的最大绝对误差为 \(4.45\times10^{-16}\)，无效点的最大改动为零。两列保守投影均小于零时解为零。例如 \(H+\lambda I=\left[\begin{smallmatrix}1&0.2\\0.2&1\end{smallmatrix}\right]\) 和 \(b_-=(-0.1,0.5)\) 时，两个方向各算系数得到 \(g=(0,0.5)\)，收益目标为 0.25。共用系数时，每个方向的系数为 \(1/6\)，收益目标为 0.06667。当前已完成数学验算，新版的源域和正式识别成绩待端到端训练及冻结评分。
