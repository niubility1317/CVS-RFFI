# LoRa 与 WiSig 接收端估计量及源域早期结果

两个候选均用当前包的接收 IQ 估计观测模型。每个 clean 和 practical 包都运行完整恢复器，再由冻结识别器读取该包的恢复输出。以下训练诊断来自源 U 留出波形，单位为各训练实现定义的无量纲误差。正式验收继续采用冻结后的同包识别准确率。

## LoRa W24

| 环节 | 接收量和估计方法 |
| --- | --- |
| 输入和坐标 | 每包八条原生 chirp，每条 1,024 个复采样点，采样率 1 MS/s。中心区按固定比例 48/125 重采样，取每条 384 点。W24 将每条两端各 24 个原生实测点与中心区拼为 432 点，使用由实测中心区得到的包级 RMS 归一化。恢复器由中心区实测 IQ 计算相位旋转、相干性和逐 chirp RMS。 |
| 边缘观测 | 对两端分别计算归一化能量的截断对数与相邻复采样乘积的实部和虚部，共六个条件量。 |
| 观测算子 | 估计直达复系数、镜像复系数和一采样点移位分量，局部系数与对数超额项按四点块聚合。对相位对齐且归一化的中心 IQ 做单位化 FFT，取绝对频率索引大于 64 的频点功率中位数，除以 ln 2 后截断，再结合学习的超额项得到逐位置有效方差。该量以归一化观测残差为标度，含噪声及观测模型失配。 |
| 求解和输出 | 两次先验与观测约束更新，各做两步共轭梯度。末步相对于接收 IQ 的修正乘固定系数 0.5，撤销相位变换与 RMS 归一化后写回中心区。识别器读取恢复后的中心区和同一包实测边缘。 |

恢复器以 IQ、按固定位置切出的边缘和由这些样本计算的统计量为输入，无需另外采集空闲段或提供仿真侧信息。新旧训练共享源归档提交 `7615e8e4024e7f38688ffe69db3f632f5256f613` 的 `dura_w24_model.py` 和 `dura_capacity.py` 前向。 [训练登记](../../automation_reports/CV-SincNet/20261125-phase1-lora-w24-outer-objective-source-s2026112991-r01/report.md) · [部署读出](../../experiments/pamf_lora_main/w24_formal.py#L195) · [原 W24 冻结测试](LORA_W24_UNGATED_FORMAL_20261125.md)

在同一份 500 包源 U 留出集上，第 1,800 步新配方的半量读出误差下降约 5.40%，全量末步误差上升约 13.41%。半量读出按八条 chirp 等权比较，在新日志上用首尾均值的 25% 与中间均值的 75% 重算。

| --- | ---: | ---: |
| 粗恢复误差 | 0.139435 | 0.135826 |
| 第一阶段观测约束输出误差 | 0.160812 | 0.158952 |
| 全量末步输出误差 | 0.780126 | 0.884778 |
| 半量读出误差，八条 chirp 等权 | 0.661839 | 0.626123 |

## WiSig 居中 FIR

| 环节 | 接收量和估计方法 |
| --- | --- |
| 输入和坐标 | 每包读取一个 256 点、25 MS/s 的原生复采样窗。两路线均使用已登记的 `post_sync/noeq` 视图。输入按当前窗 RMS 归一化，恢复后乘回 RMS，路线名无需传入恢复网络。 |
| 观测算子 | 从归一化接收 IQ 与粗估计共同拟合居中的 81 抽头复 FIR 和逐点直达、镜像系数，FIR 使用反射边界。每包另估计一个观测残差方差标度，映射范围为 10⁻⁶ 至 0.5，由观测残差似然训练。 |
| 逐频观测权重 | 两个候选组首阶段和第二阶段的观测精度倍率均为 8 和 1。固定组各频点权重为 1。逐频组取接收 IQ 与当前观测模型创新量的对数频谱功率，经频率中心化后生成逐频权重。权重几何均值为 1，各频点在 0.25 至 4 之间，表示相对观测精度。求解中同一个权重作用于右端项和正规算子。 |
| 求解和输出 | 两阶段各做两步共轭梯度，两个候选均逐包提交末步恢复 IQ。 |

观测量均可从当前窗口复算。两组复用源归档提交 `ef9f4c227ce57c79dc17a3aeb599395cc25d883b` 中 `wisig_native_fir.py` 的居中 FIR。现有训练记录支持对同包 IQ 拟合误差的比较，尚缺绝对方差、复 FIR 抽头和逐频幅相估计的独立误差测量。R69 的历史训练监督与正式推理输入另有记录。 [训练登记](../../automation_reports/CV-SincNet/20261125-phase1-wisig-spectral-precision-source-m2-r01/report.md) · [逐频算子](../../experiments/pamf_unrolled_restore/wisig_spectral_precision.py) · [R69 与冻结测试](WISIG_UNGATED_CLEAN_MAIN_20261125.md)
