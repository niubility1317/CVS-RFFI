# LoRa 与 WiSig 信道恢复的文献对照

本项目在固定识别器前恢复包级复 IQ。最终比较使用同一批物理包、同一实收视图和同一识别器。文献中的解调误码、估计误差、特征分类和图像重建分别对应不同任务。以下只对照与当前接收输入、估计量和训练监督直接相关的机制。 [项目目标](../goals/OBSERVABLE_SATELLITE_RECOVERY_LORA_WISIG.md) · [数据协议](../PROJECT_PROTOCOL.md)

## 已发表方法与本项目的差别

## 当前接收估计量的解释

- **接收作用 `Â`。** WiSig 的短训练重复可估计局部相对相位与重叠一致性。对于名义周期 20 点的窗口，假如参与拟合的区间严格周期，FIR 的两个相隔 20 点的输入列在共同有效区内重合。用该区间拟合出的算子只约束被激励的分量。前缀过渡和非重复段能补充约束，但覆盖与残差应单列。LoRa 可从实收 chirp 重复和公开参考估计共享作用，保留 chirp 独有部分和识别器所用边缘。
- **有效方差 `σ̂²`。** 对已对齐、同尺度、共享同一信号的两段重复，独立等方差噪声下，复差分均方除以 2 才是每段复噪声功率。去相位、幅度比、相关噪声、时变作用和模板失配会改变这个关系。短训练差分先记为观测残差功率，并明确复功率和每实分量方差的口径。R69 的窗口标量由网络估计，影响先验的反投影残差及求解权重，直接替换需要匹配量纲和有效作用语义。 [R69 推理定义](../DURA_V1.md)
- **恢复置信度。** 是否启用恢复、估计器可解释多少实收 IQ、求解器使用何种方差是三个量。当前 WiSig Main 常规盲矩阵的每条路线各有 1,008,000 次受扰观测，两候选各仅激活 50 次，说明门控选择已限制实际可改变的类别。源 V 上只保留 R69 的估计 FIR，相对单位作用两路线六景各多判对 1,306 / 10,800。把短训练差分直接当方差，clean 从 1,775 降到 1,527 / 1,800。两项源证据来自 `20261125-diagnostic-wisig-r69-observation-source-m2-r01`，门控统计来自 `20261125-phase1-wisig-dura-estimated-main-m2-r01` 的四份冻结预测。
- **波形保真及识别。** 已完成的 LoRa 同预算对照中，额外主带保真损失把源域弱复谱误差再降 3.63%，目标 Full 六景少判对 99 / 18,000。后续机制收益需要通过同训练预算、同接收窗口、同冻结识别器的比较，并保留逐景、逐接收机的改对、改错和 clean。 [LoRa 主带对照](../../automation_reports/CV-SincNet/20261125-phase1-lora-w24-native-mainband-m2-r01/report.md)

当前有证据定位可用观测与失效机制。若要把接收端 FIR、有效方差或保守更新声明为新贡献，需用合法源 IQ 固定实现、预算和推理规则，再由独立正式测试证明相应机制的单独收益。
