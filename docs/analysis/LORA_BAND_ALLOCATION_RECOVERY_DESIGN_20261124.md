# LoRa 等量分带恢复设计

首版检验一个机制。保持每包在原始复 IQ 坐标中的总修正量，用实收前导判断修正应落在哪些频带。频带内沿用已有解析修正的复数方向，用正实数缩放，避免网络再次自由旋转弱复谱。Full 和 Residual 使用同一套权重、阈值和推理规则。当前阶段是设计，模型名称待验证后确定。

## 粗恢复、观测约束与细化

1. **构造固定方向。** 复用合法源 U 的跨频复协方差。去扫后将六条重复按正交坐标分为一个公共分量和五个差分分量，形成方差保持的非载波解析修正 \(d\)。按已有规则作半量回写，整包实际编辑 RMS 上限为实收 IQ 的 15%。FFT 用酉归一化。对 \(d\) 取绝对频率 1–8、9–32、33–128 kHz 三段，保留零频载波。每段 \(d_b\) 回原 IQ 坐标后计算平方范数 \(q_b\)，包含实际逐 chirp RMS。三个频带正交，因此总修正平方范数等于三个 \(q_b\) 之和。同一个增益乘该带的六条修正，保留该带内的相位和公共／独有相对比例。
2. **估计各带值得回写多少。** 粗分支只读实收统计、外带方差、按频带分离的重复置信和源 U 先验，估计三段复投影的收益及不确定度。合法源参考为 \(x\) 时，监督量为 \(h_b=\operatorname{Re}\langle d_b,x-y\rangle\)，其中 \(x,y,d_b\) 已在同一原采样坐标和尺度。沿第 \(b\) 带回写 \(g_b d_b\) 的平方误差收益是 \(2g_bh_b-g_b^2q_b\)。训练预测归一化投影 \(t_b=h_b/q_b\) 及其误差尺度，倍率 \(v_b=\operatorname{clip}(t_b^-,0.5,1.5)\)。\(t_b^-\) 是减去不确定度裕量的预测。无有效方向时该带更新为零，置信不足时保留该带原解析剂量。
3. **施加等总量约束。** 设 \(e_b=q_bv_b^2\)。对可重新分配的频带取 \(u_b=\operatorname{clip}(\eta e_b,0.25q_b,2.25q_b)\)，选共同正比例 \(\eta\) 使 \(\sum_bu_b=\sum_bq_b\)，冻结和空带也计入两边。每个区间包含原始 \(q_b\)，因此有可行解。实现按最多六个截断边界求分段线性解，在活动区间保留对 \(e_b\) 的梯度。最终 \(g_b=\sqrt{u_b/q_b}\)。用同权的 \(g_b=1\) 作为直接消融。对无有效再分配的包沿用原解析比例。对门关闭、跟踪失败或数值无效的包直通。记录旁路原因、逐带剂量和总量误差。
4. **细化并回写。** 在粗层回写之后计算实收与相对前向预测之间的残差。相对模型只在重复段可验证的分量施加约束，以接收方差和留出失配加权。细分支读粗层预测、接收残差和原有特征，再估计一次 \(t_b^-\)，重新执行同量求解。观测损失只惩罚超出接收残差预算的部分，防止模型靠拟合噪声降低残差。最后将频带增量映回原 IQ。若相对作用为单位，等量条件使只看整包能量的残差项失去区分度，因此保留逐带留出残差和弱复谱监督。

解析工程对照用同样的方向和总量，把各带源方差扣除后的正超额能量和外带方差折算的带能量各取一半，作为拟议分配比例。有效带的拟议能量下限取原带能量的百万分之一，两项都无有效观测时保留原配比。再将有效带比例投影到同一上下界。这两项是观测代理。低信噪比下，弱指纹可能和干扰占据同一方向。分带只能调整已有方向的回写量。Boll 的谱减从非语音活动估计噪声谱，SURE-LET 用风险估计组合基础去噪量。这里用同包接收量和合法源 IQ 学习复投影，在实际 IQ RMS 一致时评价冻结 RFFI。已有 LoRa 信道鲁棒 RFFI 工作主要训练特征与识别器，本方案冻结后输出复 IQ。独立机制证据来自同权同量消融，效果和创新性都待验证。 [Boll 原论文](https://doi.org/10.1109/TASSP.1979.1163209) · [SURE-LET 原论文](https://bigwww.epfl.ch/publications/blu0702.html) · [LoRa 指纹原论文](https://arxiv.org/abs/2107.02867) · [作者实现](https://github.com/gxhen/LoRa_RFFI)

## 训练与首轮测试

- **隔离归因。** 先固定解析方向、同包激活集和原 IQ RMS，交叉替换各带能量与各带复方向。至少报告解析方向／解析带能量、解析方向／精确带能量、精确方向／解析带能量、精确方向／精确带能量，以及只替换 1–8、9–32 或 33–128 kHz 方向的读出。精确方向与能量取自隔离的非载波扣噪。诊断运行与候选的训练、校准、选模及部署隔离。若带内方向解释主要差距，记录为分配机制的限制。
- **工程对照。** 直通、仅同步、同步加正则 LS 和频域 MMSE/Wiener、包内半盲相对增益、固定解析半量和解析分带。同步对照单列粗细频偏、有效时偏和可辨识的采样时钟漂移。仅对可由留出重复验证的相对偏移施加补偿，回采到原长度和采样率，保留公共基准相位和功率。按前导长度、置信及失配分组审计。共用短窗、原坐标、同一旁路。另保留半量 DURA。新增观测量的消融分别把相对作用置单位、把实收噪声方差换为源校准常量，并保留原权重和其余估计量。
- **端到端学习。** 用 20,000 个合法源 U 包，batch 24，一次连续训练 40,000 步，共抽取 960,000 个物理包实例。粗层、观测约束和细层在同一个 AdamW 循环优化，保留状态至终步。同权 \(g_b=1\) 消融共享全部权重、数据、预算和前向调用，最后一步关闭分带重分配。在固定整包能量时共同增益恒为 1，单独训练共同增益没有额外自由度。参考损失使用原始地面源 IQ 及同包的两份独立通用受扰 IQ。权重调整按预登记步数。损失含按带复误差、合法源包之间真实弱差异的幅相保真、前向留出残差、方差置信和 clean 恒等。以共享通用扰动的源 IQ 对监督有符号复差异，按公共和独有分量分别归一化。源 V、TX、识别器、目标数据、模拟信道参数和真实噪声隔离于训练和冻结。2,500 个独立 U 用于门限与风险校准，500 个 U 留出监控曲线。若重校 clean 门限，预分 1,250 包。用其余两个互斥子集先校准粗层，再以冻结粗层校准细层。各层都按逐包有效频带中最大的标准化高估取单侧 97.5% 有限样本分位，覆盖仅对应源校准分布。用末步作固定 checkpoint。健康训练走满预算，按 N607 的实际空闲容量并行独立任务，批处理前导、FFT 和留出方程。
- **单种子源域。** 源 V 固定 900 个物理包，Tri-set 种子 2026092702。两路线分别跑 clean 加六景。矩阵涵盖上述工程读出、学习粗层、无前向约束、完整联合和同权等量消融。两路线预测全部固定后独立 truth-last 评分。主候选晋级要求每条路线六景正确数超过同次匹配 DURA，clean 正确数持平或提高。低城区和逐 RX 都保留正负结果。分带机制的独立收益另外要求同权同量增益及配对区间支持结论。

## 正式矩阵与报告

仅源域通过后的已冻结候选进入 15 台未见 RX、30,000 个物理包和三种子 2026092701／02／03。每路线七个视图。新方法两路线共享单一恢复权重、阈值和推理规则。Full 同包比较直通、历史半量 DURA 与既有最好冻结版本；Residual 同包比较直通与原冻结 Residual R69 半量。匹配的原冻结预测可逐物理包复用；缺失的对照先补齐。Full 的正式下限为六景 67.0%、低强城区 53.0%、clean 64,490/90,000。两条路线分别提高匹配 DURA 的六景并保持 clean。Full 六景离同方案 clean 不超过 3 个百分点为进一步目标。 [LoRa 三种子基线](OBSERVABLE_SATELLITE_RECOVERY_20261123.md) · [项目验收目标](../goals/OBSERVABLE_SATELLITE_RECOVERY_LORA_WISIG.md)

每轮给出冻结测试结果或明确的未评分项。报告按路线、种子、场景、接收机的正确数、分母、clean、同包错变对与对变错及净差。在各 RX 内按物理包配对重抽，将同一包跨景、跨种子的判定作为同一簇，另给逐 RX 与跨路线区间。保存原时间坐标、物理 RMS、触发比例、逐带复相关、幅相误差和独有分量保真，按实收质量分层。另记录可训练参数、冻结先验大小、优化步数、处理包数、墙钟、峰值显存、恢复器及恢复加识别的 B1 分位时延。全部正式预测固定后再由独立评分器接入真值。

## 设计数值验算

在 1,600 个随机复六窗中，用不等的逐窗 RMS、单位模回写相位和部分固定频带检查预算。三个频带覆盖 16、48、191 个频点，非载波恰好覆盖一次。原 IQ 修正 RMS 的最大相对误差为 3.775×10⁻¹⁵，分带平方能量和的最大相对误差为 7.772×10⁻¹⁵。固定频带增益逐项为 1，零频编辑为零。验算使用浮点双精度和二分参考解，检验同量与载波性质。本轮没有新增训练或识别测试。
