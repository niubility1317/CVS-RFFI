# LoRa 载波跟踪泄漏与弱旁带可预测性

实收载波的频偏特征可以解释一部分弱带误差。检查目标复谱的坐标之后，这部分收益主要来自强载波的谱泄漏。在原地面坐标中，9–32 kHz 的逐 chirp 独有弱旁带基本无法用这一组载波特征预测。

## 源域测量

从合法源 U 调取 20,000 个物理包，每台源接收机 4,000 包。另有互斥的 500 包留出，每台 100 包。每折只用其他四台接收机的 16,000 包拟合，在留出的第五台上评分。各角色均从登记的 1 MS/s 原始源 U 记录提取六条 256 点复 IQ。没有识别器、源 V、TX 标签、目标或真实仿真信道与噪声读取。

接收量是每条 chirp 的相对载波幅度、跨 chirp 的相对有效频移和有效频移平均值。另测加入相邻窗去频移相位的对照。所有量来自当前包的六窗和公开参考。有效频移保留时偏、频偏、跟踪误差及硬件变化的混合，绝对包增益和相位不进入特征。模型是同数据、同预算的固定岭回归，分别预测每个弱旁带的实部和虚部。平移一包的条件量作负对照。广义线性复估计使用复数及其共轭，这里用实值载波特征直接拟合 I/Q，并检验估计是否关联可用的具体接收量。LoRa 既有工作使用 CFO 作为识别特征，也记录其时变；本试验只预测弱复谱。 [复数估计原论文](https://ieeexplore.ieee.org/document/403373) · [LoRa CFO 与指纹原论文](https://arxiv.org/abs/2101.01668)

各折分别测原始地面 IQ、独立圆复噪声和目标独立通用突发。后两种条件从其各自受扰 IQ 估计载波信息。比较一个无条件源均值与三个条件特征子集，对同一合法源波形构造三个参考。第一种将地面完整 IQ 除以受扰包的跟踪相位与尺度。第二种先在地面坐标分离出拟合的单载波，再将其余地面 IQ 映入同一个受扰坐标。第三种直接使用原地面坐标的去载波复谱。三个参考均只在源 U 测量侧使用。

## 9–32 kHz 实测结果

下表为相对同折无条件均值的复平方误差降幅，各格取五台留出接收机中位数。使用载波相对幅度及有效频移，不含相邻窗相位。正数表示复误差下降。

| 源 U 观测 | 参考 | 公共成分 | 逐 chirp 独有成分 |
| --- | --- | ---: | ---: |
| 地面 IQ | 自身坐标 | +16.26% | +1.17% |
| 独立圆复噪声 | 完整地面 IQ 映入受扰坐标 | +17.88% | +45.82% |
| 独立圆复噪声 | 先扣主载波再映入受扰坐标 | +17.64% | +1.30% |
| 独立圆复噪声 | 原地面弱旁带坐标 | +17.83% | +0.11% |
| 通用突发 | 完整地面 IQ 映入受扰坐标 | +29.38% | +89.46% |
| 通用突发 | 先扣主载波再映入受扰坐标 | +10.37% | +19.18% |
| 通用突发 | 原地面弱旁带坐标 | +10.17% | −0.34% |

通用突发中，完整参考的 9–32 kHz 独有成分五台 RX 的降幅范围为 +71.55% 至 +89.83%。改为原地面弱旁带以后，范围变为 −1.02% 至 +3.78%。只看载波相对幅度时，中位数为 −0.17%。把幅度、频移条件量平移一包后，原地面独有弱旁带中位数为 −1.41%。部分公共谱保留可预测性，通用突发下原地面坐标的范围是 −7.49% 至 +16.26%。该试验只说明对这组特征与固定回归器的测量结果。

这项对照揭示了波形监督中的一个混淆。用受扰跟踪坐标计算源参考时，原地面载波会进入其他频点。训练可能降低这个容易回归的强分量误差，却未改善同频带的原有弱指纹。后续分带复方向比较应在同一个预登记矩阵中检验完整参考和先分离主载波的参考，并沿用相同的实收处理与 IQ 回写坐标。当前解析载波特征不能直接作为逐 chirp 弱谱重建依据。
