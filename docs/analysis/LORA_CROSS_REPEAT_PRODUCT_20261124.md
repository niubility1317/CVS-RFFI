# LoRa 跨重复频谱乘积的源域可观测性

跨组复数乘积在独立噪声下改善了公共弱谱预测。在通用突发下改善很小，两个受扰条件的独有弱谱误差均上升。后续固定工程对照只让乘积项进入公共修正。

从登记的未加扰源 U 选取 20,000 个拟合包及独立 500 个留出包。五个折各用四台源接收机拟合，在剩余一台的 100 个包上评分。地面、独立圆复噪声和通用突发分别用同样的物理包、角色和固定种子。每包六条 chirp 按索引间隔三分组成三组。预测一组时读取其余两组，不读取该组实收。预测目标用地面源 IQ 各自跟踪坐标的去载波弱谱，按对应地面载波幅度归一。这样避免用受扰跟踪造成的强载波泄漏为回归提供容易解释的目标。 [同源载波泄漏分离结果](LORA_CARRIER_LEAKAGE_20261124.md)

线性模型保留目标频点、共轭镜像和左右邻项。乘积模型额外使用八个固定偏置 (l) 上的 (Z_a(l)Z_b(k-l))，交换两组求平均。负对照在预测构造时将第二组频谱的包序滚动一位，再形成乘积。三个模型用相同正则强度的逐折逐频闭式岭回归。误差拆成公共均值和逐 chirp 独有量。

Mendel 讨论加性高斯过程对高阶累积量的性质，Bendory 等在多参考对齐中使用双谱恢复傅里叶相位。这里的乘积用于构造具体 LoRa 频点的复预测增量，保留由实收前导给出的相位基准。独立噪声下跨响应乘积可以压低同一观测内的乘积偏差。窗跟踪、相关干扰和真实 chirp 差异仍可能影响该关系，因此分别报告三种观测条件的实测误差。 [Mendel 原文](https://sipi.usc.edu/~mendel/publications/HOSATutorial.pdf) · [Bendory 等原论文](https://arxiv.org/abs/1705.00641)

表中正值为复平方误差减少，指标为相对同折线性基线的五台 RX 中位数。独立噪声下，9–32 kHz 公共项同包增益的逐 RX 范围为 +0.99% 至 +21.58%，错包为 +7.15% 至 +10.96%。错包也有部分改善，说明统计特征与额外拟合自由度均可能贡献。结果用于检验当前信息来源的适用范围。错包对照只运行在源 U 测量，冻结工程比较只访问当前包。
