# LoRa 与 WiSig 信道恢复研发复盘

2026-11-26。复盘覆盖两个历史聊天的恢复研发、DURA R02–R17 的早期谱系、LoRa W24 与 WiSig 后续路线。结果按数据集、冻结识别器、输入口径和证据范围引用。源域已知信道与精确扣噪仅用于定位误差。正式目标评分仅用于报告和验收。

## 一、现有证据支持的判断

1. **LoRa 已经有可复现的全量测试收益，距离目标仍大。** 40,000 步 W24 DURA 在 Full 六景达 137,631/180,000（76.4617%），low urban 达 15,660/30,000（52.20%），clean 为 28,539/30,000（95.13%）。相对当前 90%／85%／28,566 的目标，分别少 24,369 次、9,840 次和 27 次正确判定。相对旧半量复响应，六景净增 3,818 次，95% 按 RX 分层的配对区间约为 [3,498，4,109]。
2. **LoRa 的主要可恢复信号在中心窗，首尾 chirp 和原生边缘都值得单独验证。** 源域精确扣噪显示幅度很大的潜在收益，实收估计器只能实现其中一小部分。当前模型把回写从 0.5 倍增至 1 倍，虽改善中心窗波形误差，却让两路线的设备识别变差。
3. **WiSig 的关键差距集中在首轮物理求解及其幅相结果。** 旧 R69 的 FIR 作用是已测最有贡献的单独组件。只提供更准的时标、换成 FIR 参数化、调观测权重或加相位损失，均未单独补齐差距。旧门控一度把候选失败隐藏为近乎直通。
4. **恢复结构可以迁移，已有权重需要逐个核对。** 早期 WiSig R07 的估计器用模拟真实算子和附加噪声方差监督。R17 和 R69 均有继承链，R69 的上游 R65 还有已暴露正式结果后的人工选择。它们适合做冻结历史对照。LoRa 当前研发生效的训练及冻结权限以本轮源 IQ 约定为准。 [LoRa 正式结果](LORA_W24_UNGATED_FORMAL_20261125.md) · [WiSig 正式结果与 R69 谱系](WISIG_UNGATED_CLEAN_MAIN_20261125.md)

## 三、LoRa 两条旧研发路线怎样收敛到 W24

### 从旧输入试验到固定主口径

早期 LoRa 已按不同假设试过双采样率、分侧协方差触发、公开 chirp 镜像和短回波、局部方差、弱复谱保真。旧 Tri-set 用 `6×2×256` 输入；15 台接收机的 3,000 包子集，每条路线六景 18,000 次。旧扩容半量对照为 Full 10,401、Residual 9,931 次正确。同包下，双采样率变化为 **+27／−103**，弱复谱平衡重训 **−85／+83**，局部方差 **−83／−156**，分侧协方差 **+23／−2**。最后一项 Full 区间为 [−36，78]，同方案 clean 少 3 包，曾在四台目标 RTL 的 336 个 clean 包触发。四组都未同时改善两条路线。这些子集使用原冻结 Tri-set，和 E104 W24 正式矩阵分开。 [双采样率盲测](https://github.com/niubility1317/CVS-RFFI/blob/6766a75b34fd42f6b9ff76cff74d1e74599c0a84/automation_reports/CV-SincNet/20261125-phase1-lora-dura-dual-aperture-pilot-s2026092702-r01/report.md) · [弱复谱平衡盲测](https://github.com/niubility1317/CVS-RFFI/blob/6766a75b34fd42f6b9ff76cff74d1e74599c0a84/automation_reports/CV-SincNet/20261125-phase1-lora-dura-balanced-transfer-pilot-s2026092702-r01/report.md) · [分侧协方差盲测](https://github.com/niubility1317/CVS-RFFI/blob/6766a75b34fd42f6b9ff76cff74d1e74599c0a84/automation_reports/CV-SincNet/20261125-phase1-lora-dura-signed-covariance-pilot-s2026092702-r01/report.md)

这些负结果解释了若干机制为什么停留在诊断阶段。受控镜像校正整窗 NMSE 下降约 70%，在 practical 激活包上中位降幅均不到 0.01%。短回波校正改善整窗时，许多包的 9–32 kHz 独有复谱误差反而上升。外带功率在源 RTL 有显著正负不对称，分侧统计能改善独立随机噪声检测，重复的跨 chirp 干扰几乎未触发。局部方差对通用突发噪声的 9–32 kHz 源波形改善有移位反事实支持，但目标子集识别随替换下降。这些现象提示噪声统计会吸收接收机响应、重复干扰或弱指纹，需核查经求解后实际改动的复 IQ。 [双采样率与公开参考诊断](https://github.com/niubility1317/CVS-RFFI/blob/6766a75b34fd42f6b9ff76cff74d1e74599c0a84/automation_reports/CV-SincNet/20261125-phase1-lora-dura-dual-aperture-s2026112991-r01/report.md) · [局部方差子集](https://github.com/niubility1317/CVS-RFFI/blob/6766a75b34fd42f6b9ff76cff74d1e74599c0a84/automation_reports/CV-SincNet/20261125-phase1-lora-dura-local-variance-pilot-s2026092702-r01/report.md)

### W24 模型与正式结果

W24 固定 `lora_full_packets_v1`、`lora_rx5_main_v1:392005`、原 E104 权重和默认头。每包八条原生 chirp，接收端用每条的 384 个中心点和 48 个原生边缘点组成 `8×2×432`；恢复与分类各自按固定前端处理。40,000 步 W24 DURA 从源 U_s 随机初始化，20,000 fit、500 held，原版本另用 2,500 源 U 包校准历史门限。通用成对扰动在原生采样率生成，训练含时频波形、弱细节差分传递、观测一致性、方差和 clean 恒等保真。时频粗提案、实收外带方差、局部复主项／镜像／短回波、两级 prior 和每级 2 CG 组成恢复。无门控正式读出对每包执行网络，把中心修正乘 0.5，保留两端原生实收；Full 与原生 Residual 共用权重和规则。Residual 使用单独登记的 1 MHz 残余接收快照，未对 Full 波形再次叠加信道。 [估计量与训练](LORA_WISIG_RECEIVE_ESTIMATES_AND_EARLY_FIT_20261125.md) · [Residual 生成入口](../../experiments/pamf_lora_main/w24_native_residual.py) · [正式报告](LORA_W24_UNGATED_FORMAL_20261125.md)

### 受控可恢复性、实际回写和 clean 的分歧

- **噪声强度。** 独立 300 包 Full 源 V 扫描，在保持信号与时标的前提下，按已知噪声幅度扣除 90% 得六景 91.89%、低城区 77.00%；扣光才到 94.56%、87.67%。因此原生 W24 对该源面板确有接近目标的识别潜力；达到六景参考线所需的噪声抑制明显小于达到低城区参考线的难度。此曲线不用于拟合新候选。 [精确噪声扫描](LORA_W24_SOURCE_NOISE_SWEEP_20261125.md)
- **位置与可用信息。** 在另一处同口径归因中，精确扣掉八条中心窗噪声，Full 六景／低城区达 93.33%／86.33%，Residual 达 92.67%／84.33%。精确只处理首尾两条 chirp，两路低城区分别净增 69、77 包；只处理中间六条分别为 37、44。已固定半量中心时，精确去边缘噪声使六景增加 32、36 次，基于实收的边缘平滑分支只变化 −1、+1 次。精确分量和实收算法应分别验证。 [噪声位置](../../automation_reports/CV-SincNet/20261125-diagnostic-lora-w24-noise-aperture-source-s2026112559-r01/report.md) · [边缘消融](../../automation_reports/CV-SincNet/20261125-diagnostic-lora-w24-edge-denoise-source-s2026112559-r01/report.md)
- **回写和指纹。** 0.5 倍改为 1 倍，源低城区 Full 的 0–100 kHz 复 NMSE 由 0.01060 降为 0.00478，正确数从 164 降至 158。Residual 误差由 0.04636 降为 0.00579，正确数从 131 降至 102。两路直通／0.5／1.0 的 clean 分别为 297／293／292。等能量提高跨 chirp 共用修正，六景少判对 35、31 次；提高独有修正也未超过原半量。仅把同一旧修正向首尾重分配，Full +5、Residual −5，配对区间均跨零。 [回写扫描](LORA_W24_READOUT_SWEEP_20261125.md) · [实际复波形](../../automation_reports/CV-SincNet/20261125-diagnostic-lora-w24-waveform-source-s2026112559-r02/report.md) · [共用与独有成分](../../automation_reports/CV-SincNet/20261125-diagnostic-lora-w24-repeat-partition-s2026112559-r01/report.md)

## 四、WiSig 的独立对照及迁移经验

WiSig 的现代正式对照固定 Main split 共 168,000 个物理包，含 cross_rx 126,000 和 cross_both 42,000，并用三个冻结 Tri-SIG-TIME 种子读出。六景每路线 3,024,000 次识别判定。旧门控使 Estimated／Blind 各只在 1,008,000 个受扰观测中实际恢复 50 个，约 99.995% 直通。补齐强制恢复后，Estimated 和 Blind 的 clean 分别是 439,365、439,816/504,000，均超过 R69 的 438,286。两条路线的六景均值分别约 56.50%、56.76%，直通约 70.58%，R69 约 79.13%。Full 的 Blind 相对 R69 改对 229,162 次、改错 905,734 次。clean 和受扰能力必须各验。 [旧门控](WISIG_ESTIMATED_DURA_MAIN_20261125.md) · [全包正式结果](WISIG_UNGATED_CLEAN_MAIN_20261125.md)

- **时延可估，方差和相位难估。** 用短训练重复和标准前导，常规场景约 90.56% 时延误差在 1 点内；用重复差分估计噪声方差，两个面板的绝对误差中位数约 16.2、17.7 dB。将该方差替入 R69 后，源 V 的两路 clean 均掉 248/1,800，六景掉 2,038、2,040 次。单独保留 R69 FIR 比单位观测作用多判对 1,306/10,800，常量方差则损失 783／787 次。只留逐点主项和镜像项低于单位算子。短延迟复乘积能改善受控同步，在源 V 却比直通少判对 74／72 次；受损与参考窗位置可以对齐，仍可能存在相位和边界内容误差。 [前导、作用和方差](WISIG_PREAMBLE_ACTION_AND_NOISE_SOURCE_20261125.md)
- **首轮求解依赖粗锚点和匹配的作用。** 固定居中 FIR 的其他部件，把学习粗恢复换成实收锚点，Full／Residual 末步分别少判对 863／843 次。单增第一阶段观测权重，六景末步恢复 137／140 次，远小于差距。360 包低城区中，时延和整体复增益对齐后，隔离波形误差中位数 R69 约 0.0145、居中 FIR 约 0.0340。固定居中 FIR 幅度只换 R69 相位，六景净增 316／317；只换幅度净增 178／184。幅相交换用于归因。 [原生 FIR 对照](WISIG_NATIVE_FIR_SOURCE_RESULTS_20261125.md) · [幅相交叉](../../automation_reports/CV-SincNet/20261125-diagnostic-wisig-stage-polar-source-s2026112501-r01/report.md)
- **后续从零训练均已完成源评分。** 在同一 1,800 包源 V 上，固定权重／逐频观测权重／相位保真三种末步 Full 六景分别 8,286／8,364／8,313 次，Residual 8,285／8,358／8,316 次。直通为 9,057／9,062，R69 为 10,194／10,195。逐频组 clean 两路为 1,777，低城区却比固定权重少 13／11 包。相位保真组 clean 1,773，低城区 1,046／1,046，仍低于直通。三臂均 40,000 步，分别 576,089、576,283、576,089 参数。这三组未达到源晋级规则。N607 的原始评分位于相应 `wisig-spectral-precision-source` 和 `wisig-phase-fidelity-source` run 根的 `source-scores.json`。 [训练设计](../../automation_reports/CV-SincNet/20261125-phase1-wisig-spectral-precision-source-m2-r01/report.md) · [相位保真登记](../../automation_reports/CV-SincNet/20261125-phase1-wisig-phase-fidelity-source-s2026092701-r01/report.md)

## 五、状态和下一轮实验的证据要求

- **N607 已核实，首尾损失 W24 候选进入正式预测。** `20261125-phase1-lora-w24-formal-outer-objective-s2026092702-r01` 通过真实 E104 源 smoke，原负责人的 Full 和 Residual 预测正在推进。11:35 HKT 读回时有 6 份 RX 盲预测，6 个分片尚未全部固定，正式得分待定。中心与边缘联合训练仅已确认源域结果。 [首尾版正式登记](../../automation_reports/CV-SincNet/20261125-phase1-lora-w24-formal-outer-objective-s2026092702-r01/report.md)
- **两次旧 W24 复测属于技术失败。** IO 与 SatAug Full 的 r01 在真实权重 smoke 失败；r02 目录仍显示 `PREDICT`，但各自四个分片在首个受扰视图报 `ModuleNotFoundError: experiments.pamf_unrolled_restore.denoise`，每条链只发现四份 clean 数组，未找到所属预测工人。已有 clean 产物保留。这些是预测链失败，训练完成和同权重另一套正式成绩仍各自成立。把受扰信道生成放进与正式同入口、同 CPU 子进程导入顺序的源 U 检查，可在正式矩阵前发现这类故障。
- **下一个机制的优先级。** LoRa 首先检验扰动下首尾中心窗的复相位、幅度和细微谱差异能否由实收预测，并用 clean 恒等约束控制过修。边缘保留为独立消融，因为精确扣噪和当前可部署边缘头的结果方向不同。双路线共用模型及读出；源域冻结后同包看实际回写、整量输出、每一步和接收机分布。第三步展开仍是可检验的 R17 假设，需匹配两步结构、源数据、预算、回写和 clean，同时披露额外参数与两次 CG 的成本。当前新增三步实验保留在本地草稿阶段，没有发布。
- **判据。** 每轮同时报告直通与匹配旧恢复器、纠错和改错、低城区与 clean、五台源／15 台目标的适用接收机分组；按源条件冻结后才进入既定盲测。权重训练及源冻结只使用合法源 IQ 和通用模拟配对，源域冻结读出才用 W24。全量正式评分仅用于验收。LoRa 性能目标继续 active。
