# LoRa 接收端局部相位恢复设计

## 设计依据

沿用 full practical 与 residual practical 共同提供的六条对齐前导 chirp。每条 256 个复采样，采样率 256 kS/s，冻结 Tri-set 仍接收原来的六条 IQ。Full 的原始包包含 1 MHz 前导上下文，residual 的登记入口是六条低速率快照。两者共用接收端算法、冻结权重和门限。

先前 full 源域的位置诊断对配对波形进行相位替换，两端覆盖净多 169 次正确，中段净少 15 次。单纯增加首尾两条 chirp 后，1 MHz 中段相位估计净少 7 次正确。前一个结果用于确定消融的时间位置，精确配对波形只用于原隔离诊断。另一个源域实验使用六条实际 chirp 做交叉留出，短训两臂在全部激活包上总选择本组细化。其两条路线的最强固定读出也都落后原 DURA。主方案由逐包硬选改为直接估计局部相位修正。[历史位置诊断](../../automation_reports/CV-SincNet/20261123-phase1-lora-dura-chirp-ends-phase-m1-r01/report.md) · [交叉留出短训](../../automation_reports/CV-SincNet/20261124-phase1-lora-crossfit-choice-source-m4-r01/report.md)

## 接收输入与恢复

| 输入或估计 | 来源与可用时点 | 用法和误差 |
| --- | --- | --- |
| 六条实收 IQ | 收齐登记的前导裁窗 | 训练和推理使用同一接收路径，输出回到原样点和原尺度。 |
| 去扫频参考、粗细有效频偏和相干度 | 已知 LoRa 上扫频参考，去扫后峰值及滞后相关 | 只用于计算内部坐标。上扫窗口内有效频偏可能混合载频偏移和时偏。置信不足时减弱恢复。 |
| 局部相位曲率与跨 chirp 一致性 | 当前包，对长度 1、4、12 采样的相位二阶差分做稳健汇总 | 恒定相位和线性相位项会消掉。外侧缺少实收邻点时掩掉相应特征。幅度低、跨 chirp 有相关干扰时一致性会偏。 |
| 有效扰动功率 `σ̂²` | 去扫频后高频带功率中位数，以及组间短窗预测误差 | 用前者归一化、后者判断观测可信度。保留各自原始值和触发分布。两者可能含设备细节、传播失配和干扰，误差分析单列。 |
| 相对复作用 `Â` | 对当前包重复 chirp 的短窗摘要做带正则的相对拟合 | 以其余五条的稳健共识为参考。在短窗中估计 `g = (Σ w z conj(m) + λ)/(Σ w |m|² + λ)`，其中 `m` 为参考，`w` 为稳健权重。该估计只反映窗内相对复增益，相对残差大或参考能量低时向恒等收缩。绝对发端响应和绝对传播响应由这些观测难以分别确定。 |

1. **粗恢复。** 去扫频后，每条 chirp 保留自己的相位与幅度坐标。对去扫频波形 `z` 的单位相位 `u` 计算 `u[n+l] u[n−l] conj(u[n])²`。每条 chirp 的粗分支读取自身实部、虚部、局部幅度和曲率，也读取其余五条的置信加权稳健曲率。由共享分支提供重复证据，独有分支保留本条 chirp 的差异。输出一条有界相位轨迹。
2. **观测约束与细化。** 细分支读取原 IQ、粗波形、重复结构预测残差和估计置信度，输出局部相位增量。复观测残差以 `σ̂²` 和拟合置信度加权，限制在可靠观测上做大幅改动。低置信重复观测不强行拉齐。网络一次处理当前包，无多包识别投票。
3. **投影与回写。** 用实收功率乘窗口作为权重拟合预测相位的常数项和线性项。残差乘窗口后，这两项在实收功率加权下均为零。用 `y_out[n] = y[n] exp(i δ[n])` 回写，逐点幅度和原时间坐标保留。相位峰值上限先固定 0.35 rad，整包修正 RMS 上限为实收 IQ RMS 的 10%，另给同轨迹半量读出。相对作用估计退化时回退到恒等作用，门限或投影给出零修正时逐元素复制原样。

两端臂和中段臂的窗口用循环移动 128 点匹配非零点数及窗范数。卷积、参数、训练数据、扰动、剂量上限和观测损失完全一致。循环移动只构造掩码，曲率计算跨裁窗边缘时不拼接两端。实际修正量按景和接收机统计。借用 LoRa 前导同步中的时频估计和参考波形。现有两遍同步工作旨在补偿 CFO、STO、SFO 以恢复通信数据，且依赖完整前导结构。现有 LoRa 指纹工作计算信道鲁棒分类特征并训练识别器。本方案输出与现有冻结识别器兼容的复 IQ，并单独检验保留实收幅度和低阶相位后的局部恢复收益。[Tapparel 与 Burg 原论文](https://arxiv.org/abs/2502.08485) · [GNU Radio 作者实现](https://github.com/tapparelj/gr-lora_sdr) · [Shen 等原论文](https://arxiv.org/abs/2107.02867) · [作者代码](https://github.com/gxhen/LoRa_RFFI)

## 连续训练和放大策略

- **预算。** 源 U 训练 20,000 个物理包，旁路校准 2,500 个，固定留出 500 个。五台源 RX 各取 4,000、500、100 个，三组互斥。每臂 40,000 步、batch 24，每臂 960,000 次物理包抽取。两臂匹配单 AdamW 及连续余弦日程，按实际余量分到不同 GPU。现有任务照常运行。40,000 步是预登记工程预算，收敛程度由固定留出曲线和实际冻结识别判断。
- **监督。** 同一源 U IQ 生成两次独立通用受扰视图，再取一组共享扰动下的弱源相位差异。通用扰动独立于登记信道配置。粗恢复用多频带复谱保真，细化同时约束接收残差及弱相位差异传递。观测项和弱差异项的预定权重在同一优化循环内逐步接入。使用源 U 未加扰 IQ 作为复波形参考。拟合和校准隔离真实信道、真实噪声、TX 真值、冻结识别器、源 V 和目标。固定记录第 1,800、6,000、12,000、20,000、30,000 与末步的留出损失，留出只读。终步冻结前记录参数量、实际训练墙钟和峰值显存。
- **工程与位置消融。** 在原数据规则下比较直通、原 DURA、同步单独回写、同步加相对作用、仅相位学习、完整联合恢复。两端和中段共享固定统计门限，比较粗恢复、全量和半量。另在匹配冻结读出上分别旁路 `Â` 和 `σ̂²`，记录两者对识别和幅相的贡献。半量用半角旋转，保留逐点幅度。第一个冻结源域矩阵取同一 900 个物理包、两路线、七景，完整预测后独立 CPU 评分。两路六景正确数均须超过匹配 DURA，各路 clean 同时持平。正向候选再扩大到三种子。
- **正式门槛。** 15 台未见接收机、30,000 个物理包及同一冻结 Tri-set 三种子。候选同一份最终权重、门限和规则覆盖两路线。Full 六景均值至少 67.0%，低强度城区至少 53.0%，clean 至少 64,490/90,000。Residual 须比匹配原 R69 提高六景均值并保持 clean。Full 同包还对比直通、成熟半量 DURA 和当前最好冻结版本。进一步目标是六景均值距同方案 clean 不超过 3 个百分点。冻结后一次性写完预测再评分，按种子、接收机、场景报告纠错、改错、净变化及配对区间。波形诊断对齐时标和幅相坐标，逐频带给出传递误差；真实信道和噪声只进入隔离诊断。

## 本轮已完成的测试

- 32 个合成包验算已通过。检验了两窗口范数和支持匹配、有效时间点不足时零修正、旁路逐点一致、复数相位曲率对常数与线性相位不变及相位投影。幅度最大误差 `4.77e-7`，曲率变换最大误差 `5.85e-7`，最大实际修正 RMS 比为 9.4921%。这些数值仅验证数学约束。[验算代码](../../tools/lora_phase_design_probe.py)
- 交叉留出扩展预算的代码通过本地 batch 24 梯度、固定留出重放和独立 P0/P1 复核。该行用于判断短训后的硬选结论是否持续，和相位新主方案分开记录。此轮停在 LoRa 设计，N607 未提交这条扩展训练，相位方案尚无新识别成绩。[扩展预算预登记](../../automation_reports/CV-SincNet/20261124-phase1-lora-crossfit-choice-long-source-m4-r01/experiment.json)

## 相对作用和外带功率的隔离验算

使用实际实现的接收估计函数。合成信号含固定的弱复数相位细节，并只在首条 chirp 注入一个已知、随时间缓变的相对复作用。比较 3、4、6 条 chirp、0、6、18 dB 及独立白噪声和组间相关有色噪声，共 18 个条件，各 256 个合成包。候选函数输入仅为受扰观测与其相干度。模拟器参数在独立统计中作为误差参考，未用于训练、门限或权重选择。[隔离估计代码](../../tools/lora_phase_estimate_diagnostic.py)

在 6 dB 独立白噪声下，3、4、6 条 chirp 的相对作用 RMSE 中位数分别为 0.156、0.154、0.151，恒等对照为 0.208。六条设置在 0 和 18 dB 下的相对作用误差分别为 0.188 和 0.090，说明更低扰动的收益明显大于在该范围内增加重复数的收益。六条设置在 0 dB 独立白噪声下，外带功率比真实总功率的中位数为 0.998，10% 至 90% 分位为 0.853 至 1.149。在同功率的有色相关扰动下，外带比为 0.213，分位为 0.171 至 0.268，且接收置信中位数从 0.072 升至 0.175。该构造中相关干扰会同时降低外带和组间残差，并抬高重复置信。识别消融和同包实测分布另见局部相位实验。[源域实验记录](../../automation_reports/CV-SincNet/20261124-phase1-lora-local-phase-source-m4-r01/report.md)
