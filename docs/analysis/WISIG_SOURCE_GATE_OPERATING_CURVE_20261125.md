# WiSig 短训练差分门控的源域覆盖

冻结门限触发少，短训练差分本身也难以区分正常波形与受扰波形。在校准集以外的源 U 样本上，约 1% 的 clean 误触发只覆盖约 2.7% 至 2.8% 的受扰包。把误触发放宽到约 5.6%，覆盖仍在约 21%。

## 数据与计算

复用 `20261125-phase1-wisig-dura-estimated-main-m2-r01` 的合法源 IQ 缓存和第一个扰动计划。沿用当时的 U_s 排序，`2026092701` 打乱后，前 4,096 包只用于取得 clean 顺序统计量，余下 52,604 包用于同包比较。Full 与 Residual 的配对受扰子集沿用原训练路由，分别为原计划 `quantile` 不小于 0.575 的 22,370 包、介于 0.15（含）和 0.575 之间的 22,403 包。该值只用来划出诊断子集。运行在 N607 普通账号的 CPU 上，TX、F、源 V、目标及精确噪声参数读取为零。

每窗按 256 点复 IQ 的 RMS 归一化。取零起点区间 `48:128` 和 `68:148`，用两段复内积的辐角估计相对旋转。将该旋转施加于第一段，分数是两段残差的复功率均值乘 0.5。严格大于门限时触发。每个预算先用校准 clean 确定顺序统计量，再报告余下样本的触发比例。NumPy 观测分数在原门限下重现先前的校准 clean 3/4,096、留出 clean 32/52,604，以及两份完整受扰视图的 68/52,604。

Full 同包受扰分数高于原 clean 的比例为 **90.22%**，Residual 为 **90.62%**。跨包时，将一条受扰分数和另一条独立 clean 分数用于排序，两路线 ROC AUC 分别为 **0.6527** 和 **0.6546**。同包内分数常随扰动升高，但固定门限还需面对不同包原始差分的重叠。现在的部署输入只有当前实收窗，同包 clean 只用于诊断。
