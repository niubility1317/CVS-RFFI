# LoRa 受控复数相消恢复设计

## 方案依据

首轮从同包可测、可互相校验的相关干扰开始。现有长训实验中，局部相位修正压低了部分复谱误差，但识别未超过 DURA。包间距离半量读出相对 DURA 在 full 和 residual 分别少判对 41 和 128 次，调整总体距离也没有保住局部近邻。另一组隔离诊断里，保载波的逐点精确扣噪相对全量协方差 Wiener 在两条路线分别净增 423 和 871 次正确。给同一个 Wiener 换用真实总噪声功率后，正确数分别减少 3 和 138 次。优先检验能否识别并压低干扰的具体复数方向，同时保留弱信号幅相。精确扣噪分数只用于定位。 [局部相位结果](../../automation_reports/CV-SincNet/20261124-phase1-lora-local-phase-source-m4-r01/report.md) · [包间距离结果](../../automation_reports/CV-SincNet/20261124-phase1-lora-packet-relation-source-m4-r01/report.md) · [隔离扣噪结果](../../automation_reports/CV-SincNet/20261123-diagnostic-lora-noise-floor-source-m2-r01/report.md)

Full 和 residual 都读冻结 Tri-set 使用的六条对齐上扫 chirp，每条 256 个复采样，256 kS/s。额外的 1 MHz 上下文不进入共用模型。主读出返回相同时间坐标和尺度的六条 IQ。只凭上扫频时，去扫峰一般混合了时偏和频偏。内部同步使用联合有效偏移及跨 chirp 的斜率一致性，不强制将它拆成独立的 CFO 和 STO。完整前导双向同步及明确的采样时钟回写作为工程对照，只有当前视图确实提供可辨识观测的步骤才参加比较。 [LoRa 项目数据协议](../PROJECT_PROTOCOL.md) · [两遍同步原论文](https://arxiv.org/abs/2502.08485) · [作者前导实现](https://github.com/tapparelj/gr-lora_sdr/blob/master/lib/frame_sync_impl.cc)

## 接收计算和端到端训练

1. **粗恢复。** 复用接收去扫坐标、64 点短时复谱和留一 chirp 的先验。粗分支分别处理六条 chirp 的公共成分与每条相对公共分量的残差。结合 `Â` 与预测方差，把实收短时复谱与源先验融合。公共和独有分量共同回写。跨 chirp 预测弱时收紧同包融合，保留本条观测。直流载波与回写的原始索引保持固定。实际工程对照先跑仅同步，再跑同步加正则 LS 相对估计和频域 MMSE/Wiener。
2. **限制干扰参考中的真实信号。** 用未加扰的合法源 U 拟合目标频带中心、相对中心的功率和参考到目标的复交叉协方差。相消分支用每条 256 点去扫频谱，按实际 1 kHz 分辨率区分 1–8 和 9–32 kHz，并分别统计公共与独有分量。以交叉协方差的主参考方向构造正交投影，从参考中屏蔽最容易传递实际源变化的方向。记录剩余源泄漏能量，两个匹配候选共用同一个保护投影。该投影只在估计干扰时使用。
3. **交叉留出计算相消剂量。** 两条 chirp 一组，固定分为三组。每次轮换一组拟合低秩复数相消器，一组验证预测残差，一组执行修正，再拼回六条。公共模式和独有模式都采用这种切分。拟合与验证读保护间隔外的特征。额外用互不重叠的短时段核对噪声统计，短时段只用于可分辨的宽频带，补记有色干扰导致折间相关时的剂量偏差。设留出待修残差为 `e = y − μ`，参考预测的干扰为 `d`，`c = Re mean(eᴴd)`，`v = mean(||d||²)`。取 `b = c − sqrt(V_s·v) − m`，剂量为 `clip(b / (v + ε), 0, 1)`。其中 `V_s` 来自独立源 U 校准，按相同接收坐标、频带和公共／独有模式固定，并在源 U 按 RX 留一核对覆盖。留出裕量 `m` 用独立 U 扰动重复估计。推理相消项为 `−αd`。短时粗层重叠相加，再把相消项合入，并在反去扫前显式清零整 chirp 载波的修正分量。整包修正另受训练前预定 RMS 上限制约，入门统计低于 clean 门限时逐元素复制。
4. **细化与拟合。** 细分支看原 IQ、粗恢复和相消只读估计，拟合联合观测残差。由明确剂量约束参考驱动的修正，其余采用同步粗层的原始噪声收缩，避免旁路相关分支时连带关掉独立噪声恢复。输入、输出和弱差异损失在同一实收坐标计算。每次更新用同一源包的两份独立通用受扰视图和未加扰源 IQ。另一对使用共享通用扰动传递源包间实际小幅复谱差异。损失包含按频带归一的复风险、公共／独有的有符号复数变化、干净包的恒等回写以及加权接收残差。通用扰动覆盖独立白噪声、带色噪声、窄带干扰、短回波和时频漂移。模型与损失只看生成的受扰 IQ 和合法源 IQ。拟合、校准和冻结隔离 TX、F、源 V、目标及仿真信道和噪声参数。

在 `E||s − μ||² ≤ V_s` 且留出估计可迁移时，柯西–施瓦茨给出噪声均方改善的下界 `2αb − α²v`，其中 `m ≥ 0` 为额外保守量。六条实收 chirp 的折间共享干扰和源、目标接收机差异都可能破坏覆盖。所以上式是带条件的风险控制依据。报告源留出覆盖、实际残差误差、剂量引起的弱复谱损失和同包识别净变化。响应在全部观测上与源指纹共线又缺少独立参考时，单包存在不可辨识性，相消项应退回零。

Widrow 等从含干扰的参考学习相消滤波器，并量化参考信号泄漏对真实信号的损伤。Noise2Self 利用不同观测维度的噪声独立性。这里的参考来自同一个短前导，允许折间相关，显式保护实测源 IQ 可重复的复数方向，用留出风险控制决定剂量。LoRa 的公开信道鲁棒指纹方法通过特征和识别训练获取鲁棒性。本方案返回复 IQ，由既有冻结识别器检验。可验证的新机制限定为上述接收端相消剂量，在同预算下检验其对识别及弱复谱的独立作用。 [参考相消原论文](https://isl-www.stanford.edu/~widrow/papers/j1975adaptivenoise.pdf) · [Noise2Self 原论文](https://proceedings.mlr.press/v97/batson19a.html) · [LoRa 指纹原论文](https://arxiv.org/abs/2107.02867) · [作者实现](https://github.com/gxhen/LoRa_RFFI)

## 首轮训练和冻结测试

- 两臂同骨架、初始化、数据和优化日程。匹配组用保护后的相消参考与固定剂量，经同一 clean 旁路和 RMS 上限。候选组用上述交叉留出剂量。固定权重再做无相消、关闭 `Â`、关闭 `σ̂²`、半量等归因读出，旁路条件保持一致。参数量、训练墙钟、峰值显存和 B1 激活／旁路时延分别实测。
- 首轮每个频带、每类分量用至多两个复参考维度和一个输出方向，在同带的有效频点合并拟合。拟合按参考平均功率加 0.01 倍复岭正则。维度或有效能量不足时，该带相消系数置零。固定剂量组取 1，整包修正 RMS 上限两臂均取实收 IQ 的 10%。clean 旁路沿用去扫后外带入门统计，门限定为独立 U 校准集最大值的 1.05 倍。门限、参考泄漏和失配裕量都记录源 U 实测分布，随后冻结。
- 每臂使用 20,000 个按源 RX 均衡选取的合法 U 包，另有互斥的 2,500 个未加扰校准包及 500 个留出包。每臂 40,000 个 AdamW 更新，batch 24，共 960,000 次物理包抽取。粗层、观测约束和细化在同一循环连续优化。1,800、6,000、12,000、20,000、30,000 和末步写留出曲线，按终步冻结。训练加速来自按实际空闲容量分卡、批处理短时频谱和每包低维方程。健康训练完整走到预算末步。
- 用冻结 Tri-set seed 2026092702 在同一 900 个源 V 物理包上预测 clean 和六景，每条路线至少复现直通、原 DURA、本轮工程同步与均衡对照、学习粗层、两种联合恢复以及估计量归因。两路线全部预测固定后独立评分。主读出须在两路分别超过原 DURA 的六景正确数并保持对应 clean。另列低强度城区以及逐景、逐接收机净纠错。按源 RX 分层重抽物理包，保留同包跨景相关性。
- 通过源域门槛后扩大到冻结 Tri-set 三种子、15 台未见 RX、30,000 个物理包。两路线共用同一候选权重、门限和规则，分别与匹配原 DURA 检验六景改善及 clean 保持。Full 另需六景至少 67.0%、低强度城区至少 53.0%、clean 至少 64,490/90,000，并与半量 DURA 及当前最好冻结版本同包比较。进一步目标为六景距同方案 clean 不超过 3 个百分点。报告训练、推理成本及三种子逐景、逐 RX 的纠错、改错和配对区间。真实信道、精确扣噪及配对参考只在独立隔离归因出现。

## 设计验算结果

复数构造检查使用 4,096 行单独源样本构造投影。每种受扰条件再取 2,048 行拟合、2,048 行核对剂量、4,096 行评分。真实噪声只作验算计量。相关干扰条件的相消剂量为 0.707957，噪声均方误差下降 75.8345%。独立噪声条件剂量为 0，逐样点保持原值。参考的一个方向完全携带源信号，未保护相消器会传递相当于目标信号范数 99.0074% 的源分量，保护投影把这个构造的泄漏降至数值零。仅给真实源信号并将其同时当作相消预测，风险判据给出零剂量。这里使用理想可投影的信号及较多独立观测，验算覆盖了相消符号、风险判据和旁路，实际六 chirp 稳定性及识别收益仍待冻结评估。 [可复现验算](../../tools/lora_reference_cancel_probe.py)
