- [baseline_summary.csv](baseline_summary.csv)：3份基线的168000口径及U0原生198000口径，总体正确数、总数和准确率。

- [test_cells.csv](test_cells.csv)：33个RX×day测试cell与样本数。

- [evidence.json](evidence.json)：原评分、远端全量FCR复算、成员一致性与checkpoint路径等证据。非有限的无关遥测统一编码为null。
- [related_report_index.csv](related_report_index.csv)：本地关联报告版本索引，含路径与内容摘要校验值；重复报告/失败版本不计新实验。
