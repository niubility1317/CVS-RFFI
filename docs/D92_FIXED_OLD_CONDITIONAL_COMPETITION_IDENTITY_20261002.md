# 冻结旧类条件函数与统一竞争的逐样本恒等式

日期：2026-10-02。状态：**纯数学推导，FREEZE**。

**固定 B 的旧类条件排序，使 C 在旧类样本上的正确事件成为 B 正确事件的子集；它不保证注册后旧类准确率不下降。下降量恰好是 B 原本正确、随后被新类统一竞争夺走的比例。** 这是预测公式的确定性恒等式，不是泛化定理或实际性能结论。

本文只依据[原数学定义第 4 节、式 (11)](D92_LOCAL_RIDGE_JOINT_GENERALIZATION_COST_NOTE_20261002.md)和公开预测源码检查同分语义。未读取实际数据、权重、缓存、配置、日志、评分、索引或运行产物；未执行数值工具、测试、Git、SSH 或实验。未修改已有源码、参数或运行。本文与其他人的工作并行，仅新增本文件及同名镜像。

## 1. 对象、配对与预测规则

令旧类集合为 \(\mathcal O\)，新类集合为 \(\mathcal N\)，二者不相交且非空。对一个固定物理样本 \(x\)，定义

\[
p_B(o\mid x)=\operatorname{softmax}(f_B(x))_o,\qquad
p_N(n\mid x)=\operatorname{softmax}(h_N(x))_n.
\tag{1}
\]

\(f_B\) 是本次 B 阶段实际得到、在 C 阶段对所有输入冻结的旧类函数。C 可以更新新 head 和 gate，但不能改变这里的旧类条件函数、旧列对应的物理类 ID 或其同分规则。统一概率与分数是

\[
\begin{aligned}
P_C(o\mid x)&=\sigma(g(x))p_B(o\mid x),&
s_o(x)&=\log\sigma(g(x))+\log p_B(o\mid x),\\
P_C(n\mid x)&=\sigma(-g(x))p_N(n\mid x),&
s_n(x)&=\log\sigma(-g(x))+\log p_N(n\mid x).
\end{aligned}
\tag{2}
\]

两组概率总和为 1。C 面对 \(\mathcal O\cup\mathcal N\) 的全部列统一竞争。令 \(b(x)\)、\(n(x)\) 分别为旧、新组最大条件概率的胜者；组内相等时，取已注册物理类 ID 的词典序最小者。记

\[
m_B(x)=p_B(b(x)\mid x),\qquad m_N(x)=p_N(n(x)\mid x).
\tag{3}
\]

物理**样本** ID 用来保证 B、C 对同一个 \(x\) 配对；它不决定预测类别，也不用来对 query 作全局重排。同分优先级属于物理**类** ID，不能另设“旧类优先”或“新类优先”。

以下准确率比较要求同一 row、同一物理样本集合、同一权重，以及 C 真正调用的那个 B 函数。仅有相同参数坐标不够：不同 inner fold 重拟合的旧 head 是不同函数。对 C inner 训练目标，应以该 fold 的 old-inner-train prior 为参照；不能把它与另一个 full-support B 混作配对证据。

## 2. 稳定竞争边界与同分

因为 \(\log\sigma(g)-\log\sigma(-g)=g\)，两组最高统一 log 分数之差为

\[
\Delta(x)=g(x)+\log m_B(x)-\log m_N(x).
\tag{4}
\]

定义旧组胜出事件

\[
W_O(x)=\{\Delta(x)>0\}\ \cup\
\{\Delta(x)=0,\ b(x)<_{\rm lex}n(x)\},\qquad W_N(x)=W_O(x)^c.
\tag{5}
\]

类 ID 唯一且两组不相交，所以恰好同分时也只有一个胜者。于是

\[
\widehat y_C(x)=
\begin{cases}b(x),&W_O(x),\\n(x),&W_N(x).\end{cases}
\tag{6}
\]

式 (6) 是**全部列 argmax 的代数化简**：先分别求两组最大值，再比较这两个候选；非最大列不可能成为全局胜者。它不是先按 \(g>0\) 硬路由一组，也不使用样本的真实 old/new 身份。每个样本的两个条件 head 和 gate 都必须计算。

一般边界是

\[
g(x)\gtrless\log m_N(x)-\log m_B(x),
\tag{7}
\]

不是 \(g(x)\gtrless0\)。若旧类数为 \(m\)、新类数为 \(q\)，条件概率归一化给出边界的粗范围 \([-\log q,\log m]\)；实际判断仍使用本样本的两组最大条件概率，不能把类数范围替换成决策阈值或配额。

公开实现 [ProtoFrameState.predict](../code/cvsrffi/d92_proto_frame_joint_local_ridge.py#L547) 在已排序的类列上取旧、新 raw head 的组内 argmax，按 \(g+lo[bo]-ln[bn]\) 的实际运算顺序求差，再依正、负、恰好零选择旧、新、词典序较小的类。新 SupportMetric 状态通过同一公开结构化预测接口复用该语义。

精确实数运算下，式 (4) 与式 (2) 完全等价。float64 下，共同的大 log offset 可能使原本不同的旧类分数相加后舍入为同分。因此不能用已舍入的整张 log-score 表再次 argmax，替换公开结构化预测；也不能擅自增加“近似相等就按词典序”的容差。源码按**实际计算的 gap 是否恰好为零**处理跨组同分。后文恒等式对按式 (6) 固定的决策逐点成立，不依赖浮点 gap 恰好等于无限精度差值。

## 3. 旧类正确集合与精确下降量

现在只在数学评价中令真实标签 \(y\in\mathcal O\)，定义 \(B_{\rm ok}(x,y)=\mathbf1\{b(x)=y\}\)。由两组不相交及式 (6)，

\[
\boxed{\mathbf1\{\widehat y_C(x)=y\}
=B_{\rm ok}(x,y)\mathbf1\{W_O(x)\}.}
\tag{8}
\]

证明：新组胜出时，预测标签属于 \(\mathcal N\)，不可能等于旧真值；旧组胜出时，预测就是冻结的 \(b(x)\)。因此

\[
\{C\text{ 在旧样本上正确}\}\subseteq\{B\text{ 在同一样本上正确}\},
\tag{9}
\]

且错误事件是不相交并集

\[
\{C\text{ 错}\}=\{B\text{ 错}\}\ \dot\cup\ \{B\text{ 对且 }W_N\}.
\tag{10}
\]

对同一组 \(N_O>0\) 个物理旧样本，记 B 准确率为 \(a_B\)、C 旧类准确率为 \(a_{C,O}\)。均匀权重时

\[
\boxed{\operatorname{old\_drop}=a_B-a_{C,O}
=\frac1{N_O}\sum_{i:y_i\in\mathcal O}
\mathbf1\{b(x_i)=y_i\}\mathbf1\{W_N(x_i)\}.}
\tag{11}
\]

这就是配对 **competition-loss identity**；同一组非负权重下逐项加权也成立。等价地，

\[
a_{C,O}=a_B(1-\ell_O),\qquad
\ell_O=\Pr(W_N\mid B\text{ 对},Y\in\mathcal O).
\tag{12}
\]

\(a_B=0\) 时条件概率 \(\ell_O\) 不定义，仍使用无除法的式 (11)。

- \(0\le\operatorname{old\_drop}\le a_B\)，且 \(a_{C,O}\le a_B\)。
- old_drop 为零，当且仅当没有 B 原本正确的旧样本被新组夺走。B 原本错误的旧样本改成新类预测，也不会再增加准确率下降量。
- 若只在 C 的旧类列内部竞争，胜者仍逐点等于 B。因此“旧列内部排序变化造成的下降”为零，全部旧类下降都来自跨组竞争。此分解依据公开结构化胜者，不依据可能发生 offset 舍入同分的重新 argmax。
- 冻结排序只证明下降量非负；它不证明下降量小于 1 个百分点，也不提供任何其他小遗忘上界。训练旧锚点约束不能自动扩展成对未见样本的同一竞争结论。

若 Ground A 在同一旧样本上有固定原始预测，准确率为 \(a_A\)，则

\[
a_{C,O}-a_A=(a_B-a_A)-\operatorname{old\_drop}.
\tag{13}
\]

不能把 A 替换成原型、R0 或其他 row 的 B；缺失实际配对 A 时，相应实测量应记 N/A。

## 4. 新类条件错误与竞争损失

对真实 \(y\in\mathcal N\)，令 \(N_{\rm ok}(x,y)=\mathbf1\{n(x)=y\}\)。同样有

\[
\boxed{\mathbf1\{\widehat y_C(x)=y\}
=N_{\rm ok}(x,y)\mathbf1\{W_N(x)\}.}
\tag{14}
\]

令仅在新类列内部竞争的准确率为 \(a_N\)，统一 C 新类准确率为 \(a_{C,N}\)，则

\[
a_N-a_{C,N}=\Pr(N\text{ 对且 }W_O\mid Y\in\mathcal N),
\qquad 0\le a_{C,N}\le a_N.
\tag{15}
\]

新类错误分成“新条件 head 原本分错”和“新条件 head 原本分对但输给旧组”两个不相交部分。不能把条件分类准确率与无条件的 gate 组判断准确率直接相乘；正确的因子是 \(a_N\Pr(W_N\mid N\text{ 对},Y\in\mathcal N)\)，没有独立性假设。

gate 可以改变正确新候选是否胜出，却不能在新组胜出时把错误的 \(n(x)\) 变成另一个正确新类。改善后一种错误必须改变新 head 的条件函数。新 head 还会改变 \(m_N\)，所以即使组内 winner 不变，也可能改变式 (4) 的竞争边界。

## 5. 可改善部分与结构上限

1. **B 决定旧类条件正确率的上限。** C 的 gate、新 head 或新 adapter 不能修复 \(b(x)\ne y\) 的旧类错误。要让 C 旧类准确率超过当前 \(a_B\)，必须先在 B 的合法旧 support 适应中改变旧条件函数，或明确研究允许改变旧函数的另一种方法。合法 support 更新本身仍不保证未见样本上的 \(a_B\) 提高。
2. **C 可以减少额外竞争损失。** 固定 B 下，改进 gate/新 head 有可能让更多 B 正确旧样本保留胜出，让 \(a_{C,O}\) 接近 \(a_B\)。这不等于改善旧类内部排序，也不保证与新类准确率同时单调改善。
3. **新 head 与 gate 各有职责。** 新 head 决定 \(a_N\) 及条件置信度；gate 决定两组质量如何参与统一竞争。完整联合导数可以表达这种耦合，但不能据此宣布已经达到两个条件正确率上限。

若两组均有评价样本，使用 \(H=2a_{C,O}a_{C,N}/(a_{C,O}+a_{C,N})\)，其对非负两个变量单调，故

\[
H\le\frac{2a_Ba_N}{a_B+a_N}\le\frac{2a_B}{a_B+1},
\tag{16}
\]

分母为零时按零处理。这是给定两个条件 head 的结构上界，不是可达性保证。例如，一个 B 正确旧样本与一个新 head 正确新样本若产生完全相同的条件输出与 gate 输入，确定性统一决策对二者只能选同一组，不能同时达到两个样本的条件正确上限。

对任意固定评价权重 \(\pi_O,\pi_N\ge0\)、\(\pi_O+\pi_N=1\)，总体准确率至多 \(\pi_Oa_B+\pi_Na_N\)。这些权重只用于固定预测后的数学评价，不能传入 predictor 当作真实组比例或配额。改变旧、新比例后的总体分数也不能替代式 (11) 的配对下降量。

若 \(q=0\)，新条件分布不存在，不能补一个虚构新组。现有 new0 规则是 C 原对象复用 B；旧类下降恰为零，新类准确率、H 与新旧 gap 为 N/A。

## 6. 手工符号例子

取两个旧类、两个新类，仅作代数验证：

| 固定条件输出与 gate | 统一比较 | 结论 |
|---|---|---|
| 旧真类是 B 胜者，\(m_B=3/5\)，\(m_N=9/10\)，\(g=0\) | 旧最大质量 \(3/10\)，新最大质量 \(9/20\) | B 对而 C 错，式 (11) 的该样本贡献为 1。两组 gate 质量相等仍可丢失旧类正确性。 |
| B 的旧胜者错误；改变 \(g\)，条件输出冻结 | 旧组赢则预测错误旧类，新组赢则预测新类 | 对这个旧样本，C 始终错误，gate 不能修复 B 组内错误。 |
| 新真类是新 head 胜者，\(m_N=9/10\)，\(m_B=3/5\)，\(g=0\) | 新最大质量 \(9/20>3/10\) | 新条件分类正确且统一竞争胜出，C 正确。 |
| 上一行条件输出不变，取 \(g=\log9\) | 旧最大质量 \(27/50\)，新最大质量 \(9/100\) | 新 head 仍分对，C 却输给旧组，错误来自式 (15) 的竞争部分。 |
| \(m_B=3/5\)，\(m_N=9/10\)，\(g=\log(3/2)\) | 精确算术下两组最大质量均为 \(9/25\) | 由候选物理类 ID 的词典序决定。旧候选为 \(\mathtt{c01}\)、新候选为 \(\mathtt{c10}\) 时旧组赢；不另加旧/新优先规则。 |

最后一行是精确符号等式，不承诺有限精度计算 \(\log(3/2)\) 后得到 bit-exact 零。实际源码仍使用实际 gap 的符号与恰好零分支，不为该例改变预测规则。

## 7. 适用范围

本文是式 (2) 与固定同分规则的自推确定性证明，没有将论文结果引用成这套组合模型的性能保证。结论适用于相同实际 B 冻结、同列身份、同样本配对的预测；不适用于任意允许改变旧类相对分数的 residual/QP 方法，也不能跨 row、跨 fold 或跨旧 head 拼接指标。

真实标签只出现在固定预测后的正确事件定义与评价中，不进入 predictor、gate 路由或全局重排。本文不选择参数，不根据任何历史或当前成绩决定下一步实验，也不增加实验准入门槛。
