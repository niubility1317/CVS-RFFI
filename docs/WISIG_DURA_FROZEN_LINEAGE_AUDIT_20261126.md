# WiSig 冻结 DURA 逐阶段诊断

运行编号 `20261126-diagnostic-wisig-dura-frozen-lineage-m4-r01`。对比原模拟器监督、旧 Adaptive 波形反拟合、Adaptive 直接算子与混合快估四条已完成的 DURA 谱系。统一读出共同 R02 和各组 R07、R17、R38、R44、R46、R65、R69 的 E20 固定权重。R69 识别数据复用各自正式实验的同包预测。其余阶段的输出使用相同三种子冻结 PAMF。

- 源域使用固定的 128 个 R07 源验证物理包，沿用原 R07 同参考探针抽样。用真实配对 clean IQ 衡量每阶段的 NMSE、按参考谱能量加权的相位误差及频谱幅度 NMSE，覆盖 clean 和六种 Practical。源诊断不读 TX 标签或目标数据。
- 目标诊断固定抽取 2,048 个 Main 物理包，其中 cross-RX 1,536 个、cross-both 512 个，分别使用种子 `2026112603`、`2026112604` 对物理索引抽样。覆盖默认 Full、加重 Full 的 clean 和六种 Practical。两档使用相同物理 ID。报告逐阶段准确率、Low Urban 和相对于同阶段其他谱系的配对百分点及 95% 区间，按物理包在两个划分内重采样。使用两个 Full 条件集中诊断本轮已知的差距。正式全量四组合成绩保持独立。
- R07 交换旧波形版和 Adaptive 直接版的信道作用与噪声方差输出，用共同粗恢复和原 MAP 求解。R17 交换两组冻结的 R07 上下文和各自的先验，沿用原迭代。交换只做诊断，无训练和参数拟合。
- N607 普通账户，原项目 CVS-RFFI Python，FP32、TF32 关闭，批量 96。最多两个具备足够显存的工作进程；在真实权重源 IQ 无 query 检查后执行。故障停止限于权重来源或物理样本不匹配、非有限输出、任一诊断无法合法闭合。三组正式训练与产物保持独立。

发布入口 `experiments.pamf_unrolled_restore.wisig_dura_lineage_audit publish`，远端工作目录 `releases/<run>-release`，输出 `runs/<run>`。输出包括 `smoke.json`、`source.json`、`predictions/{default,strong}`、独立 `scores.json` 和日志。两档预测全部封存后，单独的 CPU 进程才读目标真值。该诊断不用于重新选择权重和调整方法。

## 完成结果

R07 同参考补测使用 128 个源 V 物理包及相同的两组随机复数探针。四组冻结 R07 的六景均值分别为原版 2.07%、旧波形版 5.30%、Adaptive 直接算子 2.73%、混合快估 5.56%。Adaptive 直接算子版的 Low Urban 为 7.17%，原版、旧波形和混合快估分别为 4.82%、13.52%、12.38%。这确认直接算子版的源域算子质量改善确实传到了 R07 权重。

下表每格是同一批 2,048 个目标物理包的默认 Full／加重 Full 六景平均识别准确率，单位为百分比。R02 共享粗恢复的准确率为 75.68／71.46。R69 使用正式全量预测中相同物理包的结果。

Adaptive 相对旧波形的 R07 六景差为默认 +0.15、加重 −0.09 个百分点，两档 95% 配对区间均跨零。只换噪声方差使六景均值变化约 −0.01、−0.04 个百分点。R17 在默认 Low Urban 首次出现明确退化，差 −1.77 个百分点，95% 区间为 −2.86 至 −0.62。保持旧 R07 上下文只换 Adaptive 的 R17 先验，默认 Low Urban 变化 −1.84 个百分点，区间 −2.96 至 −0.68；保持旧先验只换 Adaptive R07 上下文，同一指标变化 −0.02 个百分点。R38 的两档六景排序反转，说明 R17 的局部差距没有单调累积。

R46 是两档六景平均首次出现同向、区间均低于零的阶段。Adaptive 比旧波形低 1.21 和 1.17 个百分点。R44→R46，旧波形分别提高 1.25 和 0.87 个百分点，Adaptive 变化 −0.11 和 +0.18。两个版本在该转换上的收益差分别为 −1.36 个百分点（−1.90 至 −0.83）、−0.69 个百分点（−1.29 至 −0.07）。这些区间是同一物理包的配对重采样。R69 样本差距为 −0.71 和 −1.03 个百分点，与全量正式测试的 −0.75 和 −0.99 方向一致。

源 V 上，Adaptive 的 R17 恢复 IQ NMSE 为 2.19%，旧波形为 2.49%；到 R46 仍为 2.61% 对 2.71%。R17 的先验交换和 R46 两档识别收益差表明，平均物理误差的排序和 PAMF 的识别排序发生分离。现有交换能定位早期 R17 的先验因素，逐阶段观察能定位 R46 的放大效应。R46 内具体负责的特征或层未经过模块交换。四组各阶段都完整训练 20 轮，没有用后续目标诊断选模或改权重。
