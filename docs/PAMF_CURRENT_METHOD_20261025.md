# 当前 PAMF：普通伪标签暂代半监督方法

2026-10-25，按用户最新要求，当前 PAMF 半监督方法采用普通置信度伪标签。接收机外推伪标签方案退出当前主方法，保留原结果作为历史对照。机器可读身份见 [pamf_current_method.json](../configs/pamf_current_method.json)。

正文统一使用“PAMF（监督训练）”“PAMF（普通伪标签）”“DURA 恢复器”“直接识别”“恢复后识别”。外部方法统一命名为 RIEI、DRIFT、IB-RFF、SDG，不添加版本后缀。原始代码、实验编号和历史方法名只用于追溯，不另造新的方法名。

普通伪标签使用当前模型评估模式、无梯度前向，阈值 0.95、权重 1，按完整无标签批次平均，不使用教师模型、复杂筛选、风格扰动、梯度投影、无标签融合对比或接收机外推。保留 PAMF 原有标签配方；有标签端平滑系数 0.01，普通伪标签交叉熵平滑系数为 0。

累计 50 轮、11100 更新，前 13 轮仅有标签、后 37 轮联合训练；有标签批量 128、无标签批量 256，按 20＋10＋20 分段，默认头与骨干联合训练。匹配监督版不读取无标签训练数据，但仍保留有标签表示学习目标，不称纯交叉熵网络。

当前已有 11 个数据设置、监督/普通伪标签、三个模型种子，共 66 个主比较模型。直接识别和两类同契约恢复器读出均已冻结并独立评分，因此不需要为主比较重新训练。

普通伪标签之外的历史机制不能改名继承。原外推方案的含无标签核心消融、结构消融、恢复器组件组合和交叉种子读出，不自动成为当前普通伪标签证据。严格监督结构和无标签关闭的可匹配控制可保留各自原语义。
