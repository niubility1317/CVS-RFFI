# 前瞻源研究假设：等角身份分类头

本文件在本轮 coherence clean 预测及评分之前固定后续研究假设。仅依据完整源曲线、合规 source checkpoint 的分类器权重聚合几何及代数性质；不读目标 IQ、truth、seed/RX/TX 评分，也不改变本轮已冻结候选。当前只是条件性假设，尚未新建或启动实验；本轮若已充分达到目标，不必执行。

数学上，K个单位类别向量的最大两两内积至少为−1/(K−1)：由平方范数 `||sum(w_k)||²>=0` 得平均两两内积下界，再由最大值不小于平均值得到。维度≥K−1时正则单纯形达到该界。当前K=6、嵌入160维来自地面已注册类别及既有结构，不使用query真实类别数量或配额。由合法源码权重测得的Gram只是参数几何，不是逐样本特征或目标拟合证据。

若继续研究，保留 source-selected 身份特征与 PA 残差融合，比较普通 CE 下的可学习旋转单纯形头和固定单纯形头。候选分类几何在此固定；不增加骨干深宽，不增加额外损失或温度扫描，scale沿用30。可学习方案用160×5权重的QR正交框架与固定6类Helmert单纯形构造，固定方案使用同维确定性正交框架；全部scratch，同4seed/划分/E200×50。正式实施前仍需正确性、QR满秩/梯度/单包与真实预算验证及预登记，不能因几何界就推定性能更好。

通信上，学习的身份坐标可以重编码接收信号中的弱指纹，等角分类只约束潜空间竞争，不消除CFO或信道。物理上保持Sinc、time/frequency/PA等观测路径，潜空间旋转不是TX/RX物理解耦。射频指纹上，该头检验统一类别角间隔是否减少身份竞争中的几何偏差，接收机、信道、内容仍可能被编码，不能保证泛化。

后续若正式执行，源选择保持性能优先、成本次要，只有完整源结果后冻结一个，默认clean单包面对全部注册类、prediction固定后独立truth评分。所有结果保留，不测试旧未选候选、不加载未知/污染checkpoint、不利用本轮或历史target结果选参数、seed、预算或重跑。
