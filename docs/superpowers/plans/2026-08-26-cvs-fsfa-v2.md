# CVS-FSFA-V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不重训完整Phase1的前提下，实现receiver/LEO因子化慢基、8维解析域码、真正nested receiver评估和明确DA0回退，并发布source-only最小可证伪实验。

**Architecture:** 地面模块从`GroundFeatureCache`分离几何中心、receiver rank4和paired LEO rank4，部署bundle只保留聚合慢参数。support-only解析器按旧类求8维域码并执行覆盖率、一致性和margin安全门；nested evaluator为每个outer receiver重新拟合慢基，A0/B3/B5共享相同support/query draw。

**Tech Stack:** Python、PyTorch、pytest、现有CVS-RFFI Phase1.5缓存和N607发布流程。

**Spec:** `analysis/factored_slow_fast_v2_traceability_20260826.md`

## Global Constraints

- Phase2必须保持`p2_min_v1`、source-free、support-only适配和query只读。
- 新类support不得参与域码估计；本轮正式矩阵仅`DA0_REG0/DA1_REG0`。
- outer receiver的任何样本不得进入其慢基拟合或inner超参数选择。
- 首轮主检只比较A0、B3和B5；z-dom、物理先验、interaction和中间层Adapter延期。
- 所有新行为先写失败测试，再写最小实现。
