`extract_sid_fft96`使用去复均值、带保护RMS归一化、Hann窗和`torch.fft.fftshift(torch.fft.fft(...))`。所有池化通过固定线性插值产生`24/24/16/16/16`维；`phase`模式确定性清零幅度、镜像和带边分组。最终对96维向量做`nan_to_num`、去均值和带保护L2归一化。

`SIDFFT96Residual`保存固定mask buffer，使用`Linear(96,embedding_dim)→GELU→Linear(embedding_dim,embedding_dim)`；最后一层权重和偏置均为零。forward返回：

```python
{
    "z_raw": z_raw,
    "z_sid": F.normalize(z_raw + residual_scale * delta, dim=1),
    "sid_fft96": features,
    "sid_delta": delta,
    "sid_group_norms": diagnostics["group_norms"],
    "sid_valid_bin_ratio": diagnostics["valid_bin_ratio"],
}
```
