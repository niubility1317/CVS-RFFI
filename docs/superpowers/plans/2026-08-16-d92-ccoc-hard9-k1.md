# D92 CCOC Hard9+K1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为已通过truth-free G0的`E0_FULL_CROSS_CLASS_OFFBLOCK_CONSENSUS`建立独立、不可覆盖、truth-last的Hard9+K1执行与分析闭环。

**Architecture:** 新增独立CCOC矩阵、runner和analyzer，不通过module-global monkeypatch包装CSOAS/TCRA runner，也不在运行后递归改写JSON。九个performance outer和一个K1 liveness outer各执行三scene；prediction及其COMMIT先不可变落盘，独立scorer随后连接truth，analyzer按`outer_key+scene+arm`显式连接同排E0证据并一次性裁决。

**Tech Stack:** Python3.10、NumPy、pytest、现有D92 E0D prediction/scorer入口、JSON/CSV/NPZ不可变artifact、Git Bash、Conda`ssr-gpu`。

## Global Constraints

- 协议固定为`p2_min_v1`，复用`VALIDATED_ONCE`数据；不得重新验证或改变received-IQ、physical IDs、support/query split、receiver/TX、scene、K或schema。
- 唯一arm为`E0_FULL_CROSS_CLASS_OFFBLOCK_CONSENSUS`，candidate为`d92_e0_full_cross_class_offblock_consensus`，registered mode为`ccoc_full`。
- performance outer严格为九项：`rx_7_7__seed_713104__k_5__new_20`、`rx_7_7__seed_713103__k_10__new_5`、`rx_8_8__seed_713103__k_5__new_20`、`rx_8_8__seed_713103__k_10__new_5`、`rx_8_8__seed_713106__k_5__new_20`、`rx_7_14__seed_713104__k_10__new_10`、`rx_3_19__seed_713102__k_10__new_5`、`rx_7_7__seed_713105__k_10__new_20`、`rx_7_7__seed_713104__k_10__new_5`。
- K1 liveness严格为`rx_20_1__seed_713106__k_1__new_20`，不得进入performance均值、稳定性或晋级裁决；G0 outer`rx_7_7__seed_713106__k_10__new_5`必须排除。
- scene严格为`leo_clear_weak`、`leo_low_elev_weak`、`leo_rain_weak`；10 jobs、30 scene receipts、8 shards，job按冻结顺序`index % 8`分配。
- K>2必须是two-state total fit=`2`、after actual fit=`1`、FULL fit=`1`、dense/full/compile solve各`1`、candidate attempt=`1`、fallback reference=`0`；BLOCK/LOO/Fisher/scan/额外fit均`0`。K1必须是`d92_full_alias`、total/actual=`3/3`、reason=`K1_K2_EXACT_D92_FULL_ALIAS`。
- query truth/fit/update/selection/role Oracle/class quota/global reassignment全部为false；query MAC和永久state bytes必须与同排E0逐row精确相同。
- 资源硬门逐`outer_key+scene`执行：candidate绝对`registration_incremental_peak_working_set_bytes<=1,048,576`、wall`<=150,000,000ns`、candidate/E0 wall ratio`<=1.50`；目标仍为peak`<=524,288`、wall P90`<=120,000,000ns`、ratio P90`<=1.25`。E0 peak不得抵消candidate peak。
- 八指标严格方向：`H_old_new`、old balanced accuracy、`c_old_acc`、old floor、seen-new accuracy均`>E0`；average forgetting、new-to-old、old-to-new均`<E0`。任一tie、反向、fallback、证据不完整或资源硬门失败即`REJECT_ROUTE`。
- 幅度目标为H`+0.010`、old BA`+0.015`、`c_old_acc +0.010`、old floor`+0.040`、seen-new`+0.005`、forgetting`-0.015`、两向混淆各`-0.005`。八方向全对但幅度、稳定性或资源目标未齐且硬门未破时仅`REVISE_ONCE`；全部通过才`ADVANCE_TO_TARGET125_CANDIDATE`。
- runner不得读取性能决定停止；truth只能在immutable prediction后由隔离scorer读取。禁止scorer/truth输入进入predictor命令、fit receipt或health stop。
- 新runner必须首次写出最终CCOC schema，exclusive创建；禁止module-global monkeypatch、事后递归schema rewrite、跨shard写入、位置`zip`连接、宽`pkill`或同run重试。
- Windows命令必须使用精确Git Bash outer；测试串行激活`ssr-gpu`。所有代码、配置、报告和发布物必须进入Git；N607只接受本地验证后的SCP。
