# MARC-OT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现由Phase1分块权重校准基、support set域状态和support-only残差更新组成的MARC-OT Stage2-B软件路径，并闭合最小R矩阵的协议测试、预测和独立评分接口。

**Architecture:** Phase1从receiver/day/scene episode得到允许block的weight delta bank，并用现有FOMAML outer loop训练support encoder与任务条件化gate/LR。Phase2加载冻结bank，从合法old-class support预测初始权重修正，再以冻结head、cross-fit/D92和合法聚合摘要损失做分块主任务优先更新；所有选择在query前冻结并保留`alpha=0`回退。

**Tech Stack:** Python3.11、PyTorch、NumPy、pytest、现有CV-SincNet/WISER/D92/meta episode基础设施。

**Spec:** `docs/superpowers/specs/2026-09-01-marc-ot-design.md`

## Global Constraints

- `protocol_schema=p2_min_v1`，复用匹配`VALIDATED_ONCE/capsule_id/split_id`。
- Phase2不得读取source/clean IQ、样本级source embedding、source BatchNorm状态、query truth/role、query类别配额或scorer输出。
- OT只允许发生在合法support与冻结Phase1聚合摘要或weight bank之间，禁止跨query OT或全局重排。
- Stage2-B只产出`phi_D`；Stage2-C默认冻结`phi_D`并另训`phi_R`。
- source classifier永久冻结；query前模型、bank、gate/LR、残差、插值和D92状态全部冻结。
- 所有生产行为必须先有失败测试并观察预期失败；禁止`nan_to_num`、非有限梯度静默跳步或清零掩盖。
- 现有WISER/D92/Meta-adapter历史接口保持兼容；新功能使用独立`MARC-OT`文件和config。
- 中文报告遵循中文排版习惯，不在中文与英文、数字、缩写、变量之间增加额外空格。

```python
@dataclass(frozen=True)
class SupportDomainState:
    q: torch.Tensor
    uncertainty: torch.Tensor
    block_gates: torch.Tensor
    block_lrs: torch.Tensor

class SupportSetEncoder(nn.Module):
    def forward(self, features, labels, physical_tokens) -> SupportDomainState:
        if features.ndim != 2 or labels.shape != (features.shape[0],):
            raise ValueError("support feature geometry drift")
        if len(set(physical_tokens)) != len(physical_tokens):
            raise ValueError("physical support tokens must be unique")
        sample_h = self.phi(features)
        class_h = torch.stack([
            sample_h[labels == class_id].mean(dim=0)
            for class_id in torch.unique(labels, sorted=True)
        ])
        pooled = class_h.mean(dim=0)
        raw = self.rho(pooled)
        q, raw_u, raw_gate, raw_lr = self._split_outputs(raw)
        return SupportDomainState(
            q=q,
            uncertainty=torch.sigmoid(raw_u),
            block_gates=torch.sigmoid(raw_gate),
            block_lrs=self.lr_min + (self.lr_max - self.lr_min) * torch.sigmoid(raw_lr),
        )
```

以共享`phi`编码样本，按类mean/variance聚合后再对类求mean，最后由`rho`输出。`uncertainty=sigmoid`、`block_gates=sigmoid`、`block_lrs=lr_min+(lr_max-lr_min)*sigmoid`。

```python
@dataclass(frozen=True)
class BankFastState:
    parameters: OrderedDict[str, torch.Tensor]
    block_lrs: dict[str, torch.Tensor]

def first_order_bank_adapt(functional_forward, initial_state, block_lrs, support, steps):
    fast = OrderedDict((name, value) for name, value in initial_state.items())
    for _step in range(steps):
        loss = functional_forward(fast, support)
        names = tuple(fast)
        grads = torch.autograd.grad(loss, tuple(fast.values()), create_graph=False)
        fast = OrderedDict(
            (name, fast[name] - block_lrs[parameter_block_key(name)] * grad.detach())
            for name, grad in zip(names, grads, strict=True)
        )
    return BankFastState(parameters=fast, block_lrs=block_lrs)
```

每步使用`torch.autograd.grad(loss, tuple(fast.values()), create_graph=False)`并detach梯度；fast parameter更新保留对initial state和learned LR的一阶outer梯度路径。

```python
def support_bank_transport(
    support_task_features: torch.Tensor,
    frozen_bank_task_features: torch.Tensor,
    epsilon: float,
    iterations: int,
) -> torch.Tensor:
    cost = torch.cdist(support_task_features.float(), frozen_bank_task_features.detach().float()).square()
    log_a = cost.new_full((cost.shape[0],), -math.log(cost.shape[0]))
    log_b = cost.new_full((cost.shape[1],), -math.log(cost.shape[1]))
    log_k = -cost / epsilon
    log_u = torch.zeros_like(log_a)
    log_v = torch.zeros_like(log_b)
    for _step in range(iterations):
        log_u = log_a - torch.logsumexp(log_k + log_v[None, :], dim=1)
        log_v = log_b - torch.logsumexp(log_k + log_u[:, None], dim=0)
    plan = torch.exp(log_u[:, None] + log_k + log_v[None, :])
    if not torch.isfinite(plan).all():
        raise ValueError("support-bank transport became nonfinite")
    return plan
```

FP32 log-domain Sinkhorn；bank输入detach；不持久化虚拟source样本；输入非有限或边际失败时抛`ValueError`。
