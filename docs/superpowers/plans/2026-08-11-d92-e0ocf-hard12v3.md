# D92-E0OCF Hard12-v3实施计划

> 状态：`DESIGN_FROZEN`。本计划只实现并验证已经冻结的同注册状态旧类contrast融合，不再扩展方法轴。

## 目标

在保留D92的288维联合特征、ground-spectrum Cauchy center、task-balanced covariance和F0查询头的前提下，以`E0_FULL_ONLY`为低成本主干，修复其旧类最低类下降，同时维持相对原`D92_FULL`的性能和注册计算优势。

## 三轮回顾结论

1. 完整部件消融显示B的平均作用近零，E只提供小幅旧类保护；160维Lite和强制tie闭合已经否决。
2. Hard12-v1的B/E四臂复验确认E0是唯一值得保留的效率底座：相对FULL的H几乎不变，注册wall和peak明显下降；B0/B0E0不延续。
3. fresh/disjoint Hard12-v2的D几何五臂确认`E0_FULL_ONLY`把K5/K10注册fit降到2/2，并把wall降低约95%–98%，平均H提高0.336个百分点；但old floor下降0.833个百分点。该损失不是简单old→new侵入：10个performance outer的old→new仅增加0.083个百分点，且最严重floor下降5个百分点的outer中old→new和old→old错误都下降、old BA反而上升。`E0_FIXED50`相对FULL_ONLY提高old floor约1.167个百分点，但全类共同融合使H下降约0.438个百分点。

因此第四轮只检验一个新假设：block几何对旧类内部contrast有保护价值，而把block几何同时作用于新类和旧/新组间校准会造成平均性能交换。

## 冻结方法

五臂固定为：

1. `D92_FULL`：原D92对照。
2. `E0_FULL_ONLY`：E关闭、注册后仅full主几何。
3. `E0_FIXED50`：既有全类full/block 0.5/0.5融合，对照“全类融合”副作用。
4. `E0_OCF25`：唯一可晋级主候选。
5. `E0_OCF50`：仅作固定强度诊断，不得在结果返回后替代OCF25晋级。

令同一个`DA0_REG1`support上的full和block仿射头分别为`(Wf,bf)`和`(Wb,bb)`，旧类集合为`O`。定义旧类行内contrast：

```text
Cf = Wf[O] - mean_O(Wf[O])
df = bf[O] - mean_O(bf[O])
Cb = Wb[O] - mean_O(Wb[O])
db = bb[O] - mean_O(bb[O])
rf = RMS(X_old @ Cf.T + df)
rb = RMS(X_old @ Cb.T + db)
Cb_aligned = (rf / rb) * Cb
db_aligned = (rf / rb) * db
C_lambda = (1-lambda) * Cf + lambda * Cb_aligned
Wout[O] = mean_O(Wf[O]) + C_lambda
bout[O] = mean_O(bf[O]) + ((1-lambda) * df + lambda * db_aligned)
Wout[new] = Wf[new]
bout[new] = bf[new]
```

`lambda`只允许固定为0.25或0.50。不得按class、receiver、seed、scene、K、Cn、support CE、query结果或历史困难类选择lambda；不得clip对齐ratio；不得做二次全类centering。实现必须保证新类行byte-exact等于FULL_ONLY、旧类contrast行和为0、旧类组均值等于FULL_ONLY。K1/K2严格回退原D92路径。

OCF只在support注册阶段增加第二个block component fit和旧support RMS/融合代数。K5/K10的two-state计数为4/4，after实际component fit为2；查询仍为单一288维FP32 affine head，query MAC和永久state bytes与FULL_ONLY完全一致。

## 晋级门

只有`E0_OCF25`可晋级；`E0_OCF50`无论数值多高都只解释强度曲线。

- 相对`E0_FULL_ONLY`：mean old floor严格增加，至少8/10个performance outer的old floor不下降；mean H、old BA、seen-new均不下降，forgetting不增加。
- 相对`D92_FULL`：mean ΔH至少`+0.005`，至少8/10个outer的H不下降；old BA、old floor、seen-new均不下降，forgetting不增加。
- 注册资源：相对`D92_FULL`的median wall至少下降60%，incremental peak不高于`D92_FULL`；OCF K5/K10 fit计数4/4、after实际2/2；query MAC和state bytes精确等于FULL_ONLY。
- 同时报告old→old、old→new、new→old，不允许只凭floor晋级。
- 60/60 job、K1五臂state/prediction严格别名、query fit/update/selection/truth/role/quota/global reassignment全部为0/false。
