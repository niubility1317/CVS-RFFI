# D92 QIC G0 frozen plan

## Objective

Implement and run one truth-free K10/new5 three-scene G0 for `E0_FULL_D42_QUANTIZATION_INTERCEPT_CLOSURE` before any Hard matrix.

## Frozen method

1. Run the existing E0 FULL registration once. For `K<=2`, publish the exact D92 FULL alias.
2. After the single D42 coefficient codec, decode the deployed coefficient rows `w_tilde[c]` and compute each class support mean `mu[c]` in that deployed coordinate from support only.
3. Compute `a[c] = -0.5 * dot(mu[c], w_tilde[c]) + log(1/C)` and `a_centered[c] = a[c] - fsum(a)/C`.
4. Publish `FP16(a_centered)` in the existing intercept slot. Coefficient codes/scales, `log_diag`, class registry and state shape remain byte-exact.
5. Define the common-shift-invariant self-consistency residual as `sum(abs(center(intercept_fp16)-a_centered))`. QIC is active only when the deployed candidate residual is finite and strictly lower than the E0 residual and at least one FP16 intercept bit changes; otherwise publish exact E0.

## Hard constraints

- `p2_min_v1`; support only; no query/clean/source/truth/role/quota/global access.
- All classes use one formula; class and support-row permutations are equivariant.
- K>2: one actual FULL fit, no BLOCK/LOO/Fisher/scan/second codec. K<=2: exact alias.
- Query remains one D42 affine head with E0-exact MAC count and state byte count.
- Extra persistent state is 0B. QIC work is `O(C*288)` with no `288x288` candidate matrix; N607 G0 hard limits are wall<=150ms and peak<=1MiB.

## G0 decision

All three frozen scenes must be active, non-fallback, non-E0, residual-strictly-improved, one-FULL, query-zero-access, query MAC/state exact, and pass resource hard limits. Any failure rejects QIC; no strength scan or corrective retry.
