# CAPTA-P0-LS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and experimentally publish a support-only, zero-backprop CAPTA-P0 Stage2-B prototype-transport path on the frozen ADV3B02 checkpoint.

**Architecture:** A dedicated `stage2_capta` package converts frozen source anchors and legal target support features into immutable transported prototypes, then freezes a support-only source/target gate before any query is opened. The existing validated row loader and paired scorer remain the protocol and truth boundaries.

**Tech Stack:** Python 3, PyTorch, NumPy, pytest, existing ADV3B02 runner and Stage2 paired scorer.

**Spec:** `docs/superpowers/specs/2026-08-24-capta-p0-ls-design.md`

## Global Constraints

- Runtime inputs are exactly `p2_min_v1`, `VALIDATED_ONCE` fixed received IQ, legal old-class support labels, frozen class prototypes/mapping, frozen checkpoint, and preregistered config.
- No source/clean samples, source cache/statistics, query truth/role/quota, query fit, cross-query assignment, persistent classifier head, model gradients, optimizer, or model/buffer mutation.
- Rank is at most 4; backward count and trainable parameter count are exactly 0; query state updates are exactly 0.
- Query opens only after CAPTA state freezes and every query independently faces all registered old classes.
- The first remote matrix is single-seed Target5 A0/A1/A2/A3/A6; Target25 is conditional on the preregistered mean/floor promotion threshold.
