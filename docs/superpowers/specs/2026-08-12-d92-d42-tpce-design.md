# E0 FULL D42 Tail-Pair Code Exchange设计

状态：`DESIGN_FROZEN`

## 1.目标与生命周期

`E0_FULL_D42_TAIL_PAIR_CODE_EXCHANGE`仅在`DA1_REG1`且`K>2`时激活。它完整复用E0的288维特征、ground-spectrum稳健中心、task-balanced covariance、唯一FULL fit及D42单F0头。`DA1_REG0`保持E0，K1/K2保持D92 FULL精确alias；REG0的seen-new与H为`N/A`。

候选只读取同一outer的合法注册support、标签和已经编译的E0 D42 state。query及其view不参与fit、更新、选择、回退或停止；禁止clean/source、query truth、role Oracle、class quota和跨query重排。

## 2.E0部署态与固定tail

将E0正式D42 state记为`S0=(q1,q2,s1,s2,b,h)`，其中`q1,q2`为两级int8系数码，`s1,s2`为每类每块FP16尺度，`b`为FP16截距，`h`为冻结变换。用`h`变换support并由`S0`实际解码头计算logit。

- 对六个旧类分别计算true-vs-all margin，使用`np.quantile(method="lower",q=0.20)`冻结tail阈值，阈值并列样本全部纳入。
- 对全部新类support合并计算true-new-vs-max-old margin，以同一lower-Q20规则冻结一个pooled-new tail。
- 旧类tail样本的竞争者是除真实类外的E0最大logit类；新类tail样本的竞争者是E0最大旧类。最大值并列竞争者全部纳入，候选后不得重排tail或竞争者。

## 3.一次性D42码交换

对每个冻结tail样本`i`、真实类`y`、并列竞争类`r`及D42块`B_b`，只考虑同时满足下列边界的坐标`j`：

`q2[y,j]+sign(x[i,j]) in [-127,127]`，

`q2[r,j]-sign(x[i,j]) in [-127,127]`。

该原子交换在实际解码margin上的精确一阶增益为

`g(i,y,r,j)=abs(x[i,j])*(s2[y,b]+s2[r,b])`。

每块选择最大正增益坐标；坐标并列按冻结特征索引选择，类别并列全部保留。所有原子`+1/-1`先在int32缓冲中同步求和，再一次性检查int8边界。若聚合结果越界，不做截断发布，直接精确回退E0。否则仅替换`q2`，`q1/s1/s2/b/h`逐字节复用；不再调用`_quantize_coefficients`，不扫描步长、lambda或候选arm。

## 4.实际解码守卫

在候选D42 state实际解码后重新计算所有冻结集合。只有同时满足以下条件才激活：

- state非E0，`q2`至少一个码元改变，且`q1/s1/s2/b/h`byte-exact；
- 六个旧类各自固定tail平均margin增益都严格大于冻结机器精度容差；
- pooled-new固定tail的true-new-vs-max-old平均margin增益严格大于同一容差；
- pooled-new固定tail的true-vs-all平均margin不下降；
- old→new与new→old零阈值support hinge均不增加；
- query MAC、永久state bytes与E0精确相等。

非有限、tail为空、无可移动坐标、聚合饱和、零码差、state闭包或任一守卫失败时，返回原E0 state并标记`LOCAL_INVALID`。fallback不得作为性能成功。

## 5.对称性与资源

所有注册类、tail样本和竞争者使用同一公式；类别ID只作注册表索引，不参与分支。old/new组内标签置换时，tail、竞争者集合和码交换随置换映射。旧类逐类门、pooled新类门和两向hinge共同避免单边任务收益。

TPCE新增组件fit为0，K>2仍为two-state`2`、`DA1_REG1`实际FULL fit`1`。两次support全类打分MAC上界为`2*C*C*K*288`，在`C<=26,K<=10`时不超过`3,893,760`；坐标比较与int32缓冲单列审计，不能把MAC上界写成时延。最终必须以N607证明wall P90≤150ms、配对中位倍率≤1.50、peak≤E0+512KiB。

## 6.困难矩阵与裁决

只运行冻结Hard10的10个performance outer加1个K1 liveness outer、三场景、单候选、8shard；不重跑D92或E0。八项同排均值任一平或反向即`REJECT_ROUTE`；八项全正但幅度、稳定性或目标资源不足且硬资源门未破时仅`REVISE_ONCE`；全部冻结门通过才输出`ADVANCE_TO_TARGET125_CANDIDATE`，不得自动运行完整Target125。
