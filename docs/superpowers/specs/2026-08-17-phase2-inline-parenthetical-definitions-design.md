# Phase2报告首次出现括号定义修订设计

## 目标

将当前报告中的25处独立“符号说明”“缩写说明”和“术语说明”改为首次正文出现处的中文全角括号解释，使导师阅读正文时无需跳转即可理解术语、符号及其物理意义。

## 修订规则

1. 标题保持简洁。若术语第一次出现在标题中，在标题后的第一句正文首次使用该术语时加入括号解释。
2. 括号采用中文全角形式`（……）`，放在被解释的术语、缩写或数学符号之后。
3. 缩写的括号内容依次说明英文全称、中文名称和本报告中的具体作用；项目内部标识只说明项目含义，不虚构通用英文全称。
4. 数学符号的括号内容说明数学对象、上下标、取值或运算含义，并补充其在CVS-RFFI中的物理对应关系。
5. 数学变量、上下标、集合和运算符继续使用Word原生公式对象，不使用纯文本模拟上下标，也不保留可见LaTeX标记。
6. 删除原有独立“符号说明：”“缩写说明：”“术语说明：”段落，避免同一概念重复解释。
7. 对过长的一组符号，可在同一首次定义句中使用一个完整括号，并用分号分隔各符号含义；不得把解释移到文末符号表。

## 不变范围

- 不改标题编号、章节顺序和正文论证逻辑。
- 不改17张实验表及其任何数值。
- 不改方法损失函数、训练数据、更新对象、实验权限和结果边界。
- 不新增参考文献，不修改现有5篇对比方法论文引用。
- 继续使用qKNN名称，不恢复D92旧称。
- 保持中文宋体、英文与数字Times New Roman，以及现有标题、表格和强调色样式。

## 输出与验证

- 从`CVS-RFFI_Phase2详细复现报告1_qKNN符号缩写首次出现说明版_截至20260801.docx`生成新文件，不覆盖用户当前可能打开的版本。
- 结构检查：25个独立说明标签全部消失；17张表数量不变；公式对象数量不得减少；页眉页脚保持为空。
- 内容检查：首次出现处包含对应括号定义；无可见LaTeX反斜杠；无D92旧称；实验数值和参考文献保持不变。
- 版式检查：渲染全部页面并逐页检查括号造成的换行、孤行、表格截断、公式错位和字体替换。
