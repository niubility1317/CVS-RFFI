# Phase2实验结果按配置拆分设计

## 目标

将报告后半部分的三张大结果表改为按实验配置拆分的小表，使读者能够直接定位某一组`K-shot`与新类规模，并在同一配置内比较方法，避免跨配置、跨实验口径混读。

## 拆分规则

1. 正式LEO弱信道结果按`K-shot`与新类数的唯一组合拆分；每张表只保留该配置实际执行的方法及其注册后旧类准确率、新类准确率、旧新调和均值和遗忘。
2. qKNN共同LEO切片对照按5个切片分别拆分；每张表保留qKNN、CSIL官方流程和MoPC-HR官方流程三行，不改变“描述性对照、非严格paired比较”的结论边界。
3. matched无LEO新类诊断按`K-shot`与新类数的唯一组合拆分；每张表保留方法、无LEO新类准确率及相对正式LEO结果的三项变化。
4. 正式LEO、共同切片和无LEO诊断保持为三个独立小节，禁止把不同数据与训练权限的数值合并成同一比较表。

## 版式

- 每组以“配置：K=...，新类数=...”或“共同切片：K.../new...”作为加粗蓝色配置标题。
- 配置标题与对应表格保持同页；表格使用现有结果表样式、宋体/Times New Roman字体和Word公式对象。
- 删除拆分后重复的`K-shot`与“新类数”列，以方法为首列，减少横向拥挤。
- 表格允许连续排列，但不同配置之间保留稳定间距。

## 完成标准

- 原三张大表的所有数据行恰好出现一次，数值和单位不变。
- 5个共同切片各自包含3种方法。
- 正式LEO与无LEO诊断的实验口径说明保留。
- 全文Word公式对象、参考文献和非结果表内容不受影响。
- 最终DOCX通过结构审计，并完成逐页渲染检查。
