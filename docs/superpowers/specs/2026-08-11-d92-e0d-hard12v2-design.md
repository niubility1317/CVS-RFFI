# D92-E0D-5arm-Hard12v2设计规格

状态：`DESIGN_FROZEN`

## 可行性摘要

1. 首轮真实Hard12证明E是主要效率因子：E0注册wall降低54.04%，H仅下降0.0114pp。
2. B0几乎不省计算且退化，第二轮固定B开启。
3. 第二轮固定A=288维、B、C=0.5/0.5、E0、F0，只隔离D几何。
4. 四个E0臂为纯D对照；另加同run D92_FULL作为实际性能参考。
5. `E0_FULL_ONLY`是唯一晋级候选；其余臂只解释几何与LOO作用。
6. D切换仅在`registered && K>2`生效；注册前和K1/K2五臂精确走D92_FULL。
7. FULL_ONLY/BLOCK_ONLY不执行LOO，fit数K5/K10均为2/2。
8. FIXED50只做full/block主拟合和固定0.5/0.5 RMS融合，fit数4/4。
9. E0_FUSION保留D46 classwise support-LOO soft融合，fit数24/44。
10. D92_FULL保留Fisher/Pareto，fit数48/88。
11. query仍为逐样本全注册类单一F0头，MAC不增加。
12. 使用与Hard12-v1零交集的Hard12-v2，12outer×5arm=60job。
13. Hard12-v2完全由历史D92与NEXT-R5 `DA0_REG1`冻结，不读取本轮候选结果。
14. 复用匹配`VALIDATED_ONCE`数据，不因方法变化重复验证。
15. 只保留method identity、不可覆盖、prediction→score绑定、P0/P1四项最低审查。
16. Hard12-v2只决定是否进入完整125确认，不产生正式性能主张。

## 目标与现有证据

首轮`D92-BE-2x2-Hard12-v1`完整48/48job闭合。相对D92_FULL，E0的mean ΔH为−0.00011395，10个performance outer中8个非负，old floor增加0.0016667，注册wall中位降低54.04%，增量peak降低30.15%。因此第二轮不继续删除B，而是在E0共同路径内删除D46昂贵的K折LOO，并隔离full、block和固定融合。

历史D0略高于FULL仅作方向先验。历史消融通过替换整个D62 builder同时绕过Fisher、rollback和部分共同路径，不能作为纯D结论；本轮必须在同一D92 builder内只切换registered-state D aggregator。

## 五臂定义

|臂|注册后且K>2计算图|K5/K10 fit|角色|
|---|---|---:|---|
|`D92_FULL`|B→D46 full/block LOO融合→D62 Fisher/Pareto→F0|48/88|同run参考|
|`E0_FUSION`|B→D46 full/block classwise support-LOO soft融合→F0|24/44|E0控制|
|`E0_FULL_ONLY`|B→D92 full主拟合→F0|2/2|唯一晋级候选|
|`E0_BLOCK_ONLY`|B→D92 block3主拟合→F0|2/2|几何解释臂|
|`E0_FIXED50`|B→full/block主拟合→support-logit RMS→固定0.5/0.5融合→F0|4/4|LOO解释臂|

所有臂固定：

- A：`joint288_z160_fft96_rf32`；
- B：ground-spectrum Cauchy robust center开启；
- C：旧/新注册任务协方差固定0.5/0.5；
- F：F0 FP32 weight+bias；
- query：逐样本面对全部已注册类，zero-fit、zero-update、zero-selection；
- 通用有限性、正定性、canonical gauge、rollback/fail-closed和不可变提交不删除。

`E0_FUSION/E0_FULL_ONLY/E0_BLOCK_ONLY/E0_FIXED50`共同固定E关闭，构成纯D因果矩阵。`D92_FULL`是外部同run参考，不参与D主效应解释。

## 资源证据

不得复用现有`estimated_lda_fit_macs`自证D46/D62节省，因为该字段没有覆盖额外注册图。本轮资源结论以三项为主：

1. 实际component fit调用清单及精确总数；
2. 同outer、同节点、同线程的注册wall配对；
3. 注册调用期间的增量peak working set配对。

可额外输出逐组解析MAC inventory，但不得把解析MAC写成时延。query头仍为单一`C×288`仿射，逐项MAC必须相同。

## 严格晋级门

只有`E0_FULL_ONLY`可晋级，且必须同时满足：

- 60/60job闭合；10个performance outer先场景等权、再同outer配对；
- 五臂`DA0_REG0`状态和预测逐值一致；两条K1的`DA0_REG1`状态和预测逐值一致；
- query fit/update/selection/truth/role/quota/global-reassignment全部为0；
- 相对`E0_FUSION`：mean ΔH>0且至少8/10 outer的ΔH非负；
- 相对`D92_FULL`：mean ΔH≥0.005且至少8/10 outer的ΔH非负；
- 相对`D92_FULL`：mean old-balanced、old-floor、seen-new均不下降，forgetting不增加；
- FULL_ONLY K5/K10 fit精确为2/2；
- 注册wall中位相对E0_FUSION至少下降40%，相对D92_FULL至少下降60%；
- 增量peak不高于E0_FUSION；query MAC逐项不变。

任一门失败即`NO_D_GEOMETRY_PROMOTION`，不得从解释臂中事后挑最好者。通过只允许冻结FULL_ONLY并进入完整Target125确认。

## 明确拒绝

- 不使用LOO硬选择：仍需两几何×K折拟合，不能瘦身且增加tie不连续性；
- 不在本轮把block改成真正分块求解；那是独立工程优化，会混淆几何因果；
- 不引入DA、160维Lite、query选择、truth/role/quota或类别顺序tie-break；
- 不复用Hard12-v1作为第二轮性能门；
- 不增加重复数据验证、整树SHA、额外签名或发布平台。
