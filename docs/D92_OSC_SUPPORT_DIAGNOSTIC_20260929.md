# OSC support 诊断的信息边界

日期：2026-09-29。**现有记录足以核对 support 物理留出、逐类 NLL 和留出判别，但不足以判定四相位信息是否消失、类别是否不可辨识，或实际 query 性能。**本分析只使用完整 support 诊断，不读取或引用 query scores、query summary、query predictions、IQ 或特征数组，不修改公式、预算或选参。

## 证据与完整性

完整读取以下两组 r02 的 8 份本地 `results/fit_logs/<row>/compact.jsonl`，以及对应远端 `<row>/osc/fit_trace.jsonl`：

- `20260929-phase2-d92-osc-repeat-rx3-m4-r02`：4 个模型，每模型 900 次任务拟合，共 3,600 次。
- `20260929-phase2-d92-osc-repeat-rx1-m4-r02`：4 个模型，每模型 300 次任务拟合，共 1,200 次。

覆盖模型 seed 2026092701 至 2026092704、全部 K、新类规模、接收机、场景和 support seed。未挑选有利或不利任务。4,800 次本地 compact 与远端 trace 的 split ID、任务坐标和 OOF 分组 NLL 逐条一致；注册任务坐标无重复。每次任务均记录 `selection=none_cv_diagnostic_only`、唯一固定公式、0 个优化器更新以及 0 个 source/query 拟合行。

结构化结果、每模型和每批次的完整分组、78 项 K×物理类别统计、8 个源文件的路径与字节数见[诊断 JSON](D92_OSC_SUPPORT_DIAGNOSTIC_20260929.json)。JSON 只保存诊断汇总与输入清单，不复制样本特征或 query 结果。

## 每个 K 的真实留出规模

每个 K 都有 1,200 次任务，其中 240 次只含 6 个旧类，960 次同时含新旧类。注册类别数 C 为 6、8、11、16 或 26。下表每折的 n/h 是每类实际训练/留出物理样本数，来自全量 trace 的 train/held ID 核对，不把四视图计成四个样本。

| K | 有 OOF 的任务数 | 三折 n/h | 每任务留出总数 | 全部留出预测次数 |
|---|---:|---|---:|---:|
| 1 | 0 | 无 fold | 0 | 0 |
| 5 | 1,200 | 3/2、3/2、4/1 | 5C | 80,400 |
| 10 | 1,200 | 6/4、7/3、7/3 | 10C | 160,800 |
| 20 | 1,200 | 13/7、13/7、14/6 | 20C | 321,600 |

每个有 OOF 的任务中，训练与 held ID 互斥，二者并集等于该任务全部 support；每个 support 恰好留出一次。每折记录的真实训练 ID、实际 n 和 `nu=C*(n−1)` 一致。合计 562,800 次留出预测，但按接收批次和物理 ID 去重只有 10,605 个 support ID。相同物理样本在不同模型、K、类别规模或 support 抽样中复用，因此不能把 562,800 次预测当成同样多的独立样本。

**K1 没有独立 OOF 证据。**1,200 次 K1 均为 `oof=null`、0 个 fold，最终状态为 `ZERO_PHYSICAL_RESIDUAL`。这表示每类只有一个物理 support，按公式不估计物理残差协方差；不表示四视图彼此相同，也不是分类成功或失败的证据。四相位视图不能替代独立物理验证样本。

## 视图统计是否足够

现有 trace 保存 medoid 物理 ID、每个训练样本的循环 shift、对齐后跨物理样本残差的 `covariance_trace`、平均联合特征能量以及零残差阈值。最终拟合的协方差 trace 范围为：K5 为 0.07709 至 0.52874，K10 为 0.09030 至 0.51990，K20 为 0.09994 至 0.50048；上述 3,600 次最终拟合均进入 `SHARED_COVARIANCE_FIT`。联合特征能量为 1，仅有 K1 的浮点舍入误差。

这些量的含义有限：

- `covariance_trace` 是类模板周围、完成对齐后的跨物理残差，并非同一物理样本四视图之间的变化。非零值不能证明相位结构含有类别信息。
- 联合特征能量接近 1 主要来自固定块归一化，不能证明类别间可分或预测可靠。
- medoid 和 shift 记录了离散选择结果，但没有最优与次优循环距离的间隔、medoid 目标间隔或对输入扰动的稳定性。
- 日志没有逐物理四视图方差、视图间相似度、跨类别 orbit 距离、模板间重叠、协方差完整谱，或同一 held 样本在不同视图/不同特征块下的对照分数。OOF 真类 NLL 和 argmax 类别也不能恢复全部 C 维 logits。

因此，目前记录不足以区分“编码器对相位完全不敏感”“相位变化存在但主要反映无关扰动”“类别 orbit 有重叠”“有限 support 的模板估计不稳定”或“固定打分尺度造成 NLL 变化”等不同解释。本次没有通过读取特征数组或增加实验来补这些缺口。

## 能与不能推断的可辨识性

可以确认：当前固定表示与固定 OSC 判别器，在所记录的物理 support 留出任务上产生了可核查的 NLL 和标签预测；给定任务内每个 held 物理样本均不在该折训练集合中。完整逐类记录允许描述这些已观察任务中的类别差异，且诊断未触发候选选择。

不能由此确认：类别在该表示中的信息论可辨识性、Bayes 最优错误率、任意判别器的性能上限、四相位机制相对于视图均值的独立贡献，或对真实 query、其他接收机和新数据的泛化表现。有限 support 上的错误可能涉及表示、估计或固定判别规则；缺少相应观测和对照时，聚合 NLL/accuracy 无法唯一定位原因。尤其不能用 K1 的“零物理残差”或无 OOF 来声称 K1 可辨识或不可辨识。

本报告只核对信息边界，不提出模型、阈值、预算或下一实验参数，也不把已知历史 query 结果带入解释。
