## 9. 研发判断与限制

本轮配置与健康运行保持冻结。源证据支持优先解决三点：一是分开诊断动作敏感性与 train/eval dropout 差异，并检查有限 margin 惩罚是否在辅助步骤过度主导成熟 CE 方向；二是让 R 先在留出 TX 上证明差值幅度和方向可靠，不能只降低 c 门槛扩大激活；三是 C0/C1 的 clean CE 续训改善源 clean，却降低多种压力表现，说明保持 clean margin 不等价于保住父模型的扰动稳健性。

以上是基于完整源证据的后续方向，不是当前自动改参、停机、重训或重新选模指令。本报告源 row 无缺失，目标 scores/predictions/truth 均未访问。84% 三 seed clean 的验收仍由独立冻结测试报告给出；源 V 高准确率不能替代目标泛化结论。
