# 固定Phase1的D92优化

## 目标与验收

用户于2026-09-28要求继续优化D92，允许较大改动，并选择“固定Phase1：优先提升各K的新旧类综合H，并约束旧类退化”。Phase1固定现有从零训练、epoch200最终权重及原始物理数据契约。当前goal保持进行中，不能因代码或源域诊断完成而标记成功。

主指标为每个K=1/5/10/20的新旧类准确率调和均值H，先逐episode计算，再对匹配receiver/scene/new-count/support-seed/model-seed聚合。旧类约束在同一注册类别表、同一query、同一row比较；旧6类任务单列，不能与6旧+N新直接相减。工作验收口径：每K的平均H均提高，旧类平均准确率相对原D92下降不超过1个百分点；同时报告各场景和最差receiver，不能用平均值掩盖明显退化。这是本轮目标的可检验解释，不是新协议门槛。单模型单seed结果不构成稳定性结论。

已有目标评分已经公开。不得从已评分矩阵选择超参数、seed、候选或重跑。候选的性能开发只用合法source证据和算法内部合法support；最终确认口径等待用户选择独立未暴露样本或一次性描述性重放。历史产物全部保留。

## 已核实实现事实

- 当前D92为P2-256-FULL：identity160+FFT96、E0去RF32；K≤2回退单位协方差最近中心，未启用D92注册任务平衡协方差。
- 原路径还含旧类support对角度量与多层融合。具体性能归因仍需实验，不能仅凭K1低分就判定某个模块是原因。
- 新版本独立实现，不修改原D92代码或既有输出。

## D92-SCV-v1候选

1. identity与FFT各自归一化，统一使用全部注册类构建判决；省去旧版多层度量/融合链。
2. K≥2仅从support的类内残差估计协方差，旧/新注册任务等权，加入正值球形正则，避免小样本奇异逆。
3. 在每类最多3个物理support留出fold上选择FFT权重、ridge和旧类保护强度；先满足同类别竞争下的旧类准确率约束，再最大化support-H，以平衡NLL打破平局。类别标签置换使用相同公式。所有fold状态丢弃，最后只用全support拟合。
4. K1没有独立类内方差证据，使用固定identity余弦原型。默认旧类条件判决采用冻结Phase1 logits。联合注册中只重分配旧类内部概率，不改变support估计的旧/新总质量，全部query仍面对全部注册类。该性质不保证联合旧类准确率不退化，必须实测。
5. query只逐样本前向，无truth/role、batch类别配额或全局重排。source原型不用于在线拟合头，Phase1不更新。

初始grid固定：FFT权重0/0.5/1/4，ridge0.1/1/10，保护强度0/0.5/1。目标query不用于选grid。候选名标识机制变化，不借用D92原结果宣称性能。
