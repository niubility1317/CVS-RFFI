# CVS 分数频偏校正：前瞻原型

本轮仅形成新结构原型，尚未正式训练、选模或测试，不宣称识别收益。后续约束仍为普通交叉熵、无增强、仅身份骨干、原物理划分、从零训练、性能优先、源冻结后选中候选独立 clean 收尾。

## 源证据和问题

完整同步、乘性坐标保留、加性坐标注入的源实验都没有超过固定原残差源控制。加性等变核心 E200 四 seed 源 V 为 97.3333%、最差源 RX 为 92.7639%，原残差为 98.0694% 和 94.4954%。相同参数与 seed 的加性对乘性 V 平均改善 0.0306 个百分点，最差 RX 改善 0.0046 个百分点，不能称可靠优势。

完整冻结 40 行加性内部消融显示，等变核心屏蔽频率后平均下降 0.0278 个百分点，改变 70.5/27000 个预测；屏蔽全部坐标下降 0.0620 个百分点，四 seed 都下降。加性注入增加了实际坐标依赖，但不足以弥补与原残差的差距。这里不把内部消融当作硬件因果干预。

新的假设是：先完整减去 received 频偏，再从三个标量补回身份特征，可能形成表达瓶颈。相对频偏包含 TX、RX 和传播的混合贡献，不能默认全部属于可删除的干扰。频偏在波形上的作用是逐样点复指数调制，直接在该作用位置保留一部分频率坐标，比仅在最终实特征中注入方向更贴近通信关系。**这是机制假设，源实验尚未证明它有效。**

仅依据[加性完整源报告](../automation_reports/CV-SincNet/20261002-phase1-cvs-additive-identity-manysig-m8-r01/report.md)的源字段及[冻结源消融](../automation_reports/CV-SincNet/20261002-diagnostic-cvs-additive-usage-source-manysig-m40-r01/report.md)。完整源报告包含按协议保留的历史测试附录，附录测试分数不参与本设计。

## 物理作用和边界

重复字段给出 ω(x)=arg(C)/20，仍沿用 80:160、20 点周期、25 MHz、256 点 received IQ。改为 `y[n]=x[n]exp(-j α ω(x)n)`。所有身份路径只读 y，不加原始 IQ 旁路、特征 conditioner、类别专用分支或额外损失。

比较同一 equivariant_memory 核心的两个原型：α 固定为 0.5；α=σ(a)，a 是全类别、全包、全 RX 共用的一个可学习标量，零初始化对应 α=0.5。两者初始输出精确相同，固定半校正用于分离“改变作用位置”和“学习校正比例”两件事。核心宽度、深度、160 维身份头及 scale30 不变。

额外相对频率 ν 作用为 `x'=exp(jνn)x`。在相关有效且不跨主值分支时，ω(x')=ω(x)+ν，因此：

`y(x')[n] = exp(j(1-α)νn) y(x)[n]`。

该式描述残余频率的协变，不是整网频偏不变。常量公共相位不改变 ω，已有复等变核心的整体常相位性质仍保留。采样幅度不变，记录的 αω 与 y 可以逐点重建原 received IQ；这不是从最终身份特征恢复原信号的承诺。

α 是源域判别折中参数，**不是 TX 或 RX 晶振占比估计**。不宣称任意信道/RX不变、绝对 CFO、唯一硬件参数或因果身份分离。CFO 的歧义仍为 1.25 MHz，主值约 ±625 kHz；跨主值分支时上述协变公式不适用。退化相关在 atan2 前安全回退零频率，不进行校正。

数学上有限 a 对应 0<α<1；浮点 sigmoid 可能饱和到端点，实际 α 必须测量并报告，不能声称始终严格保留非零残余频率。学习 α 并不保证源域或跨接收机性能更好。
