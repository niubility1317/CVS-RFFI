# 后续源研究假设：相位增量与局部频谱差分

本方向在读取 attentive clean 结果前确定，仅依据合法源曲线和现有原生网络接口。attentive 源均值池化候选 E200 的源 V 为 97.7194%，最差源 RX 均值为 93.2963%；聚合层的可学习权重并未改善这些源指标。当前原生网络已有确定性的 PhaseDeltaStabilityStem 和 DSQFreqStabilityStem 接口，尚未在本轮基础网络比较中启用。本文件只是固定后续结构假设，尚未登记或启动新实验，不改变任何已发布模型。

固定两个候选：`phase_delta` 在原残差 CVS 中增加原生默认 8 通道相位增量线索；`phase_dsq` 再增加原生默认 4 通道频谱差分线索。保留原始 time/frequency/PA 路径、宽度、深度、160 维嵌入、稠密融合、PA 残差头和 dropout。新增通道来自明确定义的物理统计，不扫描任意隐层宽度，不增加损失、增强、域骨干、接收机标签、checkpoint 继承或 query 拟合。

数学上，令 Sinc 后复特征为 z，邻时刻乘积 `z_t conjugate(z_(t-1))` 的实部和虚部分别对应 dot/cross。在统一复相位旋转下，乘积和包络均不变；原生 stem 用其相位角的 sin/cos、归一化包络和包络差分产生补充特征。此不变性只适用于该 stem，不适用于保留原始 IQ 路径的整个网络。有限精度、低能量样本和边界须用实际梯度测试核实。

局部频谱差分为 `(I-A_5)F`，A_5 是现有 5 点平均算子。它精确消去特征轴上添加的常数，但任意信道变化并不等于给这些压缩特征添加常数；不能据此声称完成信道补偿。原始频谱特征同时保留，避免将可能有身份信息的缓慢变化全部删除。

通信上，邻时刻相位变化可包含调制、载波偏移和相位噪声等响应，发射机与接收机均可能贡献；本结构不把 CFO 当成发射机专属指纹，也不抹去原路径中的 CFO 线索。物理上，包络差分和相位响应与非线性及记忆效应相关，频谱局部差分可能为非理想频谱纹理提供补充，但不唯一辨识硬件系数。RFFI 上检验的是确定性补充表征是否改善同一身份 CE 的特征学习，不能凭原理先宣称性能必然提升或实现 TX/RX 解耦。

若执行，仍为两候选×四固定 seed、同物理划分、scratch E200×50、普通身份 CE、无增强和域骨干，按既定四 seed 源 V/最差源 RX 分数冻结一个候选后默认仅测 clean。未选候选不测试；当前或历史目标成绩不用于选候选、系数、调参或选择性重跑。参数与计算是次要条件，必须实测性能、成本并报告负结果。
