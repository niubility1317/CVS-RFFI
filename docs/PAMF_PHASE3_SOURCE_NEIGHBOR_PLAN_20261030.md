# PAMF 源端匿名跨接收机正对

本轮先验证下一版未知身份结构学习的输入是否可靠，不继续增加二元拒识器容量。参考条件 C1 已完整负结果；源 paired1000 虽有 94.2525% AUROC，合法运行点未知拒识只有 43.7143%，简单拼接视图也没有解决尾部重叠。本轮不根据开发 Q 调整阈值或选择源 checkpoint。

## 研究依据与边界

[OpenNCD](https://arxiv.org/html/2305.13095v1)联合学习表示与原型组关系，并尝试估计未知类别数。这里借鉴的是“需要学习未知内部结构”，不是复现其网络或假定其视觉结果能转移到 RF。[近期 RF 向量量化工作](https://arxiv.org/html/2610.05979v1)把识别、拒识和发现连接到共享潜空间，但其注册使用有标签数据，不能直接作为本项目无标签注册的证据。

本实验只准备直接正对。没有目标端拟合、类别注册、未知 TX 真值、真实未知 K、配额、原 U_s、V 或 novel 输入，也不产出正式 A_K/R_U/未来 A_N。无人工 TX 标签的 OE 关系仍可能错误；L 的精度不能当作 OE 的真实精度。

## 数据和特征

沿用原 original F0 Tri-SIG-TIME SSL E50/11100、六类默认头、232993 参数和匹配 DURA v1 祖先。输入仅为已验证 source G10 MIX01 L6300、OE6134，source 五 RX、三日。L 的真实旧六类 y 可用于源训练规则校准；OE 只允许 opaque ID、RX/day 和同条星地观测，不解封 TX/K。

P1 完整单位 fused160 直接复用 `20261029-phase3-star-joint-ova-s2026092701-r02/teacher/{L,OE}.npz`，该 teacher 来自 original F0，不是 joint-OVA 增量模型。逐 ID、source cache handle、F0/DURA 身份必须一致。缺少的 P0 完整单位 fused160 由同原 F0 对既有 `received.npy` 导出；不重新抽信道，不读 clean，不读取缓存 restored 值或运行 G。真实 F 新前向共 12434 行，烟测另 2 行；历史 P1 导出和 G 缓存成本保留。重复计算不增加独立物理样本。

## 固定两个关系规则

- P1 控制：每条记录在每个其他 RX 中寻找 day 也不同的最近邻；对应 RX 的反向关系也必须选回。
- PAIR 唯一主：在同条 P0 和 P1 特征上独立搜索，上述双向最近邻关系必须在两条路径完全一致。

距离为 FP64 cosine distance。候选搜索不接收 y；ties 按 opaque ID 字典顺序确定，不按 TX、输入顺序或真值破平。每个无向对只留一次。P1 距离为 d1，PAIR 距离为 max(d0,d1)。

对每个规则，仅在 L 上选最大的可行距离阈值，距离 ties 整组处理。全局、五个 RX incident-edge 组、六个已知 TX incident-edge 组分别要求正对精度≥98%、每组至少 25 个候选边。组内有任一端属于该组即计入，错边在涉及的各组均计错。没有可行阈值则为 null、输出空边；不替换规则或放宽精度。

两规则 L 阈值全部冻结后才对 OE 挖掘和应用阈值。OE 不接收真实 y、TX 数或设备映射。报告直接边数、节点覆盖、RX/day 分布；连通分量即使输出也仅作链式合并诊断，不当作真实类别数或传播为硬伪标签。

## 事前科学判定

本轮只是可证伪的学习输入验证。PAIR 若有合法源阈值，L 与 OE 的总体直接边节点覆盖均≥20%、各 RX 节点覆盖均≥10%，且 OE 直接边≥256，才可进入另一个独立源训练候选的设计与发布；控制不能替换主方法。它不证明 OE 精度达到 98%，更不证明 Phase3 达标。否则保留 NO_RELIABLE_SOURCE_NEIGHBORS，不启动依赖该正对的训练。

下一训练候选只考虑直接跨 RX 正对的身份一致性和防塌缩目标，匹配同记录视图一致性控制；保留原默认身份头与原 F0 同输入保护。当前不实现、不启动下一神经训练，不以连通分量充当设备标签。

## 执行与范围

唯一新 run/output root、一个代码提交、一次直接 P0/P1 审查、一次 N607 preflight、单 archive 比较/compile；launcher 先真实 original F0 合成 G10 无 query smoke，PASS 后立即导出，再独立 CPU 挖掘。每卡最多新增两个本任务进程，本轮仅一个特征导出 GPU worker，启动实际 free≥4096 MB；foreign 工作不整卡排除，不停止、修改或重启其他任务。

运行状态、精确命令、路径和逐行矩阵留在 experiment.json/run 报告。所有产物保留，无自动重试、热改或科学分数触发停止。UNKNOWN 核查原 PID/root。没有私有 truth 输入，因此本轮不存在目标 truth 评分；全部指标明确属于 source L 规则拟合及无标签 OE 覆盖诊断。完整 Phase3、targets v3、正式 RX 和未来匿名注册目标保持 ACTIVE。
