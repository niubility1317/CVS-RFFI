# CVS 可学习相位记忆残差：前瞻设计与确认规则

目标仍是提高固定 clean 测试的身份识别性能。训练只用交叉熵，不使用星地增强或域骨干；保持原物理划分，各模型从零训练。本文冻结结构假设和源选择规则，不把公共公式检查或源域成绩当作测试提升。

## 设计依据与本轮差异

上一轮固定半权重 Volterra 输入的两个候选在完整四 seed 源规则下未超过 coupled_lag4 控制。控制性能分数为 97.0287037%，固定 lag1、lag4 分别为 96.9861111%、96.8847222%。源末 batch 的三阶输入相对控制变化约 0.559 至 0.722，五阶约 0.485 至 0.690。证据来自完整源记录和实际卷积输入；这些变化尚不能证明是性能下降的原因。

本轮保留 lag4 包络控制的初始函数，以两个 CE 训练的全局系数学习相位记忆残差。固定候选只有 phase lag1、lag4，各四个模型 seed。没有对系数、延迟、门控初始化或训练预算做目标成绩驱动的扫描。此前六环境测试仅作报告，未用于本设计。

核心仍为 12 个复数行为输入、原时间/行为六个复数块、原位置功率读出、160 维嵌入和尺度 30 的余弦分类头。总参数由 202553 增至 202555；增量仅两个全局系数，全部参数参与 CE 更新。相对 residual_fusion 的 164225 参数，本家族不是等参数对照，必须同时披露这一差异。

## 数学结构与初始化

令 z 为原输入层的径向裁剪复数 IQ，P[t]=|z[t]|²。对每个 m=0,1,2,3，令 t=n-m；负下标作零填充。定义：

```text
p[t] = (P[t] + P[t-4]) / 8
C_l[t] = z[t-l]^2 conj(z[t-2l]) / 4
a3 = tanh(raw3), a5 = tanh(raw5)
u1 = z[t]
u3 = z[t] p[t]   + a3 (C_l[t]   - z[t] p[t])
u5 = z[t] p[t]^2 + a5 (C_l[t] p[t] - z[t] p[t]^2)
```

raw3、raw5 从精确零初始化，是模型参数；不按包、类别、接收机或测试数据拟合。系数允许正负值，属于残差修正，不是凸混合或已辨识的 PA 系数。AdamW 使用原学习率和权重衰减，对这两个参数也生效。

在零初始化时 u3、u5 精确等于原 lag4 控制。实现直接复用原控制的浮点计算顺序，再加零残差，因此公共检查不仅验证代数等价，也验证 torch.equal 的输入、共享 state 和初始 logits。新增零参数不消耗随机初始化序列；从零构造的共享参数逐项相同，没有加载控制 checkpoint。

对任一阶 r，门参数的 CE 梯度为 `(1-tanh(raw_r)^2) <dL/du_r, Q_r-B_r>`，内积包含 batch、四个延迟和复数的两个实分量。raw=0 时 tanh 导数为 1，新增系数可以获得非零梯度；此时旧骨干的输入 Jacobian仍与控制相同。实际训练是否改变系数，由每步梯度、优化前后 raw 和实际系数记录证明，不能仅从 requires_grad 推断。

该做法借鉴零初始化残差保持初始函数的思路；[ReZero 原论文](https://arxiv.org/abs/2003.04887)不证明本模型的动力学等距、收敛速度或 RFF 性能。这里保持的是既有控制函数，并不是把整个深网络初始化为恒等映射。

## 通信与相位性质

对仿射相位 `z'[t]=exp(j(phi+omega*t))z[t]`，包络 p 不变。三阶项的相位为 `2(phi+omega(t-l))-(phi+omega(t-2l))=phi+omega*t`，因此 C、z p、C p 和 z p² 对当前 t 具有相同相位因子。每个延迟槽的 lift 对仿射相位协变，四槽分别具有 n-m 的相位。

整网只保留已有常相位性质；有限卷积、频谱前端和学习滤波器仍可对频偏产生响应，不能由 lift 的协变推出整网 CFO 不变。raw 输入保留，固定 alpha=0，不做频率校正。重复场相关只记录 received 相对频率，不声称估计发射机晶振或把 TX/RX 频偏分离。

25 MHz 采样下，phase lag1、lag4 是 40 ns、160 ns，新增三阶项最大历史 2l 为 80 ns、320 ns；固定包络历史 lag4，四槽另有 0 至 3 点延迟。它们是设计时间尺度，不是实测器件记忆常数。边界零填充，不使用循环卷回或未来样本。

## 物理与射频指纹解释

复基带 Volterra 项包含有、无共轭的延迟乘积，可表述具有记忆的非线性系统；[复数系统 Volterra 推导论文](https://www.sciencedirect.com/science/article/abs/pii/S0165168416302043)是此结构的物理动机。上述延迟组合、缩放和残差门控是本项目自己的受限结构，并不是该论文的完整模型或其 RFF 性能结论。

目的在于让身份骨干直接接触包络之外的延迟复相位交互，检验这些 received 特征能否增加跨接收机稳定的身份信息。它不等于恢复唯一 TX 硬件参数。传播、接收机非线性、均衡和未知激励都可能生成相同或相近的接收项；公共 TX/RX 镜像和三阶同波形反例继续保留。不能据此声称完整 Volterra、DPD、因果 TX/RX 解耦或任意 LTI/RX 不变。

源最终诊断覆盖全部 V 的 TX×RX×day 90 个单元，记录嵌入几何和 received 相关；公共冻结链覆盖 5 TX 设置×6 RX 设置、常相位及±80 kHz 干预。公共设置没有真实源身份标签，不给合成身份准确率。弱输入和短输入用于有限性检查，公共合成波形不用于正式训练增强。
