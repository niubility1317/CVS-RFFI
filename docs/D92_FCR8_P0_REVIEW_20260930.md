## 数学与实现核对

- 核心 `latent_coordinates()` 对 `H/√N` 作缩放后的薄 SVD；数值秩阈值来自冻结配置。W 仅定义优化坐标，固定 U 时共享坐标不参与 inner head 的距离、带宽或核。满秩换基的等价性只适用于保留子空间相同、数值秩判定一致及可逆坐标变换；有限精度阈值附近不宣称无条件等价。
- `U=anchor_U+ZWᵀ` 保留原始 U 的未训练方向。Z=0 精确复制 anchor；C_seq 继承原 B 的 U 后重新构造当前 W，C_reset_init 从 U=0 开始，两者共用同一固定 B 教师准备。N_new=0 精确复用 B。
- 物理样本平均的 pre-tangent 位移平方是 `||Z||²`，近端项为 `0.5||Z||²`，无第二次除以 N；总梯度为 `G_U W+Z`。rank=0、全零 H、秩缺失与极端非有限逆尺度均有明确处理。字典只预计算一次，未利用外折 held 输入构建 W。
- 核、原始带宽、trace normalization 和 task/keep 两个伴随通道沿用现有合法机制。教师 head 仅拟合旧类 inner-train，teacher score/q 与 ID、mask 一并归档；没有 query fit、query 反馈或 source 样本读取。
- 四轮、每轮至多三次固定 trial，接受同时要求 Armijo、实际总目标非增和实际 keep 风险达标。接受与拒绝缓存隔离，最终状态及目标来自最后一次接受缓存。该结论是带既定舍入容差的训练目标条件，不是泛化准确率或连续优化收敛保证。
- 完整 Z/U/W、梯度、方向、教师及 trial 状态保存于独占 NPZ，JSON 为原生有限数值，汇总从归档重算坐标、近端项、位移、三项接受条件、停止原因和计数。输出创建使用独占路径；失败保留已有产物，不重启健康其他 lane。
- 最大可训练坐标数为 `736×8=5888`。材料化 U 与固定 V0 各 47104 bytes，共 94208 bytes；head、原始/适应 support、继承状态、H/W、教师和优化缓存另计。固定 160 parent / 4 row 预算区分 baseline、共享准备、教师、trial head、两种伴随与最终评分。未测量传输量及 GPU 指标保留 N/A。
