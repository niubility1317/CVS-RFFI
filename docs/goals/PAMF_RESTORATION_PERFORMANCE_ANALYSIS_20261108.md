# 星地恢复性能分析与优化方向

截至 2026-11-08。识别器为同一冻结地面 Tri-SIG-TIME SSL 默认头。Main 两个互斥总体合计 168000 条；原始 clean 正确 145385 条，准确率 86.538690%。用户要求六个星地场景逐个距 clean 不超过 3 个百分点，即每景至少 140345 条正确、83.538690%；两个 clean 总体也要分别保持。以下都是单个模型种子的正式测试结果，已反复用于研发，不能称为独立盲测。

## 哪些方向已有可量化收益

1. **识别特征响应约束值得保留。** 在已预登记的匹配对照中，连续特征响应相对只用稠密 IQ 响应的版本，低城区净增 2829 条、提高 1.683929 个百分点，中城区提高 0.900595 个百分点，低郊区提高 0.491667 个百分点；高郊区下降 0.233929 个百分点。它说明针对冻结识别器的连续特征有实际价值，但仍落后 DURA，且是一个种子下的整套训练配方比较。
2. **提高源响应约束的可靠性有帮助。** 可靠度加权版相对等权匹配版，六景分别提高 0.393 至 0.503 个百分点，但低城区仍只有 66.255952%，比 DURA 低 2.545238 个百分点，另一 clean 总体净少 17 条。不能只看相对弱对照的提升。 [结果](../../automation_reports/CV-SincNet/20261108-phase1-Restore-ResponseReliability-E30-s2026092701-r02/analysis.md)
3. **源接收机先验失配训练对弱城区有收益。** 与原条件均值匹配版相比，低城区净增 1264 条、提高 0.752381 个百分点，中城区提高 0.317262 个百分点；clean 降低 0.170833 个百分点。下一步需要保护 clean，而不是根据目标成绩逐场景拼接版本。
4. **增加网络规模或多假设本身不足以保证收益。** 源波形多假设融合版低城区 62.322619%，有界投影版为 68.347619%，均低于 DURA；前者两个 clean 总体仍分别净增 237、13 条。说明应优先保护识别相关信息和物理估计，再判断扩容效果。 [多假设](../../automation_reports/CV-SincNet/20261108-phase1-Restore-MixtureFusion-E30-s2026092701-r01/analysis.md)；[有界投影](../../automation_reports/CV-SincNet/20261108-evaluation-Restore-ScoreRepairBounded-s2026092701-r01/analysis.md)。

## 信道估计和可恢复性的证据

固定 480 条源验证记录的低城区模拟对照：原盲估正确 401 条；仅将主路/镜像调制替换为模拟真值后正确 424 条；完整模拟算子已知时正确 430 条；再给出真实噪声标量为 426 条；raw clean 为 474 条。替换真实物理参数是不可部署的源端反事实，受源样本和原模型限制；其数值既不是目标数据表现，也不是任何恢复网络的理论上界。该对照支持优先研究时间变化的主路/镜像调制估计，但不能忽略噪声和其他误差。[源端归因](../../automation_reports/CV-SincNet/20261107-diagnostic-Restore-action-factor-sourceV-s2026092701-r01/analysis.md)

进一步拆分同一 480 条源样本的接收调制：只给定主路整体相位时，低城区从 401 提升至 422 条正确；给定完整主路为 424 条，仅替换镜像分量仍为 401 条。这个源模拟面板中，主路相位校正的净增 21 条占完整调制净增 23 条的 91.3%。它说明相位是该固定模拟器和恢复器下的重要误差来源，不能推断其他信道的镜像分量不重要。无需真值的协方差加权相位估计在该面板得到 414 条，仍低于已知相位的 422 条；另一等权估计反而降至 378 条，说明估计方法和先验可能引入偏差。[调制分量归因](../../automation_reports/CV-SincNet/20261107-diagnostic-Restore-modulation-components-sourceV-s2026092701-r01/analysis.md)；[可观测相位估计](../../automation_reports/CV-SincNet/20261107-diagnostic-Restore-coherent-main-phase-sourceV-s2026092701-r01/analysis.md)

已有从零训练的调制分量监督版，相对其原物理版匹配对照仅使低城区提高 0.039881 个百分点，clean 降低 0.090476 个百分点；该版未使用 F 指导。已知相位的反事实收益不能直接视作可训练模型能获得的收益。未来设计需在合法源域检验相位估计误差、可识别特征、clean 保护和负迁移，再做固定的完整正式测试。[已完成的调制监督实验](../../automation_reports/CV-SincNet/20261107-phase1-Restore-ModulationCovariance-E30-s2026092701-r01/analysis.md)

正式 Main 测试给出了更具体的边界：冻结 CovarianceMAP 上增加协方差加权主路相位估计后，低城区从 67.198214% 提升至 68.233333%，净增 1739 条，即 +1.035119 个百分点；两个 clean 总体分别比 raw 净增 300、145 条。低城区仍比 DURA 低 0.567857 个百分点，也未达验收。此对照的新相位路径运行在 CPU，原版控制流复用了 GPU 预测，设备和数值路径不同，不能把全部差异都归因于相位方法。另一个从零训练的独立相位监督版本低城区为 56.278571%、六景均未达标，且两个 clean 总体未同时保持；它与匹配版的结构和监督同时变化，不能单独归因于相位监督。两个结果表明，相位信息值得进一步研究，但简单叠加监督或无保护校正并不保证收益。[可观测相位正式测试](../../automation_reports/CV-SincNet/20261107-evaluation-Restore-CoherentMainPhase-CPU-main-s2026092701-r01/analysis.md)；[独立相位监督正式测试](../../automation_reports/CV-SincNet/20261107-phase1-Restore-PhaseSupervisedCovariance-E30-s2026092701-r01/analysis.md)

低城区当前最好已测识别率 69.490476% 约为 clean 识别率 86.538690% 的 80.30%。这是两个准确率之比，不是原始 IQ 波形或发射机信息恢复了八成，也不是理论极限。仅靠现有测试不能给出普遍有效的 IQ 恢复上限；需要在明确波形误差、信道噪声、原始 clean 和识别任务口径下分别评估。

另一项事后分析只比较五条已固定的预测：原受损输入、DURA 和三个已完成恢复器。假设能逐条知道哪一路的真实答案，低城区五路正确集合并集为 146533/168000，即 87.222024%；仍有 21467 条五路全错。这个数是**这五条既有预测在真值选路下的上限**，比验收门槛多 6188 条正确，却依赖部署时不可用的真实标签。它说明现有输出存在互补，不能证明无标签路由可以达到该数，更不是任意新恢复网络的信息论上限。该事后结果只作描述，不用于当前网络训练或选模。[五路固定预测互补性](../../automation_reports/CV-SincNet/20261108-analysis-Restore-FiveWayComplementarity-Main-s2026092701-r01/analysis.md)

## 接收机先验失配

固定 480 条源 V 样本的低城区诊断中，在相同盲估信道和噪声下，使用同源接收机拟合的先验得到 412 条正确；只把均值换成其他源接收机时为 408，只换协方差为 364，均值和协方差都换为 341。两套先验均来自各 12600 条合法 L_s/U_s IQ，源 V 仅用于冻结后诊断。该固定反事实中协方差失配影响更大，而且均值和协方差共同变化存在交互，不能简单相加。[源端先验分量对照](../../automation_reports/CV-SincNet/20261107-diagnostic-Restore-prior-factor-sourceV-s2026092701-r01/analysis.md)

该对照使用已知源接收机身份选择先验，并不能在未知接收机部署时直接取得同组先验，更不证明 Main 性能差距都由协方差造成。已有观测条件化方差分支的源 E02 小面板显示，其附加方差已接近零且局部梯度很小；该面板仅 70 条 L_s，不能外推到整个训练集或判定唯一失效原因。对应正式版的低城区为 67.087500%，clean 两总体分别净增 154、净减 12 条，未优于 DURA。后续需在合法源域验证能否从当前观测可靠调节先验，同时保持正定性、噪声稳定和 clean；不能把源接收机身份或目标真值当作部署路由。[源训练诊断](../../automation_reports/CV-SincNet/20261107-diagnostic-Restore-conditional-variance-E02-sourceLU-s2026092701-r01/analysis.md)；[条件方差正式结果](../../automation_reports/CV-SincNet/20261107-phase1-Restore-ConditionedCovariance-E30-s2026092701-r02/analysis.md)

## 反演和特征约束的边界

对于局部线性模型 y = Ax + n，若噪声在实数 IQ 坐标下是方差为 σ² 的白噪声，使用已知 A 的伪逆 A⁺ 反演后，噪声误差为 A⁺n。在 A 的奇异值为 sᵢ > 0 的右奇异方向上，误差方差为 σ²/sᵢ²：信道对该方向的响应越弱，直接反演越容易放大噪声。实际网络可以使用先验和非线性处理，真实噪声也不一定满足白噪声假设；这一公式说明取舍，不给出本数据集的可恢复比例或任意恢复器的识别上界。已有源响应诊断中，低城区许多 1% 合成扰动的信道输出相对噪声很弱；按可靠度约束响应是可检验的方向，而不应强制所有弱方向无限放大。[源可观察性诊断](../../automation_reports/CV-SincNet/20261108-diagnostic-Restore-ResponseObservability-sourceLU-s2026092701-r01/analysis.md)

当前 F 引导使用的是每条 IQ 的 160 维连续特征，输入为 2 × 256 = 512 个实数。在 F 可微的点，其特征雅可比矩阵至多 160 阶，因此至少存在 352 维输入扰动方向在该点不改变特征的一阶近似。这个维数结论不证明这些方向含有真实发射机信息，也不代表有限幅扰动或受限信号流形上的变化不可识别；它说明仅靠 160 维特征匹配不能约束整个 IQ 波形。现有配对 IQ/STFT 目标可补充这类约束，最终仍需逐设备真实 TX 测试，而不能只检查特征相似度。

图像任务中的研究也提出过用任务网络特征指导恢复，并指出指导网络的偏置可能限制被恢复的有用信息；该研究使用图像及交替更新任务网络，不能当作本项目星地结果，也不能据此更改冻结 Tri-SIG-TIME SSL、源数据或无 TX 标签的约束。[Kim 等，CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/papers/Kim_Beyond_Image_Super-Resolution_for_Image_Recognition_with_Task-Driven_Perceptual_Loss_CVPR_2024_paper.pdf)

## 正在验证的单阶段新网络

原 CovarianceDetail 对物理信道估计和 IQ/特征细节分开反向传播。新源域诊断对固定 28 条 L_s/U_s 源记录分别计算 E0 和 E30：特征损失梯度能够穿过高斯求解到达物理估计头；特征与物理监督梯度余弦为负的样本分别为 15/28、4/28。E0 时 IQ 与物理梯度在 23/28 条上方向相反。该样本很小且不代表总体，不能作为性能提升证明。[源域诊断](../../automation_reports/CV-SincNet/20261108-diagnostic-Restore-PhysicalFeatureGradient-sourceLU-s2026092701-r02/analysis.md)

据此，新候选让波形与冻结 F0 连续特征经可微后验回传，传入物理估计器的这部分梯度预固定缩放为 0.05；物理监督本身在合并前不缩放。合并后的物理分支还会执行梯度裁剪和 AdamW 更新，因此不能断言最终物理参数更新与原训练一致，也不能保证冲突被消除。0.05 是源小样本启发式，不保证最优。恢复器从零单阶段训练 30 轮，使用原 L_s/U_s 模拟配对，不用 TX 标签、分类 logits、V/OE 或目标数据训练；F 引导版本明确不是 F-free。固定最终模型后自动完成两总体七景预测和独立 truth-last 评分。真实源样本和冻结 F0 的前向、梯度检查已通过；正式性能尚待训练和评分。

优先后续方向是在合法源域评估可部署的时间变化主/镜像调制估计、对识别特征变化的保护、以及 clean 身份映射保护。每次只做预登记的源端决策，冻结后完整报告六景和两总体 clean，不能根据本测试集结果反复挑 checkpoint 或按场景拼接。参数量不设人为上限；训练效率单独按实际单阶段耗时和资源统计。
