# Tri 的数据自适应训练设计

先提升十类和六源的固定 E50 跨接收机 clean。固定配置的匹配实验继续进行，用于识别哪些损失和视图值得放进自适应范围。自适应机制最终应在未用于设计规则的数据设置和新训练种子上使用同一套决策规则，比较它离各设置事后最优固定方案还有多远。

当前固定剂量矩阵不支持用单一指标选参数。十类八个新候选中，按最高 E50 源验证选中的 clean 为 83.8954%，按最低监督 CE 为 83.9158%，实际最高为 84.0507%。六源分别为 86.3340%、86.2361%、86.4486%。伪标签正确率很高，按其排序也没有找到各组 clean 最优。这里的准确率用于诊断指标差异，不写入控制器。[固定剂量证据](../../automation_reports/CV-SincNet/20261118-phase1-pamf-repl-auxviewdose-clean-m16-r01/analysis.md)

## 设置级和样本级分工

**设置级选择机制。** 将基础伪标签 CE 剂量、配对 KL 视图与剂量、跨接收机辅助剂量作为有界动作。首版只纳入已有匹配证据支持的少量动作，采用同一套候选生成和评分规则。一次性在正式目标预测前，用合法源接收机留出小试验估计每个动作的效果。留出的源接收机不能出现在该小试验训练或父 checkpoint 中，因此不能拿已经见过全部源 RX 的 E20 直接当作留出试验的起点。每个小试验使用对应合法源样本和固定预算，独立测留出的源 RX；源标签仅用于评分。先比较相对同预算基础配置的各 RX 得分，再看最差 RX 变化。优势不稳定时保留事先登记的稳健默认剂量。规则、源角色和候选动作在任何正式目标访问前固定。正式模型沿用对应 Phase1 契约，训练至固定 E50。

**样本级分配信号。** 复用已有原始评估分布、普通加噪和原始训练 logits。先在固定 0.95 掩码内，计算视图对伪类别的一致性、分布分歧以及合法跨 RX 正对是否存在。首版只测试在固定总剂量下对单个损失重分配权重。对接受集合中的非负可靠性权重做均值归一化，保留按全批大小归一的现有损失，让“重新分配给哪些样本”和“加大整项损失”可以分别归因。一次只在 KL 或浅层/融合中试验，不同时修改接受门槛、CE、KL 和辅助项。无接受样本时对应损失保持为零，权重上限及有效锚点数随训练记录。所有信号只由可用的源 IQ、模型输出和合法源标注构成，冻结后才读取的 U 真值只做诊断。

梯度冲突、AdamW 额外位移、监督 CE 和源 V 用于解释结果。源留出验证的作用是判断当前规则是否具备可迁移的选择信号；它的排序还需要用独立 clean 验证。现有六源优势只有 29 条预测，正式复核保留普通 PL、固定强对照和自适应三组。

## 验证顺序

1. 完成当前定向 KL 固定矩阵，继续提高两个设置的 clean，并为不同视图和剂量建立匹配效应。在目标结果之外，用新源留出试验检验候选动作数量及评分规则。
2. 固定同一规则并做三个对照，分别为固定配方、仅设置级选择、设置级选择加样本级加权。按同一 E50、同物理 ID 与普通 PL 对照。报告各设定的 clean、净纠错、各 RX 表现，以及自适应和该设置固定候选最好结果的差距。
3. 用独立训练种子和事先登记的新数据设置复核。用多个设置的配对差值、低分设置和相对固定候选的差距检验适用范围。

## 首轮动态样本权重结果

固定各设置最强的 KL 与辅助损失配方后，完成了十类和六源各 7 个按接受样本动态分配 KL 的变体。十类最佳 84.0905%，比固定配方高 0.0398 个百分点，仍比普通 PL 低 0.1089 个百分点。六源最佳自适应 86.4313%，低于固定配方 86.4486%。两组的差距集中在接收机和日期同时变化的 `cross_both`。下一轮性能探索优先检验源接收机与源日期的联合覆盖，设置级自适应继续按源 RX 留出框架设计。新种子和新设置的验证尚未完成。[配对与训练证据](../../automation_reports/CV-SincNet/20261119-phase1-pamf-repl-adaptivekl-clean-m14-r01/analysis.md)
