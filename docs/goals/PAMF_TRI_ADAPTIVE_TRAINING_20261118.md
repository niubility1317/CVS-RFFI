# Tri 的数据自适应训练设计

当前目标是让 Tri 在其他数据设置中使用同一套自适应规则，保持原 Tri 相对普通 PL 的 clean 领先幅度，并检验有充分源域证据时能否进一步提升。主指标仍为固定 E50 的 `cross_rx + cross_both`，同设置、同种子、同物理样本比较自适应 Tri、原 Tri 和普通 PL。十类和六源保留为开发参考。正式复核报告每个设置的领先幅度变化、最弱设置、选择触发率与独立种子配对结果。

已读回其余九个设置的三种子历史 clean 基线。原 Tri 相对普通 PL 在七个设置领先，包括标准划分 +1.94、两源 +4.07、三源 +1.73 和四源 +2.39 个百分点。1% 标注和单源平均分别为 −0.10、−0.74 个百分点。单独报告原本领先的设置是否保持领先，以及原本落后设置的差距如何变化。历史目标分数不输入选择器。[历史基准登记](../../automation_reports/CV-SincNet/20261027-phase1-pamf-paper-completion-m119-r03/report.md)

当前固定剂量矩阵不支持用单一指标选参数。十类八个新候选中，按最高 E50 源验证选中的 clean 为 83.8954%，按最低监督 CE 为 83.9158%，实际最高为 84.0507%。六源分别为 86.3340%、86.2361%、86.4486%。伪标签正确率很高，按其排序也没有找到各组 clean 最优。这里的准确率用于诊断指标差异，不写入控制器。[固定剂量证据](../../automation_reports/CV-SincNet/20261118-phase1-pamf-repl-auxviewdose-clean-m16-r01/analysis.md)

## 设置级和样本级分工

**设置级选择机制。** 首版动作是保留原 Tri（无标签总权重 6），或在其余机制及 0.95 掩码相同的条件下将总权重调至 4.5 或 3。第一批要求两折均改善且每个 RX×日期源单元均无净损失，四个设置全部回退。第二批在未用于规则开发的四个设置要求两折均改善、整体配对净增的一侧名义阈值为 0.025、最差源单元下降在 0.25 个百分点以内。合格候选按折平均准确率增量排序，同分选接近原配方者。源证据不足时沿用原配方。留出单元从小试验的 L、U 与训练用 V 同时排除，折内 E20 从零训练。完整数据设置的 E20 只可用于最终同契约训练或同契约冒烟，禁止继承给折内模型。每个折只用其单独的合法源 V 留出部分判断，U 真值和目标预测不参与选择。第二批源单元的筛选余量与正式 E50 保持原领先幅度的要求分开。[首轮选择结果](../../automation_reports/CV-SincNet/20261119-phase1-pamf-repl-sourceadapt-pilot-m8-r01/analysis.md)

至少三源使用两个完整 RX 留出折。两源使用两组 RX×日期留出单元，保证每个训练折仍具备两个 RX 和三个日期，它仅是联合分组代理。单源缺少识别跨 RX 收益所需的源证据，首版沿用原 Tri，单独报告这次回退。左右极值 RX 的选择按已有物理接收机 ID 排序固定，不看成绩。九个非主攻设置的源缓存、两折数据量和留出验证覆盖已读回核验。八个有折的设置均满足保留全部训练类别和有效 L/U/V。每个留出 `RX×日期` 单元有 1800 条源 V 样本。

**样本级分配信号。** 复用已有原始评估分布、普通加噪和原始训练 logits。先在固定 0.95 掩码内，计算视图对伪类别的一致性、分布分歧以及合法跨 RX 正对是否存在。首版只测试在固定总剂量下对单个损失重分配权重。对接受集合中的非负可靠性权重做均值归一化，保留按全批大小归一的现有损失，让“重新分配给哪些样本”和“加大整项损失”可以分别归因。一次只在 KL 或浅层/融合中试验，不同时修改接受门槛、CE、KL 和辅助项。无接受样本时对应损失保持为零，权重上限及有效锚点数随训练记录。所有信号只由可用的源 IQ、模型输出和合法源标注构成，冻结后才读取的 U 真值只做诊断。

梯度冲突、AdamW 额外位移、监督 CE 和源 V 用于解释结果。源留出验证的作用是判断当前规则是否具备可迁移的选择信号；它的排序还需要用独立 clean 验证。现有六源优势只有 29 条预测，正式复核保留普通 PL、固定强对照和自适应三组。

## 验证顺序

1. 首批源域试点按数据设计覆盖 Main split、Receiver split 1、1% 标注与两源 RX。两折、三剂量，折内 scratch E20 后等预算续训至 E24。E24 用于评估选择规则的可行性，同一折和种子的原 Tri 为对照。源域 E24 有收益仍需验证它是否能预测完整设置 E50 的收益。
2. 固定规则后逐设置完成 E50，同时比较原 Tri 与普通 PL。报告每个设置原有领先幅度、自适应后领先幅度、最弱设置、净纠错，以及哪些场景实际调整了参数。单源、零触发和下降均保留。领先幅度保持对应同种子自适应相对原 Tri 的净增非负，最少应有实际触发产生收益才能宣称自适应有效。
3. 用接收机划分二、5% 标注、三源、四源以及独立种子复核，按相同准则处理未用于开发规则的场景。只有在设置级基线可靠后才检验新增的样本级分配。

## 首轮动态样本权重结果

固定各设置最强的 KL 与辅助损失配方后，完成了十类和六源各 7 个按接受样本动态分配 KL 的变体。十类最佳 84.0905%，比固定配方高 0.0398 个百分点，仍比普通 PL 低 0.1089 个百分点。六源最佳自适应 86.4313%，低于固定配方 86.4486%。两组的差距集中在接收机和日期同时变化的 `cross_both`。下一轮性能探索优先检验源接收机与源日期的联合覆盖，设置级自适应继续按源 RX 留出框架设计。新种子和新设置的验证尚未完成。[配对与训练证据](../../automation_reports/CV-SincNet/20261119-phase1-pamf-repl-adaptivekl-clean-m14-r01/analysis.md)

## 全局剂量校准后的判断

两批共八个设置的前瞻源域选择全部回退到原权重 6。开发集上选择的两个减权配置经过完整 E50 验证，两设置的三种子平均领先幅度都收窄。标准划分 3 个种子均退化，接收机划分一只有开发种子改善。下一批保留原生 U 剂量、CE 与保护，按同伪类跨 RX 正对的实际分布检验浅层和融合两个分配通道。[三种子校准](../../automation_reports/CV-SincNet/20261119-phase1-pamf-repl-sourceadapt-calibration-clean-m12-r01/analysis.md)

## 融合正对均衡的复核结果

在保持原 U 权重 6 的情况下，对当前已接受同伪类跨 RX 正对按实际接收机占比分配融合损失。四设置三种子相对原 Tri 的平均变化分别为接收机划分一 +0.1192、接收机划分二 −0.0526、5% 标注 +0.0633、三源 −0.0148 个百分点。5% 标注的三个种子均改善，接收机划分一仍随种子波动。原 Tri 作为默认。下一处需要验证的是，能否在完整源域上辨认均衡实际抑制的是接收机集中还是可靠正对，并据此选择启用方式。独立训练种子的复核已经完成，尚未验证这套规则能保持全部数据设置的原优势。[复核与完整证据](../../automation_reports/CV-SincNet/20261119-phase1-pamf-repl-rxbalance-seedcheck-clean-m8-r02/analysis.md)
