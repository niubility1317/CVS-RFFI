## 两类关系必须分别定义

同一物理包的 `x → H_k(x) → G(H_k(x))` 在不同信道实现下形成同包正对，不需要 U 的 TX 标签。它的 RX 始终是原 RX；模拟星地信道不会生成真实的新接收机标签，也不能仅靠同包视图一致性证明跨接收机泛化。加入噪声是训练视图变化，不增加物理样本数。强噪声和受损视图可能使身份信息不可辨，不按波形差异大小判断收益。

跨 RX 的两个不同物理包，只有 TX 身份一致时才应成为身份正对。L 使用真 TX；U 仅使用普通 PL／FastTrust 多证据认证后的伪身份。已知 RX 用来限定跨 RX 正对、平衡不同 RX 的正对贡献，并在评估中报告逐 RX／TX×RX 净纠错；不对所有不同 RX 记录盲目拉近，也不把同 RX 直接当负类。

原型分成两个独立可诊断项：

- 同包恢复视图项：所有 U 都可参与多个 G(H) 到停止梯度 raw 特征的对应，不把其他 U 当作异 TX 负例。普通 CE 和跨 RX 身份项负责防止身份表示整体塌缩。raw 参照是否过度保留接收机特征，需要源诊断，不预先断言有效。
- 跨 RX 身份关系项：L 真标签不受模型置信度筛选；U 只在可信时形成身份边。对同一身份内的不同正对 RX 分配相同总权重，避免样本多的 RX 占满关系；完整批次分母保留低接受率的剂量衰减。FastTrust 控制新增边的可靠性和预算，不能将 softmax 质量误写成真实安全率。

原型代码在 `experiments/pamf_u_history/receiver_trust.py`；尚无训练器调用它，不能声称机制已实际训练。高斯工具支持显式 IQ 相对 SNR，检查中用 35 dB 验证比例计算，这个测试数值不是已选训练配方。

## L 与 U 共享机制，但不共享标签不确定性

| 项目 | L | U |
| --- | --- | --- |
| 原身份监督 | 保留原 T1 真标签目标 | 保留原 `.95` 普通 PL |
| 多信道／G／噪声视图 | 可使用同一生成族，真实 TX 仍可监督 | 同包正对不需 TX；身份 CE 另走可信路由 |
| 跨 RX 关系 | 真 TX 决定正负关系 | 认证伪身份决定，未认证不作身份边 |
| FastTrust 身份门控 | 不用模型置信拒绝正确 L 标签 | 决定新增身份监督类型和剂量 |
| RX 贡献平衡 | 使用已知 RX | 同样使用已知 RX |

需要比较两条新机制范围，原有 L／普通 PL 始终保持：`U` 为新增分支只优化 U，L 特征作为停止梯度参照；`LU` 为 L/U 都承受新增分支，L 使用真 TX，U 使用可信伪身份。两条从同一个合法单视图 E20 独立分叉，后续若发布则均按 +10＋20 至 E50，不串接失败方法、不补训旧 PL 对照。这个两行差异专门回答用户的 L/U 作用范围问题，不能同时更换预算、随机视图量或分类头。
