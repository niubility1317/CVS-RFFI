# 单视图 PAMF 选择性相关一致性

2026-10-26 用户最新指定优先研究同包、物理扰动驱动的选择性协方差一致性，其次是有界接收响应校正。此前 RXTrust 源诊断保留为已完成证据，其尚未发布的 U／LU 训练暂不启动。完整 PAMF、单视图 SIG_TIME、原默认头、原 L/T1 和普通 PL `.95/weight1` 保持；既有 PL/Sup 对照复用，另一对话的任务和文件不改。

当前状态：统计／损失原型 `experiments/pamf_u_history/selective_covariance.py` 已实现，5项数值和角色边界检查通过；尚未在实际 E20 上拟合完整 L 掩码，也没有该方法的训练或性能结论。下一项实际工作是 source-only 的完整L掩码拟合与真实特征诊断，不再先扩大同TX拉近范围。

## 方法依据及差别

[RobustNet](https://arxiv.org/abs/2103.15597) 使用扰动前后相关统计的变化识别敏感项，并对选中的相关项施加趋零的白化损失。这里采用用户给出的**同包成对一致性**：比较 raw／As 的选中相关项，不要求选中项为0，不改变前向特征为单位协方差，也不进行求逆。该RF变体不是原论文方法的直接复现，分割上的收益不作为射频有效性证据。

[Causal Matching](https://proceedings.mlr.press/v139/mahajan21b.html)说明类条件域不变性并非泛化的充分条件，提示保留类内变化／同一对象对应的重要性；其对象假设不自动证明模拟As保留全部TX信息。[Wadia等](https://proceedings.mlr.press/v139/wadia21a.html)对白化导致信息损失的分析也有模型假设，不能扩展为所有统计约束必然有害。

PAMF参考分支的已知解释边界保持：接收相对响应仍混有RX／信道／均衡作用，不能从单条IQ任意分离TX与RX。当前方法选中的是**观测到的物理扰动敏感相关项**，不是已识别的纯RX硬件成分。

## 固定统计对象

在实际 `time_down` 与 `t2.pool` 的 `[N,C,T]` 特征上，逐包沿时间去均值，以总体协方差和相对对角ridge `1e-3` 得到正则化相关矩阵。仅使用严格上三角，不强迫对角项等于1，不对模型前向特征作白化；短序列无需协方差求逆。零信号、幅度变化及梯度有限性已经做数值检查，真实层位／时间长度仍需实际checkpoint读回。

只在合法、已完成的单视图普通PL E20/4440上冻结F，用原训练L6300的raw与三种practical residual同包As拟合掩码；不读取U的TX真值、V或目标来选元素。数据角色、物理ID、checkpoint来源沿已有验证结论核对，不重新建数据hash链。全部原L样本作为训练统计，不声称独立未见数据验证。

每层选择规则先固定，再读取实际统计：

1. 扰动敏感度为同包raw／三As相关差的平方均值，按已知RX分别汇总，取5个RX的中位数，避免只由单个RX支配。
2. TX关联度为每个RX／day内TX条件均值的类间方差，与相应类内方差之和的比例。RX／day条件化避免把TX组成差异直接算成身份区分证据；仍只是单变量关联，不能保护所有非线性身份信息。
3. 候选项须在敏感度最高25%、TX关联度最低50%的交集中；按 `sensitivity/(TX_association+1e-6)` 排序，选全部上三角项的10%。不足这个数量时报告规则不支持，不自动降低筛选条件。
4. 掩码在新增训练期间固定，不随U伪标签、V、目标或成绩更新。后续训练可能旋转通道基底，掩码陈旧是需要报告的风险，不据测试结果重选。

两个层位分别拟合，各层随机控制使用固定seed `2026102623` 的同尺寸掩码；全部相关项控制为所有严格上三角。随机项不强制与选择项互斥。输出的实际掩码／中间统计仅保存在实验private产物，公开报告给出聚合计数／敏感度／关联度。

## 如何利用 U 与已知 RX

新损失只需要同一物理包的两份IQ，不需要TX，因此可覆盖未通过 `.95` PL 的全部U。普通PL仍独立产生原硬标签CE，不能用协方差机制替换／减少该基线。已知RX用于掩码统计的条件化、跨RX敏感性检查和U损失的组间等权平均；不能将RX标签当成纯硬件分解的证明。

损失先对每包的选中相关项取均方，再对观测到的RX等权平均，使稀疏／随机／全部项具有相同单位，避免元素多的全部项仅因求和尺度更大而占优。此归一化是用户Frobenius形式的显式尺度约定。采用同包raw/As差，两端都可反传；原有L跨RX CRIC继续保留，不新增更强的全身份特征收缩。

训练适配应优先复用原L的实际raw和As前向及普通PL的U raw前向，只给U增加所需的同包As前向与训练统计；不要为“复用”默默改变原增强、前向次数或梯度。真实成本、有效时间长度与额外矩阵运算需实测，不将“无新增推理分支”写成训练免费。

正式判断同时看类内跨RX关系、异TX分离、raw clean、六practical与同DURA读出。源统计／距离改善不等于目标性能；目标仍要求同一方法完成原三seed等全部范围，不能拼接最优列。冻结模型后自动执行预登记预测和独立truth-last，全部负值保留，不按目标反馈改掩码、权重、epoch或选择性重跑。
