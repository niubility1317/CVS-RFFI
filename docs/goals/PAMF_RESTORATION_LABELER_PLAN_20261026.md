# NoSIG 恢复域标签专家：下一条源证伪路线

状态：**两个匹配标签专家及完整源评估已完成，固定质量条件失败；不生成U标签或启动学生。** 原三种子联合目标不变。下文保留本轮诊断前固定方法，不放宽或重跑RGPL／本轮门槛。

## 依据和可证伪假设

RGPL在新NoSIG E30困难V2326条中仅认证17条，14条正确，纠正0／引错1；恢复图单独固定规则37/62正确。旧恢复辅助方法多数从原raw教师或其几何结构生成监督，源恢复域损失下降仍可能伴随目标退步。下一步只检验：**用真实L在恢复输入上联合训练骨干与原默认头，是否能产生原raw教师缺少的可信标签。** 不先把恢复IQ继续压入学生，不据恢复图高置信认为其标签可信。

## 首轮固定两行标签专家

单学生seed2026092701。两个专家都从本轮NoSIG普通PL的固定E30严格加载，绝不加载旧SIG F、REPL F50或失败图标签。父来源是同契约从零NoSIG E20＋10，父已用过合法隐藏U；下面“L适配”只指新增训练，不冒充整个系统从未用U。

- RawLabeler：新增10轮×222步×L128，仅真实L原始IQ的CE；新增适配排除RX1，使用原L中其他四RX的5040条。
- GLabeler：相同父、物理记录顺序、预算、CE和优化器，仅将输入换成同一记录的冻结G恢复IQ。

两个专家各累计E40，新训练只开上述相同5040条L，不打开U或V训练迭代器；V仅冻结评估。RX1不参加新增适配优化，仍单列其标签质量；E30父和G已见过源RX1，不能称真正未见接收机验证。原PAMF学生和NoSIG监督／普通PL控制的E50预算不变。本轮不训练半监督学生。

专家使用完整NoSIG骨干和原6×160默认头一起更新，不冻结骨干另训头，不新增头或域网络。不是把推理Reader的冻结Sinc过滤器拿来训练；从原native构造网络严格加载，再用原CENTER_25K／CENTER_UNITS AdamW与物理clip5。显式重置优化器：base LR0.0002、WD0.0001、eps1e−8、betas(.9,.999)，2220步cosine至base LR的1%，LS0.01。只用单次CE，新增阶段无PL／EMA／一致性／对比或普通增强。它是独立标签专家配方，不能改称PAMF完整监督对照。

G保持同契约原固定G-LU及FP32／TF32off路径。四个已固定source namespace×lowSuburban/midUrban/lowUrban，12个视图；一个物理包不计作12个独立样本。先缓存L6300×12恢复IQ，G不读TX真值、不更新；标签仅由F专家读取真实L。GLabeler按`view=(step−1)%12`均匀轮换，每视图185个L128 batch。无G后波形归一化、噪声叠加、IQ混合或按F分数挑实现。

## 预测先固定，再判断标签可行性

两个专家冻结后：RawLabeler预测V原始IQ；GLabeler预测V同包12恢复视图，平均softmax概率。原NoSIG E30 raw confidence<0.95的2326条固定困难V仍是检查集合，不能按适配后置信度重定义困难池。

当RawLabeler与GLabeler均最大概率≥0.95且同类时认证；12恢复视图聚合只作为同一包的一份证据，不宣称独立投票。先保存全部V认证决定，再用V标签计算质量。固定进入学生研发条件为：**认证≥200条、观察precision≥99.5%、相对原E30 raw净纠正≥100条**。另报告每RX/day/TX的覆盖、纠正及引错；不以某一组高分替代整体判断。任何一项失败，保留本轮负结果，不放宽阈值，不自动继续学生训练或生成U标签。

RawLabeler单独与GLabeler单独的固定规则质量同时报告，区分额外L训练、恢复域专家及两者筛选的贡献。源V质量只是代理，不是真实U正确率或目标泛化保证。

若通过，另行登记：冻结两专家给原隐藏U生成标签，再用同一认证集合做“标签只训raw”“两次raw控制”“0.75raw＋0.25G”三个学生匹配行；各从原NoSIG E30＋20到E50，原高置信PL和完整L骨架保留，认证困难样本替换旧self-PL，总CE剂量1。新增U机制同样排除RX1，原L/rawPL不排除；图输出不再参与。原held额外分支RX1 G三景≥+.3pp、overallVraw≥−.1pp的学生源条件保留。单seed源证伪通过后，才扩三学生seed及原F0 raw／同G-LU clean＋六practical目标测试。最终仍需同一方法满足原clean≥1pp、raw六景>1.5pp和同G六景提升，且超过新的NoSIG匹配对照。
