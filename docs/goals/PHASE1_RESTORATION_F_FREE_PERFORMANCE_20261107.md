# Phase1 无识别器指导恢复：性能主线

2026-11-07，用户最新要求“专注于性能提升”。本文件记录本对话的优先级和当前验证范围，不改变其他对话、默认 DURA 或已有模型的数据身份。

## 目标与边界

- 目标保持六种 practical 场景的性能下降均不超过 3%，并保留 clean 对照。基座固定地面训练的 Tri-SIG-TIME SSL、Main split、原默认头，逐景使用同一 168000 个物理记录。Phase3 不进入本对话主比较。
- raw clean 为 86.538690%。绝对下降 3 个百分点对应 83.538690%，相对下降 3% 对应 83.942530%。报告两种口径，不能借更宽松口径或场景均值宣布完成。
- 恢复训练只使用合法源 L_s/U_s IQ 与模拟配对，TX 标签（含 L_s 标签）、F 权重及输出、V 和目标均不进入训练。F 只用于冻结后的评估。来源与数据契约按已有项目协议核实。
- 每个正式候选完成既定冻结规则及全部七景预测后，独立 truth-last 评分；报告与 DURA 的修复、损伤和 TX/RX/day 分组。测试结果不回流选模、调权或选择性重跑。
- 当前证据为单模型、已反复观察的地面模拟基准，不称独立盲测或真实在轨结果。

## 工作优先级

后续优先研究识别性能与身份细节保持，收齐现有候选的正式成绩。不再新增训练／推理速度实验，已有速度结果不能替代性能进展。保留独立架构探索和 DURA 改进两条研究线；已停止的五项旧方法不自动恢复。

当前局部正收益是合成响应约束：低郊区、中城区和低城区相对 DURA 分别提高 0.0530、0.1065、0.1583 个百分点；其余三景下降，两种 3% 口径均仅 1/6 达标。默认 DURA 不替换。完整证据见[近期汇总](../../automation_reports/CV-SincNet/20261107-phase1-restoration-recent-crossrun-summary/analysis.md)。

## 已发布性能路线

- 条件对抗恢复：`20261107-phase1-dura-conditional-adversary-source-s2026092701-r02`，五轮源训练后自动七景评分。r01 尚未训练的等待队列被精确替代，r02 在 GPU 3 执行；科学配方和代码 `b18026ad64849318f6f614e6b0f04b42c0664394` 保持。判别器只做源 clean／恢复波形判别，不学习 TX 身份、不进入部署。
- 反向配对流及双路径识别：固定 final5 后分别评估先平均 IQ 与先经同一默认头再平均概率；路径与等权规则事先固定，没有目标调权。双路径增加一次恢复后 F 前向，收益须由完整七景判断。
- 相位等变、混合时间采样条件流、四阶约束、掩码／时间先验和独立直接流等已登记任务按原矩阵完成；运行状态以各 run 的进程、日志和完整产物核实。
- 独立相位等变恢复：`20261107-phase1-direct-phase-source-s2026092701-r01` 从零训练 62496 参数的复数网络，仅接收单条 IQ，DURA 不参与拟合。训练使用 32768 个合法源 ID、三视图、20 轮，最终 checkpoint 固定后自动进行全部七景预测与独立 truth-last。设计依据是固定原 DURA 的源域相位一致性诊断，而非事后按地面成绩选择的候选；源波形检查不代表身份性能。[训练记录](../../automation_reports/CV-SincNet/20261107-phase1-direct-phase-source-s2026092701-r01/report.md)。
- 独立共轭相位等变恢复：`20261107-phase1-direct-circular-source-s2026092701-r01` 与上一行各自从零训练，增加局部共轭特征、保持整体相位等变；63456 参数，源数据、20 轮、冻结及七景测试预算相同。它不加载上一行权重或依据目标结果选择，DURA 不参与拟合。[训练记录](../../automation_reports/CV-SincNet/20261107-phase1-direct-circular-source-s2026092701-r01/report.md)。
- DURA 共轭修正：`20261107-phase1-dura-circular-source-s2026092701-r01` 冻结原 DURA，并为 received、恢复输出和物理残差各自构造局部共轭特征；新修正分支 35008 参数、从零训练，固定源数据和 5 轮后自动七景评分。相位等变仅针对三个上下文共同旋转的分支，不能外推为完整 DURA 链路等变。它不继承其他候选权重，且不依据目标结果选模。[训练记录](../../automation_reports/CV-SincNet/20261107-phase1-dura-circular-source-s2026092701-r01/report.md)。
- DURA 条件相位双分支：`20261107-phase1-dura-conditional-phase-source-s2026092701-r01` 冻结原 DURA，从零训练 32483 参数的局部复数修正及整体相位幅度修正，逐记录学习混合；固定 32768 源 ID、三视图与 5 轮，随后自动完成七景预测和评分。设计只依据原 DURA 的源相位诊断，不用其他候选目标结果选模；整体候选不声称严格相位等变。[训练记录](../../automation_reports/CV-SincNet/20261107-phase1-dura-conditional-phase-source-s2026092701-r01/report.md)。
- DURA 复矩条件相位：`20261107-phase1-dura-phase-moments-source-s2026092701-r01` 在上述双分支之外增加逐记录二阶、四阶归一复数统计，独立从零训练 32867 参数；数据、种子、源训练预算和固定七景矩阵与双分支匹配。源小样本的统计非零仅作为探索依据，不能等同于身份信息。GPU 源训练已完成，七景预测运行中；评分完成后再配对比较。[训练记录](../../automation_reports/CV-SincNet/20261107-phase1-dura-phase-moments-source-s2026092701-r01/report.md)。
- DURA 源配对相位监督：`20261107-phase1-dura-supervised-phase-source-s2026092701-r01` 使用与复矩版匹配的结构、源数据和 5 轮预算，另加合法源 clean 派生的受限相位目标，监督完整组合输出的相对相位；无 F/TX/V/目标训练，部署不读取 clean。该候选已启动 GPU 源训练，固定末轮后自动七景评分；源理想角不可部署、不能预示身份收益。[训练记录](../../automation_reports/CV-SincNet/20261107-phase1-dura-supervised-phase-source-s2026092701-r01/report.md)。

独立源域假设检查发现，固定 DURA 对合成输入相位旋转的响应在 clean 和低城区源组之间不同：90° 旋转后，clean 两组均更接近同步旋转的 clean，而低城区两组多数记录更接近原相位。可研究基于输入条件的相位处理；合成旋转不证明实际信道分布或身份性能，不据此更改当前模型、训练或测试。[源诊断](../../automation_reports/CV-SincNet/20261107-phase1-dura-phase-nuisance-source-s2026092701-r01/analysis.md)。

源域相位可预测性诊断进一步固定 24579 个物理记录拟合、8189 个物理记录留出，所有记录的三个视图不跨侧。三种预定 ridge 特征组合的留出相位 MSE 相对零相位下降 3.29% 至 3.99%，但波形 NMSE 均略高于原 DURA；训练侧常数仅降低约 0.023%。这不证明非线性相位估计无效，也不是身份准确率，不能因该诊断更改已冻结测试。[完整源域结果](../../automation_reports/CV-SincNet/20261107-phase1-dura-phase-predictability-source-s2026092701-r02/analysis.md)。

训练损失、波形 NMSE、源表示相似度和判别器损失都不是 TX 识别准确率。局部正收益不等于目标完成，任何新默认版本仍需用户指定。

## 防止间接使用地面成绩

曾准备把人工信号响应损失与输入噪声响应约束合并，从零训练 DURA 修正网络；基础单测及真实源 checkpoint 六步 GPU smoke 通过，没有发布正式训练或目标预测。独立审查指出，提出合并方案时引用的噪声敏感性诊断，是在看到合成响应版地面成绩后选取该模型作事后解释；不能证明本次候选选择与目标成绩独立。现不发布该组合，不用该事后诊断为后续训练选权重或选模型。仅供追溯的未发布代码保留在本机临时目录，不能视为已登记候选或正式性能证据。

下一候选需基于与该地面成绩选择无关的预先来源或新的合法源域研究固定；已发布的训练和七景测试按原矩阵继续。这个决定不暂停整个目标，也不更改默认 DURA。
