# LoRa 与 WiSig 可部署星地信道恢复

研发一套基于接收端可用信息的星地信道恢复方法。在 LoRa 和 WiSig 的冻结识别主对比上，提高受损信号的设备识别准确率，并保持 clean。可以重构同步、均衡、降噪、前向观测模型和网络。现有 DURA 保留为对照，最终方法名称由结构和验证结果决定。研发先看识别收益和跨设置稳定性，同时记录参数量、时延和训练成本。

## 正式验收

- **LoRa。** 沿用 15 个未见接收机、30,000 个物理包和同一冻结 Tri-set 三种子。在 full practical 中，六景平均准确率至少为 **67.0%**，低强度城区至少为 **53.0%**，clean 至少为 **64,490/90,000（71.6556%）**。同包比较直接识别、已完成的半量 DURA（六景 55.8517%、低强度城区 41.7733%）和当前最好冻结版本（56.0024% 和 42.05%）。六景均值距同方案 clean 不超过 3 个百分点作为进一步目标。
- **WiSig。** 纳入已登记的 **Main split 主对比**。按 cross_rx 和 cross_both 分别报告，另给合法的 168,000 条合并口径。在同一冻结识别器、相同数据和信道视图下配对评估直通、原冻结 DURA v1.0/R69 和新方法。新方法的六景均值必须超过同次重跑的原 DURA，clean 正确数至少持平。源域探索先用单种子，对进入主对比的候选做至少三种子配对验证。若本轮冻结识别器不同于旧版 F50，以本轮同识别器重跑的结果作为比较基线。报告原 DURA 的历史训练监督与推理输入。
- 两套数据都验证已登记的 full practical 和 residual practical。每套数据用同一份冻结恢复权重、阈值和推理规则覆盖两条路线。允许两套数据使用各自合法源 IQ 训练权重，允许按公开波形协议调整同步和输入前端。跨路线的验收要求两套数据的两条路线分别提高匹配原 DURA 的六景均值，并保持 clean 正确数。若缺少某条路线的同口径基线，先用原冻结 DURA 补齐同包评测。逐景、逐接收机报告收益与退化。

## 接收信息和训练权限

- 恢复器可显式接入当前包的实收 IQ、接收机估计的信道作用 `Â`、估计的噪声方差 `σ̂²` 及估计置信度。`Â` 可以来自实际收到的已知前导或导频、可用的包内重复结构、盲或半盲估计。可使用部署时已知且基准合法提供的校准量、导航先验、协议波形和采样参数。`σ̂²` 可以来自同带宽同增益的空闲观测、导频预测残差或包内观测统计。导频残差可能包含干扰、硬件失配与估计误差，记录它的测量口径和误差。训练与推理沿用同样的估计路径。基准缺少空闲段或额外测量时使用已有 IQ 估计或置信度旁路。记录每项输入的来源、可用时点、计算方法和误差。[ETSI TR 102 768 §11.2.1](https://www.etsi.org/deliver/etsi_tr/102700_102799/102768/01.01.01_60/tr_102768v010101p.pdf#page=97)
- 每包真实信道算子、真实噪声方差、实际逐点噪声、仿真轨迹、场景号、专用信道参数表及其代理只进入隔离诊断。不将精确或仿真生成的真实信道和噪声参数提供给候选作输入、回归监督、校准或选模。精确扣噪及精确反演结果单独标为诊断对照。候选不得按测试场景、路径名称、接收机或生成种子硬编码补偿规则。
- 用合法源 IQ、自监督和与目标测试独立的通用波形扰动训练。恢复拟合、源校准与冻结过程隔离 TX 真值、冻结识别器的参数和输出、目标 IQ、目标真值及目标统计。冻结识别器只在候选冻结后用于评测。源 V 可以独立评分比较已冻结的候选。目标结果不回流训练、阈值、超参、候选选择或选择性重跑。

## 探索路线

1. **建立成熟工程对照。** 逐项验证接收前导同步、粗细频偏与采样时钟校正、正则化最小二乘信道估计、MMSE/Wiener 频域均衡、盲或半盲估计。对照直通、仅同步、同步加估计均衡、仅学习恢复及联合恢复。按前导长度、观测质量和失配程度核查估计误差与指纹损伤，记录 `Â`、`σ̂²` 各自能贡献多少。
2. **探索原创恢复机制。** 可以重做学习先验、观测模型和求解结构。优先研究如何在压低噪声的同时保住真实弱复谱的幅度和相位，例如用真实源 IQ 差异约束保真、分开处理包内重复与独有成分、用估计不确定性控制均衡强度，以及受观测约束的自监督恢复。根据源域证据调整路线。查阅最接近的原始论文和公开实现，写清算法、训练监督、输入权限和识别任务上的相同点与实质区别。用匹配数据、预算和冻结识别器的消融证明至少一项新机制的独立收益。创新结论限于已核对的相关工作及实际验证范围。
3. **按识别损益归因。** 核对原始 IQ 与恢复 IQ 的时间坐标、归一化、clean 保持、强弱受扰样本的复数幅相和逐频带真实信号保真。报告按物理包的纠错、改错和净变化。波形损失和精确算子诊断用于定位原因。以预登记、冻结后的同包识别准确率判断收益。

## 执行和交付

每个候选一次端到端训练，在同一优化循环中联合粗恢复、观测约束和细化。允许连续训练中分阶段调整损失权重、学习率和模块训练强度，沿用优化器状态。按空闲容量将独立实验分到不同 GPU。记录配置、预算、耗时和独立核验的运行状态。先用合法源域快速筛查，再扩大到预登记的单种子和多种子矩阵。全量预测固定后独立 truth-last 评分，保留全部失败和负结果。

交付可复现代码、配置、接收信息和估计量清单、相关工作证据、消融、两套数据的主对比报告。按种子、场景、接收机、划分和信道路线给出准确率、clean 正确数、同包净纠错和配对不确定性。仅在所有硬指标与正式矩阵通过独立复核后完成目标。
