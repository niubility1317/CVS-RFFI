日期：2026-10-21。状态：**设计已落实；F0 已有冻结结果可并表；新增跨配置训练和统一时延尚未启动**。本文件固定研究范围，不是训练完成证明。

## 1. 固定方法与对比问题

部署判决始终为当前观测 `y → DURA G(y) → CRIC F → 原联合训练默认头`，clean 也经过 G。不能按真实场景或真值选择是否绕过 G，不能换头、另训头或使用缓存恢复 IQ 的读取时间冒充在线 G＋F 时延。

CRIC 保留 SIG_TIME_X3、时域／频域／PA 残差融合、参考响应、CENTER_25K／CENTER_UNITS、原 R-Drop（两个实际普通增强 L 前向）、LS0.01、浅中层跨 RX 对比、原 ownEMA 与原 U 门控／熵项。50 轮为 33 轮 L-only＋17 轮 L/U 联合。原 CRIC **没有 As 星地训练分支**。用户本次固定该方法，因而完整方法不静默加 As，也不改成普通 PL。外部方法继续其已冻结的 clean＋satellite 拼接配方；另设同增强 PAMF 监督／普通 PL 对照解释配方差异。

DURA 固定两阶段、每阶段两次 CG、266951 个唯一参数，G 内 27 次 FFT/IFFT；FP32、TF32 off、`reuse=True, graph=True, native=False`。固定 F0 权重见 `experiments/pamf_stage2_inference/frozen_version.json`。G 训练只使用合法源 IQ 和模拟配对，不读 TX 标签、训练好的 F 权重／输出或 target。部署只需当前收到的 IQ。

论文需要分别回答：完整系统能否优于外部完整方法；各方法 Full 相对自身 CE 是否有效；CRIC 与 G 是否有独立及交互贡献；U 的收益是否超过普通 PL；源数量、标注总量、恢复器数据权限是否混杂；实际识别收益是否值得计算代价。纯 CE 高于 Full 时保留负结果，不能按测试表现替换基线或隐藏 CE。

## 4. 识别效果与机制消融

所有正式行固定后自动测试 clean、high/mid/low suburban、high/mid/low urban，共七视图。每行所有预测固定后独立 CPU scorer 连接 truth，不用分数调参、选 seed、重排或选择性重跑。已暴露工程基准不宣称新独立盲测。

主指标为 RX 等权 Accuracy、Macro-F1、最差 RX；同时保留包加权 Accuracy、逐 TX/RX/day/RX-day、完整混淆矩阵、同物理 ID 纠错／损伤／净纠错、clean 损伤、六环境逐 seed 先平均再跨 seed 的 mean±样本 SD。ManySig 等满单元时两种 Accuracy 相等，ManyRx 不能默认相等。三个 seed 以配对差及3/3正差数描述，不靠包数巨大制造种子层面的显著性。

### 4.1 首要消融：CRIC 与 G 的2×2

F0 的 BASE、ALL_TX、CROSS_RX 各三 seed 已有匹配 E50 模型。BASE 是无新增 SupCon 的 F，仍有 R-Drop／原 SSL，**不是纯 CE**。对九个 F 分别 raw／DURA，共18个读出×7景＝126个模型视图；CRIC 的42格已有，其余按精确产物补预测，不能把已有 clean 扩称已有七景。

主要2×2为 BASE/raw、CRIC/raw、BASE/G、CRIC/G。分别报告 CRIC 主效应、G 主效应，以及交互项 `(CRIC/G−CRIC/raw)−(BASE/G−BASE/raw)`。ALL_TX 同样接同一 G，用于判断跨 RX 筛选是否比普通同 TX 对比更好。G 只用当前 IQ，不使用真实 RX/day/TX 作为输入。

### 4.3 G 的结构、蒸馏与求解预算

固定同一三个 CRIC F、F0 角色与同预算，分别测试 coarse-only、prior-only无CG、无镜像作用项、prior不读反投影残差。更换结构后重新训练对应学生，先明确哪些参数复制、哪些随机初始化；不得把未经训练的删除结果解释为机制无用。coarse-only同时去先验与DC，只回答整体增益，不隔离其中一个。

蒸馏采用“初始化复制开／关×IQ阶段教师损失开／关”2×2。默认复制＋蒸馏已有；另外三格分别固定同预算、数据顺序、paired监督与STFT，不读 F。它区分初始化和教师损失，避免把 scratch 无教师与继承＋教师的总差都称蒸馏收益。上述4结构＋3蒸馏格＝7个新最终学生设置，三 student seed 共21次最终学生训练；父教师成本单列，不冒充21条独立完整祖先谱系。

求解敏感性单独预定：每阶段 CG=1/2/4，τ倍率=0.5/1/2，及只执行阶段1。默认点重合只执行一次。先固定所有运行行，再逐版七景测试；相同权重但求解预算不同也须另记推理版本。这是运行预算诊断，不是同预算重训的结构因果消融，不根据 target 排名替换默认 DURA。所有恢复器版本都报告最终识别、clean损伤与身份净纠错，NMSE／STFT不能替代识别真实性。

## 5. 时延与成本：实际测量边界

### 5.1 三种时延口径

1. **GPU驻留在线判决**：输入已在设备内；每次输入复制、实际 G/F、原默认头、返回输出的拥有权复制、数值有效性检查及前后同步均计入。禁止恢复 IQ 缓存绕过 G。
2. **CPU输入到CPU类别**：固定 pinned CPU IQ，H2D→完整 G/F→argmax→D2H类别；同步后停表。loader／磁盘另列，不和第一口径混合排名。
3. **冷启动**：新进程加载、权重迁移、形状预热、Graph capture、首次可用结果与预分配内存，单独记录；主表稳态不含首次 capture。

CUDA 异步调用的壁钟必须同步。主指标为每次真实调用的 median／P95；CUDA events 的设备执行时间另列，不能将只测 kernel 的数值冒充CPU可用决策时延。PyTorch官方说明同步、预热和重复计时的必要性：[CUDA 语义](https://docs.pytorch.org/docs/2.1/notes/cuda.html)、[Benchmark Timer](https://docs.pytorch.org/docs/2.1/benchmark_utils.html)。

硬件固定同一 N607 RTX3090，Python3.10／Torch2.1 环境、CPU线程2、FP32、TF32均关闭。旧外部时延来自Torch1.11环境，与DURA原绝对值不能直接排序，统一重测。所有方法均给 eager；可合法 capture 的方法额外给 Graph，不能仅给本方法 Graph 加速。Graph 不支持时明确 N/A 并保留 eager、错误和原因，不偷偷换精度／结构。

**正式时延只在独占GPU测量。** 当前比较训练继续；不在GPU2/3共享负载下测正式延迟，不停止任何健康进程腾卡。无可用独占卡时排队。记录时钟、温度、功耗、显存、其他进程及实际环境。方法顺序预先平衡交替，seed仅用于模型变化，计时轮次变化另列。

批量固定 B=1/8/32/64/128。每模型／运行方式五轮：B1每轮预热100次、测1000次；其余每轮预热20次、测100次。B1共5000个实测，其他各500；报告样本数、轮次中位与P95，不给500样本的P99作主要结论。吞吐用实际完成样本／总测量时间，整批延迟除B只是摊销成本，不是B1用户等待时间。第一个短轮只用于测ETA和合法执行，不用目标结果选择测哪些方法。

输入来自合法源V的固定同一128条 received IQ，覆盖clean＋六景；计时循环轮换当前输入，不循环读取Graph内旧输入。B128以上不加新批量。用非查询 smoke 比较 eager/Graph，检验更换输入会更换输出、输出不被下次调用覆盖、模型状态不更新，保留logit差和argmax一致性。需要完整正式数值验证时沿既定七景预测和truth-last执行。

### 5.2 部署主表

RIEI、DRIFT、IB-RFF、SDG各Full/自身CE＝8网络，取F0三个seed；加 CRIC/F-alone、CRIC＋DURA 三seed及G-only单G。F0监督和PL改变权重不改推理结构；主时间表用监督外部权重作固定代表，附表用PL权重核实参数／执行图相同，绝不把跨硬件旧时间接入主表。至少报告参数、部署字节、Conv/Linear MAC、FFT/IFFT次数、B1 median/P95、各B整批延迟与吞吐、常驻／增量峰值内存、冷启动。

部署权重计数包含学得的冻结分类权重，即使 `requires_grad=False` 或被注册为 buffer；不把 optimizer／EMA／训练辅助分支算部署模型。原 F 总训练wrapper900722、部署f_theta232033、余弦W960分别注明；G266951。组合名义相加499944只是候选核对值，必须按实际部署可达唯一权重确认，不能把共享权重重复计数。原G-only Conv/Linear MAC25068072不包含全部FFT和CG复杂数开销，不能当总 FLOPs。

完整系统训练成本包含 F、全部G祖先／教师、模拟与缓存生成、训练／验证／预测时间，以及故障尝试。部署文件只导出所需state，原checkpoint含optimizer或metadata的体积另列，不通过删除optimizer冒充结构压缩。

### 5.4 F／训练机制分项

SIG_TIME_X3／X1／无TIME／无SIG、PA、参考响应、Sinc核构造和默认头均单列实际参数／MAC／模块时间。Sinc固定权重核物化属于执行缓存对比，不等于训练坐标优化；必须验证缓存随合法权重变化失效。模块profiler另开一次诊断，不用带hook／profiler测主时延，不把各模块中位相加充当端到端。

R-Drop第二前向／KL、浅中层描述子与对比相似度、EMA前向与更新、三个U门控、熵项、增强生成、Sinc单位优化器分别计训练step forward/backward/optimizer和峰值内存。两L原前向复用的SupCon**额外NN前向=0，但描述子与相似度计算耗时不是0**。这些训练目标部署时不执行；不能用推理“删除loss”宣称提速。伪标签筛选即使接受率0，存在的U前向和状态路径仍计成本。

训练性能用同源batch、同模型状态快照、同数据／随机序列分别执行隔离的短步计时，不更新正式权重；正式训练日志给整轮／总墙钟。单步计时与跨卡并行的历史训练秒数不能混成固定速度倍率。
