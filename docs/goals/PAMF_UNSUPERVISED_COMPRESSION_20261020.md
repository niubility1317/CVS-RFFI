同时研究可训练的紧凑物理估计和轻量先验，使用原合法模拟配对/当前 IQ 的物理一致性、clean 重建及原 R17 IQ 函数约束。蒸馏只提供源 IQ 参照与稳定初始化，不能把“更像教师”当成性能优化成功；最终收益必须由正式测试证明。是否联合优化压缩的coarse/action、具体损失、结构/秩、预算和矩阵在新 run 发布前固定，不因 R37 或其他目标分数调整。
