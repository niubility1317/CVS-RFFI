# REPL 的 L/U 恢复视图研究

用户最新提出两个共同目标：提高原始 clean 的跨接收机泛化，并提高同一 DURA 后的识别性能；希望利用同包多星地信道恢复视图和高斯噪声，明确 U 的 RX 标签可用，并比较半监督阶段 L/U 的优化方式。完整 PAMF 保留单视图 SIG_TIME、原默认头；原三个 REPL 候选和新增六个匹配基线继续原计划，不联系其他对话。

## 已有证据与本次差异

同一原始包经不同信道实现，G 输出确实不同。旧多实现四模型只改变 U 恢复输入，损失、冻结三教师伪标签与低剂量不变；相对固定实现的源净正确数仅 −1 至 +4（16200次判断）。该结果不支持“增加实现数量本身即可解决退步”，也不能否定新的 L/U 监督组织。见[完整旧结果](../../automation_reports/CV-SincNet/20261026-phase1-PAMF-URealizations-sourceHold-m4-r01/report.md)。

旧 `restoration_bridge.relation_loss` 的正对条件为：同伪标签、不同 RX，并限定跨视图。因此同一物理包的两份 G 视图因为 RX 相同，不属于该损失的正对。旧附加 G 任务主要训练 U，L 保持原 As/ordinary/raw 骨架；没有同时回答“用真标签训练 L 的恢复视图是否更好”。原 40dB 后置噪声在 6/9 源单元超过0.5%预测变化门槛，未进入旧训练；该稳定性条件不等于噪声增强的普遍无效定理。

## 两种关系分别使用

1. 同一物理包的 raw/G_a/G_b：底层 TX 相同，RX 也相同。U 无需猜 TX 就能建立同包视图关系。该关系可用于预测/表示一致性，但不能单独证明跨 RX 泛化，也可能把两份共同错误的 G 预测拉得更一致。
2. 不同物理包、不同 RX、同 TX：L 使用真标签；U 使用可靠的原始 IQ 伪标签。已知 RX 只证明接收机不同，不能证明两个 U 的 TX 相同。跨 RX 正对保留，错误正对与身份间距需单列。

L 始终保留真实 TX 标签，不把 L 重新当成伪标签样本或按模型置信度丢掉难 L。需要比较的是 L 是否也采用多 G 视图、配对一致性和跨 RX 关系，而不是把标签权限改成 U。U 的原始 IQ 高置信分类、同包无标签视图约束、跨 RX 伪类别约束分别记账，避免把接受率当作伪标签正确率。

## 诊断后拟定的训练比较

先用已完成的同预算单视图 REPL 作为参照，按独立从同一E20到E50的轨迹比较“只在U使用恢复视图”“只在L使用恢复视图”“L/U均使用”，再按诊断决定是否独立加入无TX门控的同包一致性。不得把四项机制一次全部叠加，随后只比较总分。

原 raw/ordinary、L 的 As 真标签压力与同 TX 跨 RX 对齐保留。恢复视图优先替换一部分原有 ordinary 配对位置，避免重复增加易样本CE和更多F前向；L/U的分类标签分别来自真标签/原始IQ伪标签。两个不同G视图的额外噪声、是否对原低置信U使用同包一致性、是否在恢复视图扩展跨RX关系，都须作为独立消融；最终loss/权重/剂量/预算在训练前固定，本文件不冒充已启动矩阵。

现有结果显示替换全部As为G会退步，故不移除原As。当前REPL的U/L梯度封顶频繁，故不预设把统一U权重继续加大。若需要增加F前向，必须披露并区分视图收益与额外计算；所有新增训练照常最小登记、实际smoke、固定final后正式测试。

## 目标与比较口径

目标始终是同一方法的三个F种子、原F0每seed168000物理包（cross_rx126000+cross_both42000，按正确数合并）、raw/同G clean和六practical。三模型种子不是三个变体，三份信道视图也不是三份独立物理样本。

新增单视图监督/普通PL是严格同架构基线，原历史对照仍保留。最终raw clean至少高出监督和PL中较高者1pp，raw六景超过二者中较高者1.5pp；同G六景也必须超过对应监督/PL。同时保留原历史绝对下限，不借更换架构降低目标。可表达为：clean≥max(历史Sup,历史PL,单视图Sup,单视图PL)+1pp；raw六景>max(对应四基线)+1.5pp；同G六景>max(对应四基线)。新基线结果尚未产生，这些是固定的符号比较规则，不是按测试成绩选新方案。

候选、epoch、seed和信道实现的选择仍按合法源证据在新目标访问前固定。源诊断只帮助淘汰或组织机制，正式性能改善须由完整冻结预测后的独立truth-last评分证明；当前目标未完成。
