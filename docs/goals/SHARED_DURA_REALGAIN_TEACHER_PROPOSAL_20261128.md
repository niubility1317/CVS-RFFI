# 共用源域识别器指导选择器方案

**授权状态：**用户于 2026-11-28 明确选择“授权两数据集的源域教师指导训练”。本授权及原数据边界见 `docs/PROJECT_PROTOCOL.md` 中的当前任务条款。

## 需要明确的权限

本方案在 **WiSig 当前融合任务**中使用其冻结 Tri-SIG-TIME SSL F0 和原默认头指导恢复器训练。此前协议对源域 F 指导的既有授权限定于另列 Phase1 F50 对照；本任务的 WiSig F0 使用现已获用户单独授权。LoRa 的实增益祖先已有 E104 指导和伪标签历史；新共同选择器使用 E104 指导时同样明示该知识来源。

## 两数据集共用的方法

对各自合法源 U 的一条物理 IQ，抽取一组模拟受扰和 clean 配对。分别由各自合法、冻结的实增益和 R17 专家恢复受扰信号。将 clean 及两路恢复信号送入该数据集原冻结识别器，得到默认头概率分布；比较两路分布到同一 clean 教师分布的 KL 散度，散度较小者作为选择器的二元训练目标。对 clean 输入重复同样的计算，损失为受扰选择 BCE 加 0.5 倍 clean 选择 BCE。

LoRa 与 WiSig 共用同一个 `SharedPacketSelector`、物理残差特征、KL 偏好规则、优化器和最终逐包推理规则，分别用各自源数据、原专家、冻结识别器和权重。LoRa 教师是原 W24 E104 默认头，WiSig 教师是同数据契约的 Tri-SIG-TIME SSL F0 原默认头。教师、两路专家均冻结；门控推理只用当前收到的 IQ、两路专家输出和 R17 物理作用，不需要 clean 或训练教师。

教师分布是伪标签，可能继承教师错误。训练不读取 U 的真实 TX 标签，不读取源 V、目标 IQ、目标真值或目标统计。方法必须标为 **识别器指导训练**，报告教师来源、原有标签知识、额外推理成本和相应不确定性，不能称为 F-free。原识别器及默认头保持不变，最终仍须以其对恢复信号的独立预测和 truth-last 评分衡量。

## 固定预算与筛查

预备单种子 `2026112937`，各数据集均固定 AdamW、1,000 步和最后一步权重；LoRa batch 4、WiSig batch 24。各步对每条源 U 使用一条模拟受扰及 clean；当前准备代码每条执行六次冻结教师前向，LoRa 预计 24,000 次、WiSig 预计 144,000 次，另记源教师自身历史训练成本及专家成本。实际显存、耗时和延迟以运行记录为准。

在新候选的任何筛查结果读取前沿用已登记的物理包、信道观测、低城区和 clean：LoRa 源 V 的 `b200_1` 60 包、WiSig 源 V 的 RX1 360 包。原输入、R17、数据集匹配实增益、LoRa 源训练 R69 结构适配或 WiSig 固定 DURA v1 分别作为同包对照。LoRa 对每个对照的两个固定半区各净增至少 1 包且 clean 净损失不超过 1 包；WiSig 每半区各净增至少 2 包且 clean 净损失不超过 2 包。使用已多轮曝光的源 V，任何通过仍需预先固定的额外源样本复现，之后才可固定正式矩阵。历史 LoRa Full 已有曝光背景，最终结论需披露。

匹配无识别器指导的既有选择器筛查作为权限与成本不同的机制参考；它们的预算和 seed 不完全匹配，不能用于宣称教师指导的独立因果效果。如需归因，另登记相同 seed、优化器及 1,000 步的无指导控制。完整正式测试和全部对照依原目标执行，未完成前目标仍为进行中。
