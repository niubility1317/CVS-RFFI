# MILKR 适配 Tri-SIG-TIME SSL：改进方案与对照实验设计

日期：2026-10-31。状态：**仅设计，未实现、未启动、无新版性能结果**。本文件提出项目研发候选，不替换现行 MILKR、DURA 或 Phase2 协议，不修改在跑任务。机器矩阵见同目录 `pamf_milkr_trisigtime_experiment_plan_20261031.json`。

## 1. 决策与证据

建议保留 Tri-SIG-TIME SSL 的完整冻结 F，以“身份优先的固定核几何＋默认头残差适应＋B 函数继承”作为严格单视图主候选；另设同一支持物理样本的 raw/restored 双视图候选，解决只在 support 使用 DURA 的部署需求。先做有限的源端代理实验，固定超参数，再进行小单元技术核验和已冻结确认矩阵。

不建议增加目标端深网络微调、教师、迭代伪标签或 query 自适应。当前失败也不应通过把 S1Q0 改成 S1Q1 来掩盖。尚不能承诺新版不降性能，下面所有数值验收均为建议研究目标。

现有证据来自[完整诊断](../analysis/PAMF_PHASE2_DIAGNOSIS_20261031.md)，不再重新运行旧模型：

| 事实 | 已核实结果 | 对设计的约束 |
|---|---|---|
| B 的 S0Q0 与 S1Q0 | 66.87% 与 46.94% | 两条路线分别检验，不能只报告 DURA 两侧都开的成绩 |
| C 的 S0Q0 与 S1Q0 | H=48.31% 与 18.91% | 必须同时处理新类识别和旧新竞争 |
| S1 支持集自身拟合 | B=97.88%，C 全 26 类=98.51% | 不是增加训练轮数的问题 |

| C 的 tau 中位数 | raw=0.55252，restored=0.12444 | 避免局部尺度随注册类数突然重建 |

既有结果已暴露。它们只用于提出机制假设，不能用于确定新版 FFT 权重、核宽度、正则或混合系数。保持原三池、旧新 TX、7 RX、信道概率及 query 量，不通过降低任务难度制造提升。

## 4. 模块 G：适配最终身份表示的核几何

这里 G 是 geometry 模块记号；恢复器仍写 DURA，避免二者混用。以下单位化只发生于特征，不改变既有 IQ 归一化协议。

### 4.1 核定义

五个特征块分别单位化：最终身份 z、FFT96 的 e、time 的 t、frequency 的 f、PA 的 p。定义：

\[
k_z=z^Tz',\quad k_e=e^Te',\quad k_a=(t^Tt'+f^Tf'+p^Tp')/3,
\]
\[
k_b=(k_z+k_e)/2,\quad
k_{int}=(k_b+k_a+k_bk_a)/3,\quad
k_{sem}=(k_z+k_{int})/2.
\]

全部都是半正定核；乘积项采用逐元素乘积，隐式计算，不展开 123616 维交互向量。单视图自核为 1。原 FFT 的系数 4 改成背景内对称尺度，同时为真正部署的 joint160 单独保留一半基础核；这些等权系数是结构建议，不能称为已证明最优。

\[
d^2(x,x')=k_{sem}(x,x)+k_{sem}(x',x')-2k_{sem}(x,x'),
\]
\[
k(x,x')=\tfrac12 k_{sem}(x,x')+
\tfrac16\sum_{s\in\{1/4,1,4\}}\exp[-d^2(x,x')/(s\tau_B)].
\]

这是线性/交互的全局项和固定三尺度局部项的加和。全局项避免远离支持锚点时所有响应都只剩接近零的窄 RBF；三尺度共享距离、仅增加指数运算。它不是自动域对齐，不能凭公式承诺提升。

### 4.2 带宽和正则稳定

- 严格 S0、S1 各从当前旧类 support 的**所有异类物理样本对**计算 d² 中位数，作为 tau_B；不再用每个点最近异类的中位数。
- SD 从当前旧类 raw support 计算同一规则的 tau_B。其新增 raw 信息按 SD 身份披露。
- C 加入新类后继承 tau_B，不重新估计；K、episode 改变则重新初始化。
- 不使用当前 support 的经验中心化、trace-match 或随类数重置的截距。输出用统一中心化标签、固定核尺度和正则控制，见第 5 节。
- 只保留一个全局 lambda，候选 `{0.001,0.01,0.1,1}`，只用源代理选择一次。K1/5/10/20 和所有 RX/N 共用选定值；不逐 target 或方法变体调优。
- 异类距离中位数为 0 时使用在源端预先固定的正 tau_source，而非读取 query 或静默 jitter；记录退化。tau_source 为校准 seed2026092701 的源代理 raw 旧类距离中位数，并在全部模型 seed 共享。源端本身也为 0 时不发布该候选，报告无有效尺度。
- 浮点距离只容许数值容差内的小负值截为 0；明显负值、非有限值或分解失败记技术失败，不临时调 lambda。

“冻结几何”仅指同一个 K/episode 的 B→C，不能把不同任务的 target 尺度带过去。直接 A→C 同样先由六旧类当前 support 计算尺度，再一次求解全类；不提前用新类帮助 B。

## 5. 模块 P/I：默认头残差与 B→C 继承

### 5.1 B 保留当前源默认头的函数

旧类数 O=6。对当前处理路径的一个输入 x，取原 F 默认头的 softmax：

\[
h_A(x)=\operatorname{softmax}(\ell_A(x))-\mathbf 1/O.
\]

不拟合新源分类头，不调整原 logits 温度。softmax 只将原头变成与 one-hot 同量纲的有界先验，不把其数值当作已校准的真实概率。令标签目标 \(T_B(i)=e_{y_i}-\mathbf1/O\)，解析求解：

\[
r_B=\arg\min_r \frac12\sum_i\frac1K
\|h_A(x_i)+r(x_i)-T_B(i)\|^2+\frac\lambda2\|r\|_{\mathcal H_k}^2.
\]

因此 \(A_B=K_B+\lambda K I\)，
\[
\alpha_B=A_B^{-1}[T_B-h_A(S_B)],\qquad f_B=h_A+k_{xB}\alpha_B.
\]

每类总权重为 1；C 增加类数不会再把旧类样本的单点权重除以新的总类数。K 改变的正则规律也明确：双重矩阵的对角项是 lambda×K，不是默默沿用原版 sum-loss 的 lambda=1。原版与新版属于不同目标，不能叫数值修复。

P 的作用是假设少样本修正之外仍保留 A 的可用知识，而非废弃原头重建全部决策。S1Q0 中，离恢复锚点远的 raw query 仍有原 raw F 先验；这可避免某些无依据的远域外推，但它不保证新类性能。

### 5.2 C 继承 B 的判决函数

总类数 C=O+N，按 canonical 类表显式嵌入旧类列，而非假设旧类永远是前六个排序位置。C 还必须处理新类没有源默认头列的问题：若只补零而原旧类先验很强，远离 support 的新 query 可能始终输给旧类。为此，给新类设置一个同核、无新超参数的相对原型初值。

令 m_c(x) 为当前类 c 的 K 个物理核锚点的平均相似度。对于新类 j，取 `u_j(x)=m_j(x)-mean_old(m_c(x))`；旧类 u 列为 0。对全部 C 列去均值得到 Pi_C。这样新类初值表达“比平均旧类更近多少”，而不是给全部新类添加一个正偏置。所有原型只由当前合法 support 构成，Pi_C 也是同一核空间函数，不另设可训练温度/偏置。定义：

\[
g_C(x)=\operatorname{embed}_{old\to C} f_B(x)+\Pi_C(x),\qquad
T_C(i)=e_{y_i}-\mathbf1/C.
\]

对所有旧、新 support 求一个残差：

\[
\delta_C=\arg\min_\delta \frac12\sum_{i\in S_{old}\cup S_{new}}\frac1K
\|g_C(x_i)+\delta(x_i)-T_C(i)\|^2+\frac\lambda2\|\delta\|_{\mathcal H_k}^2,
\]
\[
\alpha_\delta=(K_C+\lambda K I)^{-1}[T_C-g_C(S_C)],\quad f_C=g_C+k_{xC}\alpha_\delta.
\]

旧类 support 是合法当前记忆，C 显式重放；没有额外旧类标签。这个目标在函数空间惩罚偏离 B 的修正量。**它不是“旧类函数严格不变”定理**，C 仍能修改旧类边界，新增类仍参与统一竞争。新类初值 0 也不是拒识门，不使用已知/新类 oracle 路由。

所有输出列的目标和先验均为零和；同一残差目标和 lambda 处理全部列。只使用一个 all-(6+N) argmax，不给旧类/新类另调偏置或专属温度。相对原型也可能初始化不佳，所以源端必做 `Pi_C=0` 控制，检查新类是否受源头压制或原型过强。仍需用实际 C_old、C_new、H 和交叉混淆检验可比性；零和本身不能证明校准或不遗忘。

### 5.3 合并部署与矩阵继承

Pi_C 可写成 `k_xC Gamma`：每个新类列在该类支持行置 1/K，在全部旧支持行置 -1/(O K)，最后逐行对 C 个输出列去均值。将 B 的系数嵌入 C 的旧支持行/旧类列后，与 Gamma、alpha_delta 相加：

\[
f_C(x)=\operatorname{embed}h_A(x)+
k_{xC}[\operatorname{embed}\alpha_B+\Gamma+\alpha_\delta].
\]

因此部署只保留一份 C 头，不串行跑 B、C 两个核分类器，也不增加 F 前向。保存 B 检查点用于过程审计，不算作查询必需状态。

固定几何、相同 K/lambda 和支持算子下，C 系统矩阵的旧旧块就是 A_B。可以复用 B 的 Cholesky，通过 Schur 补增加新支持行；这只节约求解，不改变目标。K5 时 B 为 30×30，新部分为 100×100，C 总矩阵 130×130。完整重分解作为同公式数值参考，不能作为另一个性能方法。

### 5.4 AC 与 ABC 的真实区别

| 路线 | C 的先验 | 可见物理标签 | 成本与声明 |
|---|---|---|---|
| 原 MILKR AC/ABC | 无 B 函数先验，完整重建 | 6K＋NK | 终态相同，保留历史定义 |
| 新版直接 AC | embed(h_A)＋Pi_C | 6K＋NK | 直接全类解析拟合，不额外计算 B 系数 |
| 新版 ABC | embed(f_B)＋Pi_C | 同一 6K＋NK | B 后求 C 残差；终态一般不同，必须报告 B 成本与 C 增量 |
| 新版 AC 内部先算虚拟 B | embed(f_B)＋Pi_C | 同一 6K＋NK | 等价 ABC 的计算流程，不能写成无 B 成本的 AC |

新版直接 AC 只需替换上述 C RHS 中的先验；其 C 核矩阵与 ABC 相同，可共享分解做性能比较。资源报告则必须分别测真正直接 AC 的冷启动成本和 ABC 增量成本，不能把跨实验共享的分解当作用户部署免费成本。

## 6. 模块 D：支持双视图的物理锚点

对物理支持样本 i，严格路线只有一个视图；SD 路线为 \(V_i=\{x_i,G(x_i)\}\)。定义对任意函数的线性观测：

\[
L_i f=|V_i|^{-1}\sum_{v\in V_i} f(v),\qquad
\bar k_{ij}=\frac{1}{|V_i||V_j|}\sum_{v\in V_i,u\in V_j}k(v,u),
\]
\[
\bar k_{qi}=|V_i|^{-1}\sum_{v\in V_i}k(q,v).
\]

这是核空间均值嵌入的 Gram，仍然半正定。每个物理样本只有一行和一个标签，训练的是**平均输出**接近目标；不把平均后自核强行恢复为 1。所有 B/C 公式中，把支持函数值换成 L_i h 或 L_i g，把 Gram 换成 bar-k 即可；query 仍是一个实际输入，不能把 raw query 和 restored query 在 Q0 偷偷平均。

这既保留 raw 锚点也提供恢复对应，且矩阵维数不变。相对严格单视图，每个 query 需与两个支持视图计算核；F(query) 仍只运行一次，Q0 的 DURA 调用为 0。

重要局限：平均损失不能保证两个视图分别拟合良好，可能出现一侧高、一侧低而平均正确。源端必须比较下式的完整逐视图控制：

\[
\tfrac12\sum_i\sum_{v\in V_i}\frac1{K|V_i|}
\|f(v)-T_i\|^2+\tfrac\lambda2\|f-prior\|^2.
\]

它有 2n 行，K5 的 C 为 260×260；不能将复制标签后保持原 sample weight 的做法充当控制，那会改变有效正则。平均锚点与逐视图损失是不同算法；若均值压缩在源端丢失明显收益，不能先假定它可替代完整逐视图解。

物理重复控制：令两视图都是同一个 raw，则 bar-k、先验观测和目标严格还原单视图候选。这个恒等关系用于实现验证，不需要新增 target 实验。

## 7. 严格 S1Q0 的补救候选：源端低秩特征桥

这是次级、单独命名的 `H-source`，不是核心方案已含的机制。只有源代理证据表明严格改造仍缺少跨路径迁移时，才考虑将它冻结后纳入新的确认矩阵。

使用合法源 L 的模拟 received 及其 DURA 结果，分别提取五个单位特征块，拟合 restored→raw 的线性残差桥。每块用源训练角色拟合 ridge 残差矩阵，再截断 SVD 至 rank=8；源 holdout 只验证、不进入矩阵拟合。ridge 系数固定 0.01，rank 固定 8，不做 target 搜索：

\[
\hat u_{raw}=\operatorname{unit}\{u_r+\mu_\Delta+(u_r-\mu_r)A_8B_8^T\}.
\]

五块合计存储约 `2×8×736+2×736=13248` 个 FP32 标量，即约 51.75 KiB，支持/恢复查询变换约 11776 MAC/条，不新增网络反传。该数不含拟合工作区及源开发成本。

在严格 S1Q0 中只变换 restored support 的核特征，raw query 不变，且不读取 raw target support 的 F 特征；原默认头先验仍使用实际 F 输出。S1Q1 时 restored query 也执行相同桥。桥只作用于核几何，不伪造 F 默认头的输入或重训它。

源桥学的是源模拟分布的平均对应，不能重建已经丢失的具体衰落/噪声，可能损伤原 S1Q1。需要源 RX 留组验证及 S1Q1 保护。它若只有 waveform/特征误差改善而没有源头层分类收益，不作为成功方案。源成本、桥参数、存储和额外变换全部单列。核心预算不包含它，条件预算为 5 次源 ridge/SVD 加 120 次源头层分解；不自动添加新的 target 行。

| R5 | 新 G | 双视图观测 h_A | embed(f_B)＋Pi_C，ABC | SD | 推荐双视图候选；R4→R5 只改变 C 继承 |
| A-id | 仅 z 的对应核 | h_A | embed(f_B)＋Pi_C | S0/S1/SD | 检查多分支是否真有额外价值 |
| A-global | k_sem，无局部 RBF | h_A | embed(f_B)＋Pi_C | S0/S1/SD | 检查局部项是否帮助而非制造尺度问题 |
| A-single | 一个 s=1 的 RBF＋全局项 | h_A | embed(f_B)＋Pi_C | S0/S1/SD | 三尺度是否必要；先限源端 |
| A-reset | 新 G，但 C 重估 tau | h_A | embed(f_B)＋Pi_C | S0/S1/SD | 区分尺度继承和函数继承；先限源端 |
| A-viewloss | 新 G、完整逐视图 loss | h_A | embed(f_B)＋Pi_C | SD，2n 行 | 物理均值压缩是否损失效果；先限源端 |
| A-zero-new | 新 G | h_A | embed(f_B)，Pi_C=0 | S0/S1/SD | 相对原型初值是否真帮助新类；先限源端 |

R1 同时改变权重、核混合、带宽规则、中心化和 loss 尺度，所以它只支持“几何组件整体”的结论。若要声称 FFT 权重或某一单项是主因，必须在源端增加对应一次只变一项的对照，不能用 R0→R1 单独归因。

### 8.1 源端筛选，先于任何新版 target 预测

1. 仅用 seed2026092701 的固定 F；五个源 RX 各建立 8 个确定模拟 episode，共 40 个。每类 K=5 support、32 个物理互斥 held 样本，使用合法 L 角色；同 episode 每条记录一份 received，并计算同一 DURA 视图。
2. 每个源 episode 建立 B6；另从六已知类中分出 3 个伪旧类＋3 个伪新类，测试 B3→C6。20 种 3/3 类划分按事前顺序轮换两遍，类选择不看成绩。B3 的原头只保留伪旧三列并重新 softmax，不提供伪新默认头列。
3. 此代理的 F 已在全部源六类及五 RX 上训练。它验证头层适配/路径兼容，**不是骨干未见类或未见 RX 的独立泛化实验**，不能替代真实新 20 类测试。
4. 只为最终结构做四个 lambda。评分目标 J 为 S0Q0 和 SDQ0 的 B6 宏准确率及伪 C6 H 四项的等权均值；J 距最高值 0.2 个百分点内取更大的 lambda。其余消融共用此值，不逐行重新调参。
5. 选定 lambda 后，运行 R0/R1、A-id、A-global、A-single、A-reset、A-viewloss、A-zero-new 的源端控制。R2/R4 的直接 C 和 A-zero-new 仅改变 RHS，可复用已存在分解。H-source 是有条件次级路线，单列。
6. 源 V 保持原验证角色；不把它的标签/特征加入头拟合。U_s 真标签不解封。源代理物理划分和仿真 seed 在生成前固定。

建议源端进入确认阶段的科学条件：R3 的 raw B/H 均不低于 R0 超过 0.5pp；R5 的 J 比原版对应 raw/strict-S1 组合平均提高至少 2pp；严格 S1Q1 的 B/H 均不降超过 1pp。源 C_old/C_new 分别检查，任何一项较对应原版降低超过 1pp 都不能靠平均 J 通过。若只恢复 raw 基线而 SD 相对新 raw 无收益，结论是双视图未证明有额外价值，不以击败原失败路线包装 DURA 收益。

源端未通过则保留负结果，不发布多 seed 新版。可以定位具体机制，不能转而用已暴露 target 分数挑另一个 lambda。所有 target 确认行在其首次预测前固定；小单元 target 分数不用于选择其余确认行。

## 10. 轻量化与计算资源记录

### 10.1 矩阵、状态和复杂度

设 n=(6+N)K，D=736。严格头存储 n×D 的 FP32 特征，SD 为 2n×D；Gram/Cholesky 和系数 FP64。以下是**设计载荷估算**，含一份全尺寸 Cholesky，不含 F/G、Python 对象、重复 Gram、工作区、原 IQ、缓存或历史 B 检查点。

| C 工作点 | n | 严格头载荷 | SD 头载荷 | 逐视图完整控制维数 |
|---|---:|---:|---:|---:|
| K5/N20 | 130 | 0.520 MiB | 0.885 MiB | 260 |
| K20/N20 | 520 | 3.626 MiB | 5.086 MiB | 1040 |

估算式：`4*n*D*views + 8*n*n + 8*n*C` 字节。若部署不保留分解，可再减去 `8*n*n` 字节。K5/N20 合并系数为 3380 个，K20 为 13520 个；这是数据拟合系数，不能因无梯度而写成“零训练参数/零适应成本”。F/G 的网络更新参数为 0，头梯度步数为 0。

核构造严格约 O(n²D)、SD 约四份视图块核，解析分解 O(n³)；每 query 严格约 O(nD+nC)，SD 约 O(2nD+nC)，均无高维交互显式展开。固定三尺度不增加 F/G 前向。实际速度取决于实现/硬件，不能由复杂度预报毫秒。

部署优先同时保留两个可解释版本：F＋R3 S0Q0（无 G 查询开销）；F＋G_support＋R5 SDQ0（增加支持处理，query 无 G）。S1Q1 继续作性能/成本上界参考，不能假定新版一定维持旧 82.04%。

### 10.2 每阶段必须记录的字段

| 范围 | 必填资源信息 |
|---|---|
| A 历史来源 | 实际复用 checkpoint、原累计 epochs/updates、已有 wall/GPU 时间及遥测缺项；不以 0 新训练掩盖历史成本 |

| B | raw/DURA 支持条数、物理标签数、G/F 次数及时间、核构造、分解/三角求解、state 写入、总 wall、CPU 核秒、GPU 活跃秒 |

| query | Q0/Q1、G/F/核头/总延迟，batch1/128、p50/p95/p99、samples/s；明确冷启动、热缓存及 I/O 是否计入 |

资源基准在 K1/5/10/20 记录实际一次适应总耗时；固定代表单元用支持数据复测解析头 20 次，排除前 3 次后报告分位数。查询微基准先 5 次预热、再 30 次测量，GPU 计时前后同步。并发实验给真实运行遥测，另在有空闲资源时做同卡/同线程微基准；不能为了测时停止其他 owner。

旧实验没有细粒度资源记录时，只补 source/support-only 的适应计算测时或冻结推理微基准，不重训 F/G，不补造历史训练遥测。若一次重放没有原并发环境，就只称“当前环境参考成本”，不覆盖原 run 的历史 wall time。

## 11. 实验预算与复用

“状态”指一个 B、直接 AC 或 ABC 拟合结果；“分解”包括新增 Schur 块分解；“指标行”指一种状态的一路 query 结果，不是 query 条数。特征计算可共享，但资源账本保留部署冷启动成本。

| 矩阵 | 新拟合状态 | 新核分解 | 指标行 | 去重说明 |

| 主确认 672 单元 | 6048 | 4032 | 12096 | 每单元 3 支持族×3 状态；C 直接/继承共享核分解；每状态 2 个 Q |
| K/N 附加 | 8316 | 4536 | 16632 | 84×16；B 跨 N 共用；扣除 MIX01/K5/N20 的 84 主单元 |
| 三单景 1260 单元 | 11340 | 7560 | 22680 | 每单元同主确认 |
| 三个归因附表 | 1344 | 1344 | 2688 | R1：84×2 支持族×B/C；A-id/A-global 各 84×3×B/C |
| 核心目标合计 | **27048** | **17472** | **54096** | 不含 R0/外部旧结果，不重跑主/附表重叠单元 |
| 条件分批注册上限 | 2016 次 C 更新 | 最多 2016 | 最多 4032 | 84×3支持族×2顺序×4sessions；已有等价首 session 预测可复用，资源测量单独记 |

源预算：四 lambda×40 episodes×3 支持族×(B6/B3/C6)=1440 次小矩阵分解；另 R0=240、R1=360、A-id=360、A-global=360、A-single=360、A-reset 的 C=120、A-viewloss=120，合计上限 **3360** 次分解，C 直接/继承和 A-zero-new 的额外 RHS 不另算分解，但必须记录三角求解成本。原始特征上限为 40×6×(5+32)=8880 份 raw、8880 份 restored，共 17760 条 F 输入和 8880 条 G 输入；控制共享它们。代理只使用一个源模型，不新增 F/G 训练。

目标 F/G 特征复用与实际总 query 数以数据/现有缓存清单为准，本设计不凭最大池容量虚构总 GPU 小时。先用代表单元实测分解出 F/G/核头成本，再按新工作量估算；不能拿“27048 个小头”误称“27048 次深网络训练”。

执行顺序：源代理与冻结 → 主表单元技术核验 → MIX 主确认 → K/N 与纯场景 → 已冻结归因附表。各行训练/适应冻结后完成其预定全部预测，再独立评分。每张 N607 GPU 最多两个本轮训练/预测 worker，其他 owner 另计但必须核实显存；解析小头优先 CPU FP64，避免为小矩阵长期占 GPU。上述是以后执行的资源安排，**本文件未启动任何任务**。

## 12. 验证、验收与结论边界

实施时只做与新行为有关的检查：

1. 默认头与 F/G 冻结、阶段输入隔离、K/episode 不继承；严格 S1 不得打开 raw support 特征，Q0 不得调用 DURA。
2. 单/双视图核半正定、raw 重复恒等、物理权重不翻倍、lambda×K 正确、C 标签/旧列映射正确。
3. 解析残差正规方程、full vs Schur 分解、合并前后预测函数在数值容差内一致；不是验证“继承一定比直接好”。
4. 改变 query 批次/顺序不改变模型状态或同条判决；没有 query 统计更新或旧/新 oracle 路由。
5. 一次合法真实 checkpoint 的 no-query smoke 后，遵守现有最小发布流程；不额外引入报告审批、hash 链或重复数据重验。

建议确认目标（未达到的目标也照实报告，不根据目标反馈重调同一确认矩阵）：

| 目标 | 建议判据 |
|---|---|
| S0Q0 主要收益 | B 与 C H 相对原版均争取至少 +3pp，C_old/C_new 不能靠一项明显损伤换 H；同时给全配对差 |
| 严格 S1Q0 修复 | B 与 C H 相对原严格 S1Q0 均至少 +5pp；不足则明确严格路线仍未解决 |
| SDQ0 实用性 | 相对原 S1Q0 的 B/H 至少 +10pp；还需相对新版 S0Q0 不低超过 0.5pp，且至少一个端点额外 +1pp，才声称 support DURA 有额外价值 |
| 保护 | 新严格 S1Q1 的 B/H 不低于原版超过 1pp；同时报告每 RX/纯场景负差，不以总均值遮掩 |
| 对外方法 | 能否达到/超过 DADDA 当前 raw B=72.98% 是结果，不是用以选 lambda 的目标端门槛；比较达到相同准确率所需适应时间和内存 |
| 轻量化 | 满足第 10 节载荷/调用/时间目标，且源开发与历史训练成本都披露 |

如果严格 R3 的 S1Q0 失败而 SDQ0 成功，应报告“同物理双视图支撑的部署改进”，不能写“原四格只恢复 support 已无损”。如果 C 旧类变好而新类/H 不改善，则不算注册改进。如果只有支持拟合提高，不算正式有效。无梯度不等于无计算成本；继承 B 不等于消除所有类竞争；均值核不等于逐视图一致性。

## 13. 文献依据与原创边界

- [Bertinetto 等，Meta-learning with differentiable closed-form solvers，ICLR 2019](https://arxiv.org/abs/1805.08136)：支持少样本中用小规模解析 ridge 降低适应开销的思路。本设计不引入其端到端元训练，也不冒充 R2-D2 复现。
- [Zhang 等，Tip-Adapter，ECCV 2022](https://www.ecva.net/papers/eccv_2022/papers_ECCV/html/154_ECCV_2022_paper.php)：支持保留冻结预训练函数并以少样本缓存修正的动机。本设计没有 CLIP 文本侧，也不把它加入用户限定的 RFFI 外部比较。
- [McDonnell 等，RanPAC，NeurIPS 2023](https://arxiv.org/abs/2307.02251)：说明冻结表示与解析统计可以共同服务类别/域增量问题。本设计不采用其随机投影，未宣称具有该论文的无记忆条件。

核均值物理锚点、这里的固定核配方、默认头概率残差及 C 函数继承公式是本项目的待验证组合设计。本文给出数学定义和资源估算，不构成新性能证据或文献中的现成 MILKR 版本。

交付时已用不含项目数据的抽象矩阵核对：核均值 Gram 的半正定性、Schur 与完整求解的一致性、原型/B/残差合并的一致性及输出零和；该示例最大系数差约 6.7e-16。还独立核对了预算去重和载荷计算。这只是设计算式核验，没有加载 IQ、F/G checkpoint、目标 query 或启动真实实验，不能替代实施后的真实 checkpoint smoke 和正式测试。
