## 已核实的原因

历史 REPL 是普通伪标签之上的组合配方：门槛 .95、U 权重 6、六次 U 学生前向、浅中层风格混合、完整 joint160 对比、完整特征外推及 L 梯度保护。全量退步不能全部归因于其中一个模块。

从完整公开汇总独立复算 44 个三 seed 配对对比：11 设置中 raw clean 有 7 个均值提高，raw 六景 0 个提高，同 G-LU 六景只有 3 个提高。F0 跨 RX clean 差值为 +.525661pp，三 seed 分别 +1.127778／+.920635／−.471429pp；同 G 六景差 −.229762pp，分别 +.268519／+.372354／−1.330159pp。这有明显 seed 依赖。历史按 33 个完整候选中已公开的 F0 clean 结果选定 REPL，保留这一选择背景，不称独立盲选。

去风格混合较完整 REPL 的 raw 六景 +.365608pp；去外推的 G 六景 +.214771pp，raw clean 仅 −.081746pp。完整配方中的 joint 和梯度保护条件消融同时降低 clean 和 G 六景，先保留作为待检验组成，不宣称普适因果收益。上述去模块结果也没有同时超过普通 PL 的全部指标，不能直接命名为成功的新方法。

源几何提供了更具体的风险证据。普通 PL→REPL，同 TX 跨 RX 距离 .070755→.025384，不同 TX 同 RX 距离 .346678→.205825，差值 .275923→.180441。REPL 同时压缩了身份间距。源 +25 kHz CFO 干预的特征位移下降，默认头翻转率却由 34.0741% 升至 41.2963%；特征更不变不能替代判决更稳。这些是源诊断，尚不能证明目标退步由某个身份分量丢失单独造成。

仅 1 个源 RX 时风格混合计数确为 0，跨 RX joint／外推没有合法正配对；REPL 仍保留六视图、U 权重与梯度保护。该设置同 G 六景下降 .419342pp，故“所有退步都是跨 RX 外推错配”不成立。三 seed 梯度冲突累计为 7623／7588／7445，接受率约 99.54% 至 99.60%；门控并未关闭，接受率也不代表 U 真正正确率。

## 吸收哪些正收益

1. 优先吸收匹配消融中去风格混合、限制完整特征外推的收益，保留它们各自对照，不把两项增益相加。
2. 保留 REPL 的跨 RX 学习思路，检验只外推由真实 L 支持的接收机变化，避免直接把两个同伪类样本的全部差异当成接收机因素。
3. 暂保留 joint 与 L 梯度保护；后者只约束当前参数梯度，不能保证 Adam 整步、全轨迹或未见域性能。
4. AllURDrop 的原目标 raw 六景 +2.3530pp、PeerT1U2 +1.9203pp 说明困难／受损样本有可用信息，但两者 G 六景分别 −.7567／−.6333pp。吸收“检查未利用样本与输入域差异”的经验，不把已失败的损失直接叠加。
5. 最新 NoSIG 有噪声困难标签六行源 raw 提高 +.2963 至 +.3370pp，G 三景全部下降；GCE、重复 raw、G/HG 并未消除权衡。保留其数据利用证据，停止把恢复 IQ 加强当作默认捷径。

## 新假设：身份保护的接收机外推

复用已完成的单视图普通 PL E20 前缀，以及已有完整监督、普通 PL、单视图 REPL／结构参照；不新增对照或为新公共 E30 父单独补训。先做不训练的必要条件诊断，决定是否形成学生配方。L6300 真标签用于估计类别／接收机均值，不使用 U TX 标签、V 更新或目标。原 NoSIG 缓存不用于当前单视图方向估计；此前已登记的 NoSIG RXGeometry 在输入读取前取消，没有执行或产生科学结果。

对归一化特征，记 `mu[y,r]` 为 L 类别 y、接收机 r 的均值；`b[r]=mean_y(mu[y,r]−mean_r(mu[y,r]))`。均匀平均类别，避免 TX 数量差把类别变化混入 RX 偏移。再从 `b[r]` 中移除 L 类别均值差张成的子空间，得到 `b_perp[r]`。候选外推为 `z_ext=z+.25*(b_perp[rx_i]−b_perp[rx_j])`，不外推整条 `z_i−z_j`。alpha 沿用 .25，不扫描。

这是假设，不是已经验证的物理 RX 分解。RX 与 TX 交互可能占主导，投影后也可能几乎没有有效方向。首先检查完整 L/V 缓存的双因素分解、跨类别留一的 RX 方向一致性、移除身份子空间后的能量和 V 方向迁移。V 仅用于最后只读诊断，不构建 b、投影或阈值。restored_features 是 12 个 G 视图特征的归一化平均，只能作几何参考，不能写成单个 G 场景的实际识别结果。

必要条件在读取新诊断结果前固定：raw 和 restored_mean12 两类表征均要求，保护后的共享 RX 能量占类内 RX 能量至少 5%，跨类别留一平均余弦 >.1、正方向比例 >.5，固定 L 方向对 V 的平均余弦 >.1。它们只排除近零或明显不迁移的方向，不代表提高分类准确率。任一失败便不按这版“共享加性 RX 方向”启动学生；不扫描阈值、alpha 或重新放大方向。

该必要条件失败就保留负结果，不靠放大近零方向补救；若成立，再以当前 L 特征更新统计，避免冻结旧中心的坐标漂移。训练实现必须在发布前明确每步有效类别/RX、缺失单元回退、停止梯度、真实方向能量、实际分类头和梯度，不能用诊断公式代替已实现机制。

下一批只发布改进候选，不再启动 REPL／监督／普通 PL 的重复控制。原单视图 REPL 三 seed 结果直接复用。候选为去风格混合、去风格且去外推、去风格且只外推 RX 方向；从同 seed 已完成的单视图普通 PL E20 独立 +10＋20 到 E50，沿原分段预算。必要条件先用单 seed 源证伪，训练实际机制与候选选择在新目标访问前固定。当前这些改进学生尚未登记或启动。

通过源条件后才扩三个学生 seed；最终固定同一候选，自动完成原目标 raw／同 G clean＋六 practical 及独立 truth-last。新性能仍须用实际目标结果证明。已暴露的历史目标只用于问题定位与如实披露，不再按目标名次挑 epoch、seed 或扫描参数。
