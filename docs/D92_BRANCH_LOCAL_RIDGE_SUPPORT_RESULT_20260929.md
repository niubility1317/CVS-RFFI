## 1. 覆盖、口径与筛选

完整覆盖 4,800 个 parent episode：1,200 个真实 K1 只做数值诊断；3,600 个 parent 完成标准 OOF 和 proxy。其中含新增类的 parent 为每种诊断各 2,880 个，old-only 为各 720 个。按 K×新增类数，每种诊断每格 240 个 parent；含新增类的每个 K 合计 960 个 parent。覆盖 4 个 model seed、2 个 cohort，共 8 个冻结模型/cohort 组合，以及既定接收机、场景、support seed 矩阵。

标准 OOF 以每类物理 ID 排序后的位置模 3 分折，K=5、10、20 时三折训练 K 分别为 3/3/4、6/7/7、13/13/14。每折独立估计带宽、trace 比例和头，held 不进入拟合。proxy 对每个 parent 遍历全部 K 个锚点位置，每类只选 1 个物理样本训练，其余 K−1 个样本持出，共 42,000 个 anchor。视图没有增加 K，也没有跨越物理 train/held 边界。

proxy 先在 parent 内平均所有 anchor，再对 parent 等权平均；标准 OOF 与 proxy 分开汇总。每臂 7,879,200 次 proxy held 出现是重复持出计数，不是独立样本量。多个 seed、support draw、anchor 以及共享数据的模型结果相关，本报告不作独立重复、显著性或因果效应声明。

A/B 原规则是：两种诊断都在每个 parent K 下，相对 BranchRidge 和 InteractionRidge 同时满足 Δ新>0、ΔH>0、Δ旧≥−1 个百分点。严格共同改善另报，不增加“全部 K×新增类数组格必须全正”的门槛。下文 H 是各 parent 旧类与新类准确率调和均值的均值，不是汇总旧、新准确率再计算的 H。

## 6. 机制证据与数值状态

本轮只有一个冻结候选。它复用原始 received 对应的五块特征，采用与 InteractionRidge 完全相同的隐式表示 φ=[B,A,vec(BAᵀ)]。对每个训练物理样本寻找最近异类平方距离，包含零距离，以所有训练样本该距离的中位数作为 τ；核为 exp(−d²/τ)。τ、中心化统计量和 γ 全部只由当前训练折确定。query 或 held 只用固定状态逐样本评分，不重新估计带宽。

候选把中心化径向核的 trace 缩放到原始 interaction 中心化核的 trace，λ=1、每物理样本权重 1 保持不变。因此，相对 InteractionRidge 的收益不能简单解释成提高了总核能量或统一减弱了 ridge 正则。该控制只匹配 trace，没有匹配全谱、有效自由度、各对角元或未见样本范数。本轮支持“这一固定径向头在同一合法支持诊断中优于原头”的受控比较结论，不足以证明局部性是唯一原因，也不证明换场景后必然改善。推导和退化规则见 [冻结设计](D92_NEXT_AFTER_ORBIT_20260929.md)，实现见 [core](../code/cvsrffi/d92_branch_local_ridge.py)。

52,800 次候选拟合全部完成，没有因 C1、全同特征或零带宽减少 Cholesky；本矩阵的最小注册类数为 6。所有最近异类零距离比例为 0，OOF τ 范围为 0.527096 至 2.836176，proxy 为 0.466001 至 3.733913。γ 范围分别为 0.942194 至 2.633987、0.847365 至 3.138099。零带宽及单类退化的正确性来自预先合成测试，本轮实际数据没有覆盖这些退化，不能把数值测试冒称实测退化发生率。

候选归一化线性方程残差的最大值为 8.90×10⁻¹⁷，trace 相对误差最大值为 8.01×10⁻¹⁶，均低于冻结的 128·eps64·max(N,C) 阈值。残差分母使用 1+s0 的谱范数上界，并非实际测量的谱范数。旧对照的残差字段是原始绝对残差，不能与候选的归一化残差直接排序。

按拟合 stage 等权统计，候选 OOF/proxy 的有效自由度均值为 50.727/6.844；训练准确率均值为 99.992%/100%，训练减 held 准确率差为 41.831/60.180 个百分点。这些 stage 统计含 old-only，且 proxy 的 anchor 权重不同于正文 parent 等权指标，只用于诊断，不能替换主要结果。训练识别接近饱和没有消除持出误差；proxy 的相似度诊断中，“正确类最大相似度减最近错误类最大相似度”的 stage 均值为 −0.027079，说明许多单锚点任务的最近支持关系仍不可靠。

分类准确率改善也不等于概率校准改善。含新增类任务中，候选相对 InteractionRidge 的 macro NLL 在 OOF/proxy 分别增加 0.007980/0.016832；相对 BranchRidge 则分别降低 0.028760/0.004252。这里 NLL 由固定 ridge 分数的未校准 softmax 得到，三臂都没有交叉熵训练、温度搜索或梯度更新。

## 8. 常驻头大小与预先合成检查

这部分来自实现公式和此前已经完成的合成测试，与上一节真实 support 运行分开。一般非退化候选的常驻数值状态是五个 float64 数组：B（N×256）、A（N×480）、alpha（N×C）、参考核行（N）、中心化均值（N），加 4 个 float64 标量。故数值状态字节数为 8N(738+C)+32。注册表、审计字典、Python 对象和临时 Gram/QR 不在此口径内。

| 合成形状 | N | 常驻数值状态 | 一个 N×N float64 矩阵 | 已测合成拟合时间 |
|---|---:|---:|---:|---:|
| C26K1 | 26 | 158,944 bytes | 5,408 bytes | 约 0.0305 秒 |
| C26K20 | 520 | 3,178,272 bytes | 2,163,200 bytes | 约 12.4185 秒 |

C26K20 的合成 tracemalloc 记录峰值约 23 MB，只覆盖被追踪的 Python/NumPy 分配，不是进程 RSS。合成测试采用本地恢复后的数值环境，时延不能与上一节实际运行逐阶段时间直接作速度比较。真实标准 OOF 的最大训练 N 为 364，proxy 的训练 N 最高为 26；合成 N=520 检查验证的是可能的完整支持拟合形状，不代表本轮 support probe 实际拟合过完整 N=520 的候选头。

依据本轮实测最大训练形状与上述状态公式，OOF 的最大候选常驻数值状态为 2,224,800 bytes（N=364、C=26），proxy 为 158,944 bytes（N=C=26）。这是由实测形状计算的头大小，不是 RSS 测量，也不把临时矩阵计入常驻状态。

距离用 rank-2 reduced QR 按最多 256 对分块计算，未物化 123,616 维完整 φ。训练距离与核需要 O(N²·736)，Cholesky 需要 O(N³)，单个待识别样本评分需要 O(N·736+NC)，并保留固定 support。标准数值路径没有 jitter、谱裁剪或回退原头。

## 9. 当前结论与交接边界

现有证据支持保持唯一候选和全部配置冻结，并按主任务已有授权进入评分与拟合隔离的重复 query benchmark。该后续评测正在由主任务准备；本报告不记录其结果，不参与基于 query 的带宽、正则、特征、类数组或 K 拼接选择。

可声明的是：完整 support 诊断中，标准 OOF 在每个 K 及全部新增类数格实现两个对照下的旧/新/H 正增益；proxy 通过允许轻微旧类退化的原筛选规则，但没有实现旧新共同严格改善，且保留一个 H 负向分层。尚不能声明真实 K1、所有 episode、新增独立数据条件或全面性能目标已经改善。
