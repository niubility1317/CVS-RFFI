# CVS 已知激励相对响应候选

本轮由全量源域 L-STF 对应诊断提出，未使用目标测试成绩设计。仍保持相同物理划分、普通身份 CE、无增强、无域骨干、四 seed、E200×50，性能第一。它是待验证候选，不是已完成的物理感知或性能提升结论。

## 结构与作用位置

已知标准 L-STF 在 25 Msps 下为20点周期。参考系数来自[作者固定版本](https://raw.githubusercontent.com/bastibl/gr-ieee802-11/ad0598e4a874f4b8e1f391a1e0323e80df2b34ff/examples/wifi_phy_hier.grc)，tone间隔312.5kHz，按20MHz激励解析采样，不复制作者示例的10MHz采样率。源 L6300/V27000 的80:160窗口模板相关中位数约0.9975，但源RX分组平均值差异约0.2114；该事实支持已知参考，同时阻止把残差直接归因TX。

固定80:160四周期，以lag20相位估计wrapped相对CFO，将该窗口按已知周期相干平均。有限320个时移参考通过匹配滤波前向独立求最大相关，步长1/16样本；没有optimizer、模型/跨包状态更新、标签输入或类条件query处理。这里的相关与归一化均是固定逐包数学表征，不进行query训练/校准/统计聚合。

令周期均值单位能量化为u，已选公共参考为s，匹配复标量 `g=<u,s>/20`。12个激励频点的相对接收响应为：

`D_k = (U_k/S_k) * conj(g) / (|g|²+1e-6)`。

复残差 `D_k-1` 通过固定半径4的平滑有界函数，形成24实维；再拼接匹配质量、lag20相干度、相干周期能量比例、显式相对CFO（模1.25MHz）和窗口/整包能量比例，共29维。29→64→160小MLP及LayerNorm后，以160通道零初始化tanh门控残差加到原residual_fusion身份特征。原核心的每seed随机初值完整一致，初始全部logits与基线严格相等；不加载原权重。CE第一步即可训练门控，随后投影获得非零梯度。

新模型177025参数，原残差164225，增加12800（约7.79%）。改进假设是给身份网络提供“相同已知激励下的相对响应坐标”，不是单纯扩大通道数。原time/Sinc/frequency/received-PA代理路径保留，避免未经性能验证删除身份信息。参考分支受限flat增益/相位归一化，不宣称整个网络不变；显式保留CFO与原始身份路径也阻止此类全网声明。

## 物理闭式与混淆边界

在已知稳态激励、平坦线性接收链的孤立三阶模型 `y=s+κs|s|²` 下，设C为三阶项频谱，`b_k=C_k/S_k`，则除声明的正则化因子外，`D_k=(1+κb_k)/(1+κmean(b))`。实κ对应弱AM/AM形状，虚κ对应一阶AM/PM形状；不是饱和PA或精确幅相分离。独立闭式测试包含该正则化因子，并验证已选时移为零，不用同一实现生成期待值。

受控机制链为100Msps标准周期激励→TX三阶/镜像/延迟三阶→周期稳态因果FIR信道→RX增益/镜像/三阶→12tone带限→25Msps采样→相对CFO→整包RMS。100Msps生成三阶分量，避免在25Msps先非线性再错误解释混叠。固定5种TX配置×6种RX/信道条件，共30组合，不加到正式训练。它仅覆盖稳态12tone投影，没有噪声、onset、完整重采样或真实WiSig的MMSE均衡复现。

固定RX条件含平坦增益相位、80kHz相对CFO、两tap信道、RX镜像和RX三阶。冻结模型分别报告相对响应与整网单位嵌入距离，不把五个合成TX配置当作六个真实源身份、不给“合成身份准确率”。unitychannel下TX镜像和RX镜像、TX三阶和RX三阶可得到相同波形，必须保留这些反例。未知任意频响也可吸收激励频点内的部分非线性失真；该分支是相对接收响应代理，不是已辨识TX PA/IQ参数。

公共相位、flat增益的归一化只在分支且非退化输入上成立，含epsilon时是数值近似。近零输入及硬时移路由边界不承诺精确不变或处处光滑；零输入前向和梯度需有限。L-STF共轭与10点时移/复增益等价，不判定I/Q约定。CFO为TX-RX相对量，不能称作TX晶振频偏。模型不读取RX标签作为输入，源RX/day标签仅在验证分层。

## 固定实验与收尾

4个新scratch源行，加4份已核实、完整相同契约的原residual_fusion源记录（只读指标，不加载权重），合计8源记录。四seed固定2026092701至2026092704；原物理L6300/V27000/U56700unused；AdamW2e-4、wd1e-4、cosine1e-6、FP32、无梯度裁剪。最终E200固定权重；V不更新任何模型/normalization状态。

选择最大四seed `0.5×V+0.5×最差源RX`。完全相等才依次比较V、最差RX、实数ConvLinearMAC、参数和baseline/reference固定顺序。没有成本容差带。物理机制诊断和源嵌入几何用于解释，不另加科学结果硬gate或以测试重排。

若新候选胜出，冻结后默认4个新clean预测，复用原20个固定对比预测，同168000物理query、6TX、7RX；全部预测完整后独立truth-last评分和完整同row报告。若原基线胜出，保留其已完成历史测试，不重跑历史任务、不测试未选候选。clean历史暴露，按既有代理基准解释，不宣称新盲测/真实卫星。任何目标成绩不得反馈结构、调参、选择性重跑。

日志保存逐步完整JSONL、epoch详细文本、紧凑JSONL/CSV；记录实际参考分支响应/门控/梯度、CE权重、LR、整体梯度、源V/最差RX和耗时。冻结后90个TX×RX×day源V单元的准确率/嵌入几何、30合成组合及全部负结果保留。成本报告实数ConvLinearMAC与独立6400 complex correlator MAC（等价25600实数MAC）、FFT次数、参考常量buffer字节、实际训练/推理耗时与峰值显存；不能只报参数数目。

性能提升与物理机制证据必须分别成立；零门控初值不证明后续有效学习，源高分不证明测试提升，分支正确不证明整网已经实现真实TX/RX解耦。
