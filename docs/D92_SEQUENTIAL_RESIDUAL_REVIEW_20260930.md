## 设计核对

- 平均目标 `mean(CE) + (||ΔU||² + ||ΔV||²)/(2N)` 与物理和目标相差常数正倍数；解析梯度中的两个近端项均为 `Δ/N`。Adam 必须按明确规定的平均目标、固定 epsilon 与梯度裁剪执行，不能因目标的极小点等价而随意改成物理和梯度。
- 非零 DCT 初始化 U、零 V 产生零残差。首步 U 的 CE 梯度为零，但 V 的梯度通常非零；训练前向不能按 V=0 跳过可训练分支。全零 z、单类等真实零梯度情况应保持确定性，不需要人为产生更新。
- q 仅由当前阶段 train 的冻结基线分数估计。B/C 各自计算，且 C reset/sequence 共用 C 基线与 q。q 精确为零时取 1；正尺度不用于跨头 raw logit 比较，非有限派生量保留技术失败。
- C 初始分数为完整 C LocalRidge 基线除 q_C，再加继承的 B 残差旧列；新残差列为零，不等于新类总分数为零。不得混接 B 基线旧列与 C 基线新列。C 的 U 和全部 V 列可训练，锚点固定为各自初始化值，Adam 一二阶矩重新置零。
- B 与 C 的旧 train 必须具有相同物理 ID、标签与缓存特征。每个外层 fold/anchor 重新构建 train-only 状态；held 标签仅在冻结分数后评价，held 数值不决定 q、优化步数或最终状态。
- Nnew0 两个残差对照都复用 B 基线、q、参数和分数，不产生 C 更新。真实 K1 parent 无拟合/持出性能；parent K5/10/20 的单 anchor proxy 可训练 K1，并保持独立解释。
- 160 parent 的 1,760 条有效路径中，352 条 Nnew0 路径各拟合一个基线，其余 1,408 条各两个：共 3,168 次 base fit。残差 B 共训练 1,760 次，C reset/sequence 各 1,408 次，共 4,576 个阶段与 292,864 个固定 Adam 更新。完成记录必须从实际调用计数核对，不能把期望数当成已测量数。
- R_seq 与 R_reset 同时改变 C 初始参数和近端锚点，设计已明确只能解释顺序继承整体效果。全类 softmax 与逐样本全类 argmax 保持部署规则；C_old 只用于固定分数后的离线分解。物理 class ID 精确并列规则保持不变，类别重命名等变测试应将非并列性质与并列时的字典序规则分别核对。
