# BranchLocalRidge联合微调：数学依据、论文对应与可验证假设

日期：2026-09-30。用户要求微调结合数学原理与相关论文，不以参数组合搜索作为主要路线。本文补充MC-Residual8冻结设计的理论依据；不是性能报告，不改变Phase1、数据协议、既定矩阵或健康实验。

## 1. 先定义要解决的机制

最终分类器始终是BranchLocalRidge。目标域合法support训练表示适配器；每次改变表示后，重新解析拟合当前注册类的LocalRidge。微调的损失直接作用于这个最终分类器的分数，而不是另训一个CE分类头再希望其表示能迁移到LocalRidge。

设固定地面编码器给出z，适配器为Tθ，当前注册类集合为C。联合训练的结构为

`θ* ≈ argminθ L[Sθ(inner-held),合法support标签]`，

`Sθ = LocalRidge(Tθ(inner-train), Tθ(inner-held))`。

inner-held仍是本次合法训练support，其标签参与θ更新；它不是独立验证集。outer-held只评分，不参与拟合或候选选择。B阶段只有旧类；C阶段继承实际B状态，并对全部注册类统一竞争。root掌握的历史query结果不进入候选设计或训练。

## 2. 可微闭式求解：让微调与最终头一致

R2-D2把ridge闭式解置于可微学习链中，并利用样本空间的解避免高维特征矩阵求逆。这支持“通过最终解析头学习表示”的方向。[Bertinetto等，ICLR2019，§3.2、式3至5](https://www.robots.ox.ac.uk/~vedaldi/assets/pubs/bertinetto19meta-learning.pdf)。

下列是本项目头的记号化推导。设中心化、迹缩放后的kernel为Kθ，`Mθ=Kθ+I`，中心标签为Yc。忽略此处不影响求导的标签均值记号，

`αθ=Mθ⁻¹Yc`，`Sθ=Kθ,cross αθ+Ymean`。

微分线性方程`Mα=Yc`得到

`dα=−M⁻¹(dM)α`，

`dS=(dKcross)α−Kcross M⁻¹(dM)α`。

给定损失对分数的伴随G，先求

`Q=M⁻ᵀ KcrossᵀG`，

则`bar_Kcross=Gαᵀ`，`bar_M=−Qαᵀ`（对称kernel方向取对称部分）。Cholesky分解可复用，两次三角求解得到Q。参数数目增加不会要求按每个参数重拟合一次头，但会增加adapter前后向及保存状态的开销。

本项目还必须继续求导距离、当前带宽、中心化和迹缩放。只对`Tθ(z)`求导、把拟合头或带宽当常量，会漏掉`−Kcross M⁻¹(dM)α`等项，优化的已经不是宣称的联合目标。两个损失通道复用同一分解，分别计算实际伴随工作量。

与R2-D2的区别：本项目不重新做地面跨任务meta-training，不学习该论文的ridge/温度超参数，也不使用其独立测试集作为卫星训练输入；仅借鉴可微解析求解原则。有限差分能检查导数实现，不能证明目标域准确率会上升。

## 3. 低秩表示适配：参数约束有依据，rank8仍是预算选择

Houlsby等用冻结基座和小型瓶颈adapter完成参数高效迁移。[ICML2019，§3](https://proceedings.mlr.press/v97/houlsby19a/houlsby19a.pdf)。LoRA将权重增量因式分解，并让一侧零初始化，使初始增量为零。[Hu等，§4.1](https://arxiv.org/html/2106.09685v2)。ReFT则研究在冻结模型的表示空间中学习干预。[Wu等，2024](https://arxiv.org/html/2404.03592v3)。

MC-Residual8更接近瓶颈adapter/表示微调：`v=U GELU(Vx)`，U为736×8、V为8×736。它不是原始LoRA的线性权重增量，也不是LoReFT的正交子空间替换。GELU和样本相关切向投影不能直接合并进固定encoder权重，所以不能搬用LoRA的“合并后无额外推理时延”结论。

其结构性性质可以直接推导：

- 参数量为`2dr`，当前d=736、r=8，所以是11776；这是参数量，不是训练总计算或模型总内存。
- 固定θ时，映射v对x的Jacobian为`U diag(GELU'(Vx)) V`，秩至多8。切向投影本身依赖x，不能据此宣称整个最终映射的Jacobian全局秩也至多8。
- U=0时输出残差为零；非零V0保留`∂v/∂U`，而`∂v/∂V=0`。若U、V都初始化为零，则两侧可能一起失去数据梯度；不应把“恒等初始化”误写为“跳过反向”。
- 缓存特征免去了encoder反向与逐trial重提IQ特征；是否节省总时间和峰值内存仍需测量，尤其两个解析伴随和教师会增加开销。

固定encoder也带来无法靠adapter消除的边界：若两个不同类别的观测被encoder映射为完全相同z，则任何相同输入、确定性的Tθ都输出相同表示。该信息损失不能靠增加迭代、换学习率或加大rank恢复。当前候选检验的是“已有特征中包含可用信息，但几何不适合目标域LocalRidge”的假设，而不是承诺恢复encoder已经丢失的区分信息。

论文没有证明本任务最优rank为8。rank8、DCT初始化、κ=0.25、四次迭代属于提前固定的表达/数值/预算选择。本轮不扫描这些组合，也不把这些具体取值包装成理论最优。

## 4. 保持几何：可以证明什么

对非零分支r=ρw，`||w||=1`。切向残差`t=(I−wwᵀ)v`满足`wᵀt=0`。定义

`δ=κt/sqrt(κ²+||t||²)`，`r'=ρ(w+δ)/||w+δ||`。

因此`||r'||=ρ`，且转角满足

`angle(r,r')=atan(||δ||)<atanκ`。

它限制分支能量和表示扰动的角度；不能证明扰动方向正确，不能证明类内距离一定减少，也不能证明新旧类一定分开。

联合距离`D=.5Doriginal+.5Dadapted`给出`D>=.5Doriginal`。适配器即使把两个样本映射到相同位置，也不会单独抹掉原有非零距离。两份欧氏平方距离的加权和可解释为拼接表示的欧氏平方距离，因此对应Gaussian kernel保留合法kernel结构。稳定差分计算、有限正带宽和实际数值误差仍需检查。

这说明为什么保留原几何具有明确作用；它不说明混合系数.5最优。系数提前固定，性能结果不能回流把它改成某个较好组合。

## 5. 旧类功能保持必须面对新类竞争

LwF通过保存旧模型输出约束新任务训练，强调功能保持而不只约束参数距离。[Li与Hoiem，§3及§5](https://arxiv.org/pdf/1606.09282)。本项目借鉴这一原则，但采用合法旧support上的真实标签margin；不是完整复现其概率蒸馏损失。

对旧样本，当前正确margin为

`m_all=S_y−max_(j≠y,全部注册类) S_j`。

进一步令`m_old=S_y−max_(j≠y,旧类)S_j`、`m_new=S_y−max_(j∈新类)S_j`，则新类非空时

`m_all=min(m_old,m_new)`。

只保持旧类列，最多约束m_old；即使旧类列完全不变，仍可能被新类夺走预测。因此C阶段保持损失应对m_all计算。这个竞争机制不靠学习率组合解释。

冻结折内教师给出`q=clip(m_teacher,0,1)`，保持半平方缺口为`[q−m_all]⁺²/2`。q=0时不强求保留错误teacher winner，仍鼓励负margin向零改善；q>0时才提供正margin保护。旧类teacher只由相应inner旧train拟合，不能使用完整B头掩盖折隔离。B参数已接受合法旧support监督，C教师不是无偏独立验证。

类风险先跨折汇总，再取RMS。设任务半平方unit-margin类均值为ℓc，`Rtask=sqrt(mean_c ℓc²)`。对当前训练持出support，误分类必有m<=0，从而单样本任务损失至少1/2，所以

`macro训练错误率 <= 2 mean_c ℓc <= 2 Rtask`。

这是训练风险上界，可以很松；它不推广成query保证。若旧teacher阈值q低于γ的样本比例为p_low(γ)，对任意符号分析阈值γ>0，有

`macro旧训练错误率 <= p_low(γ)+2 Rkeep/γ²`。

γ仅用于解释界，不是新增模型参数或搜索项。大量q=0会让界无信息，说明保持项不是旧类准确率的替代指标。RMS不小于类均值，惩罚类风险不均衡；不能由此保证每个类都改进。

## 6. 梯度约束与真实风险检查

GEM把过去任务的loss保持写为约束，并投影冲突梯度。[Lopez-Paz与Ranzato，NIPS2017，§3、式6至8](https://papers.nips.cc/paper/7225-gradient-episodic-memory-for-continual-learning.pdf)。原文采用episodic memory；本项目只能用合法目标旧support，不引入源域replay、query记忆或任务身份oracle。

本候选的约束是`Rkeep(θ)<=Rkeep(anchor)+εkeep`。一阶近似给出`aᵀd<=b`，其中a为保持梯度、`b=max(0,Rlimit−Rcurrent)/t0`。求距离原下降方向d0最近的合法方向，有单半空间的闭式解：

`d=d0−a [aᵀd0−b]⁺/||a||²`（a非零；a零时直接d0）。

半空间包含原点，所以投影后方向范数不超过原方向；不能再次归一化放大受保护分量。只靠这条线性约束不能保证非线性风险不增加，因此每个实际trial都必须重算Rkeep，并满足固定上限。

参数球投影还可能改变实际位移Δ。独立审查已构造`gᵀd<0`、`gᵀΔ>0`且通过原Armijo的损失微升反例。因此冻结设计补充实际总目标非增检查：`Ltrial<=min(Lcurrent,Lcurrent+1e-4*gᵀΔ)+tolL`。这保留Armijo条件并限制真实目标增量；不能把纸上投影方向的性质直接移植到投影后位移。可保证的只是接受状态在声明浮点容差内非增，不是严格收敛、旧类准确率保持或新类提升。

`εkeep=1/(2k sqrt(Cprev))`来自一条平衡旧support出现unit-margin-deficit=1的类RMS风险量级。它不是“最多错一条”或“遗忘<=1个百分点”的证明；风险可以分散。κ、球半径、损失系数和有限步数同样不具理论最优保证。

## 7. 后续如何判断机制有效

一次候选先给出结构假设、论文对应、公式、来源和预算，再固定运行；失败后检查机制证据，不能只更换参数组合。

本候选的可证伪判断是：完整伴随确实正确、adapter确实改变表示、全类margin保持约束确实执行后，B是否改善、注册旧类损失是否减少、新类是否同时改善。如果这些内部机制执行了但完整外层support结果仍无改善，就应修正机制假设；内部loss降低不能代替外层性能。
