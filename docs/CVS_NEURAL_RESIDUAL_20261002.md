## 唯一改变量：网络结构

保持`adaptive_volterra_lag4`现有三分支、归一化、输入构造、160维embedding和cosine30分类头。所有参数从零初始化，不加载任何既有checkpoint。时域与行为分支第三层之后各放入新的可学习复数残差模块，包装在原第三层内，保持原诊断接口。

每模块为：`32通道复数特征 → 64通道复数1×1卷积 → 共享RMS与径向门 → 64通道复数depthwise k5 → 共享RMS与径向门 → 32通道复数1×1卷积 → 与输入相加`。时域使用对称padding，行为分支使用左padding。新增模块仅依赖当前样本特征，不输入RX、类别、role、全局配额或其他样本。

出口卷积为零初始化，内部卷积随机初始化。因此初始输出与同seed、同次从零构建的控制精确一致；新模块的初始化隔离RNG，不改变基座参数和后续CPU随机数流。首步内部卷积梯度为零属于零出口的数学结果，第二步应出现来自CE的梯度；已在聚焦测试中检查。没有学习率分组、分阶段训练、冻结基座或附加损失。

## 固定训练与源选择

原ManySig物理划分保持不变：L6300、U56700不使用、V27000，源RX1/3/4/6/8、day1/2/3，splitseed392005。两个候选各4个modelseed2026092701至2026092704，共8行。每行200轮×50步，batch128且不drop_last；单一`cross_entropy`，AdamW学习率0.0002、weight_decay0.0001，沿用cosine至0.000001。没有增强、域骨干、teacher、EMA、伪标签、对比项、重加权、难例采样或新训练策略。全FP32，TF32关闭。

固定E200，读取8条新源记录与4条已有adaptive控制的合规源元数据，按四seed平均`0.5V+0.5最差源RX`选择。性能完全并列后才比较成本，不选择最佳epoch，不用目标结果选择、重排或重跑。V属于已见源RX，本轮不新增留一RX训练或数据划分。
