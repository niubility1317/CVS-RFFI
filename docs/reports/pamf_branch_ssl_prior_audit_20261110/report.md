# PAMF 多分支半监督：历史路线核对

2026-11-10。研究对象为用户指定的旧版完整 PAMF：时域、频域、PA、参考响应、三视图路径描述和原默认头。用户要求研发新的监督及半监督机制，最终比较已完成普通 PL 的全部数据设置。本报告是历史证据核对，不代表新方法有效，也不授权根据已暴露目标成绩选 checkpoint、调权重或选择性重跑。

## 核对范围与结论

检索实验登记、PAMF 历史训练／源诊断报告、已有 42 条正式端点综合复盘、论文总表、实际训练代码和分支消融。2026-10-26 综合复盘本身报告完整读取 102 份相关报告和 42 个 F0 配方端点；本次复用该既有审计并针对最相似路线复核原始报告，不声称本次重新完整读取历史训练日志或全库所有实验。

分支不足优化是合理假设，现有结构与学习方式交互不能单独证明它。历史上已做过 L 浅／中时域跨 RX 对比、U 浅／中和融合特征跨 RX 对比、同伪标签风格混合、路径互补 CE、实际证据责任路由与多锚梯度保护。有限检索未发现本任务提出的时域、频域、PA、参考响应和三视图路径全部分别施加相同 L/U 身份关系损失的完全匹配实验；这不是穷尽性查新或论文首创证明。特别是它仍有与已有 UCRIC、Joint160 相同的伪身份关系和特征聚拢原则，不能只换作用层就声称已有效。

## 同口径已完成证据

除注明外，下表为旧 F0、未见 RX 的全部日期 168000 个物理记录／seed、三个匹配模型种子；raw 六景在每 seed 内等权平均；G 为同固定 DURA-LU。源数据、网络、训练日程与损失的具体差异以各原 run 为准，表格的 PL 差仅用于结果对照，不把复杂组合差值当单一模块因果效应。数据来源：[42 行正式端点](../../../automation_reports/CV-SincNet/20261026-analysis-PAMF-SSL-retrospective-r01/formal_method_endpoints.csv)。

| 方法 | 与本方向的关系 | raw clean | raw 六景 | G 六景 |
|---|---|---:|---:|---:|
| 普通 PL（F21） | 原完整 L 骨架＋U 硬伪标签 CE | 84.9817% | 70.3594% | 78.0746% |
| Joint160 | 同伪身份跨 RX 对部署融合特征施加对比，含其他 SSL 机制 | 85.6417% | 70.1712% | 78.0808% |
| Complement | 转移一部分 U CE 剂量到去路径描述的同包特征 | 84.9589% | 70.2528% | 76.4464% |
| PathComplement | 同时对去路径描述、去路径描述及参考响应的特征施加既有头 CE | 84.8187% | 70.3020% | 76.2970% |
| REPL／RX 外推，自然顺序 | 融合特征关系、特征外推及多项 U 机制 | 85.7268% | 70.0855% | 77.8977% |

Joint160 相对 PL 的 raw clean 高 0.6599 个百分点，raw 六景低 0.1881 个百分点。Complement 的 G 六景低 1.6283 个百分点，PathComplement 低 1.7776 个百分点；不能由此判定新增互补 CE 单项造成全部差距，因为与 PL 还有高权重、style、保护等差异。两种互补方法的直接设计是移走部分普通 U CE 剂量且重用原分类头，不等于分别对时域、频域和 PA 做跨 RX 对比。详见 [Joint160](../../../automation_reports/CV-SincNet/20261024-phase1-PAMF-HardPL-Joint160-m3-r01/report.md)、[Complement](../../../automation_reports/CV-SincNet/20261024-phase1-PAMF-HardPL-Complement-m3-r01/report.md)、[PathComplement](../../../automation_reports/CV-SincNet/20261024-phase1-PAMF-HardPL-PathComplement-m3-r01/report.md)。

早期 UCRIC 的伪标签跨 RX 目标已作用于时域 time_down／t2 浅中层，三个种子 raw clean 为 84.2907%、raw 六景为 71.8662%、G 六景为 77.1860%。该实验使用既有 E30 学生／自身 EMA 及其原门控，和 F21 普通 PL 的伪标签机制不同，不能把与 PL 的整体差直接归因于 UCRIC。见 [UCRIC](../../../automation_reports/CV-SincNet/20261023-phase1-PAMF-U-CRIC-m3-r01/report.md)。

真实证据责任路由对同包加性分量实施 L 监督，只向相应组件路由辅助梯度；旧 E20 三种子 clean 相对匹配 SSL 平均 −0.0542 个百分点，1/3 seed 为正，最差 RX 平均 +0.2458、最差 day 平均 −0.1802。该研究为旧单视图、旧 U 门控和 clean-only，U 阶段不运行责任辅助，不等于完整多分支 SSL。见 [责任路由三种子结果](E:/type10-7/automation_reports/CV-SincNet/20261015-phase1-SIGTIME-evidence-responsibility-e20-clean-manysig-m12-r02/report.md)。

BranchGuard 保护的是物理／非物理 **L 损失组**的梯度方向，并非时域、频域、PA 各网络分支独立梯度保护。固定 NativeAsCap2 对照下，其 raw 六景 72.4817% 对 72.4163%，但 raw clean 84.5270% 对 84.4611%，G 六景 77.0329% 对 77.0643%；均为复杂组合、三 seed 的小差异，不能说明分支保护普遍有效。见 [BranchGuard](../../../automation_reports/CV-SincNet/20261024-phase1-PAMF-HardPL-BranchGuard-m3-r01/report.md)。

另有真实标签浅／中层跨 RX 对比：旧 E30 三种子 clean 相对匹配 SSL +0.4661 个百分点、3/3 种子为正；但仅比同 TX 不限 RX 的对比高 +0.1083 个百分点，只有 1/3 种子为正，不能由该实验确认“跨 RX”本身贡献稳定。它使用旧网络和训练配方，不能直接等同当前完整 PAMF。[源实验](E:/type10-7/automation_reports/CV-SincNet/20261013-phase1-crossrx-contrastive-clean-manysig-m6-r01/report.md)。

只用 clean／直接信道视图的单视图 H2_LU_Pair 在严格同结构三种子对照中，raw clean 较 PL −0.5131 个百分点，六景 +1.4146 个百分点；三个 seed 的 clean 只有一个为正。源验证先前通过并未保证未见 RX 的 clean 也改善。该结果为单视图，不应冒充旧三视图同结构结果。[完整确认](../../../automation_reports/CV-SincNet/20261027-phase1-PAMF-SIG1-REPL-CleanH-confirm-m3-r01/report.md)。

## 数据条件和作用边界

旧三视图自然顺序的 REPL 相对相同顺序普通 PL，F0 合并人群 clean +0.7450 个百分点、六景 −0.2738。固定重排＋完整 SSL 在共同三 seed 上 clean +1.9371、六景 +0.2164，但同时改变局部顺序和 U 方法，不能把差值全部归于 SSL；六景只有 2/3 seed 为正。[完整三视图比较](../../../automation_reports/CV-SincNet/20261027-phase1-pamf-repl-shuffled-views-m16-r02/results_analysis.md)。

十类双跨 clean 中，普通 PL 83.4243%，自然 REPL 82.0438%，固定重排完整方法 82.4897%；最终方法三个 seed 均低于 PL，平均 −0.9346 个百分点。完整 step 日志分析发现十类 E21 起源 V 已落后、U 梯度冲突和限幅频繁；不能把原因定为某个独立模块或伪标签错误。[十类完整诊断](../pamf_clean_ssl_diagnosis_20261029/report.md)。

单源 RX 没有跨 RX 正对。对于一个 RX 的可行目标和多个 RX 的身份关系必须分别定义、计数和比较；单 RX 的同类不同记录关系不证明跨 RX 不变。所用 source RX/day 可公开，隐藏 U 的 TX 不可由物理记录序号或 RX 推断。

## 对新候选的直接启示

1. 不把全部五路一律聚拢当成已验证的多分支优化：分支可互补，也可能混有接收机变化；时域与三视图共用上游，五项等权相加可能重复作用于共享时域。弱频域或参考响应不能因为端到端边际贡献小就被假设为必须单独可分类。
2. 已通过 0.95 的源 V 代理可很准确，但主要覆盖容易样本。此前一项三教师代理 V 接受 25234/27000、错 8；拒绝池聚集约 98.21% 的 raw 错误。这是源 V 代理而不是实际 U 伪标签精度。仅增加已接受 U 的关系损失未必提供新信息，错误伪类还可能同时污染正负对。
3. 完整 L 梯度保护有证据但不是零风险：它约束局部欧氏梯度，无法保证 AdamW 实际更新、各 L 子项或目标性能；历史分支锚和实际更新保护均未消除 raw／G 权衡。需要同预算独立消融，不把保护当效果保证。
4. 首轮应该采用源 L 和合法 U、同普通 PL 自然顺序／训练预算／默认头，先测每条真实分支的可区分性、跨 RX 正负对和梯度作用，再固定最少量的目标及匹配控制；不直接把全部分支、L/U 对比与梯度保护堆成已定有效方法。新 prototype 目前仅合成测试／真实网络随机输入执行验证，尚未完成真实 checkpoint smoke、集成训练、独立审查、预登记或正式实验。
5. 所有条件均优于 PL 是研发目标而非保证。先做预登记最小证伪，再在符合科学门槛时扩到 11 数据设置、三配对种子；原测试集已暴露，探索结果必须披露，不能声称独立盲测。额外计算、源 RX 数为 1 的处理及潜在负差均应报告。

历史恢复 IQ 学习的证据只用于说明输入分布取舍；新训练按当前授权只使用合法源 clean IQ 及直接信道衍生物。用户明确采用含参考响应旧网络进行此轮，不将去参考新版队列或其结果混标。
