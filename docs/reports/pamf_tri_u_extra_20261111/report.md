# 无标签分支关系的额外三种子验证

延用 β=0 的无标签五分支关系及完整 Tri-SIG-TIME SSL，不改变训练配方。新增 seed 04、05、06 从各自原始同数据契约 E20 续训到 E50；同 seed 原始 Tri E50 保留原权重，并新算匹配的 clean、六个 practical 和 DURA 七景预测。三候选及三基线的预测全部冻结后独立评分；逐包核对物理 ID、标签、视图和 DURA 输入。主口径为 Main split 的 cross_rx 与 cross_both 合计，每种子每场景 168000 包。

β=0 在先前 seed 01–03 的目标结果曝光后被挑作追加验证对象。04–06 是新的配对模型种子，但测试物理样本与已有开发测试相同，不能称为独立盲测。04–06 无匹配普通 PL 结果，PL 对比仍限 01–03。
