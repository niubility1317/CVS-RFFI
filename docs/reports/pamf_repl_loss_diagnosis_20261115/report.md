# Tri-SIG-TIME SSL：十类与六源接收机的损失及权重分析

日期：2026-11-15。分析既有冻结实验，不新增训练、预测、评分或读取无标签 TX 真值。本文是权重研发建议，不改变已固定的原版方法。

## 证据与口径

复用 2026-10-29 的完整日志解析结果，并重新汇总 Main split、十类、六源接收机的逐步指标：普通 PL、自然顺序 REPL、固定重排完整 PAMF 各 3 种子，共 27 个逻辑模型。原审计对共享前缀去重后完整读取 72 份 step 日志、259740 条记录，逐模型覆盖 11100 个逻辑训练步，并读取对应 epoch JSONL/CSV；原审计范围的结构化日志未发现预算缺失或非有限数异常。本次对其全部逐 epoch 聚合行重新计算，未声称重新逐条读取远端原始日志。原审计可定位的 stdout 覆盖不完整：在这 27 个逻辑模型中，当前 PAMF 的行可定位 stdout，普通 PL 和部分历史 REPL 未定位；不可把此次结构化日志完整性当成所有 stdout 完整。

表中 E21–E50 是完整 REPL 阶段，三种子、每步均值；5 轮分组各 3330 个逻辑 step。L CE 是 `train/loss_tx_labeled`；U 各项按原日志定义，不同损失的标量大小不是梯度贡献大小。U 的真实 TX 标签不可用，接受率和源 L 诊断不能替代 U 伪标签准确率。

已有结果为既定固定终点测试，目标数据已曝光。普通 PL 保持自然顺序，当前 PAMF 为固定重排，因此两者整体差异不能完全归因于 REPL 损失；自然顺序 PL 与自然顺序 REPL 在每设置和种子共享 E20 前缀，可更直接定位 E21 后组合变化，但仍不能定位单个模块。

## 梯度保护和权重作用

|设置|t2 冲突步数|t2 限幅步数|分类头冲突步数|分类头限幅步数|t2 L/U/保护后 U 范数均值|
|---|---:|---:|---:|---:|---:|
|十类|51.071%|79.109%|49.990%|6.652%|0.23093 / 0.29863 / 0.21609|
|六源|49.505%|71.852%|41.106%|16.121%|0.17421 / 0.23803 / 0.15100|
|Main|47.943%|76.667%|40.445%|18.428%|0.17825 / 0.26062 / 0.15747|

范数是逐步范数均值，三项均值之比不是逐步保留率均值；U 为已乘名义权重的整体 U 梯度。冲突是对应组内点积为负，不是伪标签错率，也不能单独证明有害。代码先去掉与当前 L 梯度冲突的分量，再将投影后 U 范数限制为最多 L 范数。若权重缩小后某步仍限幅，缩放可能被上限抵消；若变为不限幅，实际 U 更新会减小。三组的限幅情况不同，不能把权重 6 改成 3 表述为最终所有梯度减半。

原 REPL 固定 U 总权重 6；浅中层对比系数 0.1、融合对比系数 0.05、CE 正规化 1.25，风格混合概率 0.5，外推系数从普通 CE 中重分配 0.25、外推幅度 alpha=0.25。风格混合概率和外推幅度是输入／特征变换参数，不等同于损失权重。外推调整必须保持原 CE 总剂量，否则混淆作用。

结构上损失系数可以调整，但当前冻结的配置和部分 validator 固定上述数值；不是宣称现有正式方法已经允许任意在线修改。应新建独立候选、记录实际生效配置和实现，不能覆盖原模型或改写历史结果。梯度合并后作用不可由 loss 标量大小推断。

## 结果和归因边界

十类双跨 clean，普通 PL/自然 REPL/固定重排 PAMF 分别为 83.4243/82.0438/82.4897%，当前固定方法相对 PL 的三种子差分别为 −1.5613、−0.2695、−0.9729 个百分点。六源跨 RX clean 对应监督/PL/自然 REPL/固定重排 PAMF 为 87.8154/87.8080/86.5173/87.2318%；六源双跨的完整方法较 PL 仅低 0.0676 个百分点，三种子方向不一致。六源同时改变源 RX 组成及数据量，不是单独改变源域数量。

Main 的自然 REPL 现有单项消融中，去 U 风格混合 clean +0.1516±0.2334 pp（2/3 种子），去梯度保护 −0.2151±0.2109 pp，去融合对比 −0.2336±0.0777 pp；结果不能迁移为十类或固定重排的已证实结论。已有全置信 Hybrid 辅助权重 0.25/0.5/1 的探索说明权重可改变该变体性能，但它改变的是另一套 Hybrid 额外损失，不能当作原 REPL 权重对照。

## 建议的最小研究顺序

研究问题是同样三视图、固定重排、预算和 U 权限下，是否改善十类与六源并保留 Main 的收益。单候选可先用匹配单 seed 做小规模源域筛选，再对按源域事前规则选出的候选作多 seed；这些是建议而不是已完成结果。统一使用合法匹配 checkpoint/数据契约及原 20+10+20、E50 训练成本，选模仅用预先固定的源域规则，目标结果不可回流。原 Main、十类、六源、PL 等已完成结果直接复用；保持历史完整测试暴露背景。

第一阶段固定其他机制、阈值 0.95 与限幅 1，比较 U 总权重 6（已有对照）、3、1.5；同步记录 t2/头/其他组投影前后范数、冲突和限幅，以及监督 CE、源 V、接受率。权重 3/1.5 是探索网格，不是已验证最优值；如已长时间限幅，重点解释实际梯度变化。

第二阶段在相同总权重下分别改变一个因素：浅中层对比 0.1→0.05；融合对比 0.05→0.025；外推 CE 重分配 0.25→0.125，差额返还普通 CE；风格混合概率 0.5→0.25（这是增强概率消融，不是 loss 权重）。每项独立对照；第一阶段与第二阶段交互仅在源域证据支持且事前固定时扩展。不要据 Main 删除融合或保护项；不要将名义 loss 值当作贡献比例。

源侧诊断包括逐 epoch/组的损失、L 与完整 U 及条件允许时各 U 组件的梯度方向与范数、伪类别/RX 计数与高置信曝光、可合法使用的独立 L/V 源分层预测；这些不是 U 真值精度。测试按冻结后完整 clean＋六 practical、逐 seed/scene/TX/RX/day 和净纠错独立 truth-last 评分，区分整体和不同场景。PL 自然序与固定重排 PAMF 对比保留组合效应解释；如需单独归因 REPL，另增加匹配固定重排的普通 PL 控制，不能把旧自然序 PL 改标。
