## 效率表口径

FLOPs 为计数器实际覆盖的卷积/矩阵运算，1 MAC=2 FLOPs，不称总 FLOPs。PAMF 路径代数、FFT 复数算术、归一化和逐元素操作未被完整计入；FFT/IFFT 单列调用次数。参数存储不等于部署显存。

常见网络部署请求与 PAMF 专用 GPU wall 计时分别成表。均为 RTX3090/FP32，但重复单位、传输边界及内存基线不同，不据混合数据宣称加速倍数。PAMF 专用结构计时使用 CE 冻结权重，保持其身份；旧 164225 参数 CVS 不用于替代当前 232993 参数 PAMF。
