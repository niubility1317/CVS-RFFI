## 口径

对 20261027-phase1-pamf-paper-completion-m119-r03 的 10 个非 Main 设置，各 seed 2026092701/02/03，完整解析 Tri 源训练 E21–E30 的 2220 步和 E31–E50 的 4440 步，每个模型 6660 步，共 30 行、199800 步。冲突是原梯度保护前，同一参数组内完整 L 梯度与加权完整 U 梯度内积为负的步数比例；t2 限幅是该组 U 梯度触发原有范数上限的比例。与每段 repl_state 的 calls、seen、accepted、各组冲突次数和 t2 限幅次数一致。U 接受率按实际曝光次数统计，各数据集有效 batch 数不完全相同；不是去重覆盖或伪标签正确率。三种子等权平均。

Main split 数字引用原先完成的 3 种子、E21–E50 完整逐步分析；见同目录 report.md。性能差取论文总表 14_paired_effects_summary.csv 的 raw clean、相同模型 seed 配对平均：完整 Tri 减自然时序普通 PL；差中包含固定时间重排、U 目标等组合差异。源 RX 数量采用表中共同六目标口径；Main split 的七目标跨 RX 结果不能与五源共同六目标直接合并比较。跨 RX 与双跨不是同一测试集。

仅凭上述聚合无法解释为何某设置获益；需要固定匹配顺序 PL、同设置分量消融、相同物理记录的逐 TX/RX 净纠错、源分组及多 seed，且目标已曝光的探索证据不能作为新独立盲测或测试集调参依据。
