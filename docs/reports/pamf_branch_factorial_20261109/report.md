# PAMF 三条主分支消融与后续实验清单

2026-11-09。状态：**更新后的候选设计；尚未实现、登记发布或启动训练。**本清单取代此前 205 个逻辑模型的候选统计，不覆盖此前报告或既有实验。

当前最终结构仅移除参考响应：保留时域骨干、频域骨干、功放相关支路和依附时域骨干的三视图路径描述。完整 PAMF 的半监督机制和固定局部时序重排保留；以前其他结构的结果维持原身份。

## 1. 第一优先级：三条主分支的全部非空组合

三条主分支分别为时域、频域、功放。下表每种设置使用相同数据契约、自然顺序、真实标签分类损失和三个模型种子；所有结构均不含参考响应。时域存在时默认保留依附它的三视图路径描述，时域不存在时路径描述随之移除。结构消融仅报告 PAMF 直接识别。

|设置|时域|频域|功放|路径描述|三个种子当前状态|
|---|---|---|---|---|---|
|完整基底|✓|✓|✓|✓|已有候选，可核对复用|
|去功放|✓|✓|—|✓|候选新增|
|去频域，严格单路归属|✓|—|✓|✓|候选新增|
|去时域及依赖的路径描述|—|✓|✓|—|候选新增|
|仅时域|✓|—|—|✓|候选新增|
|仅频域|—|✓|—|—|候选新增|
|仅功放|—|—|✓|—|候选新增|

“仅某分支”指仅保留该**数据依赖特征路径**及其原有内部统计、必要的固定零占位、融合层与原分类头；不加入其他被删分支的输入特征。仅功放仍保留原来属于功放路径的频谱统计，其内部可能计算 FFT；因此“仅功放”不是“网络中绝对没有频域运算”。完整原模型的圆对称性标量在原实现中与频域路径一起进入时频融合；上表严格组合中随频域路径一同保留或屏蔽。保留的融合偏置是输入无关的参数，不算额外特征支路。

此前时频方案要求“去频域骨干但保留圆对称性标量”，为保持该已提出问题，**另设一组**：保留时域、功放、三视图和圆对称性标量，仅去频域可学习骨干。它与表中的严格去频域组不同，不可合并。两组均要保留功放分支自己的频谱统计；现有原生频域开关会连带影响这些统计，不能直接开关充当消融。

## 2. 时域与路径描述的依赖控制

仅比较完整基底与“去时域”会同时移除路径描述，不能把差值全部归给时域骨干。为评估在不同其他支路条件下时域骨干的条件变化，补充四个**保留时域但去路径描述**的控制：

|保留时域的控制|频域|功放|候选状态|
|---|---|---|---|
|去路径描述|✓|✓|已有 3 种子候选|
|去路径描述和功放|✓|—|已有 3 种子候选|
|去路径描述和频域（含随频域的圆对称性标量）|—|✓|候选新增 3 种子|
|仅时域，不含路径描述|—|—|候选新增 3 种子|

第二行对应历史“去路径描述、去参考响应和去功放”三种子，只有数据、配方、模型来源与固定读出核对一致后才复用。[既有矩阵](../../../automation_reports/CV-SincNet/20261026-phase1-PAMF-noSIG-supervised-ablation-m15-r02/experiment.json)

2026-11-09 只读检查已找到该组 3 个模型的最终 checkpoint 与源冻结完成记录，均为 50 轮、11100 更新；目标访问、无标签真值访问与另训头更新在完成记录中均为 0。这里仅确认产物存在和记录的基础信息，尚未替代完整来源、配置与评分核对。

主要同种子差值按“变体 − 匹配对照”计算：

1. 每一种删分支或单分支模型减完整基底，展示实际系统变化。
2. 去时域及路径描述 − 仅去路径描述，估计频域和功放都保留时的时域条件变化。
3. 仅频域 − 保留时域与频域但去路径描述，估计功放已关闭时的时域条件变化。
4. 仅功放 − 保留时域与功放但去路径描述，估计频域已关闭时的时域条件变化；严格频域归属下两者均无圆对称性标量。
5. 三视图基底 − 同支路组合但去路径描述，分析路径描述自身在有时域条件下的差异。

负值为前者较差，正值照实保留。删除结构同时改变模型容量。无任何输入特征路径的纯常数分类器不列为神经网络主消融；七个非空组合也不能构成包含空组合的完整 2³ 因子试验，不能据此计算完整三因素交互。

第一优先级共 **12 个结构设置 × 3 种子 = 36 个逻辑模型**：七个非空主组合、一个保留圆对称性标量的频域骨干控制、四个无路径描述控制。其中 9 个模型来自三个候选复用设置，27 个为候选新增。此前候选的原始完整结构、去路径描述、去时域、去频域、去功放已包含在内，不能再次计数。所有复用只在实际数据角色、训练配方、seed、checkpoint 来源和冻结评分核对后生效。

## 3. 后续结构与完整方法实验

第一优先级之后，保留此前已盘点且与新结构有关的四类结构控制：单视图、去显式时间坐标、矩统计替代、固定局部顺序重排。各三个种子，单视图三个为候选复用，其他九个为候选新增。加上第一优先级，分类损失监督结构面板共有 **16 设置、48 逻辑模型、12 个候选复用、36 个候选新增**。

参考响应已不在新 PAMF 中，“去参考响应”和“打乱参考模板相位”不能再作为新模型内部消融；历史结果可作为新旧模型比较保留。训练机制不能被误写为网络分支：当前结构面板只用有标签分类损失；完整监督、普通 PL 和完整半监督另在主方法矩阵中比较。

|执行顺序／部分|逻辑模型|候选复用|候选新增|说明|
|---|---:|---:|---:|---|
|第一：三主支路组合及依赖控制|36|9|27|含保留圆对称性标量的频域骨干控制|
|第二：其他结构控制|12|3|9|单视图、显式时间、矩统计、局部顺序|
|第三：11 设置 × 监督/普通 PL 增强四格及完整半监督 × 3 种子|165|3|162|已有标准划分完整半监督无参考 3 种子候选|
|第四：完整半监督由三种子补至八种子|5|0|5|仅补后 5 个种子|
|第五：无增强纯 CE 架构对比|8|0|8|E200，其他网络已完成的模型不重训|
|**合计**|**226**|**15**|**211**|候选而非实际派发；复用及其他 owner 需先核对|

第一阶段完成、预测冻结并独立评分后，可以汇总该完整预登记的分支面板；主方法及其他已授权面板不按分支得分挑选、删减、重排参数或选择性重跑。第一、二阶段均是结构消融，训练仅使用真实标签交叉熵，不引入 U／EMA／伪标签／跨接收机对比或 KL。原分类损失 CE(普通输入)＋0.68 CE(信道辅助输入)、标签平滑 0、信道配方与三个 seed 按既有面板保持；E50＝20＋10＋20 段／11100 更新。

第三部分的 11 设置：标准划分、两套接收机重划分、十类、1%／5% 标签及 1／2／3／4／6 源接收机。完整监督、普通伪标签和完整半监督区分；新完整半监督仍保留三视图、固定重排和既定训练机制。10% 标注和 5 源公共目标从匹配标准模型复用，不重复算训练。

候选新增 203 个 E50 模型和 8 个 E200 模型，共 11750 模型轮、2333300 次更新。该计数不是独占 GPU 时间或实际 ETA，可能因发现额外可精确复用产物而减少。已有模型预测／评分、四种外部对比方法、DURA 和同合同缓存只按来源核验复用，不按模型重复重训。结构消融不接入恢复网络；其他主比较需要系统读出时可复用匹配的冻结恢复器并为新识别器补读出。

## 5. 数据、统计和发布准备

沿用标准六类原源接收机和日期、L6300、V27000；结构消融不读取 U。只报告目标接收机跨接收机 126000 条／景、跨日且跨接收机 42000 条／景，另给两类 168000 条／景综合，不混入源接收机单独跨日。每模型 clean 与六种 practical 场景全部决策冻结后独立 truth-last 评分。十类和其他设置按各自实际样本数统计。综合准确率用正确数／总数，综合 Macro-F1 先汇总相同模型的混淆矩阵；六景先在 seed 内平均，再按同 seed 配对并报告均值、样本标准差和实际种子数。

现需完成 15 个候选模型的完整合同和读出核对；实现严格单支路、无路径描述控制和频域统计拆分；用实际图检查每个声明关闭的支路不执行且不泄漏输入、保留的辅助统计与源实现一致。每个唯一运行按项目规则生成正式矩阵、不可覆盖输出、真实 checkpoint 无 query smoke、限定 P0/P1 审查及资源预检。保护其他 owner，分支面板优先；不把候选 CSV 当作已登记或已启动的训练。后续 Phase2／Phase3 对新识别器的适配、阈值及依赖模型仍需独立核对，未计入这里的 Phase1 数量。
