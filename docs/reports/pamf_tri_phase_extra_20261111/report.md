# 相位感知分支半监督的额外三种子验证

固定原 Tri-SIG-TIME SSL 及已接受源 U 的时域、路径和参考响应分支公共相位一致性；seed 04–06 从各自同契约原始 E20 续训至 E50。对照复用同 seed 原 Tri E50 的冻结七景 DURA 预测。新候选三组 prediction 全部冻结后独立评分，逐包核对物理 ID、输入视图和 DURA 缓存。主口径为 Main split 的 cross_rx 与 cross_both，每种子每景 168000 包。

该分支方案是在查看同一测试集的早期结果后挑选来做额外种子验证的。04–06 是新增配对模型种子，但物理测试包已曝光，并非新盲测。匹配 PL 只覆盖 01–03，不得把 04–06 对 Tri 的结果当成对 PL 的验证。

新增种子每模型均有 1701000 次原 REPL U 样本曝光，额外一致性各选择 852360 次，其中分别接受 809827、814423、810762 次；每模型增加 13320 次分支前向。三种子累计训练墙钟时间均值约 6418 秒，含共享 E20 来源；GPU 共享情况不同，不把墙钟差视为精确的模块耗时。

与完整五分支相位方案的比较表明该固定分组在本组种子上更优，但两组的分支数量与每分支权重不同，不能归因于某个分支。还需要预先冻结的不同接收机划分、标注比例和与 PL 的匹配新种子；目前不宣称普遍优势或创新性。
