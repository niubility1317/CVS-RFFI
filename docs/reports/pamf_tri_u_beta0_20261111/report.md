# 三种子无标签物理方向消融

β=0 对照保留完整 Tri-SIG-TIME SSL、原 U 伪标签与梯度保护、五分支无标签关系和同样的回波探针，但方向距离修正为零。因此本对照的分支关系不使用物理方向；不能把它的性能归因于物理信息。β=0.5 与 β=0 配方、样本选择、种子、训练预算和推理模型相同，均从各自同源 E20 继续到 E50。

Main split 合并 cross_rx 与 cross_both，每种子每场景 168000 包。所有 prediction 冻结后独立评分；逐包检查 seed、physical ID、视图、DURA 缓存和标签映射。历史目标已曝光，结果用于研发分析而非新盲测；普通 PL 的时序和训练机制不同。
