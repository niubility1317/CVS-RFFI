# PAMF 去参考响应后的实验盘点与发布准备

2026-11-09。状态：**盘点与候选矩阵，尚未构成发布、训练或测试。**用户已明确只删除参考响应分支，保留时域、频域、功放及三视图路径描述；三视图不因删除参考响应而删除。沿用当前完整半监督训练方法和固定局部时序重排，不把旧普通伪标签单独冒充完整方法。

本清单覆盖既有 Phase1 论文主比较、数据泛化、结构消融和用户此前提出的时频骨干消融。Phase2／Phase3 的识别器依赖与需要重新冻结的项目单列，不自动停止或重训其他 owner 的工作。旧报告和旧模型均保留原身份。

## 1. 模型和对照如何变化

新 PAMF 保留时域 Sinc／CNN、频域、功放相关分支、三视图路径描述和原联合分类头；删除固定参考模板、相对响应计算、参考投影及对应残差增益。时域中间层及其路径描述仍然存在，因此有标签跨接收机对比、风格扰动、梯度保护、融合对比和接收机外推按原对应配方保留，不能仅因删除参考响应而更换为普通 PL。

删除结构只改变新模型；旧完整模型、旧结果和此前确定的其他独立系统不覆盖。若新版本被当前论文采用，需要披露选择是在已有工程测试结果可见后作出；后续目标预测不再用于调整参数、排序、挑种子或选择性重跑，不能将现有公开设置描述为独立盲选。

## 4. 新结构消融

以自然顺序、无参考响应的三视图 CE 模型为基底，八项为：单视图、去显式时间坐标、去路径描述、去功放分支、矩统计替代、固定局部重排、去整个时域骨干并同时去依赖它的路径描述、去频域骨干。每项三个同种子模型；前两项中只有单视图及去路径描述已有相应无参考条件候选，其他是否有完全匹配记录继续按配置核对。

由于新模型本身已经没有参考分支，“再去参考响应”和“打乱参考模板相位”不适用于新结构；旧实验保留用作新旧结构的参考，不虚构对应新增模型。所有结构消融只报告识别器直接输出。旧的时频设计以有参考响应网络为基底，不能原样发布；将两个时频变体的共同保留分支改为新结构，再做相同配对。

去频域骨干时，需保留原圆对称性标量以及供功放分支使用的频谱统计；现有原生开关会连带改变这些量，不得直接关闭后称仅去频域。去时域骨干时路径描述一同删除，时频融合保持固定输入接口以零占缺失分支；条件差值分别比较新完整结构、仅去路径描述和再去时域。结构删减同时改变容量，结论限结构性能差。

## 5. 测试、结果与复用边界

主报标准六类目标接收机：跨接收机 126000 条、跨日且跨接收机 42000 条／景；另给两组混淆矩阵合并后的 168000 综合。无需新增源接收机单独跨日测试或把它混入综合。十类及不同数据设置使用各自的实际样本数。clean 单列，六种 practical 场景逐景及每 seed 内等权平均；种子内先配对，再汇总均值与样本标准差，负值和非单调保留。Macro-F1 对综合先合并混淆矩阵再计算。

每个新模型全部已声明决策冻结后独立 truth-last 评分。保留 Accuracy、Macro-F1、混淆矩阵及 RX/TX/day 分层；涉及旧模型的差值固定模型 seed、数据与读出。已完成的四种外部对照方法、同合同恢复器及合法缓存按来源和权限复用；恢复器不因 F 改结构而重训。主文需要恢复后系统比较时只为新 F 补匹配读出，结构消融仍只用直接识别。恢复器读取 L 与 L＋U 的权限和跨模型共享情况须显式标注。

新模型选用 E50／11100 更新的候选有 185 个；8 个 E200 架构对比各 10000 更新。候选新增合计 10850 模型轮／2133500 更新，属于模型工作量而不是墙钟或独占 GPU 时间；旧实测不能直接外推为 ETA。任何共享训练前段只能在逐行输入、随机状态、日程及数值行为确实等价后复用，不能从计算可共享推定科学模型数减少。

Phase2／Phase3 中使用旧 PAMF 特征、旧头、旧校准或依赖其输出训练的适配器与判别器，仍属于旧系统，不能静默更换识别器后沿用原性能或阈值；应先做依赖清单，再按各阶段协议登记新校准／测试或必要训练。当前未将这些阶段的重跑数量混入 Phase1 候选矩阵。

## 6. 发布准备与目前缺项

清单尚需：完整核实 12 个候选复用的实际 checkpoint／配置／预测与独立评分；核实 11 契约和缓存来源；实现新结构下的主矩阵及两个时频消融；验证无参考前向、分支真实性、梯度／损失、无标签权限、实际预算和独立评分；按实际代码生成正式唯一 run 矩阵与不可覆盖输出，再执行项目规定的 preflight、发布、启动核验。旧健康任务及其他 owner 不修改、不停止。

此前时频设计仍以有参考结构为基底，只能作为实现与评估参考，不能直接启动。此文件及候选 CSV 不是已完成的发布或执行记录，也没有启动任何新训练、预测或评分。
