# 无标签物理多分支 Tri-SIG-TIME SSL：三种子结果

保持完整三视图 Tri-SIG-TIME SSL 及原伪标签接受规则，利用已接受的源 U 伪标签构造同日跨 RX 同身份正对和同 RX 异身份负对。五个实际分支的距离依据有界时延回波方向进行修正（β=0.5，权重 0.05）；该额外无标签损失进入原有 U 梯度保护。没有读取 U 真值，也没有增加推理头。回波是接收后有限差分代理，不等同真实星地信道。

同种子原始 Tri 源 E20 续训到 E50；Main split 的 cross_rx 与 cross_both 合计为每种子每景 168000 个物理包。三种子预测全部固定后独立评分；逐包核对模型种子、DURA 缓存、视图、ID 和真值。历史目标成绩已暴露，不能称为独立盲测。PL 与本方法的时间排序和训练机制不同，不能把差值归因于单一物理模块。

每个种子的原 REPL 实际曝光 1701000 条 U 样本；额外关系分别选择 852360 条，接受 812496、812087、811093 条，其中分别有 808144、807844、806935 个有效锚点。每个模型额外执行 13320 次无梯度回波探针前向。累计训练墙钟时间三种子均值约 6870 秒，原 Tri 约 5679 秒；不同运行的 GPU 共享和负载不一致，不能据此精确归因单模块耗时。

已在读取本结果前固定并启动 β=0 三种子配对消融，保持其他机制和回波探针成本，用于检验物理方向修正的条件作用。跨 RX 划分、标注比例和额外配对种子尚未完成，暂不宣称创新性或普遍优势。
