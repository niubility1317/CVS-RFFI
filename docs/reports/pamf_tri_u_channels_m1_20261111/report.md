# 单源接收机：无标签信道一致性四组验证

四组均基于完整旧 Tri-SIG-TIME SSL，分别在 U 的五个实际分支上施加频偏、40 ns 弱回波、120 ns 弱回波、频偏加 120 ns 弱回波的一致性；监督目标和默认头不变。每组使用各自种子对应的原单源接收机 E20 继续训练至 E50。

四组均未达到用户要求：相对普通 PL，七景三种子平均全部下降。120 ns 回波组相对原 Tri 在六个 practical 场景平均提高 0.0222 至 0.1435 个百分点，但 clean 下降 0.1141 个百分点；单种子和分层仍有下降，不能称为全面领先。

每个模型续训 30 个 epoch，原无标签路径曝光 1683360 次，接受 1675694 至 1678260 次；新增一致性路径选取 846240 次曝光，接受 842365 至 843642 次（约 99.54% 至 99.69%）。这些是训练中的重复曝光次数，不是唯一物理样本数。每模型新增 13320 次分支前向，原单源接收机条件无法形成跨 RX 正样本对。

未暂停的 10 个续训模型墙钟时间约 4482 至 4647 秒，包含 E20 的累计时间约 5898 至 6088 秒；其余两条因主动避让而暂停，其墙钟时间包含等待，不能当成纯训练成本。不同 GPU 共享条件也使这些时间无法作为严格配对的额外开销。
