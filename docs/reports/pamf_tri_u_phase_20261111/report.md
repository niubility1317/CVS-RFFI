# 无标签公共相位旋转五分支一致性：三种子结果

保留原完整 Tri-SIG-TIME SSL，在已接受的源 U 上，以未旋转分支特征为停止梯度的参考，对每包施加 ±π/8 内公共 IQ 相位旋转，计算时域、频域、PA、路径和参考响应五个分支的余弦一致性，权重 0.05，并纳入原 U 梯度保护。该变换是接收端相位扰动假设，可能影响身份特征；不是已验证星地信道模型。

Main split 的 cross_rx 和 cross_both 合计每种子每景 168000 个物理包；各同 seed 原始 E20 续训至 E50。全部七景 prediction 固定后独立 truth-last 评分；核对种子、物理 ID、DURA 缓存、输入视图及标签。PL 的训练时序与机制不同，不可把差值归因于相位项。历史目标成绩已暴露，不是新盲测。

每种子原 REPL 均曝光 1701000 条 U；相位一致性各选择 852360 条，其中分别接受 813064、812113、811638 条。每模型增加 13320 次分支特征前向；累计训练墙钟时间三种子均值约 6587 秒，含共享 E20 来源。各运行的 GPU 共享情况不一致，不把墙钟差作为精确的模块开销。

相位旋转增强和相位一致性已见于 [BYOL 发射机识别](https://www.mdpi.com/2079-9292/11/21/3485) 和 [PCE-CVNN](https://ieeexplore.ieee.org/abstract/document/11464904/) 等工作；本方案是原 Tri SSL 中的五分支一致性应用，当前成绩不支持声称创新性或普遍优势。未完成额外种子、跨接收机划分和标注比例验证。
