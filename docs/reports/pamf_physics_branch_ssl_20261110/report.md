# PAMF 物理感知多分支半监督：问题、证据与候选

2026-11-10。用户指定的识别器为**含参考响应的旧版完整 PAMF**，包括时域、频域、PA、参考响应和三视图路径描述，原联合分类头保持。目标是研发有物理依据的监督／半监督训练机制，并最终在各设置与原普通 PL 及完整 SSL 比较。本文件是研究设计，不是已验证的性能结论；目前正在运行的四臂仅是多分支关系对照，并非下述物理候选。

## 1. 问题及已有证据

常规分支对比把同类特征拉近、异类拉远，但**没有说明哪些变化来自物理信道、哪些变化可能携带发射机信息**。把同一损失等权套在各分支，不能自动称作物理感知训练。当前正在跑的 `sup_l/pl_l/pl_u/pl_lu` 为后续物理机制提供有价值的基线；它没有显式使用信道参数或物理干预来定义距离。

当前完整骨架原有真实标签跨 RX 对比、同包随机前向一致性、直接星地信道 As CE 和 raw CE；普通 PL 在其上增加源 U 的当前学生伪标签 CE，阈值 0.95、权重 1。它并非完全没有物理增强。因此新方法不能仅因使用信道仿真，就宣称引入了原方法不存在的物理性。

已有 [ChannelPL 三种子正式结果](../../../automation_reports/CV-SincNet/20261025-phase1-PAMF-ChannelPL-m33-r01/report.md)：固定源 F0、168000 目标 RX 样本下，受损 U 视图的剂量重分配使 raw clean 相对普通 PL **−0.1028 pp**、raw 六景均值 **+0.2301 pp**、同 G-LU 六景 **−0.0824 pp**。它使用 raw 与 As 的同类高置信筛选，不能说简单叠加信道一致性已经解决 clean／受损域／恢复域权衡。完整 REPL 复盘中 39 个候选有 26 个提高 raw 六景，但这些候选的同 G 六景均下降；不是每种物理增强都损害恢复视图的定理。[既有完整复盘](../../../automation_reports/CV-SincNet/20261026-analysis-PAMF-SSL-retrospective-r01/report.md)

曾经的[身份保护接收机切向平坦化](E:/type10-7/automation_reports/CV-SincNet/20261014-phase1-identity-tangent-oldgate-e50-clean-manysig-s01-m4-r01/report.md)以真实 L 同 TX/day 跨 RX 的浅／中层统计差构造方向，移除批次 TX 均值子空间后，约束 joint160 的方向响应。固定三种子中，身份保护相对等能量原方向平均 **−0.2502 pp clean**，不能证明这种投影能保护全部身份信息；这是旧网络、旧 U 门控和 clean-only 结果，不是本候选的直接等价对照。[三种子确认](E:/type10-7/automation_reports/CV-SincNet/20261014-phase1-identity-tangent-oldgate-e50-clean-manysig-s0203-m8-r02/report.md)

外部已有射频半监督一致性与伪标签工作，不能把“信道增强＋一致性”当作新概念。[Wang 等，2023](https://arxiv.org/abs/2304.14795) 已组合射频信号增强、一致性与伪标签；[VC-SEI，2024](https://doi.org/10.1109/TWC.2024.3463740) 已研究可变信道下的半监督域适应，但其目标域有标注数据的协议与本项目源域训练不同，不能直接复用该权限。基于已知变换的局部不变性和切向距离早有研究，[Tangent Prop 原论文](https://proceedings.neurips.cc/paper/1991/hash/65658fde58ab3c2b6e5132a39fae7cb9-Abstract.html)可追溯这一思想。2026 年已有题为 [Physics-Constrained Self-Supervised Learning for Few-Shot Channel-Robust Specific Emitter Identification](https://doi.org/10.1109/LCOMM.2026.3744903) 的论文，题名、作者和 DOI 已经 Crossref 出版元数据核验；目前尚未取得可核查的原文，不能断言机制差异或全球首创。

进一步核对原文，[Huang 等，AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/download/37005/40967) 已将物理启发增强、类别／原型对齐和伪标签组合用于射频指纹；其完整方法还利用未标注目标域样本自适应，与本轮仅用源 L/U 训练的权限不同，因此不能把其完整结果直接当作同协议对照。论文也报告仅用源域数据训练的模型，但它使用不同数据与网络，不能据此推断 PAMF 的数值收益。[Pan 等，2025](https://arxiv.org/abs/2412.08885) 使用不同信道估计与均衡得到的残差信道视图做自监督对比，之后在新环境以少量标签微调；这提示参考响应和均衡残差可提供可检验的物理变化线索，同时也说明“残差信道视图＋对比学习”本身已有先例。以上文献不改变已登记的 PTBR 配方，也不授权使用目标样本训练或调参。

## 2. PAMF 的物理信息和不可辨识性

对概念性离散接收链，可写成 `y = R_rx(H * T_tx(s)) + n`，其后还有同步、均衡、裁窗及归一化。实际输入已是接收 IQ；不存在可直接读取的发射机真实波形或目标信道真值。

| 路径 | 可支持的解释 | 不应直接当作 |
|---|---|---|
| 时域与三视图路径 | 波形时序和非线性表征，路径同时依赖时域上游 | 独立于其他路径的五个物理传感器 |
| 频域 | 镜像压缩频谱和统计；可能反映发射端与接收链耦合 | 对任意信道天然不变的纯 TX 频谱 |
| PA 路径 | 局部网络特征及带边能量、频谱再生等统计 | 已校准的发射端 PA 参数 |
| 参考响应 | L-STF 的相对传输／质量／相对 CFO 描述；归去一个复数标量 | 分离后的 TX 硬件响应、绝对 CFO 或任意 FIR 不变量 |

代码中参考响应选用窗口 `[80,160)`、20 采样周期、12 个占用频点，输出相对频率响应、相关质量、相干性和相对 CFO；其固定接收机／信道混杂边界见 [`response_contract`](../../../experiments/cvs_reference_identity/model.py)。代码中的 PA `pa_local` 为 `pa_proj + 0.25 * pa_delta`，其中统计包括带边比、频谱再生比和频谱峰度。当前 prototype 已按该真实路径修正。

真实与合成信号中，接收机、信道和发射机的影响会重叠。项目合成级联诊断给出相同波形可由 TX 侧或 RX 侧某些图像／三次失真生成的反例；这限制任何仅从单个接收包声称恢复物理真值的说法。[受控级联代码](../../../experiments/cvs_reference_identity/physics.py) [项目结构实验的物理声明边界](../../../experiments/cric_dura_comparison/final_results.py)

原始全量源 L/V 已知激励诊断还发现，80:160 窗口的模板相关在 V 的源 RX1 均值约 0.9983，而源 RX3 约 0.7870、RX8 约 0.8010。这里的 RX 分组同时包含接收链与传播差异，不能仅归因于接收机硬件；但它提醒我们：参考路径的可靠度可能有很强的域差，不能假定每个包的参考响应都同样可信。[原始源域全量诊断](E:/type10-7/automation_reports/CV-SincNet/20261002-diagnostic-rff-known-excitation-source-manysig-m1-r01/report.md) 因此新源诊断按 RX/day/TX 报告参考质量、周期相干性与延迟格点变化，而不预先按单个阈值丢弃这些组。

文献中频谱再生与 PA 非线性相关，但 CFO 随时间变化且含收发机相对项；该论文将 CFO 作为辅助而非单独永久身份特征。[Xie 等，2024/2025](https://arxiv.org/abs/2412.07269) 因此不能把人为改变 PA 的增强一律标为身份不变，也不能把所有 CFO 变化都当作纯噪声抹去。

项目曾在五个源留出 RX、冻结识别器上比较普通增强含／不含额外 PA 作用；去掉这一额外作用后准确率平均高约 0.6002 pp，但两种增强均明显低于 raw。该实验是冻结头输入效应，不能直接推断新网络训练效果或判定所有 PA 扰动无效；它进一步说明随意把接收 IQ 的非线性变化当作身份保持增强存在风险。[源 PA 输入诊断](E:/type10-7/automation_reports/CV-SincNet/20261016-diagnostic-ordinary-PA-heldsource-manysig-s2026092701-m5-r01/report.md)

## 3. 候选：物理干预方向校正的分支关系

暂名 **PAMF-PTBR**（Physical-Tangent Branch Relations，物理干预方向校正的分支关系）。核心假设是：对同一个源 IQ 包施加**参数已知、受限**的传播扰动，可在每个实际分支中观测局部变化方向；跨 RX 身份比较时只部分减弱沿这些方向的距离，而不是要求整个分支输出完全不变。真正能否泛化、是否保护身份，必须由源域证伪与独立测试判断。

### 3.1 已知物理干预及精确边界

首个可检验版本使用接收 IQ 上的短时、无噪声单回波代理：

`(T_{c,d} x)[n] = x[n] + c x[n-d]`；越界的延迟项补零，`d ∈ {1,2,3}`，`|c| ≤ 0.1`，复相位由固定源随机流产生。

该式对应一个有界两径线性响应。因零填充延迟算子 `S_d` 满足 `||S_d||₂ ≤ 1`，故 `||T x||₂ ≥ (1-|c|)||x||₂`；在无噪、无限精度模型中 `|c|<1` 时该有限长度算子可逆。这只证明**所施加的数学变换有界且不直接删除整个输入信息**，不证明网络利用的信息不受损、真实设备身份不变、或该操作等于真实卫星链路。实际操作发生在已经接收和处理过的 IQ 上，RX 非线性／同步／噪声使其不能与“真实 TX 后、RX 前的物理信道”无条件交换。

首轮不合成额外 PA 非线性，也不把改变发射机 PA、载频或 IQ 镜像一律当作正样本。原监督路径的原 As 和完整 PL 原样保留。更复杂的 [`ResidualChannel`](../../../code/leo_practical/residual.py) 可作为**源域独立压力诊断**：它包含传播核、残余频移、接收机镜像、噪声与 AGC，不应把受损输出中估计的频谱差直接称为已知纯信道或真实硬件差。

### 3.2 在实际分支内计算有限差分方向

对真实部署分支 `b`，训练当前样本的单位向量 `z_i^b = normalize(f_b(x_i))`；另以相同冻结当前模型的 **eval 模式、no-grad** 对同一个 `x_i` 和 `T_i x_i` 各做一次前向，得到 `u_i^b = stopgrad(normalize(f_b(T_i x_i)) - normalize(f_b(x_i)))`，非零时归一化。eval 模式是为了避免两次 dropout 差异伪装成物理效应；必须恢复原模块训练状态并隔离 RNG。该方向是**经验有限差分**，不是严格导数、也不是可辨识的真实信道子空间。

对 L 的 64 条和 U 中按独立固定源 RNG 抽取的最多 128 条产生辅助物理前向；U 的候选抽样先于且独立于伪标签接收，只有候选中被原 PL 门控接收的样本参与关系损失。这样 β=0 与 β=0.5 在相同输入批次下使用相同物理候选和前向包次，即使两模型后期接收集合不同。保留所有样本原有 CE/PL 剂量，附加关系项使用其自身有效锚点归一化。无额外推理参数或部署前向，训练有额外两次无梯度前向，实际耗时与显存必须测量。

对一对特征 `δ_ij = z_i^b - z_j^b`，定义软方向校正距离：

`D_b(i,j) = ||δ_ij||² - β/2 · [(δ_ij·û_i^b)² + (δ_ij·û_j^b)²]`。

`û` 是单位有限差分，近零方向取零；`β ∈ [0,1]`。因此 `0 ≤ D_b(i,j) ≤ ||δ_ij||²`；β 只在**训练时的对比距离**中部分减弱局部方向，不删除网络分支、修改原 CE 或把整个特征投影到单一子空间。`β=0` 是必须同前向、同采样、同关系掩码、同预算的关键控制。比较关系时正负都用同一个公式；该分数因每对使用不同方向，未必满足三角不等式，不能称为严格全局度量。

参考响应包含离散延迟 `argmax`，输入微扰可能使选中的格点跳变。因此该分支的有限差分可能不光反映平滑信道变化，也包含路由跳变；必须统计源样本参考延迟格点变化率和方向范数，不能把它称为精确切空间导数。当前只在真实完整网络的随机 IQ CPU 接线中捕获了五个分支、232993 个部署参数；随机 IQ 不代表真实 L-STF，也不能用其方向幅度推断真实信道效应。

L 正对采用同真 TX、同 day、不同源 RX 的不同物理记录；负对采用不同真 TX、同 day、同 RX。U 对应使用原学生 `p≥0.95` 的伪身份，不读取 U TX 真值；错误伪标签仍会污染正负对。多个 RX 且缺合法正负对时跳过该锚点；单源 RX 则退化为同 RX/day、同类不同记录的正对，只能称为单 RX 身份关系，不能冒称跨 RX。

每个分支分别计算这些距离的 supervised contrastive loss，平均后用小权重加入完整 L 目标与原 PL 目标。先分别验证 `L only`、`U only`、`L+U`，不能用某一个结果取代另一个。拟固定 β 为 0 和 0.5 的等量比较；权重、源记录采样、是否同 RX/day 配对及全部对照在首次新预测前固定，而不是根据已暴露目标分数调整。

### 3.3 该方法相对现有工作的真实差别

- 相对当前四臂：当前使用常规跨 RX 特征关系；PTBR 的距离额外依赖同一包已知两径干预的实际分支响应，且要控制 RX/day 的正负对。
- 相对 ChannelPL：原方法在受损视图重分配伪标签 CE；PTBR 保留原 raw PL 剂量，改变 L/U **分支关系比较的局部方向权重**。两者都基于物理扰动，不能简单宣称一般性的“首次物理半监督”。
- 相对旧接收机切向平坦化：旧方法用同 TX/day 不同真实 RX 的特征统计方向、TX 子空间正交投影，并惩罚 joint160 响应；PTBR 使用同包已知线性回波有限差分，在各真实分支的成对距离中做软校正，不使用旧的身份子空间投影。但两者同属局部不变性思路，旧负结果提高了本方案的失败风险。
- 与半监督切向学习／物理约束已有文献有概念重叠。当前只可称“针对 PAMF 与源域协议的候选组合”，不能声称论文级首创；需取得最近相似论文全文并继续核对。

## 4. 关键风险、对照和验收

1. **身份方向混入干预方向。** 信道和 TX 的作用非可辨识，软校正也可能降低有用区分度。必须记录各分支方向幅度、类间方向重叠、正负距离、有效锚点和梯度范数；β=0 同计算对照不可省略，不能因公式可逆就认定效果安全。
2. **分支不独立。** 时间和路径共享上游，参考响应与频域也同源；分别相加可能重复施压。报告每条实际分支项和共享参数梯度，不把多数分支一致当独立证据。
3. **困难 U 和错误伪标签。** 原 0.95 接收池偏容易，未接受池不能被自动认定为已知真类。源 V 的标签只用于独立、只读质量诊断，不能用于训练样本配对或 U 伪标签回填。统计接收覆盖、伪标签代理正确／错误、按类/RX/day 的正负对、跨物理视图翻转，以及困难池占比。
4. **弱代理与真实场景差异。** 对两径训练变换之外，在 L/V 只读评估原真实来源 As 的三个信道场景，分别报告 clean、扰动正确率和同包翻转；不能把代理算子结果说成完整星地链路。受损测量可用于淘汰，但不能以源 V 证明未见 RX 测试必然增益。
5. **边界情况。** 检查空 accepted、单类批次、单源 RX、零输入／零方向、短末批、有限梯度、真实完整 PAMF 五个分支、默认头及按条件输出、随机流恢复。最小代码负例与真实 E20 源数据／权重无查询 forward/backward smoke 先于真实运行。

**尚未测得的因果证据：** 当前常规分支 pilot 的日志可验证关系项与有效锚点确实参与训练，也有整体梯度统计，但没有逐分支、逐损失的梯度范数与夹角；物理 probe 目前测的是分支输入扰动响应与类中心重叠，也不是这些反向梯度。因此目前不能证明纯 CE 没有充分优化某个分支、普通 PL 导致梯度冲突，或某个分支是目标表现变化的原因。后续若开展源域只读梯度诊断，需要在同一批包上拆分真实标签 CE、原 PL 和各分支关系项，分别测共享参数与分支参数上的梯度大小、方向与有效样本数，并保持归一化和损失系数清楚；这仍只能支持局部优化机制分析，不能独自证明泛化收益。

为初步检查这个假设，已对固定 F21 原普通 PL 模型做一次**源 V 只读梯度探针**：在每个源 TX×RX×day 单元取前 8 包，共 720 包，对同一 raw 输入和同一 eval 前向分别计算真实标签 hard CE 与门槛 0.95 的伪标签 CE，两者都按全部 720 包归一化。V 仅用于诊断，模型没有更新，也未读取 U 或目标数据；此处 PL 是使用 V 模拟的局部梯度，不是实际 U 训练的 train 模式梯度，真实监督原配方还包含数据增强、标签平滑和其他损失。

720 包中，688 包被置信门槛接受，其中 3 包伪标签与 V 真值不一致；32 包未接受。按实际参数组汇总后，真实 CE 与伪标签 CE 的梯度余弦：时域投影 +0.073、频域主投影 −0.125、PA 主投影 −0.397、路径描述 −0.249、参考响应投影 −0.399、共享时域中层 `t2` −0.188。参考响应组的真实 CE 梯度范数为 0.1014、伪标签 CE 为 0.0232；被拒绝包的真实 CE 梯度分量范数为 0.0630。真实 CE 与“仅接受包的真实 CE”余弦为 +0.794，而与“仅接受且伪标签正确的 PL 分量”余弦为 −0.281；这表明样本筛选、权重和少数错误标签都可能影响总体方向，不能只将差异归咎于那 3 个错标签。范数来自不同参数组，不能直接跨组当作贡献排名；组间也可能共享上游。

以上只是固定模型、一个有目的的源域分层子集与单次 raw 局部计算，既不证明训练全过程存在梯度冲突，也不证明哪些干预能提高目标性能。[诊断脚本](../../../experiments/pamf_physics_branch/source_gradient_probe.py)已纳入版本管理；含各梯度分量的完整结果保存在本机 `E:/type10-7/local_artifacts/pamf_branch_training_20261110/source_gradient_probe_decomposed.json`。逐分支关系项与完整 L 多视图梯度尚未测量。
