# CVS 基础身份网络：纯 CE、无增强、clean 测试

## 目标与判定

用户目标是凭借神经网络结构改善 CVS 身份识别，并保持轻量化；不能将旧实验的星地增强收益、额外损失、更多优化步或参数堆叠解释为结构收益。本轮固定 ManySig 物理划分，仅 6300 条有标签源样本参与梯度训练，56700 条 U 不使用，27000 条单一 V 只评估。原 CVS、CVCNN、普通 real CNN、轻量 ResNet1D 均重新从零训练，无任何数据/信道增强。

8 架构×4 模型 seed，共 32 个源训练 row；每 row 均 200 轮、每轮 50 步，AdamW lr=2e-4、wd=1e-4、cosine eta_min=1e-6、FP32、不裁剪梯度。固定 E200 权重，保持各架构原生分类头，CVS cosine scale=30 不启用标签 margin。数据加载器使用独立 seed，跨架构匹配批次顺序；原网络自身 dropout 是保留的结构组成，不生成新输入样本。

只依据四 seed 的最终源 V 选择一个 CVS 候选，之后冻结并仅测试该候选及四个固定基线，共 20 个 clean 测试 row。其他候选不接触目标数据、真值或分数。主指标为四 seed clean 准确率、Macro-F1、逐接收机结果及配对百分点差值。目标尚未证明完成，只有冻结候选 clean 结果优于原 CVS 及常见网络对照、资源成本符合轻量化要求，才能声称本次优化成功；源 V 提高不能代替目标 clean 提高。

## 观测模型与可辨识性

采用项目模型：x=R_d(H_d*T_y(s))+n。TX 硬件失真与信道、接收链偏移叠加。IQ 失衡可表示为 a z+b z*，PA 常用奇数阶记忆多项式表示 Σ a_(p,m) z[n-m]|z[n-m]|^(p-1)。这些是启发网络的局部近似，不证明对任意多径、接收机非线性可恢复唯一 TX 指纹。单一收到的波形一般不具有这种无条件可辨识性。

绝对幅度、载波相位、频偏并不全部稳定地代表发射机身份。相位旋转的不变性只针对 x→exp(jθ)x；它不等于频偏不变性、任意信道不变性或接收机 IQ 失衡不变性。尤其不贸然完全移除频偏或 IQ 信息，否则也可能删除真实硬件差异。

## 数学与物理改进

### PA 多项式正交基底

原 CVS 的 PA 分支直接展开 z、z|z|²、z|z|⁴ 及其延迟。对有限包，它们可能强相关，使后续线性层同时拟合相似方向；这属于条件数问题，尚未通过本数据实测证明为性能根因。

候选在包内对奇数阶基底按 Hermitian 内积做 Gram-Schmidt，得到 b1、b3、b5，再以包内 RMS 归一化，每阶有 1e-4 能量地板以限制退化方向放大。前三阶基底仍是同一包的确定性函数，不增加样本、不增加 loss，也不拟合 query 集体统计。为保持幅度/相位物理一致性，原 I/Q 分量分别截断改为径向幅度截断；这与正交化、归一化一起构成 PA 前端改动，不能把效果只归因于正交化。

由于每阶基底在全局旋转后均乘同一个 exp(jθ)，包内内积及 RMS 不变，因此该 PA 组件具有相位等变性。原 CVS 的其余层并非严格等变，不将组件性质外推为整网性质。保留 4 个记忆延迟、3 个奇数阶，输入输出通道布局与原 PA 卷积完全一致，无新增参数。近似退化包和零输入必须有限值；正交性与梯度在测试中核实。

### 均值与波动池化

全局均值可能隐藏同均值、不同波动强度的局部失真。候选用 μ+tanh(a)σ 代替三个分支的全局均值，输出形状保持不变，a 每通道一个参数并初始化为零，初始输出等于原平均池化。归一化后波动可能承载调幅/调相、非线性和局部纹理信息；也可能承载噪声及接收机偏移，必须通过源验证和冻结 clean 测试确认。

这里只增加 192 个参数，没有扩大投影层和分类头。分别测试正交 PA、波动池化及二者结合，区分单独和交互效应。单一 V 的 RX 指标只是评估分层，不把 V 改成多套训练或选模角色。

### 复数共享轻量骨干

第二条路线用同一组正交 PA 基底进入共享复数骨干，复杂卷积采用深度时间滤波＋点混合，减少重复分支计算。复数线性操作保留 I/Q 联合几何；非线性通过径向门控作用，包内能量归一化不使用跨包状态。readout 使用幅度均值/标准差、两个时间 lag 的 z[n]conj(z[n-k])、相邻通道复数协方差。它保留相对相位及局部相关，而在常数全局相位旋转下不变。

深度分离约束减少可学习自由度，是可能影响容量的结构假设；不能预告一定改善性能。Lag readout 不消除线性相位斜坡，不能宣称去除了 CFO。该网参数 168682，约为原 CVS 的 44.14%，但卷积实调用、FFT、激活、Python 调度都会影响时间，必须实际测量。

## 基线、消融与轻量化

| 架构 | 参数量 | 用途 |
|---|---:|---|
| 原 CVS 身份网络 | 382146 | 同条件直接基线 |
| CVCNN | 104646 | 复数卷积常见基线 |
| Real CNN | 174726 | I/Q 双通道实数卷积基线 |
| ResNet1D | 167814 | 6 个 basic residual block，宽度 32/64/96；不是作者原版 ResNet18 |
| 正交 PA | 382146 | PA 前端改动 |
| 波动池化 | 382338 | 平均/波动信息消融 |
| 正交 PA＋波动池化 | 382338 | 联合结构 |
| 复数共享骨干 | 168682 | 更小的物理表征路线 |

本轮将“轻约束”解释为候选参数不超过原 CVS 的 1.1 倍，不设额外性能启停门槛；所有候选均满足。最终同时报告总参数、实际 CE 梯度涉及参数、卷积/矩阵乘 MAC、FFT 调用、batch=1/128 推理时间、batch=128 训练时间、实际训练峰值显存、模型常驻状态字节。MAC 不包含 FFT、归一化、基底和元素运算，明确标口径。性能差别包括原生分类头，不能声称只比较单一卷积层。

每 row 的资源 benchmark 使用训练完成模型的独立复制品及随机合成输入；对复制品的 BN/优化器更新不回写正式权重，也不参与预测、选模或源训练。常驻双模型的 benchmark 峰值与真实源训练峰值分开报告。

## 选择、测试与风险边界

候选选择分数为四 seed 平均的 0.5×最终 V 准确率＋0.5×最差源 RX 准确率。与最高分相差不超过 0.2 个百分点时，优先卷积/矩阵 MAC 更少，其次参数更少，最后架构名确定性打破并列。四个固定基线不参加“优化候选”竞争，均保留后续 clean 测试。规则在目标预测前写入代码、预登记和 source_selection.json。

已公开旧目标 benchmark，后续结果披露为固定配置研究；不冒称未见盲测。禁止用 clean 分数选择另一个已训练候选、换 seed、重跑、改变架构或超参数。目标预测只读固定 clean.npy 与 opaque ID；完成全部固定预测后，由独立 scorer 连接 truth。源筛选版本不包含目标路径，不测 satellite，也不启动 Phase2。

若最终未提高，保留负结果；当前目标仍未实现。进一步研发须使用合法源证据，不将这个目标分数反馈为改动依据。PA 残差可能放大噪声，波动池化可能过度关注接收机，强不变性可能移除身份信息，深度分离可能欠拟合；这些都是需实验检验的假设。

## 原始研究依据

- [Gopalakrishnan et al., Robust Wireless Fingerprinting via Complex-Valued Neural Networks](https://arxiv.org/abs/1905.09388)：复基带监督指纹识别，以及网络可能利用报文身份捷径。本文不采用论文噪声增强。
- [Chen et al., An Analysis of Complex-Valued CNNs for RF Data-Driven Wireless Device Classification](https://arxiv.org/abs/2202.09777)：在 LoRa/WiFi 上分析 I/Q 联合结构；不能把其跨数据结果直接作为本任务的效果证明。
- [Ravanelli and Bengio, Speaker Recognition from Raw Waveform with SincNet](https://arxiv.org/abs/1808.00158)：少量截止频率参数生成带通滤波器的结构先验。原 CVS 保留已有 Sinc 前端；此文属于语音研究，不是射频效果证据。
- [Zhang et al., Radio Frequency Fingerprint Identification for Narrowband Systems, Modelling and Classification](https://pure.qub.ac.uk/files/240303245/tifs_2021_RFFI_narrowband.pdf)：发射/接收链硬件建模；本次只能检索摘要，PDF 正文读取受限，不将未读正文细节作为结论。
- [Li et al., Radio Frequency Fingerprinting Exploiting Non-Linear Memory Effect](https://www.research.ed.ac.uk/files/301504867/Radio_Frequency_Fingerprinting_Exploiting_Non_Linear_Memory_Effect.pdf)：PA 非线性记忆指纹研究；PDF 正文读取受限，引用限于检索摘要所述研究主题。

所有本轮结构改动是基于上述物理模型和数学性质提出的本项目假设，需本次 matched 实验验证，不声称来自文献的既有准确率可迁移。
