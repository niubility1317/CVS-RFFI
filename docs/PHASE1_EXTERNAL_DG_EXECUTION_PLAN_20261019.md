# Phase1 非 PAMF 对比实验执行设计

日期：2026-10-19。用户目标：继续完善设计并完成对比实验，排除 PAMF。继承三模型种子、至多两张 GPU、各领域方法原生预算、RIEI／DRIFT E100 和默认分类头联合训练约束。

本轮不训练或评估任何 PAMF 配置。旧 run 名称中含 PAMF 的24行队列，实际行只有RIEI／DRIFT／IB-RFF／SDG的full与自身CE，不包含PAMF模型；该队列按原注册继续。完整范围为**24个既有训练实例＋162个新增训练实例＋6个历史冻结模型补测实例**。各组原始分数、负结果和失败产物均保留。


## 论文设计摘要：先固定要证明什么

本设计服务于“有限标注源域监督下的跨接收机识别”，Phase1 是闭集、零目标适应：源与目标共享注册 TX，接收机集合互斥；目标 IQ、目标标签及目标成绩均不参与训练、选模或超参数选择。纯 CE 网络也在执行域泛化任务；是否使用额外 DG 损失，是训练方法的差异，不能用来定义任务资格。

论文把三种证据分开。第一，已有同配方纯 CE 网络比较检验整体架构竞争力；第二，本设计的领域方法比较检验完整公开流程在统一数据权限下的表现；第三，full−自身 CE 和同 ResNet-18 机制组检验额外训练机制的条件净收益。不同骨干之间的分数差不能单独归因于 DG 损失，公开作者全监督协议的分数也不能与本项目弱标注分数直接排名。

### C. 纯 CE 高于完整 DG 时的预先解释规则

对任一预登记方法 M，定义同 seed、同组合、同视图的差值 Δ_M=A(M-full)−A(M-CE)。主表始终同时保留两行，不在目标评分后选择每个场景更好的分支组成“最佳方法”。

- Δ_M 为负且没有确定实现错误：如实报告额外机制在当前设置下没有带来净收益；不为了恢复预期排名调低 CE 的预算、删除 CE、改测试集合或重调 full。
- PAMF 只超过 M-full、没有超过 M-CE：证据只支持超过该完整流程，不能支持超过其更强监督骨干。
- PAMF 超过 full 与 CE：在匹配的数据和测试条件下支持整体架构竞争力；跨骨干差异仍不能单独证明某项物理机制或 DG 损失的因果作用。
- full 在 clean 较弱、部分 practical 较强：报告准确率与压力鲁棒性的条件取舍，逐场景保留，不用事后综合权重掩盖负结果。

ERM 很强并不违背域泛化研究的任务定义。DomainBed 对架构、模型选择及比较条件的分析，是保留强 CE 的方法学依据。[原论文](https://arxiv.org/abs/2007.01434) 本项目是否存在机制收益，仍由冻结后的配对结果决定。

## 0 研究问题与证据结构

本次工作补齐外部对比和协议稳健性证据。PAMF已有架构实验独立保留，当前不重训、不补测PAMF，也不将其他骨干上的机制结果归因到PAMF。最终论文可以并列展示已有架构表和本次外部方法表，但只有数据、种子、视图与训练权限匹配的行才能直接比较。

| 研究问题 | 固定比较 | 为什么需要 |
|---|---|---|
| 完整领域方法是否有竞争力 | RIEI、DRIFT、IB-RFF、SDG及各自CE | 比较完整训练流程，也保留每个方法更强的可能基线 |
| 额外DG机制是否带来净收益 | 同方法、同seed、同划分的full−CE | 避免把骨干差异误当作DG机制贡献 |
| 排名是否依赖某组接收机 | F0／F1／F2各5源→7目标 | 检查接收机组合敏感性，避免只依赖一次划分 |
| 多源收益是否只是标签变多 | 1／3／5源RX，自然标签量和固定1260标签 | 分离源多样性与数据规模的作用 |
| 通用DG是否有条件收益 | 同一ResNet-18上的ERM、两种MixStyle、Fishr、source-CORAL | 在固定骨干、更新数、采样和优化设置下研究机制 |
| 能否保持跨日期稳定性 | 已见／未见日期分层，加D0至D2训练→D3测试 | 区分跨RX与跨RX＋日期；另测已见RX上的日期变化 |
| 是否仅适用于当前小规模任务 | 1%／5%标签和ManyRx 10类、16源→16目标 | 研究低标签敏感性及更多接收机条件下的适用范围 |

保留强CE／ERM是实验解释的需要。DomainBed说明模型选择和实验条件会影响DG排名；本项目不能因某方法CE更强而删去它。[DomainBed原论文](https://arxiv.org/abs/2007.01434)

所有比较均为源域训练、冻结后逐样本推理的闭集识别；U_s的TX标签隐藏，本轮不使用U_s。训练不叠加本项目星地信道增强，SDG保留其方法本身的原生增强。域泛化是训练／测试任务设置，不等于每个模型都必须使用额外DG损失。

|---|---|---|---|
| RIEI-FD-full／CE | E100；batch64；SGD1e-4、momentum0、恒定LR；full权重1.2／1.2 | 固定E100末轮 | SPAWC2023机制、项目short_stem1d输入适配；总轮数为用户设定 |

RIEI／DRIFT公开材料未给出可直接采用的总训练轮数，故E100明确标为用户指定实现预算，不写成论文推荐。此前200轮实现如有按epoch触发的日程按0.5比例调整；当前两者LR恒定、机制无分段epoch启用，实际不存在需移动的milestone。RIEI会议版与扩展版分开标注。[RIEI扩展版供版本辨别](https://arxiv.org/abs/2411.03636)、[DRIFT v2公式及设置](https://arxiv.org/html/2510.09405v2)

CE对照保留同一身份骨干和默认分类头，删除该方法特有的训练分支／损失／增强；不是把loss设零却继续执行昂贵分支。SDG的full−CE因此代表原生增强与对比学习的组合净效果，不独立归因于某一项损失。IB两侧相同早停规则仍可能产生不同实际轮数；四方法之间也不是等GPU时间比较。实际阶段轮数、每优化器更新、样本曝光、多视图前向、GPU秒及峰值显存分别列出，不能将IB的200＋200隐藏成E200。

ResNet-18标签量组采用历史CE的E200／batch128／AdamW2e-4、wd1e-4、cosine至1e-6，固定末轮。其更新数随L_s数量变化，不称等计算量。

通用DG组采用同一ResNet-18原线性头，5000更新／batch150／TX与RX均衡有放回采样／AdamW2e-4、wd1e-4。全部路线在1500步执行相同优化器重置，LR按全局更新步数推进；Fishr从该处启用λ1000，EMA0.95。V仅诊断，不据target调整强度。

MixStyle保留均值／标准差混合与p0.5、Beta(0.1,0.1)，在ResNet实际stage1／stage2末端插入。非ID版明确名为MixStyle-crossRX：按不同源RX随机选择统计量伙伴；ID版额外要求同TX。这里跨RX配对是已披露的多源实现选择，不冒充作者默认任意随机置换。推理禁用混合，无新增部署参数。

Fishr对默认线性身份头的每样本CE梯度匹配源RX内中心化方差。线性头梯度使用精确解析式，并已与逐样本autograd核对；EMA采用作者1/(1−γ)校正，旧EMA停止梯度。该惩罚反传真实骨干，不拟合新头。[Fishr／DomainBed实现依据](https://github.com/facebookresearch/DomainBed/blob/main/domainbed/algorithms.py)

CORAL只对源RX的身份表征均值和协方差进行对齐，不访问目标。协方差距离按4d²归一化；与原域适应方法的权限差异单列。

本组5000更新和统一AdamW配置是项目的固定控制实验，不能冒称所有通用方法在RFFI上的论文最优参数。MixStyle配置依据[作者代码](https://github.com/KaiyangZhou/mixstyle-release)；Fishr研究对象依据[ICML2022原论文](https://proceedings.mlr.press/v162/rame22a.html)。当前只测试预固定公开强度，不声明各方法已经充分调优；后续源域超参搜索属于另组研究，不能利用本组目标成绩修改当前配置。

## 4 数据复用与七视图

既有F0的L_s／V缓存和VALIDATED_ONCE七视图直接复用。新RX组合需要之前未生成的接收记录，构建一个共享ManySig观测存储：原有168000个ID的clean及六practical逐值复制，新出现的120000个ID才生成观测。所有fold中相同物理ID继续共享相同received IQ。ManyRx只为16个目标RX的实际123021包生成一次观测。

共享存储本身不声称源／目标互斥；每个实验契约的wrapper选择明确物理ID并一次验证其与本契约全部源角色互斥，再标VALIDATED_ONCE。后续方法复用wrapper，不重复数据验证。源训练进程只接收L_s／V缓存，不接收原pickle、目标IQ或truth路径。

六practical沿用既有冻结参数、seed392005、receiver seed2027、同一realization namespace和session。CPU生成至多4个worker，数学库每进程2线程，不占GPU。源码和配置先Git固定后再发布，禁止远端临时修改代码。

新增观测绑定原不可变发布的信道引擎7669a6de，而非当前工作区可能变化的实现。六场景分别为practical_high、practical_mid、practical_low_suburban、practical_high_urban、practical_mid_urban、practical_low_urban。它们是同一物理包的配对压力观测，七视图不能累计为七倍独立样本。WiSig输入已经equalized，叠加的六场景不构成真实在轨、完整原始链路或独立城区采集证据。

每row的全部预登记预测完成并固定后，独立CPU scorer才连接truth。chrono两个评估任务均预测完整后再评分。历史六practical补测以该六视图为本次范围，旧clean结果引用原产物，不追溯改写旧实验。

## 6 完成标准

每个训练实例必须有源配置／数据契约／默认头checkpoint／冻结依据／全部预登记视图预测／独立评分。按实际源RX、日期、TX、视图与seed分层报告Accuracy、Macro-F1、最差RX、full−CE配对差和训练／推理成本。六个冻结补测checkpoint还必须确认历史scratch来源、物理角色一致和默认头身份。

三seed均值／SD不冒充独立接收机统计；168000或123021个包不是同数量独立训练重复。所有负结果和未完成项保留。完成审计必须覆盖既有24行、162个新增训练和6个补测实例；只完成任一组都不能把整个目标标完成。

主指标为clean等权目标RX准确率：先算每个RX准确率，再取RX平均。ManySig均衡时它与总体包准确率相等，ManyRx不均衡时二者必须区分。共同报告Macro-F1（全部注册类）、每seed最差RX、源已见／未见日期、RX×日期及每TX召回／精确率。压力结果列全六场景、场景等权均值及相对同seed clean的百分点下降，不事后加权掩盖退化。

配对差定义为同seed、同fold、同视图的Δ=A_full−A_CE，报告三个原始差值、均值、样本SD和正差seed数。三个seed即使全同号，双侧精确符号翻转检验最小p=2/8=0.25；不能声称p<0.05。跨fold共享记录、包级大样本和多视图均不增加独立训练次数。结果以效应量和分层一致性为主，不用包级置信区间制造过窄误差。

| 观察结果 | 允许结论 | 后续处理 |
|---|---|---|
| full稳定高于自身CE | 在当前数据、预算和完整训练流程下有正净收益 | 保留效应大小和不一致场景，不推出普遍有效 |
| full低于自身CE，且无确定实现错误 | 当前设置下额外机制没有收益，可能有负作用 | 保留CE和full；不得为了排名修改目标驱动的权重 |
| 本文模型只超过full、未超过该方法CE | 未超过该骨干更强的监督基线 | 主表保留更强CE，收缩领先主张 |
| 自然标签预算随m上升，固定标签预算不升 | 收益可能主要来自数据量 | 不归因于源接收机多样性 |
| clean提升、某practical退化 | 存在条件取舍 | 分场景报告，不宣称全面鲁棒 |

只有确定的公式、梯度、数据或程序错误才进入技术修复；低分本身不是实现错误。当前基准有历史目标成绩暴露，完整固定后续矩阵有助于约束反馈，不能使其重新成为独立盲测。高水平期刊需要方法新意和可复核证据；本设计提高结论可信度，不保证分区或录用。
