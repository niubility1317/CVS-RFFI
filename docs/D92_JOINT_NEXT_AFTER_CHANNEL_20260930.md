# JointChannel 之后：原型条件化的 LocalRidge 联合适配

状态：DESIGN_ONLY_NOT_FROZEN_NOT_RUN。唯一候选暂称 **PrototypeTransport-LocalRidge**：以当前目标 support 的类原型确定局部竞争关系，监督学习 9 个有效共享参数，产生分支特征的有界切向旋转；保留半份原 interaction 特征，LocalRidge 仍是唯一最终分类器。本文不实现、不扫参、不注册或启动实验，所有收益均待完整 support 验证。

## 1. 为什么换结构

[完整通道复盘](D92_JOINT_CHANNEL_SUPPORT_LESSONS_20260930.md)显示，936 个阶段全部更新、7488 步全部非零；C 新类 winner 改变约 6.10%，但正确/错误转换近乎抵消，净增益仅 0.0625 pp。K5 旧类适应为负，Nnew=2 的 K5/K20 新类退化，平均绝对新旧差距扩大。因而不能再以“更新幅度不足”为主要理由延长相同门控训练。

当前 731 维门控对所有样本使用同一坐标伸缩，没有直接表示局部哪两类在竞争。下一假设是：用类原型约束变形方向、用少量参数控制其作用，比让每个缓存坐标自由改变更有机会在小 K 下泛化。原型也会有噪声，最近原型可能认错类别；本方案不假设这一机制已经有效。它尤其可能把错误邻域进一步拉紧，必须保留原几何并记录这种失败。

与过去失败的区别不在 rank、步数或学习率：没有自由 CE logits，没有受保护旧均值 span 的单纯谱收缩，也没有继续训练 731 个对角权重。实际 SFT 参数位于一个样本条件化的特征 adapter 内，梯度穿过 LocalRidge 闭式头。Phase1 encoder/BN、practical residual 数据和原特征缓存固定；本候选只使用合法目标 support，不使用地面原型、源样本或逐样本源特征，故不引入未核实的源状态。

## 2. 折内原型与局部类关系

沿用原方法一次构造的 b0∈R²⁵⁶、a0∈R⁴⁸⁰。切成五个子块 r_l：b_z/b_fft/a_t/a_f/a_pa，维数 160/96/160/160/160；权重 4、辅助缩放和 floor 已包含其中，不再次归一化成原始输入。定义 ρ_l(x)=||r_l(x)||，非零时 w_l(x)=r_l(x)/ρ_l(x)，零块的 w=0。

对某一合法训练集合 T、每个注册类 c，计算两组目标原型：

`p_cl = mean_{i∈T,y_i=c} r_l(x_i)`；

`m_cl = mean_{i∈T,y_i=c} w_l(x_i)`。

p 保留原分支能量用于距离，m 是单位方向的均值、范数不超过 1，用于切向方向。二者均只由该次头的 train support 构建。没有每类可学习向量、伪样本或 class-specific logit 参数。

对任一样本 x，计算 `d_cl(x)=||r_l(x)−p_cl||²`，`D_c^0(x)=Σ_l d_cl(x)`。令 J(x) 包含按 D⁰ 排序的前两个类；若第二个距离有并列，包含全部并列类。这个邻域按原特征固定，在本次训练的各次参数更新中不改变。它不看 x 的标签；类重命名不改变集合。对 query 也只依赖该 query 自身的特征与固定训练原型，不依赖其他 query。

原型尺度仅由 T 定义：

`ν_T = median_{i∈T} min_{c≠y_i} D_c^0(x_i)`，包括零值。

单类或 ν_T=0 时，预先定义本原型变形分支为恒等、参数梯度为零，记录退化原因；不猜温度、不加 epsilon 变成另一个方法。ν_T 正但数值计算无法可靠表示时是技术失败。该退化不改变原 LocalRidge 头本身；其核仍可按原规则拟合。

每个内折必须独立构造 p、m、ν、J 及 LocalRidge 的所有统计。完整 outer-train 原型不能借给内折。inner-held 特征可用于自身前向 J(x)，其标签只用于下面的监督损失，不用于原型或邻域构建。共享训练参数从全部 inner-held 标签学习，因此内层指标属于训练指标，外层 held 才是只评分数据。

## 3. 十个存储参数、九个自由度

参数为 θ=(β_1…β_5,η_1…η_5)：

`|β_l|≤π/4`；`Σ_l η_l=0，|η_l|≤log(2)/2`。

β 控制各块旋转方向和强度，η 控制近邻类比较时各分支的相对权重。η 的零和约束主动固定分支权重的几何均值为 1，形成固定温度规范；ν 保持固定，不另学习温度。η 共同平移会使加权距离乘以同一个正数，改变 softmax 的温度，因此不是可删除的冗余。九个自由度来自这个主动约束。对 c∈J(x)：

`a_c(x;η)=softmax_{c∈J(x)}[−Σ_l exp(η_l)d_cl(x)/ν_T]`。

其他类权重为零。实现先减共同的最小加权距离，再除 ν，避免大负数直接指数；没有用真实类为 attention 提供额外权重。

每块定义 `μ_l(x)=Σ_c a_c m_cl`，`t_l=μ_l−w_l(w_lᵀμ_l)`，q_l=||t_l||。非零 r_l 的变换为：

`r'_l = ρ_l [cos(β_l q_l)w_l + β_l sinc(β_l q_l)t_l]`，其中 `sinc(z)=sin(z)/z`、sinc(0)=1。

零 r_l 仍为精确零。因为 t 与 w 正交且 ||μ||≤1，该映射保持块范数，单次旋转角不超过 π/4；β 可正可负，不预设只能向原型吸引。不同样本的 J、a、t 不同，故它是由类关系决定的非线性特征变换，而不是全局对角门控。它仍不能恢复原 encoder 丢失的信息，也不能任意独立搬动每一类。

全零 β 前向直接返回原 b0/a0，不做重新归一化；即便 η 非零也是如此。训练时仍计算 β 导数：`∂r'/∂β|β=0=ρ t`，一般非零。η 的首步数据梯度为零，因为 β 尚为零；β 更新后 η 可获得梯度。这里没有两层同时零初始化导致整个 adapter 死梯度的问题，日志要如实区分两组参数的活跃情况。

## 4. 保留原信息的 LocalRidge 头

拼接 r' 得 bθ、aθ，构造原样的 interaction `φθ=(bθ,aθ,bθ⊗aθ)`。实际核距离使用：

`d_joint²(x,z)=0.5 d_original²(x,z)+0.5 ||φθ(x)−φθ(z)||²`。

这等价于特征 `[φ0,φθ]/sqrt(2)`，不是相加两个分类器的 logits。零 β 时距离和分数精确走原 R0 路径；正常梯度仍计算。保留原分量使 `d_joint²≥0.5 d_original²`，即使非线性原型变形合并了两个点，也不能抹掉原输入中的区分。该下界不说明类间分离一定更好，也没有旧谱方法的上界。

两项距离都使用原稳定差分 rank-2 引擎，不显式存储 123616 维 φ。Gaussian 带宽仍是当前联合距离的最近异类中位数；训练中心迹匹配到**该次 inner-train 原未适配 interaction s0**，ridge 物理和系数为 1。最终拟合和逐样本全类竞争均由这一 LocalRidge 头完成，不加温度、旧类偏置或辅助分类器。

原 b/a 相等时，固定原型下变换也相等；原不相等时固定原距离分量保证联合距离正。因而 tau0=0 的原精确等价核及零导数可以复用，理由是保留原分量，不是错误声称非线性旋转全局可逆。距离下溢、非有限、未分辨正带宽/径向迹以及闭式残差异常均保留状态后报技术失败，不能换原型数或静默改核。

## 5. 类别对称的训练目标

outer-train 的物理 k≥2 时，沿用每类物理 ID 排序、模 min(k,3) 的内折。每个物理 support 恰好作为一次 inner-held；不等折按真实样本数合并。给定 θ，每折只用自身 inner-train 原型及特征拟合 LocalRidge，然后得到 inner-held 分数 S。

对每个当前注册类 c，先跨所有内折累计它的监督损失：

`ℓ_c(θ)= [Σ_{i:y_i=c} max(0,1−S_i,c+max_{j≠c}S_i,j)²]/(2 n_c)`。

采用类损失的均方根，而不是对旧/新组设置不同权重：

`L_data(θ)=sqrt[(1/C)Σ_c ℓ_c(θ)²]`；

`L(θ)=L_data(θ)+||θ−θ_anchor||²/(2N)`。

这里 N 是全部 outer-train 物理样本数，n_c 是其中类 c 的数量。头的物理和 ridge 系数保持 1；adapter 的类别聚合明确改变了训练目标，不能再把 L_data 描述为等权物理损失和。若所有类损失相同，它退化为普通类平均；困难类获得更大但非负的梯度权重：`∂L_data/∂ℓ_c=ℓ_c/(C L_data)`。全零类损失时数据梯度为零。

该聚合希望减少“多数已经较强的类带动平均损失，而弱类净收益几乎为零”的情况；它不识别某类是旧类还是新类，不能根据 Nnew 调权。有限支持集中的困难类也可能只是噪声，这种重加权可能损害泛化，必须报告每类/分组 held 转换，不能把公式当效果保证。此目标和原型变形作为一个预声明候选评估，单轮对照不能独立归因二者的贡献。

单类无错误类 max，数据损失定义为零，不做监督适配。C 阶段使用全部注册类的同一目标。不会用实际旧/新 query 的比例、真标签或目标差距去设权重；10/1/3 pp 仍是理想方向。

## 6. 梯度和有限优化预算

沿用已验证的 ridge 伴随：`A=(K+I)⁻¹Y，S=Kcross A`，`V=(K+I)⁻¹(KcrossᵀG_S)`，`bar_K=−sym(VAᵀ)`、`bar_Kcross=G_S Aᵀ`。每折复用同一 Cholesky，不按十个参数重新拟合。联合距离的 adapter 反向多乘 0.5；原距离项及原 s0 不求导。tau 的 min/median 与错误类 max 并列仍取全部并列分支的对称平均广义导数。

原型和 J 在一个内折内固定，不对训练集统计反向更新。attention 的导数为：

`∂a_c/∂η_q=−a_c exp(η_q)[d_cq−Σ_j a_j d_jq]/ν_T`。

再由 `∂μ_l=Σ_c(∂a_c)m_cl`、`∂t_l=(I−w_lw_lᵀ)∂μ_l` 得旋转梯度。设 q=||t||、z=βq，则：

`∂r'/∂β=ρ[−q sin(z)w+cos(z)t]`；

对 δt，`δr'=ρ[A δt+B t(tᵀδt)−β² sinc(z)w(tᵀδt)]`，

其中 `A=sin(βq)/q`，`B=[βq cos(βq)−sin(βq)]/q³`。q→0 时用连续展开 `A→β`、`B→−β³/3`，不用除零后截断。所有范数用稳定缩放，原型均值按规范物理 ID 累加；浮点范数/正交残差须检查。

预设优化器为**四次有界归一化投影梯度迭代，内含最多三次 Armijo 回溯**，不是对旧候选搜索学习率：

1. 当前梯度 g 非零时，方向为 `−g/||g||`。从 t=1/8 开始，最多尝试 t、t/2、t/4；β 投影到区间，η 使用欧氏投影到零和盒：`η_l=clip(v_l−λ,−h,h)`，`h=log(2)/2`，λ 满足 `Σ_l clip(v_l−λ,−h,h)=0`。这一定义给出唯一投影向量；实现须验证盒约束和零和残差，不以“减均值再截断”代替。
2. 设投影位移 δ。只在同一内层训练目标满足 `L(θ+δ)≤L(θ)+10⁻⁴ gᵀδ`（允许声明的 float64 比较容差）时接受；不看 outer-held。相同候选内的回溯是优化器求下降步，不是跨候选或外层成绩选择。
3. 梯度精确零、投影位移精确零或三次试探均未取得下降时，记录相应 solver 状态，保留当前已接受参数并结束本阶段；不加步数或重跑。回溯预算用尽是有限优化的可报告结果，不自动伪装成技术故障，也不声称收敛。
4. 完成四次迭代或上述有界停止后，使用当前参数，不挑历史最佳外层表现。保留每次失败试探、损失分项、步长、梯度、实际位移和计时。

最多一次初始前向和 12 次试探前向，共 13 个完整目标/39 个内头。接受试探的前向分解缓存用于下一次梯度，最多四次反向/每折八次三角求解，即每三折阶段最多 24 次伴随三角求解。缓存复用必须真实实现和计数；若未实现，不能沿用这个预算。没有额外“最好步”评估，最后接受状态已评估，最终全 support 头另拟合一次。

这可限制本目标的明显上升，不能保证外层泛化。与通道方案相比，最坏前向次数增加、反向次数减少，总时间必须实测，不能只用参数从 731 降至 9 推断更快。

## 7. B/C 继承和 K1

B 从 θ=0、anchor=0 开始，仅使用旧类 support 的内层监督；保存 θ_B、最终旧原型 p/m 和原 LocalRidge 所需状态。C_seq 必须继承当前 row、同一旧物理 support 的 θ_B 和最终旧原型，不读取其他 row 的适应结果。最终 C 原型表保留旧原型列原值并追加新类原型；ν_C 及全注册头按全部当前 support 重算，最近竞争类集合也可能改变。

C 的内折仍重新从 inner-train 估计旧/新原型，不能借 B 完整旧原型给内折。继承 θ_B 用作合法共享参数初始化和近端锚点，inner-held 标签通过先前训练影响 θ_B 属于顺序监督过程，不是给闭式头直接泄露 held 标签。C_reset 使用相同折、原型构造和目标，从零参数及零 anchor 开始，控制整个继承策略。

C 全部注册类对称竞争，不因旧类身份冻结其 logits。旧原型保留不保证旧分数不变：新邻居、attention、ν_C、参数更新和闭式头重拟合都可改变它。只保护旧类而牺牲新类不是本候选目标。Nnew=0 直接复用对应 B，不额外拟合 C。

物理 k=1 没有内持出监督；B 参数保持零，C 保留合法 anchor，不伪造增强样本。在本平衡 K1 矩阵里 B anchor 为零，故此候选仍精确 R0，不能承诺 K1 增益。true K1 诊断仍只做数值检查；one-shot proxy trainK1 不能冒充新的独立 K1 改善证据。k=2 可以内持出训练，但原型只有一条记录时方差很大，这正是需要外层检查的风险。

## 8. 实现接口、成本和反驳方式

提议接口（当前不存在实现）：

```python
prepare_prototype_transport(
    *, five_blocks, support_labels, support_ids, classes, old_classes,
    inherited=None, context=None,
) -> PrototypeTransportTraining

evaluate_transport_objective(prepared, theta, anchor, *, gradient=True,
                             forward_cache=None)
    -> loss, gradient, audit, forward_cache

fit_prototype_transport_local_ridge(prepared, *, mode='B', baseline_state=None,
                                   log_callback=None)
    -> immutable_state_with_score_predict_audit
```

prepared 保存各内折 p/m/ν、训练/持出 ID、原距离/原 s0 和固定邻居信息。state 保存最终原型表、θ、原/适配 support b/a、核头及继承绑定；不保留 query 集合统计。query 每次独立构造自身特征、固定原型距离和变形，再对所有注册类输出 LocalRidge 分数。原型 attention 是特征计算，不能作为另一分类器的预测混入结果。

实现必须保留以下数值合同：零 β 前向快捷路径仍执行 adapter 的向量—雅可比反向，双距离的反向只对适配分量乘 0.5；试探缓存与已接受缓存分离，拒绝 trial 不能替换当前已接受状态。非零参数 score 必须使用原/适配两份 support 分量，不能直接复用 Channel 的单份适配距离评分。适配分量允许非单射，因此不能直接套用要求输入与输出相等关系双向一致的原 `_checked_distances` 检查：原分量相等必须推出适配分量相等，原分量不等但适配分量相等合法；检查的是联合等价关系及 `d_joint²≥0.5 d_original²`。这些合同必须有独立合成回归，不能只依赖最终准确率。

十个 float64 参数为 80 B；两组 C×736 原型在 C=26 时为 306176 B。还必须计原/适配支持特征、alpha、中心化状态、原缓存、继承元数据与优化缓存。近邻原型比较每样本约 O(C·736)，原型变形是 O(|J|·736)，核评分仍需 O(N·736) 级稳定 interaction 距离；不能称为 80 B 的完整模型。将分别测训练准备、原型构造、每次 trial/梯度/头分解、评分、峰值 RSS、持久状态、部署包和增量传输字节，保留硬件和线程设置。未测项为 N/A。

若沿用同一 160 parent 完整 pilot，仍仅 R0、R_transport_seq、R_transport_reset 三路径。最多 936 个可训练阶段×39=36504 个内头，另 936 个最终头及 3168 个共享基线，共 40608 个头；伴随三角求解最多 22464。这是保守计数上界，拒绝试探也计费，早停预算结果、K1/N0 和缓存共享按实际记录。它不是更大性能矩阵或启动门槛。

必要合成检查为：零 β 精确 R0 且 β 梯度活跃；η 首步零梯度但后续可辨；原型/邻居/尺度的 inner-train 隔离；全链条有限差分和 q→0 连续导数；并列原型/类别重命名/行置换等变；固定原距离下界、零带宽与近重复稳定性；B/C 旧原型逐元素继承、N0/K1；所有回溯费用与失败状态完整保留。类别均方根损失必须跨所有内折先累计每类，再聚合，不能错误地对内折风险均值等权。

完整 pilot 中同时检查 B0→B、B→C 旧类变化、C 新类/旧类/差距及 H，保留全 K×新增类数与模型/接收机场景分层。重点反驳三点：局部原型变形是否只是把错误邻域拉紧；类风险聚合是否过度追逐低 K 噪声；C 引入新邻居后是否再次以新类损失换旧类保持。若训练间隔改善但这些外层指标恶化，结构假设不被支持；不因此改回溯预算或择层报告。

本方案的合理性是可检验的机制假设，不是性能结论。未使用 query 反馈，未改既有健康运行，未开始代码或新实验。
