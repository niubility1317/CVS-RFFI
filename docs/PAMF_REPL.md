# PAMF-REPL：接收机外推伪标签学习

> 2026-10-25 状态更新：本文保留历史定义。当前 PAMF 半监督方法暂用[普通伪标签](PAMF_CURRENT_METHOD_20261025.md)，本文方法不再作为当前半监督主方法。

2026-10-24，用户要求“选取 clean 性能最强的作为半监督方法，并取名”。本研究的半监督方法据此选定为 **PAMF-REPL**，英文为 **Receiver-Extrapolated Pseudo-Labeling**，固定标识为 `pamf_repl`。

已核对 30 份完整目标汇总，合并去重后共 33 个同口径半监督方案。以三个固定模型种子的 PAMF 原始读出 clean 总正确数排序，PAMF-REPL 为第一：432063/504000，均值 **85.726786%**，样本 SD **0.641460 个百分点**。保留三个种子，不从目标成绩挑选单个种子、epoch 或替换权重。

## 方法机制

1. 当前模型在原始源 IQ 上生成置信伪标签，门控固定为 0.95，U 损失权重为 6，伪标签平滑系数为 0.01。U 的 TX 真值保持隐藏。
2. 对通过门控、伪类别相同且接收机不同的源样本，复用浅层／中层风格扰动及跨接收机对比学习，并在实际部署使用的完整 160 维融合特征上计算对比目标，权重为 0.05。
3. 对合法跨接收机配对作完整特征外推：`h_i_ext = h_i + 0.25 * (h_i - h_j)`。使用原默认分类头计算外推特征的伪标签 CE。有效配对的普通 CE 系数由 0.5 分为原始特征 0.25 与外推特征 0.25，保留 1.25 的 CE 归一化；无合法配对的样本保留原 CE。外推复用已有骨干前向，每步增加两次既有分类头调用，推理参数不增加。
4. 使用实际获选版本的完整 L 梯度保护：按 `t2/cls_head/other` 分组，移除与完整 L 梯度冲突的 U 分量，U/L 梯度范数上限为 1。模型骨干与原默认头联合训练。

累计训练为 E50/11100 步，即 13L＋37LU；37LU 阶段联合使用 L/U。每个种子从原同契约 F21 E20/4440 继续自己的原生 10＋20 轮，新增 6660 步。精确机制块来自三个种子实际执行记录，并保存在定义 JSON 中。
