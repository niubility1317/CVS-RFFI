## 2 RIEI：均值接近，但逐行验收失败

本地真正的会议论文是 [SPAWC 2023 正文](../baselines/Receiver-Agnostic_Radio_Frequency_Fingerprint_Identification_via_Feature_Disentanglement.pdf)，题名 *Receiver-Agnostic Radio Frequency Fingerprint Identification via Feature Disentanglement*，DOI `10.1109/SPAWC53906.2023.10304544`，第 4 页规定最后 10 个 epoch 的均值和标准差，第 5 页 Table III 给出 12 个 RX 组合。[2025 年期刊扩展版](https://arxiv.org/html/2411.03636)采用最后 5 轮。以下严格绑定会议版 last10，不混用两个版本的统计窗口。

## 3 DRIFT：修改版达到历史均值门槛，严格复现未证明

必须区分 [v1](https://arxiv.org/html/2510.09405v1) 与 [v2](https://arxiv.org/html/2510.09405v2)：v1 是 batch 64、最后 5 轮平均；v2 是 batch 256、5 个 seed 的最终轮平均。同一三源 RX 组合 `1-1,14-7,7-7` 的参照分别为 75.62% 和 73.54%。这些版本差异不允许用更换统计口径补足成绩。

历史五种子 mean 版本在 Day1 训练，7 个明确指定目标 RX 为 `1-19,19-2,2-1,2-19,20-1,7-14,8-8`，每 seed 8,400 个目标包。原 metrics final 的正确数复算如下：

| Seed | 第 200 轮正确数／8,400 | 准确率 |
|---:|---:|---:|
| 1337 | 6,504 | 77.4286% |
| 2024 | 5,413 | 64.4405% |
| 3407 | 5,808 | 69.1429% |
| 4242 | 6,609 | 78.6786% |
| 7777 | 6,223 | 74.0833% |

均值 **72.7548% ± 5.9345%**（种子间样本标准差），相对 v2 表中 73.54% 低 **0.7852 个百分点**，确实满足当时 ±2 个百分点的均值工程门槛。seed 同时控制模型与随机数据抽样，不能把方差全归为模型初始化。该历史工程结论保留。

但严格论文效果仍有三个实质限制：

- **损失尺度不同。**v2 Eq.(23) 是逐样本平方 L2 和，再对 batch 求均值。历史 `mean_v1` 对特征维也求均值；固定代码 `9ee5c71` 的 `negative_mse_separation` 可直接确认。两个分支各 256 维，因此保留 `lambda_mse=0.02` 时，mean 版本等价于原 sum 公式使用 `0.02/256=0.000078125`。这会改变相对其他损失的优化强度。常数输入验证得到 sum=−256、mean=−1。同一历史发现矩阵中，按公式 sum、无 cap 的单 seed V201 final 为 **64.1667%**，没有五种子的字面公式成功证据。
- **覆盖和选择边界。**只完成一个训练 RX 组合；目标固定为上述 7 RX，而 v2 文字写全部剩余未见 RX，目标集合尚未逐项对齐。mean 候选由历史已暴露的目标成绩选出，不构成新的独立盲测；不能用一个组合的接近均值代替完整表复现。
- **历史评分证据层级。**当前包可验证总计数、逐 RX 计数、完整日志与统计；没有逐包匿名 prediction/物理 ID 文件供再次连接独立 truth。本次没有补写或追溯宣称该证据存在。

因此应标为“**DRIFT mean 项目实现：历史工程均值达标；严格原公式／完整表复现未验证**”，而不是无条件的 `paper_effect_verified=true`。历史发现阶段 seed 1337 的 72.6786% 与后续确认同名 seed 的 77.4286% 也不同；本次未证明二者的原始数据抽样及全部运行状态一致，不把它们当作严格配对实验计算增益。完整历史来源见[DRIFT 修复与确认报告](../automation_reports/CV-SincNet/paper_repro_drift_v2_repair_20260714_141223/report.md)。

## 4 对当前项目结论的影响

2026-09-27 CVS 弱标签、星地拼接实验的 RIEI-FD-CE **67.29% ±1.49%**、DRIFT-CE **63.94% ±10.54%** 是另一数据和预算口径，仍单独保留。不能拿它们替代上述原协议历史结果，也不能通过原协议全监督成绩推断 CVS 或卫星部署效果。

本次检查回答了“已有复现是否达到论文效果”：RIEI 未达到原定逐行验收；DRIFT 修改版达到历史均值门槛，但严格复现证据不完整。两篇新选方法 IB-RFF、SDG 已完成的作者代码／日志复现结果及全文缺口见[总核查报告](RFFI_DG_REPRODUCTION_AUDIT_20261019.md)。
