# Phase3 无标签适应与发现的后续机制

2026-10-29。当前仅为研究设计，未实现、未启动新实验，不改变正在运行的十轮固定预算。现有源端开发最高未知宏拒识92.6667%，正式跨RX星地U/Q尚未模型访问；这不是无标签适应或匿名注册结果。

## 已核对的相关工作

[Source-Free Open-World RF Fingerprint Identification](https://proceedings.mlr.press/v306/li26bl.html)提出用可扩展输出几何和无标签流对齐处理旧类保持与新类发现。[作者公开实现](https://github.com/likunling-jingjing/SFOW_RFFI/blob/main/SFOW_RFFI_stage_2.py)使用总类别数和新类百分比参数，并在训练过程中评价测试集。会议摘要与公开实现已核对，PDF正文尚未完整读取。其代码是参考，不能直接替代本项目的无真实类别数、固定预算与独立future query约定。

[From Identification to Discovery: Holistic RF Fingerprinting via Learning-Aided Quantization](https://arxiv.org/html/2610.05979v1)为2026年10月预印本，采用可扩展码本，并将连续拒识强度传递给密度聚类；发现样本与注册后评价样本分离。论文保留源核心点，而本项目部署不读取逐样本源特征。迁移时须改成聚合状态，并重新验证；不直接继承其实验数字。

## 结合当前 PAMF 的待证假设

1. **拒识与新类可分性分别验证。** 均匀OE主要约束六类logits，不直接要求不同未知设备分离。未来应分别测量拒识成功、候选簇纯度、合并／拆分及独立新观测识别；不能用更高拒识率推定注册可用。冻结编码器的time/frequency/PA等分支可保留为未知身份表征候选，是否有效仍需独立源实验。
2. **用聚合局部几何检验单原型的信息损失。** 当前每类单原型与共享收缩协方差不保留多模态邻接。可在合法source L内按统一公式形成每类固定少量均值微簇及局部半径，导出聚合状态；禁止把原始源特征或单样本核心点带入部署。接受后的旧类身份仍由原六类头给出，以单独考察拒识贡献。先做source证伪，不提前声称优于当前读出。
3. **把拒识置信度保留到发现阶段。** 独立无标签U中，靠近拒识边界的样本不应与强未知证据同权建簇。可用连续权重、互近邻和稳定性检查形成匿名候选；真实TX、未知类别数和配额均不参与。增强或复制只能改变计算权重，不能增加物理记录数或达到注册最少独立观测数。
4. **已知适应与未知发现隔离。** 仅高可靠旧类候选参与小幅适应，并保留冻结源模型／聚合锚点的约束。不确定样本先暂缓，不能全部赋予旧类伪标签。未知候选用于结构发现，不以均匀分配强迫填满预设类别。无标签U允许跨样本建模，future Q只逐样本推理。
5. **匿名注册用未来识别验收。** U中形成的匿名ID、聚合代表和接受半径冻结后，再面对独立Q。评分端可做ID置换匹配，匹配不回流。旧／新注册类共同竞争，报告旧类损伤、新类宏准确率、重复注册、未知合并及后续未注册类拒识；保持原95%／5%／2pp／80%目标。

以上是本项目的推断与设计，不是上述论文已经证明的结论。下一次实际候选须事前固定唯一机制、源数据角色、预算、控制组和推进规则；不把本笔记当额外发布门槛，也不改写当前正在训练的配方。
