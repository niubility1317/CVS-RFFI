数学结构与实际成本

AJLR 固定旧类物理参考测度及 B 的 τ/γ，但参考点随当前 U 重新映射；C 以实际 B 函数 m_B 为先验，闭式拟合残差：α=(K+I)⁻¹(Y−M_B)。没有自由截距或二次样本中心化。完整中心参考 VJP、pooled class-RMS CE 与 0.5||Z||² 通过最终 LocalRidge 头联合更新。详见[数学设计](D92_JOINT_AFTER_FCR8_DESIGN_20261001.md)。

固定宽度8的字典，实际保留秩 r≤8，最多736r≤5888个 adapter 梯度训练坐标；闭式拟合的分类头另计。U/V0合计94208 B。函数近端控制当前 support 上投影前的均方增量，不提供 query 准确率保持保证。C 不继承后验协方差且重用旧数据，不能称为精确顺序 Bayes。无截距与固定旧参考造成的混合类拟合限制已在设计中推导。多项结构一起改变，没有消融不能把收益归于某一项。
