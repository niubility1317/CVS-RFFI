# Phase1补偿响应架构：创新边界与证据缺口

核对日期：2026-10-03。对应[已实现设计](CVS_CHANNEL_RESPONSE_DESIGN_20261003.md)及[12模型正式实验](../automation_reports/CV-SincNet/20261003-phase1-cvs-channel-response-identity-manysig-m12-r01/report.md)。本次核对不改变已经启动的结构、训练、源选择或测试矩阵。

## 判断

“把信道先验放进神经网络”和“学习一个补偿器”均已有明确先例。当前可验证的具体候选贡献是：**辅助支路只读出补偿引起的特征变化，并以恒等补偿时严格归零的结构约束，排除该支路直接退化为重复普通特征描述子的路径。**它是否具有足够的新颖性、是否提高跨接收机识别，以及是否足以支撑独立Phase1论文，尚未成立。

单一分类交叉熵、固定训练流程能够隔离架构影响，是实验设计优点，本身不构成方法首创。不能把不使用额外训练策略写成已有所有工作都依赖额外策略。

## 结构究竟保证什么

固定一个输入包x，记其产生的补偿算子为G_x=I+A_x，特征映射为F，公共有效裁剪为C。模型使用

\[
\Delta=C\{F(G_xx)-F(x)\},\qquad
D=C\{F(G_xx)-G_xF(x)\}.
\]

响应交叉项为共轭F(x)与Δ的逐点乘积，再以当前包每通道平均功率归一化；第三候选还使用D。后续值编码和输出投影不含bias，激活在零点为零。因此G_x=I必有Δ=D=0，注意力权重无论如何变化，辅助输出仍为零。原主干可以独立工作，所以这不强迫模型利用辅助支路。

以下局部解释是本项目推导，不归属于上表论文。将复数IQ视为实向量，在F可微、二阶余项有界且扰动足够小时，固定本包G_x系数，有

\[
\Delta=C\{J_F(x)[A_xx]\}+O(\|A_xx\|^2),
\]

\[
D=C\{J_F(x)[A_xx]-A_xF(x)\}+O(\|A_xx\|^2).
\]

这里J_F是实雅可比，不是假定复全纯的导数；第二式要求输入与特征使用同一组FIR系数和一致的边界定义。它说明Δ表征局部输入扰动响应，D进一步表征特征映射与该变换的局部不交换性。它没有证明响应来自发射机，更没有证明实际信道改变时响应保持不变。

单包真实因素分离还受到可辨识性限制。例如在线性频域子模型X=RHT_yS中，若允许的模型族同时容纳可逆Q，则T'_y=QT_y、H'=H/Q产生相同X。对任意宽泛信道族宣称唯一恢复发射机因素不成立；实际可辨识性必须依赖受限模型、已知激励或观测条件。这个反例不否定特定数据分布上学习稳定分类特征的可能。

当前可称为“具有恒等零响应约束的补偿响应网络”，不能直接称为“已实现信道不变性”或“已解耦TX/RX”。

## 论文主张与实际证据

|主张|当前证据|仍缺少什么|
|---|---|---|
|改善辅助特征的机制约束|已实现恒等归零、逐包独立；相关单元测试通过；旧模型完整源V归因支持移除重复描述子路径。|新模型冻结后的完整源V依赖诊断；诊断只能说明给定权重的依赖，不能代替从零训练消融。|
|性能来自架构|12个scratch模型保持原始单一CE、数据、采样和优化流程；包含既有shallow和dual四seed固定控制。|完整E200源结果与冻结后的预登记clean结果。当前尚不能报告提升。|
|收益来自响应结构而非容量|三个候选区分均匀/注意力汇聚与额外D输入。|当前没有精确匹配新支路参数和算子的普通特征支路重训控制；历史容量控制只能作辅助证据。不能用参数较少或单次消融直接排除容量影响。|
|跨接收机稳定|预登记clean包含完整RX分层与同seed配对。|当前数据为equalized=1、center256、unitRMS，只能支持其观测边界内的结论。不能将跨RX变化全部归因为传播信道。|
|原始多径信道鲁棒|本轮未直接检验。|受控信道变化或合规独立场景证据；不自动追加到当前clean-only实验。|
|独立Phase1论文|已有结构、理论边界、训练与评分实现。|稳定的实际优势、合理对比、结构消融与更广泛独立证据；四个model seed不是四个独立数据集。|

当前ManySig测试是历史已暴露的固定测试集，不能称为首次盲测。源规则在本轮新目标访问前固定；目标结果不能回流修改结构、超参数、选择顺序或挑选重跑。即使本轮测试提升，也须如实报告全部负结果及历史暴露情况。

## 本轮执行不变

先完成12模型E200及120000步日志核对，按既定20行源矩阵选模并冻结。只有新候选胜出才生成4份新的clean预测，并与40份既有冻结预测统一独立评分；旧控制胜出则复用其已完成测试。上述论文证据缺口不是新增训练门槛，不改变当前实验，也不授权停止或重启健康任务。
