# D92无源数据辅助适应

## 当前授权与方法

用户明确要求辅助训练不使用源域数据，可使用地面已有原型等以减少卫星传输负担。用户已确认不设硬传输上限，优先原型与少量统计，报告字节数。正式4个Phase1模型继续冻结。原源TX留出训练不执行，未启动相关训练。

首版候选D92-SFHead-v1采用冻结identity160表征上的统一线性分类头。所有训练样本都来自当前row的合法卫星support，所有注册类共同参与softmax。旧类与新类各占监督目标的一半；旧类support的冻结Phase1输出提供旧类条件蒸馏。新类support不被强加旧类teacher标签。

令单位化support特征为z，类别均值单位化后为m，初始化W0=10m、b0=0。固定目标为：

`L = task_balanced_support_CE + KL_old_support/(K+1) + (||W-W0||² + ||b||²)/(200*K*C)`。

这里只更新W、b，编码器及teacher冻结。K1采用相同公式，不制造虚假holdout、不增加独立物理样本或LEO view。数值优化固定为float64 L-BFGS-B，max_iter=300、gtol=1e-6、ftol=1e-12；记录实际loss分量、权重、梯度范数、迭代数、耗时和终止状态。未收敛不能隐瞒为收敛，数值异常不能自动换算法。

公式由未读取目标评分的独立开发任务根据用户约束提出，不使用本任务已有目标成绩选择超参数。没有候选网格、query拟合或query早停。query在训练结束后逐样本面对全部已注册类别；顺序、batch大小和真实query角色不能影响输出。

摘要只能来自已存在的模型绑定文件。读取接口拒绝错误checkpoint、类序、schema及非法成员，不调用build_ground，不打开source IQ或逐样本feature，不构造源loader。普通原型遵守项目协议5.3.1；量化分布摘要遵守5.3.2。首版不把摘要当作训练样本，不需要新增地面统计，也不持久保存反量化域×类bank。
