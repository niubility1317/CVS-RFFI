# PAMF Phase1 域泛化对比实验方案

日期：2026-10-19。状态：设计提案，未发布新训练或测试。PAMF 指用户选定并改名的 SIG_TIME 主模型；历史 CVS、SIG_TIME 目录和结果保持原样。

**当前优先补齐同条件的域泛化方法比较，并保留每种方法自身骨干的 CE 对照。** PAMF 仅用交叉熵取得更好的跨接收机表现，可以支持其架构价值；实验不以“域泛化损失必须有效”为前提。若删除某种机制后性能提高，应保留这个结果，明确该机制在本设置下的作用范围。

## 1 已完成的证据与尚未回答的问题

当前完整证据来自固定 split392005、纯 CE、从零 E200、8 个模型种子、固定末轮默认分类头的 clean 测试。以下数值为准确率的模型种子均值与样本标准差；它们共享同一数据划分。

| 网络 | clean 准确率（%） | 当前可支持的结论 |
|---|---:|---|
| PAMF，历史名 CVS SIG_TIME | 81.5965 ± 0.3997 | 当前主模型的固定基准结果 |
| CVS residual_fusion | 78.9608 ± 1.0124 | PAMF 相对该历史结构配对提高 2.6357 个百分点，8/8 正差 |
| ResNet-50-1D | 74.9862 ± 1.0593 | 较强的通用监督网络对照 |
| Complex ResNet-18-1D | 72.9711 ± 1.9541 | 复数卷积结构对照 |
| ResNet-18-1D | 72.7422 ± 1.2680 | 适合承载通用 DG 机制的常见骨干 |

完整 14 网络表及逐种子结果见[现有 E200 分析](../automation_reports/CV-SincNet/20261014-phase1-sigtime-purece-e200-clean-manysig-m8-r01/final_analysis.md)。主文可展示代表网络，完整矩阵保留在补充材料；不能只保留 PAMF 优势较大的网络或接收机。

这张表主要回答“相同纯 CE 配方下，哪种网络更适合当前跨接收机任务”。它尚未证明 PAMF 超过所有完整 DG 方法，也没有单独证明 R、S 或其他物理模块的因果贡献。

IB-RFF 和 SDG 已完成作者代码/数据协议下的复现，分别达到四折均值 93.9097% 和三目标日均值 93.2444%。这些成绩的标签比例、RX/day、测试任务和选模规则不同，不能并入本表，也不能与 PAMF 的 81.5965% 直接计算差距。RIEI、DRIFT 的旧结果还包含不同增强和版本边界，详见[复现核查](RFFI_DG_REPRODUCTION_AUDIT_20261019.md)。

## 2 如何处理域泛化机制的负结果

研究任务和训练损失应分别描述。训练期间不使用目标域数据、冻结后在未见接收机测试，就是这里的域泛化评价设置；纯 CE 网络也可以在这个任务上表现很好。“专门的 DG 方法”则指额外设计了不变学习、解耦或增强机制的方法。

对每种外部方法 B，同时比较 PAMF-CE、B 的骨干-CE 和完整 B：

| 观察结果 | 支持的解释 |
|---|---|
| PAMF-CE 高于骨干-CE 和完整 B | PAMF 在当前匹配设置中优于两种对照；架构不依赖该 DG 机制也能取得较好泛化 |
| 完整 B 高于自身骨干-CE，但低于 PAMF-CE | B 的机制有收益，PAMF 整体仍更强；不能把 B 解释为无效 |
| 完整 B 低于自身骨干-CE | B 的额外机制在本设置下产生负收益；同时报告差值、波动与场景差异 |
| PAMF-CE 高于完整 B，但低于 B 的骨干-CE | PAMF 不能仅靠击败完整 B 宣称领先，应正面报告更强的 CE 对照 |
| clean 更高，部分 practical 更低 | 存在场景取舍，分别报告；不能概括为全面鲁棒性更强 |

发现负收益后，只依据公式、代码、源侧梯度与实际配置检查是否存在确定的实现错误。没有技术错误就保留结果，不增加目标反馈调参、删除弱种子或选择性重跑。修复确定错误时使用新 run，说明修复内容并保留旧产物。

只有同骨干消融才能较直接地归因于某个机制。不同骨干之间的排名评价整套实现，不能证明某一损失普遍无效。所有结论限定到当前弱标注、短 IQ、RX/day 和训练预算。

## 3 三组互相衔接的比较

### 3.1 纯 CE 网络结构比较

复用现有完整 14 网络、8 种子 E200 结果，主文保留 PAMF、residual_fusion、ResNet-18-1D、ResNet-50-1D 和 Complex ResNet-18-1D 等代表结构。已有固定 clean 评分无需重训或重复预测。

这组控制损失与训练设置，评价架构和输入适配的整体差异。不同网络的原生分类头、1D/2D 输入组织等差异仍应披露，不能称所有结构细节完全相同。

### 3.2 专用 RFFI 域泛化方法及自身 CE 对照

优先使用以下四对配置。每对的输入处理、骨干、部署分类头、采样、训练预算和选模规则匹配；CE 对照删除所研究的额外训练机制，保留必要的前向结构。

| 方法组 | CE 对照 | 完整机制 | 对照必须保持的条件 |
|---|---|---|---|
| RIEI-FD | RIEI 身份路径＋身份 CE | 绑定版本的完整解耦训练 | 同一身份骨干/头/输入；额外训练分支的移除边界明确 |
| DRIFT | DRIFT 身份路径＋身份 CE | 原公式的对抗、中心与分离目标 | 不把历史额外除以特征维度的 mean 修改版冒充原式 |
| IB-RFF | FAN＋CE，两阶段均无 IB 项 | FAN＋两阶段 HSIC-IB | 两条路线采用相同阶段边界及优化器重置，比较阶段二有/无 IB |
| SDG / Avoiding Shortcuts | 作者身份骨干＋CE | 作者定义的增强与对比训练 | 整体方法对照同时删除其方法专属增强和辅助目标，另注明不是单一 loss 消融 |

RIEI-FD 可首先绑定已有全文的 SPAWC 2023 版；若采用 [RIEI 扩展版](https://arxiv.org/abs/2411.03636)，须独立写明版本，不能借用会议版的验收窗口。DRIFT 建议绑定 [v2](https://arxiv.org/abs/2510.09405v2)，旧 mean 修改版仅保留为历史诊断。

[IB-RFF 作者实现](https://github.com/BeechburgPieStar/IB-RFF)为 FAN 与 HSIC 信息瓶颈的两阶段方案；匹配 E200 时建议明确采用 100＋100 轮，CE 对照也作同样重置。这是本项目的固定预算移植，不等同于作者“每阶段最多 200 轮＋源验证早停”的原协议复现。不能将两阶段 200＋200 轮隐藏为 E200。

[SDG 作者实现](https://github.com/BeechburgPieStar/SDG-for-Channel-Robust-SEI)的原验证包含单源跨天任务。本项目使用固定多 RX 源池时，应标为“SDG 机制在当前源池上的移植”，不能把原跨天分数当作跨接收机成绩。其算法原生增强属于该方法的组成部分，应披露多视图和计算成本；不额外加入卫星信道训练增强。

四对共 8 个新配置。建议正式接续现有表时采用 8 个模型种子，共 64 次训练。完整方法与自身 CE 都进入结果表，无论哪一条更高。ASKNet、WaveMLP 可作为后续有领域针对性的架构补充；DIFL 的精确特征位置尚有原文边界，先单列实现状态。TFMix 可保留为候补，不用其公开默认 1 轮充当论文预算。

作者原表是否取得，不阻断可明确定义的项目匹配实验；它限制的是“严格达到论文原表效果”的声明。若关键公式、输入或损失单位本身不能确定，则只搁置受影响方法，继续其他已明确的方法。

### 3.3 同骨干通用机制比较

第二批用两种固定骨干，检验“机制是否有效”及“是否与 PAMF 互补”。

| 骨干 | ERM，即身份 CE | MixStyle-ID | Fishr-head | CORAL |
|---|---|---|---|---|
| ResNet-18-1D | 精确匹配时复用已有结果 | 新配置 | 新配置 | 新配置 |
| PAMF | 精确匹配时复用已有结果 | 新配置 | 新配置 | 新配置 |

这组有 6 个新配置，8 种子为 48 次训练。三个机制分别覆盖浅中层统计混合、梯度方差约束和表征二阶统计对齐，避免只在最终 embedding 上更换损失。

- MixStyle-ID：固定在 PAMF 时间路径 t1、t2 的特征图，以及 ResNet 的对应浅中层使用；在 L_s 内同 TX、不同源 RX 间配对。记录准确模块位置、统计轴、混合概率/强度和未配对处理。它是为 RFFI 保护身份的适配版，应与[原 MixStyle](https://arxiv.org/abs/2104.02008)区分。
- Fishr-head：明确使用每样本身份 CE 对当前默认分类头参数的梯度，按源 RX 分组，对中心化梯度方差施加约束，并让其反向影响骨干。默认头保持联合训练，不能换线性头来省实现成本。余弦头适配和历史浅中层骨干梯度变体分别命名；[原作者实现](https://github.com/alexrame/fishr)及[DomainBed 代码](https://github.com/facebookresearch/DomainBed/blob/main/domainbed/algorithms.py)用于核对梯度对象和方差定义。
- CORAL：按源 RX 对齐同一指定表征的均值和协方差，固定小样本分组处理及损失归一化，不混入目标特征。

优先沿用原基线的物理样本遍历与每轮 50 个更新，不为这些机制改变 ERM 的数据顺序分布。若实际实现必须改为域均衡重采样或增加训练曝光，则另补匹配的 ERM 对照，并更新预算；不能继续无条件复用旧 ERM。

外部方法保留定义该算法所必需的原生训练机制和辅助分支。它们不属于事后另训的 TX/RX 诊断探针；部署只使用该方法既有身份头。所有方法禁止冻结骨干后重新拟合、重训或替换身份分类头。

固定轮数不等于计算量完全相同。外部方法可有原生优化器、阶段或多视图，但必须在首个目标预测前固定并与自身 CE 对照匹配，报告物理样本曝光、更新数、前向次数和实际耗时。不能把同 E200 描述为各算法都已充分调优。另行采用作者原预算的实验分表披露。

损失权重、单位、阶段启用和方法代码版本必须先在源侧确定并写入实际 run 的配置。没有统一默认值时，不能从作者各目标折参数中按本项目目标成绩挑选。需要源开发折的后续调参研究，应遵守[协议中的 L_s 内部分折要求](PROJECT_PROTOCOL.md)，使用相同 L_train/L_dev 从零建立匹配基线，不继承见过开发记录的旧权重，也不继续称与历史全 L_s 表严格匹配。

## 5 测试与统计

clean 是跨接收机识别的主要结果。新发布实验默认同时测试六个 practical：`practical_high`、`practical_mid`、`practical_low_suburban`、`practical_high_urban`、`practical_mid_urban`、`practical_low_urban`。它们评价固定模拟扰动下的压力表现，不等同于实际卫星接收机验证。

所有方法使用相同物理样本、相同固定 received IQ 和场景随机性。逐 row 训练及冻结后自动进入预测；该 row 的全部预登记视图固定后，独立 scorer 才读取 truth。不要等待整批训练完成，也不要让先完成 row 的成绩改变后续 row。

现有仅 clean 的历史 run 保持其原矩阵。需要 practical 时，在独立补测 run 中复用冻结 checkpoint、保留原 clean 结果，只补缺失预测；不得把历史 clean-only run 改称原本就做完了七视图。

每个场景报告 Accuracy、Macro-F1、逐 RX、逐 TX 召回率、混淆矩阵及实际种子数。先在每个种子取最差 RX，再汇总其均值/SD；它不同于对 RX 均值取最小值。存在已见与未见日期时，分别汇总“已见日×未见 RX”和“未见日×未见 RX”，不把混合总体一概称为跨 RX＋跨天。

每对完整方法与 CE、PAMF 与对照，均报告逐种子配对差、差值均值/样本 SD 和正差种子数。8 个种子描述固定划分上的训练随机性，7 个 RX 也不是 7 个模型种子；不把 168000 包或 8 倍预测条数当作独立实验重复来制造显著性。总体 Macro-F1 与单 TX 上的六类平均 F1 不混用。

六 practical 的等权平均可作预先定义的辅助汇总，仍保留全部逐场景结果。clean 较高但 practical 较低时直接呈现场景取舍，不用后验加权制造新的总冠军。

## 6 PAMF 分支与物理机制消融

域泛化方法对比优先；架构贡献由独立分支消融补足。按当前实现，T 是时间主干，F 是频域路径，P 是 PA 路径，R 是参考响应，S 是依赖 T 中间特征的 SIG_TIME 读出。

| 配置 | 唯一移除边界 |
|---|---|
| 完整 PAMF | 无，复用合规完整基线 |
| w/o R | 移除整个参考响应贡献及其投影、归一化和增益 |
| w/o S | 移除整个 SIG_TIME 贡献 |
| w/o P | 移除 PA 路径及其侧统计；时间路径的三次项仍保留 |
| w/o F | 移除频域路径，并切断频谱统计进入 P 的通路 |
| w/o T–S | 同时移除时间主干及依赖它的 S |
| w/o R–S | 在当前 PAMF 代码上精确关闭 R 与 S，其余行为保持 |

**旧 residual_fusion 不能直接当成最后一行。**现有报告已记录其与 PAMF 还存在参考处理、CFO 输入策略等整体差异；未经逐项证明行为等价，不能复用旧分数完成 R/S 的 2×2 消融。完整、w/o R、w/o S、w/o R–S 四行可计算 R/S 交互，但交互只是所用性能指标尺度上的条件效应，不证明独立的物理因果。

因此按保守预算，这组有 6 个新配置，8 种子共 48 次训练。应从零联合训练，推理时临时将成熟模型的分支置零只能作敏感性诊断，不能替代重训消融。

后续内部机制优先级为：PA 高阶×显式记忆的 2×2及通用 lift 替代；R 的复增益商/内部 CFO 补偿；S 的时间面积/常量项/COV＋常量控制；镜像显式统计与圆对称性；Sinc 与同感受野普通 FIR。具体定义复用[物理感知消融设计](CVS_PURECE_SIGTIME_PHYSICS_ABLATION_20261014.md)。不立即展开所有机制与所有 DG loss 的笛卡尔积。

配合合法源数据或可控合成链路作冻结模型的单因素响应分析，不另拟合诊断分类头。保留相位、残余 CFO、噪声、FIR 等因素的适用边界：PA 非线性可能承载身份，不能要求对所有非线性都不敏感；RMS 会消除部分幅度干预；相对参考响应不保证任意频率选择性信道不变。当前 Sinc 频带几乎未更新，应论证结构化滤波先验，不能称已学到最优频带。

## 7 优先级与建议预算

| 顺序 | 工作 | 新训练配置 | 8 种子训练数 | 主要回答的问题 |
|---|---|---:|---:|---|
| 先复用 | 整理现有完整 CE 表与 RX/day 分层 | 0 | 0 | 结构比较已有证据是什么 |
| 第一批 | 四个 RFFI 方法与各自 CE 对照 | 8 | 64 | PAMF 与完整方法谁更强；机制对自身骨干有何作用 |
| 第二批 | 两骨干×三个通用机制 | 6 | 48 | 通用机制是否有效，是否与 PAMF 互补 |
| 第三批 | 七行 PAMF 分支表，复用完整模型 | 6 | 48 | 哪些路径贡献识别与鲁棒性 |
| 后续重点 | 物理机制及泛化范围扩展 | 单独固定 | 不并入上述预算 | 为具体机制与更广声明补证据 |

前三批合计 160 次新的 E200 训练；第一批是当前推荐优先完成的 64 次。预算不含源侧工程检查、额外输入适配对照、推理和独立评分；不得把该提案直接视为已经发布的矩阵。若新增采样或阶段控制导致额外 CE 行，先更新实际矩阵，不能隐去成本。

未完成的同条件第一批比继续增加普通大网络更直接地补足论文证据。所有行先固定，不根据首种子或目标成绩决定是否补足剩余种子。性能较差属于结果，不作为技术停止条件。

更广泛化的后续优先考虑预先固定的另一 RX 划分、日期分层和源标注量敏感性。新的源/目标划分只能从零训练并独立核对物理角色，不能继承旧模型。1%/5%/10% 等标注量须明确相对训练池的分母，使用嵌套源标签子集，不扩大现有标签权限；全标签 80/20 只作独立监督参考。固定划分上的 8 种子结果不能替代这些外部条件变化证据。

## 8 论文呈现与执行边界

主文依次呈现纯 CE 结构比较、完整 DG 与自身 CE、同骨干机制矩阵和分支消融。配套图展示 RX 差异、配对增益和六 practical 下的性能变化；完整旧结果、负结果及逐种子数据保留在补充材料。

若 PAMF-CE 领先，结论写为“在固定弱标注跨接收机协议下，物理先验多分支架构仅使用 CE 即取得较强泛化表现”。只有匹配方法与场景结果齐全后，才能具体写明优于哪些实现、哪些条件。不预设所有物理模块有效，不从架构存在推导 TX/RX 完全解耦，不将本次已暴露代理基准称为新的独立盲测或在轨验证。

本轮只有设计和证据整理，没有访问新 target IQ/truth，没有修改模型、权重、数据或运行中的任务。实际发布时沿用项目八项最小流程，将各 row 的确定参数、命令、代码提交、环境、GPU、独占路径、停止规则和预期产物写入新 run 的 experiment.json/report.md；不另设设计审批、报告哈希、重复数据验证或额外审查链。

方法和超参数的选择仅使用合法源侧证据。[DomainBed 对选模信息来源的区分](https://github.com/facebookresearch/DomainBed)可作为评价设计参照；本项目不使用其 oracle target 选模。已有 benchmark 暴露背景、E20 探索与 E200 正式对比的成本差异均保留。
