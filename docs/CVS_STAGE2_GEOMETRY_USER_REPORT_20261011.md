# 二、从物理上看，首先需要回答“哪些差异能够被辨认”

## 2.1 数字增强不能补回原始观测中缺失的可辨识信息

可以把接收过程概念性地写成：

\[
x=\mathcal P\!\left[
\mathcal R_{\rho}
\left(
\mathcal H_h\bigl(\mathcal T_{\beta_y}(s)\bigr)
\right)
+\epsilon
\right].
\]

其中：

- \(y\)：TX 身份；
- \(\beta_y\)：发射端硬件参数；
- \(h\)：传播链路；
- \(\rho\)：接收端参数；
- \(\mathcal P\)：采样、均衡、截取、归一化等数据处理。

当前 L/T 对已经接收并处理的 IQ 做数字变换：

\[
\widetilde x=A_\eta(x).
\]

若动作随机性在给定 \(x\) 后不再含额外身份信息，那么：

\[
I\!\left(Y;X,\eta,A_\eta(X)\right)=I(Y;X).
\]

这个等式说明：

> 数字增强可以提供训练约束、改善有限样本学习，但不能让一个原本不可区分的 TX/RX 分解突然变得可辨识。

例如，若两种不同的物理参数组合产生完全相同的 \(x\)，再对 \(x\) 做十种数字滤波，也无法分清最初是哪种组合。

数字动作与真实接收条件变化还可能作用于不同位置：

\[
A(Hu+n_{\mathrm{RX}})=AHu+An_{\mathrm{RX}},
\]

而改变接收机噪声之前的传播链路，可能产生：

\[
x_{\mathrm{real}}'=AHu+n_{\mathrm{RX}}'.
\]

二者的噪声结构不同。

**因此，当前 L/T 更准确的定位是“具有明确数学定义的接收后压力测试”，其对真实跨 RX 变化的代表性仍需源域证据支持。**

---

## 2.2 对任意线性链路完全不变，可能同时删除 TX 的线性指纹

考虑：

\[
X_k=H_kT_{y,k}S_k.
\]

如果每个有效频点的 \(H_k\) 都可以独立变化，那么两个 TX 的响应 \(T_{1,k}\)、\(T_{2,k}\) 可以通过：

\[
H_k' = H_k\frac{T_{1,k}}{T_{2,k}}
\]

互相解释。

在这种模型下，**TX 的静态幅频、相频差异与未知链路本来就混在同一作用空间里**。

进一步，在稳态周期近似下，若两个响应具有相同的非零频谱支持，一个逐频率自由的 LTI 算子就可以把一个响应变成另一个。于是，对这整个 LTI 类完全不变的特征，也无法区分这两个响应。

这意味着下一版必须明确：

- 允许消除的是哪一类线性变化；
- 其幅度、记忆长度和频率自由度有多大；
- 哪些 TX 信息与它重合；
- 重合部分是否应该全部删除。

**当前有界 L/T 设定，更适合有限稳定性与软抑制，不适合直接追求整个扰动子空间的永久清除。**

## 2.3 当前前导存在一个非常具体的 IQ 不可辨识性

源码中的已知前导，在 25 Msps 下周期为 20 个样点，激活频点为：

\[
m=\pm1,\ldots,\pm6,
\]

频点间隔为 1.25 MHz。参考分支使用 \([80,160)\)，即四个周期、3.2 μs。[已知激励定义](https://github.com/niubility1317/CVS-RFFI/blob/5fb0acbbd685112e0cc5cfdc79f7b44d398c2a0e/experiments/cvs_rff_physics/known_excitation.py)

根据该前导的系数，可以严格推出：

\[
\boxed{s^*[n]=-j\,s[n-10].}
\]

我用源码中的系数做了独立数值核验，误差约为 \(7\times10^{-15}\)，与双精度舍入量级一致。

因此：

\[
A(z)s+B(z)s^*
=
\left[A(z)-jz^{-10}B(z)\right]s.
\]

只要未知线性链路允许对应的延迟自由度，共轭分量就可以被普通线性响应解释。

这里需要区分两个范围：

- 这是对**允许相应延迟或逐频点自由响应的未知链路**的不可辨识结论。
- 它不意味着当前只有 1、3 样点 tap 的人工 L 动作，已经包含全部这种自由度。

它直接影响下一步设计：

**增加 widely-linear 分支、共轭输入或 IQ 参数回归头，并不自动得到可分辨的 TX IQ 不平衡。首先要证明允许的 nuisance 模型没有把这组参数完全吸收。**

## 2.4 四次重复可以降低估计方差，却不会增加激励秩

若一个周期的回归设计矩阵为 \(\Phi\)，四次相同重复对应：

\[
\Phi_{\mathrm{rep}}=\mathbf 1_4\otimes\Phi,
\]

所以：

\[
\operatorname{rank}(\Phi_{\mathrm{rep}})
=
\operatorname{rank}(\Phi).
\]

在独立同分布噪声的理想条件下，重复可以增加信息量、降低方差，但不会把原本共线的参数方向变成独立方向。

这也是为什么不能仅凭“有四周期”就同时估计很多 PA 阶数、记忆 tap、IQ、相位噪声和同步参数。

另外，WiSig 的均衡版本会在均衡后重新加回估计的频偏，再截取前 256 个样点。因此，“经过均衡”也不意味着 CFO 已被消除，更不意味着剩余 CFO 是纯接收因素。[arxiv.org](https://arxiv.org/pdf/2112.15363?utm_source=chatgpt.com)

观察到的频偏通常混合了 TX、RX 及其他相位演化：

\[
f_{\mathrm{obs}}
=
f_{\mathrm{TX}}-f_{\mathrm{RX}}+f_{\mathrm{other}}.
\]

**T 应约束有依据的有限频偏变化，不能未经分析就要求身份表示与全部 CFO 信息无关。**

# 三、用数学定义“更有效的特征空间”

我建议把“有效”分成两个层次：

1. **物理上能否区分 TX 变化与 nuisance 变化。**
2. **现有数据与网络能否稳定利用这种区别。**

这两个层次分别对应有效 Fisher 信息与经验判别几何。

## 3.1 物理层：消去 nuisance 后还剩多少 TX 信息

在一个明确的局部模型下，写成：

\[
x=\mu_0+J_\beta\delta\beta+J_\eta\delta\eta+\epsilon,
\qquad
\epsilon\sim\mathcal N(0,\Sigma).
\]

这里使用实数化 IQ，避免复数参数与噪声的记号歧义。

定义白化后的方向：

\[
B_\beta=\Sigma^{-1/2}J_\beta,\qquad
B_\eta=\Sigma^{-1/2}J_\eta,
\]

以及 nuisance 投影：

\[
P_\eta=B_\eta B_\eta^\dagger.
\]

则消去 nuisance 后的有效 Fisher 信息是：

\[
\boxed{
\mathcal I_{\mathrm{eff}}
=
B_\beta^\top(I-P_\eta)B_\beta.
}
\]

它也可以写成 Fisher 矩阵的 Schur 补。

最直观的解释是：

\[
\min_{\delta\eta}
\left\|
\Sigma^{-1/2}
\left(J_\beta\delta\beta-J_\eta\delta\eta\right)
\right\|^2
=
\delta\beta^\top
\mathcal I_{\mathrm{eff}}
\delta\beta.
\]

也就是：

> 允许 nuisance 尽量模仿某个 TX 参数变化后，还剩多少无法被模仿的观测差异？

如果某个方向的有效信息为零，说明它在这个局部模型中无法单独辨认。这个 nuisance 消除思路有明确的统计推导，但一般非线性条件下只能视为局部近似。[arxiv.org](https://arxiv.org/html/1903.01473v1?utm_source=chatgpt.com)

例如，对严格常模激励：

\[
r=h\left(s+\alpha_3|s|^2s\right)+w
=h(1+\alpha_3)s+w,
\]

未知复增益 \(h\) 可以完全吸收 \(\alpha_3\)。即使“已知 \(h\)”时 PA 参数很好估计，“未知 \(h\)”时也可能不可辨识。

这是理解边界的例子，并不是把当前幅度变化的 STF 当作常模信号。

### 有界扰动更适合软度量

如果把局部 nuisance 近似为协方差有限的随机量：

\[
\delta\eta\sim(0,\Omega_\eta),
\]

那么边际观测协方差是：

\[
\Sigma_{\mathrm{eff}}
=
\Sigma+J_\eta\Omega_\eta J_\eta^\top.
\]

相应距离由：

\[
\Sigma_{\mathrm{eff}}^{-1}
\]

决定。

它会降低 nuisance 方向的权重，但通常不会把这些方向全部置零。只有在相应 nuisance 不确定性趋于无穷的极限下，才趋向硬投影消除。

**这与当前“有限幅度的 L/T”更一致：对可信范围内的变化做软抑制，同时保留与其重合的部分身份信息。**

---

## 3.2 数据层：在 joint160 中计算身份与扰动的广义判别比

令：

\[
z_0(x)\in\mathbb R^{160}
\]

是固定父模型最终归一化表示。

先按 RX/day 等权计算每个 TX 的均值：

\[
\mu_y
=
\frac1{|\mathcal E_y|}
\sum_{e\in\mathcal E_y}\mu_{y,e},
\qquad
\mu=\frac16\sum_y\mu_y.
\]

定义身份散度：

\[
S_{\mathrm{TX}}
=
\frac16
\sum_y
(\mu_y-\mu)(\mu_y-\mu)^\top.
\]

对 L/T，用已知物理参数建立局部响应：

\[
J_k^0(x)
=
\left.
\frac{\partial z_0(A_{k,a}x)}{\partial a}
\right|_{a=0}.
\]

再定义：

\[
C_k
=
\mathbb E_x
\left[
J_k^0(x)\Omega_kJ_k^0(x)^\top
\right].
\]

这里的 \(\Omega_k\) 必须明确。否则频偏从 Hz 改成 kHz，敏感度排名就可能改变。它代表预先规定的动作尺度或协方差，不能默认宣称是真实接收环境的分布。

对 R，只纳入跨 TX 留出可预测的条件位移，形成 \(C_R\)。组合：

\[
C_N
=
\kappa_LC_L+\kappa_TC_T+\kappa_RC_R
+C_{\mathrm{res}}+\rho I.
\]

其中 \(C_{\mathrm{res}}\) 是包级剩余变化，不应未经验证称为纯热噪声。

然后求：

\[
\boxed{
S_{\mathrm{TX}}v_j
=
\lambda_j C_Nv_j.
}
\]

大的 \(\lambda_j\) 表示：

- 这个方向上 TX 均值差异较大；
- 对当前可信、已覆盖的接收变化较稳定。

这属于“保留标签关系，同时抑制域变化”的判别表示思路；相关原始工作可以参考 DICA，但这里的关键在于用不同证据构建 L、T、R 的变化度量。[proceedings.mlr.press](https://proceedings.mlr.press/v28/muandet13.html?utm_source=chatgpt.com)

### 这一步应先作为特征空间审计

我建议先回答：

- 高判别比方向是否在不同 RX/day 上复现？
- L、T、R 分别覆盖哪些方向？
- 身份方向与扰动方向重合到什么程度？
- 现有分类头是否充分利用了这些方向？

不要一开始就把 160 维硬压成几个特征。

因为当前只有 6 个 TX，基于类均值的 \(S_{\mathrm{TX}}\) 秩最多为 5。**这只限制了这项分析能发现的均值结构，不意味着身份空间只需要 5 维。** 协方差结构、非线性结构及未来 TX 的信息不包含在这个结论里。

## 3.3 现有 cosine 头只约束了表示空间的一小部分

当前 logits 为：

\[
a_c(x)=30\,\widehat w_c^\top z_\theta(x).
\]

令：

\[
H_6=I_6-\frac16\mathbf1\mathbf1^\top,
\qquad
\overline W=H_6\widehat W.
\]

softmax 只依赖中心化 logits，因此：

\[
\operatorname{rank}(\overline W)\le5.
\]

这意味着，**保持当前 6 类预测，并不能唯一确定整个 160 维表示的几何结构。**

但也不能说“原始 joint 的任意 155 维变化都不影响分类”，因为归一化还会耦合范数：

\[
\frac{\partial(v/\|v\|)}{\partial v}
=
\frac1{\|v\|}
\left(I-zz^\top\right).
\]

以上球面推导还默认 joint 范数高于实现中的归一化截断阈值。

这对 R 很重要：学生可能保持分类预测，同时把接收条件信息移动到固定 R 投影没有监测的方向。仅靠固定分类头，也不能彻底排除这种情况。

# 四、我最看好的两个新增物理表示

## 4.1 同包时间响应的自参考表示

这是我认为比增加一般高阶统计量更值得优先尝试的方向。

假设同包不同区间 \(b\) 中，相同频点满足：

\[
Y_{b,k}=H_kT_{b,k}S_k.
\]

若这些区间共享同一个静态线性链路 \(H_k\)，则：

\[
\boxed{
\frac{Y_{b,k}}{Y_{\mathrm{ref},k}}
=
\frac{T_{b,k}}{T_{\mathrm{ref},k}}.
}
\]

共同链路被消去，保留下来的是响应如何随时间变化。

它可能包含：

- 增益建立或稳定过程；
- 随时间变化的幅相耦合；
- 频率相关的响应演变；
- 线性稳态模型解释不了的短时变化。

这些是否来自 TX，需要跨 RX/day 检验。RX AGC、振荡器以及预处理也可能产生类似动态。

### 用复射影表示避免依赖一个参考分母

对某个频点，令：

\[
\mathbf y_k=
\begin{bmatrix}
Y_{1,k}&\cdots&Y_{B,k}
\end{bmatrix}^{\top}.
\]

构造：

\[
\boxed{
P_k=
\frac{\mathbf y_k\mathbf y_k^H}
{\mathbf y_k^H\mathbf y_k}.
}
\]

若：

\[
\mathbf y_k=H_k\mathbf t_k,
\]

则 \(P_k\) 对非零复增益 \(H_k\) 精确不变。

这里使用的是一个明确而有限的物理对称性：**同一频点、不同时间区间共享复增益。**

它与“对任意整包 LTI 变换都不变”不是同一个假设。

### 当前数据如何使用

| 区间 | 建议用途 | 必须先核验的条件 |
|---|---|---|
| \([80,160)\) | 参考区间 | 重复前导与稳定性 |
| \([0,80)\) | 与参考区间比较早期响应 | 同一激励、对齐、边界影响 |
| \([160,240)\) | 候选扩展区间 | 不能默认与前段属于相同 STF |
| \([240,256)\) | 尾部质量或位置相关描述 | 不能当作一个完整独立符号 |

这里有两个关键失效条件。

第一，一般卷积与截窗不交换：

\[
W_bHx=HW_bx+[W_b,H]x.
\]

因此，早期区间尤其需要检查边界项。不能一边用暂态，一边无条件假设每段都满足静态逐频点乘法。

第二，如果同步对齐后各区间完全稳态：

\[
T_{b,k}=T_k,
\]

那么比值退化为 1，\(P_k\) 也退化为固定结构。**此时没有新增身份信息，应接受这个负结果。**

我建议首先检查这种时间响应表示在受控 L 动作下是否稳定，再检查它对 TX 的区分是否跨 RX/day 保留。

## 4.2 已知激励下，可识别的非线性剩余响应

PA 的 memory-polynomial 基可以写为：

\[
\phi_{p,m}[n]
=
s[n-m]|s[n-m]|^{p-1},
\qquad p=1,3,5,\ldots
\]

这类模型有明确的射频建模依据，但非线性阶数、记忆与采样条件都需要一起考虑。[s3-us-west-1.amazonaws.com](https://s3-us-west-1.amazonaws.com/ptab-filings%2FIPR2025-00691%2F1008?utm_source=chatgpt.com)

下一版不宜直接输出一组“PA 系数”。我建议先做残差化。

设 \(X_L\) 包含允许的线性、DC、同步等解释，\(\Phi_N\) 包含候选非线性基。定义：

\[
\widetilde X_L=\Sigma^{-1/2}X_L,
\qquad
Q_L=I-\widetilde X_L\widetilde X_L^\dagger,
\]

\[
U_N=Q_L\Sigma^{-1/2}\Phi_N.
\]

然后计算：

\[
U_N=U_rD_rV_r^H.
\]

真正值得保留的是 \(U_N\) 中可稳定估计的奇异方向，例如：

\[
\phi_{\mathrm{NL}}(x)
=
U_r^HQ_L\Sigma^{-1/2}x.
\]

这样得到的是**难以由已允许线性/同步变化解释的响应坐标**。

它比反演全部系数更稳，因为反演系数需要除以小奇异值，容易放大噪声。

### 当前前导上的两个具体结果

根据公开模板的代数核验：

- \([s,s|s|^2,s|s|^4]\) 在理想离散模型中秩为 3，但条件数约为 **54.5**；
- 重复四周期仍然是秩 3。

更关键的是，**采样前后的非线性不能混用**。

当前基波最高到 ±7.5 MHz。连续三阶产物可以达到 ±22.5 MHz，五阶可以达到 ±37.5 MHz。直接在 25 Msps 的样点上计算非线性，会把部分高频成分混叠回来；真实模拟滤波可能已经把它们去掉。

因此，构造物理基时应采用：

> 连续频率或足够高采样率的非线性展开 → 接收有效限带 → 最终采样。

不能把离散乘法产生的别名频率当作实际测到的频谱再生。

还有一个更强的限制：若只信任 nominal 20 MHz 严格内带，消除原有 12 个激活音调，再把 DC 作为 nuisance 去掉，可用的新谐波位置主要剩下 ±8.75 MHz。

对当前模板，在这两个频点上：

\[
\boxed{
\Phi_5(\pm8.75\,\mathrm{MHz})
=
\frac{17}{8}\Phi_3(\pm8.75\,\mathrm{MHz}).
}
\]

我独立核验了这个比例。

**因此，仅靠这两个频点，无法分别辨认三阶和五阶，只能辨认它们的一个复响应组合。**

这正是“往数学物理上靠”的实际价值：模型输出维度应服从可辨识秩。

### 如何判断这个剩余响应是否值得加入身份网络

至少看三件事：

1. 是否具有高于同步泄漏与随机创新的可重复分量；
2. 是否在跨 RX/day 条件下保留 TX 区分；
3. 是否相对现有 joint160 提供额外可读出的身份信息。

四周期可以用于估计可重复能量：

\[
\widehat E_{\mathrm{rep}}
=
\frac1{B(B-1)}
\sum_{b\ne b'}
\operatorname{Re}(e_b^He_{b'}).
\]

在独立零均值噪声模型下，它估计共同剩余响应的能量。单次估计可以为负，不应先截零再称无偏；真实相位变化也会进入创新项，不能把它直接解释为热噪声估计。

# 五、L/T 下一版：用有限身份风险替代完整 margin 恢复

## 5.1 动作搜索目标与身份学习目标应分开

当前 L/T 已经分别拟合过，再被冻结用于 E40；问题并非“辅助网络完全没有训练”。

不过，最大化父 margin 下降，得到的是**父模型弱点的搜索器**。它并不自动成为接收条件参数估计器。[本次交接](https://github.com/niubility1317/CVS-RFFI/blob/5fb0acbbd685112e0cc5cfdc79f7b44d398c2a0e/docs/CVS_STAGE2_AUXILIARY_FINETUNING_HANDOFF_20261011.md)

我建议作如下区分：

- **动作准备阶段**：寻找合法范围内有覆盖度、能检验任务风险的动作。
- **身份微调阶段**：只修复不足的身份风险，不恢复每个样本的全部高置信 margin。

准备阶段的 margin 下降可以保留为搜索启发式，但应同时考察真实风险、动作覆盖和边界集中程度。进一步改成有上限的风险搜索，应作为独立变体，避免一次改变太多机制后无法归因。

## 5.2 一个明确的有限风险目标

定义 raw-logit margin：

\[
m_\theta(x,y)
=
a_y(x)-\max_{c\ne y}a_c(x).
\]

选择一个固定、有限的任务 margin \(m_{\mathrm{req}}>0\)，定义：

\[
\boxed{
L_{LT,k}
=
\frac12
\left[
\frac{
\min\{\operatorname{sg}(m_\theta(x,y)),m_{\mathrm{req}}\}
-
m_\theta(A_kx,y)
}{
m_{\mathrm{req}}
}
\right]_+^2.
}
\]

这个定义直接写出无量纲单侧平方，避免 Huber 与 SmoothL1 的单位混用。

它有三个需要的性质。

**第一，零动作严格为零。**

在相同确定性前向下，若 \(A_0x=x\)，则括号内不大于零，损失与梯度都为零。

**第二，任务完成后停止加压。**

clean margin 很高时，增强样本只需达到 \(m_{\mathrm{req}}\)，不必恢复父模型 15、20 一类的高 margin。

**第三，真实增强仍直接经过身份骨干。**

这不是只在虚拟特征上训练。梯度来自实际 \(A_kx\) 的身份前向。

主 clean CE 继续负责身份学习。若额外再保留无截断增强 CE，就应承认它在零动作时仍增加一份 CE 梯度；不能再说“全部 L/T 辅助梯度在零动作时为零”。

### \(m_{\mathrm{req}}\) 可以有任务解释

对 6 类 softmax，若：

\[
m\ge
\log\frac{5(1-\varepsilon)}{\varepsilon},
\]

则模型概率满足：

\[
p_y\ge1-\varepsilon.
\]

例如 \(\varepsilon=0.05\) 时：

\[
m_{\mathrm{req}}\approx4.554.
\]

这个数可作为起始设计的解释依据，但它不是校准概率保证，更不是跨 RX 准确率保证。最终取值应按源域设计一次性冻结。

keep 也应采用类似的有限父目标：

\[
L_{\mathrm{keep}}
=
\mathbf1_{\{m_0>0\}}
\frac12
\left[
\frac{\min(m_0,m_{\mathrm{req}})-m_\theta(x,y)}
{m_{\mathrm{req}}}
\right]_+^2.
\]

## 5.3 固定、刷新与交替更新怎样选

首版继续采用**固定辅助机制、微调身份模型**。

需要区分以下情况：

| 源域现象 | 更合理的解释 |
|---|---|
| 固定动作风险消失，独立合法动作池也没有明显风险 | 模型可能已经对该动作族足够稳定 |
| 固定动作风险消失，独立动作池仍有明显风险 | 动作策略可能覆盖不足或已经过时 |
| 压力主要来自窗边界、异常质量或不可信动作 | 应修正动作定义 |
| 风险一直很高，身份训练也无法改善 | 检查身份信息是否被破坏、目标是否冲突或优化是否不足 |

只有第二类证据，才比较支持低频刷新。

刷新时点和预算应预先固定，例如将“中途一次刷新”作为完整 E40 的单独候选，而不是训练中根据坏分数临时改变方法。每步 min-max 暂时没有足够理由成为默认配置。

# 六、R 下一版：我建议比原候选再改四个关键点

原候选把 margin 改成 rank-2 表示差分，这个方向合理。但还存在坐标、约束范围和统计估计问题。[R 源域目标候选](https://github.com/niubility1317/CVS-RFFI/blob/5fb0acbbd685112e0cc5cfdc79f7b44d398c2a0e/docs/CVS_STAGE2_R_SOURCE_OBJECTIVE_AUDIT_20261011.md)

## 6.1 继续低秩预测，但不要把它解释成纯 RX 参数

每个 fold 用另外 4 个 TX 拟合：

\[
B_f:\mathbb R^{40}\rightarrow\mathbb R^{160},
\qquad
\operatorname{rank}(B_f)\le2.
\]

训练目标为条件中心化差分：

\[
\min_{\operatorname{rank}(B_f)\le2}
\sum_gw_g
\left\|
\widetilde z_g^0-B_f\widetilde s_g
\right\|^2
+
\lambda\|B_f\|_F^2.
\]

三折、标准化、基底、回归和可靠度的边界继续保留。

但要承认：

- 当前状态中 PSD、功率矩等仍可能带 TX 信息；
- 同 TX/day 的跨 RX 差异仍可能含信道混杂；
- 现有质量分箱在 17/18 个 TX/day 条件块里退到单 bin，不能称为精确 SNR 匹配；
- 共同物理作用经非线性编码器后，可能是随波形改变的变形，并非全局共同平移。

因此，rank-2 是一个可检验的近似，不是物理上天然存在的两维 RX 空间。

## 6.2 可靠度改成向量可靠度，避免依赖任意基底

若：

\[
B_f=U_fA_f,
\]

同一个预测也可以写成：

\[
B_f=(U_fQ)(Q^\top A_f).
\]

原候选逐坐标计算 \(c_1,c_2\)，一般会随 \(Q\) 改变。尤其两个奇异值接近时，小的样本变化就可能旋转基底。

首版建议使用单一向量可靠度：

\[
\boxed{
c_f=
\left[
1-
\frac{
\operatorname{MSE}_{\mathrm{pred,vector}}
}{
\operatorname{MSE}_{\mathrm{zero,vector}}
}
\right]_{[0,1]}.
}
\]

同时报告预测子空间内误差、完整向量误差和误差谱。

这个 \(c_f\) 对正交坐标变化不敏感，但仍只是启发式可靠度，不是校准概率，也不保证每一条关系都正确。

## 6.3 预测可以低秩，学生目标应约束完整 160 维组差

这是我最推荐的新改动。

对合法组对 \(g,h\)，定义：

\[
d_{gh}^0=\mu_g^0-\mu_h^0,
\]

\[
p_{gh}=B_f(\bar s_g-\bar s_h),
\]

\[
d_{gh}^*=d_{gh}^0-\alpha p_{gh}.
\]

然后约束：

\[
\boxed{
L_{R,gh}^{\mathrm{pop}}
=
\frac{c_f}{2}
\left\|
d_{gh}^\theta-d_{gh}^*
\right\|^2.
}
\]

这里直接比较完整的 160 维差分，不只比较 \(U_f^\top d^\theta\)。

它的含义是：

> 按固定比例消减可靠预测的条件位移，同时暂时保留父模型尚未解释的条件均值差。

### 为什么能阻止原先的投影逃逸

假设旧预测空间只有 \(e_1\)，目标差异为零。学生把条件差异从 \(e_1\) 旋转到 \(e_2\)：

\[
d_\theta=e_2.
\]

旧投影看到：

\[
e_1^\top d_\theta=0,
\]

可以误判为完成；新目标仍然得到：

\[
L_R=c_f/2>0.
\]

这样就不需要首先引入复杂 Procrustes、全局正交损失或新的身份分类分支。

### 它的能力边界

这个目标约束组均值差，仍允许：

- 每个 TX 的共同均值变化；
- 组内零均值变化；
- RX 信息转移到协方差或更高阶结构。

它也会保留父模型尚未预测到的 RX 差异，可能限制一些有益变化。

因此，准确的目标是**修正可靠的条件均值作用**，不能宣称实现了完整统计独立。

---

## 6.4 保留父控制变量，并让方差修正参与反向传播

缓存完整父特征：

\[
z_i^0\in\mathbb R^{160},
\]

只需要：

\[
6300\times160\times4
=
4{,}032{,}000\ \text{bytes},
\]

约 4.03 MB。对当前规模，没必要为了只存两维而接受明显的投影漏洞。

定义：

\[
q_i=z_\theta(x_i)-z_i^0.
\]

抽取组内小袋后：

\[
\widehat e_{gh}
=
\bar q_{B_g}-\bar q_{B_h}+\alpha p_{gh}.
\]

父初始化时，确定性前向保证 \(q_i=0\)，因此组差估计没有来自特征值的抽样波动；但样本 Jacobian 仍不同，梯度并非完全无噪。

对于组内简单随机无放回抽样，令：

\[
\widehat t_g
=
\frac1{n_g-1}
\sum_{i\in B_g}\|q_i-\bar q_{B_g}\|^2.
\]

方差迹估计为：

\[
\widehat v_{gh}
=
\frac{1-n_g/N_g}{n_g}\widehat t_g
+
\frac{1-n_h/N_h}{n_h}\widehat t_h.
\]

使用：

\[
\boxed{
\widehat L_{R,gh}
=
\frac{c_f}{2}
\left(
\|\widehat e_{gh}\|^2-\widehat v_{gh}
\right).
}
\]

则在相应抽样条件下：

\[
\mathbb E[\widehat L_{R,gh}]
=
L_{R,gh}^{\mathrm{pop}}.
\]

我对一个小型有限总体作了穷举核验，估计均值与总体目标一致。

这里有两个实现点必须保持：

- **方差修正不能 detach。** 否则损失值可无偏，梯度却仍多出组内方差压缩。
- **单批负损失不能截零。** 截零会破坏上述目标含义。

只需计算方差的 trace，不需要构建 \(160\times160\) 协方差矩阵。

---

## 6.5 组间预测还必须满足环路一致性

如果：

\[
p_{gh}=B(s_g-s_h),
\]

那么天然满足：

\[
p_{gh}+p_{h\ell}+p_{\ell g}=0.
\]

原候选中逐对限幅需要小心：独立裁剪每条边，可能破坏这个性质。

例如组势为：

\[
a=(0,2,4).
\]

三个有向差分为 \((-2,-2,4)\)，和为零；逐边裁剪到 \([-2,2]\) 后，变成 \((-2,-2,2)\)，和为 \(-2\)。

此时学生面对的组差目标不能同时满足。

**建议在条件块内统一缩放组势，再计算组差：**

\[
a_g=B(s_g-\bar s_b),
\qquad
p_{gh}=\kappa_b(a_g-a_h).
\]

\(\kappa_b\) 与 \(\alpha_b\) 在块内固定，可靠度只作为损失边权。

这保证环路一致性，但不自动保证目标能由单位球内的组均值实现。还要检查目标幅度与父组几何，而不能仅凭“\(\alpha=0.25\) 很小”就宣布可行。

# 七、交互网络：先区分三个不同来源

\[
L=I+h_1S_1+h_3S_3,

且每个 tap 的实部、虚部均不超过 0.06。因此：

\[
\boxed{
0.8303\le |H(\omega)|\le1.1697.
}

实际有限移位矩阵也有相同的最小奇异值下界。因此，**当前 L 不能泛称为会产生深零点的动作**。[当前动作实现](https://github.com/niubility1317/CVS-RFFI/blob/5fb0acbbd685112e0cc5cfdc79f7b44d398c2a0e/experiments/cvs_stage2_decouple/actions.py)

\[
M_\nu D_\tau
=
e^{j2\pi\nu\tau}D_\tau M_\nu.
\]

当前 \(|\nu|\le3120\) Hz、\(|\tau|\le10\) ns，因此：

\[
|2\pi\nu\tau|
\le1.96\times10^{-4}\ \mathrm{rad}.
\]

L 与 CFO 的交换子相对算子范数上界约为：

\[
2.66\times10^{-4}.
\]

这是很小的作用。完整 T 还含相噪与分数延迟，不能用 CFO-only 上界代表全部 T；当前 FFT 零延拓、裁窗也会额外引入边界效应。

此外：

\[
F(LTx)-F(TLx)
\]

与：

\[
F(LTx)-F(Lx)-F(Tx)+F(x)
\]

是不同对象。后者即使在 \(L,T\) 可交换时，也会因 \(F\) 的非线性而非零。

因此，下一版应分别记录：

1. **IQ 算子的真实次序差；**
2. **有限窗边界造成的差；**
3. **编码器对组合变化的混合曲率。**

比较时固定动作参数、使用相同相噪 realization，不能在变换后的 state 上重新生成参数后，再把全部差异归于物理非交换。

**只有组合残差稳定、可预测，并且单因素约束确实遗漏了任务风险，才值得增加 \(D_{LT}\)。**

# 八、特征增强、采样与 Fishr 应如何接入

## 8.1 特征增强：在动作参数中采样，再映射到当前波形的响应方向

我不建议直接把不同 TX 的特征差拿来相加。相同物理扰动对不同波形的作用一般不同。

更有依据的形式是：

\[
\Delta z_k(x,a)\approx J_k^0(x)a.
\]

动作参数 \(a\) 可以来自其他合法源条件，但响应方向使用**当前接收样本自己的 Jacobian**。

归一化表示中的局部增强可以写为：

\[
\widetilde z
=
\operatorname{Norm}
\left[
z_\theta(x)
+
\Pi_{z_\theta(x)}J_k^0(x)a
\right],
\]

其中：

\[
\Pi_z=I-zz^\top.
\]

这只能作为局部近似。使用之前应测量：

\[
E_{\mathrm{lin}}
=
\frac{
\|z_0(A_ax)-z_0(x)-J_k^0(x)a\|
}{
\|z_0(A_ax)-z_0(x)\|+\epsilon
}.
\]

还要分别看绝对误差，避免真实变化接近零时比值失真。

我的建议是：**先让真实 IQ 动作建立可靠性，再加入切向特征增强作为独立增量。** 父坐标逐渐过时、局部线性近似失效时，不应继续把虚拟特征当作真实反事实。

已知变换方向导数用于选择性不变约束，有 Tangent Prop 这一明确的原始方法基础；本任务仍需验证射频动作与局部近似是否成立。[proceedings.neurips.cc](https://proceedings.neurips.cc/paper/1991/hash/65658fde58ab3c2b6e5132a39fae7cb9-Abstract.html?utm_source=chatgpt.com)

---

## 8.2 采样首先应支持估计目标

建议保留主 CE 的共同采样流，同时让 R 的关系袋满足其统计公式。

尤其是：

- 关系组内保持不同物理 ID；
- 所有对照共享关系安排；
- R 的无偏方差修正使用与实际采样一致的公式；
- 质量共同支持不足时明确记为缺项；
- 同包增强视图不算新的独立物理样本。

如果以后按困难度或不确定性选择 R 袋，当前简单随机抽样下的公式就不再自动成立。需要相应的包含概率或重加权，不能一边改变采样分布，一边沿用“精确无偏”的解释。

动作采样则可以采用：

\[
q_k(a\mid x)
=
(1-\rho)q_{k,\mathrm{coverage}}(a)
+
\rho q_{\psi_k}(a\mid x).
\]

固定覆盖分量能减少动作网络只集中在少数边界的情况。但 \(\rho\) 和动作范围应预先冻结，不以测试结果调整。

---

## 8.3 Fishr 暂时放在后续单独对照

这次更应区分三个量：

| 对象 | 讨论的问题 |
|---|---|
| 物理 Fisher | IQ 观测能否区分 TX 与 nuisance 参数 |
| 分类模型 Fisher | 当前分类概率对某种变化有多敏感 |
| Fishr 梯度方差 | 不同训练域的损失梯度分布是否接近 |

Fishr 匹配的是跨域梯度方差，与物理参数的有效 Fisher 信息不是同一个对象。原论文给出相关联系及条件，而 empirical Fisher 也不能一般性地等同于真实模型 Fisher。[proceedings.mlr.press](https://proceedings.mlr.press/v162/rame22a.html?utm_source=chatgpt.com)

当前父模型 clean CE 已接近饱和。此时：

- 梯度方差很小，可能只是分类饱和；
- 强行归一化很小的梯度，可能放大估计噪声；
- Fishr 不能代替对前导激励秩、物理作用和 R 监督语义的分析。

**此前按成熟 CE 梯度比例给辅助约束定权的建议，在当前第二阶段设定下不宜继续沿用。** 新 R 稿与主交接在这一点上确实存在未整合的冲突。

下一版应使用有限、预定的权重，并记录绝对 raw/weighted 梯度、任务违约和实际参数变化。CE 分母接近零时，比例记为 N/A；不能据此自动关闭一个有可靠预测信息的 R。

# 九、下一版的具体研究与实验顺序

## 第一步：先完成源域特征空间审计

使用每个 seed 对应的固定 E200 父模型，提取合法 \(L_s\) 的最终表示与必要响应。

优先完成以下四项：

| 分析 | 需要回答的问题 |
|---|---|
| joint160 的广义判别谱 | 是否已存在跨源条件稳定的身份方向？ |
| 身份与 L/T/R 响应空间的重合 | 当前不变约束是否正在压制身份证据？ |
| 自参考时间响应 | 是否有共同链路消除后仍可重复的 TX 动态？ |
| 非线性残差的有效秩与噪声 | 是否存在可可靠测量、且现有表示未充分利用的响应？ |

这里的小矩阵计算很便宜，额外 IQ 前向才是主要准备成本，应单独计入。

跨 TX 留出只证明辅助作用模型的迁移能力：父身份模型已经见过这些 TX，不能把它描述成未见 TX 注册实验。

---

## 第二步：首轮 E40 采用一个紧凑矩阵

我建议主矩阵保持四组：

| 组别 | 配置 | 核心问题 |
|---|---|---|
| B0 | 同预算纯 CE | 第二阶段自身的参照 |
| B1 | 确定性比较＋有限风险，使用固定覆盖的 L/T | 物理增强与有限目标本身是否有效？ |
| B2 | B1 换成已核验的条件动作策略 | 动作网络是否优于同强度、同视图预算的采样？ |
| B3 | B2＋完整 160 维组差 R | 真实跨 RX 统计是否提供额外收益？ |

所有组从同 seed 的同一个纯 CE 父模型独立分叉：

- 每行 40 epoch、8,880 次身份更新；
- 全部三个 seed；
- 主 CE、关系采样、学习率和数据契约一致；
- \(L_s\) clean 为训练基础；
- 无 U 训练、伪标签、EMA teacher 或默认星地拼接；
- 保留时频、PA、reference、内部门控、cosine 分类头和 cosine LR；
- 固定最终 E40，按既定冻结与独立评分规则执行。

当前交接是 clean-only 的特定范围；它不应被外推为所有后续实验永久取消 practical。后续场景范围应沿最终登记的实验契约执行。

这个矩阵可以回答动作网络和 R 的增量。若要单独归因“确定性修复”与“有限目标重设”的效果，再增加一个明确对照；不能把组合收益全部归给其中一项。

## 第三步：有增量证据后，再让新物理表示进入身份路径

如果自参考时间响应或非线性剩余响应，在源域新 ID 和留出条件上表现出**相对 joint160 的额外可读出身份信息**，再增加一个独立特征变体：

\[
v_\theta^{+}(x)
=
v_\theta(x)+W_{\mathrm{phys}}\phi_{\mathrm{phys}}(x).
\]

令新增末端投影初始化为零，可以使初始输出严格复现父模型。

需要保留同结构 CE 对照，区分：

- 新物理表示的贡献；
- 新增容量的贡献；
- 新辅助损失的贡献。

这一阶段可以增加推理计算，只要收益来源清楚。没有必要为了维持原推理成本而放弃已证明有价值的物理观测。

|---|---|
| 固定全局 nuisance 子空间跨 TX 失效，但条件化后稳定 | 研究状态条件的低秩作用算子 |

| 前导残差有效信息接近零 | 改变观测或激励，避免继续增加不可辨识参数 |

# 十、真正再往数学物理深入，最终会走到“观测与激励设计”

如果上述分析发现，当前短前导在 nuisance 消除后只剩很少可辨识方向，那么更深的改进点可能是数据本身。

可以用：

\[
s^*
=
\arg\max_s
\log\det\left(
\mathcal I_{\mathrm{eff}}(s)+\epsilon I
\right)
\]

或最大化最小有效特征值，指导未来的激励设计。

具体需要的观测包括：

- 多种已知激励，而不是同一前导的更多重复；
- 不同包络与幅度分布，以区分 PA 阶数；
- 能分离线性链路与非线性响应的频谱结构；
- 更完整且位置可信的时间区间；
- 有同步物理 ID 的跨 RX 接收；
- 已标定的参考链路或接收机响应。

这些不属于当前数据契约内可以凭数字增强生成的信息。当前版本应先把已有观测中的有效方向提取出来；若信息边界已经被触及，就把下一步研究投入到能打破混叠的观测条件。

## 我建议最终冻结的下一版主方案

**训练主线：**

\[
\boxed{
\text{固定纯 CE 父模型}
+
\text{确定性有限风险 L/T}
+
\text{低秩预测、完整组差约束的 R}
}
\]

**特征研究主线：**

\[
\boxed{
\text{joint160 的稳健判别几何}
\quad+\quad
\text{同包自参考时间响应}
\quad+\quad
\text{可识别的非线性剩余响应}
}
\]

这次最有价值的深化，是给每个新增结构一个明确的问题：

- **L/T**：哪些允许的物理变化会使身份风险超过有限要求？
- **R**：哪些真实条件位移能跨 TX 预测，并可被保守修正？
- **特征空间**：哪些 TX 方向在 nuisance 尽力解释之后仍然存在？
- **新物理特征**：哪些可重复响应确实提供了现有表示未充分利用的信息？

只要把这四个问题分别验证，多解耦路线就能从网络分工，推进到**有可辨识性依据、有几何目标、有明确失效条件的射频身份学习方法**。
