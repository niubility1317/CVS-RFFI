# PAMF 与四种对比方法实验报告（2026-10-25）

当前 PAMF 半监督方法暂用普通伪标签；原接收机外推方案退出主方法。四种外部方法统一命名 RIEI、DRIFT、IB-RFF、SDG，正文使用“识别器”“DURA 恢复器”“直接识别”“恢复后识别”等可读名称，旧代号仅在附录追溯。

主比较为 198 个模型结果：四种外部方法的固定信道增强＋普通伪标签设置各 33 个，PAMF 监督与普通伪标签各 33 个。含四种外部全部训练设置时，保留 594 个模型结果。完整 11 个数据设置、三次模型训练、三类泛化、clean 与六种信道全部已冻结评分。

标准划分跨接收机、恢复后六景准确率：RIEI 56.7258%、DRIFT 60.7526%、IB-RFF 62.2090%、SDG 67.1214%、PAMF 监督 77.3597%、PAMF 普通伪标签 78.5161%。监督系统与伪标签系统的恢复器数据权限不同；同一使用全部源训练 IQ 的恢复器下，伪标签相对监督的配对差为 +0.1422±0.3601 个百分点，不能将完整系统 +1.1563 个百分点全部归因于伪标签。

本次新增训练、预测、真值评分与恢复器训练均为 0。新报告包为 `exports/reports/20261025-PAMF-PL-comparison-r18.zip`，不覆盖此前结果。PAMF 自身结构与机制实验的适用范围和待补项目见完整报告第 12 节；本次未发布补实验。
