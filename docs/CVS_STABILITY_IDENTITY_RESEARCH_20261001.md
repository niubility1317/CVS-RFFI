# CVS 性能优先源研究：相位增量与局部频谱差分

本方向在读取 attentive clean 结果前确定，仅依据合法源曲线和现有原生网络接口。attentive 源均值池化候选 E200 的源 V 为 97.7194%，最差源 RX 均值为 93.2963%；聚合层的可学习权重并未改善这些源指标。当前原生网络已有确定性的 PhaseDeltaStabilityStem 和 DSQFreqStabilityStem 接口，尚未在本轮基础网络比较中启用。本轮依据此前固定的结构假设登记新实验；候选、通道数和数学形式不根据 attentive clean 结果调整。已发布模型与产物保持原位置和内容。原始前瞻假设见 [预先固定的假设](CVS_PHYSICAL_STABILITY_HYPOTHESES_20261001.md)。

固定两个候选：`phase_delta` 在原残差 CVS 中增加原生默认 8 通道相位增量线索；`phase_dsq` 再增加原生默认 4 通道频谱差分线索。保留原始 time/frequency/PA 路径、宽度、深度、160 维嵌入、稠密融合、PA 残差头和 dropout。新增通道来自明确定义的物理统计，不扫描任意隐层宽度，不增加损失、增强、域骨干、接收机标签、checkpoint 继承或 query 拟合。

数学上，令 Sinc 后复特征为 z，邻时刻乘积 `z_t conjugate(z_(t-1))` 的实部和虚部分别对应 dot/cross。在统一复相位旋转下，乘积和包络均不变；原生 stem 用其相位角的 sin/cos、归一化包络和包络差分产生补充特征。此不变性只适用于该 stem，不适用于保留原始 IQ 路径的整个网络。有限精度、低能量样本和边界须用实际梯度测试核实。

局部频谱差分为 `(I-A_5)F`，A_5 是现有 5 点平均算子。它精确消去特征轴上添加的常数，但任意信道变化并不等于给这些压缩特征添加常数；不能据此声称完成信道补偿。原始频谱特征同时保留，避免将可能有身份信息的缓慢变化全部删除。

通信上，邻时刻相位变化可包含调制、载波偏移和相位噪声等响应，发射机与接收机均可能贡献；本结构不把 CFO 当成发射机专属指纹，也不抹去原路径中的 CFO 线索。物理上，包络差分和相位响应与非线性及记忆效应相关，频谱局部差分可能为非理想频谱纹理提供补充，但不唯一辨识硬件系数。RFFI 上检验的是确定性补充表征是否改善同一身份 CE 的特征学习，不能凭原理先宣称性能必然提升或实现 TX/RX 解耦。

执行矩阵为两候选×四固定 seed、同物理划分、scratch E200×50、普通身份 CE、无增强和域骨干，按既定四 seed 源 V/最差源 RX 分数冻结一个候选后默认仅测 clean。未选候选不测试；当前或历史目标成绩不用于选候选、系数、调参或选择性重跑。参数与计算是次要条件，必须实测性能、成本并报告负结果。

## 实际接口与验证

保留 native lite_d 的 Sinc24、time 48→72→96→96、frequency 16→32→32、PA48→64→64、emb160 和原 dropout。time_stability_channels=8、freq_stability_channels=4 是原生默认 cue 预算；不扫描隐藏宽度。新增输入列及 pointwise stem 是确定性统计的学习投影，并非独立观测、接收节点或新增标签。分支运行状态由实际构建的模型读取，写入 resolved、step、epoch、CSV 和详细文本日志。

PhaseDelta 用包内包络 `sqrt(I²+Q²+eps)`、`log1p(amp/mean(amp))`、包络差分、邻点角的 sin 和 cos−1，经过原生1×1卷积、GroupNorm 和 SiLU。包络差分没有幅度归一化，不声称整体增益不变。DSQ 在已计算的四个镜像压缩频谱特征上做局部平均差分，再作原生 pointwise 投影；原压缩特征在同一频率分支保留。没有真值、域标签、全局 batch 统计、适应器或额外损失。

4 项聚焦检查包括新增全部参数与原投影的真实 CE 梯度、整网单包推理与零/常量输入有限值、phase stem 在统一相位旋转下的数值一致、DSQ 在特征添加常数后的数值一致及源选择/无继承防护。性质检查只证明组件实现，不证明全网相位/信道不变或 clean 提升。代码从零构建，原 source run 仅分析引用，不加载任何其权重。

源矩阵与此前完全同物理 L6300/U56700unused/V27000、split392005、四 model seed、E200×50、batch128、AdamW2e-4/wd1e-4/cosine1e-6、FP32/no clipping。按四 seed E200 的源 V 与最差源 RX 等权最高分选一个，成本只在性能完全并列时比较。默认确认选中4预测与原20只读控制，共24行、同168000query、7RX/6类，prediction 完整后独立 scorer 读取 truth。未选候选不测试，不根据目标评分调参或重跑。

性能主要、资源次要。CPU profile 只核实计量，正式报告使用 N607 实测参数、实际梯度参数、MAC、FFT、状态、训练/推理耗时及真实峰值。新统计会增加额外逐元素计算，MAC 不覆盖 atan2、sin/cos、归一化、局部池化等成本，不将少量参数等同低计算。所有负 seed/RX/TX 结果保留，重复历史公开基准不是新盲测；仍仅 Phase1 clean 闭集，不作卫星、support 适应或新类声明。
