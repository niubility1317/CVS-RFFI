# PAMF 天基论文矢量插图：构图与使用说明

这些图为已有方法的十一种不同视觉表达，并非十一个模型或新增实验。每个 SVG 由矢量路径和可编辑文本组成，不内嵌位图；另提供矢量 PDF 和预览 PNG。波形、频谱和分类输出图形均为说明性绘制，不是实测数据或性能结果。

| 类别 | 版本 | 画面侧重 | 建议用途 |
|---|---|---|---|
| PAMF | A | 横向多分支、时频融合与残差融合 | 正文完整网络结构候选 |
| PAMF | B | 从同一 IQ 发散后汇合的特征流 | 正文紧凑网络结构候选 |
| PAMF | C | 三视图局部路径、固定位置顺序 | SIG-TIME 方法细节或补充材料 |
| PAMF | D | 完整分支及三视图局部编码 | 需要同时讲清结构和编码时使用 |
| DURA | A | 粗估计、观测作用、两阶段恢复 | 正文恢复器结构候选 |
| DURA | B | 两阶段与单阶段内部机制 | 需要解释先验和数据一致性时使用 |
| DURA | C | 基于波形的恢复迭代构图 | 简洁恢复过程候选 |
| DURA | D | 粗估计、作用估计、两阶段及阶段公式 | 需要展示恢复器内部机制时使用 |
| 系统 | A | 地面辐射源、星地传播与两条识别路径 | 论文整体系统图候选 |
| 系统 | B | 源域训练、冻结及直接／恢复后推理 | 重点交代数据权限时使用 |
| 系统 | C | 天基接收与两条推理路径 | 版面有限时使用 |

三视图来自同一时域中间特征的三个独立投影，固定排列只改变局部特征路径；原始 IQ 不被重排。时间特征和镜像频谱先形成时频特征，之后再与非线性记忆、参考响应和 SIG-TIME 特征融合。所有示意性分类输出和路径波形均不应读作实测性能。

DURA 的粗估计和观测作用由当前 IQ 及粗估计形成；两个恢复阶段各执行学习先验与两次 CG 更新。PAMF 和 DURA 分别使用合法源域数据训练并在推理前冻结。系统插画表示天基应用概念；当前论文实验是地面实测 WiSig 信号叠加模拟星地信道，不能据此声称真实卫星在轨验证。

本组不修改已选实验图或实验数据。图中文字默认使用 DejaVu Sans，最终投稿时应按照目标 IEEE 期刊的字号、尺寸、配色及可访问性要求再检查；用户可以在矢量编辑软件中调整各个文字和图形元素。
