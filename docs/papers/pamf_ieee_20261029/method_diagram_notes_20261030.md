# 方法修订与示意图说明

本版依据已经冻结的方法定义与实验结果组织论文，不改变训练、评测和结果。方法部分先解释每项设计需要解决的问题，再给出必要公式；输入形状、权重、日程和求解预算集中放在实验设置中，方便复现。

PAMF 的时域与镜像频谱提供互补表征，非线性记忆分支提供功放启发的归纳偏置，参考响应分支以已知前导为参照。SIG-TIME 的三个视图来自同一中间时域特征的不同投影；固定重排发生在局部特征路径内部，原始 IQ 和时域主干的先后顺序不被打乱。不同分支可受接收机和信道共同影响，不能解释成已分离的真实物理因素。

Tri-SIG-TIME SSL 在训练时利用高置信伪身份、跨源接收机配对、特征扰动和有标签梯度锚定。它不新增推理分类头，也不使用目标域更新。DURA 通过粗估计、观测作用估计、学习先验与两阶段数据一致性更新形成独立可选前端；恢复器所用源数据必须与相应实验设置匹配。
