# Phase1 星地恢复研究进展（2026-11-06）

本文只汇总 Phase1 地面 Main split 已固定预测、独立评分的结果。识别器为同一冻结 Tri-SIG-TIME SSL 原默认头，模型种子 2026092701；每景 168000 条，六个星地场景均为模拟信道。该测试集已被反复用于研发观察，不能称为独立盲测或真实卫星链路结果。

原始 clean 识别准确率为 86.538690%。若“下降不超过 3%”按 3 个百分点定义，六景各自必须至少达到 83.538690%；若按相对下降 3% 定义，须至少达到 83.942530%。当前没有任何下列候选同时满足六景目标。

**正收益：** crossfit、边界保护和复数融合的六个星地场景均高于同一 DURA 对照，但提升较小。crossfit 六景分别提高 0.029、0.074、0.138、0.158、0.371 和 0.545 个百分点；低城区仍比 raw clean 低 17.192 个百分点。三者训练均使用冻结识别器的特征或判决损失，不能冒充本对话无 F 训练方法，也不据目标结果选择新父权重。

**收益不均：** 直接物理混合在高、中、低郊区和高城区高于 DURA，但中、低城区分别低 1.515、3.107 个百分点。spectral prior 在中、低城区分别高 0.079、0.276 个百分点，其余四景低于 DURA。单场景提升不表示整体达标。

**负收益：** iterative geometry 六个星地场景均低于 DURA；该增强实验六景明显低于 DURA。直接注意力、教师蒸馏注意力、独立先验 PnP 和结构化先验等结果见 [前次七景汇总](../automation_reports/CV-SincNet/20261103-phase1-shared-physical-parallel-source-perf-s2026092701-r02/phase1_ground_comparison.md)。

crossfit、边界保护、复数融合、学习作用、spectral、geometry 和增强的原始逐景分数与配对修复/损伤记录分别在 N607 `runs/<实验ID>-auto-audit/independent_audit.json`；原流程完成标记为 `GROUND_SCORE_AND_INDEPENDENT_AUDIT_COMPLETE`。直接物理混合的正式评分和与 DURA 配对记录见 [直接物理混合](../automation_reports/CV-SincNet/20261102-phase1-free-mixture-ground-test-s2026092701-r01/paired_dura.json)。

## 已停止和本轮新证据

按用户要求停止的 physical fusion、physical wide、physical local teacher 均未完成七景评分，不能依据局部预测推断最终性能；共享全量重放也已停止。已完成的 geometry 与 spectral 结果保留。[停止记录](../automation_reports/CV-SincNet/20261103-phase1-shared-physical-full-replay-s2026092701-r01/termination_report.md)

本轮另完成一项无 F、无 TX 标签的源 IQ 物理诊断：在 672 条既有源样本上，即使使用不可部署的逐条理想步长，沿 DURA 的观测残差单方向修正，RX8 低城区平均 IQ NMSE 仅降低约 0.594%，28/48 条样本的最优方向为负。它不构成全方法上界，也不代表身份准确率。[源域诊断](../automation_reports/CV-SincNet/20261106-phase1-dura-innovation-source-oracle-s2026092701-r01/analysis.md)

新路线尝试把物理方向和独立的正交波形修正分开学习，保持 DURA 初始输出，并继续遵守源 L_s/U_s 配对 IQ、无 TX 标签与无 F 训练约束。此处仅为正在开发的架构，不是已经验证的恢复结果；完整 Phase1 七景测试和 3% 目标仍待实现。

## 正交波形修正的七景评分

正交修正版已完成七景预测及独立评分。它相对同一 DURA 在 clean 和六个受损场景均下降：六景分别下降 0.6655、0.5292、0.4893、0.6208、0.5220 和 0.4607 个百分点。低城区准确率为 68.3405%，距 raw clean 低 18.1982 个百分点；六景只有高郊区通过 3 个百分点口径，按相对下降 3% 口径则均未通过。完整配对及逐 TX/RX/day 见 [七景分析](../automation_reports/CV-SincNet/20261106-phase1-dura-orthogonal-ground-test-s2026092701-r01/analysis.md)。

正交保护版也已完成七景评分。六景相对 DURA 分别下降 0.3940、0.3577、0.3798、0.4065、0.4631 和 0.4524 个百分点；低城区 68.3488%。它七景准确率均高于无保护正交版，但两版训练硬件等执行条件不同，差异不能全部归因于保护项。两种 3% 口径均仅高郊区通过。[保护版七景分析](../automation_reports/CV-SincNet/20261106-phase1-dura-orthogonal-guard-ground-test-s2026092701-r01/analysis.md)
