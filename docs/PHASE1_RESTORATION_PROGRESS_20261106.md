# Phase1 星地恢复研究进展（2026-11-06）

本文只汇总 Phase1 地面 Main split 已固定预测、独立评分的结果。识别器为同一冻结 Tri-SIG-TIME SSL 原默认头，模型种子 2026092701；每景 168000 条，六个星地场景均为模拟信道。该测试集已被反复用于研发观察，不能称为独立盲测或真实卫星链路结果。

原始 clean 识别准确率为 86.538690%。若“下降不超过 3%”按 3 个百分点定义，六景各自必须至少达到 83.538690%；若按相对下降 3% 定义，须至少达到 83.942530%。当前没有任何下列候选同时满足六景目标。

## 源域训练准备缓存

GPU 7 上对固定 8192 条源 IQ 和三个模拟视图，完整重算两遍 DURA 上下文；缓存的接收 IQ、anchor、物理残差、方差、clean IQ 五类张量与重算结果逐值相同。首次准备 68.305 秒，再次准备 67.932 秒，缓存写入 0.197 秒、读取 0.172 秒，约 192.1 MiB；本次准备阶段节省约 67.76 秒，完整训练加速尚在实测。[详细结果](../automation_reports/CV-SincNet/20261106-phase1-dura-source-cache-benchmark-s2026092701-r01/analysis.md)。

同模型五轮现算与缓存训练的完整权重一致性和总耗时对照已登记并在 GPU 运行；运行中不改变既有预测。另核对实际 8192 条源拟合记录的公共元数据，包含 RX 1/3/4/6/8、day 1/2/3，并排除 RX4/6/8 day3；此前联合自监督源记录中将源 pilot 范围误写成训练集合的字段已更正。

完整五轮训练对照：现算 140.37 秒，缓存 76.63 秒，单次加速约 1.83 倍；五轮损失相同，但最终 22 个参数张量逐位不完全相同，最大绝对差约 4.21×10⁻⁷。因尚无同路径重复性对照，不能判断差异来源，不能宣称权重或目标预测完全不变。同缓存路径重复训练已启动。[完整训练对照](../automation_reports/CV-SincNet/20261106-phase1-dura-cache-training-parity-s2026092701-r01/analysis.md)。

## 独立双域网络七景结果

从零训练的 42308 参数独立时频网络已完成 168000×7 预测和独立 truth-last 评分。clean、高郊区、中郊区、低郊区、高城区、中城区、低城区准确率依次为 63.8167%、60.2976%、57.9232%、55.3345%、57.8798%、46.2423%、38.0161%；受损六景比同记录 DURA 低 24.05 至 30.79 个百分点，全部未达目标。源训练不使用 DURA、F、TX 标签、V 或目标；DURA 只参与冻结后的配对比较。[完整逐组与净纠错](../automation_reports/CV-SincNet/20261106-phase1-direct-dualdomain-ground-test-s2026092701-r01/analysis.md)。

同一缓存、相同种子的两次 GPU 完整训练也出现逐位差异，22 个参数张量中最大绝对差 4.25×10⁻⁷，与现算和缓存对照的差异同量级。这表明当前 GPU 训练自身不保证逐位重复，但不能排除缓存影响；尚不能声称目标预测相同。[同路径重复结果](../automation_reports/CV-SincNet/20261106-phase1-dura-cache-repeat-control-s2026092701-r01/analysis.md)。

为验证确定性训练，新增独立标识的源缓存：构建和使用均需匹配 CUDA 确定性配置，旧缓存不能混用。新的完整源上下文重算核验正在 GPU 7 进行；通过后才可比较确定性训练权重。

确定性源缓存的五类完整张量与重算结果逐值相同，重复准备 97.08 秒、缓存读取 0.23 秒。首个确定性训练 smoke 因 GPU 插值反向无确定性实现失败；修复后采用数学等价的切片插值，r02 真实 checkpoint smoke 已通过，并自动进入完整现算／缓存训练对照。切片插值与旧路径可能存在浮点舍入差异；尚无目标预测一致性证据。

修复后的确定性模式完整训练对照已完成：同一源数据现算与缓存得到的全部参数、五轮损失与源域分组结果逐位相同；完整进程耗时分别为 176.95 秒和 92.56 秒，单次加速约 1.91 倍，节省 47.7%。这是同环境源训练对照；不同于原普通路径的确定性插值可能改变浮点舍入，尚无正式目标预测逐位一致性的测试。[完整对照](../automation_reports/CV-SincNet/20261106-phase1-dura-deterministic-training-parity-s2026092701-r02/analysis.md)。

## 固定源表征恢复器

GPU 7 的真实权重小样本验证通过，正式五轮训练完成，优化耗时 114.7 秒，确定性源上下文缓存读取 0.23 秒；先前辅助编码器训练及缓存构建成本另计。源 pilot 的 12 个受损分组中 9 组波形 NMSE 低于 DURA，两类接收机的低城区组均较高。七景正式测试已完成，结果见下文“固定源 IQ 自监督七景”。[源训练与成本](../automation_reports/CV-SincNet/20261106-phase1-dura-fixed-iq-ssl-source-s2026092701-r01/analysis.md)。与先前联合训练编码器版本，编码器日程和执行设置均不同，最终差异不能只归因于冻结。

## 源多视图教师目标分析

在当前 clean IQ + 0.5 教师 IQ 二次损失中，无约束最优目标等价于 `(clean+0.5 teacher)/1.5`。由固定源三视图误差交叉项推得，使用另外两个视图的教师 NMSE 均值 0.014773，使用三个视图的均值 0.012170；按目标权重相对 clean 的有效目标 NMSE 分别 0.001641、0.001352。两视图教师与当前 DURA 误差的有效目标归一化平均内积 0.002322，三视图教师为 0.004057。这是源样本代数统计，不能推断目标身份效果；已登记的三视图学生配置不因该分析改变。[详情](../automation_reports/CV-SincNet/20261107-phase1-dura-multiview-consistency-source-s2026092701-r01/analysis.md)。
