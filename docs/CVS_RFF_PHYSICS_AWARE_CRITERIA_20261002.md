# CVS 的 RFF physics aware 研发标准

日期：2026-10-02。用户要求识别性能优先、参数成本次要，并要求真正的 RFF physics aware。本文明确下一步的物理问题与可验证标准，不用已经公开的目标测试成绩选择结构、阈值、超参数或重跑。当前实验范围继续是身份骨干、普通身份交叉熵、无训练增强、相同物理划分与 clean-only。

## 1. 物理目标与声明层次

需要建立“硬件变化 → 接收波形变化 → 身份表征响应”的可核查关系，并检查相同响应是否也能由接收机或信道产生。识别正确与硬件参数辨识是两个问题。

| 层次 | 应证明的内容 | 当前证据 |
|---|---|---|
| 物理约束算子 | 复数乘法、因果记忆、相位变换与数值梯度符合方程 | MP/GMP 算子已完成合成正确性验证；约束仅覆盖指定算子 |
| 物理可解释身份表征 | 对指定 AM/AM、AM/PM、IQ 镜像等变化的响应可预测；对明确的干扰变换具有可验证的性质；源域跨 RX 身份信息保留 | 仍需整体表征及实际输入链的证据，局部算子测试不能替代 |
| 发射机硬件辨识 | 在明确的可辨识假设下恢复 TX 参数或稳定的相对参数，给出接收机、信道与尺度不确定性 | 当前未知接收链和普通 CE 不足以支持唯一恢复声明 |

“真正 physics aware”的当前可执行目标是第二层。第三层需要额外的校准、已知激励或可辨识模型假设。第二层不要求把分类权重命名为某台发射机的 PA 参数，也不能承诺对任意接收链完全不变。

## 2. 首先解决可辨识性

项目观测模型为 `x=R_rx(H*T_tx(s))+n`。接收数据中的非理想性可能来自多个位置。以下是独立数学反例，不是实际 WiSig 硬件测量：

1. **复增益分解**：`r*t=(r/c)*(c*t)`。已知 `s` 仍不能唯一分开 TX 和 RX 的未知复增益。逐包 RMS 还会消除理想正标量增益，因此不能由当前输入恢复绝对发射功率。
2. **频偏归属**：接收 CFO 为 `f_TX-f_RX`，两端频率同时增加同一个值不改变观测。全部消除接收 CFO 也可能删去与 TX 有关的可用信息；保留 CFO 又不能把它直接命名为 TX 晶振参数。
3. **IQ 归属**：在允许可逆广义线性 TX/RX 链的平坦特例中，级联矩阵 `W_R W_T=(W_R Q^{-1})(Q W_T)` 不变；两组 TX 镜像系数可以不同。该特例足以否定无条件的唯一 TX 参数恢复，不能否定校准后的恢复。
4. **非线性归属**：单位信道下，将相同三阶无记忆失真放在 TX 或 RX，得到相同的波形。接收端的“非线性残差”不天然等于发射机 PA。
5. **已知重复前导码**：同一周期内，非线性失真落在原有激励频点的部分，可以被未知线性频响吸收；原激励之外的分量未必能吸收，但仍需排除 RX 非线性、频偏、边界及噪声。稳定重复段中相差一个周期的延迟也相同；起始瞬态与字段转换可能解除这个歧义。

广义线性 TX/RX 模型的物理依据见 [Korpi 等，IEEE JSAC](https://arxiv.org/html/1402.6083)。上述分解歧义是本文对该模型的推导，不是原论文对 WiSig 的结论。绝对参数不可唯一恢复不意味着 TX 无法分类；跨 TX/RX 的重复观测可以检验稳定的相对身份信息。

可执行反例脚本为 [identifiability.py](../experiments/cvs_rff_physics/identifiability.py)，独立登记为 `20261002-diagnostic-rff-identifiability-synthetic-m1-r01`。它不读取任何真实 IQ、源/目标标签、模型权重或评分。手工 12 音信号具有 L-STF 的频率位置及周期，但不是标准 L-STF 系数，也不是 WiSig 的生成器复现。

## 3. 已核实的官方输入处理边界

[WiSig 原论文，IV-B](https://arxiv.org/html/2112.15363)描述均衡和 CFO 加回。[官方 equalize_channel.m](https://github.com/WiSig-dataset/wisig-process-raw/blob/6530c6ed6be1d08544ac295040ed50f5babde86a/matlab_equalization/equalize_channel.m)提供更具体的参考实现：

- 25 Msps 先重采样为 20 Msps，检测 L-STF，校正粗、细 CFO；用 L-LTF 估计信道和噪声。
- 把 320 点 STF/LTF 合并序列分为五个 64 点块进行 FFT；只保留频点 −26 至 −1、1 至 26，施加 MMSE，再补零做 IFFT。
- 最后加回估计 CFO，重采样为 25 Msps。被频域置零的信息不能从处理后的输入直接恢复。

L-STF 在 20 MHz 下长 8 μs、占 12 个子载波，短重复周期 0.8 μs；对应 25 Msps 下 20 点。[MathWorks L-STF 文档](https://www.mathworks.com/help/wlan/ref/wlanlstf.html)

因此，当前 256 点输入不能直接当作未经过处理的完整 PA 输出。不能用处理后频谱中的“带外能量”声称测出了真实带外发射，也不能把任意局部突变都当作 TX 瞬态。64 点分块与 STF/LTF 转换需要单独检查；本文没有将参考代码重跑所得视图替换当前数据，没有变更 equalized=1、物理 ID 或 capsule。官方代码、论文和数据配置相符，也不等于已经逐包重建了 MATLAB 的实际处理链。

## 4. 下一步结构研发路线

先做源域输入与可观测量诊断，再固定下一轮网络。候选、预算与源选择规则必须在任何新的 target 访问前登记。

### 4.1 已知激励与失真响应

核实源 L/V 中前导码的位置、短周期、幅度激励范围以及处理边界。标准参考必须有可追溯的系数和与现有采样率一致的生成方式；没有核实时不能把手工多音模板冒充标准前导码。参考只来自公开协议，不能从 query 构造“无失真 clean 波形”。

身份表征应分别覆盖幅度响应（AM/AM）、幅度相关的相位响应（AM/PM）、带限内的复数记忆与 IQ 镜像。每一项写清变量的单位、物理作用位置、作用于理想激励还是 received IQ、与哪些未知接收量仍会混淆。对当前处理链已删除或无法激励的量标为不可观测，不强行增加参数头。

### 4.2 整体身份路径的干扰处理

任何不变性声明必须覆盖进入最终分类器的全部信息路径。保留普通 IQ 时间分支时，不能把一个不变 PA 分支的性质归给整个网络。仅在真实输入前端成立的性质可以用于设计：复增益、常相位、仿射相位、时延和多径是不同变换，不能用一个“归一化”统一宣称消除。

例如，直接由 received IQ 定义

`u_d(t)=x(t)conj(x(t-d))/sqrt((|x(t)|²+eps)(|x(t-d)|²+eps))`

及 `c_d(t)=u_d(t)conj(u_d(t-d))`，其相位对应二阶差分。对给定序列的 `x(t)→exp(j(θ+ωt))x(t)`，`c_d` 严格不变并保留非仿射相位变化。这是可验证的数学性质，可用于测试 AM/PM 响应，但不能推出 RX IQ 失真、多径或 Sinc 前置滤波后的 CFO 不变。删除 CFO 信息对身份识别的影响也需要合法源域证据，不能仅凭公式决定采用。该公式目前是诊断路线，尚未加入训练网络。

### 4.3 验证表征，不只验证公式

物理正确性证据采用与正式训练完全分离的合成已知激励，不作为训练增强。先固定硬件参数及干扰扫描范围，再测量：

- 改变指定 TX 非理想参数时，观测与表征如何变化；是否能由解析式预测。
- 保持 TX、改变明确允许的接收干扰时，哪些表征量稳定，哪些仍变化。
- 改变 RX 非线性或 IQ 镜像时，是否出现与 TX 变化相同的响应；必须保留反例。
- 用当前处理链的简化分量检查哪些信息被保留、混合或删除。简化模拟只声明覆盖的分量。

随后在固定 source L/V 上报告逐 TX×RX×day 身份性能、最差 RX、类内跨 RX 分散与类间分离。这些分析使用合法源标签，不启用域骨干或新增训练损失。跨 RX 稳定性由源域验证评估，不能把嵌入紧致直接写成真实硬件解耦证明。

## 5. 性能与发布收尾

下一轮仍从零训练，只用普通 CE；不加载旧受测权重、不引入训练增强或 query 拟合。性能优先的源选择规则继续固定：四 seed 源 V 与最差源 RX 得分最高优先，性能完全并列后才比较成本。参数量、计算和内存是次要报告项。

选中候选先冻结，再完成预登记 clean 单样本预测与独立 truth-last 评分，保留全部 seed、RX、TX 和负结果。目标成绩不用于重排候选、调整物理参数范围、修改结构或选择性重跑。当前 clean 集已历史暴露，结果只能按既有代理基准口径解释。物理证据和冻结测试上的识别收益须分别成立，才能声称完成本轮物理感知且性能更好的基础网络目标。

本文及合成反例仅完成下一步问题定义和可辨识性诊断；不是新网络的源训练或最终测试结果，也不自动授权扩大数据、增加损失或开展硬件采集。

## 6. 已知激励全量源诊断补充

`20261002-diagnostic-rff-known-excitation-source-manysig-m1-r01` 已完成，L6300/V27000、180单元，无模型/权重/target。标准系数来自独立解析的作者固定版本，按20MHz tone间隔在25Msps解析采样，未误用示例10MHz采样率。固定80:160窗口的V模板相关中位数0.997489、均值0.915368，支持该段与标准L-STF对应。源RX分组均值为0.998342、0.786960、0.994275、0.996249、0.801012；与RX及链路分组相关的差异明显，不能直接将模板残差称为TX PA/IQ参数。这是相关标量的分组证据，不是RX硬件贡献的因果分解。

L-STF还满足 `s*[n]=-j s[n-10]`（25Msps），共轭、半周期时移与复增益存在歧义。新的前端必须保留这个可辨识边界，不能输出已判定的I/Q约定。相位增益/CFO/时移合成检查、非标准周期负例和LTI残差混淆检查8项PASS；初始共轭判定断言的失败保留为数学修正证据。
