## 3. 每一轮实际推进了什么

### 首版：建立了多网络结构，但作用几何未转化为识别收益

首版 L/T 学习受控线性/时间变化，R 学习条件匹配 RX 统计残差，交互网络学习 `h11−h10−h01+h00`。辅助网络仅在训练时使用，没有第二个身份分类器或部署拼接分支。

32 行机制执行全部核验。独立 L/T/R 的各 seed 中，L/T 各拟合 9,990 次，R 拟合 9,989 至 9,990 次，R 身份约束各执行 9,989 步。问题不是“辅助网络完全没有运行”，而是所拟合的特征变化与需要改善的身份判别方向未被充分对应。R 又包含无法唯一分离的接收链路和传播因素，不能把模型残差当作纯硬件真值。

这一轮的负结果否定的是该具体目标、权重及作用方式的收益，不能直接否定所有多解耦结构。来源：[执行计数](../automation_reports/CV-SincNet/20261009-phase1-multi-disentangle-manysig-m32-r01/results/mechanism_execution_summary.json)。

### 源作用诊断：发现“特征拟合更好”与“判别预测更好”并不等价

四 seed 的固定参考诊断使用 1,920 个辅助拟合包和 960 个辅助留出包。身份模型原训练见过这些合法源包，因此这里的留出只针对辅助网络，不是全模型的独立泛化测试。

R 在 clean 的 h 作用 skill 为 22.57%，但组 margin 变化 MAE 为 0.9767，高于零作用基线的 0.7657。也就是在特征误差上超过零预测，却对身份判别变化预测得更差。L 的跨 TX 目标在 source practical_mid 的 G 后 skill 从 11.54% 提至 16.66%，clean 没有同向改善；T 也没有一致收益。这里的 skill 不是分类准确率。

因此辅助训练目标必须包含它最终需要解释的判别量；不能因为 h-MSE 降低，就默认可据其预测更新身份网络。来源：[完整源作用诊断](../automation_reports/CV-SincNet/20261009-phase1-multi-action-audit-manysig-m4-r02/results/summary.md)。

### 状态条件版：小幅改善成立，代价和梯度位置仍不理想

该版把接受作用样本的状态纳入作用网络，比较解析/神经增量、不同维度与阶数；R 采用独立分袋、TX 辅助留出和固定目的源 RX 锚点。默认虚拟作用只更新 G/分类器，EG 变体扩大到编码器，真实 IQ 路径正常更新编码器。

LTR 四 seed 的 R 有效身份调用为 10,840 至 11,765 次，尝试各 19,980 次，约为 54.3% 至 58.9%。这里的分母包含两种源条件，不应与后续版本的 9,990 次尝试直接比较绝对次数。单个关系总数超过六百万也不是六百万独立物理样本：共享组、重复分袋和重复调用都不能增加独立样本数。

结果支持“R 在该状态版 LT 之上有一定增量”，但不支持“越多网络越好”或“约束 E 的范围越广越好”。来源：[状态版资源与机制记录](../automation_reports/CV-SincNet/20261009-phase1-multi-state-action-manysig-m36-r02/results/resources.json)。

### 真实动作风险版：改为用真实 IQ 接受 L/T 约束，R 仍停留在虚拟后段

此版开始使用纯 CE 底座。L/T 网络提出动作，再通过真实 IQ 核验，身份 E/G/C 沿真实端点接收梯度。R 的目标改为五维竞争 margin 的均值、协方差和尾部风险，身份 CE/CVaR 仍只更新 G/C。

这比直接信任虚拟特征更接近可核验的作用，但小袋高维分布目标、参考与当前模型的重复审核，会带来统计和计算负担。补查已有 35 行目标评分后，完整三 seed 的单 L 增益仍小，LTR 只有一个 seed；不能把下一节特征版的日志统计写成该 48 行原矩阵的完整结果。来源：[动作风险版报告](../automation_reports/CV-SincNet/20261010-phase1-multi-action-risk-manysig-m48-r01/report.md)、[只读历史证据](../automation_reports/CV-SincNet/20261011-phase1-stage2-decouple-manysig-m12-r01/evidence/stage2_historical_target_readback.json)。

### 特征增强版：增加机制后，源域提升仍小，主要瓶颈已可定位

源证据覆盖 39 行 E1–E200，共 7,800 条完整 epoch，34 行有完整八视图源诊断；不是全 48 行完整矩阵。native、关系采样 S、LTR_S、LTR_S_AF5 的三 seed clean 源 V 均值分别为 98.5272%、98.5679%、98.5568%、98.5877%。七种源压力均值分别为 97.7656%、97.7935%、97.9981%、97.9884%。这些全部是源域指标，不能写成约 98% 的目标域准确率。

- **R 更新频率与可靠度不足。** 24 个 LTR 行中，R 正权重身份步占尝试的 5.13% 至 8.61%，中位为 6.69%；后半程可靠度跨行中位约 0.000464，再乘固定系数 0.01。更关键的是 R 路径仍 detach 编码器，所以对 E 没有直接约束。
- **统计任务超出当前袋支持。** 目标袋通常约 5 个不同物理样本，却需要估计均值、协方差和尾部；重复审核及多个小可靠度连乘进一步减少有效作用。拟合步数不能增加独立样本支持。
- **当前 Fishr 的后期梯度很小。** 18 个 LTR＋Fishr 行的稀疏审核点中，E 上 Fishr/CE 梯度比的跨行中位从 E41–E100 的约 3.67e−5 降至 E101–E200 的约 5.57e−9。不能把该现象泛化为所有 Fishr 无效，但可说明这套实现的固定早期校准没有保持后期作用。
- **L/T 的真实 IQ 路径确实作用于 E。** 三项真实动作合计梯度比的对应中位从约 8% 降至约 1.57%；该变化不是完全失活，也不能单凭有梯度证明最终收益。原 L/T/联合损失系数是固定 .015/.015/.02，epoch fraction 只影响辅助学习率，不能误写成损失又被一次 ramp 缩小。

梯度统计来自全部预登记每 888 步审核点，不是每个训练步。来源：[本地完整源审计汇总](../automation_reports/CV-SincNet/20261011-phase1-stage2-decouple-manysig-m12-r01/evidence/historical_feature_source_audit.json)、[已冻结的第二阶段设计第 3 节](CVS_MULTI_DISENTANGLE_STAGE2_20261011.md)。

## 4. 成本需要与收益一起解释

以下是现有共享 RTX 3090 环境下的源训练经过时间，不是隔离 GPU kernel 时间，也不能用来宣称固定加速倍数。

## 5. 实现失败与机制负结果必须分开

状态条件版 r02 修复 checkpoint 反序列化前的 native 模块初始化顺序，保持科学配置不变。特征版有 15 行已经训练完 E200，却在训练后诊断因真实 Dual 模型含两个 `t_proj` 而失败；修复将 hook 限定为身份骨干最终时间投影，并复用完成权重，不把诊断失败写成训练未收敛，也不借故重跑选择成绩。

另有历史稀疏梯度 epoch 归一化错误，动作风险版报告已保留说明；旧错误值不能继续解释为实际梯度余弦。以上是技术可靠性问题。R 的低有效率、Fishr 后期小梯度或没有测试增益，则是需要如实记录的机制结果；低性能本身不是停止、重启或选择性重跑的理由。

## 6. 归纳后的研发判断

1. **解耦对象应贴近判别损失。** 需要降低的是合法条件变化带来的额外身份判别损失，不是删除所有 RX 信息或强迫完整特征向量相等。通信链路与发射机非理想性可能占据相同方向，任意去域可能同时删除身份线索。
2. **每个辅助网络需要可核验的职责。** L/T 应提出有界且可在真实 IQ 上检验的变化；R 应证明能在辅助留出 TX 上预测条件组之间的判别差异。重构好看、调用次数多、网络互相独立都不是职责完成的证据。
3. **梯度路线和监督可信度必须同时成立。** 只有 G/C 梯度不能实现对 E 的直接约束；但对不可靠虚拟目标扩大梯度范围也可能有害。新设计采用真实 IQ 的弱条件裕量作为更新来源，并停止强条件在关系项中的直接梯度。这是待验证假设，不把局部 stop-gradient 当作全训练不退化保证。
4. **有限数据应先做低维、条件一致的统计。** 八个独立 ID 的袋并不支持任意高维分布建模。先固定同 TX/day/粗质量条件的标量组均值差，报告方差和覆盖；缺条件就记缺项，不以重复分袋补足独立样本数。
5. **可靠度不能同时承担太多职责。** 把拟合质量、方向、覆盖、当前学生状态全部连乘，会让分支长期无效。新设计分别记录交叉 TX 预测价值、方向模糊性和学生是否仍违反约束，可靠度只乘一次；不足时可为零，不能人为设正下限制造“有效”。
6. **用同父模型、同预算对照提高解释力。** C0−P0 反映共同第二阶段配方，C3−C0 反映多解耦组合增量。达到 84% 与证明多解耦有贡献是两个结论；若 C0 已达标、C3 不优于 C0，就不能把达标归功于解耦。

以上判断保留了设计冻结前的研发逻辑。此次历史补查没有产生按目标排名选择的新结构或参数，也不把描述性的历史最高值改成新矩阵主结果。第二阶段仍按预指定 C3 及三 seed 均值口径验收；现已完成的实际结果见下一节。

## 7. 新第二阶段验证回填

此处单独记录固定纯 CE E200 父权重上的 E40 微调，不与前述从零 E200 历史实验拼成同一组 seed。12 行 C0–C3 已完成 clean 测试，各组均为三 seed；本轮按用户明确范围没有追加 practical。

| 方案 | 三 seed clean 均值 | 相邻机制增量 |
|---|---:|---:|
| P0：E200 父模型 | 80.5264% | — |
| C0：纯 CE 第二阶段 | 80.8746% | C0−P0：+0.3482 个百分点 |
| C1：增加父正确样本保护 | 80.7558% | C1−C0：−0.1188 个百分点 |
| C2：增加真实 L/T 约束 | 79.6325% | C2−C1：−1.1232 个百分点 |
| C3：增加 R 单向关系修复 | 79.6698% | C3−C2：+0.0373 个百分点 |

**C3 没有达到 84%，相对同预算 C0 下降 1.2048 个百分点。** R 的小增量在三个 seed 上都为正，但不能据此宣称显著的大幅收益。L/T 组合是该增量矩阵中的主要下降来源；本轮不能继续拆分为 L、T、动作 CE 或 drop 的单独因果效应。

本轮源诊断已经验证 R 梯度可到达编码器，目标增量仍很小；因此“修通梯度”解决的是执行正确性，不能独立解决监督价值和覆盖不足。源域还观察到预定审核点上的加权 drop 梯度明显大于 CE，这支持作用强度可能不合适的解释假设，但不是按目标分数回调系数的授权或新配置。该结果与旧版 Fishr 后期弱梯度放在一起，说明“辅助作用更大”与“识别更好”没有简单单调关系。

实际共享准备约每 seed 24 至 26 s，E40 训练、逐轮验证及最终源诊断的三 seed 平均合计，C0 为 337.36 s、C3 为 410.99 s。它证明复用父模型的短程执行已落实，不证明性能目标完成。源 E200 历史成本继续单列；不得把旧训练耗时按 epoch 比例外推成加速倍数。完整逐 seed、成本、源诊断及独立测试技术恢复见 [第二阶段正式报告](../automation_reports/CV-SincNet/20261011-phase1-stage2-decouple-manysig-m12-r01/report.md)。
