# PAMF SSL 分支风格干预与 WiSig 主对比

PAMF 现有 MixStyle 在半监督阶段混合同伪标签、跨源接收机样本的 `time_down` 和 `t2.pool` 通道均值与标准差。这两处干预也会改变后续时域读出和 SIG-TIME 的输入。频域、PA 和参考响应有各自的张量轴与物理含义。首轮比较直接迁移 MixStyle，以及对各分支保留结构的干预。

## 现有证据

- 正式三视图 PAMF 的 8 个历史模型在 WiSig Main split 的 clean 为 86.6307% ± 1.0082%，六种 practical 均值为 70.8577% ± 0.4990%（样本标准差）。从同一正式 run 取 seed 2026092701 的冻结 E20 作为共同前缀，并以该 seed 的冻结 E50 预测核对重放和计算逐物理 ID 净纠错。见 [方法定义](PAMF_METHOD_DEFINITION_20261027.md) 和 [原对比](PAMF_REPL_SHUFFLED_VIEWS_20261027.md)。
- 较早的 U-MixStyle 与去 MixStyle 探索出现 clean 与 practical 不同方向的变化，训练配方和时序设置与本次不完全匹配。当前配方下，是否需要直接扰动其他分支，仍需同前缀对照。见 [历史 SSL 排名](analysis/PAMF_SSL_METHOD_RANKING_20261027/report.md)。
- 原论文以实例级通道均值和标准差生成训练风格。频谱幅值交换与条件重校准是可迁移的思路。它们在视觉域的证据无法确立 WiSig 上接收机、传播路径与发射机证据的分解。见 [MixStyle](https://arxiv.org/abs/2104.02008)、[Fourier DG](https://openaccess.thecvf.com/content/CVPR2021/html/Xu_A_Fourier-Based_Framework_for_Domain_Generalization_CVPR_2021_paper.html)、[CrossNorm/SelfNorm](https://openaccess.thecvf.com/content/ICCV2021/html/Tang_CrossNorm_and_SelfNorm_for_Generalization_Under_Distribution_Shifts_ICCV_2021_paper.html)。

## 配对与作用范围

当前学生用未干预 IQ 在 eval/no-grad 下出硬伪标签，阈值 0.95。仅对已接受、同伪 TX、不同合规源 RX 的配对干预。每一步的原配对、Beta(0.1, 0.1) 系数、两层 Bernoulli(0.5) 随机数在六个对齐 U 学生前向之间共享。直接分支共用原中层 Bernoulli 门，以统一基于步骤的干预概率。带时域 MixStyle 的行保留浅、中层原门。每个损失和梯度保护继续使用原监督与原 REPL 目标，去除时域干预后仍生成原配对供联合特征外推使用。无有效 donor 时该样本按原路径前向。

候选统计均 detach。donor 不参与 anchor 的梯度。新模块在当前 U 学生每次前向临时挂钩，教师、L_s、V、预测沿用原图。所有行保留固定局部排列 `[0,5,3,6,2,1,4,7]`、三条独立 SIG-TIME 投影、默认联合 160 维头和 232993 个部署参数。新增骨干前向数为 0。

## 分支候选

令 \(a=1-\lambda\) 为 donor 权重。(i) 为 anchor，(j) 为同伪 TX 跨 RX 的 donor。所有限制在目标访问前固定。

|分支和层位|本轮干预|保留的结构与解释|
|---|---|---|
|时域 `time_down`、`t2.pool`|原 MixStyle。分别沿时间轴统计每通道均值、标准差，用其凸组合重标定标准化轨迹。|原时间相对顺序与训练期路径。此操作也会传到签名的共享时域输入。|
|频域 `f2` 输出|直接 MixStyle 沿压缩频率轴做全带通道矩混合。独立结构化行把第 0、1、2 个余弦模式投影定义为平滑分量，只加 donor 与 anchor 的平滑差。|后者保留该层在正交补中的窄带结构与原频率轴。每通道扰动 RMS 上限为原通道 RMS 的 25%。这些是学习特征的低阶频谱模式，仍需检验是否包含 TX 线索。|
|PA `pa_b2` 或 `pa_lift` 输出|直接 MixStyle 只作用于学习的中层 PA 时序特征。结构化行用零延迟一阶 I/Q 的 8 段对数 RMS 估计慢包络，插值后沿原 memory lag 对齐。|结构化行对同一延迟的所有 I/Q 对和奇数阶对施加共同正增益，保留其方向及同延迟阶间幅度比。完整 log 增益幅度至多 0.22。这个量描述基底特征扰动，实际 PA 系数和接收通道仍相互混杂。|
|参考响应 `response` 输出|在 12 个有序有效音调的复数残差上拟合常数、线性、二次模式，混入 donor 的低阶差值。复数增量峰值上限 0.15，并受原半径 4 的剩余幅度约束。|保持原高阶残差、质量变量、相干性及 CFO 屏蔽坐标。此干预位于固定参考计算之后，参考模板和实际符号序列始终保持。|
|三视图 SIG-TIME 局部投影|每个视图的 96→6 投影、tanh 前，按四个窗口计算投影轨迹相对端点连线的 RMS，以 donor 的窗口弯曲能量作有界缩放。|每窗首末点逐值保留，六坐标共享每窗比例，原固定排列与时间通道均保留。既有一阶端点增量保持，二阶路径面积可以改变。|
|联合特征|原 REPL 已有在 160 维上沿同伪 TX 跨 RX 方向外推的分支。新增行只联合上述局部干预。|四个结构化作用共享 donor 与剂量，保留原联合外推。联合行用于检查叠加结果，单独的分支贡献由对应单干预行判断。|

## 首轮预登记比较

十行的编号和输出以 [实验登记](../automation_reports/CV-SincNet/20261124-phase1-pamf-wisig-branch-style-m10-r01/experiment.json) 为准。

|行|时域 MixStyle|直接分支干预|
|---|---|---|
|time|开|原时间基准，按本轮共同 E20 重放|
|none|关|关闭直接统计干预，保留其余 REPL|
|frequency-moments|关|频域均值和标准差|
|frequency-envelope|关|频域平滑包络|
|pa-moments|关|PA 中层均值和标准差|
|pa-envelope|关|PA 基底共增益包络|
|reference-trend|关|参考响应复数低阶趋势|
|signature-bend|关|三视图局部曲率剂量|
|time-frequency-envelope|开|频域平滑包络|
|all-structured|开|频域、PA、参考、签名四种结构化干预|

每个候选先与 `none` 比较单独干预的绝对效果，再与 `time` 比较对当前配方的增益。直接矩混合与结构化处理在频域和 PA 各有一组匹配比较。时域×频域的交互用差分中的差分 `time-frequency-envelope − time − frequency-envelope + none`，对 clean 与 practical 均值分别报告。频域和 PA 结构化候选的算子及在 PA 中的干预层位均不同，PA 对比识别的是整个机制的差异。全部结构化的效果同时包含多个干预，不能归给单个分支。

沿用已验证的六类 WiSig Main split。源 RX 1/3/4/6/8，D1–D3，L_s 6300、U_s 56700、V 27000。U_s TX 始终隐藏。测试 RX 0/2/5/7/9/10/11，D1–D3 跨 RX 126000 条、D0 跨 RX 和日期 42000 条。六种 practical 为 suburban 和 urban 各 high、mid、low，和 clean 共用 168000 个固定物理 ID。共用同 seed 的原 E20 前缀，后续各自 E21–E30 与 E31–E50，新增每行 6660 步，累计每行 11100 步。训练沿用这个历史主配方的 L 侧 As、U 侧原始 As 槽和无额外卫星拼接的实现。正式结果使用原默认头直接识别，不接恢复网络。

每行 E50 冻结后自动完成两人群七景预测。独立 CPU scorer 在该行及历史对照的全部 opaque ID 和决策闭合后读取真值，产出准确率、Macro-F1、修复、损伤、净纠错和 RX、日期、RX×日期、TX 分层。训练代码保存实际接受率、配对有效数、逐层干预次数与采样 RMS。区分历史时间行和本轮时间重放的差值。单 seed 只能建立该训练种子的比较证据。初筛证据参考事前设定的 clean +0.5 个百分点、六景均值 +0.5 个百分点、单景回退不超过 1 个百分点三个条件，相对本次重放时间行计算。结果只用于判断是否存在值得独立验证的信号，后续模型和评估划分不由本轮部署自动选择。

## 后续可检验的干预

1. **频域**。在原镜像压缩频域特征进入 `f1` 前，按实际频带分段估计幅度趋势，冻结镜像相对关系。学到的低频模式若同时改变窄带身份细节，下一轮用互补滤波、分段有界增益和纯相位对照分别定位。只在原图实际保留复相位的层开展相位候选。
2. **PA**。对每个原始样本的高阶／低阶复数比按同一延迟建模，只比较高包络与低包络下的幅相残差。可用源 L 的同 TX 跨 RX 配对估计接收机扰动范围，用 U 的可靠伪标签作训练约束。需报告门控前后的阶间差、有限能量段的覆盖与源 V 的真实身份保持。传统 PA 的 AM/AM、AM/PM 参数解释需要校准测量才能成立。
3. **参考响应**。当前低阶加性扰动后，可比较乘性复数校准。先在同 TX 源对估计平滑的 log 幅值差及连续相位斜率，保留高阶复相位残差。深衰落或低相干区域跳过该变换并记录覆盖。检验相干度门槛是否使少数 RX/TX 系统性地 失去可混样本。
4. **SIG-TIME**。先比较窗口级弯曲强度与时间参数化。可对内点作有界单调时间重采样，或对六维局部残差施加收缩协方差变换。单窗口只有 8 点，协方差应由多个源窗口聚合并向对角阵收缩。保持实际固定排列、端点、时间坐标及各视图的独立投影。
5. **分支路由及损失**。用源 L 同 TX 跨 RX 差分估计各支的主要接收机变化方向，在 U 对这些方向做裁剪扰动，或让同记录的原视图和扰动视图经过原默认头并做一致性正则。比较时匹配 U 权重、样本曝光与额外前向成本。将共享 donor 与独立 donor、边缘统计与交互统计作为显式对照。
6. **诊断与扩展**。对源 V 的已接受伪标签核对精度与配对纯度，用既有默认头测每个分支干预前后的同记录类别余量与各 TX 损伤。按 RX×日期检查覆盖，区分变换本身强度、U 接受率和配对样本分布的影响。跨 seed 稳定性与独立验证集各有用途，Main split 的复测保留历史曝光背景。
