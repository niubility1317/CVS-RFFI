## 结论与实际状态

2026-10-22 再次核查后，现有主比较的配置覆盖完整，但机制归因仍有明确缺项，不能仅以“实验数量很多”认定证据完备。本次按实际生效的任务配置、输入绑定替代表和已登记矩阵核查，不读取目标得分来决定补哪些实验。

实际配置核查确认：17 个数据契约×3 种训练设置×3 个 F seed，共 **153 个主比较逻辑行**均已安排；SIG_TIME、NO_TIME、NO_SIGNATURE、NO_PA、NO_REFERENCE、COV_X3、SHUFFLE_TIME、WRONG_REFERENCE 八个监督结构各 3 seed 也均已发布。当前 owner 是 `20261022-phase1-T1-DURA-stop-invalid-F-control-r01`；只读快照为 379 COMPLETE、25 RUNNING、449 QUEUED 和 1 个已由 r02 替代的历史时延失败。COMPLETE 是阶段任务状态，不等于所有论文面板已完成。

本次固定 **15 次新 F 训练、75 行只复用权重的目标读出、15 行源侧诊断和一套新增结构时延**。合计 90 行新目标读出、211 个后续阶段任务；**新增 G 训练为 0**。它们目前是 `PLANNED_NOT_PUBLISHED`，尚未加入远端运行队列。现有健康任务、模型、预算和调度不变。实现、针对性验证和不可覆盖发布排在当前已登记训练／预测范围之后；本次没有把“已登记”写成“已开跑”。

唯一逐行补充矩阵由 `experiments/cric_dura_comparison/completeness.py` 生成，五个科学 run 的 `experiment.json` 记录具体行及来源；本报告解释研究问题和边界，不维护第二份逐行配置。

## 缺项一：跨 RX 配对本身是否必要

现有“有／无 CRIC”只能检验对比项的总作用，不能独立证明不同物理 RX 的正对优于一般监督对比。旧 ALL_TX 属于旧日程，不能拿来填当前 T1 单元。

新增两种正对策略，各 3 seed，共 **6 次 native T1 训练**：

| 新设置 | 正对定义 | 保持不变 |
| --- | --- | --- |
| ALL_RX_POS | 同 TX、任意 RX、不同物理 ID | 原六 L 前向、特征层位、负对、温度 0.2、warm5/ramp10、最终权重 0.1、采样与完整 T1 的 U 机制 |
| WITHIN_RX_POS | 同 TX、同一物理 RX、不同物理 ID | 同上 |

同一物理 ID 的重复曝光不能成为正对，也排除 self。负对始终是不同 TX；按有效 anchor 和正对数归一化，记录覆盖与数量，无合法正对时返回有限零。两控制、原默认跨 RX 和修复 F16 共同比较，不能用变化后的正对数量解释为额外标签或额外训练预算。

每个模型仍从零开始自身 20＋10＋20，累计 E50／11100 更新，三 seed2026092701/02/03；F0 数据不变，接同一个合法 DURA-LU。raw/G 七视图冻结后独立评分。新增行也执行同一组源 L 几何诊断。此项是 F0 机制研究，不是新增 m=5 源数量扫描。

## 缺项二：Sinc 与 PA 的结构先验对照

删除分支会改变容量，不能单凭掉分证明物理先验。新增三种严格监督结构，各 3 seed，共 **9 次 F 训练**。以修复后的 F15 三路 CE＋默认拼接为共同基线；不读 U、不启用 CRIC/RDrop/EMA，LS0，全部 E50／11100 更新，raw 与 G-L 七视图。

| 新设置 | 具体修改 | 可以回答与不能回答的问题 |
| --- | --- | --- |
| SINC_FIXED_INIT | 冻结从 scratch 初始化得到的 24×79 Sinc 滤波器，后续主体／默认头继续联合训练 | 检验频带学习的作用；比自适应版少 48 个可训练频率参数，不称完全同优化器控制 |
| FIR_SINC_INIT | 将同一批 scratch Sinc 核复制为 24×1×79 无约束实数 FIR，I/Q 共享、无 bias、相同 padding；其他初始张量不变 | 初始频响相同，比较持续 Sinc 约束与一般 FIR 的差异；FIR 为 1896 个可训练 tap，非等参数。使用普通 AdamW 参数单位，不能套 Hz 梯度倍率 |
| PA_LINEAR_LIFT | 所有高阶记忆多项式槽换成相同延迟的 order1 IQ，并复制到原宽度；保留 clip、门控、卷积、PA 统计和投影 | 保留全部可训练容量，单独检验高阶 lift；有效秩下降，其他 PA 非线性仍在，不能称“整个网络线性化”或真实 PA 参数恢复 |

Sinc 控制必须在相同初始核和相同源 IQ 上验证前向、I/Q 权重共享、冻结梯度或 FIR 梯度、默认头梯度及优化器实际参数组。冻结核须为 scratch 初值，不能偷换为训练后核。新增控制的预测 reader、CUDA 图与 optimizer 必须实际适配，未完成实现前不发布为可运行实验。

补充这三种结构的 F-only／G-L＋F 独占时延：3×2×5 batch×5 round=**150 case-round**。既有 X3_CE 基线用原监督结构面板，统一 500 和原监督 450 case-round 不重复。CRIC 正对策略不改变部署图，不重复计相同网络的推理时延。

## 缺项三：将 F 与 G 使用 U 的效果分开

实际有效配置显示：全部 17 契约的 Sup-F 已有 raw、G-L、G-LU；PL-F 只有 raw、G-LU。缺少的正是 **PL-F＋G-L，共 17×3=51 行**，不是 51 次新训练。

| F 的训练 | G-L | G-LU |
| --- | --- | --- |
| matched Sup | 已安排 | 已安排；单独标为 F 无 U、G 有 U 的诊断 |
| ordinary PL | **本次补 51 行** | 已安排 |

只复用合法、已冻结的 PL-F 与同契约 G-L；raw 复用原决定。每个契约独立计算两种 G 下的 PL−Sup、两种 F 下的 G-LU−G-L，以及差分中的差分。由相同 seed、相同物理目标 ID 和相同视图计算，不把 PL-F＋G-L 称全监督系统。原 native T1 监督目标和门控不同，不能放入这个普通 PL 的 2×2 当作同因素的一格。

这个补充覆盖 F0、F1、F2、chrono、ManyRx、标签比例和全部已授权源数量条件，新增 F/G 训练均为 0；F0 仅复用原有／修复已安排的权重，不新增五源数量训练。

## 缺项四：给外部方法相同的恢复预处理

只比较 PAMF＋DURA 与外部 raw，无法回答收益有多少来自通用恢复器。新增 **F0 四方法 Full／自身 CE×三 seed=24 行**冻结读出，均接现有 F0-G-L，严格不让系统读取 U IQ。

这 24 行保留外部模型、默认头、原预算、标签映射、输入归一化和冻结权重，不重训、不适配。先在合法源 L 上核实解包后的原生推理一致，再对同一份收到的 IQ 执行 G-L→外部模型；既有 raw 决定直接复用。报告每方法内部的加 G 收益，再在相同 G-L 下与 PAMF 比较。结果无论正负都保留，不按场景选择绕过 G。

它属于“冻结恢复器的跨骨干迁移”，不冒充外部论文提出的 DURA 训练方法。外部原生 Full 仍与自身 CE 配对比较；不能因为新读出更差就删掉。此处不重复追加 24 行外部 PL＋G，普通 PL 与 G 使用 U 的完整归因已由上一节的 51 行提供；若以后声称恢复器在所有外部 SSL 配方上都普适，须另立相应范围。

## 缺项五：CRIC 的源几何不能只写在文字里

已发布的物理诊断随监督结构执行，不能自动证明 native CRIC 改变了实际部署几何。新增原最终 T1 与修复 F01/F02/F03/F16 各三 seed，共 **15 行冻结源侧诊断**；无训练、无 target 预测、无拟合 RX/TX 探针。

各行使用同一组 L_s 物理 ID，每 TX×RX×day 最多 8 包，F0 最多 720 包。沿用已固定的 11 项源干预和同日 anchor 等权几何，联合报告同 TX 跨 RX 距离、不同 TX 同 RX 距离、间隔、默认头翻转与有效 anchor 数。新增正对策略和 Sinc/PA 结构的这项诊断随各自读出执行，不再建重复任务。

另外保留 Sinc 初始／末态核、频响与合法频带参数变化。它是结构解释；不能把可视化漂亮、波形 NMSE 改善、源几何变化单独当作目标识别收益。

## 补充执行顺序、成本和交付

1. 现有有效任务按原计划完成；补充设计现在固定，不依据随后返回的 target 分数增删或挑 seed。

3. 15 个新 F 各完成后自动接七视图预测和独立 CPU truth-last。可复用的 75 行只补恢复读出；15 行源诊断不读 target。正式时延等待独占 GPU，不能终止健康任务抢占。
4. 按三 seed、逐 RX/TX/day、Macro-F1、净纠错、完整 F/G 父成本和实际时延汇总；补入 IEEE 实验部分和新不可覆盖导出包。当前大矩阵完成后不能因旧范围闭合提前删除监控。

## 不为“完备”无限扩张范围

当前源数量结论明确限定一条预定嵌套链；三个模型 seed 不代表三个源 RX 子集重复。若论文要泛化为任意接收机组合的因果规律，未来须有多组合重复；本轮不伪造这个结论，也不重复已取消的五源扫描。

G 机制当前不声称复制×KD 完整重复 2×2 的交互；m3 交叉设计用于区分已有 G/F 波动，不改称全部 F0 三条独立完整系统。真实硬件参数辨识、真实卫星采集、Phase2 适配、unknown 拒识均不属于本轮 Phase1 完备性的必需单元。目标驱动调参、重排队列、选择性重跑，以及解封 U 真值的所谓全监督上界不加入本轮。

上述边界应写入实验解释。补齐后应称“当前明确比较与归因问题得到覆盖”，不能用实验数量承诺期刊分区或把代理模拟夸大为在轨结论。
