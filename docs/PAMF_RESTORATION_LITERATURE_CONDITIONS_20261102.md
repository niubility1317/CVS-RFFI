# 身份保真恢复：原始论文的条件核对

**论文支持把波形恢复与识别效用分别检验，但没有给出本任务“最多恢复成 clean 几成”的数值，也不能替代本项目七景实测。** 本次定向核查 5 篇原始论文，关注它们使用什么信息、优化哪个输出，以及哪些条件可用于当前恢复器。不是系统综述或跨论文排名。

当前主验收仍为原地面完整 Tri-SIG-TIME SSL/defaulthead/Main：六景分别距同一 raw clean ≤3 个百分点，并保持 cross_rx 与 cross_both 各自的 clean 性能。原 raw clean 为145385/168000，合并场景门槛为140345条正确。原 Main 已有开发曝光，不声称新的盲测。

## 对当前网络研究的具体约束

**识别支路接在哪里，比“联合去噪与识别”这个名称更重要。** 潜在编码特征容易分类、解码 IQ 接固定识别器容易分类、真实 TX 正确率提高，是三个不同事件。PSC-DAE 的分类头接编码器；本项目正在检验的 CovarianceFeature 则将原冻结 F0 的连续特征损失直接施加在当前 received 经实际物理后验得到的 IQ 上。梯度回到 G，F0 不更新；不用 TX/logits/类别原型或新身份头。这个设计差别是代码事实，效果仍需正式测试，不由论文推出。

**均衡的目标应是移除新增接收作用，同时保留参考 IQ 中已有的设备细节。** LTE-V2X 论文显示了利用协议结构区分二者的一种条件化方法，并未证明任意窗口都可无损分离。本项目 R07 的 clean 已是原地面记录，不是理想发射符号；恢复到理想调制波形会改变参考任务。当前 full Action 相对 MSE、IQ NMSE 和 F0 特征误差也不能相互替代。

跨接收机的方法需要特别核对“是否训练新识别器、是否用 TX 监督、是否使用目标接收机校准”。论文中的 DG 与 DA 也不是同一个权限范围。本项目已有源 RX/day 特征几何结果不支持“源方差加权放大 RX 均值”这一具体解释，不能仅因 DRIFT 使用域正则就直接采用删均值投影。[既有源几何证据](../automation_reports/CV-SincNet/20261101-diagnostic-Restore-Fgeometry-RXday-s2026092701-r01/analysis.md)。

## “恢复 clean 几成”仍不能给单值

在当前相同 Main 基座，DURA 低档城区真实 TX 准确率68.801190%，相当于 raw clean 准确率的79.503388%。这是已达到的任务准确率比例，不是波形或身份信息恢复率，也不是所有恢复方法的上限。[当前基座完整汇总](PAMF_RESTORATION_MAIN_PERFORMANCE_AUDIT_20261101.md)。

完整源协方差、真实源 Action 和噪声方差标量的诊断中，低档城区 Fclean 一致率87.743733%；该源内有限 Gaussian 模型拥有部署不可得的真实参数，而且 Fclean 可以保留原识别错误，因此它也不是 Main 真 TX 的上界。噪声路径还没有获得实际噪声实现或完整 I/Q 协方差。[源参数归因与信息范围](../automation_reports/CV-SincNet/20261102-diagnostic-Restore-covariance-parameter-source-s2026092701-r01/analysis.md)。

据既有理论说明与这些信息条件，本项目仍需分别报告波形误差、Fclean 保持、真实 TX 修复/损伤和 clean 性能。固定 F0 的 raw clean 准确率并非最优分类器的 Bayes 准确率；改善 F0 对观测中已有信息的使用，有可能纠正部分 clean 分类错误，也不能据此声称生成了新的身份事实。[已有数学边界说明](../automation_reports/CV-SincNet/20261101-phase1-Restore-FeatureCond-E30-s2026092701-r01/theoretical_limits.md)。这些是问题定义与推断，不是当前新 G 已获收益的结论。
