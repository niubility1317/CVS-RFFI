# PAMF Phase3 再优化设计：保留身份几何的开放识别

**下一版首先解决“优化后未知设备身份结构变弱”的问题。** 原 PAMF 仍指 Tri-SIG-TIME SSL，Phase1/2 的固定模型和历史成绩不变。新候选暂称 PAMF-OW protected160，不将设计写成已完成实验或已达到目标。机器可读定义见 `configs/pamf_phase3_protected_geometry_20261030.json`。

## 为什么需要重新设计

最近完成的 physical-open 主 P_LOE，在跨接收机 G10 开发测试上为 A_K69.270833%、C_K95.833333%、R_U20.138889%、H31.205502%。原 F0 在同一 P1 输入上的闭集准确率为 72.916667%，开放识别总损伤为 3.645833 个百分点，超过 2 个百分点；高已知接收率没有转化为高未知拒识率。[实际开放结果](PAMF_PHASE3_PHYSICAL_OPEN_RESULTS_20261030.md)

随后固定五种表征，对已有源未知设备做独立几何诊断：原 F0 fused160 的同时跨 RX/day 近邻命中率为 76.603175%，P_LOE fused160 为 75.523810%，独立 open64 为 67.301587%。open64 的 RX 组间方差比例为 0.178240，原 fused160 为 0.028875；TX 比例则从 0.421118 降至 0.085569。全部特征非零、有效秩非零，问题不是简单常量塌缩。[完整几何结果](PAMF_PHASE3_PHYSICAL_GEOMETRY_RESULTS_20261030.md)

因此，当前证据支持“拒识表示没有保住足够的身份结构”这一工作假设，不能仅将问题归因于阈值。它还不足以证明 RX 是唯一成因，也不能用这些已暴露的源设备统计选择未知类别、训练标签或阈值。

VICReg 的方差与协方差约束用于避免常量塌缩，不直接规定哪个方向必须承载设备身份；本项目实测也不能以更高秩替代身份有效性。[VICReg 原论文](https://arxiv.org/abs/2105.04906) 另一项图像开集研究报告闭集质量与开放识别的相关性，但该结论不能保证跨接收机星地 RFFI 在同一运行点达到本项目目标。[开放识别研究](https://arxiv.org/abs/2110.06207)

## 固定任务与验收口径

后 Phase1 的新输入统一为已固定 G10 星地观测；本轮沿用 P1，即同一 received 经冻结 DURA v1.0 恢复的输入。跨接收机是默认条件。P0 若在未来独立设计中使用，也仍是星地 received，不是 clean。

主报使用真实设备等权的宏平均 A_K、R_U、H，C_K 作为硬约束。A_K 是全部已知样本中“分类正确且被接收”的比例，不能用接收样本内准确率替代；H 为 A_K 与 R_U 的调和均值。v3 目标保持：C_K≥90%、R_U≥90%，A_K 距同输入原 F0 闭集不超过 2 个百分点，逐 RX/场景/设备明示缺项，不以均值掩盖预登记硬门槛。[指标定义](PAMF_PHASE3_METRICS_20261029.md)

以现有开发 Q 的已知 576 条为例，原 F0 正确 420 条。若原身份输出完全保持，最多只能额外拒绝其中 11 条正确预测，才能将损伤限制在 2 个百分点内。这比单独要求 C_K≥90% 更严格。冻结原分类器只消除身份分支漂移，并不能保证拒识后 A_K 合格。

## 网络改动

已知身份路径保留原 F0 的完整 Tri-SIG-TIME SSL 编码器和 checkpoint 内六类默认头；所有原参数与 buffers 冻结，身份输出始终为原 F0 在同一 P1 上的 logits。拒识分支不替换、单独重训或改变身份头。

拒识／未来发现表征从原身份 fused160 出发。复用同次前向中四项实际融合贡献：时频、带原 gain 的 PA、带原 gain 的参考响应、SIG-TIME，按固定顺序形成 640 维输入。保留小型 640→64→64 投影器，内部 64 维仅用于生成残差方向；最终判决空间回到 160 维。删除当前没有输入作用的常量 conditioner。

令 f 为原 fused160，u 为上述分支产生的单位 160 维方向，a 为零初始化的 160 维可训练向量：

\[
\delta=0.1\lVert f\rVert_2\tanh(a)\odot u,\qquad z=\operatorname{normalize}(f+\delta).
\]

因此 \(\lVert\delta\rVert_2\le0.1\lVert f\rVert_2\)，初始状态 z 与原单位 fused160 完全一致。该约束限制变形幅度，不保证任意训练后近邻不变，也不证明未知拒识提高。原身份头只消费 f，拒识器只消费 z；不能让原有 identity residual 再次改变已知 logits。

关系评分器使用 query／合法旧类 support 原型的绝对差与逐元素积，共 320 维，经过 320→32→1 输出成员分数；使用旧类 support 的最大关系分数及固定源校准阈值决定接收。部署端不知道未知 TX 或真实未知类数。

按当前明确层结构计算，新增部署参数预期为 66177，连同原 F0 active 参数为 299170；这只是实现前算术，后续须以实际模块和实测路径复核。模型容器中原未使用辅助头、训练时缓存、原型／阈值和资源成本分别报告，不宣称无成本或压缩成功。

模型组件新增参数为 66177；与完整原 F0 配对的 active299170、container966899 已在本轮 N607 真实 checkpoint 路径确认。早期组件测试使用合成 native 接口契约，实际运行证据另见后文结果更新，二者分别报告。

## 首个实验：一个候选与两个控制

| 项目 | N0 无 OE 控制 | R0 关闭残差控制 | R1 唯一主候选 |
|---|---|---|---|
| 完整新结构、初始化、L 采样、更新预算 | 相同 | 相同 | 相同 |
| 原 F0 与默认身份头 | 全冻结 | 全冻结 | 全冻结 |
| 最终拒识特征 | 原 fused160＋有界可学习残差 | 原单位 fused160，残差关闭 | 原 fused160＋有界可学习残差 |

2026-10-30 实际发布实现前核对科学协议，源 OE 研究必须报告匹配无 OE 对照，因此在尚未打开新数据或启动实验时补入 N0。原主 R1、R0 对照和科学指标不变。N0 不打开 OE 训练特征、不构造 OE 采样或计算 OE 损失，只以 L 成员损失＋0.1 L 邻域项学习；R0/R1 仍为成员损失＋OE 成员损失＋0.1×0.5×（L邻域＋OE邻域）。

R0 的特征适配部分没有实际梯度更新，N0/R1 有更新；这项差别必须披露，不能冒充相同可训练参数数。R0/R1 具有相同完整结构、样本和前向调用，N0 具有相同 L 调用和更新预算、较少辅助数据与计算。独立 L/OE 随机流确保三组 L 与旧类子集完全一致；不用跳过 R0 的昂贵路径来宣称速度优势。新增优化步各固定 2220、总计6660，不以验证早停；AdamW lr1e−4、weight decay1e−4、clip5，初始化 seed2026092701，sampler2026103017、slots2026103018。

训练只使用原 L6300 的合法六类标签及独立 OE6134 的 outside-six 成员监督；OE 真实 TX/K 隐藏，原 Us56700 不新增使用。每步 support96、query96、OE64；旧六类中每个 episode 的“已注册子集”按 2/3/4/5 类均匀循环，剩余可见旧类模拟未知，query 的真正成员关系由合法 L 标签产生。

采样按五 RX×三日期的 15 个公共格固定：L 每个旧 TX 在每格各取 1 条，再从随步轮转的一格加 1 条，得到每类16条 support；query 同样每类16条，与本步全部 support ID 互斥。OE 每格4条共60，再从随步轮转的四个不同格各加1条；不用未知 TX 或配额。每个 query 的每类 support 原型只用不同 RX 且不同日期的该类 support 求均值后单位化，不用同域正例填空。缺格／不足样本在发布前按真实公共 metadata 判为不可执行，不能静默回退抽样或改成未知标签分组。

L 成员损失为 query 对“已注册子集”原型的最大关系 logit 的二元 CE，模拟已知与模拟未知 query 各占一半平均权重。OE 对完整六类原型的最大 logit 计算目标0的二元 CE。两项权重各1；加下述0.1软邻域项。该规则使训练目标和最终最大关系拒识相同，但仍不保证泛化到未见 TX。此设计配置尚不包含可直接运行的 launcher。

这里的模拟未知来自原六类，全部已被原 F0 训练见过；只能模拟关系评分器的注册边界，不能称为编码器未见设备测试。真正源未知设备仍只由冻结后的独立评分端读取，不改变其只读权限。

不再加入会把未知样本逐一当负类的硬实例标签，也不复用本次导致几何损失的 VICReg 目标。软邻域项使用同 P1 的原 F0 单位 fused160，在 L（support/query 合并192条）、OE（64条）内分别产生跨 RX 且跨 day、排除同 opaque ID 的 cosine 软分布，温度0.1。每候选的基础权重为其所属 RX/day 格的可用候选数的倒数，分别乘入教师和学生的指数分数后归一化；学生 z 对教师做 KL。Anchor 先各 RX/day 格平均再等权平均，两角色各占一半，总权重0.1。不生成未知硬标签或真实 K。教师来自原已冻结 F0，不能由 source novel 或目标预测反向更新。

若已存在身份、物理 ID、路径和同次贡献一致的合法缓存，可复用；否则一次提取 L/OE 共 12434 条原 F0 特征及四贡献。不得将只有 fused160 的旧缓存当成四贡献缓存，或凭名称静默替换来源。优先将同次原 f 作为 stop-gradient 教师，不额外加载第二个 F0；缓存／新增 F 行数和合成 smoke 单列。原始历史训练成本不隐去。

这与已完成的“fused160→MLP＋Gram＋Mahalanobis”不同：输入包含四项实际贡献，最终特征以原 fused160 为严格零初始化锚点和幅度约束，判决为按 support 学习的关系而非类协方差距离，几何项匹配软邻域而非 Gram。[旧负结果](PAMF_PHASE3_STAR_METRIC_EMBEDDING_RESULTS_20261030.md) 区别不代表新方案必然有效，首轮就是验证该假设。

## 数据、校准和是否进入目标端

首轮只做单模型种子的源侧反证。每行训练和模型状态先冻结；known V27000 只按既定 predicted-class/common-tail 规则校准已知风险，不训练拒识网络。Source novel3150 仅在该行所有表征／分数／阈值固定后由独立 scorer 连接真值，不能用于阈值、超参数、epoch 或候选选择。各行冻结后立即自动进入自己的预测／评分，不因其余行训练尚未结束而等待；已返回评分不改变其他健康行。

三个 arm 都须完成预登记的全部源预测及独立评分，报告宏 A_K/C_K/R_U/H、曲线、逐 RX/day/scene/TX、原 F0 错误与拒识新增错误，以及与原 F0 的未知几何诊断。Novel 同次前向顺带输出原 unit160 与 protected160，另存只含 opaque ID、公共 RX/day 和特征的私有诊断 NPZ，不增加 F 前向、不部署 source 行 bank。两表征的四条件近邻索引在该行唯一真值读取前全部固定，再报告跨 RX/day 检索、cosine gap、秩和方差比例；这些指标仅作诊断，不新增晋级门槛。不得只报告训练 loss、源 closed 或更高有效秩。

只有唯一主 R1 通过预登记已知风险组、源宏 R_U≥90%，才单独预登记一次跨 RX G10 开发测试；源成功不代替跨新接收机结果。未通过则保留两组负结果，不访问目标 Q、不扩多 seed 或正式 RX24-18。已有开发 Q 是已暴露测试，不称新盲测。缺场景／类支持保持 N/A，不补采样来改变本批组成。

进入目标评估也仍需同时满足宏 CK90/RU90 和 A_K 损伤≤2pp，报告 H 及分组结果。后续无标签适应只消费合法 U，未来独立 query 不回流；历史 Q 不能转训练。这些后续数据边界已由协议固定，本轮不另建未来状态机。

部署支持状态只从冻结后的 source L 聚合六类×15公共域的特征和及数量，不保留 source 物理样本行。依据 query 的公共 RX/day 排除相同 RX 或日期的 source 域，再为每个旧类聚合单位原型。Source V 校准和之后的预测使用同一规则；推理未知 TX、真实 K 或目标标签不进入聚合。此状态不训练新身份头，输出身份仍取原 F0。

## 后续消融与分工

域对抗暂不与首轮绑定。RX 方差比例增加是风险线索，不能据此宣称消除 RX 信息就能保留未知身份。若 protected160 仍有可复现域差异，再在同预算控制下添加轻量、按合法 L 身份条件化且 RX/day 平衡的对抗头；OE 设备构成随域变化可能混杂，不能把无条件 OE 域混淆当作成功证据。软邻域、域准确率与身份指标必须同时报告。

实现分工沿用当前 owner：主 agent 负责数据权限、模型接口、矩阵、发布与综合结论；模型／训练执行和独立真值评分分开；已有独立审查人只在实际新候选准备发布时做一次直接 P0/P1 审查。代码、配置、预算、成本、聚焦负测和真实 checkpoint 无 query smoke 完成后按项目最小流程发布，不新增设计批准或重复审查。
