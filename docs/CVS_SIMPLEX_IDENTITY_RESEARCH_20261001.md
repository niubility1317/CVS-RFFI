# CVS 等角分类头：源域前瞻假设的实施

本轮依据 coherence clean 测试前已固定的[源域假设](CVS_SIMPLEX_SOURCE_HYPOTHESIS_20261001.md)，保留源域选中的 coherence_phase 身份编码器，只将自由学习的六个类别方向改成正则单纯形。性能为首要目标，参数和成本为次要条件；源选择只有性能完全相同时才以成本区分。当前候选不是依据目标成绩选择，全部从零训练，不加载先前源权重。

## 数学设计

六个单位方向 w_k 的平均两两内积至少为−1/5，因为 `||sum(w_k)||²>=0`。最大两两内积不小于平均值，故任何六类方向的最大相似度至少为−1/5。在160维中，5维正则单纯形达到此界：全部非对角内积为−0.2，类别夹角101.53696°。这是原型几何界，不能推定数据分布、训练优化或泛化准确率必然更好。

构造5×6 Helmert矩阵H：第j行前j+1项为 `1/sqrt((j+1)(j+2))`，下一项为其−(j+1)倍，其余0；乘 `sqrt(6/5)`。于是每列单位范数、`H.T@H`非对角−0.2。可学习160×5矩阵A作薄QR，按R对角符号统一Q，类别原型为 `(Q@H).T`。已注册六类来自合法地面类别，不从query的真值数量、比例或配额推断。

`simplex_learned`学习A，H固定；`simplex_fixed`固定同样的初始原型，不学习分类方向。二者均用 `30*normalize(f)@normalize(P).T`，普通交叉熵为唯一损失，没有标签相关margin、温度扫描、附加几何损失或新特征深宽。两个候选每个配对seed的初始原型数值逐项相等；固定原型为连续存储，可学习原型转置后的存储不同，GEMM舍入造成约1e−6的初始logit差，因此仅logit使用FP32容差，未声称逐bit相同。

生成A使用同seed从零构建的原身份头随机权重前五行转置，不读取已训练checkpoint。保留每个编码器和PA残差融合初始张量，构造新头不再抽随机数。原自由头960个权重被800个可学习A元素或固定原型替换。可学习候选165233个总/可训练参数；固定候选164433个。减少分类器参数不是研发成功标准。

QR反向要求满列秩。聚焦检查验证初始及三次真实CE更新后的秩、原型Gram、分类框架/编码器/PA融合有效有限梯度、严格state_dict回读、单包独立推理和零/常量有限输出；不额外引入source之外的数据。正式每步监测CE和总梯度有限，完整日志保留真实方法状态。QR因子分解不纳入Conv/mm MAC计数，实测训练和推理时间包含QR及其反向，不能据较少参数或MAC声称加速。

## 通信、物理与射频指纹解释

类别角间隔约束发生在身份潜空间，训练中的特征映射仍可重新表达信号内的身份线索。它不消除载波频偏、信道变化或接收机贡献。原Sinc、time/frequency、PA分支、均值池化、dense融合、相干增量8通道保持一致，DSQ关闭、epsilon1e−6、160维身份嵌入不变。

PA非线性、记忆效应、振荡器等信号差异仍通过原观测路径编码。等角头检验统一身份竞争的几何是否有帮助，不证明TX/RX物理解耦，也不保证弱指纹被正确使用。若性能下降，应保留结果；不能用理论最大角间隔替代实际实验。
