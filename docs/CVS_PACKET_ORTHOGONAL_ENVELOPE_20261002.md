# CVS 包内正交包络输入：结构假设与固定实验

状态：待源训练验证。目标仍是原物理划分下，身份骨干仅用交叉熵、无信道增强、最终只测 clean 的识别性能提升。本设计不依据已见目标成绩选择结构、延迟、尺度或超参数，不宣称已经提升性能。

## 数学动机与实现

传统输入 `z, z p, z p²` 共享同一个接收包络 p，三个阶次可能高度相关。固定相同输入项数、相同卷积深度和宽度时，这种相关性可能使 CE 梯度难以区分线性响应与高阶创新。正交化是改善输入坐标数值条件的假设，不是网络优化速度或准确率提高的定理。

两种输入包络固定为 `p[n]=|z[n]|²/4`（瞬时）和 `p[n]=(|z[n]|²+|z[n-4]|²)/8`（记忆4）。z 是既有核心首层使用的径向截幅后 IQ。对 m=0,1,2,3，每包分别令 `v=z[n-m]`、`q=p[n-m]`、`w=|v|²`，用同一包的 256 点闭式加权矩计算：

```text
M = sum(w); mu = sum(w*q)/max(M,1e-12)
d = q-mu; s2 = sum(w*d²)/max(M,1e-12)
a = (sum(w*d³)/max(M,1e-12))/max(s2,1e-8)
h1 = v; h3 = 4*v*d; h5 = 16*v*(d²-a*d-s2)
```

加权平均中的权重使复数内积 `<v f(q),v g(q)>` 化为实加权内积 `sum(w*f*g)`。非退化且分母未被保护截断时，`Ew[d]=0`、`Ew[d²]=s2`、`Ew[d³]=a*s2`，因此同一包、同一延迟内 h1/h3/h5 两两正交。不要求高斯信号分布。四个延迟之间不保证正交，不同类别之间也不保证正交。零输入、恒包络和极小方差采用保护分母；不把此时的近似当作精确正交证明。

原项可由包内三角关系重建：

```text
v*q  = h3/4 + mu*h1
v*q² = h5/16 + (2*mu+a)*h3/4 + (mu²+s2)*h1
```

此关系在保护分母下仍成立到浮点误差。它证明逐包原项的代数可恢复性，不能证明使用固定卷积权重的整个旧网络与新网络函数等价，因为系数随包变化。原始截幅后 IQ h1 完整保留；不能声称还原截幅前已丢失的信息。

## 通信、物理和射频指纹含义

PA 的幅度非线性和包络记忆可以用奇阶复数项表述，本设计把收到的非线性项改写为相对线性项的创新坐标。固定 25 MHz 下的 4 点延迟对应 160 ns，这是设计延迟，不是测得的器件记忆时间常数。整个投影使用全包矩，虽然延迟采取因果零填充，投影不是流式因果运算。

共同相位变换 `z→exp(j theta)z` 不改变 p、w 或各矩，三个阶次都具有相同 charge1。仿射相位 `theta+omega*n` 下，第 m 个延迟项的相位为 `theta+omega*(n-m)`；不能把所有项当作同一个时刻的共同相位，也不能据此宣称整个分类器对 CFO 不变。公共检查保留全模型 CFO 响应和常相位误差。

射频指纹需要身份相关非理想性。本设计保留原 IQ、相对高阶残差能量和原位置功率读出，不对各阶分别白化，避免把阶次能量作为必然无关量删除。但接收 IQ 是 TX、信道、RX、噪声的共同作用，三阶/五阶创新同样可能来自 RX。公共 TX/RX 产生完全相同波形的反例仍保留；包内正交不构成 TX/RX 因果解耦、硬件系数恢复或唯一身份识别。

每包闭式矩是只读输入变换，只有同一个收到的 IQ，未使用标签、接收机 ID、角色、其他样本、support 或 query 群体统计。没有持久矩、拟合目标、优化器或跨样本状态，不属于目标域训练。模型内部仍通过唯一 CE 对全部原有参数反向传播，矩计算不截断梯度。

## 结构与成本

只替换首个行为卷积前的 12 个复数输入坐标。保留全部卷积/投影深度宽度、160 维身份表示、类别头、位置功率读出和六个共享能量归一化块。两种模型各 202553 参数，较当前自适应源控制 202555 少两个门参数，没有增加卷积参数。Conv/Linear MAC 仅统计这些模块，未计入包内矩、幂、除法与逐元素运算，不能据此宣称总计算量相同。实际训练和推理耗时、可训练参数、显存和状态按固定硬件测量。

## 一手文献与声明边界

Ghannouchi、Younes 和 Rawat 的 [Distortion and impairments mitigation and compensation of single- and multi-band wireless transmitters](https://ietresearch.onlinelibrary.wiley.com/doi/10.1049/iet-map.2012.0663) 讨论发射机非线性、记忆、调制器缺陷及行为模型复杂度。应用场景是建模/补偿；不能直接移植为本身份分类器的有效性结论。上述闭式正交与重建关系是本设计自行推导，并由实际代码检查。
