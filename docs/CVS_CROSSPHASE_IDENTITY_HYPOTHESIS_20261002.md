# 跨复数滤波通道相干读出：零新增参数原型

本轮只做公共数学输入上的结构原型，不读取正式 IQ、历史权重或目标成绩，不启动训练、选模或测试。依据是实际 `InvariantReadout` 的表达式及其可构造信息损失，不依据任何目标测试结果。

现有读出对每个复数滤波通道保存 log 功率均值/标准差、滞后 1/2 的复相干及四段 log 功率均值。它对每个通道各自施加一个常相位也不变。因此，在读出入口构造两组每通道功率和时间相关相同、通道间相对相位不同的复响应，现有读出不能区分。前面的复卷积可把通道交互隐式编码进功率，不能据此声称整个旧模型丢弃全部相对相位。

带记忆非线性、频带响应与 AM/PM 可能体现在复响应之间的相位关系。RX/信道也影响这种关系，本原型不把它解释为唯一 TX 参数。提出同维度的显式表示：保留六个原能量/时间相干量，用与两个固定通道 anchor 的复相干实部/虚部替换四段位置功率。两个 anchor 是通道 0 与 floor(C/2)，不根据包、类别、RX、query 集合或评分选择。

`rho[c,a] = mean_n z[c,n] conj(z[a,n]) / sqrt(mean_n |z[c,n]|² mean_n |z[a,n]|² + 1e-6)`。

共同复相位在分子中抵消，保留跨通道相位，同时保持每通道 10 个量、最终 320 维和原分类投影权重。代价是去掉四段位置功率，是否有利必须由合法源实验检验。两个原型 `crossphase_raw`、`crossphase_half` 使用现有共享 RMS 核心，分别原输入及固定半量校正，均 202553 参数；无新增学习参数、深度、宽度或损失。构造只使用新的 scratch 参数，与对应旧核心同 seed 时全部初始化 state 相同。

公共检查覆盖信息损失反例、共同相位、同维度/初始化/参数量、随机/弱/零/常量输入的 CE 与全部参数梯度、整网相位和严格状态回读。通过不代表源或 clean 性能改善，也不证明 TX/RX 因果分离。

尚无正式矩阵或发布。若推进，继续原物理划分、CE 唯一、无增强、仅身份骨干、scratch、完整 FP32、E200×50；先按合法源性能规则与既有不可变源控制比较。候选与选择规则在新 query 前登记，冻结后只测试选中的新候选，独立 truth-last；目标结果不回流设计、选模或重跑。
