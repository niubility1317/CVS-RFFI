# 跨复数滤波通道相干读出：零新增参数原型

本方案最初只在公共数学输入上建立结构原型；2026-10-02原无增强目标恢复后，推进下文预登记的源域实验。依据是实际 `InvariantReadout` 的表达式及其可构造信息损失，不依据新旧目标测试结果。正式候选只从零训练，无历史权重继承。

现有读出对每个复数滤波通道保存 log 功率均值/标准差、滞后 1/2 的复相干及四段 log 功率均值。它对每个通道各自施加一个常相位也不变。因此，在读出入口构造两组每通道功率和时间相关相同、通道间相对相位不同的复响应，现有读出不能区分。前面的复卷积可把通道交互隐式编码进功率，不能据此声称整个旧模型丢弃全部相对相位。

带记忆非线性、频带响应与 AM/PM 可能体现在复响应之间的相位关系。RX/信道也影响这种关系，本原型不把它解释为唯一 TX 参数。提出同维度的显式表示：保留六个原能量/时间相干量，用与两个固定通道 anchor 的复相干实部/虚部替换四段位置功率。两个 anchor 是通道 0 与 floor(C/2)，不根据包、类别、RX、query 集合或评分选择。

`rho[c,a] = mean_n z[c,n] conj(z[a,n]) / sqrt(mean_n |z[c,n]|² mean_n |z[a,n]|² + 1e-6)`。

共同复相位在分子中抵消，保留跨通道相位，同时保持每通道 10 个量、最终 320 维和原分类投影权重。代价是去掉四段位置功率，是否有利必须由合法源实验检验。两个原型 `crossphase_raw`、`crossphase_half` 使用现有共享 RMS 核心，分别原输入及固定半量校正，均 202553 参数；无新增学习参数、深度、宽度或损失。构造只使用新的 scratch 参数，与对应旧核心同 seed 时全部初始化 state 相同。

公共检查覆盖信息损失反例、共同相位、同维度/初始化/参数量、随机/弱/零/常量输入的 CE 与全部参数梯度、整网相位和严格状态回读。通过不代表源或 clean 性能改善，也不证明 TX/RX 因果分离。

正式矩阵为 `20261002-phase1-cvs-crossphase-identity-manysig-m8-r01`：两个候选×四模型seed，继续原物理划分、CE唯一、无增强、仅身份骨干、scratch、完整FP32、E200×50。对照是既有 `energy_equivariant` 的四份不可变源指标，不加载其权重；同seed两个新模型与该对照具有相同初始state、核心、深宽、读出维度和202553参数，改变的是读出运算，half另有前瞻固定alpha0.5。较原始residual_fusion的164225参数更多，因此“零新增参数”限于同核心energy对照，不能称与原始residual等参数。

在12个源记录齐全后，按四seed平均 `0.5×源V准确率+0.5×最差源RX准确率` 最高优先。完全并列才比较V、最差RX、成本和固定顺序。诊断误差及任何target分数不参与排序；各模型只用E200。若新候选选中，冻结后只测试该候选的4份权重，复用24行既有冻结clean控制，独立truth-last。若旧源赢家保留，则保留其原已核实clean测试，新候选测试为N/A；不为找到高分追加未选候选测试。

## 数学、通信、物理及射频指纹依据

数学上，令全部复通道响应乘相同 `exp(jθ)`，复相干分子的相位抵消，分母功率不变；按不同通道分别旋转时，相干相位则变化。因此该表示保留共同相位等价类之外的跨通道关系。这是读出性质，不证明整个旧模型必然丢弃这些信息，也不等于整网频率／RX／LTI不变。

通信上，滤波器组不同频带或延迟响应的相位关系可反映相对群延迟、幅相耦合和带记忆响应；所提读出显式提供这类关系。以固定anchor降低全C×C相关成本，代价是anchor弱能量时信息被ε压低，且舍弃位置功率可能损失有用非平稳特征。两种损失都以实际源日志和冻结测试检查，不预断优劣。

物理上，观测仍是 `R_d(H_d*T_y(s))+n`。共有载波相位可作为外部干扰处理，但RX频响、镜像和非线性也能进入相干特征；不能由结构独自保证TX／RX分离。固定半校正alpha不是晶振贡献比例，估计为received相对CFO且存在主值歧义。公共级联保留TX／RX产生相同波形的反例，避免把可分类特征误称唯一硬件参数。

射频指纹依据包括功放非线性记忆及滤波链路的设备差异，但相关原理只支持提出候选，不预先证明当前WiSig数据的识别优势。非线性记忆作为RFF特征的实测研究见[IEEE TCCN原论文](https://ieeexplore.ieee.org/document/9913208/)；接收机非理想性会干扰TX指纹提取的实测研究见[作者论文](https://arxiv.org/abs/2207.02999)。本轮不采用这些论文的额外损失或对抗训练，仅改变身份网络读出。

本地与远端丢弃副本检查共同相位、读出信息反例、实际参数、退化输入CE／梯度及严格state回读。正式训练保留完整stepJSONL、完整epochJSONL、去除数组的compactJSONL／CSV及详细文本；固定alpha和六block能量保持、实际两个anchor的相干强度均测量而非猜填。源验证和公共物理诊断不更新任何训练状态；它们的误差不作新增停机或排序门槛。
