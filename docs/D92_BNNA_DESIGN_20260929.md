# D92-BNNA-v1：有界非线性 support 适配器

日期：2026-09-29。状态：核心、冻结配置与合成测试已实现，尚未启动真实实验。设计保持对目标评分盲态。

本候选检验：能否只用当前 row 的真实 support，识别冻结编码器对接收后数学视图的不稳定方向，并通过最多 8 个共享系数作小幅、非线性、不可塌缩的收缩。它不训练 Phase1，不训练完整 MLP，不引入新的地面统计。设计未读取任何目标 scores、结果或解释报告，也不预先声称各 K 或旧、新类性能改善。

## 1. 权限与实际接口

输入仅为现有固定 Phase1 checkpoint、预登记配置、`p2_min_v1/VALIDATED_ONCE` received IQ、当前 row 合法 support 标签和注册类表。普通地面原型与量化聚合摘要都不是首版输入，因此不存在由普通原型拟合可训练分类状态或恢复 source feature bank 的问题。新增 source payload 为零。

`experiments/adv3b02_xuc/code/cvsrffi/identity_only_forward.py` 可只执行冻结 identity backbone，`model_dual_cvsincnet.py` 的兼容前向默认不更新 CRRA/NMFDU support 状态。继续使用确切 checkpoint 架构与同一 identity feature key，不运行 domain 分支、source loader、clean 恢复或 LEO 模拟。模型始终 eval，参数与 buffer 不变。

现有 `spectral_logmag_sketch` 提供逐样本 FFT96。新的辅助表示在 identity160 上训练，FFT96 保持固定。所有注册类使用同一个变换、同一原型公式和同一分数尺度；旧、新类成员关系只用于外层 support 风险比较，绝不用于 query 路由。

已有方法中“先在全部 support 上学习表示，再只对分类头留一”的结构不能移入本方法。每个外层物理 fold 必须重新执行全部表示拟合步骤；以下第 6 节明确其顺序。

## 2. 四个固定视图与物理样本计数

对每个 256 点 received 复数 IQ `x_i`，固定四个视图：

`v_iv = i^v x_i，v=0,1,2,3`。

仅通过 I/Q 交换和符号翻转实现四分之一圈旋转。没有裁剪、随机增强或新的信道观测。四个视图仍只属于一个物理 ID，K 不增加。

冻结编码器输出 `z_iv = unit(f(v_iv)) ∈ R^160`。同一物理样本只计算一次 `f_i=FFT96(x_i) ∈ R^96`；FFT 幅度不因四分之一圈相位旋转增加信息。

这里及下文固定 `unit(x)=x/max(||x||₂,ε)`，`ε=1e-12`。FFT 自身沿用已有公式及 `1e-8` 阈值，不改为新的频谱实现。零向量保持零，记录退化计数，不伪造特征或样本。

四视图不是新的独立信息源。可利用的是冻结非线性编码器对同一 IQ 的不同响应；相位稳定性是否有助于跨物理样本识别是待验证假设。它不能估计 K1 未观察到的真实类内变化，也不能模拟未观察到的 LEO 条件。

## 3. 只在训练 support 中估计不稳定子空间

设当前拟合集每类有 n 个物理样本，共 N=Cn，V=4。首先只用该拟合集计算：

`m_i = (1/V) Σ_v z_iv`，

`S = (1/(NV)) Σ_i Σ_v (z_iv-m_i)(z_iv-m_i)^T`。

每个物理样本总权重相同；相同 n 使每类总权重相同。不得用 query、外层 heldout support 或其他 row 更新 S。

S 是当前 target support 视图差协方差，不是 source 统计或生成样本。只用于确定最多 8 个正交方向，不做逆协方差放大。

- 若 `trace(S) <= 1e-24`，设 r=0，适配器精确退化为 identity，不执行优化；记录 `NO_VIEW_VARIATION`、实际 trace 和 active rank 0。
- 否则仅保留大于 `64 * eps_float64 * trace(S)` 的特征值，按降序取前 `r=min(8,有效方向数)` 个方向。阈值固定为浮点退化处理，不按目标结果调整。
- 得到 `B ∈ R^(r×160)`，满足 `BB^T=I_r`。记录实际 active rank、特征值与正交误差。
- 协方差累加前按物理 ID 排序。特征向量符号采用首个非零主元素为正；近重根簇按固定数值容差分组，在其投影子空间内依标准坐标轴顺序做确定性正交化，再截取所需方向，避免重根基底选择成为未登记随机性。容差同为 `64 * eps_float64 * trace(S)`。

若所有有效方向均被数值阈值排除，也按 r=0 处理。禁止用 source 方向补齐 rank。

## 4. 最多 8 个参数的非线性收缩

只训练 `a∈[0,0.5]^r`，初始化严格 `a=0`。固定 `τ=sqrt(160)`：

`t(z)=tanh(τ Bz)/τ`，

`w_a(z)=z-B^T(a⊙t(z))`，

`q_a(z)=unit(w_a(z))`，

`h_iv(a) = concat(q_a(z_iv), f_i)/sqrt(2) ∈ R^256`。

FFT 与 identity 块系数固定相同，不按类、TX 或注册新类数量改变。不使用 BN、dropout、可训练类偏置或可训练温度。

对单位 z，残差满足：

`||w_a(z)-z||₂ <= min(0.5, 0.5*sqrt(r/160))`。

r≤8 时第二个上界约为 0.111804。归一化前，子空间各坐标映射的导数为 `1-a_j*sech²(τ(Bz)_j)`，介于 0.5 与 1，因此该收缩不翻转或压塌任何子空间坐标；正交补保持不变。归一化后的单位 identity 向量偏转上界为 `asin(0.111804)`，约 6.42°。这只是变换上界，不是准确率保障。

数值边界：输入范数低于 ε 时，`unit` 定义可能产生非单位向量。此时单位向量的 6.42° 上界不适用。实现记录 `subunit_identity_count`，按实际输入范数使用相对残差界 `min(0.5,0.5*sqrt(r/160)/||z||)` 核验角度，零向量不计算角度。这只是对同一公式的正确数值审计，不改变适配器或阈值。

非零 a 时 tanh 与归一化使整个映射一般不是旧 256 维特征上的固定线性重参数化。有限合成测试只能验证构造性非线性例子与解析边界，不能证明有限观测间不存在任意线性映射。

物理样本表征和最终类原型为：

`bar_h_i(a) = (1/V) Σ_v h_iv(a)`，

`μ_i(a) = unit(bar_h_i(a))`，

`p_c(a) = unit(Σ_(i:y_i=c) μ_i(a))`。

同样的公式应用于所有注册类。均值接近零时继续使用上述 ε 规则，记录其数量；不能借 query 决定另一种聚合或回滚。全部有效表征为零时分数完全并列，由物理 class ID 的字典序稳定决定。

## 5. 唯一训练目标与固定预算

### 5.1 分类项

n≥2 时，对每个物理训练样本 i，用整份物理样本留出的类原型：

`p_c^(-i)(a)=unit(Σ_(j:y_j=c,j≠i) μ_j(a))`，

`L_cls = (1/N) Σ_i CE(y_i, {10 μ_i(a)^T p_c^(-i)(a)}_(c=1..C))`。

对非自身类别，排除 i 不改变原型；自身类别仍有 n-1 个物理样本。梯度穿过 query-side 训练表征和 support-side 原型两端。这是训练目标中的 leave-one-physical-sample 结构，并非独立验证。

n=1 时无法形成同类跨物理样本正对。唯一固定替代是同一物理样本的跨视图训练目标：将每个 `h_iv` 与同类其余三个视图的归一化和比较，其他类使用其四个视图的归一化和，CE 在四视图平均后再在物理样本平均。明确只称为训练约束，不称为 holdout、校准、泛化或选参证据。不得把四视图解释为 K=4。

### 5.2 一致性与参数约束

`L_view = (1/(NV)) Σ_i Σ_v ||h_iv(a)-bar_h_i(a)||₂²`，

`L_gate = ||a||₂²/r`，

`L = L_cls + L_view/(n+1) + L_gate/(n+1)`。

每次拟合使用该训练部分的实际 n。r=0 时 L_gate 定义为 0，不运行优化。约束、低参数量、从 identity 初始化、物理样本等权和固定参数惩罚共同限制过拟合，但不保证消除少样本偏差。

采用纯 NumPy float64 的解析梯度与投影 Adam：64 次完整训练集更新，学习率 0.03，β1=0.9、β2=0.999、ε_Adam=1e-8，标准 bias correction；每次更新后逐坐标 clip 到 `[0,0.5]`。无随机采样、无候选学习率、无 loss 驱动早停、无 checkpoint 选择。完成 64 步后使用最终系数，而非挑选训练损失最小的一步。

所有非有限输入、损失、梯度或状态都作为明确技术错误终止当前拟合；不得静默改用另一个算法或访问额外数据。r=0 是公式明确规定的精确退化，不是技术失败回退。

## 6. 外层物理 CV 与 K1 规则

K1 不做任何验证或选择，直接按第 3 至 5 节拟合当前 row；除 r=0 外固定 64 步。不得借其他 row 的 support、query 或历史结果选择是否启用适配器。

K≥2 仅比较两个预先定义的状态：固定预算训练得到的 a，与 a=0。不搜索 rank、视图、惩罚、学习率、步数或温度。

外层 `F=min(K,3)`；每类按物理 ID 排序后，以位置模 F 分折。同一物理 ID 的全部四视图共同留出。每折严格执行：

1. 只取 trainfold 的物理 support；从零重估 m_i、S、有效 rank 和 B。所有尺度均为固定常数，不得估计全 support 归一化尺度。
2. 在该 trainfold 中从 a=0 开始，按实际 n=K-held_per_class 完整训练 64 步。n=1 时使用明确的跨视图训练目标。
3. 只用 trainfold 重算 μ_i 和所有类原型。另独立构造 a=0 的 trainfold 基准原型。
4. 对 heldout 物理样本逐个执行固定视图和冻结 fold 状态，两臂都面对全部注册类。heldout 不能更新 B、a、原型或任何尺度。
5. 拼接每物理 support 恰好一次的 OOF 分数，计算每类平均 NLL，再分别计算旧、新类组的宏平均 NLL；主风险为两组中较大者，不存在的组忽略。

训练臂主风险小于 a=0 臂（均按十位小数比较）时选择训练臂；主风险并列再比较全类宏平均 NLL；完全并列选 a=0。旧、新成员关系仅用于这个 support 风险比较，不改变表示、训练权重或 query 公式。

选择训练臂后，丢弃全部 fold 状态，使用完整当前 row support 从零重估 S/B、重新训练 64 步、重算原型。选择 a=0 则直接用完整 support 构造原型，无须再次训练或持久化 B。禁止把某个 fold 的系数 warm-start 到最终拟合。

OOF 被用于两臂选择，因此选中臂的 OOF 数值不是无偏的独立性能保证；不得将其冒充最终测试结论。完整真实预测按预登记流程冻结后，才由独立 scorer 验收。

## 7. 纯 NumPy 解析梯度路径

不需要 Torch autograd 或 Phase1 骨干反向传播。骨干只在一次特征导出中前向。

对 `u=unit(x)`，在 `||x||>ε` 时，其向量积梯度为：

`J_unit(x)^T g = (g-u(u^Tg))/||x||`。

在 `||x||<=ε` 的固定分支使用 `g/ε`；记录近零归一化数量。原型、物理均值和 q 的反向传播都复用此公式。

分类损失可统一实现为一组训练表征 e_t：n≥2 时 `e_t=μ_i`，n=1 时 `e_t=h_iv`。每类先求表征和 `T_c`，当前样本正类原型用 `unit(T_c-e_t)`，负类用 `unit(T_c)`。softmax 的 logit 梯度是 `(prob-onehot)/训练表征数`。

逐 t 计算到表征和、原型归一化输入的梯度，并按类别累加，再从自身贡献中扣除 leave-one 的项。无需存储全部 `N×C×D` 中间数组；一个 `C×D` 类梯度累计量与一份训练表征梯度足够。n=1 的四视图 CE 平均权重确保每个物理样本总权重仍相同。

一致性项梯度为 `2(h_iv-bar_h_i)/(NV)`。n≥2 的分类梯度经过 `μ_i=unit(bar_h_i)` 后平均分给四个 h。n=1 的分类梯度直接到 h。

反向传播到 q 时取 h 的前 160 维并除以 sqrt(2)；再经过 q 的 unit 梯度得到 `g_w`。预计算的 `t(z)` 与 B 不参与求导，系数梯度为：

`∂L/∂a_j = -Σ_(i,v) t_j(z_iv) * (B g_w,iv)_j + 2a_j/[r(n+1)]`，

其中 `g_w` 已包括分类项和按 `1/(n+1)` 加权的一致性项。B 在一次拟合内固定，不能每步根据 a 重估。

后续实现须用中心有限差分校验系数梯度，覆盖 n=1、n≥2、非零系数及未触及 clip 边界的状态；归一化分支边界不作为光滑导数测试点。解析路径只依赖现有 NumPy，不为 8 个参数安装新的优化框架。

## 8. 实际计算路径与存储

### 8.1 一次冻结特征提取

每物理样本每模型为四次冻结 native 前向和一次 FFT96。与身份、checkpoint、视图配置完全匹配的原视图缓存最多可复用一次，新增三次；不得把已有 MVKME 的三个 Fourier 聚合块反解成四个 identity 视图。

float32 缓存为 `4×160+96=736` 个数，即 2944 字节/物理样本/模型，另计物理 ID 和元数据。缓存独立于 support 标签和 row；只允许共享这种冻结、逐样本生成的表示。

### 8.2 每次 support 拟合

S 构造为 `O(NVd²)`，160 维对称分解为 `O(d³)`，d=160。预计算 `t(z_iv)` 一次，后续每步无需重复计算 Bz 或 tanh。

每步真实路径是：重建有界残差和 q → h → 物理均值/类和 → 训练 CE 与一致性损失 → 原型和归一化的解析反向 → 8 维 Adam 更新。没有每步骨干前向、FFT、特征分解或大分类头求解。

对 n≥2，前向主要乘加约为 `NVrd + NCD`，D=256；反向另有同量级的残差与原型梯度工作，必须单独实测，不能当作前向免费。n=1 的 CE 使用 NV 个视图表征，其原型比较项为 `NVCD`。

在 C=26、K=20、V=4、r=8 时，完整拟合每步残差重建约 2662400 次乘加，原型比较约 3461120 次乘加，合计约 6123520 次前向主要乘加；64 步约 3.92 亿次，反向和归一化另计。这不是墙钟时间承诺。

F=3 时最多训练三个 fold 与一次全 support，最多 256 次参数更新。对于各 fold 训练 n≥2 的常见 K，三个 trainfold 的样本数总和恰为 2N，若最终选择训练臂，则训练样本加权工作量相当于三次完整 support 的 64 步，而非四次完整 N。上述最大 C/K 情形前向主要乘加总量约 11.76 亿次，另加反向、三个 fold 和最终拟合各自的 S/分解。

K=2 的外层 trainfold n=1，必须按跨视图 CE 的实际 NV 成本计算，不能套用 n≥2 的估算。K1 仅训练一次 64 步。r=0 或外层选择 a=0 的情况按实际发生的工作记账。

S 只需 `160×160×8=204800` 字节；不要用全部训练表征对构建 N² Gram。最大 r=8 时 B 为 10240 字节、a 为 64 字节。FP64 类原型为 `256C×8` 字节，C=26 时为 53248 字节；训练臂主要持久数值状态合计 63552 字节，标识符和配置另计。a=0 臂只需要类原型。训练工作数组和进程峰值 RSS 必须另报。

无需新的地面 source 样本、统计或模型训练。既有冻结模型包的实际字节与新增 source payload=0 分列；模型是否已部署不能仅凭“复用”推断。以上不含 IQ 本身已有通信，也不把本地 received 缓存误称地面传输。

## 9. 日志、合成验证与可证伪边界

每次拟合记录实际 n、物理样本数、rank、S trace、B 正交误差、64 步各项训练损失及权重、实际学习率、梯度范数、clip 前后系数范围、残差/角度上界核验、近零归一化数量、耗时和停止状态。r=0 明确记录 0 步及退化原因；不打印虚构 epoch、源域验证或收敛保证。

每外层 fold 记录训练/留出物理 ID、类计数、重新估计的 basis 标识、实际拟合预算、两臂逐类及组宏 NLL、完整选择依据。完整日志保留，紧凑 JSONL/CSV 不含大数组；非适用值写 null 并说明。

实施前的合成测试至少覆盖：

- 数值梯度与解析梯度一致，训练目标权重使用实际 trainfold n；
- a=0 精确恢复原表征，零视图散度 r=0 且不调用优化器；
- 系数约束、正交性、导数下界和表示偏转上界；
- 类表及 support 排序等变，旧新类别不影响变换或先验；
- 每外层 fold 的 basis、系数和原型只依赖 trainfold；改动 heldout 数据不能改变训练状态；
- K1 没有验证调用，同物理视图不能跨 fold；
- query 前后状态字节不变，单条、分块及顺序变化不改变逐样本分数；
- 近零与重复特征、rank 退化、非有限值和稳定并列处理；
- 完整实际训练日志、缓存/状态字节与 64 步预算核算。

若外层物理 OOF 选择 a=0，表示该 row 的这条固定适配机制未获得 support 选择证据；不得继续查 query 决定新学习率或新视图。K1 则没有独立的支持集选参证据，必须如实报告。即使训练损失下降，也不能据此断言真实新样本或所有 K 的旧、新类和 H 一定改善。

## 10. 已实现接口与验证记录

核心文件为 `code/cvsrffi/stage2_d92_bnna.py`，专门测试为 `tests/test_d92_bnna.py`，冻结配置为 `configs/d92_bnna_frozen_20260929.json`。配置只含 `algorithm=FROZEN_CONFIG`，不提供 CLI 改参入口。

- `fit_bnna(support_identity_views[N,4,160], support_fft[N,96], support_labels, support_ids, classes, old_classes)`，全部为关键字参数。
- 返回 immutable `BNNAState`；`state.score(identity_views,fft)` 输出全部注册类分数，`state.predict(identity_views,fft)` 输出物理 class ID，`state.audit_dict()` 输出纯 JSON 结构。

audit 的 `steps` 是所有 fold/final 更新的扁平列表，各行字段统一，含 scope、fold、step、实际训练 K、rank、真实 loss 三分量及权重、总 loss、学习率、梯度范数、更新前后 gate 范围、clip 数量、近零计数与耗时。loss 明确在当前步更新之前测量。第 64 步更新之后另测 `final_fit.final_losses` 和最终梯度，不把第 64 条更新前损失误称最终状态损失。

`folds` 保留每个物理 fold 的训练/留出 ID、实际 K、独立训练状态审计及两臂 NLL；`candidates` 保留两臂完整 OOF 风险。最终选择 identity 时不再训练，记录 `IDENTITY_SELECTED` 和 0 步；rank0 记录 `NO_VIEW_VARIATION` 与真实退化损失。未记录任何源域验证。

2026-09-29 在 `ssr-gpu` Python 中运行 14 项专门合成测试通过。测试覆盖 n=1/2/3 的解析梯度有限差分、重复特征值基底、K1 固定 64 步且无 CV、rank0 精确退化、变换界、完整物理 fold 隔离、K5 折内实际 K、两臂选择、类/样本置换、query 分块/排序不可变、26 类 K1、近零输入及负测。改动 heldout 物理样本时，对应 trainfold 的 B、a 和原型保持逐字节不变；有限差分检查误差在指定数值容差内。这些是正确性证据，不是分类性能结论。
