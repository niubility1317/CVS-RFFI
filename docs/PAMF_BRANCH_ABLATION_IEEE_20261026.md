# PAMF 网络分支消融：IEEE 聚焦版（2026-10-26）

本报告仅采用“仅分类损失的监督训练”中，PAMF 直接识别、日期与接收机同时变化的测试结果。完整 PAMF 加五个结构变体，各 3 个模型种子，共 18 个模型。每个测试场景含 42000 包、6 类。

差值统一为“变体减完整 PAMF”，负值表示下降、正值表示提高。以下为同种子配对后的六景准确率变化，单位为百分点；± 为三个配对差的样本标准差。

| 结构变体 | 六景准确率变化 |
|---|---|
| 去除显式时间坐标 | -0.54±1.04 |
| 去除路径描述支路 | +0.85±0.25 |
| 去除功放相关支路 | -5.63±1.95 |
| 去除参考响应支路 | -0.30±0.06 |
| 打乱参考模板相位 | +0.04±0.23 |

“完整删除 SIG-TIME”与“去除路径描述支路”是同一个实验；“去除显式时间坐标”单独列出。“打乱参考模板相位”完整保留。

本版不展示其他推理链、其他测试群体或效率内容。既有旧报告与导出包均保留。本次没有新增训练、预测或目标真值访问。新不可覆盖包为 `exports/reports/20261026-PAMF-branch-IEEE-r21.zip`，解包可用纯标准库复算。
