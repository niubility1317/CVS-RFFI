## 错误记录

| 错误 | 尝试 | 处理结果 |
|---|---:|---|
| 普通PowerShell会话找不到`python` | 1 | 改为串行使用`conda run -n ssr-gpu` |
| 非交互PowerShell无法直接`conda activate ssr-gpu` | 1 | 使用命名环境运行器，未修改Conda配置 |
| 会话索引搜索触发Conda GBK编码错误 | 1 | 设置`PYTHONUTF8=1`和`PYTHONIOENCODING=utf-8`后成功 |
| 首个远端多行Bash统计脚本末尾语法错误 | 1 | 不采信未输出部分，改用流式`python3 -`只读补扫并成功 |

| 畸形UTF-8测试样本触发Conda外层GBK输出包装错误 | 1 | 显式设置`PYTHONUTF8=1`和`PYTHONIOENCODING=utf-8`后重跑，确认并修复真实测试问题 |
