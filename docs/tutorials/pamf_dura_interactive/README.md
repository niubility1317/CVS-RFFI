# PAMF 与 DURA 交互学习手册

从复数 IQ、张量、卷积、归一化和梯度开始，逐步解释 PAMF 共同识别主干、原 T1 与 PAMF-REPL 训练机制，以及 DURA v1.0 的接收算子、局部 MAP、两步 CG、训练与执行优化。

20 章、20 个确定性交互算例、10 道解释型自测。数值例子明确标注为简化教学模型，不读取数据、权重或目标真值，不执行实验。保留真实结构与权限边界。

## 构建与验证

使用 Python 3 标准库和 Node.js：

```text
python build.py
node verify.cjs
```

构建得到 `dist/index.html`，可直接离线打开。可用 `python build.py --export <绝对输出路径>` 同时生成独立交付文件。字体、公式渲染器、样式、章节和交互脚本全部内嵌。KaTeX 0.16.22 按 MIT 许可保留在 `vendor/katex/`；仅初次重新取得依赖时才需 `python build.py --fetch-vendor --vendor-only`。

## 验证范围

`verify.cjs` 检查所有教学公式能被渲染、章节／交互槽完整、基础数值恒等式及离线依赖。页面还需在浏览器检查导航、滑块、公式展开、符号表、自测、主题和窄屏；不把这些教学例子验证描述成模型性能验证。

学习进度和自测选项仅保存在当前浏览器的本地存储，无法访问时仍可正常阅读。各章记录来源路径。原 T1、REPL 与 DURA 的历史结果不互相改标。
