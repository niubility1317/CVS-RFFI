# FCR8 与 BranchLocalRidge 联合优化：完整 support 结果

日期：2026-10-01。完整 160 个 support 配置及 4576 个训练阶段已经独立核验。

**结论：本轮有小幅最终收益，但没有形成明确的联合改善，保留 BranchLocalRidge 主线，不启动 FCR8 的 query 评分。** 顺序主方法相对 R0 的最终旧类、新类和 H 分别增加 0.3212、0.0703 和 0.1115 个百分点；仅旧类适应结果下降 0.1736 个百分点，逐配置绝对新旧差增大 0.5530 个百分点。没有根据 reset 或局部较好配置更换预登记主方法。

## 数据与三阶段口径

run：`20260930-phase2-d92-fcr8-support-m2-r01`。训练 runtime：`33673fe02a857d790aa69a1ace17fdb9638099d0`；独立分析 commit：`f07e3c9222120f43df9de46eeac028772c364bda`。

- 固定合规 source-only 地面 Phase1；两模型 seed（2026092701、2026092702）× 两个 capsule cohort，每行 40 配置，共 160。星地信道为 practical residual/post_sync/noeq、fs=25MHz。
- 每配置 6 个旧类，新增 0/2/5/10/20 类，总注册 6/8/11/16/26 类。K=1/5/10/20 是每类原始合法 support 数，不是新增类数。
- A 为地面模型未适应旧类准确率，本次 support 诊断未测，统一 N/A。B0/R0 是原 BranchLocalRidge support 分类器，不能替代 A，不能据 B−B0 判断是否达到适应提升 10 个百分点的理想目标。
- B 只使用旧类 support 训练残差；C_seq 继承本行实际 U_B，使用合法新旧类 support 拟合全部注册类。C_reset_init 重置 U、保留实际 B 教师，只作机制对照。部署和评价始终让全部已注册类统一竞争。
- oof 是合法 support 外层持出诊断：同一配置、旧类 support 与物理旧类 held 样本配对 B/C。内层 held 标签参与监督训练；外层 held 只评价冻结状态。本结果不是 query 准确率，也不是新增独立数据验证。
- 主总体统计 K5/10/20、新增 2/5/10/20 的 96 个可测配置；128 个 new-present parent 中另 32 个 K1 为 N/A。H 先逐配置计算 2ON/(O+N)，再平均；新旧差先逐配置取绝对值，再平均。
- K1 无可独立持出的样本，oof 为 N/A。proxy 从 K>1 support 库抽每类单样本 anchor、其余 support 评分；train K=1 按冻结规则不训练 adapter，不能解释为真实 K1 的独立验证。完整 40 个 K1 数值配置、120 个 oof 配置及 1400 个 proxy anchor 均保留。

## 数学机制与实际资源

FCR8 固定 8 行正交 DCT 字典，仅训练输出 U。对当前合法训练 support 的 H/√N 做一次薄 SVD，构造 W；训练 U=U_anchor+ZWᵀ，近端项为 0.5||Z||²。它对应当前 support 上投影前残差函数的均方位移，不是完整 Fisher 自然梯度。C 原样保留 U_B，再建立当前 support 坐标。LocalRidge 是唯一分类器。详见[数学设计](D92_JOINT_AFTER_MC_DESIGN_20260930.md)。

该候选同时固定输入字典、改变优化坐标和近端度量；没有受控证据将收益归因于其中某一项。完整训练机制诊断另见[训练发现](D92_FCR8_TRAINING_FINDINGS_20261001.md)。不根据参数范数推断实际功能变化。

N607 x86_64、96 logical CPUs，2 个并行 CPU lane，每 lane BLAS 线程 2，float64，无 GPU。完整 run 墙钟 59.1993 分钟，最大 lane 峰值 RSS 865.3164 MiB。
