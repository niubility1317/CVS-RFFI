# CVS可学习包内矩残差

目标仍是提升基础网络在交叉熵唯一、无信道增强、原物理划分、身份骨干和clean测试条件下的识别性能。参数轻量是次要条件。本轮不宣称已取得性能提升；它提出可由完整源训练及冻结后独立测试证伪的结构假设。

## 设计依据与方案选择

此前完整源实验显示，直接把原包络输入替换为正交坐标会降低固定源性能分数。公共坐标诊断说明逆变换系数随包变化；完整逆变换只恢复原输入函数，不能单独构成性能改进。原始IQ仍在网络中，因而不能据此断言信息已经丢失或确定退步的因果原因。

本轮考虑三种处理方式：保持硬替换并增加尺度超参数，会改变实验问题且缺少明确源侧依据；加入完整逆变换，仅重现原函数；保留原输入参照并让交叉熵学习矩残差的作用，可保持初始函数并允许非零系数改变网络。选择第三种。瞬时和记忆4两种固定矩定义各使用4个模型种子，不根据目标成绩选择定义或系数。

## 数学结构

固定控制为`adaptive_volterra_lag4`。对经过原径向限幅的接收IQ z，沿用：

```
p4[n] = (|z[n]|² + |z[n-4]|²)/8
B = [z, z*p4, z*p4²]
C[n] = z[n-4]² * conj(z[n-8])/4
Q = [z, C, C*p4]
A = B + tanh(alpha)*(Q-B)
```

alpha为原有的两个全局可训练参数，分别控制三阶和五阶；一阶系数始终为0。每个坐标保留延迟m=0、1、2、3，共12个复数输入通道。

新候选对每个包、每个延迟计算闭式加权矩：

```
p = |z|²/4                      # moment_residual_instant
p = (|z|²+delay4(|z|²))/8       # moment_residual_memory4
w = |delay_m(z)|²
mu = E_w[p]
variance = E_w[(p-mu)²]
a = E_w[(p-mu)³]/max(variance,1e-8)
O = [z, z*(p-mu), z*((p-mu)²-a*(p-mu)-variance)]
I = A + tanh(beta)*(O-B)
```

实际计算时z及p按同一m对齐。B始终使用原lag4包络，而O使用本候选固定矩定义。beta是两个新全局参数，对三阶和五阶分别作用，一阶始终为0。O没有此前硬替换的4和16倍幅度系数，也没有逐阶能量白化。alpha与beta均从0开始，仅由源交叉熵更新。

beta=0时，输入与原adaptive控制完全相同，包括任意非零alpha的状态；同种子scratch参数及匹配训练态dropout随机状态下，完整初始函数相同。新增beta的真实梯度和更新已在公共随机输入上检查。非零beta提供依赖当前包矩的低阶坐标修正，通常改变输入函数；它不等于完整逆变换，也不保证最终混合输入正交。负beta允许反向修正，范围由同一tanh公式约束，不设置类别或接收机专属分支。

## 通信、物理与RFF解释

记忆4的间隔为25MHz采样下的160ns，原相位记忆最大延迟8对应320ns；这是固定离散模型的设计间隔，不是从硬件测量得到的时间常数。包络记忆和复共轭三阶项描述接收波形的非线性及时序行为；未知激励、传播和RX处理仍可能产生相同观测。

包内矩只使用已接收的同一256点IQ，不访问身份标签、TX/RX标识、角色、其他包或目标数据，不保存统计状态，也不执行拟合目标。完整包内矩需要包中后续采样点，因此不宣称流式因果处理。

包络及权重在常相位或线性相位变换下不变。三阶相位记忆因4+4-8=0与当前z保持相同线性相位阶次；每个延迟槽按n-m变换。新残差保留该输入协变关系，但完整卷积和频谱路径仍可对CFO作出响应，不能由输入公式推出整网CFO或任意RX/信道不变性。

这些参数是身份分类网络的可训练系数，不是已识别的TX PA系数。公共TX/RX同波形反例继续保存；本轮不宣称唯一TX硬件恢复、TX/RX因果分离、完整Volterra识别、数字预失真或实测在轨验证。真正的RFF机制证据与测试性能均仍需要完成。

## 固定实验与交付

模型202557参数，比当前控制202555增加2参数。原有深度、宽度、12个行为输入、6个复值块、160维表征、位置功率读出和scale30分类头不变。没有加载控制或历史checkpoint；控制只读取4份完整源元数据。

新矩阵为2候选×4种子（2026092701至2026092704），各200轮、每轮50步、batch128；L6300、V27000、U56700未使用，物理split392005固定。AdamW初始学习率2e-4、weight decay1e-4，cosine降至1e-6；无梯度裁剪、teacher、EMA、增强、域骨干或额外损失。完整FP32，TF32关闭。

源冻结只比较12份E200记录：8个新模型和4个adaptive控制。按四种子mean(0.5V+0.5最差源RX)最大选择，完全并列后比较V、最差RX、MAC、参数及固定顺序。公开物理数值是诊断，不参与源排名、停机或提前选模。

日志保留每步四个系数的raw、tanh、梯度及更新前后值，完整损失/LR/梯度/实际执行状态，完整与紧凑epoch JSONL及CSV；每轮末28个源包核对实际卷积输入、原一阶IQ、两种残差相对变化、包内矩及6个共享归一化块。训练结束保存全部90个源TX/RX/day分层、公共30组通信链、相位响应及实际资源测量。

若新候选胜出，只给冻结候选的4个模型做clean测试，并复用32份原控制预测，共36行、每行168000个固定物理ID、6类、7RX。全部预测固定后，由独立scorer连接truth，报告总体及RX的288条指标和全部负差值。若原控制保留，不测试未选新候选，复用既有控制测试。测试结果不回流结构、矩定义、超参数、seed排除、选模或选择性重跑。

实际时间、显存、模型常驻状态与可训练参数需分别记录。Conv/Linear MAC未包含包内矩和逐元素运算，参数仅增加2不能推出总算力成本不变。无support/SFT/新类；未测量项写N/A。
