## 4. 方法与协议边界

R0为原BranchLocalRidge；R_fixed为未经训练的类内谱收缩；R_joint为真实监督谱adapter+LocalRidge，R_reset共享同一B但在C把初始化和近端锚点归零。最终分类器均为LocalRidge形式，未另叠加自由logits。R_joint训练2个谱参数，固定8步投影梯度、学习率0.1，最后状态唯一；没有最好步、早停、网格或外层反馈选参。

每个inner fold仅用自己的旧inner-train估计方向/谱，仅用全部注册inner-train拟合核与分类头。inner-held标签仅监督共享谱参数；outer-held仅在状态固定后评分。B后C继承共享参数及完整旧类几何，但C内折仍重估几何；C最终核/头全类重拟合。新类support合法参与C监督。不同任务、外折、模型或cohort不继承目标状态。

true K1没有独立留出信息；proxy trainK1精确复用R0、没有实际参数更新。内折几何不可辨的阶段不制造额外view或样本。只有真正执行8步的936个阶段计入训练，不能把其余回退路径当微调成功。
