## 数学范围

令 `P=I−1qᵀ`，完整中心化核的伴随为 `gamma sym(Pᵀ A P−q 1ᵀ B P)` 和 `gamma B P`。[独立 helper](../tools/d92_affine_analysis_math.py)用行列求和与外积展开这两个式子，把分析中的时间复杂度从 `O(n³+hn²)` 降到 `O(n²+hn)`。移动 reference 的项保留；现有非零截距伴随、saddle 方程、距离及 adapter 反向、最终梯度和容差仍逐项核验。[完整公式与浮点边界](D92_AFFINE_ANALYSIS_CENTER_VJP_20261001.md)区分实数等价与浮点逐位一致。

对于 `sum(q)=1`，`Pᵀq=0`。首轮近抵消测试误把伴随零方向写成全 1 向量；非均匀 q 下该假设不成立。该项与独立稠密矩阵 oracle 的比较已经通过。修复仅把 fixture 的 gauge 改为 `qvᵀ+vqᵀ`，实现、原断言和容差均不变。
