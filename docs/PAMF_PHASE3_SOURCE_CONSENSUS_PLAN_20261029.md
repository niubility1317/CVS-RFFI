# Phase3 跨分支类别对应证据

2026-10-29。候选 `20261029-phase3-source-consensus-s2026092701-r01`。完整六类冻结源 OE 的 MLP 拒识为 76.6032%，源 known 风险校准后为 81.4603%，均未达到总体和每 RX 的 95% 源推进门槛。本候选只改变拒识描述符，检验保留物理分支与同一默认类别的对应关系是否有用；不把它预先称为接收机不变特征。

原描述符将每分支六类 cosine 与负 Mahalanobis 距离分别排序。它保留相似程度，但不保留各分支的高值是否对应默认头支持的同一类别。新描述符使用完整默认六类 logits 的稳定 softmax 概率 `p_k`。对每个分支的六维证据 `a_k`，提取最大值、第二大值、均值、总体标准差、`sum_k p_k a_k` 及 `max_k a_k - sum_k p_k a_k`。cosine 和负 Mahalanobis 平方距离各提取六项，八分支共 96 项，再加原 MSP、maxlogit、margin、logsumexp 四项，仍是 100 维。

同时置换默认头和源原型的六类列时，上述统计应保持不变；概率加权也避免 argmax 同分造成的类别索引依赖。各条记录只使用自己的冻结 logits／分支与源几何，不计算验证或 query 批量统计，不输入 RX/TX 标签或未知类别数。原六类身份决策仍是未改动默认头的 argmax。

复用原 source-open parent 的完整特征导出和 L-only 几何，不重新前向 F、不改变原 L/U/V 或辅助数据角色。首步用两条合法 source L 特征加载实际父拒识 checkpoint，完成原评分前向和新描述符的有限值 smoke；不能将此写成再次运行完整 F。新 linear／MLP 读出仍为 101／1633 参数，CPU seed2026092701、各 200 次全批量 L6300＋OEtrain4200 更新，损失、AdamW、学习率和归一化权限与前版完全相同。它们是本候选新读出，不将父读出与新 100 维语义混用；新冻结状态必须标记 `head_aligned_branch_summary_v1`。
