# PAMF Phase3 联合性能口径

2026-10-29。根据用户要求，在继续实验前明确衡量综合性能的指标。本文固定定义和报告方式，不降低既有目标、不追改历史实验。数值门槛仍由 `configs/pamf_phase3_targets_20261029.json` 管理。目标工具中较早的星地 95% 字样不覆盖用户后续明确的星地 90% 要求。

## 条件与类别角色

Phase3 主评估为未见接收机、G10 星地观测、零目标 TX 标签、独立未来样本。P0 是星地 received，P1 是同一 received 经冻结 DURA；当前部署主路径为 P1，P0 是配对对照。clean 仅保留 Phase1 地面参考和历史诊断，不新增 Phase3 clean 路线。G10 MIX 总体与六实际场景切片分别报告，不能把原生单景与 MIX 中的同名条件混为一组。

第 t 轮的 O 是此前全部已注册身份，N 是本轮无标签发现池实际到达的新设备，L 是未参与本轮发现的后续未知设备。真实角色、TX、类数只由 builder/scorer 确定。注册前拒识对象为 N∪L，注册后分别衡量 N 的身份识别和 L 的拒识；分母不随算法成功发现的簇数缩小。持续阶段的 O 包含此前匿名注册的设备，不能始终只指 Phase1 原六类。

## 主性能与保护

| 量 | 定义 | 用途 |
| --- | --- | --- |
| A_K / A_O | 已知／旧类中身份正确且被接收的逐 TX 宏平均比例 | 主性能，误拒和错身份都计错 |
| C_K | 已知样本未被拒绝的逐 TX 宏平均比例 | 保护指标；错身份接收仍在分子中 |
| FRR_K | 1−C_K | 合法设备误拒 |
| R_U | 注册前 N∪L 被拒识的逐 TX 宏平均比例 | 未知检测主性能 |
| FAR_U | 1−R_U | 未知设备误接；错误 anonymous 接收不算拒绝 |
| A_N | 本轮所有真实到达设备在未来独立 Q 上的正确身份接收宏平均 | 无标签注册主性能 |
| R_L | 后续未知设备在未来 Q 上的拒识宏平均 | 注册后的持续开放性 |

宏平均为先在每个事前要求的 TX 内计算比例，再对 TX 等权。主表同时给出样本计数、每 TX 结果、接收机、日期、场景、模型 seed、信道 episode 和覆盖。缺少必需 TX 样本时对应宏值为 N/A，不能认证通过；真实新类有未来样本而未发现时 A_N=0。无匿名簇时纯度为 N/A，不能称为零污染或注册成功。

旧类保护使用同输入、同路径的原冻结 F0 闭集结果：D_total=A_F0_closed−A_O。注册遗忘使用同 DA 状态、同 Q 的未注册版本：D_REG=A_O(REG0)−A_O(REG1)。原 F0 保护只适用于它实际拥有的原六类；持续阶段新变成旧类的身份另以此前冻结注册系统在同一新 Q 上的表现作配对基线。

## 综合比较与配对收益

固定源阈值下 H_OS=2 A_K R_U/(A_K+R_U)，任一项为 0 则为 0。它是项目逐 TX 宏平均版的开放集 H-score；经典思想来自 [Fu et al., ECCV 2020](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123600562.pdf)。

同时报告宏加权 AUROC 和 OSCR 面积。OSCR 的纵轴为正确身份接收率、横轴为未知误接率，参考 [Dhamija et al., NeurIPS 2018](https://proceedings.neurips.cc/paper_files/paper/2018/file/48db71587df6c7c442e5b76cc723169a-Paper.pdf)。本项目每个已知和未知 TX 各自等权，ties 整组处理；`oscr_auc_macro` 与历史未注明宏权重的 `oscr` 分开命名。曲线只在独立评分端概括固定预测，不产生部署阈值或回填模型。

完整系统可附 H_OW=3/(1/A_O+1/A_N+1/R_L)。这是项目自定义描述性总分，不是文献标准、没有独立晋级阈值，不替代各项硬约束。任一实测项为 0 则 H_OW=0；未执行阶段或覆盖缺失则 N/A。

四态 DA0_REG0、DA1_REG0、DA0_REG1、DA1_REG1 共用物理 Q 和 received。DA 收益分别比较 DA1_REG0−DA0_REG0、DA1_REG1−DA0_REG1，主看 A_O 的配对改善并同时检查 R_U/R_L、C_K 和 H。REG0 的 A_N/H_OW 是 N/A，不填 0 制造注册收益。未来 anonymous→TX 的唯一评分置换在 U 拟合并冻结，在 Q 不重拟合。

## 验收与证据

现有门槛保持：星地跨 RX 总体及预登记主场景 R_U/R_L≥90%；已知／应注册类宏平均接收≥95%；同输入 F0 到旧类 open 损伤≤2pp；无标签 DA 取得可报告正收益且保住拒识/身份；未来 A_N≥80%；D_REG≤2pp。单项、综合 H、AUROC 或 source 通过均不替代完整验收。

源端验证只可证明源域开发能力，不写成跨 RX 目标成功。单 RX/单模型 seed 是开发证据；确认阶段报告多 seed、未见 RX 与配对差异，重复信道实现不计为更多独立物理记录。点估计门槛与置信区间分开；同 RX 记录的二项区间不能冒充跨 RX 总体区间。正式 Q 不用于模型、阈值或候选选择，历史 Q 不回收训练。

当前反例：G10 单 F0 RMD 的 DA1_REG0 中，P1 的 C_K=97.5694%，A_K=71.1806%，R_U=2.7778%，H_OS=5.3469%；四态注册 K=0、A_N=0。高接收率和低“应注册 FRR”均不能解释为综合成功。原实测及其原始判定保留在 `docs/PAMF_PHASE3_STAR_RELATIVE_RESULTS_20261029.md`。
