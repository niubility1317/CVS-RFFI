# CVS 基础网络研发：保留物理分支，压缩身份融合

## 研发范围与已知证据

用户追加要求基准继续运行，先研发 CVS。本批不修改、停止或重启已有 source-only release；研发只读取合法源域日志，不打开当前目标 clean 输入或 truth。既有基准与四个初始 CVS 候选继续按原配置训练。

读取首批两个 seed 的完整可用逐轮源日志，采用共同 E60 做配对诊断，而不是对齐不同网络的最新轮。原 CVS 的源 V 平均准确率为 96.909%，最差源 RX 平均准确率为 91.731%；共享复数候选分别为 92.806%、80.713%。训练 CE 分别约 0.09994 和 0.01698。共享候选较低训练 CE 与较弱源验证并存，但这不能确认相位不变性、池化、正交归一化或容量中的哪项导致差距，也不能代替四 seed 的 E200 结论或目标泛化结论。完整曲线保留，E60 只是共同诊断点。

## CE 实际图与参数成本

原身份网络共 382146 个参数；真实 CE 反向传播涉及 317665 个参数。`con_proj`、`cls_head.imp_merge`、`cls_head.pa_head` 共 64481 个参数只服务其他输出，`return_aux=False` 的身份分类不执行它们。严格控制测试中，移除这三个模块后，在相同 dropout RNG 下训练 logits 和全部有效参数梯度逐元素完全一致。该控制说明账面参数包含未参与 CE 的部分，不能把移除这些参数说成识别性能改进。

剩余分类路径仍包含多级 160 维投影：base→identity，base/PA→PA，再门控 identity，与 PA 拼接后投影 joint。PA 路径还使用 base，通用信息在多个位置重复混合。这里提出一个可检验假设：保持原特征提取器，减少分类头自由度和串联非线性，让 PA 补充直接作用于身份表示，可能改善源样本较少时的学习；当前没有证据证明原头是性能根因。

## 残差融合结构与数学性质

令 u 为原时域＋频域融合输出，p 为原 PA_local＋PA_delta。新头为：

`h = LN(u) + tanh(a) ⊙ LN(p)`，`logits_c = 30 × cos(h, w_c)`。

`a` 每个 embedding 通道一个参数，初始化为 `atanh(0.25)`。LayerNorm 只使用本样本的特征维度，不使用 batch/query 集合统计。两个原分支投影共同接收唯一的身份 CE 梯度，没有 stop-gradient。通道增益界限为 (-1,1)，允许正负补充；它不是估计得到的物理 PA 系数，也不被解释为测量置信度。

当增益为零时，h 精确回到 LN(u)，通用分支保留直接路径；对融合输入 u 的局部导数是 J_LN(u)，不再依次通过原头的三个 learned projection 和多个 ReLU。LayerNorm 本身会去掉均值与尺度方向，余弦头也有归一化，不能据此承诺梯度满秩或永不消失。该结构借鉴残差学习的直接路径思想，但不是对图像 ResNet 效果的射频迁移证明。[He et al., Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385)提出了以输入为参照的残差学习框架；本批不增加网络深度。

新头只有 1760 个参数，包括两个 LayerNorm、160 个增益和 6×160 分类权重。原时域、频域、PA 的 convolution、Sinc、非线性基底、记忆深度、输入截断、辅助物理统计及分支 dropout 完整保留；整体没有被强制设成全局相位不变。这保留了学习 IQ 失衡、相对相位、频偏和非线性纹理的可能性，但也保留接收机捷径风险。收到的单包不能无条件分离 TX、信道和 RX，不宣称这个结构已经实现物理解耦。

PA 显式延迟与后续 convolution 在线性、统一边界条件下存在可合并项；当前 native PA 的每延迟/阶数通道又有时间变化的 envelope gate，因此不能把其整个展开声称为精确冗余并直接折叠。本轮保持 PA 原实现，先隔离融合头这一处改动。

## 两个固定候选

| 候选 | 改动 | 总参数／本地有效 CE 参数 | 卷积及矩阵 MAC/样本 |
|---|---|---:|---:|
| residual_fusion | 原三分支＋残差融合头 | 164225／164225 | 9708836 |
| residual_fusion_moment | 同上＋三个均值/波动池化 | 164417／164417 | 9708836 |

第二候选只将三个全局均值池化替换为 `mean+tanh(b)*std`，b 从零开始，共 192 个参数。它与标准拼接均值/标准差不同，保持旧投影输入宽度；可能丢失独立重建两个矩的信息。统计池化存在于说话人 embedding 研究，例如 [Snyder et al., X-vectors](https://danielpovey.com/files/2018_icassp_xvectors.pdf)聚合时间帧均值和标准差；本批不采用该论文的数据增强，也不引用其识别成绩支持射频效果。

原网络分支 dropout 保留，但原分类头内部的 dropout 随旧头移除，因此效果包括融合形式、容量、归一化和头部正则化的共同变化，不能只归因于残差相加。

参数较原模型减少约 57%，但相对于有效 CE 参数减少约 48.3%；MAC 仅减少约 1.56%，FFT 仍有两次。这是因为原卷积特征提取占主要计算量。CPU 合成 batch128 训练测量分别约 210.24 ms、192.86 ms，是局部机制检查，不是 N607 速度结论。参数减少主要降低权重常驻状态及优化器存储，不能宣称同步减少了同等比例的时间或显存。正式训练后报告 GPU 测量、源训练峰值与 benchmark 双模型峰值的区别。

## 从零训练与后续选择

新 run：`20261001-phase1-cvs-residual-identity-manysig-m8-r01`；2 候选×4 seed。每行源 L=6300、U=56700 未用、V=27000 只评估，复用既有物理角色与 VALIDATED_ONCE 数据，不重新划分或重验。无任何 checkpoint/teacher/EMA/optimizer 继承；父 run 仅提供源诊断背景。模型 seed 为 2026092701 至 2026092704，split seed=392005，其余 data/augmentation/support/evaluation 角色为 N/A；loader RNG 独立按模型 seed 固定。

保持 200×50 次优化、batch128、无 drop_last、AdamW lr2e-4/wd1e-4/cosine1e-6、FP32、无梯度裁剪。无输入/信道增强、域骨干或额外损失；固定 E200 权重，不按中间 V 更换 epoch。

旧 run 的源选择记录保留。本批在任何当前 clean 预测前，联合原四个 CVS 候选和新两个候选，依据全部四 seed 的 E200 源 V 选择一个最终 CVS。按 0.5×V accuracy＋0.5×worst_RX accuracy 排序；最高分 0.2 个百分点内优先较小 MAC，再较少参数。四个固定基线均保留，共五个网络进入 clean 测试。联合冻结记录单独写 `research_selection.json`，不覆盖旧 run 的选择。若来源矩阵不完整，记录缺失并保持目标未评分，不用已有目标分数挑选替代候选。

新 dispatcher 先等待旧 owner 的 QUEUED 行全部获得终态或启动，再参与剩余槽位调度。这是避免两个 launch owner 同时抢占同一空槽的资源安排，不要求旧任务全部训练完成，也不增加数据或性能审批。之后计入旧的运行进程，每 GPU 最多两个总训练任务，并要求 12 GB 空闲显存。健康任务继续运行，新 source release 不执行目标预测或评分。
