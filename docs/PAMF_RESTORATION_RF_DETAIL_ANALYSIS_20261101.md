# 射频细节能否被保留或增强：现有证据与边界

**恢复器可能改善可用于识别的细节表达，但“响应更强”不能单独证明真实发射机特质被增强。** 当前主目标仍是原地面完整 Tri-SIG-TIME SSL/Main 六景逐个距 raw clean≤3 个百分点并保持 clean；该目标尚未达到。本文只复用历史已公开的 R31 源域射频响应诊断，补充解释细节保留和理论极限，不新增实验、不改变当前 RolloutBridge 的训练或测试。

R31 固定的是原 R17 `unroll_unshared`，不是 DURA v1.0，也不是当前新恢复器。它使用原源 V1800、原 5 个源 RX/3 日期，没有为反事实新增 F 读出或正式 Main 测试。记录来源的旧 TX 分组不赋予变化后的波形真实 TX 标签。原 F50 的来源与名称仍保留，但这些方向响应量本身是 IQ 函数的测试，不能改标成当前 Tri-SIG-TIME SSL 的成绩。

## 测量了什么

对同一条源 clean IQ 的预设方向 δ，令 A 为缓存的接收作用，在同一噪声下比较恢复器对 `y+Aδ` 与 `y−Aδ` 的输出，中央响应为 `d=[G(y+Aδ)−G(y−Aδ)]/2`。投影增益为 `Re〈d,δ〉/||δ||²`，方向误差为 `||d−δ||²/||δ||²`。

增益 1 对应目标方向的幅度保持，0 对应没有相应方向响应；负值、超过 1 或较强的正交误差都可能出现。因此必须同时看方向误差和曲率，不能把增益越大当作越好，更不能把增益数值读成准确率或信息恢复百分比。这里的“1%/2%”是扰动与原 IQ 的范数比例，不是已标定的硬件参数改变量。

原诊断先用 FP64 去除方向的复标量分量，再归一化并转回 FP32。预设方向是 PA 幅度、PA 相位、IQ 镜像、延迟残差及等幅随机参照；这些是源录音 IQ 坐标中的数学探针，不是已识别的真实 TX 参数导数。A 固定了原缓存的 AGC/旋转，双侧观测共享原噪声，没有完整重新生成非线性接收链。

“可观察”是这份历史诊断的固定条件：方向有效、Fisher 能量≥9、已知 A/原 SCALE² 的零 prior MAP 方向 NMSE≤0.1、CG64 相对残差≤0.001。它使用额外已知作用与有限求解器，不能部署，不能当作真实硬件细节可恢复的数学界，也不能推广为 Main 样本的比例。

1% 幅度下，四个物理方向只有约 7.4% 至 10.2% 的原源记录通过该条件。在这些子集中，PA 幅度、PA 相位、IQ 镜像的增益中位数约 0.74 至 0.76，提示原 R17 对部分可观察小变化仍有衰减。随机参照也出现衰减，增益中位数约 0.54，所以证据同时包含一般局部响应与去噪的权衡，不能称为 RF 特有的删除。

其余记录不满足条件，不能据此要求网络补全所有微小变化，也不能把没有通过条件解释为这些记录完全没有身份信息。不同方向的子集不同，不能拼接它们的高值或将 1800 条记录按方向重复计算成独立样本。

## 对当前优化意味着什么

- “恢复成 clean 的几成”没有单一指标。Main 准确率保留比例、IQ 重建误差、F(clean) 判决一致率、局部方向响应和理论可辨识性回答不同问题。
- 对发射机特质的增强，需要方向正确、误差受控，并最终改善真实 TX 的净纠错和跨 RX/day 性能。增加能量、置信度或某个合成方向增益均不能单独证明成功。
- 不能对全部弱方向强制单位响应，这可能同时放大噪声和不可靠细节。若今后研究局部响应保持，应明确作用、噪声、可观察范围及随机参照，并以原 Main 全七景验收；这不是当前训练已新增的约束。
- 当前新 G 的实际射频方向保留尚未由本报告验证。RolloutBridge 正检验源端已观察到的逐步退化，保持原 L_s/U_s、从零单阶段 30 轮、冻结原 F0 及无 TX/V/OE/target 优化边界。该训练不因这份历史分析改变。
