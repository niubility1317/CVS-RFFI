# 同参数复数相位记忆输入

目标保持 CE 唯一、无信道增强、身份骨干、原物理划分、scratch、clean-only。本设计依据现有输入表达和公开复基带模型，未使用目标指标做结构或延迟选择。当前固定源规则保留的控制为 `coupled_lag4`，只读取其四份源元数据，所有新模型从零训练。

复基带 Volterra 的奇数阶项可以包含不同延迟的复数样本与共轭样本乘积，超出仅用一个样本乘包络功率的形式。这里采用这一建模启发，不复制完整 PA 模型或拟合硬件系数。[Crespo-Cadenas 等，Signal Processing 131（2017），245–248，DOI 10.1016/j.sigpro.2016.08.018](https://www.sciencedirect.com/science/article/abs/pii/S0165168416302043)。已核实论文公开摘要和基带模型式；出版社全文入口受限。本文具体延迟平衡构造及分类收益假设为本项目推导，不是论文已证明的 RFF 结论。

在原径向截幅 received IQ 上令 `P[t]=|z[t]|²`、`p[t]=(P[t]+P[t-4])/8`，控制输入为 `z, zp, zp²`。本轮定义 `C_l[t]=z[t-l]² conj(z[t-2l])/4`，每个原延迟 m=0 至 3 的三个输入改为 `z[t]`、`(z[t]p[t]+C_l[t])/2`、`(z[t]p[t]²+C_l[t]p[t])/2`，其中 t=n-m，l 固定为 1 或 4。半权重前瞻固定，不做系数扫描。仍为 12 项，全部学习模块、参数形状、初始状态与源控制匹配，202553 个参数；读出、深宽与分类头不变。

数学上，共同相位旋转对 C 的相位权重为 2−1=1。若乘上 `exp(j(theta+omega*n))`，C 的相位为 `2phi(t-l)-phi(t-2l)=phi(t)`，与 z[t] 一致；因此输入 lift 在因果补零下具有逐延迟的仿射相位协变性。该性质不等于整网频偏不变：保留的有限复数卷积、原 FFT 和相关读出仍可响应频偏，raw received 输入和 alpha0 保留。

相同幅度和当前 z、不同历史相位可以使原当前延迟的包络项相同而 C 不同，证明输入层存在额外相位交互。这个局部反例不证明旧整网不能用后续非线性近似相同函数，也不证明分类一定提高。公共合成的 l=1/4 对应 40/160 ns，最大新增历史延迟 2l 对应 80/320 ns；不是实测器件时间常数。

通信和 RF 含义是受限跨时刻复三阶、五阶记忆项，可表达历史相位与包络共同作用。它们在未知发射激励、信道、RX 滤波、IQ 不平衡、非线性和噪声下仍属于 received 响应，不能唯一归因于 TX；TX/RX 产生相同波形的公共反例继续保留。不是完整 Volterra、DPD、PA 参数恢复或普遍信道不变模型。纯增加输入代数表达不能替代最终冻结测试的性能证据。

本地检查使用公共 IQ：独立复数公式、因果性、FP64 输入层仿射相位协变、整网实际 FP32 常相位误差、相同 scratch state/参数数、CE 全参数梯度、状态回读和批次独立。原 Sinc 内部固定 FP32，整网误差按实际精度报告，不将 model.double() 当成完整 FP64。Conv/Linear MAC 不计新增复乘等逐元素开销，实际训练/推理耗时和峰值内存另测。

正式矩阵为两个 l×四模型 seed，8 行 E200×50，共 80000 步；固定源分数为四 seed mean(0.5V+0.5最差源RX)，完全并列后才比较性能分量与成本。最高新候选冻结后默认做四份 clean 预测，复用 28 份既有控制，32 行预测完整后才独立连接 truth。控制保留则复用其既有测试，新候选测试 N/A。所有负结果保留，不根据目标结果回调结构、延迟、系数、选模或重跑。
