# PAMF 网络分支消融实验报告（2026-10-25）

本报告仅报告“仅分类损失的监督训练”结果。9 种结构、3 个模型种子，共 27 个识别器；直接识别与接入同一既有 DURA 后的结果分列。所有结构均保持原默认分类头联合训练，50 轮、11100 次更新；没有无标签训练、教师、跨接收机对比损失或配对 KL。

跨接收机六景平均准确率，完整网络为 71.3993±0.4039%，去除功放相关支路后为 64.1881±0.7137%；同种子配对差为 7.2112±0.7008 个百分点。接入同一 DURA 后，配对差为 3.6091±0.8432 个百分点。其他分支效果随群体和推理路径改变，固定打乱局部顺序的变体在部分设置优于完整网络，负值与非单调结果均保留。

本次新增训练、预测、目标真值访问和 DURA 训练均为 0。新不可覆盖包为 `exports/reports/20261025-PAMF-branch-ablation-r19.zip`，含逐接收机／发射机／日期指标、逐种子配对、净纠错、训练实际曝光、去重成本、450 组计时重复与纯标准库复算器。此报告不自动代表其他训练目标或数据划分。
