# CVS分层相位曲率残差

目标是在原物理划分、交叉熵唯一、无信道增强、身份骨干、scratch及clean测试条件下提高性能。参数轻量是次要条件。本设计尚未训练或测试，不宣称性能提升。

## 选择依据

已有源实验的可学习包内矩修正确实改变输入并得到梯度，但没有提高四seed固定源分数。既有crossphase改变的是读出，既有Volterra/adaptive把对称延迟三阶项放在输入端；本轮改为六个复数FIR输出上的混合延迟差分。原核心、通道、深度、频域路径、位置功率读出和分类头保持，区别是明确的时序算子，不以增加参数矩阵替代结构依据。

备选一是在输入端再加入两个混合延迟门，成本低，但仍只改变同一输入位置；备选二是在六个滤波尺度上增加明确的相位曲率作用，能作用于不同滤波特征；备选三扩宽网络，不能单独回答物理算子的价值。本轮选择第二种，两种固定延迟(1,4)与(2,4)各四seed，不由目标成绩选择延迟或位置。

## 数学算子

令y是一个复数FIR的输出，v是同一点径向限幅到2的y，不做逐通道RMS或跨包统计。定义：

```
D_ab(v)[t] = (v[t-a] v[t-b] conj(v[t-a-b]) - v[t] |v[t]|²)/4
y'[t] = y[t] + tanh(beta) D_ab(v)[t]
```

t<a+b时D固定为0。每个FIR一个全局beta，共六个，全部零初始化，仅由源CE学习；原adaptive输入的两个alpha仍保留，总八个全局系数、202561参数，比控制202555增加6。已有参数键与初始化随机流不变；beta全为0时整个函数保持原own-scratch控制，包括匹配dropout随机状态的训练态，不加载控制checkpoint。

v的复数模长不超过2，因此|D|<=4；已有y线性输出保持，修正有界，随后才执行原共同RMS和径向门。mask避免零填充边界产生虚假的纯音响应；没有未来点、环绕、标签、TX/RX、角色、跨包拟合或持久统计。

若v[t]=A exp(j(theta+omega t))，a+b平衡使延迟积与瞬时三阶项相等，D=0。对v[t]=A exp(j(theta+omega t+kappa t²))，在非前缀区域：

```
D_ab(v)[t] = |A|² v[t] (exp(-j 2 kappa a b)-1)/4
```

因此该差分具有明确的相位曲率响应，而非对静态共同相位或纯线性相位的任意放大。对任意序列乘exp(j(theta+omega t))，D与原序列同相位协变。完整网络的FIR、频域和读出仍保留频偏响应，不能把此算子性质写成整网CFO不变。现有径向非线性网络可能近似某些交互；显式算子是归纳偏置，不宣称旧网络不可能表达。

## 通信、物理与RFF边界

两组a,b固定为(1,4)和(2,4)。六个FIR输出的原输入采样网格间隔依次为2、4、4、2、4、4点；25MHz下，第一层两候选的最大历史分别400ns和480ns，后两层分别800ns和960ns。这是滤波特征网格的设计跨度，不是实际器件时间常数。原时间FIR含非因果对称padding，因此不声称整网流式因果性。

算子作用于received特征，可能响应TX、RX、信道、调制或噪声造成的包络与相位曲率。源前导码诊断支持重复段与后段变化分别处理的必要性，但不授予唯一TX归属。保留原输入alpha0及相对频率信息，不额外执行同步修正或增强；不使用目标support/SFT。

公共机制检查使用已冻结的TX→信道→RX级联、孤立TX干预、RX交换、常相位和±80kHz响应，以及已有TX/RX同波形反例。公共波形不进入正式训练，没有真实源身份标签，不报告合成身份准确率。六系数是网络参数，不是PA、晶振或已识别Volterra核；不宣称唯一硬件恢复、TX/RX因果分离、任意RX/LTI不变或实测在轨验证。

## 固定实验与证据

两候选×四model seed，原L6300/V27000、U56700未使用、split392005；E200×50、batch128、AdamW2e-4、wd1e-4、cosine至1e-6，完整FP32/TF32关闭。原source V/worstRX性能最高优先，完全并列后才比成本；只用E200，不从测试结果重排或选择性重跑。
