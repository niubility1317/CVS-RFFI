## 数学实现与诊断

固定字典 \(h=\operatorname{GELU}(V_0x)\) 按每个物理记录、同一归约顺序计算一次；不计算 V 梯度。每个 preparation 的 H/√N 只做一次缩放薄 SVD。按 Gram 能量阈值 \(128\epsilon_{64}\max(N,8)\) 保留方向；阈值、完整谱、r、是否实际估计和条件数相关白化容差全部记录。不建参数维度平方矩阵。

Z 的近端为 \(\|Z\|^2/2\)，梯度为 Z，不是 Z/N。其对应 support 上 **pre-tangent 残差 v** 的平均功能位移，不等于归一化后特征 T、核或 score 的变化。代码另用实际 U−anchor_U、H 重算该位移，报告与坐标等式的舍入差。

内头仍完整反传 alpha、中心化、trace scale、带宽、Gaussian、两个几何和切向映射；只对适配距离的 VJP 乘 1/2。task 与 keep 各用同一已缓存 Cholesky 的两次伴随三角求解，最后转换为 `G_U @ W`。正向 alpha 求解、两通道反向求解分别计费。

四次迭代、每次最多三个固定试探，保留实际非增、Armijo、keep 三条件及原物理 slack。没有 U/V 产品球；归一化方向和含原点的保持半空间使阶段 Z 路径长度不超过 1/2。这个界不代表查询功能位移或准确率保持。拒绝的 trial cache 不会覆盖接受 cache，最后只保留最后接受参数。

已有 forward 直接提供的机制量：各块角度和 tangent/κ，正原始距离 pair 的适配/联合相对变化，零距离 pair 数，kernel 范数；fit 将初始 cache 与当前 cache 对齐，补 kernel 变化、held score RMS 变化与 winner 变化。没有为这些指标多拟合一个头。tau0=0 绕开适配距离时，对未实际测量的适配距离变化写 null 与原因，不从最终原核不变推算适配几何不变。

## 记录、费用与退化

事件为 `FCR_INNER_PREPARED`、`FCR_INITIAL`、`FCR_GRADIENT`、`FCR_TRIAL`、`FCR_STEP`、`FCR_FINAL`。结构化 stage 保留 initial/final objective、gradients/trials/steps 和真实成功/拒绝/停止原因。

`state_callback(key, arrays)` 外置无损数组并返回 JSON 引用；initial/trial/final 保存 Z、U、anchor_U、W 和谱，gradient 再保存 g_Z、keep_g_Z、d_Z。准备记录保存 H/W/谱及每折 teacher score/q/旧类 mask。拒绝 trial 也保留，key 不可重复。没有 callback 时保留只读内存记录。JSON 边界使用严格原生有限标量，不用 `default=str`。

沿用 MC 的 teacher、initial、inner、final head/factorization，logical objective、forward/backward、task/keep derivative solve、trial attempt/completed/accepted/rejected；`mc_*` 名称改为 `fcr_*`。新增真实 `latent_svd_count` 和 `dictionary_physical_evaluation_count`。初始 B cache 费用归 preparation，重用不重复计费；final cached objective 是展示，不当作新增求解。

K1、单类、全内折几何退化时不做 SVD 或目标更新，但保留实际字典计算数和原内折几何。`rank_estimated=False` 时 r=0 表示空优化坐标，不声称数据真实 rank 为零。H 全零时确实无可学字典方向。`original_inner_geometry` 保留原有 fold IDs/tau0/s0，不能以 effective 内折空列表抹掉已经计算的距离费用。prepared 不使用任何 outer-held。

内存字段分开统计部署 head、原坐标 U、实际物化 V0、原始绑定状态、prepared H/W/谱和缓存；外置数组记录大小由入口实际文件统计。V0 虽不训练仍占实际数值存储；少参数不代表总训练/评分时间更少。
