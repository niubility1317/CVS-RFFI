# 恢复器源模拟与 Main 观测设置核对

静态证据未发现核心信道实现发生漂移；存在已记录的载频设置差异，但不足以把新恢复器的性能差距归因为信道不匹配。本核对不启动新模型或重建数据，不改变健康实验，也不是新增数据验证门槛。

原 R07 源配对来自固定发布 `c8ccdfdbd03ab5ad8828b1eb9210b99a664ebe7b`；Main 观测元数据引用原信道发布 `7669a6de973959290089a04293cc542db26e5fe1`。只读这两个不可变发布与 Main 既有 manifest，不读 IQ、prediction 或真值，不运行神经网络。

| 项目 | 原 R07 源配对 | Main 存储生成部分的元数据 | 结论 |
|---|---|---|---|
| 核心 channel/residual/equalization 三模块 | 固定 R07 发布 | 固定原 Main 引擎 | 三个模块的完整语法树与函数/类定义分别相同；未检查的依赖不据此声称相同 |
| 采样率 | 25 MHz | 25 MHz | 一致 |

| 处理路线 | residual/post_sync/noEQ | residual/post_sync/noEQ | 一致 |

两份 Main wrapper 分别选择126000和42000条物理样本；它们指向同一288000条 union 存储。每景 manifest 记载168000条从旧存储复制、120000条本轮生成。**生成部分的配置不能独立证明全部历史复制样本的参数，也不能仅凭 union 总数断定某个 wrapper 全属于哪一部分。** 因此，本记录不将“Main生成配置为2.450 GHz”扩写为“每条Main都已证实采用2.450 GHz”。来源细目保留在同名JSON。

源端六种场景、15% clean混合及20个固定draw来自R07原配方，新G的30轮使用20draw再重复前10；Main各景为独立固定测试观测。共享实现或相同参数不意味着源/目标IQ、接收机、日期、随机作用或噪声相同，也不消除跨接收机分布差异。

这次只消除了一个可具体核查的实现漂移疑点。载频差异是否影响任务仍未知，不能用它解释DURA与其他新G之间的全部差距，也不支持仅凭此项重新生成缓存、增加目标数据使用或选择性重跑。下一步继续当前已冻结候选的完整Main七景和独立truth-last，以真实身份性能判断新架构；后续源模拟变更仍需在新run预登记。

## 2026-11-07 按实际绑定复核源 IQ 与历史 Main

**原 63,000 条源 clean IQ 在按实际训练绑定对齐后只存在浮点舍入差异。** 原 F0 配置目录的 IQ 文件是链接，配置目录的 ID 顺序与底层数组的存储顺序不同。最初直接按配置目录的行顺序比较，误把重排当成了波形差异。原训练代码通过已解析的存储路径寻找物理 ID 索引，再用 ID 对齐数组。实际累计第 20、30、50 轮三个训练段的源冒烟均记录了同一绑定，L_s 重排 6,298/6,300 行，U_s 重排 56,699/56,700 行。

R07、G10、F0 的同条物理 ID、源角色、接收机和日期相同。对齐后的 IQ 复算如下。NMSE 每条用右侧对照的 IQ 能量归一化，再对该角色取均值。

| 源角色 | 配对 | 逐值相同的记录 | 平均 NMSE | 最大逐点差 |
|---|---|---:|---:|---:|
| L_s | R07 对 F0 | 4,145/6,300 | 1.154e-15 | 2.384e-07 |
| L_s | G10 对 F0 | 34/6,300 | 2.173e-15 | 2.384e-07 |
| L_s | R07 对 G10 | 34/6,300 | 1.756e-15 | 2.384e-07 |
| U_s | R07 对 F0 | 37,213/56,700 | 1.162e-15 | 2.384e-07 |
| U_s | G10 对 F0 | 249/56,700 | 2.189e-15 | 4.768e-07 |
| U_s | R07 对 G10 | 249/56,700 | 1.768e-15 | 4.768e-07 |

R07 对 F0 的最大逐点差为 2.3842×10⁻⁷。这个结果核对的是实际输入绑定，不能由目录行顺序或文件名判断。

**Main 两个总体的 168,000 个 ID 全部来自 2026-10-02 的原六景缓存。** 已完成的 F0 正式预测只读取物理 ID 数组用于核对，两个总体分别匹配 126,000 和 42,000 个原 ID，新增 union 记录为 0。原 union 构建器对这些 ID 复制原 clean 和每景 received 观测。已复用原 VALIDATED_ONCE，未重新生成或逐字节重验 Main IQ。原六景配置和 union 新增部分逐项相同，六景原载频均为 2.450 GHz。这个溯源结果补足上文对历史复制样本载频的保留。

R07 源训练以原源 RX×day 生成 15 个虚拟接收会话，原 Main 使用一个共同的 virtual_target_session0。这与真实地面记录的接收机划分是两个维度。R07 源载频 2.462 GHz，源训练接收机种子 2026101911，Main 原接收机种子 2027。两者仍存在模拟会话与随机实现的分布差异。现有证据核清了输入和来源，尚未测定这些差异造成的识别性能变化。

本次只读原 L_s/U_s IQ、原 F0 源绑定记录和历史 Main 的物理索引及 manifest。没有读取 Main IQ、预测值、TX 真值、源 V 或 OE IQ，也没有运行模型、修改现有候选或从结果选择新参数。
