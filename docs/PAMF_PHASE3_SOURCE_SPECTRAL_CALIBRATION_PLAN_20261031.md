# Phase3 源接收机幅频补偿证伪（2026-10-31）

本轮先检验一个输入层假设：接收机共有的平滑功率谱差异能否在不使用 TX 标签拟合、不依赖伪标签的条件下补偿，并保留身份信息。主研究基线仍为 PCD_predicted_ratio；此行只用源 L，不访问目标 U/Q，不替换基线，不证明跨未见 RX 泛化或未知拒识。

相比继续修改已反复检验的特征密度或置信度伪标签，本行改变波形的平滑幅频形状。它不估计完整物理逆信道，不恢复相位响应，不训练 DURA。候选的选择与常量在源诊断前固定，未按目标 Q 调节。

## 输入与固定方法

只读取原合同 392005 的源星地 L6300，经冻结 DURA v1.0 R69 得到的原 P1 缓存。源 RX1/3/4/6/8（1-19/18-2/19-2/2-19/3-19），2021-03-08/15/23，六旧 TX 与历史 L 角色不变。原 F0 三视图 E50/11100、source-only r03 E_SIGNAL2220、DURA 全部冻结；不加载任何 target-adapted PCD 权重。真实模型已经见过这些 RX、TX 及源 L 物理记录，因此只是训练角色的时序诊断，不是独立测试。

每 RX 用早日 03-08 的 420 条 P1，先计算每记录 256 点复 FFT 的功率，再将功率除其频率均值，只在统计拟合中消除每记录能量差异。平均后用循环 17 点箱形平滑，floor1e-8 并归一到频率均值 1。该步骤不改输入波形 RMS，不读取 y。

对每 RX，参考谱为其余四 RX 早日谱的逐频几何均值，再归一。增益为 sqrt(reference/own)，固定裁剪到 [0.5,2]。处理波形使用 256 点循环 FFT/逐频实正增益/IFFT，输出 FP32，不再 RMS。它是循环、无相位补偿的数字变换；幅频增益并不强制关于正负频率偶对称，复杂 IQ 可以保持复杂输出。不得将其写成新增独立观测或物理信道估计已成功。

五个状态全部冻结后，对 L6300 完成 IDENTITY 与 RECEIVER_PSD 两路 F0 默认头及纯源 r03 表征预测；全部预测文件固定后才使用源 y 计算诊断。早日 2100 条属于统计拟合角色，后两日 4200 条只推理评分。后日不参与谱状态拟合；模型训练已见后日的事实保留。源 V/NV/OE/Us、目标 U/Q 和 private truth 新读均为 0，不重拟合密度或阈值。源场景 metadata 缺失，逐景记 N/A，不重建新信道。

## 事前固定的源筛选

只比较这两路，不搜索平滑宽度、增益范围或频谱参考。后两日每个 RX 的 F0 六类宏闭集准确率较同 P1 原始输入最多下降 2 个百分点；同 TX 跨 RX 的 r03 单位类中心平均 cosine 距离至少下降 10%；六 TX 整体类中心间平均 cosine 距离至少保留 95%。三者同时满足才记 SOURCE_SCREEN_PASS_REQUIRES_TARGET_CONFIRMATION，否则 SOURCE_SCREEN_FAILED。降低接收机差异若同时压塌身份分离不能通过。

筛选只提供下一候选的源侧资格，不自动触发目标访问，不宣称开放拒识或匿名注册通过。A_K/C_K/R_U/H/AN/HOW 本行均不适用。完整目标保持 clean 跨 RX RU≥95%、星地跨 RX RU≥90%、CK≥90%、同 DURA 原 F0 闭集减 AK≤2pp；发现及未来匿名注册仍未完成。
