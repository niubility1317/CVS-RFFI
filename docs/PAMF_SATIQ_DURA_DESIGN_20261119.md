# SatIQ 上的 PAMF 跨时间识别与 DURA 恢复实验

状态：实验设计及源期数据核查完成。本文中的预算、阈值及比较行均为拟定设置，尚未产生模型结果。

## 研究问题和实验路线

第一轮依次回答两个问题。第一，PAMF 的三视图表征和半监督机制能否提高真实 Iridium 下行的跨时间卫星编号识别。第二，前置恢复能否在相同物理记录和相同冻结识别器上减少错分，尤其是检测质量较低的记录。

现有 Zenodo 8220494 版有 1,706,556 条消息，25 MS/s，每条 11,000 个复数 IQ 点，来自牛津屋顶的单站接收。以 ra_sat 为卫星编号标签。ra_cell 是波束编号，首轮仅用于评分分层。接收站只有一个，时间和接收机身份不能互换。作为对照，完整 PAMF 的跨 RX 监督对比、伪标签配对、MixStyle 和特征外推都需要真实 RX。首轮选按源日期配对的 SatIQ 适配版本，并用关闭配对的匹配对照量化这项替换。原封不动的跨 RX PAMF 需要另选真实多 RX 的数据契约，或另行建立 SatIQ 多站点版本的合法划分。

所有 F 和 G 权重按 SatIQ 的数据契约从零训练。既有 WiSig 的 F 和 DURA checkpoint 属于不同的数据契约。可复用实现和结构定义，不能加载既有权重、归一化统计、原型或阈值到这项正式对比。SatIQ 是星发地收的实测外部数据，项目的地发星收主结论仍按其原协议验证。

## 输入表示先在源域确定

25 MS/s 下，256 点只覆盖 10.24 μs。Iridium 速率 25 ksymbol/s，每符号约 40 μs。对 data_005_009.tar.gz 的第 008 段前 512 条源期记录，取起始 8,000 点，Hann 加窗计算每包 FFT 能量的中位占比，±25 kHz 为 97.4%，±100 kHz 为 98.8%。这项抽查说明基带能量大多集中在窄频带，尚不能判断高频能量是否携带可分辨的硬件信息。

以公开下变频和 IQ 导出代码、公共同步模板和源期波形确认固定消息头及切片边界；不能把 uw_start 命名当作数组起点依据。主候选和对照的数据均完成同一套源域对齐检查。只使用确认不含身份载荷的公共前导部分，滤波边界以对应公共片段本身延拓，避免临近载荷影响。解码字节、波束、中心频率、位置、日期、检测质量均不作为识别器的波形输入。源训练日期仅供配对。

| 选项 | 表示 | 回答的问题 |
|---|---|---|
| 方案 A | 对齐后，从公共前导中选一个固定过渡附近的连续 256 点，保留 25 MS/s | 短窗和高采样率瞬态能保留多少身份信息 |
| 方案 B | 经源域固定的抗混叠 FIR，将 8,000 个公共前导采样按 4/125 比例变成 256 点、0.8 MS/s。初拟通带 ±100 kHz，阻带自 ±350 kHz 起 | 横跨约 8 个符号的上下文是否更有效 |

两个方案都输出 FP32 [B,2,256]。A 的过渡按协议及不带身份标签的源期平均波形确定。B 必须核实公共片段的 8,000 点覆盖及相位对齐，再核对 Sinc 初始化和滤波边界以 0.8 MS/s 解释。相同张量尺寸不代表相同频率或记忆时间。对每种表示用同一个 CE 训练预算（拟 1,000 更新）在同一 L/V 上比较，按 V 宏 F1 选择，持平时优先保留 25 MS/s。选中的表示供后续 F 和 G 所有正式行共享。若两个表示都不能在 V 明显区分六类，返回源域检查对齐和前导长度，不用目标结果挑裁剪位置。

## 识别实验及归因

三视图 SIG-TIME 和默认六类余弦头从零联合训练。实验以相同物理 L/U、输入、模型初始化种子和有标签采样日程对齐。识别器的 ordinary/raw 视图沿用协议兼容的配对波形路径，As 槽保持既定的源波形角色并明确实际增广，首轮采用真实下行和通用匹配扰动，不附加原项目六种仿真信道。先在源域核实残余频偏与时间变化，避免通过额外 CFO 校正或相位对齐主动抹掉希望识别的硬件信息。

| 行 | 方法 | 比较意义 |
|---|---|---|
| F1 | PAMF-CE，纯 CE，自然顺序，U 关闭 | 识别结构基线 |
| F2 | PAMF-Sup 的跨时间适配，自然顺序。跨源日期的同卫星监督对比、ordinary/raw KL、As 真实标签 CE、As KL 为 0 | 完整有标签骨架在跨时间训练中的效果 |
| F3 | F2 加普通 PL，阈值 0.95、权重 1，自然顺序 | 普通半监督增益 |
| F4 | F3 加固定局部重排 [0,5,3,6,2,1,4,7] | 隔离固定重排和半监督方法的收益 |
| F5 | PAMF 的 SatIQ 跨时间适配。保留三视图、固定重排及 REPL 骨架，同类不同 RX 配对改为同类不同源日期配对 | 与 F4 比较适配 REPL 的净增益 |
| F6（归因行） | F5 关闭所有需要不同日期的 L/U 配对项、MixStyle 和外推，保留相同重排、其他损失及正向学生预算 | 检验日期配对机制本身是否有贡献。解释 F5–F6 时披露同时关闭的监督与半监督配对项 |

先用单模型种子 2026092701，固定 50 个等长训练阶段，每阶段 100 更新，共 5,000 更新。E1–13 仅 L，PL 行从 E14 开启，F5/F6 自 E21 启用相应 REPL 项，F3/F4 保持普通 PL。L/U 批量 128/256，U 真实身份始终隐藏。split seed 拟 2026111901，扰动随机状态与模型 seed 分离。报告日期配对覆盖、各日 U 伪标签接受率、每行更新数和实际计算成本，保留固定终点。适配版称为“PAMF（SatIQ 跨时间适配）”。不将日期替换后的结果作为原跨 RX 完整方法的复现。

## DURA 恢复实验

SatIQ 只有接收后的 y。传播、接收机和发射机都会改变 IQ，因此从 y 单独反推出无失真的发射波形并不唯一。高质量的接收记录仍含真实链路与接收机影响。首轮把 DURA 的研究问题限定为“在保留身份信息的同时，能否抑制额外退化”，再用自然接收数据检验冻结识别能否获益。

### DURA 训练和逐级扩展

1. **准备同包配对。** 从合法源 L/U 波形中按训练期 magnitude 的上 20% 固定抽取高检测质量的接收参考 z。G 端只看到波形和采样需要的 ID。对选定表示中的 z 加入独立生成的带限复噪声，得到 y′。只添加噪声，使用同一测量带宽定义额外加噪信噪比 $10\log_{10}(P_B(z)/P_B(n_{add}))$，训练抽样范围 0 至 20 dB，V 和冻结后的 Q 合成对照用固定的 0、10、20 dB。该量只描述已知附加噪声。各对照收到相同 y′，保留低质量自然接收记录用于真实测试。
2. **先做可识别的恢复。** 复用 DURA 双阶段先验与软数据一致性的结构，从零训练。对于首轮加性噪声，将前向作用固定为单位算子，方差由输入估计并限制为正，以便区分网络学习与人为信道假设。两阶段各保留一次先验预测，数据一致性可使用闭式更新 $x_k=(\tau^2 y'+v p_k)/(\tau^2+v)$。它属于 DURA 结构变体，公开既有 DURA 实现中的可学习作用算子及迭代预算与本版不同。F-free 主行使用配对复 IQ 归一化误差与弱多尺度谱损失，G 训练看不到 F 或 TX 真值。固定训练预算，拟 2,000 更新。
3. **后续单因素扩大作用算子。** 如果首轮配对恢复和真实身份保护均过线，再选源域证据支持的一种额外退化，如有界的残余频偏或短时线性多径，保留只有加噪的原对照。届时按所选表示的真实采样率定义抽头覆盖时间，复核复数伴随和范数边界，再比较是否需要恢复原复数主／镜像算子。F 指导属于另一种实验，需要同合同、同源冻结的 F 和单列对照来量化监督贡献。所有新增 G 从合法源拟合，不能用自然 Q 反向更新。

### 同包评估

在识别实验和 G 冻结后，对同一条自然接收 IQ，以及它的固定人为加噪版，分别比较以下路径。所有路径共用 F5 的同一冻结 checkpoint 和默认头，使用相同的输入归一化统计及同一评估 ID。传统基线采用在源域固定的带限滤波器，不使用每条的真实附加噪声或参考。

| 路径 | 作用 |
|---|---|
| IQ → F5 | 身份基准 |
| 固定带限滤波 → F5 | 量化纯带宽限制可带来的收益或损伤 |
| SatIQ 双阶段恢复 → F5 | 检验恢复是否优于两条基线 |

主要终点为真实未来 Q 的宏 F1 与宏召回。对 G 报告相对直通的净纠错、错变对、对变错及其配对差。以源训练期 magnitude 下 20% 的数值阈值定义低检测质量组，同时报告上 20% 和全体结果。质量字段只供评分，不输入预测器。按卫星、波束、UTC 日期和质量分层，使用时间块重采样给出配对区间。合成配对上同时报告相对已观测 z 的复 IQ NMSE、频谱偏差及识别结果。天然接收数据无对应发射端参考，天然 Q 仅凭分类增益或输出外观不能证明恢复了无失真发射波形。若关心接收机或传播参数，用有同一发射观测和明确校准关系的采集另行验证。

首轮拟用以下晋级标准，所有阈值为研究决策而非既有成绩：F5 相对 F4 的自然 Q 宏 F1 至少提高 2 个百分点才考虑扩模型种子。G 在固定合成低 SNR 条件下须优于直通和传统滤波，同时真实低质量组的宏召回净提升至少 2 个百分点，自然 Q 总宏 F1 与高质量组均至多下降 1 个百分点，才值得扩大恢复器矩阵。阈值用于判定本轮是否晋级，所有已登记预测均先冻结再评分；若结果展现波形分数好转但真实下行识别变差，保留负结果和原始基线。时延按相同设备和 batch 1 测量，并计入滤波或降采样。

## 执行和声明边界

本机先生成输入诊断及独立数据角色，分别保留 source、public query 和 truth 对象。正式执行前按当前仓库最小实验流程登记实际数据句柄、方法、样本数、固定命令、环境、N607 资源、停止规则和唯一输出目录。预测器不读取真值，独立评分器在每个已预登记行的全部视图预测冻结后连接真值。外部 SatIQ 自定义时序任务不使用原 WiSig Phase2 的数据句柄。源期的谱占比和类别计数是这份设计的可行性检查，尚未训练识别器、恢复器或读取目标波形生成实验预测。
