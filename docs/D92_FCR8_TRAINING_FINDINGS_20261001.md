## 9. 得到支持的解释与仍未确定的原因

| 判断 | 本轮证据与边界 |
|---|---|
| 函数坐标有真实可测的 support 位移意义 | 直接位移与坐标平方的最大重构误差 1.60e-16，白化残差均在实际容差内；只支持当前 support 的 pre-tangent 等式 |
| 方法确实训练并改变前向与判决 | 936 信息阶段全部更新，初始梯度非零，角度、核、score 和 winner 实际变化；不能再用“训练没执行”解释 |
| 数值秩截断不是本轮信息阶段瓶颈 | 所有实际 SVD 保留 8 维；仍不能证明固定 8 维字典有足够类别表达能力 |
| keep 硬约束没有截断实际方向或 trial | guard/keep 拒绝均 0，接受状态有正 keep 余量；软 keep 信号仍真实影响目标 |
| 连续训练改善能部分传到训练准确率 | 三模式训练 margin、task 与净准确率均值改善；不等于未参与训练的样本更好 |
| 有限方向与 trial 预算留下未消除任务梯度 | 806 阶段耗尽，末 task 梯度全部非零；不能称收敛，也不能承诺更小步或更多迭代一定有收益 |
| seq 与 reset 的差异可测 | seq 末训练准确率更高但增量更小，anchor、initial U 和 keep 上限同时改变；不作单因素因果结论 |
| 表达、正则、head 重拟合或训练泛化缺口谁是主要原因 | 当前训练证据无法单独识别；需要当前外层 support 报告及后续预声明结构比较，不能从本报告固定候选或反馈 query |

关于“监督 margin 已改善而持出无明显收益”的陈述，前半句已由本报告实测支持；后半句必须由主 Agent 的独立外层 support 报告核实，本报告没有读取该分数。若外层报告确认没有新旧共同改善，可以解释为当前训练机制与未参与训练样本之间存在缺口；不能进一步把缺口唯一归因于某种 loss、归一化、教师、固定字典、继承或 head 重拟合。
