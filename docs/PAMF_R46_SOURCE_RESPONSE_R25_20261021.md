可以确认的现象与边界如下：

- R22 恒等版在本 clean 训练面板的 paired clean NMSE 较 R18 降低 24.1399%，但 random 0.005 的父响应差异为 R18 的 2.153424 倍（0.0039626311 对 0.0018401535）。其 clean random 步长差异均值约 1.00384e-5，median 约 2.338e-7，存在少量更高值，不能仅用均值推断普遍不稳定。
- 在 received01/20 上，恒等版两档幅度、两种方向的平均父响应误差均略低于 R18；random 约 0.15，phase 约 0.27。该诊断没有支持“R22 所有源响应都更差”的解释。历史正式性能仍存在取舍，源输出或源响应指标均不能保证目标 TX 性能。
- received01/20 的 phase floor 命中率分别 15.234375% 和 15.625%；相对指标须结合 response_error_clean_nmse 及原父响应增益解读。0.005 幅度下 received20 恒等版 random/phase 的 clean 归一化响应误差约 1.1829e-6 / 2.305e-7，不能把相对比值夸大为同等幅度的波形损伤。
- 两档幅度给出的平均响应误差基本一致，为本范围有限扰动诊断提供稳定性证据；仍未证明更小步长极限、完整 Jacobian、TX 身份或在轨真实性。

本轮机制结论：平均输出拟合与局部响应保留不是同一个目标；新增复频谱/恒等约束改变两者取舍，但 R25 无法唯一定位正式 TX1 退化的因果来源。后续可检验同一原父、同一压缩图上“扰动后输出拟合”与“成对 odd 响应拟合”的等前向成本对照；只用原训练 L_s/U_s IQ，不能读取 F/TX/V/target 来设置损失，不能以本诊断替代每个新训练版本的七场景正式测试。
