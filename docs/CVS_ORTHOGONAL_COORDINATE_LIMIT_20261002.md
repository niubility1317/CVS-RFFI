# 包内正交坐标的实验结果与结构限制

本轮硬替换正交输入没有提升源域识别。四种子固定性能分数为：原控制 `adaptive_volterra_lag4` 97.0806%，`orthopoly_instant` 94.9523%，`orthopoly_memory4` 95.1505%。8个新模型均从零完成200轮、每轮50步；只使用交叉熵，不使用增强或域骨干。源规则保留原控制，两个新候选没有访问目标query。本文件解释已经验证的坐标关系，不把公共诊断当成分类性能或退步原因的证明。

## 数学关系

同包、同延迟的原输入为 `b=[z,zp,zp²]`。正交输入为：

```
d = p - μ
h = [z, 4zd, 16z(d² - ad - v)]
μ = E_w[p], v = E_w[(p-μ)²], a = E_w[(p-μ)³]/max(v,1e-8)
w = |z|²
```

存在精确逆变换 `b=T(μ,v,a)h`：

```
T = [[1,          0,           0],
     [μ,          1/4,         0],
     [μ²+v,       (2μ+a)/4,    1/16]]
```

矩阵T依赖当前包的IQ统计量。原IQ保留，因此不能把退步解释成数学上丢失了全部原始信息。问题是同样的固定卷积系数现在作用于随包变化的坐标，原有多项式项对应的系数关系不再是一个固定三阶矩阵。完整CNN可能从原IQ间接学习这些量；上述关系不构成完整CNN表达能力的下界或上界。

固定原滤波器W在正交坐标中的对应形式为 `WT(μ,v,a)h`。显式接回整个T会精确恢复原lift及其函数，不能单凭这种函数等价改写宣称识别性能提高。11项聚焦检查验证了逆变换的数值、输入Jacobian、退化包、包间形状边界，以及公共卷积恢复。

## 公共通信链诊断

使用既有30组公开合成通信链IQ（6组TX设置×5组RX设置），不使用真实身份标签、正式源数据、目标数据或训练checkpoint。每个延迟统一拟合一个实数阶次混合矩阵，仅用于检查坐标关系；没有按TX/RX名称分支，也没有更新分类器或源选模。

|正交输入|逐包精确恢复最大误差|实际scratch卷积恢复最大误差|统一实数逆矩阵相对残差范围|
|---|---:|---:|---:|
|instant|1.1102e-16|4.4409e-16|0.003995至0.004060|
|memory4|5.5511e-17|4.4409e-16|0.001848至0.001879|

本诊断使用CPU float64验证坐标恒等式；不能拿这些误差替代正式FP32源训练的误差。统一矩阵的残差按三阶坐标总体范数计算，不是身份错误率。拟合覆盖全部公共包的I/Q和时间点，没有独立测试集；它用于说明一个固定实数逆矩阵不能精确替代记录中的逐包逆矩阵，不评价泛化，也不覆盖所有复数时域卷积。实测矩阵系数在这些公共包间变化，符合闭式公式。

## 物理与射频指纹含义

接收IQ中的包络矩同时受发射波形、TX非线性、传播和RX处理影响。对接收IQ计算μ、v和a，不会自动得到发射机PA系数。用正交多项式描述一个已知激励下的PA，与对未知发射符号经过RX后的IQ做逐包正交化，具有不同的参数含义。

本轮已核对的TX/RX同波形反例保持成立。不能从正交Gram、源分类分数或逐包逆变换推出唯一TX硬件恢复、TX/RX因果分离、任意信道不变性或实测在轨泛化。原始瞬时/记忆输入、相位和幅度信息的保留，需要分别与具体硬件扰动敏感性核对。

## 后续实现约束

源实验与公共诊断支持保留原有接收非线性坐标作为明确参照，而不是把包内Gram改善等同于指纹识别改善。下一结构应清楚说明：固定滤波器实际接收哪些坐标、逐包统计量如何进入函数、哪些原有路径保留，以及新增作用如何区别于完全等价的逆变换。

若探索原坐标与正交残差的联合或可学习组合，需要从零源训练并按既有四种子源规则冻结，再只测试被选中的新候选。这里没有指定新超参数、发起新训练或使用目标分数确定结构。性能仍是主要目标；参数和运算成本是次要比较。本次源负结果与公共诊断都不证明总体性能目标已完成。
