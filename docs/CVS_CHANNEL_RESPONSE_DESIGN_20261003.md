# 显式补偿响应：下一轮Phase1架构

状态：模型与单CE训练入口已实现并完成本地正确性验证，尚未发布正式训练。识别性能及论文贡献仍待验证。本设计只使用完整源V归因证据；不使用目标结果制定结构或选模规则。

## 源证据与改动理由

[完整源V归因](../automation_reports/CV-SincNet/20261003-diagnostic-cvs-channel-attribution-source-manysig-m8-r01/report.md)覆盖8个冻结模型、44个条件。双路读出平均余弦相似度0.99998243，投影相似度0.99992968。关闭整个辅助支路降低源V准确率0.14537个百分点，但将G设为恒等仅降低0.00185个百分点，四模型合计108000次预测只变化7次。辅助支路在当前权重下的主要贡献不能直接归为补偿贡献。

order的D相对特征幅度为0.00180122，D投影/原主干范数为0.00016875；关闭D只改变2次预测。D交叉项时序相干比例约0.62966，因此不能把结果主要归因于严重的时序平均抵消。下一步优先移除重复u/v描述子的直接相加通路，同时保留可学习的局部读出，检验是否能学到有效补偿响应。

这些是冻结权重下的源域依赖诊断，不是从零重训的因果效应，也不能证明目标泛化。

## 实际结构

保留原`neural_residual_shallow`完整主干、频率路径与分类头。新辅助分支保留同一个有界逐包复FIR补偿器G、共享全采样率复特征映射F和共同有效裁剪，但不再提供单独的`readout(F(x))`或`readout(F(Gx))`投影。

令u=F(x)，v=F(Gx)，Δ=v−u。每个通道每个位置构造有符号复交叉项：

\[
q_{c,t}=\frac{\overline{u_{c,t}}\,\Delta_{c,t}}
{\max(\operatorname{mean}_t|u_{c,t}|^2,10^{-6})}.
\]

实部与虚部形成16个逐位置输入通道，经无bias的16→64点卷积、GELU、无bias的64→64点卷积生成值向量。64通道分为4头，每头16维，分别作均匀或可学习时间汇聚，拼接后由无bias的64→160线性层投影，加回原主干特征；最后沿用原分类头的一次L2归一化。

注意力从u的逐位置功率除以同通道包均值后取log1p，经8→16→4点卷积与GELU生成，沿当前包时间维softmax。它不读取接收机编号、发射机标签、其他包或目标统计。

第三个候选额外输入D=F(Gx)−G(F(x))的同类有符号交叉项，共32个输入通道，其余结构相同。G在输入和特征上使用同一组由原x计算的系数。全部辅助计算保留原256采样率，左右各裁5点，保留246位置。

## 结构保证与限制

**当G为恒等时，新辅助输出严格为零，即使其余权重已经训练。**这由Δ=D=0、值编码与投影无bias、GELU(0)=0保证，避免旧辅助分支通过重复普通F(x)描述子获得全部收益。它不保证G一定学到真实信道，也不保证网络必须依赖补偿分支；原主干仍可单独完成任务。

G系数出口零初始化；值编码与投影保持非零随机初始化。新模块RNG与主干隔离，初始完整分类函数与相同seed的原主干完全相同。Δ交叉项在零点附近保留一阶梯度，因此G出口第一步即可收到CE梯度；本地测试确认全部新增参数张量最迟在第三步得到非零梯度。没有预训练、额外loss、增强、重加权、采样变化、分阶段解冻或人工提升响应权重。

共同相位不变、逐包独立与“恒等补偿时输出为零”是结构正确性结论；它们不是任意多径/接收机不变性或TX/RX可辨识性结论。当前equalized=1、center256、unitRMS数据边界保持不变。方法新颖性及论文核心贡献尚未成立，必须由相关工作区分、结构消融和独立性能证据支持。

计划3候选×4原model/loader seed，共12个从零训练模型。保持原数据物理角色、E200×50、batch128、AdamW与cosine、FP32和单一CE。与原shallow四份和上一轮源域胜出的dual四份固定源记录组成20行选择矩阵；后者不能因目标结果而被排除，也不继承其权重。
