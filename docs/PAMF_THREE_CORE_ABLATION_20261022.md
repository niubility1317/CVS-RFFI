# PAMF 三核心机制：按功能归组的主消融

## 分组依据

按用户 2026-10-22 最新要求，将学习机制收敛为 **两个监督机制和一个半监督机制**。分组来自实际目标函数、数据权限和执行依赖，不读取目标收益来决定成员，也不将已有细项的正负结果用于改组。

| 组 | 主机制 | 合并包含的实现 | 不单独作为主贡献的细项 |
| --- | --- | --- | --- |
| A | 跨接收机身份对比（CRIC） | 同 TX／不同物理 RX 正对、异 TX 负对、浅／中层共同约束、特征标准化与温度、warm/ramp | 单层位、单温度、各层权重不分别占主表 |
| B | 成对预测一致性 | ordinary128、ordinary64、raw128 各槽随机两前向的对称 KL，统一开关 | 各槽 KL、重复前向的细节不拆成多个机制 |
| C | 选择性半监督自训练 | 自身 EMA、RX/day 置信度、相邻观测筛选、强视图筛选、伪标签 CE、全部 U 的熵项 | 每个筛选器、EMA 和熵不各自成为主机制 |

网络的 SIG_TIME_X3、时频／PA／参考响应融合与默认头在本组消融中固定。它们属于结构面板，不与训练目标和数据权限混成同一个开关；DURA 作为独立恢复器固定复用。这样三组分别回答“跨域身份关系”“随机预测稳定性”“无标签利用”三个问题，不把一次结构删除后的容量变化混入学习机制。

As KL=0、真实标签 CE 路由、raw 权重、label smoothing、Sinc 参数坐标／优化单位和三段日程是共同骨架，不按收益包装成额外主贡献。特别是 B 关闭后仍保留相同的两次 CE：它检验 KL 一致性本身，不同时减少标签剂量、增强样本或网络前向。

## 实际目标函数与开关

固定真实标签部分为

\[
L_{\mathrm{MVCE}}=0.5CE_{2,ord128}+0.25CE_{2,ord64}
 +0.25CE_{2,As64}+0.25CE_{2,raw128},
\]

每个 \(CE_2\) 是相同输入的两次真实标签 CE 均值，LS0.01，总 CE 剂量 1.25。As 始终只用真实标签 CE、KL0；没有 ordinary 与 As 之间的跨视图 KL。

\[
L(a,b,c)=L_{\mathrm{MVCE}}+a\lambda_{RX}L_{RX}
 +b(0.5KL_{ord128}+0.25KL_{ord64}+0.25KL_{raw128})
 +c(0.16L_{PL}+0.01L_{ent}),\quad a,b,c\in\{0,1\}.
\]

A 保留原同 TX 跨 RX、两层／两前向、温度0.2、warm5/ramp10到0.1。B 的 ordinary/raw KL 系数与原 T1 一致。C 是完整原生选择性 SSL，不改成普通 PL：EMA0.999、分组分位数0.86裁剪[0.92,0.97]、相邻一致性、噪声0.015强视图筛选、PL0.16、熵0.01共同启停。C=0 时不构造或遍历 U，不建立／更新 EMA，不运行无标签前向，全部50轮仍使用相同 L 监督骨架。

这是固定最终 T1 的匹配消融。它继续保留原 T1 的 As 生成／CE 路由及原生 U 例外；不额外叠加默认 concat0.68 从而改变完整 T1。既有比较方法、matched Sup／普通 PL 和严格监督结构面板继续原默认拼接配方。000 是“固定多视图 CE 骨架”，不是 F15 的 LS0／默认 concat 纯 CE 配方，也不是历史 SIG_TIME E200 网络表。

## 数据、预算和预测

使用已验证且 IQ 按物理 ID 对齐的 F0：ManySig、六 TX，源 RX1/3/4/6/8，源 day1/2/3，L6300／U56700／V27000。C=0 的 U IQ 使用为0。目标 RX0/2/5/7/9/10/11、四日期、168000物理包，测试为 clean＋六 practical。它是五源固定条件下的机制研究，不是重启已取消的五源数量扫描。

三 seed2026092701/02/03，split392005、固定收到的七视图 IQ 和原类别顺序不变。每个新 F 从零开始自身20(13L＋7LU)→10LU→20LU；C=0 时三段全部 L-only。共E50／11100更新、L128／222步每逻辑轮，三段重置 AdamW、cosine和原 temporal 状态。保留 lr2e-4、wd1e-4、cosine到1e-6、CENTER_UNITS、全模型物理 clip5、默认160维／六类余弦头联合训练，不另训探针或分类头。

新12个 F 增量为600模型epoch／133200更新，不新增 G。每模型按 raw、同一 G-L、同一 G-LU 读出；原 raw 和已闭合 G-LU 决定复用。111/011/101只补九个 G-L 行；110 的 G-L 复用已发布 T1_SUP 读出。总新增12训练＋21预测＋21评分＋1独立CPU汇总=55阶段任务。

主机制推断首先看 raw，从而完全排除恢复器的 U 权限因素。G-L 和 G-LU 作为各自固定的系统读出分层报告，不混合：C=0＋G-L 是全系统不使用 U；C=0＋G-LU 仅说明 F 不使用 U，不能写成全监督。各读出条件于固定 G，三个 F seed 不冒充三次独立完整系统重复。

每行全部预定读出／七视图冻结后，才由独立 CPU scorer 连接真值。正式汇总同时报告 Accuracy／Macro-F1、每 RX/TX/day、最差 RX、clean 损伤、修复／损伤／净纠错和实际训练成本；负差、无收益与缺项完整保留。111−011、111−101、111−110 是其他组开启时的条件效果；完整八格另给平均主效应、AB/AC/BC平均交互和ABC交互，按 seed 内先计算再汇总三 seed 样本SD。不得把七场景、包数或交叉格当独立模型样本。

推理图在八格中相同，A/B/C都不参加部署，不重复已闭合统一时延；训练开销取实际共享负载下的完整段／轮成本，不能把原第二前向删除的 F05 耗时当成 B 的匹配开销。源 L 几何／11项固定干预随新读出诊断，不拟合头、不读 target，不用于按分数重排。

## 发布与安全边界

主科学run为 `20261022-phase1-PAMF-core-mechanisms-m24-r01`，九个复用 G-L 读出为 `20261022-phase1-PAMF-core-G-L-readouts-m9-r01`，CPU汇总为 `20261022-phase1-PAMF-core-factorial-analysis-r01`。唯一资源owner为独立 `20261022-phase1-PAMF-core-control-r01`；实际发布后在各登记记录 Git、PID/CWD/argv/GPU与日志增长，不能把本地验证写成远端运行。

新控制器先通过一次真实固定 checkpoint 无 query smoke和四个新增组合的实际源 L／默认头梯度检查，然后精确接管旧owner；保留健康worker原PID/CWD/配置和其 per-job release。核心12新F及 F04/F16/F20 依赖按本次主表范围固定优先，不依据目标得分。原预算、数据、其他owner及当前资源上限不改；同技术指纹两次停止新派发。全部预测和分析完成后汇入 IEEE 实验章节和新不可覆盖导出，相关权重／IQ／原始日志／私有runtime不提交。
