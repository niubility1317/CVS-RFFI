## 物理依据与确定的变更

完整源诊断已确认：公共相位约束在真实 V 上成立；固定正负 80 kHz 相对 CFO 仍改变整个表征，时间、行为与频率路径均有响应。已经核实的 80:160 周期段和 25 Msps 下 20 点短周期，支持在全部身份路径之前研究逐包同步。WiSig equalized=1 的参考均衡链先校正 CFO、均衡，再加回 CFO；当前输入不是未处理的原始 PA 输出。出处与处理边界沿用[物理标准](CVS_RFF_PHYSICS_AWARE_CRITERIA_20261002.md)，不新建数据视图或改变实际物理 ID。

令 `C=Σ x[n]conj(x[n−20])`，总和跨 80:160 内 3 对相邻周期、60 对样点。估计 `ωhat=arg(C)/20`（rad/sample），`fhat=ωhat×25e6/(2π)`（Hz），全部 256 点使用 `S(x)[n]=x[n]exp(−jωhat n)`。这个确定性的网络前端在训练和推理同样执行，没有随机视图或增强损失，所有后续路径只收到 S(x)。

对 `x'[n]=exp(j(θ+δn))x[n]`，有 `C'=exp(j20δ)C`。当 C 有效且主值不跨界时，`ωhat'=ωhat+δ`，所以 `S(x')=exp(jθ)S(x)`。后面的整网常相位不变核心即可得到有条件的仿射相位不变。此性质不要求输入理想重复，前端协变公式对有效 C 成立；把估计解释为真实频偏则还需要重复、近似稳定信道及噪声等假设。估计仍是 TX−RX 相对频偏，不是发射机晶振参数。

主值范围为 −625 kHz 至 625 kHz，歧义间隔 1.25 MHz。跨分支会留下一个 1.25 MHz 倍数的相位斜率，不声明任意 CFO 不变。相关相干度阈值 1e−6、能量地板 1e−12 固定；退化时零频率校正并报告 fallback，不宣称该分支仿射不变。atan2 在输入替换后计算，避免零/弱信号梯度未定义。全包前端使用未来周期，整体不声明在线因果推理。

同步点乘单位模复指数，保持每个样点的幅度、时间位置和整包非线性形状，只改变仿射相位坐标。它同时删除相对线性相位信息，可能损害身份性能。不能把同步成功或公式成立当作性能成功。AM/AM、AM/PM、记忆响应仍受未知接收链耦合；既有 TX/RX 镜像、三阶相同波形反例继续保留。
