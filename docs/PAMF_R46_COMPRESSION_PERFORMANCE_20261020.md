八行均直接从用户指定的 R46 prune_refine350521 分叉，新增 E20/4940，同一配对 clean IQ、三尺度谱误差及冻结父 IQ 教师目标，全部 coarse/action/prior 联合优化。R48 micro64，R49 micro256 加直接 float32 buffer，全局 batch256 及 L/U 曝光相同。每组件累计 100 轮、组件和 300 轮、串行累计 140 pass，F50 训练另计。追加预算、剪枝和吞吐实现分别披露，不能将所有差异归因于压缩。

恢复器训练读取 TX 标签、F 输出、V 和 target 的次数均为 0；使用了合法 source clean/受损模拟配对及无 TX 标签的 U_s，属于 TX 无标签源域自监督，不能称为无 clean 盲学习。正式准确率使用事后独立真值评分，不会反向更新恢复器。
