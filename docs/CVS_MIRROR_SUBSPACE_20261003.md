# 镜像频对子空间CVS：设计与实现约定

目标保持为仅靠Phase1神经网络架构改善身份识别和接收条件变化下的稳定性。保持原单TX交叉熵、源物理划分、scratch初始化、四模型seed、E200和原优化器/FP32；不增加训练策略、增强、损失、目标适应或query反馈。本轮设计已完成固定预算实验；结果未支持识别性能改善，论文目标尚未完成。

## 依据与路线选择

已完成的谱时间关系源实验中，逐频分母相对同主干Shallow的固定源分数提升0.2343±0.1215个百分点、4/4个seed为正。全源V约29.4%的频点触及能量下限；公开有限窗FIR的delay16仍有较大变化。这些源证据支持保留频域相对关系的方向，也要求严格限定理论域。本设计不使用历史目标成绩、目标RX/TX分层或错误样本决定结构。

考虑了三种扩展：多尺度STFT减少某些有限窗边界影响，但同时改变时间/频率分辨率；局部时序协方差增加可表示的关系秩，但秩更高本身不保证保留更多身份信息；镜像频对联合建模则直接覆盖接收机IQ失衡引入的共轭混合。选择第三种作为本轮可检验机制。有限窗多径问题仍然保留，不将两者混为一个已解决问题。

## 物理模型与不变性

在包内近静态、理想逐频信道模型下，将发射信号的镜像频对写为两行时间序列：

\[
T_f=\begin{bmatrix}S_t(f,:)\\\overline{S_t(-f,:)}\end{bmatrix},\qquad
Y_f=M_fT_f,
\]

\[
M_f=\begin{bmatrix}aH_f&b\overline{H_{-f}}\\
\overline bH_f&\overline a\overline{H_{-f}}\end{bmatrix}.
\]

这里a、b描述接收机的频率无关widely-linear IQ混合，H描述信道。对于真实窗的STFT，时域y=ax+b conj(x)与镜像频对混合精确对应；有限长时域FIR不精确等同每帧相同的逐频乘法。频率选择性接收机滤波、CFO与非线性不自动满足该简化模型。

输入仍为B×2×256 IQ。沿用64点周期Hann窗、hop32、7帧、fftshift及窗L2归一化。只使用31个非自共轭镜像频对：fftshift索引(33,31)、…、(63,1)，按正频率1至31排列。DC与Nyquist不进入新分支，原主干的绝对路径完整保留。

对两行共同右乘同一个可学习A的转置，A∈C^(4×7)：Z_f=Y_f A^T∈C^(2×4)。第二行先共轭负频信号再应用A，不使用conj(A)；因此Z'_f=M_fZ_f。两候选的A、实卷积编码器、输出维数、参数量、初始化和接线完全相同。

未正则化的行空间投影为：

\[
P(Z)=Z^H(ZZ^H)^{-1}Z.
\]

当Z满行秩且M可逆时，P(MZ)=P(Z)。这是线性代数性质，不是本项目发明，也不意味着恢复了H、a、b或唯一发射机硬件。它可以同时消除某些TX线性IQ/频响差异，因此需要保留原RFF物理主干与绝对响应。

## 两个相同参数量的结构

固定E_f=||Z_f||²，F=max(mean_f(E_f)/64,1e-6)，d_f=max(E_f,F)，N_f=Z_f/sqrt(d_f)，alpha_f=E_f/d_f。两个候选为：

- `mirror_energy`：Q=N^H N，保留两行的相对能量与相关性；满能量时trace为1，仅对两行共同尺度及酉混合不变。
- `mirror_subspace`：令C=NN^H、D=max(det(C),0)，Q=(alpha/2) N^H adj(C) N / max(D,1e-3)。数学上使用2×2伴随矩阵公式；数值实现采用等价外积Gram与Cauchy–Binet行列式，避免秩亏区大数相减，不截断trace。无SVD/eigh或额外拟合。det下限在设计时固定，不扫描，也不依据真实样本或测试成绩设定。

后一种在能量floor与det floor均未触发时等于P/2；只对变换前后均满足这两个条件的可逆混合声称不变。弱能量或近秩亏频对被衰减。零输入的分母有界，所有算子与梯度须实测有限。两种Q均为Hermitian PSD、秩至多2；energy的trace和Frobenius范数至多1，subspace的trace至多1、Frobenius范数至多1/sqrt(2)，数值检验允许明确的FP32误差。秩一极限中subspace分支趋于零，不保留该单一方向，这是明确代价。

通道顺序为Q的4×4实部row-major，再接4×4虚部row-major。注意Q_ij=sum_r conj(N_ri)N_rj，不能沿用旧v_i conj(v_j)的虚部符号。Q形成B×32×31，编码器沿用Conv1d32→32(k3,pad1)、GELU、同形卷积、GELU、AdaptiveAvgPool(4)、无bias Linear128→160。最后投影零初始化，加到原b.f_proj(f)后再经过原频率统计和融合。新增参数预计26744，总参数247731；以实际实例计数为准。新随机初始化隔离，初始整网函数必须等于自己的scratch Shallow。

## 性质检查与反例

公开tensor验证：镜像索引/共轭和左右乘方向；与complex128直接逆/投影对照；Hermitian/PSD/秩/trace；满秩可逆2×2混合的资格域不变；energy控制在非酉混合下的反例；时域IQ混合到频对矩阵的精确关系；弱能量、秩亏和零输入有限梯度；全部新增参数仅由原CE更新；初始同函数、RNG和state往返；实际模块接线与checkpoint契约。

必须同时报告纳入/排除频对数量、完整域差异和资格域差异。不为使性质测试通过而忽略弱频点或秩亏反例。公开FIR与非线性干预为固定前向诊断，不是训练增强，也不用于候选选模。对有限窗多径、整网或任意接收机不作不变性保证。

## 实验与交付

本地数学/梯度检查通过后，按原流程登记两个候选各四seed的独立scratch训练；源控制为Shallow、Anchor与已完成的逐频谱关系源赢家，仅复用元数据，不继承权重。完整20源记录按原性能优先分数冻结。只有选中新候选时才生成其4份clean预测，结合已有48份冻结预测形成52行、416条ALL/RX评分；若保留旧控制，仅核验其已冻结测试，不测试未选新候选。所有测试结果不得回流本轮或下一轮的设计、排序、调参或选择性重跑。

源日志记录整个新分支和各组件梯度、输出、能量floor、det floor、trace及Frobenius范数；完整V逐样本标量与90个TX/RX/day单元保留，独立复算。新增方法与旧方法源码、checkpoint、输出隔离。发布前完成唯一独立P0/P1审查、Git交付和远端路径/容量读回；不干预其他健康任务。

## 相关工作与声明边界

[ChaRRNets（Brown等，2021）](https://arxiv.org/abs/2105.03568)已经提出基于传播变换群的频域等变/不变RF网络；本项目不能声称首次引入信道不变思想。[Kiayani等（2012）](https://doi.org/10.1155/2012/730537)系统研究TX/RX IQ失衡、信道和CFO，镜像频率耦合具有既有物理模型。本轮将这些作用组织为可微镜像频对子空间分支，并与保留绝对信息的RFF主干结合，是本轮已实验检验的结构方案，结果见下文。子空间投影、二阶池化和矩阵归一化本身都不能单独算新颖性；检索尚不足以确认该组合的首创性。

发布前验证：108项本地检查、8模型公开CE/物理检查及唯一独立P0/P1审查通过。8个正式训练已发布，源release为bb0ffae4263419a992a44de8975ec7eb83c4596f；实际进程及配置核验通过。条件clean工具也已实现并独立审查通过，现已完成8×E200并按源规则保留原控制，条件clean未激活；原控制测试证据已复核。

## 固定实验结果

8份从零训练的固定E200模型、80000步日志与720个全V关系分支单元已核验。mirror_energy源分数97.0981%，相对Shallow为-0.0236±0.0801个百分点，2/4个seed正提升。mirror_subspace源分数97.1171%，相对Shallow为-0.0046±0.1423个百分点，3/4个seed正提升。固定源规则保留relation_frequency_energy；四seed配对SD描述固定划分下模型随机性，不是置信区间。

只复核所选控制已有clean证据；未激活新候选测试，不能宣称镜像子空间关系已提高独立泛化。[完整报告](../automation_reports/CV-SincNet/20261003-phase1-cvs-mirror-subspace-identity-manysig-m8-r01/report.md)。

相对当前源赢家`relation_frequency_energy`，两种镜像候选的源分数在四seed中均下降；子空间平均差为−0.2389个百分点。公开理想可逆混合性质成立，但源识别收益及有限窗多径鲁棒性未建立。完整解释见[源机制分析](../automation_reports/CV-SincNet/20261003-phase1-cvs-mirror-subspace-identity-manysig-m8-r01/source_analysis.md)。
