# Practical LEO剩余执行优化

范围：合成IQ、随机初始化真实CVS模型、独立目录的有界服务器基准；不读取目标truth、不加载历史checkpoint、不启动正式训练、不修改活动任务。

本轮逐项：物理常量缓存、相位递推C实现、不可变full配置复用、训练轻量元数据、residual恒等滤波短路、clean验证特征复用、CPU生成/GPU消费有界重叠。

前五项由`practical_execution_fast`接入，默认关闭。完整物理Config和随机数派生不变；每个训练epoch/角色/场景的首次日志及固定评估仍保留完整元数据。clean验证由`source_validation_reuse`接入，保留原第二遍DataLoader遍历，逐批核对输入，模型参数/缓冲变化或超出128MiB缓存预算时回退。固定评估通过`--practical-prefetch`接入一任务预取，异常时显式关闭生产线程。

训练跨batch预取尚未启用：普通增强与模型随机操作共用全局RNG，直接前移增强会改变样本。固定评估预取的收益不得写成训练预取收益，也不得把局部信道收益写成整epoch收益。

本地验证：四配置×六环境逐项/组合精确IQ及终态；完整元数据或轻量保留字段一致；8192点递推和末状态一致；真实CVS clean验证指标、模型状态、DataLoader RNG一致；预测器及异常清理回归。88项测试通过。

独立审查的两项P2已修正：真实外层模型类型支持；消费者异常关闭预取生成器。

服务器结果：待独立读回基准产物后补充，当前不声称加速比例。
