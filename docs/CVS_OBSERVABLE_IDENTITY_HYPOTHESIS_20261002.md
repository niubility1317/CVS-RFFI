# CVS 整体物理观测身份网络：前瞻假设

2026-10-02。由已核实的信号链、相位变换规律和固定源域统计提出；任何历史或后续目标评分均不是结构、候选、窗口、预算或选择规则的输入。身份骨干、普通 CE、无增强、同物理划分、clean-only 与性能优先继续有效。

## 物理观测与信息保留

直接在 received IQ 上构造固定前端，全部身份路径都使用其输出，不保留原始 IQ 绕行。功率 `p=|x|²`，幅度响应观测 `A=log(1+p)`；延迟 d∈{1,2,5,20} 分别对应40/80/200/800ns。

`u_d(t)=x(t)conj(x(t-d))/sqrt((p(t)+eps)(p(t-d)+eps))`，`c_d(t)=u_d(t)conj(u_d(t-d))`，`eps=1e-6`。缺失历史补零；差分幅度的缺失位置置零，前端不访问未来、不环绕窗口。

- `observable_phase`：A、四个ΔA、四组u的实虚部、四组c的实虚部，共21通道。
- `observable_affine`：保留A、ΔA、c，共13通道；消除给定输入序列上`exp(j(θ+ωt))`的仿射相位。移除u同时可能移除有用的相对频偏信息，因此只由固定源规则比较。

两个候选及整个分类网络均严格常相位不变。对于全程非零、相邻样本相位连通的序列，A与u1包含幅度和相邻相位关系，可恢复原波形至一个常相位；正则化改变u模长但不改变其非零相位。零值及断开的相位段需要单独限定，不能据此声称任意输入无损。

对纯AM/PM模型`x=s exp(jβ|s|²)`，u相位增量变化为`β(p_t-p_{t-d})`，c的变化为`β(p_t-2p_{t-d}+p_{t-2d})`。因此能够检验幅度相关相位响应如何进入表征。AM/AM通过A与ΔA体现，但它们仍是接收观测，不是已估计的发射机增益曲线。IQ镜像及多径会改变这些量，不能声称已被消除或归属TX。

## 源域依据与结构

[全量源诊断](../automation_reports/CV-SincNet/20261002-diagnostic-rff-preamble-source-manysig-m1-r01/report.md)覆盖L6300/V27000全部样本、180个TX/RX/day/角色分层；两角色lags1..32的相关性峰值均为20点。V的窗口0:80、80:160、160:240相关性均值分别为0.757812、0.943506、0.328100。这支持固定80:160重复窗口，但不证明标准前导码逐包精确对齐或TX硬件来源。

三条路径：

1. 完整256点物理观测→48通道时间卷积与两个残差块→均值/标准差汇聚→160维。
2. 80:160固定4×20网格→32/48通道二维卷积→跨周期汇聚，保留20点内位置，压缩为10个位置→160维。
3. 物理观测的实FFT功率→32/48通道卷积→均值/标准差汇聚→160维。其频谱表示幅度/相位观测随时间的变化，不是原始RF带外谱。

分支采用逐包GroupNorm和LayerNorm，无BatchNorm、dropout、跨包统计或域标签输入。以时间表征为基底，重复与频谱分支通过逐通道tanh有界增益相加，初始增益0.25；普通可学习余弦分类器固定scale30、6类、无标签相关margin。两个候选建立相同21通道完整随机初始化后，affine保留对应13列；共同列与后续权重按配对seed一致。

这是完整身份结构的修改，不能把识别差异只归因于某一个不变性或某一硬件机制，也不能把分类权重当作TX参数。物理前端因果；后续整包卷积/归一化/FFT/汇聚不保证在线因果推理。严格常相位/仿射相位性质限定于给定IQ上的乘性变换，不等价RXIQ链中的频偏校正、SFO、多径或任意接收机不变。

## 固定验证与预算

聚焦检查包括：整个网络常相位不变；affine整个网络仿射相位不变；phase确实保留相对频偏；手工AM/AM/AM/PM解析响应；u/c有界和零历史；前端因果；逐包独立；零/弱信号有限梯度；所有分支收到CE梯度；共同初始化；多径/RX镜像反例；Conv1d/Conv2d资源计数。

合成物理检查与训练分离，不构成增强。两个候选×四modelseed（2026092701..04），scratch、E200×50、batch128、AdamW2e-4、wd1e-4、cosine至1e-6、FP32/no clip，sourceL/V和split392005保持固定，U不使用；无继承、teacher、EMA、域骨干或额外损失。源V仅评估，不更新模型或持久归一化状态。最终源诊断报告TX/RX/day准确率和按TX/RX聚合的嵌入分散；聚合仅为报告，不参与训练或改变选择规则。

四seed最终源V与最差源RX等权得分最高优先；性能完全并列后才比较V、最差RX与成本。独立审查后按该规则冻结一个候选，默认仅该4行预测clean，与既有20个固定控制预测合并24行独立truth-last评分，全部seed/RX/TX和负结果保留。未选候选不因最终测试结果被补测，评分不回流研发。

参数轻量是软约束，资源报告包括实测延时与峰值、常驻状态、Conv1d/Conv2d及矩阵乘MAC；FFT、归一化和逐元素物理计算不计入该MAC口径，但包含于实测耗时与内存。最终是否达到目标由物理证据和冻结测试性能共同判断，不能用理论性质、源分数或较少参数替代独立测试提升。
