# D92 独立验收数据可用性核查

日期：2026-09-29。方法固定为 `D92-BranchRidge-v1`，不依据新数据改变表示、ridge 系数、类先验或模型选择。本核查只读数据清单、配置、capsule manifest 和 NPZ `ids` 成员；没有读取 IQ、truth、预测、查询评分、方法结果或适应状态，没有构建数据或启动实验。

## 结论与边界

**现有证据没有证明存在可立即用于完整独立验收的数据集。** 在现有 ManyTx 的 19 RX 清单内，排除 5 个 Phase1 源 RX 和本轮已暴露的 11 个目标 RX 后，仅剩 3 个候选 RX；其中 2 个缺少所需 TX，另 1 个最少只有 14 条物理记录，不能完成包含 K=20、6 旧类加 20 新类的原矩阵。

最近两个 cohort 的 4 个 RX，最少剩余物理记录也不足 K=20。最初 7 个目标 RX 的总库存没有现成逐类记录，**其未用余量为 UNKNOWN**，不能宣称没有，也不能宣称足够。其它数据文件的 TX 覆盖及跨文件物理重复关系未核实；文件名称不同不能证明独立。

新 RX 确认与同 RX 新物理样本确认是两种不同结论。若后者最终满足排除与数量条件，只能声明已知目标 RX 上未用样本的确认，不能写成新 RX 泛化。不得为了凑足数据降低当前 K、删除困难 TX、跨 RX 拼接类，或将同一物理记录的新信道 seed／新裁剪称为独立采集。

## 新数据的最小契约

1. **身份与来源**：记录真实 TX、RX、原始采集文件／数据版本、日期／session、包或观测编号、片段坐标以及跨文件去重映射。26 个 TX 必须对应冻结 registry 中同一组物理发射机；6 个旧 TX 必须与 Phase1 身份一致。无法确认身份映射时，不能用相同字符串替代证据。若真实硬件不可再采集，是否存在合规新记录本身为未知。
2. **独立性**：新 RX 必须同时不属于 Phase1 源 RX、不属于全部已暴露 RX；新 physical ID 必须与上述 56,160 个 ID 不交，并核对其它已用数据来源的同包／重裁剪／复制关系。同 RX 路线仍必须满足物理记录未作任何 support、query 或方法选型证据。对缺少完整暴露台账的部分明确保留 UNKNOWN。
3. **信号与处理状态**：实际复数 IQ 的 I/Q 约定、采样率、中心频率、采集增益、同步／频偏／均衡状态与 session 信息必须可解释；当前冻结入口接收 `float32 [N,2,256]`、25 MHz 的同义处理输入。原始记录到 256 点的选取规则和归一化须事先固定，不根据查询表现修订；不把改变处理流程伪装为原数据直接兼容。
4. **一次性数据构建**：为每个物理观测固定唯一 received IQ 与 LEO 场景／实现；3 个场景使用互不相交的物理记录，support 与 query 物理隔离。runtime capsule 只给 received IQ、opaque ID、注册类表、支持标签与 split 元数据；query truth 留给独立 scorer。新的采集／ID／received 输入按 `p2_min_v1` 完成一次 builder 验证后保存 `VALIDATED_ONCE/capsule_id/split_id`，不重复验证旧 capsule。
5. **固定方法和验收**：冻结四个原 Phase1 checkpoint、BranchRidge 配置和 D92 基线；各模型共享同一新 capsule。新数据上先完成全部预测，再独立连接 truth。保留每 K／新类数的新类、旧类及综合 H；不得读取新结果后选择方法、删 cell 或重跑来作为同一次独立确认。

## 数量口径

若保留当前 rx1 的 3 场景、K={1,5,10,20}、新类数={0,2,5,10,20}、5 个 support seed 和每类 30 条 query，**每个新 RX 的每个 TX 至少需要 180 条独立物理记录**：3×(30 条 support pool+30 条 query)，即 26×180=**4,680 条／RX**，300 splits／模型／RX。若严格沿用 rx3 的 36 条 support pool，则需 **198 条／TX／RX，即 5,148 条／RX**。保留 3 个新 RX 则分别需要 14,040 或 15,444 条，且逐 RX/TX 均满足阈值，不能只满足总数。

这些是维持既有矩阵的库存下限，不是统计功效保证。四个模型和五个 support seed 复用同一物理数据，不乘以四或五计算采集量，也不视作新增独立 query。若坚持与 rx3 完全相同的池大小，则采用 198，不能在执行时静默降到 180。仅从代数可拟合角度的更低数量不作为本次验收建议，也未获授权用于替代完整矩阵。
