# 单输入盲信道估计与条件信号先验原型

将仿真短窗前向过程近似为 64 抽头固定复数滤波器。轻量卷积网络只读当前接收 IQ，预测有效复数信道核和每个实分量噪声方差；使用源训练模拟信道参数作为训练监督。实际推理不需要 DURA、仿真信道或干净波形。网络预测的信道和噪声输入已固定的共享／条件高斯源信号先验，计算 IQ 后验均值，再由冻结 Tri-SIG-TIME SSL 的原有分类头识别。

预设 8,192 条源训练物理记录（不含先验训练物理 ID），3 轮、批量 64、AdamW 学习率 0.0005，源训练缓存 11–13；最终第 3 轮固定，不通过留出集选轮次。另以 8,192 条不同源训练记录拟合信号先验（冻结基座高置信伪类别），在 RX8 第 3 天的六个受损场景各固定 64 条源记录、缓存 19 比较原输入、DURA、盲估计后验和仅供诊断的已知真实仿真信道后验。验证物理 ID 与训练和先验记录互不重叠，但可能在此前其他信道视图中被观察。训练阶段不加载分类基座或 DURA；分类基座和 DURA 只在训练后用于先验和比较。

报告逐场景波形误差、干净基座高置信伪标签一致数、盲估计核误差及噪声估计误差。干净基座伪标签不是真实标签，已知信道对照不可部署；不读 TX 标签、U_s 真值、V 或测试。该原型只做源域探索，不能代表 Phase1 测试或真实卫星链路。
