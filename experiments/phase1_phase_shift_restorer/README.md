# Phase1 输入时移—相位锚定的独立时频恢复网络

网络使用冻结的自适应相位因子和输入 IQ，先做固定 24 点时移与相位修正，再由从头初始化的时域空洞卷积和多尺度时频注意力预测波形。网络前向不调用 DURA；源训练中用冻结 DURA 和冻结 Tri-SIG-TIME SSL 作教师。训练和选模不读取 TX 标签、U_s 真值、V 或测试 IQ。

24 点时移根据 384 条源训练样本的探索性对齐观察确定。仅有时移及相位校正仍不足以恢复分类，必须检查完整网络。固定相位因子来自先前源域筛选后的第 3 轮，物理 ID 有重用，不能称独立盲测。

使用源训练缓存 11–15、源选模缓存 19；候选为第 1、3、5 轮，锚定输出与修复输出的比例 0.5、1，以及门控阈值 0.8、0.99。融合在相同时移与相位坐标下进行；关闭门控时保留原输入。RX4/6 day3 的源高置信基座伪标签和波形误差与 DURA 比较：每组识别损失不超过 0.5%，干净波形误差不超过 DURA+0.001、受损不超过 1.2 倍 DURA，且受损正确数合计净增至少 10；RX8 不参与选择。预设条件不满足则不产出新候选。此实验只做源域筛选，不自动读取测试集。

CPU 数值约束：N607 的 PyTorch 2.1 CPU 环境在启用 MKL-DNN 时出现过零损失梯度非零及梯度溢出。源训练入口在 CPU 上关闭 MKL-DNN，并记录其状态；GPU 配置不受这一设置影响。12 组合成梯度检查和 64 个真实源训练批次通过，但不保证所有输入均无数值异常。
