# Phase1 DURA source IQ-space gradient projection

- Candidate: the existing independently initialized DURA-anchored multiscale context architecture, frozen DURA and blind gate, trained afresh. The objective has the same value as the prior protected source waveform-plus-reader objective.
- For each source example, calculate output-IQ gradients for the waveform/relative-DURA protection loss and the frozen-reader feature/distillation/pseudo-margin loss. If their dot product is negative, remove the conflicting component of the latter against the former; otherwise leave it unchanged. A zero-value, detached first-order surrogate implements this samplewise output-space gradient. This does not guarantee nonconflicting model-parameter gradients, monotonic test improvement, or accuracy.
- Source-only low-urban exploratory diagnostics suggested small cosine values and some negative values between aligned IQ and clean-F pseudo-cross-entropy gradients; these are not identical to the full training objectives and are not causal proof. These explored source examples are not blind validation.
- Fixed 8192 allowed source IDs, views 21/22/23, five training epochs, paired clean source IQ, frozen Tri-SIG-TIME SSL guidance and source group balancing. F-guided; no direct TX identity, U_s truth, V, ground data, or ground feedback.
- Real-source smoke first, then freeze final checkpoint and 672 source predictions before source truth-last score. Weak source scores do not stop evaluation. Source replay followed by clean and six Phase1 Main views, 168000 records each, fixed before truth-last scoring and independent 119-group paired DURA audit.
- Source run: 20261103-phase1-dura-iqproject-source-s2026092701-r01. Ground run: 20261103-phase1-dura-iqproject-ground-test-s2026092701-r01. Explored simulated development data are not an independent blind or real satellite test.
