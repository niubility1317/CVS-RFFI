# 扩展训练的盲信道与条件信号先验网络

源域小样本原型在低城市仍落后 DURA；为检验信道估计是否随数据和训练预算改善，将盲估计器从头训练扩展至 38,951 条源训练物理记录，保留另 8,192 条不重叠的源记录拟合固定条件信号先验。每轮批量 64、学习率 0.0005、AdamW 权重衰减 0.001，源信道缓存 11 至 20，共 10 轮，直接固定最终轮，不依据留出结果选轮次。

使用与原型完全相同的 RX8 第 3 天六个受损场景各 64 条记录进行配对比较，含原始 IQ、DURA、盲估计条件后验及不可部署的已知仿真信道条件后验。记录此前已用于原型观察，此扩展受其结果启发，不是独立盲测；只能解释为探索性源域结果。训练使用仿真信道核和噪声监督，推理只读取当前接收 IQ 和源训练固定参数，不调用 DURA 或仿真参数。

地面基座固定为 Tri-SIG-TIME SSL。分类对照为干净基座高置信伪标签而非真实标签；不读取 TX 标签、U_s 真值、V 或 Phase1 测试数据。真实源数据基础检查、零梯度及有限非零梯度检查通过后才能启动。
