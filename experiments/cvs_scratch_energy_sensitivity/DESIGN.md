# 下一批：保留样本间幅度的浅中层损失敏感度

状态：已实现并通过本地检查，发布状态以同 run 的 experiment.json 为准。依据是本轮完整源侧优化器证据和 CE/margin 梯度恒等式；不依据目标得分选择校准策略或种子。仍保留 84% 三种子均值的目标。

## 固定对比

|方案|敏感度|幅度处理|训练安排|
|---|---|---|---|
|固定历史参考|margin|每样本 RMS 归一化|复用 identity9 的预登记主方案 DELAYCAP_JOINT 三种子，不重跑或挑选|
|MARGIN_ENERGY|原始 margin 梯度|每层固定一个源 L 标量，保留样本间相对幅度|随机学生 20 轮，三种子|
|CE_ENERGY（主方案）|真实单样本 CE 梯度|同上，保留置信度因子及其混合二阶导数|随机学生 20 轮，三种子|

新增固定 2×3=6 行。模型种子为 2026092701、2026092702、2026092703。MARGIN_ENERGY 与 CE_ENERGY 是主要同预算对照；与历史参考的比较同时包含“移除逐样本归一化”和新增一次固定尺度测量，资源差异必须报告。CE_ENERGY 不再逐样本归一化；不另跑理论上主要变号的 CE + 单样本归一化变体。

沿用历史主方案的配置，不从已看到的分数中重选：浅层 time_down、中层 t2.pool；444 次身份更新后固定校准；联合辅助梯度上限 0.2；均使用 clean 与四个原有凸插值 MixStyle 候选的整批最大 CE 选择及同掩码重放。这里复用的是 identity9 的候选机制，不从在训 POS/BIDIR 的目标成绩选择供体方向。

## 固定尺度是单位校准，不是逐样本归一化

设第 l 层每个样本的虚拟仿射敏感度是 g_il，坐标是已有逐通道 a/b。原实现把每个 g_il 单独变为近似固定长度，削弱了身份损失难度的幅度信息。本批改为：

`score_il = g_il / s_l`。

s_l 是该模型在第 444 次身份更新后、合法源 L 的固定 12 对 A/B 样本上测量的一个全层 RMS：对全部 1,440 次样本读取及该层所有坐标累积平方和，用 float64 聚合，再取平方根。要求有限且大于 0；不得将失败静默改成旧尺度或重新挑选样本。尺度从计算图分离，之后 3,996 次活动身份更新期间固定。不同样本和不同 RX 共用同一个 s_l，样本之间的相对幅度保留。

此操作避免原始坐标单位使四次齐次的方差内积极小、固定系数过早触及数值上限。它只改变每层常数尺度，不引入逐样本自归一化，也不引入训练中动态统计。若不考虑既有系数上限，该常数与后续梯度系数校准会相应抵消；核心改变仍是保留样本间幅度。

测完 s_l 后，再在同一固定 12 对样本上执行原有自身项梯度校准，得到每层 `min(10000, 0.2*mean_CE_gradient_norm/(mean_term_gradient_norm+epsilon))`。两遍之间身份参数、buffer、模式、随机流均保持；没有 optimizer 更新。每模型校准额外共 48 次前向、2,880 次 L 读取（历史参考为 24 次／1,440 次），不能写成同计算成本。

CE_ENERGY 必须从 `cross_entropy(logits, labels, reduction='none').sum()` 对虚拟坐标求导，保留 create_graph。不得使用分离的 `(1-p_y)` 乘 margin 梯度来近似，也不得把各样本 CE 先平均而引入额外 batch 缩放。MARGIN_ENERGY 使用已有平滑 margin。两方案保持相同 A/B 抽样、有限总体方差校正、有符号跨批内积、层均值分母 2、固定系数及 ramp。

## 训练、来源和最终测试

身份网络仍为原生旧门控与分类头，cos 指 cosine 学习率。每模型随机初始化，20 轮、每轮 222 步、共 4,440 次身份更新。AdamW 峰值 0.0002、终值 0.000001、weight decay 0.0001；L batch 128，label smoothing 0；warmup 444、ramp 888。没有新辅助可训练头。

U 使用原始纯 CE E20 的另外两个 seed 的固定概率均值，ALL soft KL；U TX 真值始终隐藏。教师完整训练契约及固定来源继续核验；学生不加载教师权重。无 EMA、星地增强和 U 风格混合。L6300、U56700、V27000 数据角色保持，V 仅按 E5/10/15/20 健康读出，不参与拟合或选模。

每行固定 final20 后自动对 168,000 个 clean query 预测并独立 truth-last 评分，六行共 1,008,000 个决策；六行共 26,640 次身份更新。所有种子与负结果保留，不从目标结果选择性重跑。每卡不超过 3 个总 GPU 进程，当前健康矩阵不修改。

固定尺度、固定损失系数、校准时点、原始 RMS、逐 RX/身份幅度、真实梯度、来源和额外成本均须存入 calibration/auxiliary state/日志；评估只用冻结身份模型。后续加载用于再训练或诊断时必须恢复这些尺度，不能用默认 1 代替。纯评估无需安装虚拟敏感度 hook。

## 必须验证的行为

1. 六分类 CE/softplus 与梯度恒等关系，包括置信度导数，已经有本轮合成证据；新实现另用有限差分检查浅中层虚拟坐标的一阶及身份参数混合二阶导数。
2. 固定尺度跨样本相同、无训练中更新；同一原始 g 上改变置信度幅度不会被单样本归一化抵消。尺度计算不改变身份参数或 RNG。
3. 两遍校准实际发生在完成第 444 次身份更新之后，下一个 L/U batch 之前；实际读出计数为 48／2,880，旧固定系数不继承。
4. 早期纯 CE 路径、真正的两个浅中层 hook、二阶梯度、零辅助头、每 4 次身份更新一次 A/B、全部 L/U 预算及完整训练日志均按实际执行验证。
5. 自身 checkpoint/尺度往返、缺失或错配尺度拒绝、U 真值拒绝、来源检查、唯一输出、容量限制与逐行自动 clean 测试全部覆盖。

以上是对损失统计内容的源侧探索。它仍是虚拟特征坐标上的 Fishr 类约束，不声称原论文的完整参数梯度 Fishr，也不把 84% 当成已被机制推导保证的结果。


## 实现映射

- `design.py`：两目标 × 三种子，固定主方案 CE_ENERGY；原 identity9 DELAYCAP_JOINT 为全部同种子外部对照。
- `multilevel.py`：原生 time_down、t2.pool 虚拟坐标，真实 CE/margin 导数与固定层尺度；原 A/B 方差估计不变。
- `calibration.py`：第 444 次更新后两遍相同 12 对 L，48 次前向／2880 L，冻结尺度及系数。
- `model.py`、`source.py`、`evaluate.py`：状态显式保存、加载校验及 checkpoint 与校准报告一致性。
- `style.py`、`objective.py`、`joint_cap.py`：原困难 MixStyle、U KL、分组联合限幅；不增加头、EMA、星地增强。
- `checks_energy.py`：两目标一阶／混合二阶数值导数、校准计数与同批次、状态／随机性保存、无效继承拒绝、反向传播。
- `checks.py`：原生网络 CUDA 集成，纯 CE 预热与活动目标前向预算。
- `analyze_source.py`：逐步审计两目标、固定尺度、原始 RX×TX 幅度、分量／限幅／资源；完整源日志不采样。
- `dispatch.py`、`evaluate.py`：每卡最多 3 个总进程，逐行固定 final20 后 clean168000，prediction 固定后独立评分。

合成检查只验证实现，不代表真实识别提升。固定源尺度不同于逐样本 RMS，也不等同于标准参数梯度 Fishr。
