# Phase1 DURA source worst-two-view training

- Candidate: independently initialized DURA-anchored multiscale context network. Train using three separately simulated channel views of each source physical record, and average the two largest source losses for each record before balancing source receiver groups. The per-view loss is aligned paired source IQ, power, frozen Tri-SIG-TIME SSL feature/distillation/pseudo-margin guidance, and soft DURA-relative paired-IQ protection. It does not select views by true identity or by ground results. Single-view inference does not use another observation or a clean reference.
- Training: same 8192 allowed source IDs, view epochs 21/22/23, five passes, fixed original DURA and blind gate. The paired batch contains 8 source records times three views; the resulting optimizer update count differs from the unpaired context baseline, so any comparison is not a single-factor ablation. F-guided; no TX identity, U_s truth, V, test data or test feedback.
- Source training observations and pseudo-target diagnostics have been explored; multiple views are simulated and worst losses may concentrate on pathological noise or noisy pseudo-targets. This is a testable hypothesis, not a promised benefit.
- After a real-source smoke, fix the final source checkpoint and all 672 source predictions before source truth-last scoring. Source results do not stop the ground evaluation. Replay source, then complete all seven Phase1 Main views, 168000 records each, before truth-last score and independent 119-group matched-DURA audit.
