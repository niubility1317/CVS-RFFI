# Research prototype — not launch ready

This package is an exploratory implementation, not a registered experiment or
an established method. The user's subsequent historical audit identified
closely related negative or mixed results. Do not train, launch, or claim a
performance improvement from this prototype without a new source-grounded
candidate decision, integrated validation, and the project's minimum experiment
workflow. In particular, equal branch weighting, low-confidence coverage,
single-receiver behavior, and U gradient protection require scientific review.

The training scope is incomplete: no complete run configuration, source
trainer, prediction/scoring pipeline, or launch registration is provided.
The tests exercise small synthetic inputs. One random-input CPU forward through
the real architecture only established that branch features can be captured;
it is not a real-checkpoint smoke or experimental result.
