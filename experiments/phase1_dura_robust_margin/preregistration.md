# DURA source reader-stability training

Candidate: the same zero-initialized DURA-anchored context architecture and phase-equivariant IQ correction as the ordinary context model. Its additional source-only loss tests whether the restored waveform remains stable to a first-order adversarial IQ displacement relative to the clean source waveform's frozen Tri-SIG-TIME SSL pseudo class. For each output, calculate the pseudo-cross-entropy gradient in IQ space, normalize it to 1% RMS of the output, detach it and classify the displaced IQ with frozen F. Add 0.1 times confidence-weighted, receiver-balanced pseudo cross entropy to the existing aligned-IQ, frozen-reader and soft DURA-relative protection objective. There is no direct TX identity supervision.

The perturbation is a mathematical local sensitivity probe, not a calibrated satellite-channel sample. It may create off-manifold inputs, exploit F or reduce waveform quality; epsilon and weight are fixed before evaluation and there is no guarantee of real-world robustness. Training uses the same 8192 source fit IDs, epochs 21/22/23, five passes, seed, original DURA, blind noise and gate as ordinary context. F, DURA and all signal gates are frozen; no TX identities, U_s truth, V, ground data or ground feedback enter G. Inference uses one received IQ, the frozen DURA output and blind noise estimate; no perturbation generation, clean reference or identity is needed at inference.

First run a 64-ID real-source training smoke, then freeze the checkpoint and all 672 source predictions before legitimate source scoring. Source results do not stop the registered clean plus six-view Phase1 ground predictions, 168000 physical records each. Verify all predictions before truth-last scoring and independent 119-group audit. CPU two threads with established load limit; preserve other experiments.
