# DURA iterative source feature-geometry experiment

Independently initialize and train the same three-step DURA-anchored time/frequency network used by the matched DURA iterative baseline on the same ordered 8,192 source records, three source views, seed, optimizer and five epochs. Retain its original paired-source, frozen-reader and DURA-relative waveform losses. Add a 0.05-weight relational KL: compare the frozen reader's restored-to-clean feature similarity distribution with the corresponding clean-to-clean similarity distribution across the current source mini-batch, using cosine similarities, temperature 0.05, and equal receiver-group weighting. The complete clean-reference geometry is detached. No transmitter identities or hand-coded class labels enter this objective. Same-batch clean features can be similar, so no source record is forced to be a negative by identity.

The reader, DURA, blind estimator and input gate remain frozen. Training reads paired Phase1 source IQ and frozen reader features, not TX identities, U_s truth, V or ground data. Inference uses a single received IQ and fixed components with no clean reference, extra records or target feedback. Fixed source predictions precede legal L_s scoring and independent source audit; all seven ground predictions are fixed before truth-last scoring and independent audit. Separate optimization trajectories mean this compares full training recipes. Source and simulated ground development records are previously explored; results are neither a blind test nor an in-orbit measurement.
