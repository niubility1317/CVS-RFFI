# 任务指导的可微盲信道后验原型

以固定的盲信道估计器和源训练条件 IQ 先验为起点，把盲信道矩阵、条件高斯后验、冻结 Tri-SIG-TIME SSL 串成可微链路。仅更新信道估计器；训练损失包含配对干净 IQ、冻结基座特征和软预测，以及源仿真信道核／噪声约束。推理仅需当前接收 IQ、固定先验和网络参数，不使用 DURA、真实信道或干净信号。

预设最多使用 4,096 条源训练物理记录、批量 8、一次遍历，学习率 0.00002，缓存 20。源先验拟合 ID 与本次训练 ID 不重叠；固定更新预算和最终权重后，在 RX8 第 3 天六个受损场景各 64 条已用于此前原型的源记录上对比原输入、冻结 DURA、原盲后验和本模型。DURA 只在训练结束后加载作为对照，基座全程冻结。

这是源域可行性原型：不读取 TX 标签、U_s 真值、V 或测试 IQ，分类目标是干净基座高置信伪标签，不是真值；已有权重和留出记录此前已被使用，因此不属于独立盲测。真实信道参数只用于源训练物理约束，不进入推理。
