# Phase1 标签无关信号库的频谱残差门控源域试验

仅以 Phase1 源 L_s/U_s 的地面干净 IQ 构建 8192 条物理 ID 互异的信号库；每个输入检索 16 条不同源记录，依输入拟合复增益并加权形成公共波形参考。频谱网络依据输入及参考的复数差异预测逐频率复数修正，初始化为输入恒等；它直接输出 IQ，不在推理时调用 DURA。既有相位因子在更早的源域实验中曾以冻结 DURA 为教师，输入保护门控也固定。信号库存在混入其他发射机指纹的风险，因此必须检查分类及 IQ 两项指标。

预设仅训练 2048 条源训练物理记录，保留同一训练池中另 256 条未参与训练和库构建的物理记录观察，训练缓存 11、观察缓存 14；每批 32、64 次更新、种子 2026112454/2026112455。训练目标为冻结 Tri-SIG-TIME SSL 干净特征及软预测、配对干净 IQ 波形。训练结束后才加载冻结 DURA 作源域对照，不使用 TX 标签、U_s 真值、V 或测试 IQ。已用 32 条真实源记录检查零梯度、有限且非零的学习梯度。

固定比较原始输入、DURA、相位锚点、信号库参考的 0.05 / 0.25 标量融合及频谱门控，报告高置信干净基座伪标签一致数和配对波形误差；干净场景未纳入此次短试验。这是探索性试验，不自动保存检查点、不进行模型选取或目标集预测，源物理记录此前已有其他信道视图被观察，不是盲测。
