# Joint blind channel and signal diagnostic

Starting from frozen blind channel and conditional Gaussian source prior, estimate source IQ then solve a regularized complex 64-tap channel update anchored to the input-only initial channel. Repeat three times for three fixed regularizations. This is alternating plug-in MAP, not exact expectation maximization: posterior covariance in the channel update is omitted. The inference uses only received IQ and frozen source models; no known simulation channel, DURA, or identity labels. Ground F pseudo labels and DURA provide source-only comparison. Source simulated channel metadata is read only after predictions and estimated channel arrays have been fixed and hashed; it describes an effective midpoint operator, not a deployment input. Small observed source samples do not constitute independent test accuracy.

The optional uncertainty-aware follow-up computes the full conditional Gaussian-mixture posterior covariance, including between-component variation, and includes its expected design Gram matrix in each regularized channel update. It is exact only under the fixed Gaussian/linear/noise assumptions; channel anchoring is an explicit regularization and real channels may violate the model.
