# DURA edge-preserving complex spectral fusion

Extend the existing edge-protected, DURA-anchored spectral-expert fusion from one real-valued gate to two bounded per-time coefficients: the real gate applies the aligned expert-minus-DURA residual and the imaginary gate applies its 90-degree complex rotation. Each component is bounded by 0.5, so the combined complex magnitude can reach 0.707; unlike the previous real gate, the imaginary component may alter phase. Missing aligned expert boundary samples are filled using the same DURA waveform, so their residual and correction are exactly zero. Zero initialization returns DURA exactly. With the imaginary coefficients zero, the new gate can reproduce the real-gate model. The expert and DURA are frozen.

Use the existing 8192 source fit records, source views 21/22/23, five passes, seed, frozen Tri-SIG-TIME SSL and the same protected paired-source IQ objective as the real-gate edge-protected model. Model output is single-window continuous IQ; the training uses no TX identities, U_s truth, V, target IQ or feedback. Inference uses current received IQ, frozen DURA and spectral expert and blind noise estimate, never identity, source clean IQ or another target example. Complex rotations may amplify noise or misalign identity features; no improvement is assumed. The six-scene ground results that motivated exploring this model are previously observed development evidence, not independent validation.

Run 64-record real-source smoke, then fix all 672 source predictions before source L_s scoring. Do not stop the registered ground test based on source score. Fix seven Phase1 ground views of 168000 records before truth-last scoring and independent 119-group audit. Use two CPU threads and existing load limit, without interfering with running experiments. Source and ground data have been repeatedly explored and channels are simulated; results are not blind or real-satellite validation.
