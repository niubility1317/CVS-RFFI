# E20＋20：独立双批 Fishr 与浅中层监督 MixStyle

本轮按已完成的源诊断 `20261012-phase1-e20-moment-audit-manysig-m3-r01` 设计。该诊断发现固定小批配额下的 Fishr 平方估计含明显噪声偏差，弱 MixStyle 的局部特征位移有限。本轮不依据历史目标测试排名、错误或分层结果选择方法和权重。目标仍为固定方案的三个种子 clean 均值达到 84%，同时报告全部种子；不能保证本轮达成。

## 固定矩阵与预算

|CE|合法 L 的纯 CE，无 U、教师、辅助头及增强|
|SSL|L CE＋另外两个原 E20 固定教师的 U 软 KL|
|OLD_PAIR|SSL＋两独立 L 批的旧 Fishr 平方均值，浅中两层|
|F_SHALLOW|SSL＋浅层修正 A/B Fishr|
|F_MIDDLE|SSL＋中层修正 A/B Fishr|
|F_BOTH|SSL＋浅中两层修正 A/B Fishr|
|L_REPLAY|SSL＋额外同批 clean 主身份 CE，无风格 hook|
|STYLE_SHALLOW|SSL＋额外浅层 MixStyle 主身份 CE|
|STYLE_MIDDLE|SSL＋额外中层 MixStyle 主身份 CE|
|STYLE_BOTH|SSL＋额外浅中两层 MixStyle 主身份 CE|

每方案三种子 2026092701、2026092702、2026092703，共 33 行。每行继承同种子的原生纯 CE＋旧门控＋cos E20，再训练 20 轮，每轮 222 次主更新，L batch128，合计 4440 次、累计 40 轮。重置 AdamW；lr 0.0002 按 20 轮 cosine 降到 0.000001，weight_decay=0.0001，label_smoothing=0。前 444 次只有 L CE，之后用固定 888 次线性 ramp 引入其他损失。无 EMA、无星地训练增强，无额外最终层约束。

SSL 沿用源域独立教师诊断确定的完整软分布：每个学生排除自己的种子，使用另外两个原 E20 的概率均值，温度 1，对全部 U 的 KL 以整个 batch128 为分母，KL 权重及其既有设置由逐行 config 固定。教师不更新，不读取 U TX 真值；共享概率库每个原 E20 对 U56700 前向一次，总 170100 次样本模型读出。预测仅运行学生。CE 历史成本 40 模型轮；使用两个额外教师的学生为 80 模型轮，不把复用视为零历史成本。

## Fishr：先修正统计，再更新浅中层

作用点为 `time_down`、`t2.pool` 的实值时序特征均值。每层独立六类线性辅助头在完整合法 L6300 冻结特征上预热 200 次、B60，AdamW lr0.003、weight_decay0.0001；随后丢弃预热优化器。只有五个 Fishr 方案启用辅助头；样式单项没有无用头或辅助前向。

每四次活跃主更新执行一次 Fishr，合计 999 步。每步从同一 day 的每个 TX/RX 格分别抽两个不重复 L 样本，构成 A、B 各 B60。两批独立，允许跨批重复 PID；每批均含六个 TX 和五个源 RX。不能强制两批互斥，否则破坏独立估计假设。两条特征图保留梯度；辅助头 W/b 在 Fishr 计算中 detach。两批使用同一时刻的模型和辅助头，计算后统一 optimizer.step。

设每 RX 的六个类别均匀混合，格容量为 N_k，配额 m=2。每类样本方差 s_k² 使用 m−1 分母，类别样本均值的方差 Bhat 使用 K=6 分母：

`Vhat = Bhat + mean_k[(1 − (K−1)/(K m) − 1/(K N_k)) s_k²]`。

修正 Fishr 为 `mean((Vhat_A − mean_RX Vhat_A) * (Vhat_B − mean_RX Vhat_B))`。该值允许为负；不截断、不取绝对值、不按符号重采样。无偏指固定模型下相对有限 L 总体的条件期望，不等于低方差或保证泛化。旧对照用相同 A/B 和相同两次前向，计算两次原始 n 分母方差平方损失的平均值，以隔离估计器变化。

辅助 CE 使用 detach 后的 clean A/B 特征，仅训练两个头，权重 0.1×ramp，不给身份骨干增加深监督。Fishr 用初始头预热后独立抽取的 12 个 L 批对校准，三 day 均覆盖；以固定旧双批估计器的实际骨干梯度范数为分母，主身份 clean CE 的对应梯度范数为分子：`coef_l = min(10000, 0.2 * mean_norm_CE_l / (mean_norm_old_pair_l + eps))`。浅层参数参照 time_fuse，中层参照 t2；每层最终固定除以 2。0.2 是校准时、层均值前的参考比例，不是后续每步或每层实际更新比例。

校准不更新任何模型状态，额外 1440 个 L 样本模型读出；所有 Fishr 方案在同种子使用同一校准定义，包含未启用层的校准结果。训练中系数冻结，只有预设时间 ramp 改变；记录实际主 CE、每项及合并 Fishr 的骨干梯度，不根据当批梯度重新缩放。校准尺度可能随特征变化失配，这属于需要实测的局限。主图更新和辅助采样均保留独立随机流；Fishr 辅助统计关闭 dropout。

## MixStyle：主身份损失直接监督内部特征

保留原 clean L CE，活跃阶段每步额外对同一 L batch 做一次主身份前向；额外 CE 权重 1×ramp。L_REPLAY 使用相同额外 clean 前向和损失预算，不装风格 hook。三个样式方案分别在浅层、中层、两层装 hook；联合方案与两层样式相同。

每个 hook 用 p=0.5、Beta(0.1,0.1)、最大插值强度 1×ramp，仅匹配同真实 TX、同 day、不同 RX、不同真实 PID 的合法 L donor。均值和标准差 detach，混合是端点间凸插值，没有外推。L batch 跨采样轮次可能重复 PID，允许重复 occurrence，但不能把同 PID 当不同 donor。未匹配样本保持原样；未启用轮次保留完整额外 CE，这部分由 L_REPLAY 控制。

额外前向保留正常训练 dropout，但通过 fork_rng 不消耗主路径随机流。双层 hook 在真实网络中依次生效，不把缓存上的两次独立变换冒充端到端效果。记录层实际位移、可配对/改变比例、主身份 CE/准确率/margin、预测改变及各损失真实梯度。训练预测改变同时包含 dropout 差异，不宣称它是孤立风格因果效应。U 不进行风格配对、不读取 U 真值。

## 数据、评价与交付

数据角色保持 L6300/U56700/V27000 的同一物理划分，V 仅 eval/no_grad 健康记录，不选 epoch 或方案，不更新持久状态。输入沿用已验证的原 E20 完整来源链；新头、优化器及校准新建，不加载历史多解耦状态。旧打包缓存反序列化 L/V，但训练只有指定角色进入各路径。

所有 33 行均固定追加 final20，不按测试结果重排、选择或重跑。每行冻结后自动预测相同 168000 条 clean query，再由独立 scorer truth-last 评分并复算；33 行共 5544000 个预测。报告全部 seeds、均值/SD、配对差、RX/TX/day 分层、Macro-F1、资源。主方案 JOINT 的预登记成功条件是完整三种子均值 ≥84%；其余方案作为固定对照完整报告，不能事后拼接单种子最佳结果。

额外计算并不相同：每个 Fishr 行有 200 次头更新、6300 次缓存读出、1440 次校准读出、999×120 次辅助训练读出；每个 L_REPLAY/样式行额外 3996×128 次主模型读出。总共 146520 次主更新、660 个增量模型轮。八张 GPU 每卡最多三个总进程，保留其他任务，逐行自动测试。启动、预测和评分单 owner，独占 run/release/output；技术异常保留产物，不因性能低停止。

这是已暴露基准上的固定方案探索，不是全新盲测。完整数学和源统计证据见上一轮源诊断；真实效果必须由本轮完整冻结后测试证明。实际配置以登记中的逐行 `config` 为准。
