# v2：保护TX RFF的补偿优化

历史记录：v3按用户新要求增加默认关闭的可选传播均衡和直接残差路径；本文的“禁止均衡”不再是当前可选功能限制，参见V3_FULL_RESIDUAL.md。

用户要求：按验收建议优化；不使用可能抹去TX RFF的均衡。

## 已实现的默认行为

- 根据接收质量区分locked（≥15dB）、degraded（5–15dB）、unlocked（<5dB）。阈值是工程先验，不是实测捕获门限。
- 频偏/相位残差倍率clip(10^((20-SNR)/20),1,10)。失锁只保留粗几何Doppler补偿（500Hz标准差误差），不补偿新增本振CFO、不假装精细相位跟踪成功。
- RX IQ校准与AGC保持开启。RX校准是session级独立校准，不根据当前包SNR重新拟合；只修正本次注入的RX响应。
- 频偏校正相位连续累积，避免每块估计频率改变时直接重算f*t引入额外跳变。
- channel_equalization_applied=false、tx_impairment_correction_applied=false。禁止多径逆均衡、频谱白化、PA逆失真、TX IQ补偿；原receiver_processor参数非空时报错，禁止间接传入任意变换。
- 三次Lagrange传播时延改为49抽头Kaiser窗sinc，公共因果延迟24点保留并记录。该滤波器生成传播损伤，不是接收均衡器。不能把输出与输入按原样本序号直接比较，需考虑这24点数值延迟。

## 质量与连续性边界

默认质量是仿真波形相对新增噪声底的SNR，不是含原始地面噪声的真实总SNR估计。ChannelStream.process支持quality_snr_db显式传入外部接收质量。状态每块判定，没有迟滞、捕获概率、导频长度模型或真实PLL；持续跟踪状态仍是代理，不可据此直接评估真实链路可用率。

质量决策与AGC均依赖process块划分。连续流宜固定块长；相位/阴影/时延历史连续，但不宣称默认全链路任意分块完全等价。数组相邻样本仍不自动被当作物理连续捕获。

地面与星载共用算法，分别使用已有receiver配置；无设备证据时不硬编码某类接收机更优。既有地面IQ内的TX特征、原RX影响和上游同步/均衡不被逆推出去。实际包检测/定时恢复没有完整前导时不伪造已实现；多径均衡按用户要求明确禁用。

## 合成验收

原生ssr-gpu、NumPy2.2.6、Torch2.10.0+cu128，CPU。v2_r01通过16项；最终元数据修订对应v2_r02证据，均在acceptance_results目录。

- 半采样延迟在0–0.4fs频带的最大幅度偏差约0.000429dB，v1同一诊断约0.738dB。不覆盖近Nyquist与所有真实数据边界效应。
- 25/10/0dB质量得到locked/degraded/unlocked，残差倍率1/3.162/10。失锁关闭精细载波及相位跟踪。
- RFF保护控制输入含TX IQ镜像、PA非线性、TX CFO。在无传播失真、理想新增RX校准的控制条件下，计入24点延迟后，输出与输入最大差约6.05e-8。只证明该控制下不执行TX去失真，不保证任意信道均无损保留RFF。
- 噪声底/AGC、状态矩阵、功率、上下文、重排/拆batch、Torch适配等回归通过。连续流分块对照同时关闭块AGC和质量自适应。

未运行真实数据、分类训练、目标评估、GPU性能或完整长时统计验收。不能将工程阈值与补偿效果代理称为实际接收机性能。
