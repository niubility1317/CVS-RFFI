## 验收结论与未解决问题

结论是“基础数值行为通过，物理真实性及完整接收机验收未完成”，不能简称所有验收通过。

1. **分数时延近似偏差**：半采样三次Lagrange核，在0–0.4fs频带的最大幅度偏差约0.738dB。它是单个滤波核的诊断，不是整个信道或实际数据集的损失。尚需结合实际占用带宽确定容差，或改用有明确带宽/群时延的滤波器。此次未改算法。
2. **补偿误差与接收质量脱钩**：默认残余CFO、IQ估计误差及相位跟踪误差不依赖SNR、导频长度、遮挡、捕获状态；即使严重衰落仍相当于接收机保持锁定。适用于“已同步成功条件下”的代理，尚不适合无条件评估链路可用率。
3. **定时同步/多径均衡仅接口**：默认未运行真实同步器或信道估计器，不能通过设置名称宣称已开启。
4. **传播过程未全面统计验收**：未做长时间ACF/PSD、经验状态占比/驻留、多径边界效应、多采样率统计一致性和真实数据频谱检查。
5. **场景未实测标定**：当前工程先验和补偿残差不等于地面或星载实际硬件性能；未对地面/卫星配置逐一运行全部检查，也未运行CLI转换或CUDA路径。

## 建议的默认处理策略（待后续实现/标定）

- 保持已有频偏、RX IQ、相位跟踪和AGC默认开启；开启表示接收机尝试补偿，不表示残差为零或必然锁定。
- 补偿前传播状态与补偿后残差分别记录；绝对轨道频移与残余CFO不能重复叠加。
- 实际完整包有前导/导频时默认执行包检测、粗细定时、频偏估计和正则化信道均衡；在目前独立短IQ片段上不能假定这些观测存在。
- 原始输入已同步/已均衡时明确记录上游状态；只处理新增信道，避免无依据地重复均衡或声称去除了原RX损伤。
- 增加`locked/degraded/unlocked`状态或外部估计质量。残差由接收质量、导频与硬件模型决定；真实输入中不凭类别标签设定补偿强度。
- 拟使用均衡器时，避免默认无噪声正则的理想逆信道，防止深衰落噪声放大；不能把TX指纹作为待消除的RX误差。
- 地面与星载接收共用处理结构；硬件误差、噪声预算和算力限制在有依据后分别设置，不根据位置名称硬编码优劣。

本轮只验收和说明，上述新增锁定状态、SNR耦合、真实同步/均衡均未实现，不修改旧LEO/LEO_WEAK实验定义。
