## 四条路线的真实连接

**CF-EG。**原点F1/F0分别产生自己的完整EG预测点和校正场，再计算g0＋β(g1−g0)。F0只关闭编码器对抗；域头L/U监督不变。每个候选从同一原始AdamW参数和矩出发，独立全局裁剪、权衰减和更新；提交所选候选的完整状态。90条轮换源L按6TX×5RX×3day覆盖，硬约束聚合到TX×已激活场景的负概率margin。默认β集合{1,.5,0}、容忍.01；.02和每5/10步稀疏版单列。H只监测校准权重下伪类概率，P只监测候选集合质量，不将其作为真实标签或硬约束。记录β、实际增量、候选逐组损伤及H/P参照/候选读回。

**TR-EG。**先完成双方普通预测，取同一IQ、同一视图在两个位置的真实域头输入；不自行归一化。SO(d) Procrustes带det修正，ρ=.01×二阶矩平均尺度，R停止梯度。只将预测域头首层改为(1−γ)A＋γARᵀ，再计算完整第二场、恢复原点并正式更新。γ=.5，E21–60渐增；0/.25/1和不匹配样本旋转单列。监测L物理ID与拟合批次不重叠，记录拟合外旋转解释率和域CE恢复。坐标估计使用固定eval随机条件，训练两场仍是原生训练模式；这项估计没有修改永久编码器、教师或原型。

**XT-DANN。**每20接受步轮换互斥TX集合，两边都覆盖全部15个源RX/day域；使用额外90条合法L，不读U隐藏TX。一步内环LR等于当前域头LR；外层μ=.1，头的meta链保留二阶导。编码器对抗通过停止参数的临时域头保留输入梯度；两EG场共享划分、各自重算临时响应。日志包含双向fit变化和跨TX监测变化。μ0/.05/.2及相同额外L曝光的普通域头目标均已配置；等总计算预算需未来测量，不能以相同数据条数冒充相同计算。

**DRIC-Lite。**每4接受步构造局部任务参照，其余步为普通simultaneous。只对`t_proj/f_proj`身份末端和域对抗头增加位移修正。其他参数保留正常DANN更新，未冻结早期网络或删除其对抗。为使局部预算可解释，旧尾部、任务尾部及最终候选的风险全部在同一“其他参数已普通更新”的固定背景上测量；它不是全骨干任务反事实保证。

DRIC的B/C从显式带符号的训练模式L/U域目标分别求导，不对GRL求高阶导；局部重算采用公共固定随机状态。任务漂移、响应方向、任务方向及高风险TX梯度构成每边≤4维的基，最大8×8。采用当前LR定义的正等距预条件，Q是PSD投影梯度外积＋正定近端项与.1曲率阻尼；μ=1e-4，残差阈值1e-5。枚举小空间活动半空间，并对半径乘子最多执行5次Newton迭代；记录实际次数、谱阻尼、KKT残差、风险违约和线性化误差。残差失败回滚并抛出明确技术错误，不悄悄提交无约束解。

DRIC参数位移直接提交，绝不把u/v当成AdamW梯度。正式矩状态是唯一一次普通AdamW状态，任务分支状态只供虚拟参照、不混合或提交。E21–40将普通候选的实际位移渐增插值到完整局部候选；满强度时局部线性预算适用，过渡期实际风险单独记录，不能宣称每个过渡步满足完整候选预算。λE=0退化为相同任务/普通更新；零方向保留正常域头训练。

响应跟踪和CGD对照使用匹配的局部参数空间、原点独立B/C及普通AdamW位移作为预条件输入，不使用DRIC任务参照或身份预算；明确标记为局部对照，不宣称完成文献算法的全维逐项复现。另有RK2/Heun完整场参照。任务投影对照去掉双边耦合，使用任务梯度半空间；DRIC去漂移、去身份预算、打乱漂移、L-only-head对照分别登记。

## 验收覆盖及解释边界

- 原生53项回归：真实模型字段、U梯度权限、DAOT教师缓存、H/P分支、增强/卫星曝光、原点除数、状态回滚、配对、指标/评分接口。
- 新增测试：CF有历史AdamW矩和裁剪下β0/1精确等价、最大可行选择及异常回滚；已知旋转补偿和秩退化；XT二阶头/输入梯度及跨TX域覆盖；DRIC非对称解析导数、零头gap漂移反例、联合约束残差、真实模型主路径、零强度/极小强度/零对抗/空方向、非选中参数保持普通更新、漂移分解，以及相关局部对照真实连接。
- 配置逐行重新解析，核对resolved参数与原生DR有效开关；四种入口实际调用默认解析分支，并将train替换为抛错函数，证明解析阶段没有训练调用或输出目录创建。

本地验收证明可达路径、数学/状态语义和配置一致性，不证明训练收益、机制长期非零、数值求解在全部真实步上都成功，也不证明目标泛化或创新成立。需要的LEO均值、Macro-F1、RX/day/TX、最弱类/接收机、Rescue/Harm、配对seed均值±SD和差分中的差分，继续沿用独立prediction→truth评分链。

DRIC局部重放根据计算图判断哪些叶模块不依赖选中的尾部/域头参数，对固定背景下这些模块复用结果与随机状态；依赖局部参数的模块重新计算。外层原生前向控制流及函数式运算仍会执行，不能将骨干调用次数直接当作完整骨干FLOPs。日志同时保留骨干调用、局部叶模块重算/重放和导数调用统计；测试验证重放后的输出、选中参数梯度及随机状态一致。TR当前另计4次坐标估计/监测前向与SVD，未宣称零额外开销。全维文献CGD逐项复现不属于当前匹配局部对照，不能冒充已完成。等计算预算和目标性能结论都要等未来另行授权的实验。
