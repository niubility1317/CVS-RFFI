# 多信道视图的物理后验残差网络

固定盲信道估计器和条件先验，以其重建 IQ 与接收残差的反投影为输入，从头训练轻量残差校正网络。网络初始严格保持后验输出；训练目标联合配对干净 IQ、冻结 Tri-SIG-TIME SSL 特征及软预测，并仅对合法 L_s 训练记录使用真实类别监督。推理不依赖 DURA 或仿真信道真值。

固定不与 8,192 条先验拟合物理记录重叠的 38,951 条源训练物理记录，使用已核验与原始训练 ID 相同的源信道缓存 21、22、23，分别训练 3 轮；批量 16，AdamW 学习率 0.001。训练只读取 L_s 的地面标签，元数据读取全部 6,300 条用于 ID 绑定，只有本训练集合中的 L_s 标签进入损失；U_s 真值、V 和测试 IQ 不读取。

固定第 3 轮后，在先前已观察过的 RX8 第 3 天六个受损场景各 64 条源记录，与未修正盲后验和 DURA 比较；DURA 仅在训练结束后加载。分类口径为干净基座高置信伪标签，另报告归一化 IQ 误差。训练预算和学习率选择受前一原型与缩放诊断启发，属于探索，不是独立盲测；干净信号在正式推理需要盲保护门。
