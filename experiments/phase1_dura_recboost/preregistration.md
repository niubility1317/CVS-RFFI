# Phase1 wide DURA residual with recognition guidance

- Candidate: independently initialized DURA-anchored context architecture with four times the ordinary residual amplitude. It returns DURA exactly at initialization; each inference uses only the received IQ, frozen DURA, blind noise estimate and gate. DURA itself and Tri-SIG-TIME SSL remain frozen.
- Source-only exploratory comparison found some fixed candidates matched the clean-F pseudo target while their paired-source aligned IQ error was larger than DURA. This is a small, previously explored and non-causal observation, not ground evidence.
- Training uses aligned paired-source IQ, output power, frozen-reader feature/distillation/pseudo-margin loss, and an additional confidence-weighted cross entropy to the clean-F pseudo class (weight 0.2). It does not include the prior DURA-relative source error penalty. This intentionally permits larger changes and may harm waveform quality or exploit the frozen classifier. F-guided; no direct TX identity, U_s truth, V, ground data or ground feedback.
- Five epochs over fixed 8192 source IDs and view epochs 21/22/23. A 64-ID real source smoke precedes full training; freeze 672 source predictions before truth-last scoring. Regardless of source score, replay and complete seven Phase1 Main views of 168000 records before independent pre-truth checks, truth-last score and 119-group DURA audit.
- Source: 20261103-phase1-dura-recboost-source-s2026092701-r01. Ground: 20261103-phase1-dura-recboost-ground-test-s2026092701-r01. Reused source and ground data are explored simulations, not independent blind or real satellite testing.
