# Phase1 source-disagreement-focused DURA context experiment

- Candidate: independently initialized 163698-parameter phase-equivariant multiscale context correction anchored to frozen original DURA. Architecture and same source IDs, view epochs, initialization seed and five-epoch budget are identical to phase1_dura_context; only the source objective changes.
- Difficulty weighting: compare frozen reader on source clean features and frozen DURA output; when clean max probability is >= 0.95 and predicted classes disagree, weight the source example 8, otherwise 1. Labels are generated by frozen Tri-SIG-TIME SSL, not TX truth. Each receiver's loss is normalized by its weight sum and receiver losses are equally averaged. Base aligned IQ, power and frozen-reader feature, distribution and margin terms plus 5 times positive aligned IQ degradation vs frozen DURA remain; the same weight applies to all terms. The weight and clean reference exist only in source training.
- This is F-guided. Train solely with legal L_s/U_s source IQ pairs and public receiver groups; no direct TX identities, U_s truth, V, target data or feedback. Per-record deployment reads received IQ, frozen DURA and blind noise estimate; no clean reference, label, scenario or cross-sample statistics. The protection term is soft.
- Source: 20261103-phase1-dura-focus-source-s2026092701-r01. CPU two threads, actual-source 64-fit / 28-eval smoke first, then fixed 8192 source IDs x three approved views for five epochs, followed by 672 fixed source predictions before any authorized L_s score.
- Ground: 20261103-phase1-dura-focus-ground-test-s2026092701-r01. After source prediction freeze, replay source and predict Phase1 Main split clean plus six practical scenes with 168000 fixed IDs each, frozen Tri-SIG-TIME SSL; independent pre-truth verification and truth-last 119-group audit. Source score does not stop the ground test.
- Stop only for technical, numerical, data-contract, frozen-component or process failures. Preserve unrelated tasks and outputs. Ground results are explored development data, not independent blind or real satellite results.
- Artifacts: real-source smoke, source checkpoint and fixed predictions, authorized source score, source replay, seven fixed ground views, independent pre-truth audit, score and subgroup analysis. Immutable release and Git commit identify code.
