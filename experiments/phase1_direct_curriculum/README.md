# Phase1 direct IQ hard-example curriculum

An independent raw-IQ temporal and spectral attention restorer initialized from the fixed prior direct-source epoch 10 checkpoint. It does not depend on DURA. Frozen Tri-SIG-TIME SSL supplies source clean features, soft predictions and differentiable logits; its parameters are never updated. The original 6,300 permitted Phase1 L_s metadata records are loaded and validated against their source IQ; only L_s labels belonging to the 47,143 training IDs are retained and used. U_s true labels are never read. Confident (>=0.95) frozen clean teacher predictions provide pseudo labels for U_s. A training example receives threefold classification weight when the raw-IQ frozen teacher is wrong against its permitted target; otherwise it receives unit weight. The objective combines this supervised/pseudo-label classification term with soft-output distillation, feature matching and paired IQ/deviation regularizers.

All receiver 4/6/8 day3 records and 4096 fixed source sampled IDs are excluded from training. Four source epochs use cache views 16–19, batch 32, AdamW lr 0.0001. No V, target IQ, target labels or DURA are used during training. For source model selection, cached view 20 receiver 4/6 day3 compares frozen-teacher high-confidence clean pseudo target decisions and source IQ for epochs 1/2/4 and blend coefficients .25/.5/1. Every clean cell must preserve its correct count and IQ MSE <=0.001; impaired cells may lose at most one correct decision and have IQ MSE <=1.1 times raw plus 1e-6; aggregate impaired gain must be >=2, else raw is retained. Receiver8 day3 is recorded only as exploratory holdout; it has been inspected before and is not independent blind. L_s metadata for all source IDs are read as a file for provenance validation, but only training-ID L_s labels enter the objective; source selection uses pseudo labels only.

If selected, freeze the model and evaluate all seven Phase1 development views with Tri-SIG-TIME SSL, sealing all predictions before accessing test truth, then independently score and compare with same-record DURA. Development test has been observed repeatedly and uses simulated channels.
