# PA 身份证据跨 RX 重组：数学与真实模型原型

当前状态是已验证原型，尚未发布训练实验，也没有泛化性能结论。用户最新 c718649d 报告要求先验证等 U 时序，再主攻同身份证据重组。等 U 时序 R02 已保持原计划独立运行；本原型没有叠加时序、Sinc、关系蒸馏或新伪标签规则。

研究问题是：CVS 实际 PA 增量能否被训练成同一身份在不同接收条件下可重组的判别证据？特征插值已有 [Manifold Mixup（ICML 2019）](https://proceedings.mlr.press/v97/verma19a.html)；[MixStyle（ICLR 2021）](https://openreview.net/pdf?id=6xHJ37MVxxp)研究实例级特征统计混合。这里待检验的贡献在于 CVS 可分离 PA 增量、同身份跨 RX 配对和原默认头的学习信号，不能把混合特征本身当成新发明。

## 目标与梯度

从真实部署的 `joint160=a+b+c` 提取原 `id_feat_cls`、已乘 PA 增益的 `id_feat_pa`、已乘 reference 增益的实际投影输出。`features.actual_parts` 独立检查和实际部署向量一致。

对同 TX、同 day 的两个不同物理包，对称计算：

`z̃_i=a_i+b_i+c_i+α(b_j−b_i)`，

`z̃_j=a_j+b_j+c_j−α(b_j−b_i)`。

辅助损失为两个真实身份 CE 的平均，使用当前默认类别 W 的停止梯度副本，以及原 scale30/normalize eps1e−4；PA/ref 增益仅在辅助重组中停止梯度，内部 a/b/c 特征保留图。主 CE 正常联合训练原 W、增益和骨干，不替换、另训或重训分类头。原型 α=.2、辅助系数=.1 固定，仅表示初始待验证选择，不代表已经有效，也不依据 target 调整。

仅修改 PA 实际增量，a 与 c 保持各自原样；不是整个特征 MixUp，不随机删除证据，不复制教师响应。这是特征空间任务，不能解释为重新生成 TX→信道→RX 传播，也不假设不同采集包的底层波形相同。

## 等曝光对照

所有原型配对只允许合法 L_s，TX 标签0至5、RX1/3/4/6/8、day1/2/3。U、V、query 角色均被拒绝；数据契约仍须由实际训练入口保证，数学函数不替代数据权限检查。

每个 TX/day 内先保留至少两个不同物理包的 RX cell，至少存在两个这样的 RX cell 才参与。用私有 CPU 随机生成器从各合格 cell 选相同的最小包数，形成共同样本集合。SAME_RX 在 cell 内循环位移，CROSS_RX 在 RX cell 间循环位移；每个样本在两个条件中都恰作一次 anchor 和一次 donor。两向 CE 中每个端点出现两次，类别/day/RX 样本曝光完全匹配。重复物理包只选一个代表，丢弃数量不足和不平衡部分并记录 coverage，不为覆盖率放松身份或物理边界。

ZERO 同成本计算诊断，但辅助训练梯度精确为0；SAME_RX 与 CROSS_RX 分别使用匹配的同 RX、跨 RX donor。α=0 或 PA 增量相同，恢复共同样本集合的原默认 CE。无需额外取样、前向、库或辅助模型；实际接入同一已有 L batch 的方式仍待训练入口实现。

## 已验证与限制

- 数学 CPU FP64：α=0、相同 b、极小范数时默认 eps1e−4 等价；一对一共同端点曝光；同 TX/day/不同物理包边界；非法角色、标签、RX/day 及冲突物理元数据负例；私有 RNG；ZERO/空集合精确0，均通过。21包合成样本选13包共同集合，重复1、不平衡4、数量不足3；这不是实际 L 的覆盖率。
- 数学内部梯度：SAME 的 a/b/c norm=.280264/.251171/.280264，CROSS=.272203/.242125/.272203；W和辅助增益梯度None。ZERO内部梯度精确0。
- 实际 CVS CPU FP32：真实844754参数/191state、原默认6×160/scale30、实际joint160重构、α0恢复默认CE及U角色负例通过。辅助 SAME/CROSS 对真实t1/PA_b1/PA_proj/ref_projection均给出有限非零梯度，W/PA增益/ref增益辅助梯度None；主CE对这些头参数的梯度均非零。新增参数0，模型权重结构未改。
- 真实模型接线使用36个随机源形状包及合成标签，ref_gain=.1只用于局部梯度fixture；真实训练初始值和checkpoint未修改。源数据读取0、训练更新0、分类头拟合0、U truth/target访问0。原型不能证明真实 PA 具有跨 RX 可交换性或实际识别收益。

数学检查入口为 `python -m experiments.cvs_pa_recomposition.checks --compact`。原型接口返回 compact JSON 计数、CE/true-margin/probability/替换范数，以及仅供即时检查的配对与图张量；训练时不得跨步保留计算图。

下一步按相同默认头与预算，独立比较原训练、同 RX、跨 RX；先仅把本机制用于 L，保持原 U 训练方式。必须报告真实 L cohort 覆盖、分支梯度/参数更新、源健康、固定种子 clean 结果与负例，再判断可交换性。若跨 RX 明显损害身份而同 RX 没有，应接受反证；不增加 α 强行制造收益。原已接受 U+合法 L donor 的扩展、语义间隔、分支更新约束都尚未实施。
