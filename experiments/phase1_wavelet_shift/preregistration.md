# Phase1 independent wavelet with randomized grid origin

- Candidate: the independent four-level phase-equivariant wavelet IQ network, independently initialized and trained afresh. During each source training batch, uniformly sample a 0–15 point circular shift; run both received IQ and its raw initial signal on the shifted grid, then inverse-shift output before computing the same paired-source objective. The shift is shared only as augmentation within a training batch; no sample is mixed. In evaluation the model uses the fixed original window origin, without extra inference views. Zero output initialization returns the received input exactly.
- Motivation: in explored source IQ, a fixed trained wavelet network sometimes changes waveform and frozen-F predictions after shifting then unshifting its input. Circular boundaries are artificial; this is a structural diagnostic rather than evidence of a true-channel cause.
- Training: same 8192 allowed source IDs, epochs 21/22/23 and five epochs, paired source IQ, output power, frozen Tri-SIG-TIME SSL features, distillation and pseudo-margin. F-guided; no direct TX identity, U_s truth, V, target IQ or target feedback. A blind gate and blind noise estimate are frozen. Single-window inference.
- Real source smoke first; final checkpoint and 672 source predictions are fixed before source truth-last score. Weak source results do not cancel the fixed seven-view plan. Replay source predictions, then all seven Phase1 Main views of 168000 records, followed by independent pre-truth checks, truth-last scoring and 119-group DURA audit.
