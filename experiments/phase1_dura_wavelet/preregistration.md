# Phase1 DURA multiscale wavelet correction

- Candidate: independently initialized four-level IQ wavelet residual network operating on the current received IQ and frozen original DURA output. The same phase-equivariant architecture as the independently trained wavelet route is used with DURA as an anchor; zero initialization exactly returns DURA. Single-window inference only.
- Source-only pretest analysis of 48 low-urban signals per source RX group found DURA residual energy across Haar scales; the clean-reference alignment used in that analysis is diagnostic, never available at inference. These source examples are explored, and the analysis establishes no causal relation to identity accuracy.
- Training: the same 8192 allowed source IDs, epochs 21/22/23 and five epochs as the DURA context baseline; paired source IQ, frozen Tri-SIG-TIME SSL features, soft predictions, pseudo-margin and group-balanced relative-DURA source waveform protection. This is F-guided. No direct TX identity, U_s truth, V, test data or test feedback.
- Real-source smoke precedes full training. Freeze final model and 672 source predictions before source truth-last scoring; poor source metrics alone do not stop ground evaluation. Source replay precedes all seven Phase1 Main views of 168000 records each; independently verify fixed predictions and raw physical IDs, then truth-last score and 119-group DURA audit.
- Source run: 20261103-phase1-dura-wavelet-source-s2026092701-r01. Ground run: 20261103-phase1-dura-wavelet-ground-test-s2026092701-r01. Source and ground datasets are explored simulated development data, not a blind or real satellite test.
