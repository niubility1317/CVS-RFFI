# Phase1 DURA multiscale context experiment

- Candidate: independently initialized phase-equivariant nonlinear correction on frozen original Phase1 DURA. A multiscale convolutional encoder and decoder use within-sample global temporal attention; no cross-record attention or batch statistics. Zero-initialized output returns DURA. Inputs are one received IQ window, its frozen DURA output, and one blind noise estimate. This is a continuous waveform generator, not a class-conditioned router.
- Training: fixed identical 8192 source IDs, source epochs 21/22/23 and five epochs as source-protected memory. Frozen Tri-SIG-TIME SSL feature/distribution/margin and source IQ loss, power loss, and 5.0 times source-only group-balanced DURA-relative IQ degradation penalty. Permitted paired L_s/U_s IQ only; no TX identity, U_s truth, V, target data or target feedback. F-guided; penalty is a soft source training term, not a test-time guarantee.
- On N607, CPU two threads and existing load guard; source-only real checkpoint smoke is first: 64 source fit IDs, 28 source evaluation records, frozen components and nonzero feature gradients. A technical, numeric or protocol failure stops the run; weak source metrics alone do not stop it.
- Source run: 20261103-phase1-dura-context-source-s2026092701-r01. Ground run: 20261103-phase1-dura-context-ground-test-s2026092701-r01. Frozen source output and 672 source holdout predictions precede authorized source score.
- Source replay then Phase1 Main split, same 168000 IDs for clean and the six practical views, with frozen Tri-SIG-TIME SSL. Each input independent. Once all seven predictions are fixed, run independent pre-truth ID/raw matching, truth-last scoring and 119-group audit against DURA.
- Reused ground data are development evaluation, not an independent blind test or real satellite measurements. Model updates or selection cannot use ground truth. Preserve unrelated tasks and outputs.
- Expected artifacts: real-source smoke, frozen source checkpoint and 672 predictions, source score, source replay, seven fixed views, independent scoring and subgroup audit. Code commit and immutable release identify the run.
