# Phase1 same-window frozen-reader feedback to DURA recovery

- Candidate: a new continuous IQ residual generator around frozen DURA. It takes the current received IQ, DURA IQ, blind noise estimate, and 160-dimensional features plus six logits from the frozen Tri-SIG-TIME SSL applied to that same DURA output. The model uses the normalized feature vector and softmax distribution to condition temporal attention, rather than routing among classes or candidate outputs. Zero initialization returns DURA; residual amplitude is twice the ordinary context model's scale.
- The source trained model has an independently initialized correction and a separately loaded, frozen copy of the same F for conditioning. F is also frozen in the source objective and final classifier. One current input window is required; no clean reference, true identity, scene or other sample is used at inference. Full input phase equivariance is not claimed because the F condition itself can change under a phase rotation.
- Training: fixed 8192 source IDs and view epochs 21/22/23 for five epochs, aligned paired-source IQ, output power and frozen F feature/distillation/pseudo-margin guidance, without extra relative-DURA IQ penalty. F-guided; no direct TX identity, U_s truth, V, ground data or feedback. This can amplify mistaken F beliefs or overfit F; full ground evaluation is required.
- A source-only analysis of fixed output sets found common errors on some source L_s records. It does not prove this new conditional model can repair them. F and source records have been explored.
- Run a real-source 64-ID smoke before training; freeze 672 source predictions before source truth-last score. Source results do not cancel seven-view ground evaluation. Replay 112 source records then predict all seven Phase1 Main views of 168000 records before independent pre-truth checks, truth-last scoring and 119-group paired DURA audit.
- Source: 20261103-phase1-dura-feedback-source-s2026092701-r01. Ground: 20261103-phase1-dura-feedback-ground-test-s2026092701-r01. Simulation and reused records are not blind or real-satellite validation.
