# Source-trained bounded identity correction

Hypothesis: learn an input-conditioned correction toward a local identity-guidance direction during Phase1 source training, while using no identity label or ground IQ at inference. The network sees the received IQ, frozen blind posterior and estimated-channel backprojection, and its total L2 correction is capped at 2% of the parent waveform norm. Training forms a single-step normalized input gradient of frozen Tri-SIG-TIME SSL: true labels for legal L_s fit IDs and high-confidence clean-F pseudo labels for U_s fit IDs. Ground paired IQ error and frozen-F classifier loss also enter training. The gradient is a training target only; F and blind parent remain frozen; DURA loads after training only for comparison.

Pilot predeclared after the true-L_s oracle diagnostic: 4096 source train IDs disjoint from 8192 source prior fit IDs, source channel views 21/22/23 once each, batch16 AdamW 0.0003, final epoch 3. The source L_s metadata file has 6300 labels but only fit-ID L_s labels enter training; U_s truth, V and test are never read. Evaluate fixed final checkpoint on 384 previously explored RX8 source records, 64 per impaired view, against parent and DURA using clean-F pseudo-target agreement, direct IQ NMSE and correction norm. No automatic target testing.

The training objective can exploit classifier vulnerability; even a bounded IQ correction is not guaranteed physically faithful. The source classifier saw source L_s IDs; source physical IDs and views have been explored. Source pseudo targets are not test truth. Broader source validation, legitimate source truth audit and Phase1 fixed-prediction truth-last scoring are required before any performance claim.

After observing the source pilot, predeclare a fixed-output scale diagnostic on the same 384 source RX8 impaired records: scales 1, 4 and 8, each projected to the original 2% global L2 bound, comparing pseudo-target agreement, per-record repairs and damages, direct IQ error and actual correction norm. No retraining, labels or target test. This explores the frozen direction only; it does not establish physical validity.
