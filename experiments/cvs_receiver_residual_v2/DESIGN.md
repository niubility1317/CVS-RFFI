# 跨TX共同位移补偿与分支贡献预测

本轮检验强`reference_response`骨干上的两种小幅修正，固定四组、四seed消融。尚无本轮性能结论。历史benchmark已暴露，不能写成全新盲测；当前测试结果不回流设计、调参或重跑。

## 共同基础

四组为`baseline`、`displacement`、`contribution`、`combined`。均从零训练同一个身份骨干，仅使用源L标签的普通CE和原生clean/satellite拼接。沿用当前三个practical场景分阶段采样，residual/post_sync/noeq；E1开始拼接，E80起卫星CE权重0.68，cleanCE权重1。原域骨干、GRL、正交、MixStyle、伪标签、EMA、DAOT、RC4均关闭。

物理划分不变：source RX=1/3/4/6/8，day=1/2/3，六TX；L/U/V=6300/56700/27000，U不使用。B128、每epoch50次更新、E200=10000次；AdamW学习率2e-4、weight decay1e-4，cosine降至1e-6，FP32、TF32关闭，不裁剪梯度。四个modelseed沿用2026092701至2026092704，物理split392005固定，增强/receiverseed2027固定。

E1至40只训练共同基础，两个新增头的输出初始化为零。E41至60线性增加残差强度，之后强度为1。额外头初始化不消耗共同骨干的随机数序列，单机制与组合中对应头的初始化一致。

## 机制A：跨TX共同位移补偿

工作假设为`mu[c,d] = s[c] + b[d] + epsilon[c,d]`。不把它当作已证实的物理分离。`mu[c,d]`是当前模型在源L的TX×RX单元均值，每单元210个样本。E40至200末尾刷新，下一epoch使用，完全detach，不采用EMA。所有组执行同样的L只读前向诊断，额外6300次样本前向/epoch单独记账。

对训练样本所属TX `c`，位移目标为其他五TX的接收机均值差的逐坐标中位数：

`Delta[-c,d,e] = median{k != c}(mu[k,d] - mu[k,e])`。

小网络`29 -> 64 -> 16 -> 160`从每个数据包的接收参考响应`q`预测补偿向量`n(q)`。利用当前L batch的TX×RX预测均值，学习它在两个RX间的差等于上述目标；同TX跨RX平均补偿压向零，以限制吞掉类别常量的捷径。损失采用按L特征RMS归一化的SmoothL1差值监督（权重1）和零均值平方惩罚（权重0.1）。

部署特征为`z - ramp * capped(n)`，补偿范数最多为基础`z`范数的25%。预测只读本包IQ，不输入RX或TX标签，不携带源均值或训练样本状态。辅助监督仅cleanL，卫星CE仍经过实际部署路径。`q`含TX与RX混合信息，留TX目标和零均值约束不构成可辨识性证明。

## 机制B：分支贡献预测

精确抽取三个实际贡献：`b_tf`、`tanh(g_pa)*b_pa`和` tanh(g_ref)*b_ref`。三者之和等于原模型特征，不把PA当作参考响应。

使用当前未加新增修正的特征`z`和同一个分类头，计算单分支删除的源L监督：

`u_b = CE(classify(z-b_b), y) - CE(classify(z), y)`。

目标完全detach，截到[-2,2]；`29 -> 64 -> 3`预测该增量，SmoothL1权重0.2。高贡献分支的权重上调，负贡献分支下调。融合为`z + sum_b(ramp * 0.25 * tanh(pred_b) * b_b)`，最大相对权重变化25%，始终保留基础贡献。该量是当前分类头上的删枝敏感度代理，不是因果效应；辅助训练不读取U或query标签。

组合先做贡献残差，再减共同位移补偿。所有辅助权重乘同一ramp，身份CE同时监督最终部署路径。没有全局协方差、正交矩阵或对抗域分类。

## 验证、测试与判定

数值验证覆盖：基础骨干初始权重和随机数状态一致；新增头初始零输出时logits逐位相同；分支和一致；跨TX目标严格排除被监督TX；辅助头有有限非零梯度；单包推理与批次组成无关；checkpoint严格往返；source配置拒绝target/truth。

先完成全部16源模型并固定各自E200。源侧偏好按照四seed平均`0.5V + 0.5worstRX`，完全同分才比较参数量。固定消融全部测试，不按偏好删减候选。

复用已有VALIDATED_ONCE的clean和六个完整practical residual视图，每视图168000相同物理ID。全部16×7预测完成后，独立进程才读truth，输出Accuracy、Macro-F1、最差RX、逐RX/TX混淆矩阵、四seed均值/样本SD、配对差值及交互项，第二种bincount实现重算指标。七个完整视图不是互斥LEO场景分层，不作正式Phase2、K、新TX或H声明。

位移机制是否适配强骨干，还需检查L跨TX位移的一致性、实际补偿幅度与删枝贡献预测；这些是机制诊断。识别收益必须由冻结后的独立测试确认。无收益、负交互和成本增加均完整保留。技术故障保留产物、不自动重试，不因低性能停止，也不干预其他健康任务。

## R2初始化修复

R1的CPU头初始化错误重置CUDA dropout RNG，保留为含随机性混杂的诊断，健康任务不停止、不热改。R2从零重新执行固定16行，不继承R1权重；仅修复CPU私有生成器，不改变结构、损失或预算。设计在R1任何target预测前固定。R2使用剩余合法GPU名额，最多4个worker、每GPU总任务最多2个；已验证CPU与CUDA随机数状态均保留。
