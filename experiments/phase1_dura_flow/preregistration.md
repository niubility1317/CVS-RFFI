# DURA-anchored conditional flow restoration

A continuous IQ velocity network starts from the fixed DURA output and makes four fixed Euler updates. Each update uses only the current received IQ, the fixed DURA anchor, the current self-generated state, the blind noise estimate and the step time. Invariant complex correlations condition bounded coefficients multiplying received, anchor and current IQ with learned complex temporal filters. Zero initialization reproduces DURA, and the restoration is globally phase equivariant. The output is one continuous waveform, not a true-label selector.

Train on paired source IQ with two objectives. First, backpropagate the established aligned IQ, frozen Tri-SIG-TIME SSL feature/soft-output and DURA-relative protection losses through the four-step rollout. Second, use fixed weight 0.25 for source flow matching: align the clean source waveform to its DURA anchor using the established bounded time shift and complex gain, fill out-of-window edges with DURA, randomly interpolate between anchor and this source endpoint, and train velocity toward endpoint minus anchor. Alignment and source target are detached. This auxiliary path uses paired source clean IQ only at training; inference starts from DURA and never receives clean IQ, TX identity, scene label, target truth or another record. Straight interpolation and finite Euler steps are modeling choices, not proofs of an accurate posterior or of satellite-channel realism.

Use the same 8192 source fit IDs, source epochs 21/22/23, five training epochs and frozen DURA, blind estimator, gate and classifier as the ordinary context model. The extra random interpolation consumes additional RNG. No direct TX identity, U_s truth, V, ground data or ground feedback enter the recovery model. Source and ground records have been repeatedly explored.

Run real-source 64-ID smoke first. Fix all 672 source predictions before authorized source scoring. Regardless of source outcome, fix seven Phase1 ground views of 168000 records before truth-last scoring and independent 119-group audit. Two CPU threads and the established load limit apply; do not interfere with existing runs. Source and ground channels are simulated, not independent blind or real-satellite validation.
