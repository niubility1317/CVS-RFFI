# 已知仿真信道的条件信号先验诊断

这是 Phase1 源域探索，不是可部署恢复器。用 8,192 条源训练物理记录的干净信号，按冻结 Tri-SIG-TIME SSL 的高置信输出分组，拟合 6 个正则化高斯波形分布及共享高斯对照；不读取 TX 标签或 U_s 真值。使用接收机 8 留出的六个受损场景各 64 条、缓存 19，训练和留出物理 ID 互不重叠，但其他视图曾参与探索。

推理假设已知该条记录的真实仿真信道算子和由仿真参数导出的噪声协方差，分别计算共享后验、条件分布的边缘似然混合及最大概率分支，冻结 Tri-SIG-TIME SSL 对恢复 IQ 识别，并比较原始受损 IQ 和 DURA。另计算需要干净基座目标的条件分支作为不可部署的对照。分类指标只比较高置信干净基座伪标签，波形误差使用配对干净源 IQ；没有 V、测试或真值标签。

信道算子、噪声信息和干净目标在部署时不可用；自动增益也使近似似然不再严格。结论只是固定先验及特定源样本上的机制诊断，不是可部署网络、真实卫星准确率，也不是恢复性能上界。若显现有用信号，下一阶段必须独立学习盲信道估计，并进行源域保护和完整 Phase1 测试。

信道线性算子与噪声协方差引用 `20261031-DURA-known-action-Gaussian-r01` 固定快照，并核验提交及文件 SHA-256；该参考曾以原生前向算子验证一致。
