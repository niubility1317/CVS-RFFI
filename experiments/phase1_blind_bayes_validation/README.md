# 盲信道条件先验固定模型的源域复核

固定 `20261102-phase1-blind-bayes-action-full-s2026092701-r01` 最终第 10 轮权重（SHA-256 `0ef60a205f785bda45f9936d519e925179dbbddeef2fd6cd285a83b02a284338`），使用完全相同的 8,192 条源训练物理记录拟合条件先验，保护门控只观察输入 IQ。RX4/6 第 3 天共 7,840 条记录用于筛选，RX8 共 3,921 条记录作为不参与选择的留出比较，均为源训练角色、与当前信道模型及先验拟合物理 ID 不重叠；这些记录此前其他信道视图已在研发中使用，不能称为独立盲测。

固定 0.8、0.99 两种盲保护阈值。对 RX4/6 的每个接收机与场景，候选与 DURA 的高置信干净 Tri-SIG-TIME SSL 伪目标正确数相比，下降不得超过 max(1,ceil(0.5% × 有效数))；干净波形对齐误差不得超过 DURA + 0.001；六个受损场景合计须至少多对 10 条。主规则还要求每个受损单元的平均对齐误差不超过 1.2 × DURA + 0.000001。另报告不对受损误差设硬门槛的识别导向结果，单独保留波形数值；两个规则都只使用 RX4/6，不以 RX8 选择。未满足规则不自动测试。

批量算子以固定复数核在反射边界上构造等效矩阵；验证其与已核验的源仿真算子一致。恢复输入只有接收 IQ、冻结盲估计器、源训练信号先验及保护门，不在推理时加载 DURA 或使用真实仿真信道；DURA 仅在源域比较时调用。分类数字是干净基座伪标签一致数，不是实际准确率；不读 TX、U_s 真值、V 或测试数据。
