# Bounded identity-guided source oracle

Diagnostic hypothesis: ground-classifier errors may or may not be locally correctable without a large IQ change. Fix the input-only blind posterior parent and input gate 0.8. First store and hash parent/raw/DURA source predictions and parent IQ for all 910 previously explored impaired L_s source records (RX4/6 = 613, RX8 = 297) before reading any source truth. Then use only legal L_s training truth to optimize each individual parent IQ through frozen Tri-SIG-TIME SSL; test relative L2 waveform-change limits 0.02, 0.05 and 0.10, 16 normalized gradient steps each. Report truth correct counts, repairs, damages and direct IQ error per receiver group and scene.

The true device label is deliberately supplied to this optimization and is unavailable for a new test record. This is an oracle feasibility diagnostic, not a deployable network, a bound on all approaches, or a test result. A small norm does not ensure a physically faithful signal; optimization may exploit classifier vulnerabilities. The frozen ground classifier trained on these source L_s records and these source views were previously explored. No U_s truth, V, Phase1 test or real satellite data.
