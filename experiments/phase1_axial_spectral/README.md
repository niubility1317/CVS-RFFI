# Phase1 direct IQ temporal / spectral attention restoration

Independent direct reconstruction from impaired IQ, not a DURA refinement. A residual dilated temporal network with receptive field 517 samples proposes additive IQ corrections. Two complex STFT branches (32/64 points) use time and frequency self-attention to predict bounded complex masks. Both output heads start at zero, making the initial mapping the identity. The temporal branch can generate additive information; the spectral branches reshape the signal using distinct resolutions.

Training uses only paired simulated Phase1 source IQ from the established L_s/U_s cache. No F weights, F outputs, source TX labels, V, test, or DURA are read during training or source selection. Source IDs are checked against the Tri-SIG-TIME contract. Sample seed 2026110551 sets 4096 reserved IDs; all receiver 4/6/8 day 3 records are excluded from training, and sampled receiver 4/6 day 3 and receiver 8 day 3 are validation and heldout respectively. Frozen teacher and other historical models may have seen these source IDs; the receiver/day split pertains to this new network only.

Ten cached source channel views (epochs 01–10), batch 32, AdamW 0.0003, seed 2026110754, shuffle 2026110755. Target is clean IQ aligned to received IQ within ±64 samples and complex gain; loss combines gain-invariant normalized IQ error, normalized fixed-target error (0.5), and a small input-deviation penalty (0.01). Checkpoints 2/5/10 and mixing coefficients .25/.5/1 are compared on the reserved cache epoch 20 using input-only predictions and paired IQ. For each receiver 4/6 and all seven scenes, candidates must not increase normalized alignment error over raw by more than 1e-4 on clean or 1e-6 on impaired; the greatest sum improvement is selected, or raw is retained. Receiver 8 results are reported but never enter selection. These rules do not claim that raw is competitive with DURA.

If a candidate is selected, an independent source smoke test freezes the chosen network and Tri-SIG-TIME SSL. Then predictions for the seven full Phase1 development views are sealed before truth is read; independent scoring and same-record DURA paired comparison follow. No adaptive target feedback is used. The historical development set has been observed repeatedly; results are nonblind and simulated, not real satellite performance.
