# Source teacher-disagreement correction for the direct IQ student

A one-pass independent temporal/spectral direct IQ student with a learnable global complex gain and fixed input-only clean-protection detector. DURA is used solely as a frozen source training teacher and post-freeze comparison; inference has no DURA dependency. The student initializes from the immutable epoch3 checkpoint of the concurrently running independent student (commit a90a5e381c19e94455bfafd9c67321833c764491), chosen before that run's final source selection.

Training uses Phase1 source L_s/U_s IQ and simulated cached channel views 6–10. Frozen clean Tri-SIG-TIME SSL and frozen DURA-derived SSL predictions define a hard source example only when the clean prediction confidence is >=0.95 and DURA's predicted class differs from it. This is teacher disagreement, not a known true classification error. On hard inputs, DURA IQ imitation has weight .25 instead of 1, DURA-logit KL .1 instead of .5, clean-logit KL 3 instead of .2, plus .5 pseudo-class cross entropy; paired complex-gain-invariant IQ loss has weight .2. Other inputs retain parent weights. No TX labels, U_s truth, V, or target IQ are read, and all teachers and the gate remain frozen.

Five epochs use 47,143 source training IDs, gate-active subset, batch32 and AdamW lr .0001. All RX4/6/8 day3 and original 4096 sampled IDs are excluded from student/gate training. Source selection evaluates 7840 RX4/6 day3 IDs and holds RX8 day3 3921 IDs on cached view17. These identities appeared in previous source analyses under other channel views: selection is correlated and exploratory, not an independent blind test. Predetermined epochs1/3/5, alpha .5/1 and gate thresholds .8/.99 are compared with frozen DURA on high-confidence clean SSL pseudo targets and paired IQ. Each validation cell may lose at most max(1,ceil(.5% valid)) correct; clean IQ <= DURA + .001, impaired IQ <=1.2x DURA+1e-6, and aggregate impaired net gain >=10; otherwise retain DURA. Heldout RX8 is never used to select. If fixed source selection succeeds, predict all seven Phase1 development views before reading truth, then score and compare DURA. The development test is previously observed and simulated.
