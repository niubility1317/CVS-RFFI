# DURA source feature-response matching

Candidate: the same zero-initialized DURA-anchored context architecture as the ordinary context model. Train it on paired source IQ with an additional local feature-response loss. For each source pair, draw one identity-independent Gaussian IQ direction and scale it to 2% of clean source RMS. Apply the same additive direction to the clean and restored IQ. Match the finite differences of their L2-normalized frozen Tri-SIG-TIME SSL features, dividing by 0.02, and average by source receiver group. The clean feature response and perturbation are detached. Add 0.2 times this loss to the existing aligned IQ, frozen-reader guidance and DURA-relative protection objective. The source objective uses no direct TX identity.

This is an exploratory geometric regularizer, not a calibrated satellite-channel model or proof that local feature similarity improves identity. The perturbation may be off-manifold, and the reader's sensitivity may itself be harmful. The perturbation amplitude and loss weight are fixed before evaluation. Use the same 8192 source fit IDs, source views 21/22/23, five passes, seed and frozen DURA, reader, blind estimator and gate as ordinary context; the random direction consumes additional training RNG. No TX identities, U_s truth, V, ground data or ground feedback enter the recovery model training. Inference requires only the current received IQ, fixed DURA output and blind noise estimate; no perturbation, clean reference, identity or other sample.

Run a 64-ID real-source training smoke. Fix the checkpoint and all 672 source predictions before scoring source L_s; source metrics do not stop the registered ground test. Fix all seven Phase1 ground views of 168000 records before truth-last scoring and independent 119-group audit. Use two CPU threads and the established load limit; do not interfere with other experiments. The dataset has been repeatedly explored and uses simulated channels; it is neither blind nor real-satellite validation.
