# Phase1 自适应相位因子源域可行性试验

使用输入 IQ 的旋转不变量估计不变规则与相位抵消规则的混合权重，输出复数相位因子。此处仅测试相位代理任务，不是完整恢复网络，不产生目标集预测，也不构成识别率提升。

冻结 DURA 仅作为源域教师：对输入及教师输出拟合中央 128 点、±64 采样延迟和复数增益，增益相位作为代理目标。冻结输入门控选择参与样本。训练只读取 Phase1 源训练 IQ；不读取 TX、U_s 标签、V 或测试集，地面基座后续仍使用 Tri-SIG-TIME SSL。与教师相位一致并不代表恢复或识别性能提升。

固定 47143 个源训练 ID，RX4/6 day3 的 7840 条为选择集，RX8 day3 的 3921 条仅做留出观察；物理 ID 在其他信道视图下已被使用，不能称为独立盲测。候选为第 1、2、3 轮，选择集加权平均相位余弦损失须至少优于恒等相位 5%，每个场景接收机单元至多劣化 0.05，否则保留恒等相位。留出集不参与选择。

源训练样本相位旋转探针显示，高信号更接近随相位旋转，低城市更接近不随相位旋转；每个场景样本只有几十条，仅用于提出假设。两个 probe 是只读源训练诊断。
