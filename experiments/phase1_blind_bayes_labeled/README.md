# 盲信道恢复器的 Phase1 有标签源记录诊断

该诊断复用固定第 10 轮信道估计器、固定条件信号先验和阈值 0.99 的输入保护门，在源训练角色 L_s 中选取接收机 4、6、8 第 3 天的留出物理记录；排除此前固定的 4,096 条旧抽样记录。阈值及模型已在既有源域探索中观察，诊断不是独立盲测或模型选择。

第一步只读取源 IQ、角色、接收机和场景，分别固定干净 Tri-SIG-TIME SSL、原始受损、DURA、盲恢复四列预测，并写入带 SHA-256 的不可变预测完成清单；不读取任何类别真值。第二步核验完整物理 ID 与预测哈希后，才读取合法 L_s 的地面训练标签，计算 RX4/6 合并及 RX8 的逐场景准确计数、相对 DURA 的修复与损伤。U_s 真值、V、Phase1 测试数据均不读取。

冻结基座可能曾在这些 L_s 物理记录上训练，且这些记录的其他模拟视图已用于探索；该结果只反映此源域对照，不能代表独立泛化或真实卫星性能，也不自动选择模型或触发测试。
