# IR-EG实验准备与判定

本执行包继承指定提交的完整DAOT＋FastTrust配置，新增IR响应与BR历史预测。实验矩阵处于`PREPARED_NOT_LAUNCHED`。当前开发验证只使用随机初始化和合成源数据，不使用已有checkpoint或目标数据。

## 比较顺序

1. 数学、原生目标和状态事务验收，以及IR-ref/IR-cached CPU/CUDA对齐。
2. 一个固定模型seed 392005做源侧筛查；保留全部尝试、消融、失败和成本。
3. 冻结候选后按392005/392006/392007报告配对确认；其他随机流固定并单独登记。
4. 对比SIM、完整EG、IR。IR_G0严格使用零曲率响应；OR_EG只将响应的特征锚改为原点；编码器对抗关闭保留L/U域头监督。
5. BR_EG与BR_IR独立做效率研究；它们不是IR的执行等价优化。IR-ref仅作语义参照。

每个配置有独立输出目录。实际数据启动前绑定现有冻结source manifest，核对源RX1/3/4/6/8、day1/2/3及6300/56700/27000个L/U/V物理ID。不因本次求解器变化重建或重复验证未变化的数据。checkpoint从零初始化，无历史权重继承；未来若使用resume，仍须核对完整训练数据契约及来源。

## 预算与科学完成

E200/44400接受主步是历史预算审计。`convergence_confirmation.json`单独保留设计给出的源侧窗口规则。没有已批准的后续学习率与安全上限manifest，因此该文件明确`frozen=false`，不能启动确认训练。它不覆盖原有200epoch限制，也不授权延长、暂停或停止任何已有任务。

## 日志、成本与判定

分别统计configured、eligible、executed、applied、nonzero、fallback、accepted。两次CG截断可用，与精确收敛、数值回退分开记录。重诊断在阶段边界及每1000个接受步进行，临时域头只拟合源训练记录，并在固定V面板监测；负收益不截断。固定V面板为原生非shuffle验证加载器的前256条，报告物理ID和覆盖切片，不冒充全V统计。统计交互不解释为物理链路参数恢复。

效率同时报告相同物理曝光和相同冻结源侧收敛判据下的成本。必须包含数据、教师、snapshot、CG、日志和评估开销，以及FP32历史缓存显存。局部合成测试的用时只证明执行路径和成本测量可达，不等于完整RFFI训练加速。

候选和checkpoint冻结后才生成目标预测，独立scorer随后连接真值。clean、三种LEO、Macro-F1、最弱TX/RX、day0及RX×TX条件差值逐seed报告；3个seed同号不等于统计显著。完整记录负差值、缺项和技术失败，不选择性重跑，不自动晋升为默认方法。
