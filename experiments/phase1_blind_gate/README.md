# Phase1 blind input-only corruption gate

A stand-alone input-IQ detector protects a fixed single-pass direct restoration network. It learns clean-versus-simulated-corruption from source scene metadata only, not TX labels, DURA, V, or target IQ. A temporal convolutional network plus normalized complex frequency spectrum receives each 256-sample IQ input; random phase augmentation and weighted clean examples are applied during three source epochs. When the input's detector probability is below the selected threshold, inference returns the input exactly. This is not an oracle; simulator scene labels are never available to the detector at inference.

The restorer is one of fixed epoch 1/3/5 checkpoints of the prior source-only Tri-SIG-TIME SSL feature-guided experiment (commit c957ef168f4ff6ef5671331668481b40d111228c), whose earlier unprotected candidates failed the clean IQ guard. Gate training uses 47,143 Phase1 L_s/U_s source IDs; receiver 4/6/8 day3 and all prior 4,096 sampled IDs are excluded. Candidate validation uses all 7,840 remaining receiver 4/6 day3 IDs, and records 3,921 receiver8 day3 heldout IDs. These IDs are disjoint from that prior fixed 4096-record source evaluation. Ground F and historical source models may have seen them, and the gate design was prompted by prior observed source behavior; no independent-blind claim is made.

The gate is trained on source cache epochs 1–3, batch 128, AdamW 0.0003, phase augmentation, and 4x clean weight. Frozen F is loaded only after gate training. On epoch20 source validation, combinations of fixed parent checkpoints 1/3/5, alpha .25/.5, and probability thresholds .8/.9/.95/.99 are evaluated. Source labels are high-confidence (>=0.95) clean F pseudo targets; real TX labels remain unopened. Each validation cell allows at most max(1,ceil(0.5% valid)) correct decisions lost, and normalized aligned IQ MSE <=0.001 on clean or <=1.1 times raw plus 1e-6 on impaired. Choose largest total impaired net gain >=10; otherwise retain raw. Heldout receiver8 is not used in selection. If selected, source smoke and all seven Phase1 development predictions run; test truth is read only after all predictions are sealed. DURA is used only as an external post-freeze comparator.
