# Phase1 信号自身重复结构的自参考网络

输入 IQ 经固定相位及时移锚定后，网络将相隔 80 点的两个 64 点片段做输入内相位对齐，以它们的差异和相关性作为参考；轻量空洞卷积逐位置预测复数混合与全窗残差，初始化为恒等输出。网络不需要外部 IQ 信号库，推理不调用 DURA。保护门控与相位模块均固定；相位模块此前在源域由 DURA 教师指导。

预设 2048 条源训练记录、另留 256 条不同源训练记录、批量 32、64 次更新；训练与观察缓存分别为 11 和 14，种子 2026120154/2026120155。使用干净配对 IQ 和冻结 Tri-SIG-TIME SSL 特征、软预测训练，不读取 TX、U_s 真值、V 或测试 IQ；DURA 在训练后才作为源对照加载。比较原始输入、DURA、相位锚点、固定重复平均及网络，指标为高置信干净基座伪标签一致数及对齐 IQ 误差。真实 32 条源记录的零梯度和有限非零训练梯度检查通过。

这是探索性短试验，不选模型、不保存权重、不进行 Phase1 测试；源物理记录此前已在其他模拟信道视图下被观察，不构成独立盲测。
