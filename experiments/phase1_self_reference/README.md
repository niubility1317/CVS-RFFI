# Phase1 信号自身重复结构的自参考网络

输入 IQ 经固定相位及时移锚定后，网络将相隔 80 点的两个 64 点片段做输入内相位对齐，以它们的差异和相关性作为参考；轻量空洞卷积逐位置预测复数混合与全窗残差，初始化为恒等输出。网络不需要外部 IQ 信号库，推理不调用 DURA。保护门控与相位模块均固定；相位模块此前在源域由 DURA 教师指导。

预设 2048 条源训练记录、另留 256 条不同源训练记录、批量 32、64 次更新；训练与观察缓存分别为 11 和 14，种子 2026120154/2026120155。使用干净配对 IQ 和冻结 Tri-SIG-TIME SSL 特征、软预测训练，不读取 TX、U_s 真值、V 或测试 IQ；DURA 在训练后才作为源对照加载。比较原始输入、DURA、相位锚点、固定重复平均及网络，指标为高置信干净基座伪标签一致数及对齐 IQ 误差。真实 32 条源记录的零梯度和有限非零训练梯度检查通过。

这是探索性短试验，不选模型、不保存权重、不进行 Phase1 测试；源物理记录此前已在其他模拟信道视图下被观察，不构成独立盲测。

## 预登记源域正式筛选

随机初始化自参考网络，源训练 47143 条物理记录，批量 32、3 轮，使用缓存 11 至 13；RX4/6 的 7840 条记录用于筛选，RX8 的 3921 条作为留出观察，缓存均为 19。使用干净配对 IQ 和冻结 Tri-SIG-TIME SSL 伪目标、特征训练；固定输入保护门控与相位锚点。模型种子 2026120254，训练顺序种子 2026120255。

固定比较 3 个轮次、两个残差比例（0.5、1）及两个输入保护阈值（0.8、0.99）。每个 RX4/6 场景的伪目标正确数不得比 DURA 低超过 max(1, ceil(0.5% × 高置信数))；干净 IQ 误差不得超过 DURA + 0.001，受损 IQ 误差不得超过 1.2 倍 DURA + 0.000001，六个受损场景的合计正确数必须至少提高 10。RX8 结果不参与选择；全部未通过则保留 DURA，不进行测试。DURA 在三个候选权重固定后仅用于源域对照。

源域伪目标一致率不是真实准确率；所有源记录可能已在其他信道视图中被观察，不能声称独立盲测。网络推理仅使用当前输入、固定相位锚点和门控，不使用 DURA 或信号库。

Phase1 评估接口要求完整源筛选结束并重新计算入选规则、逐项核对所选轮次权重及冻结相位和门控，先用源样本检查推理，再生成七视图预测；预测固定后才能评分。若未入选则不读取测试 IQ。当前接口检查只使用模拟模型，并非正式候选或测试结果。

## 识别导向的独立源域补充分析

在第 3 轮训练期间、任何完整源域筛选结果产生前固定：额外检查同一 12 组候选是否满足 RX4/6 每个场景伪目标正确数保护、干净 IQ 误差不超过 DURA + 0.001，及六个受损场景合计至少多对 10 条。受损 IQ 相对 DURA 的误差不设硬门槛，单独报告最差比值；RX8 不参与选择。此分析不改变原来的分类和受损 IQ 联合筛选，也不自动读取测试集；如果补充候选与主筛选结果不同，需要固定候选及波形质量边界后再做下一步评估。伪目标一致数不是实际准确率。
