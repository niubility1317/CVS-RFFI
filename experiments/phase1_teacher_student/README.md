# Independent direct IQ restorer with source-only DURA distillation

A one-pass independent temporal/spectral attention student, not the DURA architecture. The student accepts received IQ and has an additional bounded global complex amplitude/phase head to learn the broad source input-to-teacher phase difference. It begins from a fixed source-only semantic-direct epoch5 checkpoint, with the new head zero-initialized. A fixed previously trained input-IQ detector protects signals classified as clean: when disabled the student returns input exactly. At inference neither DURA nor source scene labels are needed.

On Phase1 source L_s/U_s signals, frozen DURA provides paired teacher IQ and frozen Tri-SIG-TIME SSL supplies teacher/clean output distributions. Students minimize normalized DURA IQ imitation + 0.5 temperature-2 DURA-logit KL + 0.2 clean-logit KL + 0.2 aligned complex-gain-invariant clean IQ error. Only gate-active source inputs train the student. No TX labels, U_s truth, V, or test IQ are read in training or selection; DURA and Tri-SIG-TIME SSL are frozen. Source input-to-DURA phase variation was observed on 128 source records and motivated the new global complex head; this is not a universal channel statement.

Five epochs use 47,143 source training IDs, cached views 1–5, batch32, AdamW lr 0.0001. All rx4/6/8 day3 and the original 4,096 sampled IDs are excluded from student and gate training. Fixed source selection uses 7,840 rx4/6 day3 IDs and 3,921 rx8 day3 heldout IDs in cache18. The physical IDs have appeared in prior source selection (under other cached views) so this evaluation is correlated and exploratory. For epoch1/3/5, alpha .5/1 and gate thresholds .8/.99, use high-confidence frozen clean F pseudo targets and paired IQ: per receiver/scene classification may lose at most max(1,ceil(0.5% valid)) vs DURA, IQ MSE <= DURA + .001 on clean or <=1.2 times DURA plus 1e-6 on impaired, and aggregate impaired net gain >=10; otherwise retain DURA and do not test. Heldout RX8 is never used for selection.

If selected, the frozen student and input-only gate run Phase1 seven-view predictions before test truth, followed by independent score and matched DURA comparison. Development test has been repeatedly observed and uses simulated channels.
