# Learned ground denoiser and blind data-prox source pilot

Independent DURA-free restoration: train a noise-conditioned denoiser only on clean Phase1 source IQ and frozen Tri-SIG-TIME SSL features; no TX labels or U_s truth. At inference, use the previously frozen input-only blind action estimator and source Gaussian posterior as initialization. Alternate the learned ground-signal denoiser with a proximal update solving the estimated linear channel data-consistency system. The fixed run makes three updates with noise-to-signal assumptions 0.20, 0.10 and 0.05 and evaluates data-consistency strengths 0.1, 1.0 and 10.0 times mean channel energy. This is a plug-and-play learned prior, not a claim of exact Bayesian sampling.

Predeclared source pilot: choose 4096 ground source training physical IDs disjoint from 8192 Gaussian prior IDs and from RX4/6 validation and RX8 holdout. Three passes over these 4096 records, batch 16, AdamW 0.0003, noise levels 0.05/0.1/0.2/0.4; final epoch 3. Only source paired denoising and frozen F soft targets/features train the denoiser. Load blind action model, conditional Gaussian prior and DURA only after training, DURA solely for comparison. Evaluate 64 previously explored RX8 source records in each of six impaired views, with high-confidence clean F pseudo-target agreement and direct IQ NMSE. No TX labels, U_s truth, V or test data.

Ground physical IDs and diagnostic views have been explored; these numbers are not independent blind evaluation or real satellite performance. No automatic Phase1 test or model selection; clean-input gate and broader source audit needed before any fixed test.
