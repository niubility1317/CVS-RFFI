# Phase1 DURA cross-view channel-consistency experiment

- Candidate: independently initialized 163698-parameter multiscale context waveform correction anchored to frozen DURA, same source IDs and other source losses as phase1_dura_context.
- Training additionally uses three separately seeded simulated received views of each permitted source physical ID. Train on ordered view blocks (21,22,23), reconstruct each other source view cyclically; select an alignment within +/-64 samples and fit a local complex gain in four 32-sample segments of the central 128. Normalize squared residual by the other received view's energy and add 0.5 times the receiver-balanced mean. Alignment and gain selection are detached; gradients pass through the restored waveform. Per-view native channel and noise remain unknown; this is a simplified training regularizer, not a calibrated likelihood.
- The main loss retains source clean paired IQ, frozen Tri-SIG-TIME SSL feature/distribution/margin and source DURA-relative soft degradation protection. F-guided. No TX identities, U_s truth, V, target or target feedback enter training. Paired source views share physical IDs but different simulations; during inference use one received IQ only and no clean/other source view.
- Reuse same legal 8192 source IDs and epochs 21/22/23, five epochs. Triple batches contain the same physical IDs in all three views, producing 24576 exposures per epoch but fewer optimizer steps than the unpaired context experiment; comparison is not a controlled single-loss ablation.
