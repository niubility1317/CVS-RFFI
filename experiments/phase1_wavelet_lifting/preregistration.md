# Phase1 independent multi-resolution wavelet recovery

- Candidate: an independently initialized single-window IQ restorer, not DURA. Four invertible Haar levels decompose the received IQ. A shared multiscale convolutional network uses phase-invariant magnitude and cross-products to predict complex, bounded local residual coefficients, including low-frequency context for detail bands; inverse Haar synthesis returns IQ. The initial network is exactly the input and global IQ phase rotation is preserved.
- Training: fixed 8192 allowed source IDs and views 21/22/23 for five epochs, using aligned paired source IQ, output power and frozen Tri-SIG-TIME SSL features, soft predictions and pseudo-class margin. This is F-guided; no TX identity, U_s truth, V, target data or target feedback. Frozen blind noise estimator and blind clean gate are used; inference takes only the current IQ.
- Freeze final checkpoint and all 672 source predictions before source scoring. A real-source 64-ID/28-record smoke precedes full training. Weak source results do not stop subsequent seven-view evaluation.
- Run fixed source replay, then all seven Phase1 Main views of 168000 records. Independently verify IDs and raw predictions before truth-last scoring and a 119-group same-record DURA audit. Ground outcomes cannot alter this or other registered experiments.
- Source run: 20261103-phase1-wavelet-lifting-source-s2026092701-r01. Ground run: 20261103-phase1-wavelet-lifting-ground-test-s2026092701-r01. Source and ground datasets are previously explored; these are simulated development tests, not an independent blind or real satellite experiment.
