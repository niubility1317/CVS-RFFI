# Unaugmented matched control for DURA source augmentation

Train the same DURA-anchored ContextRecovery model and use the same aligned IQ, power and frozen Tri-SIG-TIME SSL feature/distribution objective as `20261103-phase1-dura-augment-source-s2026092701-r01`. Use the same 8,192 source IDs, three cached source-view epochs, model and optimizer initialization, order, five-epoch schedule, frozen DURA/reader/blind estimator/gate and prediction interface. The only intended difference is removal of additional source-channel augmentation. The augmented model has its own separate random generator, so its augmentation does not consume the model/optimizer random stream. Verify the fixed training inputs and source predictions, but numerical effects of model updates can differ after the inputs differ.

Both models use aligned IQ targets and frozen-reader guidance, not transmitter identity labels. No source U_s truth, source V, target adaptation, ground truth before complete fixed predictions or Phase3. Source truth-last score the same 672 records, independently recount, and retain both previously registered ground experiments regardless of source scores; predictions for each model are fixed for all seven views of 168,000 records before independent 119-group truth scoring. Source and ground development records have been explored and channels are simulated; this paired ablation is not an independent real-satellite experiment.
