# Noise-conditioned nonlocal IQ correction

Independent DURA-free Phase1 source pilot. Freeze the input-only blind action estimator, source conditional Gaussian posterior and Tri-SIG-TIME SSL. A new network takes the received IQ, blind posterior IQ, estimated-channel backprojection and predicted log-noise variance. Two full-time attention blocks allow every sampling position to use long-range context; the IQ correction is initialized to zero and projected to at most 20% of the posterior L2 norm. DURA is loaded only after training for comparison.

Source training: 4096 physical IDs from the source training role, disjoint from the 8192 Gaussian prior fit IDs and RX4/6 source validation/RX8 source holdout. Use source simulator views 21/22/23 once each, batch16, AdamW 0.0003, final epoch3. Loss uses paired clean source IQ and frozen F features/soft output; hard source examples get extra soft-target weight. Only L_s fit-ID true labels enter cross-entropy; U_s uses clean F pseudo targets, never U_s truth. The source label metadata contains all 6300 L_s labels for ID verification, but only fit-ID labels enter the optimizer.

Fixed pilot evaluation: same previously explored 384 RX8 source impaired records, 64 per scene; compare parent and DURA by high-confidence clean-F pseudo-target agreement, direct IQ NMSE and correction norm. No clean protection gate in this impaired-only pilot, no source V or test access. The 20% L2 cap and F identity loss do not guarantee physical fidelity; source views previously explored, pseudo targets not true accuracy. Broader guarded source screening and truth-last Phase1 testing are required.
