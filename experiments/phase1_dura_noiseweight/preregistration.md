# Phase1 DURA relative-noise-weighted source training

- Independently initialized 163698-parameter phase-equivariant multiscale context correction anchored to frozen original DURA, same source IDs, three source view epochs, five epochs, batch and optimization settings as phase1_dura_context.
- Source example weight is 1 + 7 sigmoid(log_variance - log(mean(received^2)) + 3), between 1 and 8, based only on each received IQ and the frozen blind noise estimate. Within-receiver weighted means are averaged across receiver groups. Noise estimate is a proxy and may be miscalibrated; no source or target scene label is used by the loss. Threshold was motivated by previously inspected source development records; those records are not an independent blind evaluation.
- Primary paired clean-IQ alignment, frozen Tri-SIG-TIME SSL feature/distribution/margin guidance, power and 5x soft DURA-relative waveform protection are weighted together. F-guided; training uses only legal L_s/U_s source IQ pairs and public RX groups, never TX identity, U_s truth, V, target or target feedback.
- Source run: 20261103-phase1-dura-noiseweight-source-s2026092701-r01. Two CPU threads with load guard; 64-fit/28-eval real source smoke first, verify frozen components and nonzero adaptive gradient, then 8192 source IDs, epochs 21/22/23 for five training epochs. Record total sample weights and number >= 4.5. Freeze 672 source predictions before authorized L_s source scoring.
- Ground run: 20261103-phase1-dura-noiseweight-ground-test-s2026092701-r01. Source replay and 168000 fixed Phase1 Main IDs per clean and six practical views; one received signal per inference, frozen Tri-SIG-TIME SSL. Independent pre-truth matching, truth-last scoring and 119-group audit follow all seven fixed predictions. Source metrics alone do not stop ground testing.
- Stop only for technical, numeric, data-contract, frozen-component or process failures; preserve unrelated tasks and outputs. Ground test is explored development data, not independent blind or real satellite measurements.
