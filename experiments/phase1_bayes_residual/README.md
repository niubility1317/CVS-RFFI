# 物理后验残差恢复原型

在固定盲信道估计和条件 IQ 后验之后，计算接收信号与重建信号经估计信道的残差，并通过信道伴随算子反投影到地面 IQ 坐标。轻量膨胀卷积以当前后验 IQ 和该反投影为输入，预测有界残差；初始化时严格保持原后验。推理只用接收 IQ、固定盲估计器、条件先验和残差网络，不调用 DURA、干净信号或真实仿真信道。

预设从不与 8,192 条先验拟合记录重叠的源训练池抽取 4,096 条物理记录，批量 8、一遍训练，AdamW 学习率 0.0001；保留干净 IQ 与冻结 Tri-SIG-TIME SSL 特征／软预测约束，合法 L_s 训练记录另使用真实标签交叉熵；U_s 只使用基座软预测，绝不读取 U_s 真值。L_s 元数据读取全部 6,300 条标签以核对物理 ID，只有本次训练物理 ID 的 L_s 标签被复制到损失，RX4/6/8 第 3 天留出 ID 的标签不用于优化。

训练完成后固定权重，再将原始信号、DURA、父盲后验和残差恢复在 RX8 第 3 天六场景各 64 条先前观察过的源记录上比较；此阶段分类目标为高置信干净基座伪标签，并非真实准确率。DURA 只在训练结束后作为源对照加载。保留源训练与留出物理 ID 不重叠，但基座、父模型和这些样本的其他信道视图此前已经参与研发；结果不能称为独立盲测。无 V 或 Phase1 测试 IQ 读取。
