# 多视图残差恢复器的固定源域复核

等待多视图残差训练的固定第 3 轮和源诊断完整生成后，核验代码版本、父模型与先验哈希、源训练标签权限和冻结状态。使用固定盲保护门，对 RX4/6 的 7,840 条源记录逐接收机、逐场景比较 DURA、父盲后验及残差恢复；RX8 的 3,921 条源记录只作留出观察，不参与选择。源 ID 未参与残差网络训练，但其其他模拟视图此前用于研发，不能称独立盲测。

固定门控阈值 0.8、0.99，分别以 DURA 和父恢复器为参照：每个 RX4/6 单元的高置信干净基座伪目标正确数下降不得超过 max(1,ceil(0.5% × 有效数))，干净对齐 IQ 误差不得超过参照 + 0.001，六个受损场景合计至少多匹配 10 条；主规则要求每个受损单元 IQ 误差不超过参照的 1.2 倍 + 0.000001，另单列不设该受损波形门槛的分类导向分析。两种参照、两种规则均预先固定。

推理只用接收 IQ、固定盲信道模型、条件先验、残差网络与保护门；DURA 仅用于源域比较。伪标签不是真实准确率；不读取 U_s 真值、V 或测试 IQ，不自动运行 Phase1 测试。
