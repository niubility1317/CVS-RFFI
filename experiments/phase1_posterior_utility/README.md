# Source-trained utility for conditional posterior IQ

Given one received IQ, a frozen blind channel estimator and a fixed six-class source Gaussian mixture produce a parent posterior mean and six class-conditioned IQ candidates. A small shared utility network sees only input-derived evidence: frozen Tri-SIG-TIME SSL features and probabilities of parent/candidate, source-posterior weights, candidate class index, blind estimated noise, measurement residual and waveform difference. It predicts whether a candidate is safer than the parent. Candidate selection is input-only and abstains when scores are below fixed thresholds; DURA is never used by the selector and is loaded only for source comparison.

Training target: source fit L_s true labels and high-confidence clean-F U_s pseudo labels only. For candidates whose F class differs from the parent, label a repair positive only if the candidate fixes the training target and its direct paired clean-IQ error is at most 1.2 times the parent; label as negative a parent-correct/candidate-wrong switch or a waveform-guard violation. Other pairs do not enter the loss. This is a source-only supervised ranking experiment; IQ ground data and labels are not available at inference.

Predeclared pilot: 4096 source fit physical IDs disjoint from 8192 prior IDs and source validation/holdout; source views21/22/23 once each, freeze F and blind parent, train utility MLP ten epochs AdamW .001 after source pair extraction. Require at least 100 pairs and at least 10 examples of each target class; otherwise do not train. Source L_s metadata has 6300 labels, only fit-ID L_s labels enter loss; U_s truth, V and test not read. Source evaluation uses 384 previously explored RX8 records, three fixed utility thresholds .5/.75/.9, no target tuning or automatic test.

Class-conditioned source priors can hallucinate identity, pair labels are source-derived and F pseudo targets are not truth. Candidate scores require later robust source guard and truth-last Phase1 evaluation. This is not a general bound or real satellite validation.

Balanced-pairs source pilot: `--balanced-pairs` weights positive repair pairs by the observed training negative/positive ratio. Scores under weighted training are ranking scores and are not calibrated probabilities; fixed thresholds require separate source evaluation. This option is tested only on source and does not authorize test evaluation.
