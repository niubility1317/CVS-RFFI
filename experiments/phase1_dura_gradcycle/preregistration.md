# Phase1 gradient-balanced DURA cross-view experiment

- Candidate: independently initialized 163698-parameter DURA-anchored multiscale context model, same source IDs, simulated views, budgets and primary and cross-view source objectives as phase1_dura_crosscycle. No reused trainable recovery checkpoint.
- For every source batch, obtain primary and cross-view gradients of the output layer. When their dot product is negative, remove the auxiliary gradient component opposing the primary gradient in this layer. Scale the remaining auxiliary gradient toward 20% of the primary gradient norm, capped at 50 times the original auxiliary loss. Both coefficient and scale are detached, and the resulting scalar objective is used for the whole model: projection guarantees apply only to the output layer, not all parameters. If the primary output gradient is zero, retain the original auxiliary loss; if the projected auxiliary gradient is zero, retain the primary alone.
- Primary objective: paired source IQ alignment/power, frozen Tri-SIG-TIME SSL feature, distribution and margin guidance, and soft DURA-relative waveform protection. Auxiliary objective: separately seeded source-view cycle with +/-64 alignment and piecewise complex gain, weight 0.5 before gradient balancing. Training uses only permitted L_s/U_s IQ and public RX group; no direct TX identities, U_s truth, V, target or target feedback. This is F-guided.
- Source: 20261103-phase1-dura-gradcycle-source-s2026092701-r01. Same 8192 source IDs, three approved view epochs and five epochs, paired 3-view batches. Two-thread CPU and load guard. First actual source smoke uses 64 IDs/28 source eval records; checks paired views, frozen components and nonzero gradient. Log batch count, conflict count and applied scale; this is source training only.
- Ground: 20261103-phase1-dura-gradcycle-ground-test-s2026092701-r01. Source replay and 168000 fixed Phase1 Main IDs per clean and six practical views, frozen Tri-SIG-TIME SSL, one received signal per inference. Independent pre-truth matching, truth-last scoring and 119-group audit follow all seven fixed predictions; weak source scores alone do not stop it.
- Stop only on technical, numerical, data-contract, frozen-component or process failures; preserve unrelated jobs. Ground testing is explored development data, not independent blind or real satellite measurements. Expected artifacts: source smoke, frozen checkpoint/predictions, authorized source score, seven-view ground predictions and independent audit.
