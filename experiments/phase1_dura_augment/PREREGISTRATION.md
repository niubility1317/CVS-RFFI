# Phase1 DURA source-channel augmentation

Train the existing DURA-anchored context correction using the frozen source-only view epochs 21, 22 and 23. Before the frozen blind estimator and DURA process each training window, randomly augment 75% of source windows, independently of labels, receiver identity, source role, scene and target data. Add one zero-padded echo with delay uniformly chosen from 1 to 12 samples, magnitude uniformly in [0, 0.35) and phase uniformly in [0, 2π); rotate by an additional frequency offset in [-0.01, 0.01) radians per sample; and add independent IQ Gaussian noise of 20–35 dB relative to input IQ component RMS. Leave the other 25% unchanged. Fixed seed 2026110419. Counts for original scenes describe cached scenes before augmentation. This augmentation compounds an existing simulated source view and is a stress test, not an assertion that its distribution represents the satellite channel.

The source clean IQ remains the paired target. Use the existing aligned IQ and frozen Tri-SIG-TIME SSL feature/distribution guidance, with no additional DURA-relative waveform penalty. Freeze DURA, blind estimator, gate and reader. No TX identities are read by training. At source evaluation and Phase1 inference, apply no augmentation, use only one received window and frozen modules, and allow no target labels, target learning or target feedback. Do not read source U_s truth, source V, ground truth before fixed predictions, or Phase3.

Use 8,192 disjoint source fit records, five epochs and 672 fixed source predictions before truth-last scoring. Run the declared ground experiment independently of source score: fix all seven outputs for 168,000 records, then run independent scoring and 119-group audit. Report both the relative 3% and three-percentage-point thresholds, together with paired DURA. Source and ground development data were previously explored; channels are simulated, not real satellite observations. Source augmentation may suppress transmitter information or teach an unrealistic compound channel, so superiority is not assumed.
