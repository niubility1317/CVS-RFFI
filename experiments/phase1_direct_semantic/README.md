# Source-only recognition-aware direct IQ restoration

A direct raw-IQ temporal / multi-resolution spectral attention network, initialized from the previous source-only direct model epoch 10, without DURA dependency. Frozen Tri-SIG-TIME SSL processes clean IQ to supply six-class soft outputs and 160-dimensional features, and processes restored IQ to deliver gradients only to the restoration network. Source training uses no TX labels, V, target IQ or DURA. Five source epochs use cached channel views 11–15 and 47,143 training IDs. The parent source split excludes all receiver 4/6/8 day 3 records and 4096 sampled source IDs. Fixed training output blend 0.5; loss is temperature-2 KL + 0.2 cosine feature loss + 0.4 complex-gain-invariant IQ error + 0.2 aligned fixed-target IQ MSE + 0.01 deviation, with AdamW lr 0.0001.

Fixed source validation receiver 4/6 day 3 uses epoch20, seven scenes, and only high-confidence (>=0.95) frozen clean teacher pseudo targets. For checkpoints 1/3/5 and output blends .25/.5/1, each validation receiver/scene cell may lose at most one correct prediction (zero on clean); normalized aligned IQ MSE must be <=0.001 for clean and <=1.1 times raw plus 1e-6 on impaired. Choose largest aggregate impaired-scene net gain, at least two, else retain raw. Receiver 8 day 3 is logged as an exploratory holdout, never used in selection. Prior exploration has observed results on this source holdout and frozen models historically saw source IDs, so no independent blind claim is made.

If a candidate passes, freeze it and perform a source smoke test, then predict seven full Phase1 development views with Tri-SIG-TIME SSL; seal all predictions before truth. An independent scorer and matched DURA comparison follow. The network never consumes DURA output. Target data are used only after source selection and are historically nonblind.
