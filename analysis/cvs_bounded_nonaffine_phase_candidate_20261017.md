# 有界非恒定相位视图：唯一候选与放弃条件

2026-10-17，底座 F＋跨 RX 同 TX、3 SIG_TIME、统一 Sinc、joint160、NoExplicitCFO、原默认 cosine 头正常联合训练、后续 E20 保持。本候选先做两个合法冻结默认头的 fitL 身份保持检查；尚未训练或证明 A_g 有效。

上一相位曲率统计在全部 fitL5040／72 格／18 held TX/day 组通过 RX 关联条件，MSE 减少 91.368334%。但该统计包含 TX、传播、滤波及均衡；不识别纯 RX 振荡器。源均值相位模板直接积分后的多数大差异 RX 对 RMS 为 1.28 至 1.38 rad，不支持轻度模板回放。这里不使用任何 RX 模板、标签或分组决定扰动，不声称覆盖全部源 RX 差异。

## 唯一算子

对每包全部 256 点产生 Float64 g[n] iid N(0,0.006^2)，令 phi=cumsum(g)。用固定样本索引中心 t=n−127.5，去掉常数与线性项：u=phi−mean(phi)−t·sum(t·phi)/sum(t²)。令 theta=u·min(1,0.1/max(abs(u)))，零轨迹取缩放1；整个已接收复数 IQ（包括原有噪声）乘 exp(j theta)，输出仍为 Float32 两路 IQ。

0.006 rad/step 是实际旧普通增强已有的未缩放上限；0.1 rad 峰值是本轮先验工程约束，使每点复数相对变化上界 2sin(0.05)<10%，不是由 source／target 曲线选出的幅度。尺度按整包统一收缩，不逐点剪裁、不删尾、不重抽、无置信度或 RX/TX/day 条件。保留所有极端轨迹并记录缩放；这个有界、去仿射过程不是未经修改的 Wiener 分布，不能命名为真实 RX LO 重建。

逐点幅度和全包功率在精确算术下保持；Float32 舍入误差实际记录。不恢复 RMS、不引入常相位/CFO、不改变窗口/切片/循环边界或必要内部补偿。没有 AWGN、MP、PA、DAC、TX IQ 不平衡、量化、剪裁或 practical 生成。随机过程本身没有 TX 标签输入。

旧 ordinary 本来含低概率 Wiener 相位噪声，因此本方案是独立、全覆盖、有界且去仿射的相位视图变体，不是新增强原理。旧 commonphase E20 的每包常相位、可训练 feature-curvature、线性频移和已关闭候选保持关闭。另一对话正在做 practical 噪声控制和时间栅格训练，本候选不复刻其算子或使用其权重。

## 文献依据及限制

[Chen等原始论文，2023](https://arxiv.org/pdf/2307.04955)在多天线接收模型中区分发射失真与接收振荡器相位噪声，并采用随机相位模型。这支持乘性接收相位变化的研究动机，不证明本有界过程、幅度或弱标注跨RX训练有效；不采用其多天线融合、滤除器、额外分类器或实验增益。源相位曲率结果也不替代本固定身份检验。

当前唯一假设是：该轻度、全包、无仿射相位的独立 IQ 视图可保持 TX 身份，值得进一步匹配训练。身份保护失败即关闭本算子；通过后仍须正式识别结果。联合目标 ACTIVE，low urban>60%／clean净增益／suburban距clean≤2pp探索目标均未证明。
