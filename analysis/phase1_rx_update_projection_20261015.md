# 下一独立假设：约束 AdamW 的实际特征位移

状态：设计与纯数学原型，尚未读取真实数据、训练或发布。84% 默认头 clean 三种子目标仍未达到。

最近的完整 E20 loss-gap 矩阵为负结果。随后，SIG_TIME＋CENTER25K 的跨 RX PA 完整交换源原型也有 0/8 个单元通过既定信号／虚拟方向条件。初始梯度与普通辅助 CE 很接近，末态梯度虽不同，临时特征更新仍未形成足够的独立源身份改善。末态三模式在四 cohort 上的 V pre-W CE 都比更新前高；这一稀疏观察提示需要直接检查位移方向，但还未证明真实训练时的源 RX 梯度冲突。不能据此认定所有中期证据学习都无效，也不能靠扩大辅助权重制造下一项结论。

下一项只研究训练机制：**在原 AdamW 提议之后，纠正会增加某个源 RX 身份风险的特征位移**。默认分类头继续按原主损失联合训练；没有新增分类器、特征投影层或可训练参数。旧隐藏 U 监督若进入后续正式训练，仍作为原主目标的一部分，不能用 U 真类生成约束。

设部署特征参数为 \(\theta_F\)，排除默认分类权重及 PA、参考响应、SIG_TIME 三个融合增益。原实际 AdamW 含裁剪、动量和 weight decay 后提议位移为 \(d_0\)。在与当前主批物理 ID 不重合的合法有标签训练样本中，按五个源 RX 计算固定当前默认 W／增益的身份 CE 梯度 \(g_r\)。求解

\[
d^*=\arg\min_d\frac12\lVert d-d_0\rVert_2^2,
\qquad g_r^\top d\le0,\quad r\in\{1,3,4,6,8\}.
\]

这里的符号是参数“位移”，不是下降梯度。约束只表示固定读出下、各源 RX 身份 CE 的局部一阶预测不增加。它不保证有限步 CE、不保证未见 RX 泛化，也不保证真实主头轨迹的风险下降。源验证 V 和目标域均不能用于梯度或在线投影约束。

可行域始终包含零位移。如果原位移已经可行，则原样返回。如果修正几乎把全部更新压为零，应作为无用机制记录，不能通过再放大或改阈值伪装为学习机会。欧氏距离使用当前固定 CENTER25K 参数坐标，不能声称参数单位或重参数化不变。五个约束的 Gram 矩阵只有 5×5，可在 FP64 中枚举最多 32 个 active set；有限精度残差、退化约束和实际参数舍入必须显式记录。

梯度冲突处理已有明确基础。PCGrad 将冲突的任务梯度作投影，CAGrad 用单任务局部改善约束平均任务优化。这项假设的具体区别是：约束对象为**既有 AdamW 实际提议的部署特征位移**，分组为源 RX，使用原默认身份头，且不将“梯度可行”误当作“AdamW 后实际参数位移可行”。这仍是有 prior 的研究假设，不是已证明的新方法。[PCGrad](https://arxiv.org/abs/2001.06782)，[CAGrad](https://arxiv.org/abs/2110.14048)。
