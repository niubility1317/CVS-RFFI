# 单侧边缘可见性：固定候选与最小源身份检验

2026-10-17。状态：原始文献与既有实现核查完成，已实现登记，19输入/配置负例与7科学判断反例及一次P0/P1审查PASS；尚未启动真实源检验。当前唯一候选是单侧边缘可见性变化，不是改名重跑已关闭的周期残差、时移、频移、谱响应或同TX插值。固定基线为F＋跨RX同TX、三路SIG_TIME、统一Sinc、joint160、NoExplicitCFO、默认cosine头联合训练；模型训练预算E20。

## 原始依据和反证

[Jiang等，2026，III-C](https://arxiv.org/html/2601.03063)在ADS-B增量识别中使用起端或末端归零遮挡，长度最大为样本的六分之一；作者还讨论中段遮挡的谱泄漏。该工作同时包含冻结骨干、Adapter/GMM和蒸馏，没有单独证明遮挡对当前WiFi或跨RX有效，本项目不引入其网络、头拟合、目标适配或数据筛选。

[Zhao等，2024，3.1及4.3.2](https://onlinelibrary.wiley.com/doi/full/10.1155/2024/7891968)的对照显示cutout和random-erasing会损害所测RFF识别，说明删掉局部观测不能直接当作标签保持。其邻点插值方法和双分支网络不是本候选；不复制其强度或基于目标的选择。

[Pan等，2025，III-A](https://arxiv.org/html/2412.08885)组合均衡残差、AWGN与block masking，不提供当前CVS上mask的独立增量。不能把组合成绩当作本候选证据。旧ordinary已包含Wiener相位噪声、AWGN、多径和弱双侧Tukey窗；不能称这些算子原来缺失。

当前选择是一个可证伪的观测可见性假设：轻度端部缺失是否保留原默认头身份判决，并在以后匹配E20中改善未见RX clean识别。它不是接收机硬件变化、采样时移、去噪或提高SNR，不承诺泛化成立。

## 读取真实源数据前固定

输入原生RMS EQ1、25Msps、[2,256]。只处理一个端部的16点：端外8点为0，另8点使用半余弦上升至1；右端用其镜像。所有其他输入点精确不变，特别是固定参考[80:160]。同一实数窗用于I/Q；没有时移、重采样、CFO/相位旋转、PA/量化/剪裁、附加噪声、传播或功率恢复。归零不是幅值阈值剪裁。没有按TX/RX/day/置信度选择位置或强度。16/256=6.25%是预先固定的有限支持，不是用目标准确率选出的幅度。

旧ordinary的Tukey只作弱双侧边窗且本次保持原样；新候选是另外的raw派生视图，不串接ordinary或As。中段mask不采用；不把输入参考不变等同全部模型特征或质量指标不变。

先用两份既有合法source-only、scratch final20的F＋跨RX B00模型（seed2026092701/02）作冻结默认头诊断，0更新、0另训头。模型来源沿原不可变后端，L5040/U45360/V21600、RX1整RX留出、默认cos30、final-only、无目标选择/未知祖先；只作操作诊断，不作为未来训练初始化。两个模型与同一fitL物理角色完全匹配。

每模型在同一5040个fitL上评估raw、左端、右端各一次；共30240个源前向＋一次真实CP合成2包no-query smoke=30242NN。全部6TX×4RX×3day、每格70包，禁止删包。原缓存反序列化L6300、未用V/历史特征；RX1的1260包先排除，U只有角色ID元数据、无IQ或标签。U/V/heldRX1/target不参与本次观察。

两模型、每个端部均须：accuracy和macro-F1相对raw下降≤0.5pp；每RX/TX/day accuracy下降≤1pp；raw正确集合保留率≥99%；相对IQ RMS变化中位数≥.01且最大≤.35；输入参考区间和支持外精确不变、未增加总功率。后两项是非空与轻度/接线检查，不能代替身份判据。分层和72单元完整保留。任一失败关闭这套16点/8zero8taper/双端独立规则，不缩短或换边、平滑形状、阈值、RX或seed救跑。

全部通过也只支持另行登记匹配E20的raw槽／边缘视图两组，保留共同raw.75＋ordinary.25与原SupCon，额外.25同IQ RDrop对，8次L前向和原U规则匹配，默认头联合训练；要求clean至少+1pp、macro-F1不降、每practical和seenV下降≤.5pp。该训练尚未实现/登记/启动，单源种子通过仍需独立确认；不访问target来选参数或候选。
