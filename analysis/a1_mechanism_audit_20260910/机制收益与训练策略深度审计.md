# A1/R3/ECRS机制收益、训练策略与后续创新审计

日期：2026-09-10。范围：分析与设计建议；本次未修改训练代码、未启动或干预实验。

**总体判断：已经找到小幅正向信号，但没有证据表明当前探索的机制普遍带来高收益。现阶段最值得投入的是恢复可靠无标签身份监督、检查从零训练的优化节奏，以及让物理因子真正受到可验证的约束。新模块应解决这些具体缺口。**

本报告使用截至2026-09-09 20:43的17条完整E200评分记录，以及2026-09-10 00:00的3条未完成训练快照。完整记录包含2条继承旧基座的A1历史对照；它们不进入干净从零训练的机制增益结论。逐epoch统计覆盖全部可得训练记录，未完成行分别为R3_B120的E113、R3_B160的E95、R3_REFERENCE_CLEAN_CROSS_RX的E128。这里的“截至”是证据时间，并非当前进程状态；本次没有刷新远端状态。

当前对照均不足以支持多seed稳定提升或独立泛化晋级。目标结果已经被观察，以下原因分析属于事后探索；不得把同一目标上的后续调参结果重新称为独立测试。未来训练仍限于授权source数据，目标query/truth不得进入梯度、阈值拟合、选模或重跑选择。

**一、什么机制真正有效，收益有多大**

1. **R3的联合辅助训练有目前最清楚的正向信号。**R3_REFERENCE达到clean=79.1125%、LEO均值=68.5133%，相对R3_STRUCTURE_CONTROL提升约1.12pp和0.95pp。控制行保留R3结构和相关前向、关闭辅助目标，因此这是self/swap/shared等联合辅助训练的贡献，不能写成“R3新架构单独提升1.12pp”，也不能拆给某一项损失。还缺self-only、self+swap、self+shared等对应消融。
2. **clean跨接收机身份约束值得保留为候选。**X1达到79.1327%/68.5167%，相对X0提升0.66pp/0.39pp。它直接利用同TX跨RX正对和同RX不同TX负对，是与任务契合的小收益；现在还不能称为强增益。
3. **warm EMA只有很弱的信号。**X系列两个场景均小幅上升，F系列clean略降、LEO略升。变化约0.16—0.19pp的LEO增益，尚不能排除训练波动。
4. **更多约束不等于更好。**从X1增加LEO配对变成X2后两个指标下降；coverage KL在X、F两条线均未改善LEO；均衡采样、bounded domain和组合项的LEO退步更明显。X7相对X2下降4.11pp，不能作为默认配置。
5. **速度优化与科学增益分开评价。**F1相对F0的本批壁钟缩短约16.65%，但clean下降0.91pp；R3顺序优化仅约0.82%的壁钟收益，同时精度下降。GPU共用条件影响时间，不能当作独占硬件加速比。局部数值一致性验证也不能替代全训练轨迹一致性。

F0_FIXED_BASE的clean为79.8464%，高于本批R3和X1；X1与R3的LEO均值只差约0.0034pp，可视为本次观测几乎相同。因此没有一个候选在clean、LEO、时间等方面全面取代基线。DAOT、MUSE、Fishr、域对抗和开放集相关目标虽然存在于训练路径，当前矩阵没有逐项匹配消融，不能从非零loss推导它们各自的收益。

R3在E181—200平均每个256样本U批次仅约1.89个样本进入身份监督，原始入选比例约0.74%；F0约43.58个，约17.02%。加权覆盖率分别为0.6156%和15%。这两个覆盖率口径不同，不能把0.6156%说成原始样本比例。R3从E41开始partial路由的阶段均值为零，E91—150的hard比例也只有约0.384%。

这证明**RC4的H/P身份监督利用不足**，不证明无标签数据完全没有使用：R3重构、表征学习和其他U路径仍可工作。0.15是有效身份权重上限，不是必须填满的最低配额；绝不能为覆盖率强行灌入错误伪标签。

现有路由叠加了校准就绪、预测集合大小、正确性风险阈值、多视图一致性、类别/RX限制及权重预算。风险权重还包含阈值以上余量的平方，再乘一致性和集合大小因子。已经入选但刚越过阈值的样本也可能权重很低。校准只在E1、21、41、91、161更新；教师的特征范数等校准输入随训练变化，固定很久的校准器可能失配。anchor=false时一票来自重复使用的EMA clean输出，不是三个独立教师。

**目前不能确定崩落由哪一环引起。**最小诊断应记录每一筛选步骤前后的样本数、风险概率分布、APS集合大小、分组校准误差与教师一致性；再用同一source V对当前模型做只读校准重放，比较原校准器与重新拟合校准器在相同输入上的通过率和错误率。若更新校准恢复覆盖且保持精度，才支持“校准陈旧”；若仍无法恢复，就要看教师判别力、强增强难度或身份表征变化。V只用于协议允许的校准和评价，不反向传播，也不转成额外训练集。

源验证准确率约98.5%，而目标clean约79%、LEO约68%，说明“source分类很好”尚未转化为跨接收机/信道鲁棒性。它本身不能证明模型容量不够，更不能证明必须加大骨干。

**三、训练策略、调度和权重是否合理**

现有策略有明确意图：监督起步、逐步增加扰动与一致性、EMA稳定、后期低学习率收敛。但它更像从成熟A1训练配置延续而来的组合，尚未证明适合全部参数从零初始化的R3。

|核对项|实际行为|判断及下一步|
|---|---|---|
|无标签总权重|MUSE启用时`_compose_unlabeled_closed_loss`返回`base + muse_total`；不走`lambda_u * identity`分支|`lambda_u=0.16`不是全部U损失的总旋钮。须追踪内部权重与独立加入的R3_U、DAOT_U|
|R3辅助尺度|`a1_r3_aux_scale=1`，L/U各自加入总目标；并非一个明确的共享梯度预算|E1—20两项标量均值合计约12.85，总loss约19.68。约65%的标量占比不能证明梯度占优，但足以要求检查真实加权梯度|
|R3中段调度|E91—150在原FCR日程中隔步切到transplant/necessity；精简R3实际只实现self/swap/shared/eta交集|当前半数step的R3辅助分支为零，日志active均值0.5。应给精简R3独立、连续的日程；这是减少的实现范围与完整日程不完全匹配，不是完整necessity已经执行|
|早期课程|RC4身份路由E21启动；LEO难度/比例以固定epoch切换|从零训练的教师是否在E21就绪，需要source可靠性数据，不能只看日期|
|ECRS的LEO路径|X2的clean跨RX约束E1已激活；LEO计数到E80才首次非零|“配置包含LEO”不等于前79epoch都训练了该路径。其他模块的LEO课程不能代替ECRS实际调用证据|
|校准节奏|E1/21/41/91/161更新，其余阶段冻结|表示变化快时可能滞后；先重放诊断，再比较固定周期与有界漂移触发更新|

损失值不能直接互相比大小：重构、CE、KL、距离、EMA归一化目标的尺度不同。现有部分梯度遥测测的是原始分项相对CE，且只在稀疏诊断位置；不是所有实际加权损失对共享骨干的梯度。仓库已有开放集与closed目标之间的budget/surgery入口，它也不等于R3内部self/swap/shared或R3与身份监督之间的完整控制。

建议先测`g_k=∇θ_shared(w_k L_k)`的范数、与监督身份梯度的余弦和裁剪比例，分别覆盖身份、RC4、R3、DAOT/其他辅助组。在固定少量训练step上采样，避免每步做多次反传拖慢训练。若只是尺度失衡，使用有界缩放；只有持续方向冲突时才考虑投影，不应默认将全部目标梯度强行等大。GradNorm和PCGrad是已有方法，可作工程对照，不能包装成新发明。[GradNorm原论文](https://proceedings.mlr.press/v80/chen18a.html)、[PCGrad原论文](https://arxiv.org/abs/2001.06782)。

调度对照应一次只改一类：先保留200epoch、保持其余机制，比较原日程与取消精简R3空档；再单独比较后40epoch的骨干衰减。不能同时换EMA、重构系数、学习率和采样，再把增益归因给其中一项。具体阈值和权重须在source规则下确定，不能根据这里的目标分数挑选。

**四、还有哪些信息没有被充分利用，创新应落在哪里**

**候选A：可靠性约束下的无标签身份课程，最高优先级。**

围绕“可信样本太少时为何少、如何恢复”设计闭环：source校准器评估当前教师，路由区分hard与partial，课程只根据source校准可靠性和允许的U统计调整。可以在不降低预设精度目标的前提下选择更合适的校准更新频率、修正过度压缩的权重映射，并把难样本送往低风险的一致性或集合监督。校准样本不足的TX/RX单元向全局估计收缩，不能硬拟合极小组阈值；U的预测类可以用于路由，但不可读取U隐藏真值。

最小损失形式仍可写成`L_U = a_h(t)Σw_h CE + a_p(t)Σw_p L_set + a_c(t)L_cons`，三个系数分别记录实际有效质量，不以单一`lambda_u`代理。关键证据是source校准精度保持、覆盖率合理恢复、身份梯度有效，并最终在预登记评价中获益。如果覆盖上升而错误率显著恶化，设计失败。FreeMatch已经研究按学习状态自适应阈值；本任务可能的差异应是**跨RX/LEO可靠性、集合标签与训练漂移的联合控制**，而不是“动态阈值”四个字。[FreeMatch原论文](https://arxiv.org/abs/2205.07246)。

**候选B：质量加权的跨接收机身份几何，优先于更强均衡采样。**

目前ECRS用归一化z_id上的triplet；同TX跨RX正对并未严格固定day/view，负对限定不同TX且相同RX/day/view。对所有合法三元组求均值，容易三元组可能稀释有效梯度。X1平均有效anchor约127.92/128，本来就超过99.9%，说明当前并不主要缺合法anchor。X5改变成每批4TX×4个RX/day单元×8样本，会改变batch覆盖与采样分布；本次大幅退步不能简单归咎于某一个因素，但没有必要仅为制造更多合法对再次强制均衡。

建议保持原始L采样，增加训练专用的source同TX跨RX多正例原型或短期记忆，用质量和半难度加权；正例尽量对齐可用day/view条件，负例保留同RX难负例，避免域差异成为捷径。记忆只存授权source L身份或符合协议的U预测状态，按模型版本/陈旧程度更新；不使用目标。普通prototype、SupCon、memory bank均不是创新点，真正待验证的是**质量受控、条件匹配、跨RX身份收缩而类间间隔保持**。

验收应同时看同TX跨RX距离、同RX异TX间隔、各source RX的宏平均和最弱组表现。不能只追求“receiver分类器猜不出来”，因为把身份信息一起抹掉也会达到这个表面目标。额外显存和编码次数要与现有triplet对照记录。

**候选C：物理扰动等变性与身份必要性，最值得形成论文主机制。**

R3已有canonicalizer、content、fingerprint、structured nuisance与physics-ordered decoder，不需要再虚构一个“首次物理解耦分支”。但是当前`apply_sat_fn(..., return_meta=True)`返回的metadata被丢弃，eta目标为零且valid全false；所有epoch的eta监督为零。当前swap主要是同一IQ的clean↔模拟LEO互换，不是真实跨接收机反事实。latent cycle、factor、necessity和定向transplant没有进入当前精简R3目标。

因此，重构成功只能说明模型可重建，不能说明三个因子分别对应内容、发射机和信道。内容分支、nuisance分支都可能吸收身份信息；现有结构约束降低旁路风险，却没有完成可辨识性证明。

更有价值的研究设计是对同一source IQ施加**已知、可记录、语义对齐的物理干预**：

- 身份不变：对可信强度的干预，约束`z_id(T_delta x)`接近`z_id(x)`，并保持不同TX间隔。
- nuisance等变：只对可观测且坐标定义明确的参数，约束`eta(T_delta x) ≈ C_delta(eta(x))`。必须使用真实的参数复合关系；频偏/相位、幅度、时延、信道卷积不都能简单相加。
- 身份必要：替换或破坏身份因子后，模型对原TX的证据应有可解释变化；固定/限制decoder后检查身份分支是否真正承担判别信息。对合成反事实同时做再编码一致性和质量约束，避免网络利用生成伪影作弊。
- 局部敏感性：只有干预不会破坏身份可辨识性时，压低身份表征沿干扰方向的变化；不能要求极端衰落、低信噪比下仍严格恒等，也不能声称恢复不可逆丢失的信息。

不能直接把LEO metadata当作真实receiver硬件参数标签，不能把不同接收机采到的不同载荷波形当成像素级配对真值。真实跨RX优先在身份空间建立约束；只有确认同一物理事件和内容对齐时才考虑波形级交换目标。

“身份不变+nuisance按已知干预变化+身份因子必要”三类证据合起来，比仅增加重构loss更有研究说服力。已有RFFI工作已经研究特征解耦与接收机对抗，泛泛的“解耦+对抗”不能当作新意。[跨接收机RFFI原论文页面](https://arxiv.org/abs/2510.09405)。这里提出的是候选研究方向，尚未做完整新颖性检索或实验验证。

**候选D：以身份梯度为参照的辅助目标调度，作为训练支撑。**

把R3自重构、swap/shared、RC4和DAOT分别监测，针对梯度尺度或冲突采取有界调节。早期先让身份可分性形成，再渐进加强物理和跨域约束；后期保留足够表征学习率，避免辅助路径刚能用、骨干已几乎冻结。它应服务候选A/C，而不是把“自动调权”单独当作论文主贡献。若测不到冲突或缩放后效果不变，则停止增加复杂性。

**候选E：按source困难程度平滑加权，作为后续选项。**

已有目标逐类结果差异很大，例如内部类1的LEO准确率约30%—35%，而部分容易类超过95%。这提示平均分掩盖薄弱身份，但不能据此给目标类1写专用规则。可在source L上利用类别间混淆、每RX风险和样本质量做平滑加权，限制最大权重与最小样本数。避免直接取最难样本或最差小组，否则噪声、异常信号会主导。只有source证据显示稳定困难组时再做，与X5的大幅改变batch组成区分开。

**五、下一轮应如何验证，避免继续堆模块**

建议顺序是：先完成RC4过滤原因和真实加权梯度诊断；然后保留固定底座做候选A；再验证候选B或候选C的最小子项；只组合已经分别有效的项。不要将R3+clean跨RX的收益提前相加，该组合在本报告快照仍未完成。

|建议对照|一次回答的问题|通过条件|
