# 新旧联合路线实施计划与逐项验收

本次只实现、生成配置和执行有界合成验收，不调用实验训练循环，不发布N607任务。原生DR＋完整EG的既有18行主矩阵、R1模板及53项验收保留。新附件包含两份报告、四条方法；分别实现，不叠加成FULL。

## 实施顺序与共同契约

1. 固定原生A1双骨干、DAOT两视图mean/.5/.2、FastTrust H/P、N/anchor关闭、U→身份GRL=0但U训练域头。L/U/V及scratch继承现有契约；200epoch×222接受步、L128/U256、AdamW2e-4/WD1e-4/clip5、κEG=1。新方法统一复用原点实际归一化除数；增强、路由、教师、原型在一个主步内固定。
2. 将新方法配置独立于旧joint配置，运行入口显式解析；默认只解析，不训练。新增场开关只关闭编码器对抗，不关闭域头监督，区别于旧ADV0整项移除对照。
3. CF-EG实现同状态F1/F0两条完整EG轨迹；对原始校正梯度插值，每个β候选从原始AdamW状态独立裁剪/更新。轮换合法L的6TX×5RX×3day监测批，每TX×已激活场景聚合负概率margin；选择最大可行β。保存选中参数和对应矩，教师等只提交一次。H/P仅监测，不进入硬约束。
4. TR-EG保留双方预测，在同样本同增强实际域头输入上拟合SO(d)近单位Procrustes，只输运预测域头首层。独立监测样本计算旋转解释率/域CE恢复；R停止梯度，不改变永久坐标。
5. XT-DANN按合法L轮换互斥TX集合，两边覆盖所有RX/day；临时一步域头内环，域头外层保留二阶链，编码器通过停止参数的对手保留输入梯度。两场重算内环、共享划分，U不参与TX分组。匹配额外L曝光的普通域头对照单列。
6. DRIC使用任务AdamW虚拟参照位移，建立显式非对称B/C与任务漂移，不对GRL做二阶导。额外响应限于身份末端/域头；其余参数保留普通DANN更新。局部新旧风险均在同一普通更新背景上计算，避免将不受局部约束的背景变化计入尾部保证。构造每边最多4维的方向空间、PSD域头曲率、谱阻尼和身份风险半空间＋半径约束，联合求解后直接提交参数位移。矩状态采用唯一普通AdamW提交，任务状态只作虚拟参照；额外位移不冒充梯度。记录局部残差及真实风险违约，不声称全局保证。此处按设计6.1“早期骨干保留原有梯度”修正了最初“其余参数全部任务更新”的不完整表述。
7. DRIC E1–20普通更新，E21–40渐增、每4接受步校正；CF/TR/XT E1–20完整EG，E21起单机制；TR至E60渐增，XT每20步。E80前不增加LEO真实标签保护，尾段遵循原生退火。
8. 生成配对seed392005/6/7主候选、消融、简单解释及等计算预算模板。先机制测试后完整扫描，依赖源域证据的匹配强度/等计算预算参数保持待填，不伪造数值。不启动这些实验。
9. 验收真实模型连接、数学玩具反例、退化等价、梯度权限、冻结状态、异常回滚、配置逐行读回；回归原生53项。独立P0/P1审查一次并修复实质问题。提交、push、核对远端OID。

## 已固定的数值和实现细节

- DRIC：身份`t_proj/f_proj`末端、域对抗头，局部维度各≤4；当前LR白化正等距度量，Q采用PSD投影梯度外积＋近端单位项＋.1平均曲率阻尼；谱最小强单调性1e-4，残差1e-5，半径乘子Newton最多5次。失败回滚后抛错，不静默关机制。
- Lite参照背景固定为非选中参数的普通更新；虚拟task尾部与原尾部在相同背景上比较。正式optimizer矩只提交普通分支一次。E21–40从普通实际位移插值至完整局部候选；完整线性预算只对满强度候选声明，实际过渡风险照常记录。零对抗、空方向及零强度均有退化测试。
- 局部导数采用显式训练场与固定公共随机状态；风险采用固定eval监测。局部重放仅用于白名单内确定性、无buffer内建叶模块，同时检查参数依赖、实际输入及参数版本；真实模型验证输出、梯度、正式状态和随机状态一致。
- FR标签仅作为“相应响应跟踪基线”的内部短名；CGD采用原点、匹配局部参数空间的预条件竞争方程，无DRIC风险/任务参照。这不是全维文献代码复现。RK2/Heun提供完整场求解器参照。
- 108行是完整探索配置覆盖，首轮主候选18行；不预先把所有敏感性/消融同时跑满。模型三seed，其他随机流固定392005，与旧计划一致。
- 统计复用独立评分工具；未做目标反馈、无新数据验证链、无额外审批。旧R1中既有的延后项保留原记录，不包装成已执行。
