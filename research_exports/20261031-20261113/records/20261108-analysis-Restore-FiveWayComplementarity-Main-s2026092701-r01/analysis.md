# 已固定恢复输出的互补性（2026-11-08）

## 样本与方法

原地面 Main 168000 条、同一冻结 Tri-SIG-TIME SSL 默认头，两个测试群体及 clean、六个 practical 视图。读取先前已经完成独立 truth-last 评分的三版 final30 预测，核验所有物理 ID、原始输入、DURA、F0 和预测矩阵后，持共享评分锁计算原受损输入、DURA、JointPrior、ProjectedPriorDetail、MismatchedPrior 的 32 种正确性组合。各群体、各视图的四组 raw／恢复正确性边际均与前一独立三方分析一致；本地独立计算进一步核对了 7 视图 × 4 恢复器 × 4 组合，每视图均 168000 条。

没有训练或加载模型、IQ、新增预测、目标拟合、选模或可部署选路。此结果是已曝光单种子测试的事后描述，并非盲测。代码 commit 9d83bcb97eb4cc904076738e0fb4da63568258ec。

## 五路正确集合的并集

假设不可能实现的真值 oracle：五种固定预测中只要有一种正确即记正确。五路同时错误之外的数量，就是在这五个固定预测中逐样本选择其中一个预测时的正确率上限；该 oracle 不能实际部署。阈值为 140345/168000 = 83.538690%，即距 raw clean 86.538690% 不超过 3 个百分点。

urban 低场景的五路理想并集比门槛多 6188 条正确，但仍有 21467 条五路全错。各预测之间确有互补；这不证明能从 IQ 自动判断哪一路正确，不证明可训练选择器能达到该数，也不证明可以恢复相应物理细节。之前 raw＋DURA 的二路 oracle 上限为 78.640476%；二路上限和五路并集之间的差别反映了更多固定预测的互补性，不是性能增益。

urban 低场景五路中恰有一路正确的条数分别为：原受损 6888、DURA 7968、JointPrior 2080、ProjectedPriorDetail 1209、MismatchedPrior 1404。它们是交叠集合的描述，不作为目标驱动选模依据。通过源域模拟研究多假设生成和连续融合是可测试的方向；正式候选、训练和源域冻结必须在目标评分之前固定，不能使用这里的真值构造规则。

32 格总体计数；每个测试群体和每视图的固定汇总保存在远端 runs 本分析目录，不含逐条预测或 truth。源预测自身来自既有完成实验。
