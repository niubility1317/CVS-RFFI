# DURA GPU 梯度吞吐短测

[计算环境] GPU 上，原 DURA 使用源域 IQ 做临时完整梯度更新，不保存或覆盖权重。每种批量各 3 步，以后 2 步计算稳定吞吐；不包含加载及数据准备。批量 16 为 87.50 条/秒，批量 32 为 162.95 条/秒，约 1.86 倍；峰值 PyTorch 已分配显存分别约 231 MiB 与 343 MiB。

样本分组与批量同时变化，且计时仅两步，其他 GPU 任务也可能影响计时；该结果只说明短测条件下批量 32 吞吐较高，并非严格同样工作量或完整训练提速保证。批量会改变优化轨迹，不保证权重或识别结果不变。模拟信道辅助模型已事前固定批量 32，完整训练 5 轮约 894.2 秒，另准备约 76.3 秒；两项不可直接相除作为提速倍数。

原始证据：[计算环境] runs/20261106-phase1-dura-gradient-speed-source-s2026092701-r01/result.json；无 F、TX 标签、V 或目标读取。
