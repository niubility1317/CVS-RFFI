# 连续缺口源 IQ 先验：GPU 训练

独立初始化 70562 参数的膨胀卷积网络，输入遮挡后的 clean IQ 和 32 点缺口位置，利用 32768 条合法源 L_s/U_s clean IQ 训练 5 轮，batch 64，AdamW；不读取 F、TX 标签、V 或目标。DURA 真权重只用于 8 条源记录的运行检查，不参与先验训练。固定最后一轮，在互斥的 672 条、此前已探索源 pilot 上测试固定随机缺口；GPU 7 训练及 pilot 计算内部计时 30.31 秒，不含初始化与数据读取。

五轮训练损失为 0.4624、0.2637、0.2260、0.2121、0.2035。14 组各 48 条，表中为缺口处 IQ 平方误差除以对应记录整体 clean IQ 能量的均值；模型全部 672 条低于线性插值。按源缓存场景元数据分组，输入仍是 clean 波形，不能解读为星地受损性能。
