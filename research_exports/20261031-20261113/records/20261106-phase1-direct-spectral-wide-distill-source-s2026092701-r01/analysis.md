# 扩展源数据的独立时频学生：GPU 训练

独立初始化的学生仅使用单条 received IQ 推理，训练用合法源 clean IQ 与冻结 DURA 的同记录源波形教师，损失权重 1 与 0.5；无 F、TX 标签、V 或目标读取。固定 32768 条源记录、三个模拟视图、20 轮、batch 32。此前 8192 条、20 轮学生的源 ID 全部包含在新集合；本版曝光与优化步数四倍，结果不能只归因于更多不同记录。

[计算环境] GPU 7 上 20 轮优化 1376.2 秒，读取既有源上下文缓存 0.839 秒、传输 0.225 秒；缓存首次生成 432.1 秒及原 DURA 训练成本另计。真实 checkpoint 源训练 smoke、最终固定权重的 112 条源预测 smoke 均通过。
