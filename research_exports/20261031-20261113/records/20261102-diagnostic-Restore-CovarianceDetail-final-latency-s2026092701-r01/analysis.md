# 冻结最终版恢复器与 Tri-SIG-TIME SSL 的实测延迟

VERIFIED：正式 Main 全部预测和评分完成后，才启动本诊断。使用同一实际 final30 G、原始地面完整 Tri-SIG-TIME SSL 默认头，以及固定 DURA R69 图执行版本。该诊断不计算准确率，不更新模型，也不按时延改选网络。

实测设备为 NVIDIA GeForce RTX 3090，Torch 2.1.0+cu121 / CUDA 12.1，CPU 线程 2，TF32 关闭。GPU 为共享环境；结果只描述本次固定面板和运行条件，不能直接推广为独占设备的延迟保证。

512 条原 Ls/Us 源 IQ 的固定第 1 信道实例面板，不含身份标签。批量 1 使用 25 个固定样本点、每点 4 次；批量 128 使用 4 个固定块、每块 5 次。每条路径、每种批量预热 3 次，五条路径轮换先后次序。共 600 次计时、30 次预热、5 次真实源 2 条样本检查。完整顺序与全部次数核对一致，没有丢弃较慢记录。

中位延迟按每次同步前向计时，包含恢复与识别的实际执行、设备同步及部署路径内部检查；输入已在 GPU。模型加载、文件读取、输入传输、样本选择、首次图捕获、预热及输出后的有限性检查不在计时范围内。DURA 图捕获内部额外前向未计数，因此 6098 是 DURA 的逻辑记录数。新版 G 实际处理 6098 条、F 实际处理 9147 条。

显存计数时三个模型、512 条源输入和全部 DURA 图同时驻留。表中增量峰值是当前路径相对该次前向前分配量的变化；CSV 同时给出全部驻留状态下的峰值。两者都不能解释为单模型独立进程显存。

新版 G 使用 FP32 信道估计与细节网络、FP64 后验求解；DURA 使用固定 47c264/R69、FP32、reuse=True / graph=True / native=False。二者执行路径如实保留；不能把差异解释成纯架构效率结论。旧 F50 配对的 4.531972 ms 不作为本次 Tri-SIG-TIME SSL 测量值。

独立 CPU 复算通过，最大统计误差 0；实际最终权重、冻结状态、真实源检查、GPU worker 独立运行快照及先完成 Main 的顺序均核对。0 次优化、0 TX、0 V/OE/novel/target 输入。性能目标仍由同一 Main 七景报告判定，本报告不宣称目标完成。
