# 交叉半窗自监督 DURA：源域训练

最终五轮权重固定，未按源域或目标成绩选模。冻结 DURA 和从头初始化的多尺度修正网络结合，辅助编码器针对同一条记录的受损与 clean 前后半窗进行交叉自监督；随后冻结编码器对恢复 IQ 与 clean 的同半窗表示施加 0.05 权重约束。辅助编码器只在训练中使用，可能学习报文或接收机特征，并非已证实的 TX 身份表示。

[计算环境] GPU 7，8192 个合法源 fit ID、3 个模拟视图、5 轮、batch 32；源缓存读取 0.257 秒，训练优化 209.4 秒，缓存首次构建、DURA 原训练成本另计。训练无 F 权重或输出、TX 标签、V、目标读取。真实 checkpoint 源训练 smoke 及冻结后的 112 条源记录预测 smoke 通过。
