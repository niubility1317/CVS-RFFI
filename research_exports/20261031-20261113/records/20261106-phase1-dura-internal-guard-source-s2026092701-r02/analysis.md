# DURA 内部优化：源域结果

从来源合规的 DURA E20/4940 加载独立副本，用冻结原 DURA 作为源 IQ 参考。GPU 7、batch32、AdamW 重置（学习率 1e-5、weight decay 0），以 8192 条源 IQ 的三个固定模拟视图继续训练 5 轮；候选 DURA 的物理估计及先验参数可更新。训练不读取 F、TX 标签、V 或目标。源数据准备 65.99 秒，5 轮优化 803.4 秒。

| 源组（每组 48 条） | 原 DURA IQ NMSE | 内部优化版 IQ NMSE |
|---|---:|---:|
| RX8 clean | 0.00003287 | 0.00002773 |
| RX8 低城区 | 0.10067829 | 0.10242646 |
| RX4/6 clean | 0.00004552 | 0.00004299 |
| RX4/6 低城区 | 0.03740450 | 0.04302329 |

两个 clean 组波形误差降低，两个低城区组升高；这是源 IQ 指标，不等于发射机身份准确率。源样本此前被探索且原 DURA 可能见过对应源域，不能称为独立泛化证据。按预登记，固定模型已进入完整 Phase1 七景预测，所有预测完成后独立 truth-last。

r01 仅 source smoke，因原 DURA GPU batch32 预计算与 batch8 重算存在最大 1.43e-6 浮点差异而停止；r02 保持容差并改为同批量比较后通过。r01 未产生训练权重。远端证据：runs/20261106-phase1-dura-internal-guard-source-s2026092701-r02/source_summary.json。
