# 投影修正尖峰的源端网络层追踪

第二次独立临时重放再次在第 11 轮同一逻辑批位置捕获大幅修正：25 次临时更新后，首个 32 条微批有 21 条投影修正 NMSE 超过 100；最大值为 **191.0235**。本次检查最大的异常记录，接收 IQ 范数约为 16.0000，后验基线范数约为 15.6905，基线对同条源 clean 的 NMSE 为 0.004383；细节网络提案范数却达到 **177.0467**。

这条实际提案经投影后范数为 221.1380，是提案的 **1.2490 倍**；该样本的投影算子谱范数为 7.5430。与前一次实际方向缩小的记录共同说明，投影对不同提案方向可以缩小，也可以放大。两次重放的异常条数和数值不同，不能假定它们完全再现原训练中的同一条记录或相同内部状态。

该异常记录的网络层逐元素 RMS：输入卷积 1.2008，三个编码块依次为 1.4424、2.5661、4.8177，首个注意力块为 11.0273，三个解码块依次为 12.2519、16.7176、16.5560，输出修正为 7.8244。各层张量形状不同，RMS 只是幅度描述，没有同批正常样本的配对层级基准，不能据此把根因归给某一个网络层。它确实表明：在该复现实例中，正常量级的接收与后验基线进入细节网络后产生了很大的提案，投影又沿该提案方向放大了约 25%。

由源 clean 能量约 0.5 和投影修正范数独立计算的 NMSE 为 191.02348，与保存值一致。现场 `P × 提案` 与实际修正一致性检查通过；原后验求解残差为 7.22×10⁻¹⁴，细节分支该微批裁剪前梯度范数为 611.8663。梯度是按原逻辑批大小缩放的微批梯度，不直接等于原训练的轮均值。

真实原 E10、原 F0 和两条源样本检查通过。固定源 L_s/U_s、原 draw11、原训练顺序和初始优化器／随机状态；零 TX、V、OE 或目标读取，未修改原训练或保存复现模型。共享 GPU 数值路径可能不同，现有证据不证明原始第 11 轮的精确样本、最终模型质量或 Main 识别收益。原模型继续按既定 final30／七景测试，不因诊断结果改变。
