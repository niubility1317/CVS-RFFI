# 前导重复成分与整包 IQ 的源端识别归因

固定源 V480 的低档城区，原 BF 判对 401 条。只替换 80–159 采样点内的周期一致误差后判对 418 条，只替换窗口外误差后判对 473 条，raw clean 判对 474 条。窗口外两段合计占 IQ 误差能量的 84.84%。

两段合计占 176/256 个采样点。结果定位到这个窗口以外的误差，尚未区分前段与后段，也未分离接收机、信道、时变增益或发射机特征。反事实直接替换为源 clean 的真实误差分量，不能估算部署提升、理论上界或 Main 达标状态。
