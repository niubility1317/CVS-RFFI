# 遮挡教师预计算的配对训练对照

在本机 RTX 5070 Ti、FP32、TF32 关闭和确定性算法下，使用固定源先验与初始恢复网络，对 512 个源 ID 的三个模拟视图运行五轮训练。原路径和 batch 256 教师预计算路径各运行两次，顺序交替。两条路径共享预生成的随机顺序和遮挡；预计算耗时计入对应路径，双方均不计共享日程生成。

| 对照 | 原路径 | 预计算路径 | 逐步损失与最终参数 |
| --- | ---: | ---: | --- |
| 第一次 | 5.500 秒 | 5.406 秒 | 全部逐值一致 |
| 第二次 | 5.187 秒 | 5.266 秒 | 全部逐值一致 |

每次 240 步。两次结果都没有损失或参数差异，但第一对预计算快 0.094 秒，第二对慢 0.079 秒；两次均值各为 5.3435 秒、5.3360 秒，差异约 0.14%。本次没有观测到可重复的整段训练加速；前一项约 8.1 倍仅为单独的短时教师计算，不能推广到训练总时长。

此为有限源数据、本机 GPU 技术对照，并非完整 32768 源 ID 预算或 [计算环境] 的实测。未读取 F、TX 标签、V 或目标，也未保存模型；不推断七景预测一致或识别效果。独立 P0/P1 审查指出预热样本数错误，修复后定向复核通过。当前没有依据把该改动接入正式训练，原运行继续。
