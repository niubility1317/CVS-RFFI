# 源域噪声统计量与 clean 分离度

使用原 DURA 对 672 条固定源 pilot 逐条计算 log10（DURA 估计噪声方差／DURA 输出的实 IQ 均方）。RX4/6 和 RX8 各七景，每组 48 条；源模拟 scene 只作事后分组。没有拟合门控，没有读取 F、TX 标签、V 或目标，也没有更新模型。原 DURA 可能见过对应源域。

两组 clean 的统计量中位数为 -4.010、-3.989，95% 分位数为 -3.975、-3.950。12 个受损场景分组的 5% 分位数均高于 -2.501；逐组将 practical 作为正类时，clean 与受损场景的全配对 AUC 均为 1.000。AUC 表示源样本内统计量排序，不是目标场景的识别准确率，也不保证新数据分离。

该分离为基于当前输入的噪声条件保护提供源域依据：可以在低方差时压低新修正、在较高方差时保留修正，再独立完成正式七景测试。连续门控的具体边界如果使用本 pilot 确定，必须公开承认使用了这批源结果，不能将其称为独立验证，也不保证目标 clean 不受损。

真实 DURA checkpoint GPU smoke 通过，诊断计算约 3.14 秒；远端证据：[计算环境] runs/20261106-phase1-variance-separability-source-s2026092701-r01/result.json。
