# 源域物理后验教师生成

对固定 8192 条合法源 IQ 的三个模拟视图，共 24576 个源视图，使用固定 DURA 估计的信道／噪声和源 IQ 二阶矩计算 160 步相关先验后验；以同条源 clean IQ 在 DURA→后验方向上选取 [0,0.5] 的理想归一化步长，生成训练用教师波形。未读取 F、TX 标签、V 或目标，未更新任何模型。

源拟合样本本身的平均波形 NMSE：DURA 0.023053，理想教师 0.022093，相对减少 4.16%。77.69% 的源视图采用非零正向步长，22.31% 的未截断最优步长为负并被限制为零；这种训练集上的理想选择不是泛化测试。

GPU 后验教师生成 365.3 秒；平均／最大 CG 真实相对残差 0.000231／0.010578，部分样本未达到 1e-4。源缓存首次构建、原 DURA 训练及此前先验拟合等成本另计。

教师波形及每条理想步长依赖该条源 clean，**不能用于目标推理**；只有另行训练、冻结并完成正式测试的学生可部署。教师误差不等于身份识别收益。

远端证据：[计算环境] runs/20261106-phase1-source-posterior-teacher-s2026092701-r01/result.json 和私有 teacher.pt。
