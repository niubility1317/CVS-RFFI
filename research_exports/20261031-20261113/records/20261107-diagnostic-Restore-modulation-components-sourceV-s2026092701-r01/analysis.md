# 接收调制各分量对发射机识别的影响

固定 480 条源 V 的低档城区，原盲估、主路相位、主路复增益、完整主路、完整镜像、双路都已知的 TX 正确数依次为 401／422／423／424／401／424。raw clean 为 474/480。

固定 CovarianceMAP E30 盲估的 FIR 和噪声、原全协方差高斯先验与原 Tri-SIG-TIME SSL 默认头。按上一轮的规范，将真实 FIR 与盲估 FIR 归一化并在内积相位下对齐。主路相位使用真主路相对盲估主路的最小二乘复比例的角度。随后加上同一比例的幅度，再换入真主路完整时变轨迹。镜像路径单独替换真镜像，保持估计主路。两路都替换的对照复用原预测。

再对齐上一版盲相位推断已冻结的 120 条源样本。相对已知主路相位，低档城区绝对角误差均值从不修正的 3.97° 降至 3.63°，60/120 条更接近已知主路相位。该盲估作用于整个算子，已知角度只对齐主路，角误差比较只用于诊断。

这组替换访问的是固定源模拟参数。它用于定位接收调制需要改进的分量，外推以 Main 七景和两个 clean 总体的实际成绩为准。
