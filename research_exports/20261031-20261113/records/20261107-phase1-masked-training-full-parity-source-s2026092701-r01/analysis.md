# 遮挡先验损失精简：全量源训练一致性

固定已有 DURA 源上下文与源域遮挡先验，使用 32768 个合法源物理 ID 的三个模拟视图，按原流程在 [计算环境] CPU 构建 DURA 后重建同一个修正网络初始状态。对原实现和删除未使用插值的精简实现，在本机 RTX 5070 Ti、FP32、TF32 关闭、确定性算法下分别训练五轮，batch32；模型初始参数、源视图顺序、随机遮挡及优化器相同。每条路径先使用 192 个源视图预热一轮。

| 项目 | 结果 |
| --- | --- |
| 更新步骤 | 每条路径 15360 |
| 每步损失 | 全部逐值相同 |
| 每轮损失 | 全部逐值相同 |
| 最终参数 | 22 个张量全部逐值相同，最大差 0 |
| 源输出 | 192 条全部逐值相同 |
| 优化阶段耗时 | 原实现 379.172 秒；精简实现 350.656 秒 |

按该次测量，耗时下降 7.52%，约 1.081 倍；两条路径计时顺序固定、桌面 GPU 共享负载，因此仅为本机一次全量源训练配对结果，不是对 [计算环境] 的受控速度结论。保存的两个最终权重文件经独立重新加载，22 个张量也逐值一致。

对照不读取 F、TX 标签、V 或目标数据；初始化由同代码顺序重建，而非从正在运行的 [计算环境] 进程直接捕获。源样本及 checkpoint 为私有产物，不提交。当前 [计算环境] 训练不受影响；此结果不能证明该进程的训练权重或 168000×7 目标预测逐值一致。
