# 原识别边界上的源端后验不确定性

低档城区在已知模拟算子和标量噪声的同一高斯模型下，剩余 IQ 方差占源先验 17.42%。投影到原 F0 clean 第一与第二名的分数差，剩余方差比例为 20.49%，汇总所有五个竞争类别为 19.90%。

固定原冻结 Tri-SIG-TIME SSL 默认头、源 V120 和既有七景。每个源 clean 固定 F0 原最高分及五个竞争类别。只对 clean IQ 求五个分数差的输入导数，冻结模型所有参数和持久状态。复用已知模拟算子和真实噪声标量路径的恢复 IQ、F0 分数及总体 IQ 后验方差。新增 120 条 clean 前向和 600 条输入方向导数，恢复 IQ 及分数复用 840 条。

令 g 为 clean 分数差的输入梯度，C 为原源高斯先验协方差，L 为 A C Aᵀ + σ² I 的 Cholesky 因子。已知固定模拟信道下，该方向的后验方差是 gᵀ C g − ‖L⁻¹ A C g‖²。表内分数差比例为各方差的和之比，量化局部方向上的波形不确定性。

## 用实际分数变化检查局部近似

低档城区全部分数差实际变化 RMS 为 3.058885，一阶预测相对实际变化的误差 RMS 为 2.833735。实际有 12 条改判，一阶预测 4 条，两者重合 3 条。以 clean 分数差与一个后验标准差比较，5 条进入边界组，其中 3 条实际改判。
逐记录最近边界方差比例的中位数为 11.71%，总和之比受高方差方向影响较大，不能解读为每条记录的边界都比总体 IQ 更难恢复。

投影方差依赖原源高斯先验、缓存模拟信道和在 clean 处求的导数。实际判决还取决于各类别的非线性分数变化。本面板的局部线性读出漏掉多数实际改判，后续若做判别保真训练，评价应保留完整冻结 F0 的前向与实际 TX 配对。这些数值说明这个固定模型下哪些方向仍有不确定性，真实星地信道的信息上界和 TX 准确率仍须另行验证。
