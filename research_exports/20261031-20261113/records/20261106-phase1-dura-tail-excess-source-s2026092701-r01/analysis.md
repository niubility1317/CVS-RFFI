# DURA 源域尾部保护：GPU 训练

固定 DURA、独立初始化多尺度修正；每个 batch 对候选相对 DURA 超额波形 NMSE 的最大四分之一额外赋予 0.5 权重。严格正超额才产生该项梯度，避免初始零超额的不必要梯度；原 DURA guard 不变。该目标不使用 F、TX 标签、V 或目标，也不证明身份保真。

[计算环境] GPU 7，8192 源 fit ID、3 个模拟视图、5 轮、batch 32；源缓存读取 0.224 秒，优化 93.3 秒，缓存首次构建和 DURA 原训练成本另计。真实 checkpoint GPU 源训练 smoke 和固定权重 112 条源记录预测 smoke 均通过；最终五轮权重按预登记冻结，七景预测进行中。
