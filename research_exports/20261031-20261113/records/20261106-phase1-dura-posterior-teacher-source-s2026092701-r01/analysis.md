# 源物理后验教师学生：源训练结果

冻结原 DURA，独立初始化多尺度修正网络，以合法源 IQ、DURA guard 和权重 0.5 的源后验教师波形误差训练。源教师通过同记录 clean 选择理想步长，只用于训练；推理不读取教师、源 clean、步长或后验求解。训练不读取 TX 标签、F 权重或输出、V 或目标，固定 8192 条源 IQ、三个模拟视图和五轮最终 checkpoint。

[计算环境] GPU 7、确定性模式、batch32：读取源上下文与教师耗时 0.409 秒，设备转移 0.105 秒，五轮优化 83.2 秒。教师预生成另需 365.3 秒，源上下文首次构建约 97.9 秒，源先验拟合和原 DURA 训练成本另计。完整推理参数 384013，另含 DURA 物理求解；后验教师的 160 步求解不在推理中。

此前探索过的源 pilot 每组 48 条，候选拟合排除这些记录，但原 DURA 可能见过该源域。下表为波形 NMSE，越低越好；普通保护是同架构、同数据与预算的确定性源训练对照，尚未单独完成该执行版本的正式目标测试。

12 个受损源分组中，学生 11 组平均 NMSE 低于 DURA，但仅 3 组低于普通保护。这里比较的是小样本源波形误差，不代表统计显著或身份识别性能；训练目标损失因教师项而不能与普通保护直接比较。训练和正式推理采用数学等价的确定性／普通插值路径，浮点舍入可能不同。
