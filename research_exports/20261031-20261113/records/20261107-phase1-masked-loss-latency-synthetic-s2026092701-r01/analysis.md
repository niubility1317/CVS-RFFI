# 遮挡先验损失精简：本机 GPU 配对检查

固定真实源 clean IQ 先验 checkpoint，使用一批 32 条固定合成 IQ，不读取实际源／目标 IQ、F、TX、V 或目标真值。原路径为输出和 clean 分别计算遮挡，同时计算未被损失使用的线性插值；新路径复用同一遮挡并省略插值，先验的两次前向保持独立。

本机 RTX 5070 Ti、FP32、TF32 关闭、确定性算法；4 次预热后交替顺序做 20 组同步计时。损失加对输出梯度的中位数：原路径 8.0989 ms，新路径 6.7980 ms，约 1.19 倍，耗时下降约 16.1%。20 组损失及对输出梯度逐值一致，最大梯度绝对差 0。另外三个合成随机输入种子的局部检查也逐值一致。

这是单批合成输入、一个设备和一次共享桌面负载下的训练损失局部测量，不包含完整恢复器前向、权重更新、数据传输或目标预测；不能推断完整训练加速或目标测试逐位一致。运行中的 [计算环境] 实验仍使用其启动时冻结版本，没有热替换。
