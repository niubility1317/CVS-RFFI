# 独立 FIR 学生省略 DURA 的源域检查

对固定的独立 FIR 学生、DURA 和 Tri-SIG-TIME SSL，在 [计算环境] CPU 两线程、batch 8 下，使用 RX4/6、RX8 各七种源视图共 112 条 IQ。原路径计算 DURA 上下文及 raw／anchor／恢复三次分类；快速路径只运行独立学生，并计算 raw／恢复两次分类。每种路径预热一次，逐批交替执行顺序。

112 条源恢复波形、raw logits 和恢复 logits 最大绝对差均为 0；raw／恢复决策与原路径均无差异，原路径 raw／anchor 决策也与固定源 pilot 一致。该探针自身包含有限值检查，计时为原路径 1.7113 秒、快速路径 0.5427 秒，约 3.15 倍；不含模型加载，是共享机器单次短样本结果，不保证完整测试加速比例。

检查仅对已冻结源 IQ 推理，不读取目标或 TX 真值，不训练、选模或改写正在运行的预测。完整七景的原始和恢复 logits、波形未作为原预测产物保存；全量只能逐条核对保存的类别决策。完整无真值重放已独立登记并等待原七景预测全部固定。
