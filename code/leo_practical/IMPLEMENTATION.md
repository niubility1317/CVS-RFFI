## 设计对应

| 设计内容 | 实现位置及边界 |
|---|---|
| 几何、路径损耗、公共多普勒 | channel.py：简化过境或外部状态向量；局部距离线性化；记录几何来源 |
| 仰角/环境三状态 | state_probabilities；按物理状态修正论文公式编号歧义 |
| 有时间单位的状态转移 | transition_matrix与ChannelStream中的精确采样间隔转移概率；混合时间不等于驻留时间 |
| 连续阴影 | 精确离散OU；dB转线性幅度；不逐IQ点独立重抽 |
| 相关散射 | 有限角度射线＋复高斯系数；边际复高斯，近似Jakes谱；公共轨道Doppler不重复作为散射扩展 |
| 多径 | 三条散射径共享指定总功率；LOS仅主径；总期望PDP决定目标RMS延迟；因果分数延迟 |
| 噪声与AGC | 统一无遮挡期望功率标定、固定参考噪声底、加噪后AGC；不按瞬时衰落重设噪声 |
| IQ失衡 | 独立I/Q支路增益及相位公式，纯正交相位误差不退化为公共旋转 |
| pre_sync/post_sync | 相同seed对应同一次生成链；后者在IQ失衡后数字补偿；不双算轨道频偏 |
| 地面/星载接收补偿 | 两套明确命名的配置；IQ解析逆、频偏估计误差和相关相位跟踪残差代理；无测量证据时二者不人为设成不同强度 |
| 定时/均衡扩展 | receiver_processor接收IQ及公开接收参数，不接收真实信道、clean或标签；默认不执行实际定时捕获或多径均衡 |
| session硬件一致性 | receiver_seed和session_id派生，避免每个TX/样本随机分配硬件 |
| 独立记录/连续片段 | batch每记录独立；ChannelStream只用于证明连续的输入 |
| 元数据 | 每记录状态/几何/噪声/CFO/延迟/功率/IQ/AGC/能量指标及配置散列 |
| 采样率缺失 | 配置模板null；API/CLI拒绝未指定采样率，不冒用25MHz |
| 输出形式 | 任意T的原始IQ；没有FFT、补零、配对、标签生成或模型训练 |

## 仍是工程代理的部分

论文是聂欣、米红、武向军：《基于综合信道模型的星地信道性能研究》，航天器工程2012，21(1)：48–52，DOI 10.3969/j.issn.1673-8748.2012.01.008。原文三状态思想被采用，表1的Ka来源天气参数未迁移到S波段，表2历史自然对数参数未作为本实现默认。

LOS默认标准差1dB，因此是轻阴影Loo，严格Rician检查需设置los_std_db第一项为0。状态间参数在转移时直接改变，尚无测量标定的渐变区。默认三状态先验来自GNSS文献，不宣称为LEO实测；散射时延、噪声底、相关尺度、RX误差仍为明确标记的工程启动值。

CTMC在单个局部几何窗口内使用固定仰角先验，不是完整随轨迹变化的半马尔科夫模型。有限射线谱、Lagrange延迟边界、块AGC有明确近似。大气仅提供简化无额外天气和外部已计算衰减接口；标准天气预测、完整轨道传播、绝对链路预算、真实同步器未实现。没有clean混合修复、没有目标标签调参。

补偿代理使用仿真内部真参数加估计误差来构造处理效果，并非盲估计器或已实现PLL。只补偿额外注入的虚拟信道/RX，不能去掉已有地面原记录的全部接收影响。目标识别网络不接收这些真参数；元数据用于独立诊断。外部接收处理接口有意不传输真参数。
